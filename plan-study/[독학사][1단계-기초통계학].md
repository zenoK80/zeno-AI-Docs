# 독학사 1단계 기초통계학

## 범위와 목표

- 위치: `content/독학사/basic_statics/`
- 자료를 정리하고 확률을 계산한 뒤 표본으로 모집단을 추론하는 기본 흐름을 익힌다.
- 계산 결과를 숫자로 끝내지 않고 실제 상황의 말로 해석할 수 있게 한다.

## 작성 기준

- 5~10개의 작은 원자료를 먼저 보여 주고 표·그래프·공식으로 연결한다.
- 모집단과 표본, 모수와 통계량처럼 비슷한 용어를 짧은 표로 비교한다.
- 공식의 기호를 먼저 설명하고 계산 뒤 결과가 뜻하는 바를 한 문장으로 적는다.
- 평균·확률·추정 공식은 MathJax, 분포·변화·자료 비교는 Recharts를 우선 사용한다.
- 확률변수나 분포의 매개변수를 움직이는 실습은 JSXGraph, 표본에서 추론으로 이어지는 단계는 Mermaid 또는 필요한 경우 React Flow로 표현한다.
- 차트에는 제목, 축 이름, 단위와 텍스트 요약을 제공하고 색상만으로 값을 구분하지 않는다.
- 본문 약 5분 뒤 같은 문서의 4지선다 3문제로 복습한다.

## 목차 (16편)

1. `01_population-sample-and-data-types.mdx` — 모집단, 표본과 자료의 종류
2. `02_frequency-tables-and-graphs.mdx` — 도수분포표와 그래프
3. `03_measures-of-center.mdx` — 평균, 중앙값과 최빈값
4. `04_spread-and-relative-position.mdx` — 범위, 분산, 표준편차와 백분위수
5. `05_probability-basics.mdx` — 표본공간, 사건과 확률 법칙
6. `06_conditional-probability-and-bayes.mdx` — 조건부확률, 독립과 베이즈 정리
7. `07_random-variables.mdx` — 확률변수, 기댓값과 분산
8. `08_discrete-distributions.mdx` — 이항, 포아송과 초기하분포
9. `09_normal-distribution.mdx` — 정규분포와 Z점수
10. `10_sampling-distributions.mdx` — 표본평균의 분포와 중심극한정리
11. `11_estimation.mdx` — 점추정과 신뢰구간
12. `12_hypothesis-testing.mdx` — 가설, 유의수준, p값과 오류
13. `13_population-tests.mdx` — 평균과 비율 검정
14. `14_analysis-of-variance.mdx` — 분산분석의 기본 원리
15. `15_correlation-and-regression.mdx` — 상관과 단순회귀
