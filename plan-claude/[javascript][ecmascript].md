# JavaScript — ECMAScript

## 범위와 목표

- 위치: `content/javascript/ECMAscript/`
- JavaScript 코드가 해석되고 값을 계산하는 언어 자체의 규칙을 배운다.
- DOM, `fetch`, `localStorage`처럼 실행 환경이 주는 기능은 Web APIs 계획에서 다룬다.

## 작성 기준

- 실행 가능한 짧은 코드와 예상 결과를 먼저 보여 준다.
- 문법 이름보다 값이 어떻게 바뀌고 왜 그런 결과가 나오는지를 설명한다.
- 초보자가 자주 섞는 `undefined`와 `null`, 원시 값과 객체, 동기와 비동기를 비교한다.
- 세부 내부 알고리즘은 결과를 이해하는 데 필요한 수준까지만 다룬다.
- 본문 약 5분 뒤 같은 문서의 4지선다 3문제로 복습한다.
