# Zeno AI Docs

Next.js + Nextra로 만든 AI 학습 문서 사이트.

인강이나 책을 사지 않고, **이미 결제한 AI 서비스와 API로 학습 자료를 직접 만들어서 공부하는 것**이 목표입니다. 돈은 최대한 안 쓰고 품질은 챙기기.

현재 JavaScript(ECMAScript 35편, Web APIs 30편)와 React(기초·중급·실무 46편). 문서 안에서 코드를 바로 실행하고 퀴즈로 확인합니다.

**https://zeno.it.kr**

## 방법 1 — API 파이프라인

과목 하나를 5단계로 쪼개서 단계마다 잘하는 모델에 맡깁니다.

- **Grok** 대상 독자·목표·범위 정의
- **Perplexity** 웹 검색으로 자료 조사, 목차 설계
- **Claude** 편별 MDX 본문 작성
- **Gemini** 사실 확인, 계산 검산, 퀴즈 정답 검증
- **GPT** 검수 반영과 내용 보강

`실행/작업지시.md`에 과목을 적고 단계별 bat을 실행합니다. 호출 비용은 `costs/`에 자동으로 쌓이고 `비용보고서.bat`으로 집계합니다.

## 방법 2 — Agent

Claude Code나 Codex에게 "3단계 해줘"라고 시킵니다. 구독 요금 안에서 처리되니 API 비용이 안 듭니다.

두 방법은 산출물 경로가 같아서 섞어 씁니다. 호출량이 많은 본문 작성은 Agent로, 검색이 필요한 조사는 API로.

## 구조

```
content/    사이트에 올라가는 MDX. 폴더 구조가 곧 메뉴 구조
prompts/    단계별 AI 지시문 + MDX 문법 규칙
scripts/    파이프라인 실행기, MDX 검사기, 홈 데이터 생성기
실행/       작업지시서와 단계별 bat
```

홈 카드와 문서 수는 `content/`를 스캔해 자동 생성됩니다. MDX는 `node scripts/check-mdx.js content`로 검사하고 `fix-mdx.js`로 교정합니다. 볼드 안 괄호처럼 빌드는 통과하는데 화면만 깨지는 함정이 있어서 만들었습니다.
