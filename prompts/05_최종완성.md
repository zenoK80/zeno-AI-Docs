# 5단계 — 보강·완성 (검수 반영 + 내용 보강)

> 담당: **GPT** (다른 눈으로 읽고 살 붙이는 단계)
> 입력: `prompts/plan/[과목]/03_초안/NN_파일명.mdx` 1편 + `04_검수.md` (+ `00_MDX규칙.md` 전문이 함께 제공됨)
> 산출물: 보강된 최종 MDX (스크립트가 `content/[배치경로]/`에 저장하고 `_meta.js` 생성·빌드까지 수행)
> 다음: 최상위 메뉴 연결·브라우저 확인·커밋은 Claude Code가 수행

## 역할

너는 학습 문서의 마감 편집자다. Claude가 쓴 완성 MDX 한 편을 받아 **더 좋은 최종본**으로 만든다.
같은 글을 처음부터 다시 쓰는 게 아니라, **읽고 → 고치고 → 살 붙이는** 작업이다.

## 해야 할 일 (순서대로)

1. **검수 반영**: 함께 제공되는 `04_검수.md`에서 이 파일에 해당하는 지적을 찾아 반영한다.
   - **심각**(사실 오류·계산 오류·퀴즈 정답 오류)은 반드시 수정
   - **보통·경미**는 타당하면 수정
   - "확인 필요" 항목은 임의로 확정하지 말고 그대로 두되, 본문에 영향 없는 선에서 보수적으로 처리
2. **보강 아이디어 적용**: 이 사이트의 컨셉은 "무조건 깊고 자세히 — 초보자가 읽어도 그 자리에서 전문가"다. 그 기준으로 읽으면서 다음을 찾아 **실제로 추가**한다:
   - 설명이 얇은 개념 → 동기·계산 과정·해석·자주 틀리는 점 보충
   - 있으면 좋을 **새 섹션** (실무 사례, 비교표, 심화 팁, 자주 묻는 질문 등)
   - 비유·생활 예시가 없는 개념 → 추가
   - 글보다 그림이 나은 자리 → mermaid·표·CodePlayground 추가
   - 퀴즈가 안 다루는 핵심 개념 → 퀴즈 추가 (일반 편 5~8개 범위 안에서)
   - 영단어 병기·기호 읽는 법이 빠진 곳 → 채우기
3. **지키면서**:
   - 기존의 좋은 내용을 함부로 삭제·요약하지 않는다. 이 단계는 **추가·개선**이 기본이고, 삭제는 명백한 오류·중복일 때만.
   - 문서가 길어지는 것은 환영이다. 짧게 줄이는 방향의 편집 금지.
   - 함께 제공되는 `00_MDX규칙.md`의 규칙(파일 구조·컴포넌트·금지 규칙)을 전부 준수한다.
   - 맨 아래 `## 참고 자료` 섹션을 유지하고, 보강하며 새로 참고한 자료가 있으면 링크를 추가한다.
4. **출력**: 보강이 끝난 **파일 전체**를 완성본으로 출력한다 (frontmatter부터 참고 자료까지). 코드펜스로 감싸지 않는다. 변경 요약이나 코멘트를 덧붙이지 않는다 — 출력 전체가 그대로 .mdx로 저장된다.

## 이 단계 이후 (참고 — 스크립트·Claude Code 담당)

- 5단계 스크립트가 출력물을 `content/[배치경로]/`에 저장하고, 과목 `_meta.js`를 자동 생성한 뒤 `npm run build`를 실행한다.
- Claude Code가 최상위 `content/_meta.js` 메뉴 연결([guide/menu-structure.md](../guide/menu-structure.md)) + 홈 문서 수 갱신 + 브라우저 표본 확인(볼드 깨짐은 빌드로 안 걸러짐) + 커밋(`docs: 설명`, AI 서명 금지)을 수행한다.
