> 산출물: `content/[카테고리]/[과목]/NN_파일명.mdx` + `_meta.js` 연결 + 빌드 통과 + 커밋

## 작업 절차

1. `04_검수.md`의 지적 사항을 초안에 반영한다. **심각**은 반드시, **보통·경미**는 타당하면 반영. "확인 필요" 항목은 사용자에게 물어본 뒤 진행.
2. 초안을 아래 규칙에 따라 MDX로 변환한다 (파일 구조·컴포넌트 규칙 → MDX 금지 규칙 순서로 적용).
3. `02_목차.md`의 배치 경로에 `content/` 폴더·파일을 생성한다.
4. [guide/menu-structure.md](../guide/menu-structure.md) 절차대로 `_meta.js`를 연결한다 (과목 `_meta.js` 생성 + 상위/최상위 `_meta.js` + 홈 문서 수 갱신).
5. `npm run build`로 빌드 통과를 확인한다. 볼드 렌더링 깨짐은 빌드로 안 걸러지므로 `npm run dev`로 브라우저에서 표본 확인한다.
6. 커밋한다: 메시지 `docs: 설명` 형식, **AI 서명·Co-Authored-By 금지**, 과목 완성 후 즉시 커밋·push.

- frontmatter는 `title`, `description`만.
- 컴포넌트는 전역 등록되어 있으므로 **import 문을 쓰지 않는다** ([guide/tech-stack.md](../guide/tech-stack.md) 참고).

## Quiz 컴포넌트 규칙

```mdx
<Quiz
  questionNumber={1}
  question="문제 내용"
  options={['①보기1', '②보기2', '③보기3', '④보기4']}
  correctAnswer={2}
  explanation="정답 근거와 오답 이유"
  optionExplanations={['오답 이유', '정답 근거', '오답 이유', '오답 이유']}
/>
```

- `correctAnswer`: **1-indexed** 정수 (1~4)
- `question`, `explanation`: **큰따옴표**로 감싼다
- `options`, `optionExplanations` 배열 원소: **작은따옴표**로 감싼다. **원소 안에 작은따옴표 절대 금지** — 내부 따옴표는 제거하거나 문장을 바꾼다
- 해설은 정답 근거와 각 오답이 틀린 이유를 함께 설명

## CodePlayground 규칙

```mdx
<CodePlayground
  template="react"
  activeFile="/App.js"
  showConsole
  label="설명"
  files={{
    '/App.js': `코드...`,
```

- 코드 안에서 JS 템플릿 리터럴이 필요하면 백틱은 `` \` ``, 달러중괄호는 `\${`로 **이스케이프**한다

## MDX 금지 규칙 (어기면 빌드 또는 렌더링이 깨짐)

### 1. JSX prop 배열 원소 안 작은따옴표 금지 (빌드 에러)

```mdx
❌ options={['변수를 'let'으로 선언한다']}
✅ options={['변수를 let으로 선언한다']}
```

### 2. 볼드(`**`) 안에 괄호 금지 (렌더링 깨짐 — 빌드는 통과함)

여닫는 괄호 한 쌍이라도 볼드 안에 있으면 볼드 전체가 `**텍스트**` 그대로 노출된다. 위치 불문.

```mdx
❌ **용어(English)**        ❌ **1단계: 계급(구간) 나누기**
✅ **용어**(English)        ✅ **1단계**: 계급(구간) 나누기
```

### 3. 볼드가 `%`로 끝나고 바로 뒤에 글자가 붙으면 금지 (렌더링 깨짐)

```mdx
❌ 실제로는 **약 8.8%**에 불과합니다.
✅ 실제로는 약 **8.8퍼센트**(8.8%)에 불과합니다.
```

### 4. 표 셀 안 `~`·raw `*` 금지 (빌드 에러)

서로 다른 셀의 `~`가 취소선 쌍으로, 셀 안 `*` 하나가 emphasis로 오인되어 빌드가 깨진다.
범위는 **en dash(`–`)**, 기호 자체는 **백틱 코드 스팬**으로.

```mdx
❌ <tr><td>0~2</td><td>2~4</td></tr>     ✅ <tr><td>0–2</td><td>2–4</td></tr>
❌ <tr><td>*</td><td>0개 이상</td></tr>   ✅ <tr><td>`*`</td><td>0개 이상</td></tr>
```

### 5. JSX prop 안 `<`, `>` 금지 (빌드 에러)

백틱으로 감싸도 소용없다 — prop 문자열 자체가 JSX 파서를 거친다. HTML entity(`&lt;` `&gt;`)를 쓰거나 꺾쇠 없이 표현한다.

```mdx
❌ question="T<string>이란?"           ❌ question="`<h1>제목</h1>`은?"
✅ question="T&lt;string&gt;이란?"     ✅ question="제네릭 T(string)이란?"
```

### 6. 산문(코드블록 밖)에 raw `{`, `}`, `<`, `>` 금지 (빌드 에러)

`{}`는 JSX 표현식으로, `<>`는 태그로 해석된다. 인라인 코드 스팬으로 감싸거나 괄호로 바꾼다.

```mdx
❌ 프로세스 ID는 {pid}로 확인합니다.     ✅ 프로세스 ID는 `{pid}`로 확인합니다.
❌ 0.0.0.0 ~ 255.255.255.255 <클래스 A>  ✅ 0.0.0.0 ~ 255.255.255.255 (클래스 A)
```

### 7. 큰따옴표 prop 안 `\"` 이스케이프 금지 (빌드 에러)

```mdx
❌ explanation="브라우저에서 \"module\" 속성이 필요합니다."
✅ explanation="브라우저에서 module 속성이 필요합니다."
```

### 8. 수식 한 줄에 `\quad`로 여러 계산 금지 (모바일 가로 스크롤)

```mdx
❌ $$\bar{x} = \frac{10+20+30}{3} = 20, \quad \bar{y} = \frac{60+90}{3} = 50$$

✅ $$
   \bar{x} = \frac{10+20+30}{3} = 20
   $$

   $$
   \bar{y} = \frac{60+90}{3} = 50
   $$
```

수식 바로 아래에는 각 변수의 뜻을 항목별로 쓴다 (초안에 이미 있어야 하며, 없으면 보충).
