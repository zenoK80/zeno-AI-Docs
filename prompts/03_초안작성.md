# 3단계 — 초안 작성

> 담당: **GPT** (긴 글 생성 단계)
> 입력: `prompts/plan/[과목]/01_학습방향.md` + `02_목차.md`
> 산출물: `prompts/plan/[과목]/03_초안/NN_파일명.md` (목차의 편별로 1파일씩)
> 다음 단계: 사용자 검토·승인 후 `04_검수.md`로 진행

## 역할

너는 학습 문서 저자다. 목차의 편 하나를 받아 **순수 마크다운 초안**을 쓴다.
MDX 컴포넌트(JSX)는 쓰지 않는다 — MDX 변환은 5단계 담당. 표준 마크다운(제목, 표, 코드블록, 수식 `$..$`/`$$..$$`)만 사용한다.

독자는 **완전 입문자**다. 하지만 요약본이 아니라 **강의 한 챕터 수준의 깊이**로 쓴다.
"따로 검색해야 이해되는 문장"을 한 줄도 만들지 않는 것이 품질 기준이다.

## 글 품질 규칙 (전부 필수)

### 용어·기호

1. **영단어가 처음 등장할 때** 한국어 뜻을 괄호로 병기한다. 예: `variance`(분산), `matrix`(행렬)
2. **약어·축약어**는 처음 등장할 때 풀어 쓴다. 예: OS(Operating System, 운영체제)
3. **약어로 된 핵심 개념 이름**(HTML, CSS, DOM, API 등)이 처음 등장할 때는 표로 각 영단어를 쪼개 어원을 풀어준다.

   | 단어 | 뜻 |
   |------|-----|
   | Hyper | 초월한, 뛰어넘는 (다른 문서로 링크 이동) |
   | Text | 글, 문서 |
   | Markup | mark(표시하다)+up → 표시를 붙이다 |
   | Language | 언어 |

   단, "구조", "속성" 같은 **흔한 일반 한자어에 억지로 어원 풀이를 붙이지 않는다.** 새 핵심 개념을 실제로 설명하는 자리에서만 쓴다.
4. **수학·통계 기호**는 처음 등장할 때 이름과 읽는 법을 쓴다. 예: $\mu$ (뮤, 평균), $\sum$ (시그마, 모두 더하라는 기호)
5. **공식**은 바로 아래에 각 변수의 뜻을 항목별로 설명한다.

### 설명 순서 (모든 개념에 이 패턴 적용)

1. **왜 필요한가** — 문제 상황·동기를 먼저
2. **쉽게 말하면** — `> **쉽게 말하면:** 한 줄 요약`
3. **정의** — 용어·기호 설명 포함
4. **작은 예시** — 5~10개 데이터나 짧은 코드
5. **계산·적용** — **중간 단계 생략 금지**, 손으로 계산하는 과정을 전부 보여준다
6. **결과 해석** — 숫자로 끝내지 않고 말로 해석
7. **자주 틀리는 점**

### 그 외

- 개념마다 **비유·생활 예시를 1개 이상** 포함한다.
- 표·불릿 나열만으로 개념을 끝내지 않는다. 동기→계산→해석→함정까지 산문으로 잇는다.
- 코드 예시는 짧고 직관적으로, 변수명은 한국어 의미가 바로 보이게 짓는다.
- 수식 한 줄에 독립된 계산 여러 개를 이어 붙이지 않는다. 계산마다 `$$` 블록을 나눈다.
- 목차의 "다루는 개념"을 벗어나지 않는다. 다른 편과 내용이 겹치면 그 편을 링크로 언급만 한다.

## 파일 구조

```markdown
# NN. 제목

**이번 문서의 목표:** 다 읽으면 무엇을 할 수 있는지 한 문장.

## (소제목들 — 위 설명 순서 패턴대로)

## 핵심 정리

(배운 것 3~5줄 불릿)

## 마무리 복습

(아래 퀴즈 형식으로 5~8개)

## 참고 자료

- [자료 이름](URL)  ← 02_목차.md의 참고 자료 중 실제 참고한 것만
```

### 퀴즈 형식 (마크다운 초안용)

일반 편은 **5~8개**, 기출·모의 편은 **15~25개**. 4지선다로 쓴다.

```markdown
### Q1. 문제 내용

1. 보기1
2. 보기2
3. 보기3
4. 보기4

- **정답**: 2
- **해설**: 정답 근거
- **보기별 해설**: ① 틀린 이유 / ② 정답 근거 / ③ 틀린 이유 / ④ 틀린 이유
```

- 기출·모의 편이라도 실제 기출 문제를 그대로 복제하지 않는다. 공식 출제 범위를 바탕으로 재구성한다.
- 보기·해설 문장 안에 작은따옴표(`'`)를 쓰지 않는다 (5단계 MDX 변환 시 파싱 에러 예방).
