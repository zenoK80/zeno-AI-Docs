## POST는 Windows 이전의 점검이다

전원을 켜면 펌웨어가 CPU, 메모리, 그래픽 출력, 저장장치 같은 기본 하드웨어를 확인한다. 이 과정을 POST(Power-On Self-Test)라고 한다. 이 단계가 끝나야 BIOS/UEFI가 부팅 장치를 고르고 Windows가 시작된다.

```txt
전원 -> POST -> BIOS/UEFI -> 부팅 장치 -> Windows
```

## 증상으로 범위 좁히기

| 증상 | 우선 확인할 곳 |
| --- | --- |
| 전원 LED와 팬이 모두 반응 없음 | 전원 케이블, 파워, 멀티탭 |
| 팬은 돌지만 화면이 없음 | 모니터 입력, 케이블, 메모리, 그래픽 출력 |
| BIOS 화면은 나오지만 부팅 장치 오류 | 저장장치 인식, 부팅 순서 |
| Windows 로고 뒤 멈춤 | 복구 환경, 드라이버, 업데이트 |

## 점검 원칙

전원을 끈 뒤 케이블과 주변기기부터 확인하고, 한 번에 하나의 조건만 바꾼다. 메모리와 그래픽 카드를 동시에 분리했다면 무엇이 원인이었는지 알 수 없다.

<Callout type="important">
비프음과 LED 패턴은 메인보드 제조사마다 의미가 다르다. 소리 자체를 외우기보다 제조사 매뉴얼을 확인하는 습관이 안전하다.
</Callout>

## 이번 편 정리

- POST 이전 문제와 Windows 이후 문제는 점검 도구가 다르다.
- 증상이 시작된 단계를 찾으면 원인 후보를 줄일 수 있다.
- 다음 편에서는 CPU, 메모리, 메인보드의 역할과 기본 점검을 다룬다.
