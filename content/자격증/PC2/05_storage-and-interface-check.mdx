## 저장장치가 보이지 않을 때

저장장치는 운영체제와 파일을 보관한다. BIOS/UEFI에서 장치가 보이는지, Windows에서 파티션과 드라이브 문자가 보이는지에 따라 문제 단계가 달라진다.

| 종류 | 연결 방식 | 주로 확인할 곳 |
| --- | --- | --- |
| SATA SSD/HDD | 데이터 케이블과 전원 케이블 | 케이블, SATA 포트, BIOS 목록 |
| NVMe SSD | 메인보드 M.2 슬롯 | 슬롯 호환성, BIOS 목록, 디스크 관리 |

## BIOS와 Windows를 나누어 확인하기

1. BIOS/UEFI에서 저장장치 모델명이 보이는지 확인한다.
2. 보이지 않으면 케이블·포트·장착·슬롯 호환성을 확인한다.
3. BIOS에는 보이지만 Windows 탐색기에 없으면 디스크 관리를 확인한다.
4. 디스크 관리에서 초기화·포맷은 데이터 손실 가능성을 확인한 뒤에만 한다.

```txt
BIOS에서 안 보임 -> 하드웨어·연결 단계
BIOS에는 보임, 탐색기에서 안 보임 -> Windows 파티션·드라이브 문자 단계
```

## 직접 확인하기

`Win + X`에서 **디스크 관리**를 열고 디스크 번호, 파티션, 드라이브 문자를 읽어 보자. 이 단계에서는 어떤 항목도 변경하지 않는다.

## 이번 편 정리

- SATA는 케이블, NVMe는 M.2 슬롯 연결을 주로 확인한다.
- BIOS/UEFI와 Windows에서 보이는지에 따라 원인 범위를 나눈다.
- 다음 편부터 BIOS/UEFI 설정을 직접 읽고 변경 기준을 익힌다.
