## 이번 편의 목표
- CPU, 메모리, 메인보드의 역할을 구분한다.
- 소켓, 세대, 메모리 규격 등 호환성 조건을 확인한다.
- 화면 없음과 불안정 증상을 최소 구성으로 진단한다.

## 먼저 알아둘 말

| 용어 | 쉬운 뜻 |
| --- | --- |
| CPU | 프로그램의 명령을 해석하고 계산하는 핵심 처리 장치 |
| 소켓 | CPU를 메인보드에 물리적·전기적으로 연결하는 자리 |
| 칩셋 | 메인보드에서 장치 연결과 기능 구성을 지원하는 제어 구조 |
| RAM | 실행 중인 프로그램과 데이터를 잠시 보관하는 빠른 메모리 |
| DIMM | 데스크톱용 메모리 모듈의 대표적인 물리 규격 |
| 메모리 채널 | CPU와 메모리가 데이터를 주고받는 통로 |
| 방열판 | CPU 열을 넓게 퍼뜨려 식히는 금속 부품 |
| 서멀 페이스트 | CPU와 방열판 사이의 미세한 틈을 채워 열 전달을 돕는 물질 |

부품 이름이 맞는 것만으로 호환되는 것은 아니다. 물리 규격, 지원 세대, 전력, 펌웨어 지원을 순서대로 확인해야 한다.

## 주변 개념 지도

CPU가 명령을 처리하려면 RAM에서 데이터를 읽어야 하고, 메인보드는 두 부품에 전원과 통신 경로를 제공한다. 셋 중 하나의 장착이나 호환 문제가 POST 실패와 불안정 증상으로 이어질 수 있다.

<Callout type="info">
메인보드 고장으로 결론 내리기 전에 전원, 장착 상태, 최소 구성, 호환 부품 교차 점검으로 다른 원인을 먼저 제외한다.
</Callout>

## 세 부품의 관계

| 부품 | 역할 | 점검 관점 |
| --- | --- | --- |
| CPU | 명령을 실행하고 연산한다. | 소켓, 전원, 냉각, 핀 상태 |
| RAM | 실행 중인 코드와 데이터를 임시 저장한다. | 규격, 슬롯, 장착, 모듈 불량 |
| 메인보드 | 부품을 연결하고 전원·통신 경로를 제공한다. | 전원 커넥터, 펌웨어, 슬롯, 진단 표시 |

부품의 규격이 맞는 것과 정상 동작하는 것은 다르다. 같은 소켓이어도 BIOS/UEFI 버전이 해당 CPU 세대를 지원하지 않을 수 있다.

## 호환성 확인 순서

1. 메인보드 정확한 모델과 리비전을 확인한다.
2. 제조사 CPU 지원 목록과 필요한 BIOS 버전을 확인한다.
3. 메모리 세대, 용량, 속도, 슬롯 구성을 확인한다.
4. 파워서플라이의 메인 24핀과 CPU 보조 전원 연결을 확인한다.
5. 쿨러 장착과 팬 연결 상태를 확인한다.

<Callout type="warning">
CPU 소켓과 핀을 힘으로 누르지 않는다. 방향 표시를 확인하고, 손상된 핀은 전원을 넣기 전에 제조사 서비스 절차를 따른다.
</Callout>

## 메모리 진단

전원은 들어오지만 DRAM 진단 LED가 켜져 있다면 다음 순서로 확인한다.

1. 전원을 분리하고 ESD 안전을 확보한다.
2. 설명서가 권장하는 단일 모듈 슬롯을 확인한다.
3. 메모리 한 개만 정확히 재장착한다.
4. POST 여부를 확인한다.
5. 같은 모듈을 다른 슬롯, 다른 모듈을 같은 슬롯에 하나씩 시험한다.

이 교차 점검으로 모듈 문제와 슬롯 문제를 구분할 수 있다. 운영체제까지 부팅된다면 Windows 메모리 진단 등으로 추가 검사한다.

## CPU와 냉각 점검

부팅 직후 꺼지거나 온도가 빠르게 오르면 쿨러 장착, 팬 연결, 서멀 인터페이스를 확인한다. 쿨러를 분리했다면 기존 서멀 재료를 제조사 지침에 맞게 정리하고 적절히 다시 적용한다.

CPU 보조 전원 커넥터를 그래픽카드용 PCIe 전원과 혼동하지 않는다. 모양이 비슷해도 핀 배열과 용도가 다르다.

## 메인보드 판단은 마지막에

메인보드 불량은 다른 부품과 전원 문제를 배제한 뒤 판단한다.

- 전원 커넥터와 케이블 정상
- 지원되는 CPU와 메모리 사용
- 최소 구성에서도 동일 증상
- 다른 정상 부품으로 교차 점검
- 소켓·슬롯에 물리적 손상 확인

이 근거 없이 보드를 교체하면 비용만 늘고 원인이 남을 수 있다.

CPU·RAM·메인보드 문제는 호환성과 장착 상태를 먼저 확인하고 최소 구성과 교차 점검으로 좁힌다. 메인보드 교체 판단은 전원과 다른 부품을 배제한 뒤 내려야 한다.
