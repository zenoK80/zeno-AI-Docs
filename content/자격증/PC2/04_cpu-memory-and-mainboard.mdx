## 세 부품은 서로 다른 일을 한다

| 부품 | 역할 | 문제가 생겼을 때 보일 수 있는 증상 |
| --- | --- | --- |
| CPU | 명령을 처리 | 부팅 불가, 과열, 심한 성능 저하 |
| 메모리(RAM) | 실행 중인 데이터를 임시 보관 | 화면 미출력, 불안정, 블루스크린 |
| 메인보드 | 부품을 연결하고 전원을 분배 | 장치 미인식, 슬롯·포트 문제 |

CPU와 메모리는 메인보드 위에서 함께 동작한다. 따라서 “메모리가 인식되지 않는다”는 문제는 메모리 자체, 슬롯, 장착 상태, 펌웨어 설정을 모두 확인해야 한다.

## 안전한 확인 순서

1. Windows 시스템 정보에서 설치된 메모리 용량을 확인한다.
2. BIOS/UEFI에서도 같은 용량이 보이는지 확인한다.
3. 실제 장착 작업이 필요하면 전원을 끄고 케이블을 뽑은 뒤 정전기 방지에 주의한다.
4. 한 개의 메모리와 한 개의 슬롯씩 바꾸어 원인을 분리한다.

<Callout type="warning">
CPU 쿨러를 분리하거나 CPU를 재장착하는 작업은 손상 위험이 크다. 단순 인식 문제에서 가장 먼저 할 작업이 아니다.
</Callout>

## 이번 편 정리

- CPU는 처리, 메모리는 임시 저장, 메인보드는 연결과 제어를 맡는다.
- 인식 문제는 부품·슬롯·장착·설정을 분리해 확인한다.
- 다음 편에서는 부팅 장치와 연결되는 SATA, NVMe 저장장치를 다룬다.
