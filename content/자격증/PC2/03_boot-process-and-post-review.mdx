## 복습 방법

증상만 보고 부품부터 고르지 않는다. 네 선택지에서 가장 안전하고 진단 순서에 맞는 조치를 선택한 뒤 해설을 확인한다.

<Callout type="warning">
실제 장비 작업 전에는 전원과 데이터 손실 위험을 확인한다. 전원공급장치 내부처럼 고전압 위험이 있는 부분은 교육 없이 분해하지 않는다.
</Callout>

## 4지선다 문제

### 문제 1

부팅 과정의 자연스러운 순서는?

① 전원 및 하드웨어 초기화 → POST → 부팅 장치 선택 → 부트로더 → 운영체제

② 운영체제 → POST → 전원 → CPU 장착

③ 로그인 → 전원 → UEFI → POST

④ 부트로더 → 케이블 연결 → 전원 제거

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

전원이 들어오면 펌웨어가 하드웨어를 초기화하고 POST한 뒤 부팅 장치의 부트로더가 운영체제를 시작한다.

- **①** 정답이다.
- **②** 운영체제가 POST보다 먼저 실행될 수 없다.
- **③** 로그인은 운영체제 시작 뒤다.
- **④** 순서와 동작이 맞지 않는다.

</Collapse>

### 문제 2

팬은 돌지만 화면과 POST 신호가 전혀 없다. 우선 확인할 범위는?

① 전원 연결, 메모리·그래픽 장착, 진단 LED나 비프 코드

② 문서 편집기 설정

③ 인터넷 브라우저 쿠키만

④ 운영체제 바탕화면 색상

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

운영체제 이전 POST 단계에서 멈춘 가능성이 커서 기본 하드웨어와 전원 신호부터 본다.

- **①** 정답이다.
- **②** 운영체제 이후 응용 프로그램 영역이다.
- **③** 화면이 나오기 전 단계와 무관하다.
- **④** 운영체제가 시작되지 않은 상태에서 확인할 수 없다.

</Collapse>

### 문제 3

UEFI 화면에서 저장장치는 보이지만 운영체제가 시작되지 않는다. 다음 확인으로 가장 적절한 것은?

① 부팅 순서와 부트로더 상태

② 모니터 포장 상자

③ 키보드 색상

④ CPU를 즉시 폐기

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

펌웨어가 장치를 인식했으므로 다음 단계인 부팅 대상 선택과 부트로더를 확인한다.

- **①** 정답이다.
- **②** 부팅 논리와 무관하다.
- **③** 문제 원인이 아니다.
- **④** 진단 없이 폐기하면 안 된다.

</Collapse>

### 문제 4

비프 코드 해석 시 주의할 점은?

① 모든 제조사와 보드에서 의미가 완전히 같다.

② 메인보드 또는 펌웨어 제조사의 설명서를 확인한다.

③ 소리는 항상 운영체제 오류만 뜻한다.

④ 비프음은 기록할 필요가 없다.

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

비프 패턴의 의미는 제조사와 펌웨어에 따라 다를 수 있으므로 공식 매뉴얼을 확인한다.

- **①** 표준이 완전히 같지 않다.
- **②** 정답이다.
- **③** POST 단계의 하드웨어 진단 신호다.
- **④** 패턴과 횟수를 기록해야 한다.

</Collapse>

### 문제 5

CMOS 초기화를 먼저 시도하면 안 되는 이유는?

① 원인과 무관할 수 있고 사용자 설정을 잃을 수 있어서

② 항상 CPU 속도가 두 배가 되어서

③ 모든 파일이 자동 백업되어서

④ 모니터가 새것으로 바뀌어서

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

초기화는 설정 문제를 의심할 근거가 있을 때 절차를 확인해 사용하며 기존 설정을 기록해야 한다.

- **①** 정답이다.
- **②** 그런 효과는 없다.
- **③** 백업 기능이 아니다.
- **④** 하드웨어 교체 기능이 아니다.

</Collapse>

## 직접 적용하기

‘제조사 로고는 나오지만 No bootable device가 표시된다’는 상황의 진단 순서를 작성하자.

<Collapse title="풀이 및 검증 보기">

POST와 화면 출력은 통과했으므로 UEFI에서 저장장치가 인식되는지 확인한다. 인식되면 부팅 순서와 UEFI/Legacy 모드, 부트로더 상태를 확인한다. 인식되지 않으면 전원을 차단한 뒤 저장장치 연결과 슬롯 호환성을 점검한다. 각 조치 후 장치 목록과 오류 문구가 달라졌는지 기록한다.

</Collapse>

## 결과 점검

- 5개 정답: 조치 순서와 안전 이유를 함께 말해 본다.
- 3~4개 정답: 틀린 문제의 용어와 진단 단계를 본편에서 다시 확인한다.
- 0~2개 정답: 용어표와 사례 진단을 다시 읽고 재도전한다.
