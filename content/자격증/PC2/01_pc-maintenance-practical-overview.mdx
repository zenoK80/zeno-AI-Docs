## 이 문서의 목표

PC정비사 2급 실기는 설정 창을 많이 아는지보다, 증상을 보고 점검 순서를 정할 수 있는지를 다룬다. 이 편에서는 PC 문제가 어느 단계에서 생겼는지 나누고, Windows에서 현재 상태를 읽는 방법을 먼저 익힌다.

핵심 질문은 단순하다.

```txt
문제는 전원이 켜지기 전인가?
펌웨어가 장치를 찾는 단계인가?
Windows가 시작되는 단계인가?
Windows가 켜진 뒤의 설정·장치 문제인가?
```

이 질문에 답하면, 무작정 재설치하거나 BIOS 설정을 바꾸는 위험한 행동을 피할 수 있다.

## 부팅 과정으로 증상을 나누기

```txt
전원 공급 -> POST -> BIOS/UEFI 장치 확인 -> 부팅 장치 선택 -> Windows 로드 -> 로그인 후 사용
```

| 증상 | 먼저 의심할 단계 | 첫 확인 |
| --- | --- | --- |
| 전원 LED도 켜지지 않음 | 전원 공급 | 전원 케이블, 멀티탭, 파워 스위치 |
| 전원은 켜지지만 화면이 없음 | POST·하드웨어 | 모니터 연결, 메모리, 그래픽 출력 |
| 저장장치를 찾지 못함 | BIOS/UEFI | SSD·HDD 인식, 부팅 우선순위 |
| Windows 로고에서 멈춤 | Windows 부팅 | 복구 옵션, 최근 드라이버·업데이트 |
| 로그인 뒤 장치가 동작하지 않음 | Windows 설정·드라이버 | 장치 관리자, 이벤트 뷰어 |

<Callout type="important">
증상 하나에 원인이 하나라고 단정하지 않는다. 다만 문제가 시작된 단계를 찾으면 확인할 후보를 줄일 수 있다. 이것이 정비 문제의 가장 중요한 첫 단계다.
</Callout>

## BIOS/UEFI와 Windows는 하는 일이 다르다

BIOS/UEFI는 Windows보다 먼저 실행되는 펌웨어다. CPU, 메모리, 저장장치 같은 기본 하드웨어를 확인하고 어떤 장치로 부팅할지 정한다. 반면 Windows는 사용자 계정, 드라이버, 네트워크, 파일, 보안 설정을 관리한다.

예를 들어 SSD가 BIOS/UEFI 목록에는 보이지만 Windows 탐색기에는 보이지 않는다면, 케이블 불량보다 파티션이나 드라이브 문자 같은 Windows 단계의 문제일 수 있다. 반대로 BIOS/UEFI에서 SSD 자체가 보이지 않는다면 Windows 설정을 먼저 만질 이유가 없다.

## 첫 진단 과제: 내 PC 상태를 읽기

다음 작업은 설정을 바꾸지 않고 정보를 확인하는 안전한 연습이다.

<Steps>
### 시스템 정보를 확인한다

`Win + R`을 누르고 `msinfo32`를 실행한다. 운영체제 이름, BIOS 모드(UEFI 또는 레거시), 설치된 메모리, BIOS 버전을 찾는다.

### 장치 관리자를 확인한다

시작 메뉴에서 장치 관리자를 열고 노란 느낌표 또는 알 수 없는 장치가 있는지 본다. 발견했다면 장치 이름과 상태 메시지를 기록한다.

### 디스크와 부팅 관련 정보를 확인한다

파일 탐색기에서 드라이브 용량을 보고, `Win + X`에서 디스크 관리를 연다. 디스크와 파티션이 어떻게 나뉘어 있는지 확인만 한다. 삭제·포맷·크기 조절은 하지 않는다.

### 네트워크 상태를 확인한다

명령 프롬프트에서 아래를 실행한다.

```bat
ipconfig /all
```

IPv4 주소, 기본 게이트웨이, DNS 서버가 어디에 표시되는지 찾는다. PC정비에서는 하드웨어와 Windows뿐 아니라 기본 네트워크 설정도 함께 점검한다.
</Steps>

## 실제 작업 문제를 푸는 순서

실기에서는 목표를 먼저 읽고, 현재 상태를 확인한 뒤, 필요한 설정만 바꾸고, 결과를 검증해야 한다.

```txt
문제 요구 확인 -> 현재 상태 확인 -> 설정 변경 -> 결과 검증 -> 문제 조건 재대조
```

예를 들어 “부팅 순서를 USB가 먼저 오도록 설정하라”는 문제라면, BIOS/UEFI에서 부팅 메뉴를 찾고 USB 장치를 선택한 뒤 저장·재부팅 여부를 확인한다. 메뉴 이름은 제조사마다 달라도 목표와 검증 방식은 같다.

## 최근 환경을 공부에 반영하기

최근 ICQA 실기 공지는 PC정비사 환경을 Windows 10과 Windows 11로 안내한다. Windows 11에서는 UEFI, Secure Boot, TPM 같은 항목이 더 자주 연결된다. 다만 실제 시험 시간과 장비 구성은 회차별 공지를 최종 기준으로 삼아야 한다.

## 흔한 실수

- 문제가 생기자마자 Windows 초기화나 재설치를 선택하기
- BIOS/UEFI와 Windows 설정의 위치를 혼동하기
- 장치 관리자 오류를 무조건 드라이버 재설치로 해결하려 하기
- 제조사마다 다른 BIOS 메뉴 이름을 외워서 적용하기
- 데이터가 있는 디스크를 확인 없이 초기화·포맷하기

## 이번 편 정리

- PC정비는 증상이 나타난 부팅 단계를 먼저 찾는 일이다.
- BIOS/UEFI는 부팅 전 하드웨어와 부팅 장치, Windows는 운영체제와 장치·계정을 관리한다.
- `msinfo32`, 장치 관리자, 디스크 관리, `ipconfig /all`은 안전한 첫 진단 도구다.
- 다음 편에서는 실습 환경과 작업 전 안전 수칙을 구체적으로 준비한다.
