## 복습 방법

증상만 보고 부품부터 고르지 않는다. 네 선택지에서 가장 안전하고 진단 순서에 맞는 조치를 선택한 뒤 해설을 확인한다.

<Callout type="warning">
실제 장비 작업 전에는 전원과 데이터 손실 위험을 확인한다. 전원공급장치 내부처럼 고전압 위험이 있는 부분은 교육 없이 분해하지 않는다.
</Callout>

## 4지선다 문제

### 문제 1

M.2와 NVMe의 관계를 가장 정확히 설명한 것은?

① M.2는 물리 형태, NVMe는 주로 PCIe를 사용하는 저장장치 통신 규격이다.

② 둘은 언제나 완전히 같은 뜻이다.

③ M.2는 운영체제이고 NVMe는 CPU다.

④ NVMe는 케이블 색상이다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

M.2 슬롯에는 NVMe뿐 아니라 조건에 따라 SATA 방식 장치도 있으므로 형태와 프로토콜을 구분해야 한다.

- **①** 정답이다.
- **②** M.2 SATA가 있어 항상 같지 않다.
- **③** 둘 다 저장장치 관련 규격이다.
- **④** 색상 규칙이 아니다.

</Collapse>

### 문제 2

SATA 저장장치가 인식되지 않을 때 물리 단계에서 확인할 것은?

① SATA 데이터 케이블과 전원 케이블 연결

② 웹 브라우저 방문 기록

③ 모니터 밝기

④ 프린터 용지

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

SATA 장치는 통신용 데이터 케이블과 전원 연결이 모두 필요하다.

- **①** 정답이다.
- **②** 저장장치 연결과 무관하다.
- **③** 화면 설정이다.
- **④** 프린터 소모품이다.

</Collapse>

### 문제 3

UEFI/BIOS에서 저장장치가 보이지 않는다. 우선 범위는?

① 물리 연결, 슬롯 지원 규격, 펌웨어 설정

② 운영체제 드라이브 문자만

③ 문서 파일 이름만

④ 사용자 계정 배경화면

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

펌웨어 단계에서 보이지 않으면 운영체제보다 앞선 연결·호환·펌웨어 인식부터 확인한다.

- **①** 정답이다.
- **②** 운영체제도 장치를 받지 못했을 가능성이 크다.
- **③** 인식 단계와 무관하다.
- **④** 개인 설정이다.

</Collapse>

### 문제 4

S.M.A.R.T. 경고와 반복 읽기 오류가 나타났다. 가장 적절한 조치는?

① 중요 데이터를 우선 백업하고 장치 상태를 추가 진단한다.

② 성능 시험을 무한 반복한다.

③ 경고 기록을 삭제하고 계속 사용한다.

④ 전원이 켜진 채 케이블을 뽑는다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

고장 가능성이 있으므로 추가 부하보다 데이터 보호가 먼저다.

- **①** 정답이다.
- **②** 장치 상태를 악화시킬 수 있다.
- **③** 위험 신호를 숨길 뿐이다.
- **④** 손상과 안전 위험이 있다.

</Collapse>

### 문제 5

저장장치 인식 진단 순서로 가장 적절한 것은?

① 물리 연결 → UEFI/BIOS 인식 → 운영체제 장치 인식 → 파티션·파일 시스템

② 드라이브 문자 → 케이블 → 전원

③ 포맷 → 백업 → 상태 확인

④ 파일 삭제 → 장치 구매 → 증상 확인

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

아래 단계는 위 단계가 장치를 넘겨줘야 동작하므로 바깥에서 안쪽 순서로 확인한다.

- **①** 정답이다.
- **②** 운영체제 결과부터 보면 앞 단계 실패를 놓친다.
- **③** 백업보다 포맷을 먼저 하면 데이터가 손실된다.
- **④** 진단 순서가 거꾸로다.

</Collapse>

## 직접 적용하기

새 M.2 SSD를 장착했지만 파일 탐색기에 나타나지 않는다. 데이터 손실 없이 확인할 네 단계를 작성하자.

<Collapse title="풀이 및 검증 보기">

먼저 메인보드 매뉴얼에서 슬롯이 장치의 M.2 SATA 또는 NVMe 규격을 지원하는지 확인하고 안전하게 재장착한다. UEFI/BIOS 장치 목록을 확인한다. 운영체제의 장치 관리자와 디스크 관리에서 인식 여부를 본다. 새 빈 디스크라면 파티션과 파일 시스템이 없는지 확인한 뒤 목적에 맞게 초기화하지만, 기존 데이터가 있는 장치는 포맷하지 말고 백업·복구 가능성을 먼저 검토한다.

</Collapse>

## 결과 점검

- 5개 정답: 조치 순서와 안전 이유를 함께 말해 본다.
- 3~4개 정답: 틀린 문제의 용어와 진단 단계를 본편에서 다시 확인한다.
- 0~2개 정답: 용어표와 사례 진단을 다시 읽고 재도전한다.
