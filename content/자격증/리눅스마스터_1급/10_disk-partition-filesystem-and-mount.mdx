## 블록 장치와 장치명

리눅스에서 디스크는 /dev/ 디렉터리 아래의 장치 파일로 표현됩니다.

| 장치명 예시 | 설명 |
|-----------|------|
| /dev/sda | 첫 번째 SATA/SAS/USB 디스크 |
| /dev/sdb | 두 번째 SATA/SAS 디스크 |
| /dev/sda1 | /dev/sda의 첫 번째 파티션 |
| /dev/sda2 | /dev/sda의 두 번째 파티션 |
| /dev/nvme0n1 | 첫 번째 NVMe SSD |
| /dev/nvme0n1p1 | NVMe SSD의 첫 번째 파티션 |

```bash
# 현재 블록 장치 트리 확인
lsblk

# 출력 예시
NAME        MAJ:MIN RM   SIZE RO TYPE MOUNTPOINT
sda           8:0    0   100G  0 disk
├─sda1        8:1    0     1G  0 part /boot
├─sda2        8:2    0    20G  0 part /
└─sda3        8:3    0    79G  0 part /home
sdb           8:16   0   500G  0 disk
nvme0n1     259:0    0   256G  0 disk
└─nvme0n1p1 259:1    0   256G  0 part /data
```

## 파티션 생성: fdisk vs gdisk

### fdisk (MBR 파티션 테이블)

- MBR 방식: 디스크 크기 **최대 2TB** 지원
- 기본 파티션 **최대 4개** (기본 파티션 3개 + 확장 파티션 1개 → 논리 파티션 추가 가능)
- 2TB 이하 디스크에 적합

```bash
# fdisk로 /dev/sdb 파티션 관리
fdisk /dev/sdb

# fdisk 내부 명령
# m: 도움말
# p: 파티션 목록 출력
# n: 새 파티션 생성
# d: 파티션 삭제
# t: 파티션 타입 변경
# w: 변경 사항 저장 후 종료
# q: 저장 없이 종료

# 파티션 목록 확인
fdisk -l /dev/sdb

# 출력 예시
Disk /dev/sdb: 500 GiB, 536870912000 bytes, 1048576000 sectors
Device     Boot    Start       End   Sectors  Size Id Type
/dev/sdb1           2048  20973567  20971520   10G 83 Linux
/dev/sdb2       20973568 1048575999 1027602432 490G 83 Linux
```

### gdisk (GPT 파티션 테이블)

- GPT 방식: **2TB 초과** 디스크 지원 (이론상 최대 9.4ZB)
- 파티션 개수 제한 사실상 없음 (기본 128개)
- UEFI 부팅 환경에 필요

```bash
# gdisk로 /dev/sdb 파티션 관리
gdisk /dev/sdb

# gdisk 내부 명령 (fdisk와 유사)
# p: 파티션 목록
# n: 새 파티션 생성
# d: 삭제
# w: 저장
# q: 종료
```

## 파일시스템 생성 (포맷)

파티션을 생성한 뒤에는 파일시스템을 만들어야 합니다.

### ext4와 xfs 비교

| 특징 | ext4 | xfs |
|------|------|-----|
| 개발 | Linux 커뮤니티 | SGI → Linux |
| 최대 파일 크기 | 16TB | 8EB |
| 최대 파일시스템 크기 | 1EB | 8EB |
| 축소(shrink) | 가능 | 불가능 |
| 저널링 | 지원 | 지원 |
| 주요 용도 | 범용, 소규모 | 대용량 파일, 고성능 |
| RHEL 기본 | RHEL 6 이하 | RHEL 7 이상 |

```bash
# ext4 파일시스템 생성
mkfs.ext4 /dev/sdb1

# 출력 예시
mke2fs 1.46.5 (30-Dec-2021)
Creating filesystem with 2621440 4k blocks and 655360 inodes
Filesystem UUID: a1b2c3d4-e5f6-7890-abcd-ef1234567890
Superblock backups stored on blocks: 32768, 98304, 163840

# xfs 파일시스템 생성
mkfs.xfs /dev/sdb2

# 출력 예시
meta-data=/dev/sdb2       isize=512    agcount=4, agsize=32006001 blks
data     =                bsize=4096   blocks=128024002, imaxpct=25
```

## 마운트와 언마운트

파일시스템을 디렉터리에 연결하는 작업입니다.

```bash
# 마운트 포인트 디렉터리 생성
mkdir -p /mnt/data

# 임시 마운트 (재부팅 시 해제됨)
mount /dev/sdb1 /mnt/data

# 파일시스템 타입 명시
mount -t ext4 /dev/sdb1 /mnt/data

# 읽기 전용으로 마운트
mount -o ro /dev/sdb1 /mnt/data

# 언마운트
umount /mnt/data
# 또는 장치명으로 언마운트
umount /dev/sdb1

# 현재 마운트된 파일시스템 확인
mount | grep sdb

# 출력 예시
/dev/sdb1 on /mnt/data type ext4 (rw,relatime)
```

## /etc/fstab 영구 마운트 설정

재부팅 후에도 마운트가 유지되려면 /etc/fstab에 등록해야 합니다.

### /etc/fstab 구조 (6개 필드)

```bash
# 파일 내용 예시
cat /etc/fstab

# <장치>          <마운트포인트>  <파일시스템>  <옵션>         <dump>  <pass>
/dev/sda1         /boot           ext4          defaults       1       2
/dev/sda2         /               ext4          defaults       1       1
/dev/sda3         /home           ext4          defaults       1       2
UUID=a1b2c3d4     /mnt/data       ext4          defaults       0       0
/dev/sdb2         /mnt/large      xfs           defaults,nofail 0      0
```

### 각 필드 설명

| 필드 번호 | 이름 | 설명 |
|----------|------|------|
| 1 | 장치 | 장치명(/dev/sda1) 또는 UUID, LABEL |
| 2 | 마운트포인트 | 마운트할 디렉터리 경로 |
| 3 | 파일시스템 | ext4, xfs, vfat, swap 등 |
| 4 | 옵션 | defaults, ro, noexec, nofail 등 |
| 5 | dump | 백업 여부(0=안함, 1=백업) |
| 6 | pass | fsck 검사 순서(0=안함, 1=루트, 2=나머지) |

```bash
# /etc/fstab에 등록 후 전체 마운트 적용 (재부팅 없이)
mount -a

# UUID로 장치 확인하기
blkid /dev/sdb1
# 출력: /dev/sdb1: UUID="a1b2c3d4-e5f6-7890-abcd-ef1234567890" TYPE="ext4"
```

## 디스크 사용량 확인

```bash
# 마운트된 파일시스템 사용량 (human-readable)
df -h

# 출력 예시
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda2        20G   12G  6.8G  64% /
/dev/sda1       974M  215M  692M  24% /boot
/dev/sda3        79G   45G   30G  61% /home
/dev/sdb1        10G  2.1G  7.4G  22% /mnt/data

# 특정 디렉터리 크기 확인 (summarize)
du -sh /home/user

# 출력 예시
4.2G    /home/user

# 하위 디렉터리별 크기 확인
du -sh /home/*

# 출력 예시
1.2G    /home/alice
4.2G    /home/user
512M    /home/bob
```

## 핵심 정리

- 장치명: /dev/sda(첫 번째 디스크), /dev/sda1(첫 번째 파티션), /dev/nvme0n1(NVMe 디스크)
- fdisk는 MBR 방식(최대 2TB, 기본 파티션 최대 4개), gdisk는 GPT 방식(2TB 초과 지원)
- 파일시스템 생성: mkfs.ext4, mkfs.xfs
- 영구 마운트는 /etc/fstab에 등록, 6개 필드: 장치, 마운트포인트, 파일시스템, 옵션, dump, pass
- mount -a 로 /etc/fstab 전체 마운트 적용, df -h 로 사용량 확인, lsblk 로 장치 트리 확인
