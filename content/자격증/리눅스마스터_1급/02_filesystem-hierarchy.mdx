## FHS(Filesystem Hierarchy Standard)란?

FHS는 리눅스 파일 시스템 디렉터리 구조의 표준이다. 배포판마다 세부 차이는 있지만, 주요 디렉터리의 역할은 공통적으로 정의된다. 모든 경로는 루트(`/`)에서 시작한다.

## 주요 디렉터리 구조

```bash
/
├── bin      # 필수 명령어 실행 파일 (일반 사용자)
├── sbin     # 필수 시스템 관리 명령어 (관리자)
├── etc      # 시스템 전체 설정 파일
├── home     # 일반 사용자 홈 디렉터리
│   └── zenok/
├── root     # root 사용자 홈 디렉터리
├── var      # 가변 데이터 (로그, 스풀, 캐시)
│   ├── log/
│   └── spool/
├── tmp      # 임시 파일 (재부팅 시 삭제)
├── usr      # 사용자 프로그램 및 데이터
│   ├── bin/   # 일반 사용자 명령어
│   ├── sbin/  # 관리자 명령어
│   └── lib/   # 공유 라이브러리
├── proc     # 가상 파일시스템 (커널/프로세스 정보)
├── dev      # 장치 파일 (디스크, 터미널 등)
├── lib      # 필수 공유 라이브러리
├── lib64    # 64비트 공유 라이브러리
├── boot     # 부트 파일, 커널 이미지
├── mnt      # 임시 마운트 포인트
└── media    # 이동식 미디어 마운트 포인트
```

## 디렉터리별 역할 상세

| 디렉터리 | 역할 | 주요 파일/특성 |
|----------|------|----------------|
| `/` | 루트. 모든 경로의 시작점 | 파일 시스템의 최상위 |
| `/bin` | 필수 실행 파일 (일반 사용자) | ls, cp, mv, cat, bash |
| `/sbin` | 필수 시스템 관리 명령어 | fsck, ifconfig, iptables |
| `/etc` | 시스템 설정 파일 | passwd, shadow, fstab, hosts |
| `/home` | 일반 사용자 홈 디렉터리 | /home/username/ |
| `/root` | root 계정 홈 디렉터리 | /home이 아님에 주의 |
| `/var` | 가변 데이터 (크기가 변하는 파일) | /var/log, /var/spool, /var/www |
| `/tmp` | 임시 파일 (재부팅 시 삭제됨) | 누구나 쓰기 가능, sticky bit |
| `/usr` | Unix System Resources. 대부분의 명령어 | /usr/bin, /usr/lib, /usr/share |
| `/proc` | 가상 파일시스템. 커널과 프로세스 정보 | 디스크에 없음, 메모리에서 생성 |
| `/dev` | 장치 파일 | /dev/sda(디스크), /dev/tty(터미널) |
| `/lib` | 필수 공유 라이브러리 | .so 파일 (Windows의 .dll 해당) |
| `/boot` | 부팅 파일, 커널 이미지 | vmlinuz, initrd |
| `/mnt` | 수동 임시 마운트 포인트 | 관리자가 직접 마운트할 때 |
| `/media` | 이동식 미디어 자동 마운트 | CD-ROM, USB |

## /proc 가상 파일시스템

`/proc`는 디스크에 실제로 존재하지 않는 **가상 파일시스템**이다. 커널이 메모리에 동적으로 생성한다.

```bash
# CPU 정보 확인
cat /proc/cpuinfo
# 출력 예시
processor   : 0
model name  : Intel(R) Core(TM) i7-9700K CPU @ 3.60GHz
cpu MHz     : 3600.000
cache size  : 12288 KB

# 메모리 정보 확인
cat /proc/meminfo
# 출력 예시
MemTotal:       16384000 kB
MemFree:         8192000 kB
MemAvailable:   10240000 kB

# 특정 프로세스 정보 (PID 1 = systemd)
cat /proc/1/status
# 출력 예시
Name:   systemd
State:  S (sleeping)
Pid:    1
PPid:   0
```

## 절대 경로 vs 상대 경로

| 구분 | 설명 | 예시 |
|------|------|------|
| 절대 경로 | `/`(루트)에서 시작하는 전체 경로 | `/home/zenok/documents/report.txt` |
| 상대 경로 | 현재 위치를 기준으로 하는 경로 | `./documents/report.txt` 또는 `../etc/hosts` |

특수 경로 기호:

| 기호 | 의미 |
|------|------|
| `.` | 현재 디렉터리 |
| `..` | 상위(부모) 디렉터리 |
| `~` | 현재 사용자의 홈 디렉터리 |
| `-` | 직전 작업 디렉터리 (`cd -`로 이동) |

## 경로 탐색 명령어

```bash
# 현재 작업 디렉터리 확인
pwd
# 출력 예시
/home/zenok

# 홈 디렉터리로 이동
cd ~
# 또는
cd

# 절대 경로로 이동
cd /etc/nginx

# 상대 경로로 이동 (현재 위치가 /home/zenok인 경우)
cd ../root
# /home에서 상위로 이동 후 root 디렉터리로

# 직전 디렉터리로 돌아가기
cd -
# 출력 예시
/home/zenok

# 디렉터리 내용 확인 (파일+숨김파일+상세정보)
ls -al /etc | head -15
# 출력 예시
total 1372
drwxr-xr-x 120 root root   12288 Jan 15 10:00 .
drwxr-xr-x  20 root root    4096 Jan 10 08:30 ..
-rw-r--r--   1 root root    3028 Jan  1 00:00 adduser.conf
drwxr-xr-x   3 root root    4096 Jan 10 08:31 alternatives
drwxr-xr-x   8 root root    4096 Jan 10 08:31 apt
-rw-r--r--   1 root root    2981 Jan  1 00:00 bash.bashrc
-rw-r--r--   1 root root     367 Jan  1 00:00 bindresvport.blacklist
drwxr-xr-x   2 root root    4096 Jan 10 08:31 binfmt.d
```

## /etc 주요 설정 파일

시험에 자주 출제되는 `/etc` 하위 파일들:

| 파일 | 내용 |
|------|------|
| `/etc/passwd` | 사용자 계정 정보 (이름, UID, GID, 홈, 셸) |
| `/etc/shadow` | 암호화된 패스워드와 만료 정보 |
| `/etc/group` | 그룹 정보 |
| `/etc/hosts` | 정적 호스트명-IP 매핑 |
| `/etc/hostname` | 시스템 호스트명 |
| `/etc/fstab` | 파일시스템 자동 마운트 설정 |
| `/etc/resolv.conf` | DNS 서버 설정 |
| `/etc/crontab` | 시스템 cron 작업 설정 |
| `/etc/sudoers` | sudo 권한 설정 |

## 핵심 정리

- FHS는 리눅스 파일 시스템 디렉터리 구조의 표준이다
- `/bin`: 일반 사용자 필수 명령어, `/sbin`: 관리자 필수 명령어
- `/etc`: 설정 파일, `/var`: 가변 데이터(로그), `/tmp`: 임시 파일
- `/proc`: 가상 파일시스템. 디스크에 없고 메모리에서 커널이 생성
- `/home`: 일반 사용자 홈, `/root`: root 계정 홈 (위치가 다름에 주의)
- 절대 경로는 `/`로 시작, 상대 경로는 `.`(현재) 또는 `..`(상위) 기준
