## 스크립트 기본 구조

```bash
#!/bin/bash
# 첫 줄은 shebang: 이 스크립트를 실행할 인터프리터 지정
# 주석은 # 으로 시작

# 스크립트 실행 방법 두 가지:
# 1. 실행 권한 부여 후 실행
chmod +x script.sh
./script.sh

# 2. 인터프리터 직접 지정
bash script.sh
```

## 변수

```bash
#!/bin/bash

# 변수 선언: = 앞뒤에 공백 없음 (공백 있으면 오류!)
name="Alice"
count=10
today=$(date +%Y-%m-%d)  # 명령어 결과를 변수에 저장

# 변수 사용: $변수명 또는 ${변수명}
echo "이름: $name"
echo "날짜: ${today}"

# 큰따옴표 내에서 변수 확장됨
echo "파일 개수: ${count}개"

# 작은따옴표 내에서는 변수 확장 안 됨 (리터럴)
echo 'name=$name'  # 출력: name=$name

# 변수 기본값 설정 (변수가 비어 있으면 기본값 사용)
echo "${username:-guest}"   # username이 없으면 guest 출력
echo "${port:-8080}"        # port가 없으면 8080 출력
```

## 특수 변수

| 변수 | 의미 |
|------|------|
| $0 | 스크립트 자신의 이름 |
| $1 ~ $9 | 첫 번째 ~ 아홉 번째 인수 |
| $# | 전달된 인수의 개수 |
| $@ | 모든 인수 (각각 따옴표 처리) |
| $* | 모든 인수 (하나의 문자열) |
| $? | 직전 명령의 종료 코드 (0=성공, 비0=실패) |
| $$ | 현재 셸의 PID |
| $! | 마지막 백그라운드 프로세스 PID |

```bash
#!/bin/bash
echo "스크립트 이름: $0"
echo "첫 번째 인수: $1"
echo "인수 개수: $#"
echo "모든 인수: $@"

ls /tmp
echo "ls 종료 코드: $?"  # 성공이면 0

ls /nonexistent 2>/dev/null
echo "ls 종료 코드: $?"  # 실패이면 2
```

## 조건문

### if-elif-else

```bash
#!/bin/bash

score=85

if [ $score -ge 90 ]; then
    echo "A 학점"
elif [ $score -ge 80 ]; then
    echo "B 학점"
elif [ $score -ge 70 ]; then
    echo "C 학점"
else
    echo "F 학점"
fi
```

### test 조건 연산자

| 연산자 | 의미 |
|--------|------|
| **파일/디렉터리** | |
| -f 파일 | 파일이 존재하고 일반 파일 |
| -d 경로 | 디렉터리가 존재함 |
| -e 경로 | 파일/디렉터리가 존재함 |
| -r 파일 | 읽기 권한 있음 |
| -w 파일 | 쓰기 권한 있음 |
| -x 파일 | 실행 권한 있음 |
| -s 파일 | 파일이 존재하고 크기가 0보다 큼 |
| **문자열** | |
| -z "$str" | 문자열이 비어 있음 |
| -n "$str" | 문자열이 비어 있지 않음 |
| "$a" = "$b" | 문자열이 같음 |
| "$a" != "$b" | 문자열이 다름 |
| **숫자** | |
| $a -eq $b | 같음 (equal) |
| $a -ne $b | 다름 (not equal) |
| $a -lt $b | 작음 (less than) |
| $a -gt $b | 큼 (greater than) |
| $a -le $b | 작거나 같음 |
| $a -ge $b | 크거나 같음 |

```bash
#!/bin/bash

# 파일 존재 확인
if [ -f "/etc/passwd" ]; then
    echo "/etc/passwd 파일이 존재합니다"
fi

# 디렉터리 확인
if [ ! -d "/backup" ]; then
    mkdir -p /backup
    echo "백업 디렉터리를 생성했습니다"
fi

# 인수 개수 확인
if [ $# -eq 0 ]; then
    echo "사용법: $0 <파일명>"
    exit 1
fi
```

## 반복문

### for 문

```bash
#!/bin/bash

# 목록 순회
for fruit in apple banana cherry; do
    echo "과일: $fruit"
done

# 출력:
# 과일: apple
# 과일: banana
# 과일: cherry

# 숫자 범위 (C 스타일)
for ((i=1; i<=5; i++)); do
    echo "번호: $i"
done

# seq 활용
for i in $(seq 1 5); do
    echo "번호: $i"
done

# 파일 목록 처리
for logfile in /var/log/*.log; do
    echo "로그 파일: $logfile"
done
```

### while 문

```bash
#!/bin/bash

count=1
while [ $count -le 5 ]; do
    echo "카운트: $count"
    count=$((count + 1))
done

# 파일을 한 줄씩 읽기
while IFS= read -r line; do
    echo "줄: $line"
done < /etc/hosts
```

## case 문

```bash
#!/bin/bash

day=$(date +%u)  # 요일 숫자 (1=월, 7=일)

case $day in
    1)
        echo "월요일"
        ;;
    2)
        echo "화요일"
        ;;
    6|7)
        echo "주말"
        ;;
    *)
        echo "평일"
        ;;
esac

# 문자열 패턴 매칭
os="ubuntu"
case $os in
    ubuntu|debian)
        echo "Debian 계열: apt 사용"
        ;;
    centos|rhel|fedora)
        echo "Red Hat 계열: yum/dnf 사용"
        ;;
    *)
        echo "알 수 없는 배포판"
        ;;
esac
```

## 함수

```bash
#!/bin/bash

# 함수 정의
check_service() {
    local service=$1  # local: 함수 내 지역 변수
    if systemctl is-active --quiet "$service"; then
        echo "$service: 실행 중"
        return 0
    else
        echo "$service: 중지됨"
        return 1
    fi
}

# 함수 호출
check_service nginx
check_service mysql

# 반환값 확인
if check_service sshd; then
    echo "SSH 서버가 정상 동작합니다"
fi
```

## 실용 예시: 로그 파일 모니터링 스크립트

```bash
#!/bin/bash
# log_check.sh: /var/log에서 오늘 생성된 로그 파일 개수 확인

LOG_DIR="/var/log"
TODAY=$(date +%Y-%m-%d)
COUNT=0

for logfile in "$LOG_DIR"/*.log; do
    if [ -f "$logfile" ]; then
        COUNT=$((COUNT + 1))
    fi
done

echo "[$TODAY] $LOG_DIR 내 로그 파일 수: ${COUNT}개"

if [ $COUNT -gt 10 ]; then
    echo "경고: 로그 파일이 많습니다. 확인이 필요합니다."
fi
```

```bash
# 실행
chmod +x log_check.sh
./log_check.sh

# 출력 예시
[2026-08-23] /var/log 내 로그 파일 수: 14개
경고: 로그 파일이 많습니다. 확인이 필요합니다.
```

## 핵심 정리

- 스크립트 첫 줄: #!/bin/bash (shebang), 실행: chmod +x 후 ./script.sh 또는 bash script.sh
- 변수 선언: name="값" (공백 없음), 사용: $name 또는 ${name}
- 특수 변수: $0(스크립트명), $1~$9(인수), $#(인수수), $?(종료코드), $$(PID)
- 조건: -f(파일), -d(디렉터리), -z(빈문자열), -eq/-ne/-lt/-gt(숫자 비교)
- for 반복, while 반복, case 패턴 매칭, 함수 내 local 변수 사용
