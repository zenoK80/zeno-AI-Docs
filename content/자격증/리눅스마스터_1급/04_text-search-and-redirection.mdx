## 표준 입출력 개념

리눅스의 모든 명령어는 세 가지 표준 스트림을 가진다:

| 스트림 | 번호 | 기본 방향 | 설명 |
|--------|------|-----------|------|
| stdin (표준 입력) | 0 | 키보드 | 명령어가 읽는 데이터 |
| stdout (표준 출력) | 1 | 터미널 화면 | 정상 결과 출력 |
| stderr (표준 오류) | 2 | 터미널 화면 | 오류 메시지 출력 |

## 리다이렉션

리다이렉션은 표준 스트림의 방향을 파일로 바꾼다.

```bash
# > : stdout을 파일로 덮어쓰기 (기존 내용 삭제)
echo "Hello World" > output.txt
cat output.txt
# 출력 예시
Hello World

# >> : stdout을 파일에 추가
echo "Second line" >> output.txt
cat output.txt
# 출력 예시
Hello World
Second line

# < : 파일을 stdin으로 사용
wc -l < /etc/passwd
# 출력 예시
45

# 2> : stderr를 파일로 리다이렉션
find / -name "hosts" 2> /tmp/errors.txt
# 오류 메시지는 errors.txt에 저장, 정상 결과만 화면 출력

# 2>&1 : stderr를 stdout과 같은 곳으로 (둘 다 파일로)
find / -name "hosts" > /tmp/output.txt 2>&1
# 정상 결과와 오류 모두 output.txt에 저장

# /dev/null : 출력을 버리는 특수 장치
find / -name "hosts" 2>/dev/null
# 오류 메시지 없이 정상 결과만 출력
```

| 기호 | 의미 |
|------|------|
| `>` | stdout → 파일 (덮어쓰기) |
| `>>` | stdout → 파일 (추가) |
| `<` | 파일 → stdin |
| `2>` | stderr → 파일 |
| `2>>` | stderr → 파일 (추가) |
| `2>&1` | stderr를 stdout과 같은 곳으로 |
| `&>` | stdout + stderr → 파일 (bash 전용) |

## 파이프(Pipe)

파이프(`|`)는 왼쪽 명령의 **stdout**을 오른쪽 명령의 **stdin**으로 연결한다.

```bash
# 프로세스 목록에서 nginx만 검색
ps aux | grep nginx
# 출력 예시
www-data  1234  0.0  0.1  ... nginx: worker process
root      5678  0.0  0.1  ... nginx: master process

# grep 결과에서 grep 자신 제외
ps aux | grep nginx | grep -v grep

# 여러 파이프 연결
cat /etc/passwd | cut -d: -f1 | sort | head -10
# 출력 예시 (사용자명 알파벳 순 상위 10개)
_apt
backup
bin
daemon
games
gnats
irc
list
lp
mail
```

## grep - 패턴 검색

```bash
# 기본 사용 (파일에서 패턴 검색)
grep "error" /var/log/syslog
# 출력 예시
Jan 15 10:05:23 server kernel: [  123.456] error: disk read failed

# -i : 대소문자 구분 없이 검색
grep -i "ERROR" /var/log/syslog

# -v : 패턴이 없는 줄만 출력 (반전)
grep -v "^#" /etc/hosts
# 출력 예시 (주석 제외한 실제 설정만)
127.0.0.1   localhost
127.0.1.1   myserver

# -n : 줄 번호 함께 출력
grep -n "root" /etc/passwd
# 출력 예시
1:root:x:0:0:root:/root:/bin/bash

# -r : 디렉터리 재귀 검색
grep -r "ServerName" /etc/apache2/

# -l : 패턴이 있는 파일명만 출력
grep -l "error" /var/log/*.log

# -c : 매칭된 줄 수만 출력
grep -c "Failed" /var/log/auth.log
# 출력 예시
42

# 정규표현식 사용
grep "^root" /etc/passwd      # root로 시작하는 줄
grep "bash$" /etc/passwd      # bash로 끝나는 줄
grep -E "[0-9]{1,3}\.[0-9]{1,3}" /etc/hosts  # IP 패턴 (-E: 확장 정규식)
```

| 옵션 | 설명 |
|------|------|
| `-i` | 대소문자 구분 없음 |
| `-v` | 패턴 없는 줄만 출력 (반전) |
| `-n` | 줄 번호 표시 |
| `-r` | 디렉터리 재귀 검색 |
| `-l` | 파일명만 출력 |
| `-c` | 매칭 줄 수만 출력 |
| `-E` | 확장 정규표현식 |

## wc - 줄/단어/바이트 수 계산

```bash
# 줄, 단어, 바이트 수 모두 출력
wc /etc/passwd
# 출력 예시
 45  90 2345 /etc/passwd
# 순서: 줄 수  단어 수  바이트 수  파일명

# 줄 수만
wc -l /etc/passwd
# 출력 예시
45 /etc/passwd

# 단어 수만
wc -w /etc/passwd

# 바이트 수만
wc -c /etc/passwd
```

## sort - 정렬

```bash
# 알파벳 순 정렬
sort /etc/hostname

# 역순 정렬 (-r)
sort -r names.txt

# 숫자 순 정렬 (-n)
sort -n numbers.txt
# 출력 예시 (숫자 순)
1
5
10
100

# 특정 필드 기준 정렬 (-k: 필드 번호, -t: 구분자)
sort -t: -k3 -n /etc/passwd
# :로 구분된 세 번째 필드(UID) 기준 숫자 정렬

# 중복 제거하며 정렬 (-u)
sort -u duplicates.txt
```

## uniq - 중복 줄 제거

```bash
# sort 후 uniq 사용 (인접한 중복만 제거하므로 반드시 sort 선행)
sort access.log | uniq

# 중복 횟수 포함 출력 (-c)
sort access.log | uniq -c | sort -rn | head -10
# 출력 예시 (접속 빈도 상위 10개)
    523 192.168.1.100
    342 10.0.0.1
     98 172.16.0.5
```

## cut - 필드 추출

```bash
# /etc/passwd에서 사용자명만 추출 (-d: 구분자, -f: 필드 번호)
cut -d: -f1 /etc/passwd
# 출력 예시
root
daemon
bin
sys
zenok

# 여러 필드 추출 (1번째, 6번째: 사용자명과 홈 디렉터리)
cut -d: -f1,6 /etc/passwd
# 출력 예시
root:/root
daemon:/usr/sbin
zenok:/home/zenok

# 문자 위치로 추출 (-c)
cut -c1-5 /etc/hostname
```

## tee - 화면과 파일 동시 출력

```bash
# 결과를 화면에 출력하면서 파일에도 저장
ls -al | tee /tmp/ls_result.txt
# 화면에 출력되면서 동시에 파일에도 저장됨

# 파이프라인 중간에 사용하여 중간 결과 저장
grep "error" /var/log/syslog | tee /tmp/errors.txt | wc -l
```

## 실용 복합 명령 예시

```bash
# 에러 로그에서 IP별 오류 횟수 집계
grep "error" /var/log/nginx/error.log | grep -oE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+" | sort | uniq -c | sort -rn

# nginx 프로세스가 실행 중인지 확인
ps aux | grep nginx | grep -v grep

# 사용자 목록을 파일로 저장
cat /etc/passwd | cut -d: -f1 | sort > /tmp/users.txt

# 시스템 로그에서 오류 통계
grep -i "error" /var/log/syslog | sort | uniq -c | sort -rn | head -5
```

## 핵심 정리

- `>`: stdout 덮어쓰기, `>>`: stdout 추가, `<`: stdin 파일 연결
- `2>`: stderr 리다이렉션, `2>&1`: stderr를 stdout과 같은 곳으로
- `/dev/null`: 출력 버리는 블랙홀 장치
- 파이프 `|`: 왼쪽 stdout → 오른쪽 stdin
- `grep -i -v -n -r -l`: 대소문자무시, 반전, 줄번호, 재귀, 파일명만
- `wc -l`: 줄 수, `sort -n`: 숫자정렬, `uniq -c`: 중복 횟수
- `cut -d: -f1`: 구분자 기준 필드 추출
