## SSH 기본 접속

**SSH**(Secure Shell) 는 암호화된 채널로 원격 시스템에 안전하게 접속하는 프로토콜입니다.

```bash
# 기본 접속 (포트 22)
ssh user@192.168.1.100

# 다른 포트 지정
ssh -p 2222 user@192.168.1.100

# 특정 개인키 파일 사용
ssh -i ~/.ssh/my_key user@192.168.1.100

# X11 포워딩 (GUI 원격 실행)
ssh -X user@192.168.1.100

# 원격 명령 실행 (접속 없이 명령만)
ssh user@192.168.1.100 'df -h'

# 출력 예시
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda2        20G   12G  6.8G  64% /
```

## 키 기반 인증 설정 (3단계)

비밀번호 인증 대신 공개키/개인키 쌍으로 인증하는 방법입니다. 보안성이 높고 자동화에 필수적입니다.

### 1단계: SSH 키 쌍 생성

```bash
# RSA 4096비트 키 생성
ssh-keygen -t rsa -b 4096

# 출력 및 진행 예시
Generating public/private rsa key pair.
Enter file in which to save the key (/home/user/.ssh/id_rsa): [Enter]
Enter passphrase (empty for no passphrase): [비밀번호 입력 또는 Enter]
Enter same passphrase again: [재입력]
Your identification has been saved in /home/user/.ssh/id_rsa
Your public key has been saved in /home/user/.ssh/id_rsa.pub

# 생성된 키 파일 확인
ls -la ~/.ssh/
# id_rsa     (개인키 - 절대 유출 금지!)
# id_rsa.pub (공개키 - 서버에 배포)

# Ed25519 알고리즘 (더 안전하고 빠름)
ssh-keygen -t ed25519 -C "my_comment"
```

### 2단계: 공개키를 서버에 복사

```bash
# ssh-copy-id로 자동 복사 (권장)
ssh-copy-id user@192.168.1.100

# 출력 예시
/usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s)
Number of key(s) added: 1
Now try logging into the machine with: "ssh 'user@192.168.1.100'"

# 수동 복사 방법
cat ~/.ssh/id_rsa.pub | ssh user@192.168.1.100 'mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys'
```

### 3단계: 권한 설정 (서버 측)

```bash
# 서버에서 ~/.ssh 디렉터리와 authorized_keys 권한 설정
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

# 이후 비밀번호 없이 접속 가능
ssh user@192.168.1.100
```

## sshd_config 보안 강화

SSH 서버의 설정 파일 `/etc/ssh/sshd_config`를 수정하여 보안을 강화합니다.

```bash
# 설정 파일 편집
vi /etc/ssh/sshd_config

# 주요 보안 설정 항목:

# SSH 포트 변경 (기본 22에서 변경)
Port 2222

# root 직접 로그인 차단 (핵심 보안 설정)
PermitRootLogin no

# 비밀번호 인증 비활성화 (키 인증만 허용)
PasswordAuthentication no

# 특정 사용자만 SSH 접근 허용
AllowUsers alice bob deploy

# 특정 그룹만 허용
AllowGroups sshusers

# 인증 최대 시도 횟수
MaxAuthTries 3

# 로그인 타임아웃 (초)
LoginGraceTime 30

# 유휴 세션 자동 종료
ClientAliveInterval 300
ClientAliveCountMax 2

# 빈 비밀번호 계정 로그인 차단
PermitEmptyPasswords no

# X11 포워딩 설정
X11Forwarding no

# 설정 파일 문법 검사 후 적용
sshd -t  # 문법 오류 확인
systemctl restart sshd
```

## SSH 터널링

### 로컬 포트 포워딩 (-L)

로컬 포트를 통해 원격 서버의 서비스에 접근합니다.

```bash
# 로컬 8080 → 원격 서버를 통해 db.internal:3306으로 터널링
ssh -L 8080:db.internal:3306 user@jumphost.example.com

# 이후 로컬에서 127.0.0.1:8080으로 접속하면 db.internal:3306에 연결됨
mysql -h 127.0.0.1 -P 8080 -u dbuser -p
```

### 원격 포트 포워딩 (-R)

원격 서버의 포트를 로컬 서비스로 연결합니다 (방화벽 우회에 활용).

```bash
# 원격 서버의 9090 포트 → 로컬 localhost:3000으로 포워딩
ssh -R 9090:localhost:3000 user@remote.example.com

# 원격 서버에서 localhost:9090 접속 시 내 로컬 3000번 포트로 연결됨
```

## 파일 전송

### scp (Secure Copy)

```bash
# 로컬 → 원격 복사
scp /local/file.txt user@192.168.1.100:/remote/path/

# 원격 → 로컬 복사
scp user@192.168.1.100:/remote/file.txt /local/path/

# 디렉터리 전체 복사 (-r)
scp -r /local/dir/ user@192.168.1.100:/remote/dir/

# 다른 포트 지정 (-P 대문자)
scp -P 2222 file.txt user@192.168.1.100:/path/
```

### rsync (효율적인 동기화)

변경된 파일만 전송하여 대용량 동기화에 적합합니다.

```bash
# 원격 서버로 동기화 (-a: 아카이브, -v: 상세, -z: 압축)
rsync -avz /local/dir/ user@192.168.1.100:/remote/dir/

# 출력 예시
sending incremental file list
./
file1.txt
file2.log

sent 15,234 bytes  received 89 bytes  10,215.33 bytes/sec
total size is 15,100  speedup is 0.99

# 삭제된 파일도 동기화 (원본에서 삭제된 파일을 대상에서도 삭제)
rsync -avz --delete /local/dir/ user@192.168.1.100:/remote/dir/

# SSH 포트 지정
rsync -avz -e "ssh -p 2222" /local/dir/ user@192.168.1.100:/remote/dir/

# 진행률 표시
rsync -avz --progress /local/dir/ user@192.168.1.100:/remote/dir/
```

## ~/.ssh/config 단축 설정

접속 설정을 파일에 저장하여 단축 이름으로 SSH 접속합니다.

```bash
# ~/.ssh/config 파일 작성
cat ~/.ssh/config

Host webserver
    HostName 192.168.1.100
    User deploy
    Port 2222
    IdentityFile ~/.ssh/deploy_key

Host db-tunnel
    HostName jumphost.example.com
    User admin
    LocalForward 3306 db.internal:3306

# 설정 후 단축 접속
ssh webserver          # ssh deploy@192.168.1.100 -p 2222 -i ~/.ssh/deploy_key 와 동일
ssh db-tunnel          # 터널링 포함 접속

# ~/.ssh/config 권한 설정 (필수)
chmod 600 ~/.ssh/config
```

## 핵심 정리

- ssh user@호스트 -p 포트 -i 키파일 로 SSH 접속
- 키 인증 3단계: ssh-keygen -t rsa -b 4096 → ssh-copy-id → authorized_keys에 등록됨
- /etc/ssh/sshd_config 핵심 보안 설정: PermitRootLogin no, PasswordAuthentication no, AllowUsers
- SSH 터널링: -L(로컬 포트→원격 서비스), -R(원격 포트→로컬 서비스)
- 파일 전송: scp(단순 복사), rsync -avz(증분 동기화, 대용량 적합)
