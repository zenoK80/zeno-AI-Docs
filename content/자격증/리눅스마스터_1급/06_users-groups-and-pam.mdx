## 사용자 관련 파일

### /etc/passwd - 사용자 계정 정보

모든 사용자 계정 정보가 담긴 파일로 누구나 읽을 수 있다 (비밀번호는 /etc/shadow에 별도 저장).

```bash
cat /etc/passwd | head -3
# 출력 예시
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
zenok:x:1000:1000:Zeno K,,,:/home/zenok:/bin/bash
```

7개 필드를 콜론(`:`)으로 구분:

| 필드 | 예시 | 설명 |
|------|------|------|
| 1 | `zenok` | 사용자명(login name) |
| 2 | `x` | 비밀번호 자리 (`x`는 /etc/shadow에 저장) |
| 3 | `1000` | UID (User ID) |
| 4 | `1000` | GID (Primary Group ID) |
| 5 | `Zeno K,,,` | GECOS (사용자 설명, 전화번호 등) |
| 6 | `/home/zenok` | 홈 디렉터리 |
| 7 | `/bin/bash` | 로그인 셸 |

### /etc/shadow - 암호화된 비밀번호

root만 읽을 수 있는 비밀번호 파일.

```bash
sudo cat /etc/shadow | grep zenok
# 출력 예시
zenok:$6$salt$hashedpassword...:19723:0:99999:7:::
```

9개 필드:

| 필드 | 예시 | 설명 |
|------|------|------|
| 1 | `zenok` | 사용자명 |
| 2 | `$6$...` | 암호화된 비밀번호 (`$6$` = SHA-512) |
| 3 | `19723` | 마지막 비밀번호 변경일 (1970-01-01 기준 일수) |
| 4 | `0` | 최소 변경 주기(일) |
| 5 | `99999` | 최대 유효 기간(일) |
| 6 | `7` | 만료 경고 일수 |
| 7 | (빈칸) | 비밀번호 만료 후 계정 비활성화까지 기간 |
| 8 | (빈칸) | 계정 만료일 |
| 9 | (빈칸) | 예약 필드 |

### /etc/group - 그룹 정보

```bash
cat /etc/group | grep zenok
# 출력 예시
zenok:x:1000:
developers:x:1001:zenok,alice,bob
```

4개 필드: `그룹명:비밀번호:GID:멤버목록`

## 사용자 관리 명령어

### useradd - 사용자 추가

```bash
# 기본 생성 (홈 디렉터리 없음)
useradd alice

# 홈 디렉터리 함께 생성 (-m)
useradd -m bob

# 셸 지정 (-s)
useradd -m -s /bin/zsh charlie

# 기본 그룹 지정 (-g)
useradd -m -g developers dave

# 보조 그룹 지정 (-G, 여러 그룹은 쉼표로)
useradd -m -G sudo,developers eve

# 홈 디렉터리 경로 직접 지정 (-d)
useradd -m -d /data/users/frank frank

# 계정 만료일 지정 (-e)
useradd -m -e 2024-12-31 tempuser

# 사용자 생성 후 비밀번호 설정
passwd alice
# 출력 예시
New password:
Retype new password:
passwd: password updated successfully
```

| 옵션 | 설명 |
|------|------|
| `-m` | 홈 디렉터리 생성 |
| `-s 셸` | 로그인 셸 지정 |
| `-g 그룹` | 기본 그룹 |
| `-G 그룹` | 보조 그룹(쉼표로 다수 지정) |
| `-d 경로` | 홈 디렉터리 경로 |
| `-u UID` | UID 직접 지정 |
| `-e 날짜` | 계정 만료일 (YYYY-MM-DD) |

### usermod - 사용자 수정

```bash
# 보조 그룹에 추가 (-a: append 필수, -G와 함께)
usermod -aG developers alice
# -a 없이 -G만 쓰면 기존 그룹이 교체됨 (주의!)

# 로그인 셸 변경
usermod -s /bin/zsh alice

# 홈 디렉터리 변경 (-d) 및 실제로 이동 (-m)
usermod -d /new/home/alice -m alice

# 계정 잠금 (-L: Lock)
usermod -L alice
sudo cat /etc/shadow | grep alice
# 출력 예시 (비밀번호 필드 앞에 ! 추가됨)
alice:!$6$...

# 계정 잠금 해제 (-U: Unlock)
usermod -U alice

# 사용자명 변경 (-l: login)
usermod -l alice_new alice
```

### userdel - 사용자 삭제

```bash
# 사용자만 삭제 (홈 디렉터리 남아 있음)
userdel alice

# 홈 디렉터리와 메일 스풀까지 삭제 (-r)
userdel -r bob
```

## 그룹 관리 명령어

```bash
# 그룹 생성
groupadd developers

# GID 지정하여 생성
groupadd -g 2000 webteam

# 그룹명 변경
groupmod -n webteam_new webteam

# 그룹 삭제
groupdel developers

# 현재 사용자가 속한 그룹 확인
groups
# 출력 예시
zenok sudo developers

# 사용자 ID 및 그룹 정보 상세 확인
id alice
# 출력 예시
uid=1001(alice) gid=1001(alice) groups=1001(alice),27(sudo),1002(developers)
```

## 사용자 상태 확인 명령어

```bash
# 현재 로그인된 사용자 목록
who
# 출력 예시
zenok    pts/0        2024-01-15 09:30 (192.168.1.10)
alice    pts/1        2024-01-15 10:15 (192.168.1.20)

# 로그인 사용자 상세 정보 (현재 실행 명령 포함)
w
# 출력 예시
 10:30:00 up 2 days,  3:45,  2 users,  load average: 0.12, 0.08, 0.05
USER     TTY      FROM             LOGIN@   IDLE JCPU   PCPU WHAT
zenok    pts/0    192.168.1.10    09:30    0.00s  0.15s  0.02s w
alice    pts/1    192.168.1.20    10:15   10:00   0.05s  0.05s bash

# 로그인 기록
last
# 출력 예시
zenok    pts/0    192.168.1.10    Mon Jan 15 09:30   still logged in
alice    pts/1    192.168.1.20    Mon Jan 15 10:15   still logged in
reboot   system boot  5.15.0-91-generic Mon Jan 13 06:30

# 현재 사용자명
whoami
# 출력 예시
zenok
```

## PAM (Pluggable Authentication Module)

PAM은 인증 방식을 모듈화하여 응용프로그램이 직접 인증 로직을 구현하지 않아도 되도록 하는 프레임워크다.

### PAM 설정 파일

```bash
ls /etc/pam.d/
# 출력 예시
common-auth  common-account  common-password  common-session  login  sshd  sudo

# sshd 인증 설정 확인
cat /etc/pam.d/sshd
# 출력 예시
@include common-auth
@include common-account
@include common-session
session  optional  pam_motd.so
```

### PAM 모듈 유형(Type)

| 유형 | 설명 |
|------|------|
| `auth` | 사용자 인증 (비밀번호 확인, 토큰 검증) |
| `account` | 계정 유효성 확인 (만료, 접속 허용 시간대 등) |
| `password` | 비밀번호 변경 처리 |
| `session` | 세션 시작/종료 시 처리 (로그, 환경 설정) |

### PAM Control 플래그

| 플래그 | 설명 |
|--------|------|
| `required` | 실패해도 나머지 모듈 계속 실행, 최종적으로 실패 반환 |
| `requisite` | 실패 즉시 인증 거부 (나머지 모듈 실행 안 함) |
| `sufficient` | 성공 시 이전에 required 실패 없으면 인증 성공 (이후 모듈 실행 안 함) |
| `optional` | 결과가 최종 성패에 영향 없음 (보조적 모듈) |

### PAM 설정 파일 형식

```
# 형식: 유형  control  모듈경로  [옵션]
auth    required    pam_unix.so    try_first_pass
auth    optional    pam_permit.so
account required    pam_unix.so
account required    pam_time.so
password required   pam_unix.so    sha512 shadow
session required    pam_unix.so
session optional    pam_lastlog.so
```

```bash
# 주요 PAM 모듈
# pam_unix.so  : 전통적인 /etc/passwd, /etc/shadow 기반 인증
# pam_ldap.so  : LDAP 기반 인증
# pam_google_authenticator.so : 2단계 인증
# pam_limits.so : 자원 제한 (ulimit 설정)
# pam_time.so  : 시간대 기반 접속 제한

# pam_limits.so 설정 파일
cat /etc/security/limits.conf
# 출력 예시
#<domain>  <type>  <item>   <value>
zenok      hard    nofile   65536
@developers soft   nproc    100
```

## 핵심 정리

- `/etc/passwd`: 7개 필드. 사용자명:x:UID:GID:설명:홈:셸
- `/etc/shadow`: 9개 필드. 사용자명:암호화비밀번호:마지막변경일:...
- `useradd -m -s /bin/bash -G sudo user`: 홈생성, 셸지정, 그룹지정
- `usermod -aG group user`: 기존 그룹 유지하며 추가 (-a 필수)
- `usermod -L/-U`: 계정 잠금/해제
- `userdel -r user`: 홈 디렉터리 포함 삭제
- PAM 유형: auth(인증), account(계정확인), password(비밀번호변경), session(세션)
- PAM control: required(실패해도 계속), requisite(실패 즉시 거부), sufficient(성공 시 즉시 통과), optional(보조)
