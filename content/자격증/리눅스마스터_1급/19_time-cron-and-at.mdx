## 시스템 시간 확인과 설정

### date 명령

```bash
date                          # 현재 날짜와 시간 출력
date "+%Y-%m-%d %H:%M:%S"    # 형식 지정 출력 (예: 2025-08-23 14:30:00)
date -s "2025-08-23 14:30:00" # 시스템 시간 설정 (root 권한 필요)
date +%s                      # Unix 타임스탬프 출력 (epoch)
```

### timedatectl — systemd 시간 관리 (권장)

```bash
timedatectl                           # 현재 시간, 시간대, NTP 동기화 상태 확인
timedatectl set-time "2025-08-23 14:30:00"  # 시스템 시간 설정
timedatectl set-timezone Asia/Seoul   # 시간대 설정
timedatectl set-ntp true              # NTP 동기화 활성화
timedatectl set-ntp false             # NTP 동기화 비활성화
timedatectl list-timezones            # 지원 시간대 목록
timedatectl list-timezones | grep Seoul  # 서울 시간대 확인
```

### hwclock — 하드웨어 클록

시스템에는 OS가 관리하는 **소프트웨어 클록**과 전원이 꺼져도 유지되는 **하드웨어 클록**(RTC) 이 있습니다.

```bash
hwclock                   # 하드웨어 클록 시간 출력
hwclock --show            # 하드웨어 클록 시간 상세 출력
hwclock --hctosys         # 하드웨어 클록 → 시스템 클록 동기화
hwclock --systohc         # 시스템 클록 → 하드웨어 클록 동기화
hwclock --utc             # UTC 기준으로 설정
```

## NTP — 네트워크 시간 동기화

### chronyd (현재 표준 — RHEL 7+ / Debian 계열)

```bash
systemctl status chronyd       # 서비스 상태 확인
systemctl enable --now chronyd # 활성화 및 시작

# /etc/chrony.conf 주요 설정
cat /etc/chrony.conf
# server 0.rhel.pool.ntp.org iburst
# server 1.rhel.pool.ntp.org iburst
# driftfile /var/lib/chrony/drift
# makestep 1.0 3
# rtcsync

# 동기화 상태 확인
chronyc tracking       # 현재 동기화 상태 및 오차
chronyc sources        # NTP 서버 목록과 상태
chronyc sourcestats    # NTP 서버 통계
```

### ntpd (구버전 — 레거시)

```bash
systemctl status ntpd
# /etc/ntp.conf 설정 파일

ntpq -p               # NTP 피어 상태 확인
ntpstat               # 동기화 요약 상태
```

<Callout type="info">
  최신 리눅스 배포판은 `ntpd` 대신 `chronyd`를 사용합니다. 시험에서는 두 가지 모두 출제될 수 있으므로 설정 파일 경로를 구분하세요.
</Callout>

## crontab — 반복 예약 작업

### crontab 명령

```bash
crontab -e         # 현재 사용자 crontab 편집 (vi 편집기)
crontab -l         # 현재 사용자 crontab 목록 출력
crontab -r         # 현재 사용자 crontab 전체 삭제
crontab -u user -l # 특정 사용자의 crontab 목록 (root만 가능)
crontab -u user -e # 특정 사용자 crontab 편집 (root만 가능)
```

### crontab 5필드 문법

```
분  시  일  월  요일  명령
*   *   *   *   *    /path/to/command
│   │   │   │   └── 요일 (0-7, 0과 7 모두 일요일)
│   │   │   └────── 월 (1-12)
│   │   └────────── 일 (1-31)
│   └────────────── 시 (0-23)
└────────────────── 분 (0-59)
```

### 특수 문자

| 문자 | 의미 | 예시 |
|---|---|---|
| `*` | 모든 값 | `* * * * *` = 1분마다 |
| `,` | 목록 | `1,15 * * * *` = 1분, 15분 |
| `-` | 범위 | `1-5 * * * *` = 1~5분 |
| `/` | 간격 | `*/5 * * * *` = 5분마다 |

### crontab 예시

```bash
# 매일 새벽 2시에 백업 스크립트 실행
0 2 * * * /usr/local/bin/backup.sh

# 5분마다 시스템 상태 체크
*/5 * * * * /usr/local/bin/check.sh >> /var/log/check.log 2>&1

# 평일(월~금) 오전 9시에 리포트 생성
0 9 * * 1-5 /usr/local/bin/report.sh

# 매월 1일 자정에 로그 정리
0 0 1 * * /usr/local/bin/cleanup.sh

# 매주 일요일 오전 4시에 데이터베이스 백업
0 4 * * 0 mysqldump -u root -p dbname > /backup/db.sql

# 1월, 7월 매일 오후 6시에 실행
0 18 * 1,7 * /usr/local/bin/semi-annual.sh

# 매시간 10분, 40분에 실행
10,40 * * * * /usr/local/bin/task.sh
```

### 시스템 cron 디렉터리

```bash
/etc/cron.d/       # 시스템 cron 작업 파일 (개별 파일로 관리)
/etc/cron.daily/   # 매일 실행되는 스크립트
/etc/cron.weekly/  # 매주 실행되는 스크립트
/etc/cron.monthly/ # 매월 실행되는 스크립트
/etc/crontab       # 시스템 전체 crontab (사용자명 필드 추가됨)

# /etc/crontab 형식 (사용자명 필드 포함)
# 분 시 일 월 요일 사용자  명령
0  3  *  *  *  root  /usr/bin/updatedb
```

### cron 접근 제어

```bash
/etc/cron.allow    # 이 파일이 있으면 목록에 있는 사용자만 cron 사용 가능
/etc/cron.deny     # 이 파일이 있으면 목록에 있는 사용자는 cron 사용 불가
```

<Callout type="info">
  **우선순위:** `cron.allow`가 존재하면 `cron.deny`는 무시됩니다. `cron.allow`에 있는 사용자만 허용됩니다. 두 파일 모두 없으면 root만 사용 가능합니다(배포판에 따라 다름).
</Callout>

## at — 일회성 예약 작업

`at`은 지정한 시간에 한 번만 실행되는 작업을 예약합니다.

### at 명령 사용법

```bash
# 시간 지정 방법
at 14:30                   # 오늘 오후 2시 30분
at 14:30 tomorrow          # 내일 오후 2시 30분
at 14:30 2025-12-31        # 특정 날짜 오후 2시 30분
at now + 1 hour            # 1시간 후
at now + 30 minutes        # 30분 후
at midnight                # 자정
at noon                    # 정오

# 입력 예시
at 14:30
at> /usr/local/bin/backup.sh
at> <Ctrl+D>  # 입력 종료
# job 3 at Sat Aug 23 14:30:00 2025

# 파일에서 명령 읽기
at 14:30 < /path/to/script.sh
echo "/usr/local/bin/backup.sh" | at 14:30
```

### at 관련 명령

```bash
atq          # 대기 중인 at 작업 목록 표시 (at -l과 동일)
at -l        # 대기 중인 at 작업 목록
atrm 3       # 작업 번호 3번 삭제
at -d 3      # 작업 번호 3번 삭제 (atrm과 동일)
at -c 3      # 작업 번호 3번의 내용 확인
```

### at 접근 제어

```bash
/etc/at.allow    # 이 파일이 있으면 목록에 있는 사용자만 at 사용 가능
/etc/at.deny     # 이 파일이 있으면 목록에 있는 사용자는 at 사용 불가
```

## cron vs at 비교

| 항목 | cron | at |
|---|---|---|
| 실행 주기 | 반복 실행 | 일회성 실행 |
| 설정 방법 | crontab -e | at 시간 |
| 목록 확인 | crontab -l | atq |
| 삭제 | crontab -r | atrm 번호 |
| 접근 제어 | cron.allow / cron.deny | at.allow / at.deny |

## 핵심 정리

- `timedatectl set-timezone Asia/Seoul`: 시간대 설정
- `timedatectl set-ntp true`: NTP 동기화 활성화
- `chronyd`: 현재 표준 NTP 데몬, 설정 파일 `/etc/chrony.conf`, 상태 확인 `chronyc tracking`
- crontab 5필드: `분 시 일 월 요일 명령` (요일 0=일요일, 7=일요일)
- `*/5 * * * *`: 5분마다, `0 2 * * *`: 매일 새벽 2시, `0 9 * * 1-5`: 평일 오전 9시
- `/etc/cron.d/`, `/etc/cron.daily/`: 시스템 cron 디렉터리
- `/etc/cron.allow`: 존재 시 목록 사용자만 허용, `/etc/cron.deny`: 목록 사용자 차단
- `at 14:30`: 일회성 예약, `atq`: 대기 목록, `atrm 번호`: 삭제
