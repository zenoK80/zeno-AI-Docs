</Callout>

## 파일 권한 표기 읽기

`ls -l` 출력의 첫 번째 열이 권한이다:

```bash
ls -l /bin/bash
# 출력 예시
-rwxr-xr-x 1 root root 1396520 Jan  1 00:00 /bin/bash
```

권한 문자열 `-rwxr-xr-x` 분해:

| 위치 | 문자 | 의미 |
|------|------|------|
| 1번째 | `-` | 파일 유형 (`-`=파일, `d`=디렉터리, `l`=링크) |
| 2~4번째 | `rwx` | **소유자**(owner) 권한 |
| 5~7번째 | `r-x` | **그룹**(group) 권한 |
| 8~10번째 | `r-x` | **기타**(others) 권한 |

각 권한 비트:

| 문자 | 값 | 파일 의미 | 디렉터리 의미 |
|------|-----|-----------|---------------|
| `r` | 4 | 읽기 | 디렉터리 내용 목록 조회 |
| `w` | 2 | 쓰기 | 파일 생성/삭제 |
| `x` | 1 | 실행 | 디렉터리 진입(cd) |
| `-` | 0 | 해당 권한 없음 | 해당 권한 없음 |

### 권한 8진수 변환 예시

`rwxr-xr--` → **754**
- `rwx` = 4+2+1 = **7**
- `r-x` = 4+0+1 = **5**
- `r--` = 4+0+0 = **4**

## chmod - 권한 변경

### 8진수 표기

```bash
# 소유자: 읽기+쓰기+실행(7), 그룹: 읽기+실행(5), 기타: 읽기만(4)
chmod 754 script.sh

ls -l script.sh
# 출력 예시
-rwxr-xr-- 1 zenok zenok 512 Jan 15 10:00 script.sh

# 모든 사용자 읽기+쓰기 (666)
chmod 666 shared.txt

# 소유자만 모든 권한, 나머지 없음 (700)
chmod 700 private_script.sh
```

### 기호 표기

| 대상 | 기호 |
|------|------|
| u | 소유자(user) |
| g | 그룹(group) |
| o | 기타(others) |
| a | 모든 사용자(all) |

| 연산 | 의미 |
|------|------|
| `+` | 권한 추가 |
| `-` | 권한 제거 |
| `=` | 정확히 지정 |

```bash
# 소유자에게 실행 권한 추가
chmod u+x script.sh

# 그룹과 기타에서 쓰기 권한 제거
chmod go-w important.conf

# 기타 사용자 권한 완전히 제거
chmod o= secret.txt

# 모든 사용자에게 읽기 권한 추가
chmod a+r README.txt

# 디렉터리 하위 전체에 적용 (-R: 재귀)
chmod -R 755 /var/www/html
```

## chown - 소유자 변경

```bash
# 소유자만 변경 (root 권한 필요)
chown zenok /tmp/myfile.txt

ls -l /tmp/myfile.txt
# 출력 예시 (변경 후)
-rw-r--r-- 1 zenok root 0 Jan 15 10:00 /tmp/myfile.txt

# 소유자와 그룹 동시 변경
chown zenok:developers /var/www/html/index.php

# 그룹만 변경 (:만 쓰고 소유자 생략)
chown :webdev /var/www/html/

# 재귀적으로 변경 (-R)
chown -R zenok:zenok /home/zenok/
```

## chgrp - 그룹 변경

```bash
# 파일 그룹 변경
chgrp developers project.py

# 재귀적으로 변경
chgrp -R webteam /var/www/html/
```

## 특수 권한

일반 rwx 외에 세 가지 특수 권한이 있다. 이들은 보안에 직접 영향을 미치므로 시험에 자주 출제된다.

### SetUID (SUID) - 4000

파일을 **실행할 때 소유자 권한**으로 실행된다.

```bash
# passwd 명령어 확인 (root 소유, SetUID 설정됨)
ls -l /usr/bin/passwd
# 출력 예시
-rwsr-xr-x 1 root root 68208 Jan  1 00:00 /usr/bin/passwd
#   ↑ s : SetUID가 설정되어 있음 (소유자 실행 비트 위치)

# 일반 사용자가 passwd 실행하면 root 권한으로 /etc/shadow 수정 가능
# → 이것이 SetUID의 용도

# SetUID 설정
chmod u+s /usr/local/bin/myapp
chmod 4755 /usr/local/bin/myapp

# 실행 권한 없이 SetUID만 설정 시 대문자 S로 표시
chmod 4644 testfile
ls -l testfile
# 출력 예시
-rwSr--r-- 1 root root 0 Jan 15 10:00 testfile
#   ↑ S (대문자): 실행권한 없는 SetUID
```

### SetGID (SGID) - 2000

- **파일에 설정:** 실행 시 **그룹 권한**으로 실행
- **디렉터리에 설정:** 해당 디렉터리에 생성되는 파일이 **디렉터리의 그룹을 상속**

```bash
ls -l /usr/bin/wall
# 출력 예시
-rwxr-sr-x 1 root tty 35048 Jan  1 00:00 /usr/bin/wall
#        ↑ s : SetGID가 설정됨 (그룹 실행 비트 위치)

# SetGID 설정 (디렉터리)
chmod g+s /shared/project
chmod 2755 /shared/project
```

### Sticky Bit - 1000

디렉터리에 설정 시, 해당 디렉터리 내 파일은 **파일 소유자만 삭제** 가능. (다른 사용자가 삭제 불가)

```bash
ls -ld /tmp
# 출력 예시
drwxrwxrwt 15 root root 4096 Jan 15 09:00 /tmp
#         ↑ t : Sticky Bit 설정됨

# Sticky Bit 설정
chmod +t /shared/uploads
chmod 1777 /shared/uploads
```

### 특수 권한 8진수 표기 정리

| 특수 권한 | 값 | 표기 위치 | `ls -l` 표시 |
|-----------|-----|-----------|--------------|
| SetUID | 4000 | 소유자 x 자리 | `s` (x 있을 때) / `S` (x 없을 때) |
| SetGID | 2000 | 그룹 x 자리 | `s` (x 있을 때) / `S` (x 없을 때) |
| Sticky Bit | 1000 | 기타 x 자리 | `t` (x 있을 때) / `T` (x 없을 때) |

```bash
# SetUID + 일반 755 권한
chmod 4755 /usr/local/bin/myapp
# → rwsr-xr-x

# Sticky Bit + 일반 777 권한
chmod 1777 /tmp
# → rwxrwxrwt
```

## umask - 기본 권한 마스크

`umask`는 새로 생성되는 파일과 디렉터리의 기본 권한에서 **차감**하는 값이다.

- 파일 기본 최대 권한: **666** (실행 권한 없음)
- 디렉터리 기본 최대 권한: **777**

```bash
# 현재 umask 확인
umask
# 출력 예시
0022

# 8진수로 확인
umask -S
# 출력 예시 (기호 표기)
u=rwx,g=rx,o=rx
```

### umask 계산 예시

**umask 022 일 때:**
- 파일: 666 - 022 = **644** (`rw-r--r--`)
- 디렉터리: 777 - 022 = **755** (`rwxr-xr-x`)

**umask 027 일 때:**
- 파일: 666 - 027 = **640** (`rw-r-----`)
- 디렉터리: 777 - 027 = **750** (`rwxr-x---`)

**umask 077 일 때:**
- 파일: 666 - 077 = **600** (`rw-------`)
- 디렉터리: 777 - 077 = **700** (`rwx------`)

```bash
# umask 임시 변경 (현재 셸 세션만)
umask 027

# 새 파일 생성 후 권한 확인
touch testfile.txt
ls -l testfile.txt
# 출력 예시
-rw-r----- 1 zenok zenok 0 Jan 15 10:00 testfile.txt
# 640 권한 적용됨

# 시스템 기본 umask 설정 파일
# /etc/profile 또는 /etc/bashrc, ~/.bashrc
```

<Callout type="info">
  umask는 단순 뺄셈이 아니라 **비트 AND NOT** 연산이지만, 시험에서는 뺄셈으로 계산해도 같은 결과가 나온다. 단, 666에서 음수가 나오는 경우(예: umask 777)는 0으로 처리한다.
</Callout>

## 핵심 정리

- 권한 3자리: 소유자(u)/그룹(g)/기타(o). r=4, w=2, x=1
- `chmod 755`: 소유자 rwx(7), 그룹 r-x(5), 기타 r-x(5)
- `chown user:group`: 소유자와 그룹 동시 변경
- SetUID(4000): 실행 시 소유자 권한. `/usr/bin/passwd` 예시
- SetGID(2000): 실행 시 그룹 권한. 디렉터리엔 그룹 상속
- Sticky Bit(1000): 디렉터리 내 파일을 소유자만 삭제. `/tmp` 예시
- umask 022 → 파일 644, 디렉터리 755 (기본값에서 차감)
