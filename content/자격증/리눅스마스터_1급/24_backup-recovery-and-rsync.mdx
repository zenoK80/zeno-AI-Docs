## tar — 아카이브 백업

tar(Tape ARchiver)는 여러 파일을 하나의 아카이브로 묶고 압축하는 표준 백업 도구입니다.

### tar 주요 옵션

| 옵션 | 역할 | 설명 |
|---|---|---|
| `-c` | Create | 아카이브 생성 |
| `-x` | eXtract | 아카이브 해제 |
| `-t` | lisT | 아카이브 내용 목록 확인 |
| `-z` | gzip | gzip 압축/해제 (.tar.gz, .tgz) |
| `-j` | bzip2 | bzip2 압축/해제 (.tar.bz2) |
| `-J` | xz | xz 압축/해제 (.tar.xz, 최고 압축률) |
| `-v` | Verbose | 진행 파일명 출력 |
| `-f` | File | 아카이브 파일 이름 지정 (항상 마지막) |
| `-p` | Preserve | 권한과 소유자 보존 |
| `-C` | directory | 압축 해제 경로 지정 |
| `--exclude` | - | 특정 경로 제외 |

### tar 기본 사용법

```bash
# 백업 생성 (c: create, z: gzip, v: verbose, f: file)
tar -czvf backup.tar.gz /data/           # /data/ 전체 백업
tar -czvf backup.tar.gz /data/ /etc/    # 여러 디렉터리 백업

# bzip2 압축 (더 높은 압축률, 느림)
tar -cjvf backup.tar.bz2 /data/

# xz 압축 (가장 높은 압축률, 가장 느림)
tar -cJvf backup.tar.xz /data/

# 아카이브 내용 목록 확인 (t: list)
tar -tzvf backup.tar.gz

# 아카이브 해제 (x: extract)
tar -xzvf backup.tar.gz                  # 현재 디렉터리에 해제
tar -xzvf backup.tar.gz -C /restore/    # 특정 경로에 해제
tar -xzvf backup.tar.gz data/file.txt   # 특정 파일만 해제

# 절대 경로 보존 없이 해제 (기본동작: /로 시작하는 경로에서 / 제거)
tar -xzvf backup.tar.gz -C /            # 원래 경로에 복원
tar -xzvf backup.tar.gz --strip-components=1  # 최상위 디렉터리 제거
```

### 특수 옵션

```bash
# 특정 경로 제외
tar -czvf backup.tar.gz /data/ --exclude=/data/cache --exclude=/data/tmp

# 권한과 소유자 보존 (root로 실행 시 자동, 일반 사용자는 -p 필요)
tar -czvpf backup.tar.gz /data/

# 아카이브에서 특정 파일만 해제
tar -xzvf backup.tar.gz ./data/important.txt
```

### 증분 백업 (변경된 파일만)

```bash
# 특정 날짜 이후 수정된 파일만 백업
tar -czvf incremental.tar.gz --newer-mtime="2025-08-01" /data/

# 특정 파일보다 최근에 수정된 파일만 백업
tar -czvf incremental.tar.gz --newer /var/backup/last_backup /data/

# 날짜 파일 업데이트 후 다음 증분 백업에 활용
touch /var/backup/last_backup
```

## rsync — 효율적인 파일 동기화

rsync는 소스와 대상을 비교하여 변경된 부분만 전송하는 강력한 동기화 도구입니다.

### rsync 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-a` | 아카이브 모드: 권한, 소유자, 타임스탬프, 심볼릭 링크 보존 (-rlptgoD와 동일) |
| `-v` | 상세 출력 (verbose) |
| `-z` | 전송 중 압축 (네트워크 전송 시 유용) |
| `-P` | 진행률 표시 + 부분 전송 재개 (--progress --partial) |
| `--delete` | 소스에 없는 파일을 대상에서 삭제 (정확한 미러링) |
| `--dry-run` | 실제 실행 없이 수행 내용 미리보기 (-n과 동일) |
| `-n` | --dry-run 단축 옵션 |
| `--exclude` | 특정 파일/디렉터리 제외 |
| `--bwlimit=KB` | 대역폭 제한 (KB/s 단위) |
| `-e ssh` | SSH를 통한 원격 전송 (기본값이므로 생략 가능) |
| `-r` | 재귀 복사 (디렉터리) |
| `-l` | 심볼릭 링크 보존 |
| `-u` | 소스가 더 최신인 경우만 덮어씀 |

### 로컬 동기화

```bash
# 기본 동기화 (소스 → 대상)
rsync -avz /data/ /backup/data/
# 주의: /data/ (슬래시 있음) = data 안의 내용 복사
#      /data  (슬래시 없음) = data 디렉터리 자체 복사

# 미러링 (대상을 소스와 동일하게, 소스에 없는 파일 삭제)
rsync -avz --delete /data/ /backup/data/

# 실행 전 미리보기
rsync -avz --delete --dry-run /data/ /backup/data/

# 특정 파일 제외
rsync -avz --exclude='*.log' --exclude='cache/' /data/ /backup/
```

### 원격 동기화 (SSH 기반)

```bash
# 로컬 → 원격 서버 동기화
rsync -avz /data/ user@192.168.1.10:/backup/data/
rsync -avzP /data/ user@server.example.com:/backup/  # 진행률 표시

# 원격 서버 → 로컬 동기화 (다운로드)
rsync -avz user@192.168.1.10:/backup/data/ /restore/

# SSH 포트 변경 시
rsync -avz -e "ssh -p 2222" /data/ user@server:/backup/

# SSH 키 인증 사용 (비밀번호 없이)
rsync -avz -e "ssh -i /root/.ssh/id_rsa" /data/ user@server:/backup/

# 삭제 포함 완전 미러링 + 압축
rsync -avz --delete /data/ user@server:/backup/data/
```

### rsync 데몬 모드

```bash
# rsync 데몬 설정 파일
cat /etc/rsyncd.conf
# [backup]
#     path = /backup
#     comment = Backup Directory
#     read only = no
#     hosts allow = 192.168.1.0/24

# 데몬 모드로 연결 (:: 사용)
rsync -avz /data/ rsync://server/backup/
rsync -avz /data/ server::backup/
```

## dd — 디스크 이미지 생성

dd는 블록 단위로 데이터를 복사하는 저수준 도구로 디스크 이미지 생성, 복제, 파티션 백업에 사용합니다.

```bash
# 디스크 전체 이미지 생성
dd if=/dev/sda of=/backup/sda.img bs=4M status=progress

# 이미지를 디스크에 복원
dd if=/backup/sda.img of=/dev/sdb bs=4M status=progress

# 파티션 이미지 생성
dd if=/dev/sda1 of=/backup/sda1.img bs=4M

# gzip 압축하면서 이미지 생성 (파이프 활용)
dd if=/dev/sda bs=4M | gzip > /backup/sda.img.gz

# 압축 이미지 복원
gzip -dc /backup/sda.img.gz | dd of=/dev/sdb bs=4M

# MBR만 백업 (첫 번째 512바이트)
dd if=/dev/sda of=/backup/mbr.bin bs=512 count=1

# MBR 복원
dd if=/backup/mbr.bin of=/dev/sda bs=512 count=1

# 디스크 완전 초기화 (0으로 채우기)
dd if=/dev/zero of=/dev/sdb bs=4M status=progress
```

<Callout type="warning">
  **dd 주의사항:** `if`(input file)와 `of`(output file) 순서를 반드시 확인하세요. if와 of를 반대로 입력하면 백업 파일이 지워집니다. `--dry-run` 옵션이 없으므로 실행 전 반드시 재확인하세요.
</Callout>

## 3-2-1 백업 규칙

안전한 백업을 위한 업계 표준 원칙입니다.

| 원칙 | 내용 |
|---|---|
| **3** | 3개의 데이터 복사본 유지 (원본 + 백업 2개) |
| **2** | 2가지 다른 저장 미디어 사용 (예: HDD + NAS) |
| **1** | 1개는 오프사이트(외부 장소) 보관 (예: 클라우드, 원격 서버) |

## cron을 이용한 자동 백업 스크립트

### 백업 스크립트 예시

```bash
#!/bin/bash
# /usr/local/bin/backup.sh

# 설정 변수
BACKUP_SRC="/data"
BACKUP_DEST="/backup"
REMOTE_USER="backup"
REMOTE_HOST="192.168.1.100"
REMOTE_PATH="/remote-backup"
DATE=$(date +%Y%m%d)
LOG_FILE="/var/log/backup.log"

echo "===== 백업 시작: $(date) =====" >> "$LOG_FILE"

# 1. 로컬 tar 백업 생성
tar -czvf "$BACKUP_DEST/data-$DATE.tar.gz" "$BACKUP_SRC" >> "$LOG_FILE" 2>&1

if [ $? -eq 0 ]; then
    echo "tar 백업 성공: data-$DATE.tar.gz" >> "$LOG_FILE"
else
    echo "tar 백업 실패!" >> "$LOG_FILE"
    exit 1
fi

# 2. 원격 서버로 rsync 동기화
rsync -avz --delete \
    -e "ssh -i /root/.ssh/backup_key" \
    "$BACKUP_DEST/" \
    "$REMOTE_USER@$REMOTE_HOST:$REMOTE_PATH/" >> "$LOG_FILE" 2>&1

if [ $? -eq 0 ]; then
    echo "원격 동기화 성공" >> "$LOG_FILE"
else
    echo "원격 동기화 실패!" >> "$LOG_FILE"
fi

# 3. 30일 이상 된 백업 파일 삭제
find "$BACKUP_DEST" -name "*.tar.gz" -mtime +30 -delete
echo "30일 초과 백업 파일 정리 완료" >> "$LOG_FILE"

echo "===== 백업 완료: $(date) =====" >> "$LOG_FILE"
```

### crontab에 자동 백업 등록

```bash
# 스크립트 실행 권한 부여
chmod +x /usr/local/bin/backup.sh

# crontab 편집
crontab -e

# 매일 새벽 2시에 백업 실행
0 2 * * * /usr/local/bin/backup.sh

# 매주 일요일 새벽 3시에 전체 백업 + 로그 기록
0 3 * * 0 /usr/local/bin/full-backup.sh >> /var/log/full-backup.log 2>&1

# 매월 1일 새벽 4시에 월간 백업
0 4 1 * * /usr/local/bin/monthly-backup.sh
```

## 핵심 정리

- tar 옵션 조합: `c`(생성)/`x`(해제)/`t`(목록) + `z`(gzip)/`j`(bzip2)/`J`(xz) + `v` + `f`
- `tar -czvf backup.tar.gz /data/`: gzip 압축 백업 생성
- `tar -xzvf backup.tar.gz -C /restore/`: 특정 경로에 해제
- `--newer-mtime="날짜"`: 증분 백업 (지정 날짜 이후 변경 파일만)
- rsync `-a`: 아카이브 모드(권한/소유자/타임스탬프/심볼릭 링크 보존)
- rsync `--delete`: 소스에 없는 파일 대상에서 삭제 (미러링)
- rsync `--dry-run`: 실제 실행 없이 미리보기
- 원격 동기화: `rsync -avz /data/ user@서버:/backup/`
- dd: `if=/dev/sda of=sda.img bs=4M`: 디스크 이미지 생성 (if/of 순서 주의)
- 3-2-1 규칙: 3개 복사본, 2가지 미디어, 1개 오프사이트
