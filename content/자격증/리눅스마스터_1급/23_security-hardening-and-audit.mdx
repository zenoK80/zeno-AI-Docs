## 계정 보안

### /etc/login.defs — 계정 기본 정책

```bash
cat /etc/login.defs

PASS_MAX_DAYS   90      # 비밀번호 최대 유효 기간 (일)
PASS_MIN_DAYS   7       # 비밀번호 최소 사용 기간 (일, 이전 변경 후 최소 대기)
PASS_MIN_LEN    8       # 비밀번호 최소 길이
PASS_WARN_AGE   14      # 비밀번호 만료 경고 기간 (일)

UID_MIN         1000    # 일반 사용자 UID 최솟값
UID_MAX         60000   # 일반 사용자 UID 최댓값
GID_MIN         1000    # 일반 그룹 GID 최솟값
GID_MAX         60000   # 일반 그룹 GID 최댓값

UMASK           077     # 기본 umask
CREATE_HOME     yes     # 홈 디렉터리 자동 생성
```

### PAM — 비밀번호 품질 정책 (pam_pwquality)

```bash
# /etc/security/pwquality.conf
cat /etc/security/pwquality.conf

minlen = 12        # 최소 길이
minclass = 3       # 최소 문자 종류 수 (대/소/숫자/특수)
maxrepeat = 3      # 같은 문자 최대 반복 횟수
dcredit = -1       # 숫자 최소 1개 필요
ucredit = -1       # 대문자 최소 1개 필요
lcredit = -1       # 소문자 최소 1개 필요
ocredit = -1       # 특수문자 최소 1개 필요
dictcheck = 1      # 사전 단어 사용 금지

# PAM 설정에서 활성화 확인
grep pam_pwquality /etc/pam.d/system-auth
# password requisite pam_pwquality.so try_first_pass local_users_only retry=3
```

### 계정 잠금과 비밀번호 관리

```bash
# 계정 잠금
usermod -L user1        # 계정 잠금 (비밀번호 앞에 ! 추가)
passwd -l user1         # 계정 잠금 (동일 효과)

# 계정 잠금 해제
usermod -U user1        # 잠금 해제
passwd -u user1         # 잠금 해제

# 계정 만료 설정
usermod -e 2025-12-31 user1    # 계정 만료일 설정
chage -E 2025-12-31 user1      # 동일 효과

# 비밀번호 정책 변경 (특정 사용자)
chage -M 90 user1      # 최대 유효 기간 90일
chage -m 7 user1       # 최소 사용 기간 7일
chage -W 14 user1      # 경고 기간 14일
chage -l user1         # 현재 비밀번호 정책 확인

# 다음 로그인 시 비밀번호 강제 변경
chage -d 0 user1
```

### sudo 설정

```bash
# sudo 설정 파일 편집 (visudo 사용 권장 — 문법 검사 포함)
visudo                        # /etc/sudoers 편집

# /etc/sudoers 주요 설정
# user1 ALL=(ALL) ALL                 # user1이 모든 명령 sudo 실행
# user1 ALL=(ALL) NOPASSWD: ALL       # 비밀번호 없이 sudo
# %wheel ALL=(ALL) ALL                # wheel 그룹 전체 허용
# user1 ALL=(ALL) /sbin/reboot        # 특정 명령만 허용

# sudoers.d 디렉터리 활용
echo "user1 ALL=(ALL) NOPASSWD: /usr/bin/systemctl" > /etc/sudoers.d/user1

# sudo 로그 확인
grep sudo /var/log/secure
```

## 파일 보안

### chattr — 파일 속성 설정

`chattr`은 파일에 특수 속성을 설정하여 root도 수정/삭제할 수 없도록 보호합니다.

```bash
# 불변 속성 설정 (+i: immutable)
chattr +i /etc/passwd         # 불변 속성 추가 (삭제/수정/링크 불가)
chattr +i /etc/shadow
chattr +i /etc/hosts

# 속성 제거 (-i)
chattr -i /etc/passwd

# 추가 전용 속성 (+a: append only)
chattr +a /var/log/secure     # 로그 파일에 적합 (추가만 가능)

# 속성 확인
lsattr /etc/passwd
# ----i--------e-- /etc/passwd  (i: immutable)
lsattr -R /etc/              # 재귀적 속성 확인
```

### 위험 파일 탐색

```bash
# 월드 쓰기 권한 파일 탐색 (모든 사용자가 쓸 수 있는 파일)
find / -perm -002 -type f 2>/dev/null
find / -perm -o+w -type f 2>/dev/null

# SUID 비트 파일 탐색 (소유자 권한으로 실행되는 파일)
find / -perm -4000 -type f 2>/dev/null
find / -perm /4000 -type f -ls 2>/dev/null

# SGID 비트 파일 탐색 (그룹 권한으로 실행)
find / -perm -2000 -type f 2>/dev/null

# 소유자 없는 파일 탐색 (삭제된 사용자의 파일)
find / -nouser -type f 2>/dev/null
find / -nogroup -type f 2>/dev/null

# 숨김 파일 탐색 (. 로 시작)
find /home -name ".*" -type f 2>/dev/null
```

## auditd — 감사 시스템

auditd는 커널 레벨에서 보안 이벤트를 기록하는 감사 데몬입니다.

### auditd 서비스 관리

```bash
systemctl enable --now auditd
systemctl status auditd

# 설정 파일
/etc/audit/auditd.conf      # 주 설정 (로그 파일 경로, 크기 등)
/etc/audit/rules.d/         # 감사 규칙 파일
/var/log/audit/audit.log    # 감사 로그
```

### /etc/audit/auditd.conf 주요 설정

```bash
log_file = /var/log/audit/audit.log   # 로그 파일 경로
max_log_file = 50                     # 최대 로그 파일 크기 (MB)
max_log_file_action = ROTATE          # 크기 초과 시 동작 (ROTATE/SYSLOG/SUSPEND)
num_logs = 5                          # 보관할 로그 파일 수
space_left = 100                      # 남은 공간 경고 임계값 (MB)
space_left_action = SYSLOG            # 공간 부족 시 동작
```

### auditctl — 감사 규칙 설정

```bash
# 파일 감시 규칙
auditctl -w /etc/passwd -p rwa -k passwd_change
# -w: 감시할 경로
# -p rwa: 읽기(r), 쓰기(w), 속성변경(a), 실행(x) 권한 감시
# -k: 검색 키워드 (이벤트 식별용)

auditctl -w /etc/sudoers -p rwa -k sudoers_change
auditctl -w /var/log/auth.log -p wa -k auth_log
auditctl -w /bin/ -p x -k binary_exec    # 바이너리 실행 감시

# 시스템 콜 감시
auditctl -a always,exit -F arch=b64 -S execve -k command_exec

# 현재 규칙 목록
auditctl -l

# 규칙 삭제
auditctl -D              # 모든 규칙 삭제
auditctl -W /etc/passwd  # 특정 규칙 삭제

# 영구 규칙 (재부팅 후에도 유지)
cat /etc/audit/rules.d/audit.rules
# -w /etc/passwd -p rwa -k passwd_change
# -w /etc/sudoers -p rwa -k sudoers_change
```

### ausearch — 감사 로그 검색

```bash
ausearch -k passwd_change              # 키워드로 검색
ausearch -k passwd_change -ts today   # 오늘 이벤트만
ausearch -k passwd_change -ts recent  # 최근 10분
ausearch -m AVC                       # SELinux 거부 이벤트
ausearch -m USER_LOGIN                # 로그인 이벤트
ausearch -ui 1000                     # UID 1000 사용자 이벤트
ausearch -p 1234                      # 특정 PID 이벤트

# 출력 형식 지정
ausearch -k passwd_change --format text  # 사람이 읽기 쉬운 형식
```

### aureport — 감사 요약 보고서

```bash
aureport                      # 전체 요약 보고서
aureport --login              # 로그인 이벤트 보고서
aureport --auth               # 인증 이벤트 보고서
aureport --failed             # 실패 이벤트 보고서
aureport --file               # 파일 접근 보고서
aureport --executable         # 실행 파일 보고서
aureport -ts today            # 오늘 이벤트만
```

## 로그 분석과 침해 탐지

### 주요 보안 로그 파일

```bash
/var/log/secure          # RHEL 계열: 인증/보안 로그
/var/log/auth.log        # Debian 계열: 인증 로그
/var/log/audit/audit.log # auditd 감사 로그
/var/log/messages        # 시스템 전반 로그
/var/log/syslog          # Debian 계열 시스템 로그
```

### 로그 분석 명령

```bash
# SSH 로그인 실패 탐지
grep "Failed password" /var/log/secure
grep "Failed password" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -rn

# 성공한 로그인
grep "Accepted password\|Accepted publickey" /var/log/secure

# 무차별 대입 공격 IP 탐지 (10회 이상 실패)
grep "Failed password" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -rn | awk '$1>10'

# 로그인 기록 확인
last                     # 최근 성공한 로그인 목록 (/var/log/wtmp)
lastb                    # 실패한 로그인 목록 (/var/log/btmp)
lastlog                  # 각 사용자의 마지막 로그인 시각
who                      # 현재 로그인한 사용자
w                        # 현재 로그인 사용자와 실행 중인 명령
```

### 불필요한 서비스 제거

```bash
# 현재 열린 포트 확인
ss -tuln                 # TCP/UDP 리스닝 포트
ss -tulnp                # 포트와 프로세스 정보 함께

# 불필요한 서비스 비활성화
systemctl disable --now telnet       # 텔넷 비활성화
systemctl disable --now rsh          # rsh 비활성화
systemctl disable --now vsftpd       # FTP 비활성화 (필요 없을 경우)

# 서비스 목록 확인
systemctl list-units --type=service --state=running  # 실행 중인 서비스
systemctl list-unit-files --type=service             # 전체 서비스 파일 목록
```

## 핵심 정리

- `/etc/login.defs`: 계정 기본 보안 정책 (PASS_MAX_DAYS, PASS_MIN_LEN 등)
- `/etc/security/pwquality.conf`: 비밀번호 복잡도 정책 (pam_pwquality.so)
- `usermod -L user1` / `passwd -l user1`: 계정 잠금
- `chage -M 90 user1`: 비밀번호 최대 유효 기간, `chage -d 0`: 즉시 변경 강제
- `visudo`: /etc/sudoers 안전 편집
- `chattr +i 파일`: 불변 속성(root도 삭제/수정 불가), `lsattr`: 속성 확인
- `find / -perm -4000 -type f`: SUID 파일 탐색, `find / -perm -002 -type f`: 월드 쓰기 가능 파일
- `auditctl -w /etc/passwd -p rwa -k passwd_change`: 파일 감시 규칙 등록
- `ausearch -k passwd_change`: 키로 감사 로그 검색, `aureport --login`: 로그인 보고서
- `grep "Failed password" /var/log/secure`: SSH 실패 로그인 확인
- `lastb`: 실패 로그인, `last`: 성공 로그인, `ss -tuln`: 열린 포트
