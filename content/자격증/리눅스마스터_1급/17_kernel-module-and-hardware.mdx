## 커널 버전 확인

현재 실행 중인 커널 정보를 확인할 때는 `uname` 명령을 사용합니다.

```bash
uname -r        # 커널 릴리즈 번호만 출력 (예: 5.14.0-362.8.1.el9.x86_64)
uname -a        # 모든 정보: 커널명, 호스트명, 릴리즈, 날짜, 아키텍처 등
uname -s        # 커널 이름 (Linux)
uname -m        # 하드웨어 아키텍처 (x86_64)
uname -n        # 네트워크 호스트명
uname -v        # 커널 버전(빌드 번호)
```

커널 이미지 파일은 `/boot/` 디렉터리에 저장됩니다.

```bash
ls /boot/vmlinuz*       # 커널 이미지 파일 목록
ls /boot/initramfs*     # initramfs 파일 목록 (RHEL 계열)
ls /boot/initrd*        # initrd 파일 목록 (Debian 계열)
ls /boot/System.map*    # 커널 심볼 테이블
```

## 커널 모듈 관리

리눅스 커널은 **모듈**(Module) 구조로 설계되어 있어 드라이버나 기능을 동적으로 로드하고 제거할 수 있습니다. 모듈 파일은 `.ko` 확장자를 가지며 `/lib/modules/$(uname -r)/` 아래에 저장됩니다.

### lsmod — 로드된 모듈 목록 확인

```bash
lsmod               # 현재 로드된 모듈 목록 표시
lsmod | grep nfs    # 특정 모듈 검색
```

출력 형식: `모듈명 | 크기(bytes) | 사용 횟수 | 의존 모듈`

### modinfo — 모듈 상세 정보

```bash
modinfo ext4              # ext4 모듈 정보 (설명, 작성자, 매개변수 등)
modinfo -F filename ext4  # 모듈 파일 경로만 출력
modinfo -F depends ext4   # 의존 모듈만 출력
```

### modprobe — 의존성을 포함한 모듈 로드/제거 (권장)

```bash
modprobe nfs                 # nfs 모듈과 의존 모듈을 함께 로드
modprobe -r nfs              # nfs 모듈과 의존 모듈을 함께 제거
modprobe -n nfs              # 실제 로드 없이 어떤 모듈이 로드될지 미리보기
modprobe --show-depends nfs  # 의존성 목록 출력
```

`modprobe`는 `/etc/modprobe.d/` 설정 파일을 참고하고, `modules.dep` 파일을 통해 의존성을 자동으로 처리합니다.

### insmod / rmmod — 단순 로드/제거 (의존성 처리 없음)

```bash
insmod /lib/modules/$(uname -r)/kernel/drivers/net/dummy.ko  # 절대 경로로 로드
rmmod dummy     # 모듈 제거 (사용 중이면 실패)
rmmod -f dummy  # 강제 제거 (비권장)
```

<Callout type="warning">
  **insmod vs modprobe:** `insmod`는 절대 경로를 지정해야 하고 의존성을 자동으로 해결하지 않습니다. 운영 환경에서는 반드시 `modprobe`를 사용하세요.
</Callout>

### 모듈 명령 비교

| 명령 | 역할 | 의존성 처리 |
|---|---|---|
| `lsmod` | 로드된 모듈 목록 조회 | - |
| `modinfo` | 모듈 상세 정보 조회 | - |
| `modprobe 모듈명` | 모듈 로드 | 자동 처리 |
| `modprobe -r 모듈명` | 모듈 제거 | 자동 처리 |
| `insmod 경로.ko` | 모듈 로드 | 수동 처리 필요 |
| `rmmod 모듈명` | 모듈 제거 | 수동 처리 필요 |

### 부팅 시 자동 로드 설정

```bash
# /etc/modules-load.d/ 디렉터리에 .conf 파일 생성
cat /etc/modules-load.d/mymodules.conf
# br_netfilter
# overlay

# 모듈 옵션 설정 (매개변수 포함)
cat /etc/modprobe.d/dummy.conf
# options dummy numdummies=4

# 블랙리스트 (특정 모듈 로드 금지)
cat /etc/modprobe.d/blacklist.conf
# blacklist nouveau
```

## 하드웨어 정보 조회

### lspci — PCI 장치 목록

```bash
lspci               # PCI 장치 전체 목록
lspci -v            # 상세 정보 포함
lspci -vv           # 매우 상세한 정보
lspci -nn           # 장치 ID(숫자) 포함
lspci | grep -i vga # 그래픽 카드만 필터
lspci | grep -i eth # 네트워크 카드 필터
```

### lsusb — USB 장치 목록

```bash
lsusb               # USB 장치 전체 목록
lsusb -v            # 상세 정보 (verbose)
lsusb -t            # 트리 형태로 표시
```

### lscpu — CPU 정보

```bash
lscpu                       # CPU 아키텍처, 코어 수, 스레드, 클럭, 캐시 정보
lscpu | grep "CPU(s)"       # 전체 CPU(논리 코어) 수
lscpu | grep "Core(s)"      # 물리 코어 수
lscpu | grep "Thread(s)"    # 코어당 스레드 수
```

### lsmem — 메모리 정보

```bash
lsmem               # 메모리 범위 및 사용 가능 여부
lsmem --summary     # 요약 정보만 출력
free -h             # 현재 메모리 사용량 (human-readable)
free -m             # MB 단위로 출력
```

### dmidecode — BIOS/하드웨어 상세 정보

```bash
dmidecode                          # 전체 DMI 정보 (BIOS, 메모리, CPU 등)
dmidecode -t bios                  # BIOS 정보만
dmidecode -t memory                # 메모리 슬롯 정보 (실제 장착 용량 확인)
dmidecode -t processor             # CPU 정보
dmidecode -s system-serial-number  # 시스템 시리얼 번호
```

### /proc 파일시스템으로 정보 확인

```bash
cat /proc/cpuinfo   # CPU 상세 정보 (모델명, 플래그 등)
cat /proc/meminfo   # 메모리 상세 정보 (MemTotal, MemFree, Buffers 등)
cat /proc/version   # 커널 버전 및 컴파일 정보
cat /proc/modules   # 로드된 모듈 목록 (lsmod 원본 데이터)
cat /proc/devices   # 등록된 블록/문자 장치 번호 목록
cat /proc/partitions # 파티션 정보
```

## 장치 파일과 /dev

리눅스에서 하드웨어는 `/dev/` 디렉터리의 **장치 파일**(device file) 을 통해 접근합니다.

| 장치 파일 | 설명 |
|---|---|
| `/dev/sda`, `/dev/sdb` | SATA/SCSI 디스크 (첫 번째, 두 번째) |
| `/dev/sda1`, `/dev/sda2` | 파티션 번호 |
| `/dev/nvme0n1` | NVMe SSD (첫 번째 컨트롤러, 첫 번째 네임스페이스) |
| `/dev/nvme0n1p1` | NVMe 파티션 |
| `/dev/tty0` | 첫 번째 가상 터미널 |
| `/dev/ttyS0` | 첫 번째 시리얼 포트 |
| `/dev/null` | 데이터 버림 (블랙홀) |
| `/dev/zero` | 0으로 채워진 데이터 생성 |
| `/dev/random` | 난수 생성기 |

장치 파일 유형은 `ls -l`의 첫 번째 글자로 구분합니다.

```bash
ls -l /dev/sda
# brw-rw---- 1 root disk 8, 0 ...
# b = 블록 장치 (block device): 디스크, CD-ROM 등

ls -l /dev/tty
# crw-rw-rw- 1 root tty 5, 0 ...
# c = 문자 장치 (character device): 터미널, 시리얼 포트 등
```

## sysfs와 /sys 파일시스템

`/sys/` 는 커널이 제공하는 가상 파일시스템으로 하드웨어 정보 조회와 커널 파라미터 변경에 사용됩니다.

```bash
ls /sys/class/net/             # 네트워크 인터페이스 목록
cat /sys/class/net/eth0/speed  # 네트워크 속도 (Mbps)
cat /sys/block/sda/size        # 디스크 섹터 수
ls /sys/bus/pci/devices/       # PCI 장치 목록
```

## sysctl — 커널 파라미터 관리

```bash
sysctl -a                             # 전체 커널 파라미터 목록
sysctl net.ipv4.ip_forward            # 특정 파라미터 값 조회
sysctl -w net.ipv4.ip_forward=1       # 파라미터 임시 변경 (재부팅 시 초기화)
sysctl -w kernel.hostname=myserver    # 호스트명 변경

# 영구 적용: /etc/sysctl.conf 또는 /etc/sysctl.d/*.conf 에 추가
echo "net.ipv4.ip_forward = 1" >> /etc/sysctl.d/99-forward.conf
sysctl --system   # 설정 파일 전체 재로드
sysctl -p         # /etc/sysctl.conf 재로드
```

자주 사용하는 커널 파라미터:

| 파라미터 | 기능 |
|---|---|
| `net.ipv4.ip_forward` | IP 포워딩 활성화 (라우터/NAT 용) |
| `net.ipv4.tcp_syncookies` | SYN Flood 공격 방어 |
| `vm.swappiness` | 스왑 사용 적극성 (0~100, 기본 60) |
| `kernel.core_pattern` | 코어 덤프 저장 경로 |
| `fs.file-max` | 시스템 전체 최대 파일 디스크립터 수 |

## 핵심 정리

- `uname -r`: 커널 릴리즈 번호, `uname -a`: 전체 커널 정보
- `lsmod`: 로드된 모듈 목록 조회, `modinfo`: 모듈 상세 정보
- `modprobe 모듈명`: 의존성 자동 처리 로드 (권장), `modprobe -r`: 의존성 포함 제거
- `insmod 경로.ko` / `rmmod 모듈명`: 의존성 처리 없는 단순 로드/제거
- `/etc/modules-load.d/`: 부팅 시 자동 로드할 모듈 설정
- 하드웨어 조회: `lspci`(PCI), `lsusb`(USB), `lscpu`(CPU), `lsmem`(메모리), `dmidecode`(BIOS/상세)
- 장치 파일 유형: `b`(블록 장치, 디스크), `c`(문자 장치, 터미널)
- `sysctl -w`: 임시 변경, `/etc/sysctl.d/`에 추가 후 `sysctl --system`: 영구 적용
