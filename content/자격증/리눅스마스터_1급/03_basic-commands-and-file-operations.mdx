## ls - 파일 목록 확인

```bash
ls -al /etc | head -10
# 출력 예시
total 1372
drwxr-xr-x 120 root root 12288 Jan 15 10:00 .
drwxr-xr-x  20 root root  4096 Jan 10 08:30 ..
-rw-r--r--   1 root root  3028 Jan  1 00:00 adduser.conf
drwxr-xr-x   3 root root  4096 Jan 10 08:31 alternatives
```

출력 필드 해석 (왼쪽부터):
1. 파일 유형+권한 (`-rw-r--r--`)
2. 하드링크 수
3. 소유자
4. 소유 그룹
5. 파일 크기(바이트)
6. 최종 수정 시각
7. 파일명

| 옵션 | 설명 |
|------|------|
| `-a` | 숨김 파일(`.`으로 시작) 포함 |
| `-l` | 상세 정보(권한, 소유자, 크기, 시간) |
| `-h` | 파일 크기를 K/M/G 단위로 표시 |
| `-r` | 역순 정렬 |
| `-t` | 수정 시간 순 정렬 |
| `-R` | 하위 디렉터리까지 재귀 출력 |

## cp - 파일/디렉터리 복사

```bash
# 파일 복사
cp /etc/hosts /tmp/hosts_backup
# 출력 없음 (성공 시)

# 디렉터리 전체 복사 (-r 필수)
cp -r /etc/nginx /tmp/nginx_backup

# 파일 속성(권한, 타임스탬프) 유지하며 복사
cp -p /etc/passwd /tmp/passwd_backup

# 덮어쓰기 전 확인
cp -i /etc/hosts /tmp/hosts_backup
# 출력 예시
cp: overwrite '/tmp/hosts_backup'? y
```

| 옵션 | 설명 |
|------|------|
| `-r` | 디렉터리 재귀 복사 |
| `-p` | 권한, 소유자, 타임스탬프 유지 |
| `-i` | 덮어쓰기 전 확인 |
| `-v` | 복사 과정 출력 |
| `-a` | `-r -p` 등 아카이브 모드 (백업에 유용) |

## mv - 파일/디렉터리 이동 또는 이름 변경

```bash
# 파일 이동
mv /tmp/hosts_backup /home/zenok/

# 파일 이름 변경 (같은 디렉터리 내)
mv old_name.txt new_name.txt

# 이동 전 확인 (-i)
mv -i report.txt /backup/
# 출력 예시
mv: overwrite '/backup/report.txt'? y
```

## rm - 파일/디렉터리 삭제

```bash
# 파일 삭제
rm /tmp/tempfile.txt

# 디렉터리 삭제 (-r 필수)
rm -r /tmp/old_directory

# 확인 없이 강제 삭제 (-f: force)
rm -rf /tmp/junk_dir

# 삭제 전 확인 (-i)
rm -i important.log
# 출력 예시
rm: remove regular file 'important.log'? y
```

<Callout type="warning">
  `rm -rf /`는 루트 이하 전체를 삭제하는 매우 위험한 명령이다. 현대 배포판은 `--no-preserve-root` 없이는 실행을 막는다. 항상 경로를 확인하고 실행하라.
</Callout>

## mkdir / rmdir - 디렉터리 생성/삭제

```bash
# 디렉터리 생성
mkdir /tmp/mydir

# 중간 경로까지 한 번에 생성 (-p)
mkdir -p /tmp/a/b/c

# 빈 디렉터리 삭제
rmdir /tmp/mydir

# rmdir은 비어 있지 않으면 실패 → rm -r 사용
rmdir /tmp/a
# 출력 예시
rmdir: failed to remove '/tmp/a': Directory not empty
```

## 파일 내용 확인

```bash
# 전체 내용 출력
cat /etc/hostname
# 출력 예시
myserver

# 행 번호 포함 출력
cat -n /etc/hosts
# 출력 예시
     1  127.0.0.1   localhost
     2  127.0.1.1   myserver
     3  ::1         localhost ip6-localhost

# 첫 5줄만 출력 (기본 10줄)
head -5 /var/log/syslog

# 마지막 20줄 출력
tail -20 /var/log/syslog

# 실시간으로 파일 끝 추적 (로그 모니터링)
tail -f /var/log/syslog

# 페이지 단위 출력 (스페이스: 다음 페이지, q: 종료)
less /etc/passwd
```

## touch - 파일 생성 또는 타임스탬프 변경

```bash
# 빈 파일 생성 (파일 없으면 생성, 있으면 타임스탬프만 갱신)
touch newfile.txt

# 타임스탬프 확인
ls -l newfile.txt
# 출력 예시
-rw-r--r-- 1 zenok zenok 0 Jan 15 11:30 newfile.txt
```

## ln - 하드링크와 심볼릭 링크

링크는 하나의 파일을 여러 이름으로 접근할 수 있게 한다. 두 종류의 링크는 동작 방식이 완전히 다르다.

### 하드링크(Hard Link)

```bash
# 하드링크 생성
ln /etc/hosts /tmp/hosts_hard

# inode 번호 확인 (-i 옵션)
ls -il /etc/hosts /tmp/hosts_hard
# 출력 예시
393216 -rw-r--r-- 2 root root 222 Jan  1 00:00 /etc/hosts
393216 -rw-r--r-- 2 root root 222 Jan  1 00:00 /tmp/hosts_hard
# → inode 번호(393216)가 동일함. 링크 수가 2로 증가
```

- 같은 **inode**를 공유 (같은 데이터 블록 가리킴)
- 원본 삭제 후에도 링크를 통해 데이터 접근 가능
- 디렉터리에 하드링크 불가, 다른 파일시스템에 하드링크 불가

### 심볼릭 링크(Symbolic Link = Soft Link)

```bash
# 심볼릭 링크 생성
ln -s /etc/hosts /tmp/hosts_link

# 링크 확인
ls -il /etc/hosts /tmp/hosts_link
# 출력 예시
393216 -rw-r--r-- 1 root root 222 Jan  1 00:00 /etc/hosts
524289 lrwxrwxrwx 1 root root  10 Jan 15 11:35 /tmp/hosts_link -> /etc/hosts
# → inode 번호가 다름. 파일 유형이 l(link)

# 원본 삭제 시 링크 깨짐
rm /etc/hosts
cat /tmp/hosts_link
# 출력 예시
cat: /tmp/hosts_link: No such file or directory
```

- **다른 inode**, 원본 경로를 가리키는 포인터
- 원본 삭제 시 링크가 깨짐 (dangling link)
- 디렉터리에도 사용 가능, 다른 파일시스템에도 사용 가능

### 하드링크 vs 심볼릭 링크 비교

| 항목 | 하드링크 | 심볼릭 링크 |
|------|----------|-------------|
| inode | 원본과 동일 | 별도의 inode |
| 원본 삭제 시 | 데이터 유지 | 링크 깨짐 |
| 디렉터리 가능 | 불가 | 가능 |
| 다른 파일시스템 | 불가 | 가능 |
| `ls -l` 표시 | `-` (일반 파일) | `l` (링크) |
| 생성 명령 | `ln 원본 링크명` | `ln -s 원본 링크명` |

## find - 파일 검색

```bash
# 이름으로 검색
find /home -name "*.conf"
# 출력 예시
/home/zenok/.ssh/config
/home/zenok/app.conf

# 파일 유형으로 검색 (f: 파일, d: 디렉터리, l: 심볼릭링크)
find /tmp -type f -name "*.log"

# 수정 시간 기준 검색 (-mtime +7: 7일 이전, -7: 7일 이내)
find /var/log -mtime +30 -type f

# 크기 기준 검색 (+100M: 100MB 초과)
find / -size +100M -type f 2>/dev/null

# 검색 후 명령 실행 (-exec)
find /home -name "*.conf" -type f -exec ls -l {} \;
# 출력 예시
-rw-r--r-- 1 zenok zenok 245 Jan 10 09:00 /home/zenok/app.conf

# 권한으로 검색 (SetUID 파일 찾기)
find / -perm -4000 -type f 2>/dev/null
# 출력 예시
/usr/bin/passwd
/usr/bin/sudo
```

| 옵션 | 설명 |
|------|------|
| `-name` | 파일명 패턴 |
| `-type` | 파일 유형 (f/d/l) |
| `-mtime` | 수정 시간 (일 단위) |
| `-size` | 파일 크기 |
| `-perm` | 권한 |
| `-user` | 소유자 |
| `-exec ... {} \;` | 찾은 파일에 명령 실행 |

## 핵심 정리

- `ls -al`: 숨김 파일 포함 상세 목록. 첫 번째 문자가 파일 유형(-, d, l)
- `cp -r`: 디렉터리 복사 필수 옵션. `-p`로 속성 보존
- `mv`: 이동과 이름 변경 모두 처리
- `rm -rf`: 강제 재귀 삭제. 경로 확인 필수
- `head -n`: 상위 n줄, `tail -f`: 실시간 추적
- 하드링크: 같은 inode, 원본 삭제 후 유지. 심볼릭링크: 다른 inode, 원본 삭제 시 깨짐
- `find -name -type -mtime -exec`: 강력한 파일 검색 도구
