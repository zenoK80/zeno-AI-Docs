## 패키지 관리 개요

| 계열 | 패키지 형식 | 저수준 도구 | 고수준 도구 |
|------|-------------|-------------|-------------|
| Red Hat 계열 | `.rpm` | `rpm` | `yum`, `dnf` |
| Debian 계열 | `.deb` | `dpkg` | `apt`, `apt-get` |

- **저수준 도구(rpm, dpkg):** 파일 직접 설치. 의존성 자동 해결 없음
- **고수준 도구(yum, dnf, apt):** 저장소(repository)에서 패키지와 의존성을 자동으로 찾아 설치

## RPM (Red Hat Package Manager)

RPM은 `.rpm` 패키지 파일을 직접 다루는 저수준 도구다. 의존성이 있을 경우 수동으로 해결해야 한다.

### rpm 패키지 파일명 규칙

```
nginx-1.24.0-1.el9.x86_64.rpm
 │      │     │    │      │
 │      │     │    │      └─ 아키텍처 (x86_64, i686, noarch)
 │      │     │    └─────── OS/배포판 (el9 = RHEL9)
 │      │     └──────────── 릴리즈 번호
 │      └────────────────── 버전
 └───────────────────────── 패키지명
```

### rpm 설치/업그레이드/삭제

```bash
# 패키지 설치 (-i: install, -v: verbose, -h: 진행률 표시)
rpm -ivh nginx-1.24.0-1.el9.x86_64.rpm
# 출력 예시
Verifying...                          ################################# [100%]
Preparing...                          ################################# [100%]
Updating / installing...
   1:nginx-1.24.0-1.el9               ################################# [100%]

# 업그레이드 (-U: upgrade, 없으면 설치도 됨)
rpm -Uvh nginx-1.25.0-1.el9.x86_64.rpm

# 신버전이 있을 때만 업그레이드 (-F: freshen)
rpm -Fvh nginx-*.rpm

# 패키지 삭제 (-e: erase)
rpm -e nginx
```

### rpm 조회(Query) 옵션

조회 옵션은 반드시 `-q`를 붙인다.

```bash
# 설치된 모든 패키지 목록
rpm -qa
# 출력 예시 (일부)
bash-5.1.8-6.el9.x86_64
glibc-2.34-60.el9.x86_64
nginx-1.24.0-1.el9.x86_64

# 특정 패키지 설치 여부 확인
rpm -q nginx
# 출력 예시 (설치됨)
nginx-1.24.0-1.el9.x86_64
# 출력 예시 (미설치)
package nginx is not installed

# 패키지 상세 정보 (-qi: query info)
rpm -qi nginx
# 출력 예시
Name        : nginx
Version     : 1.24.0
Release     : 1.el9
Architecture: x86_64
Install Date: Mon 15 Jan 2024 09:30:00 AM KST
Group       : System Environment/Daemons
Size        : 3012345
License     : BSD
Description : Nginx is a web server...

# 패키지에 속한 파일 목록 (-ql: query list)
rpm -ql nginx
# 출력 예시
/etc/logrotate.d/nginx
/etc/nginx/nginx.conf
/usr/sbin/nginx
/var/log/nginx

# 특정 파일이 어느 패키지에 속하는지 (-qf: query file)
rpm -qf /usr/sbin/nginx
# 출력 예시
nginx-1.24.0-1.el9.x86_64

# 패키지의 의존성 확인 (-qR: query requires)
rpm -qR nginx
# 출력 예시
/bin/sh
libc.so.6()(64bit)
libcrypto.so.3()(64bit)
```

| 옵션 조합 | 설명 |
|-----------|------|
| `-qa` | 설치된 모든 패키지 |
| `-q 패키지명` | 특정 패키지 설치 여부 |
| `-qi 패키지명` | 패키지 상세 정보 |
| `-ql 패키지명` | 패키지 파일 목록 |
| `-qf 파일경로` | 파일이 속한 패키지 |
| `-qR 패키지명` | 의존성 목록 |
| `-ivh` | 설치 + 진행률 |
| `-Uvh` | 업그레이드 |
| `-e` | 삭제 |

## YUM / DNF (의존성 자동 해결)

YUM(Yellowdog Updater Modified)은 RPM 기반 고수준 패키지 관리자다. DNF는 YUM의 개선판으로 Fedora, Rocky Linux 9+에서 기본 사용한다. 명령어 문법은 거의 동일하다.

```bash
# 패키지 설치 (의존성 자동 해결)
yum install nginx
dnf install nginx
# 출력 예시
Dependencies resolved.
==============================================
 Package       Arch     Version    Repository Size
==============================================
Installing:
 nginx         x86_64   1.24.0     appstream  587 k
Installing dependencies:
 nginx-core    x86_64   1.24.0     appstream  567 k
 ...
Is this ok [y/N]: y

# 패키지 삭제
yum remove nginx
dnf remove nginx

# 패키지 업데이트
yum update nginx
dnf update nginx

# 모든 패키지 업데이트
yum update
dnf upgrade

# 패키지 검색
yum search web server
dnf search nginx

# 패키지 정보 조회
yum info nginx
dnf info nginx
# 출력 예시
Name         : nginx
Version      : 1.24.0
Release      : 1.el9
Architecture : x86_64
Summary      : A high performance web server
...

# 설치된 패키지 목록
yum list installed
dnf list installed

# 사용 가능한 패키지 목록
yum list available
dnf list available

# 저장소 목록 확인
yum repolist
dnf repolist
# 출력 예시
repo id          repo name                           status
appstream        Rocky Linux 9 - AppStream           enabled
baseos           Rocky Linux 9 - BaseOS              enabled
```

### YUM vs RPM 핵심 차이

| 구분 | RPM | YUM/DNF |
|------|-----|---------|
| 의존성 해결 | 수동 | 자동 |
| 패키지 소스 | 로컬 .rpm 파일 | 온라인 저장소 |
| 사용 편의성 | 낮음 | 높음 |
| 패키지 검색 | 불가 | 가능 |

## APT (Debian 계열)

```bash
# 패키지 목록 업데이트 (설치 전 반드시 실행)
apt-get update
# 출력 예시
Hit:1 http://archive.ubuntu.com/ubuntu jammy InRelease
Get:2 http://archive.ubuntu.com/ubuntu jammy-updates InRelease [119 kB]
...

# 패키지 설치
apt-get install nginx

# 패키지 삭제 (설정 파일 유지)
apt-get remove nginx

# 패키지 삭제 (설정 파일까지 삭제)
apt-get purge nginx

# 모든 패키지 업그레이드
apt-get upgrade

# 패키지 검색
apt-cache search web server

# 패키지 정보
apt-cache show nginx

# 설치된 패키지 목록 (dpkg)
dpkg -l
dpkg -l nginx

# 파일이 속한 패키지 (dpkg)
dpkg -S /usr/sbin/nginx
# 출력 예시
nginx: /usr/sbin/nginx
```

## 소스 컴파일 설치 (3단계)

소스 코드에서 직접 컴파일하여 설치하는 방법. 패키지 저장소에 없거나 최신 버전이 필요할 때 사용한다.

### 1단계: ./configure - 환경 설정 및 Makefile 생성

```bash
# 압축 풀기
tar -xzf nginx-1.25.3.tar.gz
cd nginx-1.25.3

# configure 실행 (설치 경로, 활성화할 모듈 등 지정)
./configure --prefix=/usr/local/nginx --with-http_ssl_module
# 출력 예시
checking for OS
 + Linux 5.15.0-91-generic x86_64
checking for C compiler ... found
 + using GNU C compiler
 + gcc version: 11.4.0
...
Configuration summary
  + using system PCRE2 library
  + OpenSSL library: /usr/lib/x86_64-linux-gnu
nginx path prefix: "/usr/local/nginx"
```

`configure`는 시스템 환경(컴파일러, 라이브러리)을 확인하고 컴파일 설정이 담긴 `Makefile`을 생성한다.

### 2단계: make - 컴파일

```bash
# 소스 컴파일 (CPU 코어 수만큼 병렬 처리 -j)
make -j4
# 출력 예시
make -f objs/Makefile
make[1]: Entering directory '/root/nginx-1.25.3'
cc -c -pipe -O -W -Wall -Wpointer-arith ...
...
make[1]: Leaving directory '/root/nginx-1.25.3'
```

### 3단계: make install - 설치

```bash
# 컴파일된 파일을 시스템에 복사 (root 권한 필요)
make install
# 출력 예시
make -f objs/Makefile install
make[1]: Entering directory '/root/nginx-1.25.3'
test -d '/usr/local/nginx' || mkdir -p '/usr/local/nginx'
cp conf/nginx.conf '/usr/local/nginx/conf/nginx.conf'
...
```

### 전체 소스 설치 흐름

```bash
# 완전한 소스 설치 예시
wget https://nginx.org/download/nginx-1.25.3.tar.gz
tar -xzf nginx-1.25.3.tar.gz
cd nginx-1.25.3
./configure --prefix=/usr/local/nginx
make
make install

ls /usr/local/nginx/
# 출력 예시
conf/  html/  logs/  sbin/
```

<Callout type="info">
  소스 설치 순서: **configure → make → make install** 이 순서는 반드시 암기해야 한다. configure 없이 make 실행 시 Makefile이 없어 오류가 발생한다.
</Callout>

## 핵심 정리

- RPM: 의존성 수동 해결. `-ivh`(설치), `-Uvh`(업그레이드), `-e`(삭제)
- RPM 조회: `-qa`(전체목록), `-qi`(정보), `-ql`(파일목록), `-qf`(파일→패키지)
- YUM/DNF: 의존성 자동 해결. `install/remove/update/search/info`
- APT: Debian 계열. `apt-get update` → `apt-get install`
- `dpkg -l`: 설치된 패키지 목록, `dpkg -S 파일`: 파일이 속한 패키지
- 소스 설치 3단계: `./configure` → `make` → `make install`
