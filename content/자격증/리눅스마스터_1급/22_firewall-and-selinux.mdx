## firewalld — 동적 방화벽 관리

firewalld는 RHEL 7+ 이후 기본 방화벽 관리 도구로, zone 기반의 동적 방화벽을 지원합니다.

### 서비스 관리

```bash
systemctl enable --now firewalld
systemctl status firewalld
systemctl stop firewalld          # 방화벽 중지 (주의)
firewall-cmd --state              # 방화벽 실행 상태 확인
```

### 런타임 vs 영구 설정

```bash
# 런타임 변경 (즉시 적용, 재시작 시 사라짐)
firewall-cmd --add-port=8080/tcp

# 영구 변경 (재시작 후에도 유지, --permanent 필요)
firewall-cmd --permanent --add-port=8080/tcp

# 영구 변경을 런타임에 적용
firewall-cmd --reload

# 영구 + 런타임 동시 적용 (--runtime-to-permanent 또는 --permanent 후 --reload)
firewall-cmd --permanent --add-service=http
firewall-cmd --reload
```

### 주요 firewall-cmd 명령

```bash
# 현재 설정 전체 출력
firewall-cmd --list-all
firewall-cmd --list-all --zone=public

# 포트 관리
firewall-cmd --permanent --add-port=8080/tcp       # 포트 허용
firewall-cmd --permanent --remove-port=8080/tcp    # 포트 제거
firewall-cmd --list-ports                          # 허용된 포트 목록

# 서비스 관리 (포트 번호 기억 없이)
firewall-cmd --permanent --add-service=http        # http(80) 허용
firewall-cmd --permanent --add-service=https       # https(443) 허용
firewall-cmd --permanent --remove-service=ftp      # ftp 제거
firewall-cmd --list-services                       # 허용된 서비스 목록
firewall-cmd --get-services                        # 지원하는 서비스 목록

# 리치룰 (고급 규칙)
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" accept'
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="10.0.0.1" drop'
```

### Zone (존) 개념

존은 네트워크 신뢰도에 따라 다른 규칙을 적용합니다.

| Zone | 신뢰도 | 용도 |
|---|---|---|
| trusted | 최고 | 모든 트래픽 허용 |
| home | 높음 | 가정 네트워크 |
| internal | 높음 | 내부 네트워크 |
| work | 중간 | 회사 네트워크 |
| public | 낮음 | 공용 네트워크 (기본값) |
| external | 낮음 | 외부 네트워크 (NAT) |
| dmz | 낮음 | DMZ 서버 |
| block | 매우 낮음 | 인바운드 차단 (아웃바운드 허용) |
| drop | 최저 | 모든 인바운드 무조건 폐기 |

```bash
# 기본 존 확인 및 변경
firewall-cmd --get-default-zone
firewall-cmd --set-default-zone=public

# 인터페이스를 특정 존에 할당
firewall-cmd --permanent --zone=trusted --add-interface=eth1

# 특정 IP를 존에 추가
firewall-cmd --permanent --zone=trusted --add-source=192.168.1.0/24
firewall-cmd --permanent --zone=public --add-source=10.0.0.0/8
```

## iptables — 전통적 방화벽

iptables는 넷필터(Netfilter) 프레임워크를 기반으로 하는 전통적인 리눅스 방화벽입니다.

### 체인(Chain) 구조

```
인바운드 트래픽: INPUT 체인
아웃바운드 트래픽: OUTPUT 체인
포워딩 트래픽: FORWARD 체인
```

### iptables 기본 명령

```bash
# 규칙 목록 조회
iptables -L             # 체인별 규칙 목록
iptables -L -n          # IP를 이름으로 변환하지 않음 (빠름)
iptables -L -n -v       # 패킷 카운터 포함 상세 출력
iptables -L INPUT -n    # INPUT 체인만 조회

# 규칙 추가 (-A: 끝에 추가, -I: 앞에 삽입)
iptables -A INPUT -p tcp --dport 80 -j ACCEPT       # HTTP 허용
iptables -A INPUT -p tcp --dport 443 -j ACCEPT      # HTTPS 허용
iptables -A INPUT -p tcp --dport 22 -j ACCEPT       # SSH 허용
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT  # 기존 연결 허용
iptables -A INPUT -j DROP                           # 나머지 모두 차단

# 특정 IP 차단
iptables -A INPUT -s 10.0.0.1 -j DROP
iptables -A INPUT -s 10.0.0.0/8 -j DROP

# 특정 IP에서 특정 포트 허용
iptables -A INPUT -s 192.168.1.0/24 -p tcp --dport 3306 -j ACCEPT

# 규칙 삭제
iptables -D INPUT -p tcp --dport 80 -j ACCEPT  # 규칙 삭제
iptables -F INPUT    # INPUT 체인 모든 규칙 삭제
iptables -F          # 전체 규칙 삭제

# 기본 정책 설정
iptables -P INPUT DROP    # 기본 정책을 DROP으로 (화이트리스트 방식)
iptables -P INPUT ACCEPT  # 기본 정책을 ACCEPT로 (블랙리스트 방식)
```

### iptables 설정 저장과 복원

```bash
# 현재 규칙 저장
iptables-save > /etc/iptables/rules.v4
iptables-save > /root/iptables.backup

# 저장된 규칙 복원
iptables-restore < /etc/iptables/rules.v4

# RHEL 계열에서 영구 저장
service iptables save   # /etc/sysconfig/iptables에 저장
```

## SELinux — 강제 접근 제어

SELinux(Security Enhanced Linux)는 NSA가 개발한 MAC(Mandatory Access Control) 시스템으로, 프로세스가 접근할 수 있는 파일, 포트, 프로세스를 정책으로 세밀하게 제어합니다.

### SELinux 모드

| 모드 | 설명 |
|---|---|
| Enforcing | 정책을 강제 적용, 위반 시 접근 거부 및 로그 기록 |
| Permissive | 정책 위반을 로그에만 기록, 실제 차단 없음 (디버깅용) |
| Disabled | SELinux 완전 비활성화 |

```bash
# 현재 모드 확인
getenforce          # Enforcing / Permissive / Disabled 출력
sestatus            # SELinux 상태 상세 정보

# 임시 모드 변경 (재부팅 시 원래 모드로)
setenforce 0        # Permissive 모드로 전환
setenforce 1        # Enforcing 모드로 전환
```

### 영구 모드 변경

```bash
cat /etc/selinux/config

# SELINUX=enforcing    ← 기본값 (권장)
# SELINUX=permissive   ← 디버깅 시
# SELINUX=disabled     ← 완전 비활성화 (재부팅 필요)

# disabled → enforcing 변경 후 재부팅 시 .autorelabel 파일 생성 권장
touch /.autorelabel
reboot
```

### SELinux 컨텍스트 확인

모든 파일, 프로세스, 포트에는 `사용자:역할:타입:레벨` 형식의 컨텍스트가 붙습니다.

```bash
# 파일 컨텍스트 확인
ls -Z /var/www/html/        # 파일 컨텍스트
ls -Z /etc/passwd

# 프로세스 컨텍스트 확인
ps -Z                       # 모든 프로세스 컨텍스트
ps -Z | grep httpd          # httpd 프로세스 컨텍스트

# 포트 컨텍스트 확인
semanage port -l            # 모든 포트 컨텍스트
semanage port -l | grep http  # http 관련 포트
```

### 파일 컨텍스트 변경

```bash
# 일시적 컨텍스트 변경 (재레이블링 시 원복)
chcon -t httpd_sys_content_t /var/www/html/mysite/
chcon -R -t httpd_sys_content_t /var/www/html/mysite/   # 재귀

# 기본 컨텍스트로 복원
restorecon /var/www/html/mysite/
restorecon -R /var/www/html/           # 재귀 복원
restorecon -Rv /var/www/html/          # 재귀 + 변경 내용 출력

# 영구적 컨텍스트 규칙 추가
semanage fcontext -a -t httpd_sys_content_t '/custom/web(/.*)?'
restorecon -Rv /custom/web/
```

### SELinux Boolean — 정책 스위치

```bash
# Boolean 목록 확인
getsebool -a                          # 전체 Boolean 목록
getsebool httpd_can_network_connect   # 특정 Boolean 확인
semanage boolean -l | grep httpd      # httpd 관련 Boolean

# Boolean 변경
setsebool httpd_can_network_connect on    # 임시 변경
setsebool -P httpd_can_network_connect on # 영구 변경 (-P 옵션)

# 자주 사용하는 Boolean
setsebool -P httpd_can_network_connect on     # httpd가 외부 네트워크 연결 허용
setsebool -P httpd_enable_homedirs on         # httpd가 사용자 홈 디렉터리 서빙
setsebool -P ftp_home_dir on                  # FTP 사용자가 홈 디렉터리 접근
setsebool -P allow_ftpd_full_access on        # FTP 전체 접근 허용
```

### SELinux 로그 분석과 정책 생성

```bash
# SELinux 거부 로그 확인
grep "avc: denied" /var/log/audit/audit.log
ausearch -m AVC -ts today                # 오늘 AVC 거부 로그
ausearch -m AVC -c httpd                 # httpd 관련 거부 로그

# 거부 메시지로 정책 자동 생성 (audit2allow)
ausearch -m AVC | audit2allow            # 정책 규칙 출력
ausearch -m AVC | audit2allow -M mypolicy  # 정책 모듈 파일 생성
semodule -i mypolicy.pp                  # 정책 모듈 설치
```

## 핵심 정리

- `firewall-cmd --permanent --add-port=8080/tcp`: 영구 포트 허용 후 `--reload`로 적용
- `firewall-cmd --list-all`: 현재 존의 전체 방화벽 규칙 확인
- 존(zone): public(기본), trusted(전체 허용), dmz, drop(전체 차단) 등
- iptables 체인: INPUT(인바운드), OUTPUT(아웃바운드), FORWARD(포워딩)
- `iptables -A INPUT -p tcp --dport 80 -j ACCEPT`: HTTP 허용
- `iptables-save > 파일`, `iptables-restore < 파일`: 규칙 저장/복원
- SELinux 모드: Enforcing(강제), Permissive(감사만), Disabled(비활성화)
- `getenforce`: 현재 모드 확인, `setenforce 0/1`: 임시 전환
- `/etc/selinux/config`: 영구 모드 설정
- `ls -Z`: 파일 컨텍스트, `ps -Z`: 프로세스 컨텍스트
- `chcon -t 타입 경로`: 임시 컨텍스트 변경, `restorecon -R 경로`: 기본값 복원
- `setsebool -P Boolean on`: Boolean 영구 변경
