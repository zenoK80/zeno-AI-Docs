## 파일 권한과 특수 권한

| 권한 | 의미 | 8진수 |
|------|------|------|
| SUID | 소유자 권한으로 실행 | 4000 |
| SGID | 그룹 권한으로 실행 | 2000 |
| Sticky Bit | 소유자만 삭제 가능 | 1000 |

**umask**: 기본 권한에서 빼는 마스크. 파일=666-umask, 디렉터리=777-umask

---

## 핵심 설정 파일 경로

| 파일 | 설명 |
|------|------|
| /etc/passwd | 사용자 계정 정보 |
| /etc/shadow | 암호화된 비밀번호 |
| /etc/group | 그룹 정보 |
| /etc/hosts | 로컬 호스트명-IP 매핑 |
| /etc/resolv.conf | DNS 서버 주소 |
| /etc/fstab | 자동 마운트 설정 |
| /etc/crontab | 시스템 cron 설정 |
| /etc/sshd/sshd_config | SSH 서버 설정 |
| /etc/samba/smb.conf | Samba 설정 |
| /etc/exports | NFS 공유 설정 |
| /etc/httpd/conf/httpd.conf | Apache 설정 |
| /etc/nginx/nginx.conf | Nginx 설정 |

## 핵심 명령어 요약

### 프로세스 관리
```
ps aux              # 전체 프로세스
kill -9 PID         # SIGKILL 강제 종료
kill -15 PID        # SIGTERM 정상 종료
nice -n 10 명령     # 우선순위 낮춰 실행
renice 5 -p PID     # 실행 중 우선순위 변경
```

### 네트워크
```
ip addr show        # IP 주소 확인
ip route show       # 라우팅 테이블
ss -tuln            # 열린 포트 확인
tcpdump -i eth0     # 패킷 캡처
nmap 192.168.1.0/24 # 포트 스캔
```

### 디스크 관리
```
df -h               # 파일 시스템 사용량
du -sh /경로        # 디렉터리 사용량
lsblk               # 블록 디바이스 목록
fdisk -l            # 파티션 정보
mkfs.ext4 /dev/sdb1 # ext4 포맷
mount /dev/sdb1 /mnt # 마운트
```

## 시그널 번호

| 번호 | 이름 | 동작 |
|------|------|------|
| 1 | SIGHUP | 재시작 |
| 2 | SIGINT | Ctrl+C |
| 9 | SIGKILL | 강제 종료 (무시 불가) |
| 15 | SIGTERM | 정상 종료 요청 |
| 18 | SIGCONT | 프로세스 재개 |
| 19 | SIGSTOP | 프로세스 중지 (무시 불가) |
