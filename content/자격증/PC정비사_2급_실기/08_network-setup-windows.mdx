## IP 주소 수동 설정 (GUI)

1. Win + R → `ncpa.cpl` 입력 (또는 설정 → 네트워크 및 인터넷 → 이더넷 → 어댑터 설정 변경)
2. 사용할 네트워크 어댑터(예: 이더넷) 우클릭 → 속성
3. 인터넷 프로토콜 버전 4(TCP/IPv4) 더블클릭
4. 다음 IP 주소 사용 선택
5. IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 주소 입력
6. 확인 → 확인

**입력 예시:**

| 항목 | 값 예시 |
|------|---------|
| IP 주소 | 192.168.1.100 |
| 서브넷 마스크 | 255.255.255.0 |
| 기본 게이트웨이 | 192.168.1.1 |
| 기본 설정 DNS 서버 | 8.8.8.8 (Google) |
| 보조 DNS 서버 | 8.8.4.4 |

## IP 주소 수동 설정 (PowerShell)

관리자 권한 PowerShell에서 실행한다.

```powershell
# IP 주소 설정
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.100 -PrefixLength 24 -DefaultGateway 192.168.1.1

# DNS 설정
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 8.8.8.8,8.8.4.4

# 현재 IP 설정 확인
Get-NetIPAddress -InterfaceAlias "Ethernet"

# IP 설정 제거 (DHCP로 복원)
Remove-NetIPAddress -InterfaceAlias "Ethernet" -Confirm:$false
Set-NetIPInterface -InterfaceAlias "Ethernet" -Dhcp Enabled
```

`-PrefixLength 24`는 서브넷 마스크 255.255.255.0과 동일하다.

## 네트워크 진단 명령어

시험에서 직접 명령어를 입력하고 결과를 해석해야 한다.

### ipconfig 계열

```
# 기본 IP 정보 확인
ipconfig

# 전체 정보 (MAC 주소, DHCP 서버, DNS 서버 포함)
ipconfig /all

# DHCP IP 주소 반납
ipconfig /release

# DHCP IP 주소 새로 할당받기
ipconfig /renew

# DNS 캐시 삭제
ipconfig /flushdns

# DNS 캐시 내용 보기
ipconfig /displaydns
```

### ping (연결 확인)

```
# 인터넷 연결 확인 (Google DNS)
ping 8.8.8.8

# 게이트웨이 연결 확인
ping 192.168.1.1

# 도메인 이름으로 확인 (DNS 동작 확인)
ping google.com

# 연속 ping (Ctrl+C로 중지)
ping -t 8.8.8.8

# 패킷 크기 지정
ping -l 1472 8.8.8.8
```

### tracert (경로 추적)

```
# 목적지까지의 라우팅 경로 추적
tracert 8.8.8.8

# DNS 이름 조회 없이 IP만 표시 (속도 빠름)
tracert -d 8.8.8.8
```

### netstat (포트/연결 상태 확인)

```
# 모든 포트 상태 확인
netstat -an

# 프로세스 ID 포함 표시
netstat -ano

# 수신 대기(LISTENING) 포트만 확인
netstat -an | findstr LISTENING
```

### nslookup (DNS 조회)

```
# 도메인 IP 조회
nslookup google.com

# 특정 DNS 서버로 조회
nslookup google.com 8.8.8.8
```

## 공유 폴더 설정

### GUI 방법

1. 공유할 폴더 우클릭 → 속성
2. 공유 탭 → 공유 클릭
3. 사용자 또는 Everyone 추가 후 권한 수준(읽기/읽기·쓰기) 설정
4. 공유 클릭 → 완료

고급 공유를 사용하면 공유 이름과 최대 사용자 수를 세밀히 설정할 수 있다.

### 네트워크 검색 활성화

공유 폴더에 접근하려면 같은 네트워크의 상대방 PC도 네트워크 검색이 켜져 있어야 한다.

1. 제어판 → 네트워크 및 공유 센터 → 고급 공유 설정
2. 현재 프로필(개인 또는 공용)에서 "네트워크 검색 켜기" 선택
3. "파일 및 프린터 공유 켜기" 선택 후 변경 내용 저장

## 네트워크 스택 초기화

네트워크 연결이 지속적으로 문제가 될 때 TCP/IP 스택과 Winsock을 초기화한다.

```
# TCP/IP 스택 초기화 (관리자 권한 필요)
netsh int ip reset

# Winsock 초기화
netsh winsock reset

# 방화벽 초기화
netsh advfirewall reset

# 초기화 후 재시작 필수
shutdown /r /t 0
```

## 핵심 정리

- IP 고정 설정: ncpa.cpl → IPv4 속성 → 수동 입력
- `ipconfig /all`: MAC 주소, DNS, DHCP 서버 확인
- `ipconfig /flushdns`: DNS 캐시 초기화
- `ping 8.8.8.8`: 인터넷 연결 확인
- `tracert`: 목적지까지 경로 추적
- 네트워크 초기화: `netsh int ip reset` + `netsh winsock reset`
