## Windows 내장 백업 방법

### 파일 기록(File History)

개인 파일을 외장 드라이브 또는 네트워크 드라이브에 자동으로 정기 백업하는 기능이다.

1. 설정 → 업데이트 및 보안 → 백업
2. 드라이브 추가 → 외장 HDD 또는 네트워크 드라이브 선택
3. 자동 파일 백업 켜기 (기본: 1시간마다)
4. 고급 설정에서 백업 주기, 보관 기간 조정 가능

백업 대상: 라이브러리(문서, 사진, 음악, 동영상), 바탕화면, 즐겨찾기, 연락처

### 시스템 이미지 백업

시스템 전체를 스냅샷으로 저장하여 재난 복구(DR)에 사용한다.

1. 제어판 → 백업 및 복원(Windows 7)
2. 시스템 이미지 만들기
3. 저장 위치 선택: 하드 디스크, DVD, 네트워크 위치
4. 백업할 드라이브 선택 후 시작

복구 시: WinRE → 시스템 이미지 복구 선택

### 복구 드라이브 만들기

시스템이 부팅 안 될 때를 대비한 USB 복구 미디어이다.

1. "복구 드라이브 만들기" 검색 후 실행
2. 시스템 파일을 복구 드라이브에 백업 체크
3. USB 드라이브 선택 (16 GB 이상 권장)
4. 만들기 클릭 (30분~1시간 소요)

## robocopy (강력한 파일 복사 도구)

robocopy는 Windows 내장 명령으로, xcopy보다 강력한 미러링과 오류 재시도 기능을 제공한다.

```
robocopy C:\Users\문서 D:\Backup\문서 /MIR /R:3 /W:5 /LOG:D:\backup_log.txt
```

### 주요 옵션

| 옵션 | 의미 |
|------|------|
| /MIR | 미러링: 원본 삭제된 파일도 대상에서 삭제 |
| /E | 빈 하위 폴더 포함 복사 |
| /COPYALL | 파일 속성, 보안, 타임스탬프 모두 복사 |
| /R:3 | 오류 시 3번 재시도 |
| /W:5 | 재시도 간격 5초 대기 |
| /LOG:파일경로 | 복사 로그를 파일로 저장 |
| /XF 패턴 | 특정 파일 제외 (예: /XF *.tmp) |
| /XD 폴더 | 특정 폴더 제외 |
| /FFT | FAT 파일 시간 허용 (2초 오차 허용) |

### 사용 예시

```
# 문서 폴더 미러링 백업
robocopy "C:\Users\사용자명\Documents" "D:\Backup\Documents" /MIR /R:3 /W:5

# 모든 하위 폴더 포함 복사
robocopy C:\Data D:\Backup\Data /E /COPYALL

# 특정 확장자 제외
robocopy C:\Data D:\Backup /MIR /XF *.tmp *.log
```

## xcopy (기본 파일 복사)

```
xcopy C:\Data D:\Backup /E /I /H /Y
```

| 옵션 | 의미 |
|------|------|
| /E | 빈 폴더 포함 하위 폴더 모두 복사 |
| /I | 대상이 폴더인 경우 폴더로 복사 |
| /H | 숨김 파일 및 시스템 파일 포함 |
| /Y | 덮어쓰기 확인 없이 자동 수락 |

xcopy는 /MIR 기능이 없어 삭제된 파일을 대상에서 제거하지 않는다. 미러링이 필요하면 robocopy를 사용한다.

## 파티션 이미지 백업 도구

| 도구 | 특징 |
|------|------|
| Clonezilla | 무료 오픈소스, USB 부팅 기반, 디스크 클론 |
| Macrium Reflect Free | GUI 기반, Windows에서 실행, 무료 |
| Acronis True Image | 유료, 기능 풍부, 클라우드 백업 지원 |

Clonezilla는 USB로 부팅하여 디스크 전체 또는 파티션을 이미지 파일로 저장하거나 다른 디스크로 직접 클론할 수 있다.

## BitLocker 드라이브 암호화

드라이브 전체를 암호화하여 분실 또는 도난 시 데이터 보호한다.

### 활성화 방법

1. 파일 탐색기에서 드라이브 우클릭 → BitLocker 켜기
2. 잠금 해제 방법 선택 (암호 또는 스마트 카드)
3. 복구 키 백업 방법 선택 (Microsoft 계정, 파일 저장, 인쇄)
4. 암호화 시작

<Callout type="warning">
  복구 키를 반드시 안전한 곳에 보관해야 한다. 복구 키를 잃으면 드라이브 데이터에 영구적으로 접근 불가하다.
</Callout>

### PowerShell로 BitLocker 상태 확인

```powershell
# BitLocker 상태 확인
Get-BitLockerVolume

# BitLocker 활성화 (C 드라이브)
Enable-BitLocker -MountPoint "C:" -RecoveryPasswordProtector
```

## 3-2-1 백업 규칙

랜섬웨어와 재해 복구에 대비한 백업 전략이다.

- **3:** 데이터 복사본을 3개 이상 유지
- **2:** 서로 다른 2가지 미디어(HDD + 클라우드 등)에 저장
- **1:** 1개는 외부 오프사이트(오프라인 외장 HDD, NAS 또는 클라우드)에 보관

랜섬웨어는 연결된 모든 드라이브를 암호화하므로 오프라인 백업(USB, 외장 HDD 분리 보관)이 필수이다.

## 핵심 정리

- 파일 기록: 설정 → 백업, 자동 정기 백업
- robocopy /MIR: 원본과 완전히 동일한 미러 복사
- xcopy /E /H /Y: 숨김 파일 포함 하위 폴더 전체 복사
- BitLocker: 드라이브 암호화, 복구 키 안전 보관 필수
- 3-2-1 규칙: 3개 복사본, 2가지 미디어, 1개 오프사이트
