  **이번 문서의 목표:** USB 부팅 미디어를 만들고 Windows 10/11 새 설치를 처음부터 끝까지 순서대로 수행할 수 있다.
</Callout>

## USB 부팅 디스크 만들기

### 방법 1: Rufus (추천)

1. Rufus 공식 사이트에서 프로그램 다운로드 (rufus.ie)
2. USB 드라이브(8GB 이상) 연결
3. Rufus 실행 → 장치: USB 선택
4. 부트 선택: Windows ISO 파일 선택
5. 파티션 구성: GPT / 대상 시스템: UEFI(CSM 제외)
6. 파일 시스템: NTFS → 시작 클릭

### 방법 2: Windows Media Creation Tool (Microsoft 공식)

1. Microsoft 공식 홈페이지에서 Media Creation Tool 다운로드
2. 실행 → 다른 PC용 설치 미디어 만들기 선택
3. 언어, 버전, 아키텍처(64비트) 선택
4. USB 드라이브 선택 후 다운로드 및 쓰기 자동 진행

## Windows 11 최소 요구사항

| 항목 | 요구사항 |
|------|---------|
| CPU | Intel 8세대(Coffee Lake) 이상 또는 AMD Ryzen 2000 이상 |
| RAM | 4 GB 이상 |
| 저장공간 | 64 GB 이상 |
| 펌웨어 | UEFI, Secure Boot 지원 |
| TPM | TPM 2.0 |
| 디스플레이 | 720p 이상, 9인치 이상 |

<Callout type="warning">
  TPM 2.0과 Secure Boot가 없으면 Windows 11 공식 설치가 차단된다. BIOS에서 TPM 상태와 Secure Boot 활성화 여부를 먼저 확인하자.
</Callout>

## Windows 10/11 설치 순서

### 1단계: USB로 부팅

- BIOS/UEFI에서 부팅 순서를 USB 우선으로 변경
- PC 재시작 후 "Press any key to boot from USB..." 메시지 시 아무 키 입력

### 2단계: 언어 및 지역 설정

- 설치 언어: 한국어
- 시간 및 통화 형식: 한국어(대한민국)
- 키보드: Microsoft IME
- 지금 설치 클릭

### 3단계: 제품 키

- 제품 키 보유 시: 입력
- 없을 경우: "제품 키가 없음"을 클릭하여 건너뛰기 (나중에 활성화 가능)

### 4단계: 설치 유형 선택

- **업그레이드:** 기존 Windows를 유지하면서 버전 업그레이드 (기존 데이터 보존)
- **사용자 지정(새 설치):** 파티션을 새로 만들고 완전히 새로 설치 (기존 데이터 삭제)

**시험에서는 반드시 "사용자 지정(새 설치)"을 선택한다.**

### 5단계: 파티션 선택 및 생성

1. 기존 파티션이 있다면 모두 선택 후 삭제
2. 할당되지 않은 공간 선택
3. 새로 만들기 클릭 → 용량 설정 → 적용
4. Windows가 자동으로 시스템 파티션(EFI, MSR)을 생성
5. 기본 파티션(드라이브 0 파티션 X: 기본 파티션)을 선택 후 다음 클릭

### 6단계: 설치 진행

- 파일 복사, 업데이트 설치, 기능 설치가 자동 진행
- 여러 차례 자동 재부팅이 발생하므로 USB는 그대로 두되 재부팅 시 부팅 디스크에서는 부팅하지 않도록 주의

### 7단계: 초기 설정(OOBE)

- 국가/키보드 레이아웃 선택
- 네트워크 연결 (인터넷 연결 없이 로컬 계정 설정 권장)
- **로컬 계정 만들기 방법:** "인터넷이 없음" 또는 이더넷 케이블/Wi-Fi 연결 해제 후 진행 시 로컬 계정 생성 가능
- 사용자 이름, 암호, 보안 질문 설정

### 8단계: 설치 완료

- 바탕화면 진입 확인
- 장치 관리자에서 드라이버 설치 상태 확인
- Windows 업데이트 실행

## 활성화 상태 확인

```
# 활성화 상태 확인
slmgr /xpr

# 활성화 기간 상세 확인
slmgr /dlv

# 제품 키로 활성화
slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

# 온라인 활성화
slmgr /ato
```

## 시험 빈출 포인트

- 설치 유형: 반드시 "사용자 지정(새 설치)" 선택
- 파티션 삭제 후 새로 만들기 → 시스템 파티션 자동 생성
- Windows 11: TPM 2.0, Secure Boot, 8세대 이상 CPU 필수
- 로컬 계정: 인터넷 연결 해제 후 설치 진행

## 핵심 정리

- USB 부팅 미디어: Rufus 또는 Media Creation Tool
- 새 설치: 사용자 지정 → 파티션 삭제 → 새로 만들기 → 설치
- Windows 11 필수: TPM 2.0 + Secure Boot + 최신 CPU
- 활성화 확인: `slmgr /xpr`
