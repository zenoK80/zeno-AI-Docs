## POST(Power On Self Test)란?

전원을 켜는 순간 BIOS/UEFI가 자동으로 실행하는 하드웨어 자가 점검 과정이다.

POST 진행 순서:
1. CPU 초기화 및 마이크로코드 로드
2. 메모리(RAM) 검사
3. 그래픽카드(GPU) 초기화 → 화면 출력 시작
4. 저장장치(HDD/SSD) 감지
5. 확장 장치(USB, PCIe) 감지
6. 부팅 장치 선택 및 부트로더 실행

POST가 정상 완료되면 OS 부팅이 시작된다. POST 실패 시 비프음 또는 오류 화면이 표시된다.

## 비프음 코드 (Award BIOS 기준)

| 비프음 패턴 | 의미 | 조치 |
|-------------|------|------|
| 짧은 1번 | POST 정상 완료 | 없음 |
| 짧은 2번 | POST 일반 오류 | BIOS 설정 확인 |
| 긴 1번 + 짧은 2번 | 그래픽카드 오류 또는 미장착 | GPU 재장착, 모니터 케이블 확인 |
| 긴 1번 + 짧은 3번 | 비디오 메모리 오류 | 그래픽카드 RAM 불량 가능성 |
| 연속적으로 울림 | RAM 오류 또는 미장착 | RAM 재장착, 슬롯 변경 |
| 비프음 없음 + 화면 없음 | PSU 불량 또는 메인보드 사망 | 파워 점검, 메인보드 점검 |

<Callout type="warning">
  비프음 코드는 BIOS 제조사(Award, AMI, Phoenix)마다 다르다. ASUS, MSI 등 메인보드 제조사 매뉴얼을 확인하자.
</Callout>

## 증상별 진단 표

### 전원이 안 켜질 때

| 확인 항목 | 점검 방법 |
|-----------|-----------|
| 전원 케이블 연결 | 벽 콘센트, 파워 스트립, PSU 후면 케이블 확인 |
| PSU 스위치 | PSU 후면 I/O 스위치 ON 여부 확인 |
| 24핀 + 8핀 케이블 | 메인보드 전원 커넥터 완전 삽입 여부 |
| 파워서플라이 불량 | 클립으로 24핀 PS_ON핀과 GND 단락 후 팬 회전 테스트 |
| 케이스 전원 버튼 | 메인보드 PWR_SW 단자에 직접 단락 테스트 |

### 화면이 안 나올 때

| 확인 항목 | 점검 방법 |
|-----------|-----------|
| 모니터 전원 및 케이블 | 모니터 전원 ON, 케이블 연결 확인 |
| 모니터 입력 신호 선택 | 모니터 메뉴에서 HDMI/DP 입력 선택 |
| 그래픽카드 미장착/불량 | GPU 재장착, PCIe x16 슬롯 확인 |
| GPU 보조 전원 | PCIe 6핀/8핀 전원 케이블 연결 여부 |
| RAM 오류 | RAM 재장착, 슬롯 변경 |
| 내장 그래픽으로 테스트 | GPU 빼고 메인보드 내장 그래픽으로 연결 |

### 부팅 중 멈추거나 루프될 때

| 증상 | 원인 | 조치 |
|------|------|------|
| BIOS 화면에서 멈춤 | BIOS 설정 오류 | BIOS 초기화 |
| 부팅 로고 후 멈춤 | OS 손상, 부트로더 오류 | 시동 복구, SFC 실행 |
| 계속 재시작 반복 | 드라이버 충돌, OS 손상, 과열 | 안전 모드 진입 후 확인 |
| HDD/SSD 인식 안 됨 | SATA 케이블, 저장장치 불량 | 케이블 교체, SMART 확인 |

### 과열로 인한 강제 종료

| 확인 항목 | 조치 |
|-----------|------|
| CPU 쿨러 팬 동작 여부 | 팬 회전 확인, 전원 케이블 연결 확인 |
| 써멀 컴파운드 상태 | 오래된 경우 재도포 |
| 케이스 통풍 | 케이블 정리, 추가 케이스 팬 설치 |
| 흡기/배기 방향 | 전면 흡기, 후면 및 상단 배기 구성 확인 |
| CPU 온도 모니터링 | HWMonitor, Core Temp로 온도 확인 |

CPU 온도 기준: 대기 시 40도 이하, 부하 시 80~85도 이하가 정상이다. 90도를 초과하면 쓰로틀링(클럭 감소) 또는 강제 종료가 발생한다.

### 블루스크린(BSOD, Blue Screen of Death)

| 원인 | 주요 오류 코드 |
|------|--------------|
| 드라이버 충돌 | IRQL_NOT_LESS_OR_EQUAL, DRIVER_IRQL_NOT_LESS_OR_EQUAL |
| RAM 오류 | MEMORY_MANAGEMENT, PAGE_FAULT_IN_NONPAGED_AREA |
| 저장장치 오류 | CRITICAL_PROCESS_DIED, INACCESSIBLE_BOOT_DEVICE |
| 과열 | KERNEL_SECURITY_CHECK_FAILURE |

## 진단 도구

| 도구 | 용도 | 비고 |
|------|------|------|
| MemTest86 | RAM 오류 검사 | USB 부팅 실행, 무료 |
| CrystalDiskInfo | HDD/SSD S.M.A.R.T. 상태 확인 | 노란/빨간 표시 = 이상 |
| HWMonitor | CPU/GPU 온도, 전압, 팬 속도 | 실시간 모니터링 |
| Core Temp | CPU 코어별 온도 확인 | 경량 도구 |
| GPU-Z | 그래픽카드 상세 스펙 및 온도 | GPU 정보 |
| CPU-Z | CPU, 메인보드, RAM 스펙 확인 | 하드웨어 식별 |

## 이벤트 뷰어 활용

Windows 부팅 오류, 드라이버 오류 등 시스템 로그를 확인할 수 있다.

```
# 이벤트 뷰어 열기
Win + R → eventvwr.msc → Enter

# 확인 경로
Windows 로그 → 시스템 → 오류(빨간 X) 항목 확인
Windows 로그 → 응용 프로그램 → 오류 항목 확인
```

## 핵심 정리

- POST: 전원 ON 시 BIOS가 하드웨어를 자동 점검
- 연속 비프음: RAM 오류 / 긴1+짧은2: GPU 오류
- 과열 기준: CPU 90도 초과 시 쓰로틀링 또는 강제 종료
- 진단 도구: MemTest86(RAM), CrystalDiskInfo(HDD), HWMonitor(온도)
