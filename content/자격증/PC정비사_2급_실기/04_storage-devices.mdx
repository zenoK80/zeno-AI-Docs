## HDD vs SSD 비교

| 항목 | HDD | SSD |
|------|-----|-----|
| 속도 | 100~200 MB/s | SATA 최대 600 MB/s, NVMe 최대 7000 MB/s |
| 소음 | 회전 소음 있음 | 무음 |
| 충격 내성 | 약함 (회전 디스크) | 강함 (낸드 플래시) |
| 가격 | 용량 대비 저렴 | 용량 대비 비쌈 |
| 수명 | 기계적 마모 | 쓰기 횟수(TBW) 제한 |
| 용량 | 대용량 저렴(4TB~20TB) | 소용량 고속(256GB~4TB) |

## SSD 인터페이스 종류

| 인터페이스 | 커넥터 | 최대 속도 | 특징 |
|------------|--------|-----------|------|
| SATA | L자형 SATA 커넥터 | 약 600 MB/s | 구형·저가형, HDD와 동일 케이블 |
| NVMe(PCIe) | M.2 슬롯 | 약 7000 MB/s | 고속, PCIe 4.0/5.0 지원 시 더 빠름 |

## M.2 폼팩터 규격

M.2 SSD는 크기를 숫자로 표시한다. 숫자 앞 2자리가 폭(mm), 뒤 2자리가 길이(mm)이다.

| 규격 | 크기 | 사용 빈도 |
|------|------|----------|
| 2280 | 22 × 80 mm | 가장 일반적 (데스크탑, 노트북 공통) |
| 2242 | 22 × 42 mm | 일부 노트북, 소형 PC |
| 2260 | 22 × 60 mm | 드물게 사용 |

메인보드에서 지원하는 M.2 슬롯 길이를 확인하고, 맞는 규격의 SSD를 선택해야 한다.

## 저장장치 설치 방법

### SATA HDD/SSD 설치

1. HDD/SSD를 케이스의 드라이브 베이에 나사로 고정
2. SATA 데이터 케이블 한쪽을 HDD/SSD SATA 포트에 연결
3. SATA 데이터 케이블 반대쪽을 메인보드 SATA 포트에 연결
4. 파워서플라이의 SATA 전원 커넥터를 HDD/SSD에 연결

### M.2 NVMe SSD 설치

1. 메인보드 M.2 슬롯 위치 확인 (고정 나사 구멍 위치 확인)
2. M.2 슬롯에 SSD를 약 30도 비스듬히 기울여 꽂기
3. SSD를 수평으로 눕혀 메인보드에 밀착
4. 고정 나사(M2 규격 작은 나사)로 SSD 끝부분 고정
5. M.2 NVMe는 전원 케이블 불필요 (슬롯에서 직접 전력 공급)

## 파티션 설정

### MBR vs GPT

| 항목 | MBR | GPT |
|------|-----|-----|
| 최대 디스크 용량 | 2 TB | 사실상 무제한 |
| 최대 기본 파티션 수 | 4개 | 128개 |
| 부팅 방식 | 레거시 BIOS | UEFI (Windows 11 필수) |
| 복구 파티션 | 없음 | GUID 기반 파티션 테이블 |

Windows 11 및 NVMe SSD 사용 시에는 GPT를 사용해야 한다.

### diskpart 명령으로 GPT 파티션 생성

Windows 설치 미디어 또는 복구 환경의 명령 프롬프트에서 실행한다.

```
diskpart
list disk
select disk 0
clean
convert gpt
create partition efi size=100
format fs=fat32 quick
assign
create partition msr size=16
create partition primary
format fs=ntfs quick
assign
exit
```

- `clean`: 디스크의 모든 파티션 삭제 (데이터 완전 삭제)
- `convert gpt`: MBR에서 GPT로 변환
- EFI 파티션(100MB, FAT32)은 UEFI 부팅에 필요
- MSR 파티션(16MB)은 Windows 관리용 예약 파티션

### 디스크 관리 GUI (diskmgmt.msc)

명령어 없이 GUI로 파티션을 관리할 수 있다.

```
Win + R → diskmgmt.msc 입력 후 Enter
```

- 디스크 초기화: 디스크 우클릭 → GPT/MBR 선택
- 볼륨 만들기: 할당되지 않은 공간 우클릭 → 새 단순 볼륨
- 볼륨 축소/확장: 기존 파티션 우클릭

## 파일 시스템 종류

| 파일 시스템 | 단일 파일 최대 크기 | 용도 |
|------------|-------------------|------|
| NTFS | 16 TB 이상 | Windows 표준, 권한 관리 지원 |
| exFAT | 16 EB | USB 외장 저장장치, 크로스 플랫폼 |
| FAT32 | 4 GB | 구형 장치 호환, 4GB 초과 파일 불가 |

## 저장장치 상태 확인

```
# 디스크 모델과 용량 확인
wmic diskdrive get model, size

# 디스크 목록 (PowerShell)
Get-PhysicalDisk | Select-Object FriendlyName, Size, MediaType

# S.M.A.R.T. 상태 (CrystalDiskInfo 활용 권장)
```

## 핵심 정리

- HDD: 저렴·대용량, SSD(NVMe): 최대 7000 MB/s 고속
- M.2 2280 규격이 가장 일반적 (22mm 폭 × 80mm 길이)
- MBR: 최대 2TB, 4파티션 / GPT: 2TB 초과, 128파티션, UEFI 필요
- Windows 표준 파일 시스템: NTFS, USB 외장용: exFAT
