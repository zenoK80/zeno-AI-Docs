## PC 구성 5대 요소

PC는 역할에 따라 5가지 요소로 나눌 수 있다.

| 요소 | 역할 | 대표 장치 |
|------|------|-----------|
| 입력 | 사용자 명령을 PC로 전달 | 키보드, 마우스, 스캐너 |
| 처리 | 데이터 연산 및 제어 | CPU, RAM |
| 저장 | 데이터 영구·임시 보존 | HDD, SSD, RAM |
| 출력 | 처리 결과를 사람에게 전달 | 모니터, 프린터, 스피커 |
| 통신 | 네트워크 연결 및 데이터 송수신 | LAN 카드, Wi-Fi 카드 |

## 내부 부품 목록

PC 케이스 안에 장착되는 주요 부품이다. 시험에서는 부품 사진을 보고 이름과 역할을 답하는 문제가 자주 출제된다.

| 부품명 | 역할 | 비고 |
|--------|------|------|
| CPU(중앙처리장치) | 모든 연산·제어 담당 | Intel LGA, AMD AM5 소켓 |
| 메인보드(Motherboard) | 모든 부품을 연결하는 기판 | 폼팩터에 따라 크기 다름 |
| RAM(메모리) | 실행 중인 데이터 임시 저장 | DDR4, DDR5 |
| 저장장치 | OS·파일 영구 저장 | HDD, SSD(SATA/NVMe) |
| 그래픽카드(GPU) | 화면 출력 처리 | PCIe x16 슬롯 장착 |
| 파워서플라이(PSU) | 각 부품에 전력 공급 | 80PLUS 인증 등급 |
| CPU 쿨러 | CPU 발열 냉각 | 공랭/수랭 방식 |
| 케이스 | 부품을 보호하고 통풍 관리 | 폼팩터와 호환 필수 |

## 외부 장치(주변기기) 목록

| 장치 | 역할 | 연결 방식 |
|------|------|-----------|
| 모니터 | 화면 출력 | HDMI, DisplayPort, VGA |
| 키보드 | 문자·명령 입력 | USB, PS/2, 무선 |
| 마우스 | 포인터 조작 입력 | USB, 무선(2.4GHz) |
| 프린터 | 문서·사진 인쇄 출력 | USB, 네트워크(TCP/IP) |
| USB 허브 | USB 포트 확장 | USB-A, USB-C |

## 폼팩터(Form Factor) 크기 비교

케이스와 메인보드의 폼팩터가 일치해야 조립이 가능하다.

| 폼팩터 | 크기 | 확장 슬롯 수 | 용도 |
|--------|------|-------------|------|
| ATX | 305 × 244 mm | 7개 | 일반 데스크탑, 고성능 PC |
| MicroATX | 244 × 244 mm | 4개 | 중소형 케이스 |
| Mini-ITX | 170 × 170 mm | 1개 | 초소형 PC, HTPC |

## 슬롯과 포트 구분

메인보드 및 케이스 후면에서 확인할 수 있는 주요 슬롯·포트이다.

| 슬롯/포트 | 용도 | 특징 |
|-----------|------|------|
| PCIe x16 | 그래픽카드 | 가장 긴 슬롯 |
| PCIe x1 | 사운드·네트워크 확장카드 | 짧은 슬롯 |
| M.2 | NVMe/SATA SSD | 2280(22 × 80 mm) 규격 다수 |
| SATA | HDD, SATA SSD | L자형 커넥터 |
| USB-A | 일반 USB 장치 | USB 3.2 Gen1/Gen2 |
| USB-C | 고속 장치, 충전 | Thunderbolt 겸용 가능 |
| HDMI | 모니터, TV 연결 | 오디오 신호 포함 |
| DisplayPort | 고해상도·고재생률 모니터 | 4K 144Hz+ 지원 |

## 시험 빈출 포인트

- 부품 사진을 보고 이름과 역할을 즉시 답해야 한다.
- PCIe x16(그래픽카드)과 PCIe x1(확장카드)의 슬롯 길이 차이를 구분한다.
- M.2 슬롯은 NVMe SSD와 SATA SSD를 모두 지원할 수 있지만, 메인보드 스펙을 확인해야 한다.
- 케이스 폼팩터와 메인보드 폼팩터가 맞지 않으면 장착 불가이다.

## 핵심 정리

- PC 5대 요소: 입력, 처리(CPU+RAM), 저장, 출력, 통신
- 내부 주요 부품: CPU, 메인보드, RAM, 저장장치, GPU, PSU, 쿨러, 케이스
- 폼팩터 순서(크기 큰 것부터): ATX 보다 크고, MicroATX 보다 크고, Mini-ITX 순
- PCIe x16(그래픽카드), M.2(SSD), SATA(HDD/SSD) 슬롯 구분 필수
