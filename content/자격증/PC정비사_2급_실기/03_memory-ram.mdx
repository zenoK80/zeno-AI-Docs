## DDR 세대별 비교

RAM은 세대마다 전압, 속도, 핀 수, 노치 위치가 다르므로 세대가 다른 RAM은 물리적으로 장착이 불가능하다.

| 항목 | DDR4 | DDR5 |
|------|------|------|
| 전압 | 1.2V | 1.1V |
| 기본 속도 | 2133~3200 MHz | 4800~6400 MHz |
| 핀 수(DIMM) | 288핀 | 288핀 |
| 노치 위치 | 중앙 기준 왼쪽 치우침 | 중앙 |
| ECC 지원 | 일부 지원 | 기본 내장 |
| 소켓 호환 | DDR4 메인보드 전용 | DDR5 메인보드 전용 |

DDR4와 DDR5는 핀 수가 같지만 노치 위치가 달라 슬롯에 맞지 않으면 삽입이 되지 않는다. 세대를 혼용할 수 없다.

## DIMM vs SO-DIMM

| 항목 | DIMM | SO-DIMM |
|------|------|---------|
| 용도 | 데스크탑 PC | 노트북, 소형 PC |
| 크기 | 긴 형태 | 짧은 형태(약 절반) |
| DDR4 핀 | 288핀 | 260핀 |
| DDR5 핀 | 288핀 | 262핀 |

## 일반적인 용량 조합

- 8GB 단일 채널: 가벼운 사무 작업
- 16GB(8GB × 2 또는 16GB × 1): 일반 업무, 게임
- 32GB(16GB × 2): 영상 편집, 가상 머신
- 64GB(32GB × 2): 고성능 워크스테이션

## 듀얼채널(Dual Channel) 구성

**듀얼채널이란** 동일 용량·동일 속도의 RAM 2개를 특정 슬롯에 장착하여 메모리 대역폭을 2배로 늘리는 방식이다.

슬롯 번호 배치(대부분의 메인보드 기준, CPU 소켓에서 가까운 순서):

```
[슬롯1] [슬롯2] [슬롯3] [슬롯4]
```

- **2개 장착 시:** 1번 + 3번 슬롯 (같은 색 슬롯) 또는 2번 + 4번 슬롯에 장착
- 메인보드마다 색이 같은 슬롯이 듀얼채널 쌍이다. 반드시 메인보드 매뉴얼 확인
- 같은 색 슬롯에 장착해야 자동으로 듀얼채널 활성화

<Callout type="warning">
  RAM 2개를 1번 + 2번처럼 인접 슬롯에 꽂으면 싱글채널로 동작한다. 반드시 같은 색(1·3번 또는 2·4번)에 장착하자.
</Callout>

## RAM 설치 순서

1. 슬롯 양쪽 고정 클립(클램프)을 바깥쪽으로 밀어 열기
2. RAM 하단의 노치 위치를 슬롯 돌기와 맞추어 방향 확인
3. 슬롯 양 끝에 힘을 균등하게 주며 RAM을 수직으로 눌러 삽입
4. 양쪽 클립이 RAM 고정 홈에 딸깍 소리와 함께 잠기는지 확인
5. RAM이 기울어지지 않고 완전히 꽂혔는지 육안으로 확인

## 메모리 용량 확인 방법

```
# 작업 관리자
Ctrl + Shift + Esc → 성능 → 메모리

# 명령 프롬프트
wmic memorychip get capacity, speed, manufacturer

# PowerShell
Get-WmiObject -Class Win32_PhysicalMemory | Select-Object Capacity, Speed, Manufacturer
```

## 고장 진단

RAM 문제 시 나타나는 증상과 조치 방법이다.

| 증상 | 원인 | 조치 |
|------|------|------|
| 전원은 켜지는데 화면 안 나옴 | RAM 접촉 불량 | RAM 빼고 금 접촉 부위 지우개로 닦은 후 재장착 |
| 부팅 중 무한 재부팅 | RAM 오류 | 슬롯 변경 또는 RAM 1개씩 테스트 |
| 블루스크린(BSOD) | RAM 오류/불량 | MemTest86으로 메모리 테스트 |
| 인식 용량 부족 | 슬롯 인식 안 됨 | 다른 슬롯에 장착, BIOS 확인 |
| 비프음(연속 울림) | RAM 미장착 | RAM 재장착 |

MemTest86은 USB로 부팅하여 RAM 불량 여부를 검사하는 무료 도구이다. 최소 1 Pass(전체 테스트 1회) 이상 오류 없이 통과해야 정상이다.

## 시험 빈출 포인트

- 듀얼채널: 1·3번 슬롯 또는 2·4번 슬롯 (색이 같은 슬롯)에 동일 RAM 2개 장착
- DDR4와 DDR5는 노치 위치가 달라 혼용 불가
- RAM 설치 후 클립이 딸깍 소리와 함께 잠겨야 정상
- 블루스크린 반복 시 MemTest86으로 RAM 검사

## 핵심 정리

- DDR5 주요 특징: 전압 1.1V, 속도 4800MHz 이상, DDR4 슬롯 호환 불가
- 듀얼채널 구성: 같은 색 슬롯(1·3번 또는 2·4번)에 동일 사양 RAM 2개
- RAM 설치: 클립 열기 → 노치 방향 맞추기 → 수직으로 눌러 클립 잠금 확인
- RAM 고장 진단 도구: MemTest86
