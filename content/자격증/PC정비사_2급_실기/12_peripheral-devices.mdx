## 프린터 설치

### USB 프린터 설치

1. 프린터를 PC에 USB 케이블로 연결
2. Windows가 자동으로 드라이버를 검색하여 설치 시도
3. 자동 설치 실패 시: 제조사 홈페이지(삼성, HP, Canon, Epson 등)에서 드라이버 다운로드 후 설치
4. 설정 → 블루투스 및 기타 디바이스 → 프린터 및 스캐너에서 등록 확인

### 네트워크 프린터 설치 (TCP/IP)

공유기 또는 프린트 서버에 연결된 네트워크 프린터를 추가하는 방법이다.

1. 설정 → 블루투스 및 기타 디바이스 → 프린터 및 스캐너 → 프린터 또는 스캐너 추가
2. "원하는 프린터가 목록에 없습니다" 클릭
3. TCP/IP 주소 또는 호스트 이름을 사용하여 프린터 추가 선택
4. 프린터의 IP 주소 입력 (예: 192.168.1.200)
5. 장치 종류: 자동 검색 선택 후 다음
6. 드라이버 선택 또는 제조사 목록에서 모델 선택

### 기본 프린터 설정

```
# 기본 프린터 확인 및 설정
설정 → 블루투스 및 기타 디바이스 → 프린터 및 스캐너
→ 원하는 프린터 클릭 → 관리 → 기본값으로 설정

# 명령줄 (PowerShell)
Get-Printer | Select-Object Name, Default
Set-Printer -Name "프린터명" -IsDefault $true
```

### 프린터 문제 해결

| 증상 | 원인 | 조치 |
|------|------|------|
| 인쇄 안 됨 | 인쇄 대기열 막힘 | 인쇄 스풀러 서비스 재시작 |
| 오프라인으로 표시 | 연결 불량 | 케이블 확인, 프린터 전원 확인 |
| 드라이버 오류 | 손상된 드라이버 | 드라이버 삭제 후 재설치 |

```
# 인쇄 스풀러 재시작 (관리자 권한)
net stop spooler
del /Q /F /S "%systemroot%\System32\spool\PRINTERS\*.*"
net start spooler
```

## 모니터 설정

### 해상도 및 재생률 설정

1. 바탕화면 우클릭 → 디스플레이 설정
2. 디스플레이 해상도: 권장 해상도(모니터 네이티브 해상도) 선택
3. 고급 디스플레이 설정 → 디스플레이 어댑터 속성 → 모니터 탭
4. 화면 재생률: 60Hz, 75Hz, 144Hz, 165Hz 중 모니터 지원 최대 값 선택

### 다중 모니터(듀얼 모니터) 설정

1. 두 번째 모니터를 HDMI 또는 DisplayPort로 연결
2. 설정 → 디스플레이 → 여러 디스플레이 드롭다운 선택
   - **확장:** 두 모니터가 하나의 넓은 화면으로 연결
   - **복제:** 두 모니터에 동일한 화면 표시
   - **두 번째 화면만 표시:** 1번 모니터 끄고 2번만 사용
   - **첫 번째 화면만 표시:** 기본 모니터만 사용
3. 기본 모니터: 작업 표시줄과 시작 버튼이 표시되는 주 모니터 설정

### 모니터 케이블 종류

| 케이블 | 특징 | 최대 지원 |
|--------|------|----------|
| HDMI | 오디오+비디오 통합, 범용 | HDMI 2.1: 4K 120Hz |
| DisplayPort | 고해상도·고재생률, 데이지체인 | DP 1.4: 4K 144Hz, 8K 60Hz |
| VGA | 아날로그, 구형 모니터 | 최대 2048×1536 |
| DVI | 디지털/아날로그 겸용, 구형 | 최대 2560×1600(DVI-D Dual) |

## 웹캠 및 마이크 설정

### 장치 인식 확인

1. 장치 관리자 → 카메라(웹캠) 또는 사운드, 비디오 및 게임 컨트롤러 항목 확인
2. 노란 느낌표가 있으면 드라이버 설치 필요

### 개인 정보 보호 설정

```
설정 → 개인 정보 보호 → 카메라
→ 앱이 카메라에 액세스하도록 허용 켜기
→ 개별 앱 접근 허용 목록에서 원하는 앱 켜기

설정 → 개인 정보 보호 → 마이크
→ 동일하게 설정
```

## 외장 저장장치 관리

### USB 드라이브 안전 제거

데이터 손실 방지를 위해 반드시 안전 제거 절차를 따른다.

1. 작업 표시줄 오른쪽 하단 트레이 아이콘 클릭 (숨겨진 아이콘 표시)
2. 하드웨어 안전하게 제거 및 미디어 꺼내기 아이콘 클릭
3. 제거할 드라이브 선택
4. "하드웨어를 안전하게 제거할 수 있습니다" 메시지 확인 후 분리

### 외장 드라이브 포맷

```
# GUI 방법
파일 탐색기 → 드라이브 우클릭 → 포맷

# 명령 프롬프트
format D: /FS:exFAT /Q

# diskpart 방법
diskpart
list volume
select volume 번호
format fs=exfat quick label="MyDrive"
```

## Bluetooth 기기 연결

1. 설정 → 블루투스 및 기타 디바이스
2. Bluetooth 스위치 켜기
3. 기기 추가 → Bluetooth 선택
4. 연결할 Bluetooth 기기를 페어링 모드로 전환 (기기별 방법 다름)
5. 목록에서 기기 선택 → 연결

### Bluetooth 문제 해결

```
# Bluetooth 지원 서비스 재시작 (관리자 권한 PowerShell)
Restart-Service bthserv

# 장치 관리자에서 Bluetooth 드라이버 확인
devmgmt.msc → Bluetooth 항목 확인
```

## 핵심 정리

- 네트워크 프린터: 설정 → 프린터 및 스캐너 → TCP/IP 포트로 IP 주소 입력
- 인쇄 대기열 막힘: 스풀러 서비스 재시작 및 spool 폴더 청소
- 다중 모니터: 디스플레이 설정 → 확장/복제/두 번째 화면만 표시
- USB 안전 제거: 트레이 아이콘 → 하드웨어 안전하게 제거
