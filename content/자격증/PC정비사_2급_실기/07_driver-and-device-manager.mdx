## 장치 관리자 열기

장치 관리자는 PC에 연결된 모든 하드웨어와 드라이버 상태를 확인·관리하는 도구이다.

```
# 방법 1: 실행 창
Win + R → devmgmt.msc → Enter

# 방법 2: 빠른 링크 메뉴
Win + X → 장치 관리자

# 방법 3: 검색
작업 표시줄 검색창 → "장치 관리자" 입력
```

## 드라이버 문제 표시 기호

| 표시 기호 | 의미 | 조치 |
|-----------|------|------|
| 노란 느낌표 (!) | 드라이버 오류 또는 충돌 | 드라이버 업데이트 또는 재설치 |
| 빨간 X | 장치 비활성화 | 장치 우클릭 → 장치 사용 |
| 아래 화살표 | 장치 수동 비활성화 상태 | 우클릭 → 장치 사용 |
| 물음표 (?) | 드라이버 없음, 장치 인식 안 됨 | 드라이버 설치 필요 |

장치 관리자에서 노란 느낌표(!)가 보이면 해당 장치를 클릭하여 오류 코드를 확인한다. 오류 코드 표시 예: "코드 43: Windows에서 이 장치를 중지했습니다."

## 드라이버 설치 방법

### 방법 1: 제조사 홈페이지 직접 다운로드 (권장)

가장 최신 드라이버를 정확히 얻을 수 있다.

1. 장치 제조사 공식 홈페이지 접속
2. 지원 또는 드라이버 다운로드 메뉴에서 모델 검색
3. OS 버전(Windows 10/11, 64비트) 확인 후 다운로드
4. 설치 파일 실행 또는 장치 관리자에서 수동 설치

### 방법 2: 장치 관리자에서 자동 검색

1. 장치 관리자에서 해당 장치 우클릭
2. 드라이버 업데이트 선택
3. 드라이버 자동 검색 → Windows Update에서 검색

### 방법 3: Windows Update 자동 설치

- 설정 → Windows 업데이트 → 고급 옵션 → 선택적 업데이트 → 드라이버 업데이트

## 드라이버 설치 순서

Windows 새 설치 후 드라이버는 아래 순서로 설치해야 한다. 순서가 틀리면 이후 드라이버가 제대로 설치되지 않을 수 있다.

1. **칩셋(Chipset) 드라이버:** 메인보드 제조사 홈페이지, CPU와 주변 장치 간 통신 제어
2. **그래픽카드(GPU) 드라이버:** NVIDIA GeForce Experience 또는 AMD Software
3. **네트워크(LAN/Wi-Fi) 드라이버:** 인터넷 연결을 위해 우선 설치
4. **사운드(Audio) 드라이버:** 메인보드 내장 사운드 또는 사운드 카드
5. **기타 드라이버:** USB 컨트롤러, Bluetooth, 지문인식 등

<Callout type="tip">
  칩셋 드라이버를 가장 먼저 설치해야 USB, SATA, PCIe 등 모든 버스 컨트롤러가 정상 인식된다. 그래야 이후 드라이버들도 제대로 설치된다.
</Callout>

## 드라이버 롤백

드라이버 업데이트 후 문제가 발생하면 이전 버전으로 되돌린다.

1. 장치 관리자에서 해당 장치 우클릭 → 속성
2. 드라이버 탭 선택
3. 드라이버 롤백 클릭 (이전 드라이버가 없으면 버튼이 비활성화됨)
4. 롤백 사유 선택 후 확인
5. 재시작 여부 묻는 경우 재시작

## 드라이버 삭제 후 재설치

드라이버가 손상된 경우 완전히 삭제 후 다시 설치한다.

1. 장치 관리자에서 해당 장치 우클릭 → 디바이스 제거
2. "이 장치의 드라이버 소프트웨어를 삭제합니다" 체크 후 제거
3. 작업 메뉴 → 하드웨어 변경 내용 검색 클릭 (또는 PC 재시작)
4. 드라이버가 자동 재설치되거나, 제조사 드라이버 파일로 수동 설치

## 서명되지 않은 드라이버 설치

일부 오래된 드라이버는 Windows 디지털 서명이 없어 기본 설치가 차단된다.

**임시 방법 (재시작 후 적용):**
1. 설정 → 업데이트 및 보안 → 복구 → 지금 다시 시작
2. 문제 해결 → 고급 옵션 → 시작 설정 → 다시 시작
3. F7 키: 드라이버 서명 적용 안 함 선택

**영구 적용 (테스트 모드):**
```
# 관리자 권한 명령 프롬프트
bcdedit /set testsigning on
```

## 핵심 정리

- 노란 느낌표(!): 드라이버 오류 → 업데이트 또는 재설치
- 드라이버 설치 순서: 칩셋 → 그래픽 → 네트워크 → 사운드 → 기타
- 드라이버 롤백: 속성 → 드라이버 탭 → 드라이버 롤백
- 드라이버 재설치: 디바이스 제거 → 하드웨어 변경 내용 검색
