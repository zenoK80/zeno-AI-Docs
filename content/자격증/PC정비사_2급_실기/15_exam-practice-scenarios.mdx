## 시험 개요 복습

- 시험 시간: 40분
- 합격 기준: 100점 만점, 60점 이상
- 주요 작업: 부품 식별, 조립, BIOS 설정, OS 설치, 네트워크 설정, 고장 진단
- 자격증 발급: 한국정보통신자격협회(ICQA)

<Callout type="warning">
  시험 시간은 40분으로 짧다. 각 시나리오의 순서를 완전히 암기하고, 명령어를 오타 없이 빠르게 입력하는 연습이 필수이다.
</Callout>

## 시나리오 1: 새 PC 조립 완료 후 OS 설치

새 PC를 조립한 후 Windows 11을 새로 설치하는 전체 과정이다.

### 1단계: 부팅 전 체크리스트

- CPU 소켓 일치 여부 확인 (Intel LGA1700 또는 AMD AM5)
- RAM 듀얼채널 슬롯 확인 (1·3번 또는 2·4번)
- 24핀 ATX 전원 케이블 연결 확인
- 8핀 CPU 전원 케이블 연결 확인
- GPU가 있는 경우 PCIe 보조 전원(6핀/8핀) 연결 확인
- 저장장치 연결 확인 (M.2 고정 나사 또는 SATA 케이블)

### 2단계: BIOS 진입 및 설정 확인

1. 전원 ON 후 Del 또는 F2 연타하여 BIOS 진입
2. **Secure Boot 활성화:** Security 탭 또는 Boot 탭 → Secure Boot → Enabled
3. **TPM 상태 확인:** Security 탭 → TPM 2.0 Enabled 확인
4. **부팅 순서 변경:** Boot 탭 → Boot Option #1 → USB 드라이브 선택
5. **XMP 활성화(선택):** AI Tweaker 또는 OC 탭 → XMP/EXPO → Profile 1
6. F10 저장 후 종료

### 3단계: Windows 11 새 설치

1. USB 부팅 미디어 삽입 후 "Press any key to boot from USB..." 시 아무 키 입력
2. 언어: 한국어 / 시간 형식: 한국어(대한민국) / 키보드: Microsoft IME → 지금 설치
3. 제품 키: "제품 키가 없음" 클릭
4. Windows 11 에디션 선택 (Home 또는 Pro)
5. 사용 조건 동의
6. **설치 유형: 사용자 지정**(새 설치) 선택
7. 파티션 처리:
   - 기존 파티션 모두 선택 후 삭제
   - 할당되지 않은 공간 선택 → 새로 만들기 → 적용
   - Windows가 자동으로 EFI, MSR, 기본 파티션 생성
   - 기본 파티션(가장 큰 파티션) 선택 → 다음
8. 설치 진행 (자동 재부팅 여러 번)

### 4단계: 초기 설정(OOBE)

1. 국가 선택: 대한민국
2. 키보드 레이아웃: Microsoft IME
3. 인터넷 연결 화면: 이더넷 케이블 분리 또는 Wi-Fi 연결 안 함 선택
4. "로그인 옵션이 더 있습니다" 또는 "오프라인 계정" 클릭 → 로컬 계정 생성
5. 사용자 이름, 암호, 보안 질문 설정
6. 개인 정보 설정은 모두 아니요 또는 최소화 → 동의

### 5단계: 드라이버 설치

1. 칩셋 드라이버 설치 (메인보드 제조사 홈페이지)
2. 그래픽카드 드라이버 설치 (NVIDIA/AMD 공식 사이트)
3. 네트워크 드라이버 설치
4. 사운드 드라이버 설치
5. Windows 업데이트 실행

## 시나리오 2: 네트워크 공유 폴더 구성

두 PC(PC-A, PC-B)가 같은 공유기에 연결된 상태에서 PC-A의 폴더를 PC-B에서 접근하는 설정이다.

### 1단계: PC-A 고정 IP 설정

```
# 방법 1: GUI
Win + R → ncpa.cpl → 이더넷 우클릭 → 속성 → IPv4 더블클릭

# 수동 IP 설정
IP 주소: 192.168.1.100
서브넷 마스크: 255.255.255.0
기본 게이트웨이: 192.168.1.1
DNS: 8.8.8.8

# 방법 2: PowerShell (관리자 권한)
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.100 -PrefixLength 24 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 8.8.8.8
```

### 2단계: 네트워크 검색 및 공유 활성화

```
제어판 → 네트워크 및 공유 센터 → 고급 공유 설정 변경
→ 개인: 네트워크 검색 켜기, 파일 및 프린터 공유 켜기
→ 변경 내용 저장
```

### 3단계: 공유 폴더 생성 및 권한 설정

```
# C:\Shared 폴더 생성 (명령 프롬프트)
mkdir C:\Shared

# net share로 공유 생성
net share MyShare=C:\Shared /GRANT:Everyone,FULL

# 또는 GUI: 폴더 우클릭 → 속성 → 공유 탭 → 공유 → Everyone 추가 → 읽기/쓰기 설정
```

### 4단계: 방화벽 확인

```
# 파일 및 프린터 공유 방화벽 규칙 확인
netsh advfirewall firewall show rule name="파일 및 프린터 공유(에코 요청 - ICMPv4-In)"

# 방화벽 규칙 허용
netsh advfirewall firewall set rule group="파일 및 프린터 공유" new enable=Yes
```

### 5단계: PC-B에서 접근 확인

```
# PC-B에서 파일 탐색기 주소 입력
\\192.168.1.100\MyShare

# 네트워크 드라이브 매핑
net use Z: \\192.168.1.100\MyShare /persistent:yes

# 연결 테스트
ping 192.168.1.100
```

## 시나리오 3: 고장 PC 진단 및 복구

증상: PC 전원은 켜지는데 Windows 부팅이 안 되는 상황이다.

### 1단계: 하드웨어 1차 점검

```
증상 확인:
- 전원 LED 켜짐? → 파워 정상
- 비프음 여부? → 연속 비프: RAM 점검 / 긴1+짧은2: GPU 점검
- 화면 출력? → 없으면 GPU·모니터 케이블 점검
```

RAM 점검:
1. RAM 빼고 금 단자 부분을 지우개로 청소
2. 한 개씩 슬롯 교체하며 부팅 시도
3. 슬롯 1번(CPU 소켓 가장 가까운 슬롯)에 1개만 꽂고 테스트

### 2단계: 저장장치 점검

```
# CrystalDiskInfo로 SMART 상태 확인
주의(노란) 또는 불량(빨간) 항목 있으면 저장장치 교체 고려

# BIOS에서 HDD/SSD 인식 여부 확인
BIOS → SATA Information 또는 Boot 탭에서 저장장치 목록 확인
```

### 3단계: Windows 복구 환경(WinRE) 진입

```
방법 1: 자동 진입
전원 버튼으로 2~3회 강제 종료 시 자동으로 복구 환경 진입

방법 2: USB 부팅 미디어
BIOS에서 USB 부팅 → 컴퓨터 복구 클릭 (설치 시작 말고 왼쪽 하단)
```

### 4단계: 시동 복구

WinRE 메뉴:
```
문제 해결 → 고급 옵션 → 시동 복구
```
자동으로 부트로더와 시작 파일 복구 시도

### 5단계: 명령 프롬프트 복구

```
# WinRE → 명령 프롬프트

# 1. 시스템 파일 복구
sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows

# 2. DISM으로 이미지 복구
DISM /Image:C:\ /Cleanup-Image /RestoreHealth /Source:D:\Sources\install.wim

# 3. 부트로더 복구
bootrec /fixmbr
bootrec /fixboot
bootrec /rebuildbcd

# 4. 디스크 오류 수정
chkdsk C: /f /r
```

## 시나리오 4: 바이러스 감염 PC 복구

증상: PC가 매우 느리고, 광고 팝업이 지속적으로 뜨며, 일부 파일에 접근 불가

### 1단계: 안전 모드 부팅

```
방법 1: WinRE
문제 해결 → 고급 옵션 → 시작 설정 → 다시 시작 → F4(안전 모드) 또는 F5(네트워킹 포함 안전 모드)

방법 2: 정상 부팅 가능 시
Win + R → msconfig → 부팅 탭 → 안전 부팅 체크 → 적용 → 재시작
```

### 2단계: 의심 시작 프로그램 비활성화

```
안전 모드에서:
Ctrl + Shift + Esc → 시작 프로그램 탭
→ 모르는 프로그램 또는 게시자 없음 항목 → 사용 안 함

레지스트리 시작 프로그램 확인:
Win + R → regedit
→ HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
→ HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
→ 의심스러운 항목 삭제 (백업 필수)
```

### 3단계: Windows Defender 전체 검사

```powershell
# PowerShell (관리자 권한)
Update-MpSignature           # 바이러스 정의 업데이트
Start-MpScan -ScanType FullScan    # 전체 검사 실행

# 오프라인 검사 (더 강력한 검사)
Start-MpWDOScan
# 또는 설정 → Windows 보안 → 바이러스 및 위협 방지 → 검사 옵션 → Microsoft Defender 오프라인 검사
```

### 4단계: 의심 네트워크 연결 확인

```
# 현재 네트워크 연결 확인 (알 수 없는 IP 확인)
netstat -ano

# PID로 프로세스 확인
tasklist /fi "PID eq 의심PID"

# 의심 프로세스 종료
taskkill /PID 의심PID /F
```

### 5단계: 정상 부팅 후 확인

```
# msconfig의 안전 부팅 체크 해제 후 정상 부팅
Win + R → msconfig → 부팅 탭 → 안전 부팅 체크 해제 → 적용 → 재시작

# 정상 부팅 후 동작 확인
- 팝업 광고 없어졌는지 확인
- 작업 관리자에서 CPU/메모리 사용률 정상 여부 확인
- 기존 파일 접근 가능 여부 확인
```

### 랜섬웨어 감염 시 추가 조치

```
증상: 파일이 .encrypted, .locked 등 확장자로 변경되어 열리지 않음

조치:
1. 즉시 인터넷 및 네트워크 연결 차단 (추가 암호화 방지)
2. 감염된 PC를 네트워크에서 격리
3. 백업 파일로 복구 (오프라인 백업이 있는 경우)
4. No More Ransom 프로젝트 (nomoreransom.org)에서 무료 복호화 도구 확인
5. 백업이 없으면 전문 복구 업체 의뢰 검토
```

## 빈출 명령어 최종 정리

| 작업 | 명령어 |
|------|--------|
| IP 정보 확인 | `ipconfig /all` |
| IP 고정 설정 | `New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.100 -PrefixLength 24 -DefaultGateway 192.168.1.1` |
| 네트워크 연결 테스트 | `ping 8.8.8.8` |
| DNS 캐시 초기화 | `ipconfig /flushdns` |
| 공유 생성 | `net share Share=C:\Data /GRANT:Everyone,FULL` |
| 네트워크 드라이브 연결 | `net use Z: \\192.168.1.1\Share` |
| 시스템 파일 복구 | `sfc /scannow` |
| 이미지 복구 | `DISM /Online /Cleanup-Image /RestoreHealth` |
| 계정 생성 | `net user 이름 암호 /add` |
| 관리자 추가 | `net localgroup administrators 이름 /add` |
| Defender 검사 | `Start-MpScan -ScanType FullScan` |
| 활성화 확인 | `slmgr /xpr` |
| 원격 데스크탑 | `mstsc.exe` |

## 핵심 정리

- 시나리오 1(OS 설치): BIOS 설정 → USB 부팅 → 사용자 지정 → GPT 파티션 → 드라이버
- 시나리오 2(공유 폴더): 고정 IP → 공유 활성화 → net share → 방화벽 허용 → 접근 확인
- 시나리오 3(복구): 하드웨어 점검 → WinRE 진입 → sfc → DISM → bootrec
- 시나리오 4(악성코드): 안전 모드 → 시작 프로그램 비활성화 → Defender 검사 → 정상 부팅 확인
