## 파일 공유 설정

### 사전 준비: 네트워크 검색 및 공유 활성화

같은 네트워크의 다른 PC가 공유 폴더에 접근하려면 먼저 공유 설정을 활성화해야 한다.

1. 제어판 → 네트워크 및 인터넷 → 네트워크 및 공유 센터
2. 고급 공유 설정 변경 클릭
3. 개인 프로필(현재 사용 네트워크 유형):
   - 네트워크 검색 켜기 선택
   - 파일 및 프린터 공유 켜기 선택
4. 변경 내용 저장

### 폴더 공유 설정 (GUI)

1. 공유할 폴더 우클릭 → 속성
2. 공유 탭 → 공유 버튼 클릭
3. 사용자 추가:
   - 특정 사용자 이름 입력 후 추가
   - 또는 Everyone 입력 후 추가 (모든 사용자 접근 허용)
4. 권한 수준 설정:
   - **읽기:** 파일 보기와 다운로드만 가능
   - **읽기/쓰기:** 파일 추가, 수정, 삭제 가능
5. 공유 버튼 클릭 → 완료

### 고급 공유 (더 세밀한 설정)

1. 폴더 속성 → 공유 탭 → 고급 공유 버튼
2. 이 폴더 공유 체크
3. 공유 이름 지정 (UNC 경로에서 사용되는 이름)
4. 최대 사용자 수 제한 설정 (기본 최대 20명)
5. 사용 권한 버튼 → 세밀한 권한 설정

### 공유 폴더 접근 방법

```
# 파일 탐색기 주소 입력
\\서버IP주소\공유폴더이름
\\192.168.1.100\Shared

# 실행 창
Win + R → \\192.168.1.100\Shared
```

UNC(Universal Naming Convention) 경로 형식: `\\호스트명또는IP\공유이름`

## net 명령으로 공유 관리

### 공유 만들기

```
# C:\Data 폴더를 "Share"라는 이름으로 모든 사용자에게 공유
net share Share=C:\Data /GRANT:Everyone,FULL

# 읽기 권한만 부여
net share Share=C:\Data /GRANT:Everyone,READ

# 특정 사용자에게만 권한 부여
net share Share=C:\Data /GRANT:홍길동,CHANGE

# 최대 동시 접속 제한
net share Share=C:\Data /USERS:5
```

### 공유 목록 및 삭제

```
# 현재 공유 목록 확인
net share

# 공유 제거
net share Share /delete
```

### 네트워크 드라이브 연결

원격 공유 폴더를 로컬 드라이브 문자로 매핑한다.

```
# Z 드라이브로 매핑 (자격 증명 입력)
net use Z: \\192.168.1.1\Share

# 사용자 이름과 암호 지정
net use Z: \\192.168.1.1\Share /user:admin password123

# 부팅 시 자동 연결
net use Z: \\192.168.1.1\Share /persistent:yes

# 연결 해제
net use Z: /delete

# 모든 네트워크 연결 해제
net use * /delete

# 현재 매핑된 드라이브 목록
net use
```

### 사용자 및 그룹 관리

```
# 로컬 그룹 목록
net localgroup

# 특정 그룹 구성원 확인
net localgroup administrators

# 공유 접속 세션 확인 (서버 측)
net session

# 공유 파일 사용 현황
net file
```

## 원격 데스크탑(RDP) 설정

### 서버 PC (원격 접속을 허용할 PC) 설정

1. Win + X → 시스템 선택
2. 고급 시스템 설정 또는 원격 데스크탑 검색
3. 원격 탭 → "이 컴퓨터에 대한 원격 연결 허용" 선택
4. 네트워크 수준 인증(NLA) 사용 확인

또는:
```
# 레지스트리로 RDP 활성화
reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f

# PowerShell로 RDP 활성화
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -name "fDenyTSConnections" -Value 0
```

### 방화벽 허용

```
# 원격 데스크탑 방화벽 규칙 활성화 (관리자 권한)
netsh advfirewall firewall set rule group="원격 데스크탑" new enable=Yes

# PowerShell
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"
```

### 기본 RDP 포트

- 기본 포트: **3389** (TCP)
- 포트 변경 시 방화벽에 변경된 포트 추가 필요

### 클라이언트 PC (접속하는 PC) 설정

```
# 원격 데스크탑 클라이언트 실행
Win + R → mstsc.exe

# 또는 시작 메뉴에서 "원격 데스크탑 연결" 검색
```

접속 방법:
1. mstsc.exe 실행
2. 컴퓨터 필드에 원격 PC IP 주소 입력 (예: 192.168.1.100 또는 192.168.1.100:3389)
3. 연결 클릭
4. 원격 PC의 사용자 이름과 암호 입력
5. 연결

### RDP 고급 옵션

mstsc.exe 실행 후 "옵션 표시" 클릭:
- 디스플레이 탭: 원격 화면 크기, 색 깊이 설정
- 로컬 리소스 탭: 로컬 드라이브, 클립보드, 프린터 공유 여부
- 환경 탭: 시작 시 실행할 프로그램 지정

## 원격 지원 (빠른 지원)

Windows 10/11에 기본 내장된 원격 지원 도구이다. RDP와 달리 별도 설정 없이 코드를 공유하여 즉시 원격 지원이 가능하다.

```
# 빠른 지원 실행
Win + R → msra.exe

# 또는 시작 메뉴에서 "빠른 지원" 검색
```

- 지원 제공자: 보안 코드 생성 후 상대방에게 전달
- 지원 받는 사람: 6자리 코드 입력 후 화면 공유

## 핵심 정리

- 공유 폴더 접근: `\\IP주소\공유이름` (UNC 경로)
- `net share 이름=경로 /GRANT:Everyone,FULL`: 공유 생성
- `net use Z: \\IP\공유`: 네트워크 드라이브 매핑
- RDP 기본 포트: 3389 / 클라이언트: `mstsc.exe`
- RDP 활성화: 시스템 속성 → 원격 탭 → 원격 연결 허용
