## CPU 주요 스펙

CPU를 선택할 때 확인해야 할 핵심 스펙이다.

| 스펙 | 설명 | 예시 |
|------|------|------|
| 소켓 | CPU와 메인보드 연결 규격 | Intel LGA1700, AMD AM5 |
| 코어 수 | 독립 연산 단위 수 | 6코어, 8코어, 16코어 |
| 스레드 수 | 동시 처리 가능한 작업 수 | 코어당 1~2개 |
| 클럭(GHz) | 초당 연산 횟수 | 3.6GHz 기본, 5.0GHz 부스트 |
| TDP(W) | 열 설계 전력, 쿨러 선택 기준 | 65W, 125W, 253W |
| 내장 그래픽 | GPU 내장 여부 | Intel iGPU, AMD Radeon |

## 소켓 호환성 — 가장 중요한 규칙

**CPU 소켓과 메인보드 소켓이 반드시 일치해야 한다.** 소켓이 다르면 물리적으로 장착이 불가능하다.

| 제조사 | 소켓 | 호환 CPU 세대 |
|--------|------|--------------|
| Intel | LGA1700 | 12세대(Alder Lake), 13세대(Raptor Lake), 14세대 |
| Intel | LGA1851 | 14세대 Core Ultra, 15세대 |
| AMD | AM5 | Ryzen 7000, 8000, 9000 시리즈 |
| AMD | AM4 | Ryzen 1000~5000 시리즈 |

LGA(Land Grid Array)는 핀이 메인보드 소켓에 있고 CPU 하면이 평평한 방식이다. PGA(Pin Grid Array)는 핀이 CPU에 있는 방식으로 AMD AM4 이전 세대에서 사용했다.

## 메인보드 구성 요소

메인보드에서 각 커넥터의 위치와 역할을 파악해야 한다.

| 구성 요소 | 역할 |
|-----------|------|
| CPU 소켓 | CPU 장착, 소켓 타입 일치 필수 |
| RAM 슬롯(DIMM) | 메모리 장착, 2~4개 슬롯 |
| PCIe x16 슬롯 | 그래픽카드 장착 |
| PCIe x1 슬롯 | 확장카드 장착 |
| M.2 슬롯 | NVMe/SATA SSD 장착 |
| SATA 포트 | HDD, SATA SSD 데이터 케이블 연결 |
| 24핀 ATX 전원 | 메인보드 주 전원 공급 |
| 8핀 CPU 전원 | CPU 전용 전원 공급 (EPS 12V) |
| I/O 패널 | USB, HDMI, 오디오 등 후면 포트 집합 |
| CMOS 배터리 | BIOS 설정값 유지, CR2032 규격 |
| 칩셋 | CPU와 주변 장치 연결 허브 역할 |

## 칩셋의 역할

칩셋(Chipset)은 CPU와 메모리, 저장장치, PCIe 슬롯 등 주변 장치 사이의 데이터 흐름을 관리하는 제어 허브이다. Intel의 경우 Z790, B760, H770 등 등급이 있고, AMD는 X670, B650, A620 등이 있다. 고급 칩셋일수록 오버클럭 지원, PCIe 레인 수, USB 포트 수가 많다.

## CPU 설치 순서

CPU 설치는 정해진 순서를 지켜야 핀 손상을 방지할 수 있다.

1. 메인보드 CPU 소켓의 레버(또는 브래킷)를 올려 잠금 해제
2. CPU 모서리의 삼각형 표시(▲)와 소켓의 삼각형 표시를 일치시켜 방향 확인
3. CPU를 소켓 위에 살며시 올려놓기 (절대 힘으로 누르지 않는다)
4. 레버를 내려 CPU 고정
5. 써멀 컴파운드(서멀 그리스)를 CPU 중앙에 쌀알 크기만큼 도포
6. 쿨러를 CPU 위에 올리고 고정 나사 또는 클립으로 장착
7. 쿨러 팬 전원 케이블을 메인보드 CPU_FAN 헤더에 연결

## 주의사항

- **핀 구부러짐 주의:** LGA 소켓은 메인보드 소켓의 핀이 매우 가늘다. CPU를 비스듬히 올리거나 떨어뜨리면 핀이 휜다.
- **써멀 컴파운드:** 너무 많이 도포하면 주변으로 흘러 회로를 손상시킬 수 있고, 너무 적으면 발열 관리가 안 된다. 쌀알 크기(약 0.3g)가 적당하다.
- **CPU 전원 케이블:** 24핀 전원 외에 8핀(또는 4+4핀) CPU 전원 케이블을 반드시 연결해야 부팅된다.

## CPU 정보 확인 방법

```
# 작업 관리자 방법
Ctrl + Shift + Esc → 성능 탭 → CPU 선택

# 명령 프롬프트
wmic cpu get name

# PowerShell
Get-WmiObject -Class Win32_Processor | Select-Object Name, NumberOfCores, MaxClockSpeed
```

## 핵심 정리

- CPU 소켓과 메인보드 소켓은 반드시 일치
- Intel LGA1700 / AMD AM5가 현재 주류 소켓
- CPU 설치 순서: 레버 올리기 → 방향 맞춰 올려놓기 → 레버 내리기 → 써멀 컴파운드 → 쿨러 장착
- 24핀(메인보드 전원) + 8핀(CPU 전원) 모두 연결 필수
