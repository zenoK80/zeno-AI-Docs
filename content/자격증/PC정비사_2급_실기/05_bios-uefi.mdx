## BIOS vs UEFI 차이

| 항목 | BIOS(레거시) | UEFI |
|------|-------------|------|
| 인터페이스 | 텍스트 기반(키보드만 가능) | GUI 기반(마우스 가능) |
| 부팅 방식 | MBR | GPT(MBR도 지원) |
| 최대 디스크 용량 | 2 TB | 사실상 무제한 |
| Secure Boot | 미지원 | 지원(Windows 11 필수) |
| 부팅 속도 | 느림 | 빠름(Fast Boot 지원) |
| 드라이버 지원 | 16비트 | 32/64비트 |

현재 판매되는 대부분의 PC는 UEFI를 사용한다. 단, 구형 OS 호환을 위해 CSM(Compatibility Support Module)을 통해 레거시 BIOS 모드를 에뮬레이션할 수 있다.

## BIOS/UEFI 진입 방법

PC 전원을 켜는 순간(POST 시작 직후) 특정 키를 반복해서 눌러 진입한다.

| 제조사 | 진입 키 |
|--------|---------|
| ASUS | Del 또는 F2 |
| MSI | Del |
| Gigabyte | Del 또는 F2 |
| ASRock | F2 또는 Del |
| HP | F10 또는 Esc |
| Dell | F2 또는 F12 |
| Lenovo | F1 또는 F2 |

<Callout type="warning">
  키를 한 번만 누르면 놓치기 쉽다. 전원 버튼을 누른 직후부터 해당 키를 빠르게 반복해서 눌러야 한다.
</Callout>

## 주요 설정 항목

### 부팅 순서(Boot Order / Boot Priority)

OS 설치용 USB나 진단 도구를 부팅하려면 USB를 1순위로 변경해야 한다.

설정 경로(메인보드별로 다를 수 있음):
- Boot 탭 → Boot Option #1 → USB Drive 선택
- 저장 후 종료: F10 → Yes

일반 사용 시에는 HDD/SSD를 1순위로 복원해야 정상 부팅된다.

### Secure Boot

Windows 11 설치 및 실행에 필수 기능이다. 허용되지 않은 부트로더의 실행을 차단하여 악성 코드로부터 보호한다.

- 경로: Boot 탭 또는 Security 탭 → Secure Boot → Enabled
- Secure Boot 활성화 시 OS 모드를 UEFI(Windows UEFI mode)로 설정해야 한다.
- 일부 구형 Linux 배포판이나 비서명 드라이버 사용 시 비활성화가 필요할 수 있다.

### XMP / EXPO (메모리 오버클럭 프로파일)

RAM의 최대 정격 속도로 동작하도록 활성화하는 설정이다. 기본 상태에서는 RAM이 JEDEC 기본 속도(DDR4 2133~2400 MHz)로 동작한다.

- Intel: XMP (eXtreme Memory Profile)
- AMD: EXPO (Extended Profiles for Overclocking)
- 경로: AI Tweaker 탭(ASUS) 또는 OC 탭(MSI) → XMP 또는 EXPO → Profile 1 선택

### 가상화(Virtualization)

Hyper-V, VMware, VirtualBox 등 가상 머신 소프트웨어 사용 시 반드시 활성화해야 한다.

- Intel: VT-x (Intel Virtualization Technology)
- AMD: AMD-V (SVM Mode)
- 경로: Advanced 탭 → CPU Configuration → Intel Virtualization Technology → Enabled

### CSM (Compatibility Support Module)

구형 OS나 레거시 BIOS 기반 장치를 사용할 때 필요한 호환 모드이다.

- Windows 11 또는 순수 UEFI 환경에서는 비활성화(Disabled) 권장
- 레거시 OS나 구형 그래픽카드 사용 시 활성화
- CSM 활성화 시 Secure Boot를 동시에 사용하기 어려울 수 있음

### Fast Boot

BIOS POST 과정을 단축하여 부팅 시간을 줄이는 기능이다. 부팅 문제 진단 시에는 비활성화하여 전체 POST를 확인해야 한다.

## BIOS 초기화 방법

BIOS 설정이 잘못되어 부팅이 안 될 때 초기화한다.

1. **BIOS 내부에서 초기화:** 설정 화면 내 `Load Optimized Defaults` 또는 `Load Setup Defaults` 선택 후 저장
2. **CMOS 배터리 분리:** 메인보드의 CR2032 배터리를 30초~1분간 분리 후 재삽입
3. **CMOS Clear 점퍼:** 메인보드의 CLRCMOS 또는 JBAT1 점퍼를 메뉴얼 기준으로 단락

## POST 오류 비프음 코드 (Award BIOS 기준)

| 비프음 패턴 | 의미 |
|-------------|------|
| 짧은 1번 | POST 정상 완료 |
| 짧은 2번 | POST 일반 오류 |
| 긴 1번 + 짧은 2번 | 그래픽카드 오류 또는 미장착 |
| 긴 1번 + 짧은 3번 | 비디오 메모리 오류 |
| 연속적으로 울림 | RAM 오류 또는 미장착 |
| 없음 | PSU 또는 메인보드 불량 가능성 |

## 핵심 정리

- UEFI는 BIOS보다 빠르고 GPT/Secure Boot 지원
- 부팅 순서 변경: Boot 탭 → Boot Option #1 → USB 선택 → F10 저장
- Secure Boot: Windows 11 필수 항목
- XMP/EXPO 활성화로 RAM이 정격 속도로 동작
- 가상화(VT-x/AMD-V): Hyper-V, VMware 사용 시 필수 활성화
