## 시작 프로그램 관리

컴퓨터 부팅 시 자동 실행되는 프로그램이 많을수록 시작 시간이 늘어난다.

### GUI 방법 (작업 관리자)

1. Ctrl + Shift + Esc → 작업 관리자 실행
2. 시작 프로그램 탭 선택
3. 불필요한 프로그램 선택 후 우클릭 → 사용 안 함
4. "시작 시 영향" 열을 참고하여 높음(High) 항목 우선 검토

### 레지스트리 시작 프로그램 위치

```
# 현재 사용자 시작 프로그램
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run

# 모든 사용자 시작 프로그램
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

# 시작 폴더 경로
C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup
C:\Users\사용자명\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

## 디스크 정리

### GUI 방법 (cleanmgr.exe)

1. Win + R → `cleanmgr.exe` 입력
2. 정리할 드라이브 선택 (보통 C 드라이브)
3. 임시 파일, 휴지통, 임시 인터넷 파일 등 항목 체크
4. 시스템 파일 정리 버튼 클릭 시 Windows 업데이트 캐시 등 추가 항목 포함
5. 확인 클릭

### PowerShell 방법

```powershell
# 휴지통 비우기
Clear-RecycleBin -Force

# 임시 파일 삭제
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "C:\Windows\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue
```

### 디스크 정리 자동화 (작업 스케줄러 연동)

```
cleanmgr /sagerun:1
```

## 디스크 조각 모음 및 TRIM

### HDD 조각 모음

HDD는 파일이 디스크 여러 곳에 분산 저장(단편화)되면 읽기 속도가 느려진다.

```
# 최적화 실행 (GUI)
파일 탐색기 → 드라이브 우클릭 → 속성 → 도구 탭 → 최적화

# 명령줄
defrag C: /U /V
```

옵션 설명:
- /U: 진행 상황 표시
- /V: 상세 정보 표시
- /A: 분석만 실행 (조각 모음 안 함)

### SSD TRIM

SSD는 조각 모음이 불필요하며 오히려 수명을 단축한다. Windows는 TRIM 명령을 주기적으로 자동 실행한다.

```
# TRIM 활성화 상태 확인
fsutil behavior query DisableDeleteNotify
# 결과 0 = TRIM 활성화, 1 = TRIM 비활성화

# TRIM 활성화
fsutil behavior set DisableDeleteNotify 0
```

## Windows 업데이트

```
# 설정 방법
설정 → Windows 업데이트 → 업데이트 확인

설정 → Windows 업데이트 → 고급 옵션 → 업데이트 일시 중지
```

## 사용자 계정 관리

### 관리자 vs 표준 사용자

| 계정 유형 | 권한 | 특징 |
|-----------|------|------|
| 관리자 | 모든 시스템 변경 가능 | 드라이버 설치, 프로그램 설치, 계정 관리 가능 |
| 표준 사용자 | 제한된 권한 | 자신의 파일만 변경, 시스템 설정 변경 불가 |

### UAC (사용자 계정 컨트롤)

관리자 권한이 필요한 작업 실행 시 확인 팝업이 나타난다.

- 관리자 계정: "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → 예/아니요
- 표준 사용자: 관리자 암호 입력 필요

### 계정 관리 명령어

```
# 사용자 목록 확인
net user

# 새 사용자 계정 생성
net user 홍길동 password123 /add

# 관리자 그룹에 추가
net localgroup administrators 홍길동 /add

# 표준 사용자로 변경 (관리자 그룹에서 제거)
net localgroup administrators 홍길동 /delete

# 계정 비활성화
net user 홍길동 /active:no

# 계정 삭제
net user 홍길동 /delete

# 암호 변경
net user 홍길동 newpassword
```

### 계정 관리 (GUI)

```
# 로컬 사용자 및 그룹 관리자
Win + R → lusrmgr.msc

# 제어판 방법
제어판 → 사용자 계정 → 다른 계정 관리
```

## 작업 스케줄러

정기적인 작업을 자동으로 실행하도록 예약한다.

```
# 작업 스케줄러 열기
Win + R → taskschd.msc

# 명령줄로 예약 작업 생성
schtasks /create /tn "백업작업" /tr "robocopy C:\Data D:\Backup /MIR" /sc daily /st 02:00

# 예약 작업 목록 확인
schtasks /query /fo LIST

# 예약 작업 삭제
schtasks /delete /tn "백업작업" /f
```

## 성능 모니터 (perfmon.exe)

CPU, 메모리, 디스크, 네트워크 사용량을 실시간으로 측정한다.

```
# 성능 모니터 실행
Win + R → perfmon.exe

# 리소스 모니터 (더 간편)
Win + R → resmon.exe

# 작업 관리자 빠른 확인
Ctrl + Shift + Esc → 성능 탭
```

## 핵심 정리

- 시작 프로그램: 작업 관리자 → 시작 프로그램 탭 → 불필요한 것 비활성화
- HDD 조각 모음: `defrag C: /U /V` (SSD는 실행 금지)
- SSD TRIM: `fsutil behavior query DisableDeleteNotify` (0이면 활성화)
- 계정 생성: `net user 이름 암호 /add`
- 관리자 그룹 추가: `net localgroup administrators 이름 /add`
