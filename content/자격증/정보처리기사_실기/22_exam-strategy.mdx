## 반드시 암기할 순서·분류

### 결합도 순서 (낮음 → 높음, 낮을수록 좋음)

**데 - 스 - 제 - 외 - 공 - 내**

데이터 → 스탬프 → 제어 → 외부 → 공통 → 내용

### 응집도 순서 (높음 → 낮음, 높을수록 좋음)

**기 - 순 - 교 - 절 - 시 - 논 - 우**

기능 → 순차 → 교환(통신) → 절차 → 시간 → 논리 → 우연

### 정규화 순서

**1NF → 2NF → 3NF → BCNF → 4NF → 5NF**

- 1NF: 원자값(다중값 제거)
- 2NF: 부분 함수 종속 제거
- 3NF: 이행 함수 종속 제거
- BCNF: 결정자가 후보키

## 핵심 계산 공식

| 공식 | 내용 |
|------|------|
| PERT 기대 시간 | (낙관치 + 4×최빈값 + 비관치) / 6 |
| 가용성 | MTBF / (MTBF + MTTR) |
| CPI | EV / AC (1 이상: 예산 내) |
| SPI | EV / PV (1 이상: 일정 앞섬) |
| McCabe 복잡도 | V(G) = E - N + 2 (E:간선, N:노드) |

## 시험 전략

1. 단답형은 정확한 용어 사용 (영어 약어도 정확하게)
2. 서술형은 정의 → 특징 → 예시 순으로 작성
3. SQL 작성 시 키워드 대소문자 통일
4. 계산 문제는 공식 먼저 쓰고 값 대입
