## 프로세스 vs 스레드

| 구분 | 프로세스 | 스레드 |
|------|----------|--------|
| 정의 | 실행 중인 프로그램 | 프로세스 내의 실행 단위 |
| 자원 | 독립적 메모리 공간 | 프로세스 자원 공유 |
| 통신 | IPC 필요 | 공유 메모리로 직접 통신 |
| 생성 비용 | 높음 | 낮음 |
| 장애 영향 | 독립적 | 한 스레드 오류 시 프로세스 전체 영향 |

---

## 프로세스 상태 전이

```
생성(New)
  ↓ (준비 큐에 삽입)
준비(Ready) ←──────── 대기(Waiting/Blocked)
  ↓ (CPU 할당)          ↑ (I/O 요청)
실행(Running) ──────→
  ↓ (완료)
종료(Terminated)
```

## CPU 스케줄링 알고리즘

| 알고리즘 | 설명 | 특징 |
|----------|------|------|
| FCFS | 먼저 온 프로세스 먼저 처리 | 비선점, Convoy Effect |
| SJF | 실행 시간 짧은 것 먼저 | 비선점, 평균 대기시간 최소 |
| SRTF | SJF의 선점 버전 | 선점형 SJF |
| RR(Round Robin) | 정해진 타임 퀀텀씩 순서대로 | 선점, 타임 퀀텀이 핵심 |
| Priority | 우선순위 높은 것 먼저 | 기아(Starvation) 문제 |
| MLQ | 여러 레벨의 큐 사용 | 복잡 |

## 교착상태 (Deadlock)

두 개 이상의 프로세스가 서로 상대방이 가진 자원을 기다리며 무한히 대기하는 상태입니다.

### 교착상태 4대 발생 조건

| 조건 | 설명 |
|------|------|
| 상호 배제(Mutual Exclusion) | 자원은 한 번에 하나의 프로세스만 사용 |
| 점유와 대기(Hold and Wait) | 자원을 점유하면서 다른 자원을 기다림 |
| 비선점(No Preemption) | 다른 프로세스의 자원을 강제로 빼앗을 수 없음 |
| 순환 대기(Circular Wait) | 프로세스들이 순환적으로 자원을 기다림 |

### 교착상태 해결 방법

| 방법 | 설명 |
|------|------|
| 예방(Prevention) | 4가지 조건 중 하나를 제거 |
| 회피(Avoidance) | 은행가 알고리즘으로 안전한 상태 유지 |
| 탐지(Detection) | 교착상태 발생 감지 후 복구 |
| 복구(Recovery) | 프로세스 종료 또는 자원 강탈 |

---

## 메모리 관리

| 기법 | 설명 |
|------|------|
| 단순 연속 할당 | 메모리를 연속적으로 할당 |
| 페이징(Paging) | 물리 메모리를 고정 크기 프레임으로 분할 |
| 세그멘테이션 | 논리적 단위(세그먼트)로 분할 |
| 가상 메모리 | 디스크를 메모리처럼 사용 (페이지 폴트) |

### 페이지 교체 알고리즘

| 알고리즘 | 설명 |
|----------|------|
| FIFO | 가장 오래된 페이지 교체 |
| LRU | 가장 오래전에 사용된 페이지 교체 |
| LFU | 가장 적게 사용된 페이지 교체 |
| OPT | 앞으로 가장 오래 사용 안 할 페이지 교체 (이론적 최적) |
