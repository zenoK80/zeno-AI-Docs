## 소프트웨어 비용 산정

### COCOMO 모델

| 유형 | 규모 | 특징 |
|------|------|------|
| 조직형(Organic) | 50KDSI 이하 | 소규모, 경험 있는 팀 |
| 반분리형(Semi-detached) | 300KDSI 이하 | 중간 규모, 혼합 경험 |
| 임베디드형(Embedded) | 제한 없음 | 하드웨어 제약, 복잡 |

### 기능 점수(FP)

- 사용자 관점의 기능 기반 측정
- 언어·기술에 독립적
- 5가지 기능 유형: EI, EO, EQ, ILF, EIF

## 일정 관리

### PERT (3점 추정)

```
기대 시간 = (낙관치 + 4 × 최빈값 + 비관치) / 6

예: O=2, M=5, P=14 → (2 + 20 + 14) / 6 = 36 / 6 = 6일
```

### CPM (임계 경로법)

- **임계 경로**: 프로젝트 시작→종료의 가장 긴 경로
- 임계 경로 상의 작업: 여유 시간(Float) = 0
- 임계 경로 지연 = 전체 프로젝트 지연

### 간트 차트 vs 네트워크 다이어그램

| 비교 | 간트 차트 | 네트워크 다이어그램 |
|------|----------|-------------------|
| 표현 | 막대 그래프 | 화살표 연결 |
| 강점 | 직관적, 일정 시각화 | 의존성, 임계 경로 표현 |
| 약점 | 의존성 표현 어려움 | 복잡할 수 있음 |

## EVM (획득가치관리)

| 용어 | 설명 |
|------|------|
| PV (계획 가치) | 이 시점에 완료해야 할 계획 작업의 예산 |
| EV (획득 가치) | 실제 완료한 작업의 계획 예산 |
| AC (실제 비용) | 실제 완료한 작업에 든 실제 비용 |
| CPI | EV / AC (1 이상: 예산 내, 미만: 초과) |
| SPI | EV / PV (1 이상: 일정 앞서, 미만: 지연) |

---

## 위험 관리 전략

| 전략 | 설명 | 적용 상황 |
|------|------|----------|
| 회피(Avoidance) | 위험 활동 제거 | 발생 확률 높고 영향 큼 |
| 전가(Transfer) | 제3자에게 이전 | 발생 확률 낮고 영향 큼 |
| 완화(Mitigation) | 확률·영향 감소 | 예방 가능한 위험 |
| 수용(Acceptance) | 결과 수용 | 발생 확률 낮고 영향 작음 |
