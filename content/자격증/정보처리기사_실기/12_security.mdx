## 정보보안 3대 요소 (CIA)

| 요소 | 설명 | 위협 예시 |
|------|------|-----------|
| 기밀성(Confidentiality) | 인가된 사용자만 접근 | 도청, 스니핑, 데이터 유출 |
| 무결성(Integrity) | 데이터 변조 방지 | 위변조, 악성코드 |
| 가용성(Availability) | 인가된 접근 보장 | DoS/DDoS, 랜섬웨어 |

---

## 암호화 방식

### 대칭키 암호화

| 항목 | 내용 |
|------|------|
| 특징 | 암호화·복호화에 동일한 키 사용 |
| 장점 | 빠름, 대용량 데이터 적합 |
| 단점 | 키 배송 문제, 키 관리 어려움 |
| 알고리즘 | AES, DES, 3DES, ARIA |

### 비대칭키 암호화 (공개키)

| 항목 | 내용 |
|------|------|
| 특징 | 공개키(암호화) + 개인키(복호화) 사용 |
| 장점 | 키 배송 문제 없음, 전자서명 가능 |
| 단점 | 느림, 소용량 데이터에 적합 |
| 알고리즘 | RSA, ECC, DH |

### 해시 함수

- 단방향 함수 (복호화 불가)
- 임의 길이 → 고정 길이 출력
- MD5(128bit), SHA-1(160bit), SHA-256(256bit)
- 무결성 검증, 패스워드 저장에 활용

## 주요 보안 공격

| 공격 | 분류 | 대응 |
|------|------|------|
| DoS/DDoS | 가용성 침해 | 트래픽 필터링, CDN |
| 피싱(Phishing) | 사회공학 | 사용자 교육, 이메일 필터링 |
| SQL 인젝션 | 코드 인젝션 | 파라미터화 쿼리 |
| XSS | 코드 인젝션 | 입력값 이스케이프 |
| CSRF | 위조 요청 | CSRF 토큰 |
| 스니핑(Sniffing) | 도청 | 암호화(SSL/TLS) |
| 랜섬웨어 | 악성코드 | 백업, 보안 소프트웨어 |
| APT | 표적 공격 | 위협 인텔리전스 |

## 접근 제어 모델

| 모델 | 결정자 | 특징 |
|------|--------|------|
| DAC (임의적) | 소유자 | 유연, 보안 약함 |
| MAC (강제적) | 시스템 | 엄격, 군사·정부 |
| RBAC (역할 기반) | 역할 | 기업 환경에 적합 |

---

## PKI와 전자서명

```
전자서명 생성: 메시지 해시값 → 서명자의 개인키로 암호화
전자서명 검증: 공개키로 복호화 → 해시 비교
```

- 부인방지: 서명자의 개인키로 서명 → 부인 불가
- CA(인증기관): 공개키 인증서 발급·관리

---

## ISMS (정보보호 관리체계)

- 국내 정보보호 관리체계 인증
- ISMS-P: 정보보호 + 개인정보보호 통합 인증
- ISO 27001: 국제 정보보안 관리체계 인증
