## 결합도 (Coupling) — 낮을수록 좋음

두 모듈 간의 상호 의존 정도입니다.

| 강도 | 유형 | 설명 |
|------|------|------|
| 가장 낮음(좋음) | 데이터 결합(Data) | 매개변수로 데이터만 전달 |
| ↑ | 스탬프 결합(Stamp) | 구조체 등 복합 데이터 전달 |
| ↑ | 제어 결합(Control) | 제어 플래그를 전달 |
| ↑ | 외부 결합(External) | 외부 환경 공유 |
| ↑ | 공통 결합(Common) | 전역 변수 공유 |
| 가장 높음(나쁨) | 내용 결합(Content) | 다른 모듈 내부 직접 참조 |

암기: **데스제외공내** (낮음→높음)

---

## 응집도 (Cohesion) — 높을수록 좋음

한 모듈 내 구성 요소의 연관성 정도입니다.

| 강도 | 유형 | 설명 |
|------|------|------|
| 가장 높음(좋음) | 기능적 응집(Functional) | 단일 기능 수행 |
| ↓ | 순차적 응집(Sequential) | 이전 출력이 다음 입력 |
| ↓ | 교환적 응집(Communicational) | 동일 데이터 사용 |
| ↓ | 절차적 응집(Procedural) | 특정 순서로 실행 |
| ↓ | 시간적 응집(Temporal) | 동일 시간에 실행 |
| ↓ | 논리적 응집(Logical) | 논리적으로 유사한 기능 |
| 가장 낮음(나쁨) | 우연적 응집(Coincidental) | 관계 없는 기능 |

암기: **기순교절시논우** (높음→낮음)

---

## 아키텍처 스타일

| 패턴 | 설명 | 활용 |
|------|------|------|
| 레이어(Layered) | 계층 간 단방향 의존 | 웹 애플리케이션 |
| MVC | Model-View-Controller 분리 | GUI 애플리케이션 |
| 파이프-필터 | 데이터 처리를 단계적으로 연결 | 컴파일러, Unix 파이프 |
| 이벤트 기반 | 이벤트 발생-처리 중심 | GUI, 메시지 큐 |
| 마이크로서비스 | 독립적 서비스로 구성 | 대규모 분산 시스템 |
| 서비스 지향(SOA) | 서비스 단위로 조합 | 기업 시스템 통합 |

---

## 모듈화 설계 원칙

| 원칙 | 설명 |
|------|------|
| 추상화 | 복잡성을 숨기고 핵심만 노출 |
| 정보 은닉 | 모듈 내부 구현을 숨김 |
| 모듈화 | 독립적 기능 단위로 분리 |
| 단계적 분해 | 복잡한 문제를 작은 단위로 분해 |
