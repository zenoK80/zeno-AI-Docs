## OSI 7계층 상세

| 계층 | 이름 | 역할 | 프로토콜/장비 |
|------|------|------|--------------|
| 7 | 응용 계층 | 사용자 인터페이스 | HTTP, FTP, SMTP, DNS |
| 6 | 표현 계층 | 암호화, 형식 변환, 압축 | SSL/TLS, JPEG |
| 5 | 세션 계층 | 세션 설정·유지·종료 | NetBIOS, RPC |
| 4 | 전송 계층 | 신뢰성 있는 데이터 전송 | TCP, UDP |
| 3 | 네트워크 계층 | 경로 선택, IP 주소 기반 | IP, ICMP, ARP, 라우터 |
| 2 | 데이터링크 계층 | MAC 주소 기반 통신 | Ethernet, 스위치 |
| 1 | 물리 계층 | 비트 전송 | 케이블, 허브 |

**암기법**: 물데네전세표응 (1층→7층)

## TCP vs UDP 비교

| 특성 | TCP | UDP |
|------|-----|-----|
| 연결 방식 | 연결 지향 (3-way handshake) | 비연결 |
| 신뢰성 | 높음 (재전송, 순서 보장) | 낮음 |
| 속도 | 느림 | 빠름 |
| 오버헤드 | 높음 | 낮음 |
| 활용 | HTTP, FTP, 이메일 | DNS, VoIP, 스트리밍 |

### TCP 3-way Handshake

```
클라이언트              서버
    |----SYN----------->|   (연결 요청)
    |<---SYN+ACK--------|   (수락 + 확인)
    |----ACK----------->|   (확인)
    (연결 수립 완료)
```

### TCP 4-way Handshake (연결 종료)

```
클라이언트              서버
    |----FIN----------->|   (종료 요청)
    |<---ACK------------|   (수신 확인)
    |<---FIN------------|   (서버도 종료)
    |----ACK----------->|   (최종 확인)
```

## 주요 프로토콜과 포트 번호

| 프로토콜 | 포트 | 전송층 | 설명 |
|----------|------|--------|------|
| HTTP | 80 | TCP | 웹 통신 |
| HTTPS | 443 | TCP | 암호화된 웹 통신 |
| FTP | 20, 21 | TCP | 파일 전송 |
| SSH | 22 | TCP | 보안 원격 접속 |
| Telnet | 23 | TCP | 원격 접속 (비암호화) |
| SMTP | 25 | TCP | 이메일 전송 |
| DNS | 53 | UDP/TCP | 도메인 이름 해석 |
| DHCP | 67, 68 | UDP | IP 자동 할당 |
| POP3 | 110 | TCP | 이메일 수신 |
| IMAP | 143 | TCP | 이메일 수신 (동기화) |
