## SQL 분류

| 분류 | 명령어 | 설명 |
|------|--------|------|
| DDL | CREATE, ALTER, DROP, TRUNCATE | 테이블 구조 정의 |
| DML | SELECT, INSERT, UPDATE, DELETE | 데이터 조작 |
| DCL | GRANT, REVOKE | 권한 제어 |
| TCL | COMMIT, ROLLBACK, SAVEPOINT | 트랜잭션 제어 |

---

## SELECT 기본 구조

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 조건
GROUP BY 그룹핑 컬럼
HAVING 그룹 조건
ORDER BY 정렬 컬럼 [ASC|DESC];
```

### SELECT 실행 순서

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

## 집계 함수

| 함수 | 설명 |
|------|------|
| COUNT(*) | 전체 행 수 |
| COUNT(컬럼) | NULL 제외 행 수 |
| SUM(컬럼) | 합계 |
| AVG(컬럼) | 평균 |
| MAX(컬럼) | 최대값 |
| MIN(컬럼) | 최소값 |

## JOIN 유형

```sql
-- INNER JOIN (교집합)
SELECT a.name, b.dept_name
FROM employees a
INNER JOIN departments b ON a.dept_id = b.dept_id;

-- LEFT OUTER JOIN (왼쪽 테이블 모두 포함)
SELECT a.name, b.dept_name
FROM employees a
LEFT OUTER JOIN departments b ON a.dept_id = b.dept_id;
```

---

## 서브쿼리

```sql
-- WHERE 절 서브쿼리
SELECT name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);

-- IN 서브쿼리
SELECT name FROM employees
WHERE dept_id IN (SELECT dept_id FROM departments WHERE location = '서울');

-- EXISTS 서브쿼리
SELECT name FROM employees e
WHERE EXISTS (SELECT 1 FROM orders o WHERE o.emp_id = e.emp_id);
```

## DDL 예시

```sql
-- 테이블 생성
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    grade CHAR(1),
    created_at DATE DEFAULT CURRENT_DATE
);

-- 컬럼 추가
ALTER TABLE students ADD COLUMN email VARCHAR(100);

-- 테이블 삭제
DROP TABLE students;
```

## 실기 출제 유형 예시

```sql
-- 문제: 급여가 300만원 이상인 직원의 이름과 부서명을 조회하시오
SELECT e.name, d.dept_name
FROM employees e
JOIN departments d ON e.dept_id = d.dept_id
WHERE e.salary >= 3000000
ORDER BY e.salary DESC;

-- 문제: 부서별 평균 급여를 조회하되 평균이 250만원 이상인 부서만
SELECT dept_id, AVG(salary) AS avg_salary
FROM employees
GROUP BY dept_id
HAVING AVG(salary) >= 2500000;
```
