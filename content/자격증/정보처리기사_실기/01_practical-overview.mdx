<Callout type="info">
  **정보처리기사 실기**는 필기 합격 후 응시하는 시험으로 단답형과 서술형이 혼합됩니다. 코드 작성, SQL 작성, 개념 서술 등 다양한 유형이 출제됩니다.
</Callout>

## 시험 구성

| 항목 | 내용 |
|------|------|
| 시험 방식 | 필답형(단답·서술·코드 작성) |
| 시험 시간 | 2시간 30분 |
| 합격 기준 | 60점 이상 |
| 문항 수 | 20문항 내외 |

| 과목 | 주요 내용 | 출제 비중 |

## 실기 시험 유형

### 단답형

- 용어나 개념을 1-3단어로 쓰는 문제
- 예: "HTTP 메서드 중 서버 자원을 삭제하는 메서드는?" → **DELETE**

### 서술형

- 개념이나 비교를 2-5문장으로 서술하는 문제
- 예: "트랜잭션의 ACID 특성을 설명하시오"

### 코드 작성 / 코드 분석

- 주어진 코드의 출력 결과를 쓰거나 빈칸을 채우는 문제
- C, Java, Python이 주로 출제

### SQL 작성

- 조건에 맞는 SELECT, INSERT, UPDATE, DELETE, DDL 작성

---

## 합격 전략

| 전략 | 설명 |
|------|------|
| 코드 직접 작성 | C/Java/Python 핵심 문법을 손으로 써보며 연습 |
| SQL 반복 연습 | JOIN, 서브쿼리, 집계 함수를 실제로 작성해보기 |
| 용어 암기 | 정보보안, 네트워크, 소프트웨어 공학 용어 암기 |
| 기출 분석 | 최근 5년 기출문제 풀이 및 패턴 파악 |

---

## 고득점을 위한 핵심 영역

1. **SQL 작성** - SELECT/JOIN/서브쿼리는 거의 매 회 출제
2. **프로그래밍 코드 분석** - 변수 추적, 반복문 결과 도출
3. **소프트웨어 공학 용어** - SDLC, UML, 설계 패턴 용어
4. **네트워크/보안** - OSI 계층, 암호화, 공격 유형
