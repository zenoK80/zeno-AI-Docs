## 기본 자료구조

### 스택 (Stack) — LIFO

```
push(A) → push(B) → push(C)
     top → C
           B
           A
pop() → C 반환
```

- 연산: push(삽입), pop(삭제), peek(최상단 조회)
- 활용: 함수 호출 스택, DFS, 괄호 검사, 되돌리기(undo)

### 큐 (Queue) — FIFO

```
enqueue(A) → enqueue(B) → enqueue(C)
front → A B C ← rear
dequeue() → A 반환
```

- 연산: enqueue(삽입), dequeue(삭제)
- 활용: BFS, 프린터 스풀, 프로세스 스케줄링

### 트리 (Tree)

| 용어 | 설명 |
|------|------|
| 루트 노드(Root) | 최상위 노드 |
| 단말 노드(Leaf) | 자식이 없는 노드 |
| 차수(Degree) | 노드의 자식 수 |
| 깊이(Depth) | 루트에서 해당 노드까지의 거리 |
| 높이(Height) | 트리의 최대 깊이 |

### 이진 트리 순회

| 순회 | 순서 | 활용 |
|------|------|------|
| 전위(Pre-order) | 루트 → 왼쪽 → 오른쪽 | 트리 복사 |
| 중위(In-order) | 왼쪽 → 루트 → 오른쪽 | BST 오름차순 출력 |
| 후위(Post-order) | 왼쪽 → 오른쪽 → 루트 | 메모리 해제 |

## 정렬 알고리즘 시간 복잡도

| 알고리즘 | 최선 | 평균 | 최악 | 안정 |
|----------|------|------|------|------|
| 버블 정렬 | O(n) | O(n²) | O(n²) | 안정 |
| 선택 정렬 | O(n²) | O(n²) | O(n²) | 불안정 |
| 삽입 정렬 | O(n) | O(n²) | O(n²) | 안정 |
| 합병 정렬 | O(n log n) | O(n log n) | O(n log n) | 안정 |
| 퀵 정렬 | O(n log n) | O(n log n) | O(n²) | 불안정 |
| 힙 정렬 | O(n log n) | O(n log n) | O(n log n) | 불안정 |

---

## 빅오(Big-O) 표기법 복잡도 순서

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
상수  < 로그    < 선형 < 선형로그    < 이차   < 지수   < 팩토리얼
```

---

## 탐색 알고리즘

| 알고리즘 | 설명 | 시간 복잡도 |
|----------|------|------------|
| 순차 탐색 | 처음부터 순서대로 | O(n) |
| 이진 탐색 | 정렬된 배열에서 반으로 나눔 | O(log n) |
| 해시 탐색 | 해시 함수로 직접 접근 | O(1) |
