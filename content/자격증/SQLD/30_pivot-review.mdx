## 직접 적용하기

다음 입력을 지역별 행, PAID·CANCELED 열의 건수 표로 바꾸자.

| city | status |
| --- | --- |
| 서울 | PAID |
| 서울 | PAID |
| 서울 | CANCELED |
| 부산 | PAID |

<Collapse title="풀이">

| city | PAID | CANCELED |
| --- | ---: | ---: |
| 서울 | 2 | 1 |
| 부산 | 1 | 0 또는 NULL |

PIVOT `COUNT(*)`의 구체적인 빈 조합 표시는 DBMS 문법과 변환에 따라 확인한다. 조건부 집계에서 `SUM(CASE ... ELSE 0 END)`를 쓰면 부산 CANCELED가 0이다.

```sql
SELECT city,
       SUM(CASE WHEN status = 'PAID' THEN 1 ELSE 0 END) AS paid,
       SUM(CASE WHEN status = 'CANCELED' THEN 1 ELSE 0 END) AS canceled
FROM sales
GROUP BY city;
```

</Collapse>
