## SELECT 기본 문법

SELECT 문은 데이터베이스에서 원하는 데이터를 **조회**할 때 사용하는 가장 기본적인 명령입니다. 구조는 크게 두 부분으로 나뉩니다.

```sql
SELECT 열이름1, 열이름2, ...
FROM 테이블이름;
```

- **SELECT 절**: 어떤 열(컬럼)을 가져올지 지정합니다.
- **FROM 절**: 어떤 테이블에서 가져올지 지정합니다.

### 특정 열만 조회하기

사원의 이름과 급여만 조회하는 예시입니다.

```sql
SELECT 이름, 급여
FROM EMP;
```

**결과:**

| 이름   | 급여    |
|--------|---------|
| 김민준 | 4500000 |
| 이서연 | 3200000 |
| 박지훈 | 6000000 |
| 최수아 | 2500000 |
| 정도윤 | 4800000 |

### 모든 열 조회하기 (SELECT \*)

`*`(별표)는 "모든 열"을 의미합니다.

```sql
SELECT *
FROM EMP;
```

테이블의 모든 열이 그대로 출력됩니다. 실무에서는 필요한 열만 명시하는 것이 성능상 유리하지만, 시험에서는 `SELECT *`도 자주 등장합니다.

## DISTINCT: 중복 제거

**DISTINCT**는 조회 결과에서 중복된 행을 제거하여 고유한 값만 보여주는 키워드입니다.

EMP 테이블에서 부서번호를 조회하면 같은 값이 여러 번 나옵니다.

```sql
-- DISTINCT 없이 조회
SELECT 부서번호
FROM EMP;
```

**결과 (중복 포함):**

| 부서번호 |
|---------|
| 10      |
| 20      |
| 10      |
| 30      |
| 20      |

```sql
-- DISTINCT 사용
SELECT DISTINCT 부서번호
FROM EMP;
```

**결과 (중복 제거):**

| 부서번호 |
|---------|
| 10      |
| 20      |
| 30      |

<Callout type="warning">
  **주의:** DISTINCT는 SELECT 바로 뒤에 한 번만 쓸 수 있으며, 이후에 나오는 **모든 열을 조합한 행** 기준으로 중복을 제거합니다. `SELECT DISTINCT 부서번호, 직급`처럼 여러 열이 있으면 두 열의 조합이 동일한 경우에만 중복으로 처리됩니다.
</Callout>

## 별칭(Alias): 결과 열 이름 바꾸기

**별칭(Alias)**은 조회 결과에서 열 이름을 임시로 다르게 표시하고 싶을 때 사용합니다. `AS` 키워드를 사용하며, AS는 생략할 수도 있습니다.

```sql
SELECT 이름 AS 사원명, 급여 AS 월급
FROM EMP;
```

**결과:**

| 사원명 | 월급    |
|--------|---------|
| 김민준 | 4500000 |
| 이서연 | 3200000 |
| 박지훈 | 6000000 |
| 최수아 | 2500000 |
| 정도윤 | 4800000 |

별칭에 공백이나 특수문자가 포함된 경우 큰따옴표(`"`)로 감쌉니다.

```sql
SELECT 급여 AS "월 급여"
FROM EMP;
```

### 테이블 별칭

FROM 절에서 테이블에도 별칭을 붙일 수 있습니다. 테이블 이름이 길거나 조인(JOIN) 쿼리에서 특히 유용합니다.

```sql
SELECT E.이름, E.급여
FROM EMP E;
```

여기서 `E`가 `EMP` 테이블의 별칭입니다. `E.이름`처럼 `별칭.열이름` 형식으로 사용합니다.

## SQL 실행 순서

SQL 문은 **작성 순서**와 **실제 실행 순서**가 다릅니다. 시험에서 자주 출제되는 중요한 개념입니다.

| 실행 순서 | 절 |
|---------|-----|
| 1       | FROM (어떤 테이블에서 가져올지 결정) |
| 2       | WHERE (행 필터링) |
| 3       | GROUP BY (그룹 묶기) |
| 4       | HAVING (그룹 필터링) |
| 5       | SELECT (열 선택 및 별칭 적용) |
| 6       | ORDER BY (정렬) |

<Callout type="warning">
  **핵심 포인트:** SELECT 절은 실행 순서상 5번째입니다. 그래서 WHERE 절에서는 SELECT에서 붙인 별칭을 사용할 수 없습니다. 별칭은 ORDER BY에서는 사용 가능합니다.
</Callout>

## 핵심 정리

- `SELECT 열이름 FROM 테이블이름;`이 가장 기본 구조입니다.
- `SELECT *`는 모든 열을 조회합니다.
- `DISTINCT`는 SELECT 직후에 붙여 중복 행을 제거합니다.
- `AS`로 열 이름에 별칭을 붙이며, 공백이 있는 별칭은 큰따옴표로 감쌉니다.
- SQL 실행 순서: **FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY**
- WHERE 절에서는 SELECT 별칭을 사용할 수 없습니다.
