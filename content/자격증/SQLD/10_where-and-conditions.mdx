<Callout type="info">
  **이번 문서의 목표:** WHERE 절에서 사용하는 다양한 조건식(비교, 논리, IN, BETWEEN, LIKE)을 이해하고 흔한 함정을 피할 수 있습니다.
</Callout>

## WHERE 절의 역할

WHERE 절은 FROM 절로 가져온 테이블에서 **원하는 행만 추려내는 필터** 역할을 합니다.

```sql
SELECT 열이름
FROM 테이블이름
WHERE 조건;
```

SQL 실행 순서에서 WHERE는 FROM 다음, SELECT 이전에 실행됩니다. 조건이 TRUE인 행만 다음 단계로 넘어갑니다.

## 비교 연산자

가장 기본적인 조건 방식입니다.

| 연산자 | 의미 | 예시 |
|--------|------|------|
| `=`    | 같다 | 부서번호 = 10 |
| `<>`   | 같지 않다 | 직급 <> '사원' |
| `>`    | 크다 | 급여 > 4000000 |
| `<`    | 작다 | 급여 < 3000000 |
| `>=`   | 크거나 같다 | 급여 >= 4500000 |
| `<=`   | 작거나 같다 | 급여 <= 3200000 |

```sql
-- 급여가 400만 원 초과인 사원
SELECT 이름, 급여
FROM EMP
WHERE 급여 > 4000000;
```

**결과:**

| 이름   | 급여    |
|--------|---------|
| 김민준 | 4500000 |
| 박지훈 | 6000000 |
| 정도윤 | 4800000 |

## 논리 연산자: AND, OR, NOT

여러 조건을 조합할 때 사용합니다.

### AND: 두 조건 모두 만족

```sql
-- 부서번호가 10이고 급여가 500만 원 이상인 사원
SELECT 이름, 부서번호, 급여
FROM EMP
WHERE 부서번호 = 10 AND 급여 >= 5000000;
```

**결과:**

| 이름   | 부서번호 | 급여    |
|--------|---------|---------|
| 박지훈 | 10      | 6000000 |

### OR: 두 조건 중 하나 이상 만족

```sql
-- 부서번호가 10이거나 30인 사원
SELECT 이름, 부서번호
FROM EMP
WHERE 부서번호 = 10 OR 부서번호 = 30;
```

**결과:**

| 이름   | 부서번호 |
|--------|---------|
| 김민준 | 10      |
| 박지훈 | 10      |
| 최수아 | 30      |

### 논리 연산자 우선순위

**NOT > AND > OR** 순으로 우선순위가 높습니다. 헷갈리면 괄호로 명확히 구분하세요.

```sql
-- 아래 두 쿼리는 결과가 다릅니다
WHERE 부서번호 = 10 OR 부서번호 = 20 AND 급여 > 4000000
-- AND가 먼저 처리 → (부서번호=10) OR (부서번호=20 AND 급여>4000000)

WHERE (부서번호 = 10 OR 부서번호 = 20) AND 급여 > 4000000
-- 괄호 안이 먼저 처리 → 10 또는 20번 부서 중 급여 400만 초과
```

## IN: 여러 값 중 하나와 일치

`IN`은 OR 조건의 간결한 표현입니다.

```sql
-- 부서번호가 10 또는 20인 사원 (OR로 쓴 것과 동일)
SELECT 이름, 부서번호
FROM EMP
WHERE 부서번호 IN (10, 20);
```

**결과:**

| 이름   | 부서번호 |
|--------|---------|
| 김민준 | 10      |
| 이서연 | 20      |
| 박지훈 | 10      |
| 정도윤 | 20      |

### NOT IN과 NULL 함정

<Callout type="warning">
  **NOT IN에 NULL이 포함되면 결과가 없습니다!** 이것은 SQLD 시험에서 매우 자주 나오는 함정입니다.

  `WHERE 부서번호 NOT IN (10, NULL)` 처럼 NULL이 리스트에 포함되면 어떤 행도 반환되지 않습니다. NULL과의 비교는 항상 UNKNOWN이 되기 때문입니다.
</Callout>

```sql
-- NULL이 포함된 NOT IN → 결과 없음 (주의!)
SELECT 이름
FROM EMP
WHERE 부서번호 NOT IN (10, NULL);
-- 결과: 0행
```

## BETWEEN: 범위 조건

`BETWEEN a AND b`는 **a 이상 b 이하**인 행을 조회합니다. 양쪽 경계값이 포함됩니다.

```sql
-- 급여가 300만 이상 500만 이하인 사원
SELECT 이름, 급여
FROM EMP
WHERE 급여 BETWEEN 3000000 AND 5000000;
```

**결과:**

| 이름   | 급여    |
|--------|---------|
| 김민준 | 4500000 |
| 이서연 | 3200000 |
| 정도윤 | 4800000 |

```sql
-- BETWEEN은 아래와 완전히 동일합니다
WHERE 급여 >= 3000000 AND 급여 <= 5000000
```

## LIKE: 패턴 매칭

문자열의 일부분이 일치하는 행을 찾을 때 사용합니다. 와일드카드 두 가지를 기억하세요.

| 와일드카드 | 의미 | 예시 |
|-----------|------|------|
| `%`       | 0개 이상의 임의 문자 | '김%' → '김', '김민준', '김영희' 모두 일치 |
| `_`       | 정확히 1개의 임의 문자 | '김_준' → '김민준', '김영준' 일치, '김준' 불일치 |

```sql
-- 이름이 '김'으로 시작하는 사원
SELECT 이름
FROM EMP
WHERE 이름 LIKE '김%';
```

**결과:**

| 이름   |
|--------|
| 김민준 |

```sql
-- 이름의 두 번째 글자가 '도'인 사원
SELECT 이름
FROM EMP
WHERE 이름 LIKE '_도%';
```

**결과:**

| 이름   |
|--------|
| 정도윤 |

```sql
-- 이름에 '준'이 들어가는 사원
SELECT 이름
FROM EMP
WHERE 이름 LIKE '%준%';
```

**결과:**

| 이름   |
|--------|
| 김민준 |
| 박지훈 |

<Callout type="warning">
  **NOT LIKE**도 사용 가능합니다. `WHERE 이름 NOT LIKE '김%'`는 이름이 '김'으로 시작하지 않는 사원을 조회합니다.
</Callout>

## 조건별 비교 정리

| 조건 | 문법 | 특징 |
|------|------|------|
| 비교 | `=`, `<>`, `>`, `<` 등 | 단일 값 비교 |
| 논리 | AND, OR, NOT | 우선순위: NOT > AND > OR |
| 범위 | BETWEEN a AND b | 경계값 포함 |
| 목록 | IN (값1, 값2, ...) | NULL 포함 시 주의 |
| 패턴 | LIKE '%' '_' | %: 0개 이상, _: 정확히 1개 |
| NULL | IS NULL, IS NOT NULL | = NULL 은 틀림 |

## 핵심 정리

- WHERE는 FROM 다음에 실행되며 조건이 TRUE인 행만 통과시킵니다.
- 논리 연산자 우선순위: **NOT > AND > OR** (헷갈리면 괄호 사용)
- `IN (값1, 값2)`는 여러 OR 조건의 축약형입니다.
- `NOT IN` 리스트에 NULL이 있으면 결과가 0행이 됩니다.
- `BETWEEN a AND b`는 a 이상 b 이하로 경계값 포함입니다.
- LIKE: `%`는 임의의 0개 이상 문자, `_`는 정확히 1개 문자입니다.
- NULL 비교는 `= NULL` 대신 반드시 `IS NULL`을 사용합니다.
