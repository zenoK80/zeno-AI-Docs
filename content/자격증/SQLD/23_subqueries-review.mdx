## 직접 적용하기

다음 주문에서 회원별 평균보다 큰 주문을 찾자.

| order_id | member_id | amount |
| ---: | --- | ---: |
| 1 | A | 100 |
| 2 | A | 300 |
| 3 | B | 200 |
| 4 | B | 200 |

1. 회원별 평균을 계산한다.
2. 결과 주문 번호를 적는다.
3. 상관 서브쿼리를 작성한다.

<Collapse title="풀이">

A 평균은 200이므로 300인 주문 2만 평균보다 크다. B 평균은 200이고 두 주문 모두 평균과 같으므로 결과가 없다.

```sql
SELECT o.order_id, o.member_id, o.amount
FROM orders o
WHERE o.amount > (
  SELECT AVG(o2.amount)
  FROM orders o2
  WHERE o2.member_id = o.member_id
);
```

결과는 `order_id = 2` 한 행이다.

</Collapse>
