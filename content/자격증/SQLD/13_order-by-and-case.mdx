## ORDER BY: 결과 정렬

**ORDER BY**는 SELECT 결과를 지정한 열 기준으로 정렬하는 절입니다. SQL 실행 순서에서 **가장 마지막**에 실행됩니다.

```sql
SELECT 열이름
FROM 테이블이름
ORDER BY 정렬기준열 [ASC | DESC];
```

- **ASC**: 오름차순 (기본값, 생략 가능) — 작은 값 → 큰 값
- **DESC**: 내림차순 — 큰 값 → 작은 값

### 급여 기준 오름차순 정렬

```sql
SELECT 이름, 급여
FROM EMP
ORDER BY 급여 ASC;
```

**결과:**

| 이름   | 급여    |
|--------|---------|
| 최수아 | 2500000 |
| 이서연 | 3200000 |
| 김민준 | 4500000 |
| 정도윤 | 4800000 |
| 박지훈 | 6000000 |

### 급여 기준 내림차순 정렬

```sql
SELECT 이름, 급여
FROM EMP
ORDER BY 급여 DESC;
```

**결과:**

| 이름   | 급여    |
|--------|---------|
| 박지훈 | 6000000 |
| 정도윤 | 4800000 |
| 김민준 | 4500000 |
| 이서연 | 3200000 |
| 최수아 | 2500000 |

### 여러 열로 정렬

여러 열을 콤마로 나열하면 순서대로 적용됩니다. 첫 번째 기준이 같을 때 두 번째 기준이 사용됩니다.

```sql
-- 부서번호 오름차순, 같은 부서 내에서는 급여 내림차순
SELECT 이름, 부서번호, 급여
FROM EMP
ORDER BY 부서번호 ASC, 급여 DESC;
```

**결과:**

| 이름   | 부서번호 | 급여    |
|--------|---------|---------|
| 박지훈 | 10      | 6000000 |
| 김민준 | 10      | 4500000 |
| 정도윤 | 20      | 4800000 |
| 이서연 | 20      | 3200000 |
| 최수아 | 30      | 2500000 |

### ORDER BY에서 별칭 사용

ORDER BY는 실행 순서상 SELECT 다음이므로 SELECT에서 정의한 **별칭을 사용할 수 있습니다.**

```sql
SELECT 이름, 급여 AS 월급
FROM EMP
ORDER BY 월급 DESC;  -- SELECT에서 만든 별칭 '월급' 사용 가능
```

### ORDER BY에서 열 번호 사용

SELECT 절에서 나열한 열의 순서 번호로도 정렬할 수 있습니다.

```sql
SELECT 이름, 부서번호, 급여
FROM EMP
ORDER BY 3 DESC;  -- 세 번째 열인 급여 기준 내림차순
```

## NULL 정렬 위치

ORDER BY에서 NULL 값은 특별히 처리됩니다.

| DBMS | 기본 동작 |
|------|---------|
| Oracle | NULL을 **가장 큰 값**으로 취급 → DESC 정렬 시 맨 앞, ASC 정렬 시 맨 뒤 |
| SQL Server | NULL을 **가장 작은 값**으로 취급 → ASC 정렬 시 맨 앞 |

### Oracle에서 NULL 위치 명시적 지정

```sql
-- NULL을 맨 앞에 표시
SELECT 이름, 직급
FROM EMP
ORDER BY 직급 ASC NULLS FIRST;

-- NULL을 맨 뒤에 표시
SELECT 이름, 직급
FROM EMP
ORDER BY 직급 ASC NULLS LAST;
```

## CASE 표현식

**CASE 표현식**은 조건에 따라 서로 다른 값을 반환합니다. 프로그래밍의 if-else 구문과 유사합니다.

### 단순 CASE (Simple CASE)

특정 열의 값이 무엇인지에 따라 반환값을 결정합니다.

```sql
SELECT 이름,
       CASE 부서번호
           WHEN 10 THEN '개발팀'
           WHEN 20 THEN '영업팀'
           WHEN 30 THEN '기획팀'
           ELSE '기타'
       END AS 부서명
FROM EMP;
```

**결과:**

| 이름   | 부서명 |
|--------|--------|
| 김민준 | 개발팀 |
| 이서연 | 영업팀 |
| 박지훈 | 개발팀 |
| 최수아 | 기획팀 |
| 정도윤 | 영업팀 |

### 검색 CASE (Searched CASE)

조건을 자유롭게 표현식으로 작성합니다. 더 유연하게 사용할 수 있습니다.

```sql
-- 급여 수준을 등급으로 분류
SELECT 이름, 급여,
       CASE
           WHEN 급여 >= 5000000 THEN 'A등급'
           WHEN 급여 >= 4000000 THEN 'B등급'
           WHEN 급여 >= 3000000 THEN 'C등급'
           ELSE 'D등급'
       END AS 급여등급
FROM EMP;
```

**결과:**

| 이름   | 급여    | 급여등급 |
|--------|---------|---------|
| 김민준 | 4500000 | B등급   |
| 이서연 | 3200000 | C등급   |
| 박지훈 | 6000000 | A등급   |
| 최수아 | 2500000 | D등급   |
| 정도윤 | 4800000 | B등급   |

<Callout type="warning">
  **CASE 표현식 주의사항:** WHEN 조건은 위에서 아래로 순서대로 평가하여 **처음으로 TRUE가 되는 조건**을 사용합니다. 조건의 순서가 결과에 영향을 미칩니다. 그리고 `END`로 반드시 닫아야 합니다.
</Callout>

### CASE를 이용한 조건부 집계

CASE와 집계 함수를 조합하면 피벗(Pivot) 형태의 집계가 가능합니다.

```sql
-- 부서별로 각 직급의 사원 수 집계
SELECT
    COUNT(CASE WHEN 부서번호 = 10 THEN 1 END) AS "개발팀 인원",
    COUNT(CASE WHEN 부서번호 = 20 THEN 1 END) AS "영업팀 인원",
    COUNT(CASE WHEN 부서번호 = 30 THEN 1 END) AS "기획팀 인원"
FROM EMP;
```

**결과:**

| 개발팀 인원 | 영업팀 인원 | 기획팀 인원 |
|-----------|-----------|-----------|
| 2         | 2         | 1         |

## DECODE 함수 (Oracle 전용)

**DECODE**는 Oracle에서만 사용 가능한 단순 CASE의 간략한 표현입니다.

`DECODE(기준값, 비교값1, 결과1, 비교값2, 결과2, ..., 기본값)`

```sql
SELECT 이름,
       DECODE(부서번호,
              10, '개발팀',
              20, '영업팀',
              30, '기획팀',
              '기타') AS 부서명
FROM EMP;
```

위 DECODE는 단순 CASE와 동일한 결과를 냅니다. 표준 SQL은 CASE를 사용하고, Oracle 환경에서는 DECODE도 자주 씁니다.

## 핵심 정리

- ORDER BY는 실행 순서상 마지막이며, SELECT 별칭 사용 가능합니다.
- **ASC**: 오름차순(기본값), **DESC**: 내림차순
- 여러 열 정렬 시 왼쪽 열이 우선, 같을 때 오른쪽 열 기준 정렬
- Oracle에서 NULL은 ORDER BY ASC 시 맨 뒤, DESC 시 맨 앞 (NULLS FIRST/LAST로 변경 가능)
- **단순 CASE**: `CASE 열 WHEN 값 THEN 결과 END`
- **검색 CASE**: `CASE WHEN 조건 THEN 결과 END` — 더 유연한 표현식 사용
- DECODE는 Oracle 전용의 단순 CASE 축약 버전
