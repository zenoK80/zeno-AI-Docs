## 복습 방법

각 테이블의 행을 선으로 연결한다고 생각하자. 조건을 만족하는 선 하나가 결과 한 행이다.

<Callout type="info">
  쿼리를 읽기 전에 먼저 관계가 일대일·일대다·다대다 중 무엇인지 표시하면 행 수 함정을 줄일 수 있다.
</Callout>

## 직접 적용하기

다음 두 테이블을 `member_id`가 같다는 조건으로 내부 조인하자.

`members`

| member_id | name |
| --- | --- |
| M01 | 민지 |
| M02 | 준호 |
| M03 | 소라 |

`orders`

| order_id | member_id |
| ---: | --- |
| 101 | M01 |
| 102 | M01 |
| 103 | M03 |
| 104 | M99 |

1. 결과 행 수를 적는다.
2. 결과의 `name, order_id`를 모두 적는다.
3. 주문 104가 사라지는 이유를 설명한다.

<Collapse title="풀이와 검증 SQL">

결과는 3행이다.

| name | order_id |
| --- | ---: |
| 민지 | 101 |
| 민지 | 102 |
| 소라 | 103 |

M99 회원 행이 없으므로 주문 104는 내부 조인 조건을 만족하는 짝이 없다.

```sql
SELECT m.name, o.order_id
FROM members m
JOIN orders o
  ON m.member_id = o.member_id
ORDER BY o.order_id;
```

</Collapse>
