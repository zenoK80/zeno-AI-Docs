## 직접 적용하기

금액이 `500(A), 400(B), 400(C), 300(D), 200(E)`인 데이터에 대해 다음 결과 행의 이름을 적자.

1. `ROW_NUMBER() <= 2`
2. `RANK() <= 2`
3. `DENSE_RANK() <= 2`

<Collapse title="풀이">

동점의 ROW_NUMBER 순서는 이름 오름차순을 보조 기준으로 정했다고 하자.

1. ROW_NUMBER: A, B
2. RANK: A, B, C
3. DENSE_RANK: A, B, C

데이터에 다음 값 300이 더 있어도 RANK의 다음 순위는 4, DENSE_RANK는 3이 된다.

</Collapse>
