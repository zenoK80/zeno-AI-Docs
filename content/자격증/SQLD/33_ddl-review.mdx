## 직접 적용하기

다음 규칙을 만족하는 `products` 구조를 설계하자.

- product_id: 필수 고유 식별자
- name: 필수
- price: 0 이상 필수
- status: ACTIVE 또는 INACTIVE, 기본 ACTIVE

<Collapse title="풀이">

```sql
CREATE TABLE products (
  product_id VARCHAR(10) PRIMARY KEY,
  name       VARCHAR(100) NOT NULL,
  price      NUMBER(12) NOT NULL CHECK (price >= 0),
  status     VARCHAR(10) DEFAULT 'ACTIVE' NOT NULL
             CHECK (status IN ('ACTIVE', 'INACTIVE'))
);
```

`P01, 키보드, 50000, ACTIVE`는 허용된다. 음수 가격, NULL 이름, 목록 밖의 SOLDOUT 상태는 거부된다.

</Collapse>
