## ROLLUP: 소계와 총계

`GROUP BY ROLLUP`은 지정한 컬럼 조합의 **소계와 총계**를 자동으로 생성합니다.

```sql
SELECT 부서번호, 직급, SUM(급여) AS 급여합계
FROM   EMP
GROUP BY ROLLUP(부서번호, 직급);
```

| 부서번호 | 직급 | 급여합계   |
| -------- | ---- | ---------- |
| 10       | 과장 | 4500000    |
| 10       | 부장 | 6000000    |
| 10       | NULL | 10500000   |  ← 부서 10 소계
| 20       | 대리 | 3200000    |
| 20       | 과장 | 4800000    |
| 20       | NULL | 8000000    |  ← 부서 20 소계
| 30       | 사원 | 2500000    |
| 30       | NULL | 2500000    |  ← 부서 30 소계
| NULL     | NULL | 21000000   |  ← 전체 총계

`NULL`이 나타나는 행이 소계/총계 행입니다. 이를 구분하기 위해 `GROUPING()` 함수를 사용합니다.

### GROUPING() 함수

```sql
SELECT 부서번호,
       GROUPING(부서번호) AS 부서소계여부,
       SUM(급여) AS 급여합계
FROM   EMP
GROUP BY ROLLUP(부서번호);
```

| 부서번호 | 부서소계여부 | 급여합계 |
| -------- | ------------ | -------- |
| 10       | 0            | 10500000 |
| 20       | 0            | 8000000  |
| 30       | 0            | 2500000  |
| NULL     | **1**        | 21000000 |

`GROUPING(컬럼) = 1`이면 소계/총계 행, `= 0`이면 일반 데이터 행입니다.

## CUBE: 모든 조합의 소계

`GROUP BY CUBE`는 지정한 컬럼들의 **모든 조합**에 대한 소계를 생성합니다. ROLLUP보다 더 많은 소계 행이 생깁니다.

```sql
SELECT 부서번호, 직급, SUM(급여)
FROM   EMP
GROUP BY CUBE(부서번호, 직급);
```

ROLLUP(부서번호, 직급) 결과에 추가로 **직급별 소계**도 생성됩니다.

| 부서번호 | 직급 | SUM(급여) |
| -------- | ---- | --------- |
| NULL     | NULL | 21000000  |  ← 전체 총계
| NULL     | 과장 | 9300000   |  ← 직급별 소계 (CUBE 추가)
| NULL     | 대리 | 3200000   |  ← 직급별 소계 (CUBE 추가)
| NULL     | 부장 | 6000000   |  ← 직급별 소계 (CUBE 추가)
| NULL     | 사원 | 2500000   |  ← 직급별 소계 (CUBE 추가)
| 10       | NULL | 10500000  |  ← 부서 소계
| 10       | 과장 | 4500000   |
| 10       | 부장 | 6000000   |
| ...      | ...  | ...       |

## GROUPING SETS: 원하는 조합만 선택

소계를 원하는 컬럼 조합으로만 생성합니다.

```sql
-- 부서번호별 소계와 직급별 소계만 생성 (교차 조합 없음)
SELECT 부서번호, 직급, SUM(급여)
FROM   EMP
GROUP BY GROUPING SETS(부서번호, 직급);
```

| 부서번호 | 직급 | SUM(급여) |
| -------- | ---- | --------- |
| 10       | NULL | 10500000  |
| 20       | NULL | 8000000   |
| 30       | NULL | 2500000   |
| NULL     | 과장 | 9300000   |
| NULL     | 대리 | 3200000   |
| NULL     | 부장 | 6000000   |
| NULL     | 사원 | 2500000   |

## 윈도우 함수 기본 문법

윈도우 함수(Window Function)는 **집계 없이** 행마다 그룹 내 순위나 누적값을 계산합니다.

```sql
함수명() OVER (
  PARTITION BY 그룹기준컬럼
  ORDER BY     정렬컬럼
  ROWS/RANGE BETWEEN 시작 AND 끝
)
```

## 순위 함수: ROW_NUMBER, RANK, DENSE_RANK

세 함수 모두 순위를 매기지만 **동점 처리 방식**이 다릅니다.

```sql
SELECT 이름, 부서번호, 급여,
       ROW_NUMBER()  OVER (ORDER BY 급여 DESC) AS ROW_NUM,
       RANK()        OVER (ORDER BY 급여 DESC) AS RANK,
       DENSE_RANK()  OVER (ORDER BY 급여 DESC) AS DENSE_RANK
FROM   EMP;
```

아래 예시는 이해를 위해 급여 3위가 동점인 상황을 가정합니다.

| 이름   | 급여    | ROW_NUM | RANK | DENSE_RANK |
| ------ | ------- | ------- | ---- | ---------- |
| 박지훈 | 6000000 | 1       | 1    | 1          |
| 정도윤 | 4800000 | 2       | 2    | 2          |
| 김민준 | 4500000 | 3       | 3    | 3          |
| 이서연 | 3200000 | 4       | 4    | 4          |
| 최수아 | 2500000 | 5       | 5    | 5          |

**동점이 있을 때 차이**(가정: 이서연·최수아 동점 3위)

| 이름   | 급여    | ROW_NUM | RANK | DENSE_RANK |
| ------ | ------- | ------- | ---- | ---------- |
| 박지훈 | 6000000 | 1       | 1    | 1          |
| 정도윤 | 4800000 | 2       | 2    | 2          |
| 이서연 | 3200000 | 3       | 3    | 3          |
| 최수아 | 3200000 | 4       | **3** | **3**     |
| 김민준 | 4500000 | 5       | **5** | **4**     |

- `ROW_NUMBER`: 동점이어도 순차적으로 부여 (1, 2, 3, 4, 5)
- `RANK`: 동점이면 같은 순위, 다음 순위는 건너뜀 (1, 2, 3, 3, **5**)
- `DENSE_RANK`: 동점이면 같은 순위, 다음 순위는 연속 (1, 2, 3, 3, **4**)

## LAG / LEAD: 이전/다음 행 값

```sql
SELECT 이름, 급여,
       LAG(급여, 1) OVER (ORDER BY 급여)  AS 이전급여,
       LEAD(급여, 1) OVER (ORDER BY 급여) AS 다음급여
FROM   EMP;
```

| 이름   | 급여    | 이전급여 | 다음급여 |
| ------ | ------- | -------- | -------- |
| 최수아 | 2500000 | NULL     | 3200000  |
| 이서연 | 3200000 | 2500000  | 4500000  |
| 김민준 | 4500000 | 3200000  | 4800000  |
| 정도윤 | 4800000 | 4500000  | 6000000  |
| 박지훈 | 6000000 | 4800000  | NULL     |

## SUM() OVER: 누적 합계

```sql
-- 급여 순으로 정렬하며 누적 합계 계산
SELECT 이름, 급여,
       SUM(급여) OVER (ORDER BY 급여 ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS 누적급여
FROM   EMP;
```

| 이름   | 급여    | 누적급여  |
| ------ | ------- | --------- |
| 최수아 | 2500000 | 2500000   |
| 이서연 | 3200000 | 5700000   |
| 김민준 | 4500000 | 10200000  |
| 정도윤 | 4800000 | 15000000  |
| 박지훈 | 6000000 | 21000000  |

`PARTITION BY`를 추가하면 부서별 누적 합계를 구할 수 있습니다.

## ROLLUP vs CUBE vs GROUPING SETS 비교

| 함수           | 생성 소계                             |
| -------------- | ------------------------------------- |
| ROLLUP(A, B)   | (A, B), (A), () — 계층적 소계         |
| CUBE(A, B)     | (A, B), (A), (B), () — 모든 조합 소계 |
| GROUPING SETS  | 지정한 조합만                         |

## 핵심 정리

- **ROLLUP**: 계층적 소계 + 총계 자동 생성
- **CUBE**: 모든 조합의 소계 + 총계 (ROLLUP보다 더 많은 행)
- **GROUPING SETS**: 원하는 그룹 조합만 지정
- `GROUPING()`: 소계 행이면 1, 일반 행이면 0
- **ROW_NUMBER**: 동점 없이 순차 번호
- **RANK**: 동점 같은 번호, 다음 순위 건너뜀
- **DENSE_RANK**: 동점 같은 번호, 다음 순위 연속
- **LAG**(컬럼, N): N행 이전 값, **LEAD**(컬럼, N): N행 이후 값
- **SUM() OVER**(ORDER BY ...): 누적 집계
