## 복습 방법

업무 문장을 데이터 구조로 바꾸어 생각한 뒤 답을 고른다. 정답뿐 아니라 나머지 선지가 틀린 이유까지 확인한다.

<Callout type="info">
SQLD 문제는 비슷한 용어의 경계를 바꾸어 묻는 경우가 많다. 정의를 외우는 데서 끝내지 말고 회원·상품·주문 사례에 대입한다.
</Callout>

## 4지선다 문제

### 문제 1

개념 데이터 모델의 주된 목적은?

① 업무의 핵심 대상과 큰 관계를 이해관계자와 확인한다.

② 특정 DBMS의 자료형과 인덱스를 모두 확정한다.

③ 운영 서버를 즉시 설치한다.

④ SQL 실행계획만 분석한다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

개념 모델은 업무 전체 모습을 높은 수준에서 이해하고 합의하는 데 초점을 둔다.

- **①** 정답이다.
- **②** 물리 모델의 결정에 가깝다.
- **③** 배포 작업이다.
- **④** 성능 튜닝 단계다.

</Collapse>

### 문제 2

논리 데이터 모델에서 주로 다루는 것은?

① 엔터티·속성·식별자·관계 규칙을 DBMS와 비교적 독립적으로 상세화한다.

② 케이블 제조사만 고른다.

③ 화면 배경색만 정한다.

④ 실제 디스크 블록 위치를 직접 적는다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

논리 모델은 업무 데이터 구조를 자세히 표현하지만 특정 제품의 물리 구현 결정은 뒤 단계로 넘긴다.

- **①** 정답이다.
- **②** 물리 장비 선택이다.
- **③** UI 디자인이다.
- **④** 저장 장치 내부 구현 수준이다.

</Collapse>

### 문제 3

물리 데이터 모델에서 결정할 내용은?

① 선택한 DBMS의 테이블명, 열 자료형, 인덱스 등

② 업무 대상의 큰 관계만

③ 사용자 인터뷰 질문만

④ 모니터 크기만

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

물리 모델은 논리 구조를 실제 DBMS에 구현할 수 있는 구체적인 구조로 바꾼다.

- **①** 정답이다.
- **②** 개념 모델에 가깝다.
- **③** 요구사항 수집 활동이다.
- **④** 데이터 구조와 무관하다.

</Collapse>

### 문제 4

ERD에서 1:N 관계가 뜻하는 것은?

① 한쪽 인스턴스 하나가 다른 쪽 여러 인스턴스와 연결될 수 있다.

② 항상 테이블이 하나뿐이다.

③ 모든 관계가 선택이다.

④ 열이 N개라는 뜻이다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

예를 들어 회원 하나가 여러 주문을 할 수 있는 관계를 1:N으로 표현한다.

- **①** 정답이다.
- **②** 두 대상 사이 관계를 나타낸다.
- **③** 필수·선택 여부는 별도 표시다.
- **④** 열 개수가 아니다.

</Collapse>

### 문제 5

관계의 선택성이 의미하는 것은?

① 인스턴스가 그 관계에 반드시 참여해야 하는지 선택적으로 참여할 수 있는지

② DBMS 제품 가격

③ 테이블 글꼴

④ 네트워크 속도

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

예를 들어 신규 회원은 아직 주문이 없을 수 있으므로 회원의 주문 참여는 선택일 수 있다.

- **①** 정답이다.
- **②** 구매 조건과 무관하다.
- **③** 표시 스타일이 아니다.
- **④** 통신 성능과 다르다.

</Collapse>

## 직접 적용하기

‘회원은 주문을 하지 않을 수도 있고 여러 주문을 할 수 있다. 모든 주문은 반드시 회원 한 명의 주문이다’를 ERD의 관계 수와 선택성 문장으로 바꾸자.

<Collapse title="풀이 보기">

회원 한 명은 주문 0개 이상과 연결될 수 있으므로 회원에서 주문 방향은 0..N이다. 주문 하나는 반드시 회원 한 명과 연결되므로 주문에서 회원 방향은 1이다. 논리 모델에서는 회원과 주문의 1:N 관계와 필수·선택 조건을 표시하고, 물리 모델에서는 주문 테이블의 회원번호 외래키로 구현할 수 있다.

</Collapse>

## 결과 점검

- 5개 정답: 사례를 바꾸어도 같은 기준으로 설명할 수 있는지 확인한다.
- 3~4개 정답: 틀린 선지의 핵심 용어를 본편에서 다시 비교한다.
- 0~2개 정답: 용어표와 완결 사례부터 다시 읽고 재도전한다.
