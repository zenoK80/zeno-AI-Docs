## 자료형이란?

**자료형(Data Type)**은 테이블의 각 열에 저장할 수 있는 데이터의 종류를 미리 정의하는 것입니다. 잘못된 자료형을 사용하면 저장 오류나 예상치 못한 비교 결과가 발생할 수 있어 SQLD 시험에서도 자주 출제됩니다.

## 문자형: CHAR vs VARCHAR2

가장 많이 혼동하는 자료형 두 가지입니다.

### CHAR (고정 길이 문자)

`CHAR(n)`은 항상 **n자리를 고정으로 차지**합니다. 입력한 값이 n보다 짧으면 나머지를 **공백으로 채웁니다.**

```sql
-- CHAR(5)에 'ABC'를 저장하면 실제 저장값: 'ABC  ' (공백 2개 추가)
```

### VARCHAR2 (가변 길이 문자)

`VARCHAR2(n)`은 최대 n자리까지 저장할 수 있지만, 입력값의 **실제 길이만큼만** 저장합니다.

```sql
-- VARCHAR2(5)에 'ABC'를 저장하면 실제 저장값: 'ABC' (공백 없음)
```

### CHAR vs VARCHAR2 비교 정리

| 구분 | CHAR(5) | VARCHAR2(5) |
|------|---------|-------------|
| 'ABC' 저장 시 | 'ABC  ' (5자리) | 'ABC' (3자리) |
| 저장 공간 | 항상 고정 | 실제 크기만큼 |
| 비교 시 특징 | 공백 포함 비교 (주의!) | 실제 값만 비교 |

<Callout type="warning">
  **CHAR 비교 주의:** CHAR 타입끼리 비교할 때는 짧은 쪽에 공백이 자동으로 채워져 비교됩니다. 반면 CHAR와 VARCHAR2를 비교할 때는 공백이 채워지지 않아 'ABC'와 'ABC  '가 다른 값으로 처리될 수 있습니다. 이 부분이 시험에 자주 출제됩니다.
</Callout>

## 숫자형: NUMBER

`NUMBER(p, s)` 형식으로 사용합니다.

- **p** (precision): 전체 유효 숫자 자릿수 (최대 38자리)
- **s** (scale): 소수점 이하 자릿수

```sql
NUMBER(7, 2) -- 전체 7자리, 소수점 이하 2자리 → 예: 12345.67
NUMBER(5)    -- 정수 5자리
```

EMP 테이블의 급여 열은 NUMBER 타입으로 4500000 같은 정수를 저장합니다.

## 날짜형: DATE

`DATE`는 날짜와 **시간(시·분·초)을 함께 저장**합니다. 날짜만 저장하는 것처럼 보여도 내부적으로 시간 정보가 포함되어 있습니다.

```sql
-- DATE 타입 저장 예
입사일: 2018-03-15 00:00:00
```

날짜 연산도 가능합니다. 날짜에서 날짜를 빼면 **일수 차이**가 숫자로 반환됩니다.

```sql
SELECT SYSDATE - 입사일 AS 근무일수
FROM EMP
WHERE 이름 = '김민준';
-- 결과: 현재 날짜에서 2018-03-15를 뺀 일수
```

## NULL이란?

**NULL**은 "값이 없는 상태"를 나타냅니다. 0(숫자 영)도 아니고, 공백(' ')도 아닙니다. 아직 알 수 없거나, 해당 사항이 없을 때 사용합니다.

EMP 테이블에서 외주 사원의 직급은 아직 정해지지 않아 NULL로 저장될 수 있습니다.

### NULL 연산 결과

NULL이 포함된 **모든 산술 연산의 결과는 NULL**이 됩니다.

```sql
SELECT 급여 + NULL AS 테스트
FROM EMP;
-- 결과: 모든 행이 NULL
```

| 연산 | 결과 |
|------|------|
| NULL + 100 | NULL |
| NULL * 0   | NULL |
| NULL \|\| '문자' | NULL (Oracle 문자 연결) |

## NULL 비교: IS NULL / IS NOT NULL

NULL은 일반 비교 연산자(`=`, `<>`)로 비교할 수 없습니다.

```sql
-- 틀린 방법 (항상 결과가 없음)
SELECT * FROM EMP WHERE 직급 = NULL;

-- 올바른 방법
SELECT * FROM EMP WHERE 직급 IS NULL;
```

<Callout type="warning">
  **절대 틀리면 안 되는 포인트:** `WHERE 열 = NULL`은 항상 아무 행도 반환하지 않습니다. NULL 비교는 반드시 **IS NULL** 또는 **IS NOT NULL**을 사용해야 합니다.
</Callout>

### 직급이 NULL인 사원 조회

```sql
SELECT 이름, 직급
FROM EMP
WHERE 직급 IS NULL;
```

현재 예시 데이터에는 NULL인 직급이 없지만, 외주 사원이 추가된다면 이 쿼리로 조회할 수 있습니다.

### 직급이 있는 사원만 조회

```sql
SELECT 이름, 직급
FROM EMP
WHERE 직급 IS NOT NULL;
```

**결과:**

| 이름   | 직급 |
|--------|------|
| 김민준 | 과장 |
| 이서연 | 대리 |
| 박지훈 | 부장 |
| 최수아 | 사원 |
| 정도윤 | 과장 |

## NULL 처리 함수

NULL이 있을 때 대체 값을 지정하는 함수들입니다.

### NVL (Oracle)

`NVL(값, 대체값)`: 값이 NULL이면 대체값을 반환합니다.

```sql
SELECT 이름, NVL(직급, '미정') AS 직급
FROM EMP;
-- 직급이 NULL인 사원의 직급을 '미정'으로 표시
```

### ISNULL (SQL Server)

SQL Server에서는 `ISNULL(값, 대체값)` 형식을 사용합니다. 기능은 NVL과 동일합니다.

### COALESCE (표준 SQL)

`COALESCE(값1, 값2, 값3, ...)`: 나열된 값 중 **첫 번째로 NULL이 아닌 값**을 반환합니다.

```sql
SELECT 이름, COALESCE(직급, '미정') AS 직급
FROM EMP;
```

COALESCE는 여러 열을 순서대로 확인할 수 있어 더 유연합니다.

```sql
-- 직급이 NULL이면 부서명을 사용하고, 그것도 NULL이면 '정보없음'
SELECT COALESCE(직급, 부서명, '정보없음') AS 표시값
FROM EMP;
```

### NVL2 (Oracle 전용)

`NVL2(값, NULL이_아닐때_반환값, NULL일때_반환값)`: NULL 여부에 따라 서로 다른 값을 반환합니다.

```sql
SELECT 이름, NVL2(직급, '직급있음', '직급없음') AS 직급여부
FROM EMP;
```

## 핵심 정리

- **CHAR**: 고정 길이, 짧은 값은 공백으로 채워짐 / **VARCHAR2**: 가변 길이, 실제 크기만큼만 저장
- **DATE**: 날짜 + 시간 모두 저장, 날짜 간 뺄셈은 일수 반환
- NULL은 0도 아니고 공백도 아닌 "값 없음" 상태
- NULL 포함 산술 연산 결과는 항상 NULL
- NULL 비교는 `= NULL` 대신 반드시 **IS NULL / IS NOT NULL** 사용
- NULL 처리 함수: **NVL**(Oracle), **ISNULL**(SQL Server), **COALESCE**(표준)
