## 복습 방법

각 SELECT 결과를 먼저 별도의 작은 표로 적는다. 그다음 행 전체를 기준으로 합집합·공통·차이를 표시한다.

## 직접 적용하기

A와 B의 결과가 다음과 같다.

| A | B |
| --- | --- |
| M01 | M01 |
| M02 | M03 |
| M03 | M04 |

`UNION`, `UNION ALL`, `INTERSECT`, `A EXCEPT B`, `B EXCEPT A`의 결과를 각각 적자.

<Collapse title="풀이">

- UNION: M01, M02, M03, M04
- UNION ALL: M01, M02, M03, M01, M03, M04
- INTERSECT: M01, M03
- A EXCEPT B: M02
- B EXCEPT A: M04

UNION과 차집합의 출력 순서는 ORDER BY가 없으면 보장되지 않는다. 위 목록은 값 비교를 위한 표현이다.

</Collapse>
