## 복습 방법

각 행에 조건을 대입해 TRUE·FALSE·UNKNOWN 중 하나를 먼저 적고, WHERE는 TRUE만 남긴다는 순서로 푼다.

<Callout type="info">
  NULL을 빈칸처럼 눈으로만 보지 말고 “비교할 실제 값이 없다”라고 읽는다.
</Callout>

## 직접 적용하기

다음 데이터에서 각 SQL의 결과를 예측하자.

| order_id | discount_amount |
| ---: | ---: |
| 1001 | 0 |
| 1002 | 3,000 |
| 1003 | NULL |

```text
A. WHERE discount_amount = 0
B. WHERE discount_amount <> 0
C. WHERE discount_amount IS NULL
D. SELECT SUM(discount_amount), COUNT(discount_amount), COUNT(*)
```

<Collapse title="풀이 보기">

| 구문 | 결과 |
| --- | --- |
| A | 주문 1001 |
| B | 주문 1002. 1003은 UNKNOWN이라 제외 |
| C | 주문 1003 |
| D | `SUM=3000`, `COUNT(column)=2`, `COUNT(*)=3` |

SUM은 NULL을 제외하고 0과 3000을 더한다. `COUNT(discount_amount)`는 실제 값 두 개를 세며, `COUNT(*)`는 모든 행을 센다.

</Collapse>

## 결과 점검

- 5개 정답: 조건마다 TRUE·FALSE·UNKNOWN을 손으로 표시한다.
- 3~4개 정답: `= NULL`과 `IS NULL`, 두 COUNT의 차이를 다시 본다.
- 0~2개 정답: 세 행에 각 조건을 직접 대입해 본다.
