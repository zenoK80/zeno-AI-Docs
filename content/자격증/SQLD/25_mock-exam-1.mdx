## 1과목: 데이터 모델링의 이해

> **업무 규칙**
> - 하나의 강의는 반드시 하나의 강의실에서만 진행된다.
> - 하나의 강의실에서는 여러 강의가 진행될 수 있다.
> - 강의실은 현재 배정된 강의가 없을 수도 있다.

초기 상태: 계좌(계좌번호, 잔액)에 A001: 500000 존재

트랜잭션:
```sql
UPDATE 계좌 SET 잔액 = 잔액 - 100000 WHERE 계좌번호 = 'A001';
SAVEPOINT S1;
UPDATE 계좌 SET 잔액 = 잔액 - 200000 WHERE 계좌번호 = 'A001';
ROLLBACK TO S1;
UPDATE 계좌 SET 잔액 = 잔액 + 50000 WHERE 계좌번호 = 'A001';
COMMIT;
```

| 1 | ERD 관계 | 선택성/차수 | 필수/선택 구분 혼동 |
| 2 | 정규화 | 부분·이행 함수 종속 | 종속 유형 혼동 |
| 3 | 반정규화 | 목적과 부작용 | 정규화와 목적 혼동 |
| 4 | NULL 처리 | COUNT 함수 | COUNT(*) vs COUNT(컬럼) 혼동 |
| 5 | JOIN | LEFT OUTER JOIN | NULL 컬럼 처리, 미매칭 행 처리 혼동 |
| 6 | 실행 순서 | WHERE vs HAVING | WHERE에 집계 함수 사용 불가 |
| 7 | GROUP BY/HAVING | 집계 후 필터 | 합계 계산 실수 |
| 8 | 윈도우 함수 | DENSE_RANK | RANK와 DENSE_RANK 혼동 |
| 9 | TCL | SAVEPOINT/ROLLBACK TO | 복원 시점 혼동 |
| 10 | 서브쿼리 | 단일행 서브쿼리 | 서브쿼리 결과 계산 실수 |

**자주 틀리는 유형 TOP 3**:
1. WHERE vs HAVING (실행 순서)
2. NULL 연산 (COUNT(*) vs COUNT(컬럼))
3. RANK vs DENSE_RANK (동점 처리)
