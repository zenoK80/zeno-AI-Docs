## 단일행 함수 vs 집계 함수

함수는 크게 두 종류로 나뉩니다.

| 구분 | 설명 | 예시 |
|------|------|------|
| **단일행 함수** | 행마다 하나의 결과를 반환 (입력 1행 → 출력 1행) | UPPER, SUBSTR, ROUND |
| **집계 함수** | 여러 행을 그룹으로 묶어 하나의 결과 반환 | COUNT, SUM, AVG, MAX, MIN |

이번 문서에서는 단일행 함수를 중점적으로 다루고, 집계 함수는 12번 문서에서 상세히 다룹니다.

## 문자 함수

문자열을 다루는 함수입니다. SQLD에서 가장 많이 출제되는 유형입니다.

### UPPER / LOWER: 대소문자 변환

```sql
SELECT UPPER('hello') FROM DUAL;   -- 결과: HELLO
SELECT LOWER('WORLD') FROM DUAL;   -- 결과: world
```

> **DUAL**: Oracle에서 함수 결과만 확인할 때 사용하는 가상 테이블입니다.

### LENGTH: 문자열 길이

```sql
SELECT 이름, LENGTH(이름) AS 이름길이
FROM EMP;
```

**결과:**

| 이름   | 이름길이 |
|--------|---------|
| 김민준 | 3       |
| 이서연 | 3       |
| 박지훈 | 3       |
| 최수아 | 3       |
| 정도윤 | 3       |

### SUBSTR: 문자열 자르기

`SUBSTR(문자열, 시작위치, 길이)`: 시작위치부터 지정한 길이만큼 추출합니다. **위치는 1부터 시작**합니다.

```sql
SELECT SUBSTR('김민준', 1, 2) FROM DUAL;  -- 결과: 김민
SELECT SUBSTR('김민준', 2)    FROM DUAL;  -- 결과: 민준 (2번째부터 끝까지)
```

```sql
-- 이름의 첫 글자(성)만 조회
SELECT 이름, SUBSTR(이름, 1, 1) AS 성
FROM EMP;
```

**결과:**

| 이름   | 성 |
|--------|-----|
| 김민준 | 김  |
| 이서연 | 이  |
| 박지훈 | 박  |
| 최수아 | 최  |
| 정도윤 | 정  |

### TRIM / LTRIM / RTRIM: 공백 제거

```sql
SELECT TRIM('  SQL  ')   FROM DUAL;  -- 결과: 'SQL' (양쪽 공백 제거)
SELECT LTRIM('  SQL  ')  FROM DUAL;  -- 결과: 'SQL  ' (왼쪽만 제거)
SELECT RTRIM('  SQL  ')  FROM DUAL;  -- 결과: '  SQL' (오른쪽만 제거)
```

### REPLACE: 문자열 치환

`REPLACE(문자열, 찾을문자, 바꿀문자)`

```sql
SELECT REPLACE('2024-03-15', '-', '/') FROM DUAL;
-- 결과: 2024/03/15
```

### CONCAT: 문자열 연결

```sql
SELECT CONCAT(이름, ' 사원') AS 표시명
FROM EMP
WHERE 직급 = '사원';
-- 결과: 최수아 사원
```

Oracle에서는 `||` 연산자로도 연결할 수 있습니다.

```sql
SELECT 이름 || ' (' || 직급 || ')' AS 표시명
FROM EMP;
-- 예: 김민준 (과장)
```

## 숫자 함수

| 함수 | 설명 | 예시 | 결과 |
|------|------|------|------|
| `ROUND(값, 자릿수)` | 반올림 | ROUND(4567.456, 2) | 4567.46 |
| `ROUND(값, 자릿수)` | 음수 자릿수 | ROUND(4567.456, -2) | 4600 |
| `TRUNC(값, 자릿수)` | 버림(절삭) | TRUNC(4567.456, 2) | 4567.45 |
| `MOD(값, 나누는수)` | 나머지 | MOD(10, 3) | 1 |
| `ABS(값)` | 절댓값 | ABS(-5) | 5 |
| `CEIL(값)` | 올림 | CEIL(4.1) | 5 |
| `FLOOR(값)` | 내림 | FLOOR(4.9) | 4 |

```sql
-- 급여를 만 원 단위로 반올림
SELECT 이름, ROUND(급여, -4) AS 만원단위급여
FROM EMP;
```

**결과:**

| 이름   | 만원단위급여 |
|--------|------------|
| 김민준 | 50000      |
| 이서연 | 30000      |
| 박지훈 | 60000      |
| 최수아 | 30000      |
| 정도윤 | 50000      |

<Callout type="warning">
  **ROUND vs TRUNC:** ROUND는 반올림, TRUNC는 무조건 버림(절삭)입니다. TRUNC(4.9, 0)은 4를 반환합니다.
</Callout>

## 날짜 함수

| 함수 | 설명 | 예시 |
|------|------|------|
| `SYSDATE` | 현재 날짜와 시간 (Oracle) | SELECT SYSDATE FROM DUAL |
| `ADD_MONTHS(날짜, n)` | n개월 후 날짜 | ADD_MONTHS('2024-01-15', 3) → 2024-04-15 |
| `MONTHS_BETWEEN(날짜1, 날짜2)` | 두 날짜 사이의 개월 수 | MONTHS_BETWEEN('2024-04-15', '2024-01-15') → 3 |
| `LAST_DAY(날짜)` | 해당 월의 마지막 날 | LAST_DAY('2024-02-01') → 2024-02-29 |
| `NEXT_DAY(날짜, 요일)` | 다음 특정 요일의 날짜 | NEXT_DAY(SYSDATE, '월요일') |

```sql
-- 각 사원의 입사 후 경과 개월 수
SELECT 이름, 입사일,
       MONTHS_BETWEEN(SYSDATE, 입사일) AS 근무개월수
FROM EMP;
```

```sql
-- 입사일로부터 3개월 후 날짜 (수습 종료일)
SELECT 이름, ADD_MONTHS(입사일, 3) AS 수습종료일
FROM EMP;
```

## 변환 함수

자료형을 변환하는 함수입니다.

### TO_CHAR: 숫자·날짜를 문자로 변환

```sql
-- 날짜를 원하는 형식의 문자로 변환
SELECT TO_CHAR(입사일, 'YYYY년 MM월 DD일') AS 입사일표시
FROM EMP;
-- 예: 2018년 03월 15일

-- 숫자에 천 단위 구분자 추가
SELECT TO_CHAR(급여, '9,999,999') AS 급여표시
FROM EMP;
-- 예: 4,500,000
```

### TO_NUMBER: 문자를 숫자로 변환

```sql
SELECT TO_NUMBER('4500000') + 500000 FROM DUAL;
-- 결과: 5000000
```

### TO_DATE: 문자를 날짜로 변환

```sql
SELECT TO_DATE('2024-03-15', 'YYYY-MM-DD') FROM DUAL;
-- 문자열을 DATE 타입으로 변환
```

## 자주 출제되는 함수 요약

| 카테고리 | 함수 | SQLD 출제 빈도 |
|---------|------|--------------|
| 문자 | SUBSTR, LENGTH, TRIM | ★★★ |
| 문자 | UPPER, LOWER, REPLACE | ★★ |
| 숫자 | ROUND, TRUNC, MOD | ★★★ |
| 날짜 | SYSDATE, ADD_MONTHS, MONTHS_BETWEEN | ★★★ |
| 변환 | TO_CHAR, TO_DATE | ★★★ |
| NULL | NVL, COALESCE | ★★★ |

## 핵심 정리

- **단일행 함수**: 행마다 결과 반환 (UPPER, SUBSTR, ROUND 등)
- **집계 함수**: 여러 행을 묶어 하나의 결과 반환 (COUNT, SUM 등)
- SUBSTR 위치는 1부터 시작, 음수 자릿수 ROUND는 정수 부분을 반올림
- ROUND는 반올림, TRUNC는 버림(절삭)으로 결과가 다릅니다
- TO_CHAR로 날짜·숫자를 원하는 형식의 문자열로 변환합니다
- 날짜 연산: 날짜 - 날짜 = 일수, ADD_MONTHS로 개월 수 더하기
