## 복습 방법

각 문제에서 후보키를 먼저 표시한 뒤, 어느 속성이 키 전체·일부·일반 속성에 의존하는지 판단한다.

<Callout type="info">
정규형 이름만 외우지 말고 `결정자 → 종속 속성` 화살표를 직접 적으면 함정 선지를 줄일 수 있다.
</Callout>

## 직접 적용하기

다음 비정규 테이블을 3NF까지 분해하고 각 테이블의 키를 표시하자.

```text
대여원장(
  대여번호, 대여일,
  회원번호, 회원명, 회원등급코드, 회원등급명,
  도서번호, 도서명, 출판사번호, 출판사명,
  반납예정일
)

업무 규칙:
대여번호 → 대여일, 회원번호, 도서번호, 반납예정일
회원번호 → 회원명, 회원등급코드
회원등급코드 → 회원등급명
도서번호 → 도서명, 출판사번호
출판사번호 → 출판사명
```

<Collapse title="풀이 보기">

대여번호가 단일 후보키이므로 부분 함수 종속은 없다. 그러나 회원번호와 도서번호를 거치는 이행 함수 종속이 있다.

```text
회원등급(회원등급코드 PK, 회원등급명)
회원(회원번호 PK, 회원명, 회원등급코드 FK)
출판사(출판사번호 PK, 출판사명)
도서(도서번호 PK, 도서명, 출판사번호 FK)
대여(대여번호 PK, 대여일, 회원번호 FK, 도서번호 FK, 반납예정일)
```

회원명은 회원번호에, 회원등급명은 등급코드에, 도서명은 도서번호에, 출판사명은 출판사번호에 한 번만 저장된다. 대여를 삭제해도 회원·도서·출판사 사실이 사라지지 않는다.

</Collapse>

## 결과 점검

- 5개 정답: 함수 종속을 직접 적어 새로운 테이블을 분해한다.
- 3~4개 정답: 부분 종속과 이행 종속의 차이를 다시 확인한다.
- 0~2개 정답: 본편의 주문 원장을 1NF부터 순서대로 다시 분해한다.
