</Callout>

실제 SQLD는 1과목 데이터 모델링 10문항(20점), 2과목 SQL 기본 및 활용 40문항(80점), 총 100점 만점이며 과목별 40퍼센트(40%) 미만이면 과락으로 처리되어 총점과 무관하게 불합격합니다. 이 회차도 같은 배점 구조를 그대로 따릅니다. 시간을 재고 끝까지 풀어본 뒤 채점하고, 마지막 절의 복습 동선표를 따라 약한 구간만 골라 다시 보는 것을 권장합니다.

## 합격 기준 안내

SQLD는 데이터 모델링 10문항(20점)과 SQL 기본 및 활용 40문항(80점), 총 100점 만점이며 두 조건을 동시에 만족해야 합격합니다.

- **과락 방지**: 데이터 모델링에서 4문항(8점) 미만, SQL에서 16문항(32점) 미만으로 맞히면 과목별 40퍼센트(40%) 기준 미달로 과락 처리되어 총점과 무관하게 불합격합니다.
- **평균 합격선**: 두 과목 점수를 합쳐 60점(전체 30문항) 이상이어야 합니다.

이 회차에서 데이터 모델링 1–10번 중 4문항 미만을 맞혔거나, SQL 11–50번 중 16문항 미만을 맞혔다면 총점과 관계없이 위험 신호입니다. 위 복습 동선표를 따라 취약 구간부터 채우십시오.
