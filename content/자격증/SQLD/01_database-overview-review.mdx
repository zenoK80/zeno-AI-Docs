## 복습 방법

업무 문장을 데이터 구조로 바꾸어 생각한 뒤 답을 고른다. 정답뿐 아니라 나머지 선지가 틀린 이유까지 확인한다.

<Callout type="info">
SQLD 문제는 비슷한 용어의 경계를 바꾸어 묻는 경우가 많다. 정의를 외우는 데서 끝내지 말고 회원·상품·주문 사례에 대입한다.
</Callout>

## 4지선다 문제

### 문제 1

데이터베이스와 DBMS의 관계를 가장 정확히 설명한 것은?

① 데이터베이스는 저장된 데이터 구조이고 DBMS는 이를 관리하는 소프트웨어다.

② 둘은 언제나 같은 파일 이름이다.

③ DBMS는 데이터 한 행만 뜻한다.

④ 데이터베이스는 모니터 장치다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

데이터베이스는 관리 대상인 데이터의 모음이고 DBMS는 저장·조회·변경·보호 기능을 제공한다.

- **①** 정답이다.
- **②** 역할이 서로 다르다.
- **③** 행은 테이블의 개별 기록이다.
- **④** 소프트웨어와 데이터 구조에 관한 개념이다.

</Collapse>

### 문제 2

회원 테이블에서 행 하나가 일반적으로 나타내는 것은?

① 회원 한 명의 기록

② 회원 이름 열의 정의만

③ 데이터베이스 전체

④ SQL 언어 전체

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

행은 한 회원이나 한 주문처럼 한 대상의 구체적인 기록이다.

- **①** 정답이다.
- **②** 열은 공통 속성을 나타낸다.
- **③** 테이블 하나보다 더 큰 범위다.
- **④** 명령 언어와 데이터 행은 다르다.

</Collapse>

### 문제 3

기본키의 가장 중요한 목적은?

① 테이블의 각 행을 유일하게 구분한다.

② 모든 값을 같은 내용으로 만든다.

③ 열 이름을 숨긴다.

④ 데이터베이스를 그림 파일로 바꾼다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

기본키는 중복되지 않고 비어 있지 않은 값으로 행을 식별하는 기준이 된다.

- **①** 정답이다.
- **②** 구분이 불가능해진다.
- **③** 스키마 정보를 숨기는 기능이 아니다.
- **④** 파일 변환 기능이 아니다.

</Collapse>

### 문제 4

외래키의 역할로 가장 적절한 것은?

① 다른 테이블의 키를 참조해 행 사이의 관계를 표현한다.

② 현재 행을 무조건 삭제한다.

③ 모든 문장을 암호화한다.

④ 테이블의 글꼴을 선택한다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

예를 들어 주문의 회원번호 외래키가 회원 테이블의 회원을 가리켜 누가 주문했는지 연결한다.

- **①** 정답이다.
- **②** 삭제 명령 자체가 아니다.
- **③** 암호화 기능과 다르다.
- **④** 표시 스타일과 무관하다.

</Collapse>

### 문제 5

SQL은 무엇인가?

① 관계형 DBMS에 데이터 조회와 변경 등을 요청하는 언어

② 저장장치 케이블 규격

③ CPU 제조 공정

④ 이미지 압축 형식

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

SQL은 Structured Query Language로 테이블 구조와 데이터를 정의·조회·변경·제어하는 데 사용한다.

- **①** 정답이다.
- **②** SATA 등에 가까운 개념이다.
- **③** 하드웨어 제조 용어다.
- **④** 데이터베이스 요청 언어다.

</Collapse>

## 직접 적용하기

회원, 상품, 주문을 저장하려 한다. 각 테이블의 행이 무엇을 뜻하는지와 기본키 후보, 주문에서 필요한 외래키 후보를 적어 보자.

<Collapse title="풀이 보기">

회원 테이블의 한 행은 회원 한 명이고 회원번호를 기본키로 둘 수 있다. 상품 한 행은 상품 하나이고 상품번호가 기본키 후보다. 주문 한 행은 주문 사건 하나이고 주문번호가 기본키 후보다. 주문에 회원번호 외래키를 두면 주문한 회원과 연결된다. 상품과 주문의 다대다 관계는 뒤에서 주문상세 같은 별도 구조로 풀게 된다.

</Collapse>
