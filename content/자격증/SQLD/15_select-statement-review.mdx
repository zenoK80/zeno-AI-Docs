## 복습 방법

FROM의 입력 행 수를 먼저 적고 SELECT 목록이 어떤 열을 만들며 DISTINCT가 어느 조합을 비교하는지 순서대로 본다.

<Callout type="info">
  SELECT에 적었다고 원본 열이 바뀌는 것은 아니다. 이번 조회 결과의 모양만 바뀐다.
</Callout>

## 직접 적용하기

다음 데이터에 SQL을 적용한 결과를 적어 보자.

| member_name | city | points |
| --- | --- | ---: |
| 민지 | 서울 | 1,200 |
| 준호 | 부산 | 500 |
| 소라 | 서울 | 800 |

```sql
SELECT DISTINCT city,
       points * 2 AS doubled_points
FROM members;
```

<Collapse title="풀이 보기">

| city | doubled_points |
| --- | ---: |
| 서울 | 2,400 |
| 부산 | 1,000 |
| 서울 | 1,600 |

서울이 두 번이어도 doubled_points가 다르므로 `(city, doubled_points)` 조합은 모두 다르다. 따라서 DISTINCT가 제거하는 행은 없고 결과는 3행 2열이다.

</Collapse>

## 결과 점검

- 5개 정답: SELECT 목록만 보고 결과 열과 별칭을 설명한다.
- 3~4개 정답: DISTINCT가 열 조합 전체를 비교한다는 점을 다시 확인한다.
- 0~2개 정답: 입력 한 행마다 표현식을 직접 계산한다.
