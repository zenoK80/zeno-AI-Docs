<Callout type="info">
  **이번 문서의 목표:** COUNT, SUM, AVG, MAX, MIN 집계 함수를 사용하고 GROUP BY로 그룹을 나누어 HAVING으로 조건을 거는 방법을 이해합니다.
</Callout>

## 집계 함수란?

**집계 함수(Aggregate Function)**는 여러 행의 값을 하나의 결과로 합쳐주는 함수입니다. 단일행 함수와 달리 여러 행 → 하나의 결과를 반환합니다.

| 함수 | 설명 |
|------|------|
| `COUNT(*)` | 전체 행의 수를 셉니다 (NULL 포함) |
| `COUNT(열)` | 해당 열에서 NULL이 아닌 행의 수를 셉니다 |
| `SUM(열)` | 합계 (NULL은 제외하고 계산) |
| `AVG(열)` | 평균 (NULL은 제외하고 계산) |
| `MAX(열)` | 최댓값 |
| `MIN(열)` | 최솟값 |

### COUNT(\*)와 COUNT(열)의 차이

이것은 SQLD에서 자주 출제되는 핵심 차이점입니다.

```sql
-- 전체 사원 수 (NULL 포함)
SELECT COUNT(*) AS 전체사원수
FROM EMP;
```

**결과:** 5

```sql
-- 직급이 있는 사원 수만 (NULL 제외)
SELECT COUNT(직급) AS 직급있는사원수
FROM EMP;
```

**결과:** 직급이 NULL인 사원이 없으면 5, 있으면 그보다 작은 값

<Callout type="warning">
  **COUNT(\*)와 COUNT(열)의 핵심 차이:** COUNT(*)는 NULL을 포함한 모든 행을 세고, COUNT(열명)은 해당 열에서 NULL인 행을 제외하고 셉니다.
</Callout>

### 집계 함수 기본 예시

```sql
SELECT
    COUNT(*) AS 사원수,
    SUM(급여) AS 급여합계,
    AVG(급여) AS 평균급여,
    MAX(급여) AS 최고급여,
    MIN(급여) AS 최저급여
FROM EMP;
```

**결과:**

| 사원수 | 급여합계  | 평균급여 | 최고급여 | 최저급여 |
|--------|---------|---------|---------|---------|
| 5      | 21000000 | 4200000  | 6000000  | 2500000  |

## GROUP BY: 그룹으로 나누어 집계

집계 함수는 테이블 전체가 하나의 그룹이지만, **GROUP BY**를 사용하면 특정 열 기준으로 그룹을 나누어 각 그룹별 집계를 구할 수 있습니다.

### 부서별 사원 수와 평균 급여

```sql
SELECT 부서번호,
       COUNT(*) AS 사원수,
       AVG(급여) AS 평균급여
FROM EMP
GROUP BY 부서번호;
```

**결과:**

| 부서번호 | 사원수 | 평균급여   |
|---------|--------|-----------|
| 10      | 2      | 5250000   |
| 20      | 2      | 4000000   |
| 30      | 1      | 2500000   |

### 부서별 급여 합계와 최대·최소 급여

```sql
SELECT 부서번호,
       SUM(급여) AS 급여합계,
       MAX(급여) AS 최고급여,
       MIN(급여) AS 최저급여
FROM EMP
GROUP BY 부서번호
ORDER BY 부서번호;
```

**결과:**

| 부서번호 | 급여합계  | 최고급여 | 최저급여 |
|---------|---------|---------|---------|
| 10      | 10500000 | 6000000  | 4500000  |
| 20      | 8000000  | 4800000  | 3200000  |
| 30      | 2500000  | 2500000  | 2500000  |

### GROUP BY 사용 규칙

<Callout type="warning">
  **중요 규칙:** SELECT 절에 집계 함수가 아닌 열이 있다면, 그 열은 반드시 GROUP BY 절에도 있어야 합니다. 이를 어기면 오류가 발생합니다.

  ```sql
  -- 오류: 이름이 GROUP BY에 없음
  SELECT 부서번호, 이름, COUNT(*)
  FROM EMP
  GROUP BY 부서번호;  -- 이름이 없어서 오류!

  -- 올바른 예: 집계 함수 또는 GROUP BY에 포함된 열만 SELECT 가능
  SELECT 부서번호, COUNT(*)
  FROM EMP
  GROUP BY 부서번호;
  ```
</Callout>

## HAVING: 그룹에 조건 걸기

WHERE 절이 개별 행을 필터링한다면, **HAVING**은 GROUP BY로 만들어진 **그룹에 조건을 거는** 절입니다.

### WHERE vs HAVING 비교

| 구분 | WHERE | HAVING |
|------|-------|--------|
| 대상 | 개별 행 | 그룹 (GROUP BY 이후) |
| 집계 함수 사용 | 사용 불가 | 사용 가능 |
| 실행 순서 | GROUP BY 이전 | GROUP BY 이후 |

### 사원 수가 2명 이상인 부서만 조회

```sql
SELECT 부서번호,
       COUNT(*) AS 사원수,
       AVG(급여) AS 평균급여
FROM EMP
GROUP BY 부서번호
HAVING COUNT(*) >= 2;
```

**결과:**

| 부서번호 | 사원수 | 평균급여  |
|---------|--------|---------|
| 10      | 2      | 5250000 |
| 20      | 2      | 4000000 |

### 평균 급여가 400만 원 이상인 부서만 조회

```sql
SELECT 부서번호, AVG(급여) AS 평균급여
FROM EMP
GROUP BY 부서번호
HAVING AVG(급여) >= 4000000;
```

**결과:**

| 부서번호 | 평균급여  |
|---------|---------|
| 10      | 5250000 |
| 20      | 4000000 |

### WHERE와 HAVING 함께 사용

WHERE로 특정 행을 먼저 제외한 뒤 나머지 행을 그룹화하고, HAVING으로 그룹을 다시 필터링할 수 있습니다.

```sql
-- 사원(직급='사원')을 제외하고, 부서별 사원 수가 1명 이상인 부서
SELECT 부서번호, COUNT(*) AS 인원수
FROM EMP
WHERE 직급 <> '사원'
GROUP BY 부서번호
HAVING COUNT(*) >= 1;
```

## SQL 실행 순서 복습

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

- **WHERE**는 개별 행을 먼저 필터링합니다.
- **GROUP BY**로 그룹을 만듭니다.
- **HAVING**으로 그룹을 필터링합니다.
- **SELECT**에서 출력할 열을 결정합니다.

이 순서 때문에 WHERE 절에서는 집계 함수를 쓸 수 없습니다. 집계 함수 조건은 반드시 HAVING에 씁니다.

```sql
-- 틀린 예: WHERE에 집계 함수 사용 불가
SELECT 부서번호, AVG(급여)
FROM EMP
WHERE AVG(급여) > 4000000  -- 오류!
GROUP BY 부서번호;

-- 올바른 예: 집계 함수 조건은 HAVING에
SELECT 부서번호, AVG(급여)
FROM EMP
GROUP BY 부서번호
HAVING AVG(급여) > 4000000;
```

## 핵심 정리

- **COUNT(\*)**: NULL 포함 전체 행 수 / **COUNT(열)**: NULL 제외한 행 수
- SUM, AVG, MAX, MIN은 모두 NULL을 제외하고 계산합니다.
- GROUP BY는 특정 열 기준으로 행을 그룹화하고 집계를 구합니다.
- SELECT 절에 집계 함수가 아닌 열은 반드시 GROUP BY에도 포함되어야 합니다.
- **WHERE**: 개별 행 필터 (집계 함수 사용 불가) / **HAVING**: 그룹 필터 (집계 함수 사용 가능)
- 실행 순서: **FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY**
