## Top N 쿼리: 상위 N건 조회

### ROWNUM (Oracle)

`ROWNUM`은 결과 집합에 **물리적 순서 번호**를 부여하는 의사열(Pseudo-column)입니다.

**잘못된 방법:**

```sql
-- 급여 상위 3명을 구하려는 의도지만 잘못된 쿼리
SELECT 이름, 급여
FROM   EMP
WHERE  ROWNUM <= 3
ORDER BY 급여 DESC;  -- ORDER BY가 ROWNUM 이후에 적용됨!
```

이 방식은 정렬 전에 ROWNUM이 먼저 부여되어, 아무 행 3개를 선택한 뒤 정렬합니다.

**올바른 방법 (서브쿼리 사용):**

```sql
SELECT 이름, 급여
FROM   (SELECT 이름, 급여
        FROM   EMP
        ORDER BY 급여 DESC)  -- 먼저 정렬
WHERE  ROWNUM <= 3;           -- 그 다음 상위 3행 선택
```

| 이름   | 급여    |
| ------ | ------- |
| 박지훈 | 6000000 |
| 정도윤 | 4800000 |
| 김민준 | 4500000 |

<Callout type="warning">
  **ROWNUM 사용 시 주의:** `ROWNUM = 1`은 가능하지만 `ROWNUM = 2`나 `ROWNUM > 1`은 0행을 반환합니다. ROWNUM은 항상 1부터 시작하기 때문입니다.
</Callout>

### ROW_NUMBER() 활용 (표준 방법)

```sql
-- 급여 상위 3~5위 사원 조회 (페이징 처리)
SELECT 이름, 급여, 순위
FROM   (SELECT 이름, 급여,
               ROW_NUMBER() OVER (ORDER BY 급여 DESC) AS 순위
        FROM   EMP)
WHERE  순위 BETWEEN 3 AND 5;
```

| 이름   | 급여    | 순위 |
| ------ | ------- | ---- |
| 김민준 | 4500000 | 3    |
| 이서연 | 3200000 | 4    |
| 최수아 | 2500000 | 5    |

## 계층형 질의 (Hierarchical Query)

Oracle에서 **부모-자식 관계**를 가진 데이터를 트리 구조로 조회합니다.

### 예시 데이터 (관리자-사원 관계)

| 사원번호 | 이름   | 관리자번호 |
| -------- | ------ | ---------- |
| 1003     | 박지훈 | NULL       |
| 1001     | 김민준 | 1003       |
| 1005     | 정도윤 | 1003       |
| 1004     | 최수아 | 1001       |

계층 구조:
```
박지훈 (1003) - 최상위
  ├── 김민준 (1001)
  │     └── 최수아 (1004)
  └── 정도윤 (1005)
```

### 기본 문법

```sql
SELECT LEVEL, 사원번호, 이름, 관리자번호
FROM   EMP
START WITH 관리자번호 IS NULL          -- 루트 노드 조건
CONNECT BY PRIOR 사원번호 = 관리자번호 -- 부모 → 자식 방향
ORDER SIBLINGS BY 이름;                -- 같은 레벨 내 정렬
```

| LEVEL | 사원번호 | 이름   | 관리자번호 |
| ----- | -------- | ------ | ---------- |
| 1     | 1003     | 박지훈 | NULL       |
| 2     | 1001     | 김민준 | 1003       |
| 3     | 1004     | 최수아 | 1001       |
| 2     | 1005     | 정도윤 | 1003       |

### 핵심 키워드

| 키워드                          | 의미                                      |
| ------------------------------- | ----------------------------------------- |
| `START WITH`                    | 루트 노드(최상위) 조건 지정               |
| `CONNECT BY PRIOR A = B`        | A(부모)에서 B(자식)로 내려가는 방향       |
| `CONNECT BY PRIOR B = A`        | B(자식)에서 A(부모)로 올라가는 방향       |
| `LEVEL`                         | 현재 행의 깊이 (루트=1)                   |
| `ORDER SIBLINGS BY`             | 같은 레벨 내에서 정렬                     |
| `CONNECT_BY_ROOT`               | 루트 노드의 값 반환                       |
| `SYS_CONNECT_BY_PATH(컬럼, /)` | 루트부터 현재까지 경로 문자열             |

<Callout type="info">
  `PRIOR`의 위치가 방향을 결정합니다. `PRIOR 사원번호 = 관리자번호`는 "내 사원번호가 다음 행의 관리자번호" → 위에서 아래로 탐색(부모→자식)입니다.
</Callout>

### LEVEL을 활용한 들여쓰기

```sql
SELECT LEVEL,
       LPAD(' ', (LEVEL-1)*4) || 이름 AS 조직도
FROM   EMP
START WITH 관리자번호 IS NULL
CONNECT BY PRIOR 사원번호 = 관리자번호;
```

| LEVEL | 조직도         |
| ----- | -------------- |
| 1     | 박지훈         |
| 2     | &nbsp;&nbsp;&nbsp;&nbsp;김민준  |
| 3     | &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;최수아 |
| 2     | &nbsp;&nbsp;&nbsp;&nbsp;정도윤  |

## PIVOT: 행을 열로 변환

행 데이터를 열 방향으로 펼쳐서 **교차 집계표(크로스탭)**를 만듭니다.

```sql
-- 부서별·직급별 급여 합계를 교차표로
SELECT *
FROM   (SELECT 부서번호, 직급, 급여 FROM EMP)
PIVOT  (SUM(급여) FOR 직급 IN ('과장' AS 과장, '대리' AS 대리, '부장' AS 부장, '사원' AS 사원));
```

| 부서번호 | 과장    | 대리    | 부장    | 사원    |
| -------- | ------- | ------- | ------- | ------- |
| 10       | 4500000 | NULL    | 6000000 | NULL    |
| 20       | 4800000 | 3200000 | NULL    | NULL    |
| 30       | NULL    | NULL    | NULL    | 2500000 |

## UNPIVOT: 열을 행으로 변환

PIVOT의 반대 연산으로 열 데이터를 행으로 변환합니다.

```sql
-- 분기별 매출 컬럼을 행으로 변환하는 예시
SELECT 제품, 분기, 매출
FROM   분기별매출
UNPIVOT (매출 FOR 분기 IN (Q1매출 AS 'Q1', Q2매출 AS 'Q2', Q3매출 AS 'Q3', Q4매출 AS 'Q4'));
```

## 정규표현식 기본

Oracle에서 패턴 기반 문자열 검색에 사용합니다.

| 함수               | 설명                                  |
| ------------------ | ------------------------------------- |
| `REGEXP_LIKE`      | 패턴에 맞는 행 필터링 (WHERE 절)      |
| `REGEXP_SUBSTR`    | 패턴에 맞는 부분 문자열 추출          |
| `REGEXP_REPLACE`   | 패턴에 맞는 문자열 교체               |
| `REGEXP_INSTR`     | 패턴에 맞는 위치 반환                 |

```sql
-- 이름이 '김'으로 시작하는 사원 (LIKE와 유사)
SELECT 이름 FROM EMP WHERE REGEXP_LIKE(이름, '^김');

-- 이메일에서 @ 앞부분 추출
SELECT REGEXP_SUBSTR(이메일, '[^@]+') AS 아이디 FROM EMP;
```

**주요 정규표현식 패턴:**

| 패턴   | 의미            |
| ------ | --------------- |
| `^`    | 문자열 시작     |
| `$`    | 문자열 끝       |
| `.`    | 임의의 문자 1개 |
| `*`    | 0회 이상 반복   |
| `+`    | 1회 이상 반복   |
| `[0-9]`| 숫자            |
| `[a-z]`| 소문자 알파벳   |

## 핵심 정리

- **ROWNUM**: 서브쿼리에서 먼저 ORDER BY 후 외부에서 ROWNUM 조건 적용
- **ROWNUM 제한**: `= 1` 가능, `= 2` 불가 (항상 1부터 순차 부여)
- **ROW_NUMBER() OVER**: 페이징 처리에 활용
- **START WITH**: 계층형 질의의 루트(시작점) 조건
- **CONNECT BY PRIOR**: 방향 결정 (`PRIOR 부모 = 자식` → 위→아래)
- **LEVEL**: 계층 깊이 의사열 (루트=1)
- **ORDER SIBLINGS BY**: 같은 깊이 내 정렬
- **PIVOT**: 행 → 열 변환 (집계 포함)
- **UNPIVOT**: 열 → 행 변환
