## 03편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

### 문제 1

학생은 여러 강좌를 수강할 수 있고, 강좌에도 여러 학생이 참여한다. 수강신청일과 성적을 기록한다. 엔터티와 관계를 제시한다.

### 문제 2

상품 테이블에 `최근주문수량`을 저장하려 한다. 이 설계에서 확인해야 할 문제를 설명한다.

### 문제 3

"부서에는 여러 사원이 있고, 사원은 하나의 부서에 소속된다"에서 관계 수를 표현한다.

## 정답과 해설

### 문제 1

학생과 강좌는 N:M 관계다. 관계에 신청일과 성적이 있으므로 `수강신청` 연결 엔터티를 두고 학생-수강신청, 강좌-수강신청을 각각 1:N으로 만든다.

### 문제 2

최근주문수량은 상품 자체의 고정 속성이 아니라 주문에 따라 변하고 "최근"의 기준도 모호하다. 주문상세에서 계산할 값인지, 성능 때문에 별도로 보관한다면 갱신 규칙이 있는지 확인해야 한다.

### 문제 3

부서 1 : 사원 N 관계다. 사원 쪽에 부서를 참조하는 식별자가 놓이는 것이 일반적이다.
