## 복습 방법

중첩 함수는 안쪽부터 계산하고 CASE는 위에서부터 처음 TRUE인 조건에서 멈춘다고 표시한 뒤 답을 고른다.

<Callout type="info">
  함수 이름만 외우지 말고 입력 자료형, 인수의 위치와 반환값을 한 줄씩 계산한다.
</Callout>

## 직접 적용하기

다음 식의 중간 결과와 최종 결과를 계산하자.

```sql
SELECT TO_CHAR(
         ADD_MONTHS(DATE '2026-08-10', 2),
         'YYYY/MM/DD'
       ) AS result
FROM dual;
```

<Collapse title="풀이 보기">

```text
1. DATE '2026-08-10'                        → 날짜 2026-08-10
2. ADD_MONTHS(2026-08-10, 2)               → 날짜 2026-10-10
3. TO_CHAR(2026-10-10, 'YYYY/MM/DD')        → 문자 '2026/10/10'
```

| result |
| --- |
| 2026/10/10 |

최종 표시 모양은 날짜처럼 보여도 자료형은 TO_CHAR가 반환한 문자다.

</Collapse>
