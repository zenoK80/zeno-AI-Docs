## 복습 방법

PRIOR가 붙은 식 위에 “이전 단계”라고 쓰고, 시작 행부터 화살표를 한 단계씩 그린다.

## 직접 적용하기

다음 데이터에서 B를 시작점으로 순방향과 역방향 결과를 각각 적자.

| id | parent_id |
| --- | --- |
| A | NULL |
| B | A |
| C | B |
| D | B |
| E | C |

<Collapse title="풀이">

- 순방향 `PRIOR id = parent_id`: B(LEVEL 1), C·D(LEVEL 2), E(LEVEL 3)
- 역방향 `id = PRIOR parent_id`: B(LEVEL 1), A(LEVEL 2)

순방향은 B의 자손을, 역방향은 B의 조상을 찾는다.

</Collapse>
