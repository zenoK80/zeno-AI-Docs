## 서브쿼리란?

서브쿼리(Subquery)는 **다른 SQL 문장 안에 포함된 SELECT 문**입니다. 외부 쿼리(메인 쿼리)에 데이터를 제공하는 역할을 합니다.

## 단일 행 서브쿼리

결과가 **1행 1열**인 서브쿼리입니다. `=`, `<>`, `>`, `<`, `>=`, `<=` 같은 단일 행 비교 연산자와 함께 사용합니다.

```sql
-- 박지훈(부장)과 같은 부서에 근무하는 사원 조회
SELECT 이름, 부서번호, 직급
FROM   EMP
WHERE  부서번호 = (SELECT 부서번호 FROM EMP WHERE 이름 = '박지훈');
```

| 이름   | 부서번호 | 직급 |
| ------ | -------- | ---- |
| 김민준 | 10       | 과장 |
| 박지훈 | 10       | 부장 |

서브쿼리 `(SELECT 부서번호 FROM EMP WHERE 이름 = '박지훈')`는 `10`을 반환합니다.

<Callout type="warning">
  단일 행 서브쿼리가 2행 이상을 반환하면 오류가 발생합니다. 결과가 여러 행일 경우 다중 행 연산자(IN, ANY, ALL)를 사용해야 합니다.
</Callout>

## 다중 행 서브쿼리

결과가 **여러 행**인 서브쿼리입니다. `IN`, `ANY`, `ALL`, `EXISTS` 연산자와 함께 사용합니다.

### IN

```sql
-- 영업팀 또는 기획팀에 소속된 사원 조회
SELECT 이름, 부서번호
FROM   EMP
WHERE  부서번호 IN (SELECT 부서번호 FROM DEPT WHERE 부서명 IN ('영업팀', '기획팀'));
```

| 이름   | 부서번호 |
| ------ | -------- |
| 이서연 | 20       |
| 최수아 | 30       |
| 정도윤 | 20       |

### ANY / ALL

```sql
-- 영업팀(20) 사원 중 누구보다 급여가 높은 사원
SELECT 이름, 급여
FROM   EMP
WHERE  급여 > ANY (SELECT 급여 FROM EMP WHERE 부서번호 = 20);
-- ANY: 영업팀 최솟값(3200000)보다 크면 됨

-- 영업팀(20) 사원 모두보다 급여가 높은 사원
SELECT 이름, 급여
FROM   EMP
WHERE  급여 > ALL (SELECT 급여 FROM EMP WHERE 부서번호 = 20);
-- ALL: 영업팀 최댓값(4800000)보다 커야 함
```

`> ANY`는 `> MIN(...)`, `> ALL`은 `> MAX(...)`와 같은 의미입니다.

### EXISTS

```sql
-- 부하직원이 있는 사원(관리자) 조회
SELECT 이름, 사원번호
FROM   EMP E
WHERE  EXISTS (SELECT 1 FROM EMP WHERE 관리자번호 = E.사원번호);
```

`EXISTS`는 서브쿼리에 행이 **하나라도 존재**하면 TRUE를 반환합니다. 대용량 데이터에서 `IN`보다 성능이 좋을 수 있습니다.

## 상관 서브쿼리

**외부 쿼리의 값을 참조**하는 서브쿼리입니다. 메인 쿼리의 각 행마다 서브쿼리가 실행됩니다.

```sql
-- 자신의 부서 평균 급여보다 높은 급여를 받는 사원
SELECT E1.이름, E1.부서번호, E1.급여
FROM   EMP E1
WHERE  E1.급여 > (SELECT AVG(E2.급여)
                   FROM   EMP E2
                   WHERE  E2.부서번호 = E1.부서번호);
```

| 이름   | 부서번호 | 급여    |
| ------ | -------- | ------- |
| 박지훈 | 10       | 6000000 |
| 정도윤 | 20       | 4800000 |

- 개발팀(10) 평균: (4500000 + 6000000) / 2 = 5250000 → 박지훈만 해당
- 영업팀(20) 평균: (3200000 + 4800000) / 2 = 4000000 → 정도윤만 해당

## FROM 절 서브쿼리 (인라인 뷰)

FROM 절에 쓰는 서브쿼리로, **가상 테이블**처럼 사용합니다.

```sql
-- 부서별 평균 급여를 구하고, 그 중 평균이 400만 초과인 부서
SELECT 부서번호, 평균급여
FROM   (SELECT 부서번호, ROUND(AVG(급여), 0) AS 평균급여
        FROM   EMP
        GROUP BY 부서번호) 서브
WHERE  평균급여 > 4000000;
```

| 부서번호 | 평균급여 |
| -------- | -------- |
| 10       | 5250000  |
| 20       | 4000000  |

## SELECT 절 서브쿼리 (스칼라 서브쿼리)

SELECT 절에 쓰는 서브쿼리로, **반드시 1행 1열**을 반환해야 합니다.

```sql
-- 각 사원과 해당 사원 부서의 부서명 함께 조회
SELECT E.이름,
       E.급여,
       (SELECT D.부서명 FROM DEPT D WHERE D.부서번호 = E.부서번호) AS 부서명
FROM   EMP E;
```

| 이름   | 급여    | 부서명 |
| ------ | ------- | ------ |
| 김민준 | 4500000 | 개발팀 |
| 이서연 | 3200000 | 영업팀 |
| 박지훈 | 6000000 | 개발팀 |

## 집합 연산자

두 SELECT 문의 결과를 합치거나 교집합/차집합을 구합니다. **컬럼 수와 데이터 타입**이 동일해야 합니다.

| 연산자     | 의미                                   | 중복 처리  |
| ---------- | -------------------------------------- | ---------- |
| UNION ALL  | 두 결과를 그대로 합침                  | 중복 포함  |
| UNION      | 두 결과를 합치고 중복 제거             | 중복 제거  |
| INTERSECT  | 두 결과의 교집합 (공통 행)             | 중복 제거  |
| MINUS      | 첫 번째에서 두 번째 결과를 뺀 차집합  | 중복 제거  |

```sql
-- UNION ALL: 개발팀과 영업팀 사원 전체 (중복 있으면 중복 포함)
SELECT 이름, 급여 FROM EMP WHERE 부서번호 = 10
UNION ALL
SELECT 이름, 급여 FROM EMP WHERE 부서번호 = 20;
```

| 이름   | 급여    |
| ------ | ------- |
| 김민준 | 4500000 |
| 박지훈 | 6000000 |
| 이서연 | 3200000 |
| 정도윤 | 4800000 |

```sql
-- MINUS: 관리자인 사원에서 개발팀 관리자를 제외
SELECT DISTINCT 관리자번호 FROM EMP WHERE 관리자번호 IS NOT NULL
MINUS
SELECT 사원번호 FROM EMP WHERE 부서번호 = 10;
```

<Callout type="info">
  **UNION ALL vs UNION**: UNION ALL이 중복 제거 정렬 과정이 없어 성능이 더 빠릅니다. 중복이 없음을 알고 있다면 UNION ALL을 사용하는 것이 좋습니다.
</Callout>

## 핵심 정리

- **단일 행 서브쿼리**: `=`, `>` 등 단일 행 연산자, 결과가 1행 초과 시 오류
- **다중 행 서브쿼리**: `IN`, `ANY`, `ALL`, `EXISTS` 사용
- **상관 서브쿼리**: 외부 쿼리 컬럼 참조, 행마다 서브쿼리 실행
- **인라인 뷰**: FROM 절 서브쿼리, 가상 테이블로 사용
- **스칼라 서브쿼리**: SELECT 절, 반드시 1행 1열 반환
- **UNION ALL**: 중복 포함, 빠름
- **UNION**: 중복 제거, UNION ALL보다 느림
- **INTERSECT**: 교집합, **MINUS**: 차집합
