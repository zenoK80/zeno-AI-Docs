## 직접 적용하기

시작 points가 A=100, B=200, C=300이다.

```sql
UPDATE members SET points = points + 50 WHERE member_id <> 'B';
DELETE FROM members WHERE points >= 350;
```

각 문장의 영향 행 수와 마지막 데이터를 적자.

<Collapse title="풀이">

UPDATE는 A와 C 두 행을 바꿔 A=150, B=200, C=350이다. 이어진 DELETE는 C 한 행을 제거한다. 마지막은 A=150, B=200이며 영향 행 수는 차례로 2행, 1행이다.

</Collapse>
