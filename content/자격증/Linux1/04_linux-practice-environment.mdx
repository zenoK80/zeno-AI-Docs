## 실습 환경은 복구가 쉬워야 한다

리눅스 실습에서는 권한을 바꾸고, 서비스를 중지하고, 설정 파일을 수정합니다. 처음에는 실수가 자연스럽기 때문에 "문제를 일으키지 않는 환경"보다 **문제를 되돌릴 수 있는 환경**이 더 중요합니다.

실습 환경을 만들 때 목표는 세 가지입니다.

- 현재 상태를 확인할 수 있을 것
- 변경 전 상태로 빠르게 돌아갈 수 있을 것
- 실제 시험과 비슷한 터미널 작업을 반복할 수 있을 것

## 기본 작업 공간 만들기

로그인한 일반 사용자 홈 디렉터리에 실습용 폴더를 만듭니다.

```bash
mkdir -p ~/lab/{files,permissions,network,services}
cd ~/lab
pwd
tree -d 2>/dev/null || find . -type d
```

`mkdir -p`는 중간 폴더가 없어도 한 번에 만듭니다. 명령의 결과를 매번 확인하는 습관은 실기에서 오타를 줄이는 데 도움이 됩니다.

<Callout type="warning">
  연습 파일은 `/etc`, `/usr`, `/var` 같은 시스템 디렉터리 대신 처음에는 `~/lab` 아래에 만드세요. 시스템 설정을 건드릴 실습은 목적과 복구 방법을 함께 확인한 뒤 진행합니다.
</Callout>

## 스냅샷과 복원 지점

스냅샷은 가상 머신의 디스크와 설정 상태를 저장해 두는 기능입니다. 다음 시점에 하나씩 남겨 두면 좋습니다.

| 시점 | 스냅샷 이름 예시 | 이유 |
| --- | --- | --- |
| 설치 직후 | `01-fresh-install` | 깨끗한 기본 상태 확보 |
| 네트워크 확인 후 | `02-network-ready` | 패키지와 원격 실습의 출발점 |
| 서비스 실습 전 | `03-before-services` | 설정 실수에서 빠르게 복구 |

스냅샷을 자주 만들되, 무엇을 하기 전의 상태인지 이름으로 남겨야 나중에 잘못된 시점으로 돌아가지 않습니다.

## 가상 머신 네트워크 모드 이해하기

가상화 프로그램의 네트워크 모드는 "가상 머신이 어디와 통신할 수 있는가"를 정합니다. 제품 화면의 명칭은 조금 다를 수 있지만 의미는 비슷합니다.

| 모드 | 주로 쓰는 상황 | 특징 |
| --- | --- | --- |
| NAT | 인터넷 연결, 패키지 설치 | 호스트의 네트워크를 통해 외부 통신 |
| 브리지 | 같은 공유기 안에서 다른 기기와 통신 | 가상 머신이 별도 기기처럼 보일 수 있음 |
| 호스트 전용 | 내 PC와 가상 머신만 연결 | 외부와 분리한 실습에 유용 |

처음에는 NAT 하나로도 대부분의 명령 연습이 가능합니다. 네트워크 설정 문제를 풀 때는 현재 모드를 확인한 뒤 `ip addr`, `ip route` 결과를 함께 봐야 합니다.

```bash
ip addr show
ip route show
ping -c 3 1.1.1.1
```

마지막 명령은 IP 주소까지 통신이 되는지 확인합니다. 이름 해석까지 확인하려면 별도로 도메인 이름에 ping을 해 보고, 두 결과가 다를 때 DNS 문제인지 구분합니다.

## 터미널 작업의 기본 루틴

<Steps>

### 현재 상태를 확인한다

현재 사용자, 경로, 대상 파일의 권한을 먼저 확인합니다.

```bash
whoami
pwd
ls -l 대상파일
```

### 한 가지 변경만 한다

명령을 여러 개 붙여 실행하기보다, 한 번 변경하고 결과를 확인합니다.

### 결과를 검증한다

권한은 `ls -l`, 서비스는 `systemctl status`, 네트워크는 `ip addr`처럼 목적에 맞는 명령으로 확인합니다.

### 기록하고 정리한다

무엇을 바꿨는지 짧게 기록하고, 필요하면 실습 파일을 지우거나 스냅샷으로 되돌립니다.

</Steps>

## 편집기와 도움말도 환경의 일부다

설정 파일 편집 문제를 대비해 `vi` 또는 `vim`의 기본 이동, 입력, 저장, 종료는 반복해서 익혀야 합니다. 명령이 기억나지 않을 때는 내장 도움말도 활용합니다.

```bash
man ls
ls --help
man 5 passwd
```

`man 5 passwd`처럼 섹션 번호를 붙이면 명령 자체가 아니라 설정 파일 형식 문서를 찾을 수 있습니다. 모든 옵션을 암기하기보다 문서를 빠르게 읽는 능력도 실습에서 유용합니다.

## 이번 편 정리

- 실습 환경은 정상 상태로 되돌릴 수 있게 스냅샷을 관리한다.
- NAT, 브리지, 호스트 전용의 통신 범위를 구분한다.
- 확인 -> 변경 -> 검증 -> 기록 순서로 명령을 실행한다.
