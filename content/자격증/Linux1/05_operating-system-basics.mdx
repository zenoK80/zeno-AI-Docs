## 운영체제는 왜 필요할까?

웹 서버와 편집기가 동시에 실행되면 두 프로그램 모두 CPU, 메모리, 디스크를 사용하려 한다. 프로그램이 하드웨어를 직접 제어한다면 서로의 데이터를 침범하거나 한 프로그램이 CPU를 독점할 수 있다.

운영체제는 프로그램과 하드웨어 사이에서 자원을 배분하고 보호한다.

| 자원 | 운영체제의 역할 | 확인 명령 |
| --- | --- | --- |
| CPU | 실행할 프로세스와 시간을 스케줄링한다. | `ps`, `top` |
| 메모리 | 프로세스별 주소 공간을 관리한다. | `free`, `vmstat` |
| 저장장치 | 파일과 디렉터리, 접근 권한을 관리한다. | `ls`, `df`, `lsblk` |
| 장치·네트워크 | 드라이버와 통신 기능을 제공한다. | `lspci`, `ip` |

## 커널과 사용자 공간

```text
사용자
  ↓ 명령 입력
셸과 응용 프로그램        사용자 공간
  ↓ 시스템 호출
커널                      커널 공간
  ↓ 장치 제어
CPU · 메모리 · 디스크 · 네트워크
```

**커널**은 운영체제의 핵심으로 자원과 장치를 관리한다. 일반 프로그램은 커널 메모리에 직접 접근하지 않고 `open`, `read`, `write` 같은 시스템 호출을 통해 기능을 요청한다.

**사용자 공간**은 셸, 편집기, 웹 서버처럼 일반 프로그램이 실행되는 영역이다. 프로그램 하나가 잘못되더라도 커널과 다른 프로세스를 함부로 손상시키지 못하도록 경계를 둔다.

```bash
uname -r
cat /proc/version
```

두 명령은 실행 중인 커널 정보를 서로 다른 형태로 보여 준다.

## 셸은 명령을 해석하는 프로그램이다

셸은 사용자가 입력한 명령을 해석하고 프로그램을 실행한다. Rocky Linux에서 흔히 사용하는 셸은 Bash다.

```bash
echo "$SHELL"
ps -p $$ -o pid,ppid,comm
```

`$SHELL`은 로그인 셸의 경로를 보여 준다. `$$`는 현재 셸의 프로세스 ID이며, `ps` 출력에서 현재 셸도 하나의 프로세스임을 확인할 수 있다.

<Callout type="info">
셸과 터미널은 같은 말이 아니다. 터미널은 입출력 화면을 제공하고, 셸은 그 안에서 명령을 해석해 실행하는 프로그램이다.
</Callout>

## 프로그램과 프로세스

- **프로그램**: 디스크에 저장된 실행 코드다.
- **프로세스**: 프로그램이 메모리에 올라와 실행 중인 상태다.

같은 프로그램을 두 번 실행하면 프로그램 파일은 하나여도 프로세스는 둘이 될 수 있다.

```bash
sleep 300 &
sleep 300 &
pgrep -a sleep
jobs
```

`&`는 명령을 백그라운드에서 실행한다. `pgrep -a`에는 서로 다른 PID를 가진 두 프로세스가 보여야 한다.

실습을 마치면 생성한 프로세스를 정리한다.

```bash
pkill -x sleep
pgrep -a sleep || echo "sleep 프로세스 없음"
```

마지막 줄은 `sleep` 프로세스가 없을 때 안내 문장을 출력한다. 생성한 자원을 직접 정리하는 것도 실습의 일부다.

## 프로세스의 기본 상태

| 상태 문자 | 의미 |
| --- | --- |
| `R` | 실행 중이거나 CPU 실행을 기다리는 상태 |
| `S` | 이벤트를 기다리며 잠든 상태 |
| `D` | 주로 장치 입출력을 기다리는 중단 불가 수면 상태 |
| `T` | 신호 등에 의해 중지된 상태 |
| `Z` | 종료됐지만 부모가 종료 상태를 회수하지 않은 좀비 상태 |

`ps -eo pid,ppid,stat,comm | head`로 현재 프로세스의 PID, 부모 PID, 상태를 확인할 수 있다. 상태 문자는 상황을 진단하는 단서이지 그 자체만으로 장애 원인이 확정되는 것은 아니다.

## 메모리와 가상 메모리

```bash
free -h
```

Linux는 남는 메모리를 파일 캐시로 적극 활용하므로 `free` 열만 보고 메모리가 부족하다고 단정하면 안 된다. 일반적으로 새 프로그램이 사용할 수 있는 여유를 판단할 때는 `available`을 함께 본다.

스왑은 메모리 압박 시 디스크 일부를 보조 공간으로 사용하는 기능이다. 스왑 사용량이 있다는 사실만으로 장애는 아니며, 지속적인 지연과 입출력 증가 등 다른 지표와 함께 판단한다.

## 파일 시스템과 디렉터리

Linux에서는 장치와 여러 시스템 정보도 파일 형태의 인터페이스로 다뤄진다.

| 경로 | 대표 역할 |
| --- | --- |
| `/etc` | 시스템과 서비스 설정 |
| `/var` | 로그, 캐시처럼 계속 변하는 데이터 |
| `/home` | 일반 사용자 홈 디렉터리 |
| `/proc` | 프로세스와 커널 정보를 보여 주는 가상 파일 시스템 |
| `/dev` | 장치 파일 |
| `/tmp` | 임시 파일 |

```bash
df -h /
findmnt /
ls -ld /etc /var /home /proc /dev /tmp
```

`df`는 파일 시스템 공간을, `findmnt`는 어떤 장치와 파일 시스템이 해당 경로에 마운트됐는지 보여 준다.
