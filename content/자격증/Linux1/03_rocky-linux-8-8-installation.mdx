## 왜 Rocky Linux 8.8인가?

리눅스마스터 1급 실기 환경은 안내된 Rocky Linux 8.8을 기준으로 준비하는 편이 좋습니다. 리눅스 명령 자체는 여러 배포판에서 비슷하지만, 패키지 이름, 기본 설정 파일 위치, 서비스 관리 방식은 배포판과 버전에 따라 차이가 날 수 있습니다.

<Callout type="info">
  설치의 목표는 멋진 서버를 만드는 것이 아니라, 명령을 여러 번 망가뜨리고 다시 해도 되는 안전한 실습 환경을 만드는 것입니다.
</Callout>

## 설치 전에 준비할 것

- 가상화 프로그램: VirtualBox처럼 가상 머신을 만들 수 있는 도구
- Rocky Linux 8.8 설치 이미지: 시험 안내와 맞는 이미지를 사용
- 디스크 여유 공간과 가상화 기능이 켜진 PC
- 실습 기록용 메모: 설치 중 정한 계정과 네트워크 설정

가상 머신은 현재 PC 안에 별도의 가상 컴퓨터를 만드는 방식입니다. 실제 PC의 운영체제를 지우지 않고 Linux를 설치하고 초기화할 수 있어 학습에 적합합니다.

## 설치 흐름 한 번에 보기

<Steps>

### 가상 머신을 만든다

가상화 프로그램에서 새 Linux 가상 머신을 만들고 Rocky Linux 8.8 ISO를 연결합니다. CPU, 메모리, 디스크 크기는 동시에 실행할 프로그램 수와 PC 사양을 고려해 정합니다.

### ISO로 부팅한다

가상 머신을 시작해 설치 화면으로 들어갑니다. 설치 화면이 나오지 않으면 ISO 연결과 부팅 순서를 먼저 확인합니다.

### 설치 항목을 정한다

언어, 시간대, 설치 대상 디스크, 네트워크, 소프트웨어 선택, 사용자 계정을 순서대로 점검합니다. 실습용이라도 root 계정의 비밀번호는 추측하기 어렵게 정합니다.

### 설치를 완료하고 재부팅한다

설치가 끝나면 ISO를 분리한 뒤 가상 디스크로 부팅합니다. 다시 설치 화면으로 돌아간다면 ISO가 계속 연결되어 있지 않은지 봅니다.

### 버전을 확인한다

로그인 후 운영체제와 커널 정보를 확인합니다.

</Steps>

```bash
cat /etc/os-release
uname -r
hostnamectl
```

`/etc/os-release`는 배포판 정보를, `uname -r`은 현재 실행 중인 커널 버전을 보여 줍니다. 명령의 결과를 캡처하거나 메모해 두면 나중에 환경이 달라졌을 때 비교하기 쉽습니다.

## 설치 중 특히 확인할 항목

### 계정과 권한

root는 시스템 전체를 바꿀 수 있는 관리자 계정입니다. 평소 실습은 일반 계정으로 로그인하고, 필요한 순간에만 `sudo`로 권한을 올리는 습관이 안전합니다.

```bash
whoami
id
sudo -v
```

`whoami`는 현재 로그인한 사용자를, `id`는 사용자와 그룹 정보를 보여 줍니다. `sudo -v`는 현재 계정이 sudo 인증을 할 수 있는지 확인할 때 쓸 수 있습니다.

### 네트워크

패키지 설치나 원격 접속을 연습하려면 네트워크가 필요합니다. 설치 직후 아래 명령으로 인터페이스와 주소를 확인해 보세요.

```bash
ip addr
ip route
```

`ip addr`에는 네트워크 인터페이스와 IP 주소가, `ip route`에는 기본 게이트웨이를 포함한 라우팅 정보가 나타납니다.

### 스냅샷

가상화 프로그램의 스냅샷은 특정 시점의 상태를 보관하는 기능입니다. 사용자, 권한, 부트 설정 실습 전에는 정상 동작하는 상태로 스냅샷을 하나 남겨 두세요. 실습을 잘못해도 다시 설치하지 않고 되돌릴 수 있습니다.

## 설치 확인 미니 실습

다음 명령을 한 번씩 실행하고, 결과가 무엇을 의미하는지 적어 보세요.

```bash
pwd
ls -la
date
df -h
free -h
```

- `pwd`: 현재 작업 중인 디렉터리
- `ls -la`: 숨김 파일을 포함한 목록과 권한
- `date`: 시스템 시간
- `df -h`: 파일 시스템별 디스크 사용량
- `free -h`: 메모리 사용량

설치가 끝났다는 것은 로그인 화면이 보인다는 뜻을 넘어, 기본 정보를 스스로 확인할 수 있다는 뜻입니다.

## 자주 막히는 지점

- **부팅할 때마다 설치 화면이 나온다**: ISO가 가상 CD/DVD 장치에 남아 있는지 확인한다.
- **네트워크가 안 된다**: 가상 머신의 네트워크 어댑터가 활성화되어 있는지, IP가 할당되었는지 `ip addr`로 확인한다.
- **root로만 모든 작업을 한다**: 실수의 범위가 커진다. 일반 계정과 `sudo` 사용을 같이 연습한다.

## 이번 편 정리

- 시험 기준 환경에 맞는 Rocky Linux 8.8 가상 머신을 준비한다.
- 설치 뒤 배포판, 커널, 사용자, 네트워크 상태를 명령으로 확인한다.
- 실습 전 스냅샷을 남겨 언제든 복구할 수 있게 한다.
