## 이번 편의 목표

- 가상 머신을 사용하는 이유를 이해한다.
- Rocky Linux 8.8 설치 전 확인 사항과 설치 흐름을 익힌다.
- 설치가 끝난 뒤 운영체제, 계정, 네트워크 상태를 검증한다.

## 왜 가상 머신에 설치할까?

가상 머신은 현재 Windows나 macOS 안에 별도의 컴퓨터를 소프트웨어로 만드는 방식이다. 실습 중 설정을 잘못해도 주 컴퓨터를 재설치하지 않고 가상 머신만 복구할 수 있다.

시험 준비에서 중요한 것은 화려한 서버가 아니라 **실패해도 다시 시도할 수 있는 환경**이다. 이 문서에서는 VirtualBox와 Rocky Linux 8.8을 예로 들지만, 공식 시험 환경은 접수 전에 다시 확인해야 한다.

<Callout type="warning">
ISO 이미지는 Rocky Linux 공식 배포 경로에서 받고 체크섬을 확인한다. 출처를 알 수 없는 이미지는 변조나 악성 코드 위험이 있으므로 사용하지 않는다.
</Callout>

## 설치 전 체크리스트

- CPU의 가상화 기능이 BIOS/UEFI에서 활성화되어 있는가?
- 가상 머신과 ISO를 저장할 디스크 공간이 충분한가?
- Rocky Linux 8.8 ISO 파일을 준비했는가?
- 기존 가상 머신과 겹치지 않는 이름을 정했는가?
- 실습 계정 `labadmin`의 암호를 안전하게 기록했는가?

메모리와 CPU 수는 PC 사양을 고려해 정한다. 처음에는 가상 머신이 부팅되고 터미널 실습이 가능한 최소한의 자원으로 시작하고, 지나치게 느릴 때만 늘린다.

## 가상 머신 만들기

<Steps>
### 새 Linux 가상 머신을 만든다

이름은 `web01-rocky88`, 운영체제 종류는 64비트 Linux 계열로 지정한다. 가상 디스크는 동적 할당을 사용하면 실제 사용량에 따라 파일이 커진다.

### ISO를 가상 광학 드라이브에 연결한다

부팅 순서에서 ISO가 연결된 광학 드라이브가 먼저 읽히는지 확인한다. 설치 화면이 나타나지 않으면 ISO 경로와 부팅 순서를 먼저 점검한다.

### 설치 대상과 네트워크를 확인한다

언어, 시간대, 설치 디스크, 네트워크를 차례로 확인한다. 실습 초반에는 자동 파티션 구성을 사용하고 수동 파티션은 파일 시스템 편에서 따로 연습한다.

### 사용자 계정을 만든다

일반 사용자 `labadmin`을 만들고 관리자 작업이 필요할 때 `sudo`를 사용한다. 모든 실습을 `root`로 진행하면 일반 사용자 권한 문제를 익히기 어렵다.

### 설치를 완료하고 ISO를 분리한다

재부팅할 때 다시 설치 화면으로 돌아오면 가상 광학 드라이브에서 ISO를 분리하거나 부팅 순서를 확인한다.
</Steps>

## 설치 직후 검증

로그인한 뒤 다음 명령을 실행한다.

```bash
cat /etc/rocky-release
uname -r
whoami
hostnamectl --static
ip -br addr
df -h /
```

확인할 내용은 다음과 같다.

| 명령 | 정상 판단의 기준 |
| --- | --- |
| `cat /etc/rocky-release` | 설치한 Rocky Linux 릴리스가 표시된다. |
| `whoami` | `labadmin`이 표시된다. |
| `ip -br addr` | 사용할 인터페이스가 `UP`이고 주소가 있다. |
| `df -h /` | 루트 파일 시스템의 용량과 여유 공간을 읽을 수 있다. |

호스트 이름은 앞으로 사용할 `web01`로 정한다.

```bash
sudo hostnamectl set-hostname web01
hostnamectl --static
```

두 번째 명령에서 `web01`이 나오면 변경과 검증이 완료된 것이다.

## 패키지 저장소 확인

네트워크가 연결됐다면 저장소 목록을 확인한다.

```bash
sudo dnf repolist
```

오류가 난다면 무작정 재설치하지 말고 다음 순서로 확인한다.

1. `ip -br addr`에서 주소가 있는가?
2. `ip route`에 기본 경로가 있는가?
3. `ping -c 2 1.1.1.1`로 외부 IP에 도달하는가?
4. `getent hosts rockylinux.org`로 이름 해석이 되는가?

IP 통신은 되지만 이름 해석만 실패하면 DNS 설정을 우선 의심할 수 있다.

## 첫 스냅샷 만들기

가상 머신을 종료한 뒤 `01-fresh-install` 스냅샷을 만든다. 스냅샷 설명에는 설치 버전, 계정, 네트워크 확인 여부를 적는다. 이후 실습이 망가졌을 때 이 지점으로 돌아갈 수 있다.

<Callout type="info">
스냅샷은 중요한 파일의 별도 백업을 완전히 대신하지 않는다. 실습 상태를 빠르게 되돌리는 도구로 사용한다.
</Callout>
