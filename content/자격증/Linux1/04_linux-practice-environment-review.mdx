## 복습 방법

먼저 선택지를 고르고 근거를 한 문장으로 말한 뒤 정답과 해설을 연다. 명령 문제는 실행 결과까지 예상한다.

<Callout type="warning">
관리자 권한이 필요한 실습은 별도 가상 머신에서 수행한다. 중요한 파일과 실제 운영 서버를 연습 대상으로 사용하지 않는다.
</Callout>

## 4지선다 문제

### 문제 1

NAT 모드에 대한 설명으로 가장 적절한 것은?

① VM이 보통 호스트를 거쳐 외부 네트워크에 접근한다.

② VM이 어떤 장치와도 통신하지 못한다.

③ VM이 반드시 실제 공유기의 관리자 권한을 가진다.

④ 파일 시스템을 자동 삭제한다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

NAT는 호스트의 네트워크 연결을 통해 VM이 외부로 나가는 데 흔히 사용된다.

- **①** 정답이다.
- **②** 완전 격리 설명에 가깝다.
- **③** 관리자 권한을 주는 기능이 아니다.
- **④** 저장장치 기능이 아니다.

</Collapse>

### 문제 2

sudo를 사용하는 이유로 가장 적절한 것은?

① 모든 사용자의 비밀번호를 표시하기 위해

② 허가된 사용자가 필요한 명령만 관리자 권한으로 실행하기 위해

③ 네트워크 케이블을 연결하기 위해

④ 터미널 글꼴을 바꾸기 위해

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

sudo는 일반 사용자가 권한이 필요한 특정 작업을 통제된 방식으로 수행하게 한다.

- **①** 보안상 허용되지 않는 기능이다.
- **②** 정답이다.
- **③** 물리 연결과 무관하다.
- **④** 화면 설정 도구가 아니다.

</Collapse>

### 문제 3

실습에서 한 번에 설정 하나만 바꾸는 이유는?

① 작업 시간을 무조건 늘리기 위해

② 어떤 변경이 결과에 영향을 줬는지 구분하기 위해

③ 로그를 없애기 위해

④ 관리자 권한을 얻기 위해

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

여러 조건을 동시에 바꾸면 성공과 실패의 원인을 판단하기 어렵다.

- **①** 목적이 아니다.
- **②** 정답이다.
- **③** 오히려 기록을 남겨야 한다.
- **④** 권한과 별개다.

</Collapse>

### 문제 4

오류가 발생했을 때 가장 먼저 할 행동은?

① 오류 문장을 정확히 읽고 실행한 명령과 현재 상태를 기록한다.

② 같은 명령을 무한 반복한다.

③ 모든 로그를 삭제한다.

④ VM과 호스트를 동시에 초기화한다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

오류 메시지와 재현 조건은 원인을 좁히는 가장 중요한 자료다.

- **①** 정답이다.
- **②** 조건이 같으면 같은 실패를 반복할 가능성이 크다.
- **③** 진단 근거를 없앤다.
- **④** 원인에 비해 과도한 조치다.

</Collapse>

### 문제 5

스냅샷 이름으로 가장 유용한 것은?

① 새 폴더

② 아무거나

③ 03-network-before-firewall-change

④ 비밀번호 원문

<Collapse title="정답 보기">

**정답: ③**

</Collapse>

<Collapse title="해설 보기">

단계와 상태를 알 수 있는 이름은 어떤 시점으로 복구할지 판단하기 쉽다.

- **①** 어떤 상태인지 알기 어렵다.
- **②** 복구 기준을 알 수 없다.
- **③** 정답이다.
- **④** 민감정보를 이름에 넣으면 안 된다.

</Collapse>

## 직접 적용하기

VM에서 현재 사용자, 작업 디렉터리, IP 주소를 확인하고 결과를 한 표에 기록하자. 그다음 연습용 디렉터리를 만든 뒤 생성 여부를 검증하는 명령까지 적어 보자.

<Collapse title="풀이 및 검증 보기">

whoami로 사용자, pwd로 현재 위치, ip addr로 주소를 확인한다. mkdir -p ~/lab/check로 연습 디렉터리를 만들고 ls -ld ~/lab/check로 존재와 권한을 검증할 수 있다. 명령 전후 출력과 오류가 있었다면 오류 문장도 함께 기록한다.

</Collapse>

## 결과 점검

- 5개 정답: 명령의 목적과 확인 방법을 함께 말해 본다.
- 3~4개 정답: 틀린 문제의 용어를 본편에서 찾아 다시 설명한다.
- 0~2개 정답: 본편의 용어표와 작업 흐름부터 다시 학습한다.
