## 리눅스마스터 1급은 무엇을 확인할까?

리눅스마스터 1급은 명령어를 많이 외웠는지보다, 리눅스 시스템을 이해하고 운영 문제를 해결할 수 있는지를 다룬다. 운영체제 구조, 사용자와 권한, 프로세스, 파일시스템, 네트워크, 서비스, 보안이 서로 연결되어 나온다.

예를 들어 “웹 서버가 열리지 않는다”는 문제는 명령어 하나의 문제가 아니다. 프로세스가 실행 중인지, 포트가 열려 있는지, 방화벽 규칙은 맞는지, 로그에는 무엇이 기록됐는지를 순서대로 확인해야 한다.

<Callout type="important">
처음에는 명령어 목록을 통째로 외우지 말자. 각 명령어가 시스템의 어느 부분을 확인하거나 바꾸는지 연결해서 익히는 것이 1급 학습의 핵심이다.
</Callout>

## 시스템 관리자는 어떤 질문을 하는가?

| 관리 영역 | 먼저 던질 질문 | 대표 예시 |
| --- | --- | --- |
| 파일과 권한 | 누가 어떤 파일을 읽고 수정할 수 있는가? | `ls -l`, `chmod`, `chown` |
| 프로세스와 서비스 | 프로그램은 실행 중이며 정상 동작하는가? | `ps`, `systemctl`, `journalctl` |
| 저장장치 | 디스크와 파일시스템에 문제가 없는가? | `df`, `mount`, `fstab` |
| 네트워크 | 서버에 연결할 수 있고 이름이 해석되는가? | `ip`, `ss`, `ping`, `dig` |
| 보안 | 불필요한 접근이 허용되어 있지 않은가? | SSH, 방화벽, SELinux |

이 표를 지도로 삼으면 낯선 명령어를 만나도 “파일 관련인가, 네트워크 관련인가?”부터 분류할 수 있다.

## 첫 실습: 내 시스템의 기본 정보 읽기

리눅스 환경에서 다음 명령어를 한 줄씩 실행해 보자. 가상머신, WSL, 실습 서버 중 무엇을 사용해도 된다.

```bash
whoami
pwd
uname -r
ls -la
```

| 명령어 | 확인하는 것 |
| --- | --- |
| `whoami` | 현재 로그인한 사용자 |
| `pwd` | 현재 작업 중인 디렉터리 |
| `uname -r` | 실행 중인 커널 버전 |
| `ls -la` | 숨김 파일을 포함한 현재 디렉터리 목록과 권한 |

출력 결과를 외우지 말고, “현재 사용자”, “현재 위치”, “운영체제 핵심 버전”, “파일 목록”을 확인한다는 의미를 말로 설명해 보자.

## 시험 공부와 실습을 같이 하는 방법

<Steps>
### 큰 구조를 먼저 잡는다

운영체제, 파일시스템, 셸, 프로세스, 네트워크, 보안의 역할을 짧게 정리한다.

### 명령어를 문제와 연결한다

`df`는 디스크 여유 공간을, `ps`는 실행 중인 프로세스를 확인한다. 옵션보다 먼저 목적을 기억한다.

### 안전한 실습 환경을 만든다

Rocky Linux 가상머신이나 WSL처럼 실패해도 다시 만들 수 있는 환경에서 명령어를 실행한다.

### 로그를 보는 습관을 들인다

오류가 나면 추측하기 전에 `journalctl`이나 서비스 로그를 먼저 확인한다.
</Steps>

## 흔한 실수

- `sudo`를 만능 해결책처럼 사용하기: 왜 권한이 필요한지 모르면 위험한 명령을 실행할 수 있다.
- 명령어 옵션을 암기만 하기: 실제 출력과 함께 확인해야 오래 남는다.
- 리눅스를 화면 없는 운영체제로만 생각하기: 서버 관리와 자동화에 강점이 있지만 사용 목적은 다양하다.

## 이번 편 정리

- 리눅스마스터 1급은 시스템, 네트워크, 서비스, 보안을 연결해 관리하는 역량을 다룬다.
- 명령어는 이름보다 “무슨 상태를 확인하거나 바꾸는가”로 익힌다.
- 다음 편에서 1차·2차 구조와 공부 순서를 확인한다.
