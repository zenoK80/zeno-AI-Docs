## 이번 편의 목표

- 리눅스마스터 1급이 단순한 명령어 암기 시험이 아닌 이유를 설명한다.
- 시스템 관리자의 기본 문제 해결 순서를 익힌다.
- 앞으로 공부할 영역과 실습 방법을 한눈에 정리한다.

## 먼저 상황부터 생각해 보기

회사 웹 서버 `web01`에 접속이 안 된다는 연락을 받았다고 하자. 이때 곧바로 서버를 재부팅하면 원인이 사라져 진단이 더 어려워질 수 있다. 먼저 다음 질문을 순서대로 확인해야 한다.

1. 서버 자체가 켜져 있는가?
2. 네트워크 주소가 정상인가?
3. 웹 서비스 프로세스가 실행 중인가?
4. 서비스가 사용할 포트가 열려 있는가?
5. 방화벽이나 권한이 접속을 막고 있지는 않은가?
6. 로그에는 어떤 오류가 남았는가?

리눅스마스터 1급은 이런 질문에 답하기 위해 필요한 운영체제, 파일, 프로세스, 네트워크, 서비스, 보안 지식을 평가한다.

<Callout type="important">
명령어를 외울 때는 반드시 **무엇을 확인하는 명령인지**, **출력에서 무엇을 읽어야 하는지**, **변경 후 어떻게 검증할지**를 함께 익힌다.
</Callout>

## 시스템 관리의 네 단계

| 단계 | 핵심 질문 | 예시 |
| --- | --- | --- |
| 상태 확인 | 지금 무엇이 정상이고 무엇이 다른가? | `ip -br addr`, `systemctl --failed` |
| 원인 가설 | 어느 계층에서 문제가 생겼는가? | 주소, 프로세스, 포트, 권한, 설정 |
| 최소 변경 | 문제와 직접 관련된 것만 바꿨는가? | 설정 한 줄 수정, 서비스 재시작 |
| 결과 검증 | 문제가 해결됐고 부작용은 없는가? | 상태, 로그, 실제 접속 재확인 |

이 시리즈에서는 연습용 관리자 계정을 `labadmin`, 서버 이름을 `web01`로 통일한다. 같은 상황을 반복해서 사용하면 명령어가 서로 어떻게 연결되는지 보기 쉽다.

## 출제 영역을 한 장으로 연결하기

| 영역 | 배우는 내용 | 대표 확인 도구 |
| --- | --- | --- |
| 운영체제 | 커널, 프로세스, 메모리, 부팅 | `uname`, `ps`, `free`, `systemctl` |
| 파일과 권한 | 디렉터리 구조, 소유권, 접근 권한 | `ls`, `find`, `chmod`, `chown` |
| 저장장치 | 파티션, 파일 시스템, 마운트 | `lsblk`, `df`, `mount` |
| 네트워크 | 주소, 경로, 포트, 이름 해석 | `ip`, `ss`, `ping`, `dig` |
| 서비스 | 웹, DNS, 파일 공유, 메일 | `systemctl`, `journalctl` |
| 보안 | 계정, 방화벽, SELinux, 로그 | `firewall-cmd`, `getenforce` |

각 영역은 따로 떨어져 있지 않다. 예를 들어 웹 서비스 장애는 프로세스, 포트, 방화벽, 파일 권한, SELinux를 모두 살펴야 할 수 있다.

## 첫 번째 상태 점검

Rocky Linux 실습 환경에서 다음 명령을 한 줄씩 실행한다.

```bash
whoami
hostnamectl --static
pwd
uname -r
ip -br addr
systemctl --failed
```

출력값을 그대로 암기할 필요는 없다. 다음처럼 의미를 설명할 수 있으면 된다.

- `whoami`: 현재 명령을 실행하는 사용자
- `hostnamectl --static`: 현재 호스트 이름
- `pwd`: 작업 중인 디렉터리
- `uname -r`: 실행 중인 커널 버전
- `ip -br addr`: 인터페이스별 연결 상태와 IP 주소
- `systemctl --failed`: 시작에 실패한 systemd 서비스

예를 들어 `ip -br addr`에서 인터페이스가 `DOWN`이라면 웹 서비스보다 네트워크 연결을 먼저 확인해야 한다. `systemctl --failed`가 비어 있으면 적어도 systemd가 실패 상태로 기록한 서비스는 없다는 뜻이다.

## 공부할 때 남길 기록

명령어 실습은 아래 네 줄 형식으로 기록한다.

```text
목적: web01의 네트워크 상태를 확인한다.
명령: ip -br addr
관찰: enp0s3가 UP이고 192.168.56.10/24를 사용한다.
판단: 인터페이스와 주소는 정상이며 다음으로 포트를 확인한다.
```

이 기록 방식은 작업형 문제에서도 유용하다. 무엇을 바꿨는지 잊지 않고, 잘못됐을 때 한 단계씩 되돌릴 수 있기 때문이다.

리눅스마스터 1급의 중심은 시스템의 현재 상태를 읽고, 원인을 좁혀 최소한으로 변경한 뒤 결과를 검증하는 능력이다. 다음 편에서는 1차와 2차 시험의 구성과 합격 기준을 바탕으로 학습 시간을 배분한다.
