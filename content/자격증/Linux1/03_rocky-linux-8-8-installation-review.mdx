## 복습 방법

먼저 선택지를 고르고 근거를 한 문장으로 말한 뒤 정답과 해설을 연다. 명령 문제는 실행 결과까지 예상한다.

<Callout type="warning">
관리자 권한이 필요한 실습은 별도 가상 머신에서 수행한다. 중요한 파일과 실제 운영 서버를 연습 대상으로 사용하지 않는다.
</Callout>

## 직접 적용하기

설치가 끝난 VM에서 배포판 버전, 커널, IP 주소, 저장소 목록을 확인하는 검증표를 작성해 보자.

<Collapse title="풀이 및 검증 보기">

배포판은 cat /etc/os-release, 커널은 uname -r, 주소는 ip addr, 활성 저장소는 dnf repolist 등으로 확인할 수 있다. 각 출력에서 실제 값을 기록하고 네 항목이 정상일 때 ‘base-install’ 같은 이름으로 스냅샷을 만든다.

</Collapse>

## 결과 점검

- 5개 정답: 명령의 목적과 확인 방법을 함께 말해 본다.
- 3~4개 정답: 틀린 문제의 용어를 본편에서 찾아 다시 설명한다.
- 0~2개 정답: 본편의 용어표와 작업 흐름부터 다시 학습한다.
