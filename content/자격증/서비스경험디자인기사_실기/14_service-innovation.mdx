</Callout>

## 비즈니스 모델 캔버스(BMC) 9개 블록

| 블록 | 설명 |
|------|------|
| 고객 세그먼트 | 타깃 고객 그룹 |
| 가치 제안 | 고객에게 제공하는 가치 |
| 채널 | 가치를 전달하는 방법 |
| 고객 관계 | 고객과의 관계 유형 |
| 수익 구조 | 어떻게 수익을 창출하는가 |
| 핵심 자원 | 필요한 주요 자산 |
| 핵심 활동 | 가치를 만들기 위한 핵심 활동 |
| 핵심 파트너십 | 외부 파트너와 공급자 |
| 비용 구조 | 주요 비용 요소 |

## 가치 제안 캔버스(VPC)

고객 프로파일과 가치 맵의 적합성(Fit)을 찾는 도구

| 고객 프로파일 | 가치 맵 |
|------------|---------|
| 고객 과업(Jobs) | 제품·서비스 |
| 고통(Pains) | 고통 해소제(Pain Relievers) |
| 이득(Gains) | 이득 창출제(Gain Creators) |

---

## 서비스 혁신 유형

| 유형 | 설명 |
|------|------|
| 점진적 혁신 | 기존 서비스의 개선 |
| 급진적 혁신 | 새로운 서비스 모델 창출 |
| 와해적 혁신 | 기존 시장을 뒤바꾸는 혁신 |
| 비즈니스 모델 혁신 | 수익 창출 방식 변화 |
