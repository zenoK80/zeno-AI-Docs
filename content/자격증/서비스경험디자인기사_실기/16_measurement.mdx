## SERVQUAL 5가지 차원

Parasuraman이 개발한 서비스 품질 측정 모델

| 차원 | 설명 |
|------|------|
| 유형성(Tangibles) | 물리적 시설, 장비, 직원 외모 |
| 신뢰성(Reliability) | 약속한 서비스를 정확하게 제공 |
| 반응성(Responsiveness) | 빠른 서비스 제공 의지 |
| 확신성(Assurance) | 직원의 지식과 신뢰감 |
| 공감성(Empathy) | 고객 개인에 대한 관심 |

---

## UX 핵심 지표(HEART 프레임워크)

Google이 제안한 UX 측정 프레임워크

| 지표 | 설명 |
|------|------|
| H(Happiness) | 사용자 만족도 (설문, 평점) |
| E(Engagement) | 사용 빈도와 깊이 |
| A(Adoption) | 신규 기능이나 서비스 채택률 |
| R(Retention) | 재방문율, 리텐션율 |
| T(Task Success) | 태스크 완료율, 완료 시간 |

---

## 깔때기 분석(Funnel Analysis)

사용자가 전환하는 단계별 이탈률 분석

```
방문 → 회원가입 → 첫 구매 → 재구매
100%    40%       15%       8%
```
