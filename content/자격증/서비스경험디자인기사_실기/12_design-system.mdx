<Callout type="info">
  디자인 시스템은 일관된 사용자 경험을 제공하기 위한 재사용 가능한 컴포넌트와 가이드라인의 집합입니다.
</Callout>

## 디자인 시스템의 구성 요소

| 구성 요소 | 설명 | 예시 |
|----------|------|------|
| 디자인 토큰 | 색상, 크기, 간격 등의 값 | Primary Color: #0066FF |
| 기초 요소 | 버튼, 아이콘, 타이포그래피 | Heading1, Body2 |
| 컴포넌트 | 재사용 가능한 UI 조각 | Card, Modal, NavBar |
| 패턴 | 반복되는 UX 솔루션 | 로그인 폼, 검색 패턴 |
| 가이드라인 | 사용 원칙과 규칙 문서 | 접근성 지침, 어조 가이드 |

---

## Atomic Design

Brad Frost의 UI 설계 방법론

| 레벨 | 설명 | 예시 |
|------|------|------|
| 원자(Atoms) | 가장 작은 기본 요소 | 버튼, 입력 필드, 아이콘 |
| 분자(Molecules) | 원자들의 조합 | 검색 바(입력+버튼) |
| 유기체(Organisms) | 분자들의 조합 | 헤더(로고+내비+검색) |
| 템플릿(Templates) | 유기체로 구성된 레이아웃 | 페이지 구조 |
| 페이지(Pages) | 실제 콘텐츠가 담긴 화면 | 완성된 화면 |

## 디자인 토큰(Design Token)

디자인 결정사항을 이름이 있는 변수로 저장

```
--color-primary: #0066FF
--spacing-md: 16px
--font-size-body: 16px
```
