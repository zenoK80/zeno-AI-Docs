<Callout type="info">
  프로토타이핑은 아이디어를 빠르게 구체화하여 테스트하는 과정입니다. 충실도(Fidelity)에 따른 분류와 적용 시기를 학습합니다.
</Callout>

## 프로토타입 충실도(Fidelity)

| 유형 | 설명 | 적용 시기 |
|------|------|----------|
| 저충실도(Lo-fi) | 종이, 스케치 수준 | 초기 개념 검증 |
| 중충실도(Mid-fi) | 와이어프레임 | 구조와 흐름 검증 |
| 고충실도(Hi-fi) | 실제에 가까운 인터랙션 | 최종 사용성 검증 |

---

## 프로토타이핑 방법

| 방법 | 설명 | 장점 |
|------|------|------|
| 페이퍼 프로토타입 | 종이에 화면 스케치 | 빠르고 저비용 |
| 와이어프레임 | 구조와 레이아웃 설계 | 콘텐츠 배치 검증 |
| 목업(Mockup) | 디자인 외관 시각화 | 비주얼 검증 |
| 인터랙티브 프로토타입 | 클릭 가능한 프로토타입 | 흐름과 인터랙션 검증 |
| 서비스 원형(Service Prototype) | 실제 맥락에서 서비스 체험 | 전체 경험 검증 |

---

## 서비스 프로토타이핑

디지털 인터페이스를 넘어 공간, 사람, 프로세스를 포함한 전체 서비스 경험을 시뮬레이션

| 방법 | 설명 |
|------|------|
| 역할극(Role Play) | 서비스 시나리오를 직접 연기 |
| 경험 시뮬레이션 | 실제 환경에서 서비스 경험 |
| 스토리보드 | 시나리오를 이미지로 시각화 |
