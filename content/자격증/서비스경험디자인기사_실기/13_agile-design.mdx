</Callout>

## 애자일 UX 설계 방식

| 방법 | 설명 |
|------|------|
| 스프린트 0 | 개발 전 리서치와 기초 설계 |
| 린 UX | 가정을 빠르게 검증하는 경량 접근법 |
| 디자인 스프린트 | 5일간 집중적으로 문제 해결 |
| 이중 트랙(Dual Track) | 발견 트랙과 전달 트랙 병행 |

---

## GV 디자인 스프린트 5단계

| 일차 | 단계 | 활동 |
|------|------|------|
| 월요일 | 지도 그리기(Map) | 문제 정의, HMW |
| 화요일 | 스케치(Sketch) | 솔루션 스케치 |
| 수요일 | 결정(Decide) | 최선의 아이디어 선택 |
| 목요일 | 프로토타입(Prototype) | 고충실도 프로토타입 |
| 금요일 | 테스트(Test) | 5명의 사용자 테스트 |

---

## 린 UX(Lean UX)의 핵심 사이클

**가정 설정 → 검증 실험 설계 → 최소 기능 제품(MVP) 제작 → 측정 → 학습 → 반복**
