<Callout type="info">
  접근성은 장애가 있는 사람을 포함한 모든 사람이 서비스를 이용할 수 있도록 설계하는 것입니다. WCAG 원칙과 포용적 디자인을 학습합니다.
</Callout>

## WCAG 4가지 원칙(POUR)

| 원칙 | 설명 |
|------|------|
| P - 인식 가능(Perceivable) | 모든 콘텐츠를 감지할 수 있어야 함 |
| O - 조작 가능(Operable) | 인터페이스를 다양한 방법으로 조작 가능 |
| U - 이해 가능(Understandable) | 콘텐츠와 UI가 이해할 수 있어야 함 |
| R - 견고성(Robust) | 다양한 보조기술과 호환 가능 |

---

## 접근성 설계 가이드라인

| 항목 | 설명 |
|------|------|
| 대체 텍스트 | 이미지에 alt 속성으로 설명 제공 |
| 색상 대비 | 텍스트와 배경 대비 4.5:1 이상 |
| 키보드 접근성 | 마우스 없이 키보드로 모든 기능 이용 |
| 포커스 표시 | 현재 선택된 요소가 시각적으로 표시 |
| 자막 제공 | 동영상에 자막(Caption) 제공 |
| 충분한 클릭 영역 | 최소 44×44px 이상 터치 타깃 |

---

## 포용적 디자인 vs 접근성

| 구분 | 접근성 | 포용적 디자인 |
|------|--------|------------|
| 초점 | 장애인을 위한 설계 | 모든 다양성을 포용하는 설계 |
| 범위 | 법적 기준 충족 | 더 넓은 포용성 추구 |
| 접근 | 사후 보완 가능 | 처음부터 포용성 고려 |
