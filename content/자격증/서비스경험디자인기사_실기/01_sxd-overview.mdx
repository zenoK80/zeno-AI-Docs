<Callout type="info">
  서비스경험디자인기사 실기 시험은 서비스 디자인, UX 리서치, 프로토타이핑 등 실무 역량을 평가합니다.
</Callout>

## 시험 개요

| 항목 | 내용 |
|------|------|
| 시험 유형 | 작업형 실기 |
| 시험 시간 | 4시간 |
| 합격 기준 | 100점 만점 60점 이상 |
| 주관 기관 | 한국산업인력공단 |

---

## 실기 출제 범위

| 과목 | 주요 내용 |
|------|----------|
| 사용자 리서치 | 인터뷰, 관찰, 설문, 데스크 리서치 |
| 서비스 디자인 도구 | 고객 여정 지도, 서비스 청사진, 페르소나 |
| 아이디에이션 | 브레인스토밍, HMW, SCAMPER |
| 프로토타이핑 | 페이퍼 프로토타입, 와이어프레임, 목업 |
| 사용성 평가 | 사용성 테스트, 휴리스틱 평가 |

---

## 합격 전략

1. 디자인 도구별 정의와 구성 요소를 정확히 암기
2. 리서치 방법론의 차이점을 비교하여 서술 연습
3. 실제 서비스 사례를 통한 도구 적용 방법 이해
4. 용어는 한국어와 영어를 함께 학습
