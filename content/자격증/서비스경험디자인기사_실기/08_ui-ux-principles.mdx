<Callout type="info">
  UI 디자인 원칙은 시각적으로 명확하고 사용자가 직관적으로 이해할 수 있는 인터페이스를 만드는 기반입니다.
</Callout>

## Gestalt 원칙 (시지각 원리)

| 원칙 | 설명 | 예시 |
|------|------|------|
| 근접성(Proximity) | 가까운 요소를 하나로 인식 | 관련 버튼을 묶어 배치 |
| 유사성(Similarity) | 비슷하게 생긴 요소를 그룹으로 인식 | 동일한 아이콘 색상 |
| 연속성(Continuity) | 연속적으로 이어진 선을 인식 | 캐러셀 슬라이더 |
| 폐쇄성(Closure) | 불완전한 형태를 완전하게 인식 | 로고 디자인 |
| 대칭성(Symmetry) | 대칭적인 요소를 하나로 인식 | 균형 잡힌 레이아웃 |
| 전경-배경(Figure-Ground) | 대상과 배경을 구분 | 팝업 다이얼로그 |

---

## UI 설계 원칙

| 원칙 | 설명 |
|------|------|
| 일관성(Consistency) | 동일한 요소는 동일하게 표현 |
| 피드백(Feedback) | 사용자 행동에 즉각적인 반응 |
| 제약(Constraint) | 잘못된 사용을 방지하는 제한 |
| 가시성(Visibility) | 사용 가능한 기능을 명확히 표시 |
| 어포던스(Affordance) | 요소가 사용 방법을 암시 |
| 매핑(Mapping) | 제어와 결과의 관계가 직관적 |
