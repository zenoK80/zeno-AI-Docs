</Callout>

## 인터랙션 디자인의 5가지 차원

| 차원 | 설명 |
|------|------|
| 1D: 단어(Words) | 텍스트, 레이블, 마이크로카피 |
| 2D: 시각적 표현(Visual) | 이미지, 아이콘, 타이포그래피 |
| 3D: 물리적 객체(Objects) | 기기, 하드웨어, 터치 인터페이스 |
| 4D: 시간(Time) | 애니메이션, 사운드, 비디오 |
| 5D: 행동(Behavior) | 사용자 행동에 대한 시스템 반응 |

---

## 마이크로인터랙션(Microinteraction)

사용자가 단일 태스크를 완료할 때 발생하는 작고 세밀한 상호작용

### 마이크로인터랙션의 4가지 요소

| 요소 | 설명 |
|------|------|
| 트리거(Trigger) | 인터랙션을 시작하는 신호 (클릭, 스크롤 등) |
| 규칙(Rules) | 인터랙션이 어떻게 동작하는지 정의 |
| 피드백(Feedback) | 사용자에게 무슨 일이 일어나는지 알림 |
| 루프와 모드(Loops & Modes) | 반복 실행 여부와 상태 변경 |

---

## UX 라이팅(UX Writing)

| 원칙 | 설명 |
|------|------|
| 명확성 | 쉽고 간결한 언어 사용 |
| 일관성 | 동일 개념에 동일 용어 사용 |
| 유용성 | 사용자가 다음에 할 일을 안내 |
| 인간적 | 친근하고 자연스러운 어조 |
