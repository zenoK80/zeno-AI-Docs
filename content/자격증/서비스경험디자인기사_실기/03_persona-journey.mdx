## 페르소나(Persona)

### 정의
리서치를 기반으로 목표 사용자 그룹을 대표하는 가상의 인물 프로필

### 페르소나 구성 요소

| 요소 | 내용 |
|------|------|
| 이름, 사진 | 구체적인 인물감 부여 |
| 인구통계 | 나이, 직업, 거주지 등 |
| 목표(Goals) | 달성하고 싶은 것 |
| 불편함(Pain Points) | 현재 겪는 어려움 |
| 행동 패턴 | 기술 사용 습관 등 |
| 인용문 | 대표 발언 |

### 페르소나 vs 아바타

| 구분 | 페르소나 | 마케팅 아바타 |
|------|---------|------------|
| 기반 | 실제 리서치 데이터 | 가정과 추측 |
| 목적 | 디자인 의사결정 | 마케팅 타깃 |

---

## 고객 여정 지도(Customer Journey Map)

### 정의
특정 페르소나가 서비스를 이용하는 전 과정을 시각화한 도구

### 구성 요소

| 구성 요소 | 설명 |
|----------|------|
| 여정 단계(Phases) | 인식-탐색-이용-이후 등 |
| 행동(Actions) | 각 단계에서 하는 행동 |
| 생각(Thoughts) | 각 단계에서의 생각 |
| 감정(Emotions) | 감정 곡선 |
| 터치포인트 | 서비스 접점 |
| 기회(Opportunities) | 개선 가능한 포인트 |
