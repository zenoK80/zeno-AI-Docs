<Callout type="info">
  정보 아키텍처(IA)는 사용자가 정보를 쉽게 찾을 수 있도록 구조화하는 것입니다. 내비게이션 패턴과 분류 방법을 학습합니다.
</Callout>

## 정보 아키텍처(IA)의 4가지 구성 요소

| 구성 요소 | 설명 |
|----------|------|
| 조직 체계(Organization System) | 정보를 분류하고 구조화하는 방법 |
| 레이블링 체계(Labeling System) | 카테고리와 항목의 이름 짓기 |
| 내비게이션 체계(Navigation System) | 사용자가 정보를 탐색하는 방법 |
| 검색 체계(Search System) | 정보를 검색하는 방법 |

---

## 내비게이션 패턴

| 패턴 | 설명 | 적합한 경우 |
|------|------|-----------|
| 글로벌 내비게이션 | 모든 페이지에 공통 메뉴 | 사이트 전체 접근 |
| 로컬 내비게이션 | 특정 섹션의 하위 메뉴 | 섹션 내 탐색 |
| 탭 내비게이션 | 동일 레벨 항목을 탭으로 | 모바일 주요 메뉴 |
| 브레드크럼(Breadcrumb) | 현재 위치 경로 표시 | 깊은 계층 구조 |
| 햄버거 메뉴 | 숨겨진 사이드 내비게이션 | 모바일 전체 메뉴 |

---

## 콘텐츠 조직 방법 (LATCH)

| 약자 | 방법 | 예시 |
|------|------|------|
| L(Location) | 위치 기반 | 지역별 서비스 |
| A(Alphabet) | 알파벳순 | 사전, 인명록 |
| T(Time) | 시간 순서 | 뉴스, 이벤트 |
| C(Category) | 주제별 분류 | 전자상거래 카테고리 |
| H(Hierarchy) | 중요도 순서 | 검색 결과 |
