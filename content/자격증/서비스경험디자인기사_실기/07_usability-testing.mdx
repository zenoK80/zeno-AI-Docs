<Callout type="info">
  사용성 평가는 설계된 서비스/인터페이스가 사용자에게 얼마나 효과적인지 측정합니다. 평가 방법과 Nielsen의 휴리스틱 원칙을 숙지하세요.
</Callout>

## 사용성(Usability)의 5가지 요소 (Nielsen)

| 요소 | 설명 |
|------|------|
| 학습 용이성(Learnability) | 처음 사용자가 쉽게 배울 수 있는가 |
| 효율성(Efficiency) | 숙련 후 얼마나 빠르게 수행하는가 |
| 기억 용이성(Memorability) | 재방문 시 얼마나 쉽게 기억하는가 |
| 오류(Errors) | 오류 발생 빈도와 심각도 |
| 만족도(Satisfaction) | 사용이 얼마나 즐거운가 |

---

## Nielsen의 10가지 사용성 휴리스틱

| 번호 | 원칙 | 설명 |
|------|------|------|
| 1 | 시스템 상태 가시성 | 사용자에게 현재 상태를 알려줄 것 |
| 2 | 실세계와의 일치 | 사용자의 언어와 개념 사용 |
| 3 | 사용자 통제와 자유 | 실수 취소 가능한 출구 제공 |
| 4 | 일관성과 표준 | 동일 개념에 동일한 단어 사용 |
| 5 | 오류 방지 | 오류가 발생하지 않도록 설계 |
| 6 | 인식 vs 기억 | 선택지를 보여주어 기억 부담 감소 |
| 7 | 유연성과 효율성 | 초보와 숙련자 모두 지원 |
| 8 | 미적이고 최소한의 디자인 | 불필요한 정보 제거 |
| 9 | 오류 인식·진단·복구 지원 | 명확한 오류 메시지 제공 |
| 10 | 도움말과 문서화 | 도움이 필요할 때 쉽게 찾을 수 있게 |
