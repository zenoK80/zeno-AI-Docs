## 디지털 전환(Digital Transformation, DX)

고객 경험, 운영 프로세스, 비즈니스 모델을 디지털 기술을 활용하여 근본적으로 변화시키는 것

### DX의 4가지 영역

| 영역 | 설명 |
|------|------|
| 고객 경험(Customer Experience) | 디지털 채널을 통한 고객 경험 개선 |
| 운영 프로세스 | 자동화와 데이터 기반 운영 |
| 비즈니스 모델 | 디지털 기반의 새로운 수익 모델 |
| 조직 문화 | 데이터 중심 의사결정 문화 |

---

## 채널 전략

| 채널 전략 | 설명 |
|----------|------|
| 싱글채널 | 하나의 채널만 운영 |
| 멀티채널 | 여러 채널을 독립적으로 운영 |
| 크로스채널 | 채널 간 연결 있으나 완전 통합 아님 |
| 옴니채널 | 모든 채널이 통합된 일관된 경험 |

---

## CX 측정 지표

| 지표 | 설명 |
|------|------|
| NPS(Net Promoter Score) | 추천 의향 점수 (0~10점) |
| CSAT(Customer Satisfaction) | 특정 인터랙션 만족도 |
| CES(Customer Effort Score) | 서비스 이용 노력 수준 |
| CLV(Customer Lifetime Value) | 고객 생애 가치 |
| 이탈률(Churn Rate) | 고객 이탈 비율 |
