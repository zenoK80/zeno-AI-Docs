## 개인정보란 무엇인가

**개인정보**는 살아 있는 개인을 식별할 수 있는 정보입니다. 직접 식별 가능한 정보뿐만 아니라, **다른 정보와 결합하여 식별 가능한 정보**도 포함됩니다.

| 구분 | 예시 |
|------|------|
| **직접 식별 정보** | 이름, 주민등록번호, 이메일 주소, 전화번호 |
| **간접 식별 정보** | 나이+주소+직업 결합, IP 주소, 쿠키 ID |
| **민감 정보** | 건강 정보, 정치적 의견, 종교, 성적 지향 |

<Callout type="warning">
  **핵심:** 단독으로는 식별이 어려운 정보라도, 다른 정보와 **결합하면** 개인정보가 될 수 있습니다.
</Callout>

## 비식별화 기법 5가지 비교

개인정보를 분석에 활용하기 위해서는 비식별화가 필요합니다. 5가지 기법을 비교하여 이해하세요.

| 기법 | 설명 | 예시 | 특징 |
|------|------|------|------|
| **가명처리** | 직접 식별자를 다른 값으로 대체 | 홍길동 → A001, 주민번호 → 임의 코드 | 결합키 유지되어 재결합 가능 |
| **데이터 마스킹** | 일부 정보를 숨기거나 치환 | 주민번호 뒷자리 → 1234567 → 123**** | 부분 식별 억제 |
| **데이터 집계** | 개인 단위 → 집계 통계로 대체 | 개인 소득 → 평균 소득 구간 | 개인 특정 불가 |
| **데이터 범주화** | 구체적 값 → 범위·구간으로 대체 | 나이 32세 → 30대 | 정밀도 감소 |
| **데이터 삭제** | 식별 가능 정보 완전 제거 | 이름·연락처 컬럼 삭제 | 가장 강력하나 활용성 감소 |

## 재식별 위험: 비식별화의 한계

비식별화를 했더라도 여러 정보를 **결합**하면 개인을 특정할 수 있습니다. 이를 **재식별(Re-identification)** 위험이라고 합니다.

대표적 연구: 미국 인구의 87%는 **우편번호 + 생년월일 + 성별** 세 가지 정보만으로 유일하게 식별 가능했습니다 (Sweeney, 2000).

이 때문에 비식별화 후에도 **결합 가능성 검토**와 **k-익명성** 같은 추가적 안전 장치가 필요합니다.

- **k-익명성(k-Anonymity):** 동일한 준식별자 조합을 가진 레코드가 k개 이상 존재하여 개인을 특정할 수 없는 상태

## 개인정보보호법 핵심 원칙

국내 개인정보보호법의 핵심 원칙 세 가지입니다.

| 원칙 | 내용 |
|------|------|
| **목적 제한** | 수집 목적 이외의 용도로 사용 불가 |
| **최소 수집** | 목적에 필요한 최소한의 정보만 수집 |
| **안전 보호** | 개인정보 유출·훼손 방지를 위한 안전 조치 |

## GDPR: EU 개인정보보호 규정

GDPR(General Data Protection Regulation)은 EU의 개인정보보호 규정으로, 2018년 시행 이후 전 세계 기준이 되었습니다.

| GDPR 핵심 원칙 | 내용 |
|---|---|
| **정보 주체 권리** | 열람권, 삭제권(잊혀질 권리), 이동권 |
| **정보 주체 동의** | 명확하고 자발적인 동의 필요 |
| **개인정보 영향 평가** | 고위험 처리 시 사전 영향 평가 의무 |
| **침해 통지** | 72시간 내 감독기관에 침해 사실 통지 |

## 분석 윤리: 알고리즘 편향

**알고리즘 편향(Algorithm Bias)** 이란 학습 데이터의 편향이 모델의 결과에 그대로 반영되는 현상입니다.

```
편향된 학습 데이터 → 편향된 모델 → 편향된 결과
```

**실제 사례:**
- 과거 채용 데이터로 훈련한 AI 채용 시스템이 특정 성별 지원자를 체계적으로 불이익 주도록 학습
- 범죄 예측 알고리즘이 특정 인종·지역을 과도하게 위험으로 분류

편향의 원인:
1. **데이터 편향:** 학습 데이터 자체가 불균형하거나 역사적 차별을 반영
2. **선택 편향:** 특정 집단의 데이터가 과소 수집
3. **확증 편향:** 분석가가 원하는 결론을 지지하는 데이터만 선택

## 분석 윤리: 공정성

**공정성(Fairness)** 은 모델이 **보호 속성(Protected Attribute)** 에 의해 특정 집단을 차별하지 않아야 한다는 원칙입니다.

보호 속성의 예: 성별, 인종, 나이, 국적, 장애 여부

| 공정성 유형 | 내용 |
|---|---|
| **개인 공정성** | 비슷한 사람은 비슷하게 처우 |
| **집단 공정성** | 집단 간 결과의 격차가 없거나 정당화됨 |
| **반사실적 공정성** | 보호 속성이 바뀌어도 결과가 달라지지 않음 |

## 분석 윤리: 설명 가능성(XAI)

**설명 가능한 AI(XAI, eXplainable AI)** 는 모델이 왜 그런 결정을 내렸는지 사람이 이해할 수 있도록 설명하는 것입니다.

신용 대출을 거절당한 사람은 "왜 거절되었는가"를 알 권리가 있습니다. 블랙박스 모델(예: 딥러닝)은 정확도는 높지만 설명이 어렵습니다.

| XAI 기법 | 설명 |
|---|---|
| **LIME** | 개별 예측을 국소적으로 근사하여 설명 |
| **SHAP** | 각 변수의 기여도를 수치로 계산 |
| **Feature Importance** | 모델 전체에서 중요한 변수 순위 |

## 핵심 정리

- 개인정보: 살아 있는 개인을 **직접 또는 결합하여** 식별할 수 있는 정보
- 비식별화 5기법: **가명처리, 데이터 마스킹, 데이터 집계, 데이터 범주화, 데이터 삭제**
- 재식별 위험: 비식별 데이터도 결합하면 개인 특정 가능 → k-익명성으로 대응
- 개인정보보호법 원칙: **목적 제한, 최소 수집, 안전 보호**
- 알고리즘 편향: 학습 데이터 편향 → 결과 편향
- 공정성: **보호 속성(성별, 인종 등)에 의한 차별 금지**
- 설명 가능성(XAI): 결정 근거를 인간이 이해할 수 있도록 설명
