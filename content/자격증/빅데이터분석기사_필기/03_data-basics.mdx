## 데이터란?

데이터(Data)는 관찰·측정·수집된 사실 또는 수치입니다. 그 자체로는 의미가 불분명하며, 분석과 해석을 통해 **정보(Information)**가 됩니다.

```
데이터 → 정보 → 지식 → 지혜
(raw)     (맥락)  (이해)  (판단)
```

---

## 데이터의 형태: 정형·반정형·비정형

| 종류 | 설명 | 예시 |
|------|------|------|
| **정형 데이터(Structured)** | 행과 열로 구성된 표 형태 | 엑셀, 관계형 데이터베이스(RDB) |
| **반정형 데이터(Semi-structured)** | 스키마가 유연한 형태 | JSON, XML, CSV, 로그 파일 |
| **비정형 데이터(Unstructured)** | 표로 나타낼 수 없는 자유 형태 | 이미지, 동영상, 음성, 자연어 텍스트 |

> **쉽게 말하면:** 엑셀 표에 넣을 수 있으면 정형, 넣기 어렵지만 규칙은 있으면 반정형, 아예 형태가 없으면 비정형입니다.

현재 세상에서 생성되는 데이터의 **80% 이상이 비정형**입니다. 이것이 빅데이터 분석이 중요한 이유입니다.

---

## 데이터의 속성: 양적·질적 데이터

| 구분 | 설명 | 예시 |
|------|------|------|
| **양적 데이터(Quantitative)** | 수량으로 나타낼 수 있는 데이터 | 나이, 키, 매출액 |
| **질적 데이터(Qualitative)** | 범주·속성으로 나타내는 데이터 | 성별, 혈액형, 국가명 |

양적 데이터는 다시 나뉩니다:

- **연속형(Continuous)**: 소수점으로 나타낼 수 있음 (키: 175.3cm)
- **이산형(Discrete)**: 정수로만 나타낼 수 있음 (자녀 수: 2명)

---

## 척도(Scale)의 종류

통계에서는 데이터의 **측정 수준(척도)**에 따라 사용 가능한 분석 방법이 달라집니다.

| 척도 | 특징 | 예시 | 가능한 연산 |
|------|------|------|------------|
| **명목(Nominal)** | 범주 구분만 가능 | 성별, 혈액형 | 빈도, 최빈값 |
| **순서(Ordinal)** | 크기 순서는 알 수 있음 | 만족도(1~5점) | 중앙값, 순위 |
| **등간(Interval)** | 간격이 동일, 절대 0 없음 | 온도(℃), 연도 | 평균, 표준편차 |
| **비율(Ratio)** | 간격 동일 + 절대 0 존재 | 키, 무게, 나이 | 모든 연산 |

> **주의:** 온도 0°C는 "없음"이 아닙니다. 절대 0이 없으므로 등간척도입니다. 반면 키 0cm는 진짜 "없음"이므로 비율척도입니다.

## 빅데이터의 5V

빅데이터는 기존 데이터베이스 도구로는 처리하기 어려운 방대한 데이터입니다. 특성을 5가지 V로 설명합니다.

| 특성 | 영어 | 설명 |
|------|------|------|
| **규모** | Volume | 데이터의 양이 매우 크다 (기가→테라→페타→엑사바이트) |
| **속도** | Velocity | 데이터가 빠르게 생성·수집·처리된다 |
| **다양성** | Variety | 정형·반정형·비정형 등 다양한 형태 |
| **정확성** | Veracity | 데이터의 품질과 신뢰성 문제 |
| **가치** | Value | 데이터 분석으로 얻는 비즈니스 가치 |

---

## 데이터 파이프라인 — 수집에서 분석까지

```
수집 → 저장 → 처리 → 분석 → 시각화 → 의사결정
```

1. **수집(Collection)**: 웹 크롤링, IoT 센서, API, 로그 파일, 설문
2. **저장(Storage)**: HDFS(분산 파일 시스템), NoSQL, 데이터 웨어하우스(DW), 데이터 레이크
3. **처리(Processing)**: Spark, Hadoop MapReduce — 대용량 데이터 변환·집계
4. **분석(Analysis)**: 통계 분석, 머신러닝 모델 학습
5. **시각화(Visualization)**: 대시보드, 리포트

---

## 데이터베이스 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| **RDB(관계형 DB)** | 테이블 형태, SQL로 조회 | MySQL, PostgreSQL, Oracle |
| **NoSQL** | 비정형·대용량에 유연 | MongoDB(문서), Redis(키-값), HBase |
| **데이터 웨어하우스(DW)** | 분석용 대규모 통합 저장소 | Redshift, BigQuery |
| **데이터 레이크** | 원시 형태 그대로 저장 | S3 + Athena |

---

## 핵심 정리

- **정형·반정형·비정형**: 표 형태가 가능한지, 규칙이 있는지에 따라 구분.
- **양적·질적 데이터**: 수치로 표현 가능 여부.
- **4가지 척도**: 명목→순서→등간→비율 (높을수록 더 많은 연산 가능).
- **빅데이터 5V**: Volume, Velocity, Variety, Veracity, Value.
- **데이터 파이프라인**: 수집→저장→처리→분석→시각화.
