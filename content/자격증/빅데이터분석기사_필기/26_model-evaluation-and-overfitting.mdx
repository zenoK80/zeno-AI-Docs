## 혼동행렬 (Confusion Matrix)

분류 모델의 예측 결과를 4가지 경우로 분류합니다.

|  | **예측: 양성**(Positive) | **예측: 음성**(Negative) |
|--|--------------------------|--------------------------|
| **실제: 양성** | TP (True Positive, 진양성) | FN (False Negative, 미탐지) |
| **실제: 음성** | FP (False Positive, 오탐지) | TN (True Negative, 진음성) |

- **TP**: 실제 양성을 양성으로 올바르게 예측
- **TN**: 실제 음성을 음성으로 올바르게 예측
- **FP **(Type I Error): 실제 음성을 양성으로 잘못 예측 (오경보)
- **FN **(Type II Error): 실제 양성을 음성으로 잘못 예측 (미탐지)

아래는 뒤에서 계산할 예시(TP=80, FN=20, FP=10, TN=90)를 막대그래프로 본 것입니다. 맞게 예측한 TP·TN(막대가 긺)이 잘못 예측한 FP·FN(막대가 짧음)보다 훨씬 많아야 좋은 모델입니다.

## 분류 평가지표

### 수식 정리

$$\text{정확도(Accuracy)} = \frac{TP + TN}{TP + FP + FN + TN}$$

$$\text{정밀도(Precision)} = \frac{TP}{TP + FP}$$

$$\text{재현율(Recall = Sensitivity)} = \frac{TP}{TP + FN}$$

$$\text{특이도(Specificity)} = \frac{TN}{TN + FP}$$

$$\text{F1 점수} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

F1은 정밀도와 재현율의 **조화평균**(Harmonic Mean)으로, 둘 다 높아야 F1이 높습니다.

> **왜 산술평균이 아니라 조화평균인가?** 산술평균 $(a+b)/2$은 둘 중 하나가 아주 낮아도 다른 하나가 높으면 평균이 그럭저럭 높게 나옵니다. 예를 들어 정밀도 1.0, 재현율 0.0이면 산술평균은 0.5로 "꽤 괜찮아 보이는" 착시가 생깁니다. 하지만 재현율 0은 사실상 쓸모없는 모델입니다. 조화평균은 두 값 중 **작은 쪽에 훨씬 큰 벌점**을 매겨서, 하나라도 낮으면 전체 점수가 확 낮아집니다. 정밀도와 재현율 둘 다 균형 있게 높아야 F1이 높아지도록 설계된 것입니다.

### 직접 계산 예시

**TP = 80, FN = 20, FP = 10, TN = 90**

전체 = 80 + 20 + 10 + 90 = **200**

$$\text{정확도} = \frac{80 + 90}{200} = \frac{170}{200} = 0.85 \quad (85 \%)$$

$$\text{정밀도} = \frac{80}{80 + 10} = \frac{80}{90} \approx 0.889 \quad (88.9 \%)$$

$$\text{재현율} = \frac{80}{80 + 20} = \frac{80}{100} = 0.80 \quad (80 \%)$$

$$\text{F1} = \frac{2 \times 0.889 \times 0.80}{0.889 + 0.80} = \frac{1.422}{1.689} \approx 0.842$$

| 지표 | 계산 | 결과 |
|------|------|------|
| 정확도 | (80+90)/200 | **0.850** |
| 정밀도 | 80/90 | **0.889** |
| 재현율 | 80/100 | **0.800** |
| F1 점수 | 조화평균 | **0.842** |

### 정밀도-재현율 트레이드오프

임계값(Threshold)을 조정하면 정밀도와 재현율이 반대로 움직입니다.

| 임계값 | 양성 예측 | 정밀도 | 재현율 | 적합 상황 |
|--------|-----------|--------|--------|-----------|
| 낮춤 (예: 0.3) | 많아짐 | 낮아짐 | 높아짐 | 암 진단: FN 최소화 |
| 0.5 (기본) | 중간 | 중간 | 중간 | 균형 |
| 높임 (예: 0.7) | 적어짐 | 높아짐 | 낮아짐 | 스팸 필터: FP 최소화 |

## 클래스 불균형 시 주의사항

**극단적 불균형 예시:** 정상 990건, 불량 10건 (총 1,000건)

"모든 것을 정상으로 예측"하면:
$$\text{정확도} = \frac{990}{1000} = 0.99 \quad (99 \%)$$

정확도는 매우 높지만 불량품을 하나도 찾지 못했습니다!

이 경우에는 **F1 점수** 또는 **AUC-ROC**를 사용해야 합니다.

## ROC 곡선과 AUC

### ROC 곡선

임계값을 0~1로 변화시키면서 FPR(X축)과 TPR(Y축)을 그린 곡선입니다.

$$TPR(\text{재현율}) = \frac{TP}{TP + FN}, \quad FPR = \frac{FP}{FP + TN}$$

```
TPR
 1.0 │          ┌────────────
     │      ╭──╯  (좋은 모델)
     │    ╭─╯
 0.5 │  ╭─╯
     │ ╱  (무작위 모델: 대각선)
 0.0 └──────────────────────→ FPR
     0.0        0.5        1.0
```

### AUC (Area Under the Curve)

ROC 곡선 아래 면적입니다.

| AUC 값 | 의미 |
|--------|------|
| 1.0 | 완벽한 분류기 |
| 0.9~1.0 | 매우 우수 |
| 0.7~0.9 | 양호 |
| 0.5~0.7 | 보통 |
| 0.5 | 무작위 (동전 던지기 수준) |
| < 0.5 | 무작위보다 나쁨 |

## 회귀 평가지표

| 지표 | 공식 | 특징 |
|------|------|------|
| MAE (평균 절대 오차) | $\frac{1}{n}\sum\|y_i - \hat{y}_i\|$ | 이상치에 덜 민감, 단위 동일 |
| MSE (평균 제곱 오차) | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 큰 오차에 더 많은 패널티 |
| RMSE (평균 제곱근 오차) | $\sqrt{MSE}$ | MSE에 제곱근, 원래 단위와 같음 |
| $R^2$ (결정계수) | $1 - \frac{SSE}{SST}$ | 분산 설명 비율 (1에 가까울수록 좋음) |

**작은 예시:** 실제값 [3, 5, 4], 예측값 [2, 6, 4]

$$MAE = \frac{|3-2| + |5-6| + |4-4|}{3} = \frac{1+1+0}{3} \approx 0.667$$
$$MSE = \frac{1^2 + 1^2 + 0^2}{3} = \frac{2}{3} \approx 0.667$$
$$RMSE = \sqrt{0.667} \approx 0.816$$

## 과적합 방지 방법

| 방법 | 설명 | 적용 알고리즘 |
|------|------|---------------|
| 데이터 추가 | 학습 데이터 늘리기 | 모든 모델 |
| 정규화(L1/L2) | 계수에 패널티 추가 | 선형, 로지스틱 회귀 |
| 드롭아웃(Dropout) | 학습 시 랜덤 뉴런 비활성화 | 신경망 |
| 조기 종료(Early Stopping) | 검증 성능 하락 시 학습 중단 | 신경망, GBM |
| 교차검증 | 다양한 분할로 평가 | 모든 모델 |
| 가지치기(Pruning) | 불필요한 가지 제거 | 의사결정나무 |
| max_depth 제한 | 트리 깊이 제한 | 의사결정나무, 랜덤 포레스트 |

## 핵심 정리

- 혼동행렬: TP(진양성), FP(오탐지), FN(미탐지), TN(진음성)
- 정확도 = (TP+TN)/전체, 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN)
- F1 = 2×Precision×Recall/(Precision+Recall): 정밀도·재현율의 조화평균
- 임계값 낮춤 → 재현율↑, 정밀도↓ / 임계값 높임 → 정밀도↑, 재현율↓
- 클래스 불균형 시 정확도 무의미 → F1, AUC 사용
- AUC: 0.5(무작위) ~ 1.0(완벽), 클수록 좋음
- 회귀: MAE(이상치 덜 민감), MSE(큰 오차 패널티 큼), RMSE(단위 동일), R²(설명 비율)
- 과적합 방지: 데이터 추가, L1/L2 정규화, 드롭아웃, 조기 종료, 교차검증
