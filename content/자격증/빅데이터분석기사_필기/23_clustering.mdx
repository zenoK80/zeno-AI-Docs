## 군집 분석이란?

**레이블(정답)이 없는** 데이터를 유사한 그룹으로 묶는 **비지도학습**(Unsupervised Learning) 기법입니다.

- 분류(Classification): 레이블이 있음 → 지도학습
- 군집(Clustering): 레이블이 없음 → 비지도학습 (스스로 그룹 발견)

활용 예시: 고객 세분화, 문서 주제 분류, 이미지 압축, 이상치 탐지

## K-means 군집화

### 알고리즘 과정

1. K개 초기 중심(Centroid)을 무작위로 선택
2. 각 데이터 포인트를 **가장 가까운 중심**에 배정
3. 각 군집의 **평균 위치**로 중심 재계산
4. 중심이 변하지 않을 때까지(수렴) 2~3 반복

### 목적함수: WCSS

$$WCSS = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

- WCSS(Within-Cluster Sum of Squares): 군집 내 분산의 합
- K-means는 WCSS를 최소화하는 방향으로 수렴합니다.

$\|x_i - \mu_k\|$("노름", norm)은 두 점 사이의 **거리**를 나타내는 표기법입니다. 19번 문서에서 배운 유클리드 거리 $\sqrt{\sum(x_i-y_i)^2}$와 같은 개념이며, 여기서는 제곱($\|\cdot\|^2$)까지 취해 "거리의 제곱"을 씁니다. 거리가 멀수록 큰 값이 나오므로, WCSS는 결국 "각 점이 자기 군집의 중심에서 얼마나 멀리 떨어져 있는지"를 모두 더한 값입니다.

### 직접 계산 예시 (K=2, 1회 반복)

**5개 데이터 포인트 (1차원):**

| 점 | 값 |
|----|----|
| A | 1 |
| B | 2 |
| C | 4 |
| D | 9 |
| E | 10 |

**초기 중심 무작위 설정:** $\mu_1 = 1$ (A 선택), $\mu_2 = 9$ (D 선택)

**배정 단계:** 각 점을 가까운 중심에 배정

| 점 | 값 | $\|\cdot - \mu_1=1\|$ | $\|\cdot - \mu_2=9\|$ | 배정 군집 |
|----|----|----------------------|----------------------|-----------|
| A | 1 | 0 | 8 | 군집 1 |
| B | 2 | 1 | 7 | 군집 1 |
| C | 4 | 3 | 5 | 군집 1 |
| D | 9 | 8 | 0 | 군집 2 |
| E | 10 | 9 | 1 | 군집 2 |

**중심 재계산:**
$$
\mu_1 = \frac{1+2+4}{3} = \frac{7}{3} \approx 2.33
$$

$$
\mu_2 = \frac{9+10}{2} = 9.5
$$

이후 반복하면 최종 수렴: 군집 1 = &#123;A, B, C&#125;, 군집 2 = &#123;D, E&#125;

### K 선택: 엘보우 방법(Elbow Method)

K를 1, 2, 3, ...으로 늘리면서 WCSS를 계산합니다. **WCSS 감소폭이 급격히 꺾이는 지점**을 최적 K로 선택합니다.

```
WCSS
 ↑
 │●
 │  ●
 │     ●         ← 여기서 꺾임 (K=3이 최적)
 │        ●  ●  ●
 └──────────────→ K
    1  2  3  4  5
```

K=3 이후로는 WCSS가 크게 줄지 않으므로 K=3 선택

### K-means 단점

| 단점 | 설명 |
|------|------|
| K 사전 지정 필요 | 최적 K를 미리 알기 어려움 |
| 이상치 민감 | 이상치가 중심 위치를 왜곡 |
| 원형 군집 가정 | 복잡한 형태의 군집 처리 어려움 |
| 초기값 민감 | 초기 중심에 따라 결과가 달라짐 (K-means++ 으로 완화) |

## 계층적 군집(Hierarchical Clustering)

### 병합형(Agglomerative) 방식

가장 일반적인 방식입니다. 아래에서 위로 군집을 합칩니다.

```
초기: 각 점이 독립 군집
  → 가장 가까운 두 군집 합침
  → 반복
  → 하나의 군집이 될 때까지
```

### 거리 계산 방법 (연결 방식)

| 방법 | 거리 기준 | 특징 |
|------|-----------|------|
| 단일 연결(Single Linkage) | 두 군집 중 가장 가까운 점들의 거리 | 사슬 효과, 이상치에 민감 |
| 완전 연결(Complete Linkage) | 두 군집 중 가장 먼 점들의 거리 | 컴팩트한 군집, 이상치에 덜 민감 |
| 평균 연결(Average Linkage) | 모든 점 쌍의 거리 평균 | 균형 잡힌 결과 |
| Ward 방법 | WCSS 증가량 최소화 | 균일한 크기의 군집 생성 (가장 많이 사용) |

### 덴드로그램(Dendrogram)

계층적 군집 결과를 트리 형태로 시각화합니다. 원하는 높이(거리 임계값)에서 수평으로 자르면 군집 수를 결정할 수 있습니다.

```
거리↑
 │      ┌────────┐
 │  ┌───┤        └───────────────┐
 │  │   └──────┐                 │
 │  │          │      ┌──────┐   │
 │  ┌──┐   ┌──┐   ┌──┐   ┌──┐   │
    A  B   C  D   E  F   G  H
```

## DBSCAN

### 개념

**밀도**(Density) 기반 군집 알고리즘으로, 밀도가 높은 영역을 군집으로 정의합니다.

### 파라미터

- **ε **(epsilon): 이웃으로 볼 반경
- **minPts**: 핵심 포인트가 되기 위한 반경 내 최소 점 수

### 점의 종류

| 종류 | 조건 |
|------|------|
| 핵심 포인트(Core Point) | ε 반경 내에 minPts 이상의 점이 있음 |
| 경계 포인트(Border Point) | 핵심 포인트의 ε 이웃에 속하나 자신은 핵심이 아님 |
| 잡음 포인트(Noise Point) | 핵심 포인트의 ε 이웃에 속하지 않음 → 이상치 |

### K-means vs DBSCAN 비교

| 항목 | K-means | DBSCAN |
|------|---------|--------|
| K 사전 지정 | 필요 | 불필요 |
| 이상치 처리 | 군집에 강제 배정 | 잡음 포인트로 자동 탐지 |
| 군집 형태 | 원형 가정 | 임의 형태 가능 |
| 파라미터 | K | ε, minPts |
| 대용량 | 빠름 | 느릴 수 있음 |

## 핵심 정리

- 군집 분석: 레이블 없이 유사한 데이터를 그룹화하는 비지도학습
- K-means: 초기 중심 → 배정 → 중심 재계산 → 수렴. WCSS 최소화
- 엘보우 방법: WCSS가 급격히 꺾이는 K를 최적으로 선택
- K-means 단점: K 사전 지정, 이상치 민감, 원형 군집 가정, 초기값 민감
- 계층적 군집: 병합형(아래→위), 덴드로그램으로 시각화, Ward 방법이 가장 많이 사용
- DBSCAN: 밀도 기반, K 불필요, 이상치 자동 탐지, 비원형 군집 가능
