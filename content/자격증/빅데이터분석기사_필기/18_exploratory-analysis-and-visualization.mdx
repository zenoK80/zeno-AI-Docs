## EDA란?

**탐색적 데이터 분석(Exploratory Data Analysis, EDA)** 은 John Tukey가 1977년 제안한 분석 철학으로, 사전에 가설 없이 데이터 자체를 들여다보며 패턴을 발견하는 접근법입니다.

### EDA의 목적

| 목적 | 구체적 내용 |
|------|------------|
| **분포 파악** | 데이터가 어떻게 퍼져 있는가? 이상치가 있는가? |
| **관계 탐색** | 변수들 사이에 어떤 패턴이 있는가? |
| **가정 검증** | 정규성, 등분산 등 분석 모델의 가정이 맞는가? |
| **이상 탐지** | 기대와 다른 특이한 점이 있는가? |
| **모델링 준비** | 어떤 변수를 선택하고 어떻게 변환해야 하는가? |

## 단변량 분석 — 변수 1개

### 수치형 변수

**히스토그램(Histogram)**

- 연속형 데이터를 구간으로 나눠 빈도를 막대로 표시합니다
- 분포 모양(대칭/왜도), 봉우리 수, 이상치 파악

히스토그램 해석 포인트:
- **오른쪽 꼬리(양의 왜도):** 소수의 큰 값들이 있음 → 로그 변환 고려
- **왼쪽 꼬리(음의 왜도):** 소수의 작은 값들이 있음
- **두 개의 봉우리(이봉형):** 두 개의 하위 집단이 혼재할 가능성

**박스플롯(Box Plot)**

박스플롯은 5개의 요약 통계량을 한눈에 보여줍니다.

```
        ┌──────────────────┐
최솟값 ─┤ Q1  │ Q2  │ Q3  ├─ 최댓값
        └──────────────────┘
              IQR
  ●(이상치)                ●(이상치)
```

| 요소 | 의미 |
|------|------|
| 박스 왼쪽 경계 | Q1 (25번째 백분위) |
| 박스 중간선 | Q2 중앙값 (50번째 백분위) |
| 박스 오른쪽 경계 | Q3 (75번째 백분위) |
| 박스 너비 | IQR = Q3 − Q1 |
| 수염(whisker) | Q1 − 1.5×IQR ~ Q3 + 1.5×IQR |
| 점(●) | 이상치 (수염 범위 벗어난 값) |

**밀도 곡선(KDE, Kernel Density Estimate)**

히스토그램을 부드러운 곡선으로 표현합니다. 구간 폭(bin)에 덜 민감합니다.

### 범주형 변수

**막대 그래프(Bar Chart)**

각 범주의 빈도 또는 비율을 막대로 표시합니다.

- 수평/수직 모두 가능, 수직이 일반적
- 빈도 기준 또는 비율 기준 선택
- 범주가 많으면 수평 막대 그래프가 읽기 편함

**파이 차트(Pie Chart)**

전체에서 각 범주의 비율을 원 형태로 표시합니다.

<Callout type="warning">
  **파이 차트 주의사항:** 범주가 7개를 초과하거나 비율 차이가 작으면 각도 비교가 어려워 오독하기 쉽습니다. 이 경우 막대 그래프가 더 적합합니다.
</Callout>

## 이변량 분석 — 변수 2개

### 수치형 × 수치형: 산점도(Scatter Plot)

두 연속형 변수 간의 관계를 점으로 표시합니다.

산점도에서 확인할 것:
- **방향:** 양의 관계(우상향), 음의 관계(우하향), 관계 없음
- **강도:** 점들이 얼마나 직선에 모여 있는가
- **형태:** 선형인가, 비선형(곡선)인가
- **이상치:** 전체 패턴에서 벗어난 점

### 수치형 × 범주형: 그룹 비교

**그룹별 박스플롯 비교**

여러 집단의 분포를 나란히 배치하여 비교합니다.

예) A/B/C 세 마케팅 채널별 매출 분포 비교

**바이올린 플롯(Violin Plot)**

박스플롯 + 밀도 분포를 결합합니다. 분포 모양을 더 자세히 볼 수 있습니다.

### 범주형 × 범주형: 교차표와 모자이크 플롯

**교차표(Contingency Table)**

| | 구매 | 미구매 | 합계 |
|--|:----:|:------:|:----:|
| 광고 클릭 | 45 | 55 | 100 |
| 광고 미클릭 | 15 | 85 | 100 |
| 합계 | 60 | 140 | 200 |

광고 클릭 그룹의 구매율 = 45% vs 미클릭 그룹 = 15%

**모자이크 플롯:** 교차표를 면적으로 시각화

## 다변량 분석 — 변수 3개 이상

### 히트맵(Heatmap) — 상관계수 행렬

변수 간 상관계수를 색상으로 표현합니다.

- 색상이 진할수록(보통 빨간색) 상관관계 강함
- 대각선은 자기 자신과의 상관계수 = 1
- 다중 공선성(Multicollinearity) 진단에 유용

### 산점도 행렬(Pair Plot / Scatter Matrix)

모든 변수 쌍의 산점도를 격자 형태로 배치합니다.

- 대각선: 각 변수의 히스토그램 또는 밀도 곡선
- n개 변수 → n×n 격자

### 버블 차트(Bubble Chart)

산점도(x, y)에 세 번째 변수를 버블 크기로 추가합니다.

예) x=광고비, y=매출, 버블 크기=고객 수

## 그래프 선택 기준

| 분석 목적 | 변수 유형 | 추천 그래프 |
|-----------|----------|------------|
| 분포 모양 확인 | 수치형 1개 | 히스토그램, 밀도 곡선 |
| 5대 요약 통계 | 수치형 1개 | 박스플롯 |
| 범주별 빈도 | 범주형 1개 | 막대 그래프 |
| 범주별 비율 | 범주형 1개 | 파이 차트 (7개 이하) |
| 두 수치 관계 | 수치×수치 | 산점도 |
| 집단별 분포 비교 | 수치×범주 | 그룹별 박스플롯 |
| 두 범주 관계 | 범주×범주 | 교차표, 모자이크 플롯 |
| 변수 간 상관 행렬 | 수치형 다수 | 히트맵 |
| 모든 쌍 관계 | 수치형 다수 | 산점도 행렬(Pair plot) |
| 3변수 동시 표현 | 수치형 3개 | 버블 차트 |

## 그래프 해석 실전 포인트

### 히스토그램 읽기

- 분포가 **오른쪽으로 치우쳐 있으면(오른쪽 꼬리)** → 로그 변환 고려
- **정규분포에 가까운지** 확인 → 이후 통계 검정의 가정 확인
- **이상하게 높은 특정 막대** → 데이터 입력 오류나 반올림 패턴 의심

### 박스플롯 읽기

- 중앙선(Q2)이 박스 중앙에 있으면 대칭 분포
- 중앙선이 왼쪽에 치우치면 오른쪽 꼬리(양의 왜도)
- 수염 밖의 점(●)이 이상치

### 산점도 읽기

- 점들이 **직선 형태로 모이면** 강한 선형 관계
- 점들이 **곡선 형태** → 비선형 관계 (상관계수 r만으로 부족)
- 점들이 **군집**을 이루면 하위 집단 존재 가능

<Callout type="info">
  **앤스콤 사중주(Anscombe's Quartet):** 4가지 데이터 세트가 모두 같은 평균, 분산, 상관계수를 가지지만, 산점도로 보면 완전히 다른 패턴(선형, 곡선, 이상치)을 가집니다. **숫자만 보지 말고 반드시 그래프를 그려야 한다**는 교훈입니다.
</Callout>

## 핵심 정리

- **EDA 목적:** 가설 없이 탐색, 분포·패턴·이상치 발견, 모델링 준비
- **히스토그램:** 수치형 분포, 왜도 파악 → 오른쪽 꼬리면 로그 변환 고려
- **박스플롯:** Q1/Q2/Q3/IQR/이상치 한눈에 파악
- **막대 그래프:** 범주형 빈도 비교 (파이 차트보다 정확)
- **산점도:** 두 수치 변수 관계, 선형·비선형·군집·이상치 파악
- **히트맵:** 상관계수 행렬 시각화, 다중 공선성 진단
- **산점도 행렬:** 모든 변수 쌍의 관계 한눈에 파악
- **버블 차트:** 산점도 + 세 번째 변수를 크기로 표현
