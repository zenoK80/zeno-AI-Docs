## 예시 데이터

이 문서 전체에서 아래 데이터를 사용합니다.

| 광고비 $x$ (만원) | 매출 $y$ (만원) |
|:-----------------:|:---------------:|
| 10 | 150 |
| 20 | 180 |
| 30 | 240 |
| 40 | 300 |
| 50 | 350 |

$$\bar{x} = \frac{10+20+30+40+50}{5} = \frac{150}{5} = 30, \quad \bar{y} = \frac{150+180+240+300+350}{5} = \frac{1220}{5} = 244$$

---

## 피어슨 상관계수 r

두 변수 간의 **선형 관계의 강도와 방향**을 -1~+1로 나타냅니다.

$$r = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2 \cdot \sum(y_i - \bar{y})^2}}$$

### 단계별 계산

**각 편차 및 곱 계산 ($\bar{x}=30$, $\bar{y}=244$):**

| $x_i$ | $y_i$ | $x_i - \bar{x}$ | $y_i - \bar{y}$ | $(x_i-\bar{x})(y_i-\bar{y})$ | $(x_i-\bar{x})^2$ | $(y_i-\bar{y})^2$ |
|:------:|:------:|:----------------:|:----------------:|:------------------------------:|:------------------:|:------------------:|
| 10 | 150 | -20 | -94 | 1880 | 400 | 8836 |
| 20 | 180 | -10 | -64 | 640 | 100 | 4096 |
| 30 | 240 | 0 | -4 | 0 | 0 | 16 |
| 40 | 300 | 10 | 56 | 560 | 100 | 3136 |
| 50 | 350 | 20 | 106 | 2120 | 400 | 11236 |
| **합계** | | | | **5200** | **1000** | **27320** |

**계산:**

$$r = \frac{5200}{\sqrt{1000 \times 27320}} = \frac{5200}{\sqrt{27320000}} = \frac{5200}{5226.9} \approx \mathbf{0.995}$$

### r 해석

| $|r|$ 범위 | 해석 |
|:----------:|------|
| 0.7 ~ 1.0 | **강한** 상관관계 |
| 0.4 ~ 0.7 | **중간** 상관관계 |
| 0.2 ~ 0.4 | **약한** 상관관계 |
| 0 ~ 0.2 | **거의 없음** |

→ 예시: $r \approx 0.995$ → **매우 강한 양의 선형 관계**

- **r > 0:** 양의 상관 (x↑ → y↑)
- **r < 0:** 음의 상관 (x↑ → y↓)
- **r = 0:** 선형 관계 없음 (비선형 관계는 있을 수 있음)

## 상관 ≠ 인과

<Callout type="warning">
  **상관관계는 인과관계가 아닙니다!**

  여름에 아이스크림 판매량과 익사 사고 건수는 강한 양의 상관관계를 보입니다. 하지만 아이스크림이 익사를 유발하지 않습니다. 두 변수 모두 **숨겨진 변수(혼란 변수, Confounding Variable)**인 "기온"의 영향을 받기 때문입니다.

  인과관계를 주장하려면 실험 설계(무작위 배정 실험)가 필요합니다.
</Callout>

## 단순 선형 회귀

하나의 독립변수 x로 종속변수 y를 예측하는 직선 모델입니다.

$$\hat{y} = b_0 + b_1 x$$

- $b_1$: 기울기 (x가 1 단위 증가할 때 y의 변화량)
- $b_0$: 절편 (x=0일 때 y의 예측값)

### 회귀계수 계산

**기울기 $b_1$:**

$$b_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2} = \frac{5200}{1000} = \mathbf{5.2}$$

**절편 $b_0$:**

$$b_0 = \bar{y} - b_1 \bar{x} = 244 - 5.2 \times 30 = 244 - 156 = \mathbf{88}$$

### 회귀식

$$\hat{y} = 88 + 5.2x$$

**해석:** 광고비를 1만원 증가시키면 매출이 평균 **5.2만원** 증가합니다.

### 예측 예시

광고비 35만원을 집행할 때 예상 매출:

$$\hat{y} = 88 + 5.2 \times 35 = 88 + 182 = \mathbf{270}\text{만원}$$

## 결정계수 R²

회귀 모델이 종속변수의 총 변동을 얼마나 설명하는지 나타냅니다.

$$R^2 = r^2 = (0.995)^2 \approx 0.990$$

- R² = 0.990 → **매출 변동의 99.0%를 광고비로 설명**
- R² 범위: 0 ~ 1 (높을수록 모델이 데이터에 잘 맞음)
- R² = 0: 모델이 아무것도 설명 못함
- R² = 1: 완벽한 예측

---

## 잔차(Residual)

실제 관측값과 예측값의 차이입니다.

$$e_i = y_i - \hat{y}_i$$

**잔차 계산:**

| $x_i$ | 실제 $y_i$ | 예측 $\hat{y}_i$ | 잔차 $e_i$ |
|:------:|:----------:|:----------------:|:----------:|
| 10 | 150 | $88 + 5.2 \times 10 = 140$ | **+10** |
| 20 | 180 | $88 + 5.2 \times 20 = 192$ | **-12** |
| 30 | 240 | $88 + 5.2 \times 30 = 244$ | **-4** |
| 40 | 300 | $88 + 5.2 \times 40 = 296$ | **+4** |
| 50 | 350 | $88 + 5.2 \times 50 = 348$ | **+2** |

**잔차 분석으로 모델 가정 확인:**
- 잔차가 무작위로 분포 → 좋은 모델
- 잔차에 패턴이 보임 → 비선형 관계나 다른 변수 필요
- 특정 구간에서 잔차 분산이 커짐 → 등분산 가정 위반

## 핵심 정리

- **피어슨 r:** -1~+1, 선형 관계의 강도와 방향
- **r 해석:** |r| ≥ 0.7 강함, 0.4~0.7 중간, < 0.4 약함
- **상관 ≠ 인과:** 혼란 변수 주의
- **회귀식:** $\hat{y} = b_0 + b_1 x$
- **기울기:** $b_1 = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}$
- **절편:** $b_0 = \bar{y} - b_1 \bar{x}$
- **R²:** 모델이 설명하는 변동의 비율, 단순 회귀에서 $R^2 = r^2$
- **잔차:** 실제값 - 예측값, 잔차 그림으로 모델 가정 확인
