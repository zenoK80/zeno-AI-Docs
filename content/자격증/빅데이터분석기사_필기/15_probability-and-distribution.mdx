## 확률 기호부터 정리

이 문서에는 집합 기호가 자주 등장합니다. 먼저 뜻을 정리합니다.

| 기호 | 읽는 법 | 뜻 |
|------|---------|-----|
| $P(A)$ | "피 에이" | 사건 A가 일어날 확률 |
| $\cup$ | 합집합(union, 컵 모양) | "또는(or)". $A \cup B$는 "A 또는 B가 일어남" |
| $\cap$ | 교집합(intersection, 캡 모양) | "그리고(and)". $A \cap B$는 "A와 B가 동시에 일어남" |
| $P(A\vert B)$ | "피 에이 given 비" | 조건부 확률. B가 일어났다는 조건에서 A가 일어날 확률 |

> **쉽게 말하면:** $\cup$는 컵처럼 아래가 뾰족해서 "or"(둘 중 하나라도), $\cap$는 뒤집힌 컵(모자) 모양이라 "and"(둘 다)라고 외우면 헷갈리지 않습니다.

## 확률 기본 법칙

### 덧셈 법칙

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

"A 또는 B가 일어날 확률"은 "A가 일어날 확률 + B가 일어날 확률"을 더하면 되지만, **A와 B가 동시에 일어나는 경우**($A \cap B$)가 두 번 겹쳐서 더해지므로 한 번 빼줍니다.

> **비유:** 하트 카드와 킹 카드를 각각 셀 때, "하트 킹"은 두 그룹 모두에 속해서 두 번 세어버립니다. 정확한 개수를 구하려면 겹치는 만큼 한 번 빼야 합니다.

**예시:** 카드 한 장을 뽑을 때
- P(하트) = 13/52 = 0.25
- P(킹) = 4/52 ≈ 0.077
- P(하트 ∩ 킹) = 1/52 ≈ 0.019

$$P(\text{하트 또는 킹}) = \frac{13}{52} + \frac{4}{52} - \frac{1}{52} = \frac{16}{52} \approx 0.308$$

### 조건부 확률

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

B가 발생했을 때 A가 발생할 확률입니다.

**예시:** 학생 100명 중 남학생 60명, 합격자 40명(남 25명, 여 15명)
- 남학생이 합격할 확률: $P(\text{합격}|\text{남}) = \frac{25/100}{60/100} = \frac{25}{60} \approx 0.417$

### 독립 사건

두 사건이 서로 영향을 주지 않을 때

$$P(A \cap B) = P(A) \times P(B)$$

**예시:** 주사위 두 번 던지기 — 각 시행은 독립
- P(첫 번째 6) × P(두 번째 6) = 1/6 × 1/6 = 1/36

### 베이즈 정리

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

사전 확률을 새 증거로 업데이트합니다.

**스팸 필터 예시:**
- 전체 이메일 중 스팸 비율: P(스팸) = 0.3
- 정상 메일 비율: P(정상) = 0.7
- 스팸 메일에 "당첨" 단어 포함 확률: P(당첨|스팸) = 0.8
- 정상 메일에 "당첨" 단어 포함 확률: P(당첨|정상) = 0.1

"당첨"이 포함된 이메일이 스팸일 확률:

$$P(\text{스팸}|\text{당첨}) = \frac{0.8 \times 0.3}{0.8 \times 0.3 + 0.1 \times 0.7} = \frac{0.24}{0.24 + 0.07} = \frac{0.24}{0.31} \approx 0.774$$

→ "당첨" 단어 등장 시 77.4% 확률로 스팸

## 이산 확률분포

### 이항분포 B(n, p)

n번의 독립 시행에서 성공 확률이 p일 때, 성공 횟수 X의 분포

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$

이 공식을 읽기 전에 새로운 기호 두 개를 알아야 합니다.

- $\binom{n}{k}$ ("n 콤비네이션 k", 조합): n개 중에서 순서 상관없이 k개를 고르는 경우의 수. $\binom{n}{k} = \frac{n!}{k!(n-k)!}$로 계산합니다.
- $n!$ ("n 팩토리얼"): 1부터 n까지 모든 정수를 곱한 값. 예: $4! = 4\times3\times2\times1 = 24$. 정의상 $0! = 1$입니다.

$$
\binom{10}{2} = \frac{10!}{2! \times 8!} = \frac{10 \times 9}{2 \times 1} = 45
$$

즉 $\binom{n}{k}p^k(1-p)^{n-k}$는 "k번 성공하는 **특정한 하나의 순서**가 나올 확률($p^k(1-p)^{n-k}$)"에, "그 k번 성공이 n번 중 몇 가지 순서로 나올 수 있는지($\binom{n}{k}$)"를 곱한 것입니다.

- 평균: $\mu = np$
- 분산: $\sigma^2 = np(1-p)$

**예시:** 불량률 5%(p=0.05), 10개 검사(n=10)할 때 불량 2개(k=2)일 확률

$$P(X=2) = \binom{10}{2} (0.05)^2 (0.95)^8 = 45 \times 0.0025 \times 0.6634 \approx 0.0746$$

→ 약 7.5% 확률

같은 방식으로 불량 개수가 0~5개일 확률을 모두 계산해서 그래프로 그리면, 분포의 모양이 한눈에 보입니다. 불량률이 낮을수록 "불량 0개"에 확률이 몰리고 오른쪽으로 갈수록 급격히 낮아지는 모양입니다.

### 포아송 분포 Poisson(λ)

단위 시간/공간에서 평균 $\lambda$(람다)번 발생하는 사건의 횟수 분포입니다. $\lambda$는 "단위 시간(또는 공간)당 평균적으로 몇 번 일어나는지"를 나타내는 값입니다.

$$P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!}$$

$e$("자연상수", 오일러 수)는 약 2.71828인 특별한 상수로, 수학·통계에서 "연속적으로 변화하는 양"을 다룰 때 자주 등장하는 고정된 숫자입니다. $\pi$(파이)처럼 값이 정해진 상수라고 생각하면 됩니다. 직접 계산할 필요 없이 계산기나 공학용 함수로 구합니다.

**예시:** 고객 문의가 시간당 평균 3건(λ=3) 들어올 때, 0건일 확률

$$P(X=0) = \frac{e^{-3} \cdot 3^0}{0!} = e^{-3} \approx 0.0498$$

→ 약 5%의 확률로 문의가 0건

## 연속 확률분포

### 정규분포 N(μ, σ²)

통계학에서 가장 중요한 분포입니다.

**특징:**
- 종 모양(Bell curve), 좌우 대칭
- 평균 = 중앙값 = 최빈값 = μ
- 두 매개변수: 평균 μ(위치), 분산 σ²(퍼짐)

### 표준정규분포 N(0, 1)

임의의 정규분포를 표준화하면 표준정규분포가 됩니다.

$$Z = \frac{X - \mu}{\sigma}$$

### 68-95-99.7 경험칙

| 범위 | 포함 비율 |
|------|----------|
| $\mu \pm 1\sigma$ | 약 **68.3%** |
| $\mu \pm 2\sigma$ | 약 **95.4%** |
| $\mu \pm 3\sigma$ | 약 **99.7%** |

**예시:** 성인 키가 N(170, 6²)를 따를 때
- 키 158~182cm(μ±2σ) 안에 약 95% 포함
- 키 152~188cm(μ±3σ) 안에 약 99.7% 포함
- 188cm 초과는 약 0.15%의 극히 드문 경우

## 검정에 쓰이는 분포

### t분포

소표본(일반적으로 n < 30)이거나 모분산을 모를 때 사용합니다.

- **자유도**(df = n − 1) 가 클수록 정규분포에 가까워집니다
- 정규분포보다 꼬리가 두껍습니다 (이상치 발생 가능성 반영)

| 표본 크기 | 사용 분포 |
|-----------|----------|
| n ≥ 30, 모분산 알 때 | Z 분포 (표준정규) |
| n < 30 또는 모분산 모를 때 | **t 분포** |

### 카이제곱(χ²) 분포

- 항상 0 이상의 값을 가집니다
- **분산 검정:** 모집단 분산이 특정 값과 같은지 검정
- **독립성 검정:** 두 범주형 변수 간 독립성 검정 (교차표 분석)

### F 분포

- 항상 0 이상의 값
- **두 집단 분산의 비율** 검정
- **ANOVA(분산분석):** 3개 이상 집단의 평균 비교

### 분포 선택 가이드

| 상황 | 사용 분포 |
|------|----------|
| 두 집단 평균 비교, 소표본 | t 분포 |
| 범주형 데이터 독립성 | χ² 분포 |
| 두 집단 분산 비교 | F 분포 |
| 3개 이상 집단 평균 비교 | F 분포 (ANOVA) |
| n회 시행 성공 횟수 | 이항분포 |
| 단위 시간 사건 발생 횟수 | 포아송 분포 |

## 핵심 정리

- **덧셈법칙:** $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- **조건부 확률:** $P(A|B) = P(A \cap B) / P(B)$
- **독립:** $P(A \cap B) = P(A) \times P(B)$
- **베이즈:** 사전 확률 + 새 증거 → 사후 확률 업데이트
- **이항분포:** n번 시행, 성공률 p, 평균 np
- **포아송:** 단위 시간/공간의 사건 수, 평균 = 분산 = λ
- **정규분포:** 대칭 종 모양, 68-95-99.7 규칙
- **t분포:** 소표본/모분산 미지, 꼬리 두꺼움
- **χ² 분포:** 독립성 검정, 분산 검정
- **F 분포:** 두 집단 분산 비교, ANOVA
