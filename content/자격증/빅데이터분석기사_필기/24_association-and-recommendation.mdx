## 연관규칙 분석

### 개념

&#123;A&#125; → &#123;B&#125;: "A를 구매한 사람은 B도 구매한다"와 같은 패턴을 발견하는 분석입니다.

- 장바구니 분석(Market Basket Analysis)이 대표적
- 활용: 상품 진열 최적화, 쿠폰 설계, 추천 시스템

### 3가지 핵심 지표

#### 지지도 (Support)

$$\text{지지도}(A \to B) = P(A \cap B) = \frac{A와 B가 함께 등장한 거래 수}{전체 거래 수}$$

- 전체 거래에서 해당 패턴이 얼마나 자주 나타나는지
- 낮은 지지도 → 빈도가 적어 신뢰성 낮음

#### 신뢰도 (Confidence)

$$\text{신뢰도}(A \to B) = P(B|A) = \frac{A와 B가 함께 등장한 거래 수}{A가 등장한 거래 수}$$

- A를 구매한 사람 중 B도 구매한 비율
- A → B 규칙의 정확도

#### 향상도 (Lift)

$$\text{향상도}(A \to B) = \frac{\text{신뢰도}(A \to B)}{P(B)} = \frac{P(A \cap B)}{P(A) \cdot P(B)}$$

- 향상도 > 1: A와 B가 서로 양의 연관 (A 구매 시 B 구매 확률이 올라감)
- 향상도 = 1: 독립적 (A 구매가 B 구매에 영향 없음)
- 향상도 < 1: 음의 연관 (A 구매 시 B 구매 확률이 낮아짐)

### 직접 계산 예시

**거래 데이터 5건:**

| 거래 번호 | 구매 상품 |
|-----------|-----------|
| T1 | 라면, 계란, 김치 |
| T2 | 라면, 계란 |
| T3 | 라면, 계란, 참치 |
| T4 | 라면 |
| T5 | 계란, 참치 |

**집계:**
- 전체 거래 수 = 5
- 라면 포함 거래: T1, T2, T3, T4 → **4건**
- 계란 포함 거래: T1, T2, T3, T5 → **4건**
- 라면 + 계란 함께: T1, T2, T3 → **3건**

**&#123;라면&#125; → &#123;계란&#125; 규칙 계산:**

$$\text{지지도} = \frac{3}{5} = 0.6 \quad (60 \%)$$

$$\text{신뢰도} = \frac{3}{4} = 0.75 \quad (75 \%)$$

$$P(\text{계란}) = \frac{4}{5} = 0.8$$

$$\text{향상도} = \frac{0.75}{0.8} = 0.9375$$

<Callout type="warning">
  **향상도 0.9375 < 1:** 라면을 구매한다고 계란 구매 확률이 높아지지는 않습니다. 단독 확률(0.8)과 비슷합니다. 실질적 연관이 없다고 볼 수 있습니다.
</Callout>

## Apriori 알고리즘

### 원리

**최소 지지도**(min_support)를 만족하는 빈번 항목 집합(Frequent Itemset)을 효율적으로 찾습니다.

**핵심 원리 (Apriori 원칙):**
- 빈번 항목 집합의 모든 부분집합도 빈번합니다.
- 비빈번 항목 집합을 포함하는 집합은 빈번하지 않습니다 → **가지치기 가능**

### 과정

```
1단계: 1-항목 집합 중 min_support 이상인 것 선택
2단계: 선택된 항목들의 2-항목 집합 생성 → min_support 이상인 것 선택
3단계: 위를 반복
4단계: 빈번 항목 집합으로 min_confidence 이상인 연관규칙 생성
```

## 추천 시스템

### 협업 필터링 (Collaborative Filtering, CF)

사용자의 **행동 이력**(구매, 평점, 클릭)을 기반으로 추천합니다.

#### 사용자 기반 CF (User-Based)

유사한 취향의 사용자가 좋아한 아이템을 추천합니다.

```
나: 영화 A★★★★, B★★★, C★★★★★
다른 사용자: 영화 A★★★★, B★★★, C★★★★★, D★★★★★

→ 나와 취향이 비슷한 사용자가 D를 좋아하니 D를 추천
```

#### 아이템 기반 CF (Item-Based)

내가 좋아한 아이템과 유사한 아이템을 추천합니다.

```
영화 A와 영화 D를 함께 구매한 사람이 많음
→ 내가 영화 A를 구매했으니 D를 추천
```

### 콘텐츠 기반 필터링 (Content-Based Filtering)

아이템의 **속성**(장르, 감독, 키워드)과 사용자 선호를 매칭합니다.

```
내가 액션 영화를 좋아함 → 비슷한 속성(액션, 같은 감독)을 가진 영화 추천
```

### 행렬 분해 (Matrix Factorization)

사용자-아이템 평점 행렬을 저차원 잠재 요인(Latent Factor)으로 분해합니다.

$$R \approx U \times V^T$$

- R: 사용자×아이템 평점 행렬 (대부분 비어 있음)
- U: 사용자 잠재 요인 행렬
- V: 아이템 잠재 요인 행렬
- 대표 방법: SVD(특이값 분해), ALS(교대 최소 제곱법)

### 세 방식 비교

| 방식 | 장점 | 단점 |
|------|------|------|
| 협업 필터링 | 콘텐츠 분석 불필요, 새로운 관심사 발견 | 콜드 스타트, 희소 행렬 문제 |
| 콘텐츠 기반 | 새 아이템 추천 가능, 개인화 | 콘텐츠 분석 비용, 필터 버블 |
| 행렬 분해 | 협업 필터링의 희소 행렬 개선 | 계산 비용, 콜드 스타트 |

### 콜드 스타트 문제 (Cold Start)

| 상황 | 문제 |
|------|------|
| 신규 사용자 | 이력 데이터가 없어 개인화 추천 불가 |
| 신규 아이템 | 평점이 없어 CF로 추천 불가 |
| 해결책 | 인기 아이템 추천, 콘텐츠 기반 병행, 설문으로 초기 선호 파악 |

## 핵심 정리

- 연관규칙: &#123;A&#125; → &#123;B&#125; 패턴 발견, 장바구니 분석에 활용
- 지지도 = A∩B 거래 / 전체 거래 (빈도)
- 신뢰도 = A∩B 거래 / A 거래 (정확도)
- 향상도 = 신뢰도 / P(B): 1 초과이면 양의 연관, 1 이하이면 독립 이하
- Apriori: 최소 지지도로 가지치기 → 빈번 항목 집합 → 연관규칙 생성
- 협업 필터링: 유사 사용자/아이템 행동 기반 추천, 콜드 스타트 문제 있음
- 콘텐츠 기반: 아이템 속성 매칭, 새 아이템 추천 가능
- 행렬 분해(SVD, ALS): 사용자-아이템 행렬 저차원 분해
