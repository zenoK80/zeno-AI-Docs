- [ ] SMART 원칙: Specific·Measurable·Achievable·Relevant·Time-bound
- [ ] 분석 우선순위: 가치高+난이도低 → 1순위

### 2과목 핵심 암기

- [ ] 데이터 품질 6차원: 완전성·정확성·일관성·유효성·유일성·적시성
- [ ] 이상치 탐지: IQR 방법 → Q1-1.5×IQR ~ Q3+1.5×IQR
- [ ] 중앙값: 정렬 후 가운데 값 (짝수개면 두 중간값 평균)
- [ ] 표본분산: Σ(xi-μ)²/(n-1)
- [ ] p값 < α → 귀무가설 기각 / p값 ≥ α → 채택
- [ ] 1종 오류(α): 참인 귀무가설 기각 / 2종 오류(β): 거짓 귀무가설 채택

### 3과목 핵심 암기

- [ ] 지도학습(레이블 필요) vs 비지도학습(레이블 없음)
- [ ] 혼동행렬 4공식: 정확도·정밀도·재현율·F1
- [ ] K-means: 거리→배정→중심재계산 반복
- [ ] 연관규칙: 지지도·신뢰도·향상도 계산
- [ ] 과적합 진단: 훈련↑ 검증↓ 격차 큼
- [ ] Lasso(L1): 변수 선택 / Ridge(L2): 계수 축소
- [ ] 배깅(병렬, 분산 감소) vs 부스팅(순차, 편향 감소)
- [ ] AUC 0.5=랜덤, 1.0=완벽

### 4과목 핵심 암기

- [ ] 경영진 보고서: 1~2p, 핵심+권고
- [ ] 해석 4원칙: 의미→비교→불확실성→행동권고
- [ ] 상관≠인과 (허위 상관 주의)
- [ ] 통계적 유의≠실용적 의미 (효과 크기 함께 확인)
- [ ] 배포 3방식: REST API(실시간)·배치(주기적)·임베디드(앱내장)
- [ ] 데이터 드리프트(입력분포 변화) vs 컨셉 드리프트(관계 변화)
- [ ] A/B 테스트: 무작위 배정 + 통계 검정 + 충분한 기간
