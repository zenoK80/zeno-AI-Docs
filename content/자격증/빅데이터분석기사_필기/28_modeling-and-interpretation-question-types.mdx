## 유형별 문제 풀이

### 유형 1: 알고리즘 선택

상황을 보고 지도학습 / 비지도학습 / 강화학습을 구분하고, 적절한 알고리즘을 선택합니다.

---

**문제 1-1**

전자상거래 기업에서 고객 구매 이력 데이터가 있으나 "우수 고객", "일반 고객" 등의 레이블(정답)이 없다. 고객을 구매 패턴이 비슷한 그룹으로 나누고 싶을 때 가장 적절한 분석 방법은?

① 로지스틱 회귀 (Logistic Regression)

② 의사결정나무 (Decision Tree)

③ K-평균 군집분석 (K-means Clustering)

④ 랜덤 포레스트 (Random Forest)

**정답: ③**

**해설**: 정답 레이블이 없는 상태에서 유사한 개체끼리 묶는 작업은 **비지도학습의 군집분석**입니다. K-means는 대표적인 군집분석 알고리즘입니다. ①②④는 모두 정답 레이블이 필요한 **지도학습** 알고리즘입니다.

### 유형 2: 혼동행렬 계산

혼동행렬(Confusion Matrix)이 주어지면 정확도·정밀도·재현율·F1-Score를 직접 계산합니다.

**혼동행렬 공식 정리:**

| 지표 | 공식 |
|------|------|
| 정확도(Accuracy) | (TP + TN) / (TP + FN + FP + TN) |
| 정밀도(Precision) | TP / (TP + FP) |
| 재현율(Recall) | TP / (TP + FN) |
| F1-Score | 2 × (Precision × Recall) / (Precision + Recall) |

---

**문제 2-1**

이탈 고객 예측 모델의 혼동행렬이 다음과 같다. 정밀도(Precision)와 재현율(Recall)을 올바르게 계산한 것은?

- TP(실제 이탈, 예측 이탈) = 70
- FN(실제 이탈, 예측 정상) = 30
- FP(실제 정상, 예측 이탈) = 15
- TN(실제 정상, 예측 정상) = 85

① 정밀도 = 0.70, 재현율 = 0.70

② 정밀도 = 0.82, 재현율 = 0.70

③ 정밀도 = 0.70, 재현율 = 0.82

④ 정밀도 = 0.88, 재현율 = 0.85

**정답: ②**

**해설**:
- 정밀도 = TP / (TP + FP) = 70 / (70 + 15) = 70 / 85 ≈ **0.824 ≈ 0.82**
- 재현율 = TP / (TP + FN) = 70 / (70 + 30) = 70 / 100 = **0.70**
- 참고: 정확도 = (70 + 85) / (70 + 30 + 15 + 85) = 155 / 200 = **0.775**

### 유형 3: K-means 1회 반복 계산

K-means는 거리를 계산하여 클러스터를 재배정하고, 새로운 중심을 계산합니다.

---

**문제 3-1**

다음 조건으로 K-means 1회 반복 후 새로운 클러스터 중심을 구하시오.

- 데이터 포인트: A(1, 2), B(3, 4), C(5, 1), D(7, 3)
- K=2, 초기 중심: C1=(1, 2), C2=(7, 3)

1회 반복 후 새로운 중심으로 올바른 것은?

① C1=(2, 3), C2=(6, 2)

② C1=(3, 3), C2=(6, 2)

③ C1=(3, 7/3), C2=(6, 2)

④ C1=(2, 7/3), C2=(6, 2)

**정답: ①**

**해설 (단계별 계산)**:

**1단계: 각 점에서 C1, C2까지의 유클리드 거리 계산**

A(1,2):
- C1=(1,2)까지: √((1-1)²+(2-2)²) = 0
- C2=(7,3)까지: √((1-7)²+(2-3)²) = √(36+1) = √37 ≈ 6.08
- → **C1에 배정**

B(3,4):
- C1=(1,2)까지: √((3-1)²+(4-2)²) = √(4+4) = √8 ≈ 2.83
- C2=(7,3)까지: √((3-7)²+(4-3)²) = √(16+1) = √17 ≈ 4.12
- → **C1에 배정**

C(5,1):
- C1=(1,2)까지: √((5-1)²+(1-2)²) = √(16+1) = √17 ≈ 4.12
- C2=(7,3)까지: √((5-7)²+(1-3)²) = √(4+4) = √8 ≈ 2.83
- → **C2에 배정**

D(7,3):
- C1=(1,2)까지: √((7-1)²+(3-2)²) = √(36+1) = √37 ≈ 6.08
- C2=(7,3)까지: √((7-7)²+(3-3)²) = 0
- → **C2에 배정**

**2단계: 새로운 중심 계산**
- 새 C1 = A(1,2), B(3,4)의 평균 = ((1+3)/2, (2+4)/2) = **(2, 3)**
- 새 C2 = C(5,1), D(7,3)의 평균 = ((5+7)/2, (1+3)/2) = **(6, 2)**

### 유형 4: 연관규칙 계산

지지도, 신뢰도, 향상도를 주어진 수치로 직접 계산합니다.

| 지표 | 공식 | 의미 |
|------|------|------|
| 지지도(Support) | P(A ∩ B) = &#123;A,B&#125; 동시 구매 / 전체 거래 수 | 얼마나 자주 같이 나오는가 |
| 신뢰도(Confidence) | P(B\|A) = &#123;A,B&#125; 동시 구매 / A 구매 | A를 사면 B도 살 확률 |
| 향상도(Lift) | P(B\|A) / P(B) = 신뢰도 / P(B) | 우연 대비 얼마나 강한 연관인가 |

---

**문제 4-1**

10건의 거래 중 상품 A와 B를 함께 구매한 거래는 4건, 상품 A만 구매한 거래(B 포함)는 6건, 상품 B만 구매한 거래(A 포함)는 5건이다. 규칙 "A → B"의 신뢰도와 향상도를 올바르게 계산한 것은?

① 신뢰도 = 0.4, 향상도 = 0.8

② 신뢰도 = 0.67, 향상도 = 1.33

③ 신뢰도 = 0.8, 향상도 = 1.6

④ 신뢰도 = 0.5, 향상도 = 1.0

**정답: ②**

**해설**:
- 지지도 = 4/10 = 0.4
- 신뢰도 = P(B|A) = &#123;A,B&#125;/A = 4/6 ≈ **0.667 ≈ 0.67**
- P(B) = 5/10 = 0.5
- 향상도 = 신뢰도 / P(B) = 0.667 / 0.5 = **1.33**

향상도가 1보다 크면 A와 B 사이에 양의 연관관계가 있음을 의미합니다.

### 유형 5: 과적합 판단

---

**문제 5-1**

모델 훈련 결과가 다음과 같다. 이 상황에 대한 판단과 해결책으로 올바른 것은?

- 훈련 데이터 정확도: 0.96
- 검증 데이터 정확도: 0.61

① 과소적합(Underfitting)이며, 모델의 복잡도를 높여야 한다.

② 과적합(Overfitting)이며, 훈련 데이터를 더 추가하거나 정규화를 적용해야 한다.

③ 정상 범위이며, 그대로 배포해도 무방하다.

④ 검증 데이터가 너무 적어 신뢰할 수 없는 결과이다.

**정답: ②**

**해설**: 훈련 정확도(0.96)와 검증 정확도(0.61)의 차이가 0.35로 매우 크면 **과적합(Overfitting)** 상태입니다. 모델이 훈련 데이터에 너무 맞춰져 새로운 데이터에 일반화가 안 됩니다.

**해결책**:
- 훈련 데이터 추가
- 정규화(L1/L2) 적용
- 모델 복잡도 감소 (트리 깊이 제한, 특성 수 감소)
- 드롭아웃(신경망의 경우)
- 교차검증 활용

### 유형 6: ROC-AUC 해석

---

**문제 6-1**

ROC 곡선의 AUC(Area Under the Curve) 값에 대한 설명으로 가장 올바른 것은?

① AUC = 0.5이면 완벽한 분류기이다.

② AUC = 1.0이면 무작위 추측 수준이다.

③ AUC = 0.9이면 학습 데이터에서만 좋은 성능이다.

④ AUC = 0.5이면 무작위 추측과 동일한 수준이다.

**정답: ④**

**해설**: AUC 값의 해석:
- AUC = **0.5**: 무작위 추측과 동일 (분류 능력 없음)
- AUC = **0.7~0.8**: 허용 가능한 수준
- AUC = **0.8~0.9**: 우수한 수준
- AUC = **0.9~1.0**: 매우 우수
- AUC = **1.0**: 완벽한 분류 (실제로는 과적합 의심)

AUC는 임계값에 무관하게 모델의 전반적 분류 성능을 하나의 수치로 나타낸 것입니다.

### 유형 7: PCA(주성분 분석) 목적

---

**문제 7-1**

500개의 특성(변수)을 가진 유전자 데이터로 질병을 예측하는 모델을 만들려 한다. 학습이 너무 느리고 성능도 낮다. 이를 해결하기 위해 PCA를 적용하려 한다. PCA의 주목적으로 가장 적절한 것은?

① 데이터의 결측치를 채운다.

② 범주형 변수를 수치형으로 변환한다.

③ 분산을 최대한 보존하면서 변수 수를 줄인다.

④ 데이터를 정규 분포로 변환한다.

**정답: ③**

**해설**: PCA(Principal Component Analysis)는 **차원 축소** 기법으로, 원래 변수들의 선형 조합인 주성분을 만들어 데이터의 분산(정보)을 최대한 보존하면서 변수 수(차원)를 줄입니다. 학습 속도 향상, 다중공선성 제거, 시각화(2~3차원 표현) 등에 활용됩니다.

**주성분 수 선택 기준**: 누적 설명 분산이 80~95% 이상이 되는 지점까지의 주성분 수를 선택합니다.

### 유형 8: 모델 모니터링 용어

---

**문제 8-1**

온라인 쇼핑몰의 고객 이탈 예측 모델이 배포된 지 6개월이 지난 후, 입력으로 사용되는 고객 연령대 분포와 구매 카테고리 비중이 학습 당시와 크게 달라진 것이 탐지되었다. 이 현상을 정확하게 설명하는 용어는?

① 컨셉 드리프트(Concept Drift)

② 데이터 드리프트(Data Drift)

③ 과적합(Overfitting)

④ 샘플링 편향(Sampling Bias)

**정답: ②**

**해설**: **데이터 드리프트(Data Drift)**는 모델의 입력 데이터 분포가 시간이 지남에 따라 변화하는 현상입니다. 반면 **컨셉 드리프트(Concept Drift)**는 입력과 출력 사이의 관계(패턴) 자체가 변하는 현상입니다.

이 문제에서는 "입력 데이터의 분포"(연령대, 카테고리 비중)가 변했으므로 데이터 드리프트입니다.

## 핵심 정리

- 레이블 없는 군집 문제 → K-means (비지도학습)
- 혼동행렬: 정밀도=TP/(TP+FP), 재현율=TP/(TP+FN)
- K-means: 거리 계산 → 클러스터 배정 → 중심 재계산
- 연관규칙: 지지도=공동/전체, 신뢰도=공동/A, 향상도=신뢰도/P(B)
- 훈련↑ 검증↓ 격차 크면 → 과적합
- AUC 0.5=무작위, 1.0=완벽 (실제론 과적합 의심)
- PCA: 분산 보존 + 차원 축소
- 데이터 드리프트(입력 분포 변화) vs 컨셉 드리프트(관계 변화)
