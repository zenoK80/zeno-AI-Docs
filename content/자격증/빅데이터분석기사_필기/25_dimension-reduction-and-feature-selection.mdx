## 차원의 저주 (Curse of Dimensionality)

변수(특성)의 수, 즉 차원이 늘어날수록 발생하는 문제입니다.

| 문제 | 설명 |
|------|------|
| 데이터 희소 | 차원이 높을수록 동일한 데이터 밀도를 유지하려면 기하급수적으로 많은 데이터 필요 |
| 거리 의미 약화 | 고차원에서는 모든 점이 비슷하게 멀어져 거리 기반 알고리즘(KNN 등) 성능 저하 |
| 계산 비용 증가 | 변수 수에 비례하여 학습 시간, 메모리 증가 |
| 과적합 위험 | 변수가 많을수록 노이즈 학습 가능성 증가 |

**예시:** 1차원(선)에서 10개 구간 중 10 %를 커버하려면 1개 구간이면 됩니다. 3차원(큐브)에서 같은 비율을 커버하려면 $0.1^{1/3} \approx 0.46$ → 각 축의 46 %를 사용해야 합니다.

## PCA (주성분 분석)

### 원리

원래 변수들의 **선형 결합**으로 새로운 축(주성분, Principal Component)을 만들어 차원을 줄입니다.

- **주성분 1(PC1)**: 데이터의 분산(정보량)이 가장 큰 방향
- **주성분 2(PC2)**: PC1과 직교하는 방향 중 분산이 가장 큰 방향
- 모든 주성분은 서로 직교(uncorrelated)합니다.

> **직교(Orthogonal)란?** 기하학적으로는 "90도로 수직"이라는 뜻입니다. 통계에서는 "두 방향(변수)이 서로 아무 상관관계가 없다"는 뜻으로 확장해서 씁니다. PC1과 PC2가 직교한다는 것은, 이 두 축이 서로 겹치지 않는 완전히 다른 정보를 담고 있다는 의미입니다.

### 과정

1. 데이터 표준화(평균 0, 표준편차 1로 스케일링)
2. 공분산 행렬 계산
3. 고유값(eigenvalue)과 고유벡터(eigenvector) 계산
4. 고유값이 큰 순서로 주성분 선택
5. 선택된 주성분으로 데이터 변환

### 공분산 행렬, 고유벡터·고유값이 뭔가?

이 세 용어는 PCA를 처음 볼 때 가장 낯선 부분입니다. 수식 없이 개념만 이해해도 시험과 실무에 충분합니다.

- **공분산 행렬(Covariance Matrix)**: 모든 변수 쌍이 "함께 얼마나 같이 움직이는지"를 표로 정리한 것입니다. 예를 들어 "키와 몸무게"처럼 두 변수가 같은 방향으로 함께 커지는 경향이 있으면 공분산이 양수입니다. 변수가 5개면 5×5 크기의 표가 됩니다.

- **고유벡터(Eigenvector)**: 데이터를 이 공분산 행렬로 "회전·변형"시켜도 **방향이 바뀌지 않는 특별한 방향**입니다. PCA에서는 이 방향들이 곧 "데이터가 가장 넓게 퍼져 있는 축(주성분의 방향)"이 됩니다.

- **고유값(Eigenvalue)**: 그 고유벡터 방향으로 데이터가 얼마나 넓게 퍼져 있는지(분산의 크기)를 나타내는 숫자입니다. 고유값이 클수록 그 방향에 정보(분산)가 많이 담겨 있다는 뜻입니다.

> **비유:** 럭비공을 아무렇게나 던져서 바닥에 떨어뜨렸다고 합시다. 공의 흔적(그림자)이 가장 길게 늘어난 방향이 "가장 중요한 축"(첫 번째 고유벡터)이고, 그 길이가 "고유값"입니다. PCA는 이 가장 긴 방향부터 순서대로 축을 찾아내는 과정입니다.

이 과정을 사람이 손으로 계산하지는 않습니다. 통계 소프트웨어(Python의 scikit-learn 등)가 자동으로 계산해 줍니다. 시험에서는 "고유값이 큰 순서대로 주성분을 선택한다"는 **개념과 순서**를 아는 것이 중요합니다.

### 주성분 수 선택: 누적 설명 분산 비율

| 주성분 | 설명 분산 비율 | 누적 설명 분산 |
|--------|----------------|----------------|
| PC1 | 45 % | 45 % |
| PC2 | 25 % | 70 % |
| PC3 | 15 % | 85 % ← 여기서 선택(80~90 %) |
| PC4 | 8 % | 93 % |
| PC5 | 7 % | 100 % |

누적 설명 분산 비율이 **80~90 %**에 도달하는 주성분 수를 선택합니다.

### 장단점

| 장점 | 단점 |
|------|------|
| 차원 감소로 연산 효율화 | 새 변수(주성분) 해석이 어려움 |
| 다중 공선성 제거 | 비선형 관계 포착 불가 |
| 시각화(2D~3D) 가능 | 원래 변수와의 연결 단절 |

### t-SNE

고차원 데이터를 **2~3차원으로 축소**하여 군집 패턴을 시각화하는 기법입니다.

- 비선형 방법: PCA와 달리 복잡한 구조 포착 가능
- **시각화 전용**: 예측 모델 입력으로 사용하기 어려움
- 실행할 때마다 결과가 달라질 수 있음 (비결정적)

## 변수 선택 (Feature Selection)

모델 성능에 기여하는 변수만 선택하여 불필요한 변수를 제거합니다.

### 세 가지 방법 비교

| 방법 | 원리 | 장점 | 단점 | 예시 |
|------|------|------|------|------|
| 필터(Filter) | 통계적 측도로 변수 독립 평가 | 빠름, 모델 무관 | 변수 간 상호작용 무시 | 상관계수, 카이제곱 검정, 분산 분석 |
| 래퍼(Wrapper) | 변수 부분집합을 모델로 직접 평가 | 상호작용 고려 | 계산 비용 큼 | 전진 선택, 후진 제거, 단계별 선택 |
| 내장(Embedded) | 모델 학습 시 중요도 자동 산출 | 효율적, 상호작용 고려 | 특정 모델에 종속 | Lasso(L1), RF Feature Importance |

### 필터 방법 측도

| 측도 | 변수 유형 | 사용 상황 |
|------|-----------|-----------|
| 피어슨 상관계수 | 수치-수치 | 선형 관계 |
| 카이제곱 검정 | 범주-범주 | 독립성 검정 |
| ANOVA (F-검정) | 범주-수치 | 집단 간 평균 차이 |
| 정보 이득 | 수치·범주 | 엔트로피 감소량 |

### 래퍼 방법 종류

- **전진 선택(Forward Selection)**: 변수 없음에서 시작 → 성능 가장 높이는 변수 순서대로 추가
- **후진 제거(Backward Elimination)**: 전체 변수에서 시작 → 성능 가장 적게 낮추는 변수 순서대로 제거
- **단계별 선택(Stepwise)**: 전진+후진 혼합 → 추가 후 불필요 변수 제거도 반복

### 변수 중요도

#### 랜덤 포레스트 Feature Importance

각 변수가 분기 시 불순도를 평균적으로 얼마나 감소시키는지 측정합니다.

$$\text{Feature Importance}_j = \frac{\sum \text{불순도 감소량}(j)}{전체 불순도 감소량}$$

#### Permutation Importance

변수의 값을 무작위로 섞었을 때 모델 성능이 얼마나 떨어지는지 측정합니다.

- 성능 감소가 클수록 중요한 변수
- 모델에 무관하게 적용 가능

## 파생변수 (Feature Engineering)

기존 변수를 조합하거나 변환하여 새 변수를 생성합니다.

| 예시 | 방법 |
|------|------|
| 가입 기간 + 나이 → 가입 연령 비율 | 나누기 |
| 날짜 → 요일, 월, 분기 | 파생 |
| 키, 몸무게 → BMI | 공식 적용 |
| 로그 변환 | 오른쪽 치우친 분포 정규화 |
| 이진화 | 임계값 기준 0/1 변환 |

## 핵심 정리

- 차원의 저주: 차원↑ → 데이터 희소, 거리 의미 약화, 계산 비용↑, 과적합 위험↑
- PCA: 공분산 최대화 방향으로 주성분 생성, 주성분들은 직교, 누적 설명 분산 80~90 %로 주성분 수 선택
- t-SNE: 비선형 차원 축소, 시각화 전용
- 필터 방법: 통계적 측도로 독립 평가 (빠름), 래퍼 방법: 모델로 평가 (정확, 느림), 내장 방법: 학습 시 자동 산출 (Lasso, RF)
- 변수 중요도: RF 불순도 감소량, Permutation Importance
