## 의사결정나무 구조

의사결정나무는 데이터를 조건에 따라 반복적으로 분기하여 예측을 수행합니다.

```
루트 노드(Root Node): 전체 데이터 시작점
  ├── 분기 노드(Internal Node): 조건 판단 (예: 나이 >= 30?)
  │     ├── 예 → 분기 노드 또는 잎 노드
  │     └── 아니오 → 분기 노드 또는 잎 노드
  └── 잎 노드(Leaf/Terminal Node): 최종 예측값 (클래스 또는 수치)
```

- **깊이(Depth)**: 루트에서 잎까지의 단계 수. 깊을수록 복잡도↑
- **가지치기(Pruning)**: 과적합 방지를 위해 불필요한 가지 제거

## 분할 기준: 불순도 측정

어떤 조건으로 분기할지는 **불순도(Impurity)**를 얼마나 줄이는지로 결정합니다.

### 지니 지수(Gini Index)

$$Gini = 1 - \sum_{k=1}^{K} p_k^2$$

- $p_k$: 클래스 k의 비율
- 순수할수록 0에 가까움, 완전 불순(50:50)이면 0.5

**예시: 2클래스 [6, 4] (클래스 A 6개, 클래스 B 4개, 총 10개)**

$$p_A = 0.6, \quad p_B = 0.4$$
$$Gini = 1 - (0.6^2 + 0.4^2) = 1 - (0.36 + 0.16) = 1 - 0.52 = 0.48$$

순수 노드 [10, 0]:
$$Gini = 1 - (1^2 + 0^2) = 1 - 1 = 0 \quad \text{(완전 순수)}$$

### 엔트로피(Entropy)

$$H = -\sum_{k=1}^{K} p_k \log_2 p_k$$

- 순수할수록 0, 완전 불순이면 최대값
- 지니 지수와 유사하게 작동, 계산이 약간 더 복잡

**같은 예시 [6, 4]:**

$$H = -(0.6 \log_2 0.6 + 0.4 \log_2 0.4) = -(0.6 \times (-0.737) + 0.4 \times (-1.322)) \approx 0.971$$

### 정보 이득(Information Gain)

$$IG = \text{분할 전 불순도} - \sum_{\text{자식}} \frac{n_{\text{자식}}}{n_{\text{부모}}} \times \text{자식 불순도}$$

- 정보 이득이 가장 큰 분기 조건을 선택합니다.

### 장단점

| 장점 | 단점 |
|------|------|
| 결과 해석이 쉬움 (트리 시각화) | 과적합이 쉬움 (분산 큼) |
| 수치·범주 변수 모두 처리 | 데이터 변화에 민감 |
| 스케일링·정규화 불필요 | 선형 관계를 비효율적으로 표현 |
| 비선형 관계와 상호작용 포착 | 가지치기 파라미터 조정 필요 |

## 앙상블 기법

여러 개의 약한 모델(weak learner)을 결합하여 더 강한 모델을 만드는 기법입니다.

### 기법 비교 표

| 기법 | 학습 방식 | 결합 방식 | 목표 | 대표 알고리즘 |
|------|-----------|-----------|------|---------------|
| 배깅(Bagging) | 부트스트랩 샘플 → 독립 병렬 학습 | 다수결/평균 | 분산 감소 | 랜덤 포레스트 |
| 부스팅(Boosting) | 이전 오류에 가중치 → 순차 학습 | 가중 합산 | 편향 감소 | AdaBoost, GBM, XGBoost, LightGBM |
| 스태킹(Stacking) | 다양한 모델 병렬 학습 | 메타 모델 입력 | 편향+분산 감소 | - |

### 배깅(Bagging)

**Bootstrap Aggregating**의 약자입니다.

1. 원본 데이터에서 **복원 추출(부트스트랩)**으로 N개 샘플 생성
2. 각 샘플로 독립적인 모델 학습 (병렬 가능)
3. 분류: 다수결, 회귀: 평균으로 최종 예측

### 랜덤 포레스트(Random Forest)

배깅에 **무작위 변수 선택**을 추가합니다.

- 각 분기마다 전체 변수 중 일부(보통 $\sqrt{p}$개)만 고려
- 나무 간 상관관계 감소 → 더 강한 분산 감소 효과
- 변수 중요도(Feature Importance) 제공

### 부스팅(Boosting)

이전 모델이 틀린 샘플에 더 집중하여 순차적으로 학습합니다.

```
모델 1 학습 → 오류 확인 → 오류 샘플에 가중치↑ → 모델 2 학습 → ...
```

| 알고리즘 | 특징 |
|----------|------|
| AdaBoost | 오분류 샘플의 가중치 증가 |
| Gradient Boosting (GBM) | 이전 잔차(residual)를 예측하도록 학습 |
| XGBoost | GBM + 정규화 + 병렬화 → 빠르고 강력 |
| LightGBM | 리프 중심 트리 성장, 대용량 데이터에 빠름 |

### 스태킹(Stacking)

1. **1단계(Base Learners):** 다양한 모델(KNN, 나이브 베이즈, SVM 등) 학습 → 예측값 생성
2. **2단계(Meta Learner):** 1단계 예측값을 새로운 입력으로 메타 모델 학습

```
원본 데이터 → [모델 A 예측], [모델 B 예측], [모델 C 예측]
                    ↓           ↓           ↓
               [메타 모델에 입력 → 최종 예측]
```

## 핵심 정리

- 의사결정나무: 루트→분기→잎 구조, 불순도 감소 방향으로 분기
- 지니 지수: $1 - \sum p_k^2$ (CART 사용), 엔트로피: $-\sum p_k \log_2 p_k$ (ID3/C4.5 사용)
- 과적합 완화: 가지치기(Pruning), max_depth 제한, min_samples 제한
- 배깅: 부트스트랩 샘플 + 병렬 학습 → 분산 감소
- 랜덤 포레스트: 배깅 + 무작위 변수 선택 → 나무 간 상관 감소
- 부스팅: 순차 학습, 이전 오류에 집중 → 편향 감소 (XGBoost, LightGBM)
- 스태킹: 1단계 다양한 모델 + 2단계 메타 모델
