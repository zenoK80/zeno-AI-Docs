## 파라미터 vs 하이퍼파라미터

| 구분 | 결정 방식 | 예시 |
|------|-----------|------|
| **파라미터**(Parameter) | 모델 학습으로 자동 결정 | 회귀 계수 $b_0, b_1$, 신경망 가중치 $w$ |
| **하이퍼파라미터**(Hyperparameter) | 사람이 학습 전에 설정 | K(이웃 수), max_depth, 학습률, C(SVM) |

<Callout type="warning">
  **핵심 구별:** 파라미터는 데이터가 결정합니다. 하이퍼파라미터는 사람이 결정하고, 데이터로 최적화합니다(하이퍼파라미터 튜닝).
</Callout>

## 알고리즘별 주요 하이퍼파라미터

| 알고리즘 | 하이퍼파라미터 | 역할 |
|----------|----------------|------|
| KNN | K (이웃 수) | 작으면 과적합, 크면 과소적합 |
| 의사결정나무 | max_depth | 트리 최대 깊이, 클수록 복잡 |
| 의사결정나무 | min_samples_split | 분기 최소 샘플 수, 클수록 단순 |
| 랜덤 포레스트 | n_estimators | 트리 수, 많을수록 안정적 |
| 랜덤 포레스트 | max_features | 각 분기에서 고려할 변수 수 |
| SVM | C | 마진-오분류 트레이드오프 |
| SVM (RBF) | gamma (γ) | 영향 범위, 클수록 복잡한 경계 |
| 신경망 | learning_rate | 학습률, 너무 크면 발산 |
| 신경망 | epochs | 전체 데이터 반복 학습 횟수 |
| 신경망 | batch_size | 한 번에 학습하는 샘플 수 |
| 신경망 | n_layers | 은닉층 수 |

## 하이퍼파라미터 탐색 방법

### Grid Search (격자 탐색)

지정한 하이퍼파라미터 값 조합을 **모두 탐색**합니다.

**예시:** K=[1,3,5], C=[0.1, 1, 10] → 3×3 = 9가지 조합 모두 평가

| 장점 | 단점 |
|------|------|
| 지정 범위 내 최적값 보장 | 조합 수가 많아지면 계산 비용 폭발 |
| 재현성 보장 | 범위 밖 최적값 탐색 불가 |

### Random Search (무작위 탐색)

지정한 분포에서 **무작위로 샘플링**하여 탐색합니다.

| 장점 | 단점 |
|------|------|
| Grid Search보다 빠름 | 최적값 보장 없음 |
| 넓은 범위 탐색 가능 | 재현성이 seed에 의존 |
| 연속값 파라미터에 유리 | |

**연구 결과:** 랜덤 탐색이 동일 계산 예산에서 격자 탐색보다 더 나은 결과를 내는 경우가 많습니다.

### Bayesian Optimization (베이즈 최적화)

이전 탐색 결과를 기반으로 **다음 탐색 지점을 스마트하게 선택**합니다.

```
1. 초기 몇 개 랜덤 탐색
2. 결과로 대리 모델(Surrogate Model) 구축
3. 대리 모델이 유망한 지점 예측
4. 해당 지점 탐색 → 대리 모델 업데이트
5. 반복
```

| 장점 | 단점 |
|------|------|
| 적은 평가 횟수로 좋은 결과 | 구현 복잡도 높음 |
| 이전 경험을 활용 | 병렬화가 어려움 |

### 세 방법 비교

| 방법 | 탐색 방식 | 계산 비용 | 적합 상황 |
|------|-----------|-----------|-----------|
| Grid Search | 모든 조합 | 높음 (파라미터 수 증가 시 폭발) | 파라미터 수 적고 값 범위 좁을 때 |
| Random Search | 무작위 샘플링 | 중간 | 파라미터 수 많고 빠른 탐색 필요 |
| Bayesian Optimization | 이전 결과 활용 스마트 탐색 | 낮음 (효율적) | 평가 비용이 매우 클 때 |

## 모델 선택 기준

| 기준 | 고려 사항 |
|------|-----------|
| 성능 | 교차검증 AUC, F1, RMSE 등 |
| 해석 가능성 | 선형 모델 > 트리 > 앙상블 > 딥러닝 |
| 학습 속도 | 나이브 베이즈 > 선형 모델 > 트리 > 딥러닝 |
| 예측 속도 | 선형 모델 > 나이브 베이즈 > 트리 > KNN |
| 데이터 크기 | 딥러닝은 대용량 필요, 나이브 베이즈는 소규모도 효과적 |

## 학습 곡선 (Learning Curve)

학습 데이터 수 또는 학습 반복 횟수에 따른 성능 변화를 시각화합니다.

### 과소적합 패턴

```
성능 ↑
      │ 학습 ──────────── (낮음)
      │ 검증 ─────────── (낮음, 유사)
      └──────────────────→ 학습 데이터 수
```

- 학습·검증 성능 모두 낮음
- 해결: 모델 복잡도 증가, 특성 추가, 차수 높이기

### 과적합 패턴

```
성능 ↑
      │ 학습 ─────────── (높음)
      │
      │ 검증    ╲_______  (낮음, 수렴)
      └──────────────────→ 학습 데이터 수
```

- 학습 성능은 높고 검증 성능은 낮음, 갭이 큼
- 해결: 정규화 강화, 데이터 추가, 모델 단순화

## 스태킹 (Stacking)

### 개념

여러 1단계 모델(Base Learners)의 예측값을 2단계 메타 모델(Meta Learner)의 입력으로 사용합니다.

### 올바른 스태킹 방법

데이터 누수를 방지하기 위해 **학습하지 않은 데이터**에서 1단계 예측값을 생성합니다.

```
학습 데이터 → [K-Fold 교차 예측]
                  ↓
         1단계 예측값 (메타 특성)
                  ↓
         메타 모델 학습
                  ↓
         테스트 데이터 → 1단계 모델 예측 → 메타 모델 → 최종 예측
```

| 1단계 모델 | 예측값(메타 특성) |
|------------|------------------|
| 로지스틱 회귀 | [0.7, 0.3, 0.8, ...] |
| 랜덤 포레스트 | [0.65, 0.4, 0.75, ...] |
| SVM | [0.72, 0.28, 0.82, ...] |
| **메타 모델 입력** | **위 3열을 입력으로 최종 예측** |

## 핵심 정리

- 파라미터: 학습이 결정 (회귀 계수, 가중치) / 하이퍼파라미터: 사람이 설정 (K, depth, 학습률)
- Grid Search: 전체 조합 탐색, 작은 범위에 적합
- Random Search: 무작위 샘플링, 빠르고 넓은 범위 탐색
- Bayesian Optimization: 이전 결과 활용, 효율적이지만 구현 복잡
- 학습 곡선: 학습·검증 모두 낮음 = 과소적합, 학습 높음·검증 낮음 = 과적합
- 스태킹: 1단계 다양한 모델 → 2단계 메타 모델, K-Fold로 데이터 누수 방지
