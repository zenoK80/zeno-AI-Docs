## KNN (K-최근접 이웃)

### 원리

새로운 데이터 포인트로부터 **거리가 가까운 K개의 이웃**을 찾아 예측합니다.

- **분류**: K개 이웃의 다수결 (가장 많은 클래스)
- **회귀**: K개 이웃 값의 평균

### 거리 측도

| 측도 | 공식 | 특징 |
|------|------|------|
| 유클리드(Euclidean) | $\sqrt{\sum(x_i - y_i)^2}$ | 가장 일반적, 직선 거리 |
| 맨해튼(Manhattan) | $\sum\|x_i - y_i\|$ | 격자 이동 거리, 이상치에 덜 민감 |
| 코사인(Cosine) | $1 - \frac{x \cdot y}{\|x\|\|y\|}$ | 방향 유사도, 텍스트 분류에 유용 |

### K 선택과 K=3 예시

**5개 데이터 포인트, 새 점 P(5, 5)까지의 유클리드 거리:**

| 점 | 좌표 | 거리 | 클래스 |
|---|------|------|--------|
| A | (3, 4) | $\sqrt{4+1}=2.24$ | 양성 |
| B | (6, 4) | $\sqrt{1+1}=1.41$ | 양성 |
| C | (7, 7) | $\sqrt{4+4}=2.83$ | 음성 |
| D | (4, 7) | $\sqrt{1+4}=2.24$ | 음성 |
| E | (8, 5) | $\sqrt{9+0}=3.00$ | 음성 |

K=3일 때: B(1.41), A(2.24), D(2.24)가 가장 가까운 3개
→ 양성 2개, 음성 1개 → **다수결: 양성으로 분류**

### K 값과 모델 특성

| K 값 | 특성 | 위험 |
|------|------|------|
| 작음 (K=1~3) | 복잡한 경계, 노이즈에 민감 | 과적합 |
| 적당 (K=5~20) | 균형 잡힌 경계 | 교차검증으로 선택 |
| 큼 (K=50+) | 매우 부드러운 경계 | 과소적합 |

### 단점과 주의사항

- **차원의 저주**: 차원이 높아질수록 거리의 의미가 약해짐 → 차원 축소 필요
- **느린 예측**: 예측마다 전체 데이터와 거리 계산 (O(n))
- **정규화 필수**: 변수 단위가 다르면 거리가 왜곡됨 (예: 나이 vs 연봉)
- 메모리 요구량이 큼 (전체 학습 데이터를 저장)

## 나이브 베이즈(Naive Bayes)

### 베이즈 정리

$$P(C|X) = \frac{P(X|C) \cdot P(C)}{P(X)} \propto P(X|C) \cdot P(C)$$

$\propto$("비례 기호")는 "~에 비례한다"는 뜻입니다. 분모의 $P(X)$는 어떤 클래스든 상관없이 값이 똑같으므로(클래스를 비교할 때는 무시해도 대소 관계가 바뀌지 않으므로), 실제 계산에서는 분모를 생략하고 분자끼리만 비교해도 충분합니다. 그래서 "정확히 같다(=)"가 아니라 "비례한다($\propto$)"고 표현합니다.

- $P(C)$: 사전 확률 (클래스 비율)
- $P(X|C)$: 가능도 (클래스 C에서 특성 X가 나올 확률)
- $P(C|X)$: 사후 확률 (특성 X를 봤을 때 클래스 C일 확률)

### "나이브"의 의미

각 특성이 **서로 조건부 독립**이라고 가정합니다.

$$P(X|C) = P(x_1|C) \cdot P(x_2|C) \cdots P(x_p|C)$$

현실에서는 독립이 아닌 경우가 많지만, 이 단순 가정 덕분에 계산이 매우 빠릅니다.

### 스팸 분류 예시

5통 이메일 중 스팸 3통, 정상 2통 (사전 확률: P(스팸)=0.6, P(정상)=0.4)

학습 데이터에서 단어 "무료" 등장 빈도:
- P("무료"|스팸) = 2/3 ≈ 0.667
- P("무료"|정상) = 0/2 = 0 (라플라스 스무딩 필요 → 0+1 처리)

새 이메일에 "무료"가 있을 때:
$$P(\text{스팸}|\text{무료}) \propto 0.667 \times 0.6 = 0.400$$
$$P(\text{정상}|\text{무료}) \propto 0.0 \times 0.4 = 0.0 \quad \text{(스무딩 없이)}$$

→ 스팸으로 분류

### 장단점

| 장점 | 단점 |
|------|------|
| 계산이 매우 빠름 | 독립 가정이 현실과 다를 수 있음 |
| 소규모 데이터에서도 효과적 | 특성 간 상관관계 무시 |
| 텍스트 분류(스팸, 감성 분석)에 강함 | 확률값 자체는 부정확할 수 있음 |
| 새로운 데이터 빠르게 업데이트 | 연속 변수 처리 시 분포 가정 필요 |

## SVM (서포트 벡터 머신)

### 핵심 개념

두 클래스를 가장 넓은 **마진**(Margin)으로 분리하는 **결정 초평면**(Hyperplane)을 찾습니다.

```
클래스 A (+):  ○ ○   ○
                   |← 마진 →|
클래스 B (-):         × × ×
              ▲             ▲
         서포트 벡터    서포트 벡터
```

- **서포트 벡터**: 결정 경계에 가장 가까운 데이터 포인트들
- **마진**: 두 클래스의 서포트 벡터 사이의 거리
- 마진을 최대화하는 초평면을 찾는 것이 SVM의 목표

### 커널 트릭(Kernel Trick)

선형 분리가 불가능한 데이터를 **고차원 공간으로 변환**한 뒤 분리합니다.

| 커널 | 공식 | 사용 상황 |
|------|------|-----------|
| 선형(Linear) | $x \cdot x'$ | 선형 분리 가능할 때 |
| 다항식(Polynomial) | $(x \cdot x' + c)^d$ | 곡선 경계 |
| RBF(가우시안) | $e^{-\gamma\|x-x'\|^2}$ | 가장 많이 사용, 비선형 복잡 경계 |

### 주요 하이퍼파라미터

| 파라미터 | 역할 | 작은 값 | 큰 값 |
|----------|------|---------|-------|
| C | 마진-오분류 트레이드오프 | 넓은 마진, 일부 오분류 허용 (일반화) | 좁은 마진, 오분류 최소화 (과적합 위험) |
| γ (gamma, RBF) | 영향 범위 | 넓은 범위 영향, 부드러운 경계 | 좁은 범위 영향, 복잡한 경계 (과적합) |

- C 작음 + γ 작음: 과소적합 위험
- C 큼 + γ 큼: 과적합 위험

## 세 알고리즘 비교

| 항목 | KNN | 나이브 베이즈 | SVM |
|------|-----|--------------|-----|
| 학습 시간 | 빠름 (저장만) | 매우 빠름 | 느림 (대용량에서) |
| 예측 시간 | 느림 | 빠름 | 빠름 |
| 해석 가능성 | 중간 | 높음 | 낮음 |
| 고차원 성능 | 낮음 (차원의 저주) | 높음 | 높음 |
| 주요 가정 | 없음 | 조건부 독립 | 마진 최대화 |

## 핵심 정리

- KNN: K개 이웃의 다수결(분류)/평균(회귀), K 작으면 과적합, K 크면 과소적합, 정규화 필수
- 나이브 베이즈: $P(C|X) \propto P(X|C) \cdot P(C)$, 조건부 독립 가정, 텍스트 분류에 강함
- SVM: 마진 최대화 초평면, 서포트 벡터가 경계 결정, 커널 트릭으로 비선형 처리
- RBF 커널이 가장 많이 사용됨; C(마진↔오분류), γ(영향 범위) 파라미터 조정
