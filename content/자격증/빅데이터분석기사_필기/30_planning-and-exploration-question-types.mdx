### 유형 2: 데이터 품질 차원

데이터 품질 6개 차원을 상황에 맞게 구분할 수 있어야 합니다.

| 차원 | 의미 | 질문 |
|------|------|------|
| 완전성(Completeness) | 필수 필드에 값이 존재하는가 | "결측치가 얼마나 많은가?" |
| 정확성(Accuracy) | 실제 값을 올바르게 반영하는가 | "잘못 입력된 값은 없는가?" |
| 일관성(Consistency) | 여러 시스템 간 값이 동일한가 | "A 시스템과 B 시스템의 값이 다르다" |
| 유효성(Validity) | 정해진 형식·범위를 따르는가 | "날짜 형식이 제각각이다" |
| 유일성(Uniqueness) | 동일 레코드 중복이 없는가 | "같은 고객이 두 번 등록되어 있다" |
| 적시성(Timeliness) | 필요한 시점에 데이터가 제공되는가 | "보고서 작성 후에야 데이터가 들어온다" |

### 유형 3: 비식별화 기법 구분

| 기법 | 설명 | 예시 |
|------|------|------|
| 가명처리(Pseudonymization) | 식별 정보를 다른 값으로 대체 | 홍길동 → ID_A1234 |
| 마스킹(Masking) | 일부 문자를 대체 문자로 가림 | 010-1234-5678 → 010-****-5678 |
| 집계(Aggregation) | 개인 단위를 집단 단위로 변환 | 나이 28세 → 20대 |
| 범주화(Generalization) | 구체적 값을 범주로 변환 | 서울시 강남구 → 서울 |
| 삭제(Suppression) | 식별 가능 데이터 자체를 제거 | 주민번호 컬럼 삭제 |

## 핵심 정리

- 분석 과제: 대상 + 방법 + 측정 기준 3박자 갖춰야 함
- 데이터 품질 6차원: 완전성·정확성·일관성·유효성·유일성·적시성
- 비식별화 5기법: 가명처리·마스킹·집계·범주화·삭제
- CRISP-DM 순서: 비즈니스 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 배포
- p값 < α → 귀무가설 기각 / p값 ≥ α → 귀무가설 채택
- 범주형 결측치 → 최빈값 또는 '미응답' 범주 신설
