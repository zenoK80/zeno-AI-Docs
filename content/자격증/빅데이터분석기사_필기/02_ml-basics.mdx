## 머신러닝이란?

머신러닝(Machine Learning, ML)은 **데이터로부터 패턴을 학습해 새로운 데이터에 대한 예측이나 분류를 수행하는 기술**입니다. 사람이 규칙을 직접 프로그래밍하지 않아도 됩니다.

> **쉽게 말하면:** "고양이 사진 10만 장을 보여주면 스스로 고양이 특징을 찾아내는 것"이 머신러닝입니다.

**전통적 프로그래밍 vs 머신러닝:**

| 구분 | 전통적 프로그래밍 | 머신러닝 |
|------|----------------|--------|
| 입력 | 데이터 + 규칙 | 데이터 + 정답 |
| 출력 | 결과 | 규칙(모델) |

---

## 학습 유형 3가지

### 1. 지도학습 (Supervised Learning)

**정답(레이블, Label)이 있는 데이터**로 학습합니다.

- **분류(Classification)**: 이메일이 스팸인가 아닌가?
- **회귀(Regression)**: 집값은 얼마일까?

입력 $X$와 정답 $y$를 함께 학습해, 새로운 $X$가 주어졌을 때 $y$를 예측합니다.

### 2. 비지도학습 (Unsupervised Learning)

**정답 없이** 데이터 안의 패턴을 찾습니다.

- **군집(Clustering)**: 고객을 비슷한 그룹으로 묶기
- **차원 축소**: 고차원 데이터를 낮은 차원으로 압축
- **이상치 탐지**: 정상 패턴에서 벗어난 거래 찾기

### 3. 강화학습 (Reinforcement Learning)

환경과 상호작용하며 **보상을 최대화하는 행동 전략**을 학습합니다. 게임 AI, 로봇 제어에 사용됩니다.

| 유형 | 정답 필요 여부 | 주요 알고리즘 |
|------|-------------|-------------|
| 지도학습 | 필요 | 선형회귀, 의사결정나무, SVM |
| 비지도학습 | 불필요 | K-means, PCA |
| 강화학습 | 보상 신호 | Q-Learning, DQN |

## 훈련, 검증, 테스트 분할

모델이 새로운 데이터에도 잘 작동하는지 확인하려면 **데이터를 미리 나눠야** 합니다.

```
전체 데이터 100%
  ├── 훈련 세트 (Train) — 70%: 모델 학습에 사용
  ├── 검증 세트 (Validation) — 15%: 하이퍼파라미터 튜닝
  └── 테스트 세트 (Test) — 15%: 최종 성능 평가
```

- **훈련(Train)**: 모델이 패턴을 학습하는 데이터
- **검증(Validation)**: 하이퍼파라미터(모델 설정값)를 조정하며 최적 모델 선택
- **테스트(Test)**: 학습 과정에 전혀 관여하지 않은 데이터로 최종 성능 측정

<Callout type="warning">
  테스트 세트는 최종 평가에만 사용합니다. 테스트 결과를 보고 모델을 수정하면 "시험지를 미리 본" 것과 같습니다.
</Callout>

---

## 과적합과 과소적합

### 과적합 (Overfitting)

모델이 훈련 데이터에만 너무 잘 맞춰져서, 새로운 데이터에 제대로 작동하지 않는 상태입니다.

> **비유:** 시험 기출문제만 달달 외워서 새로운 유형이 나오면 못 푸는 것.

- 훈련 정확도: 매우 높음 / 검증 정확도: 낮음

### 과소적합 (Underfitting)

모델이 너무 단순해서 데이터의 패턴조차 제대로 학습하지 못한 상태입니다.

- 훈련 정확도: 낮음 / 검증 정확도: 낮음

```
          과소적합     적절    과적합
훈련 오류  [높음]      [낮음]  [매우 낮음]
검증 오류  [높음]      [낮음]  [높음]
```

---

## 특성(Feature)과 레이블(Label)

- **특성(Feature, 입력 변수)**: 모델이 학습에 사용하는 입력값. 열(Column)에 해당.
  - 예: 나이, 소득, 거주 지역 → 대출 승인 여부 예측
- **레이블(Label, 목표 변수)**: 예측하거나 분류하려는 출력값.
  - 예: 승인(1) / 거절(0)

---

## 하이퍼파라미터 vs 파라미터

| 구분 | 설명 | 예시 |
|------|------|------|
| **파라미터** | 학습을 통해 데이터에서 자동으로 결정 | 회귀의 계수(가중치) |
| **하이퍼파라미터** | 학습 전에 사람이 설정해야 하는 값 | 의사결정나무의 깊이, 학습률 |

---

## 핵심 정리

- **지도학습**: 정답 있는 데이터로 학습. 분류·회귀.
- **비지도학습**: 정답 없이 패턴 탐색. 군집·차원 축소.
- **훈련/검증/테스트 분할**: 모델이 새 데이터에도 잘 작동하는지 평가.
- **과적합**: 훈련 성능 높지만 새 데이터에서 낮음. 너무 복잡한 모델.
- **과소적합**: 훈련/검증 모두 낮음. 너무 단순한 모델.
- **파라미터**: 데이터로 학습. **하이퍼파라미터**: 사람이 설정.
