## 셸 스크립트 기본

```bash
#!/bin/bash
# 첫 줄: 인터프리터 지정 (shebang)
# #으로 시작하는 줄은 주석

echo "Hello, World!"
```

## 변수

```bash
# 변수 대입 (= 양쪽에 공백 없음!)
name="홍길동"
age=25

# 변수 사용
echo "이름: $name"
echo "나이: ${age}세"

# 읽기 전용
readonly PI=3.14

# 환경 변수
export PATH="$PATH:/usr/local/bin"

# 명령 치환
today=$(date +%Y-%m-%d)
files=$(ls -l | wc -l)
```

## 조건문

```bash
# if-elif-else
if [ "$age" -ge 18 ]; then
    echo "성인입니다."
elif [ "$age" -ge 13 ]; then
    echo "청소년입니다."
else
    echo "어린이입니다."
fi

# 비교 연산자
# 숫자: -eq, -ne, -gt, -ge, -lt, -le
# 문자열: =, !=, -z(빈 문자열), -n(비어 있지 않음)
# 파일: -f(파일 존재), -d(디렉토리), -r(읽기 가능)

# case 문
case "$day" in
    "Mon") echo "월요일" ;;
    "Fri") echo "금요일" ;;
    *) echo "다른 날" ;;
esac
```

## 반복문

```bash
# for 문
for i in 1 2 3 4 5; do
    echo "번호: $i"
done

# C 스타일 for
for ((i=1; i<=5; i++)); do
    echo $i
done

# while 문
count=1
while [ $count -le 5 ]; do
    echo "count: $count"
    ((count++))
done

# until 문 (조건이 거짓인 동안 반복)
until [ $count -gt 5 ]; do
    echo $count
    ((count++))
done
```

## 함수

```bash
# 함수 정의
greet() {
    local name=$1    # 첫 번째 인수
    echo "안녕하세요, $name!"
}

# 함수 호출
greet "홍길동"

# 반환값 (exit status만 반환 가능)
add() {
    result=$(( $1 + $2 ))
    echo $result
}
sum=$(add 3 5)
echo "합계: $sum"    # 합계: 8
```

## 배열

```bash
arr=("사과" "바나나" "포도")
echo ${arr[0]}        # 사과
echo ${arr[@]}        # 전체 요소
echo ${#arr[@]}       # 배열 길이 3

# 배열 순회
for fruit in "${arr[@]}"; do
    echo $fruit
done
```

## 핵심 정리

- 변수 대입 시 = 양쪽에 공백 없어야 함
- 조건문 `[ ]` 안에 공백 필요
- 숫자 비교: -eq/-ne/-gt/-ge/-lt/-le
- 함수 인수: $1, $2, ... / 모든 인수: $@ / 인수 수: $#
