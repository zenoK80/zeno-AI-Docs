## 포인터 (Pointer)

메모리 주소를 저장하는 변수입니다.

```c
int a = 10;
int *p = &a;   // p는 a의 주소를 저장

printf("%d\n", a);    // 10 (변수 값)
printf("%p\n", p);    // a의 메모리 주소
printf("%d\n", *p);   // 10 (역참조: 주소가 가리키는 값)
```

### 포인터 연산

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;   // 배열 첫 번째 원소를 가리킴

printf("%d\n", *p);       // 1
printf("%d\n", *(p+1));   // 2
printf("%d\n", *(p+2));   // 3
```

## 배열 (Array)

```c
int arr[5] = {10, 20, 30, 40, 50};

// 배열 순회
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}
// 출력: 10 20 30 40 50

// 문자열 배열
char str[] = "Hello";
printf("%s\n", str);   // Hello
printf("%c\n", str[0]); // H
```

## 함수 (Function)

```c
int add(int a, int b) {
    return a + b;
}

// 포인터를 매개변수로 (Call by Reference)
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

## 구조체 (Structure)

여러 자료형을 하나의 단위로 묶는 사용자 정의 자료형입니다.

```c
struct Person {
    char name[50];
    int age;
    float height;
};

struct Person p1;
p1.age = 25;
strcpy(p1.name, "홍길동");

// typedef 사용
typedef struct {
    char name[50];
    int age;
} Person;

Person p2;
p2.age = 30;
```

## 주요 코드 패턴

### 재귀 함수 - 팩토리얼

```c
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
// factorial(5) = 5*4*3*2*1 = 120
```

### 버블 정렬

```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                int temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }
}
```

## 핵심 정리

- `*p`: 포인터 역참조 (주소가 가리키는 값)
- `&a`: 변수 a의 주소
- 배열명 = 첫 번째 원소의 주소
- 구조체 멤버 접근: `.` (직접), `->` (포인터)
