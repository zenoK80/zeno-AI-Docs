## NoSQL 개요

"Not Only SQL"의 약자로 관계형 DB의 한계를 극복하기 위한 비관계형 데이터베이스입니다.

### NoSQL의 특징

| 특징 | 설명 |
|------|------|
| 유연한 스키마 | 고정 스키마 없음, 비정형 데이터 저장 |
| 수평적 확장 | 서버를 추가하여 용량·성능 확장 |
| 높은 가용성 | 분산 환경에서 고가용성 지원 |
| CAP 이론 | C(일관성), A(가용성), P(파티션 허용) 중 2개 보장 |

### NoSQL 유형

| 유형 | 설명 | 제품 |
|------|------|------|
| 키-값 (Key-Value) | 키로 값을 저장·조회, 단순 구조 | Redis, DynamoDB, Riak |
| 문서 (Document) | JSON/BSON 형태의 문서 저장 | MongoDB, CouchDB |
| 칼럼 (Column Family) | 열 기반 저장, 대용량 쓰기에 유리 | Cassandra, HBase |
| 그래프 (Graph) | 노드와 엣지로 관계 표현 | Neo4j, Amazon Neptune |

## 빅데이터 (Big Data)

### 빅데이터의 3V (초기 정의)

| 속성 | 설명 |
|------|------|
| Volume (규모) | 기존 방식으로 처리하기 어려운 대규모 데이터 |
| Velocity (속도) | 빠른 속도로 생성·처리되는 데이터 |
| Variety (다양성) | 정형·반정형·비정형 다양한 형식의 데이터 |

### 확장된 5V

- **Veracity (정확성):** 데이터의 신뢰성·품질
- **Value (가치):** 데이터에서 추출하는 비즈니스 가치

### 빅데이터 처리 기술

| 기술 | 설명 |
|------|------|
| Hadoop | 분산 파일 시스템(HDFS)과 MapReduce |
| Spark | 인메모리 처리로 Hadoop보다 빠름 |
| Kafka | 분산 메시지 스트리밍 플랫폼 |
| Hive | Hadoop 위의 SQL 인터페이스 |
| Pig | Hadoop 위의 데이터 흐름 언어 |

## 데이터 마이닝 (Data Mining)

대용량 데이터에서 유용한 패턴·규칙·지식을 추출하는 기술입니다.

### 주요 기법

| 기법 | 설명 |
|------|------|
| 분류(Classification) | 미리 정의된 클래스로 데이터 분류 |
| 군집화(Clustering) | 유사한 데이터를 그룹화 (비지도 학습) |
| 연관 규칙(Association) | 항목 간의 연관성 발견 (장바구니 분석) |
| 회귀(Regression) | 연속적인 값을 예측 |
| 이상 탐지(Anomaly Detection) | 비정상적인 패턴 식별 |

### ETL 프로세스

```
Extract (추출) → Transform (변환) → Load (적재) → 데이터 웨어하우스
```

---

## 핵심 정리

- NoSQL 유형: 키-값, 문서, 칼럼, 그래프
- 빅데이터 3V: Volume, Velocity, Variety
- Hadoop: HDFS + MapReduce / Spark: 인메모리 처리
- ETL: 추출 → 변환 → 적재
