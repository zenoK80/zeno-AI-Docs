## 빌드와 패키징

### 빌드 프로세스

```
소스코드 → 컴파일 → 링크 → 실행 파일(.exe, .jar) 또는 패키지
```

### 빌드 도구

| 도구 | 언어 | 특징 |
|------|------|------|
| Maven | Java | XML 기반, 의존성 관리 |
| Gradle | Java/Kotlin | Groovy/Kotlin DSL, 빠른 빌드 |
| npm/yarn | JavaScript | Node.js 패키지 관리 |
| pip | Python | 패키지 설치 도구 |
| Make | C/C++ | Makefile 기반 빌드 자동화 |

---

## 배포 방식

| 방식 | 설명 | 특징 |
|------|------|------|
| 현재 위치 배포(In-place) | 기존 서버에 직접 업데이트 | 단순하지만 다운타임 발생 |
| 블루-그린 배포 | 구 버전(블루)과 신 버전(그린) 동시 운영 | 무중단, 빠른 롤백 |
| 카나리 배포 | 일부 사용자에게만 신 버전 적용 | 점진적 배포, 위험 분산 |
| 롤링 배포 | 서버를 순차적으로 업데이트 | 다운타임 최소화 |

---

## 컨테이너 기술

### Docker 핵심 개념

| 개념 | 설명 |
|------|------|
| 이미지(Image) | 컨테이너 실행을 위한 읽기 전용 템플릿 |
| 컨테이너(Container) | 이미지를 실행한 인스턴스 |
| Dockerfile | 이미지 빌드 명령을 담은 설정 파일 |
| 레지스트리(Registry) | 이미지 저장·배포 서버 (Docker Hub) |

### Docker 주요 명령어

| 명령어 | 설명 |
|--------|------|
| docker build | Dockerfile로 이미지 빌드 |
| docker run | 컨테이너 실행 |
| docker ps | 실행 중인 컨테이너 목록 |
| docker pull/push | 이미지 받기/올리기 |
| docker-compose | 멀티 컨테이너 정의·실행 |

---

## 클라우드 서비스 모델

| 모델 | 설명 | 예시 |
|------|------|------|
| IaaS | 인프라(서버, 스토리지, 네트워크) 제공 | AWS EC2, Azure VM |
| PaaS | 개발 플랫폼·런타임 제공 | AWS Elastic Beanstalk |
| SaaS | 완성된 소프트웨어 서비스 제공 | Gmail, Salesforce |
| FaaS | 함수 단위 실행 (서버리스) | AWS Lambda |

---

## 패키지 설치 방식

| 방식 | 설명 |
|------|------|
| 정적 링크 | 라이브러리를 실행 파일에 포함, 이식성 높음 |
| 동적 링크 | 라이브러리를 실행 시 로드, 파일 크기 작음 |

---

## 핵심 정리

- 블루-그린: 무중단 배포, 빠른 롤백 가능
- 카나리: 일부 사용자에게 먼저 배포
- IaaS: 서버/스토리지 / PaaS: 플랫폼 / SaaS: 완성 서비스
- Docker 이미지 → 컨테이너(실행 인스턴스)
