## SELECT 기본 구문

```sql
SELECT 컬럼명, ...
FROM 테이블명
WHERE 조건
GROUP BY 그룹기준
HAVING 그룹조건
ORDER BY 정렬기준 [ASC|DESC];
```

### SELECT 실행 순서

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

---

## 조건 연산자

| 연산자 | 설명 | 예시 |
|--------|------|------|
| = | 같음 | WHERE age = 30 |
| BETWEEN | 범위 | WHERE age BETWEEN 20 AND 30 |
| IN | 목록 포함 | WHERE dept IN ('IT', 'HR') |
| LIKE | 패턴 매칭 | WHERE name LIKE '김%' |
| IS NULL | NULL 검사 | WHERE email IS NULL |
| NOT | 부정 | WHERE NOT age = 30 |

### LIKE 와일드카드

| 기호 | 의미 |
|------|------|
| % | 0개 이상의 임의 문자 |
| _ | 정확히 1개의 임의 문자 |

## JOIN

### JOIN 유형

| 유형 | 설명 |
|------|------|
| INNER JOIN | 두 테이블의 공통 데이터만 반환 |
| LEFT (OUTER) JOIN | 왼쪽 테이블 전체 + 오른쪽 일치 데이터 |
| RIGHT (OUTER) JOIN | 오른쪽 테이블 전체 + 왼쪽 일치 데이터 |
| FULL OUTER JOIN | 양쪽 테이블 전체 데이터 |
| CROSS JOIN | 두 테이블의 카테시안 곱 |
| SELF JOIN | 같은 테이블을 두 번 조인 |

```sql
-- INNER JOIN 예시
SELECT e.name, d.dept_name
FROM employee e
INNER JOIN department d ON e.dept_id = d.id;

-- LEFT JOIN 예시
SELECT e.name, d.dept_name
FROM employee e
LEFT JOIN department d ON e.dept_id = d.id;
```

## 집계 함수

| 함수 | 설명 |
|------|------|
| COUNT(*) | 행 수 |
| SUM(컬럼) | 합계 |
| AVG(컬럼) | 평균 |
| MAX(컬럼) | 최댓값 |
| MIN(컬럼) | 최솟값 |

```sql
-- GROUP BY + HAVING 예시
SELECT dept_id, COUNT(*) AS cnt, AVG(salary) AS avg_sal
FROM employee
GROUP BY dept_id
HAVING COUNT(*) >= 5;
```

## INSERT, UPDATE, DELETE

```sql
-- INSERT
INSERT INTO employee (name, dept_id, salary)
VALUES ('홍길동', 1, 3000000);

-- UPDATE
UPDATE employee
SET salary = salary * 1.1
WHERE dept_id = 1;

-- DELETE
DELETE FROM employee
WHERE emp_id = 100;
```

## 서브쿼리 (Subquery)

```sql
-- WHERE 절 서브쿼리
SELECT name FROM employee
WHERE salary > (SELECT AVG(salary) FROM employee);

-- FROM 절 인라인 뷰
SELECT * FROM (
  SELECT dept_id, AVG(salary) AS avg_sal
  FROM employee GROUP BY dept_id
) AS dept_avg
WHERE avg_sal > 3000000;
```

---

## 핵심 정리

- SELECT 실행 순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
- INNER JOIN: 교집합 / LEFT JOIN: 왼쪽 전체
- HAVING: 그룹 조건 / WHERE: 행 조건
- LIKE %: 0개 이상 / _: 정확히 1개
