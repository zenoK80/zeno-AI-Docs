## 클래스와 객체

```java
public class Person {
    // 필드
    private String name;
    private int age;
    
    // 생성자
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // 메서드
    public String getName() { return name; }
    public int getAge() { return age; }
    
    @Override
    public String toString() {
        return name + " (" + age + "세)";
    }
}

Person p = new Person("홍길동", 25);
System.out.println(p.getName());  // 홍길동
```

## 상속 (Inheritance)

```java
public class Animal {
    protected String name;
    
    public Animal(String name) {
        this.name = name;
    }
    
    public void speak() {
        System.out.println(name + "이 소리를 냅니다.");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 부모 생성자 호출
    }
    
    @Override
    public void speak() {   // 오버라이딩
        System.out.println(name + "이 왈왈!");
    }
}
```

## 인터페이스 (Interface)

```java
public interface Flyable {
    void fly();          // 추상 메서드
    default void land() {
        System.out.println("착륙합니다.");
    }
}

public class Bird extends Animal implements Flyable {
    public Bird(String name) { super(name); }
    
    @Override
    public void fly() {
        System.out.println(name + "이 날아갑니다.");
    }
}
```

### 추상 클래스 vs 인터페이스

| 구분 | 추상 클래스 | 인터페이스 |
|------|------------|------------|
| 키워드 | abstract class | interface |
| 다중 상속 | 불가 (단일 상속) | 가능 (다중 구현) |
| 생성자 | 있음 | 없음 |
| 구현 메서드 | 가질 수 있음 | default/static만 |
| 목적 | 공통 구현 공유 | 계약(Contract) 정의 |

## 예외 처리 (Exception Handling)

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("0으로 나눌 수 없습니다: " + e.getMessage());
} catch (Exception e) {
    System.out.println("예외 발생: " + e.getMessage());
} finally {
    System.out.println("항상 실행");
}
```

### 체크 예외 vs 언체크 예외

| 구분 | 특징 | 예시 |
|------|------|------|
| 체크 예외 | 반드시 처리 필요 | IOException, SQLException |
| 언체크 예외(RuntimeException) | 처리 선택 | NullPointerException, ArrayIndexOutOfBoundsException |

## 컬렉션 프레임워크

| 인터페이스 | 구현 클래스 | 특징 |
|------------|------------|------|
| List | ArrayList, LinkedList | 순서 있음, 중복 허용 |
| Set | HashSet, TreeSet | 순서 없음, 중복 불가 |
| Map | HashMap, TreeMap | 키-값 쌍, 키 중복 불가 |
| Queue | LinkedList, PriorityQueue | FIFO 또는 우선순위 |

```java
// ArrayList
List<String> list = new ArrayList<>();
list.add("Apple");
list.get(0);     // "Apple"
list.size();     // 1

// HashMap
Map<String, Integer> map = new HashMap<>();
map.put("A", 1);
map.get("A");    // 1
map.containsKey("A");  // true
```

## 핵심 정리

- 인터페이스: 다중 구현 가능 / 추상 클래스: 단일 상속
- @Override: 부모 메서드 재정의 명시
- ArrayList: 인덱스 접근 빠름 / LinkedList: 삽입·삭제 빠름
- 체크 예외: try-catch 필수 / 언체크: 선택
