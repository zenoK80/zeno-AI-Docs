## 선형 자료구조

### 배열 (Array)
- 동일 타입 데이터를 연속 메모리에 저장
- 인덱스로 O(1) 접근 가능, 삽입·삭제 O(n)

### 연결 리스트 (Linked List)
- 노드가 다음 노드의 포인터를 가짐
- 삽입·삭제 O(1), 탐색 O(n)

### 스택 (Stack)
- **LIFO** (Last In, First Out)
- 연산: push(삽입), pop(삭제), peek(최상단 확인)
- 활용: 함수 호출 스택, 괄호 검사, 역순 출력

### 큐 (Queue)
- **FIFO** (First In, First Out)
- 연산: enqueue(삽입), dequeue(삭제)
- 활용: 프린터 스풀링, BFS 탐색

### 덱 (Deque)
- 양쪽 끝에서 삽입·삭제 가능한 큐

---

## 비선형 자료구조

### 트리 (Tree)

| 용어 | 설명 |
|------|------|
| 루트(Root) | 최상위 노드 |
| 단말 노드(Leaf) | 자식이 없는 노드 |
| 높이(Height) | 루트에서 단말까지 최대 깊이 |
| 차수(Degree) | 한 노드의 자식 수 |

### 이진 트리 순회

| 순서 | 방법 | 특징 |
|------|------|------|
| 전위(Pre-order) | 루트 → 왼쪽 → 오른쪽 | |
| 중위(In-order) | 왼쪽 → 루트 → 오른쪽 | BST에서 오름차순 출력 |
| 후위(Post-order) | 왼쪽 → 오른쪽 → 루트 | |

### 이진 탐색 트리 (BST)
- 왼쪽 자식 < 부모 < 오른쪽 자식
- 탐색·삽입·삭제 평균 O(log n)

### 그래프 (Graph)
- 정점(Vertex)과 간선(Edge)으로 구성
- **BFS**: 너비 우선 탐색, 큐 사용
- **DFS**: 깊이 우선 탐색, 스택 또는 재귀 사용

---

## 정렬 알고리즘

| 알고리즘 | 평균 시간복잡도 | 최악 | 특징 |
|----------|---------------|------|------|
| 버블 정렬 | O(n²) | O(n²) | 인접 요소 비교·교환, 구현 간단 |
| 선택 정렬 | O(n²) | O(n²) | 최솟값 선택 후 배치 |
| 삽입 정렬 | O(n²) | O(n²) | 거의 정렬된 경우 효율적 |
| 퀵 정렬 | O(n log n) | O(n²) | 피벗 분할, 실용적 |
| 합병 정렬 | O(n log n) | O(n log n) | 안정 정렬, 분할정복 |
| 힙 정렬 | O(n log n) | O(n log n) | 최솟/최댓값 추출 |

---

## 탐색 알고리즘

| 알고리즘 | 시간복잡도 | 전제 조건 |
|----------|-----------|-----------|
| 순차 탐색 | O(n) | 없음 |
| 이진 탐색 | O(log n) | 정렬된 배열 |
| 해시 탐색 | O(1) 평균 | 해시 테이블 |

---

## 핵심 정리

- 스택: LIFO / 큐: FIFO
- 이진 탐색: O(log n), 반드시 정렬 필요
- 퀵 정렬: 평균 O(n log n), 최악 O(n²)
- 합병 정렬: 항상 O(n log n), 안정 정렬
