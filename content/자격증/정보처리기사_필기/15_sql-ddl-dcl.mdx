## DDL (Data Definition Language)

데이터 구조(스키마)를 정의·변경·삭제하는 언어입니다.

### CREATE

```sql
CREATE TABLE employee (
  emp_id   INT PRIMARY KEY,
  name     VARCHAR(50) NOT NULL,
  dept_id  INT,
  salary   DECIMAL(10, 2) DEFAULT 0,
  hire_date DATE,
  FOREIGN KEY (dept_id) REFERENCES department(dept_id)
);
```

### ALTER

```sql
-- 컬럼 추가
ALTER TABLE employee ADD email VARCHAR(100);

-- 컬럼 수정
ALTER TABLE employee MODIFY name VARCHAR(100) NOT NULL;

-- 컬럼 삭제
ALTER TABLE employee DROP COLUMN email;
```

### DROP vs TRUNCATE vs DELETE

| 명령 | 분류 | 데이터 삭제 | 구조 삭제 | 롤백 |
|------|------|------------|----------|------|
| DROP | DDL | O (전체) | O | 불가 |
| TRUNCATE | DDL | O (전체) | X | 불가 |
| DELETE | DML | O (선택) | X | 가능 |

## 제약 조건 (Constraint)

| 제약 조건 | 설명 |
|-----------|------|
| PRIMARY KEY | 기본키, NOT NULL + UNIQUE |
| FOREIGN KEY | 외래키, 참조 무결성 |
| UNIQUE | 중복 불허, NULL 허용 |
| NOT NULL | NULL 불허 |
| CHECK | 허용 값 범위 제한 |
| DEFAULT | 기본값 설정 |

---

## DCL (Data Control Language)

데이터 접근 권한을 제어합니다.

```sql
-- 권한 부여
GRANT SELECT, INSERT ON employee TO user1;
GRANT ALL PRIVILEGES ON employee TO admin WITH GRANT OPTION;

-- 권한 회수
REVOKE SELECT ON employee FROM user1;
```

## 트랜잭션 (Transaction)

하나의 논리적 작업 단위로 여러 SQL을 묶어 처리합니다.

### ACID 특성

| 특성 | 설명 |
|------|------|
| 원자성 (Atomicity) | 전부 성공하거나 전부 실패 (All or Nothing) |
| 일관성 (Consistency) | 트랜잭션 전후 데이터 일관성 유지 |
| 격리성 (Isolation) | 동시 실행 트랜잭션이 서로 영향 안 줌 |
| 지속성 (Durability) | 커밋된 트랜잭션은 영구 반영 |

### TCL (Transaction Control Language)

| 명령 | 설명 |
|------|------|
| COMMIT | 트랜잭션 변경 사항 확정·저장 |
| ROLLBACK | 트랜잭션 변경 사항 취소 |
| SAVEPOINT | 트랜잭션 내 저장점 설정 |
| SET TRANSACTION | 트랜잭션 격리 수준 설정 |

### 트랜잭션 격리 수준

| 수준 | 설명 | 문제 |
|------|------|------|
| READ UNCOMMITTED | 커밋 안 된 데이터 읽기 허용 | Dirty Read |
| READ COMMITTED | 커밋된 데이터만 읽기 | Non-Repeatable Read |
| REPEATABLE READ | 같은 데이터 반복 읽기 보장 | Phantom Read |
| SERIALIZABLE | 완전 직렬 실행 | 성능 저하 |

---

## 핵심 정리

- DROP: 테이블 구조·데이터 삭제 / TRUNCATE: 데이터만 전체 삭제 / DELETE: 조건 삭제
- ACID: 원자성, 일관성, 격리성, 지속성
- GRANT: 권한 부여 / REVOKE: 권한 회수
- COMMIT: 확정 / ROLLBACK: 취소
