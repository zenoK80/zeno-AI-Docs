## HTTP 프로토콜

### HTTP 메서드

| 메서드 | 설명 | 특징 |
|--------|------|------|
| GET | 리소스 조회 | 멱등성, 캐시 가능 |
| POST | 리소스 생성 | 비멱등 |
| PUT | 리소스 전체 수정 | 멱등성 |
| PATCH | 리소스 부분 수정 | |
| DELETE | 리소스 삭제 | 멱등성 |

### HTTP 상태 코드

| 범위 | 의미 | 예시 |
|------|------|------|
| 1xx | 정보 | 100 Continue |
| 2xx | 성공 | 200 OK, 201 Created |
| 3xx | 리다이렉션 | 301 Moved Permanently |
| 4xx | 클라이언트 오류 | 400 Bad Request, 401 Unauthorized, 404 Not Found |
| 5xx | 서버 오류 | 500 Internal Server Error |

## REST API

REST(Representational State Transfer)는 HTTP 기반의 웹 서비스 아키텍처 스타일입니다.

### REST 설계 원칙

| 원칙 | 설명 |
|------|------|
| 자원 기반 URI | /users, /users/1 처럼 자원을 URI로 표현 |
| HTTP 메서드 활용 | GET/POST/PUT/DELETE로 동작 표현 |
| 무상태(Stateless) | 서버가 클라이언트 상태 저장 안 함 |
| 계층 구조 | 클라이언트는 서버 구현 몰라도 됨 |

```
GET    /users        → 사용자 목록 조회
GET    /users/1      → 사용자 1 조회
POST   /users        → 사용자 생성
PUT    /users/1      → 사용자 1 전체 수정
DELETE /users/1      → 사용자 1 삭제
```

## 웹 보안

| 공격 | 설명 | 방어 |
|------|------|------|
| XSS (크로스 사이트 스크립팅) | 악성 스크립트 삽입 | 입력값 이스케이프, CSP |
| CSRF | 사용자 권한으로 위조 요청 | CSRF 토큰 |
| SQL 인젝션 | 악성 SQL 삽입 | 파라미터화 쿼리, ORM |
| 클릭재킹 | iframe으로 클릭 가로채기 | X-Frame-Options |

## 핵심 정리

- HTML: 구조 / CSS: 스타일 / JS: 동작
- GET: 조회, 멱등 / POST: 생성, 비멱등
- 2xx: 성공 / 4xx: 클라이언트 오류 / 5xx: 서버 오류
- XSS: 스크립트 삽입 / CSRF: 위조 요청 / SQL인젝션: SQL 삽입
