## 정보보안 3대 요소 (CIA 트리아드)

| 요소 | 영문 | 설명 | 위협 |
|------|------|------|------|
| 기밀성 | Confidentiality | 인가된 사용자만 접근 가능 | 도청, 스니핑 |
| 무결성 | Integrity | 데이터 변조 방지 | 위·변조, 악성코드 |
| 가용성 | Availability | 인가된 사용자의 접근 보장 | DoS/DDoS 공격 |

---

## 접근 제어 (Access Control)

### 접근 제어 모델

| 모델 | 설명 | 특징 |
|------|------|------|
| DAC (임의적 접근 제어) | 소유자가 접근 권한 결정 | 유연하나 보안 약함 |
| MAC (강제적 접근 제어) | 시스템이 보안 레벨로 결정 | 엄격, 군사용 |
| RBAC (역할 기반 접근 제어) | 역할에 따라 권한 부여 | 기업 환경에 적합 |
| ABAC (속성 기반 접근 제어) | 사용자/자원/환경 속성으로 결정 | 가장 유연함 |

### 최소 권한 원칙 (Principle of Least Privilege)

사용자에게 업무 수행에 필요한 최소한의 권한만 부여합니다.

---

## 인증 (Authentication)

### 인증 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| 지식 기반 (Something you know) | 알고 있는 정보 | 비밀번호, PIN |
| 소유 기반 (Something you have) | 소유한 것 | OTP, 스마트카드 |
| 생체 기반 (Something you are) | 신체 특성 | 지문, 홍채, 얼굴 |
| 위치 기반 (Somewhere you are) | 위치 정보 | GPS, IP 주소 |

### MFA (다중 요소 인증)

2개 이상의 인증 요소를 조합하여 보안을 강화합니다.

---

## 주요 보안 공격 유형

| 공격 | 설명 | 대응 |
|------|------|------|
| DoS/DDoS | 서비스 마비 공격 | 트래픽 필터링, CDN |
| 피싱(Phishing) | 위조 사이트로 정보 탈취 | 사용자 교육, 필터링 |
| 스푸핑(Spoofing) | IP/MAC 주소 위조 | 암호화, 필터링 |
| 스니핑(Sniffing) | 네트워크 패킷 도청 | 암호화(SSL/TLS) |
| 랜섬웨어 | 파일 암호화 후 금전 요구 | 백업, 보안 소프트웨어 |
| APT | 지속적·표적형 공격 | 위협 인텔리전스 |
| SQL 인젝션 | DB 조작 쿼리 삽입 | 파라미터화 쿼리 |
| XSS | 악성 스크립트 삽입 | 입력값 검증/이스케이프 |

---

## PKI (공개키 기반 구조)

| 구성 요소 | 설명 |
|----------|------|
| CA (인증기관) | 인증서 발급·관리 |
| RA (등록기관) | 사용자 신원 확인 |
| 인증서 | 공개키와 신원 정보 결합 |
| CRL | 폐기된 인증서 목록 |

### 전자서명 과정

```
서명: 개인키로 해시값 암호화
검증: 공개키로 복호화 후 해시 비교
```

---

## 핵심 정리

- CIA: 기밀성-무결성-가용성
- DAC: 소유자 결정 / MAC: 시스템 결정 / RBAC: 역할 기반
- MFA: 2개 이상 인증 요소 조합
- DoS: 가용성 침해 / 피싱: 기밀성 침해
