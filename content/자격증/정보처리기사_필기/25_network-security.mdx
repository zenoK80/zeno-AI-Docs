## OSI 7계층 모델

| 계층 | 이름 | 프로토콜/장비 | 데이터 단위 |
|------|------|--------------|------------|
| 7 | 응용(Application) | HTTP, FTP, SMTP, DNS | 메시지 |
| 6 | 표현(Presentation) | SSL/TLS, JPEG, MPEG | 메시지 |
| 5 | 세션(Session) | NetBIOS, RPC | 메시지 |
| 4 | 전송(Transport) | TCP, UDP | 세그먼트 |
| 3 | 네트워크(Network) | IP, ICMP, ARP | 패킷 |
| 2 | 데이터링크(Data Link) | Ethernet, MAC | 프레임 |
| 1 | 물리(Physical) | 케이블, 허브 | 비트 |

> 암기 팁: **물데네전세표응** (1→7)

## TCP vs UDP

| 특성 | TCP | UDP |
|------|-----|-----|
| 연결 | 연결 지향 (3-way handshake) | 비연결 |
| 신뢰성 | 높음 (재전송, 순서 보장) | 낮음 |
| 속도 | 느림 | 빠름 |
| 용도 | HTTP, FTP, 이메일 | DNS, 스트리밍, 게임 |

### TCP 3-way Handshake

```
클라이언트 → SYN → 서버
클라이언트 ← SYN-ACK ← 서버
클라이언트 → ACK → 서버
```

## 주요 프로토콜과 포트

| 프로토콜 | 포트 | 설명 |
|----------|------|------|
| HTTP | 80 | 웹 통신 |
| HTTPS | 443 | 암호화된 웹 통신 |
| FTP | 21 | 파일 전송 |
| SSH | 22 | 보안 원격 접속 |
| SMTP | 25 | 이메일 전송 |
| DNS | 53 | 도메인 이름 해석 |
| DHCP | 67/68 | IP 자동 할당 |
| Telnet | 23 | 원격 접속 (비암호화) |

## 네트워크 보안 장비

| 장비 | 설명 |
|------|------|
| 방화벽(Firewall) | 패킷 필터링, ACL 기반 트래픽 제어 |
| IDS (침입 탐지 시스템) | 침입 감지 후 관리자에게 알림 |
| IPS (침입 방지 시스템) | 침입 탐지 + 자동 차단 |
| WAF (웹 애플리케이션 방화벽) | 웹 공격(XSS, SQL인젝션) 차단 |
| DMZ | 외부와 내부 사이 비무장 지대 |

## VPN (Virtual Private Network)

공중망을 통해 사설망처럼 사용하는 가상 사설망입니다.

### VPN 프로토콜

| 프로토콜 | 설명 |
|----------|------|
| IPSec | IP 계층 암호화, 터널 모드/전송 모드 |
| SSL/TLS VPN | 443 포트 사용, 웹 브라우저로 접속 |
| L2TP | 2계층 터널링, IPSec과 함께 사용 |

## 암호화

### 대칭키 vs 비대칭키

| 구분 | 대칭키 | 비대칭키 (공개키) |
|------|--------|-----------------|
| 키 개수 | 1개 (암복호화 동일 키) | 2개 (공개키 + 개인키) |
| 속도 | 빠름 | 느림 |
| 키 관리 | 어려움 | 용이 |
| 알고리즘 | AES, DES, 3DES | RSA, ECC |
| 용도 | 대용량 데이터 암호화 | 키 교환, 전자서명 |

### 해시 함수

- 단방향 함수 (복호화 불가)
- MD5 (128bit), SHA-1 (160bit), SHA-256 (256bit)
- 무결성 검증, 패스워드 저장에 사용

---

## 핵심 정리

- OSI 7계층: 물데네전세표응
- TCP: 신뢰성, 연결 지향 / UDP: 빠름, 비연결
- 대칭키: 빠름, 키 1개 / 비대칭키: 느림, 키 2개
- IDS: 탐지만 / IPS: 탐지 + 차단
