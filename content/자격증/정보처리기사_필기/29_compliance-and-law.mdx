## 개인정보보호법

### 핵심 개념

| 용어 | 설명 |
|------|------|
| 개인정보 | 살아있는 개인에 관한 정보로 개인을 식별할 수 있는 정보 |
| 개인정보처리자 | 개인정보를 처리하는 공공기관, 법인, 단체, 개인 |
| 정보주체 | 개인정보의 주체가 되는 살아있는 자연인 |
| 처리 | 수집, 생성, 연계, 연동, 기록, 저장, 보유, 가공, 편집, 검색, 출력, 정정, 복구, 이용, 제공, 공개, 파기 등 |

### 개인정보 수집 원칙

- 수집 시 **정보주체의 동의** 필요
- **최소한의 개인정보만** 수집
- **수집 목적 내에서만** 이용

### 민감정보

- 건강 정보, 성생활 정보, 유전자 정보, 범죄 기록, 노동조합 가입 정보 등
- 별도의 **명시적 동의** 필요

### 개인정보보호위원회

개인정보보호 관련 업무를 총괄하는 독립 기관입니다.

## 정보통신망법 (정보통신망 이용촉진 및 정보보호 등에 관한 법률)

### 주요 내용

| 항목 | 설명 |
|------|------|

| 정보통신기반 보호 | 주요 정보통신기반시설 보호 |

## 소프트웨어 저작권

### 저작권의 주요 개념

| 개념 | 설명 |
|------|------|
| 저작물 | 인간의 사상·감정을 창작적으로 표현한 것 |
| 저작인격권 | 공표권, 성명 표시권, 동일성 유지권 (양도 불가) |
| 저작재산권 | 복제권, 배포권, 공중송신권 등 (양도 가능) |
| 보호 기간 | 저작자 사후 70년 |

### 오픈소스 라이선스 유형

| 라이선스 | 특징 | 예시 |
|----------|------|------|
| GPL | 수정 배포 시 동일 라이선스 적용 (카피레프트) | Linux 커널 |
| LGPL | 라이브러리 동적 링크 허용 | GNU 라이브러리 |
| MIT | 가장 자유로움, 저작자 표시만 | React, Node.js |
| Apache 2.0 | 특허권 명시, 자유로운 사용 | Android |
| BSD | MIT와 유사, 사용 제한 없음 | BSD OS |

### 카피레프트(Copyleft)

GPL처럼 수정 후 배포 시 동일한 조건(오픈소스)을 유지해야 하는 원칙입니다.

## 정보시스템 보안 인증

| 인증 | 설명 |
|------|------|
| ISMS (정보보호관리체계) | 국내 정보보호 관리체계 인증 |
| ISMS-P | ISMS + 개인정보보호 통합 인증 |
| ISO 27001 | 국제 정보보안 관리체계 인증 |
| CC (Common Criteria) | IT 제품 보안 인증 (ISO 15408) |

---

## 핵심 정리

- 개인정보: 동의 기반 수집, 최소 수집 원칙
- 민감정보: 명시적 동의 필요
- GPL: 카피레프트 (수정 배포 시 동일 라이선스)
- MIT: 가장 자유로운 라이선스
- ISMS: 국내 정보보호 관리체계 인증
