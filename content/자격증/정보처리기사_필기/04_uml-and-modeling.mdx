## 유스케이스 다이어그램

### 구성요소

| 요소 | 표기 | 설명 |
|------|------|------|
| Actor | 사람 모양 | 시스템과 상호작용하는 외부 개체 |
| Use Case | 타원 | 시스템이 제공하는 기능 |
| System Boundary | 사각형 | 시스템 범위 표시 |
| 연관(Association) | 실선 | Actor와 Use Case 연결 |
| 포함(Include) | 점선 + include | 필수 포함 관계 |
| 확장(Extend) | 점선 + extend | 조건부 확장 관계 |
| 일반화(Generalization) | 삼각형 화살표 | 상속 관계 |

### Include vs Extend

| 관계 | 의미 | 예시 |
|------|------|------|
| Include | A 실행 시 B 항상 포함 | 결제 → include → 본인 인증 |
| Extend | 조건 만족 시 B 추가 실행 | 주문 ← extend ← 할인 적용 |

## 클래스 다이어그램

### 클래스 표기법

```
┌──────────────────┐
│   ClassName      │  ← 클래스명
├──────────────────┤
│ -name: String    │  ← 속성 (- private, + public, # protected)
│ +age: int        │
├──────────────────┤
│ +getName(): String │ ← 메서드
│ +setAge(int): void │
└──────────────────┘
```

### 다중성(Multiplicity) 표기

| 표기 | 의미 |
|------|------|
| 1 | 정확히 1 |
| 0..1 | 0 또는 1 |
| * 또는 0..* | 0 이상 |
| 1..* | 1 이상 |
| m..n | m 이상 n 이하 |

## 시퀀스 다이어그램

### 구성요소

| 요소 | 설명 |
|------|------|
| 객체(Object) | 상단 사각형, 이름: 클래스명 |
| 생명선(Lifeline) | 객체 아래 점선 |
| 활성화 바(Activation Bar) | 메서드 실행 구간 |
| 메시지 | 객체 간 화살표 (동기=실선, 반환=점선) |
| 자기 메시지 | 같은 객체로 향하는 화살표 |

### 메시지 유형

| 유형 | 표기 | 설명 |
|------|------|------|
| 동기 메시지 | 속이 찬 화살표 | 응답 기다림 |
| 비동기 메시지 | 속이 빈 화살표 | 응답 기다리지 않음 |
| 반환 메시지 | 점선 화살표 | 결과값 반환 |
| 생성 메시지 | 점선 + new | 객체 생성 |

---

## 상태 다이어그램

객체의 상태(State)와 전이(Transition)를 표현합니다.

- **초기 상태:** 속이 찬 원
- **최종 상태:** 속이 찬 원에 테두리 원
- **전이:** 화살표 + 이벤트[조건]/액션

---

## 활동 다이어그램

업무 흐름이나 알고리즘을 표현합니다.

| 요소 | 표기 |
|------|------|
| 초기 노드 | 속이 찬 원 |
| 활동(Activity) | 모서리 둥근 사각형 |
| 결정(Decision) | 마름모 |
| 병행(Fork/Join) | 굵은 가로선 |
| 최종 노드 | 이중 원 |

---

## 핵심 정리

- Include: 항상 포함 (필수) / Extend: 조건부 확장 (선택)
- 클래스 다이어그램: -(private), +(public), #(protected)
- 시퀀스 다이어그램: 수직=시간, 수평=객체
- 상태 다이어그램: 상태 + 전이 표현
