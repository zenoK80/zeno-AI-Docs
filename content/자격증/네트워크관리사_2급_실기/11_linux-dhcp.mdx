## DHCP 서버 설치

```bash
# RHEL/CentOS 7/8
yum install dhcp-server -y

# 또는 (구버전)
yum install dhcp -y

# Ubuntu/Debian
apt-get install isc-dhcp-server -y

# 설치 확인
rpm -q dhcp-server   # RHEL
dpkg -l isc-dhcp-server   # Ubuntu
```

## 설정 파일 위치

| 배포판 | 설정 파일 경로 |
|--------|----------------|
| RHEL/CentOS | `/etc/dhcp/dhcpd.conf` |
| Ubuntu/Debian | `/etc/dhcp/dhcpd.conf` |
| 임대 파일 (RHEL) | `/var/lib/dhcpd/dhcpd.leases` |
| 임대 파일 (Ubuntu) | `/var/lib/dhcp/dhcpd.leases` |

## dhcpd.conf 작성

```bash
vi /etc/dhcp/dhcpd.conf
```

```
# 전역 설정
default-lease-time 3600;      # 기본 임대 시간 (초, 1시간)
max-lease-time 7200;          # 최대 임대 시간 (초, 2시간)
ddns-update-style none;       # DNS 동적 업데이트 비활성화

# 서브넷 선언
subnet 192.168.1.0 netmask 255.255.255.0 {
    # IP 풀 범위
    range 192.168.1.100 192.168.1.200;

    # 옵션: 게이트웨이
    option routers 192.168.1.1;

    # 옵션: DNS 서버
    option domain-name-servers 192.168.1.2, 8.8.8.8;

    # 옵션: 도메인 이름
    option domain-name "exam.local";

    # 옵션: 브로드캐스트 주소
    option broadcast-address 192.168.1.255;

    # 옵션: 서브넷 마스크
    option subnet-mask 255.255.255.0;
}
```

## MAC 주소 기반 고정 IP 예약

특정 장치에 항상 같은 IP를 배포합니다.

```
# dhcpd.conf 파일에 추가

host printer {
    hardware ethernet AA:BB:CC:DD:EE:FF;
    fixed-address 192.168.1.50;
}

host server-linux {
    hardware ethernet 00:11:22:33:44:55;
    fixed-address 192.168.1.20;
    option host-name "linux-server";
}
```

## 복수 서브넷 설정

```
subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.100 192.168.1.200;
    option routers 192.168.1.1;
    option domain-name-servers 192.168.1.2;
}

subnet 192.168.2.0 netmask 255.255.255.0 {
    range 192.168.2.100 192.168.2.200;
    option routers 192.168.2.1;
    option domain-name-servers 192.168.1.2;
}
```

## 인터페이스 지정 (선택)

서버에 여러 NIC가 있을 때 DHCP를 제공할 인터페이스를 지정합니다.

```bash
# RHEL/CentOS: /etc/sysconfig/dhcpd
vi /etc/sysconfig/dhcpd
```

```
DHCPDARGS=eth0
```

```bash
# Ubuntu: /etc/default/isc-dhcp-server
vi /etc/default/isc-dhcp-server
```

```
INTERFACESv4="eth0"
```

## 서비스 시작 및 확인

```bash
# 서비스 시작 및 자동 시작 등록
systemctl enable --now dhcpd

# RHEL에서 서비스 이름 확인
systemctl status dhcpd

# Ubuntu에서 서비스 이름
systemctl status isc-dhcp-server

# 서비스 재시작 (설정 변경 후)
systemctl restart dhcpd

# 로그 확인
journalctl -u dhcpd -f
```

## 임대 목록 확인

```bash
# 현재 임대 중인 IP 목록
cat /var/lib/dhcpd/dhcpd.leases

# 임대 파일 예시 출력
lease 192.168.1.101 {
  starts 3 2024/01/10 12:00:00;
  ends 3 2024/01/10 13:00:00;
  hardware ethernet 00:AA:BB:CC:DD:EE;
  client-hostname "client01";
}
```

## 방화벽 설정

```bash
# firewalld: DHCP 서비스 허용
firewall-cmd --permanent --add-service=dhcp
firewall-cmd --reload

# 직접 포트 허용 (UDP 67)
firewall-cmd --permanent --add-port=67/udp
firewall-cmd --reload

# iptables (구버전)
iptables -A INPUT -p udp --dport 67 -j ACCEPT
iptables -A INPUT -p udp --dport 68 -j ACCEPT
```

## dhcpd.conf 주요 옵션 표

| 옵션 | 설명 | 예시 |
|------|------|------|
| `range` | IP 풀 범위 | range 192.168.1.100 192.168.1.200; |
| `option routers` | 기본 게이트웨이 | option routers 192.168.1.1; |
| `option domain-name-servers` | DNS 서버 | option domain-name-servers 8.8.8.8; |
| `option domain-name` | 도메인 이름 | option domain-name "exam.local"; |
| `default-lease-time` | 기본 임대 시간(초) | default-lease-time 3600; |
| `max-lease-time` | 최대 임대 시간(초) | max-lease-time 7200; |

## 핵심 정리

- 설치: `yum install dhcp-server -y`
- 설정 파일: `/etc/dhcp/dhcpd.conf`
- 필수 항목: `subnet`, `range`, `option routers`, `option domain-name-servers`
- MAC 예약: `host 이름 { hardware ethernet MAC; fixed-address IP; }`
- 서비스: `systemctl enable --now dhcpd`
- 임대 확인: `cat /var/lib/dhcpd/dhcpd.leases`
