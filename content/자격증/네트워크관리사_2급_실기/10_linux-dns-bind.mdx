## BIND 설치

```bash
# RHEL/CentOS
yum install bind bind-utils -y

# Ubuntu/Debian
apt-get install bind9 bind9utils -y

# 설치 확인
named -v
```

## 주요 설정 파일 구조

| 파일 경로 | 설명 |
|-----------|------|
| `/etc/named.conf` | BIND 전체 설정 (메인 설정) |
| `/etc/named.rfc1912.zones` | 기본 영역 파일 (include됨) |
| `/var/named/` | 영역 데이터 파일 저장 디렉터리 |
| `/var/named/exam.local.zone` | 정방향 영역 파일 |
| `/var/named/1.168.192.zone` | 역방향 영역 파일 |

## named.conf 설정

```bash
vi /etc/named.conf
```

```
options {
    listen-on port 53 { any; };
    listen-on-v6 port 53 { ::1; };
    directory     "/var/named";
    dump-file     "/var/named/data/cache_dump.db";
    statistics-file "/var/named/data/named_stats.txt";
    memstatistics-file "/var/named/data/named_mem_stats.txt";

    allow-query     { any; };
    allow-recursion { any; };
    recursion yes;

    dnssec-enable yes;
    dnssec-validation yes;
};

logging {
    channel default_debug {
        file "data/named.run";
        severity dynamic;
    };
};

zone "." IN {
    type hint;
    file "named.ca";
};

zone "exam.local" IN {
    type master;
    file "exam.local.zone";
    allow-update { none; };
};

zone "1.168.192.in-addr.arpa" IN {
    type master;
    file "1.168.192.zone";
    allow-update { none; };
};
```

## 정방향 영역 파일 작성

```bash
vi /var/named/exam.local.zone
```

```
$TTL 86400
@   IN  SOA     ns1.exam.local. root.exam.local. (
                    2024010101  ; Serial
                    3600        ; Refresh
                    1800        ; Retry
                    604800      ; Expire
                    86400 )     ; Minimum TTL

;   네임 서버
@   IN  NS      ns1.exam.local.

;   A 레코드
ns1     IN  A   192.168.1.1
www     IN  A   192.168.1.10
mail    IN  A   192.168.1.20
ftp     IN  A   192.168.1.30

;   별칭 레코드
web     IN  CNAME   www

;   메일 서버 레코드
@   IN  MX  10  mail.exam.local.
```

## 역방향 영역 파일 작성

```bash
vi /var/named/1.168.192.zone
```

```
$TTL 86400
@   IN  SOA     ns1.exam.local. root.exam.local. (
                    2024010101  ; Serial
                    3600        ; Refresh
                    1800        ; Retry
                    604800      ; Expire
                    86400 )     ; Minimum TTL

;   네임 서버
@   IN  NS      ns1.exam.local.

;   PTR 레코드 (마지막 옥텟만 사용)
1   IN  PTR     ns1.exam.local.
10  IN  PTR     www.exam.local.
20  IN  PTR     mail.exam.local.
30  IN  PTR     ftp.exam.local.
```

## 파일 권한 설정

```bash
# named 프로세스가 읽을 수 있도록 권한 설정
chown root:named /var/named/exam.local.zone
chown root:named /var/named/1.168.192.zone
chmod 640 /var/named/exam.local.zone
chmod 640 /var/named/1.168.192.zone
```

## 설정 검증

반드시 서비스 시작 전에 설정 파일 오류를 확인합니다.

```bash
# named.conf 문법 검사
named-checkconf /etc/named.conf

# 영역 파일 검사
named-checkzone exam.local /var/named/exam.local.zone
named-checkzone 1.168.192.in-addr.arpa /var/named/1.168.192.zone
```

정상 출력 예:

```
zone exam.local/IN: loaded serial 2024010101
OK
```

## 서비스 시작 및 자동 등록

```bash
# 서비스 시작 및 부팅 시 자동 시작 등록
systemctl enable --now named

# 서비스 상태 확인
systemctl status named

# 서비스 재시작 (설정 변경 후)
systemctl restart named
```

## 방화벽 설정

```bash
# firewalld에서 DNS 허용
firewall-cmd --permanent --add-service=dns
firewall-cmd --reload

# 또는 포트 직접 허용
firewall-cmd --permanent --add-port=53/tcp
firewall-cmd --permanent --add-port=53/udp
firewall-cmd --reload
```

## 동작 테스트

```bash
# 로컬 DNS 서버에 쿼리
dig @localhost www.exam.local

# 역방향 쿼리
dig @localhost -x 192.168.1.10

# nslookup 사용
nslookup www.exam.local localhost

# BIND 캐시 초기화
rndc flush
```

## SOA 레코드 필드 설명

| 필드 | 예시 | 설명 |
|------|------|------|
| Serial | 2024010101 | 영역 버전, 보조 서버 동기화 기준 |
| Refresh | 3600 | 보조 서버가 갱신 확인하는 주기(초) |
| Retry | 1800 | 갱신 실패 시 재시도 간격(초) |
| Expire | 604800 | 보조 서버가 데이터 유효로 유지하는 시간(초) |
| Minimum TTL | 86400 | 부정 응답 캐시 TTL(초) |

## 핵심 정리

- 설치: `yum install bind bind-utils -y`
- 메인 설정: `/etc/named.conf`
- 영역 파일: `/var/named/영역파일명`
- 검증: `named-checkconf`, `named-checkzone 영역 파일경로`
- 서비스: `systemctl enable --now named`
- 테스트: `dig @localhost www.exam.local`
