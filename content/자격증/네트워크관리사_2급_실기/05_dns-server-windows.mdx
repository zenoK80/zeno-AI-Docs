## DNS 역할 설치

```powershell
# DNS 서버 역할 설치
Install-WindowsFeature -Name DNS -IncludeManagementTools

# 설치 확인
Get-WindowsFeature DNS
```

## 정방향 조회 영역 생성

정방향 영역은 도메인 이름 → IP 주소 변환을 담당합니다.

```powershell
# 기본 영역 파일 기반으로 생성
Add-DnsServerPrimaryZone `
  -Name "exam.local" `
  -ZoneFile "exam.local.dns" `
  -DynamicUpdate None

# Active Directory 통합 영역 (AD 환경)
Add-DnsServerPrimaryZone `
  -Name "exam.local" `
  -ReplicationScope "Domain" `
  -DynamicUpdate Secure

# 영역 목록 확인
Get-DnsServerZone
```

## 역방향 조회 영역 생성

역방향 영역은 IP 주소 → 도메인 이름 변환(PTR 레코드)을 담당합니다.

```powershell
# 192.168.1.x 대역 역방향 영역 생성
Add-DnsServerPrimaryZone `
  -NetworkId "192.168.1.0/24" `
  -ZoneFile "1.168.192.in-addr.arpa.dns"

# 또는 직접 영역 이름 지정
Add-DnsServerPrimaryZone `
  -Name "1.168.192.in-addr.arpa" `
  -ZoneFile "1.168.192.in-addr.arpa.dns"
```

## DNS 레코드 추가

### A 레코드 (IPv4 주소)

```powershell
# www.exam.local → 192.168.1.10
Add-DnsServerResourceRecordA `
  -Name "www" `
  -ZoneName "exam.local" `
  -IPv4Address "192.168.1.10"

# mail.exam.local → 192.168.1.20
Add-DnsServerResourceRecordA `
  -Name "mail" `
  -ZoneName "exam.local" `
  -IPv4Address "192.168.1.20"
```

### PTR 레코드 (역방향)

```powershell
# 192.168.1.10 → www.exam.local
Add-DnsServerResourceRecordPtr `
  -Name "10" `
  -ZoneName "1.168.192.in-addr.arpa" `
  -PtrDomainName "www.exam.local"
```

### CNAME 레코드 (별칭)

```powershell
# ftp.exam.local → www.exam.local 별칭
Add-DnsServerResourceRecordCName `
  -Name "ftp" `
  -ZoneName "exam.local" `
  -HostNameAlias "www.exam.local"
```

### MX 레코드 (메일 서버)

```powershell
# 메일 서버 등록
Add-DnsServerResourceRecordMX `
  -Name "@" `
  -ZoneName "exam.local" `
  -MailExchange "mail.exam.local" `
  -Preference 10
```

## DNS 레코드 종류 요약

| 레코드 | 용도 | 예시 |
|--------|------|------|
| A | 도메인 → IPv4 | www → 192.168.1.10 |
| AAAA | 도메인 → IPv6 | www → 2001:db8::1 |
| CNAME | 별칭(Alias) | ftp → www.exam.local |
| MX | 메일 서버 지정 | @ → mail.exam.local (우선순위 10) |
| PTR | IP → 도메인(역방향) | 10 → www.exam.local |
| NS | 네임서버 지정 | @ → ns1.exam.local |
| SOA | 권한 시작 레코드 | 영역 관리 정보 |
| TXT | 임의 텍스트 | SPF 레코드 등 |

## 레코드 확인 및 삭제

```powershell
# 영역 내 모든 레코드 확인
Get-DnsServerResourceRecord -ZoneName "exam.local"

# A 레코드만 확인
Get-DnsServerResourceRecord -ZoneName "exam.local" -RRType A

# 레코드 삭제
Remove-DnsServerResourceRecord -ZoneName "exam.local" -RRType A -Name "www" -RecordData "192.168.1.10"
```

## DNS 캐시 초기화

```powershell
# 클라이언트 DNS 캐시 초기화
Clear-DnsClientCache

# 서버 DNS 캐시 초기화
Clear-DnsServerCache

# 캐시 확인
Get-DnsClientCache
```

## nslookup으로 검증

```powershell
# 특정 DNS 서버에 쿼리
nslookup www.exam.local 192.168.1.1

# 역방향 조회
nslookup 192.168.1.10 192.168.1.1

# 특정 레코드 타입 조회 (MX)
nslookup -type=MX exam.local 192.168.1.1

# 대화형 모드
nslookup
> server 192.168.1.1
> set type=A
> www.exam.local
```

## 조건부 전달자 설정

내부 DNS가 해석하지 못하는 특정 도메인을 다른 DNS 서버로 전달합니다.

```powershell
# 조건부 전달자 추가
Add-DnsServerConditionalForwarderZone `
  -Name "partner.com" `
  -MasterServers "10.0.0.1"

# 전달자 목록 확인
Get-DnsServerForwarder
```

## 핵심 정리

- 정방향 영역: `Add-DnsServerPrimaryZone -Name "exam.local" -ZoneFile "exam.local.dns"`
- A 레코드: `Add-DnsServerResourceRecordA -Name "www" -ZoneName "exam.local" -IPv4Address "IP"`
- PTR 레코드: `Add-DnsServerResourceRecordPtr -Name "10" -ZoneName "1.168.192.in-addr.arpa" -PtrDomainName "www.exam.local"`
- 캐시 초기화: `Clear-DnsClientCache`, `Clear-DnsServerCache`
- 검증: `nslookup www.exam.local 서버IP`
