## 네트워크 인터페이스 확인

```bash
# 인터페이스 목록과 IP 주소 확인
ip addr show

# 간략 표시
ip addr show dev eth0

# 링크 상태만 확인
ip link show

# 옛날 방식 (ifconfig)
ifconfig -a
ifconfig eth0
```

출력 예시:

```
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP>
    inet 192.168.1.10/24 brd 192.168.1.255 scope global eth0
```

## 임시 IP 설정 (재시작 시 사라짐)

```bash
# IP 주소 추가
ip addr add 192.168.1.10/24 dev eth0

# IP 주소 삭제
ip addr del 192.168.1.10/24 dev eth0

# 인터페이스 활성화/비활성화
ip link set eth0 up
ip link set eth0 down

# 기본 게이트웨이 추가
ip route add default via 192.168.1.1 dev eth0

# 라우팅 테이블 확인
ip route show
```

## 영구 IP 설정 — RHEL/CentOS 7/8

설정 파일 경로: `/etc/sysconfig/network-scripts/ifcfg-eth0`

```bash
# 설정 파일 편집
vi /etc/sysconfig/network-scripts/ifcfg-eth0
```

파일 내용:

```
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.10
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8
DNS2=8.8.4.4
```

설정 적용:

```bash
# 네트워크 서비스 재시작
systemctl restart network

# 또는 NetworkManager 재시작
systemctl restart NetworkManager

# 인터페이스 재시작
ifdown eth0 && ifup eth0
```

## 영구 IP 설정 — Ubuntu 18.04+

Ubuntu는 **Netplan**을 사용합니다.

설정 파일 경로: `/etc/netplan/00-installer-config.yaml`

```bash
vi /etc/netplan/00-installer-config.yaml
```

파일 내용:

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: false
      addresses:
        - 192.168.1.10/24
      gateway4: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
```

설정 적용:

```bash
# 설정 파일 문법 검사 후 적용
netplan try

# 즉시 적용
netplan apply
```

## nmcli 명령 (NetworkManager)

RHEL/CentOS 환경에서 NetworkManager를 통한 네트워크 설정입니다.

```bash
# 연결 목록 확인
nmcli connection show

# 연결 상태 확인
nmcli device status

# 새 연결 추가 (정적 IP)
nmcli connection add \
  type ethernet \
  con-name "eth0-static" \
  ifname eth0 \
  ip4 192.168.1.10/24 \
  gw4 192.168.1.1

# DNS 설정
nmcli connection modify "eth0-static" ipv4.dns "8.8.8.8 8.8.4.4"

# 연결 활성화
nmcli connection up "eth0-static"

# DHCP로 변경
nmcli connection modify eth0 ipv4.method auto
nmcli connection up eth0

# 인터페이스 재시작
nmcli device reapply eth0
```

## DNS 설정

```bash
# /etc/resolv.conf — DNS 서버 설정
cat /etc/resolv.conf

# 직접 편집 (NetworkManager가 덮어쓸 수 있음)
echo "nameserver 8.8.8.8" > /etc/resolv.conf
echo "nameserver 8.8.4.4" >> /etc/resolv.conf

# NetworkManager를 통한 영구 설정이 권장됨
```

## 호스트명 설정

```bash
# 현재 호스트명 확인
hostname
hostnamectl

# 호스트명 변경
hostnamectl set-hostname "server01.exam.local"

# /etc/hosts에 항목 추가
echo "192.168.1.10 server01.exam.local server01" >> /etc/hosts
```

## 네트워크 연결 테스트

```bash
# ping 테스트
ping -c 4 192.168.1.1
ping -c 4 8.8.8.8

# DNS 해석 테스트
nslookup www.google.com
dig www.google.com

# 라우팅 경로 추적
traceroute 8.8.8.8

# 포트 연결 테스트
nc -zv 192.168.1.1 80
```

## 핵심 정리

- 확인: `ip addr show`, `ip route show`
- RHEL/CentOS 영구 설정: `/etc/sysconfig/network-scripts/ifcfg-eth0`
- Ubuntu 영구 설정: `/etc/netplan/00-installer-config.yaml` + `netplan apply`
- nmcli: `nmcli connection add type ethernet con-name 이름 ifname eth0 ip4 IP/24 gw4 GW`
- 재시작: `systemctl restart NetworkManager`
