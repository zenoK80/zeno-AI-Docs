  **이번 문서의 목표:** IIS 웹 서버를 설치하고 새 웹 사이트와 가상 디렉터리를 구성하여 브라우저에서 접속 테스트까지 완료합니다.
</Callout>

## IIS 역할 설치

```powershell
# 기본 웹 서버 설치
Install-WindowsFeature -Name Web-Server -IncludeManagementTools

# 추가 기능 포함 설치 (ASP.NET, 인증 기능 등)
Install-WindowsFeature -Name Web-Server, Web-Asp-Net45, Web-Basic-Auth, Web-Windows-Auth -IncludeManagementTools

# 설치된 IIS 기능 확인
Get-WindowsFeature Web-* | Where-Object Installed -eq $true
```

## 기본 웹 사이트 확인

IIS 설치 후 기본 웹 사이트가 자동 생성됩니다.

- 기본 경로: `C:\inetpub\wwwroot`
- 기본 포트: 80
- 접속 테스트: 브라우저에서 `http://localhost` 또는 `http://서버IP`

```powershell
# WebAdministration 모듈 로드
Import-Module WebAdministration

# 현재 웹 사이트 목록 확인
Get-Website

# 기본 웹 사이트 상태 확인
Get-Website -Name "Default Web Site"
```

## 새 웹 사이트 추가

```powershell
# 웹 사이트 디렉터리 생성
New-Item -Path "C:\WebSites\exam" -ItemType Directory

# index.html 파일 생성 (간단한 테스트용)
Set-Content -Path "C:\WebSites\exam\index.html" -Value "<html><body><h1>Exam Website</h1></body></html>"

# 새 웹 사이트 생성 (8080 포트)
New-Website `
  -Name "ExamSite" `
  -Port 8080 `
  -PhysicalPath "C:\WebSites\exam" `
  -ApplicationPool "DefaultAppPool"

# 웹 사이트 시작
Start-Website -Name "ExamSite"
```

## 가상 디렉터리 생성

```powershell
# 가상 디렉터리 생성
New-WebVirtualDirectory `
  -Site "Default Web Site" `
  -Name "files" `
  -PhysicalPath "C:\SharedFiles"

# 가상 디렉터리 목록 확인
Get-WebVirtualDirectory
```

## 응용 프로그램 풀 설정

```powershell
# 새 응용 프로그램 풀 생성
New-WebAppPool -Name "ExamAppPool"

# .NET 버전 설정
Set-ItemProperty IIS:\AppPools\ExamAppPool -Name managedRuntimeVersion -Value "v4.0"

# ID 설정 (ApplicationPoolIdentity 또는 NetworkService)
Set-ItemProperty IIS:\AppPools\ExamAppPool -Name processModel.userName -Value "NetworkService"

# 응용 프로그램 풀 목록
Get-WebConfiguration /system.applicationHost/applicationPools/add | Select-Object name, state
```

## 인증 방법 설정

| 인증 방법 | 특징 | 사용 사례 |
|-----------|------|-----------|
| 익명 인증 | 인증 없이 누구나 접근 | 공개 웹 사이트 |
| Windows 인증 | AD 계정으로 인증 | 내부 인트라넷 |
| 기본 인증 | ID/PW 평문 전송 | HTTPS와 함께 사용 |
| 다이제스트 인증 | 해시값으로 인증 | 중간 보안 수준 |

```powershell
# 익명 인증 비활성화
Set-WebConfigurationProperty `
  -Filter "/system.webServer/security/authentication/anonymousAuthentication" `
  -Name "enabled" `
  -Value "False" `
  -Location "ExamSite"

# Windows 인증 활성화
Set-WebConfigurationProperty `
  -Filter "/system.webServer/security/authentication/windowsAuthentication" `
  -Name "enabled" `
  -Value "True" `
  -Location "ExamSite"
```

## SSL 인증서 바인딩 (HTTPS)

```powershell
# 자체 서명 인증서 생성
$cert = New-SelfSignedCertificate `
  -DnsName "exam.local" `
  -CertStoreLocation "cert:\LocalMachine\My"

# HTTPS 바인딩 추가 (443 포트)
New-WebBinding `
  -Name "ExamSite" `
  -Protocol "https" `
  -Port 443 `
  -HostHeader ""

# 인증서 바인딩 연결
$binding = Get-WebBinding -Name "ExamSite" -Protocol "https"
$binding.AddSslCertificate($cert.GetCertHashString(), "my")
```

## 로그 경로 확인

IIS 로그 기본 경로:

```
C:\inetpub\logs\LogFiles\W3SVC1\     # Default Web Site (SVC 번호는 사이트 ID)
C:\inetpub\logs\LogFiles\W3SVC2\     # 두 번째 사이트
```

```powershell
# 로그 경로 확인
Get-WebConfigurationProperty -Filter "system.applicationHost/sites/site[@name='Default Web Site']/logFile" -Name "directory"
```

## 접속 테스트

```powershell
# PowerShell로 웹 서버 응답 확인
Invoke-WebRequest -Uri "http://localhost" -UseBasicParsing

# 상태 코드만 확인
(Invoke-WebRequest -Uri "http://localhost" -UseBasicParsing).StatusCode

# 방화벽 80 포트 열기
New-NetFirewallRule -DisplayName "IIS HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
New-NetFirewallRule -DisplayName "IIS HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow
```

## 핵심 정리

- 설치: `Install-WindowsFeature -Name Web-Server -IncludeManagementTools`
- 기본 경로: `C:\inetpub\wwwroot`
- 새 사이트: `New-Website -Name "이름" -Port 포트 -PhysicalPath "경로" -ApplicationPool "풀"`
- 인증: 익명(공개), Windows(내부), 기본(HTTPS 필요)
- 로그: `C:\inetpub\logs\LogFiles\W3SVC1\`
