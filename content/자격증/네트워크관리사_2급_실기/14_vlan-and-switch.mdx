## VLAN 개념

VLAN(Virtual LAN)은 물리적 네트워크를 논리적으로 분리하는 기술입니다.

- **브로드캐스트 도메인 분리:** VLAN 간 브로드캐스트가 전파되지 않음
- **보안 강화:** 다른 VLAN 간 기본적으로 통신 불가 (라우터 필요)
- **유연한 구성:** 물리적 위치와 관계없이 같은 VLAN에 배치 가능
- **VLAN ID:** 1~4094 범위, 기본 VLAN은 VLAN 1

## VLAN 생성

```cisco
! VLAN 10 생성 및 이름 지정
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config-vlan)# exit

! VLAN 20 생성
Switch(config)# vlan 20
Switch(config-vlan)# name Engineering
Switch(config-vlan)# exit

! VLAN 30 생성
Switch(config)# vlan 30
Switch(config-vlan)# name HR
Switch(config-vlan)# exit

! VLAN 목록 확인
Switch# show vlan brief
```

## Access 포트 설정

Access 포트는 단일 VLAN에 속하며 일반 PC·서버를 연결합니다.

```cisco
! Fa0/1을 VLAN 10 (Sales) Access 포트로 설정
Switch(config)# interface fastethernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

! Fa0/2를 VLAN 20 Access 포트로 설정
Switch(config)# interface fastethernet 0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# exit

! 여러 포트 동시 설정
Switch(config)# interface range fastethernet 0/3 - 5
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit
```

## Trunk 포트 설정

Trunk 포트는 여러 VLAN 트래픽을 IEEE 802.1Q 태깅으로 전송합니다. 스위치 간, 스위치-라우터 간 연결에 사용합니다.

```cisco
! Gi0/1을 Trunk 포트로 설정
Switch(config)# interface gigabitethernet 0/1
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk

! 허용할 VLAN 지정 (지정하지 않으면 모든 VLAN 허용)
Switch(config-if)# switchport trunk allowed vlan 10,20,30

! 네이티브 VLAN 변경 (기본은 VLAN 1)
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# exit

! Trunk 상태 확인
Switch# show interfaces trunk
Switch# show interfaces gigabitethernet 0/1 trunk
```

## VLAN 확인 명령어

```cisco
! 전체 VLAN 목록 (간략)
Switch# show vlan brief

! 특정 VLAN 상세 정보
Switch# show vlan id 10

! Trunk 인터페이스 정보
Switch# show interfaces trunk

! 포트별 VLAN 할당 확인
Switch# show interfaces fastethernet 0/1 switchport
```

## Inter-VLAN 라우팅 — Router-on-a-Stick

라우터의 단일 인터페이스에 서브인터페이스를 생성하여 여러 VLAN 간 라우팅을 제공합니다.

### 스위치 설정 (Trunk 포트)

```cisco
! 라우터 연결 포트를 Trunk로 설정
Switch(config)# interface gigabitethernet 0/0
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit
```

### 라우터 설정 (서브인터페이스)

```cisco
! 물리 인터페이스 활성화 (IP 없음)
Router(config)# interface fastethernet 0/0
Router(config-if)# no shutdown
Router(config-if)# exit

! VLAN 10용 서브인터페이스
Router(config)# interface fastethernet 0/0.10
Router(config-subif)# encapsulation dot1q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

! VLAN 20용 서브인터페이스
Router(config)# interface fastethernet 0/0.20
Router(config-subif)# encapsulation dot1q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit

! VLAN 30용 서브인터페이스
Router(config)# interface fastethernet 0/0.30
Router(config-subif)# encapsulation dot1q 30
Router(config-subif)# ip address 192.168.30.1 255.255.255.0
Router(config-subif)# exit
```

각 VLAN의 게이트웨이:
- VLAN 10: 192.168.10.1
- VLAN 20: 192.168.20.1
- VLAN 30: 192.168.30.1

## STP(Spanning Tree Protocol)

STP는 스위치 네트워크에서 루프를 방지하는 프로토콜입니다.

- **루프 문제:** 스위치가 여러 경로로 연결되면 브로드캐스트 폭풍 발생
- **Root Bridge:** STP가 선출하는 기준 스위치 (Bridge ID = 우선순위 + MAC)
- **포트 상태:** Blocking → Listening → Learning → Forwarding

```cisco
! STP Root Bridge 우선순위 낮추기 (숫자가 낮을수록 높은 우선순위)
Switch(config)# spanning-tree vlan 10 priority 4096

! Root Bridge로 강제 지정
Switch(config)# spanning-tree vlan 10 root primary

! STP 상태 확인
Switch# show spanning-tree vlan 10

! STP 요약 확인
Switch# show spanning-tree summary
```

## 핵심 정리

- VLAN 생성: `vlan 번호` → `name 이름`
- Access 포트: `switchport mode access` → `switchport access vlan 번호`
- Trunk 포트: `switchport mode trunk` → `switchport trunk allowed vlan 번호목록`
- Router-on-a-Stick: 서브인터페이스 + `encapsulation dot1q VLAN번호`
- 확인: `show vlan brief`, `show interfaces trunk`
- STP Root: `spanning-tree vlan 번호 root primary`
