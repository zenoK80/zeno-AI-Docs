## IPv4 주소 구조

IPv4 주소는 32비트(4바이트)로 구성되며 점 표기법으로 표현합니다.

```
192  .  168  .  10  .  1
11000000.10101000.00001010.00000001
```

- 각 옥텟(octet)은 8비트, 0~255 범위
- 네트워크 부분 + 호스트 부분으로 구성
- 서브넷 마스크로 네트워크/호스트 경계 결정

## IPv4 클래스

| 클래스 | 시작 비트 | 범위 | 기본 마스크 | 용도 |
|--------|-----------|------|-------------|------|
| A | 0 | 1.0.0.0 ~ 126.255.255.255 | /8 (255.0.0.0) | 대규모 네트워크 |
| B | 10 | 128.0.0.0 ~ 191.255.255.255 | /16 (255.255.0.0) | 중규모 네트워크 |
| C | 110 | 192.0.0.0 ~ 223.255.255.255 | /24 (255.255.255.0) | 소규모 네트워크 |
| D | 1110 | 224.0.0.0 ~ 239.255.255.255 | — | 멀티캐스트 |
| E | 1111 | 240.0.0.0 ~ 255.255.255.255 | — | 실험용 예약 |

특수 주소:
- **127.0.0.1** — 루프백(자기 자신)
- **169.254.x.x** — APIPA(DHCP 실패 시 자동 할당)
- **10.x.x.x, 172.16~31.x.x, 192.168.x.x** — 사설 IP

## CIDR 서브넷 계산 원리

CIDR(Classless Inter-Domain Routing) 표기에서 `/숫자`는 서브넷 마스크의 비트 수를 의미합니다.

```
/26 = 11111111.11111111.11111111.11000000
    = 255      .255     .255     .192
```

**핵심 공식:**
- 서브넷 수 = 2^(빌린 비트 수)
- 호스트 수 = 2^(호스트 비트 수) - 2 (네트워크 주소·브로드캐스트 제외)

## 서브넷 계산 상세 예시

### 예시: 192.168.10.0/26

1단계: 마스크 비트 수 확인
```
/26 → 마지막 옥텟에서 2비트 차용 (24 + 2 = 26)
마지막 옥텟: 11000000 = 192
서브넷 마스크: 255.255.255.192
```

2단계: 서브넷 수와 블록 크기
```
차용 비트 2개 → 서브넷 수: 2^2 = 4
블록 크기: 256 - 192 = 64
```

3단계: 각 서브넷 범위

| 서브넷 | 네트워크 주소 | 사용 가능 범위 | 브로드캐스트 |
|--------|---------------|----------------|--------------|
| 1 | 192.168.10.0 | .1 ~ .62 | 192.168.10.63 |
| 2 | 192.168.10.64 | .65 ~ .126 | 192.168.10.127 |
| 3 | 192.168.10.128 | .129 ~ .190 | 192.168.10.191 |
| 4 | 192.168.10.192 | .193 ~ .254 | 192.168.10.255 |

- **호스트 수:** 2^6 - 2 = 62개 (서브넷당)

## 서브넷팅 실전 문제 3개

**문제 1:** 192.168.5.0 네트워크에서 최소 50개 호스트를 수용하는 서브넷 마스크는?

```
필요 호스트 50개 → 2^n - 2 >= 50
n = 6 → 2^6 - 2 = 62 (충족)
호스트 비트 6개 → 32 - 6 = /26
정답: 255.255.255.192 (/26)
```

**문제 2:** 172.16.0.0/16을 /20으로 서브넷팅하면 서브넷 수는?

```
기본 /16에서 /20으로 → 4비트 차용
서브넷 수: 2^4 = 16개
각 서브넷 호스트 수: 2^12 - 2 = 4094개
```

**문제 3:** IP 10.0.0.130/27의 네트워크 주소와 브로드캐스트 주소는?

```
/27 → 블록 크기 32, 마스크 255.255.255.224
10.0.0.130 ÷ 32 = 4.xxx → 4 × 32 = 128
네트워크 주소: 10.0.0.128
브로드캐스트: 10.0.0.159
사용 범위: 10.0.0.129 ~ 10.0.0.158
```

## IPv6 기본

IPv6는 128비트 주소로 IP 주소 고갈 문제를 해결합니다.

- **표기법:** 16진수 8그룹을 콜론으로 구분
  - 예: `2001:0db8:0000:0000:0000:0000:0000:0001`
- **축약 규칙:**
  - 각 그룹 앞의 0 생략: `2001:db8::1`
  - 연속된 0 그룹은 `::` 로 한 번만 생략
- **주요 주소 유형:**
  - `::1` — 루프백
  - `fe80::/10` — 링크 로컬
  - `2001::/32` — 글로벌 유니캐스트

## 핵심 정리

- IPv4 클래스: A(/8), B(/16), C(/24) 기본 마스크 암기
- 서브넷 수 = 2^(차용 비트), 호스트 수 = 2^(나머지 비트) - 2
- 블록 크기 = 256 - 마스크 마지막 옥텟 값
- 네트워크 주소 = IP AND 서브넷 마스크
- 브로드캐스트 = 네트워크 주소 + 블록 크기 - 1
