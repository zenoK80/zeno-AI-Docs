## 시나리오 1: DNS + DHCP 구성

**조건:**
- 서버 IP: 192.168.1.1/24, 기본 게이트웨이: 192.168.1.254
- 도메인: exam.local
- DHCP 풀: 192.168.1.100 ~ 192.168.1.200
- DHCP 제외: 192.168.1.100 ~ 192.168.1.110 (서버용)
- DNS A 레코드: www.exam.local → 192.168.1.10

### 1단계: 서버 IP 고정 설정

```powershell
# 네트워크 어댑터 이름 확인
Get-NetAdapter

# 고정 IP 설정
New-NetIPAddress `
  -InterfaceAlias "Ethernet" `
  -IPAddress 192.168.1.1 `
  -PrefixLength 24 `
  -DefaultGateway 192.168.1.254

# DNS 서버를 자기 자신으로 설정
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.1.1
```

### 2단계: DNS + DHCP 역할 설치

```powershell
Install-WindowsFeature -Name DNS, DHCP -IncludeManagementTools
```

### 3단계: DNS 영역 및 레코드 생성

```powershell
# 정방향 영역 생성
Add-DnsServerPrimaryZone -Name "exam.local" -ZoneFile "exam.local.dns"

# 역방향 영역 생성
Add-DnsServerPrimaryZone -NetworkId "192.168.1.0/24" -ZoneFile "1.168.192.in-addr.arpa.dns"

# www A 레코드 추가
Add-DnsServerResourceRecordA -Name "www" -ZoneName "exam.local" -IPv4Address "192.168.1.10"

# PTR 레코드 추가
Add-DnsServerResourceRecordPtr `
  -Name "10" `
  -ZoneName "1.168.192.in-addr.arpa" `
  -PtrDomainName "www.exam.local"
```

### 4단계: DHCP 스코프 구성

```powershell
# 스코프 생성
Add-DhcpServerv4Scope `
  -Name "LAN스코프" `
  -StartRange 192.168.1.100 `
  -EndRange 192.168.1.200 `
  -SubnetMask 255.255.255.0 `
  -State Active

# 제외 범위 설정 (서버용)
Add-DhcpServerv4ExclusionRange `
  -ScopeId 192.168.1.0 `
  -StartRange 192.168.1.100 `
  -EndRange 192.168.1.110

# 옵션 설정 (게이트웨이, DNS)
Set-DhcpServerv4OptionValue `
  -ScopeId 192.168.1.0 `
  -Router 192.168.1.254 `
  -DnsServer 192.168.1.1 `
  -DnsDomain "exam.local"

# AD 환경이라면 권한 부여
Add-DhcpServerInDC -DnsName "SERVER01.exam.local" -IPAddress 192.168.1.1
```

### 5단계: 방화벽 및 서비스 확인

```powershell
# DNS, DHCP 서비스 상태 확인
Get-Service DNS, DHCP

# DNS 검증
nslookup www.exam.local 192.168.1.1
```

## 시나리오 2: IIS + FTP 구성

**조건:**
- 웹 루트: C:\WebSite, 포트: 80
- FTP 루트: C:\FTP, 포트: 21
- 익명 접근 금지, 기본 인증만 허용
- FTP 사용자: ftpuser1 (비밀번호: P@ssw0rd!)

### 1단계: IIS와 FTP 기능 설치

```powershell
Install-WindowsFeature -Name Web-Server, Web-Ftp-Server -IncludeManagementTools
```

### 2단계: 웹 사이트 구성

```powershell
# 웹 루트 생성
New-Item -Path "C:\WebSite" -ItemType Directory

# 테스트 페이지 생성
Set-Content -Path "C:\WebSite\index.html" -Value "<html><body><h1>Exam Web Server</h1></body></html>"

# 기본 웹 사이트 루트를 C:\WebSite로 변경
Import-Module WebAdministration
Set-ItemProperty "IIS:\Sites\Default Web Site" -Name physicalPath -Value "C:\WebSite"
```

### 3단계: FTP 사이트 구성

```powershell
# FTP 루트 생성
New-Item -Path "C:\FTP" -ItemType Directory

# FTP 사이트 생성
New-WebFtpSite -Name "FTPSite" -Port 21 -PhysicalPath "C:\FTP"

# 익명 인증 비활성화
Set-WebConfigurationProperty `
  -Filter "/system.ftpServer/security/authentication/anonymousAuthentication" `
  -Name "enabled" -Value "False" `
  -PSPath "IIS:\Sites\FTPSite"

# 기본 인증 활성화
Set-WebConfigurationProperty `
  -Filter "/system.ftpServer/security/authentication/basicAuthentication" `
  -Name "enabled" -Value "True" `
  -PSPath "IIS:\Sites\FTPSite"

# FTP 사용자 생성
net user ftpuser1 "P@ssw0rd!" /add
```

### 4단계: 방화벽 설정

```powershell
# HTTP 포트 허용
New-NetFirewallRule -DisplayName "HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

# FTP 포트 허용
New-NetFirewallRule -DisplayName "FTP" -Direction Inbound -Protocol TCP -LocalPort 21 -Action Allow
New-NetFirewallRule -DisplayName "FTP Data" -Direction Inbound -Protocol TCP -LocalPort 20 -Action Allow
```

### 5단계: 접속 테스트

```powershell
# 웹 서버 테스트
Invoke-WebRequest -Uri "http://localhost" -UseBasicParsing

# FTP 접속 테스트
ftp 192.168.1.1
```

## 시나리오 3: Active Directory 사용자 관리

**조건:**
- 도메인: exam.local (이미 구성됨)
- OU: 영업부, 하위 OU: 서울팀
- 사용자 5명 생성 후 영업팀 그룹에 추가
- GPO: 영업부정책 생성 후 영업부 OU에 연결

### 1단계: OU 생성

```powershell
# 최상위 OU 생성
New-ADOrganizationalUnit -Name "영업부" -Path "DC=exam,DC=local"

# 하위 OU 생성
New-ADOrganizationalUnit -Name "서울팀" -Path "OU=영업부,DC=exam,DC=local"
```

### 2단계: 사용자 5명 생성

```powershell
$password = ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force

# 사용자 1
New-ADUser -Name "홍길동" -SamAccountName "hong" `
  -Path "OU=서울팀,OU=영업부,DC=exam,DC=local" `
  -AccountPassword $password -Enabled $true

# 사용자 2
New-ADUser -Name "김철수" -SamAccountName "kim" `
  -Path "OU=서울팀,OU=영업부,DC=exam,DC=local" `
  -AccountPassword $password -Enabled $true

# 사용자 3
New-ADUser -Name "이영희" -SamAccountName "lee" `
  -Path "OU=서울팀,OU=영업부,DC=exam,DC=local" `
  -AccountPassword $password -Enabled $true

# 사용자 4
New-ADUser -Name "박민준" -SamAccountName "park" `
  -Path "OU=서울팀,OU=영업부,DC=exam,DC=local" `
  -AccountPassword $password -Enabled $true

# 사용자 5
New-ADUser -Name "최지우" -SamAccountName "choi" `
  -Path "OU=서울팀,OU=영업부,DC=exam,DC=local" `
  -AccountPassword $password -Enabled $true
```

### 3단계: 그룹 생성 및 사용자 추가

```powershell
# 영업팀 보안 그룹 생성
New-ADGroup -Name "영업팀" -GroupScope Global -GroupCategory Security `
  -Path "OU=영업부,DC=exam,DC=local"

# 5명 일괄 추가
Add-ADGroupMember -Identity "영업팀" -Members "hong","kim","lee","park","choi"

# 확인
Get-ADGroupMember -Identity "영업팀"
```

### 4단계: GPO 생성 및 연결

```powershell
# GPO 생성
New-GPO -Name "영업부정책"

# OU에 연결
New-GPLink -Name "영업부정책" -Target "OU=영업부,DC=exam,DC=local"

# 정책 즉시 적용
gpupdate /force

# 확인
Get-GPO -Name "영업부정책"
```

## 핵심 정리

- Windows 작업 순서: IP 고정 → 역할 설치 → 서비스 구성 → 방화벽 → 테스트
- DNS + DHCP: 역할 한 번에 설치 가능 (`-Name DNS, DHCP`)
- IIS + FTP: Web-Server와 Web-Ftp-Server 함께 설치
- AD 사용자: 비밀번호 SecureString 변환 후 `-AccountPassword`, `-Enabled $true` 필수
- GPO 적용: `New-GPO` → `New-GPLink` → `gpupdate /force`
