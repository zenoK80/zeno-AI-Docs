## Apache 설치

```bash
# RHEL/CentOS
yum install httpd -y

# Ubuntu/Debian
apt-get install apache2 -y

# 설치 확인
httpd -v       # RHEL
apache2 -v     # Ubuntu
```

## 주요 설정 파일

| 파일/디렉터리 | 설명 |
|---------------|------|
| `/etc/httpd/conf/httpd.conf` | 메인 설정 파일 (RHEL) |
| `/etc/apache2/apache2.conf` | 메인 설정 파일 (Ubuntu) |
| `/etc/httpd/conf.d/` | 추가 설정 파일 디렉터리 (RHEL) |
| `/etc/apache2/sites-available/` | 가상 호스트 설정 (Ubuntu) |
| `/var/www/html/` | 기본 웹 루트 |
| `/var/log/httpd/` | 로그 디렉터리 (RHEL) |
| `/var/log/apache2/` | 로그 디렉터리 (Ubuntu) |

## httpd.conf 핵심 지시어

```bash
vi /etc/httpd/conf/httpd.conf
```

```apache
# 서버 루트 (설정 파일 기준 경로)
ServerRoot "/etc/httpd"

# 청취 포트
Listen 80

# 서버 이름 (도메인:포트)
ServerName exam.local:80

# 관리자 이메일
ServerAdmin admin@exam.local

# 기본 웹 루트
DocumentRoot "/var/www/html"

# 기본 문서 파일 순서
DirectoryIndex index.html index.htm index.php

# Directory 블록 (접근 권한)
<Directory "/var/www/html">
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted
</Directory>

# 로그 형식 및 경로
ErrorLog "/var/log/httpd/error_log"
CustomLog "/var/log/httpd/access_log" combined
```

## 테스트 페이지 생성

```bash
# 웹 루트에 index.html 생성
echo "<html><body><h1>Apache Test</h1></body></html>" > /var/www/html/index.html
```

## 가상 호스트 설정

여러 도메인을 하나의 서버에서 서비스할 때 가상 호스트를 사용합니다.

```bash
# RHEL: 별도 설정 파일 생성
vi /etc/httpd/conf.d/vhost.conf
```

```apache
# www.exam.local 가상 호스트
<VirtualHost *:80>
    ServerName www.exam.local
    ServerAlias exam.local
    DocumentRoot /var/www/exam
    ServerAdmin admin@exam.local

    ErrorLog /var/log/httpd/exam_error.log
    CustomLog /var/log/httpd/exam_access.log combined

    <Directory /var/www/exam>
        Options Indexes FollowSymLinks
        AllowOverride None
        Require all granted
    </Directory>
</VirtualHost>

# lab.exam.local 가상 호스트
<VirtualHost *:80>
    ServerName lab.exam.local
    DocumentRoot /var/www/lab

    ErrorLog /var/log/httpd/lab_error.log
    CustomLog /var/log/httpd/lab_access.log combined
</VirtualHost>
```

```bash
# 가상 호스트 디렉터리 생성
mkdir -p /var/www/exam
mkdir -p /var/www/lab

echo "<h1>Exam Site</h1>" > /var/www/exam/index.html
echo "<h1>Lab Site</h1>" > /var/www/lab/index.html
```

## 설정 검증 및 서비스 시작

```bash
# 설정 파일 문법 검사
httpd -t
# 또는
apachectl configtest

# 정상 출력
# Syntax OK

# 서비스 시작 및 자동 등록
systemctl enable --now httpd

# 상태 확인
systemctl status httpd

# 설정 변경 후 재시작
systemctl restart httpd

# 서비스 재로드 (서비스 중단 없이 설정 적용)
systemctl reload httpd
```

## 방화벽 설정

```bash
# HTTP 서비스 허용
firewall-cmd --permanent --add-service=http

# HTTPS 서비스 허용
firewall-cmd --permanent --add-service=https

# 방화벽 규칙 적용
firewall-cmd --reload

# 현재 규칙 확인
firewall-cmd --list-all
```

## SELinux 설정

SELinux가 활성화된 경우 웹 루트 파일에 올바른 컨텍스트를 설정해야 합니다.

```bash
# SELinux 상태 확인
getenforce
sestatus

# 웹 루트 컨텍스트 확인
ls -Z /var/www/html/

# 커스텀 디렉터리에 컨텍스트 적용
chcon -R -t httpd_sys_content_t /var/www/exam
chcon -R -t httpd_sys_content_t /var/www/lab

# 영구적으로 적용 (restorecon 후에도 유지)
semanage fcontext -a -t httpd_sys_content_t "/var/www/exam(/.*)?"
restorecon -Rv /var/www/exam

# SELinux 임시 비활성화 (테스트용)
setenforce 0

# SELinux 영구 비활성화 (파일 수정)
vi /etc/selinux/config
# SELINUX=disabled
```

## 접속 테스트

```bash
# curl로 로컬 테스트
curl http://localhost

# 응답 헤더 포함 확인
curl -I http://localhost

# 가상 호스트 테스트 (Host 헤더 지정)
curl -H "Host: www.exam.local" http://192.168.1.10

# wget 사용
wget -qO- http://localhost
```

## 주요 Apache 모듈

| 모듈 | 기능 |
|------|------|
| mod_rewrite | URL 재작성 |
| mod_ssl | HTTPS/SSL 지원 |
| mod_auth_basic | 기본 인증 |
| mod_dir | 디렉터리 인덱스 |
| mod_alias | URL 별칭 |

```bash
# 모듈 로드 상태 확인
httpd -M

# mod_rewrite 활성화 (Ubuntu)
a2enmod rewrite
systemctl restart apache2
```

## 핵심 정리

- 설치: `yum install httpd -y`
- 메인 설정: `/etc/httpd/conf/httpd.conf`
- 가상 호스트: `/etc/httpd/conf.d/vhost.conf`
- 문법 검사: `httpd -t`
- 서비스: `systemctl enable --now httpd`
- 방화벽: `firewall-cmd --permanent --add-service=http`
- SELinux: `chcon -R -t httpd_sys_content_t /var/www/경로`
