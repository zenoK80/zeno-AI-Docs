## OSI 7계층 구조

OSI(Open Systems Interconnection) 모델은 네트워크 통신을 7개의 계층으로 나눈 국제 표준입니다. 각 계층은 역할이 분리되어 있어 문제 진단과 설계에 활용됩니다.

| 계층 번호 | 계층 이름 | 역할 | PDU | 대표 프로토콜/장비 |
|-----------|-----------|------|-----|--------------------|
| 7 | 응용(Application) | 사용자 인터페이스, 서비스 제공 | 데이터 | HTTP, FTP, SMTP, DNS |
| 6 | 표현(Presentation) | 데이터 형식 변환, 암호화, 압축 | 데이터 | SSL/TLS, JPEG, ASCII |
| 5 | 세션(Session) | 세션 설정·유지·종료 | 데이터 | NetBIOS, RPC |
| 4 | 전송(Transport) | 종단 간 신뢰성 있는 전송, 포트 | 세그먼트 | TCP, UDP |
| 3 | 네트워크(Network) | 논리 주소(IP), 경로 설정 | 패킷 | IP, ICMP, OSPF |
| 2 | 데이터 링크(Data Link) | 물리 주소(MAC), 오류 감지 | 프레임 | Ethernet, PPP |
| 1 | 물리(Physical) | 비트 전송, 전기 신호 | 비트 | 케이블, 허브 |

> 암기법: **아파서 탄 네 데이터 물** (응용-표현-세션-전송-네트워크-데이터링크-물리)

## TCP/IP 4계층 대응

| TCP/IP 계층 | OSI 대응 계층 | 주요 프로토콜 |
|-------------|---------------|---------------|
| 응용(Application) | 5·6·7계층 | HTTP, FTP, DNS, SMTP |
| 전송(Transport) | 4계층 | TCP, UDP |
| 인터넷(Internet) | 3계층 | IP, ICMP, ARP |
| 네트워크 접근(Network Access) | 1·2계층 | Ethernet, Wi-Fi |

## 계층별 네트워크 장비

실기 시험에서 장비가 어느 계층에서 동작하는지 묻는 문제가 자주 출제됩니다.

| 장비 | 동작 계층 | 특징 |
|------|-----------|------|
| 리피터(Repeater) | 1계층(물리) | 신호 증폭, MAC/IP 구분 불가 |
| 허브(Hub) | 1계층(물리) | 모든 포트로 브로드캐스트 |
| 브리지(Bridge) | 2계층(데이터링크) | MAC 주소 기반 포워딩 |
| 스위치(Switch) | 2계층(데이터링크) | MAC 테이블로 선택적 전송 |
| 라우터(Router) | 3계층(네트워크) | IP 주소 기반 경로 결정 |
| 게이트웨이(Gateway) | 7계층(응용) | 프로토콜 변환 |

## 캡슐화와 역캡슐화

데이터가 송신 측에서 수신 측으로 전달될 때 각 계층을 지나며 헤더가 추가되거나 제거됩니다.

- **캡슐화(Encapsulation):** 상위 계층에서 하위 계층으로 내려가며 헤더 추가
  - 응용 데이터 → 세그먼트(TCP 헤더 추가) → 패킷(IP 헤더 추가) → 프레임(MAC 헤더 추가) → 비트
- **역캡슐화(Decapsulation):** 수신 측에서 하위 계층에서 상위 계층으로 올라가며 헤더 제거

## 포트 번호 필수 암기

실기 시험에서 서비스 설정 시 방화벽 규칙, DNS 레코드, 서버 포트를 직접 입력합니다. 반드시 암기하세요.

| 포트 번호 | 프로토콜 | 서비스 | 전송 프로토콜 |
|-----------|----------|--------|---------------|
| 20 | FTP-DATA | FTP 데이터 전송 | TCP |
| 21 | FTP | FTP 제어 | TCP |
| 22 | SSH | 암호화 원격 접속 | TCP |
| 23 | Telnet | 평문 원격 접속 | TCP |
| 25 | SMTP | 메일 발송 | TCP |
| 53 | DNS | 도메인 이름 해석 | TCP/UDP |
| 80 | HTTP | 웹 서비스 | TCP |
| 110 | POP3 | 메일 수신 | TCP |
| 143 | IMAP | 메일 수신(서버 보관) | TCP |
| 443 | HTTPS | 암호화 웹 서비스 | TCP |
| 3389 | RDP | Windows 원격 데스크톱 | TCP |

## 핵심 정리

- OSI 7계층은 **물리-데이터링크-네트워크-전송-세션-표현-응용** 순서
- TCP/IP는 4계층으로 OSI를 실용적으로 단순화한 모델
- 스위치는 2계층(MAC), 라우터는 3계층(IP) 장비
- 캡슐화는 송신 측에서 헤더를 **추가**, 역캡슐화는 수신 측에서 헤더를 **제거**
- FTP(20/21), SSH(22), DNS(53), HTTP(80), HTTPS(443), RDP(3389) 포트 필수 암기
