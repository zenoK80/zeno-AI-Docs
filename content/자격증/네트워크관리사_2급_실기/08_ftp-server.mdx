## FTP 기능 설치

```powershell
# IIS FTP 서버 기능 설치 (IIS가 이미 설치된 경우)
Install-WindowsFeature -Name Web-Ftp-Server -IncludeManagementTools

# IIS와 FTP 동시 설치
Install-WindowsFeature -Name Web-Server, Web-Ftp-Server -IncludeManagementTools

# 설치 확인
Get-WindowsFeature Web-Ftp-*
```

## FTP 사이트 생성

```powershell
# FTP 루트 디렉터리 생성
New-Item -Path "C:\FTP" -ItemType Directory

# FTP 사이트 생성
New-WebFtpSite `
  -Name "FTPSite" `
  -Port 21 `
  -PhysicalPath "C:\FTP"

# FTP 사이트 상태 확인
Get-Website -Name "FTPSite"

# FTP 사이트 시작
Start-Website -Name "FTPSite"
```

## FTP 인증 설정

### 익명 인증 (비권장 — 테스트용)

```powershell
# 익명 FTP 허용 설정
Set-WebConfigurationProperty `
  -Filter "/system.ftpServer/security/authentication/anonymousAuthentication" `
  -Name "enabled" `
  -Value "True" `
  -PSPath "IIS:\Sites\FTPSite"
```

### 기본 인증 (사용자명/비밀번호)

```powershell
# 기본 인증 활성화
Set-WebConfigurationProperty `
  -Filter "/system.ftpServer/security/authentication/basicAuthentication" `
  -Name "enabled" `
  -Value "True" `
  -PSPath "IIS:\Sites\FTPSite"

# 익명 인증 비활성화 (보안)
Set-WebConfigurationProperty `
  -Filter "/system.ftpServer/security/authentication/anonymousAuthentication" `
  -Name "enabled" `
  -Value "False" `
  -PSPath "IIS:\Sites\FTPSite"
```

## 사용자 격리 설정

FTP 사용자 격리를 사용하면 각 사용자가 자신의 홈 디렉터리에만 접근하여 보안이 강화됩니다.

디렉터리 구조:

```
C:\FTP\
  LocalUser\
    ftpuser1\       ← ftpuser1 전용 홈 폴더
    ftpuser2\       ← ftpuser2 전용 홈 폴더
```

```powershell
# 사용자 격리 활성화
Set-WebConfigurationProperty `
  -Filter "system.ftpServer/security/userIsolation" `
  -Name "mode" `
  -Value "IsolateRootDirectoryOnly" `
  -PSPath "IIS:\Sites\FTPSite"

# 사용자별 폴더 생성
New-Item -Path "C:\FTP\LocalUser\ftpuser1" -ItemType Directory
New-Item -Path "C:\FTP\LocalUser\ftpuser2" -ItemType Directory

# FTP 전용 로컬 사용자 생성
net user ftpuser1 "P@ssw0rd!" /add
net user ftpuser2 "P@ssw0rd!" /add
```

## 능동(Active) vs 수동(Passive) 모드

| 항목 | 능동(Active) 모드 | 수동(Passive) 모드 |
|------|------------------|--------------------|
| 제어 포트 | 21 (서버) | 21 (서버) |
| 데이터 포트 | 20 (서버) → 클라이언트 | 클라이언트 → 서버 고포트 |
| 연결 방향 | 서버가 클라이언트에 접속 | 클라이언트가 서버에 접속 |
| NAT/방화벽 | 클라이언트 방화벽 이슈 多 | 일반적으로 방화벽 통과 용이 |
| 권장 | 내부망 | 인터넷·NAT 환경 |

## 방화벽 설정

```powershell
# FTP 제어 포트 허용
New-NetFirewallRule -DisplayName "FTP Control" -Direction Inbound -Protocol TCP -LocalPort 21 -Action Allow

# 능동 모드 데이터 포트 허용
New-NetFirewallRule -DisplayName "FTP Data Active" -Direction Inbound -Protocol TCP -LocalPort 20 -Action Allow

# 수동 모드 데이터 포트 범위 허용 (예: 50000~50100)
New-NetFirewallRule -DisplayName "FTP Data Passive" -Direction Inbound -Protocol TCP -LocalPort 50000-50100 -Action Allow
```

## FTPS (FTP over SSL) 설정

```powershell
# 자체 서명 인증서 생성
$cert = New-SelfSignedCertificate `
  -DnsName "ftp.exam.local" `
  -CertStoreLocation "cert:\LocalMachine\My"

# FTP 사이트에 SSL 인증서 적용
Set-WebConfigurationProperty `
  -Filter "system.applicationHost/sites/site[@name='FTPSite']/ftpServer/security/ssl" `
  -Name "serverCertHash" `
  -Value $cert.Thumbprint

# SSL 정책 설정 (Allow 또는 Require)
Set-WebConfigurationProperty `
  -Filter "system.applicationHost/sites/site[@name='FTPSite']/ftpServer/security/ssl" `
  -Name "controlChannelPolicy" `
  -Value "SslAllow"
```

## FTP 접속 테스트

```powershell
# 명령줄 FTP 클라이언트
ftp 192.168.1.1

# PowerShell로 FTP 접속 테스트
$ftp = [System.Net.FtpWebRequest]::Create("ftp://192.168.1.1/")
$ftp.Credentials = New-Object System.Net.NetworkCredential("ftpuser1", "P@ssw0rd!")
$ftp.Method = [System.Net.WebRequestMethods+Ftp]::ListDirectory
$response = $ftp.GetResponse()
Write-Output $response.StatusDescription
```

## 핵심 정리

- 설치: `Install-WindowsFeature -Name Web-Ftp-Server`
- 사이트 생성: `New-WebFtpSite -Name "FTPSite" -Port 21 -PhysicalPath "C:\FTP"`
- 익명 접근 금지 → 기본 인증만 활성화
- 사용자 격리: `C:\FTP\LocalUser\사용자명` 구조
- 방화벽: 21(제어), 20(능동), 수동 포트 범위 허용
- 능동 모드: 서버가 데이터 연결 개시 / 수동 모드: 클라이언트가 데이터 연결 개시
