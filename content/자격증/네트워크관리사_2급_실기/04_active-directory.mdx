## AD DS 역할 설치 및 도메인 구성 순서

1. AD DS 역할 설치
2. 도메인 컨트롤러 승격 (새 포레스트 생성 또는 기존 도메인 가입)
3. 재시작 후 도메인 계정으로 로그인
4. OU, 사용자, 그룹 생성
5. 그룹 정책 설정

## AD DS 역할 설치

```powershell
# AD DS 역할과 관리 도구 설치
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

# 설치 확인
Get-WindowsFeature AD-Domain-Services
```

## 도메인 컨트롤러 승격 — 새 포레스트

```powershell
# ADDSDeployment 모듈 임포트
Import-Module ADDSDeployment

# 새 포레스트와 도메인 생성 (exam.local)
Install-ADDSForest `
  -DomainName "exam.local" `
  -DomainNetbiosName "EXAM" `
  -ForestMode "WinThreshold" `
  -DomainMode "WinThreshold" `
  -InstallDns:$true `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Force:$true
```

승격 후 서버가 자동으로 재시작됩니다. 재시작 후 `EXAM\Administrator`로 로그인합니다.

## 기존 도메인에 DC 추가

```powershell
Install-ADDSDomainController `
  -DomainName "exam.local" `
  -InstallDns:$true `
  -Credential (Get-Credential) `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Force:$true
```

## OU(조직 구성 단위) 생성

```powershell
# 최상위 OU 생성
New-ADOrganizationalUnit -Name "영업부" -Path "DC=exam,DC=local"

# 중첩 OU 생성
New-ADOrganizationalUnit -Name "서울팀" -Path "OU=영업부,DC=exam,DC=local"

# OU 목록 확인
Get-ADOrganizationalUnit -Filter *
```

## 도메인 사용자 생성

```powershell
# 기본 사용자 생성
New-ADUser `
  -Name "홍길동" `
  -GivenName "길동" `
  -Surname "홍" `
  -SamAccountName "gildong" `
  -UserPrincipalName "gildong@exam.local" `
  -Path "OU=영업부,DC=exam,DC=local" `
  -AccountPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Enabled $true

# 사용자 목록 확인
Get-ADUser -Filter * | Select-Object Name, SamAccountName, Enabled

# 특정 사용자 상세 정보
Get-ADUser -Identity "gildong" -Properties *
```

## 사용자 계정 관리

```powershell
# 계정 잠금 해제 (시험 빈출!)
Unlock-ADAccount -Identity "gildong"

# 비밀번호 재설정
Set-ADAccountPassword -Identity "gildong" `
  -NewPassword (ConvertTo-SecureString "NewP@ss!" -AsPlainText -Force) `
  -Reset

# 계정 비활성화 / 활성화
Disable-ADAccount -Identity "gildong"
Enable-ADAccount -Identity "gildong"

# 다음 로그인 시 비밀번호 변경 강제
Set-ADUser -Identity "gildong" -ChangePasswordAtLogon $true
```

## 그룹 생성 및 사용자 추가

```powershell
# 보안 그룹 생성
New-ADGroup `
  -Name "영업팀" `
  -GroupScope Global `
  -GroupCategory Security `
  -Path "OU=영업부,DC=exam,DC=local"

# 그룹에 사용자 추가
Add-ADGroupMember -Identity "영업팀" -Members "gildong"

# 여러 사용자 한 번에 추가
Add-ADGroupMember -Identity "영업팀" -Members "user1","user2","user3"

# 그룹 멤버 확인
Get-ADGroupMember -Identity "영업팀"
```

## 그룹 정책(GPO) 설정

```powershell
# 새 GPO 생성
New-GPO -Name "영업부정책" -Comment "영업부 보안 정책"

# GPO를 OU에 연결
New-GPLink -Name "영업부정책" -Target "OU=영업부,DC=exam,DC=local"

# GPO 목록 확인
Get-GPO -All

# GPO 설정 적용 강제
gpupdate /force
```

## 도메인 가입 (클라이언트)

```powershell
# 클라이언트 컴퓨터를 도메인에 가입
Add-Computer `
  -DomainName "exam.local" `
  -Credential (Get-Credential) `
  -Restart
```

## 핵심 정리

- AD DS 설치: `Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools`
- 포레스트 생성: `Install-ADDSForest -DomainName "exam.local"`
- OU 생성: `New-ADOrganizationalUnit -Name "이름" -Path "DC=exam,DC=local"`
- 사용자 생성: `New-ADUser -Name "이름" -SamAccountName "계정명" -AccountPassword ...`
- 계정 잠금 해제: `Unlock-ADAccount -Identity "계정명"` (시험 빈출!)
- 도메인 가입: `Add-Computer -DomainName "exam.local" -Credential ...`
