## 서버 관리자(Server Manager) 역할 설치

GUI 방식은 서버 관리자 → **역할 및 기능 추가**(Add Roles and Features) 마법사를 사용합니다.

순서:
1. 서버 관리자 열기 (시작 메뉴 또는 `servermanager.exe`)
2. **관리** → **역할 및 기능 추가** 클릭
3. 설치 유형: **역할 기반 또는 기능 기반 설치** 선택
4. 서버 선택 후 설치할 역할 체크
5. 필요한 관리 도구 포함 여부 확인 후 설치
6. 설치 완료 후 **재시작 필요** 여부 확인

## PowerShell로 역할 설치

시험에서는 PowerShell 명령이 더 빠릅니다. `Install-WindowsFeature` cmdlet을 사용합니다.

```powershell
# 역할 이름 확인
Get-WindowsFeature | Where-Object Installed -eq $false | Select-Object Name, DisplayName

# 기본 설치 형식
Install-WindowsFeature -Name <역할이름> -IncludeManagementTools

# 재시작 필요 시 자동 재시작 옵션
Install-WindowsFeature -Name <역할이름> -IncludeManagementTools -Restart
```

## 자주 설치하는 역할 목록

| 역할 표시 이름 | PowerShell 이름 | 설명 |
|----------------|-----------------|------|
| DNS 서버 | `DNS` | 도메인 이름 해석 서비스 |
| DHCP 서버 | `DHCP` | IP 자동 할당 서비스 |
| 웹 서버(IIS) | `Web-Server` | HTTP/HTTPS 웹 서비스 |
| FTP 서버 | `Web-Ftp-Server` | FTP 파일 전송 서비스 |
| Active Directory DS | `AD-Domain-Services` | 도메인 컨트롤러 |
| 파일 서비스 | `File-Services` | 파일 공유 서비스 |

```powershell
# DNS 서버 설치
Install-WindowsFeature -Name DNS -IncludeManagementTools

# DHCP 서버 설치
Install-WindowsFeature -Name DHCP -IncludeManagementTools

# IIS 웹 서버 설치
Install-WindowsFeature -Name Web-Server -IncludeManagementTools

# AD DS 설치
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
```

## 컴퓨터 이름 변경

```powershell
# 컴퓨터 이름 변경 (재시작 필요)
Rename-Computer -NewName "SERVER01" -Restart

# 재시작 없이 이름만 변경
Rename-Computer -NewName "SERVER01"
```

## 고정 IP 설정

DHCP 대신 서버에 고정 IP를 설정할 때 사용합니다.

```powershell
# 네트워크 어댑터 이름 확인
Get-NetAdapter

# 고정 IP 설정
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.1 -PrefixLength 24 -DefaultGateway 192.168.1.254

# DNS 서버 설정
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.1.1

# 기존 IP 제거 후 재설정 시
Remove-NetIPAddress -InterfaceAlias "Ethernet" -Confirm:$false
```

## 방화벽 인바운드 규칙 추가

서비스 포트를 방화벽에서 허용해야 외부에서 접근 가능합니다.

```powershell
# HTTP(80) 포트 허용
New-NetFirewallRule -DisplayName "HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

# HTTPS(443) 포트 허용
New-NetFirewallRule -DisplayName "HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

# FTP(21) 포트 허용
New-NetFirewallRule -DisplayName "FTP" -Direction Inbound -Protocol TCP -LocalPort 21 -Action Allow

# DNS(53) 포트 허용
New-NetFirewallRule -DisplayName "DNS" -Direction Inbound -Protocol UDP -LocalPort 53 -Action Allow

# 방화벽 규칙 확인
Get-NetFirewallRule -DisplayName "HTTP"
```

## 서비스 시작·중지·확인

```powershell
# 서비스 상태 확인
Get-Service -Name "DNS"
Get-Service -Name "DHCP"
Get-Service -Name "W3SVC"   # IIS 웹 서비스

# 서비스 시작
Start-Service -Name "DNS"

# 서비스 중지
Stop-Service -Name "DNS"

# 서비스 재시작
Restart-Service -Name "DNS"

# 자동 시작 설정
Set-Service -Name "DNS" -StartupType Automatic
```

## 이벤트 뷰어

문제 진단 시 이벤트 뷰어에서 오류 로그를 확인합니다.

실행 방법:
- `eventvwr.msc` 실행
- 서버 관리자 → 도구 → 이벤트 뷰어

주요 로그 위치:
- **Windows 로그 → 응용 프로그램:** 애플리케이션 오류
- **Windows 로그 → 시스템:** 시스템 서비스 오류
- **Windows 로그 → 보안:** 로그인 성공/실패

```powershell
# PowerShell로 이벤트 로그 확인
Get-EventLog -LogName System -Newest 20
Get-EventLog -LogName Application -EntryType Error -Newest 10
```

## 핵심 정리

- 역할 설치: `Install-WindowsFeature -Name <이름> -IncludeManagementTools`
- 고정 IP: `New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress X.X.X.X -PrefixLength 24`
- 방화벽 규칙: `New-NetFirewallRule -DisplayName "이름" -Direction Inbound -Protocol TCP -LocalPort 포트 -Action Allow`
- 서비스: `Start-Service`, `Stop-Service`, `Get-Service`
- 이벤트 뷰어: `eventvwr.msc`
