## 시나리오 1: Linux DNS + Apache 구성

**조건:**
- 서버 IP: 192.168.1.10/24, GW: 192.168.1.1
- 도메인: lab.local
- 웹 루트: /var/www/lab
- DNS A 레코드: www.lab.local → 192.168.1.10

### 1단계: IP 설정 및 확인

```bash
# IP 설정 확인
ip addr show eth0

# 영구 IP 설정 (RHEL/CentOS)
cat > /etc/sysconfig/network-scripts/ifcfg-eth0 << 'EOF'
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.10
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=192.168.1.10
EOF

systemctl restart NetworkManager
```

### 2단계: BIND DNS 설치 및 설정

```bash
# BIND 설치
yum install bind bind-utils -y

# named.conf 설정
cat > /etc/named.conf << 'EOF'
options {
    listen-on port 53 { any; };
    directory "/var/named";
    allow-query { any; };
    recursion yes;
};

zone "." IN {
    type hint;
    file "named.ca";
};

zone "lab.local" IN {
    type master;
    file "lab.local.zone";
    allow-update { none; };
};

zone "1.168.192.in-addr.arpa" IN {
    type master;
    file "1.168.192.zone";
    allow-update { none; };
};
EOF
```

### 3단계: 영역 파일 작성

```bash
# 정방향 영역 파일
cat > /var/named/lab.local.zone << 'EOF'
$TTL 86400
@   IN  SOA     ns1.lab.local. root.lab.local. (
                    2024010101
                    3600
                    1800
                    604800
                    86400 )

@   IN  NS      ns1.lab.local.
ns1     IN  A   192.168.1.10
www     IN  A   192.168.1.10
mail    IN  A   192.168.1.20
EOF

# 역방향 영역 파일
cat > /var/named/1.168.192.zone << 'EOF'
$TTL 86400
@   IN  SOA     ns1.lab.local. root.lab.local. (
                    2024010101
                    3600
                    1800
                    604800
                    86400 )

@   IN  NS      ns1.lab.local.
10  IN  PTR     www.lab.local.
20  IN  PTR     mail.lab.local.
EOF

# 파일 권한 설정
chown root:named /var/named/lab.local.zone /var/named/1.168.192.zone
chmod 640 /var/named/lab.local.zone /var/named/1.168.192.zone
```

### 4단계: DNS 검증 및 서비스 시작

```bash
# 설정 검증
named-checkconf /etc/named.conf
named-checkzone lab.local /var/named/lab.local.zone
named-checkzone 1.168.192.in-addr.arpa /var/named/1.168.192.zone

# 서비스 시작
systemctl enable --now named

# 방화벽 허용
firewall-cmd --permanent --add-service=dns
firewall-cmd --reload

# 테스트
dig @localhost www.lab.local
dig @localhost -x 192.168.1.10
```

### 5단계: Apache 웹 서버 설치 및 구성

```bash
# Apache 설치
yum install httpd -y

# 웹 루트 생성
mkdir -p /var/www/lab

# 테스트 페이지 생성
echo "<html><body><h1>Lab Web Server</h1></body></html>" > /var/www/lab/index.html

# 가상 호스트 설정
cat > /etc/httpd/conf.d/lab.conf << 'EOF'
<VirtualHost *:80>
    ServerName www.lab.local
    DocumentRoot /var/www/lab
    ErrorLog /var/log/httpd/lab_error.log
    CustomLog /var/log/httpd/lab_access.log combined

    <Directory /var/www/lab>
        Options Indexes FollowSymLinks
        AllowOverride None
        Require all granted
    </Directory>
</VirtualHost>
EOF

# SELinux 컨텍스트 설정
chcon -R -t httpd_sys_content_t /var/www/lab

# 설정 검증
httpd -t

# 서비스 시작
systemctl enable --now httpd

# 방화벽 허용
firewall-cmd --permanent --add-service=http
firewall-cmd --reload

# 테스트
curl http://www.lab.local
```

## 시나리오 2: Cisco 라우터 2대 정적 라우팅

**조건:**
- R1: Fa0/0 = 192.168.1.1/24 (LAN1), Fa0/1 = 10.0.0.1/30 (WAN)
- R2: Fa0/0 = 10.0.0.2/30 (WAN), Fa0/1 = 192.168.2.1/24 (LAN2)
- 목표: LAN1(192.168.1.x) ↔ LAN2(192.168.2.x) 양방향 통신

### R1 설정

```cisco
! R1 기본 설정
Router> enable
Router# configure terminal
Router(config)# hostname R1

! LAN1 인터페이스 설정
R1(config)# interface fastethernet 0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# description LAN1
R1(config-if)# no shutdown
R1(config-if)# exit

! WAN 인터페이스 설정
R1(config)# interface fastethernet 0/1
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# description WAN to R2
R1(config-if)# no shutdown
R1(config-if)# exit

! 정적 경로: LAN2 (192.168.2.0/24) → R2 방향
R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

! 설정 저장
R1# copy running-config startup-config
```

### R2 설정

```cisco
! R2 기본 설정
Router> enable
Router# configure terminal
Router(config)# hostname R2

! WAN 인터페이스 설정
R2(config)# interface fastethernet 0/0
R2(config-if)# ip address 10.0.0.2 255.255.255.252
R2(config-if)# description WAN to R1
R2(config-if)# no shutdown
R2(config-if)# exit

! LAN2 인터페이스 설정
R2(config)# interface fastethernet 0/1
R2(config-if)# ip address 192.168.2.1 255.255.255.0
R2(config-if)# description LAN2
R2(config-if)# no shutdown
R2(config-if)# exit

! 정적 경로: LAN1 (192.168.1.0/24) → R1 방향
R2(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1

! 설정 저장
R2# copy running-config startup-config
```

### 검증

```cisco
! R1에서 확인
R1# show ip route
R1# show ip interface brief
R1# ping 192.168.2.1      ! LAN2 게이트웨이 ping

! R2에서 확인
R2# show ip route
R2# ping 192.168.1.1      ! LAN1 게이트웨이 ping
```

## 시나리오 3: VLAN 구성 + Inter-VLAN 라우팅 (Router-on-a-Stick)

**조건:**
- VLAN 10: Sales (192.168.10.0/24), GW: 192.168.10.1
- VLAN 20: HR (192.168.20.0/24), GW: 192.168.20.1
- 스위치 Fa0/1~5: VLAN 10, Fa0/6~10: VLAN 20
- 스위치 Gi0/1: 라우터 연결 (Trunk)

### 스위치 설정

```cisco
Switch> enable
Switch# configure terminal

! VLAN 생성
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config)# vlan 20
Switch(config-vlan)# name HR

! Access 포트 설정 (VLAN 10)
Switch(config)# interface range fastethernet 0/1 - 5
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

! Access 포트 설정 (VLAN 20)
Switch(config)# interface range fastethernet 0/6 - 10
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config-if-range)# exit

! Trunk 포트 설정 (라우터 연결)
Switch(config)# interface gigabitethernet 0/1
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20
Switch(config-if)# exit

Switch# copy running-config startup-config
```

### 라우터 설정 (Router-on-a-Stick)

```cisco
Router> enable
Router# configure terminal
Router(config)# hostname R1

! 물리 인터페이스 활성화 (IP 없음)
R1(config)# interface fastethernet 0/0
R1(config-if)# no shutdown
R1(config-if)# exit

! VLAN 10 서브인터페이스
R1(config)# interface fastethernet 0/0.10
R1(config-subif)# encapsulation dot1q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
R1(config-subif)# exit

! VLAN 20 서브인터페이스
R1(config)# interface fastethernet 0/0.20
R1(config-subif)# encapsulation dot1q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0
R1(config-subif)# exit

R1# copy running-config startup-config
```

### 검증

```cisco
! 서브인터페이스 확인
R1# show ip interface brief

! 라우팅 테이블 확인 (192.168.10.0/24, 192.168.20.0/24 모두 있어야 함)
R1# show ip route

! VLAN 간 통신 테스트 (VLAN 10 PC에서 VLAN 20으로)
! PC 192.168.10.10 에서 192.168.20.10 ping
```

## 핵심 정리

- Linux DNS+Apache: named.conf → 영역 파일 → 검증 → httpd → SELinux → 방화벽 순서
- Cisco 정적 라우팅: 양쪽 라우터에 서로의 LAN을 향하는 경로 필요
- VLAN Inter-VLAN: 스위치 Trunk + 라우터 서브인터페이스 `encapsulation dot1q`
- 모든 작업 후 `show` 명령으로 반드시 검증
