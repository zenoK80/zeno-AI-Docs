## DHCP 역할 설치

```powershell
# DHCP 서버 역할 설치
Install-WindowsFeature -Name DHCP -IncludeManagementTools

# 설치 확인
Get-WindowsFeature DHCP
```

## DHCP 스코프 생성 순서

DHCP 설정은 다음 순서로 진행합니다.

1. 스코프 이름과 IP 범위 설정
2. 제외 주소 범위 추가 (서버·프린터 등 고정 IP 제외)
3. 임대 기간 설정
4. 게이트웨이(Router), DNS 옵션 설정
5. 스코프 활성화
6. AD 환경이면 DHCP 서버 권한 부여

## PowerShell로 스코프 생성

```powershell
# 1. 스코프 생성 (기본 임대 기간: 8일)
Add-DhcpServerv4Scope `
  -Name "LAN스코프" `
  -StartRange 192.168.1.100 `
  -EndRange 192.168.1.200 `
  -SubnetMask 255.255.255.0 `
  -State Active

# 2. 제외 범위 추가 (서버용 IP 제외)
Add-DhcpServerv4ExclusionRange `
  -ScopeId 192.168.1.0 `
  -StartRange 192.168.1.100 `
  -EndRange 192.168.1.110

# 3. 임대 기간 변경 (기본값 8일, 예시는 1일)
Set-DhcpServerv4Scope `
  -ScopeId 192.168.1.0 `
  -LeaseDuration 1.00:00:00

# 4. 게이트웨이·DNS 옵션 설정
Set-DhcpServerv4OptionValue `
  -ScopeId 192.168.1.0 `
  -Router 192.168.1.1 `
  -DnsServer 192.168.1.2 `
  -DnsDomain "exam.local"

# 5. 스코프 활성화 (생성 시 -State Active로 이미 활성화 가능)
Set-DhcpServerv4Scope -ScopeId 192.168.1.0 -State Active
```

## AD 환경에서 DHCP 권한 부여

AD 도메인 환경에서는 DHCP 서버가 도메인에 **권한 부여**되어야 서비스가 정상 작동합니다. 권한 없는 DHCP 서버는 IP 배포를 차단합니다.

```powershell
# DHCP 서버를 AD에 권한 부여
Add-DhcpServerInDC -DnsName "SERVER01.exam.local" -IPAddress 192.168.1.1

# 권한 부여된 DHCP 서버 목록 확인
Get-DhcpServerInDC

# DHCP 서버 서비스 알림 구성 (선택)
Set-DhcpServerv4DnsSetting -DynamicUpdates Always -DeleteDnsRRonLeaseExpiry $true
```

## 스코프 확인 및 관리

```powershell
# 전체 스코프 목록
Get-DhcpServerv4Scope

# 특정 스코프 상세 정보
Get-DhcpServerv4Scope -ScopeId 192.168.1.0

# 제외 범위 확인
Get-DhcpServerv4ExclusionRange -ScopeId 192.168.1.0

# 옵션 값 확인
Get-DhcpServerv4OptionValue -ScopeId 192.168.1.0
```

## 임대 목록 확인

```powershell
# 현재 임대 중인 IP 목록
Get-DhcpServerv4Lease -ScopeId 192.168.1.0

# 특정 클라이언트 임대 정보
Get-DhcpServerv4Lease -ScopeId 192.168.1.0 -ClientId "AA-BB-CC-DD-EE-FF"
```

## MAC 주소 예약 (고정 IP 할당)

특정 장치에 항상 같은 IP를 할당하려면 예약을 사용합니다.

```powershell
# 프린터에 고정 IP 예약
Add-DhcpServerv4Reservation `
  -ScopeId 192.168.1.0 `
  -IPAddress 192.168.1.50 `
  -ClientId "AA-BB-CC-DD-EE-FF" `
  -Description "Network Printer"

# 예약 목록 확인
Get-DhcpServerv4Reservation -ScopeId 192.168.1.0
```

## DHCP 동작 원리

DHCP 클라이언트가 IP를 받는 과정은 **DORA** 4단계입니다.

| 단계 | 메시지 | 방향 | 설명 |
|------|--------|------|------|
| 1 | DHCPDISCOVER | 클라이언트 → 브로드캐스트 | 서버 탐색 |
| 2 | DHCPOFFER | 서버 → 클라이언트 | IP 제안 |
| 3 | DHCPREQUEST | 클라이언트 → 브로드캐스트 | 제안 수락 |
| 4 | DHCPACK | 서버 → 클라이언트 | 확인 및 임대 |

## 방화벽 설정

```powershell
# DHCP 포트(67/68) 방화벽 허용
New-NetFirewallRule -DisplayName "DHCP Server" -Direction Inbound -Protocol UDP -LocalPort 67 -Action Allow
```

## 핵심 정리

- 스코프 생성: `Add-DhcpServerv4Scope -Name "이름" -StartRange IP -EndRange IP -SubnetMask 마스크`
- 제외 범위: `Add-DhcpServerv4ExclusionRange -ScopeId IP -StartRange IP -EndRange IP`
- 옵션 설정: `Set-DhcpServerv4OptionValue -ScopeId IP -Router GW -DnsServer DNS`
- AD 권한 부여: `Add-DhcpServerInDC` (AD 환경 필수!)
- 임대 확인: `Get-DhcpServerv4Lease -ScopeId IP`
