## 필기시험은 네 과목을 고르게 본다

공식 안내 기준으로 빅데이터분석기사 필기는 객관식 80문항, 120분으로 구성되며 네 과목에서 각각 20문항이 출제된다. 과목 하나를 포기하고 다른 과목으로 만회하는 전략은 위험하다.

| 과목 | 문항 수 | 공부할 때 붙잡을 질문 |
| --- | ---: | --- |
| 빅데이터 분석기획 | 20 | 왜 이 분석을 하고 어떻게 계획하는가? |
| 빅데이터 탐색 | 20 | 데이터는 어떤 상태이며 무엇을 먼저 확인하는가? |
| 빅데이터 모델링 | 20 | 어떤 모형을 어떤 기준으로 선택하고 평가하는가? |
| 빅데이터 결과 해석 | 20 | 결과를 어떻게 설명하고 활용·관리하는가? |

필기 합격 기준은 평균 60점 이상이며, 과목별 40점 미만이면 과락이다. 시험 운영과 출제 기준은 바뀔 수 있으므로 접수 전에는 공식 사이트를 다시 확인해야 한다.

<Callout type="warning">
네 과목은 독립적인 암기 목록이 아니다. 탐색에서 확인한 데이터 특성이 모델링 방법과 평가 지표 선택에 영향을 주고, 결과 해석은 다시 분석 목적과 연결된다.
</Callout>

## 과목별로 무엇을 우선할까?

### 분석기획

분석 과제 정의, 분석 방법과 데이터 확보 계획, 개인정보와 데이터 활용의 기본 원칙을 익힌다. “좋은 분석 문제”를 문장으로 바꾸는 연습이 필요하다.

### 탐색

데이터 정제, 결측값·이상값 처리, 기초통계량, 시각화, 표본과 추론이 핵심이다. 통계 용어를 공식만으로 외우면 모델링에서 다시 막힌다.

### 모델링

회귀, 분류, 군집, 시계열, 앙상블 등 방법의 목적을 구분한다. 각 알고리즘의 수식보다 “어떤 문제에 쓰는가”와 과대적합을 먼저 이해한다.

### 결과 해석

평가 지표, 교차검증, 모형 진단, 시각화, 배포·모니터링을 다룬다. 정확도가 높아도 업무 목적과 맞지 않을 수 있다는 관점이 중요하다.

## 학습 시간을 배분하는 방법

<Steps>
### 진단 문제로 약한 과목을 찾는다

네 과목에서 각각 10문제씩 풀어 보고, 틀린 이유를 용어 부족·계산 실수·문제 해석 부족으로 나눈다.

### 연결되는 주제를 묶어 공부한다

표본추출과 가설검정은 탐색, 평가 지표와 교차검증은 모델링·결과 해석을 함께 보며 연결한다.

### 과락 방지용 최소선부터 만든다

약한 과목도 기본 개념과 빈출 용어를 먼저 확보해 40점 아래로 떨어지지 않게 한다.

### 모의고사에서는 시간까지 기록한다

80문항을 120분 안에 푸는 연습을 하고, 애매한 문제에 오래 머물지 않는 기준을 정한다.
</Steps>

## 직접 확인하기

아래 상황을 과목과 연결해 보자.

```txt
“고객 이탈을 줄이기 위해 이탈 기준을 정하고,
구매 데이터의 결측값을 확인한 뒤,
이탈 예측 모델을 평가하고,
마케팅 대상 고객을 선정한다.”
```

이 문장에는 기획, 탐색, 모델링, 결과 해석이 순서대로 모두 들어 있다. 각 단계가 어떤 과목인지 표시해 보자.

## 이번 편 정리

- 필기는 네 과목 각 20문항으로 구성되며, 평균과 과락 기준을 함께 관리해야 한다.
- 과목별 암기보다 하나의 분석 사례로 네 단계를 연결해 이해한다.
- 최신 일정·응시자격·세부 기준은 공식 공지를 기준으로 확인한다.
