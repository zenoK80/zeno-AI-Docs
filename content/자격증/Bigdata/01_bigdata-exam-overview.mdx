## 이번 편의 목표

- 빅데이터분석기사 필기가 평가하는 전체 분석 과정을 설명한다.
- 네 과목이 하나의 분석 프로젝트에서 어떻게 연결되는지 이해한다.
- 개념 암기와 계산·해석 문제를 함께 준비하는 방법을 정한다.

## 하나의 질문에서 시작하기

온라인 서비스의 고객 이탈률이 높아졌다. 담당자는 "다음 달에 서비스를 떠날 가능성이 큰 고객을 찾아 적절한 혜택을 제공하자"고 제안했다.

이 질문에 답하려면 모델 하나만 고르면 되는 것이 아니다.

```text
비즈니스 문제 정의
→ 필요한 데이터 확인
→ 수집·저장·품질 점검
→ 탐색과 전처리
→ 분석 모델 선택·평가
→ 결과 해석과 활용
→ 효과 및 위험 재점검
```

빅데이터분석기사 필기는 이 전체 흐름에서 필요한 기획, 탐색, 모델링, 결과 해석 지식을 평가한다.

<Callout type="important">
용어를 따로 외우기보다 "분석 과정의 어느 단계에서, 어떤 문제를 해결하는 개념인가?"를 함께 묻는다.
</Callout>

## 네 과목을 고객 이탈 분석에 연결하기

| 과목 | 핵심 질문 | 고객 이탈 사례 |
| --- | --- | --- |
| 빅데이터 분석기획 | 무엇을 왜 분석하며 성공을 어떻게 판단할까? | 이탈 정의, 목표, 비용, 개인정보 위험 설정 |
| 빅데이터 탐색 | 데이터가 분석 가능한 상태인가? | 결측값·이상값·분포·변수 관계 확인 |
| 빅데이터 모델링 | 어떤 방법으로 예측하고 평가할까? | 분류 모델 학습, 검증, 성능 비교 |
| 빅데이터 결과해석 | 결과를 어떻게 설명하고 사용할까? | 지표 해석, 시각화, 개선안 제시 |

앞 과목의 결정이 뒤 과목의 결과를 바꾼다. 이탈을 "30일간 로그인하지 않은 고객"으로 정의했는지, "구독을 해지한 고객"으로 정의했는지에 따라 정답 데이터와 모델의 의미가 달라진다.

## 분석 문제를 정확히 정의하기

다음 세 문장은 비슷해 보이지만 서로 다른 문제다.

1. 지난달 고객 이탈률은 얼마인가? → **현황 파악**
2. 어떤 특성이 이탈과 함께 나타나는가? → **관계 탐색**
3. 다음 달 이탈할 고객은 누구인가? → **예측**

예측 문제라면 관측 시점 이후에 생긴 정보를 학습 데이터에 넣어서는 안 된다. 예를 들어 "해지 완료 시각"은 이탈 결과를 이미 알려 주므로 예측 변수로 사용하면 **데이터 누수**가 발생한다.

## 자주 만나는 문제 유형

### 개념 구분

표본과 모집단, 지도학습과 비지도학습, 분류와 회귀처럼 가까운 개념의 차이를 묻는다. 정의와 함께 반례를 준비하면 보기 문장을 판단하기 쉽다.

### 계산

평균·분산·확률, 성능 지표, 거리 등은 손으로 계산할 수 있어야 한다. 공식만 외우지 말고 기호가 무엇을 뜻하는지 확인한다.

### 절차와 방법 선택

분석 단계의 순서나 상황에 적합한 전처리·모델·평가 방법을 고른다. 데이터 유형과 목표 변수를 먼저 찾는다.

### 결과 해석

표, 그래프, 혼동행렬, 회귀 결과를 보고 의미를 판단한다. 값이 크다는 사실과 실무적으로 좋은 결과라는 판단은 구분해야 한다.

## 첫 사례: 정확도만 높으면 좋은 모델일까?

고객 1,000명 중 실제 이탈 고객이 50명이라고 하자. 모든 고객을 "이탈하지 않는다"고 예측하면 950명을 맞혀 정확도는 95%다. 하지만 찾고 싶었던 이탈 고객은 한 명도 찾지 못했다.

이때는 실제 이탈 고객 중 몇 명을 찾았는지 나타내는 **재현율**과, 이탈로 예측한 고객 중 실제 이탈 비율인 **정밀도**를 함께 봐야 한다.

```text
정확도 = 전체 정답 수 / 전체 고객 수
재현율 = 이탈로 맞힌 수 / 실제 이탈 고객 수
정밀도 = 이탈로 맞힌 수 / 이탈로 예측한 고객 수
```

시험에서는 공식을 계산하는 문제뿐 아니라 어떤 지표가 상황에 중요한지 묻는다.

## 학습 루틴

<Steps>
### 범위 지도를 먼저 만든다
각 개념을 분석기획, 탐색, 모델링, 결과해석 중 어디에 속하는지 표시한다.

### 개념을 사례에 적용한다
고객 이탈 사례에서 해당 개념이 어떤 결정을 바꾸는지 한 문장으로 적는다.

### 계산은 손으로 재현한다
공식, 숫자 대입, 계산, 해석을 한 줄씩 나눠 쓴다.

### 오답 이유를 분류한다
개념 혼동, 계산 실수, 조건 누락, 결과 해석 오류로 구분해 다시 공부한다.
</Steps>

## 정리

빅데이터분석기사 필기는 문제 정의부터 결과 활용까지 분석의 전체 생명주기를 다룬다. 네 과목을 따로 외우지 말고 하나의 프로젝트에서 이어지는 결정으로 이해해야 한다. 다음 편에서는 실제 문항 수와 합격 기준을 바탕으로 과목별 학습 시간을 배분한다.
