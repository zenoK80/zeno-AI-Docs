## 빅데이터분석기사 필기는 무엇을 보는가

빅데이터분석기사 필기는 데이터를 활용해 문제를 정의하고, 데이터를 탐색하고, 분석 모델을 만들고, 결과를 해석할 수 있는지 확인하는 시험이다.

처음 보면 범위가 넓어 보이지만 큰 흐름은 단순하다.

```txt
분석 기획 -> 데이터 탐색 -> 모델링 -> 결과 해석
```

<Callout type="info">
빅데이터분석기사 필기는 통계, 머신러닝, 데이터 처리, 분석 절차가 한 시험 안에 섞여 있다. 각 개념을 따로 외우기보다 분석 프로젝트 흐름으로 연결해서 보는 것이 좋다.
</Callout>

## 네 과목의 역할

| 구분 | 핵심 질문 |
| --- | --- |
| 빅데이터 분석기획 | 어떤 문제를 분석할 것인가? |
| 빅데이터 탐색 | 데이터가 어떤 상태인가? |
| 빅데이터 모델링 | 어떤 방법으로 예측하거나 분류할 것인가? |
| 빅데이터 결과해석 | 결과를 어떻게 평가하고 활용할 것인가? |

이 네 과목은 따로 떨어진 암기 과목이 아니다. 실제 분석 작업의 순서를 시험 과목으로 나눈 것에 가깝다.

## 먼저 공부할 방향

처음부터 모든 알고리즘을 깊게 파고들 필요는 없다. 먼저 용어와 흐름을 잡는 것이 우선이다.

<Steps>
### 분석 절차를 먼저 익힌다

문제 정의, 데이터 수집, 전처리, 모델링, 평가의 순서를 잡는다.

### 통계 기본기를 정리한다

평균, 분산, 확률분포, 추정, 가설검정은 여러 과목에서 반복된다.

### 모델링 용어를 연결한다

회귀, 분류, 군집, 과대적합, 교차검증 같은 단어를 실제 목적과 연결한다.
</Steps>

## 이번 편 정리

- 빅데이터분석기사 필기는 분석 프로젝트 전체 흐름을 다룬다.
- 네 과목은 분석 기획, 탐색, 모델링, 결과해석으로 연결된다.
- 처음에는 세부 암기보다 전체 흐름과 반복되는 핵심 용어를 잡는 것이 좋다.
