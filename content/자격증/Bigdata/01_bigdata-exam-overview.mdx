## 이 시험은 분석의 전체 과정을 묻는다

빅데이터분석기사 필기는 통계 공식이나 머신러닝 알고리즘만 따로 묻는 시험이 아니다. 문제를 정의하고, 데이터를 확인하고, 모델을 만들고, 결과를 해석해 활용하는 **분석의 전 과정**을 다룬다.

예를 들어 온라인 쇼핑몰이 “다음 달에 이탈할 가능성이 높은 고객을 찾고 싶다”고 한다고 하자. 이 한 문장은 다음 네 단계로 나뉜다.

```txt
문제 정의 -> 데이터 탐색 -> 모델링 -> 결과 해석과 활용
```

| 단계 | 사례에서 할 일 | 필기 과목 |
| --- | --- | --- |
| 문제 정의 | 이탈을 어떻게 정의하고 무엇을 개선할지 정함 | 빅데이터 분석기획 |
| 데이터 탐색 | 구매·방문 데이터의 결측값과 분포를 확인 | 빅데이터 탐색 |
| 모델링 | 이탈 여부를 예측할 방법을 선택하고 평가 | 빅데이터 모델링 |
| 결과 활용 | 어떤 고객에게 어떤 행동을 할지 결정 | 빅데이터 결과 해석 |

<Callout type="important">
분석 모델의 정확도가 높아도, 처음에 문제를 잘못 정의하거나 데이터를 잘못 해석하면 좋은 의사결정으로 이어지지 않는다. 네 과목을 하나의 프로젝트 흐름으로 묶어 보는 이유다.
</Callout>

## 초보자가 먼저 잡아야 할 질문

모든 알고리즘을 외우기 전에 다음 질문에 답할 수 있어야 한다.

- 분석하려는 문제는 분류, 예측, 군집 중 무엇에 가까운가?
- 데이터 한 행은 고객, 주문, 날짜 중 무엇을 뜻하는가?
- 결측값과 이상값이 있으면 결과에 어떤 영향을 줄 수 있는가?
- 모델 결과를 누가 어떤 행동에 사용할 것인가?

이 질문들은 뒤의 통계, 데이터 전처리, 모델 평가 내용을 연결해 준다.

## 작은 사례로 흐름 따라가기

고객별 최근 구매일, 구매 횟수, 총 구매액이 있다고 하자.

```txt
고객 A: 최근 구매 3일 전, 구매 12회, 총 420,000원
고객 B: 최근 구매 180일 전, 구매 1회, 총 15,000원
```

고객 B를 “이탈 위험이 높을 수 있다”고 보는 것은 분석의 출발점이다. 그러나 바로 결론 내리면 안 된다. 최근 구매일이 없는 고객은 결측값인지, 회원가입만 하고 구매하지 않은 고객인지 먼저 확인해야 한다. 데이터를 살핀 뒤에야 변수를 만들고 모델을 적용할 수 있다.

## 공부 방향: 과목을 따로 외우지 않기

<Steps>
### 분석기획부터 문제를 문장으로 쓴다

“무엇을 예측할 것인가, 결과를 어디에 쓸 것인가”를 한 문장으로 정리한다.

### 탐색에서 데이터의 상태를 확인한다

자료형, 결측값, 이상값, 분포, 관계를 확인한다. 좋은 모델보다 먼저 필요한 단계다.

### 모델링에서 방법과 평가를 연결한다

분류·회귀·군집의 목적을 구분하고, 평가 지표가 무엇을 의미하는지 익힌다.

### 결과 해석에서 행동을 결정한다

분석 결과가 실제 의사결정에 어떻게 쓰이는지 생각한다. 해석할 수 없는 결과는 활용하기 어렵다.
</Steps>

## 흔한 실수

- 빅데이터를 “데이터가 매우 많은 것”으로만 이해하기
- 알고리즘 이름을 많이 알면 분석을 잘한다고 생각하기
- 정확도만 보고 불균형 데이터나 업무 비용을 무시하기
- 분석 결과를 원인으로 단정하기: 예측과 인과관계는 다르다.

## 이번 편 정리

- 빅데이터분석기사 필기는 분석기획, 탐색, 모델링, 결과 해석의 흐름을 다룬다.
- 문제 정의와 데이터 이해가 모델 선택보다 먼저다.
- 다음 편에서 필기시험의 과목 구성과 합격 기준을 확인한다.
