## 복습 방법

네 선택지 중 하나를 먼저 고른 뒤 정답을 확인한다. 맞혔더라도 근거를 설명하지 못했다면 해설을 읽는다.

<Callout type="info">
정답 번호보다 판단 기준을 기억한다. 틀린 선지가 왜 틀렸는지 설명할 수 있어야 비슷하게 변형된 문제도 풀 수 있다.
</Callout>

## 4지선다 문제

### 문제 1

여러 시스템의 데이터를 분석하기 좋은 형태로 안정적으로 수집·변환·전달하는 역할은?

① 데이터 엔지니어

② 데이터 분석가

③ 웹 디자이너

④ 법률 번역가

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

데이터 엔지니어는 데이터 파이프라인과 저장·처리 기반을 구축하고 운영한다.

- **①** 정답이다.
- **②** 주로 데이터를 해석해 업무 질문에 답한다.
- **③** 화면 디자인이 주된 역할이다.
- **④** 데이터 파이프라인 직무가 아니다.

</Collapse>

### 문제 2

데이터 거버넌스의 목적에 가장 가까운 것은?

① 모든 데이터를 아무 제한 없이 공개한다.

② 데이터의 책임자, 정의, 품질, 접근 규칙을 조직 차원에서 정한다.

③ 분석가 한 명이 모든 데이터를 개인 폴더에 보관한다.

④ 메타데이터를 모두 삭제한다.

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

거버넌스는 데이터를 일관되고 안전하게 관리하도록 역할과 정책을 정하는 체계다.

- **①** 보안과 개인정보 원칙을 위반할 수 있다.
- **②** 정답이다.
- **③** 개인 의존과 공유 문제를 만든다.
- **④** 데이터의 의미와 위치를 찾기 어려워진다.

</Collapse>

### 문제 3

메타데이터의 예로 가장 적절한 것은?

① 고객 홍길동의 실제 전화번호

② 2026년 8월의 실제 매출액

③ 고객번호 열의 의미, 형식, 담당 부서

④ 모델이 예측한 한 고객의 점수

<Collapse title="정답 보기">

**정답: ③**

</Collapse>

<Collapse title="해설 보기">

메타데이터는 실제 값이 아니라 데이터의 뜻, 구조, 출처, 관리 정보를 설명한다.

- **①** 업무 데이터의 실제 값이다.
- **②** 업무 지표의 실제 값이다.
- **③** 정답이다.
- **④** 분석 결과 데이터다.

</Collapse>

### 문제 4

데이터 생명주기의 자연스러운 순서는?

① 폐기 → 생성 → 수집 → 사용

② 생성·수집 → 저장·관리 → 활용 → 보관 또는 폐기

③ 활용 → 무조건 영구 보관 → 생성

④ 분석 → 정의 삭제 → 무제한 공유

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

데이터는 생성·수집된 뒤 관리되고 활용되며, 필요성과 법적 기준에 따라 보관하거나 안전하게 폐기한다.

- **①** 생성 전 폐기할 수 없다.
- **②** 정답이다.
- **③** 모든 데이터를 영구 보관하면 비용과 개인정보 위험이 커진다.
- **④** 정의 삭제와 무제한 공유는 올바른 관리가 아니다.

</Collapse>

### 문제 5

데이터 분석가의 활동으로 가장 적절한 것은?

① 서버 랙의 전원 배선을 교체한다.

② 업무 질문에 맞는 지표를 정의하고 데이터를 해석해 의사결정을 돕는다.

③ 모든 접근 권한을 승인 없이 부여한다.

④ 저장장치 펌웨어만 개발한다.

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

분석가는 데이터에서 의미를 찾고 업무 질문에 답하며 결과를 설명하는 역할을 한다.

- **①** 하드웨어 시설 관리에 가깝다.
- **②** 정답이다.
- **③** 거버넌스와 보안을 위반한다.
- **④** 저장장치 개발 직무다.

</Collapse>

## 직접 적용하기

쇼핑몰이 주문 데이터를 분석 서비스에 활용하려 한다. 생성부터 폐기까지 담당 역할과 관리 항목을 짧게 연결해 보자.

<Collapse title="풀이 보기">

서비스가 주문 데이터를 생성하면 엔지니어가 안정적으로 수집·저장하고, 거버넌스 담당자는 주문금액과 고객번호의 정의·책임자·접근 권한을 정한다. 분석가는 지표를 만들고 결과를 해석한다. 개인정보는 목적과 보유 기간에 맞게 제한하며 기간이 끝나면 복구되지 않도록 안전하게 폐기한다. 메타데이터에는 열의 의미와 형식, 출처, 갱신 주기를 남긴다.

</Collapse>

## 결과 점검

- 5개 정답: 핵심 구분을 이해했다. 적용 문제의 판단 과정을 말로 다시 설명한다.
- 3~4개 정답: 틀린 문제에 나온 용어를 본편의 ‘먼저 알아둘 말’에서 다시 확인한다.
- 0~2개 정답: 본편의 용어표와 사례부터 다시 읽고 재도전한다.
