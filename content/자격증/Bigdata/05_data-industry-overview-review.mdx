## 05편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

### 문제 1

실시간 로그 수집 파이프라인이 자주 멈춰 데이터가 누락된다. 가장 직접 관련된 역할은 무엇인가?

### 문제 2

부서마다 "활성 고객"의 정의가 달라 보고서 숫자가 다르다. 어떤 관리 활동이 필요한가?

### 문제 3

컬럼의 의미, 자료형, 생성 주기, 담당자를 기록한 정보는 무엇인가?

### 문제 4

분석 목적이 끝난 개인정보를 무기한 보관할 때 생길 수 있는 문제를 두 가지 적어 보자.

## 정답과 해설

1. 데이터 수집·전송 파이프라인을 담당하는 **데이터 엔지니어** 역할과 가장 가깝다.
2. 공통 정의와 책임을 정하는 데이터 표준화 및 거버넌스가 필요하다.
3. 데이터를 설명하는 **메타데이터**다.
4. 불필요한 저장 비용과 개인정보 유출·오남용 위험이 커질 수 있다.
