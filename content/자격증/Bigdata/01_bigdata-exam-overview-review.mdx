## 복습 방법

네 선택지 중 하나를 먼저 고른 뒤 정답을 확인한다. 맞혔더라도 근거를 설명하지 못했다면 해설을 읽는다.

<Callout type="info">
정답 번호보다 판단 기준을 기억한다. 틀린 선지가 왜 틀렸는지 설명할 수 있어야 비슷하게 변형된 문제도 풀 수 있다.
</Callout>

## 4지선다 문제

### 문제 1

고객 이탈을 줄이기 위한 데이터 분석의 출발점으로 가장 적절한 것은?

① 가장 복잡한 알고리즘부터 선택한다.

② 보유한 모든 데이터를 무조건 합친다.

③ 이탈을 무엇으로 정의하고 결과를 어디에 쓸지 정한다.

④ 그래프 색상과 보고서 형식부터 정한다.

<Collapse title="정답 보기">

**정답: ③**

</Collapse>

<Collapse title="해설 보기">

분석은 해결할 질문과 결과 사용 방법을 먼저 정해야 필요한 데이터와 평가 기준을 선택할 수 있다.

- **①** 알고리즘은 문제와 데이터가 정해진 뒤 고른다.
- **②** 목적 없이 데이터를 합치면 불필요하거나 위험한 정보가 섞일 수 있다.
- **③** 정답이다.
- **④** 표현 방식은 분석 목적과 결과가 정리된 뒤 결정한다.

</Collapse>

### 문제 2

분석 모델에 대한 설명으로 가장 적절한 것은?

① 데이터를 저장하는 폴더 이름이다.

② 입력 데이터를 받아 예측이나 분류 결과를 만드는 계산 규칙이다.

③ 결과의 좋고 나쁨을 판단하는 숫자 하나만 뜻한다.

④ 오류가 있는 행을 삭제하는 작업만 뜻한다.

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

모델은 입력과 결과 사이의 규칙이고, 지표는 그 모델을 평가하는 기준이다.

- **①** 저장 위치와 모델은 다른 개념이다.
- **②** 정답이다.
- **③** 평가 지표에 대한 설명이다.
- **④** 전처리 작업의 일부다.

</Collapse>

### 문제 3

이탈 고객이 전체의 1%인 데이터에서 모든 고객을 ‘이탈하지 않음’으로 예측했다. 정확도가 99%라는 이유만으로 좋은 모델이라 하기 어려운 까닭은?

① 정확도는 항상 0이어야 해서

② 중요한 이탈 고객을 한 명도 찾지 못했기 때문에

③ 데이터가 반드시 비정형이기 때문에

④ 시각화를 사용하지 않았기 때문에

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

전체 정확도는 높지만 업무상 중요한 소수 이탈 고객을 전부 놓쳤다. 문제 목적에 맞는 오류와 지표를 함께 봐야 한다.

- **①** 정확도는 0부터 1 또는 0%부터 100%로 표현할 수 있다.
- **②** 정답이다.
- **③** 데이터 형태와 이 문제의 핵심은 무관하다.
- **④** 시각화 여부보다 예측 결과가 목적에 맞는지가 중요하다.

</Collapse>

### 문제 4

다음 중 전처리에 해당하는 작업은?

① 누락된 나이 값을 어떻게 처리할지 정한다.

② 최종 보고서의 표지 디자인을 고른다.

③ 시험 접수 일정을 확인한다.

④ 서버의 전원 케이블을 교체한다.

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

전처리는 분석 전에 누락값, 오류, 중복, 형식을 정리하는 과정이다.

- **①** 정답이다.
- **②** 결과 표현 단계다.
- **③** 시험 행정 정보다.
- **④** 하드웨어 정비 작업이다.

</Collapse>

### 문제 5

빅데이터 분석의 전체 흐름으로 가장 자연스러운 것은?

① 결과 해석 → 문제 정의 → 데이터 준비 → 분석

② 문제 정의 → 데이터 준비 → 분석 → 평가와 해석

③ 알고리즘 선택 → 결론 작성 → 데이터 수집 → 문제 정의

④ 시각화 → 데이터 삭제 → 문제 정의 → 평가

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

질문을 먼저 정하고 데이터를 준비한 뒤 분석하며, 마지막에 결과가 질문과 업무에 맞는지 평가한다.

- **①** 결과를 먼저 정하면 분석이 결론에 끌려갈 수 있다.
- **②** 정답이다.
- **③** 문제보다 알고리즘을 먼저 정했고 결론도 데이터보다 앞선다.
- **④** 목적 없는 삭제와 순서 역전이 있다.

</Collapse>

## 직접 적용하기

온라인 쇼핑몰의 ‘고객 이탈 예측’을 시작한다고 가정한다. 분석 질문, 입력 데이터 두 가지, 예측 결과, 업무 지표를 각각 한 줄로 적어 보자.

<Collapse title="풀이 보기">

예시: 질문은 ‘최근 90일 안에 구매를 중단할 가능성이 높은 고객은 누구인가?’이다. 입력 데이터는 최근 구매일과 최근 6개월 구매 횟수 등을 사용할 수 있다. 결과는 고객별 이탈 가능성 점수다. 업무 지표는 예측 정확도 하나가 아니라 알림을 보낸 고객의 재구매율 증가나 이탈 감소율처럼 실제 행동 변화를 포함한다.

</Collapse>

## 결과 점검

- 5개 정답: 핵심 구분을 이해했다. 적용 문제의 판단 과정을 말로 다시 설명한다.
- 3~4개 정답: 틀린 문제에 나온 용어를 본편의 ‘먼저 알아둘 말’에서 다시 확인한다.
- 0~2개 정답: 본편의 용어표와 사례부터 다시 읽고 재도전한다.
