## 이번 편의 목표

- 데이터, 정보, 통찰, 행동, 성과의 차이를 구분한다.
- 분석 유형에 따라 답할 수 있는 질문이 달라짐을 이해한다.
- 분석의 성능과 비즈니스 가치, 위험을 함께 평가한다.

## 먼저 알아둘 말

| 용어 | 쉬운 뜻 |
| --- | --- |
| 가치 | 데이터를 활용해 비용, 시간, 위험 또는 품질을 실제로 개선한 효과 |
| KPI | 목표 달성 정도를 계속 확인하기 위해 정한 핵심 성과 지표 |
| 모델 성능 | 예측이나 분류가 기술적으로 얼마나 잘 맞는지 나타내는 수치 |
| 업무 성과 | 분석 결과를 적용해 현장에서 얻은 매출·비용·시간 등의 변화 |
| ROI | 투자한 비용에 비해 얼마의 효과를 얻었는지 보는 비율 |
| 실험 | 분석 결과를 적용한 집단과 그렇지 않은 집단을 비교해 효과를 확인하는 방법 |

좋은 분석은 높은 정확도에서 끝나지 않는다. 결과를 사용할 사람이 행동을 바꿀 수 있어야 하고, 그 변화가 비용보다 큰 효과를 만들어야 한다.

## 주변 개념 지도

모델 평가는 기술 지표와 업무 지표를 함께 본다. 예측 정확도가 조금 낮더라도 중요한 위험을 더 잘 찾아내거나 운영 비용을 크게 줄이면 업무 가치는 더 높을 수 있다.

<Callout type="info">
“얼마나 잘 맞았나”는 모델 성능이고, “그래서 무엇이 얼마나 좋아졌나”는 업무 가치다. 시험 선지에서 두 질문을 섞지 않는다.
</Callout>

## 데이터 자체가 곧 가치는 아니다

고객 1,000만 명의 로그를 저장했다는 사실은 자산을 보유했다는 뜻일 뿐, 문제가 해결됐다는 뜻은 아니다. 데이터가 가치가 되려면 질문에 답하고 행동을 바꾸며 결과가 개선돼야 한다.

```text
데이터 → 정보 → 통찰 → 의사결정 → 행동 → 성과 측정
```

고객 이탈 사례에 적용하면 다음과 같다.

| 단계 | 예시 |
| --- | --- |
| 데이터 | 로그인, 결제, 문의 기록 |
| 정보 | 최근 30일 로그인 횟수 감소 |
| 통찰 | 로그인 감소 고객의 이탈률이 높음 |
| 의사결정 | 특정 고객에게 유지 캠페인 시행 |
| 행동 | 안내와 혜택 제공 |
| 성과 | 이탈 감소분과 캠페인 비용 비교 |

## 분석의 네 가지 질문

| 분석 유형 | 질문 | 예시 |
| --- | --- | --- |
| 기술 분석 | 무슨 일이 일어났는가? | 지난달 이탈률은 8%였다. |
| 진단 분석 | 왜 일어났는가? | 가격 인상 이후 특정 요금제 이탈이 증가했다. |
| 예측 분석 | 앞으로 무엇이 일어날까? | 고객 A의 다음 달 이탈 확률은 0.72다. |
| 처방 분석 | 무엇을 해야 할까? | 고객 A에게 어떤 혜택을 제공해야 순이익이 커질까? |

예측 확률만으로 행동이 정해지는 것은 아니다. 연락 비용, 혜택 비용, 고객 생애가치, 잘못된 예측의 손실을 함께 고려해야 한다.

## 모델 성능과 업무 가치는 다르다

두 이탈 모델을 비교해 보자.

| 모델 | 재현율 | 캠페인 대상 | 월 순효과 |
| --- | ---: | ---: | ---: |
| A | 90% | 100,000명 | 500만 원 |
| B | 75% | 20,000명 | 1,500만 원 |

모델 A는 더 많은 이탈 고객을 찾지만 너무 많은 고객에게 비용을 쓴다. 목적이 순이익 개선이라면 모델 B가 더 나을 수 있다. 평가 지표는 분석 목적과 비용 구조를 반영해야 한다.

<Callout type="important">
통계적으로 유의하거나 예측 성능이 높다는 사실만으로 업무 가치가 보장되지는 않는다. 실제 행동의 비용과 편익을 별도로 검증해야 한다.
</Callout>

## 가치 평가에 포함할 항목

### 직접 효과

매출 증가, 비용 감소, 처리 시간 단축처럼 금액이나 시간으로 측정하기 쉬운 효과다.

### 간접 효과

고객 만족, 위험 조기 탐지, 직원 의사결정 속도처럼 장기적으로 영향을 주는 효과다. 측정 지표와 관찰 기간을 미리 정해야 한다.

### 위험과 부작용

개인정보 침해, 특정 집단에 대한 불공정한 결과, 자동화 오류, 설명 불가능성도 비용이다. 성능이 좋아도 법적·윤리적 위험이 크면 사용 범위를 제한해야 한다.

## 실험으로 가치 확인하기

이탈 위험 고객에게 혜택을 보낸 뒤 이탈률이 낮아졌다고 해서 혜택의 효과라고 바로 결론 내릴 수 없다. 원래 이탈률이 낮은 시기였을 수도 있다.

가능하다면 조건이 비슷한 고객을 무작위로 두 집단에 나눈다.

- 실험군: 유지 혜택 제공
- 대조군: 기존 방식 유지

두 집단의 이탈률 차이와 비용을 비교하면 행동의 인과적 효과를 더 타당하게 추정할 수 있다.

## 가치 계산 예시

캠페인 대상 1,000명에게 1인당 2,000원의 비용이 들었다. 캠페인으로 추가 유지된 고객은 50명이고 고객 한 명의 기대 이익은 60,000원이라고 하자.

```text
편익 = 50명 × 60,000원 = 3,000,000원
비용 = 1,000명 × 2,000원 = 2,000,000원
순효과 = 편익 - 비용 = 1,000,000원
```

실제 계산에서는 추정 오차, 운영비, 장기 효과도 고려해야 하지만 기본 구조는 편익과 비용의 차이다.

## 정리

빅데이터의 가치는 데이터 양이 아니라 더 나은 결정과 측정 가능한 결과에서 나온다. 모델 지표, 비용과 편익, 윤리적 위험을 함께 평가해야 한다. 다음 편에서는 이 가치가 만들어지는 데이터 산업의 참여자와 역할을 살펴본다.
