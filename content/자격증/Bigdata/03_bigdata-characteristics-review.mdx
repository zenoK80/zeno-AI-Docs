## 03편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

### 문제 1

초당 수십만 건의 센서 데이터를 즉시 분석해야 한다. 가장 직접 관련된 V는 무엇인가?

### 문제 2

JSON 로그는 일반적으로 정형, 반정형, 비정형 중 어디에 속하는가?

### 문제 3

결측값을 항상 평균으로 대체하면 안 되는 이유를 두 가지 적어 보자.

### 문제 4

수집한 데이터로 정확한 예측 모델을 만들었지만 실제 업무에서 아무 행동도 바뀌지 않았다. 가장 부족한 V는 무엇인가?

## 정답과 해설

1. 생성과 처리 속도를 뜻하는 **Velocity**다.
2. 키와 값의 내부 구조가 있으므로 **반정형 데이터**다.
3. 결측 원인 자체가 정보일 수 있고, 자료형이나 분포에 따라 평균 대치가 편향을 만들 수 있다.
4. 분석이 효용으로 연결되지 않았으므로 **Value**가 부족하다.
