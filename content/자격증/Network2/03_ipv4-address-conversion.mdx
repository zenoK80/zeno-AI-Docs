## 이번 편의 목표
- IPv4 주소가 8비트 네 묶음으로 구성됨을 설명한다.
- 10진수 옥텟을 2진수로, 2진수를 10진수로 변환한다.
- 주소와 서브넷 마스크 계산에 필요한 비트 감각을 익힌다.

## 먼저 알아둘 말

| 용어 | 쉬운 뜻 |
| --- | --- |
| 비트(bit) | 0 또는 1 한 자리로 표현되는 가장 작은 정보 단위 |
| 2진수 | 0과 1만 사용해 수를 나타내는 방식 |
| 10진수 | 일상에서 쓰는 0부터 9까지의 숫자 표현 방식 |
| 옥텟(octet) | 8개의 비트를 묶은 단위 |
| IPv4 주소 | 32비트로 장치와 네트워크 위치를 나타내는 주소 |
| 자리값 | 숫자의 위치에 따라 정해지는 값. 2진수에서는 128, 64, 32, ... 순서 |
| 네트워크 부분 | 주소에서 어느 네트워크인지 나타내는 앞쪽 비트 |
| 호스트 부분 | 같은 네트워크 안에서 장치를 구분하는 뒤쪽 비트 |

점으로 나눈 IPv4의 각 숫자는 0부터 255까지이며, 각각 8비트인 옥텟 하나를 10진수로 적은 것이다.

## 주변 개념 지도

2진수 변환은 계산 자체가 목적이 아니다. 뒤에서 서브넷 마스크와 네트워크 주소를 구할 때 주소의 어느 비트가 네트워크이고 어느 비트가 장치인지 판단하기 위한 기초다.

<Callout type="info">
8비트 자리값은 왼쪽부터 128, 64, 32, 16, 8, 4, 2, 1이다. 필요한 자리값을 더해 10진수를 만들고, 사용한 자리는 1로 표시한다.
</Callout>

## IPv4의 구조

IPv4 주소는 32비트이며, 읽기 쉽게 8비트씩 네 옥텟으로 나눈다.

```text
192      . 168      . 10       . 25
11000000 . 10101000 . 00001010 . 00011001
```

8비트의 자리값은 왼쪽부터 다음과 같다.

| 비트 자리 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

모든 비트가 0이면 0, 모두 1이면 `128+64+32+16+8+4+2+1=255`다. 따라서 각 옥텟의 범위는 0~255다.

## 10진수를 2진수로 바꾸기

`168`을 변환해 보자.

1. 168에서 가장 큰 자리값 128을 사용한다: 남은 값 40
2. 64는 사용할 수 없다: 0
3. 32를 사용한다: 남은 값 8
4. 16은 사용할 수 없다: 0
5. 8을 사용한다: 남은 값 0
6. 나머지 4, 2, 1은 모두 0

```text
자리값: 128 64 32 16 8 4 2 1
비트:     1  0  1  0 1 0 0 0
결과: 10101000
```

`25 = 16 + 8 + 1`이므로 `00011001`이다. 앞의 0도 포함해 반드시 8자리로 쓴다.

## 2진수를 10진수로 바꾸기

`11000010`에서 1인 자리값을 더한다.

```text
128 + 64 + 2 = 194
```

따라서 `11000010`은 194다.

## 빠르게 기억할 경계값

| 2진수 | 10진수 |
| --- | ---: |
| `10000000` | 128 |
| `11000000` | 192 |
| `11100000` | 224 |
| `11110000` | 240 |
| `11111000` | 248 |
| `11111100` | 252 |
| `11111110` | 254 |
| `11111111` | 255 |

이 값들은 다음 편의 서브넷 마스크 계산에서 반복해서 사용한다.

<Callout type="warning">
IPv4 옥텟에 256이나 음수는 올 수 없다. 8비트로 표현 가능한 범위가 0~255이기 때문이다.
</Callout>

## 전체 주소 변환 예제

`172.16.5.130`을 변환한다.

```text
172 = 128 + 32 + 8 + 4       = 10101100
16  = 16                     = 00010000
5   = 4 + 1                  = 00000101
130 = 128 + 2                = 10000010

172.16.5.130
= 10101100.00010000.00000101.10000010
```

## 정리
IPv4는 8비트 옥텟 네 개로 구성된다. 자리값 `128 64 32 16 8 4 2 1`로 양방향 변환할 수 있어야 서브넷 마스크와 주소 범위를 계산할 수 있다.
