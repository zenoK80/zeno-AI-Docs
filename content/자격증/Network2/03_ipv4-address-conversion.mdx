## 이번 편의 목표
- IPv4 주소가 8비트 네 묶음으로 구성됨을 설명한다.
- 10진수 옥텟을 2진수로, 2진수를 10진수로 변환한다.
- 주소와 서브넷 마스크 계산에 필요한 비트 감각을 익힌다.

## IPv4의 구조

IPv4 주소는 32비트이며, 읽기 쉽게 8비트씩 네 옥텟으로 나눈다.

```text
192      . 168      . 10       . 25
11000000 . 10101000 . 00001010 . 00011001
```

8비트의 자리값은 왼쪽부터 다음과 같다.

| 비트 자리 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

모든 비트가 0이면 0, 모두 1이면 `128+64+32+16+8+4+2+1=255`다. 따라서 각 옥텟의 범위는 0~255다.

## 10진수를 2진수로 바꾸기

`168`을 변환해 보자.

1. 168에서 가장 큰 자리값 128을 사용한다: 남은 값 40
2. 64는 사용할 수 없다: 0
3. 32를 사용한다: 남은 값 8
4. 16은 사용할 수 없다: 0
5. 8을 사용한다: 남은 값 0
6. 나머지 4, 2, 1은 모두 0

```text
자리값: 128 64 32 16 8 4 2 1
비트:     1  0  1  0 1 0 0 0
결과: 10101000
```

`25 = 16 + 8 + 1`이므로 `00011001`이다. 앞의 0도 포함해 반드시 8자리로 쓴다.

## 2진수를 10진수로 바꾸기

`11000010`에서 1인 자리값을 더한다.

```text
128 + 64 + 2 = 194
```

따라서 `11000010`은 194다.

## 빠르게 기억할 경계값

| 2진수 | 10진수 |
| --- | ---: |
| `10000000` | 128 |
| `11000000` | 192 |
| `11100000` | 224 |
| `11110000` | 240 |
| `11111000` | 248 |
| `11111100` | 252 |
| `11111110` | 254 |
| `11111111` | 255 |

이 값들은 다음 편의 서브넷 마스크 계산에서 반복해서 사용한다.

<Callout type="warning">
IPv4 옥텟에 256이나 음수는 올 수 없다. 8비트로 표현 가능한 범위가 0~255이기 때문이다.
</Callout>

## 전체 주소 변환 예제

`172.16.5.130`을 변환한다.

```text
172 = 128 + 32 + 8 + 4       = 10101100
16  = 16                     = 00010000
5   = 4 + 1                  = 00000101
130 = 128 + 2                = 10000010

172.16.5.130
= 10101100.00010000.00000101.10000010
```

## 정리
IPv4는 8비트 옥텟 네 개로 구성된다. 자리값 `128 64 32 16 8 4 2 1`로 양방향 변환할 수 있어야 서브넷 마스크와 주소 범위를 계산할 수 있다.
