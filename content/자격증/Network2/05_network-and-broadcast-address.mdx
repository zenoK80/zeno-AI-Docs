## 주소 세 가지를 구분한다

하나의 서브넷에는 네트워크를 나타내는 주소, 모든 호스트에게 보내는 브로드캐스트 주소, 실제 장비에 할당하는 호스트 주소가 있다.

```txt
IP: 192.168.10.70/26
블록: 0~63, 64~127, 128~191, 192~255
```

70은 `64~127` 구간에 있으므로 결과는 다음과 같다.

| 구분 | 값 |
| --- | --- |
| 네트워크 주소 | 192.168.10.64 |
| 사용 가능 범위 | 192.168.10.65 ~ 192.168.10.126 |
| 브로드캐스트 주소 | 192.168.10.127 |

## 계산 순서

1. CIDR을 서브넷 마스크로 바꾼다.
2. 마지막으로 변하는 묶음의 블록 크기를 구한다.
3. IP가 속한 블록의 시작값을 네트워크 주소로 잡는다.
4. 블록의 마지막값을 브로드캐스트 주소로 잡는다.
5. 양 끝 주소를 뺀 범위가 일반 호스트 주소다.

<Callout type="warning">
일반적인 IPv4 서브넷에서 네트워크 주소와 브로드캐스트 주소는 PC에 할당하지 않는다. 문제에서 호스트 IP를 묻는지 주소 범위를 묻는지 먼저 확인한다.
</Callout>

## 확인 문제

`10.0.0.130/25`를 계산해 보자. `/25`의 블록 크기는 128이므로 구간은 `0~127`, `128~255`다. 따라서 네트워크 주소는 `10.0.0.128`, 브로드캐스트 주소는 `10.0.0.255`다.

## 이번 편 정리

- 네트워크 주소는 블록의 시작, 브로드캐스트 주소는 끝이다.
- 블록 크기를 구하면 IP가 속한 범위를 빠르게 찾을 수 있다.
- 다음부터 이 계산을 Windows와 라우터 설정값에 적용한다.
