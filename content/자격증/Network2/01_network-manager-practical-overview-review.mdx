## 01편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

### 문제 1
IP 주소를 입력한 뒤 가장 먼저 확인할 네 값은 무엇인가?

### 문제 2
설정 화면에서 정상적으로 입력했는데 통신되지 않는다. 곧바로 전체 설정을 지우기 전에 해야 할 일은 무엇인가?

### 문제 3
게이트웨이가 호스트와 같은 로컬 네트워크에 있어야 하는 이유를 설명해 보자.

## 정답과 해설

1. IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버다.
2. 저장·적용 여부와 `ipconfig` 등 실제 반영 상태를 먼저 확인한다.
3. 호스트가 원격 네트워크로 보낼 프레임을 게이트웨이에 직접 전달할 수 있어야 하기 때문이다.
