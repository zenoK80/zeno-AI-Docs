## `/24`는 무엇을 뜻할까?

CIDR 표기 `/24`는 IPv4 32비트 중 앞 24비트가 네트워크 부분이라는 뜻이다. 네트워크 부분은 1, 호스트 부분은 0으로 놓으면 서브넷 마스크가 된다.

```txt
/24
11111111.11111111.11111111.00000000
255.255.255.0
```

| CIDR | 서브넷 마스크 | 한 네트워크의 주소 수 |
| --- | --- | ---: |
| /24 | 255.255.255.0 | 256 |
| /25 | 255.255.255.128 | 128 |
| /26 | 255.255.255.192 | 64 |
| /27 | 255.255.255.224 | 32 |

## 왜 마스크가 필요한가?

`192.168.10.20/24`와 `192.168.10.30/24`는 앞 24비트가 같으므로 같은 네트워크에 있다. 반면 `192.168.11.30/24`는 다른 네트워크다. 같은 네트워크면 직접 통신할 수 있고, 다르면 기본 게이트웨이가 필요하다.

## 직접 계산하기

`/26`은 앞 세 묶음이 `255.255.255`이고 마지막 묶음에서 앞 두 비트가 1이다.

```txt
11000000 = 128 + 64 = 192
따라서 /26 = 255.255.255.192
```

`/26`의 블록 크기는 마지막 값에서 `256 - 192 = 64`다. 그래서 마지막 묶음은 `0, 64, 128, 192` 단위로 네트워크가 나뉜다.

## 흔한 실수

- `/24`를 주소가 24개라는 뜻으로 이해하기
- CIDR 비트를 오른쪽부터 1로 채우기
- 블록 크기를 마스크 값 자체로 계산하기

## 이번 편 정리

- CIDR은 네트워크 부분의 비트 수다.
- `/26`은 255.255.255.192이며 마지막 묶음이 64씩 나뉜다.
- 다음 편에서는 이 블록 크기로 네트워크와 브로드캐스트 주소를 찾는다.
