## 📌 UTP 케이블 제작 개요

네트워크관리사 2급 실기 시험 시작 시 **가장 먼저 진행되는 1번 문제(시험 시간: 10분, 배점: 6.5점)**입니다. 
제공된 UTP 케이블, RJ-45 커넥터 2개, 탈피기(스트리퍼), 랜 툴(Crimper)을 이용하여 지시된 형태(다이렉트 또는 크로스)의 케이블을 직접 제작해야 합니다.

<Callout type="warning">
**시험장 주의사항**
- **제한 시간 10분**이 지나면 즉시 케이블 제작 시험이 종료되며, 작업 중이더라도 케이블 제출 후 에뮬레이터 시험으로 넘어가게 됩니다.
- 피복을 벗길 때 구리 선 내부에 흠집(스크래치)이 생겨 단선되지 않도록 주의하세요.
</Callout>

## 🎨 핀 배열 표준 (T568B / T568A)

UTP 케이블은 **8개의 선**으로 구성되어 있으며, 배열 방식에 따라 **T568B(B 규격)**와 **T568A(A 규격)**로 나뉩니다.

[RJ-45 핀 번호 방향]
커넥터의 핀(금색 단자)이 위를 향하고, 꼬리(딸깍이)가 아래를 향하게 잡았을 때
왼쪽부터 1번 ~ 8번입니다.


### 1. T568B 규격 (일반 표준)
가장 흔하게 사용되는 표준 배선 방식입니다.

* **1번**: 띠주 (주황색 흰색)
* **2번**: 주 (주황색)
* **3번**: 띠녹 (초록색 흰색)
* **4번**: 파 (파란색)
* **5번**: 띠파 (파란색 흰색)
* **6번**: 녹 (초록색)
* **7번**: 띠갈 (갈색 흰색)
* **8번**: 갈 (갈색)

### 2. T568A 규격
T568B에서 **주황색 쌍(1,2번)**과 **초록색 쌍(3,6번)**의 위치를 서로 바꾼 배열입니다.

* **1번**: 띠녹 (초록색 흰색)
* **2번**: 녹 (초록색)
* **3번**: 띠주 (주황색 흰색)
* **4번**: 파 (파란색)
* **5번**: 띠파 (파란색 흰색)
* **6번**: 주 (주황색)
* **7번**: 띠갈 (갈색 흰색)
* **8번**: 갈 (갈색)

## 🔌 케이블 종류 및 연결 장비 구분

시험 문제에서는 "다이렉트 케이블을 제작하시오"라고 직접 알려주기도 하지만, **"PC와 스위치를 연결하는 케이블을 제작하시오"**와 같이 장비를 제시하는 경우도 있습니다.

<Tabs items={['다이렉트 케이블 (Direct)', '크로스 케이블 (Cross)']}>
  <Tab>
    ### 다이렉트 케이블 (Direct Cable)
    - **양쪽 동일한 규격**: `T568B` — `T568B` (또는 T568A — T568A)
    - **용도**: **서로 다른 계층(동종이 아닌) 장비**를 연결할 때 사용
    
    | 연결 대상 예시 | 케이블 종류 |
    | :--- | :--- |
    | **PC** ↔ **Switch / Hub** | 다이렉트 케이블 |
    | **Router** ↔ **Switch** | 다이렉트 케이블 |
    | **Server** ↔ **Switch** | 다이렉트 케이블 |
  </Tab>
  <Tab>
    ### 크로스 케이블 (Cross Cable)
    - **양쪽 다른 규격**: `T568B` — `T568A` (1,2번과 3,6번이 상호 교차)
    - **용도**: **서로 같은 계층(동종) 장비**를 연결할 때 사용
    
    | 연결 대상 예시 | 케이블 종류 |
    | :--- | :--- |
    | **PC** ↔ **PC** | 크로스 케이블 |
    | **Switch** ↔ **Switch** | 크로스 케이블 |
    | **Hub** ↔ **Hub** | 크로스 케이블 |
    | **Router** ↔ **PC** (※ 개념상 동일 계층 취급) | 크로스 케이블 |
  </Tab>
</Tabs>

<Callout type="info">
**시험 팁**: 문제가 애매하다면 대부분 **다이렉트 케이블(T568B - T568B)**이 출제 비중의 90% 이상을 차지합니다. 하지만 반드시 문제지의 연결 대상을 먼저 확인하세요!
</Callout>

## 🛠 제작 단계별 절차 (Step-by-Step)

<Steps>
### 1단계: 피복 제거 (탈피)
탈피기를 이용하여 케이블 양쪽 끝의 외피(피복)를 **약 2~3cm 정도** 탈피합니다. 내부에 있는 구리 선이 씹히거나 잘리지 않도록 주의해서 돌려줍니다.

### 2단계: 선 정렬 및 펴기
꼬여 있는 8가닥의 선을 풀고 펴준 뒤, 지시된 규격(T568B 또는 T568A)의 순서대로 정렬합니다.
- **T568B**: 띠주-주-띠녹-파-띠파-녹-띠갈-갈

### 3단계: 선 자르기 (길이 조절)
정렬된 8개의 선을 엄지손가락으로 꽉 집은 후, 랜 툴의 커터(가위) 부분을 이용해 피복 끝선으로부터 **약 1.3cm ~ 1.5cm** 남기고 수평으로 일직선으로 잘라냅니다.

### 4단계: RJ-45 커넥터 삽입
RJ-45 커넥터의 **투명한 핀(금색 핀)이 있는 쪽이 위로 오도록** 잡고, 잘라낸 선을 끝까지 쑥 밀어 넣습니다.
- 외피(피복)가 RJ-45 내부의 고정 홈(압착 파트)까지 깊숙이 들어가야 찝었을 때 빠지지 않습니다.

### 5단계: 랜 툴로 압착 (Crimping)
RJ-45 커넥터를 랜 툴의 8P 구멍에 넣고 꽉 쥐어 압착합니다. "딸깍" 소리나 손에 꽉 조여지는 느낌이 들 때까지 확실히 눌러줍니다.

### 6단계: 랜 테스터기 검사 및 제출
양쪽 모두 완료되면 랜 테스터기 웰에 꽂아 불이 순서대로 들어오는지 확인 후 제출합니다.
- **다이렉트**: 양쪽 모두 1-2-3-4-5-6-7-8 순서대로 동시 점등
- **크로스**: 한쪽이 1-2-3-4-5-6-7-8일 때 다른 쪽은 3-6-1-4-5-2-7-8 순서로 점등
</Steps>

## 📝 실전 모의 문제 (Check Quiz)

<Cards>
  <Card title="문제 1" image>
    **Q. PC 2대를 1:1로 직접 연결하여 통신하려고 한다. 제작해야 하는 케이블 종류와 양쪽 끝의 핀 배선을 작성하시오.**
    
    <details>
      <summary>정답 및 해설 보기</summary>
      
      - **케이블 종류**: 크로스 케이블 (Cross Cable)
      - **한쪽 핀 배선 (T568B)**: 띠주 - 주 - 띠녹 - 파 - 띠파 - 녹 - 띠갈 - 갈
      - **반대쪽 핀 배선 (T568A)**: 띠녹 - 녹 - 띠주 - 파 - 띠파 - 주 - 띠갈 - 갈
      
      **해설**: PC와 PC는 동일한 계층의 장비이므로 크로스 케이블을 제작해야 합니다.
    </details>
  </Card>

  <Card title="문제 2" image>
    **Q. T568B 규격으로 다이렉트 케이블 제작 시 3번 핀과 6번 핀에 연결되는 케이블의 색상은?**
    
    <details>
      <summary>정답 및 해설 보기</summary>
      
      - **3번 핀**: 띠녹 (초록색 흰색)
      - **6번 핀**: 녹 (초록색)
      
      **해설**: T568B의 순서는 `1:띠주, 2:주, 3:띠녹, 4:파, 5:띠파, 6:녹, 7:띠갈, 8:갈`입니다. 3번과 6번은 초록색 계열입니다.
    </details>
  </Card>
</Cards>
