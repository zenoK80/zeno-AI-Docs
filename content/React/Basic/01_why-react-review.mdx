## 실습 — 명령형 코드를 선언형으로 바꿔보기

아래는 "좋아요 수가 100 넘으면 배지를 보여주는" 명령형 코드다.

```js
function increaseLike() {
  const countEl = document.querySelector('#count')
  let count = Number(countEl.textContent) + 1
  countEl.textContent = count

  if (count > 100) {
    document.querySelector('#badge').style.display = 'block'
  }
}
```

이걸 "count가 이 값이면 화면은 이렇다"는 선언형 문장으로 말로 풀어써 보자. (코드로 짤 필요는 없다 — 5편에서 JSX로 직접 짜본다.)

<Collapse title="예시 답안">
"좋아요 개수를 화면에 보여준다. count가 100보다 크면, 배지도 함께 보여준다."

이렇게 **"어떻게 바꿀지"가 아니라 "지금 상태에서 화면이 어떤 모습인지"** 로 표현하는 게 선언형 사고다. 10편(컴포넌트)부터 이걸 실제 코드로 만든다.
</Collapse>
