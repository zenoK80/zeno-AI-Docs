## 실습 — 나만의 React 페이지 만들기

<Steps>

### HTML 파일을 만든다

`practice.html` 파일을 만들고 본문의 예제 코드(React + ReactDOM CDN)를 그대로 붙여넣는다.

### 브라우저로 열어 확인한다

"안녕, React"가 뜨는지 확인한다.

### 내용을 바꿔본다

`React.createElement('h1', null, '안녕, React')`를 `React.createElement('h1', { style: { color: 'crimson' } }, '내가 만든 첫 화면')`으로 바꿔보고 결과를 확인한다.

### Babel과 JSX를 추가한다

`@babel/standalone` 스크립트를 추가하고, `type="text/babel"` 스크립트 안에서 `createElement` 대신 JSX로 같은 화면을 만들어본다.

</Steps>
