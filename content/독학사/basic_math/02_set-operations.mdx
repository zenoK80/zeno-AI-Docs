## 집합 연산은 조건을 조합하는 방법이다

집합 연산은 “A 또는 B에 해당하는 사람”, “A와 B 모두에 해당하는 사람” 같은 조건을 간단히 표현한다. 수학 기호를 외우기 전에 문장으로 읽어 보자.

```txt
A = {통계, 영어, 수학}       // 월요일 수업
B = {영어, 프로그래밍, 수학} // 오전 수업
```

| 연산 | 읽는 방법 | 결과 |
| --- | --- | --- |
| A union B | A 또는 B에 있는 과목 | `{통계, 영어, 수학, 프로그래밍}` |
| A intersection B | A와 B 모두에 있는 과목 | `{영어, 수학}` |
| A - B | A에는 있지만 B에는 없는 과목 | `{통계}` |

## 합집합과 교집합

합집합 `A union B`은 두 집합의 원소를 모두 모은 것이다. 같은 원소는 한 번만 쓴다. 교집합 `A intersection B`은 두 집합에 공통으로 들어 있는 원소만 모은 것이다.

```txt
A union B = {통계, 영어, 수학, 프로그래밍}
A intersection B = {영어, 수학}
```

“월요일 수업이거나 오전 수업인 과목”은 합집합이고, “월요일이면서 오전 수업인 과목”은 교집합이다. 문장의 `또는`, `그리고`를 기호와 연결해 읽는 습관이 중요하다.

## 차집합과 여집합

차집합 `A - B`는 A에서 B와 겹치는 원소를 뺀 것이다. 순서를 바꾸면 결과도 달라진다.

```txt
A - B = {통계}
B - A = {프로그래밍}
```

여집합은 먼저 전체 범위 `U`를 정해야 한다. 예를 들어 이번 학기 개설 과목이 `U = {통계, 영어, 수학, 프로그래밍, 철학}`이라면, A의 여집합은 A에 속하지 않는 `{프로그래밍, 철학}`이다.

<Callout type="warning">
여집합은 전체집합을 정하지 않으면 계산할 수 없다. “A가 아닌 것”은 무엇을 전체로 보느냐에 따라 달라진다.
</Callout>

## 직접 풀어 보기

```txt
U = {1, 2, 3, 4, 5, 6}
C = {1, 2, 3, 4}
D = {3, 4, 5}
```

1. `C intersection D`는 `{3, 4}`이다.
2. `C union D`는 `{1, 2, 3, 4, 5}`이다.
3. `C - D`는 `{1, 2}`이다.
4. C의 여집합은 `{5, 6}`이다.

답을 낸 뒤에는 각 원소가 어느 집합에 들어 있는지 하나씩 확인해 보자. 벤 다이어그램을 직접 그려도 좋다.

## 흔한 실수

- 합집합에서 중복 원소를 두 번 쓰기
- 차집합의 순서를 바꾸고 같은 결과를 기대하기
- 전체집합 없이 여집합을 쓰기
- `또는`을 일상어의 “둘 중 하나만”으로 해석하기: 집합의 합집합은 둘 다 포함해도 된다.

## 이번 편 정리

- 합집합은 둘 중 하나 이상에 속하는 원소, 교집합은 둘 다에 속하는 원소다.
- 차집합은 순서가 중요하고, 여집합은 전체집합이 필요하다.
- 집합 연산은 조건을 논리적으로 읽는 기초가 된다.
