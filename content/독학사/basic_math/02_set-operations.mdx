## 이번 편의 목표

- 합집합, 교집합, 차집합, 여집합을 계산한다.
- 전체집합이 바뀌면 여집합도 바뀐다는 점을 설명한다.
- 드모르간 법칙을 적용하고 원소 하나씩 검산한다.
- 원소 개수 문제에 포함배제 원리를 사용한다.

## 먼저 알아둘 말

| 용어 | 쉬운 뜻 | 기호를 문장으로 읽기 |
| --- | --- | --- |
| 연산 | 주어진 대상에 정해진 규칙을 적용해 새 결과를 만드는 일 | 두 집합을 합치거나 겹치는 부분을 찾기 |
| 합집합 | 두 집합 중 한쪽에라도 들어 있는 원소의 모임 | A ∪ B: A 또는 B |
| 교집합 | 두 집합에 모두 들어 있는 원소의 모임 | A ∩ B: A 그리고 B |
| 차집합 | 앞 집합에는 있고 뒤 집합에는 없는 원소의 모임 | A - B: A이지만 B는 아님 |
| 전체집합 | 현재 문제에서 생각하기로 한 모든 원소의 범위 | 학급 전체 학생 |
| 여집합 | 전체집합에는 있지만 해당 집합에는 없는 원소의 모임 | Aᶜ: A가 아님 |

**또는**은 둘 중 적어도 하나가 참이라는 뜻이라 둘 다 참인 경우도 포함한다. **그리고**는 두 조건이 모두 참이어야 한다. 이 차이를 놓치면 합집합과 교집합을 반대로 고르기 쉽다.

## 주변 개념 지도

집합 연산은 단순한 기호 계산이 아니다. 검색 조건의 OR와 AND, 확률의 “A 또는 B”, 데이터베이스의 조건 결합도 같은 생각을 사용한다. 드모르간 법칙은 조건 전체를 부정할 때 “그리고”와 “또는”이 서로 바뀐다는 규칙이다.

<Callout type="info">
계산하기 전에 기호를 한국어 조건으로 바꾼다. 예를 들어 (A ∪ B)ᶜ는 “A에도 없고 B에도 없는 원소”라고 읽을 수 있다.
</Callout>

## 집합의 연산은 조건을 결합하는 방법이다

동아리 신청 자료를 생각해 보자.

```text
전체 학생 U = {민수, 지우, 서연, 현우, 유진}
축구 신청 A = {민수, 지우, 현우}
농구 신청 B = {지우, 서연, 현우}
```

"축구 또는 농구를 신청한 학생", "두 종목 모두 신청한 학생", "축구만 신청한 학생"은 집합 연산으로 정확하게 표현할 수 있다.

## 합집합: 둘 중 하나라도 포함

**합집합(union)** `A ∪ B`는 A 또는 B에 속하는 모든 원소의 집합이다. 여기서 "또는"은 둘 다 속하는 경우도 포함한다.

```text
A ∪ B = {민수, 지우, 서연, 현우}
```

지우와 현우는 두 집합에 모두 있지만 한 번만 적는다. 집합은 중복을 세지 않기 때문이다.

## 교집합: 둘 모두에 포함

**교집합(intersection)** `A ∩ B`는 A와 B에 동시에 속하는 원소의 집합이다.

```text
A ∩ B = {지우, 현우}
```

두 집합이 공통 원소를 하나도 갖지 않으면 서로 **서로소**라고 하며, 교집합은 공집합이다.

## 차집합: 앞 집합에서 뒤 집합을 제외

**차집합(difference)** `A - B`는 A에는 속하지만 B에는 속하지 않는 원소의 집합이다.

```text
A - B = {민수}
B - A = {서연}
```

차집합은 순서가 중요하다. 일반적으로 `A - B`와 `B - A`는 다르다.

## 여집합: 전체에서 해당 집합을 제외

전체집합 `U`가 정해져 있을 때 **여집합(complement)** `Aᶜ`은 U에는 속하지만 A에는 속하지 않는 원소의 집합이다.

```text
Aᶜ = U - A = {서연, 유진}
```

<Callout type="warning">
  여집합은 전체집합이 무엇인지 알아야 구할 수 있다. A가 같아도 U가 달라지면 Aᶜ도 달라진다.
</Callout>

## 기호를 조건으로 읽기

집합 연산은 원소 `x`가 어떤 조건을 만족하는지로 읽으면 덜 헷갈린다.

| 표현 | 원소 x가 들어가는 조건 | 자연어 |
| --- | --- | --- |
| `x ∈ A ∪ B` | A에 있거나 B에 있음 | 적어도 하나 |
| `x ∈ A ∩ B` | A와 B에 모두 있음 | 둘 다 |
| `x ∈ A - B` | A에는 있고 B에는 없음 | A만 |
| `x ∈ Aᶜ` | U에는 있고 A에는 없음 | A가 아님 |

## 드모르간 법칙

두 집합을 부정할 때 합집합과 교집합이 서로 바뀐다.

```text
(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
```

첫 번째 식을 말로 읽어 보자.

- `(A ∪ B)ᶜ`: A에도 B에도 속하지 않는 원소
- `Aᶜ ∩ Bᶜ`: A에 속하지 않고 동시에 B에도 속하지 않는 원소

두 표현은 같은 조건이다.

### 실제 원소로 검산하기

```text
U = {1, 2, 3, 4, 5, 6}
A = {1, 2, 3}
B = {3, 4}
```

왼쪽부터 계산한다.

```text
A ∪ B = {1, 2, 3, 4}
(A ∪ B)ᶜ = {5, 6}
```

오른쪽도 계산한다.

```text
Aᶜ = {4, 5, 6}
Bᶜ = {1, 2, 5, 6}
Aᶜ ∩ Bᶜ = {5, 6}
```

양쪽 결과가 같으므로 법칙이 맞음을 확인할 수 있다.

## 원소의 개수와 포함배제

두 집합의 합집합 원소 수를 단순히 더하면 교집합 원소를 두 번 세게 된다. 그래서 한 번 빼준다.

```text
n(A ∪ B) = n(A) + n(B) - n(A ∩ B)
```

축구 신청자가 18명, 농구 신청자가 15명, 두 종목 모두 신청한 학생이 7명이라면 적어도 한 종목을 신청한 학생은 다음과 같다.

```text
18 + 15 - 7 = 26명
```

두 종목 모두 신청한 7명을 각각의 집합에서 한 번씩, 총 두 번 세었으므로 한 번 빼는 것이다.

## 시험형 예제

전체 학생이 40명이고 영어 수강자가 24명, 수학 수강자가 20명, 두 과목 모두 수강한 학생이 9명이라고 하자.

1. 적어도 한 과목을 수강한 학생 수
2. 어느 과목도 수강하지 않은 학생 수
3. 영어만 수강한 학생 수

계산은 다음과 같다.

```text
적어도 한 과목 = 24 + 20 - 9 = 35명
어느 과목도 아님 = 40 - 35 = 5명
영어만 = 24 - 9 = 15명
```

## 정리

<Callout type="default">
  - 합집합은 적어도 하나, 교집합은 둘 모두에 속하는 원소를 모은다.
  - 차집합은 순서가 중요하고, 여집합은 전체집합을 기준으로 한다.
  - 드모르간 법칙에서는 합집합과 교집합이 바뀌며 각 집합에 여집합이 붙는다.
  - 합집합의 원소 수는 교집합을 두 번 세지 않도록 한 번 뺀다.
</Callout>
