## 복소수의 정의

$i^2 = -1$을 만족하는 허수단위 $i$를 도입하면, $a + bi$ ($a, b \in \mathbb{R}$) 형태의 수를 **복소수**라 합니다.

- $a$를 **실수부**, $b$를 **허수부**라 합니다.
- $b = 0$이면 실수, $b \neq 0$이면 허수입니다.
- $a = 0$이고 $b \neq 0$이면 **순허수**라 합니다.

두 복소수 $a + bi = c + di$이면 $a = c$이고 $b = d$입니다.

**켤레복소수:** $z = a + bi$의 켤레복소수는 $\bar{z} = a - bi$입니다.

$$z\bar{z} = (a+bi)(a-bi) = a^2 + b^2$$

## 복소수의 사칙연산

$$\text{덧셈: } (a+bi)+(c+di) = (a+c)+(b+d)i$$

$$\text{뺄셈: } (a+bi)-(c+di) = (a-c)+(b-d)i$$

$$\text{곱셈: } (a+bi)(c+di) = (ac-bd)+(ad+bc)i$$

$$\text{나눗셈: } \frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{c^2+d^2}$$

나눗셈은 분모의 켤레복소수를 분자·분모에 곱해 분모를 실수로 만듭니다.

**예제:** $\dfrac{1+2i}{3-i}$를 계산하시오.

$$\frac{(1+2i)(3+i)}{(3-i)(3+i)} = \frac{3+i+6i+2i^2}{9+1} = \frac{3+7i-2}{10} = \frac{1+7i}{10} = \frac{1}{10} + \frac{7}{10}i$$

## 복소수의 극형식

복소수 $z = a + bi$를 좌표 평면(**복소평면**)의 점 $(a, b)$로 나타낼 수 있습니다.

복소수의 **절댓값(모듈러스):** $|z| = r = \sqrt{a^2+b^2}$

**편각:** $\theta = \arg(z)$, $\tan\theta = b/a$

**극형식:**

$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

**예제:** $z = 1 + i$를 극형식으로 나타내시오.

$$r = \sqrt{1^2+1^2} = \sqrt{2}, \quad \theta = \frac{\pi}{4}$$

$$z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$$

<Callout type="warning">
  편각 $\theta$는 복소평면에서 양의 실수축으로부터 반시계 방향으로 잰 각도입니다. 제3·4사분면에서는 각도에 주의해야 합니다.
</Callout>

## 드무아브르 정리

극형식 $z = r(\cos\theta + i\sin\theta)$에 대해 다음이 성립합니다.

$$z^n = r^n(\cos n\theta + i\sin n\theta)$$

이를 **드무아브르(de Moivre) 정리**라 합니다.

**예제:** $(1+i)^8$을 계산하시오.

$z = 1+i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$이므로

$$z^8 = (\sqrt{2})^8\left(\cos\frac{8\pi}{4} + i\sin\frac{8\pi}{4}\right) = 16(\cos 2\pi + i\sin 2\pi) = 16$$

## $n$제곱근

방정식 $w^n = z$의 해를 $z$의 $n$제곱근이라 합니다. $z = re^{i\theta}$이면 $n$제곱근은 다음과 같습니다.

$$w_k = r^{1/n}\left(\cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n}\right), \quad k = 0, 1, \ldots, n-1$$

**예제:** 1의 세제곱근 `{1, ω, ω²}`에서 $\omega = \cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3} = -\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i$입니다.

## 핵심 정리

- 허수단위: $i^2 = -1$
- 켤레복소수: $z\bar{z} = a^2+b^2$ (항상 실수)
- 극형식: $z = r(\cos\theta + i\sin\theta)$, $r = |z|$
- 드무아브르 정리: $z^n = r^n(\cos n\theta + i\sin n\theta)$
