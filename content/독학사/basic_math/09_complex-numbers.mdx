## 왜 복소수를 배우나요?

"음수의 제곱근"이 존재하지 않는다는 한계를 극복하기 위해 복소수가 등장했습니다. $x^2 = -1$이라는 방정식은 실수에서 해가 없지만, 복소수를 도입하면 해가 생깁니다. 복소수는 처음에는 인위적인 확장처럼 보이지만, 전기공학(교류 회로 분석), 신호 처리, 양자역학, 제어 이론 등 현대 기술에서 없어서는 안 되는 도구입니다.

## 복소수의 정의

$x^2 = -1$의 해가 되도록 **허수단위 `imaginary unit`** $i$를 도입합니다.

$$i^2 = -1, \quad \text{즉} \quad i = \sqrt{-1}$$

$i$를 이용하면 $a + bi$ ($a, b \in \mathbb{R}$) 형태의 수를 **복소수 `complex number`(복소수)**라 합니다.

- $a$: **실수부 `real part`** ($\text{Re}(z) = a$)
- $b$: **허수부 `imaginary part`** ($\text{Im}(z) = b$)
- $b = 0$이면 실수 (실수는 복소수의 특별한 경우)
- $b \neq 0$이면 허수
- $a = 0$이고 $b \neq 0$이면 **순허수**

두 복소수 $a + bi = c + di$이면 $a = c$이고 $b = d$입니다. (실수부끼리, 허수부끼리 같아야 함)

**켤레복소수 `complex conjugate`:** $z = a + bi$의 켤레복소수는 $\bar{z} = a - bi$입니다. 허수부의 부호만 바뀝니다.

$$z\bar{z} = (a+bi)(a-bi) = a^2 + b^2 \quad \text{(항상 실수, 항상 양수 또는 0)}$$

켤레복소수를 곱하면 허수 부분이 사라지고 항상 실수가 됩니다. 이 성질을 나눗셈에 활용합니다.

**$i$의 거듭제곱 규칙 (4주기):**
- $i^1 = i$
- $i^2 = -1$
- $i^3 = -i$
- $i^4 = 1$ (다시 반복)

큰 거듭제곱: $i^{17} = i^{16} \cdot i = (i^4)^4 \cdot i = 1^4 \cdot i = i$

## 복소수의 사칙연산

**덧셈과 뺄셈:** 실수부끼리, 허수부끼리 계산합니다.

$$\text{덧셈: } (a+bi)+(c+di) = (a+c)+(b+d)i$$

$$\text{뺄셈: } (a+bi)-(c+di) = (a-c)+(b-d)i$$

**곱셈:** $i^2 = -1$을 이용해 전개합니다.

$$\text{곱셈: } (a+bi)(c+di) = (ac-bd)+(ad+bc)i$$

외우는 방법: 일반 다항식처럼 FOIL 전개하고, $i^2 = -1$로 치환합니다.

**나눗셈:** 분모의 켤레복소수를 분자·분모에 곱해 분모를 실수로 만듭니다.

$$\text{나눗셈: } \frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{c^2+d^2}$$

**예제:** $\dfrac{1+2i}{3-i}$를 계산하시오.

$$\frac{(1+2i)(3+i)}{(3-i)(3+i)} = \frac{3+i+6i+2i^2}{9+1} = \frac{3+7i-2}{10} = \frac{1+7i}{10} = \frac{1}{10} + \frac{7}{10}i$$

## 복소수의 극형식

복소수 $z = a + bi$를 좌표 평면(**복소평면 `complex plane`**)의 점 $(a, b)$로 나타낼 수 있습니다.

- 가로축: 실수축 (실수부)
- 세로축: 허수축 (허수부)

복소수의 **절댓값(모듈러스 `modulus`):**

$$|z| = r = \sqrt{a^2+b^2}$$

복소평면에서 원점에서 점 $(a, b)$까지의 거리입니다.

**편각 `argument`:** $\theta = \arg(z)$, 양의 실수축으로부터 반시계 방향으로 잰 각도입니다.

$$\tan\theta = \frac{b}{a}$$

**극형식 `polar form`:**

$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

- 직교형식 $a+bi$: 성분으로 표현
- 극형식 $r(\cos\theta + i\sin\theta)$: 크기와 방향으로 표현

**예제:** $z = 1 + i$를 극형식으로 나타내시오.

$$r = \sqrt{1^2+1^2} = \sqrt{2}, \quad \theta = \frac{\pi}{4} \text{ (45도, 1사분면에서 실수부=허수부이므로)}$$

$$z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$$

<Callout type="warning">
  편각 $\theta$는 복소평면에서 양의 실수축으로부터 반시계 방향으로 잰 각도입니다. 제3·4사분면(실수부가 음수이거나 허수부가 음수)에서는 각도 계산에 주의해야 합니다. 제2사분면: $\theta = \pi - \arctan|b/a|$, 제3사분면: $\theta = \pi + \arctan|b/a|$
</Callout>

## 드무아브르 정리

극형식 $z = r(\cos\theta + i\sin\theta)$에 대해 다음이 성립합니다.

$$z^n = r^n(\cos n\theta + i\sin n\theta)$$

이를 **드무아브르 `de Moivre` 정리**라 합니다.

쉽게 말하면: 극형식으로 표현된 복소수를 n제곱하면, 크기는 n제곱하고 각도는 n배가 됩니다.

**왜 유용한가:** $(1+i)^{100}$처럼 큰 지수의 복소수 거듭제곱을 직접 계산하면 매우 복잡하지만, 극형식으로 바꾸면 간단하게 구할 수 있습니다.

**예제:** $(1+i)^8$을 계산하시오.

$z = 1+i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$이므로

$$z^8 = (\sqrt{2})^8\left(\cos\frac{8\pi}{4} + i\sin\frac{8\pi}{4}\right) = 16(\cos 2\pi + i\sin 2\pi) = 16(1+0) = 16$$

## $n$제곱근

방정식 $w^n = z$의 해를 $z$의 $n$제곱근이라 합니다. $z = re^{i\theta}$이면 $n$제곱근은 $n$개이고 다음과 같습니다.

$$
w_k = r^{1/n}\left(\cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n}\right)
$$

($k = 0, 1, \ldots, n-1$)

복소평면에서 $n$제곱근들은 원점을 중심으로 하는 원 위에 등간격으로 놓입니다.

**예제:** 1의 세제곱근 `{1, ω, ω²}`에서 $\omega = \cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3} = -\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i$입니다.

## 핵심 정리

- 허수단위: $i^2 = -1$, $i$의 거듭제곱은 4주기
- 켤레복소수: $z\bar{z} = a^2+b^2$ (항상 실수)
- 나눗셈: 분모의 켤레복소수를 곱해 분모를 실수화
- 극형식: $z = r(\cos\theta + i\sin\theta)$, $r = |z|$
- 드무아브르 정리: $z^n = r^n(\cos n\theta + i\sin n\theta)$
