## 이번 편의 목표

- 집합, 원소, 부분집합 기호를 정확히 읽는다.
- 원소와 부분집합을 혼동하지 않는다.
- 함수의 정의역, 공역, 치역을 구분한다.
- 주어진 대응이 함수인지 판별한다.

## 먼저 알아둘 말

| 용어 | 쉬운 뜻 | 짧은 예 |
| --- | --- | --- |
| 대상 | 우리가 분류하거나 계산하려는 것 | 숫자, 사람, 색 |
| 집합 | 분명한 기준으로 모은 대상들의 묶음 | 10보다 작은 자연수의 모임 |
| 원소 | 집합 안에 들어 있는 대상 하나하나 | 집합 `{1, 2, 3}`의 원소 2 |
| 조건 | 어떤 대상이 집합에 들어가는지 판단하는 기준 | 짝수이다 |
| 대응 | 한쪽 대상과 다른 쪽 대상을 연결하는 것 | 학생과 학번을 연결 |
| 함수 | 입력 하나마다 출력이 정확히 하나 정해지는 대응 | 숫자 x를 x + 1에 연결 |

여기서 **자연수**는 보통 1, 2, 3, ...처럼 셀 때 쓰는 수를 뜻한다. 교재에 따라 0을 포함하기도 하므로 문제에서 범위를 확인한다.

## 주변 개념 지도

집합은 대상을 **분류**하는 언어이고, 함수는 두 대상 묶음 사이의 **연결 규칙**을 표현하는 언어다. 앞으로 방정식, 확률, 그래프를 배울 때도 “어떤 값들이 가능한가”는 집합으로, “입력이 바뀌면 결과가 어떻게 바뀌는가”는 함수로 나타낸다.

<Callout type="info">
기호가 낯설어도 먼저 문장으로 읽으면 된다. x ∈ A는 “x는 A의 원소다”, f(x) = y는 “함수 f에 x를 넣으면 y가 나온다”는 뜻이다.
</Callout>

## 집합은 대상을 묶는 기준이다

**집합(set)** 은 어떤 대상들이 포함되는지 명확하게 판단할 수 있는 모임이다. 그 안에 들어 있는 각각의 대상을 **원소(element)** 라고 한다.

예를 들어 10보다 작은 양의 짝수를 모으면 다음 집합을 만들 수 있다.

```text
A = {2, 4, 6, 8}
```

`4`는 집합 `A`의 원소이므로 `4 ∈ A`라고 쓴다. `5`는 들어 있지 않으므로 `5 ∉ A`라고 쓴다.

<Callout type="important">
  집합에서는 원소의 순서와 중복을 따지지 않는다. `{1, 2, 2, 3}`과 `{3, 2, 1}`은 모두 `{1, 2, 3}`과 같은 집합이다.
</Callout>

## 집합을 나타내는 두 방법

### 원소나열법

원소를 중괄호 안에 직접 적는다.

```text
B = {1, 3, 5, 7, 9}
```

원소가 적을 때 직관적이지만, 원소가 많거나 무한하면 모두 적기 어렵다.

### 조건제시법

원소가 만족해야 하는 조건을 적는다.

```text
B = {x | x는 10보다 작은 양의 홀수}
```

세로선 `|`은 "조건을 만족하는"이라고 읽는다. 따라서 위 식은 "10보다 작은 양의 홀수인 x의 집합"이다.

## 부분집합과 진부분집합

집합 `A`의 모든 원소가 집합 `B`에도 들어 있으면 `A`는 `B`의 **부분집합(subset)** 이다.

```text
A = {1, 2}
B = {1, 2, 3}

A ⊆ B
```

두 집합이 서로 같지 않으면서 `A ⊆ B`이면 `A`를 `B`의 **진부분집합**이라고 하고 `A ⊂ B`로 나타내기도 한다. 교재에 따라 부분집합 기호 관례가 다를 수 있으므로 문제의 정의를 확인한다.

### 원소와 부분집합은 다르다

```text
A = {1, 2, {3}}
```

- `1 ∈ A`: 참
- `{3} ∈ A`: 참. 집합 `{3}` 자체가 하나의 원소로 들어 있다.
- `{1, 2} ⊆ A`: 참. 1과 2가 모두 A에 있다.
- `3 ∈ A`: 거짓. A에는 숫자 3이 아니라 집합 `{3}`이 들어 있다.

이 구분은 시험에서 자주 함정으로 나온다.

## 부분집합의 개수

원소가 `n`개인 집합의 부분집합은 `2ⁿ`개다. 각 원소마다 "포함한다/포함하지 않는다" 두 가지 선택이 있기 때문이다.

```text
A = {a, b}

부분집합:
∅, {a}, {b}, {a, b}
총 4개 = 2²
```

공집합 `∅`과 자기 자신도 항상 부분집합에 포함된다.

## 함수는 입력과 출력의 규칙이다

**함수(function)** 는 정의역의 각 원소를 공역의 원소 **정확히 하나**에 대응시키는 규칙이다.

```text
f(x) = 2x + 1
```

입력 `x = 3`을 넣으면 출력은 다음과 같다.

```text
f(3) = 2 × 3 + 1 = 7
```

함수에서는 입력 하나가 출력 여러 개로 갈 수 없다. 서로 다른 입력이 같은 출력으로 가는 것은 가능하다.

```text
f(x) = x²

f(2) = 4
f(-2) = 4
```

## 정의역, 공역, 치역

함수 `f: X → Y`를 생각해 보자.

- **정의역(domain)**: 넣을 수 있도록 정한 모든 입력의 집합 `X`
- **공역(codomain)**: 출력이 속하도록 정한 전체 집합 `Y`
- **치역(range)**: 실제로 나온 출력들의 집합

```text
X = {-2, -1, 0, 1, 2}
Y = {0, 1, 2, 3, 4, 5}
f(x) = x²
```

각 입력의 결과를 계산한다.

| x | -2 | -1 | 0 | 1 | 2 |
| --- | --- | --- | --- | --- | --- |
| f(x) | 4 | 1 | 0 | 1 | 4 |

따라서 정의역은 `X`, 공역은 `Y`, 치역은 `{0, 1, 4}`다. 치역은 공역의 부분집합이다.

## 함수인지 판별하는 방법

다음 대응을 보자.

```text
1 → a
2 → b
3 → b
```

입력 1, 2, 3이 각각 출력 하나만 가지므로 함수다. 2와 3이 같은 `b`로 가는 것은 문제가 아니다.

반면 다음은 함수가 아니다.

```text
1 → a
1 → b
2 → c
```

입력 1에 출력이 두 개이기 때문이다. 또 정의역에 포함된 입력 중 대응되는 출력이 없는 원소가 있어도 함수가 아니다.

## 시험형 예제

집합 `A = {1, 2, 3}`, `B = {a, b}`일 때 다음 대응 중 함수인 것을 판단하자.

1. `1→a, 2→a, 3→b`
2. `1→a, 1→b, 2→a, 3→b`
3. `1→a, 2→b`

1번만 함수다. 2번은 입력 1의 출력이 두 개이고, 3번은 정의역의 원소 3에 대응하는 출력이 없다.

## 정리

<Callout type="default">
  - 집합은 포함 여부가 명확한 대상들의 모임이다.
  - 원소 관계 `∈`와 부분집합 관계 `⊆`는 서로 다르다.
  - 원소가 n개인 집합의 부분집합은 `2ⁿ`개다.
  - 함수는 정의역의 각 입력을 공역의 출력 하나에 대응시킨다.
  - 치역은 실제 출력의 집합이며 공역의 부분집합이다.
</Callout>
