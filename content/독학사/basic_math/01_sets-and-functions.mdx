## 집합은 대상을 분류하는 언어다

집합은 분명한 기준에 따라 대상을 모은 것이다. 예를 들어 이번 학기에 수강하는 과목을 모아 `A = {수학, 통계, 영어}`라고 쓸 수 있다. 여기서 수학, 통계, 영어를 **원소**라고 한다.

중요한 것은 “무엇을 넣을지”가 분명해야 한다는 점이다. `좋아하는 과목의 집합`은 사람마다 달라질 수 있지만, `80점 이상 받은 과목의 집합`은 점수라는 기준이 있어 확인할 수 있다.

```txt
A = {1, 2, 3}
2 in A      // 2는 A의 원소
4 not in A  // 4는 A의 원소가 아님
```

<Callout type="info">
집합에서는 순서와 중복이 중요하지 않다. `{1, 2, 3}`과 `{3, 2, 1}`은 같은 집합이며 `{1, 1, 2}`는 `{1, 2}`와 같다.
</Callout>

## 함수는 규칙이 있는 연결이다

함수는 한 집합의 원소를 다른 집합의 원소와 연결하는 규칙이다. 단, **입력 하나는 결과 하나만** 가져야 한다.

할인율을 계산하는 규칙을 생각해 보자.

```txt
f(x) = x * 0.9
f(10,000) = 9,000
f(20,000) = 18,000
```

입력값 `x`가 가격이고 결과가 할인 후 가격이다. 같은 가격을 넣었는데 결과가 9,000원과 8,500원처럼 두 개가 나오면, 그 규칙은 함수가 아니다.

| 용어 | 뜻 | 할인 예시 |
| --- | --- | --- |
| 정의역 | 넣을 수 있다고 정한 입력의 집합 | 할인 전 가격 |
| 공역 | 결과가 속할 수 있다고 정한 집합 | 0원 이상의 금액 |
| 치역 | 실제로 나온 결과의 집합 | 9,000원, 18,000원 등 |

## 집합과 함수는 어떻게 연결될까?

함수는 “정의역의 각 원소를 공역의 원소 하나에 대응시키는 규칙”이다. 즉, 함수의 입력과 출력도 집합으로 생각한다.

```txt
정의역 D = {1, 2, 3}
f(x) = x + 10
치역 R = {11, 12, 13}
```

이 관점은 나중에 행렬, 미분, 확률변수까지 이어진다. 수식이 복잡해져도 결국은 “어떤 값을 넣었고 어떤 값이 나왔는가?”를 따지는 일이다.

## 직접 확인하기

다음 관계가 함수인지 판단해 보자.

```txt
학생 A -> 1반
학생 B -> 2반
학생 C -> 1반
```

함수다. 여러 학생이 같은 반에 갈 수는 있어도, 한 학생이 동시에 두 반에 배정되지는 않는다. 반대로 `학생 A -> 1반, 2반`이라면 함수가 아니다.

## 흔한 실수

- 출력값이 겹치면 함수가 아니라고 생각하기: 여러 입력이 하나의 출력으로 가는 것은 가능하다.
- 공역과 치역을 같은 말로 쓰기: 공역은 약속한 결과의 범위, 치역은 실제 나온 결과다.
- 집합의 중복 원소를 따로 세기: 집합에서는 같은 원소를 한 번만 센다.

## 이번 편 정리

- 집합은 기준에 따라 대상을 모은 것이고, 원소는 그 안의 대상이다.
- 함수는 입력 하나에 결과 하나를 대응시키는 규칙이다.
- 함수는 집합 사이의 연결로 이해하면 다음 개념을 받아들이기 쉽다.
