## 함수는 입력 하나에 출력 하나를 정하는 약속

**함수(function)** 는 어떤 값을 넣으면 정해진 규칙으로 결과 하나를 내놓는 약속입니다. 자판기에 버튼 하나를 누르면 정해진 음료 하나가 나오는 모습을 떠올리면 됩니다.

```math
f(x)=2x+1
```

여기서 `x`를 입력값, `f(x)`를 출력값이라고 합니다. `x=3`을 넣으면 다음과 같습니다.

```math
f(3)=2\times3+1=7
```

| 용어 | 뜻 | 위 식에서 예 |
| --- | --- | --- |
| 정의역 | 넣어도 되는 입력값의 모임 | 가능한 `x`의 범위 |
| 공역 | 출력값이 나올 수 있는 범위 | 가능한 `f(x)`의 범위 |
| 함수값 | 특정 입력에서 실제로 나온 출력 | `f(3)=7` |

## 같은 입력에서 결과가 둘이면 함수가 아니다

`x=2`를 넣었을 때 결과가 `5`와 `8` 두 개라면 어느 결과를 써야 할지 정할 수 없습니다. 그래서 함수가 아닙니다.

반대로 서로 다른 입력이 같은 출력으로 가는 것은 가능합니다. 예를 들어 `f(x)=x²`에서는 `f(2)=4`, `f(-2)=4`입니다. 입력 하나마다 출력 하나만 정해지면 함수입니다.

<Callout type="warning">
  “출력 하나에 입력 하나”가 아니라 **입력 하나에 출력 하나**가 함수의 조건입니다. 여러 입력이 같은 출력으로 가는 것은 허용됩니다.
</Callout>

## 합성함수는 함수를 차례로 적용한다

두 함수가 있다고 합시다.

```math
f(x)=x+2, \qquad g(x)=3x
```

**합성함수** `g∘f`는 먼저 `f`를 적용하고, 그 결과를 `g`에 넣는 뜻입니다.

```math
(g\circ f)(2)=g(f(2))=g(4)=12
```

반대 순서도 확인해 봅시다.

```math
(f\circ g)(2)=f(g(2))=f(6)=8
```

`g∘f`와 `f∘g`는 보통 결과가 다릅니다. 괄호 안쪽 함수부터 계산하는 습관이 중요합니다.

## 역함수는 원래 입력으로 돌아가는 규칙

**역함수(inverse function)** 는 함수가 한 일을 거꾸로 되돌리는 함수입니다. `f(x)=2x+1`은 “2를 곱하고 1을 더하는” 규칙이므로, 되돌릴 때는 “1을 빼고 2로 나누면” 됩니다.

```math
f^{-1}(x)=\frac{x-1}{2}
```

실제로 확인해 보면 다음과 같습니다.

```math
f^{-1}(f(3))=f^{-1}(7)=\frac{7-1}{2}=3
```

역함수가 있으려면 서로 다른 두 입력이 같은 출력으로 가면 안 됩니다. 그래야 출력 하나를 보고 원래 입력을 하나로 되찾을 수 있습니다.

## 핵심 정리

- 함수는 입력 하나마다 출력 하나를 정하는 규칙입니다.
- `f(3)`은 3을 함수 f에 넣어 계산한 함수값입니다.
- `g∘f`는 f를 먼저, g를 나중에 적용합니다.
- 역함수는 원래 함수의 계산을 반대로 되돌립니다.
