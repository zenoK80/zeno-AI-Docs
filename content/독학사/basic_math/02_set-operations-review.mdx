## 복습 방법

이번 복습은 본문 내용을 실제 문제처럼 확인한다. 먼저 네 선택지 중 하나를 고른 뒤에만 정답과 해설을 연다.

<Callout type="info">
틀린 문제는 정답 번호만 외우지 않는다. 해설에서 내가 놓친 용어 또는 판단 기준을 하나 찾아 본편에 표시한다.
</Callout>

## 4지선다 문제

### 문제 1

`A = {1, 2, 3}`, `B = {3, 4}`일 때 A ∪ B는?

① `{3}`

② `{1, 2, 4}`

③ `{1, 2, 3, 4}`

④ `{1, 2}`

<Collapse title="정답 보기">

**정답: ③**

</Collapse>

<Collapse title="해설 보기">

합집합은 A 또는 B 중 적어도 한쪽에 있는 원소를 중복 없이 모은다.

- **①** 두 집합에 공통인 교집합이다.
- **②** 3을 빠뜨렸다.
- **③** 정답이다.
- **④** A에서 B를 뺀 차집합이다.

</Collapse>

### 문제 2

같은 집합에서 A ∩ B는?

① `{3}`

② `{1, 2, 3, 4}`

③ `{1, 2}`

④ `{4}`

<Collapse title="정답 보기">

**정답: ①**

</Collapse>

<Collapse title="해설 보기">

교집합은 두 집합에 모두 들어 있는 원소만 남긴다.

- **①** 정답이다.
- **②** 합집합이다.
- **③** A - B다.
- **④** B - A다.

</Collapse>

### 문제 3

A - B와 B - A에 대한 설명으로 옳은 것은?

① 항상 서로 같다.

② 항상 공집합이다.

③ 원소의 순서만 다르다.

④ 일반적으로 서로 다르므로 앞뒤 순서가 중요하다.

<Collapse title="정답 보기">

**정답: ④**

</Collapse>

<Collapse title="해설 보기">

차집합은 앞 집합에서 뒤 집합의 원소를 제외하므로 방향이 있다.

- **①** A와 B가 특별한 관계일 때만 같을 수 있다.
- **②** 서로 겹치지 않을 때 A - B는 A다.
- **③** 집합은 원소 순서를 따지지 않지만 두 연산의 결과 원소가 달라질 수 있다.
- **④** 정답이다.

</Collapse>

### 문제 4

전체집합 U에서 A의 여집합 Aᶜ를 구할 때 반드시 알아야 하는 것은?

① A 원소의 배열 순서

② 전체집합 U의 범위

③ A의 원소를 더한 값

④ A가 함수인지 여부

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

여집합은 전체집합에서 A를 제외한 부분이므로 전체 범위가 정해져야 한다.

- **①** 집합은 원소의 배열 순서를 따지지 않는다.
- **②** 정답이다.
- **③** 원소의 합과 관계없다.
- **④** 함수 여부와 관계없다.

</Collapse>

### 문제 5

드모르간 법칙에 따라 (A ∪ B)ᶜ와 같은 것은?

① Aᶜ ∪ Bᶜ

② Aᶜ ∩ Bᶜ

③ A ∩ B

④ A - B

<Collapse title="정답 보기">

**정답: ②**

</Collapse>

<Collapse title="해설 보기">

‘A 또는 B’를 전체 부정하면 ‘A가 아니고 B도 아님’이 되어 여집합들의 교집합이 된다.

- **①** 합집합을 부정할 때 연산 기호는 교집합으로 바뀐다.
- **②** 정답이다.
- **③** A와 B에 모두 속하는 부분이라 의미가 다르다.
- **④** A에만 속하는 부분이다.

</Collapse>

## 직접 적용하기

`U = {1, 2, 3, 4, 5, 6}`, `A = {1, 2, 3, 4}`, `B = {3, 4, 5}`일 때 A ∪ B, A ∩ B, A - B, Aᶜ를 차례로 구하자.

<Collapse title="풀이 보기">

`A ∪ B = {1, 2, 3, 4, 5}`, `A ∩ B = {3, 4}`, `A - B = {1, 2}`, `Aᶜ = {5, 6}`이다. 합집합은 어느 한쪽에라도 있는 원소, 교집합은 양쪽 공통, 차집합은 A에만 있는 원소, 여집합은 U에서 A를 제외한 원소를 고른다.

</Collapse>

## 결과 점검

- **5문제 모두 정답**: 본편의 핵심 구분을 이해했다. 적용 문제 풀이 과정만 다시 말해 본다.
- **3~4문제 정답**: 틀린 문제 해설의 굵은 용어를 본편에서 다시 확인한다.
- **0~2문제 정답**: 본편의 ‘먼저 알아둘 말’과 핵심 예제를 다시 읽은 뒤 재도전한다.
