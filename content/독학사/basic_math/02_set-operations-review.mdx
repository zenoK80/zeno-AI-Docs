## 02편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

전체집합과 두 집합이 다음과 같다.

```text
U = {1, 2, 3, 4, 5, 6, 7, 8}
A = {1, 2, 4, 7}
B = {2, 3, 4, 8}
```

### 문제 1

`A ∪ B`, `A ∩ B`, `A - B`, `B - A`, `Aᶜ`을 구한다.

### 문제 2

`(A ∩ B)ᶜ`과 `Aᶜ ∪ Bᶜ`을 각각 계산해 같은지 확인한다.

### 문제 3

설문 참가자 100명 중 영화 A를 본 사람은 62명, 영화 B를 본 사람은 48명, 두 영화를 모두 본 사람은 30명이다. 어느 영화도 보지 않은 사람은 몇 명인가?

## 정답과 해설

### 문제 1

```text
A ∪ B = {1, 2, 3, 4, 7, 8}
A ∩ B = {2, 4}
A - B = {1, 7}
B - A = {3, 8}
Aᶜ = {3, 5, 6, 8}
```

### 문제 2

```text
(A ∩ B)ᶜ = {1, 3, 5, 6, 7, 8}

Aᶜ = {3, 5, 6, 8}
Bᶜ = {1, 5, 6, 7}
Aᶜ ∪ Bᶜ = {1, 3, 5, 6, 7, 8}
```

두 결과가 같아 두 번째 드모르간 법칙을 확인했다.

### 문제 3

```text
적어도 한 편을 본 사람 = 62 + 48 - 30 = 80명
어느 영화도 보지 않은 사람 = 100 - 80 = 20명
```

## 흔한 실수

- 합집합의 "또는"에서 교집합을 제외한다: 수학의 `A 또는 B`는 둘 다인 경우를 포함한다.
- 차집합의 순서를 무시한다: 먼저 적힌 집합에서 뒤 집합의 원소를 뺀다.
- 전체집합 없이 여집합을 계산한다: 문제에서 U를 먼저 찾는다.
- 포함배제에서 교집합을 더한다: 두 번 센 부분을 한 번 빼야 한다.
- 드모르간 법칙에서 기호만 바꾸고 여집합을 빠뜨린다: 괄호 안 각 집합을 모두 여집합으로 바꾼다.
