## 왜 벡터를 배우나요?

물체가 움직일 때 "얼마나 빠른가"뿐 아니라 "어느 방향으로 가는가"도 중요합니다. 강바람이 북쪽으로 5m/s로 불고, 배가 동쪽으로 3m/s로 가면 실제 배의 속도는 어느 방향으로 얼마나 빠를까요? 이처럼 **크기와 방향을 함께 나타내는 도구**가 벡터입니다. 물리학, 공학, 컴퓨터 그래픽, 기계 학습, 경제학 등 현대 과학기술 전 분야에서 필수적으로 사용합니다.

## 벡터의 기본 개념

**벡터 `vector`(벡터)**는 크기와 방향을 함께 갖는 양입니다. 크기만 있는 양은 **스칼라 `scalar`(스칼라)**라 합니다.

| 구분 | 예시 |
| --- | --- |
| 스칼라 (크기만) | 온도 25℃, 질량 60kg, 시간 3시간, 가격 5000원 |
| 벡터 (크기+방향) | 속도(동쪽으로 60km/h), 힘(아래 방향으로 9.8N), 변위(북쪽으로 100m) |

벡터는 화살표로 나타냅니다. 화살표의 길이가 크기, 화살표가 가리키는 방향이 방향입니다.

**표기법:** 벡터는 $\vec{v}$ 또는 굵은 글씨 $\mathbf{v}$로 씁니다.

평면 위의 벡터는 두 성분 $(a, b)$로, 공간 벡터는 세 성분 $(a, b, c)$로 나타냅니다.

$$\vec{v} = (3, -2), \quad |\vec{v}| = \sqrt{3^2 + (-2)^2} = \sqrt{13}$$

벡터의 **크기(노름 `norm`)**: 화살표의 길이입니다. 피타고라스 정리로 계산합니다.

$$|\vec{v}| = \sqrt{a^2 + b^2} \quad \text{(2차원)}, \qquad |\vec{v}| = \sqrt{a^2 + b^2 + c^2} \quad \text{(3차원)}$$

크기가 1인 벡터를 **단위벡터 `unit vector`(단위벡터)**라 합니다. 벡터 $\vec{v}$의 단위벡터는 $\dfrac{\vec{v}}{|\vec{v}|}$입니다.

**단위벡터를 만드는 이유:** 방향 정보만 남기고 크기를 1로 통일하기 위해서입니다.

## 벡터의 연산

**덧셈과 뺄셈:** 같은 위치의 성분끼리 계산합니다.

$$\vec{a} + \vec{b} = (a_1+b_1,\; a_2+b_2), \qquad \vec{a} - \vec{b} = (a_1-b_1,\; a_2-b_2)$$

**생활 비유:** 동쪽으로 3m, 북쪽으로 4m 걸어가면 최종 위치는 $(3, 4)$입니다. 이것이 벡터 덧셈입니다.

**스칼라 곱:** 스칼라 $k$를 곱하면 모든 성분에 $k$를 곱합니다. 방향은 유지하고 크기만 바꿉니다.

$$k\vec{a} = (ka_1,\; ka_2)$$

- $k > 0$: 같은 방향으로 $k$배 확대
- $k < 0$: 반대 방향으로 크기가 $|k|$배
- $k = 0$: 영벡터(크기 0)가 됨

**예제:** $\vec{a} = (2, 3)$, $\vec{b} = (-1, 4)$일 때 $2\vec{a} - \vec{b}$를 구하시오.

$$2\vec{a} - \vec{b} = (4, 6) - (-1, 4) = (5, 2)$$

## 내적 (점곱)

**내적 `dot product`(내적, 점곱)**: 두 벡터에서 계산하는 스칼라값입니다.

두 벡터 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$의 내적은 다음과 같습니다.

$$\vec{a} \cdot \vec{b} = a_1 b_1 + a_2 b_2$$

쉽게 말하면: 같은 위치 성분끼리 곱하고 더하면 됩니다.

<Callout type="warning">
  내적의 결과는 벡터가 아닌 **스칼라(숫자)**입니다. 두 벡터를 내적하면 방향이 없는 숫자 하나가 나옵니다. 내적을 통해 각도를 구할 수 있습니다.
</Callout>

내적과 사이각 $\theta$ `theta`(세타, 두 벡터 사이의 각도)의 관계는 다음과 같습니다.

$$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$$

이를 이용하면 두 벡터의 **사이각**을 구할 수 있습니다.

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$$

**수직 조건:** $\vec{a} \perp \vec{b}$ (수직)이면 $\theta = 90°$이므로 $\cos 90° = 0$이 되어 다음이 성립합니다.

$$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$$

**생활 의미:** 내적은 "두 벡터가 얼마나 같은 방향을 가리키는가"를 나타냅니다. 완전히 같은 방향이면 내적이 최대, 수직이면 0, 반대 방향이면 음수입니다.

**예제:** $\vec{a} = (1, 2)$, $\vec{b} = (3, -1)$일 때 내적과 사이각을 구하시오.

$$\vec{a} \cdot \vec{b} = 1\cdot3 + 2\cdot(-1) = 1$$

$$|\vec{a}| = \sqrt{5}, \quad |\vec{b}| = \sqrt{10}$$

$$\cos\theta = \frac{1}{\sqrt{5}\cdot\sqrt{10}} = \frac{1}{\sqrt{50}} = \frac{1}{5\sqrt{2}}$$

## 직선의 방정식 (벡터 형태)

점 $P_0 = (x_0, y_0)$을 지나고 방향벡터 `direction vector` $\vec{d} = (a, b)$인 직선의 **매개변수 방정식 `parametric equation`**은 다음과 같습니다.

$$(x, y) = (x_0, y_0) + t(a, b) \quad (t \in \mathbb{R})$$

즉, $x = x_0 + ta$, $y = y_0 + tb$입니다.

- 매개변수 $t$: 직선 위의 각 점을 구분하는 값. $t$가 변하면 점이 직선을 따라 움직입니다.
- 방향벡터 $\vec{d}$: 직선이 어떤 방향으로 뻗어 있는지를 나타냅니다.

**두 점을 지나는 직선:** 두 점 $A$, $B$를 지나면 방향벡터를 $\overrightarrow{AB} = B - A$로 잡습니다.

## 평면의 방정식 (벡터 형태)

3차원에서 평면을 나타낼 때는 **법선벡터 `normal vector` $\vec{n}$**을 사용합니다. 법선벡터는 평면에 수직인 벡터입니다.

점 $P_0 = (x_0, y_0, z_0)$을 지나고 법선벡터 $\vec{n} = (A, B, C)$에 수직인 평면의 방정식은 다음과 같습니다.

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

또는 $Ax + By + Cz = D$ 형태로 씁니다.

**이해:** 평면 위의 임의의 점 $(x,y,z)$에서 기준점 $(x_0, y_0, z_0)$을 뺀 벡터 $(x-x_0, y-y_0, z-z_0)$는 반드시 법선벡터와 수직(내적=0)이어야 합니다.

**예제:** 점 $(1, 2, 3)$을 지나고 법선벡터 $(2, -1, 3)$인 평면의 방정식을 구하시오.

$$2(x-1) - (y-2) + 3(z-3) = 0 \implies 2x - y + 3z = 9$$

## 핵심 정리

- 벡터: 크기와 방향을 함께 갖는 양, 화살표로 표현
- 벡터 크기: $|\vec{v}| = \sqrt{a^2+b^2+c^2}$
- 내적: $\vec{a}\cdot\vec{b} = a_1b_1+a_2b_2$, 결과는 스칼라
- 수직 조건: 내적 $= 0$
- 사이각: $\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$
- 직선: 점 + 방향벡터로 매개변수 표현
- 평면: 점 + 법선벡터로 $\vec{n}\cdot(\vec{r}-\vec{r_0})=0$
