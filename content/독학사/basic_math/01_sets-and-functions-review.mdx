## 01편 복습

본문을 덮고 먼저 기억나는 내용을 떠올려 보자. 답이 바로 나오지 않아도 괜찮다. 직접 답한 뒤 해설과 비교해야 무엇을 다시 볼지 알 수 있다.

<Callout type="info">
문제를 먼저 풀고 나서 정답을 확인한다. 틀린 문제는 정답만 외우지 말고, 본문의 어떤 개념을 놓쳤는지 한 줄로 기록한다.
</Callout>

## 직접 풀어보기

### 문제 1: 집합 판별

`A = {1, {2}, 3}`일 때 다음의 참·거짓을 판단한다.

1. `2 ∈ A`
2. `{2} ∈ A`
3. `{1, 3} ⊆ A`
4. `∅ ⊆ A`

### 문제 2: 부분집합 개수

집합 `B = {a, b, c, d}`의 부분집합과 진부분집합은 각각 몇 개인가?

### 문제 3: 함수 계산

`f(x) = x² - 2x`일 때 `f(-1)`, `f(0)`, `f(3)`을 계산한다.

## 정답과 해설

### 문제 1

1. 거짓. A에는 숫자 2가 아니라 집합 `{2}`가 있다.
2. 참.
3. 참. 1과 3이 모두 A의 원소다.
4. 참. 공집합은 모든 집합의 부분집합이다.

### 문제 2

원소가 4개이므로 부분집합은 `2⁴ = 16`개다. 자기 자신을 제외한 진부분집합은 `16 - 1 = 15`개다.

### 문제 3

```text
f(-1) = (-1)² - 2(-1) = 1 + 2 = 3
f(0)  = 0² - 2(0) = 0
f(3)  = 3² - 2(3) = 9 - 6 = 3
```

서로 다른 입력 `-1`, `3`이 같은 출력 3을 갖지만 여전히 함수다.

## 흔한 실수

- `{}`와 `()`를 섞어 쓴다: 집합은 중괄호를 사용한다.
- `∈`와 `⊆`를 바꿔 쓴다: 왼쪽이 원소면 `∈`, 집합이면 `⊆`인지 먼저 본다.
- 함수는 출력도 서로 달라야 한다고 생각한다: 입력마다 출력이 하나면 된다.
- 공역과 치역을 같다고 생각한다: 실제로 사용되지 않은 공역 원소가 있을 수 있다.
