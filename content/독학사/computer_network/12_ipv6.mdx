## IPv4의 한계와 IPv6 등장 배경

IPv4는 32비트 주소로 최대 약 43억 개의 주소를 제공하지만, 인터넷 폭발적 성장으로 주소 공간이 고갈되었습니다. IPv6는 이를 해결하기 위해 개발되었습니다.

| 특성 | IPv4 | IPv6 |
|------|------|------|
| 주소 길이 | 32비트 | 128비트 |
| 주소 수 | 약 43억 개 | 약 3.4 × 10의 38제곱 개 |
| 표기법 | 점-십진수 (192.168.1.1) | 콜론-16진수 (2001:db8::1) |
| 헤더 크기 | 가변 (20바이트~) | 고정 (40바이트) |
| 체크섬 | 있음 | 없음 (상위 계층에 위임) |
| ARP | 사용 | NDP로 대체 |
| IPSec | 선택적 | 내장 (기본 지원) |

## IPv6 주소 표기법

IPv6 주소는 128비트를 16비트씩 8개 그룹으로 나누어 콜론으로 구분하는 16진수로 표기합니다.

`2001:0db8:0000:0000:0000:0000:0000:0001`

### 단축 표기 규칙

1. **선행 0 생략:** `0db8` → `db8`
2. **연속된 0 그룹을 `::`으로 대체 (한 번만 사용 가능):** `0000:0000:0000` → `::`

단축 결과: `2001:db8::1`

## IPv6 주소 유형

| 유형 | 설명 | 접두사 |
|------|------|--------|
| **유니캐스트** | 단일 인터페이스를 식별 | — |
| - 글로벌 유니캐스트 | 인터넷에서 라우팅 가능한 공인 주소 | 2000::/3 |
| - 링크 로컬 | 동일 링크(서브넷) 내에서만 유효 | FE80::/10 |
| - 루프백 | 자기 자신을 가리킴 | ::1/128 |
| **멀티캐스트** | 여러 인터페이스 그룹에 전달 | FF00::/8 |
| **애니캐스트** | 가장 가까운 인터페이스 하나에 전달 | (유니캐스트 주소 공간 공유) |

<Callout type="warning">
  IPv6에는 **브로드캐스트가 없습니다**. 브로드캐스트 기능은 멀티캐스트로 대체됩니다.
</Callout>

## ICMPv6

**ICMPv6(Internet Control Message Protocol version 6)**는 IPv6 환경에서의 오류 보고와 진단을 담당합니다. IPv4의 ICMP, ARP, IGMP 기능을 통합합니다.

ICMPv6의 주요 기능:
- 오류 보고 (Destination Unreachable, Time Exceeded 등)
- 에코 요청/응답 (ping)
- **NDP(Neighbor Discovery Protocol)** 지원

## NDP (Neighbor Discovery Protocol)

**NDP**는 IPv6에서 IPv4의 ARP를 대체하는 프로토콜입니다. ICMPv6 메시지를 이용합니다.

| 기능 | IPv4 | IPv6 |
|------|------|------|
| 주소 해석 (IP→MAC) | ARP | NDP (NS/NA) |
| 라우터 탐색 | ICMP Router Discovery | NDP (RS/RA) |
| 주소 자동 설정 | DHCP | NDP + SLAAC |

**NS(Neighbor Solicitation):** ARP 요청에 해당, 목표 IP의 MAC 주소를 요청  
**NA(Neighbor Advertisement):** ARP 응답에 해당, MAC 주소 전달  
**SLAAC(Stateless Address Autoconfiguration):** DHCP 없이 라우터 공고(RA)를 통해 IPv6 주소를 자동 설정

## 핵심 정리

- IPv6: 128비트 주소, 약 3.4 × 10의 38제곱 개 주소
- 표기: 16진수 콜론 구분, 선행 0 생략, `::`으로 연속 0 그룹 단축
- 유형: 유니캐스트(글로벌·링크로컬·루프백::1), 멀티캐스트(FF00::/8), 애니캐스트
- 브로드캐스트 없음 → 멀티캐스트로 대체
- NDP: ICMPv6 기반, ARP 대체, SLAAC 지원
