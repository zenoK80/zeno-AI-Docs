## OSI 참조 모델이란?

**OSI(Open Systems Interconnection) 참조 모델**은 ISO(국제표준화기구)가 1984년 제정한 네트워크 통신의 표준 참조 모델입니다. 서로 다른 벤더의 시스템 간 통신을 가능하게 하기 위해 통신 기능을 7개 계층으로 나눕니다.

## 7개 계층 요약

| 계층 | 이름 | PDU | 주요 프로토콜/장비 |
|------|------|-----|-------------------|
| 7 | 응용 계층 (Application) | 메시지(Message) | HTTP, FTP, SMTP, DNS |
| 6 | 표현 계층 (Presentation) | 메시지(Message) | SSL/TLS, JPEG, ASCII |
| 5 | 세션 계층 (Session) | 메시지(Message) | NetBIOS, RPC |
| 4 | 전송 계층 (Transport) | 세그먼트(Segment) | TCP, UDP |
| 3 | 네트워크 계층 (Network) | 패킷(Packet) | IP, ICMP, ARP, 라우터 |
| 2 | 데이터 링크 계층 (Data Link) | 프레임(Frame) | 이더넷, PPP, 스위치, 브리지 |
| 1 | 물리 계층 (Physical) | 비트(Bit) | 허브, 리피터, 케이블 |

<Callout type="warning">
  계층 번호는 하위에서 상위 방향(1→7)으로 셉니다. "최하위 계층"은 물리 계층(1계층)입니다.
</Callout>

## 각 계층 상세 설명

### 1계층 — 물리 계층

비트(0과 1)를 전기 신호, 광 신호, 전파로 변환하여 전송합니다. 케이블, 커넥터, 허브, 리피터가 이 계층에 속합니다.

### 2계층 — 데이터 링크 계층

같은 네트워크 내 두 노드 간 신뢰성 있는 전송을 담당합니다. MAC 주소를 사용하여 프레임을 전달하고, 오류 검출(CRC) 및 흐름 제어를 수행합니다. 스위치와 브리지가 이 계층 장비입니다.

### 3계층 — 네트워크 계층

서로 다른 네트워크 간 패킷 전달(라우팅)을 담당합니다. IP 주소를 사용하여 최적 경로를 선택합니다. 라우터가 이 계층 장비이며, IP·ICMP·ARP 프로토콜이 대표적입니다.

### 4계층 — 전송 계층

종단 간(End-to-End) 신뢰성 있는 데이터 전달을 담당합니다. 포트 번호로 프로세스를 식별하고, 분할과 재조합을 수행합니다. TCP(신뢰성)와 UDP(빠른 전송)가 대표 프로토콜입니다.

### 5계층 — 세션 계층

통신 세션의 설정·유지·종료를 관리합니다. 대화 제어와 동기화를 담당합니다.

### 6계층 — 표현 계층

데이터의 형식 변환, 암호화/복호화, 압축을 담당합니다. JPEG, MPEG, ASCII 변환, SSL/TLS가 관련됩니다.

### 7계층 — 응용 계층

사용자와 직접 상호작용하는 계층으로, 네트워크 서비스를 제공합니다. HTTP, FTP, SMTP, DNS 등이 속합니다.

## 캡슐화와 역캡슐화

데이터를 전송할 때 각 계층은 자신의 헤더를 추가합니다(캡슐화). 수신 측에서는 반대로 헤더를 제거합니다(역캡슐화).

```
[응용 데이터]
[TCP 헤더 | 응용 데이터]            세그먼트 (4계층)
[IP 헤더 | TCP 헤더 | 데이터]       패킷 (3계층)
[이더넷 헤더 | IP ... | FCS]        프레임 (2계층)
0101100101...                       비트 (1계층)
```

## 핵심 정리

- OSI 7계층: 물리(1) → 데이터링크(2) → 네트워크(3) → 전송(4) → 세션(5) → 표현(6) → 응용(7)
- PDU: 비트(1) → 프레임(2) → 패킷(3) → 세그먼트(4) → 메시지(5~7)
- 장비: 허브·리피터(1계층), 스위치·브리지(2계층), 라우터(3계층)
