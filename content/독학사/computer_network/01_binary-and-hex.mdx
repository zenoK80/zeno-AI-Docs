  **이번 문서의 목표:** 이 파일을 다 읽으면 IP 주소(예: 192.168.0.1)와 MAC 주소(예: 00:1A:2B:3C:4D:5E)가 왜 그렇게 표기되는지 진법 변환으로 설명할 수 있습니다.
</Callout>

## 왜 네트워크에서 진법 변환이 필요한가?

컴퓨터는 내부적으로 모든 데이터를 0과 1(이진수)로만 다룹니다. 하지만 IP 주소나 MAC 주소를 이진수로 그대로 쓰면 사람이 읽고 기억하기 매우 어렵습니다(예: `11000000101010000000000000000001`). 그래서 네트워크에서는 이 긴 이진수를 사람이 다루기 쉬운 **10진수**나 **16진수**로 축약해서 표기합니다.

## 이진수(Binary)와 8비트 옥텟(Octet)

> **쉽게 말하면:** 옥텟은 "8개의 비트(0 또는 1) 묶음"을 가리키는 단위이며, IP 주소는 이 옥텟 4개로 구성됩니다.

**단어 풀이:**

| 단어 | 뜻 |
|------|-----|
| Octet | 라틴어로 "8개"를 뜻하는 접두사 oct-에서 유래. 8비트 묶음 |
| Bit | Binary digit(이진 숫자)의 줄임말. 0 또는 1 하나 |

**계산 예시**(이진수 → 10진수): 옥텟 `11000000`을 10진수로 변환합니다.

$$
11000000_{(2)} = 1\times2^7+1\times2^6+0+0+0+0+0+0 = 128+64 = 192
$$

**해석:** 8비트 옥텟 하나는 $2^8=256$가지($0\sim255$) 값을 표현할 수 있습니다. 이것이 IP 주소의 각 자리가 항상 0~255 사이의 숫자로만 나타나는 이유입니다.

## IP 주소의 구조 — 옥텟 4개

> **쉽게 말하면:** IPv4 주소는 32비트(0/1) 전체를 8비트씩 4묶음(옥텟)으로 나누고, 각 묶음을 10진수로 바꿔 마침표로 구분해 표기한 것입니다.

**계산 예시:** 이진수 `11000000.10101000.00000000.00000001`을 10진수 IP 주소로 변환합니다.

<Table>
  <thead>
    <tr><th>옥텟</th><th>이진수</th><th>10진수 변환</th></tr>
  </thead>
  <tbody>
    <tr><td>1번째</td><td>11000000</td><td>128+64=192</td></tr>
    <tr><td>2번째</td><td>10101000</td><td>128+32+8=168</td></tr>
    <tr><td>3번째</td><td>00000000</td><td>0</td></tr>
    <tr><td>4번째</td><td>00000001</td><td>1</td></tr>
  </tbody>
</Table>

**결과:** `192.168.0.1` — 가정에서 흔히 보는 공유기 기본 주소가 바로 이렇게 만들어진 표기입니다.

## 16진수(Hexadecimal)와 MAC 주소

> **쉽게 말하면:** 16진수는 0~9 다음에 A, B, C, D, E, F(각각 10~15를 나타냄)를 이어서 쓰는, 16개의 숫자·문자를 사용하는 진법입니다.

<Table>
  <thead>
    <tr><th>10진수</th><th>16진수</th></tr>
  </thead>
  <tbody>
    <tr><td>10</td><td>A</td></tr>
    <tr><td>11</td><td>B</td></tr>
    <tr><td>15</td><td>F</td></tr>
    <tr><td>16</td><td>10</td></tr>
  </tbody>
</Table>

<Callout type="info">
  **왜 MAC 주소는 16진수로 표기하는가?** 16진수 한 자리는 정확히 4비트를 표현합니다($2^4=16$). 따라서 8비트(1바이트)는 16진수 딱 2자리로 깔끔하게 표현되어, 이진수보다 훨씬 짧고 옥텟 경계와도 잘 맞아떨어집니다. MAC 주소(48비트)는 이 방식으로 16진수 12자리(6바이트)를 콜론이나 하이픈으로 구분해 표기합니다(예: `00:1A:2B:3C:4D:5E`).
</Callout>

**계산 예시**(이진수 → 16진수): 1바이트 `00011010`을 16진수로 변환합니다.

<Steps>
### 1단계: 4비트씩 나누기
`0001` `1010`

### 2단계: 각 4비트를 16진수 한 자리로 변환
`0001`=1, `1010`=10=A

### 3단계: 결과 결합
`0001 1010` → `1A`
</Steps>

<Callout type="warning">
  **자주 틀리는 점:** IP 주소는 8비트씩(옥텟) **10진수**로, MAC 주소는 4비트씩 **16진수**로 표기한다는 관례를 혼동하기 쉽습니다. 이는 규칙이 아니라 "사람이 읽기 편한 관례"일 뿐이며, 둘 다 결국 내부적으로는 이진수 데이터입니다.
</Callout>

## 핵심 정리

- 컴퓨터 내부는 항상 **이진수**로 동작하지만, 사람이 읽기 쉽도록 **10진수**(IP 주소)나 **16진수**(MAC 주소)로 축약해 표기한다.
- **옥텟**: 8비트 묶음. IP 주소는 옥텟 4개(32비트)로 구성되며 각 옥텟은 0~255 값을 가짐.
- 16진수 한 자리는 정확히 4비트를 표현하므로, 8비트(1바이트)는 16진수 2자리로 깔끔하게 대응된다.
- MAC 주소(48비트)는 16진수 12자리(6바이트)로 표기된다.
