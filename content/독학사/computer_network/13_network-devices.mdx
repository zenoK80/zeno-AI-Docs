## OSI 계층별 네트워크 장비

| OSI 계층 | 주소 기반 | 대표 장비 |
|----------|---------|---------|
| 1계층 (물리) | — | 허브(Hub), 리피터(Repeater), 케이블 |
| 2계층 (데이터 링크) | MAC 주소 | 스위치(Switch), 브리지(Bridge) |
| 3계층 (네트워크) | IP 주소 | 라우터(Router) |
| 7계층 (응용) | 프로토콜 변환 | 게이트웨이(Gateway) |

## 허브 (Hub) — 1계층

**허브**는 연결된 모든 포트로 데이터를 전달하는 단순 중계 장치입니다.

- 수신한 신호를 증폭하여 모든 포트로 브로드캐스트
- 동일한 콜리전 도메인(Collision Domain)을 공유
- 대역폭을 모든 포트가 공유 → 포트 수 증가 시 성능 저하
- 현재는 스위치로 대체됨

## 리피터 (Repeater) — 1계층

**리피터**는 감쇠된 신호를 증폭하여 재전송하는 장치입니다. 신호 전달 거리를 늘리기 위해 사용합니다.

## 스위치 (Switch) — 2계층

**스위치**는 MAC 주소를 학습하여 해당 포트로만 데이터를 전달하는 장치입니다.

- **MAC 주소 테이블(CAM 테이블):** 포트별 MAC 주소를 학습하여 저장
- 목적지 MAC 주소가 테이블에 없으면 모든 포트로 플러딩(Flooding)
- 포트별 독립된 콜리전 도메인 → 허브보다 효율적
- VLAN(Virtual LAN): 하나의 스위치를 논리적으로 여러 네트워크로 분리

### 스위치 vs 허브 비교

| 특성 | 허브 | 스위치 |
|------|------|--------|
| 동작 계층 | 1계층 | 2계층 |
| 주소 학습 | 없음 | MAC 주소 학습 |
| 데이터 전달 | 모든 포트로 | 목적지 포트로만 |
| 콜리전 도메인 | 하나 공유 | 포트별 독립 |
| 성능 | 낮음 | 높음 |

## 라우터 (Router) — 3계층

**라우터**는 IP 주소를 기반으로 서로 다른 네트워크 간 패킷을 전달(라우팅)하는 장치입니다.

- 라우팅 테이블을 참조하여 최적 경로 선택
- 브로드캐스트 도메인을 분리 (스위치는 분리하지 않음)
- 서로 다른 네트워크(서브넷) 간의 통신 가능
- NAT(Network Address Translation): 사설 IP → 공인 IP 변환

## 브리지 (Bridge) — 2계층

**브리지**는 두 개의 네트워크 세그먼트를 연결하는 2계층 장치입니다. 스위치는 멀티포트 브리지로 볼 수 있습니다.

## 게이트웨이 (Gateway) — 7계층

**게이트웨이**는 서로 다른 프로토콜 또는 네트워크 아키텍처 사이에서 변환하는 장치입니다.

- 모든 OSI 계층에서 동작 가능
- 예: IP 네트워크와 IPX 네트워크, 이메일 게이트웨이

## L3 스위치

**L3 스위치**는 스위칭(2계층)과 라우팅(3계층) 기능을 통합한 장치입니다. 데이터센터나 기업 네트워크의 백본 장비로 사용됩니다.

## 핵심 정리

- 허브: 1계층, 모든 포트로 브로드캐스트, 콜리전 도메인 공유
- 스위치: 2계층, MAC 주소 학습, 목적지 포트로만 전달
- 라우터: 3계층, IP 주소 기반 라우팅, 브로드캐스트 도메인 분리
- 게이트웨이: 전 계층, 서로 다른 프로토콜·아키텍처 변환
- 브리지: 2계층, 두 세그먼트 연결 (스위치의 전신)
