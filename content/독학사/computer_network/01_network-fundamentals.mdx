## 컴퓨터 네트워크란?

**컴퓨터 네트워크**는 둘 이상의 컴퓨터(또는 장치)가 데이터를 주고받을 수 있도록 연결된 시스템입니다. 네트워크는 자원 공유, 통신, 정보 검색을 가능하게 합니다.

### 네트워크 성능 평가 기준

| 지표 | 설명 |
|------|------|
| **대역폭(Bandwidth)** | 단위 시간당 전송 가능한 데이터 양 (bps) |
| **지연(Delay/Latency)** | 데이터가 출발지에서 목적지까지 도달하는 시간 |
| **처리율(Throughput)** | 실제로 전송된 데이터 양 (대역폭 이하) |
| **신뢰성(Reliability)** | 오류 없이 데이터를 전달하는 능력 |
| **보안(Security)** | 무단 접근으로부터 데이터를 보호하는 능력 |

## 네트워크 구성요소

네트워크는 다음 핵심 요소로 구성됩니다.

- **메시지(Message):** 전달하려는 정보 자체
- **송신자(Sender):** 메시지를 보내는 장치
- **수신자(Receiver):** 메시지를 받는 장치
- **전송 매체(Transmission Medium):** 메시지가 이동하는 물리적 경로 (유선·무선)
- **프로토콜(Protocol):** 통신 규칙의 집합

## 네트워크 분류

### 거리에 따른 분류

| 유형 | 영문 | 범위 |
|------|------|------|
| **PAN** | Personal Area Network | 개인 주변 (수 미터, Bluetooth) |
| **LAN** | Local Area Network | 건물·캠퍼스 내 (수 km) |
| **MAN** | Metropolitan Area Network | 도시 규모 (수십 km) |
| **WAN** | Wide Area Network | 국가·대륙 이상 |

### 교환 방식에 따른 분류

**회선 교환(Circuit Switching):** 통신 전에 전용 회선을 미리 설정하고, 통신 내내 독점 사용한다. 전화망이 대표적이다. 전송 지연이 일정하지만, 회선 이용률이 낮다는 단점이 있다.

**패킷 교환(Packet Switching):** 데이터를 일정 크기의 패킷으로 분할하여 각각 독립적으로 전송한다. 인터넷이 대표적이다. 회선을 공유하므로 이용률이 높지만 큐잉 지연이 발생할 수 있다.

**가상 회선(Virtual Circuit):** 패킷 교환의 일종으로, 논리적 전용 경로를 미리 설정하고 모든 패킷이 같은 경로를 따른다. ATM이 대표적이다.

## 네트워크 토폴로지

**토폴로지(Topology)**는 네트워크를 구성하는 장치들의 물리적·논리적 배치 구조입니다.

| 토폴로지 | 특징 | 장점 | 단점 |
|----------|------|------|------|
| **버스형(Bus)** | 모든 노드가 하나의 공유 선로에 연결 | 설치 비용 낮음 | 회선 장애 시 전체 마비 |
| **성형(Star)** | 모든 노드가 중앙 허브/스위치에 연결 | 관리 용이, 장애 격리 | 중앙 장치 고장 시 전체 중단 |
| **링형(Ring)** | 노드들이 원형으로 연결 | 일정한 전송 속도 | 한 노드 고장 시 전체 영향 |
| **메시형(Mesh)** | 모든 노드 간 직접 연결 | 높은 신뢰성 | 구축 비용 매우 높음 |
| **계층형(Tree)** | 버스형과 성형의 혼합 | 확장 용이 | 상위 노드 고장 시 하위 영향 |

## 데이터 흐름 방향

| 방식 | 설명 | 예시 |
|------|------|------|
| **단방향(Simplex)** | 한 방향으로만 전송 | TV 방송 |
| **반이중(Half-Duplex)** | 양방향이지만 동시 불가 | 무전기 |
| **전이중(Full-Duplex)** | 동시에 양방향 전송 가능 | 전화, 이더넷 |

## 핵심 정리

- 네트워크 성능: 대역폭·지연·처리율·신뢰성·보안
- 거리 기준 분류: PAN → LAN → MAN → WAN
- 교환 방식: 회선 교환(전용 경로) vs 패킷 교환(공유 경로)
- 버스형(공유 선로), 성형(중앙 허브), 링형(원형), 메시형(전 노드 연결)
- 데이터 흐름: 단방향 / 반이중 / 전이중
