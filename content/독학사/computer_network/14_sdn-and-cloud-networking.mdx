## SDN (Software-Defined Networking)

**SDN**(소프트웨어 정의 네트워킹)은 네트워크의 제어 평면(Control Plane)과 데이터 평면(Data Plane)을 분리하여 소프트웨어로 네트워크를 중앙에서 제어하는 패러다임입니다.

### 전통적 네트워크 vs SDN

| 특성 | 전통적 네트워크 | SDN |
|------|--------------|-----|
| 제어 위치 | 각 장비 분산 | 중앙 집중(SDN 컨트롤러) |
| 제어 평면 | 하드웨어 내장 | 분리·소프트웨어화 |
| 유연성 | 낮음 | 높음 |
| 프로그래밍 가능성 | 제한적 | 높음 |
| 장비 변경 | 벤더 의존적 | 개방적 |

### SDN 3계층 구조

1. **인프라 계층(Data Plane):** 실제 패킷 전달을 수행하는 스위치, 라우터 (Forwarding Device)
2. **제어 계층(Control Plane):** SDN 컨트롤러, 네트워크 전체를 보는 중앙 지능
3. **응용 계층(Application Plane):** 네트워크 서비스·정책 앱 (로드밸런싱, 보안 등)

### OpenFlow

**OpenFlow**는 SDN 컨트롤러와 네트워크 장비 간 통신을 위한 대표적인 인터페이스 프로토콜입니다. 컨트롤러가 스위치의 플로우 테이블을 원격으로 관리합니다.

## NFV (Network Functions Virtualization)

**NFV**는 방화벽, 로드밸런서, IDS/IPS 등 네트워크 기능을 전용 하드웨어 대신 일반 서버의 소프트웨어로 구현하는 기술입니다.

| 비교 | 전통적 방식 | NFV |
|------|-----------|-----|
| 구현 방식 | 전용 하드웨어 어플라이언스 | 가상 머신/컨테이너 기반 소프트웨어 |
| 비용 | 높음 | 낮음 |
| 확장성 | 어려움 | 쉬움 |
| 유연성 | 낮음 | 높음 |

## 클라우드 네트워킹

### 주요 개념

**VPC(Virtual Private Cloud):** 클라우드 내 격리된 사설 네트워크 환경입니다. AWS, Azure, GCP 등에서 제공합니다.

**오버레이 네트워크(Overlay Network):** 기존 물리 네트워크 위에 논리적인 가상 네트워크를 구성합니다. VXLAN이 대표적입니다.

**VXLAN(Virtual Extensible LAN):** 이더넷 프레임을 UDP 패킷으로 캡슐화하여 데이터센터 간 L2 네트워크를 확장합니다.

### 클라우드 서비스 모델과 네트워크

| 모델 | 설명 | 네트워크 관리 |
|------|------|-------------|
| IaaS | 인프라 제공 (VM, 스토리지) | 사용자가 일부 관리 |
| PaaS | 플랫폼 제공 (미들웨어, DB) | 클라우드 제공자 관리 |
| SaaS | 소프트웨어 제공 (이메일, 오피스) | 클라우드 제공자 전담 |

### CDN (Content Delivery Network)

**CDN**은 콘텐츠를 사용자와 지리적으로 가까운 서버(엣지 서버)에 캐싱하여 빠른 콘텐츠 전달을 가능하게 합니다.

- 정적 콘텐츠(이미지, 동영상, JS 파일) 빠른 전달
- 오리진 서버 부하 감소
- 전 세계 분산 엣지 서버 네트워크

## 핵심 정리

- SDN: 제어 평면과 데이터 평면 분리, 중앙 집중 제어, OpenFlow 프로토콜
- NFV: 네트워크 기능을 소프트웨어로 구현, 전용 하드웨어 대체
- VPC: 클라우드 내 격리된 사설 네트워크
- VXLAN: 이더넷 프레임을 UDP로 캡슐화, 오버레이 네트워크
- CDN: 엣지 서버 캐싱으로 콘텐츠 빠른 전달
