## TCP/IP 모델이란?

**TCP/IP 모델**은 인터넷에서 실제로 사용되는 프로토콜 스택입니다. ARPANET 연구에서 발전하여 현재 인터넷의 근간을 이룹니다. OSI 7계층 모델이 이론적 참조 모델인 반면, TCP/IP는 실제 구현된 모델입니다.

## OSI 7계층 vs TCP/IP 4계층 대응

| TCP/IP 계층 | OSI 계층 대응 | 주요 프로토콜 |
|------------|--------------|--------------|
| **응용 계층** | 응용(7) + 표현(6) + 세션(5) | HTTP, FTP, SMTP, DNS, DHCP |
| **전송 계층** | 전송(4) | TCP, UDP |
| **인터넷 계층** | 네트워크(3) | IP, ICMP, ARP, IGMP |
| **네트워크 액세스 계층** | 데이터링크(2) + 물리(1) | 이더넷, Wi-Fi, PPP |

## IP 헤더 주요 필드

| 필드 | 크기 | 설명 |
|------|------|------|
| Version | 4비트 | IP 버전 (IPv4=4, IPv6=6) |
| Header Length | 4비트 | 헤더 길이 (4바이트 단위) |
| TTL | 8비트 | 패킷 수명, 라우터를 거칠 때마다 1 감소 |
| Protocol | 8비트 | 상위 프로토콜 (TCP=6, UDP=17, ICMP=1) |
| Source IP | 32비트 | 출발지 IP 주소 |
| Destination IP | 32비트 | 목적지 IP 주소 |

## TCP 헤더 주요 필드

| 필드 | 크기 | 설명 |
|------|------|------|
| Source Port | 16비트 | 출발지 포트 번호 |
| Destination Port | 16비트 | 목적지 포트 번호 |
| Sequence Number | 32비트 | 데이터 순서 번호 |
| Acknowledgment Number | 32비트 | 수신 확인 번호 |
| Flags | 6비트 | SYN, ACK, FIN, RST, PSH, URG |
| Window Size | 16비트 | 수신 버퍼 크기 (흐름 제어) |
| Checksum | 16비트 | 오류 검출 |

## 잘 알려진 포트 번호

| 포트 | 프로토콜 | 용도 |
|------|---------|------|
| 20, 21 | FTP | 파일 전송 (데이터: 20, 제어: 21) |
| 22 | SSH | 보안 원격 접속 |
| 23 | Telnet | 원격 접속 (비암호화) |
| 25 | SMTP | 이메일 전송 |
| 53 | DNS | 도메인 이름 해석 |
| 67/68 | DHCP | IP 주소 자동 할당 |
| 80 | HTTP | 웹 통신 |
| 110 | POP3 | 이메일 수신 |
| 443 | HTTPS | 암호화 웹 통신 |

## 핵심 정리

- TCP/IP 4계층: 네트워크 액세스 → 인터넷 → 전송 → 응용
- 인터넷 계층 핵심: IP, ICMP, ARP, IGMP
- TCP 헤더: 포트·순서번호·ACK 번호·플래그·윈도우 크기
- 주요 포트: HTTP=80, HTTPS=443, FTP=21, SMTP=25, DNS=53, SSH=22
