## HTTP (HyperText Transfer Protocol)

**HTTP**는 웹 브라우저와 웹 서버 간에 HTML 문서를 주고받는 프로토콜입니다.

- 포트: 80 (HTTP), 443 (HTTPS)
- **비연결성:** 요청-응답 후 연결 종료 (HTTP/1.0 기본)
- **무상태성:** 서버가 클라이언트 상태를 기억하지 않음

### HTTP 메서드

| 메서드 | 설명 |
|--------|------|
| GET | 리소스 조회 |
| POST | 데이터 전송 (리소스 생성) |
| PUT | 리소스 전체 업데이트 |
| DELETE | 리소스 삭제 |
| HEAD | 헤더만 조회 |

### HTTP 상태 코드

| 범위 | 의미 | 예시 |
|------|------|------|
| 2xx | 성공 | 200 OK, 201 Created |
| 3xx | 리다이렉션 | 301 Moved Permanently |
| 4xx | 클라이언트 오류 | 404 Not Found, 403 Forbidden |
| 5xx | 서버 오류 | 500 Internal Server Error |

## DNS (Domain Name System)

**DNS**는 도메인 이름(www.example.com)을 IP 주소(93.184.216.34)로 변환하는 분산 데이터베이스 시스템입니다.

- 포트: 53 (UDP 주로 사용, 큰 응답 시 TCP)
- **계층적 구조:** 루트 → TLD(.com, .kr) → 권한 있는 DNS 서버

### DNS 조회 과정

1. 브라우저가 로컬 캐시 확인
2. 로컬 DNS 서버(Resolver)에 쿼리
3. 루트 DNS 서버 → TLD 서버 → 권한 있는 서버 순으로 반복 쿼리
4. IP 주소 반환 및 캐싱

## SMTP와 이메일 프로토콜

| 프로토콜 | 포트 | 역할 |
|---------|------|------|
| SMTP | 25 | 이메일 전송 (발신) |
| POP3 | 110 | 이메일 수신 (다운로드, 서버에서 삭제) |
| IMAP | 143 | 이메일 수신 (서버 유지, 동기화) |

**SMTP**: 이메일을 발신 서버에서 수신 서버로 전달하는 프로토콜입니다. 클라이언트가 이메일을 보낼 때도 SMTP를 사용합니다.

## FTP (File Transfer Protocol)

**FTP**는 파일을 업로드/다운로드하는 프로토콜입니다.

- 포트: **21** (제어), **20** (데이터)
- **능동 모드(Active Mode):** 서버가 클라이언트에 데이터 연결 시작
- **수동 모드(Passive Mode):** 클라이언트가 서버에 데이터 연결 시작 (방화벽 통과에 유리)

## DHCP (Dynamic Host Configuration Protocol)

**DHCP**는 네트워크에 연결된 장치에 IP 주소를 자동으로 할당하는 프로토콜입니다.

- 포트: 서버 67, 클라이언트 68 (UDP)

### DHCP 동작 순서 (DORA)

1. **Discover:** 클라이언트가 DHCP 서버를 찾는 브로드캐스트 전송
2. **Offer:** DHCP 서버가 IP 주소를 제안
3. **Request:** 클라이언트가 제안을 수락
4. **Acknowledge:** DHCP 서버가 할당을 확인

## 핵심 정리

- HTTP: 웹 통신, 포트 80/443, 비연결·무상태
- DNS: 도메인→IP 변환, 포트 53, 계층적 구조
- SMTP/POP3/IMAP: 이메일 전송(25)/수신 다운로드(110)/수신 동기화(143)
- FTP: 파일 전송, 제어(21)+데이터(20)
- DHCP: IP 자동 할당, DORA 4단계
