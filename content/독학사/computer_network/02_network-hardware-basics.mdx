  **이번 문서의 목표:** 네트워크를 구성하는 기본 장비(NIC, 케이블, 허브, 스위치, 라우터)의 역할과 차이를 설명할 수 있게 됩니다.
</Callout>

## 왜 네트워크 장비를 먼저 알아야 하는가?

앞으로 배울 OSI 7계층, IP 주소, 라우팅 같은 개념들은 모두 "실제로 데이터를 주고받는 물리적인 장비" 위에서 동작합니다. 이 문서에서는 본격적인 이론에 들어가기 전에, 그 이론이 어떤 하드웨어를 대상으로 하는지 먼저 익힙니다.

## NIC(Network Interface Card, 네트워크 인터페이스 카드)

**단어 풀이:**

| 단어 | 뜻 |
|------|-----|
| Network | 네트워크(연결망) |
| Interface | 두 시스템이 만나 정보를 주고받는 접점 |
| Card | 컴퓨터에 장착하는 부품 |

> **쉽게 말하면:** NIC는 컴퓨터를 네트워크에 연결해주는 "출입구" 역할을 하는 부품입니다. 흔히 랜카드라고도 부릅니다.

<Callout type="info">
  **01번 문서와의 연결:** 모든 NIC는 제조 시점에 전 세계에서 유일한 48비트 **MAC 주소**가 부여됩니다. 01번 문서에서 배운 16진수 12자리 표기(예: `00:1A:2B:3C:4D:5E`)가 바로 이 NIC에 새겨진 고유 주소입니다.
</Callout>

## 전송 매체(케이블)

> **쉽게 말하면:** 전송 매체는 데이터(전기 신호 또는 빛)가 실제로 이동하는 "통로"입니다.

<Table>
  <thead>
    <tr><th>종류</th><th>특징</th></tr>
  </thead>
  <tbody>
    <tr><td>UTP 케이블(Unshielded Twisted Pair, 비차폐 연선)</td><td>구리선 여러 가닥을 꼬아 만든 케이블. 가정·사무실에서 흔히 쓰이는 랜선(예: Cat.5e, Cat.6)</td></tr>
    <tr><td>광섬유(Optical Fiber)</td><td>빛의 신호로 데이터를 전송. UTP보다 훨씬 빠르고 장거리 전송·잡음 저항성이 뛰어남</td></tr>
    <tr><td>무선(Wireless)</td><td>전파를 이용해 케이블 없이 데이터를 전송(Wi-Fi 등)</td></tr>
  </tbody>
</Table>

## 허브(Hub) — 가장 단순한 연결 장비

> **쉽게 말하면:** 허브는 여러 대의 컴퓨터를 케이블로 연결해주는 "다리 역할 콘센트"와 같습니다. 한 포트로 들어온 신호를 연결된 **모든** 다른 포트로 그대로 흘려보냅니다.

<Callout type="warning">
  **허브의 한계:** 허브는 신호를 받으면 목적지를 구분하지 않고 모든 포트로 그대로 뿌립니다(무차별 전달, broadcast). 이 때문에 연결된 장치가 많아질수록 불필요한 신호 충돌(트래픽 낭비)이 크게 늘어나, 현대 네트워크에서는 거의 사용되지 않습니다.
</Callout>

## 스위치(Switch) — 똑똑해진 허브

> **쉽게 말하면:** 스위치는 허브와 달리 각 포트에 연결된 장치의 MAC 주소를 기억해두고, 데이터가 들어오면 **정확히 그 목적지 포트로만** 전달하는 똑똑한 장비입니다.

<Table>
  <thead>
    <tr><th>구분</th><th>허브</th><th>스위치</th></tr>
  </thead>
  <tbody>
    <tr><td>전달 방식</td><td>모든 포트로 무차별 전달</td><td>목적지 MAC 주소를 확인해 해당 포트로만 전달</td></tr>
    <tr><td>충돌 발생</td><td>많음</td><td>거의 없음(포트별로 독립적인 통신 경로 확보)</td></tr>
    <tr><td>동작 계층</td><td>물리 계층</td><td>데이터 링크 계층(MAC 주소 사용)</td></tr>
  </tbody>
</Table>

<Callout type="info">
  **08번 문서와의 연결:** 스위치가 "정확히 그 목적지 포트로만" 데이터를 보낼 수 있는 이유는, 각 프레임에 담긴 목적지 **MAC 주소**를 읽고 자신이 미리 학습해둔 "MAC 주소-포트" 표(MAC 주소 테이블)와 비교하기 때문입니다. 이 동작 원리는 08번 문서(LAN과 이더넷)에서 더 자세히 다룹니다.
</Callout>

## 라우터(Router) — 서로 다른 네트워크를 연결

> **쉽게 말하면:** 라우터는 스위치가 "한 네트워크 안"에서 데이터를 나눠주는 장비라면, "서로 다른 네트워크"(예: 우리 집 네트워크와 인터넷 전체)를 연결하고 최적의 경로를 찾아 데이터를 전달하는 장비입니다.

<Table>
  <thead>
    <tr><th>장비</th><th>동작 범위</th><th>사용하는 주소</th></tr>
  </thead>
  <tbody>
    <tr><td>스위치</td><td>같은 네트워크(LAN) 내부</td><td>MAC 주소</td></tr>
    <tr><td>라우터</td><td>서로 다른 네트워크 사이</td><td>IP 주소</td></tr>
  </tbody>
</Table>

**예시:** 가정용 공유기는 사실 "스위치 기능 + 라우터 기능"이 하나의 장비에 합쳐진 것입니다. 집 안의 여러 기기를 서로 연결하는 스위치 역할과, 집 네트워크를 인터넷(외부 네트워크)에 연결해주는 라우터 역할을 동시에 수행합니다.

## 핵심 정리

- **NIC**: 컴퓨터를 네트워크에 연결하는 장치. 고유한 MAC 주소를 가짐.
- **전송 매체**: UTP 케이블(가정용), 광섬유(고속·장거리), 무선(케이블 없음).
- **허브**: 모든 포트로 무차별 전달(비효율적, 현재는 거의 사용 안 함).
- **스위치**: MAC 주소를 학습해 목적지 포트로만 전달(같은 네트워크 내부에서 동작).
- **라우터**: 서로 다른 네트워크를 IP 주소 기반으로 연결하고 경로를 찾는 장비.
