## 데이터 링크 계층의 역할

**데이터 링크 계층**(Data Link Layer)은 동일 네트워크 내 두 노드 사이에서 신뢰성 있는 데이터 전달을 담당합니다.

- **프레이밍(Framing):** 비트 스트림을 프레임 단위로 구분
- **오류 검출 및 정정:** CRC(Cyclic Redundancy Check)로 오류 검출
- **흐름 제어:** 송신 속도가 수신 처리 속도를 초과하지 않도록 조절
- **매체 접근 제어(MAC):** 공유 매체에 대한 접근 순서 결정

## MAC 주소

**MAC(Media Access Control) 주소**는 네트워크 인터페이스 카드(NIC)에 부여된 48비트 하드웨어 주소입니다.

- 형식: `AA:BB:CC:DD:EE:FF` (16진수 6쌍)
- 앞 24비트: 제조사 식별자(OUI)
- 뒤 24비트: 장치 일련번호

## 이더넷 프레임 구조

| 필드 | 크기 | 설명 |
|------|------|------|
| 프리앰블 | 7바이트 | 동기화 신호 |
| SFD | 1바이트 | 프레임 시작 구분자 |
| 목적지 MAC | 6바이트 | 수신자 하드웨어 주소 |
| 출발지 MAC | 6바이트 | 송신자 하드웨어 주소 |
| 타입/길이 | 2바이트 | 상위 프로토콜(IPv4=0x0800) 또는 데이터 길이 |
| 데이터 | 46~1500바이트 | 실제 전송 데이터 |
| FCS | 4바이트 | 오류 검출용 CRC 값 |

이더넷 프레임의 최소 크기는 64바이트이며, 최대 전송 단위(MTU)는 1500바이트입니다.

## CSMA/CD

**CSMA/CD**(Carrier Sense Multiple Access with Collision Detection)는 이더넷이 사용하는 매체 접근 제어 방식입니다.

1. **CS(Carrier Sense):** 전송 전에 매체가 사용 중인지 확인
2. **MA(Multiple Access):** 여러 장치가 동일 매체를 공유
3. **CD(Collision Detection):** 충돌 발생을 감지하면 즉시 전송 중단 → **잼 신호**(Jam Signal) 전송 → **임의 시간**(Back-off) 대기 → 재전송

<Callout type="warning">
  CSMA/CD는 유선 이더넷(반이중)에서 사용됩니다. 무선 네트워크(Wi-Fi)는 충돌 감지가 어렵기 때문에 **CSMA/CA**(Collision Avoidance)를 사용합니다.
</Callout>

## ARQ 오류 제어 방식

**ARQ**(Automatic Repeat reQuest)는 오류가 발생한 프레임을 재전송하여 신뢰성을 보장합니다.

| ARQ 방식 | 동작 | 특징 |
|----------|------|------|
| **Stop-and-Wait ARQ** | 프레임 하나를 보내고 ACK를 받을 때까지 대기 | 구현 간단, 효율 낮음 |
| **Go-Back-N ARQ** | 오류 발생 시 해당 프레임부터 이후 전부 재전송 | 수신측 버퍼 불필요 |
| **Selective-Repeat ARQ** | 오류 발생한 프레임만 선택적 재전송 | 효율 높음, 수신측 버퍼 필요 |

## 핵심 정리

- MAC 주소: 48비트, 제조사(24비트) + 일련번호(24비트)
- 이더넷 프레임: 최소 64바이트, MTU 1500바이트, FCS로 오류 검출
- CSMA/CD: 충돌 감지 → 잼 신호 → 백오프 대기 → 재전송
- ARQ: Stop-and-Wait / Go-Back-N / Selective-Repeat
