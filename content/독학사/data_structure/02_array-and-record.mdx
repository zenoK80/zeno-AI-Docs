## 배열의 개념

**배열(Array)** 은 같은 자료형의 데이터를 연속된 메모리 공간에 순서대로 저장하는 선형 자료구조입니다. 인덱스를 이용해 임의 접근(Random Access)이 가능하므로 조회 시간이 $O(1)$입니다.

| 특성 | 내용 |
| --- | --- |
| 접근 시간 | $O(1)$ — 인덱스로 직접 접근 |
| 삽입/삭제 시간 | $O(n)$ — 원소 이동 필요 |
| 메모리 | 연속된 공간 필요 |

## 1차원 배열의 주소 계산

1차원 배열 A에서 시작 주소가 $\alpha$이고 각 원소의 크기가 $d$ 바이트일 때, $A[i]$의 주소는 다음과 같습니다.

$$\text{addr}(A[i]) = \alpha + i \times d$$

예를 들어 시작 주소가 100이고 원소 크기가 4바이트인 배열에서 $A[3]$의 주소는 $100 + 3 \times 4 = 112$입니다.

## 2차원 배열의 주소 계산

2차원 배열은 메모리에 1차원으로 펼쳐서 저장합니다. 저장 방식에 따라 두 가지가 있습니다.

**행 우선(Row-major order):** 행 단위로 연속 저장 (C 언어 방식)

$$\text{addr}(A[i][j]) = \alpha + (i \times n + j) \times d$$

**열 우선(Column-major order):** 열 단위로 연속 저장 (Fortran 방식)

$$\text{addr}(A[i][j]) = \alpha + (j \times m + i) \times d$$

여기서 $m$은 행의 수, $n$은 열의 수입니다.

## 레코드

**레코드(Record)** 는 서로 다른 자료형의 데이터를 하나로 묶어 표현하는 구조입니다. C 언어의 `struct`가 대표적인 예입니다.

## 희소행렬

**희소행렬(Sparse Matrix)** 은 행렬의 원소 대부분이 0인 경우입니다. 0이 아닌 원소만 따로 저장하면 메모리를 절약할 수 있습니다.

예를 들어 4×5 행렬에서 0이 아닌 원소가 3개라면, 삼중쌍(row, col, value)으로 표현합니다.

| 행(row) | 열(col) | 값(value) |
| --- | --- | --- |
| 0 | 2 | 5 |
| 1 | 4 | 3 |
| 3 | 0 | 7 |

**전치행렬(Transpose):** 행과 열을 서로 바꾼 행렬입니다. 원래 행렬 A의 전치행렬 $A^T$에서 $A^T[j][i] = A[i][j]$입니다.

## 핵심 정리

- 배열은 인덱스로 $O(1)$ 접근이 가능하며 삽입/삭제는 $O(n)$입니다.
- 1차원 배열 주소: $\alpha + i \times d$
- 2차원 배열 행 우선 주소: $\alpha + (i \times n + j) \times d$
- 희소행렬은 0이 아닌 원소만 (행, 열, 값) 형태로 저장하여 메모리를 절약합니다.
