## 최단경로 문제

**최단경로(Shortest Path)** 는 가중치 그래프에서 출발 정점에서 도착 정점까지 간선 가중치의 합이 최소인 경로를 찾는 문제입니다.

| 알고리즘 | 적용 조건 | 시간 복잡도 |
| --- | --- | --- |
| 다익스트라 | 음의 가중치 없음, 단일 출발점 | $O((V+E) \log V)$ |
| 벨만-포드 | 음의 가중치 허용, 단일 출발점 | $O(VE)$ |
| 플로이드-워셜 | 모든 쌍 최단경로 | $O(V^3)$ |

## 다익스트라 알고리즘 (Dijkstra)

음의 가중치가 없는 그래프에서 단일 출발점의 최단경로를 구합니다. 우선순위 큐(힙)를 이용해 효율적으로 구현합니다.

**과정:**
1. 출발점의 거리를 0, 나머지를 무한대(∞)로 초기화
2. 방문하지 않은 정점 중 거리가 가장 작은 정점 선택
3. 선택된 정점의 이웃 정점 거리 갱신(완화, Relaxation)
4. 모든 정점을 방문할 때까지 2~3 반복

**예시:** 출발점 A에서 각 정점까지의 최단거리 계산

```
그래프:
A --4--> B
A --2--> C
C --1--> B
B --3--> D

초기: dist = {A:0, B:∞, C:∞, D:∞}
A 방문: B=4, C=2 갱신 → dist = {A:0, B:4, C:2, D:∞}
C 방문(최소=2): B=min(4,2+1)=3 갱신 → dist = {A:0, B:3, C:2, D:∞}
B 방문(최소=3): D=3+3=6 갱신 → dist = {A:0, B:3, C:2, D:6}
```

## 벨만-포드 알고리즘 (Bellman-Ford)

음의 가중치가 있는 그래프에서 단일 출발점의 최단경로를 구합니다. 음의 사이클도 감지할 수 있습니다.

**과정:**
1. 출발점의 거리를 0, 나머지를 ∞로 초기화
2. 모든 간선에 대해 완화(Relaxation) 연산: $V-1$번 반복
3. 한 번 더 완화 시 거리가 줄어들면 음의 사이클 존재

다익스트라보다 느리지만 음의 가중치 처리 가능

## 플로이드-워셜 알고리즘 (Floyd-Warshall)

모든 정점 쌍 사이의 최단경로를 한 번에 구합니다. 동적 프로그래밍 기법을 사용합니다.

$$\text{dist}[i][j] = \min(\text{dist}[i][j],\ \text{dist}[i][k] + \text{dist}[k][j])$$

- $k$: 경유 정점, 1부터 $V$까지 반복
- 시간 복잡도: $O(V^3)$
- 음의 가중치 허용, 음의 사이클은 불허

## 세 알고리즘 비교

| 항목 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
| --- | --- | --- | --- |
| 출발점 수 | 1개 | 1개 | 전체 |
| 음의 가중치 | 불가 | 가능 | 가능 |
| 음의 사이클 감지 | 불가 | 가능 | 불가 |
| 시간 복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |

## 핵심 정리

- 다익스트라: 음의 가중치 없는 그래프, 단일 출발점, 우선순위 큐 사용
- 벨만-포드: 음의 가중치 허용, 음의 사이클 감지 가능, $O(VE)$
- 플로이드-워셜: 모든 쌍 최단경로, DP 기반, $O(V^3)$
