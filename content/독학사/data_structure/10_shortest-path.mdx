## 왜 최단경로 알고리즘이 필요한가?

네비게이션에서 "빠른 경로 찾기"를 누르면 어떻게 최단 경로를 알아낼까요? 단순히 "가장 적은 신호등" 또는 "가장 짧은 거리"만 고려하는 게 아니라, 도로마다 다른 이동 시간(가중치)을 고려해야 합니다.

이런 **가중치 그래프에서 최단 경로**를 찾는 알고리즘이 필요합니다.

**최단경로**(Shortest Path, 쇼티스트 패스)는 가중치 그래프에서 출발 정점에서 도착 정점까지 간선 가중치의 합이 최소인 경로를 찾는 문제입니다.

쉽게 말하면: 출발지에서 목적지까지 가장 적은 비용(거리, 시간)으로 가는 길은?

## 세 가지 알고리즘 한눈에 비교

| 알고리즘 | 적용 조건 | 출발점 | 시간 복잡도 |
| --- | --- | --- | --- |
| 다익스트라(Dijkstra) | 음의 가중치 없음 | 단일 출발점 | $O((V+E) \log V)$ |
| 벨만-포드(Bellman-Ford) | 음의 가중치 허용 | 단일 출발점 | $O(VE)$ |
| 플로이드-워셜(Floyd-Warshall) | 음의 가중치 허용 | 모든 정점 쌍 | $O(V^3)$ |

여기서 $V$는 정점(Vertex) 수, $E$는 간선(Edge) 수입니다.

## 다익스트라 알고리즘 (Dijkstra's Algorithm)

**다익스트라**(Dijkstra, 데이크스트라) 알고리즘은 음의 가중치가 없는 그래프에서 단일 출발점의 최단경로를 구합니다.

비유: 지도에서 출발지 A를 중심으로 가까운 곳부터 차례로 "확정"해 나가는 방식. 이미 확정된 최단거리는 바뀌지 않습니다.

**핵심 아이디어(탐욕적 방법, Greedy):** 아직 방문하지 않은 정점 중 출발점에서 가장 가까운 정점을 선택합니다.

**과정:**
1. 출발점의 거리를 0, 나머지를 무한대(∞)로 초기화
2. 방문하지 않은 정점 중 거리가 가장 작은 정점 선택
3. 선택된 정점의 이웃 정점 거리 갱신 (**완화, Relaxation**)
4. 모든 정점을 방문할 때까지 2~3 반복

**완화(Relaxation, 릴렉세이션):** "이 경로로 가면 더 짧지 않을까?" 확인하고 더 짧으면 갱신

**예시:** 출발점 A에서 각 정점까지의 최단거리 계산
```
그래프:
A --4--> B
A --2--> C
C --1--> B
B --3--> D

초기: dist = {A:0, B:∞, C:∞, D:∞}
A 방문: B=4, C=2 갱신 → dist = {A:0, B:4, C:2, D:∞}
C 방문(최소=2): B=min(4, 2+1)=3 갱신 → dist = {A:0, B:3, C:2, D:∞}
B 방문(최소=3): D=3+3=6 갱신 → dist = {A:0, B:3, C:2, D:6}
```

우선순위 큐(힙)를 이용하면 효율적: $O((V+E) \log V)$

## 벨만-포드 알고리즘 (Bellman-Ford Algorithm)

**벨만-포드**(Bellman-Ford) 알고리즘은 **음의 가중치**가 있는 그래프에서도 최단경로를 구할 수 있습니다. 또한 **음의 사이클**(Negative Cycle)도 감지할 수 있습니다.

- **음의 가중치**: 간선의 비용이 음수 (예: 할인, 이득)
- **음의 사이클**: 가중치 합이 음수인 사이클 (무한히 거리를 줄일 수 있어 최단경로가 정의되지 않음)

**과정:**
1. 출발점의 거리를 0, 나머지를 ∞로 초기화
2. **모든** 간선에 대해 완화(Relaxation) 연산을 $V-1$번 반복
3. $V$번째 완화에서도 거리가 줄어들면 → **음의 사이클 존재!**

왜 $V-1$번? 최단 경로는 최대 $V-1$개의 간선을 포함하기 때문입니다.

다익스트라보다 느리지만($O(VE)$), 음의 가중치를 처리할 수 있는 것이 장점입니다.

## 플로이드-워셜 알고리즘 (Floyd-Warshall Algorithm)

**플로이드-워셜**(Floyd-Warshall) 알고리즘은 **모든 정점 쌍** 사이의 최단경로를 한 번에 구합니다. 동적 프로그래밍(DP) 기법을 사용합니다.

핵심 아이디어: "정점 k를 경유해서 가는 것이 직접 가는 것보다 더 짧은가?"

점화식(Recurrence Formula):

$$\text{dist}[i][j] = \min(\text{dist}[i][j],\ \text{dist}[i][k] + \text{dist}[k][j])$$

- $i$: 출발 정점
- $j$: 도착 정점
- $k$: 경유 정점 (1부터 $V$까지 반복)

**예시 (간단한 3정점 그래프):**
```
초기 dist 행렬:
    1    2    3
1 [ 0    3    ∞ ]
2 [ ∞    0    1 ]
3 [ 4    ∞    0 ]

k=2 경유:
dist[1][3] = min(∞, dist[1][2] + dist[2][3]) = min(∞, 3+1) = 4

k=3 경유:
dist[1][3]은 이미 4
dist[2][1] = min(∞, dist[2][3] + dist[3][1]) = min(∞, 1+4) = 5
```

- 시간 복잡도: $O(V^3)$ (3중 루프: i, j, k)
- 음의 가중치 허용, 단 음의 사이클은 불허

## 세 알고리즘 상세 비교

| 항목 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
| --- | --- | --- | --- |
| 출발점 수 | 1개 | 1개 | 전체 (모든 쌍) |
| 음의 가중치 | 불가 | 가능 | 가능 |
| 음의 사이클 감지 | 불가 | 가능 | 불가 |
| 시간 복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |
| 구현 방법 | 탐욕(Greedy) + 우선순위 큐 | 완화 반복 | 동적 프로그래밍 |

## 핵심 정리

- **다익스트라**: 음의 가중치 없는 그래프, 단일 출발점, 우선순위 큐 사용, 빠름
- **벨만-포드**: 음의 가중치 허용, 음의 사이클 감지 가능, $O(VE)$
- **플로이드-워셜**: 모든 쌍 최단경로, DP 기반, $O(V^3)$
