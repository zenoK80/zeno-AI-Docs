## 스택을 이용한 괄호 검사

괄호 검사는 스택의 대표 응용 중 하나입니다.

**알고리즘:**
1. 여는 괄호 `(`, `[`, `{`는 스택에 push
2. 닫는 괄호 `)`, `]`, `}`를 만나면 스택에서 pop
3. pop한 여는 괄호와 닫는 괄호가 쌍이 맞는지 확인
4. 끝까지 처리 후 스택이 비어있으면 올바른 괄호

**예시:**
```
입력: {[()]}
과정:
{ → push {
[ → push [
( → push (
) → pop (, ( == ) 짝 맞음
] → pop [, [ == ] 짝 맞음
} → pop {, { == } 짝 맞음
스택 비어있음 → 올바른 괄호
```

잘못된 예: `([)]` → 닫는 괄호 `)` 앞에 `[`가 있어 불일치

## 스택을 이용한 후위 표기식 변환

**중위 표기식:** A + B * C - D

**변환 과정:**

| 읽은 문자 | 스택 | 출력 |
| --- | --- | --- |
| A | (비어있음) | A |
| + | + | A |
| B | + | A B |
| * | + * | A B |
| C | + * | A B C |
| - | - | A B C * + |
| D | - | A B C * + D |
| 끝 | (비어있음) | A B C * + D - |

**결과:** `ABC*+D-`

## 트리를 이용한 수식 표현

수식을 이진트리로 표현할 수 있습니다. 각 내부 노드는 연산자, 리프 노드는 피연산자입니다.

수식 `(A+B) * (C-D)`:

```
       *
      / \
     +   -
    / \ / \
   A  B C  D
```

| 순회 방법 | 표기식 | 결과 |
| --- | --- | --- |
| 중위 순회 | 중위(Infix) | A + B * C - D |
| 전위 순회 | 전위(Prefix) | * + A B - C D |
| 후위 순회 | 후위(Postfix) | A B + C D - * |

## 그래프를 이용한 위상 정렬

**위상 정렬(Topological Sort)** 은 방향 그래프에서 선행 조건을 만족하는 순서로 정점을 나열합니다.

- 적용 조건: 방향 비순환 그래프(DAG)
- 활용: 컴파일 순서, 강의 선수과목, 프로젝트 일정

**Kahn's 알고리즘:**
1. 진입 차수가 0인 정점을 큐에 삽입
2. 큐에서 정점을 꺼내 결과에 추가
3. 해당 정점의 인접 정점의 진입 차수를 1 감소
4. 진입 차수가 0이 된 정점을 큐에 삽입
5. 큐가 빌 때까지 반복

## 연결 리스트를 이용한 다항식 연산

다항식 $A(x) = 3x^4 + 2x^2 + 1$을 (계수, 지수) 노드의 연결 리스트로 표현합니다.

```
[3|4] → [2|2] → [1|0] → NULL
```

두 다항식의 덧셈: 지수가 같으면 계수를 더하고, 다르면 지수가 큰 쪽을 결과에 추가합니다.

## 자료구조 선택 가이드

| 문제 상황 | 적합한 자료구조 |
| --- | --- |
| 역순 처리, 괄호 검사 | 스택 |
| 순서대로 처리, BFS | 큐 |
| 빠른 최솟값/최댓값 | 힙(우선순위 큐) |
| 동적 삽입/삭제 | 연결 리스트 |
| 계층 구조 표현 | 트리 |
| 관계망 표현 | 그래프 |
| 빠른 탐색 | 해시 테이블, BST |

## 핵심 정리

- 괄호 검사: 스택 활용, 여는 괄호 push, 닫는 괄호는 pop하여 비교
- 수식 트리: 전위/중위/후위 순회로 각각 전위/중위/후위 표기식 생성
- 위상 정렬: DAG에서 선행 관계 순서 결정, 큐로 구현
- 문제에 맞는 자료구조 선택이 알고리즘 효율의 핵심
