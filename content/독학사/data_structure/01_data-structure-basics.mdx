## 자료구조란 무엇인가

**자료구조(Data Structure)** 는 데이터를 효율적으로 저장하고 처리하기 위한 조직화된 방법입니다. 자료구조를 올바르게 선택하면 같은 문제를 훨씬 빠르게 해결할 수 있습니다.

자료구조는 크게 두 가지로 분류됩니다.

| 분류 | 예시 |
| --- | --- |
| 선형 자료구조 | 배열, 연결 리스트, 스택, 큐 |
| 비선형 자료구조 | 트리, 그래프 |

## 추상 자료형 (ADT)

**추상 자료형(Abstract Data Type, ADT)** 은 자료의 집합과 그 자료에 적용할 수 있는 연산의 집합을 구현 세부사항 없이 명세한 것입니다. 즉, "무엇을 할 수 있는가"만 정의하고 "어떻게 구현하는가"는 별도로 다룹니다.

예를 들어 스택 ADT는 다음과 같이 정의됩니다.

- **데이터:** 원소들의 순서 있는 집합
- **연산:** push(삽입), pop(삭제), peek(최상단 조회), isEmpty(비어있는지 확인)

## 알고리즘의 정의와 조건

**알고리즘(Algorithm)** 은 문제를 해결하기 위한 유한한 단계의 명령 집합입니다. 올바른 알고리즘은 다섯 가지 조건을 만족해야 합니다.

| 조건 | 설명 |
| --- | --- |
| 입력 | 0개 이상의 입력이 존재한다 |
| 출력 | 1개 이상의 출력이 존재한다 |
| 명확성 | 각 명령은 모호하지 않고 명확하다 |
| 유한성 | 유한한 단계 후에 반드시 종료된다 |
| 유효성 | 각 명령은 실행 가능한 연산이다 |

## 알고리즘 복잡도와 Big-O 표기법

알고리즘의 효율은 **시간 복잡도**와 **공간 복잡도**로 측정합니다.

- **시간 복잡도:** 알고리즘이 완료되는 데 필요한 연산 횟수
- **공간 복잡도:** 알고리즘이 사용하는 메모리 양

**Big-O 표기법**은 입력 크기 $n$이 커질 때 알고리즘의 성능이 어떻게 변하는지 나타내는 점근적 표기법입니다.

| Big-O | 이름 | 예시 알고리즘 |
| --- | --- | --- |
| $O(1)$ | 상수 시간 | 배열 인덱스 접근 |
| $O(\log n)$ | 로그 시간 | 이진 탐색 |
| $O(n)$ | 선형 시간 | 순차 탐색 |
| $O(n \log n)$ | 선형로그 시간 | 퀵 정렬(평균), 합병 정렬 |
| $O(n^2)$ | 이차 시간 | 버블 정렬, 삽입 정렬 |
| $O(2^n)$ | 지수 시간 | 재귀적 피보나치 |

복잡도 크기 비교: $O(1) \lt O(\log n) \lt O(n) \lt O(n \log n) \lt O(n^2) \lt O(2^n)$

## 순환(재귀) 알고리즘

**재귀(Recursion)** 는 함수가 자기 자신을 호출하여 문제를 해결하는 방법입니다. 반드시 종료 조건(base case)이 있어야 합니다.

팩토리얼 예시: $n! = n \times (n-1)!$, 단 $0! = 1$

## 핵심 정리

- 자료구조는 데이터를 효율적으로 조직화하는 방법이며, 선형과 비선형으로 분류됩니다.
- ADT는 구현 없이 데이터와 연산만 명세한 개념적 모델입니다.
- Big-O 표기법은 알고리즘 효율을 입력 크기 기준으로 나타냅니다.
- $O(1) \lt O(\log n) \lt O(n) \lt O(n \log n) \lt O(n^2)$ 순으로 복잡도가 증가합니다.
