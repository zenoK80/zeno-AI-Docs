## 힙의 개념

**힙(Heap)** 은 완전 이진트리 구조에서 부모 노드와 자식 노드 사이에 특정 순서 조건을 만족하는 자료구조입니다.

| 종류 | 조건 |
| --- | --- |
| 최대 힙(Max-Heap) | 부모 노드의 키 값 ≥ 자식 노드의 키 값 |
| 최소 힙(Min-Heap) | 부모 노드의 키 값 ≤ 자식 노드의 키 값 |

힙은 완전 이진트리이므로 배열로 효율적으로 표현할 수 있습니다.

## 힙의 배열 표현

인덱스 1부터 시작(인덱스 0은 사용 안 함):

- 노드 $i$의 부모: $\lfloor i/2 \rfloor$
- 노드 $i$의 왼쪽 자식: $2i$
- 노드 $i$의 오른쪽 자식: $2i+1$

예시 Max-Heap:
```
배열: [_, 90, 70, 60, 50, 30, 20, 10]
인덱스:  1   2   3   4   5   6   7

       90
      /  \
    70    60
   /  \  /  \
  50  30 20  10
```

## 힙 삽입 (Sift-Up / Heapify-Up)

1. 새 원소를 배열 맨 끝(마지막 리프)에 추가
2. 부모 노드와 비교하여 힙 성질 위반 시 교환
3. 힙 성질이 만족될 때까지 위로 이동 반복

**예시:** Max-Heap에 80 삽입

```
삽입 전: [90, 70, 60, 50, 30, 20, 10]
80을 끝에 추가: [..., 80]  (80의 부모=70)
80 > 70 → 교환: [..., 80, 70이 자리 교환]
80 < 90 → 정지
```

시간 복잡도: $O(\log n)$

## 힙 삭제 (Sift-Down / Heapify-Down)

힙에서는 루트(최댓값 또는 최솟값)만 삭제합니다.

1. 루트를 제거하고 마지막 원소를 루트 자리로 이동
2. 자식 노드 중 더 큰(Max-Heap) 자식과 비교
3. 힙 성질 위반 시 교환
4. 힙 성질이 만족될 때까지 아래로 이동 반복

시간 복잡도: $O(\log n)$

## 힙 정렬 (Heap Sort)

힙 정렬은 힙 자료구조를 이용한 정렬 알고리즘입니다.

**과정:**
1. 입력 배열로 Max-Heap 구성: $O(n)$
2. 루트(최댓값)를 배열 끝과 교환
3. 힙 크기를 1 감소
4. 루트에서 Heapify-Down 수행
5. 2~4를 n-1회 반복

시간 복잡도: $O(n \log n)$ (최선, 평균, 최악 모두 동일)

공간 복잡도: $O(1)$ (제자리 정렬)

## 힙 정렬 특성 비교

| 항목 | 힙 정렬 |
| --- | --- |
| 시간 복잡도 | $O(n \log n)$ |
| 공간 복잡도 | $O(1)$ |
| 안정성 | 불안정 정렬 |
| 특징 | 최악도 O(n log n) 보장 |

## 우선순위 큐와 힙

힙은 우선순위 큐의 가장 효율적인 구현체입니다.

| 연산 | 복잡도 |
| --- | --- |
| 삽입(push) | $O(\log n)$ |
| 최댓값/최솟값 조회(peek) | $O(1)$ |
| 최댓값/최솟값 삭제(pop) | $O(\log n)$ |

## 핵심 정리

- Max-Heap: 부모 ≥ 자식, Min-Heap: 부모 ≤ 자식
- 힙은 완전 이진트리이며 배열로 표현합니다.
- 삽입: 끝에 추가 후 Sift-Up → $O(\log n)$
- 삭제: 루트 제거, 마지막 원소를 루트로 이동 후 Sift-Down → $O(\log n)$
- 힙 정렬: $O(n \log n)$, 제자리 정렬
