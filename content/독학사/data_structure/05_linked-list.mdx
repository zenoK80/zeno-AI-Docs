## 왜 연결 리스트가 필요한가?

배열은 크기가 고정되어 있습니다. 학생 명단이 처음에는 30명이었는데 50명으로 늘어난다면? 배열을 새로 만들고 데이터를 복사해야 합니다. 또 중간에 원소를 삽입하려면 뒤에 있는 모든 원소를 한 칸씩 밀어야 합니다.

이런 불편함을 해결하는 것이 **연결 리스트**(Linked List, 링크드 리스트)입니다.

생활 비유: **기차**를 생각해 보세요. 기차 칸(노드)들이 연결 고리(포인터)로 이어져 있습니다. 중간에 칸을 추가하거나 제거할 때 연결 고리만 바꾸면 됩니다. 다른 칸을 움직일 필요가 없죠.

## 연결 리스트의 개념

**연결 리스트**(Linked List)는 데이터와 다음 노드의 주소(**포인터**, Pointer)를 함께 저장하는 선형 자료구조입니다.

- **노드**(Node, 노드): 데이터와 포인터를 담는 단위. 기차 칸 하나
- **포인터**(Pointer, 포인터): 다음 노드의 메모리 주소를 담는 변수. 기차 연결 고리

배열과 달리 메모리의 연속된 공간이 필요 없습니다. 각 노드가 흩어져 있어도 포인터로 연결됩니다.

| 특성 | 배열 | 연결 리스트 |
| --- | --- | --- |
| 접근 방법 | 인덱스로 임의 접근 $O(1)$ | 순차 접근 $O(n)$ |
| 삽입/삭제 | $O(n)$ (원소 이동 필요) | $O(1)$ (포인터만 변경) |
| 메모리 | 연속된 공간 필요 | 분산된 공간 가능 |
| 크기 | 선언 시 고정 | 동적으로 변경 가능 |

## 단순 연결 리스트 (Singly Linked List)

각 노드는 데이터(data)와 다음 노드를 가리키는 포인터(link)로 구성됩니다. 오직 한 방향으로만 이동할 수 있습니다.

```
[data | link] → [data | link] → [data | NULL]
 Head                             Tail
```

- **Head**(헤드): 첫 번째 노드를 가리키는 포인터
- **NULL**: 더 이상 다음 노드가 없음을 표시

### 노드 삽입 (중간 삽입)

새 노드 X를 노드 P 다음에 삽입하는 과정:

```
1단계: X.link = P.link   (X가 P의 다음 노드를 가리킴)
2단계: P.link = X        (P가 X를 가리킴)
```

**주의:** 반드시 1단계를 먼저 해야 합니다! 2단계를 먼저 하면 P.link(원래 다음 노드)를 잃어버립니다.

### 노드 삭제 (P의 다음 노드 Q 삭제)

```
P.link = Q.link      (P가 Q의 다음 노드를 직접 가리킴)
```

Q를 완전히 건너뛰게 만들면 됩니다. 기차에서 중간 칸을 빼내고 앞뒤 칸을 직접 연결하는 것과 같습니다.

## 이중 연결 리스트 (Doubly Linked List)

단순 연결 리스트는 앞으로만 이동할 수 있어 뒤로 되돌아가려면 처음부터 다시 탐색해야 합니다. 이 문제를 해결한 것이 **이중 연결 리스트**(Doubly Linked List, 더블리 링크드 리스트)입니다.

각 노드가 이전 노드(prev)와 다음 노드(next)를 모두 가리켜서 양방향 탐색이 가능합니다.

```
NULL ← [prev | data | next] ↔ [prev | data | next] → NULL
```

| 특성 | 단순 연결 리스트 | 이중 연결 리스트 |
| --- | --- | --- |
| 포인터 수 | 1개(next) | 2개(prev, next) |
| 메모리 | 적음 | 많음 |
| 역방향 탐색 | 불가 | 가능 |
| 노드 삭제 | 이전 노드가 필요 | 현재 노드만으로 가능 |

이중 연결 리스트에서 노드 Q 삭제:
```
Q.prev.next = Q.next    (Q의 이전 노드가 Q의 다음을 가리킴)
Q.next.prev = Q.prev    (Q의 다음 노드가 Q의 이전을 가리킴)
```

총 2번의 포인터 변경으로 삭제 완료!

## 원형 연결 리스트 (Circular Linked List)

**원형 연결 리스트**(Circular Linked List, 서큘러 링크드 리스트)는 마지막 노드의 포인터가 첫 번째 노드(Head)를 가리켜서 원형으로 연결됩니다.

```
[A] → [B] → [C] → (A로 되돌아감)
```

비유: 원탁에 앉은 사람들처럼, 마지막 사람 다음이 첫 번째 사람으로 이어집니다.

tail(꼬리) 포인터를 사용하면 맨 앞/뒤 삽입을 $O(1)$에 처리할 수 있습니다.

## 다항식의 연결 리스트 표현

다항식 $P(x) = 3x^4 + 2x^2 + 1$을 (계수, 지수) 노드로 표현합니다.

- **계수**(Coefficient, 코에피션트): 숫자 앞의 수 (3, 2, 1)
- **지수**(Exponent, 익스포넌트): x의 승수 (4, 2, 0)

```
[3 | 4] → [2 | 2] → [1 | 0] → NULL
```

지수가 높은 항부터 저장하면 두 다항식의 덧셈 연산이 쉬워집니다.

## 핵심 정리

- **연결 리스트**는 포인터로 연결된 노드들의 집합입니다.
- 삽입/삭제가 $O(1)$이나 접근(탐색)은 $O(n)$입니다.
- **단순 연결 리스트**: 한 방향 포인터만 있음
- **이중 연결 리스트**: 양방향 포인터, 역방향 탐색 가능
- **원형 연결 리스트**: 마지막 노드가 첫 노드를 가리킴
