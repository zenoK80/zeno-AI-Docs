## 연결 리스트의 개념

**연결 리스트(Linked List)** 는 데이터와 다음 노드의 주소(포인터)를 함께 저장하는 선형 자료구조입니다. 배열과 달리 메모리의 연속된 공간이 필요 없습니다.

| 특성 | 배열 | 연결 리스트 |
| --- | --- | --- |
| 접근 방법 | 인덱스로 임의 접근 $O(1)$ | 순차 접근 $O(n)$ |
| 삽입/삭제 | $O(n)$ (원소 이동 필요) | $O(1)$ (포인터 변경) |
| 메모리 | 연속된 공간 필요 | 분산된 공간 가능 |
| 크기 | 고정 | 동적 |

## 단순 연결 리스트 (Singly Linked List)

각 노드는 데이터(data)와 다음 노드를 가리키는 포인터(link)로 구성됩니다.

```
[data | link] → [data | link] → [data | NULL]
 Head                             Tail
```

**노드 삽입 (중간 삽입):**
새 노드 X를 노드 P 다음에 삽입하는 과정입니다.

```
1. X.link = P.link   (X가 P의 다음 노드를 가리킴)
2. P.link = X        (P가 X를 가리킴)
```

**노드 삭제 (P의 다음 노드 Q 삭제):**
```
P.link = Q.link      (P가 Q의 다음 노드를 가리킴)
```

## 이중 연결 리스트 (Doubly Linked List)

각 노드가 이전 노드(prev)와 다음 노드(next)를 모두 가리켜서 양방향 탐색이 가능합니다.

```
NULL ← [prev | data | next] ↔ [prev | data | next] → NULL
```

| 특성 | 단순 연결 리스트 | 이중 연결 리스트 |
| --- | --- | --- |
| 포인터 수 | 1개(next) | 2개(prev, next) |
| 메모리 | 적음 | 많음 |
| 역방향 탐색 | 불가 | 가능 |
| 노드 삭제 | 이전 노드 필요 | 현재 노드만으로 가능 |

## 원형 연결 리스트 (Circular Linked List)

마지막 노드의 포인터가 첫 번째 노드(Head)를 가리켜서 원형으로 연결됩니다.

```
[A] → [B] → [C] → (Head로 되돌아감)
```

마지막 노드 앞에 삽입할 때 효율적입니다. 헤드 포인터 대신 tail 포인터를 사용하면 맨 앞/뒤 삽입을 $O(1)$에 처리할 수 있습니다.

## 다항식의 연결 리스트 표현

$P(x) = 3x^4 + 2x^2 + 1$을 (계수, 지수) 노드로 표현합니다.

```
[3 | 4] → [2 | 2] → [1 | 0] → NULL
```

지수가 높은 항부터 저장하면 덧셈 연산이 쉬워집니다.

## 핵심 정리

- 연결 리스트는 포인터로 연결된 노드들의 집합입니다.
- 삽입/삭제가 $O(1)$이나 접근은 $O(n)$입니다.
- 단순 연결 리스트: 한 방향 포인터
- 이중 연결 리스트: 양방향 포인터, 역방향 탐색 가능
- 원형 연결 리스트: 마지막 노드가 첫 노드를 가리킴
