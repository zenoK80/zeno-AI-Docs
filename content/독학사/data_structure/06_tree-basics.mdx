## 왜 트리가 필요한가?

지금까지 배운 배열, 연결 리스트, 스택, 큐는 모두 **선형** 자료구조입니다. 데이터가 일렬로 연결되죠. 하지만 세상의 많은 정보는 "계층" 구조를 가집니다.

예시:
- **회사 조직도**: 사장 아래 부장, 부장 아래 과장, 과장 아래 사원
- **폴더 구조**: 최상위 폴더 안에 하위 폴더, 그 안에 또 하위 폴더
- **생물 분류**: 동물 → 포유류 → 개과 → 개

이런 계층 구조를 표현하는 자료구조가 **트리(Tree, 트리)**입니다.

쉽게 말하면: 트리 = 뒤집어진 나무 모양으로 데이터를 계층적으로 연결한 구조

## 트리의 기본 개념과 용어

**트리(Tree)**는 계층적 관계를 나타내는 비선형 자료구조입니다. **노드(Node, 노드)**와 **간선(Edge, 엣지)**으로 구성되며, 사이클(cycle, 순환)이 없는 연결 그래프입니다.

예시 트리:
```
         A       ← 루트(Root)
        / \
       B   C
      / \
     D   E       ← 리프(Leaf)
```

| 용어 | 영어 | 설명 | 위 예시에서 |
| --- | --- | --- | --- |
| 루트(Root) | root | 트리의 최상위 노드 (부모가 없는 노드) | A |
| 부모(Parent) | parent | 자식을 가진 노드 | A, B |
| 자식(Child) | child | 부모 노드 아래의 노드 | B, C, D, E |
| 리프(Leaf) | leaf | 자식이 없는 단말 노드 | C, D, E |
| 레벨(Level) | level | 루트에서 해당 노드까지의 깊이 (루트=1) | A=1, B·C=2, D·E=3 |
| 높이(Height) | height | 트리의 최대 레벨 수 | 3 |
| 차수(Degree) | degree | 노드의 자식 수 | A의 차수=2, B의 차수=2, C의 차수=0 |

## 이진트리

**이진트리(Binary Tree, 바이너리 트리)**는 각 노드가 최대 2개의 자식(왼쪽 자식, 오른쪽 자식)을 갖는 트리입니다.

- **Binary(바이너리)** = "2"를 뜻합니다.
- 자식이 0, 1, 또는 2개일 수 있습니다. 3개 이상은 불가!

**이진트리의 중요한 수학 성질:**
- 레벨 $i$에서 최대 $2^{i-1}$개의 노드 존재
- 높이 $h$인 이진트리의 최대 노드 수: $2^h - 1$

예시: 높이 3인 이진트리의 최대 노드 수 = $2^3 - 1 = 7$개

**이진트리의 종류:**

| 종류 | 설명 | 특징 |
| --- | --- | --- |
| 포화 이진트리(Full Binary Tree) | 모든 레벨에 노드가 꽉 찬 트리 | 가장 이상적인 형태 |
| 완전 이진트리(Complete Binary Tree) | 마지막 레벨만 왼쪽부터 채워진 트리 | 힙(Heap) 구현에 사용 |
| 불완전 이진트리(Incomplete Binary Tree) | 위 조건을 만족하지 않는 트리 | 일반적인 형태 |

## 이진트리의 순회

**순회(Traversal, 트래버설)**는 트리의 모든 노드를 한 번씩 방문하는 방법입니다.

쉽게 말하면: 트리에 있는 모든 데이터를 어떤 순서로 읽을 것인가?

예시 트리:
```
       A
      / \
     B   C
    / \
   D   E
```

### 전위 순회 (Preorder, 프리오더): 루트 → 왼쪽 → 오른쪽

기억법: **루**트를 **먼저** 방문 (Pre = 먼저)

방문 순서: A → B → D → E → C

```
A 방문 → A의 왼쪽(B) 탐색
  B 방문 → B의 왼쪽(D) 탐색
    D 방문 → D는 자식 없음
  B의 오른쪽(E) 탐색
    E 방문 → E는 자식 없음
A의 오른쪽(C) 탐색
  C 방문 → C는 자식 없음
```

결과: **A B D E C**

### 중위 순회 (Inorder, 인오더): 왼쪽 → 루트 → 오른쪽

기억법: 루트가 **중간**에 (In = 중간)

방문 순서: D → B → E → A → C

이진 탐색 트리(BST)에서 중위 순회하면 **오름차순 정렬** 결과가 나옵니다!

### 후위 순회 (Postorder, 포스트오더): 왼쪽 → 오른쪽 → 루트

기억법: 루트를 **나중에** 방문 (Post = 나중)

방문 순서: D → E → B → C → A

수식 트리에서 후위 순회하면 후위 표기식이 생성됩니다.

### 순회 정리표

| 순회 | 순서 | 기억법 | 활용 |
| --- | --- | --- | --- |
| 전위 | 루트 → 왼 → 오 | 루트가 먼저 | 트리 복사, 전위 표기식 |
| 중위 | 왼 → 루트 → 오 | 루트가 중간 | BST 정렬 출력 |
| 후위 | 왼 → 오 → 루트 | 루트가 마지막 | 트리 삭제, 후위 표기식 |

## 이진트리의 배열 표현

완전 이진트리는 배열로 효율적으로 표현할 수 있습니다. 이 방법은 힙(Heap)에서도 사용합니다.

규칙 (인덱스 1부터 시작):
- 루트: 인덱스 **1**
- 노드 $i$의 왼쪽 자식: $2i$
- 노드 $i$의 오른쪽 자식: $2i+1$
- 노드 $i$의 부모: $\lfloor i/2 \rfloor$ (내림)

예시:
```
배열: [_, A, B, C, D, E]
인덱스:  0  1  2  3  4  5

       A(1)
      / \
    B(2) C(3)
   / \
 D(4) E(5)
```

## 핵심 정리

- **트리**: 계층적 관계를 표현하는 비선형 자료구조
- **이진트리**: 각 노드가 최대 2개의 자식을 갖는 트리
- 높이 $h$인 이진트리의 최대 노드: $2^h - 1$
- **전위 순회**: 루트 → 왼 → 오 (루트 먼저)
- **중위 순회**: 왼 → 루트 → 오 (BST에서 오름차순)
- **후위 순회**: 왼 → 오 → 루트 (루트 마지막)
