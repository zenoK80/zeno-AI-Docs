## 트리의 기본 개념

**트리(Tree)** 는 계층적 관계를 나타내는 비선형 자료구조입니다. 노드(Node)와 간선(Edge)으로 구성되며, 사이클이 없는 연결 그래프입니다.

| 용어 | 설명 |
| --- | --- |
| 루트(Root) | 트리의 최상위 노드 |
| 부모(Parent) | 자식을 가진 노드 |
| 자식(Child) | 부모 노드 아래의 노드 |
| 리프(Leaf) | 자식이 없는 단말 노드 |
| 레벨(Level) | 루트에서 해당 노드까지의 깊이 (루트=1) |
| 높이(Height) | 트리의 최대 레벨 수 |
| 차수(Degree) | 노드의 자식 수 |

## 이진트리

**이진트리(Binary Tree)** 는 각 노드가 최대 2개의 자식(왼쪽, 오른쪽)을 갖는 트리입니다.

**이진트리의 성질:**
- 레벨 $i$에서 최대 $2^{i-1}$개의 노드
- 높이 $h$인 이진트리의 최대 노드 수: $2^h - 1$

**이진트리의 종류:**

| 종류 | 설명 |
| --- | --- |
| 포화 이진트리 | 모든 레벨에 노드가 꽉 찬 트리 |
| 완전 이진트리 | 마지막 레벨만 왼쪽부터 채워진 트리 |
| 불완전 이진트리 | 위 조건을 만족하지 않는 트리 |

## 이진트리의 순회

순회(Traversal)는 트리의 모든 노드를 한 번씩 방문하는 방법입니다.

예시 트리:
```
       A
      / \
     B   C
    / \
   D   E
```

**전위 순회 (Preorder): 루트 → 왼쪽 → 오른쪽**

방문 순서: A → B → D → E → C

규칙: 현재 노드 방문 후 왼쪽 서브트리, 오른쪽 서브트리 순서로 재귀 탐색

**중위 순회 (Inorder): 왼쪽 → 루트 → 오른쪽**

방문 순서: D → B → E → A → C

규칙: 이진 탐색 트리(BST)에서 중위 순회하면 오름차순 정렬 결과

**후위 순회 (Postorder): 왼쪽 → 오른쪽 → 루트**

방문 순서: D → E → B → C → A

규칙: 수식 트리에서 후위 순회하면 후위 표기식 생성

| 순회 | 순서 | 활용 |
| --- | --- | --- |
| 전위 | 루트 → 왼 → 오 | 트리 복사, 전위 표기식 |
| 중위 | 왼 → 루트 → 오 | BST 정렬 출력 |
| 후위 | 왼 → 오 → 루트 | 트리 삭제, 후위 표기식 |

## 이진트리의 배열 표현

완전 이진트리는 배열로 효율적으로 표현할 수 있습니다.

- 루트: 인덱스 1
- 노드 $i$의 왼쪽 자식: $2i$
- 노드 $i$의 오른쪽 자식: $2i+1$
- 노드 $i$의 부모: $\lfloor i/2 \rfloor$

## 핵심 정리

- 이진트리는 각 노드가 최대 2개의 자식을 갖습니다.
- 전위 순회: 루트 → 왼 → 오 (루트 먼저)
- 중위 순회: 왼 → 루트 → 오 (BST에서 정렬 순서)
- 후위 순회: 왼 → 오 → 루트 (루트 마지막)
- 높이 $h$인 이진트리의 최대 노드: $2^h - 1$
