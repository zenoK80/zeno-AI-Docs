## 이진 탐색 트리 (BST)

**이진 탐색 트리(Binary Search Tree, BST)** 는 다음 성질을 만족하는 이진트리입니다.

- 왼쪽 서브트리의 모든 키 값 &lt; 루트 키 값
- 오른쪽 서브트리의 모든 키 값 &gt; 루트 키 값
- 각 서브트리도 이진 탐색 트리

## BST 탐색

키 값 k를 탐색하는 과정입니다.

1. 루트에서 시작
2. k == 현재 노드 키: 탐색 성공
3. k &lt; 현재 노드 키: 왼쪽 서브트리로 이동
4. k &gt; 현재 노드 키: 오른쪽 서브트리로 이동
5. NULL에 도달: 탐색 실패

평균 시간 복잡도: $O(\log n)$, 최악(편향 트리): $O(n)$

## BST 삽입

새 키를 삽입할 위치를 탐색으로 찾은 뒤 리프 노드로 추가합니다.

예시: 50, 30, 70, 20, 40 순서로 삽입

```
      50
     /  \
    30   70
   /  \
  20   40
```

## BST 삭제

삭제할 노드의 자식 수에 따라 세 가지 경우로 처리합니다.

| 경우 | 처리 방법 |
| --- | --- |
| 자식 없음(리프) | 노드를 단순 삭제 |
| 자식 1개 | 자식 노드로 대체 |
| 자식 2개 | 중위 후속자(or 중위 전임자)로 대체 후 해당 노드 삭제 |

**중위 후속자:** 삭제할 노드의 오른쪽 서브트리에서 가장 작은 값

## AVL 트리

**AVL 트리**는 모든 노드에서 왼쪽과 오른쪽 서브트리의 높이 차이(균형 인수)가 최대 1인 자기 균형 이진 탐색 트리입니다.

$$\text{균형 인수} = h(\text{왼쪽 서브트리}) - h(\text{오른쪽 서브트리})$$

균형 인수가 -1, 0, 1 중 하나여야 균형 상태입니다.

**회전 종류:**

| 불균형 유형 | 회전 방법 |
| --- | --- |
| LL형 | 오른쪽 단순 회전 |
| RR형 | 왼쪽 단순 회전 |
| LR형 | 왼쪽 후 오른쪽 이중 회전 |
| RL형 | 오른쪽 후 왼쪽 이중 회전 |

AVL 트리는 항상 $O(\log n)$의 탐색/삽입/삭제 시간을 보장합니다.

## BST vs AVL 트리 비교

| 항목 | BST | AVL 트리 |
| --- | --- | --- |
| 탐색 평균 | $O(\log n)$ | $O(\log n)$ |
| 탐색 최악 | $O(n)$ | $O(\log n)$ |
| 삽입 후 균형 | 불보장 | 보장 |
| 구현 복잡도 | 단순 | 복잡 |

## 핵심 정리

- BST: 왼쪽 &lt; 루트 &lt; 오른쪽 성질을 유지하는 이진트리
- 탐색/삽입/삭제 평균: $O(\log n)$, 최악(편향): $O(n)$
- 삭제 시 자식 2개인 경우 중위 후속자로 대체
- AVL 트리: 균형 인수 ±1 유지, 항상 $O(\log n)$ 보장
