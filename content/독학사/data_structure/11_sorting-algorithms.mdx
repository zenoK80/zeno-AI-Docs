## 정렬 알고리즘 개요

**정렬(Sorting)** 은 데이터를 특정 기준(오름차순, 내림차순)에 따라 배열하는 연산입니다.

| 알고리즘 | 최선 | 평균 | 최악 | 공간 | 안정성 |
| --- | --- | --- | --- | --- | --- |
| 버블 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 안정 |
| 선택 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 불안정 |
| 삽입 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 안정 |
| 쉘 | $O(n \log n)$ | $O(n^{1.3})$ | $O(n^2)$ | $O(1)$ | 불안정 |
| 퀵 | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | 불안정 |
| 합병 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | 안정 |
| 힙 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 불안정 |
| 기수 | $O(nk)$ | $O(nk)$ | $O(nk)$ | $O(n+k)$ | 안정 |

## 버블 정렬 (Bubble Sort)

인접한 두 원소를 비교하여 순서가 맞지 않으면 교환합니다. 가장 큰 원소가 매 패스마다 끝으로 이동합니다.

```
[5, 3, 8, 1]
1패스: [3, 5, 1, 8]  → 8 위치 확정
2패스: [3, 1, 5, 8]  → 5 위치 확정
3패스: [1, 3, 5, 8]  → 완료
```

이미 정렬된 경우(최선) $O(n)$ 달성 가능 (개선 버블 정렬).

## 선택 정렬 (Selection Sort)

매 패스마다 최솟값을 찾아 맨 앞 원소와 교환합니다.

```
[5, 3, 8, 1]
1패스: 최솟값 1 찾아 5와 교환 → [1, 3, 8, 5]
2패스: 최솟값 3(제자리) → [1, 3, 8, 5]
3패스: 최솟값 5 찾아 8과 교환 → [1, 3, 5, 8]
```

## 삽입 정렬 (Insertion Sort)

현재 원소를 앞의 정렬된 부분에 올바른 위치로 삽입합니다.

```
[5, 3, 8, 1]
i=1: 3을 5 앞에 삽입 → [3, 5, 8, 1]
i=2: 8은 제자리 → [3, 5, 8, 1]
i=3: 1을 맨 앞에 삽입 → [1, 3, 5, 8]
```

거의 정렬된 데이터에 효율적 (최선 $O(n)$).

## 퀵 정렬 (Quick Sort)

피벗(pivot)을 선택하여 피벗보다 작은 원소는 왼쪽, 큰 원소는 오른쪽으로 분할하고 재귀 정렬합니다.

- 평균 $O(n \log n)$으로 실제 가장 빠른 정렬
- 최악(이미 정렬된 경우): $O(n^2)$
- 불안정 정렬

## 합병 정렬 (Merge Sort)

배열을 반으로 나누어 각각 정렬한 후 합병합니다. 분할 정복 기법.

- 항상 $O(n \log n)$ 보장 (안정 정렬)
- 추가 메모리 $O(n)$ 필요

## 기수 정렬 (Radix Sort)

비교 없이 자릿수별로 정렬합니다. 자릿수 $k$가 작으면 $O(n)$에 가까운 성능.

## 핵심 정리

- 버블, 선택, 삽입 정렬: $O(n^2)$, 구현 간단
- 퀵, 합병, 힙 정렬: $O(n \log n)$
- 합병 정렬: 안정적, 추가 메모리 필요
- 퀵 정렬: 실제로 가장 빠르나 최악 $O(n^2)$
- 기수 정렬: 비교 기반이 아님, 특수 조건에서 빠름
