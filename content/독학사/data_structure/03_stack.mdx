## 왜 스택이 필요한가?

"Ctrl+Z(실행 취소)"를 사용해 본 적 있나요? 가장 최근에 한 작업부터 순서대로 되돌려집니다. 가장 나중에 한 것이 가장 먼저 취소되죠. 이런 "나중에 넣은 것이 먼저 나오는" 구조가 필요할 때 **스택**(Stack, 스택)을 사용합니다.

생활 비유: **접시 쌓기**를 떠올려 보세요. 접시를 아래부터 차례로 쌓고, 꺼낼 때는 항상 맨 위에서 꺼냅니다. 맨 처음 쌓은 접시는 맨 나중에 꺼낼 수 있습니다.

## 스택의 개념

**스택**(Stack)은 데이터를 한쪽 끝(top, 탑)에서만 삽입하고 삭제하는 선형 자료구조입니다.

가장 나중에 삽입된 데이터가 가장 먼저 삭제되므로 **LIFO**(Last In, First Out, 라이포)라고 합니다.

- **LIFO** = Last(마지막) + In(들어온) + First(먼저) + Out(나간다)
- 쉽게 말하면: 마지막에 들어온 것이 제일 먼저 나간다

**top**(탑)이란 스택에서 가장 위쪽(마지막으로 삽입된 원소)을 가리키는 포인터입니다.

## 스택의 주요 연산

| 연산 | 설명 | 시간 복잡도 |
| --- | --- | --- |
| push(x) | top에 원소 x 삽입 | $O(1)$ |
| pop() | top의 원소 삭제 및 반환 | $O(1)$ |
| peek() | top의 원소 조회(삭제 없음) | $O(1)$ |
| isEmpty() | 스택이 비어있는지 확인 | $O(1)$ |

모든 연산이 $O(1)$인 이유: 항상 맨 위(top)에서만 작업하기 때문입니다.

### 오류 상황

**오버플로(Overflow, 오버플로):** 스택이 가득 찬 상태에서 push 시도 시 발생
- "넘쳐흐른다"는 뜻. 더 이상 담을 공간이 없는데 추가하려 할 때

**언더플로(Underflow, 언더플로):** 스택이 비어있는 상태에서 pop 시도 시 발생
- "바닥이 난다"는 뜻. 꺼낼 것이 없는데 꺼내려 할 때

## push/pop 동작 예시

초기 스택: 비어있음 (top = -1)

```
push(A) → [A]         top=0
push(B) → [A, B]      top=1
push(C) → [A, B, C]   top=2
pop()   → C 반환, [A, B]  top=1
pop()   → B 반환, [A]     top=0
```

top이 -1이면 스택이 비어있다는 뜻입니다.

## 수식 표기법

우리가 수학에서 쓰는 `A + B`처럼 연산자가 두 숫자 사이에 오는 표기법을 **중위**(Infix, 인픽스) 표기법이라고 합니다. 컴퓨터는 이 방식을 직접 처리하기 어려워서 **후위**(Postfix, 포스트픽스) 표기법으로 변환합니다.

| 표기법 | 연산자 위치 | 예시 (A+B) |
| --- | --- | --- |
| 중위(Infix) | 피연산자 사이 | A+B |
| 전위(Prefix) | 피연산자 앞 | +AB |
| 후위(Postfix) | 피연산자 뒤 | AB+ |

- **피연산자**(Operand, 오퍼랜드): 연산의 대상 (A, B, 숫자 등)
- **연산자**(Operator, 오퍼레이터): 연산 기호 (+, -, *, /)

컴퓨터가 **후위 표기식**을 선호하는 이유:
1. 괄호가 필요 없습니다.
2. 연산자 우선순위를 자동으로 반영합니다.
3. 스택으로 쉽게 계산할 수 있습니다.

## 중위를 후위로 변환 (스택 이용)

연산자 우선순위: `*`, `/` (높음) 가 `+`, `-` (낮음) 보다 먼저 계산됩니다.

**알고리즘 규칙:**
1. 피연산자(숫자, 변수)는 바로 출력
2. `(`(여는 괄호)는 스택에 push
3. `)`(닫는 괄호)는 스택에서 `(`가 나올 때까지 pop하여 출력
4. 연산자는 스택 top보다 우선순위가 낮거나 같으면 pop 후 push

**예시:** `A+B*C` → 후위 변환

| 읽은 문자 | 스택 상태 | 출력 |
| --- | --- | --- |
| A | (비어있음) | A |
| + | + | A |
| B | + | A B |
| * | + * | A B |
| C | + * | A B C |
| (끝) | (비어있음) | A B C * + |

결과: `ABC*+`

해석: B와 C를 먼저 곱하고(`BC*`), 그 결과를 A와 더합니다(`+`). 곱셈의 우선순위가 높기 때문입니다.

## 후위 표기식 계산

후위 표기식 `5 3 2 * +`을 스택으로 계산합니다.

```
5 읽기 → push(5) → [5]
3 읽기 → push(3) → [5, 3]
2 읽기 → push(2) → [5, 3, 2]
* 읽기 → pop 2개(2, 3), 3*2=6, push(6) → [5, 6]
+ 읽기 → pop 2개(6, 5), 5+6=11, push(11) → [11]
결과: 11
```

규칙: 연산자를 만나면 스택에서 숫자 2개를 꺼내 계산하고 결과를 다시 넣습니다.

## 스택의 실생활 응용

스택이 쓰이는 곳을 살펴보면 스택의 특성을 더 잘 이해할 수 있습니다.

| 응용 | 설명 |
| --- | --- |
| 함수 호출 스택(Call Stack) | 함수가 호출될 때 복귀 주소를 저장, 함수 종료 후 되돌아감 |
| 괄호 검사 | 여는 괄호를 push, 닫는 괄호를 만나면 pop하여 짝 확인 |
| 뒤로 가기(웹 브라우저) | 방문한 페이지를 스택에 쌓고, 뒤로 가기 시 pop |
| 실행 취소(Undo) | 작업 기록을 스택에 저장, Ctrl+Z 시 pop |
| 미로 탐색 | 지나온 경로를 스택에 저장, 막히면 되돌아감 |

## 핵심 정리

- **스택**은 LIFO(Last In, First Out) 구조입니다.
- push/pop 연산은 모두 $O(1)$입니다.
- 빈 스택에서 pop하면 **언더플로**, 가득 찬 스택에 push하면 **오버플로**가 발생합니다.
- **중위 표기식** → **후위 표기식** 변환 시 연산자 우선순위를 스택으로 관리합니다.
- 후위 표기식 계산도 스택을 이용합니다.
