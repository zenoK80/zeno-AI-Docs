## 스택의 개념

**스택(Stack)** 은 데이터를 한쪽 끝(top)에서만 삽입하고 삭제하는 선형 자료구조입니다. 가장 나중에 삽입된 데이터가 가장 먼저 삭제되므로 **LIFO(Last In, First Out)** 라고 합니다.

접시를 쌓아두는 모습을 떠올리면 됩니다. 새 접시는 맨 위에 올리고, 꺼낼 때도 맨 위에서 꺼냅니다.

## 스택의 주요 연산

| 연산 | 설명 | 시간 복잡도 |
| --- | --- | --- |
| push(x) | top에 원소 x 삽입 | $O(1)$ |
| pop() | top의 원소 삭제 및 반환 | $O(1)$ |
| peek() | top의 원소 조회(삭제 없음) | $O(1)$ |
| isEmpty() | 스택이 비어있는지 확인 | $O(1)$ |

**오버플로(Overflow):** 스택이 가득 찬 상태에서 push 시도 시 발생

**언더플로(Underflow):** 스택이 비어있는 상태에서 pop 시도 시 발생

## push/pop 동작 예시

초기 스택: 비어있음 (top = -1)

```
push(A) → [A]         top=0
push(B) → [A, B]      top=1
push(C) → [A, B, C]   top=2
pop()   → C 반환, [A, B]  top=1
pop()   → B 반환, [A]     top=0
```

## 수식 표기법

| 표기법 | 설명 | 예시 (A+B) |
| --- | --- | --- |
| 중위(Infix) | 연산자가 피연산자 사이 | A+B |
| 전위(Prefix) | 연산자가 피연산자 앞 | +AB |
| 후위(Postfix) | 연산자가 피연산자 뒤 | AB+ |

컴퓨터는 **후위 표기식**으로 수식을 처리합니다. 괄호가 필요 없고 연산자 우선순위를 자동으로 반영합니다.

## 중위를 후위로 변환 (스택 이용)

연산자 우선순위: `*`, `/` (높음) &gt; `+`, `-` (낮음) &gt; `(` (괄호)

**알고리즘:**
1. 피연산자(숫자, 변수)는 바로 출력
2. `(`는 스택에 push
3. `)`는 스택에서 `(`가 나올 때까지 pop하여 출력
4. 연산자는 스택 top보다 우선순위가 낮거나 같으면 pop 후 push

**예시:** `A+B*C` → 후위 변환

| 읽은 문자 | 스택 상태 | 출력 |
| --- | --- | --- |
| A | (비어있음) | A |
| + | + | A |
| B | + | A B |
| * | + * | A B |
| C | + * | A B C |
| (끝) | (비어있음) | A B C * + |

결과: `ABC*+`

## 후위 표기식 계산

후위 표기식 `5 3 2 * +`을 스택으로 계산합니다.

```
5 읽기 → push(5) → [5]
3 읽기 → push(3) → [5, 3]
2 읽기 → push(2) → [5, 3, 2]
* 읽기 → pop 2개(3, 2), 3*2=6, push(6) → [5, 6]
+ 읽기 → pop 2개(5, 6), 5+6=11, push(11) → [11]
결과: 11
```

## 스택의 응용

- 함수 호출 시 복귀 주소 저장 (Call Stack)
- 괄호 검사
- 웹 브라우저의 뒤로 가기
- 되돌리기(Undo) 기능
- 미로 탐색

## 핵심 정리

- 스택은 LIFO(Last In, First Out) 구조입니다.
- push/pop 연산은 모두 $O(1)$입니다.
- 빈 스택에서 pop하면 언더플로, 가득 찬 스택에 push하면 오버플로가 발생합니다.
- 중위 → 후위 변환 시 연산자 우선순위를 스택으로 관리합니다.
