## 그래프의 개념

**그래프(Graph)** 는 정점(Vertex, V)과 간선(Edge, E)의 집합으로 정의됩니다. $G = (V, E)$

| 용어 | 설명 |
| --- | --- |
| 정점(Vertex) | 노드, 데이터를 저장하는 기본 단위 |
| 간선(Edge) | 정점 간의 연결 |
| 인접(Adjacent) | 간선으로 연결된 정점들의 관계 |
| 차수(Degree) | 정점에 연결된 간선의 수 |
| 경로(Path) | 정점에서 다른 정점으로 이어지는 정점들의 순서열 |

## 그래프의 종류

| 종류 | 설명 |
| --- | --- |
| 방향 그래프(Directed) | 간선에 방향이 있음 |
| 무방향 그래프(Undirected) | 간선에 방향이 없음 |
| 가중치 그래프(Weighted) | 간선에 가중치(비용)가 있음 |
| 완전 그래프(Complete) | 모든 정점 쌍이 간선으로 연결됨 |

## 그래프의 표현 방법

### 인접 행렬 (Adjacency Matrix)

정점 수가 $n$인 그래프를 $n \times n$ 행렬로 표현합니다.

- $A[i][j] = 1$: 정점 $i$에서 $j$로 간선이 존재
- $A[i][j] = 0$: 간선 없음

| 특성 | 내용 |
| --- | --- |
| 공간 복잡도 | $O(n^2)$ |
| 간선 확인 | $O(1)$ |
| 단점 | 간선이 적을 때 메모리 낭비 |

### 인접 리스트 (Adjacency List)

각 정점마다 연결된 정점들을 연결 리스트로 저장합니다.

| 특성 | 내용 |
| --- | --- |
| 공간 복잡도 | $O(n + e)$ (e: 간선 수) |
| 간선 확인 | $O(n)$ |
| 장점 | 희소 그래프에 효율적 |

## 깊이 우선 탐색 (DFS)

**DFS(Depth First Search)** 는 한 방향으로 끝까지 탐색한 후 되돌아오는 방법입니다. **스택** 또는 **재귀**로 구현합니다.

예시 그래프 (1-2, 1-3, 2-4, 2-5, 3-6 연결):

```
DFS(1): 1 → 2 → 4 → 5 → 3 → 6
```

시간 복잡도: 인접 행렬 $O(n^2)$, 인접 리스트 $O(n+e)$

## 너비 우선 탐색 (BFS)

**BFS(Breadth First Search)** 는 시작 정점에서 가까운 정점부터 단계적으로 탐색합니다. **큐**로 구현합니다.

```
BFS(1): 1 → 2 → 3 → 4 → 5 → 6
```

| 항목 | DFS | BFS |
| --- | --- | --- |
| 자료구조 | 스택/재귀 | 큐 |
| 탐색 방식 | 깊이 우선 | 너비 우선 |
| 최단 경로 | 보장 안 됨 | 보장 (가중치 없는 그래프) |
| 시간 복잡도 | $O(n+e)$ | $O(n+e)$ |

## 신장 트리 (Spanning Tree)

**신장 트리**는 그래프의 모든 정점을 포함하고 사이클이 없는 부분 그래프입니다. $n$개의 정점을 가지면 $n-1$개의 간선이 있습니다.

**최소 비용 신장 트리(MST):** 모든 간선 비용의 합이 최소인 신장 트리

## 핵심 정리

- 그래프 $G = (V, E)$: 정점 집합 V, 간선 집합 E
- 인접 행렬: $O(n^2)$ 공간, 간선 확인 $O(1)$
- 인접 리스트: $O(n+e)$ 공간, 희소 그래프에 효율적
- DFS: 스택/재귀, 깊이 우선 탐색
- BFS: 큐 사용, 최단 경로 탐색(비가중치 그래프)
