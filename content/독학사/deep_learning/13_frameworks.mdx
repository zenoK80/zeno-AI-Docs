## 딥러닝 프레임워크

딥러닝 프레임워크는 신경망을 쉽게 구성하고 학습시킬 수 있는 도구입니다.

- GPU 연산을 자동으로 활용
- 자동 미분(Automatic Differentiation)으로 역전파 자동 계산
- 다양한 최적화 알고리즘 제공

## PyTorch

**PyTorch**는 Facebook(Meta)이 개발한 딥러닝 프레임워크입니다. 연구자 사이에서 널리 사용됩니다.

### 핵심 개념

- **Tensor:** PyTorch의 기본 데이터 구조 (NumPy 배열과 유사, GPU 지원)
- **Autograd:** 자동 미분 엔진, 순전파 기록 후 역전파 자동 계산
- **동적 계산 그래프(Dynamic Computation Graph):** 실행 중 그래프가 구성됨

### PyTorch 기본 워크플로우

```python
import torch
import torch.nn as nn

# 1. 모델 정의
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 10)
    
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        return self.fc2(x)

# 2. 모델 생성 및 옵티마이저
model = SimpleNet()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

# 3. 학습 루프
for epoch in range(10):
    optimizer.zero_grad()      # 기울기 초기화

    loss = criterion(output, labels)
    loss.backward()            # 역전파
    optimizer.step()           # 가중치 업데이트
```

## TensorFlow / Keras

**TensorFlow**는 Google이 개발한 딥러닝 프레임워크입니다. **Keras**는 TensorFlow의 고수준 API입니다.

### 핵심 개념

- **정적 계산 그래프(Static Computation Graph):** TF 1.x (그래프 사전 정의 후 실행)
- **즉시 실행(Eager Execution):** TF 2.x (PyTorch처럼 동적 실행)
- **Keras:** 직관적이고 간결한 모델 구성 API

### Keras 기본 워크플로우

```python
import tensorflow as tf

# 1. 모델 정의
model = tf.keras.Sequential([
    tf.keras.layers.Dense(128, activation='relu', input_shape=(784,)),
    tf.keras.layers.Dense(10, activation='softmax')
])

# 2. 모델 컴파일
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# 3. 학습
model.fit(x_train, y_train, epochs=10, batch_size=32)

# 4. 평가
model.evaluate(x_test, y_test)
```

## PyTorch vs TensorFlow 비교

| 특성 | PyTorch | TensorFlow/Keras |
|------|---------|-----------------|
| 개발사 | Meta(Facebook) | Google |
| 계산 그래프 | 동적(Dynamic) | TF2: 동적, TF1: 정적 |
| API 스타일 | Pythonic, 유연 | Keras: 고수준, 간결 |
| 주요 사용처 | 연구, 학술 | 산업, 배포 |
| 디버깅 | 용이 (Python 디버거) | TF2 이후 개선 |
| 배포 | TorchServe | TensorFlow Serving, TFLite |

## 텐서 연산

두 프레임워크 모두 텐서(다차원 배열) 기반으로 동작합니다.

```python
# PyTorch
import torch
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
y = torch.zeros(2, 3)  # 2x3 영행렬
z = x @ x.T            # 행렬 곱셈

# TensorFlow
import tensorflow as tf
x = tf.constant([[1.0, 2.0], [3.0, 4.0]])
y = tf.zeros([2, 3])
z = tf.matmul(x, tf.transpose(x))
```

## 자동 미분 (Autograd)

```python
# PyTorch 자동 미분
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2 + 3 * x
y.backward()
print(x.grad)  # dy/dx = 2x + 3 = 7

# TensorFlow 자동 미분
x = tf.Variable(2.0)
with tf.GradientTape() as tape:
    y = x ** 2 + 3 * x
grad = tape.gradient(y, x)
print(grad.numpy())  # 7.0
```

## 핵심 정리

- PyTorch: Meta 개발, 동적 계산 그래프, 연구 친화적
- TensorFlow/Keras: Google 개발, 산업 배포에 강점
- 자동 미분: 역전파를 자동으로 계산
- 텐서: 두 프레임워크의 기본 데이터 구조, GPU 연산 지원
- Keras: TensorFlow의 고수준 API, 간결한 모델 정의
