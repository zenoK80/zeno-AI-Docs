## 생성 모델이란?

**생성 모델**(Generative Model)은 학습 데이터의 분포를 학습하여 새로운 유사한 데이터를 생성하는 모델입니다.

- 판별 모델(Discriminative Model): 입력 x가 주어졌을 때 클래스 y를 예측 (분류)
- 생성 모델(Generative Model): 실제 데이터와 유사한 새 데이터를 생성

**활용 분야:** 이미지 생성, 음악 생성, 텍스트 생성, 데이터 증강, 이상 탐지

## GAN (Generative Adversarial Network)

**GAN**은 2014년 Ian Goodfellow가 제안한 생성 모델입니다. **생성자**(Generator)와 **판별자**(Discriminator)가 경쟁하며 학습합니다.

### GAN 구조

```
[노이즈 z] → [생성자 G] → [가짜 이미지]
                                ↓
[진짜 이미지] ──────────→ [판별자 D] → 진짜/가짜 판별
```

- **생성자(G):** 랜덤 노이즈에서 실제 같은 데이터 생성, 판별자를 속이려 함
- **판별자(D):** 진짜와 가짜를 구분, 생성자에게 속지 않으려 함

### GAN 목적 함수

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

- 판별자: $D(x)$를 최대화 (진짜를 진짜로), $D(G(z))$를 최소화 (가짜를 가짜로)
- 생성자: $D(G(z))$를 최대화 (가짜를 진짜처럼)

### GAN의 문제점

- **모드 붕괴(Mode Collapse):** 생성자가 다양한 데이터 대신 몇 가지 패턴만 반복 생성
- **학습 불안정:** 생성자와 판별자의 균형이 맞지 않으면 학습이 발산

### GAN 변형

| 변형 | 특징 |
|------|------|
| **DCGAN** | 합성곱 신경망 기반 GAN |
| **CycleGAN** | 짝 없는 이미지 간 변환 (말 ↔ 얼룩말) |
| **StyleGAN** | 고해상도 얼굴 이미지 생성 |
| **Conditional GAN** | 조건 정보로 원하는 종류 생성 |

## VAE (Variational Autoencoder)

**VAE**는 오토인코더의 변형으로, 잠재 공간(Latent Space)에서 연속적인 분포를 학습하여 새로운 데이터를 생성합니다.

### 오토인코더(Autoencoder) 기본

```
입력 x → [인코더 E] → 잠재 벡터 z → [디코더 D] → 복원 x'
```

- 인코더: 입력을 압축된 잠재 벡터로 변환
- 디코더: 잠재 벡터를 원래 입력으로 복원

### VAE 구조

```
입력 x → [인코더] → μ (평균), σ² (분산)
                    ↓ 재매개변수화(Reparameterization)
                 z = μ + σ × ε  (ε: 표준 정규 노이즈)
                    ↓
              [디코더] → 복원 x'
```

### VAE 손실 함수

$$L_{VAE} = L_{재구성} + L_{KL}$$

$$= -\mathbb{E}_{z \sim q_\phi(z|x)}[\log p_\theta(x|z)] + D_{KL}(q_\phi(z|x) \| p(z))$$

- **재구성 손실:** 복원된 데이터가 원본과 얼마나 유사한지
- **KL 발산 손실:** 잠재 분포가 표준 정규 분포에 얼마나 가까운지

### GAN vs VAE 비교

| 특성 | GAN | VAE |
|------|-----|-----|
| 학습 방식 | 적대적 게임 | 변분 추론 |
| 출력 품질 | 매우 선명 | 약간 흐릿할 수 있음 |
| 잠재 공간 | 명시적이지 않음 | 연속적, 구조화됨 |
| 학습 안정성 | 불안정 | 상대적으로 안정적 |
| 응용 | 사실적 이미지 생성 | 잠재 공간 보간, 이상 탐지 |

## 핵심 정리

- 생성 모델: 데이터 분포 학습 후 새 데이터 생성
- GAN: 생성자(G)와 판별자(D)의 적대적 학습, min-max 게임
- GAN 문제: 모드 붕괴, 학습 불안정
- VAE: 잠재 변수의 확률 분포 학습, 재매개변수화 트릭
- VAE 손실: 재구성 손실 + KL 발산 손실
