## 대표 CNN 아키텍처 발전

| 연도 | 모델 | ImageNet 오류율 | 핵심 아이디어 |
|------|------|---------------|------------|
| 1998 | LeNet | — | 최초 실용 CNN |
| 2012 | AlexNet | 15.3% | 딥러닝 붐 촉발, ReLU, 드롭아웃 |
| 2014 | VGGNet | 6.7% | 3×3 필터로 깊은 네트워크 |
| 2014 | GoogLeNet | 6.7% | Inception 모듈, 1×1 합성곱 |
| 2015 | ResNet | 3.57% | 잔차 연결(Residual Connection) |
| 2017 | DenseNet | — | 모든 층 직접 연결 |

## LeNet

LeCun(1998)이 개발한 최초의 실용적 CNN으로, 손글씨 숫자(MNIST) 인식에 사용되었습니다.

구조: Conv → Pooling → Conv → Pooling → FC → FC → 출력

## AlexNet (2012)

- 8층 구조 (5 Conv + 3 FC)
- ReLU 활성화 함수 도입
- 드롭아웃으로 과적합 방지
- 데이터 증강 활용
- GPU 병렬 학습

## VGGNet (2014)

**핵심 아이디어:** 3×3 소형 필터만 사용하여 깊이를 늘립니다.

- VGG-16: 16층, VGG-19: 19층
- 3×3 필터를 2~3개 겹치면 5×5, 7×7 필터와 같은 수용 영역(Receptive Field)을 가지면서 매개변수는 적음
- 단순하고 규칙적인 구조 → 전이학습에 많이 사용

**3×3 필터 2개 vs 5×5 필터 1개:**

- 3×3 두 개의 매개변수: $2 \times 3^2 = 18$
- 5×5 하나의 매개변수: $5^2 = 25$
- 3×3 두 개가 매개변수도 적고 비선형성도 더 많이 추가

## GoogLeNet / Inception (2014)

**Inception 모듈:** 1×1, 3×3, 5×5 합성곱과 Max Pooling을 병렬로 적용한 후 채널 방향으로 연결(Concatenation)합니다.

```
입력
├── 1×1 Conv
├── 1×1 Conv → 3×3 Conv
├── 1×1 Conv → 5×5 Conv
└── 3×3 MaxPool → 1×1 Conv
→ Concatenation (채널 방향으로 합치기)
```

**1×1 합성곱의 역할:**
- 채널 수를 줄여 계산량 감소 (병목 구조, Bottleneck)
- 비선형성 추가

## ResNet (2015)

**핵심 아이디어: 잔차 연결**(Residual Connection, Skip Connection)

기존 신경망은 층이 깊어질수록 학습이 어려워지는 퇴화(Degradation) 문제가 발생합니다. ResNet은 이를 해결합니다.

```
기존 신경망:      x → [Conv-BN-ReLU] → H(x)
ResNet 잔차 블록: x → [Conv-BN-ReLU] → F(x)
                  x ────────────────→ x (Skip)
                  출력: F(x) + x
```

잔차 블록은 $H(x) = F(x) + x$를 학습합니다. 즉, $F(x) = H(x) - x$, 잔차(Residual)를 학습합니다.

**장점:**
- 기울기가 잔차 연결을 통해 직접 흐름 → 기울기 소실 문제 해결
- 수백 층 이상의 매우 깊은 네트워크 학습 가능
- ResNet-50, ResNet-101, ResNet-152 등 다양한 변형

## 핵심 정리

- VGGNet: 3×3 소형 필터만 사용, 깊은 네트워크
- Inception: 여러 크기의 필터 병렬 적용, 1×1 합성곱으로 계산량 감소
- ResNet: 잔차 연결(Skip Connection)으로 기울기 소실 문제 해결
- 1×1 합성곱: 채널 수 조절(병목 구조) 및 비선형성 추가
