## 전이학습이란?

**전이학습(Transfer Learning)**은 하나의 문제를 해결하기 위해 학습된 모델의 지식을 다른 관련 문제에 활용하는 기법입니다.

**필요한 이유:**
- 대규모 딥러닝 모델을 처음부터 학습하려면 막대한 데이터와 시간이 필요
- 데이터가 부족한 도메인에서도 좋은 성능 달성
- 이미 일반적인 패턴(엣지, 질감, 모양 등)을 학습한 모델 재활용

**사전학습 모델(Pretrained Model):** ImageNet(120만 장), 대규모 텍스트 등으로 미리 학습된 모델

## 전이학습 전략

### 1. 특징 추출 (Feature Extraction)

사전학습 모델의 가중치를 고정(Freeze)하고, 마지막 분류 층만 새로 학습합니다.

```
[사전학습 모델]           [새 분류층]
Conv1 → Conv2 → ... → FC → [새 FC] → 출력
 (고정: 학습 X)              (학습 O)
```

- 적합한 경우: 데이터가 매우 적을 때, 타겟 도메인이 소스 도메인과 유사할 때

### 2. 파인튜닝 (Fine-tuning)

사전학습 모델의 일부 또는 전체 층을 새 데이터로 재학습합니다.

```
[사전학습 모델]           [새 분류층]
Conv1 (고정) → Conv2~N (재학습) → [새 FC] → 출력
```

- 적합한 경우: 중간 이상의 데이터가 있을 때
- 초기 층(일반적 특징)은 고정, 깊은 층(도메인 특징)은 재학습
- 사전학습 모델의 학습률보다 **낮은 학습률** 사용 권장

### 전략 선택 기준

| 데이터 양 | 도메인 유사도 | 권장 전략 |
|---------|------------|---------|
| 적음 | 높음 | 특징 추출 |
| 적음 | 낮음 | 파인튜닝 (주의 필요) |
| 많음 | 높음 | 파인튜닝 |
| 많음 | 낮음 | 처음부터 학습 or 전체 파인튜닝 |

## 도메인 적응 (Domain Adaptation)

소스 도메인과 타겟 도메인 간의 분포 차이를 줄이는 전이학습의 특수 형태입니다.

- 예: 낮 사진으로 학습한 모델을 밤 사진에 적용
- 도메인 불변 특징을 학습하도록 모델을 수정

## 자연어 처리에서의 전이학습

| 모델 | 사전학습 방식 | 파인튜닝 적용 |
|------|-----------|------------|
| **BERT** | 마스크 언어 모델, 다음 문장 예측 | 텍스트 분류, QA, 개체명 인식 |
| **GPT** | 자기회귀 언어 모델 | 텍스트 생성, 요약 |
| **RoBERTa** | 개선된 BERT 학습 | BERT와 동일한 다운스트림 작업 |

## 핵심 정리

- 전이학습: 사전학습 모델의 지식을 새 작업에 재활용
- 특징 추출: 사전학습 가중치 고정, 새 분류층만 학습
- 파인튜닝: 사전학습 모델 일부/전체를 새 데이터로 재학습
- 데이터가 적고 도메인 유사 → 특징 추출, 데이터 충분 → 파인튜닝
- BERT, GPT 등 대규모 사전학습 모델이 NLP 전이학습의 핵심
