## LSTM (Long Short-Term Memory)

**LSTM**은 1997년 Hochreiter와 Schmidhuber가 제안한 RNN의 개선 모델입니다. **셀 상태**(Cell State)와 세 가지 **게이트**(Gate) 구조로 장기 의존성 문제를 해결합니다.

### LSTM의 핵심 구성요소

| 구성요소 | 역할 |
|---------|------|
| **셀 상태**(Cell State, C_t) | 장기 기억을 저장하는 컨베이어 벨트 |
| **망각 게이트**(Forget Gate) | 이전 셀 상태에서 어떤 정보를 버릴지 결정 |
| **입력 게이트**(Input Gate) | 새로운 정보 중 어떤 것을 셀 상태에 추가할지 결정 |
| **출력 게이트**(Output Gate) | 셀 상태에서 어떤 정보를 출력(은닉 상태)으로 내보낼지 결정 |

### LSTM 수식

**1. 망각 게이트(Forget Gate):**
$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$
- 0에 가까울수록 이전 기억을 잊음, 1에 가까울수록 기억 유지

**2. 입력 게이트(Input Gate):**
$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$
$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$
- 새 정보 중 얼마나 추가할지 결정

**3. 셀 상태 업데이트:**
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
- 이전 셀 상태를 얼마나 유지하고($f_t$) 새 정보를 얼마나 추가할지($i_t$)

**4. 출력 게이트(Output Gate):**
$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$
$$h_t = o_t \odot \tanh(C_t)$$

## GRU (Gated Recurrent Unit)

**GRU**는 2014년 Cho 등이 제안한 LSTM의 경량화 버전입니다. 셀 상태 없이 두 개의 게이트로 구성됩니다.

| 구성요소 | 역할 |
|---------|------|
| **업데이트 게이트**(Update Gate, z_t) | LSTM의 망각+입력 게이트를 통합 |
| **리셋 게이트**(Reset Gate, r_t) | 이전 은닉 상태를 얼마나 무시할지 |

### GRU 수식

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t])$$
$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t])$$
$$\tilde{h}_t = \tanh(W \cdot [r_t \odot h_{t-1}, x_t])$$
$$h_t = (1-z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

## RNN / LSTM / GRU 비교

| 특성 | RNN | LSTM | GRU |
|------|-----|------|-----|
| 구조 복잡도 | 단순 | 복잡 | 중간 |
| 게이트 수 | 없음 | 3개 | 2개 |
| 셀 상태 | 없음 | 있음 | 없음 |
| 장기 의존성 | 약함 | 강함 | 강함 |
| 계산 비용 | 낮음 | 높음 | 중간 |
| 매개변수 수 | 적음 | 많음 | 중간 |

## 핵심 정리

- LSTM: 셀 상태 + 망각/입력/출력 게이트, 장기 기억 관리
- 망각 게이트: 이전 기억 중 버릴 것 결정
- 입력 게이트: 새 정보 중 추가할 것 결정
- 출력 게이트: 현재 은닉 상태로 내보낼 정보 결정
- GRU: LSTM 경량화, 업데이트+리셋 게이트, 셀 상태 없음
