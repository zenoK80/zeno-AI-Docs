## 신경망 학습의 목표

신경망 학습은 **손실 함수(Loss Function)**의 값을 최소화하는 가중치를 찾는 최적화 문제입니다.

$$L = \text{Loss}(\hat{y}, y)$$

- $\hat{y}$: 신경망의 예측값
- $y$: 실제 정답값

## 경사하강법 (Gradient Descent)

손실 함수를 최소화하기 위해 기울기(Gradient)의 반대 방향으로 가중치를 업데이트합니다.

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

- $\eta$ (learning rate): 학습률, 업데이트 보폭 크기
- $\frac{\partial L}{\partial w}$: 가중치 w에 대한 손실의 편미분(기울기)

학습률이 너무 크면 최솟값을 지나치고, 너무 작으면 학습이 느립니다.

## 체인 룰 (Chain Rule)

역전파는 **합성 함수의 미분(체인 룰)**을 이용합니다.

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}$$

- $z = wx + b$ (가중 합)
- $a = f(z)$ (활성화 함수 적용)
- $L$ (손실 함수)

각 층의 기울기를 출력층부터 입력층 방향으로 순서대로 계산합니다.

## 역전파 동작 과정

```
순전파(Forward Pass):
입력 x → [층1] → [층2] → ... → 출력 ŷ → 손실 L 계산

역전파(Backward Pass):
손실 L → ∂L/∂w(출력층) → ∂L/∂w(층2) → ∂L/∂w(층1)
(체인 룰로 각 층의 기울기 계산)

가중치 업데이트:
w ← w - η × ∂L/∂w
```

## 계산 그래프

복잡한 신경망의 역전파를 이해하기 위해 **계산 그래프(Computational Graph)**를 사용합니다.

- 순전파: 입력에서 출력 방향으로 계산
- 역전파: 기울기를 출력에서 입력 방향으로 전파

예시: $z = x \times w + b$의 계산 그래프

```
x ─┐
   × ─── + ─── z ─── f ─── a
w ─┘         b
```

역전파 시 각 노드는 "국소 기울기(Local Gradient)"를 계산하고, 상위에서 전달받은 기울기를 곱하여 하위로 전달합니다.

## 손실 함수

| 손실 함수 | 수식 | 사용 |
|---------|------|------|
| **MSE(평균 제곱 오차)** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 회귀 |
| **Binary Cross-Entropy** | $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | 이진 분류 |
| **Categorical Cross-Entropy** | $-\sum y_i \log\hat{y}_i$ | 다중 분류 |

## 기울기 소실 문제 (Vanishing Gradient)

Sigmoid나 Tanh의 기울기는 입력이 크거나 작을 때 0에 수렴합니다. 역전파 시 이 작은 기울기가 여러 층을 거치며 곱해지면 점점 작아져 앞쪽 층의 가중치가 업데이트되지 않습니다.

**해결책:**
- ReLU 사용 (기울기가 0 또는 1)
- 배치 정규화
- 잔차 연결(ResNet)

## 핵심 정리

- 역전파: 체인 룰로 각 가중치의 기울기 계산
- 경사하강법: 기울기 반대 방향으로 가중치 업데이트
- 손실 함수: 회귀=MSE, 이진 분류=Binary CE, 다중 분류=Categorical CE
- 기울기 소실: Sigmoid/Tanh에서 발생, ReLU로 완화
