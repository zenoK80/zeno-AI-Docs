## 인공지능 · 머신러닝 · 딥러닝의 관계

세 개념은 포함 관계를 이룹니다.

```
인공지능 (Artificial Intelligence)
  └── 머신러닝 (Machine Learning)
        └── 딥러닝 (Deep Learning)
```

- **인공지능(AI):** 사람처럼 사고하고 행동하는 기계를 만드는 분야 전체
- **머신러닝(ML):** 데이터로부터 자동으로 학습하는 알고리즘 연구
- **딥러닝(DL):** 다층 인공 신경망을 이용한 머신러닝의 한 분야

## 머신러닝 vs 딥러닝 비교

| 특성 | 전통적 머신러닝 | 딥러닝 |
|------|--------------|--------|
| 특징 추출 | 사람이 직접 설계(Feature Engineering) | 자동으로 학습 |
| 데이터 양 | 적은 데이터에도 동작 | 대용량 데이터에서 강점 |
| 연산 자원 | 적게 필요 | GPU 등 고성능 필요 |
| 해석 가능성 | 비교적 높음 | 낮음(블랙박스) |
| 대표 알고리즘 | SVM, 결정 트리, 랜덤 포레스트 | CNN, RNN, 트랜스포머 |

## 딥러닝 발전사

| 연도 | 사건 |
|------|------|
| 1943 | McCulloch-Pitts 뉴런 모델 제안 |
| 1958 | Perceptron 발명 (Rosenblatt) |
| 1986 | 역전파 알고리즘 보급 (Rumelhart et al.) |
| 1998 | LeNet: CNN으로 손글씨 인식 (LeCun) |
| 2006 | 딥러닝 재조명 (Hinton, 사전 훈련) |
| 2012 | AlexNet: ImageNet 대회 압도적 우승 |
| 2014 | GAN 발표 (Goodfellow) |
| 2017 | 트랜스포머(Attention Is All You Need) |
| 2018~ | BERT, GPT 시리즈 등 대규모 언어모델 시대 |

## 딥러닝 활용 분야

| 분야 | 예시 |
|------|------|
| 컴퓨터 비전 | 이미지 분류, 객체 탐지, 얼굴 인식 |
| 자연어 처리 | 번역, 요약, 챗봇, 감성 분석 |
| 음성 인식 | 음성-텍스트 변환, 화자 인식 |
| 의료 | 질병 진단, 의료 영상 분석 |
| 자율주행 | 차선 인식, 장애물 탐지 |
| 추천 시스템 | 영화·상품 추천 |
| 생성 | 이미지 생성(GAN), 텍스트 생성(GPT) |

## 딥러닝이 주목받는 이유

1. **빅데이터:** 학습에 필요한 대용량 데이터 확보 용이
2. **GPU 병렬 연산:** 행렬 연산의 고속 병렬 처리
3. **알고리즘 발전:** 역전파, 드롭아웃, 배치정규화 등 개선
4. **오픈소스 프레임워크:** TensorFlow, PyTorch 등 접근성 향상

## 핵심 정리

- AI ⊃ ML ⊃ 딥러닝 (포함 관계)
- 딥러닝: 다층 신경망, 특징 자동 추출, 대용량 데이터·고성능 GPU 필요
- 머신러닝 vs 딥러닝: 특징 엔지니어링 여부가 핵심 차이
- 2012년 AlexNet이 딥러닝 붐을 촉발
