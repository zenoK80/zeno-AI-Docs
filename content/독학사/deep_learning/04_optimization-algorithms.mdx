## 배치 경사하강법의 종류

| 종류 | 데이터 단위 | 특징 |
|------|-----------|------|
| **배치 GD (Batch GD)** | 전체 데이터 | 안정적이나 느림 |
| **확률적 GD (SGD)** | 1개 샘플 | 빠르나 불안정 (잡음) |
| **미니배치 GD (Mini-Batch)** | 소규모 배치 (32~256) | 두 방법의 절충 (실무 주로 사용) |

## SGD (Stochastic Gradient Descent)

$$w \leftarrow w - \eta \nabla L(w)$$

**한계:**
- 학습률 설정이 어려움
- 지역 최솟값(Local Minimum)에 빠질 수 있음
- 기울기 방향이 불안정하여 수렴이 느림

## Momentum

과거 기울기의 방향을 기억하여 진행 방향에 가속도를 부여합니다. 공의 관성처럼 동작합니다.

$$v \leftarrow \beta v - \eta \nabla L(w)$$
$$w \leftarrow w + v$$

- $\beta$: 모멘텀 계수 (보통 0.9)
- 이전 기울기 방향을 누적하여 지역 최솟값 탈출 용이

## AdaGrad

각 매개변수마다 다른 학습률을 적용합니다. 자주 업데이트된 매개변수의 학습률은 작게, 드물게 업데이트된 매개변수의 학습률은 크게 조정합니다.

$$G \leftarrow G + (\nabla L)^2$$
$$w \leftarrow w - \frac{\eta}{\sqrt{G + \epsilon}} \nabla L$$

**한계:** G가 계속 누적되어 학습이 진행될수록 학습률이 0에 수렴 → 학습 중단

## RMSProp

AdaGrad의 누적 문제를 지수 이동 평균으로 해결합니다.

$$G \leftarrow \rho G + (1-\rho)(\nabla L)^2$$
$$w \leftarrow w - \frac{\eta}{\sqrt{G + \epsilon}} \nabla L$$

- $\rho$: 감쇠율 (보통 0.9~0.99)
- 최신 기울기에 더 높은 가중치 부여

## Adam (Adaptive Moment Estimation)

Momentum과 RMSProp을 결합한 알고리즘입니다. 현재 가장 널리 사용되는 최적화 알고리즘입니다.

$$m \leftarrow \beta_1 m + (1-\beta_1)\nabla L \quad \text{(1차 모멘트: 기울기 평균)}$$
$$v \leftarrow \beta_2 v + (1-\beta_2)(\nabla L)^2 \quad \text{(2차 모멘트: 기울기 분산)}$$
$$
\hat{m} = \frac{m}{1-\beta_1^t}, \quad \hat{v} = \frac{v}{1-\beta_2^t}
$$

(편향 보정)
$$w \leftarrow w - \frac{\eta}{\sqrt{\hat{v}} + \epsilon} \hat{m}$$

**주요 하이퍼파라미터:**
- $\beta_1 = 0.9$ (1차 모멘트 감쇠율)
- $\beta_2 = 0.999$ (2차 모멘트 감쇠율)
- $\eta = 0.001$ (학습률)
- $\epsilon = 10^{-8}$ (0 나눗셈 방지)

## 최적화 알고리즘 비교

| 알고리즘 | 학습률 적응 | 모멘텀 | 특징 |
|---------|-----------|--------|------|
| SGD | 없음 | 없음 | 단순, 불안정 |
| SGD + Momentum | 없음 | 있음 | SGD 개선 |
| AdaGrad | 있음 | 없음 | 학습률 소멸 문제 |
| RMSProp | 있음 | 없음 | AdaGrad 개선 |
| Adam | 있음 | 있음 | 실무에서 가장 많이 사용 |

## 핵심 정리

- SGD: 샘플 하나씩 기울기 계산, 불안정
- Momentum: 과거 기울기 방향 누적, 가속도 효과
- AdaGrad: 매개변수별 학습률 적응, 학습률 소멸 문제
- RMSProp: AdaGrad 개선, 지수 이동 평균 사용
- Adam: Momentum + RMSProp, 편향 보정 포함, 가장 널리 사용
