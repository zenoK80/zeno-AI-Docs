## 분류 성능 평가지표 복습

> **쉽게 말하면:** 머신러닝 과목 16번 문서에서 배운 평가지표들이 딥러닝 분류 모델에도 그대로 적용됩니다.

<Table>
  <thead>
    <tr><th>지표</th><th>의미</th></tr>
  </thead>
  <tbody>
    <tr><td>정확도(Accuracy)</td><td>전체 중 맞게 예측한 비율. 클래스가 불균형할 때는 오해를 부를 수 있음</td></tr>
    <tr><td>정밀도(Precision)</td><td>양성이라 예측한 것 중 실제 양성 비율</td></tr>
    <tr><td>재현율(Recall)</td><td>실제 양성 중 모델이 맞게 찾아낸 비율</td></tr>
    <tr><td>F1 Score</td><td>정밀도와 재현율의 조화평균</td></tr>
  </tbody>
</Table>

<Callout type="info">
  **09번 문서와의 연결:** 09번 문서의 손실 함수(Cross Entropy 등)는 "학습 중에 모델을 개선하기 위한" 지표이고, 이 문서의 평가지표(정확도, F1 등)는 "학습이 끝난 뒤 모델의 실제 성능을 사람이 이해하기 쉽게 요약하는" 지표라는 차이가 있습니다. 손실 값이 낮다고 반드시 정확도가 가장 높은 것은 아닐 수 있어, 두 종류의 지표를 함께 확인하는 것이 중요합니다.
</Callout>

## 하이퍼파라미터 튜닝(Hyperparameter Tuning)

> **쉽게 말하면:** 머신러닝 과목에서 배운 것처럼, 하이퍼파라미터는 학습 전에 사람이 정해야 하는 설정값입니다. 딥러닝에서는 특히 조정할 하이퍼파라미터가 많습니다.

<Table>
  <thead>
    <tr><th>하이퍼파라미터</th><th>관련 문서</th></tr>
  </thead>
  <tbody>
    <tr><td>학습률(Learning Rate)</td><td>10번 문서(경사하강법)</td></tr>
    <tr><td>배치 크기(Batch Size)</td><td>11번 문서(SGD)</td></tr>
    <tr><td>은닉층 개수·뉴런 개수</td><td>05·06번 문서(신경망 깊이)</td></tr>
    <tr><td>Dropout 비율</td><td>12번 문서(정규화)</td></tr>
  </tbody>
</Table>

<Callout type="warning">
  **자주 틀리는 점:** 하이퍼파라미터 튜닝을 테스트 데이터로 수행하면 안 됩니다. 04번 문서(머신러닝 과목)에서 배운 것처럼, 테스트 데이터는 모든 튜닝이 끝난 뒤 최종 성능을 딱 한 번 확인하는 용도로만 남겨두어야 하며, 튜닝 과정에는 반드시 별도의 검증 데이터를 사용해야 합니다.
</Callout>

## 전이학습(Transfer Learning)

> **쉽게 말하면:** 전이학습은 이미 대규모 데이터로 학습된 모델(예: ImageNet으로 학습된 CNN)의 지식을 가져와, 내가 가진 적은 데이터의 새로운 문제에 재활용하는 방법입니다.

**20번 문서와의 연결:** LLM의 사전학습→미세조정 흐름이 바로 전이학습의 대표적인 사례입니다. 이미지 분야에서도 같은 원리가 널리 쓰입니다.

**전이학습의 전형적인 방법:**

<Steps>
### 1단계: 사전학습된 모델 가져오기
14번 문서에서 배운 ResNet 등, 대규모 이미지 데이터(ImageNet 등)로 이미 학습된 모델을 가져옵니다.

### 2단계: 앞부분 층은 그대로 유지(고정)
합성곱 층들이 학습한 "모서리 감지", "질감 감지" 같은 저수준 특징은 대부분의 이미지 문제에 공통으로 유용하므로, 이 부분은 그대로 재사용합니다(가중치를 고정해 더 이상 학습하지 않음).

### 3단계: 마지막 출력층만 새로 학습
내가 풀고 싶은 새로운 문제(예: "고양이 품종 10종 분류")에 맞게, 마지막 분류층만 새로 교체하고 내가 가진(비교적 적은) 데이터로 이 부분만 학습시킵니다.
</Steps>

<Callout type="info">
  **왜 전이학습이 효율적인가?** 처음부터 모든 가중치를 학습하려면 방대한 데이터와 컴퓨팅 자원(05번 문서)이 필요합니다. 전이학습은 이미 검증된 저수준 특징 추출 능력을 재사용하고, 데이터가 적은 상황에서도 마지막 층만 학습해 좋은 성능을 빠르게 얻을 수 있게 해줍니다.
</Callout>

## 모델 배포(Deployment)

> **쉽게 말하면:** 모델 배포는 학습이 끝난 모델을, 실제 사용자가 사용하는 서비스(앱, 웹사이트 등)에 연결해 실제로 작동하게 만드는 마지막 단계입니다.

<Table>
  <thead>
    <tr><th>단계</th><th>내용</th></tr>
  </thead>
  <tbody>
    <tr><td>모델 경량화</td><td>실제 서비스 환경(스마트폰 등)에서 빠르게 동작하도록 모델 크기·연산량을 줄임</td></tr>
    <tr><td>서빙(Serving)</td><td>사용자의 요청이 들어오면 모델이 예측을 수행해 결과를 돌려주는 시스템 구축</td></tr>
    <tr><td>모니터링</td><td>배포 후에도 모델의 실제 성능을 지속적으로 관찰</td></tr>
  </tbody>
</Table>

<Callout type="warning">
  **배포는 끝이 아니라 새로운 시작:** 머신러닝 과목 17번 문서에서 배운 것처럼, 배포된 모델은 시간이 지나며 실제 데이터의 경향이 변해 성능이 점점 떨어질 수 있습니다(데이터 드리프트). 딥러닝 모델도 마찬가지로, 배포 후 주기적인 모니터링과 재학습이 필요한 순환적인 과정입니다.
</Callout>

## 핵심 정리

- **분류 평가지표**(정확도, 정밀도, 재현율, F1)는 딥러닝 분류 모델에도 동일하게 적용됨. 손실 함수와는 목적이 다름.
- **하이퍼파라미터 튜닝**은 반드시 검증 데이터로 수행하며, 테스트 데이터는 최종 평가에만 사용.
- **전이학습**: 사전학습된 모델의 앞부분(저수준 특징)은 고정하고, 마지막 층만 새로 학습해 적은 데이터로도 좋은 성능을 얻는 방법.
- **모델 배포**: 경량화 → 서빙 → 모니터링. 배포 이후에도 지속적인 관리가 필요한 순환 과정.
