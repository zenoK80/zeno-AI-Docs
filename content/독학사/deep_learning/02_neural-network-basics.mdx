## 생물학적 뉴런과 인공 뉴런

생물학적 뉴런은 수상돌기(입력) → 세포체(처리) → 축삭(출력) 구조로 동작합니다. 인공 뉴런은 이를 수학적으로 모델링합니다.

### 인공 뉴런 (Artificial Neuron)

$$y = f\left(\sum_{i=1}^{n} w_i x_i + b\right)$$

- $x_i$: 입력값
- $w_i$: 가중치(Weight) — 각 입력의 중요도
- $b$: 편향(Bias) — 활성화 임계값 조정
- $f$: 활성화 함수(Activation Function)
- $y$: 출력값

## 퍼셉트론 (Perceptron)

**퍼셉트론**은 1958년 Rosenblatt이 제안한 가장 단순한 인공 신경망입니다. 입력에 가중치를 곱하여 합산하고, 임계값과 비교하여 0 또는 1을 출력합니다.

**단층 퍼셉트론의 한계:** XOR 문제처럼 선형 분리가 불가능한 문제를 풀 수 없습니다. 이를 해결하기 위해 다층 퍼셉트론(MLP)이 등장했습니다.

## 활성화 함수 (Activation Function)

활성화 함수는 뉴런의 출력에 **비선형성**을 부여합니다. 비선형 활성화 함수 없이 여러 층을 쌓아도 결국 선형 변환에 불과합니다.

| 함수 | 수식 | 출력 범위 | 특징 |
|------|------|---------|------|
| **Step** | 임계값 초과 시 1, 아니면 0 | {0, 1} | 미분 불가 |
| **Sigmoid** | $\sigma(x) = \frac{1}{1+e^{-x}}$ | (0, 1) | 기울기 소실 문제 |
| **Tanh** | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | (-1, 1) | Sigmoid보다 중심 0 |
| **ReLU** | $\max(0, x)$ | [0, ∞) | 계산 빠름, 주로 은닉층 사용 |
| **Leaky ReLU** | $\max(0.01x, x)$ | (-∞, ∞) | Dead ReLU 문제 완화 |
| **Softmax** | $\frac{e^{x_i}}{\sum_j e^{x_j}}$ | (0, 1), 합=1 | 다중 분류 출력층 |

<Callout type="warning">
  **ReLU의 Dead ReLU 문제:** 입력이 음수이면 출력이 항상 0이 되어 해당 뉴런이 학습에 기여하지 못합니다. Leaky ReLU는 음수 영역에 작은 기울기를 부여하여 이를 완화합니다.
</Callout>

## 단층 vs 다층 신경망

**단층 신경망(Single Layer):** 입력층 + 출력층. 선형 분류만 가능합니다.

**다층 신경망/다층 퍼셉트론(MLP, Multi-Layer Perceptron):**

```
입력층 → [은닉층 1] → [은닉층 2] → ... → 출력층
```

- **입력층(Input Layer):** 데이터 입력, 뉴런 수 = 특징 수
- **은닉층(Hidden Layer):** 특징을 추상적으로 변환
- **출력층(Output Layer):** 최종 예측, 뉴런 수 = 클래스 수(분류) 또는 1(회귀)

은닉층이 깊어질수록(층이 많아질수록) 더 복잡한 패턴을 학습할 수 있습니다.

## 신경망 표기

- **완전 연결층(Fully Connected / Dense Layer):** 이전 층의 모든 뉴런과 연결
- **가중치 행렬:** $W \in \mathbb{R}^{m \times n}$ (m: 출력 뉴런 수, n: 입력 뉴런 수)
- **계층 출력:** $\mathbf{a}^{(l)} = f(W^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)})$

## 핵심 정리

- 인공 뉴런: 가중 합산 후 활성화 함수 적용
- 활성화 함수: 비선형성 부여, ReLU가 은닉층에서 가장 많이 사용
- Sigmoid: 이진 분류 출력, 기울기 소실 문제 있음
- Softmax: 다중 분류 출력층, 합이 1인 확률 출력
- MLP: 입력층 + 은닉층(들) + 출력층
