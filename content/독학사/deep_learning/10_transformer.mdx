## 어텐션 메커니즘 (Attention Mechanism)

**어텐션**(Attention)은 시퀀스에서 현재 위치와 연관성이 높은 다른 위치에 더 많은 가중치를 부여하는 메커니즘입니다.

예: "나는 은행에 가서 돈을 인출했다"에서 "인출"은 "은행(금융)"과 연관성이 높음

### 어텐션 수식

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- **Q (Query):** 현재 위치가 다른 위치를 질의
- **K (Key):** 각 위치가 제공하는 키(검색 인덱스)
- **V (Value):** 각 위치가 가진 실제 값
- **$\sqrt{d_k}$:** 스케일 인자, 내적 값이 커지는 것을 방지

## 셀프 어텐션 (Self-Attention)

**셀프 어텐션**은 시퀀스의 각 위치가 같은 시퀀스의 다른 모든 위치와 어텐션을 계산합니다.

```
입력: "고양이가 생선을 먹었다"
       ↓
각 단어가 다른 모든 단어와의 연관성 계산
"먹었다" → "생선" (목적어, 높은 가중치)
"먹었다" → "고양이" (주어, 높은 가중치)
"먹었다" → "가" (조사, 낮은 가중치)
```

## 멀티헤드 어텐션 (Multi-Head Attention)

여러 개의 셀프 어텐션을 병렬로 수행하고 결과를 연결합니다.

```
입력
├── Head 1 → 문법적 관계에 집중
├── Head 2 → 의미적 관계에 집중
├── Head 3 → 장거리 의존성에 집중
└── ... (총 h개의 헤드)
→ Concatenation → 선형 변환 → 출력
```

각 헤드가 서로 다른 종류의 관계를 학습하여 더 풍부한 표현 가능합니다.

## 트랜스포머 구조

트랜스포머는 **인코더-디코더** 구조로 이루어집니다.

```
인코더 스택 (N개 레이어)
  └── 셀프 어텐션 → Add & Norm
  └── 피드포워드 → Add & Norm

디코더 스택 (N개 레이어)
  └── 마스크드 셀프 어텐션 → Add & Norm
  └── 인코더-디코더 어텐션 → Add & Norm
  └── 피드포워드 → Add & Norm
```

- **Add & Norm:** 잔차 연결(Residual) + 레이어 정규화
- **마스크드 어텐션:** 디코더에서 미래 단어를 보지 못하도록 마스킹

## 포지셔널 인코딩 (Positional Encoding)

트랜스포머는 RNN과 달리 순서 정보가 없어, 위치 정보를 임베딩에 추가합니다.

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

사인/코사인 함수를 사용하여 각 위치마다 고유한 패턴을 부여합니다.

## BERT와 GPT

트랜스포머를 기반으로 한 대표적인 대규모 언어 모델입니다.

| 모델 | 구조 | 학습 방식 | 주요 용도 |
|------|------|---------|--------|
| **BERT** | 인코더만 사용 | 양방향 마스크 언어 모델 | 문서 분류, QA |
| **GPT** | 디코더만 사용 | 자기회귀 언어 모델 | 텍스트 생성 |

## 핵심 정리

- 어텐션: Query, Key, Value로 연관성 계산
- 셀프 어텐션: 시퀀스 내 모든 위치 간 어텐션
- 멀티헤드 어텐션: 여러 헤드로 다양한 관계 학습
- 포지셔널 인코딩: 사인/코사인으로 위치 정보 추가
- BERT: 인코더 기반, GPT: 디코더 기반
