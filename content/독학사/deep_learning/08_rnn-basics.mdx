## 시퀀스 데이터

**시퀀스(Sequence) 데이터**는 순서가 중요한 데이터입니다.

- 자연어: "나는 학교에 갔다" (단어 순서 중요)
- 시계열: 주가, 기온, 센서 데이터
- 음성: 음성 신호의 시간 흐름

일반적인 MLP나 CNN은 각 입력을 독립적으로 처리하여 이전 입력의 맥락을 반영하지 못합니다.

## RNN (Recurrent Neural Network)

**RNN**은 이전 시간 단계의 은닉 상태(Hidden State)를 현재 입력과 함께 처리하여 시퀀스의 맥락을 유지합니다.

### RNN 수식

$$h_t = f(W_h h_{t-1} + W_x x_t + b)$$

- $h_t$: 현재 시간 단계의 은닉 상태
- $h_{t-1}$: 이전 시간 단계의 은닉 상태
- $x_t$: 현재 입력
- $W_h$: 은닉 상태 가중치, $W_x$: 입력 가중치
- $f$: 활성화 함수 (주로 Tanh)

### RNN 구조 도식

```
x1 → [RNN] → h1 → [RNN] → h2 → [RNN] → h3
         ↑ h0         ↑ h1         ↑ h2
                                    ↓
                                   출력
```

같은 가중치($W_h$, $W_x$)를 모든 시간 단계에서 공유합니다(가중치 공유).

## RNN의 입출력 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| **일대일(One-to-One)** | 하나의 입력 → 하나의 출력 | 일반 분류 |
| **일대다(One-to-Many)** | 하나의 입력 → 여러 출력 | 이미지 캡셔닝 |
| **다대일(Many-to-One)** | 여러 입력 → 하나의 출력 | 감성 분석 |
| **다대다(Many-to-Many)** | 여러 입력 → 여러 출력 | 기계 번역, 품사 태깅 |

## BPTT (Backpropagation Through Time)

RNN의 역전파 알고리즘입니다. 시간을 펼쳐서(Unrolling) 역전파를 수행합니다.

```
Forward:  x1→h1→x2→h2→x3→h3→손실 L
Backward: L→h3→h2→h1 (시간을 거슬러 기울기 전파)
```

BPTT는 시간 단계 수만큼 기울기를 역으로 전파합니다.

## 장기 의존성 문제 (Long-Term Dependency)

시퀀스가 길어질수록 초기 정보가 소실됩니다.

예: "나는 어릴 때 프랑스에서 자랐기 때문에 __를 잘 한다" (빈칸: "프랑스어")

→ 현재 단어와 관련 정보가 매우 먼 과거에 있을 경우, RNN은 기울기 소실로 인해 그 정보를 기억하지 못합니다.

**원인:**
- BPTT 과정에서 시간 단계가 늘어날수록 기울기가 지수적으로 작아짐(소실) 또는 커짐(폭발)

**해결책:**
- **LSTM(Long Short-Term Memory):** 게이트 구조로 장기 의존성 해결
- **GRU(Gated Recurrent Unit):** LSTM의 경량화 버전
- **그래디언트 클리핑(Gradient Clipping):** 기울기 폭발 방지

## 핵심 정리

- RNN: 이전 은닉 상태를 현재 입력과 함께 처리, 시퀀스 맥락 유지
- $h_t = f(W_h h_{t-1} + W_x x_t + b)$
- 가중치 공유: 모든 시간 단계에서 동일 가중치 사용
- BPTT: 시간을 펼쳐 역전파
- 장기 의존성 문제: 긴 시퀀스에서 기울기 소실 → LSTM/GRU로 해결
