## 과적합 vs 과소적합

| 상태 | 설명 | 증상 |
|------|------|------|
| **과소적합(Underfitting)** | 모델이 너무 단순 | 학습 오차도 높음 |
| **적절한 적합** | 이상적 상태 | 학습·검증 오차 모두 낮음 |
| **과적합(Overfitting)** | 모델이 학습 데이터에 과도하게 적응 | 학습 오차 낮음, 검증 오차 높음 |

과적합은 모델이 학습 데이터의 잡음(Noise)까지 기억하여 새로운 데이터에 일반화하지 못하는 현상입니다.

## 드롭아웃 (Dropout)

**드롭아웃**은 학습 시 무작위로 일정 비율의 뉴런을 비활성화하는 기법입니다.

- 비율(p): 보통 0.2~0.5 (20~50%의 뉴런을 학습마다 무작위 비활성화)
- **학습 시:** 무작위 뉴런 비활성화
- **추론(테스트) 시:** 모든 뉴런 사용, 가중치를 (1-p)로 스케일링

**효과:**
- 앙상블 효과: 매번 다른 서브 네트워크를 학습하는 것과 유사
- 특정 뉴런에 의존하지 않게 하여 더 강건한 표현 학습

## L1 / L2 정규화 (가중치 감쇠)

손실 함수에 가중치의 크기에 비례하는 페널티 항을 추가합니다.

**L2 정규화 (Ridge, 가중치 감쇠):**

$$L_{L2} = L + \lambda \sum w^2$$

- 가중치를 0에 가깝게 만들지만 정확히 0이 되지는 않음
- 일반적으로 더 많이 사용

**L1 정규화 (Lasso):**

$$L_{L1} = L + \lambda \sum |w|$$

- 일부 가중치를 정확히 0으로 만들어 희소(Sparse) 모델 생성
- 특징 선택(Feature Selection) 효과

## 배치 정규화 (Batch Normalization)

각 미니배치에서 층의 입력을 정규화합니다.

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$
$$y = \gamma \hat{x} + \beta$$

- $\mu_B$: 배치 평균, $\sigma_B^2$: 배치 분산
- $\gamma, \beta$: 학습 가능한 스케일·이동 매개변수

**효과:**
- 내부 공변량 이동(Internal Covariate Shift) 감소
- 더 높은 학습률 사용 가능 → 빠른 학습
- 정규화 효과로 드롭아웃 없이도 사용 가능

## 조기 종료 (Early Stopping)

검증 데이터의 손실이 증가하기 시작하면 학습을 중단합니다.

```
에포크 증가 →
학습 손실: 계속 감소
검증 손실: 감소 후 증가 (과적합 시작)
             ↑
          이 지점에서 학습 중단
```

## 데이터 증강 (Data Augmentation)

학습 데이터를 인위적으로 늘려 과적합을 방지합니다.

- 이미지: 회전, 뒤집기, 밝기 조정, 크롭, 노이즈 추가
- 텍스트: 동의어 교체, 역번역, 문장 셔플

## 핵심 정리

- 과적합: 학습 데이터에 과도하게 적응, 검증 오차 증가
- 드롭아웃: 학습 시 무작위 뉴런 비활성화, 앙상블 효과
- L2 정규화: 가중치 제곱합 페널티, 가중치를 0 근처로
- L1 정규화: 가중치 절댓값 페널티, 희소 모델
- 배치 정규화: 미니배치 정규화, 학습 안정화·가속
- 조기 종료: 검증 손실 증가 시 학습 중단
