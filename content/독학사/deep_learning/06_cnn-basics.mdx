## CNN이란?

**CNN(Convolutional Neural Network, 합성곱 신경망)**은 이미지, 영상, 시계열 데이터 처리에 특화된 신경망입니다. 공간적 계층 구조를 학습하며, 완전 연결층(FC)보다 훨씬 적은 매개변수로 이미지를 효율적으로 처리합니다.

## 합성곱 연산 (Convolution)

**필터(Filter/Kernel)**를 입력 데이터 위에 슬라이딩하며 내적을 계산합니다.

```
입력(5×5) * 필터(3×3) = 특징 맵(3×3)

입력:           필터:
1 2 3 0 1      1 0 -1
0 1 2 3 1  *   1 0 -1  = 각 위치에서 내적
1 0 1 2 0      1 0 -1
...             (엣지 검출 필터 예시)
```

- **필터(Kernel):** 학습 가능한 가중치 행렬, 특정 패턴을 감지
- **특징 맵(Feature Map):** 합성곱 결과 출력
- **스트라이드(Stride):** 필터를 이동하는 보폭 (기본값: 1)
- **패딩(Padding):** 입력 주변에 0을 추가하여 출력 크기 유지

### 출력 크기 계산

$$\text{출력 크기} = \left\lfloor \frac{\text{입력 크기} - \text{필터 크기} + 2 \times \text{패딩}}{\text{스트라이드}} \right\rfloor + 1$$

예시: 입력 32×32, 필터 3×3, 패딩 1, 스트라이드 1 → 출력 = (32-3+2)/1 + 1 = 32×32 (Same Padding)

### 패딩의 종류

- **Valid Padding (패딩 없음):** 출력 크기 감소
- **Same Padding:** 출력 크기 = 입력 크기 유지

## 풀링 (Pooling)

풀링은 특징 맵의 크기를 줄여(다운샘플링) 계산량을 감소시키고 위치 불변성을 높입니다.

| 종류 | 동작 | 특징 |
|------|------|------|
| **최대 풀링(Max Pooling)** | 영역 내 최댓값 선택 | 주요 특징 강조, 주로 사용 |
| **평균 풀링(Average Pooling)** | 영역 내 평균값 | 전체적인 특징 보존 |

```
입력(4×4)     Max Pooling (2×2, Stride 2)     출력(2×2)
1 3 2 4                                        3 4
5 6 1 2         →                              6 3
3 2 1 0
1 2 3 4
```

## CNN 전체 구조

```
입력 이미지
  └── [Conv → ReLU → Pooling] × N   (특징 추출)
  └── [Flatten]                      (1D 벡터로 변환)
  └── [FC → ReLU] × M               (분류)
  └── [Softmax]                      (클래스 확률)
```

### 각 구성 요소의 역할

- **Conv + ReLU:** 특징 추출, 비선형성 부여
- **Pooling:** 공간 크기 감소, 계산량 절감, 위치 불변성
- **Flatten:** 2D 특징 맵을 1D 벡터로 변환
- **FC (Fully Connected):** 분류 결정

## CNN의 장점

- **지역 연결성(Local Connectivity):** 각 필터는 지역적 패턴만 학습 → 매개변수 수 감소
- **가중치 공유(Weight Sharing):** 동일 필터를 전체 입력에 적용 → 매개변수 수 대폭 감소
- **계층적 특징 학습:** 초기 층(엣지·질감) → 중간 층(모양) → 깊은 층(물체)

## 핵심 정리

- 합성곱: 필터를 슬라이딩하며 내적, 출력은 특징 맵
- 패딩: Same(크기 유지), Valid(크기 감소)
- 최대 풀링: 영역 내 최댓값, 위치 불변성 강화
- CNN 구조: [Conv-ReLU-Pool]×N → Flatten → FC → Softmax
- 가중치 공유로 매개변수 수 절감
