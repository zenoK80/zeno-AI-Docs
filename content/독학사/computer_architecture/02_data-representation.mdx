## 왜 컴퓨터는 2진수를 사용하나요?

컴퓨터는 전기 신호로 동작합니다. 전기가 흐르면 1, 흐르지 않으면 0이라는 두 가지 상태만 구분합니다. 이 두 상태를 조합하여 모든 정보를 표현하는 것이 **2진수**(Binary, 이진법)입니다.

**비유:** 전등 스위치를 생각해보세요. 켜짐(1)과 꺼짐(0) 두 상태만 있지만, 여러 개의 스위치를 조합하면 매우 많은 상태를 표현할 수 있습니다.

## 진법 (Number System)

### 진법이란?

숫자를 표현하는 방법입니다. 일상생활에서는 0~9 숫자 10개를 쓰는 10진수를 사용합니다.

| 진법 | 기저(Base) | 사용 숫자 | 표기 예 | 사용 목적 |
|------|-----------|---------|---------|---------|
| **2진수 **(Binary) | 2 | 0, 1 | 0b1010 | 컴퓨터 내부 처리 |
| **8진수 **(Octal) | 8 | 0~7 | 0o17 | 2진수 단축 표기 |
| **10진수 **(Decimal) | 10 | 0~9 | 13 | 일상생활 |
| **16진수 **(Hexadecimal) | 16 | 0~9, A~F | 0xFF | 메모리 주소, 색상 코드 |

16진수에서 10~15는 알파벳 A~F로 표현합니다: A=10, B=11, C=12, D=13, E=14, F=15

---

## 진법 변환

### 10진수 → 2진수 변환

방법: 2로 나누면서 나머지를 기록하고, 아래에서 위로 읽습니다.

**예: 13을 2진수로 변환**

```
13 ÷ 2 = 6 나머지 1  ↑ (맨 위에서 읽기 시작)
 6 ÷ 2 = 3 나머지 0  ↑
 3 ÷ 2 = 1 나머지 1  ↑
 1 ÷ 2 = 0 나머지 1  ↑ (여기서 끝)

결과: 아래에서 위로 읽으면 1101(2)
```

검증: 1×8 + 1×4 + 0×2 + 1×1 = 8 + 4 + 0 + 1 = 13 ✓

### 2진수 → 16진수 변환

방법: 2진수를 **오른쪽부터 4비트씩 묶어** 각 그룹을 16진수 한 자리로 변환합니다.

**예: 1010 1111을 16진수로 변환**

```
1010  1111
  A     F
= AF(16)
```

왜 4비트씩 묶나요? 2의 4승 = 16이므로, 4비트로 0~15(16진수 0~F)를 정확히 표현할 수 있기 때문입니다.

### 16진수 → 2진수 변환

방법: 각 16진수 숫자를 4비트 2진수로 변환합니다.

**예: 3C를 2진수로 변환**

```
  3      C(=12)
0011    1100
= 0011 1100(2)
```

## 보수 (Complement)

### 왜 보수가 필요한가요?

컴퓨터에서 뺄셈을 직접 구현하면 회로가 복잡해집니다. 보수(Complement)를 사용하면 **뺄셈을 덧셈 회로로 처리**할 수 있어 하드웨어를 단순화할 수 있습니다.

**쉽게 말하면:** 5 - 3 대신 5 + (-3)을 계산하는 것처럼, 컴퓨터도 빼는 수의 보수(음수 표현)를 더하는 방식으로 뺄셈을 처리합니다.

### 1의 보수 (One's Complement)

각 비트를 반전합니다 (0→1, 1→0).

```
0110의 1의 보수:
  0 → 1
  1 → 0
  1 → 0
  0 → 1
= 1001
```

### 2의 보수 (Two's Complement)

1의 보수에 1을 더합니다. **현대 컴퓨터에서 음수를 표현하는 표준 방식**입니다.

```
0101의 2의 보수:
1단계: 1의 보수 = 1010
2단계: +1       = 1011

따라서 0101의 2의 보수 = 1011
(즉, 5의 2의 보수 = -5를 나타냄)
```

### 2의 보수를 이용한 뺄셈

공식: **A - B = A + **(B의 2의 보수)

**예: 4비트로 9 - 6 계산**

```
9 = 1001(2)
6 = 0110(2)
6의 2의 보수: 1의 보수(1001) + 1 = 1010

  1001  (9)
+ 1010  (6의 2의 보수 = -6)
------
 10011  → 맨 앞 자리(올림수, 캐리)를 버리면 → 0011 = 3 ✓
```

**예: 4비트로 4 - 5 계산 **(음수 결과)

```
4 = 0100(2)
5 = 0101(2)
5의 2의 보수: 1의 보수(1010) + 1 = 1011

  0100  (4)
+ 1011  (5의 2의 보수 = -5)
------
  1111  → 올림수 없음 → 음수 결과
```

1111은 -1의 2의 보수 표현입니다. (1111의 2의 보수를 구하면 0001 = 1이므로, 1111 = -1) ✓

## 부호있는 정수 표현 방식 비교

| 방식 | 양수 5 표현 | 음수 -5 표현 | 문제점 |
|------|-----------|-----------|------|
| **부호-크기 **(Sign-Magnitude) | 0101 | 1101 | +0과 -0이 두 가지 존재 |
| **1의 보수** | 0101 | 1010 | +0과 -0이 두 가지 존재 |
| **2의 보수** | 0101 | 1011 | 없음 (표준으로 사용) |

현대 컴퓨터는 **2의 보수** 방식을 사용합니다. 이유는:
- 0이 하나뿐입니다 (1의 보수는 +0, -0 두 가지)
- 덧셈과 뺄셈을 동일한 회로로 처리 가능합니다

## 부동소수점 (Floating Point)

### 왜 부동소수점이 필요한가요?

0.5, 3.14, -0.001 같은 소수나 매우 큰 수(6.022×10의 23승)를 정수만으로 표현할 수 없습니다. 부동소수점은 수학의 과학적 표기법(Scientific Notation)을 2진수에 적용한 것입니다.

**비유:** 1.23456×10의 5승처럼 소수점의 위치를 '떠다니게(float)' 해서 크고 작은 수를 모두 표현합니다.

### IEEE 754 단정도(32비트, Single Precision) 형식

```
│ 부호(1비트) │ 지수(8비트) │ 가수(23비트) │
      S             E               M
```

$$
\text{값} = (-1)^S \times 1.M \times 2^{E-127}
$$

- **S (Sign, 부호):** 0이면 양수, 1이면 음수
- **E (Exponent, 지수):** 8비트로 저장하되, **바이어스 127을 더해서** 저장 (실제 지수 = E - 127)
- **M (Mantissa, 가수):** 소수점 아래 23비트 (정수부 1은 항상 1로 고정되어 생략)

**왜 바이어스 127을 더하나요?** 지수가 음수(예: 2의 -3승)일 수도 있는데, 비트로 음수를 표현하는 대신 항상 양수로 저장하기 위해 127을 더합니다. 즉 저장값 127 = 실제 지수 0, 저장값 126 = 실제 지수 -1입니다.

**예: 0.75를 IEEE 754 단정도로 표현**

```
0.75(10) = 0.11(2) = 1.1 × 2의 -1승

S = 0 (양수)
E = -1 + 127 = 126 = 0111 1110(2)
M = 10000...0 (소수 부분 1만 있고 나머지는 0)

결과: 0 01111110 10000000000000000000000
```

### 부동소수점 표현의 한계

컴퓨터는 0.1 같은 값을 **정확히 표현할 수 없습니다**. 0.1은 이진수로 표현하면 무한히 반복되기 때문입니다 (0.000110011...). 이를 **반올림 오차**(Rounding Error)라고 합니다.

프로그래밍에서 0.1 + 0.2 == 0.3이 false가 나오는 이유가 바로 이 때문입니다.

## 문자 코드

컴퓨터는 숫자만 처리할 수 있으므로, 문자도 숫자로 변환하여 저장합니다.

| 코드 | 비트 수 | 특징 | 활용 |
|------|--------|------|------|
| **ASCII** | 7비트 | 영어 알파벳·숫자·기호 총 128자 표현 | 영문 문서 |
| **확장 ASCII** | 8비트 | 256자 표현 | 서유럽 문자 포함 |
| **유니코드 **(Unicode) | 가변 | 전 세계 모든 문자 표현 가능 | 다국어 지원 |
| **UTF-8** | 1~4바이트 | 유니코드의 가변 길이 인코딩 방식 | 웹, 현대 소프트웨어 표준 |

## 핵심 정리

- **컴퓨터가 2진수를 쓰는 이유:** 전기 신호의 켜짐(1)/꺼짐(0) 두 상태만 구분하면 되기 때문
- **진법 변환:** 10진→2진(2로 나누기 반복), 2진→16진(4비트씩 묶기)
- **2의 보수** = 1의 보수 + 1, 뺄셈을 덧셈으로 처리하기 위해 사용
- **현대 컴퓨터는 2의 보수 방식**으로 음수를 표현한다 (0이 하나뿐, 회로 단순)
- **IEEE 754 단정도:** 부호(1비트) + 지수(8비트, 바이어스 127) + 가수(23비트) = 32비트
