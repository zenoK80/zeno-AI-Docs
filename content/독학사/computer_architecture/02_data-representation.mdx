## 진법 (Number System)

컴퓨터는 내부적으로 **2진수(Binary)**만 사용합니다. 사람과의 편의를 위해 8진수와 16진수도 활용됩니다.

| 진법 | 기저 | 사용 숫자 | 표기 |
|------|------|---------|------|
| **2진수** | 2 | 0, 1 | 0b1010 |
| **8진수** | 8 | 0~7 | 0o17 |
| **10진수** | 10 | 0~9 | 13 |
| **16진수** | 16 | 0~9, A~F | 0xFF |

## 진법 변환

### 10진수 → 2진수

10진수를 2로 나누며 나머지를 아래에서 위로 읽습니다.

```
13 ÷ 2 = 6 나머지 1  ↑
6 ÷ 2 = 3 나머지 0  ↑
3 ÷ 2 = 1 나머지 1  ↑
1 ÷ 2 = 0 나머지 1  ↑
         ↑
13(10) = 1101(2)
```

### 2진수 → 16진수

2진수를 **4비트씩 묶어** 16진수로 변환합니다.

```
1010 1111 (2)
  A     F
= AF(16)
```

### 16진수 → 2진수

각 16진수 숫자를 **4비트 2진수**로 변환합니다.

```
3C(16)
0011 1100(2)
```

## 보수(Complement)

보수는 컴퓨터에서 **뺄셈을 덧셈으로 처리**하기 위해 사용합니다.

### 1의 보수

각 비트를 반전(0→1, 1→0)합니다.

```
0110의 1의 보수 = 1001
```

### 2의 보수

1의 보수에 1을 더합니다. (=음수 표현에 사용)

```
0101의 2의 보수:
1단계: 1의 보수 = 1010
2단계: +1       = 1011
```

### 2의 보수를 이용한 뺄셈

**A - B = A + (-B) = A + (B의 2의 보수)**

**예시: 4비트로 '9 - 6' 계산**

```
9 = 1001(2)
6 = 0110(2)
6의 2의 보수: 1001 + 1 = 1010

  1001
+ 1010
------
 10011  → 상위 비트(캐리) 버림 → 0011 = 3(10)  ✓
```

**예시: 4비트로 '4 - 5' 계산**

```
4 = 0100(2)
5 = 0101(2)
5의 2의 보수: 1010 + 1 = 1011

  0100
+ 1011
------
  1111  = -1의 2의 보수 표현 (캐리 없음 → 음수 결과)
```

1111의 2의 보수 = 0001 = 1 → 결과 = -1 ✓

## 부호있는 정수 표현

| 방식 | 양수 4 | 음수 -4 |
|------|--------|--------|
| **부호-크기** | 0100 | 1100 |
| **1의 보수** | 0100 | 1011 |
| **2의 보수** | 0100 | 1100 |

현대 컴퓨터는 **2의 보수** 방식을 사용합니다.
- 0이 하나만 존재 (1의 보수는 +0, -0 두 개)
- 덧셈과 뺄셈을 동일한 회로로 처리 가능

## 부동소수점 (Floating Point)

실수를 표현하는 방법으로 과학적 표기법을 2진수에 적용합니다.

### IEEE 754 단정도(32비트) 형식

```
│ 부호(1) │ 지수(8) │ 가수(23) │
   S        E          M
```

$$
\text{값} = (-1)^S \times 1.M \times 2^{E-127}
$$

- **S(Sign):** 0이면 양수, 1이면 음수
- **E(Exponent):** 8비트, 바이어스 127을 더해 저장 (실제 지수 = E - 127)
- **M(Mantissa/Fraction):** 소수점 아래 23비트 (정수부 1은 암묵적으로 1)

### 예시: 0.75를 IEEE 754로 표현

```
0.75(10) = 0.11(2) = 1.1 × 2^(-1)

S = 0 (양수)
E = -1 + 127 = 126 = 0111 1110(2)
M = 1000 0000 0000 0000 0000 000(소수 부분)

결과: 0 01111110 10000000000000000000000
```

### 부동소수점 오류

컴퓨터는 0.1 같은 값을 정확히 표현할 수 없습니다. 이진수로 무한 반복되기 때문입니다. 이를 **반올림 오차(Rounding Error)**라 합니다.

## 문자 코드

| 코드 | 비트 | 특징 |
|------|------|------|
| **ASCII** | 7비트 | 영어, 숫자, 기호 128자 |
| **확장 ASCII** | 8비트 | 256자 |
| **유니코드(Unicode)** | 가변 | 전 세계 문자 표현 |
| **UTF-8** | 1~4바이트 | 유니코드 가변 길이 인코딩 |

## 핵심 정리

- 진법 변환: 10진→2진(나누기), 2진→16진(4비트씩 묶기)
- 2의 보수 = 1의 보수 + 1, 음수 표현에 사용
- 뺄셈 A-B = A + (B의 2의 보수)로 덧셈 회로 재사용
- IEEE 754: 부호(1비트) + 지수(8비트, 바이어스 127) + 가수(23비트)
- 현대 컴퓨터는 2의 보수 방식으로 정수를 표현한다
