## 컴퓨터란 무엇인가?

**왜 이것을 배우나요?** 컴퓨터 구조를 이해하면 "왜 RAM이 많을수록 빠른가?", "CPU가 왜 중요한가?" 같은 질문에 직접 답할 수 있게 됩니다. 스마트폰, PC, 서버까지 모든 전자기기가 같은 원리로 동작하기 때문입니다.

**컴퓨터**(Computer)는 데이터를 입력받아 처리하고 결과를 출력하는 전자 장치입니다. 현대 컴퓨터는 모두 **폰 노이만 구조**(Von Neumann Architecture)를 기반으로 합니다.

---

## 폰 노이만 구조 (Von Neumann Architecture)

### 왜 이 구조가 탄생했나요?

1940년대 초기 컴퓨터는 프로그램이 전선과 스위치로 하드웨어에 고정되어 있었습니다. 계산 방법을 바꾸려면 컴퓨터 내부 배선을 직접 다시 연결해야 했습니다. 물리학자 존 폰 노이만(John von Neumann)은 1945년에 이 문제를 해결하는 혁신적인 아이디어를 제안했습니다.

**쉽게 말하면:** 프로그램도 데이터처럼 메모리에 저장해 두고, CPU가 차례차례 읽어서 실행하면 된다는 것입니다.

### 저장 프로그램 방식 (Stored-Program)

폰 노이만 구조의 핵심 개념입니다.

- **프로그램(명령어)과 데이터를 같은 메모리에 함께 저장합니다**
- CPU가 메모리에서 명령어를 차례대로 꺼내서 실행합니다 (Fetch → Decode → Execute 순서로)
- CPU, 메모리, 입출력 장치가 버스(Bus, 데이터가 이동하는 통로)로 연결됩니다

**비유:** 음악 플레이어를 생각해보세요. 악보(프로그램)와 악기 조율 정보(데이터)를 같은 USB에 저장해 두고, 플레이어가 USB에서 악보를 꺼내 차례로 연주하는 것과 같습니다.

```
┌──────────────────────────────────────────┐
│              폰 노이만 컴퓨터               │
│                                          │
│  ┌────────────┐    ┌──────────────────┐  │
│  │    CPU     │←──→│   주기억장치      │  │
│  │ ┌────┐    │    │ (프로그램+데이터) │  │
│  │ │ALU │    │    └──────────────────┘  │
│  │ └────┘    │              ↑           │
│  │ ┌──────┐  │              │           │
│  │ │제어장치│  │    ┌──────────────────┐  │
│  │ └──────┘  │    │   입출력 장치     │  │
│  └────────────┘    └──────────────────┘  │
└──────────────────────────────────────────┘
```

### 폰 노이만 병목 (Von Neumann Bottleneck)

**문제:** CPU는 매우 빠른데, CPU와 메모리 사이를 잇는 버스(통로)의 속도가 이를 따라가지 못합니다. 마치 고속도로 여러 차선이 하나의 좁은 다리를 통과해야 하는 것처럼, 데이터 전송이 병목 지점이 됩니다.

**해결책:** 캐시 메모리(Cache Memory, CPU 가까이에 있는 초고속 임시 저장소)를 두어 자주 쓰는 데이터를 미리 저장해 놓습니다.

## 컴퓨터의 구성요소

컴퓨터는 크게 4가지 부품으로 나뉩니다.

### 1. 중앙처리장치 (CPU, Central Processing Unit)

**쉽게 말하면:** 컴퓨터의 두뇌입니다. 모든 계산과 판단을 담당합니다.

CPU는 세 가지 핵심 부품으로 구성됩니다.

| 구성 요소 | 영문 | 역할 |
|---------|------|------|
| **산술논리장치** | ALU (Arithmetic Logic Unit) | 덧셈·뺄셈 같은 수학 연산과 AND·OR 같은 논리 연산을 수행하는 실제 계산 담당 부품 |
| **제어장치** | Control Unit | 명령어가 무엇을 의미하는지 해석하고, 다른 부품에게 "이걸 해!"라고 지시하는 사령관 |
| **레지스터** | Register | CPU 내부에 있는 초고속 임시 저장 공간. 지금 당장 처리 중인 데이터를 잠깐 보관 |

### 2. 주기억장치 (Main Memory, 메인 메모리)

**쉽게 말하면:** 작업대입니다. 지금 실행 중인 프로그램과 데이터를 올려두는 공간입니다.

- **RAM(Random Access Memory, 랜덤 접근 메모리):** 읽고 쓰기 모두 가능, 전원이 꺼지면 내용이 사라지는 휘발성(Volatile) 메모리
- **ROM(Read-Only Memory, 읽기 전용 메모리):** 읽기만 가능, 전원이 꺼져도 내용이 보존되는 비휘발성(Non-Volatile) 메모리

### 3. 보조기억장치 (Secondary Storage)

**쉽게 말하면:** 창고입니다. 전원이 꺼져도 데이터가 유지되는 대용량 저장 공간입니다.

예: HDD(하드 디스크 드라이브), SSD(솔리드 스테이트 드라이브), USB 메모리

### 4. 입출력 장치 (I/O Device, Input/Output Device)

사람과 컴퓨터가 소통하는 수단입니다.

- **입력:** 키보드, 마우스, 마이크, 카메라
- **출력:** 모니터, 프린터, 스피커
- **입출력 모두:** 터치스크린, 하드 디스크

## 시스템 버스 (System Bus)

### 왜 버스가 필요한가요?

CPU, 메모리, 입출력 장치가 서로 데이터를 주고받으려면 연결 통로가 필요합니다. 이 통로를 **시스템 버스**(System Bus)라고 합니다.

**비유:** 버스는 도시의 도로와 같습니다. 어떤 도로는 주소 정보만 전달하고, 어떤 도로는 실제 물건(데이터)을 운반하고, 어떤 도로는 신호등 역할(제어 신호)을 합니다.

시스템 버스는 역할에 따라 3가지로 나뉩니다.

| 버스 종류 | 역할 | 방향 |
|---------|------|------|
| **주소 버스 **(Address Bus) | "메모리 100번지로 가세요"처럼 어디에 접근할지 주소를 전달 | 단방향 (CPU만 주소를 보냄) |
| **데이터 버스 **(Data Bus) | 실제 데이터(내용물)를 전송 | 양방향 (CPU↔메모리, CPU↔입출력) |
| **제어 버스 **(Control Bus) | 읽기인지 쓰기인지 등 제어 신호를 전달 | 양방향 |

<Callout type="warning">
  독학사 시험에서 "시스템 버스를 구성하는 것이 아닌 것은?" 유형이 자주 출제됩니다. **로컬 버스**(Local Bus)는 특정 장치 전용 버스로, 시스템 버스의 구성 요소가 아닙니다. 반드시 기억하세요!
</Callout>

### 버스 폭과 성능

**주소 버스 폭:** 접근 가능한 메모리 크기를 결정합니다.
- 32비트 주소 버스 → 2의 32승 = 약 43억 개 주소 = **4GB** 메모리 접근 가능
- 64비트 주소 버스 → 이론상 약 **18EB**(엑사바이트) 접근 가능

**데이터 버스 폭:** 한 번에 전송할 수 있는 데이터 양을 결정합니다. 폭이 넓을수록 한 번에 더 많은 데이터를 전송합니다.

## 명령어 수행 사이클 (Instruction Cycle)

**쉽게 말하면:** CPU가 하나의 명령어를 처리하는 과정을 단계별로 표현한 것입니다.

```
인출(Fetch) → 해독(Decode) → 실행(Execute) → 저장(Store)
     ↑_____________________________________________↓
```

| 단계 | 동작 설명 |
|------|----------|
| **인출 **(Fetch, 가져오기) | PC(Program Counter, 프로그램 카운터)가 가리키는 메모리 주소에서 명령어를 CPU로 가져옵니다 |
| **해독 **(Decode, 해석하기) | 제어장치가 "이 명령어가 무엇을 하라는 건지" 해석합니다 |
| **실행 **(Execute, 실행하기) | ALU나 다른 장치에서 실제 연산을 수행합니다 |
| **저장 **(Store, 저장하기) | 결과를 레지스터나 메모리에 저장합니다 |

이 4단계가 끝나면 다시 인출 단계로 돌아가 반복합니다.

## 컴퓨터의 분류

### 처리 성능과 규모에 따른 분류

| 종류 | 특징 | 실생활 예시 |
|------|------|----------|
| **슈퍼컴퓨터** | 세계 최고 성능, 엄청난 전력 소모 | 기상 예측, 우주 시뮬레이션 |
| **메인프레임** | 대기업·은행용 대용량 처리, 높은 신뢰성 | 은행 전산 시스템 |
| **서버** | 네트워크 서비스 제공, 24시간 가동 | 웹 서버, 게임 서버 |
| **PC **(개인용 컴퓨터) | 개인이 사용, 다목적 | 데스크탑, 노트북 |
| **임베디드 컴퓨터** | 특정 기능 전용 소형 컴퓨터 | 스마트폰, 냉장고, 자동차 |

## 핵심 정리

- **폰 노이만 구조:** 프로그램과 데이터를 같은 메모리에 저장하고 CPU가 순차적으로 실행하는 저장 프로그램 방식
- **CPU 구성:** ALU(계산) + 제어장치(지시) + 레지스터(임시 저장)
- **시스템 버스 3종류:** 주소 버스(단방향), 데이터 버스(양방향), 제어 버스(양방향)
- **주소 버스 폭**이 접근 가능한 메모리 크기를 결정한다 (32비트 → 4GB)
- **로컬 버스**는 시스템 버스의 구성 요소가 아니다
