## 컴퓨터의 기본 개념

**컴퓨터**는 데이터를 입력받아 처리하고 결과를 출력하는 전자 장치입니다. 현대 컴퓨터는 모두 **폰 노이만 구조**를 기반으로 합니다.

## 폰 노이만 구조 (Von Neumann Architecture)

1945년 존 폰 노이만이 제안한 **저장 프로그램(Stored-Program)** 개념을 기반으로 합니다.

### 핵심 개념

- **프로그램과 데이터를 메모리에 함께 저장**
- 명령어를 순차적으로 꺼내 실행 (Fetch-Decode-Execute)
- CPU, 메모리, 입출력 장치로 구성

```
┌──────────────────────────────────────────┐
│              폰 노이만 컴퓨터               │
│                                          │
│  ┌────────────┐    ┌──────────────────┐  │
│  │    CPU     │←──→│   주기억장치      │  │
│  │ ┌────┐    │    │ (프로그램+데이터) │  │
│  │ │ALU │    │    └──────────────────┘  │
│  │ └────┘    │              ↑           │
│  │ ┌──────┐  │              │           │
│  │ │제어장치│  │    ┌──────────────────┐  │
│  │ └──────┘  │    │   입출력 장치     │  │
│  └────────────┘    └──────────────────┘  │
└──────────────────────────────────────────┘
```

### 폰 노이만 구조의 문제점: 폰 노이만 병목

CPU와 메모리 사이의 **버스 대역폭 제한**으로 인해 명령어/데이터 전송이 병목이 되는 현상입니다. 캐시 메모리로 완화합니다.

## 컴퓨터의 구성요소

### 1. 중앙처리장치 (CPU)

| 구성 요소 | 역할 |
|---------|------|
| **ALU (산술논리장치)** | 산술 연산(덧셈, 곱셈 등)과 논리 연산(AND, OR) 수행 |
| **제어장치 (Control Unit)** | 명령어를 해석하고 다른 구성요소에 제어 신호 전달 |
| **레지스터 (Register)** | CPU 내부의 초고속 임시 저장 장치 |

### 2. 주기억장치 (Main Memory)

프로그램과 데이터를 저장하는 곳으로 CPU가 직접 접근합니다.
- RAM: 읽기/쓰기 가능, 휘발성
- ROM: 읽기만 가능, 비휘발성

### 3. 보조기억장치 (Secondary Storage)

대용량 데이터를 영구 저장합니다 (HDD, SSD, 광디스크 등).

### 4. 입출력 장치 (I/O Device)

키보드, 마우스 (입력), 모니터, 프린터 (출력), 디스크 (입출력).

## 시스템 버스(System Bus)

**시스템 버스**는 CPU, 메모리, 입출력 장치를 연결하는 통신 경로입니다.

| 버스 종류 | 역할 | 방향 |
|---------|------|------|
| **주소 버스 (Address Bus)** | 메모리나 장치의 주소 전달 | 단방향 (CPU → 장치) |
| **데이터 버스 (Data Bus)** | 실제 데이터 전송 | 양방향 |
| **제어 버스 (Control Bus)** | 읽기/쓰기 등 제어 신호 전달 | 양방향 |

<Callout type="warning">
  독학사 시험에서 "시스템 버스를 구성하는 것이 아닌 것은?" 유형이 자주 출제됩니다. 로컬 버스는 시스템 버스의 구성 요소가 아닙니다.
</Callout>

### 버스 폭과 성능

- **주소 버스 폭:** 접근 가능한 메모리 크기 결정 (32비트 → 4GB, 64비트 → 16EB)
- **데이터 버스 폭:** 한 번에 전송할 수 있는 데이터 양 결정

## 컴퓨터의 분류

### 처리 성능과 규모에 따른 분류

| 종류 | 특징 |
|------|------|
| **슈퍼컴퓨터** | 최고 성능, 기상 예측·과학 연산에 사용 |
| **메인프레임** | 대기업 대용량 데이터 처리, 높은 신뢰성 |
| **서버** | 네트워크 서비스 제공, 다양한 규모 |
| **PC (개인용 컴퓨터)** | 개인이 사용, 다목적 |
| **임베디드 컴퓨터** | 특정 기능 전용 (스마트폰, IoT) |

### 구조에 따른 분류

| 종류 | 특징 |
|------|------|
| **병렬 컴퓨터** | 여러 프로세서가 동시에 연산 (SIMD, MIMD) |
| **분산 컴퓨팅** | 여러 컴퓨터가 네트워크로 협력 |
| **클라우드 컴퓨팅** | 인터넷을 통해 컴퓨팅 자원을 서비스로 제공 |

## 명령어 수행 사이클

CPU가 명령어를 처리하는 기본 사이클입니다.

```
인출(Fetch) → 해독(Decode) → 실행(Execute) → 저장(Store)
     ↑_____________________________________________↓
```

1. **인출:** 메모리에서 명령어를 CPU로 가져옴 (PC가 가리키는 주소)
2. **해독:** 제어장치가 명령어의 연산 코드 해석
3. **실행:** ALU 또는 다른 장치에서 연산 수행
4. **저장:** 결과를 레지스터나 메모리에 저장

## 핵심 정리

- 폰 노이만 구조는 프로그램과 데이터를 메모리에 함께 저장하는 저장 프로그램 방식이다
- 컴퓨터 구성요소: CPU(ALU+제어장치+레지스터), 주기억장치, 보조기억장치, 입출력 장치
- 시스템 버스는 주소 버스(단방향), 데이터 버스(양방향), 제어 버스(양방향)으로 구성된다
- 주소 버스 폭이 접근 가능한 메모리 크기를 결정한다
