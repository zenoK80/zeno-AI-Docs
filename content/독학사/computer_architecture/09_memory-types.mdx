## 기억장치 분류

컴퓨터 메모리는 크게 **휘발성(Volatile)**과 **비휘발성(Non-Volatile)**으로 나뉩니다.

```
기억장치
├── RAM (휘발성, 읽기/쓰기)
│   ├── SRAM (Static RAM)
│   └── DRAM (Dynamic RAM)
└── ROM (비휘발성, 읽기 전용 또는 특수 쓰기)
    ├── Mask ROM
    ├── PROM
    ├── EPROM
    ├── EEPROM
    └── Flash Memory (NAND/NOR)
```

## RAM (Random Access Memory)

임의의 주소에 동일한 시간에 접근 가능한 읽기/쓰기 메모리입니다.

### SRAM (Static RAM)

**플립플롭** 회로로 데이터를 저장합니다.

| 특성 | 내용 |
|------|------|
| **저장 방식** | 플립플롭 (6 트랜지스터/셀) |
| **리프레시** | 불필요 |
| **속도** | 매우 빠름 |
| **용량** | 작음 (집적도 낮음) |
| **가격** | 비쌈 |
| **전력 소비** | 높음 |
| **용도** | 캐시 메모리, 레지스터 |

### DRAM (Dynamic RAM)

**커패시터(Capacitor)**로 데이터를 저장합니다. 전하가 서서히 소멸되므로 주기적인 리프레시가 필요합니다.

| 특성 | 내용 |
|------|------|
| **저장 방식** | 커패시터 (1 트랜지스터+1 커패시터/셀) |
| **리프레시** | 필요 (수 밀리초 주기) |
| **속도** | SRAM보다 느림 |
| **용량** | 큼 (집적도 높음) |
| **가격** | 저렴 |
| **전력 소비** | 낮음 |
| **용도** | 메인 메모리(RAM) |

### DRAM의 발전 종류

| 종류 | 특징 |
|------|------|
| **SDRAM** | 클럭 동기화, 100~133MHz |
| **DDR SDRAM** | 클럭 상승/하강 모두 데이터 전송 (2배 대역폭) |
| **DDR2, DDR3, DDR4, DDR5** | 세대별 속도 향상 |
| **LPDDR** | 저전력 모바일용 |

### SRAM vs DRAM 비교

| 항목 | SRAM | DRAM |
|------|------|------|
| 저장 소자 | 플립플롭 | 커패시터 |
| 리프레시 | 불필요 | 필요 |
| 속도 | 빠름 | 느림 |
| 집적도 | 낮음 | 높음 |
| 가격 | 비쌈 | 저렴 |
| 용도 | 캐시 | 메인 메모리 |

## ROM (Read-Only Memory)

전원이 꺼져도 데이터가 보존되는 비휘발성 메모리입니다.

### ROM의 종류

| 종류 | 프로그래밍 | 소거 | 특징 |
|------|----------|------|------|
| **Mask ROM** | 제조 시 | 불가 | 생산 후 변경 불가 |
| **PROM (Programmable ROM)** | 사용자 1회 | 불가 | OTP(One Time Programmable) |
| **EPROM (Erasable PROM)** | 사용자 | UV(자외선) | 자외선으로 소거 |
| **EEPROM (Electrically Erasable PROM)** | 사용자 | 전기적 | 바이트 단위 소거 |
| **Flash Memory** | 사용자 | 전기적 | 블록 단위 소거, 고속 |

## 플래시 메모리 (Flash Memory)

EEPROM의 발전형으로 블록 단위로 소거하는 비휘발성 메모리입니다.

### NAND vs NOR 플래시

| 항목 | NAND Flash | NOR Flash |
|------|----------|----------|
| **연결 방식** | 직렬 | 병렬 |
| **읽기 속도** | 느림 | 빠름 |
| **쓰기/소거 속도** | 빠름 | 느림 |
| **집적도** | 높음 | 낮음 |
| **용도** | SSD, USB, 스마트폰 | BIOS, 펌웨어 |

<Callout type="info">
  NAND 플래시는 용량 대비 가격이 낮아 SSD, USB 드라이브, 스마트폰 스토리지에 사용됩니다. NOR 플래시는 읽기 속도가 빠르고 직접 실행(XIP, Execute In Place)이 가능하여 BIOS나 펌웨어 저장에 사용됩니다.
</Callout>

## SSD (Solid State Drive)

NAND 플래시 메모리를 사용한 고속 저장 장치입니다.

| 항목 | SSD | HDD |
|------|-----|-----|
| **저장 매체** | NAND 플래시 | 자기 디스크 |
| **속도** | 매우 빠름 | 느림 |
| **내구성** | 충격에 강함 | 충격에 약함 |
| **전력 소비** | 낮음 | 높음 |
| **쓰기 수명** | 제한 있음 (P/E 사이클) | 제한 적음 |
| **가격** | 비쌈 | 저렴 |

### SSD의 셀 종류

| 종류 | 셀당 비트 | 내구성 | 속도 | 가격 |
|------|---------|--------|------|------|
| SLC | 1비트 | 매우 높음 | 빠름 | 비쌈 |
| MLC | 2비트 | 높음 | 보통 | 보통 |
| TLC | 3비트 | 보통 | 느림 | 저렴 |
| QLC | 4비트 | 낮음 | 더 느림 | 더 저렴 |

## 메모리 패키지 방식

| 방식 | 특징 |
|------|------|
| **DIMM** | 데스크톱 PC용 메모리 모듈 |
| **SO-DIMM** | 노트북용 소형 메모리 모듈 |
| **HBM** | 고대역폭 메모리, GPU 적층 |

## 핵심 정리

- SRAM: 플립플롭, 빠름, 비쌈 → 캐시 메모리
- DRAM: 커패시터, 리프레시 필요, 저렴, 용량 큼 → 메인 메모리
- ROM 종류: Mask → PROM → EPROM(UV소거) → EEPROM(전기소거) → Flash
- NAND Flash: 고집적, 빠른 쓰기 → SSD/USB / NOR Flash: 빠른 읽기 → BIOS/펌웨어
