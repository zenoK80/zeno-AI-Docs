## 왜 메모리를 종류별로 알아야 하나요?

스마트폰을 사용할 때 앱이 꺼지면 작업 중이던 내용이 사라지는 경우가 있습니다. 반면 사진이나 파일은 전원을 꺼도 남아 있습니다. 이런 차이가 바로 **메모리의 종류**에서 비롯됩니다. 메모리는 크게 전원이 꺼지면 내용이 사라지는 것과 남아 있는 것으로 나뉩니다.

**비유:** 책상 위의 메모지(전원 차단 시 사라짐)와 노트(전원 꺼도 내용 보존)를 생각해보세요.

## 기억장치 분류

컴퓨터 메모리는 크게 **휘발성**(Volatile)과 **비휘발성**(Non-Volatile)으로 나뉩니다.

- **휘발성(Volatile):** 전원이 꺼지면 저장된 내용이 모두 사라집니다. 빠르지만 임시 저장에만 사용합니다.
- **비휘발성(Non-Volatile):** 전원이 꺼져도 내용이 보존됩니다. 영구 저장에 사용합니다.

```
기억장치
├── RAM (휘발성, 읽기/쓰기 가능)
│   ├── SRAM (Static RAM, 정적 램)
│   └── DRAM (Dynamic RAM, 동적 램)
└── ROM (비휘발성, 읽기 전용 또는 특수 쓰기)
    ├── Mask ROM (마스크 롬)
    ├── PROM (피롬)
    ├── EPROM (이피롬)
    ├── EEPROM (이이피롬)
    └── Flash Memory (플래시 메모리: NAND/NOR)
```

## RAM (Random Access Memory, 랜덤 접근 메모리)

**RAM**(Random Access Memory)이란 임의의 주소에 동일한 속도로 접근 가능한 읽기/쓰기 메모리입니다.

**쉽게 말하면:** 책장에서 어떤 책이든 바로 꺼낼 수 있는 것처럼, 어떤 주소든 같은 시간에 접근할 수 있습니다.

### SRAM (Static RAM, 정적 램)

**SRAM**(Static RAM)은 **플립플롭**(Flip-Flop) 회로로 데이터를 저장합니다. 트랜지스터(Transistor, 반도체 스위치)로 만든 래치(Latch) 회로가 전원이 공급되는 동안 값을 유지합니다.

**비유:** 스위치를 ON/OFF 상태로 고정해두는 것과 같습니다. 전원이 있는 한 상태가 유지됩니다.

| 특성 | 내용 |
|------|------|
| **저장 방식** | 플립플롭 (셀당 6개 트랜지스터) |
| **리프레시**(Refresh) | 불필요 (정적으로 값 유지) |
| **속도** | 매우 빠름 (수 ns) |
| **집적도** | 낮음 (셀당 트랜지스터 多) |
| **가격** | 비쌈 |
| **전력 소비** | 활성 시 높음 |
| **주요 용도** | 캐시 메모리(Cache Memory), 레지스터 |

### DRAM (Dynamic RAM, 동적 램)

**DRAM**(Dynamic RAM)은 **커패시터**(Capacitor, 전하를 저장하는 부품)로 데이터를 저장합니다. 커패시터는 전하가 서서히 새어나가기 때문에 주기적으로 **리프레시**(Refresh, 재충전)가 필요합니다.

**비유:** 바람이 빠지는 풍선처럼, 주기적으로 다시 불어넣어야(리프레시) 합니다.

| 특성 | 내용 |
|------|------|
| **저장 방식** | 커패시터 (셀당 1 트랜지스터 + 1 커패시터) |
| **리프레시** | 필요 (수십 ms마다 재충전) |
| **속도** | SRAM보다 느림 |
| **집적도** | 높음 (셀이 단순) |
| **가격** | 저렴 |
| **전력 소비** | 낮음 |
| **주요 용도** | 메인 메모리(Main Memory, 주기억장치) |

### DDR SDRAM (Double Data Rate Synchronous DRAM)

현재 PC에서 가장 많이 사용하는 DRAM 규격입니다.

- **SDRAM(Synchronous DRAM, 동기식 DRAM):** 클럭 신호에 맞춰 동작합니다.
- **DDR(Double Data Rate, 배속 전송):** 클럭의 상승 엣지와 하강 엣지 모두에서 데이터를 전송하여 같은 클럭에서 2배의 데이터를 전송합니다.
- **DDR4, DDR5:** 세대가 올라갈수록 속도와 전력 효율이 향상됩니다.

## ROM (Read Only Memory, 읽기 전용 메모리)

**ROM**(Read Only Memory)은 전원이 꺼져도 내용이 유지되는 **비휘발성** 메모리입니다. 주로 펌웨어(Firmware, 하드웨어 제어 소프트웨어)나 부팅 코드(BIOS/UEFI)를 저장합니다.

### ROM의 발전 과정

| 종류 | 전체 이름 | 특성 |
|------|----------|------|
| **Mask ROM** | 제조 시 데이터 영구 기록 | 제조 후 수정 불가, 대량 생산에 적합 |
| **PROM** | Programmable ROM | 한 번만 쓰기 가능 (전기 신호로 회로 태워서 기록) |
| **EPROM** | Erasable PROM | 자외선(UV)으로 내용 삭제 후 재기록 가능 |
| **EEPROM** | Electrically Erasable PROM | 전기 신호로 바이트 단위 삭제/재기록 가능 |
| **Flash Memory** | EEPROM 개선형 | 블록 단위 삭제, 대용량, EEPROM보다 빠르고 저렴 |

**비유:**
- Mask ROM = 공장에서 찍어낸 CD (내용 변경 불가)
- PROM = 한 번 쓸 수 있는 공CD
- EPROM = 햇빛(자외선)으로 지우고 다시 쓸 수 있는 CD
- EEPROM = 파일 단위로 지우고 쓸 수 있는 USB
- Flash = 더 빠르고 용량이 큰 USB

## 플래시 메모리 (Flash Memory)

**플래시 메모리**(Flash Memory)는 EEPROM을 개선한 것으로, 블록(Block) 단위로 삭제하고 재기록할 수 있습니다. 현재 SSD, USB 드라이브, 스마트폰 저장장치에 사용됩니다.

### NAND 플래시 vs NOR 플래시

| 특성 | NAND 플래시 | NOR 플래시 |
|------|------------|-----------|
| **셀 연결 방식** | 직렬(Series) 연결 | 병렬(Parallel) 연결 |
| **읽기 속도** | 느림 | 빠름 |
| **쓰기/삭제 속도** | 빠름 | 느림 |
| **용량** | 대용량 가능 | 소용량 |
| **가격** | 저렴 | 비쌈 |
| **용도** | SSD, USB, 스마트폰 저장장치 | BIOS, 임베디드 펌웨어 |

**쉽게 말하면:** NAND는 대용량 저장에, NOR는 코드 직접 실행(XIP: eXecute In Place)에 적합합니다.

### SSD 셀 종류 (NAND 플래시 기준)

| 종류 | 전체 이름 | 셀당 비트 | 특성 |
|------|----------|---------|------|
| **SLC** | Single Level Cell | 1비트 | 가장 빠름, 가장 오래가며, 가장 비쌈 |
| **MLC** | Multi Level Cell | 2비트 | 속도·수명·가격 균형 |
| **TLC** | Triple Level Cell | 3비트 | 대용량 소비자용 SSD |
| **QLC** | Quad Level Cell | 4비트 | 가장 저렴, 수명 짧음 |

**비유:** 같은 크기의 방에 몇 명을 넣느냐와 같습니다. 많이 넣을수록(비트 수 증가) 저렴하지만 복잡해지고 수명이 줄어듭니다.

## SRAM vs DRAM 비교 정리

| 항목 | SRAM | DRAM |
|------|------|------|
| **저장 원리** | 플립플롭 | 커패시터 |
| **리프레시** | 불필요 | 필요 |
| **속도** | 빠름 | 느림 |
| **집적도** | 낮음 | 높음 |
| **가격** | 비쌈 | 저렴 |
| **용도** | 캐시, 레지스터 | 메인 메모리 |

---

## 핵심 정리

- **RAM:** 전원 차단 시 내용 소멸(휘발성), SRAM(플립플롭, 빠름, 캐시용)과 DRAM(커패시터, 리프레시 필요, 메인 메모리용)으로 나뉨
- **ROM 발전:** Mask ROM → PROM → EPROM(자외선) → EEPROM(전기) → Flash(블록 단위)
- **NAND 플래시:** 대용량, 저렴, SSD/USB용
- **NOR 플래시:** 빠른 읽기, 코드 직접 실행, 펌웨어용
- **SSD 셀:** SLC(1비트, 최고 성능) → MLC → TLC → QLC(4비트, 최대 용량)
- **DDR SDRAM:** 클럭 상승/하강 엣지 모두 전송, 현재 PC 메인 메모리 표준
