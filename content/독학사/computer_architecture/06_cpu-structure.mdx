## CPU의 내부 구조

CPU(Central Processing Unit)는 컴퓨터의 두뇌로 세 가지 핵심 구성요소로 이루어집니다.

```
┌─────────────────────────────────────────┐
│                  CPU                    │
│                                         │
│  ┌─────────┐   ┌─────────────────────┐  │
│  │   ALU   │   │     레지스터 파일     │  │
│  │(산술/논리│   │ PC, IR, MAR, MBR,  │  │
│  │ 연산장치)│   │ AC, PSW, SP 등     │  │
│  └────┬────┘   └──────────┬──────────┘  │
│       │                   │             │
│  ┌────┴───────────────────┴──────────┐  │
│  │          내부 버스                  │  │
│  └────────────────────┬──────────────┘  │
│                        │                │
│  ┌─────────────────────┴────────────┐   │
│  │       제어장치(Control Unit)      │   │
│  └──────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

## ALU (Arithmetic Logic Unit, 산술논리장치)

ALU는 실제 연산을 수행하는 장치입니다.

### ALU가 수행하는 연산

| 구분 | 연산 |
|------|------|
| **산술 연산** | 덧셈, 뺄셈, 곱셈, 나눗셈 |
| **논리 연산** | AND, OR, NOT, XOR |
| **시프트 연산** | 논리 시프트, 산술 시프트, 순환 시프트 |
| **비교 연산** | 두 값의 크기 비교 (플래그 설정) |

### 시프트 연산의 종류

| 종류 | 설명 |
|------|------|
| **논리 시프트** | 빈 자리를 0으로 채움 |
| **산술 시프트** | 부호 비트(MSB) 유지, 나머지 시프트 |
| **순환(Rotate) 시프트** | 밀려난 비트가 반대쪽으로 순환 |

## 레지스터의 종류

레지스터는 CPU 내부의 초고속 임시 저장 장치입니다.

### 주요 레지스터

| 레지스터 | 영문 | 역할 |
|---------|------|------|
| **프로그램 카운터** | PC (Program Counter) | 다음에 실행할 명령어의 메모리 주소 저장 |
| **명령어 레지스터** | IR (Instruction Register) | 현재 실행 중인 명령어 저장 |
| **메모리 주소 레지스터** | MAR (Memory Address Register) | 접근할 메모리 주소 저장 |
| **메모리 버퍼 레지스터** | MBR (Memory Buffer Register) | 메모리에서 읽은 데이터 또는 메모리에 쓸 데이터 임시 저장 |
| **누산기** | AC (Accumulator) | ALU 연산 결과 저장 |
| **프로그램 상태 레지스터** | PSW (Program Status Word) | 조건 코드(플래그: ZF, CF, SF, OF) 저장 |
| **스택 포인터** | SP (Stack Pointer) | 스택의 최상위 주소 저장 |
| **베이스 레지스터** | BR (Base Register) | 기준 주소 저장 |

<Callout type="warning">
  독학사 시험에서 PC(프로그램 카운터)와 IR(명령어 레지스터), MAR, MBR의 역할 구분이 자주 출제됩니다.
</Callout>

### 플래그 레지스터 (PSW)

ALU 연산 결과에 따라 설정되는 1비트 플래그들입니다.

| 플래그 | 의미 |
|--------|------|
| **ZF (Zero Flag)** | 결과가 0일 때 1 |
| **CF (Carry Flag)** | 부호없는 연산에서 올림/빌림 발생 시 1 |
| **SF (Sign Flag)** | 결과가 음수(MSB=1)일 때 1 |
| **OF (Overflow Flag)** | 부호있는 연산에서 오버플로 발생 시 1 |

## 제어장치 (Control Unit)

명령어를 해석하고 CPU의 각 구성요소에 제어 신호를 보내는 장치입니다.

### 제어 방식

| 방식 | 특징 |
|------|------|
| **하드와이어드 제어** | 논리 회로로 구현, 속도 빠름, 수정 어려움 (RISC에서 선호) |
| **마이크로프로그램 제어** | 마이크로 명령어 사용, 유연함, 속도 느림 (CISC에서 사용) |

## 명령어 사이클과 레지스터 동작

명령어 인출(Fetch) 단계에서의 레지스터 동작 순서:

1. MAR ← PC (프로그램 카운터의 주소를 MAR에 복사)
2. MBR ← Memory[MAR] (메모리에서 명령어를 MBR로 읽음)
3. IR ← MBR (명령어를 IR에 저장)
4. PC ← PC + 1 (다음 명령어 주소로 PC 증가)

## 스택 (Stack)과 SP

스택은 LIFO(Last In First Out) 구조입니다.

- **PUSH:** 스택에 데이터 저장, SP 감소 (메모리 높은 주소→낮은 주소로 성장)
- **POP:** 스택에서 데이터 제거, SP 증가

## 핵심 정리

- ALU: 산술(+,-,*,÷), 논리(AND/OR/NOT), 시프트, 비교 연산 수행
- PC: 다음 명령어 주소, IR: 현재 명령어, MAR: 접근할 주소, MBR: 메모리 데이터
- AC(누산기): ALU 결과 저장, PSW: 플래그(ZF, CF, SF, OF)
- 하드와이어드: 빠르고 수정 어려움(RISC), 마이크로프로그램: 유연하고 느림(CISC)
