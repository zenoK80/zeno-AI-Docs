## CPU란?

### 왜 CPU를 자세히 배우나요?

"CPU(Central Processing Unit, 중앙처리장치)가 컴퓨터의 두뇌"라는 말을 들어봤을 것입니다. 하지만 두뇌 안에 정확히 무엇이 있는지, 어떻게 동작하는지 알아야 "왜 이 CPU는 빠른가?", "프로그램이 어떻게 실행되는가?"를 이해할 수 있습니다.

CPU는 세 가지 핵심 부품으로 구성됩니다: **ALU(계산)**, **레지스터(임시 저장)**, **제어장치(지시)**.

```
┌─────────────────────────────────────────┐
│                  CPU                    │
│                                         │
│  ┌─────────┐   ┌─────────────────────┐  │
│  │   ALU   │   │     레지스터 파일     │  │
│  │(산술/논리│   │ PC, IR, MAR, MBR,  │  │
│  │ 연산장치)│   │ AC, PSW, SP 등     │  │
│  └────┬────┘   └──────────┬──────────┘  │
│       │                   │             │
│  ┌────┴───────────────────┴──────────┐  │
│  │          내부 버스                  │  │
│  └────────────────────┬──────────────┘  │
│                        │                │
│  ┌─────────────────────┴────────────┐   │
│  │       제어장치(Control Unit)      │   │
│  └──────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

## ALU (Arithmetic Logic Unit, 산술논리장치)

**쉽게 말하면:** CPU 안의 계산기입니다. 실제로 계산을 수행하는 부품입니다.

ALU가 수행하는 연산의 종류:

| 연산 종류 | 설명 | 예시 |
|---------|------|------|
| **산술 연산 (Arithmetic)** | 수학 계산 | 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/) |
| **논리 연산 (Logic)** | 논리 판단 | AND, OR, NOT, XOR |
| **시프트 연산 (Shift)** | 비트 이동 | 왼쪽/오른쪽 비트 이동 |
| **비교 연산 (Comparison)** | 크기 비교 | 두 값이 같은지, 크거나 작은지 판단 후 플래그 설정 |

### 시프트 연산의 종류

| 종류 | 설명 | 특징 |
|------|------|------|
| **논리 시프트 (Logical Shift)** | 빈 자리를 항상 0으로 채움 | 부호 없는 수에 사용 |
| **산술 시프트 (Arithmetic Shift)** | MSB(부호 비트)를 유지, 나머지 시프트 | 부호 있는 수의 곱셈/나눗셈에 사용 |
| **순환 시프트 (Rotate Shift)** | 밀려난 비트가 반대쪽으로 들어옴 | 비트 패턴 순환 |

## 레지스터 (Register)

### 레지스터란?

**레지스터(Register)**는 CPU 내부에 있는 초고속 임시 저장 공간입니다. 메모리(RAM)보다 훨씬 빠르지만 용량이 매우 작습니다.

**비유:** 사무실 책상 위의 메모지입니다. 지금 당장 사용 중인 것만 책상(레지스터)에 올려두고, 나머지는 서랍장(캐시)이나 창고(메모리)에 넣어둡니다.

### 주요 레지스터

| 레지스터 | 약어 | 영문 | 역할 |
|---------|------|------|------|
| **프로그램 카운터** | PC | Program Counter | 다음에 실행할 명령어가 있는 메모리 주소를 저장. 명령어를 읽을 때마다 자동으로 증가 |
| **명령어 레지스터** | IR | Instruction Register | 메모리에서 가져온 현재 실행 중인 명령어를 저장 |
| **메모리 주소 레지스터** | MAR | Memory Address Register | 메모리에 접근할 때 사용할 주소를 저장. 주소 버스와 연결 |
| **메모리 버퍼 레지스터** | MBR | Memory Buffer Register | 메모리에서 읽거나 메모리에 쓸 데이터를 임시 저장. 데이터 버스와 연결 |
| **누산기** | AC | Accumulator | ALU 연산의 결과를 저장하는 레지스터 |
| **프로그램 상태 레지스터** | PSW | Program Status Word | 연산 결과를 나타내는 조건 플래그(ZF, CF, SF, OF)들을 저장 |
| **스택 포인터** | SP | Stack Pointer | 스택의 가장 위 원소가 있는 메모리 주소를 저장 |

<Callout type="warning">
  독학사 시험에서 PC, IR, MAR, MBR의 역할 구분이 자주 출제됩니다. 특히 "다음 명령어 주소 = PC", "현재 명령어 내용 = IR", "접근할 메모리 주소 = MAR", "메모리와 교환하는 데이터 = MBR"을 반드시 구분하세요.
</Callout>

### 플래그 레지스터 (PSW: Program Status Word)

ALU 연산이 끝나면 결과의 특성에 따라 여러 플래그(Flag, 1비트 신호)가 자동으로 설정됩니다. 이 플래그들을 PSW(또는 플래그 레지스터)에 저장합니다.

| 플래그 이름 | 약어 | 의미 | 언제 1이 되나? |
|-----------|------|------|--------------|
| **제로 플래그** | ZF (Zero Flag) | 연산 결과가 0 | 계산 결과가 0일 때 |
| **캐리 플래그** | CF (Carry Flag) | 올림/빌림 발생 | 부호 없는 연산에서 자리 올림/빌림이 발생할 때 |
| **부호 플래그** | SF (Sign Flag) | 결과가 음수 | 결과의 최상위 비트(MSB)가 1일 때 (음수) |
| **오버플로 플래그** | OF (Overflow Flag) | 부호 있는 오버플로 | 부호 있는 연산에서 결과가 표현 범위를 초과할 때 |

이 플래그들은 조건 분기 명령어(if, while 등)에서 사용됩니다. 예: "ZF=1이면(계산 결과가 0이면) 점프해라"

## 제어장치 (Control Unit)

**쉽게 말하면:** CPU의 사령관입니다. 명령어를 해석하고 다른 모든 부품에게 "무엇을 언제 해야 하는지" 지시합니다.

### 제어 방식 비교

| 방식 | 특징 | 속도 | 수정 용이성 | 주로 사용 |
|------|------|------|-----------|---------|
| **하드와이어드 제어 (Hardwired)** | 고정된 논리 회로로 구현 | 빠름 | 어렵음 | RISC (ARM, MIPS) |
| **마이크로프로그램 제어 (Microprogram)** | 제어 메모리에 마이크로 명령어 저장 | 느림 | 쉬움 | CISC (x86) |

## 명령어 인출 사이클에서의 레지스터 동작

명령어를 메모리에서 CPU로 가져오는 인출(Fetch) 단계에서의 순서:

1. **MAR ← PC** (프로그램 카운터의 주소를 MAR에 복사)
2. **MBR ← Memory[MAR]** (MAR이 가리키는 메모리에서 명령어를 MBR로 읽음)
3. **IR ← MBR** (MBR의 명령어를 IR에 저장)
4. **PC ← PC + 1** (다음 명령어를 가리키도록 PC를 증가)

**비유:** 도서관에서 책을 찾는 과정입니다. "몇 번 서가에서 찾을지(PC) → 서가 번호 메모(MAR) → 책을 꺼내 임시 보관(MBR) → 책 내용 확인(IR) → 다음 책 번호로 이동(PC+1)"

---

## 스택 (Stack)과 SP

**스택(Stack)**은 LIFO(Last In First Out, 마지막에 넣은 것이 먼저 나옴) 구조의 메모리 영역입니다.

**비유:** 접시를 쌓아놓은 것처럼, 마지막에 올린 접시를 먼저 꺼냅니다.

- **PUSH(푸시):** 스택에 데이터를 넣음. SP(스택 포인터)가 감소
- **POP(팝):** 스택에서 데이터를 꺼냄. SP가 증가

함수 호출, 인터럽트 처리, 임시 변수 저장 등에 사용됩니다.

---

## 핵심 정리

- **ALU:** 산술(+,-,×,÷), 논리(AND/OR/NOT), 시프트, 비교 연산 수행
- **PC:** 다음 실행할 명령어의 주소 | **IR:** 현재 명령어 내용
- **MAR:** 접근할 메모리 주소 | **MBR:** 메모리와 교환하는 데이터
- **AC(누산기):** ALU 연산 결과 저장 | **PSW:** 조건 플래그(ZF, CF, SF, OF)
- 인출 사이클 순서: MAR←PC → MBR←Memory[MAR] → IR←MBR → PC←PC+1
- **하드와이어드:** 빠르고 수정 어려움(RISC) / **마이크로프로그램:** 유연하고 느림(CISC)
