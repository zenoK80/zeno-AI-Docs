## 플립플롭(Flip-Flop)

**플립플롭**은 1비트의 정보를 저장하는 기본 기억 소자입니다. 클럭 신호에 동기화되어 동작하며 순서논리회로의 기본 구성 요소입니다.

### SR 플립플롭 (Set-Reset)

| S | R | 다음 상태 Q(t+1) |
|---|---|----------------|
| 0 | 0 | Q(t) (유지) |
| 0 | 1 | 0 (Reset) |
| 1 | 0 | 1 (Set) |
| 1 | 1 | 불확정 (금지) |

S=R=1인 상태는 금지(Forbidden) 상태로 사용하지 않습니다.

### JK 플립플롭

SR 플립플롭의 불확정 상태를 해결합니다. J=K=1이면 현재 상태를 반전(Toggle)합니다.

| J | K | 다음 상태 Q(t+1) |
|---|---|----------------|
| 0 | 0 | Q(t) (유지) |
| 0 | 1 | 0 (Reset) |
| 1 | 0 | 1 (Set) |
| 1 | 1 | Q'(t) (반전, Toggle) |

<Callout type="info">
  JK 플립플롭은 SR 플립플롭의 불확정 상태를 Toggle 기능으로 해결했으며 가장 많이 사용되는 플립플롭입니다.
</Callout>

### D 플립플롭 (Data/Delay)

입력 D의 값이 클럭이 발생하면 Q에 저장됩니다. 가장 단순한 구조입니다.

| D | 다음 상태 Q(t+1) |
|---|----------------|
| 0 | 0 |
| 1 | 1 |

### T 플립플롭 (Toggle)

T=1이면 반전, T=0이면 유지합니다. JK에서 J=K=T로 연결하면 T 플립플롭이 됩니다.

| T | 다음 상태 Q(t+1) |
|---|----------------|
| 0 | Q(t) (유지) |
| 1 | Q'(t) (반전) |

### 플립플롭 비교

| 종류 | 특징 | 주요 용도 |
|------|------|---------|
| SR | 기본, 불확정 상태 존재 | 간단한 기억 회로 |
| JK | SR 개선, Toggle 기능 | 카운터, 시프트 레지스터 |
| D | 입력=출력, 1클럭 지연 | 레지스터, 래치 |
| T | Toggle 전용 | 카운터 |

## 레지스터 (Register)

**레지스터**는 여러 플립플롭을 연결하여 다비트 데이터를 저장하는 회로입니다.

### 병렬 레지스터

모든 비트를 동시에 저장하고 출력합니다.

### 시프트 레지스터 (Shift Register)

데이터를 클럭마다 한 비트씩 이동(shift)합니다.

| 종류 | 설명 |
|------|------|
| 직렬입력-직렬출력 (SISO) | 직렬로 입력, 직렬로 출력 |
| 직렬입력-병렬출력 (SIPO) | 직렬로 입력, 병렬로 출력 |
| 병렬입력-직렬출력 (PISO) | 병렬로 입력, 직렬로 출력 |
| 병렬입력-병렬출력 (PIPO) | 병렬로 입력, 병렬로 출력 |

**시프트 레지스터의 활용:**
- 직렬-병렬 변환 (시리얼 통신)
- 곱셈/나눗셈 (2배 곱셈 = 1비트 좌측 시프트)
- 링 카운터 구현

## 카운터 (Counter)

**카운터**는 클럭 펄스 수를 세는 순서논리회로입니다.

### 비동기 카운터 (Ripple Counter)

- 각 플립플롭이 이전 플립플롭의 출력을 클럭으로 사용
- 구현 단순하지만 전파 지연(ripple delay) 발생
- n비트 비동기 카운터: n개의 T 플립플롭(또는 JK)으로 구현

### 동기 카운터

- 모든 플립플롭이 **동일한 클럭**을 사용
- 속도 빠름, 전파 지연 없음
- 회로가 복잡

### 3비트 카운터 상태표

| 클럭 | Q2 | Q1 | Q0 |
|------|----|----|-----|
| 0 | 0 | 0 | 0 |
| 1 | 0 | 0 | 1 |
| 2 | 0 | 1 | 0 |
| 3 | 0 | 1 | 1 |
| 4 | 1 | 0 | 0 |
| 5 | 1 | 0 | 1 |
| 6 | 1 | 1 | 0 |
| 7 | 1 | 1 | 1 |
| 8 | 0 | 0 | 0 (리셋) |

### 카운터의 종류

| 종류 | 특징 |
|------|------|
| **2진 카운터** | 0~(2^n-1)까지 카운트 |
| **10진 카운터 (BCD)** | 0~9까지 카운트 후 리셋 |
| **업/다운 카운터** | 증가 또는 감소 방향 선택 |
| **링 카운터** | 1비트만 순환하며 이동 |
| **존슨(Johnson) 카운터** | 링 카운터의 변형, 2n개 상태 |

## 유한 상태 기계 (Finite State Machine, FSM)

순서논리회로를 형식적으로 표현하는 방법입니다.

- **무어 기계(Moore Machine):** 출력이 현재 상태에만 의존
- **밀리 기계(Mealy Machine):** 출력이 현재 상태와 입력에 의존

## 핵심 정리

- SR 플립플롭: S=R=1 금지, JK 플립플롭: J=K=1이면 Toggle
- D 플립플롭: Q(t+1) = D, T 플립플롭: Q(t+1) = Q XOR T
- 시프트 레지스터: 데이터를 클럭마다 1비트씩 이동
- 비동기 카운터: 전파 지연 존재, 동기 카운터: 모두 같은 클럭 사용
