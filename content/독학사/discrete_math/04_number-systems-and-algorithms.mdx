## 왜 진법과 알고리즘을 함께 다루는가?

컴퓨터과학의 기초에는 항상 "데이터를 어떻게 표현할 것인가"(진법)와 "그 데이터로 무엇을 계산할 것인가"(알고리즘)라는 두 축이 있습니다. 이 문서는 컴퓨터구조·자료구조 과목에서 이미 다룬 내용을 이산수학의 관점에서 간결하게 정리합니다.

## 진법 변환 복습

> **쉽게 말하면:** 컴퓨터는 2진수(0,1)만 이해하지만, 사람이 읽기 편하도록 8진수·16진수로 축약해서 표현합니다.

**2진수 → 10진수:**

$$
1101_{(2)} = 1\times2^3+1\times2^2+0\times2^1+1\times2^0 = 13_{(10)}
$$

**10진수 → 2진수**(2로 나누며 나머지를 역순으로):

<Table>
  <thead>
    <tr><th>계산</th><th>몫</th><th>나머지</th></tr>
  </thead>
  <tbody>
    <tr><td>13÷2</td><td>6</td><td>1</td></tr>
    <tr><td>6÷2</td><td>3</td><td>0</td></tr>
    <tr><td>3÷2</td><td>1</td><td>1</td></tr>
    <tr><td>1÷2</td><td>0</td><td>1</td></tr>
  </tbody>
</Table>

**결과:** 나머지를 아래에서 위로 읽으면 $1101_{(2)}$.

## 이진 연산

$$
1011_{(2)} + 0110_{(2)} = 10001_{(2)}
$$

> **쉽게 말하면:** 이진 덧셈도 10진수 덧셈과 같은 방식이지만, "2가 되면 자리올림"이 발생합니다($1+1=10_{(2)}$).

## 알고리즘의 표현 — 의사코드(Pseudocode)

> **쉽게 말하면:** 의사코드는 특정 프로그래밍 언어의 문법에 얽매이지 않고, 사람이 이해하기 쉬운 말로 알고리즘의 논리를 적는 방법입니다.

**예시**(최댓값 찾기 알고리즘):

```
function findMax(배열 A, 길이 n):
    max = A[0]
    for i from 1 to n-1:
        if A[i] > max:
            max = A[i]
    return max
```

## 알고리즘 분석 — 시간복잡도 복습

> **쉽게 말하면:** 알고리즘 분석은 "입력 크기가 커질 때 실행 시간이 어떻게 늘어나는지"를 평가하는 것입니다.

<Table>
  <thead>
    <tr><th>표기</th><th>이름</th><th>예시</th></tr>
  </thead>
  <tbody>
    <tr><td>$O(1)$</td><td>상수 시간</td><td>배열의 특정 인덱스 접근</td></tr>
    <tr><td>$O(n)$</td><td>선형 시간</td><td>위 findMax처럼 배열 전체를 한 번 순회</td></tr>
    <tr><td>$O(n^2)$</td><td>이차 시간</td><td>이중 반복문으로 모든 쌍을 비교</td></tr>
    <tr><td>$O(\log n)$</td><td>로그 시간</td><td>매번 절반씩 줄여나가는 탐색</td></tr>
  </tbody>
</Table>

<Callout type="info">
  **findMax 알고리즘 분석하기:** 위 의사코드는 배열의 $n$개 원소를 한 번씩 확인하는 `for` 반복문 하나로 이루어져 있어, 시간복잡도는 $O(n)$입니다. 반복문 안에 반복문이 중첩되어 있었다면 $O(n^2)$이 되었을 것입니다 — 반복문의 **중첩 개수**가 다항식 복잡도의 차수를 결정하는 직관적인 기준이 됩니다.
</Callout>

## 알고리즘의 정확성 검증

<Callout type="warning">
  **자주 틀리는 점:** 알고리즘이 "빠르다"는 것과 "정확하다"는 것은 별개의 기준입니다. 아무리 빨라도 잘못된 답을 낸다면 쓸모가 없습니다. 03번 문서에서 배운 **수학적 귀납법**은 반복문이나 재귀를 사용하는 알고리즘이 모든 입력 크기에서 항상 올바른 결과를 낸다는 것을 증명하는 데 자주 활용됩니다(예: "반복문이 $k$번째 단계까지 항상 올바른 상태를 유지한다면, $k+1$번째 단계에서도 올바르다"는 논리).
</Callout>

## 핵심 정리

- **진법 변환**: 2진수 3자리=8진수 1자리, 2진수 4자리=16진수 1자리로 간단히 변환.
- **의사코드**: 특정 언어에 얽매이지 않고 알고리즘의 논리를 표현하는 방법.
- **시간복잡도**: 반복문 중첩 개수가 다항식 복잡도의 차수를 결정하는 직관적 기준.
- 알고리즘은 **속도**(효율성)뿐 아니라 **정확성**도 함께 검증해야 하며, 수학적 귀납법이 정확성 증명에 활용된다.
