## 경우의 수 기본 원리

**덧셈 원리:** 서로 배타적인 사건 A, B가 각각 $m$, $n$가지 방법이 있으면 A 또는 B의 방법은 $m + n$가지

**곱셈 원리:** 사건 A가 $m$가지, 그 각각에 대해 사건 B가 $n$가지 방법이 있으면 A와 B의 방법은 $m \times n$가지

## 순열 (Permutation)

$n$개의 서로 다른 원소에서 $r$개를 선택하여 순서 있게 배열하는 경우의 수:

$$P(n, r) = {}_nP_r = \frac{n!}{(n-r)!}$$

**예시:** 5명 중 3명을 순서대로 나열하는 방법의 수

$$P(5, 3) = \frac{5!}{(5-3)!} = \frac{120}{2} = 60$$

## 조합 (Combination)

$n$개의 서로 다른 원소에서 $r$개를 선택하는 경우의 수 (순서 무관):

$$C(n, r) = \binom{n}{r} = \frac{n!}{r!(n-r)!}$$

**예시:** 5명 중 3명을 선택하는 방법의 수

$$C(5, 3) = \frac{5!}{3! \cdot 2!} = \frac{120}{6 \times 2} = 10$$

| 항목 | 순열 $P(n,r)$ | 조합 $C(n,r)$ |
| --- | --- | --- |
| 순서 고려 | 예 | 아니오 |
| 공식 | $\frac{n!}{(n-r)!}$ | $\frac{n!}{r!(n-r)!}$ |
| 관계 | $P(n,r) = r! \cdot C(n,r)$ | |

## 이항 계수와 이항 정리

$$C(n, r) = \binom{n}{r}$$

**이항 정리:**

$$(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k$$

**파스칼의 삼각형:**

$$\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$$

```
        1
      1   1
    1   2   1
  1   3   3   1
1   4   6   4   1
```

## 중복 순열과 중복 조합

- **중복 순열:** $n$종류에서 중복 허용, $r$개 선택 순서 있게 → $n^r$
- **중복 조합:** $n$종류에서 중복 허용, $r$개 선택 순서 없이 → $\binom{n+r-1}{r}$

## 비둘기집 원리 (Pigeonhole Principle)

$n+1$개의 물건을 $n$개의 상자에 넣으면 적어도 하나의 상자에 2개 이상의 물건이 들어갑니다.

## 핵심 정리

- 순열: $P(n,r) = n!/(n-r)!$ — 순서 중요
- 조합: $C(n,r) = n!/(r!(n-r)!)$ — 순서 무관
- 관계: $P(n,r) = r! \times C(n,r)$
- 이항 정리: $(x+y)^n = \sum \binom{n}{k} x^{n-k} y^k$
