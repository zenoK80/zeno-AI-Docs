## 재귀적 정의 (Recursive Definition)

**재귀적 정의**는 기저 단계(base case)와 재귀 단계(recursive case)로 이루어집니다.

**팩토리얼 정의:**
- 기저: $0! = 1$
- 재귀: $n! = n \times (n-1)!$ for $n \geq 1$

**피보나치 수열:**
- 기저: $F(0) = 0$, $F(1) = 1$
- 재귀: $F(n) = F(n-1) + F(n-2)$ for $n \geq 2$

## 점화식 (Recurrence Relation)

점화식은 수열의 $n$번째 항을 이전 항들로 표현한 방정식입니다.

**등차 점화식:** $a_n = a_{n-1} + d$ → $a_n = a_0 + nd$

**등비 점화식:** $a_n = r \cdot a_{n-1}$ → $a_n = a_0 \cdot r^n$

## 점화식 풀이 방법

### 반복 대입법 (Iteration Method)

$T(n) = 2T(n/2) + n$ 풀이:

$$\begin{aligned}
T(n) &= 2T(n/2) + n \\
     &= 2(2T(n/4) + n/2) + n = 4T(n/4) + 2n \\
     &= 4(2T(n/8) + n/4) + 2n = 8T(n/8) + 3n \\
     &= \ldots = 2^k T(n/2^k) + kn
\end{aligned}$$

$n/2^k = 1$이면 $k = \log n$이므로 $T(n) = n + n\log n = O(n \log n)$

### 마스터 정리 (Master Theorem)

$T(n) = aT(n/b) + f(n)$, $a \geq 1$, $b > 1$ 형태의 점화식에 적용합니다.

| 경우 | 조건 | 결과 |
| --- | --- | --- |
| 경우 1 | $f(n) = O(n^{\log_b a - \epsilon})$ | $T(n) = \Theta(n^{\log_b a})$ |
| 경우 2 | $f(n) = \Theta(n^{\log_b a})$ | $T(n) = \Theta(n^{\log_b a} \log n)$ |
| 경우 3 | $f(n) = \Omega(n^{\log_b a + \epsilon})$ | $T(n) = \Theta(f(n))$ |

**예시 1:** $T(n) = 2T(n/2) + n$
- $a=2, b=2, f(n)=n, n^{\log_2 2} = n$
- $f(n) = n = \Theta(n^1)$ → 경우 2 → $T(n) = \Theta(n \log n)$

**예시 2:** $T(n) = 4T(n/2) + n$
- $a=4, b=2, n^{\log_2 4} = n^2$
- $f(n) = n = O(n^{2-1})$ → 경우 1 → $T(n) = \Theta(n^2)$

## 대표 점화식 결과

| 점화식 | 예시 알고리즘 | 결과 |
| --- | --- | --- |
| $T(n) = T(n-1) + 1$ | 순차 탐색 | $O(n)$ |
| $T(n) = T(n/2) + 1$ | 이진 탐색 | $O(\log n)$ |
| $T(n) = 2T(n/2) + n$ | 합병 정렬 | $O(n \log n)$ |
| $T(n) = 2T(n/2) + 1$ | 이진 트리 순회 | $O(n)$ |

## 핵심 정리

- 점화식: 이전 항으로 현재 항을 정의
- 마스터 정리: $T(n) = aT(n/b) + f(n)$ 형태에 적용
- $n^{\log_b a}$와 $f(n)$ 비교로 세 가지 경우 결정
- 합병 정렬: $T(n) = 2T(n/2) + n$ → $O(n \log n)$
