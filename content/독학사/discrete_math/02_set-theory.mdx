## 집합의 기본 개념

**집합(Set)** 은 잘 정의된 서로 다른 원소들의 모임입니다.

| 기호 | 의미 |
| --- | --- |
| $a \in A$ | a는 집합 A의 원소이다 |
| $a \notin A$ | a는 집합 A의 원소가 아니다 |
| $\emptyset$ | 원소가 없는 공집합 |
| $\|A\|$ | 집합 A의 원소 수(카디날리티) |
| $A \subseteq B$ | A는 B의 부분집합 |
| $A \subset B$ | A는 B의 진부분집합(A≠B) |

## 집합의 연산

| 연산 | 기호 | 정의 |
| --- | --- | --- |
| 합집합 | $A \cup B$ | A 또는 B에 속하는 원소의 집합 |
| 교집합 | $A \cap B$ | A와 B 모두에 속하는 원소의 집합 |
| 차집합 | $A - B$ | A에 속하지만 B에 속하지 않는 원소의 집합 |
| 보집합 | $\bar{A}$ or $A^c$ | 전체 집합 U에서 A를 제외한 집합 |

**예시:** $A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6\}$

- $A \cup B = \{1, 2, 3, 4, 5, 6\}$
- $A \cap B = \{3, 4\}$
- $A - B = \{1, 2\}$
- $B - A = \{5, 6\}$

## 집합의 법칙

| 법칙 | 내용 |
| --- | --- |
| 교환 법칙 | $A \cup B = B \cup A$, $A \cap B = B \cap A$ |
| 결합 법칙 | $(A \cup B) \cup C = A \cup (B \cup C)$ |
| 분배 법칙 | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ |
| 드모르간 법칙 | $\overline{A \cup B} = \bar{A} \cap \bar{B}$ |
| 드모르간 법칙 | $\overline{A \cap B} = \bar{A} \cup \bar{B}$ |
| 동일 법칙 | $A \cup \emptyset = A$, $A \cap U = A$ |

## 멱집합 (Power Set)

**멱집합 $\mathcal{P}(A)$** 는 집합 A의 모든 부분집합의 집합입니다.

$|A| = n$이면 $|\mathcal{P}(A)| = 2^n$

**예시:** $A = \{1, 2, 3\}$ ($n=3$)

$$\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}$$

원소 수: $2^3 = 8$

**진부분집합의 수:** $2^n - 1$ (자기 자신을 제외)

## 포함-배제 원리

두 집합의 합집합 원소 수:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

세 집합의 경우:

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |A \cap C| + |A \cap B \cap C|$$

## 집합의 분할 (Partition)

집합 A의 **분할**은 A의 비어있지 않은 부분집합들의 모임으로, 각 부분집합이 서로 겹치지 않고 합집합이 A 전체가 되는 것입니다.

## 핵심 정리

- 멱집합 크기: $|A| = n$이면 $2^n$, 진부분집합은 $2^n - 1$
- 포함-배제: $|A \cup B| = |A| + |B| - |A \cap B|$
- 드모르간: $\overline{A \cup B} = \bar{A} \cap \bar{B}$
- 분할: 서로소이고 합이 전체 집합이 되는 부분집합들의 모임
