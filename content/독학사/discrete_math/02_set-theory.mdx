## 왜 집합이 필요한가?

"수학 동아리 학생"과 "체육 동아리 학생" 중에서 두 동아리 모두 가입한 학생을 찾으려면? 집합(set) 연산을 쓰면 됩니다. 데이터베이스의 SQL JOIN, 검색 엔진의 결과 필터링, 프로그래밍의 자료구조 모두 집합론이 기반입니다.

## 집합의 기본 개념 (Set)

**쉽게 말하면:** 집합(set)은 어떤 기준에 따라 명확하게 구분할 수 있는 서로 다른 원소들의 모임입니다.

**집합**(Set) 은 잘 정의된 서로 다른 원소(element)들의 모임입니다.

| 기호 | 읽기 | 의미 |
| --- | --- | --- |
| $a \in A$ | a는 A에 속한다 | a는 집합 A의 원소이다 |
| $a \notin A$ | a는 A에 속하지 않는다 | a는 집합 A의 원소가 아니다 |
| $\emptyset$ | 공집합 | 원소가 없는 집합 |
| $\|A\|$ | A의 카디날리티 | 집합 A의 원소 수 |
| $A \subseteq B$ | A는 B의 부분집합 | A의 모든 원소가 B에도 있다 |
| $A \subset B$ | A는 B의 진부분집합 | A는 B의 부분집합이지만 A ≠ B |

**기호 읽는 법:**
- $\in$ (in, 원소 기호): "속한다"를 뜻함
- $\emptyset$ (empty set, 공집합): 원소가 하나도 없는 집합
- $\subseteq$ (subset, 부분집합): A의 모든 원소가 B에도 들어있다
- $\|A\|$ (cardinality, 카디날리티): 집합의 원소 개수

**집합 표현법:**
- 원소 나열법: $A = \{1, 2, 3, 4\}$
- 조건 제시법: $B = \{x \mid x\text{는 양의 짝수}\} = \{2, 4, 6, ...\}$

<Callout type="info">
  **비유:** 집합은 상자와 같습니다. 상자 A에는 사과, 바나나, 오렌지가 들어있고, 상자 B에는 바나나, 오렌지, 포도가 들어있다고 할 때, 두 상자에 모두 있는 과일은 바나나와 오렌지입니다. 이것이 교집합입니다.
</Callout>

## 집합의 연산 (Set Operations)

| 연산 | 기호 | 읽기 | 정의 |
| --- | --- | --- | --- |
| 합집합(Union) | $A \cup B$ | A union B | A 또는 B에 속하는 원소 전체 |
| 교집합(Intersection) | $A \cap B$ | A intersection B | A와 B 모두에 속하는 원소 |
| 차집합(Difference) | $A - B$ | A minus B | A에 속하지만 B에 속하지 않는 원소 |
| 보집합(Complement) | $\bar{A}$ 또는 $A^c$ | A의 보집합 | 전체 집합 U에서 A를 제외한 원소 |
| 대칭 차집합(Symmetric Difference) | $A \triangle B$ | A symmetric difference B | A와 B 중 어느 한쪽에만 속하는 원소 |

**구체적 예시:** $A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6\}$

- $A \cup B = \{1, 2, 3, 4, 5, 6\}$ (두 집합의 모든 원소)
- $A \cap B = \{3, 4\}$ (두 집합에 공통으로 있는 원소)
- $A - B = \{1, 2\}$ (A에 있지만 B에 없는 원소)
- $B - A = \{5, 6\}$ (B에 있지만 A에 없는 원소)
- $A \triangle B = \{1, 2, 5, 6\}$ (한쪽에만 있는 원소)

## 집합의 법칙 (Set Laws)

집합 연산도 수의 연산처럼 여러 법칙이 있습니다. 논리 연산과 매우 유사합니다.

| 법칙 | 합집합 형태 | 교집합 형태 |
| --- | --- | --- |
| 교환(Commutative) | $A \cup B = B \cup A$ | $A \cap B = B \cap A$ |
| 결합(Associative) | $(A \cup B) \cup C = A \cup (B \cup C)$ | $(A \cap B) \cap C = A \cap (B \cap C)$ |
| 분배(Distributive) | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ |
| 동일(Identity) | $A \cup \emptyset = A$ | $A \cap U = A$ |
| 드모르간(De Morgan) | $\overline{A \cup B} = \bar{A} \cap \bar{B}$ | $\overline{A \cap B} = \bar{A} \cup \bar{B}$ |

**드모르간 법칙 기억법 (집합 버전):**
- NOT(A OR B) = NOT A AND NOT B → 합집합의 보집합 = 두 보집합의 교집합
- NOT(A AND B) = NOT A OR NOT B → 교집합의 보집합 = 두 보집합의 합집합

## 멱집합 (Power Set)

**쉽게 말하면:** 멱집합(power set)이란 어떤 집합의 모든 부분집합을 원소로 갖는 집합입니다. "부분집합들의 집합"입니다.

**멱집합 $\mathcal{P}(A)$** 는 집합 A의 모든 부분집합의 집합입니다.

$$|A| = n \text{ 이면 } |\mathcal{P}(A)| = 2^n$$

**왜 $2^n$인가?** 각 원소를 부분집합에 넣거나(1) 넣지 않거나(0) 2가지 선택이 있으므로, n개 원소에 대해 $2 \times 2 \times ... \times 2 = 2^n$가지 부분집합이 생깁니다.

**예시:** $A = \{1, 2, 3\}$ ($n=3$)

$$\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}$$

원소 수: $2^3 = 8$

| 부분집합 | 포함된 원소 |
| --- | --- |
| $\emptyset$ | 아무것도 없음 |
| $\{1\}$, $\{2\}$, $\{3\}$ | 원소 1개씩 |
| $\{1,2\}$, $\{1,3\}$, $\{2,3\}$ | 원소 2개씩 |
| $\{1,2,3\}$ | 원소 3개(전체) |

**진부분집합(Proper Subset)의 수:** $2^n - 1$ (자기 자신을 제외)

## 포함-배제 원리 (Inclusion-Exclusion Principle)

**쉽게 말하면:** 두 집합의 합집합 원소 수를 구할 때, 단순히 더하면 교집합이 두 번 세어집니다. 그래서 한 번 빼줍니다.

두 집합의 합집합 원소 수:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

**예:** 학급에서 수학을 좋아하는 학생 10명, 영어를 좋아하는 학생 8명, 둘 다 좋아하는 학생 3명이라면 수학 또는 영어를 좋아하는 학생 수는?

$$|A \cup B| = 10 + 8 - 3 = 15$$

세 집합의 경우:

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |A \cap C| + |A \cap B \cap C|$$

## 집합의 분할 (Partition)

**쉽게 말하면:** 분할(partition)이란 집합 A를 겹치지 않게 여러 조각으로 나누는 것입니다. 퍼즐 조각처럼 딱 맞아 떨어져야 합니다.

집합 A의 **분할**은 다음 조건을 만족하는 비어있지 않은 부분집합들의 모임입니다:
1. 각 부분집합이 서로 겹치지 않음(서로소, pairwise disjoint)
2. 모든 부분집합의 합집합이 A 전체

**예:** $A = \{1, 2, 3, 4, 5, 6\}$의 분할 예시
- $\{\{1,2\}, \{3,4\}, \{5,6\}\}$ — 유효한 분할 (겹치지 않고 합집합이 A)
- $\{\{1,2,3\}, \{3,4,5,6\}\}$ — 유효하지 않음 (3이 겹침)

## 핵심 정리

- 멱집합 크기: $|A| = n$이면 $|\mathcal{P}(A)| = 2^n$, 진부분집합은 $2^n - 1$
- 포함-배제: $|A \cup B| = |A| + |B| - |A \cap B|$
- 드모르간: $\overline{A \cup B} = \bar{A} \cap \bar{B}$ / $\overline{A \cap B} = \bar{A} \cup \bar{B}$
- 분할: 서로소이고 합이 전체 집합이 되는 부분집합들의 모임
