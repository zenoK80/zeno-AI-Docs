## 함수의 정의

**함수(Function)** $f: A \rightarrow B$는 집합 A(정의역)의 각 원소에 집합 B(공역)의 원소를 정확히 하나 대응시키는 관계입니다.

- **정의역(Domain):** 함수의 입력 집합 A
- **공역(Codomain):** 함수의 출력이 속할 집합 B
- **치역(Range/Image):** 실제 출력값들의 집합 $f(A) \subseteq B$

## 함수의 종류

### 단사 함수 (One-to-One / Injective)

서로 다른 원소는 서로 다른 함수값을 가집니다.

$$f(a) = f(b) \Rightarrow a = b$$

즉, 두 입력이 같은 출력을 가지면 그 두 입력은 반드시 같아야 합니다.

### 전사 함수 (Onto / Surjective)

공역의 모든 원소가 적어도 하나의 정의역 원소에 대응됩니다.

$$\forall b \in B,\ \exists a \in A : f(a) = b$$

즉, 치역과 공역이 일치합니다: $f(A) = B$

### 전단사 함수 (Bijective / One-to-One Correspondence)

단사이면서 전사인 함수입니다. 정의역과 공역 사이에 완전한 일대일 대응이 성립합니다.

| 종류 | 조건 | 역함수 존재 |
| --- | --- | --- |
| 단사(Injective) | 입력 다르면 출력 다름 | 가능하지 않을 수 있음 |
| 전사(Surjective) | 치역 = 공역 | 가능하지 않을 수 있음 |
| 전단사(Bijective) | 단사 + 전사 | 항상 존재 |

## 역함수 (Inverse Function)

전단사 함수 $f: A \rightarrow B$에 대해 역함수 $f^{-1}: B \rightarrow A$가 존재합니다.

$$f^{-1}(f(a)) = a,\quad f(f^{-1}(b)) = b$$

**예시:** $f(x) = 2x + 3$의 역함수

$$y = 2x + 3 \Rightarrow x = \frac{y-3}{2} \Rightarrow f^{-1}(x) = \frac{x-3}{2}$$

## 합성함수 (Composite Function)

$f: A \rightarrow B$, $g: B \rightarrow C$일 때 합성함수 $g \circ f: A \rightarrow C$는 다음과 같습니다.

$$(g \circ f)(x) = g(f(x))$$

<Callout type="warning">
  합성함수는 일반적으로 교환 법칙이 성립하지 않습니다. $g \circ f \neq f \circ g$
</Callout>

**예시:** $f(x) = x + 1$, $g(x) = 2x$일 때

$$(g \circ f)(3) = g(f(3)) = g(4) = 8$$
$$(f \circ g)(3) = f(g(3)) = f(6) = 7$$

## 바닥 함수와 천장 함수

- **바닥 함수(Floor):** $\lfloor x \rfloor$ — x보다 크지 않은 최대 정수 ($\lfloor 3.7 \rfloor = 3$)
- **천장 함수(Ceiling):** $\lceil x \rceil$ — x보다 작지 않은 최소 정수 ($\lceil 3.2 \rceil = 4$)

## 핵심 정리

- 단사: $f(a) = f(b) \Rightarrow a = b$ (다른 입력은 다른 출력)
- 전사: 치역 = 공역 (모든 출력값이 실제로 나옴)
- 전단사: 단사 + 전사, 역함수 존재
- 합성: $(g \circ f)(x) = g(f(x))$, 일반적으로 교환 법칙 불성립
