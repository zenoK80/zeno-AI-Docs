## 왜 함수가 필요한가?

컴퓨터의 모든 프로그램은 사실 함수(function)의 집합입니다. 입력을 넣으면 출력이 나오는 구조입니다. 데이터베이스의 키(key)와 값(value) 매핑, 암호화 알고리즘, 머신러닝의 모델 — 모두 수학적 함수 개념을 기반으로 합니다.

## 함수의 정의 (Function)

**쉽게 말하면:** 함수(function)는 자판기와 같습니다. 버튼(입력)을 누르면 음료수(출력)가 나오는데, 같은 버튼을 누르면 항상 같은 음료수가 나옵니다. 한 입력에는 반드시 하나의 출력만 있습니다.

**함수**(Function) $f: A \rightarrow B$는 집합 A(정의역)의 각 원소에 집합 B(공역)의 원소를 **정확히 하나** 대응시키는 관계입니다.

- **정의역(Domain):** 함수의 입력 집합 A. "어디서 출발하나?"
- **공역(Codomain):** 함수의 출력이 속할 집합 B. "어디로 갈 수 있나?"
- **치역(Range/Image):** 실제 출력값들의 집합 $f(A) \subseteq B$. "실제로 어디 도착했나?"

**중요한 규칙:** 함수에서 하나의 입력 $a$는 반드시 정확히 하나의 출력 $f(a)$에 대응해야 합니다. 출력 없음(X), 두 가지 출력(X)은 함수가 아닙니다.

**생활 예시:**
- 자판기: 버튼(입력) → 음료수(출력). 한 버튼에 하나의 음료수
- 학번 → 학생 이름: 학번 하나에 학생 이름 하나

## 함수의 3가지 종류

### 단사 함수 (Injective / One-to-One Function)

**쉽게 말하면:** 단사 함수(injective function)는 "서로 다른 입력은 서로 다른 출력을 가진다"는 성질입니다. 두 사람이 같은 자리에 앉을 수 없는 좌석 배치와 같습니다.

$$f(a) = f(b) \Rightarrow a = b$$

(또는 대우: $a \neq b \Rightarrow f(a) \neq f(b)$)

**예:** $f(x) = 2x$는 단사함수 — 다른 x값은 반드시 다른 2x값을 가짐

**단사가 아닌 예:** $f(x) = x^2$는 단사가 아님 — $f(2) = f(-2) = 4$ (다른 입력이 같은 출력)

### 전사 함수 (Surjective / Onto Function)

**쉽게 말하면:** 전사 함수(surjective function)는 공역의 모든 원소에 반드시 도달하는 함수입니다. "아무도 소외되지 않는" 함수입니다.

$$\forall b \in B,\ \exists a \in A : f(a) = b$$

즉, 치역(range) = 공역(codomain): $f(A) = B$

**기호 설명:**
- $\forall$ (for all, 모든): "모든 원소에 대해"
- $\exists$ (there exists, 존재): "적어도 하나가 존재한다"

**예:** $f: \{1,2,3\} \rightarrow \{a,b\}$에서 $f(1)=a, f(2)=b, f(3)=a$이면 전사함수 (a, b 모두 도달)

### 전단사 함수 (Bijective Function)

**쉽게 말하면:** 전단사 함수(bijective function)는 단사이면서 전사인 함수입니다. "완벽한 1대1 짝꿍 매칭"입니다. 30명 학생과 30개 좌석이 정확히 1대1로 매칭되는 경우입니다.

전단사 함수(Bijection)는 단사(Injective) + 전사(Surjective)를 동시에 만족합니다.

| 종류 | 다른 이름 | 조건 | 역함수 존재 |
| --- | --- | --- | --- |
| 단사(Injective) | One-to-One | 입력 달리면 출력 다름 | 항상 존재하지 않을 수 있음 |
| 전사(Surjective) | Onto | 치역 = 공역 | 항상 존재하지 않을 수 있음 |
| 전단사(Bijective) | One-to-One Correspondence | 단사 + 전사 | **항상 존재** |

**비유로 정리:**
- 단사: 학생 → 좌석. 두 학생이 같은 좌석에 앉지 않음 (좌석이 남을 수 있음)
- 전사: 학생 → 좌석. 빈 좌석 없음 (한 좌석에 여러 학생이 앉을 수 있음)
- 전단사: 학생 → 좌석. 딱 맞게 1대1 매칭 (학생 수 = 좌석 수)

## 역함수 (Inverse Function)

**쉽게 말하면:** 역함수(inverse function)는 함수의 방향을 뒤집은 것입니다. "언도(undo)" 버튼입니다. $f$가 "x를 f(x)로 보내면", $f^{-1}$은 "f(x)를 다시 x로 되돌립니다."

전단사 함수 $f: A \rightarrow B$에 대해 역함수 $f^{-1}: B \rightarrow A$가 존재합니다.

$$f^{-1}(f(a)) = a \quad \text{그리고} \quad f(f^{-1}(b)) = b$$

**역함수 구하는 방법:**
1. $y = f(x)$로 놓는다
2. $x$를 $y$로 표현한다
3. $x$와 $y$를 바꾼다

**예시:** $f(x) = 2x + 3$의 역함수

$$y = 2x + 3 \rightarrow 2x = y - 3 \rightarrow x = \frac{y-3}{2} \rightarrow f^{-1}(x) = \frac{x-3}{2}$$

**확인:** $f(f^{-1}(x)) = 2 \cdot \frac{x-3}{2} + 3 = (x-3) + 3 = x$ ✓

<Callout type="warning">
  역함수는 전단사 함수에서만 항상 존재합니다. 단사만이거나 전사만인 경우에는 역함수가 존재하지 않거나 유일하지 않을 수 있습니다.
</Callout>

## 합성함수 (Composite Function)

**쉽게 말하면:** 합성함수(composite function)는 두 함수를 연속으로 적용하는 것입니다. 첫 번째 공장에서 원재료를 반제품으로 만들고, 두 번째 공장에서 반제품을 완제품으로 만드는 과정입니다.

$f: A \rightarrow B$, $g: B \rightarrow C$일 때 합성함수 $g \circ f: A \rightarrow C$는 다음과 같습니다:

$$(g \circ f)(x) = g(f(x))$$

**기호 읽는 법:** $g \circ f$는 "g 합성 f" 또는 "g after f"로 읽습니다.

**중요:** $g \circ f$에서 **먼저 적용되는 함수는 $f$** 입니다! (안쪽 먼저)

**예시:** $f(x) = x + 1$, $g(x) = 2x$일 때

$$(g \circ f)(3) = g(f(3)) = g(4) = 8$$
$$(f \circ g)(3) = f(g(3)) = f(6) = 7$$

<Callout type="warning">
  합성함수는 일반적으로 교환 법칙이 성립하지 않습니다: $g \circ f \neq f \circ g$
  위 예시에서 $g \circ f = 8$이고 $f \circ g = 7$로 다릅니다.
</Callout>

## 바닥 함수와 천장 함수

프로그래밍에서 자주 사용되는 특수 함수입니다.

- **바닥 함수(Floor Function):** $\lfloor x \rfloor$ — x보다 크지 않은 최대 정수 (내림)
  - $\lfloor 3.7 \rfloor = 3$, $\lfloor -1.2 \rfloor = -2$
- **천장 함수(Ceiling Function):** $\lceil x \rceil$ — x보다 작지 않은 최소 정수 (올림)
  - $\lceil 3.2 \rceil = 4$, $\lceil -1.2 \rceil = -1$

**비유:** 바닥 함수는 "버림", 천장 함수는 "올림"입니다.

## 핵심 정리

- 함수: 정의역의 각 원소에 공역의 원소를 정확히 하나 대응
- 단사(Injective): $f(a) = f(b) \Rightarrow a = b$ (다른 입력 → 다른 출력)
- 전사(Surjective): 치역 = 공역 (모든 공역 원소가 실제로 출력됨)
- 전단사(Bijective): 단사 + 전사, 역함수 항상 존재
- 합성: $(g \circ f)(x) = g(f(x))$, 일반적으로 교환 법칙 불성립
