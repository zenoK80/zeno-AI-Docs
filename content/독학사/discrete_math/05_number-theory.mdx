## 정수 나눗셈과 나머지

정수 $a$를 양의 정수 $d$로 나눌 때:

$$a = dq + r, \quad 0 \leq r < d$$

여기서 $q$는 몫(quotient), $r$은 나머지(remainder)입니다.

표기: $r = a \mod d$

## 약수와 배수

- $d \mid a$: d는 a의 약수 (a를 d로 나눌 때 나머지가 0)
- $d \nmid a$: d는 a의 약수가 아님

## 최대공약수 (GCD)

두 정수 $a$, $b$의 최대공약수(Greatest Common Divisor)는 $a$와 $b$ 모두의 약수 중 최대값입니다.

$$\gcd(a, b) = \gcd(b, a \mod b)$$

## 유클리드 알고리즘 (Euclidean Algorithm)

$\gcd(a, b)$를 나머지 연산의 반복으로 효율적으로 구합니다.

**예시:** $\gcd(252, 198)$ 계산

```
gcd(252, 198): 252 = 198 × 1 + 54  → gcd(198, 54)
gcd(198, 54):  198 = 54 × 3  + 36  → gcd(54, 36)
gcd(54, 36):   54  = 36 × 1  + 18  → gcd(36, 18)
gcd(36, 18):   36  = 18 × 2  + 0   → gcd(18, 0) = 18

∴ gcd(252, 198) = 18
```

시간 복잡도: $O(\log(\min(a, b)))$

## 최소공배수 (LCM)

$$\text{lcm}(a, b) = \frac{a \times b}{\gcd(a, b)}$$

## 모듈러 산술 (Modular Arithmetic)

정수 $a$와 $b$가 모듈러 $m$에 대해 합동이면:

$$a \equiv b \pmod{m} \iff m \mid (a - b)$$

**모듈러 연산의 성질:**

$$\begin{aligned}
(a + b) \bmod m &= ((a \bmod m) + (b \bmod m)) \bmod m \\
(a \times b) \bmod m &= ((a \bmod m) \times (b \bmod m)) \bmod m
\end{aligned}$$

## 페르마의 소정리

$p$가 소수이고 $p \nmid a$이면:

$$a^{p-1} \equiv 1 \pmod{p}$$

암호학(RSA 등)의 수학적 기반이 됩니다.

## 중국인의 나머지 정리 (CRT)

$m_1, m_2, ..., m_k$가 쌍마다 서로소일 때, 연립 합동 방정식의 해가 유일하게 존재합니다.

## 핵심 정리

- 유클리드: $\gcd(a, b) = \gcd(b, a \bmod b)$
- $\text{lcm}(a, b) = a \times b / \gcd(a, b)$
- 모듈러 덧셈과 곱셈은 각각 mod 연산 후 다시 mod 가능
- 모듈러 합동은 동치 관계를 형성
