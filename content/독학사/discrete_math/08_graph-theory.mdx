## 왜 그래프 이론이 필요한가?

내비게이션의 길 찾기(최단 경로), 소셜 네트워크의 친구 관계, 인터넷의 라우팅, 전기 회로 설계 — 모두 그래프 이론(graph theory)으로 모델링됩니다. 그래프는 "점과 선"으로 세상의 복잡한 관계를 표현하는 가장 강력한 도구입니다.

<Callout type="info">
  **역사:** 그래프 이론은 1736년 오일러(Euler)가 "쾨니히스베르크의 7개 다리 문제"를 풀면서 시작되었습니다. "7개 다리를 한 번씩만 건너서 모든 다리를 지날 수 있는가?" — 그 답이 오일러 경로입니다.
</Callout>

## 그래프의 기본 용어

**그래프(Graph)** $G = (V, E)$는 정점 집합 $V$와 간선 집합 $E$로 구성됩니다.

| 용어 | 영어 | 설명 |
| --- | --- | --- |
| 정점(꼭짓점) | Vertex | 그래프의 점, 노드(Node)라고도 함 |
| 간선(변) | Edge | 두 정점을 연결하는 선 |
| 차수 | Degree | 한 정점에 연결된 간선의 수 |
| 경로 | Path | 정점들의 순서 있는 나열로 인접 정점이 간선으로 연결 |
| 사이클 | Cycle | 시작과 끝이 같은 경로 (닫힌 경로) |
| 연결 그래프 | Connected Graph | 모든 정점 쌍 사이에 경로가 존재하는 그래프 |
| 완전 그래프 | Complete Graph | 모든 정점 쌍이 간선으로 직접 연결된 그래프 |

**그래프 종류:**
- **단순 그래프(Simple Graph):** 두 정점 사이에 간선이 최대 1개, 자기 자신으로 돌아오는 간선 없음
- **유향 그래프(Directed Graph):** 간선에 방향이 있음 (한방통행)
- **무향 그래프(Undirected Graph):** 간선에 방향이 없음 (양방통행)
- **가중 그래프(Weighted Graph):** 간선에 가중치(비용, 거리 등)가 있음

**차수의 합 정리:** 그래프에서 모든 정점의 차수의 합 = 간선 수의 2배

$$\sum_{v \in V} \deg(v) = 2|E|$$

**왜인가?** 각 간선은 두 정점의 차수에 각각 1씩 기여하기 때문입니다.

**따름 정리:** 차수가 홀수인 정점의 수는 항상 짝수입니다. (홀수들의 합이 짝수가 되려면 홀수가 짝수 개여야 합니다.)

## 오일러 경로와 오일러 회로

### 오일러 경로 (Eulerian Path / Trail)

**쉽게 말하면:** 오일러 경로(Eulerian path)는 그래프의 **모든 간선을 정확히 한 번씩** 지나는 경로입니다. "모든 다리를 한 번씩 건너는 산책로"입니다.

### 오일러 회로 (Eulerian Circuit)

**쉽게 말하면:** 오일러 회로(Eulerian circuit)는 시작점과 끝점이 같은 오일러 경로입니다. "모든 다리를 한 번씩 건너고 집으로 돌아오는 산책"입니다.

**존재 조건:**

| 조건 | 오일러 경로 | 오일러 회로 |
| --- | --- | --- |
| 연결 그래프 | 반드시 필요 | 반드시 필요 |
| 홀수 차수 정점 수 | 정확히 2개 | 0개(모두 짝수) |
| 출발점, 도착점 | 홀수 차수 정점들 | 어느 정점에서도 가능 |

<Callout type="warning">
  **기억법:** 오일러 경로는 홀수 차수 정점이 "딱 2개"일 때 존재합니다. 오일러 회로는 홀수 차수 정점이 "0개"일 때 존재합니다.

  쾨니히스베르크의 7개 다리 문제: 홀수 차수 정점이 4개이므로 오일러 경로도 오일러 회로도 존재하지 않습니다!
</Callout>

## 해밀턴 경로와 해밀턴 회로

### 해밀턴 경로 (Hamiltonian Path)

**쉽게 말하면:** 해밀턴 경로(Hamiltonian path)는 그래프의 **모든 정점을 정확히 한 번씩** 방문하는 경로입니다. "모든 도시를 한 번씩 방문하는 여행"입니다.

### 해밀턴 회로 (Hamiltonian Circuit)

시작점과 끝점이 같은 해밀턴 경로입니다. "외판원 문제(Traveling Salesman Problem)"가 해밀턴 회로 문제입니다.

**오일러 vs 해밀턴 비교:**

| 구분 | 오일러 | 해밀턴 |
| --- | --- | --- |
| 대상 | 모든 **간선** | 모든 **정점** |
| 중복 방지 | 간선 중복 불가 | 정점 중복 불가 |
| 판별 방법 | 효율적 (차수 조건 확인) | NP-완전 (빠른 알고리즘 없음) |

<Callout type="warning">
  해밀턴 경로의 존재 여부를 효율적으로 결정하는 알고리즘은 아직 없습니다. 이는 NP-완전(NP-Complete) 문제입니다. 이론 컴퓨터 과학의 가장 큰 미해결 문제 중 하나입니다.
</Callout>

## 동형 그래프 (Isomorphic Graphs)

**쉽게 말하면:** 두 그래프가 모양은 달라 보여도 "구조적으로 같다"면 동형(isomorphic)이라 합니다. 점들의 이름을 바꾸면 두 그래프가 완전히 일치하는 경우입니다.

두 그래프 $G_1$과 $G_2$가 동형이 되려면:
- 정점 수가 같아야 합니다
- 간선 수가 같아야 합니다
- 차수 수열(각 정점의 차수를 정렬한 것)이 같아야 합니다

## 평면 그래프 (Planar Graph)

**쉽게 말하면:** 평면 그래프(planar graph)는 간선이 교차하지 않도록 평면에 그릴 수 있는 그래프입니다. "선들이 서로 겹치지 않도록 그릴 수 있는" 그래프입니다.

**오일러 공식(Euler's Formula):** 연결 평면 그래프에서

$$V - E + F = 2$$

- $V$: 정점(Vertex) 수
- $E$: 간선(Edge) 수
- $F$: 면(Face) 수 — 외부 무한 면도 포함

**예:** 정육면체(큐브)를 평면에 펼치면: $V=8, E=12, F=6$ → $8 - 12 + 6 = 2$ ✓

**비평면 그래프의 대표:**
- $K_5$ (정점 5개 완전 그래프): 평면 그래프가 아님
- $K_{3,3}$ (완전 이분 그래프): 평면 그래프가 아님

**쿠라토프스키 정리:** $K_5$와 $K_{3,3}$을 부분 그래프로 포함하지 않으면 평면 그래프입니다.

## 그래프 색칠 (Graph Coloring)

**쉽게 말하면:** 그래프 색칠(graph coloring)은 인접한 두 정점이 다른 색을 갖도록 최소한의 색으로 정점에 색을 배당하는 문제입니다. 지도에서 인접한 나라를 다른 색으로 칠하는 것과 같습니다.

- **색 수(Chromatic Number) $\chi(G)$:** 그래프를 색칠하는 데 필요한 최소 색의 수
- **4색 정리(Four Color Theorem):** 모든 평면 그래프는 4가지 이하의 색으로 색칠 가능합니다.

**이분 그래프(Bipartite Graph):** 정점을 두 그룹으로 나눌 수 있고, 간선이 두 그룹 사이에만 있는 그래프. 색 수가 2입니다.

## 핵심 정리

- 차수의 합 = 2 × 간선 수 (각 간선이 두 정점의 차수에 기여)
- 오일러 회로: 연결 그래프이고 홀수 차수 정점 수 = 0
- 오일러 경로: 연결 그래프이고 홀수 차수 정점 수 = 2
- 해밀턴: 모든 정점을 한 번씩, NP-완전 문제
- 평면 그래프 오일러 공식: $V - E + F = 2$
- 4색 정리: 모든 평면 그래프는 4가지 색으로 칠할 수 있음
