## 트리의 정의와 성질

**트리(Tree)** 는 연결되어 있고 사이클이 없는 단순 그래프입니다.

**트리의 성질 (n개의 정점일 때):**

| 성질 | 내용 |
| --- | --- |
| 간선 수 | 정확히 $n-1$개 |
| 경로 | 임의의 두 정점 사이에 경유 경로가 유일하게 존재 |
| 연결성 | 어떤 간선을 제거해도 연결이 끊어짐 (최소 연결 그래프) |
| 사이클 | 없음 |

## 루트 트리 (Rooted Tree)

특정 정점을 루트로 지정한 트리입니다. 루트에서 각 정점으로의 방향이 결정됩니다.

- **레벨(Level):** 루트에서 해당 정점까지의 거리 (루트 = 0 또는 1)
- **높이(Height):** 트리의 최대 레벨
- **내부 정점(Internal Vertex):** 자식이 있는 정점
- **리프(Leaf):** 자식이 없는 정점

## 신장 트리 (Spanning Tree)

그래프 $G$의 **신장 트리**는 G의 모든 정점을 포함하는 부분 그래프이면서 트리인 것입니다.

- 연결 그래프에 항상 신장 트리가 존재합니다.
- n개의 정점을 가지면 간선 수 = n-1

## 최소 비용 신장 트리 (MST)

**최소 비용 신장 트리(Minimum Spanning Tree, MST)** 는 가중치 그래프에서 모든 간선 가중치의 합이 최소인 신장 트리입니다.

### Kruskal 알고리즘

**탐욕 방법:** 가중치가 작은 간선부터 선택하되, 사이클을 형성하면 제외합니다.

1. 모든 간선을 가중치 기준으로 오름차순 정렬
2. 가중치가 가장 작은 간선부터 선택
3. 선택된 간선이 사이클을 형성하면 제외
4. $n-1$개의 간선이 선택될 때까지 반복

사이클 판별: **유니온-파인드(Union-Find)** 자료구조 사용

시간 복잡도: $O(E \log E)$

### Prim 알고리즘

**탐욕 방법:** 하나의 정점에서 시작하여 MST를 점진적으로 확장합니다.

1. 임의의 정점에서 시작
2. 현재 MST에 속한 정점과 속하지 않은 정점을 연결하는 최소 가중치 간선 선택
3. 해당 간선으로 새 정점을 MST에 추가
4. 모든 정점이 MST에 포함될 때까지 반복

시간 복잡도: $O(V^2)$ (단순 구현), $O(E \log V)$ (우선순위 큐 사용)

### Kruskal vs Prim 비교

| 항목 | Kruskal | Prim |
| --- | --- | --- |
| 적합 그래프 | 희소 그래프 | 밀집 그래프 |
| 기본 복잡도 | $O(E \log E)$ | $O(V^2)$ |
| 시작점 | 없음(간선 기준) | 정점에서 시작 |
| 사이클 판별 | Union-Find | 필요 없음 |

## MST의 응용

- 네트워크 설계 (전화망, 전기망 등)
- 클러스터링
- 최소 비용 배선 문제

## 핵심 정리

- 트리: 연결, 비순환, $n$정점 $\rightarrow$ $n-1$ 간선
- MST: 모든 간선 가중치 합이 최소인 신장 트리
- Kruskal: 간선을 정렬 후 사이클 없는 최소 간선 선택
- Prim: 정점에서 시작하여 최소 가중치 간선으로 확장
