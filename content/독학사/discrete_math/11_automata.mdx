## 유한 상태 기계 (Finite State Machine)

**유한 오토마타(FA)** 는 유한한 상태의 집합과 상태 전이 함수로 구성된 추상적 계산 모델입니다.

## 결정적 유한 오토마타 (DFA)

**DFA(Deterministic Finite Automaton)** 는 5-튜플 $(Q, \Sigma, \delta, q_0, F)$로 정의됩니다.

| 구성 요소 | 설명 |
| --- | --- |
| $Q$ | 유한 상태 집합 |
| $\Sigma$ | 입력 알파벳 |
| $\delta: Q \times \Sigma \rightarrow Q$ | 전이 함수 |
| $q_0 \in Q$ | 초기 상태 |
| $F \subseteq Q$ | 수락 상태 집합 |

**특징:** 각 상태에서 각 입력 기호에 대해 정확히 하나의 다음 상태가 결정됩니다.

## 비결정적 유한 오토마타 (NFA)

**NFA(Nondeterministic Finite Automaton)** 는 5-튜플 $(Q, \Sigma, \delta, q_0, F)$이지만 전이 함수가 다릅니다.

$$\delta: Q \times \Sigma_\epsilon \rightarrow \mathcal{P}(Q)$$

여기서 $\Sigma_\epsilon = \Sigma \cup \{\epsilon\}$이고 $\mathcal{P}(Q)$는 Q의 멱집합입니다.

**특징:**
- 한 상태에서 같은 입력에 여러 전이 가능
- $\epsilon$-전이 가능 (입력 없이 상태 전이)
- 계산 경로 중 하나라도 수락 상태에 도달하면 수락

### DFA와 NFA 비교

| 항목 | DFA | NFA |
| --- | --- | --- |
| 전이 함수 | $Q \times \Sigma \rightarrow Q$ | $Q \times \Sigma_\epsilon \rightarrow \mathcal{P}(Q)$ |
| 다음 상태 수 | 정확히 1개 | 0개 이상 |
| 입력 없는 전이 | 불가 | $\epsilon$-전이 가능 |
| 계산 능력 | 정규 언어 | 정규 언어 (동일!) |

<Callout type="warning">
  NFA가 더 표현력이 강해 보이지만, 모든 NFA는 동등한 DFA로 변환할 수 있습니다. 따라서 DFA와 NFA의 표현 능력은 동일합니다.
</Callout>

## NFA를 DFA로 변환 (부분집합 구성법)

NFA의 각 상태 집합을 DFA의 하나의 상태로 대응시키는 방법입니다.

1. 초기 상태: NFA 초기 상태의 $\epsilon$-클로저
2. 각 상태(집합)에서 각 입력에 대해 도달 가능한 상태들의 $\epsilon$-클로저를 계산
3. 새로운 상태가 없을 때까지 반복

## 정규 언어 (Regular Language)

DFA 또는 NFA로 인식되는 언어를 **정규 언어**라 합니다.

**폐쇄 성질:** 정규 언어는 다음 연산에 닫혀 있습니다:
- 합집합($L_1 \cup L_2$)
- 접합($L_1 \cdot L_2$)
- 스타($L^*$)
- 교집합, 보집합

## 펌핑 보조정리 (Pumping Lemma)

어떤 언어가 정규 언어가 아님을 증명하는 데 사용됩니다.

**정리:** 정규 언어 $L$이면 펌핑 길이 $p$가 존재하여, 길이 $\geq p$인 모든 $s \in L$에 대해 $s = xyz$로 분해 가능하고:
1. $|y| \geq 1$
2. $|xy| \leq p$
3. 모든 $i \geq 0$에 대해 $xy^iz \in L$

## 핵심 정리

- DFA: 각 상태에서 각 입력에 정확히 하나의 전이
- NFA: 여러 전이 가능, $\epsilon$-전이 가능
- NFA와 DFA의 계산 능력은 동일
- 정규 언어 = DFA/NFA/정규식으로 표현 가능
