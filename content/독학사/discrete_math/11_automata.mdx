## 왜 오토마타가 필요한가?

텍스트 에디터의 문법 강조(syntax highlighting), 정규식(regex) 검색, 컴파일러의 어휘 분석 — 모두 오토마타(automata) 이론을 기반으로 합니다. 오토마타(automata)는 "자동으로 계산을 수행하는 추상적 기계"입니다. 컴퓨터 과학의 이론적 기초가 됩니다.

<Callout type="info">
  **비유:** 지하철 개찰구를 생각해보세요. 교통카드를 태그하면 문이 열리고(수락 상태), 잔액이 없으면 문이 열리지 않습니다(거부 상태). 이것이 가장 간단한 유한 오토마타(finite automaton)입니다.
</Callout>

## 유한 상태 기계 (Finite State Machine, FSM)

**쉽게 말하면:** 유한 상태 기계(finite state machine, FSM)는 유한한 수의 상태(state)와 상태 간 전이(transition) 규칙으로 입력을 처리하는 추상적 계산 모델입니다.

**구성 요소:**
- **상태(State):** 기계가 현재 있는 위치나 조건
- **전이(Transition):** 입력에 따라 상태를 바꾸는 규칙
- **초기 상태(Initial State):** 처음 시작 상태
- **수락 상태(Accepting State):** 입력을 "수락"하는 최종 상태들

**자판기 예시:**
- 상태: 동전 없음, 100원 투입, 200원 투입
- 전이: 100원 투입하면 "동전 없음" → "100원 투입"
- 수락 상태: 200원이 되면 음료수 배출

## 결정적 유한 오토마타 (DFA)

**DFA(Deterministic Finite Automaton, 결정적 유한 오토마타)** 는 5-튜플 $(Q, \Sigma, \delta, q_0, F)$로 정의됩니다.

| 구성 요소 | 기호 | 설명 |
| --- | --- | --- |
| 상태 집합 | $Q$ | 유한한 상태들의 집합 |
| 입력 알파벳 | $\Sigma$ | 처리할 수 있는 입력 기호들 |
| 전이 함수 | $\delta: Q \times \Sigma \rightarrow Q$ | (현재 상태, 입력) → 다음 상태 |
| 초기 상태 | $q_0 \in Q$ | 시작 상태 |
| 수락 상태 집합 | $F \subseteq Q$ | 입력이 수락되는 상태들 |

**기호 읽기:**
- $Q$ (states): 상태 집합
- $\Sigma$ (sigma, 시그마): 알파벳 (입력 기호들의 집합)
- $\delta$ (delta, 델타): 전이 함수

**DFA의 핵심 특징:** 각 상태에서 각 입력 기호에 대해 **정확히 하나**의 다음 상태가 결정됩니다. "결정적(Deterministic)"이라는 이름이 여기서 옵니다.

**예시:** "0과 1로 이루어지고 1로 끝나는 문자열"을 수락하는 DFA
- $Q = \{q_0, q_1\}$, $\Sigma = \{0, 1\}$
- $\delta$: $q_0$ 상태에서 0 입력 → $q_0$, $q_0$에서 1 입력 → $q_1$
- $\delta$: $q_1$ 상태에서 0 입력 → $q_0$, $q_1$에서 1 입력 → $q_1$
- $q_0$ = 초기 상태, $F = \{q_1\}$ = 수락 상태

**DFA의 동작:**
1. 초기 상태 $q_0$에서 시작
2. 입력 문자를 하나씩 읽으며 전이 함수에 따라 상태 변경
3. 모든 입력을 읽은 후 수락 상태 $F$에 있으면 수락, 아니면 거부

## 비결정적 유한 오토마타 (NFA)

**NFA(Nondeterministic Finite Automaton, 비결정적 유한 오토마타)** 는 5-튜플 $(Q, \Sigma, \delta, q_0, F)$이지만 전이 함수가 다릅니다.

$$\delta: Q \times \Sigma_\epsilon \rightarrow \mathcal{P}(Q)$$

- $\Sigma_\epsilon = \Sigma \cup \{\epsilon\}$: 알파벳에 빈 문자열 $\epsilon$(엡실론)을 추가
- $\mathcal{P}(Q)$: Q의 멱집합 (상태들의 집합을 반환)

**NFA의 특징:**
- 한 상태에서 같은 입력에 여러 전이 가능 (선택지가 여러 개)
- $\epsilon$-전이(epsilon transition) 가능 — 입력 없이 상태 전이
- 계산 경로 중 하나라도 수락 상태에 도달하면 수락

**비유:** NFA는 "병렬로 모든 가능성을 동시에 탐색"하는 것과 같습니다. DFA가 한 길만 가는 것이라면, NFA는 갈림길마다 분신을 만들어 모든 길을 동시에 탐색합니다.

### DFA와 NFA 비교

| 항목 | DFA | NFA |
| --- | --- | --- |
| 전이 함수 | $Q \times \Sigma \rightarrow Q$ | $Q \times \Sigma_\epsilon \rightarrow \mathcal{P}(Q)$ |
| 다음 상태 수 | **정확히 1개** | 0개 이상 |
| 입력 없는 전이 | 불가 | $\epsilon$-전이 가능 |
| 구현 복잡도 | 단순 | 복잡 |
| 계산 능력 | 정규 언어 | **정규 언어 (동일!)** |

<Callout type="warning">
  **중요:** NFA가 더 표현력이 강해 보이지만, **모든 NFA는 동등한 DFA로 변환할 수 있습니다.** 따라서 DFA와 NFA의 계산 능력(인식하는 언어의 집합)은 완전히 동일합니다.
</Callout>

## NFA를 DFA로 변환 (부분집합 구성법)

NFA의 각 상태 **집합**을 DFA의 하나의 상태로 대응시키는 방법입니다.

**단계:**
1. 초기 상태: NFA 초기 상태의 $\epsilon$-클로저 (엡실론 전이로 도달 가능한 모든 상태)
2. 각 상태(집합)에서 각 입력에 대해 도달 가능한 상태들의 $\epsilon$-클로저를 계산
3. 새로운 상태(집합)가 나타나지 않을 때까지 반복
4. NFA의 수락 상태를 포함하는 DFA 상태가 수락 상태

**단점:** DFA 상태 수가 $2^n$개까지 증가할 수 있습니다 (NFA 상태가 n개일 때).

## 정규 언어 (Regular Language)

**쉽게 말하면:** 정규 언어(regular language)는 DFA 또는 NFA로 인식할 수 있는 언어입니다. 가장 간단한 계산 모델로 처리 가능한 언어입니다.

DFA 또는 NFA로 인식되는 언어를 **정규 언어**라 합니다.

**폐쇄 성질(Closure Properties):** 정규 언어는 다음 연산에 닫혀 있습니다 (결과도 정규 언어):
- 합집합 ($L_1 \cup L_2$)
- 접합, 연접(Concatenation) ($L_1 \cdot L_2$)
- 스타, 클레이니 스타(Kleene Star) ($L^*$)
- 교집합 ($L_1 \cap L_2$)
- 보집합 ($\overline{L}$)

## 펌핑 보조정리 (Pumping Lemma)

**쉽게 말하면:** 펌핑 보조정리(pumping lemma)는 어떤 언어가 정규 언어가 아님을 증명하는 도구입니다. "정규 언어라면 반드시 이 성질을 만족해야 한다"는 필요 조건을 제공합니다.

**정리:** 정규 언어 $L$이면 펌핑 길이 $p$가 존재하여, 길이 $\geq p$인 모든 $s \in L$에 대해 $s = xyz$로 분해 가능하고:
1. $|y| \geq 1$ (y는 비어있지 않음)
2. $|xy| \leq p$ (y는 앞 부분에 있음)
3. 모든 $i \geq 0$에 대해 $xy^iz \in L$ (y를 반복해도 L에 속함)

**활용:** $L = \{0^n 1^n \mid n \geq 0\}$ (0과 1의 수가 같은 언어)는 이 조건을 만족하지 않으므로 정규 언어가 아닙니다.

## 핵심 정리

- DFA: 각 (상태, 입력) 쌍에 정확히 하나의 전이
- NFA: 여러 전이 가능, $\epsilon$-전이 가능
- DFA와 NFA의 계산 능력은 동일 (모든 NFA → DFA 변환 가능)
- 정규 언어 = DFA/NFA/정규식으로 표현 가능한 언어
- 펌핑 보조정리: 비정규 언어 증명에 사용
