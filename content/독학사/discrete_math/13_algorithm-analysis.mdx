## 알고리즘 복잡도 분석

알고리즘의 효율성을 **입력 크기 n에 대한 함수**로 표현합니다.

- **시간 복잡도(Time Complexity):** 수행되는 연산의 수
- **공간 복잡도(Space Complexity):** 사용되는 메모리의 양

## 점근 표기법 (Asymptotic Notation)

### Big-O 표기법 (상한)

$f(n) = O(g(n))$이면: 충분히 큰 $n$에 대해 $f(n) \leq c \cdot g(n)$을 만족하는 양의 상수 $c$, $n_0$가 존재합니다.

**의미:** $g(n)$은 $f(n)$의 점근적 상한

### Big-Ω 표기법 (하한)

$f(n) = \Omega(g(n))$이면: 충분히 큰 $n$에 대해 $f(n) \geq c \cdot g(n)$

**의미:** $g(n)$은 $f(n)$의 점근적 하한

### Big-Θ 표기법 (정확한 한계)

$f(n) = \Theta(g(n))$이면: $f(n) = O(g(n))$ 이면서 $f(n) = \Omega(g(n))$

**의미:** $f(n)$과 $g(n)$은 점근적으로 같은 속도로 성장

## 복잡도 성장 순서

$$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$

| 표기 | 이름 | 예시 알고리즘 |
| --- | --- | --- |
| $O(1)$ | 상수 | 배열 인덱스 접근 |
| $O(\log n)$ | 로그 | 이진 탐색 |
| $O(n)$ | 선형 | 선형 탐색 |
| $O(n \log n)$ | 선형 로그 | 합병 정렬, 힙 정렬 |
| $O(n^2)$ | 이차 | 버블 정렬, 삽입 정렬 |
| $O(2^n)$ | 지수 | 재귀적 피보나치 |
| $O(n!)$ | 팩토리얼 | 순열 생성 |

## 점화식 분석

**분할 정복 알고리즘** 복잡도는 점화식으로 표현됩니다.

**마스터 정리:** $T(n) = aT(n/b) + f(n)$

| 경우 | 조건 | 결과 |
| --- | --- | --- |
| 경우 1 | $f(n)$ 더 작음 | $T(n) = \Theta(n^{\log_b a})$ |
| 경우 2 | 동일 속도 | $T(n) = \Theta(n^{\log_b a} \log n)$ |
| 경우 3 | $f(n)$ 더 큼 | $T(n) = \Theta(f(n))$ |

## 최선/평균/최악 분석

| 경우 | 설명 | 표기 |
| --- | --- | --- |
| 최선(Best Case) | 입력이 가장 유리한 경우 | $\Omega$ |
| 평균(Average Case) | 무작위 입력의 기대값 | $\Theta$ (일반적으로) |
| 최악(Worst Case) | 입력이 가장 불리한 경우 | $O$ |

<Callout type="warning">
  보통 알고리즘의 성능을 논할 때 **최악의 경우(Worst Case)**를 기준으로 합니다. 성능을 보장해야 하기 때문입니다.
</Callout>

## 주요 알고리즘 복잡도 정리

| 알고리즘 | 최선 | 평균 | 최악 |
| --- | --- | --- | --- |
| 버블 정렬 | $O(n)$ | $O(n^2)$ | $O(n^2)$ |
| 선택 정렬 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ |
| 삽입 정렬 | $O(n)$ | $O(n^2)$ | $O(n^2)$ |
| 퀵 정렬 | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| 합병 정렬 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ |
| 이진 탐색 | $O(1)$ | $O(\log n)$ | $O(\log n)$ |

## 핵심 정리

- Big-O: 상한, Big-Ω: 하한, Big-Θ: 정확한 한계
- 복잡도 순서: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
- 마스터 정리로 분할 정복 복잡도 분석
- 일반적으로 최악의 경우 분석을 사용
