## 형식 문법 (Formal Grammar)

형식 문법은 언어를 생성하는 규칙의 집합입니다. 4-튜플 $(V, T, P, S)$로 정의됩니다.

| 구성 요소 | 설명 |
| --- | --- |
| $V$ | 비단말 기호 집합 (변수) |
| $T$ | 단말 기호 집합 (알파벳) |
| $P$ | 생성 규칙 집합 |
| $S \in V$ | 시작 기호 |

## 정규식 (Regular Expression)

정규식은 문자열 패턴을 기술하는 표현식입니다. 정규 언어와 일대일 대응됩니다.

**기본 연산:**

| 연산 | 기호 | 의미 |
| --- | --- | --- |
| 접합 | $ab$ | a 다음 b |
| 합집합 | $a \mid b$ | a 또는 b |
| 스타 | $a^*$ | a가 0번 이상 반복 |
| 플러스 | $a^+$ | a가 1번 이상 반복 |
| 물음표 | $a?$ | a가 0번 또는 1번 |

**예시:** 0과 1로 이루어진 문자열 중 01로 끝나는 것: $(0 \mid 1)^* 01$

**클레이니 정리:** 정규 언어 = DFA/NFA로 인식 가능한 언어 = 정규식으로 표현 가능한 언어

## 촘스키 계층구조 (Chomsky Hierarchy)

노암 촘스키가 제안한 형식 언어의 분류 체계입니다.

| 타입 | 이름 | 문법 제약 | 인식 기계 |
| --- | --- | --- | --- |
| Type 0 | 재귀 열거 가능 언어 | 제약 없음 | 튜링 기계 |
| Type 1 | 문맥 의존 언어 | $\alpha A \beta \rightarrow \alpha \gamma \beta$ | 선형 유계 오토마타 |
| Type 2 | 문맥 자유 언어 | $A \rightarrow \gamma$ | 푸시다운 오토마타 |
| Type 3 | 정규 언어 | $A \rightarrow aB$ 또는 $A \rightarrow a$ | 유한 오토마타 |

언어의 포함 관계: 정규 언어 ⊂ 문맥 자유 언어 ⊂ 문맥 의존 언어 ⊂ 재귀 열거 가능 언어

## 문맥 자유 문법 (CFG)

**CFG(Context-Free Grammar)** 는 Type 2 문법으로, 모든 생성 규칙이 $A \rightarrow \gamma$ 형태입니다.

프로그래밍 언어의 구문 정의에 사용됩니다.

**예시 (괄호 언어):**

```
S → SS | (S) | ε
```

이 문법은 올바르게 쌍이 맞는 괄호 문자열을 생성합니다.

## 파스 트리 (Parse Tree)

CFG로 문자열을 유도하는 과정을 트리로 표현합니다.

- **루트:** 시작 기호 S
- **내부 노드:** 비단말 기호
- **리프 노드:** 단말 기호

**모호한 문법(Ambiguous Grammar):** 같은 문자열에 대해 둘 이상의 파스 트리가 존재하는 문법

## 정규 문법 (Regular Grammar)

Type 3 문법이며, 두 가지 형태:
- **우선형(Right-Linear):** $A \rightarrow aB$ 또는 $A \rightarrow a$
- **좌선형(Left-Linear):** $A \rightarrow Ba$ 또는 $A \rightarrow a$

우선형 정규 문법은 NFA와 동등합니다.

## 핵심 정리

- 정규식: 정규 언어와 동등한 표현
- 촘스키 계층: 정규 ⊂ 문맥 자유 ⊂ 문맥 의존 ⊂ 재귀 열거
- CFG: 프로그래밍 언어 구문 표현에 사용
- Type 3(정규): 유한 오토마타, Type 2(문맥 자유): PDA
