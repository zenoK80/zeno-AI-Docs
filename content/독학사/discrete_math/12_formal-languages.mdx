## 왜 형식 언어가 필요한가?

Python 코드를 작성하면 Python 컴파일러가 그 코드를 "읽고" 이해합니다. 이 과정에서 형식 언어(formal language) 이론이 사용됩니다. "이 코드가 올바른 Python 문법인가?" 를 판단하는 것이 바로 형식 문법의 역할입니다. 자연어(한국어, 영어)와 달리, 프로그래밍 언어는 엄격한 형식 문법으로 정의됩니다.

<Callout type="info">
  **비유:** 영어의 문법(grammar)을 생각해보세요. "The cat sat on the mat"은 올바른 영어 문장이지만, "Cat the sat mat the on"은 올바르지 않습니다. 형식 문법은 이런 규칙을 수학적으로 정의합니다.
</Callout>

## 형식 언어의 기본 개념

**알파벳(Alphabet)** $\Sigma$: 기호들의 유한 집합 (예: $\{0, 1\}$, $\{a, b, c\}$)

**문자열(String):** 알파벳의 기호들을 유한개 나열한 것 (예: "010", "abc")

**빈 문자열(Empty String):** 길이가 0인 문자열, $\epsilon$ (엡실론)으로 표기

**언어(Language):** 특정 알파벳으로 만들 수 있는 문자열들의 집합

## 형식 문법 (Formal Grammar)

**쉽게 말하면:** 형식 문법(formal grammar)은 언어를 생성하는 규칙의 집합입니다. "어떤 문자열이 이 언어에 속하는가?"를 결정하는 규칙들입니다.

형식 문법은 4-튜플 $(V, T, P, S)$로 정의됩니다:

| 구성 요소 | 기호 | 설명 |
| --- | --- | --- |
| 비단말 기호 집합 | $V$ | 문법에서 사용되는 변수/비단말 기호들 |
| 단말 기호 집합 | $T$ | 실제 알파벳 기호들 (단말, 더 이상 대체 불가) |
| 생성 규칙 집합 | $P$ | $\alpha \rightarrow \beta$ 형태의 대체 규칙들 |
| 시작 기호 | $S \in V$ | 유도를 시작하는 비단말 기호 |

**생성 규칙(Production Rule):** $\alpha \rightarrow \beta$는 "왼쪽 $\alpha$를 오른쪽 $\beta$로 대체한다"는 의미

**유도(Derivation):** 시작 기호 $S$에서 생성 규칙을 반복 적용하여 단말 기호만 남기는 과정

## 정규식 (Regular Expression)

**쉽게 말하면:** 정규식(regular expression, regex)은 문자열 패턴을 기술하는 표현식입니다. "이 패턴에 맞는 문자열을 찾아라"는 명령입니다. 텍스트 검색, 데이터 유효성 검사에 널리 사용됩니다.

**기본 연산:**

| 연산 | 기호 | 예시 | 의미 |
| --- | --- | --- | --- |
| 접합(Concatenation) | $ab$ | $ab$ | a 다음 b가 오는 문자열 |
| 합집합(Union) | $a \mid b$ | $a \mid b$ | a 또는 b |
| 스타(Kleene Star) | $a^*$ | $a^*$ | a가 0번 이상 반복 |
| 플러스(Plus) | $a^+$ | $a^+$ | a가 1번 이상 반복 ($= aa^*$) |
| 물음표(Optional) | $a?$ | $a?$ | a가 0번 또는 1번 |

**정규식 예시:**
- $(0 \mid 1)^*$: 0과 1로 이루어진 모든 이진 문자열 (빈 문자열 포함)
- $(0 \mid 1)^* 01$: 01로 끝나는 이진 문자열
- $a^*ba^*$: 정확히 하나의 b를 포함하는 a와 b의 문자열

**클레이니 정리(Kleene's Theorem):** 다음 세 가지는 모두 동등합니다:
- 정규 언어 (DFA/NFA로 인식)
- 정규식으로 표현 가능한 언어
- 정규 문법으로 생성 가능한 언어

## 촘스키 계층구조 (Chomsky Hierarchy)

**쉽게 말하면:** 촘스키 계층구조(Chomsky hierarchy)는 노암 촘스키(Noam Chomsky)가 제안한 형식 언어의 분류 체계입니다. 언어를 처리하는 기계의 복잡도에 따라 4단계로 분류합니다.

| 타입 | 이름 | 문법 규칙 형태 | 인식 기계 |
| --- | --- | --- | --- |
| Type 0 | 재귀 열거 가능 언어 | 제약 없음 ($\alpha \rightarrow \beta$) | 튜링 기계 |
| Type 1 | 문맥 의존 언어 | $\alpha A \beta \rightarrow \alpha \gamma \beta$ | 선형 유계 오토마타 |
| Type 2 | 문맥 자유 언어 | $A \rightarrow \gamma$ | 푸시다운 오토마타(PDA) |
| Type 3 | 정규 언어 | $A \rightarrow aB$ 또는 $A \rightarrow a$ | 유한 오토마타 |

**포함 관계:**
$$\text{정규 언어} \subset \text{문맥 자유 언어} \subset \text{문맥 의존 언어} \subset \text{재귀 열거 가능 언어}$$

**기억법:** 위로 갈수록(Type 0) 더 강력한 기계가 필요합니다. 아래로 갈수록(Type 3) 제약이 많아지고 단순합니다.

**인식 기계들:**
- 튜링 기계(Turing Machine): 테이프와 읽기/쓰기 헤드를 가진 이론적 기계. 모든 계산 가능한 함수를 계산 가능.
- 선형 유계 오토마타(LBA, Linear Bounded Automaton): 입력 길이에 비례하는 테이프를 가진 튜링 기계
- 푸시다운 오토마타(PDA, Pushdown Automaton): 유한 오토마타 + 스택
- 유한 오토마타(FA, Finite Automaton): DFA, NFA

## 문맥 자유 문법 (CFG, Context-Free Grammar)

**쉽게 말하면:** 문맥 자유 문법(CFG)은 프로그래밍 언어의 구문을 정의하는 데 가장 많이 사용되는 문법입니다. 모든 생성 규칙이 $A \rightarrow \gamma$ 형태 (왼쪽이 단일 비단말 기호)입니다.

**예시 1:** 올바른 괄호 문자열 생성

```
S → SS | (S) | ε
```

이 문법은 "(())", "()()", "(()())" 등을 생성합니다.

**예시 2:** 간단한 산술식

```
E → E + T | T
T → T * F | F
F → (E) | 숫자
```

이 문법은 "1+2*3", "(1+2)*3" 등을 생성합니다.

## 파스 트리 (Parse Tree)

**쉽게 말하면:** 파스 트리(parse tree)는 CFG로 문자열을 유도하는 과정을 트리로 표현한 것입니다. 컴파일러가 프로그램을 분석하는 과정에서 만들어집니다.

- **루트(Root):** 시작 기호 S
- **내부 노드(Internal Node):** 비단말 기호 (규칙의 왼쪽)
- **리프(Leaf):** 단말 기호 (실제 알파벳 기호)

**모호한 문법(Ambiguous Grammar):** 같은 문자열에 대해 **둘 이상의 파스 트리**가 존재하는 문법. 프로그래밍 언어에서 모호한 문법은 해석의 여러 가지 가능성을 만들므로 피해야 합니다.

**예:** 문법 $E \rightarrow E+E \mid E*E \mid 숫자$에서 "1+2*3"은 두 가지 파스 트리 가능:
1. $(1+2)*3$ (덧셈 먼저)
2. $1+(2*3)$ (곱셈 먼저)

## 정규 문법 (Regular Grammar)

**쉽게 말하면:** 정규 문법(regular grammar)은 가장 제약이 많은 Type 3 문법입니다. 모든 규칙이 한 비단말 기호를 하나의 단말 기호(+ 비단말 기호)로 대체합니다.

두 가지 형태:
- **우선형(Right-Linear):** $A \rightarrow aB$ 또는 $A \rightarrow a$ — NFA와 동등
- **좌선형(Left-Linear):** $A \rightarrow Ba$ 또는 $A \rightarrow a$

## 핵심 정리

- 정규식: 정규 언어와 동등한 패턴 표현
- 촘스키 계층: 정규 ⊂ 문맥 자유 ⊂ 문맥 의존 ⊂ 재귀 열거 가능
- CFG: 프로그래밍 언어 구문 표현에 사용, $A \rightarrow \gamma$ 형태
- Type 3(정규): 유한 오토마타, Type 2(문맥 자유): PDA
- 모호한 문법: 같은 문자열에 파스 트리가 2개 이상
