## SQL이란?

**SQL**(Structured Query Language)은 관계형 데이터베이스를 정의, 조작, 제어하기 위한 표준 언어입니다.

## DDL (Data Definition Language)

### CREATE TABLE

```sql
CREATE TABLE 학생 (
    학번     CHAR(8)      PRIMARY KEY,
    이름     VARCHAR(20)  NOT NULL,
    나이     INT          CHECK (나이 >= 0),
    학과코드  CHAR(5),
    FOREIGN KEY (학과코드) REFERENCES 학과(학과코드)
);
```

**주요 제약 조건:**

| 제약 조건 | 설명 |
|---------|------|
| `PRIMARY KEY` | 기본키, NULL 불가, 중복 불가 |
| `NOT NULL` | NULL 값 불허 |
| `UNIQUE` | 중복 불허 (NULL 허용) |
| `CHECK` | 조건 충족 값만 허용 |
| `FOREIGN KEY` | 외래키, 참조 무결성 |
| `DEFAULT` | 기본값 지정 |

### ALTER TABLE

```sql
-- 열 추가
ALTER TABLE 학생 ADD 이메일 VARCHAR(100);

-- 열 삭제
ALTER TABLE 학생 DROP COLUMN 이메일;

-- 열 수정
ALTER TABLE 학생 MODIFY 나이 SMALLINT;
```

### DROP TABLE

```sql
DROP TABLE 학생;          -- 테이블 삭제
TRUNCATE TABLE 학생;      -- 테이블 데이터만 삭제 (구조 유지)
```

## DML (Data Manipulation Language)

### INSERT

```sql
-- 전체 열 삽입
INSERT INTO 학생 VALUES ('2023001', '김철수', 20, 'CS');

-- 특정 열만 삽입
INSERT INTO 학생 (학번, 이름) VALUES ('2023002', '이영희');
```

### UPDATE

```sql
UPDATE 학생
SET 나이 = 21, 학과코드 = 'EE'
WHERE 학번 = '2023001';
```

### DELETE

```sql
DELETE FROM 학생
WHERE 학번 = '2023001';

-- 전체 삭제 (구조 유지)
DELETE FROM 학생;
```

## SELECT 문 기본 구조

```sql
SELECT [DISTINCT] 속성목록
FROM   테이블목록
WHERE  조건
GROUP BY 그룹속성
HAVING 그룹조건
ORDER BY 정렬기준 [ASC|DESC];
```

**실행 순서:** FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

### WHERE 절 조건

```sql
-- 비교 연산자
WHERE 나이 >= 20

-- BETWEEN
WHERE 나이 BETWEEN 18 AND 25

-- IN
WHERE 학과코드 IN ('CS', 'EE', 'ME')

-- LIKE (패턴 매칭)
WHERE 이름 LIKE '김%'     -- '김'으로 시작
WHERE 이름 LIKE '_수'     -- 두 번째 글자가 '수'

-- IS NULL / IS NOT NULL
WHERE 이메일 IS NULL
```

### 집계 함수

| 함수 | 설명 |
|------|------|
| `COUNT(*)` | 행 수 |
| `COUNT(열)` | NULL 제외 행 수 |
| `SUM(열)` | 합계 |
| `AVG(열)` | 평균 |
| `MAX(열)` | 최댓값 |
| `MIN(열)` | 최솟값 |

```sql
SELECT 학과코드, COUNT(*), AVG(나이)
FROM 학생
GROUP BY 학과코드
HAVING COUNT(*) >= 10;
```

## 핵심 정리

- DDL: CREATE, ALTER, DROP (스키마 정의)
- DML: INSERT, UPDATE, DELETE, SELECT (데이터 조작)
- SELECT 실행 순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
- HAVING: GROUP BY 결과에 대한 조건 (WHERE는 그룹화 전)
- 집계 함수: COUNT, SUM, AVG, MAX, MIN
