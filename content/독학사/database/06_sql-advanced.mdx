## JOIN

두 개 이상의 테이블을 연결하여 데이터를 조회합니다.

### INNER JOIN (내부 조인)

두 테이블에서 조인 조건을 만족하는 행만 반환합니다.

```sql
SELECT 학생.학번, 학생.이름, 학과.학과명
FROM 학생
INNER JOIN 학과 ON 학생.학과코드 = 학과.학과코드;

-- 또는 (구식 표기)
SELECT 학생.학번, 학생.이름, 학과.학과명
FROM 학생, 학과
WHERE 학생.학과코드 = 학과.학과코드;
```

### LEFT OUTER JOIN

왼쪽 테이블의 모든 행을 반환하고, 매칭되지 않는 오른쪽은 NULL로 채웁니다.

```sql
SELECT 학생.학번, 학생.이름, 수강.과목코드
FROM 학생
LEFT OUTER JOIN 수강 ON 학생.학번 = 수강.학번;
-- 수강 기록이 없는 학생도 포함 (과목코드: NULL)
```

### SELF JOIN

같은 테이블을 두 번 참조합니다.

```sql
SELECT a.이름 AS 직원, b.이름 AS 상관
FROM 직원 a
JOIN 직원 b ON a.상관ID = b.직원ID;
```

## 서브쿼리 (Subquery)

쿼리 안에 중첩된 쿼리입니다.

### 단순 서브쿼리

```sql
-- 평균 나이보다 많은 학생 조회
SELECT 이름, 나이
FROM 학생
WHERE 나이 > (SELECT AVG(나이) FROM 학생);
```

### IN 서브쿼리

```sql
-- CS 학과 학생이 수강한 과목
SELECT DISTINCT 과목코드
FROM 수강
WHERE 학번 IN (SELECT 학번 FROM 학생 WHERE 학과코드 = 'CS');
```

### EXISTS 서브쿼리

서브쿼리 결과가 존재하면 TRUE입니다.

```sql
-- 수강 기록이 있는 학생
SELECT 이름
FROM 학생 s
WHERE EXISTS (SELECT 1 FROM 수강 WHERE 학번 = s.학번);
```

### 상관 서브쿼리 (Correlated Subquery)

외부 쿼리의 값을 참조하는 서브쿼리입니다. 행마다 서브쿼리를 실행합니다.

```sql
-- 해당 학과에서 가장 나이 많은 학생
SELECT 이름, 학과코드, 나이
FROM 학생 s1
WHERE 나이 = (
    SELECT MAX(나이) FROM 학생 s2
    WHERE s2.학과코드 = s1.학과코드
);
```

## 집합 연산

두 쿼리 결과를 집합 연산으로 결합합니다. 두 SELECT의 열 수와 데이터 타입이 호환되어야 합니다.

| 연산 | 설명 | 중복 |
|------|------|------|
| `UNION` | 합집합 | 제거 |
| `UNION ALL` | 합집합 | 유지 |
| `INTERSECT` | 교집합 | 제거 |
| `EXCEPT` (MINUS) | 차집합 | 제거 |

```sql
-- CS 또는 EE 학과 학생의 학번 (중복 제거)
SELECT 학번 FROM 학생 WHERE 학과코드 = 'CS'
UNION
SELECT 학번 FROM 학생 WHERE 학과코드 = 'EE';
```

## 뷰 (View)

**뷰**는 하나 이상의 테이블에서 유도된 가상 테이블입니다. 실제 데이터를 저장하지 않고 쿼리만 저장합니다.

```sql
-- 뷰 생성
CREATE VIEW CS학생뷰 AS
SELECT 학번, 이름, 나이
FROM 학생
WHERE 학과코드 = 'CS';

-- 뷰 조회 (일반 테이블처럼 사용)
SELECT * FROM CS학생뷰;

-- 뷰 삭제
DROP VIEW CS학생뷰;
```

### 뷰의 장점

- **보안:** 특정 열/행만 노출
- **단순화:** 복잡한 쿼리를 간단하게 재사용
- **논리적 독립성:** 기본 테이블 변경 시 뷰 인터페이스 유지

### 뷰 업데이트 제한

뷰를 통한 INSERT/UPDATE/DELETE는 제한적으로만 가능합니다.

- **가능:** 기본 테이블 하나에서 생성된 단순 뷰
- **불가:** GROUP BY, DISTINCT, JOIN, 집계 함수를 사용한 뷰

## 핵심 정리

- INNER JOIN: 조인 조건 만족하는 행만 반환
- LEFT OUTER JOIN: 왼쪽 테이블 전체 + 매칭 행 (NULL 포함)
- 서브쿼리: WHERE/FROM/SELECT 절에 중첩 사용 가능
- EXISTS: 서브쿼리 결과 존재 여부 확인
- UNION vs UNION ALL: 중복 제거 vs 유지
- 뷰: 가상 테이블, 데이터 저장 없이 쿼리만 저장
