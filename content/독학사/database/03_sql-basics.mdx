## SQL(Structured Query Language)이란?

**단어 풀이:**

| 단어 | 뜻 |
|------|-----|
| Structured | 구조화된 |
| Query | 질의(질문, 데이터를 요청하는 명령) |
| Language | 언어 |

> **쉽게 말하면:** SQL은 01번 문서에서 배운 테이블에게 "이런 조건에 맞는 데이터를 보여줘"라고 질문을 던지는 전용 언어입니다.

## SELECT — 데이터 조회의 시작

> **쉽게 말하면:** SELECT는 "어떤 열을 보고 싶은지"를 지정하는 명령입니다.

**예시 테이블 — 학생**(Student):

<Table>
  <thead>
    <tr><th>학번</th><th>이름</th><th>학년</th><th>학점</th></tr>
  </thead>
  <tbody>
    <tr><td>1001</td><td>김민준</td><td>2</td><td>3.8</td></tr>
    <tr><td>1002</td><td>이서연</td><td>3</td><td>4.2</td></tr>
    <tr><td>1003</td><td>박지훈</td><td>2</td><td>2.9</td></tr>
  </tbody>
</Table>

```sql
SELECT 이름, 학점 FROM 학생;
```

**해석:** "학생 테이블에서 이름과 학점 열만 보여줘"라는 뜻입니다. 모든 열을 보고 싶다면 열 이름 대신 `*`(별표)를 사용합니다: `SELECT * FROM 학생;`

## WHERE — 조건으로 행 걸러내기

> **쉽게 말하면:** WHERE는 "어떤 조건을 만족하는 행만 보고 싶은지"를 지정하는 명령입니다.

```sql
SELECT 이름, 학점 FROM 학생 WHERE 학년 = 2;
```

**결과:**

<Table>
  <thead>
    <tr><th>이름</th><th>학점</th></tr>
  </thead>
  <tbody>
    <tr><td>김민준</td><td>3.8</td></tr>
    <tr><td>박지훈</td><td>2.9</td></tr>
  </tbody>
</Table>

**해석:** "학년이 2인 학생만" 걸러내어, 김민준과 박지훈만 결과에 포함되었습니다.

<Table>
  <thead>
    <tr><th>연산자</th><th>의미</th></tr>
  </thead>
  <tbody>
    <tr><td>=</td><td>같음</td></tr>
    <tr><td>&gt;, &lt;, &gt;=, &lt;=</td><td>크다, 작다, 크거나 같다, 작거나 같다</td></tr>
    <tr><td>AND, OR</td><td>여러 조건을 동시에(모두 만족) 또는 하나라도(둘 중 하나 만족) 결합</td></tr>
  </tbody>
</Table>

**계산 예시**(복합 조건):

```sql
SELECT 이름 FROM 학생 WHERE 학년 = 2 AND 학점 >= 3.0;
```

**해석:** "학년이 2**이고** 학점이 3.0 이상인" 학생을 찾으므로, 결과는 "김민준"만 남습니다(박지훈은 학년은 2이지만 학점이 2.9로 조건을 만족하지 못함).

## ORDER BY — 결과 정렬하기

> **쉽게 말하면:** ORDER BY는 조회 결과를 특정 열 기준으로 오름차순 또는 내림차순으로 정렬합니다.

```sql
SELECT 이름, 학점 FROM 학생 ORDER BY 학점 DESC;
```

**해석:** `DESC`(내림차순)를 붙였으므로 학점이 높은 순서대로 정렬됩니다: 이서연(4.2) → 김민준(3.8) → 박지훈(2.9). 오름차순을 원한다면 `ASC`를 사용하거나(기본값이라 생략 가능) 아무것도 붙이지 않습니다.

## 집계 함수(Aggregate Function) — 여러 행을 하나의 값으로 요약

> **쉽게 말하면:** 집계 함수는 여러 행에 걸친 데이터를, 평균이나 합계 같은 하나의 요약된 숫자로 계산해주는 함수입니다.

<Table>
  <thead>
    <tr><th>함수</th><th>기능</th></tr>
  </thead>
  <tbody>
    <tr><td>COUNT()</td><td>행의 개수</td></tr>
    <tr><td>SUM()</td><td>합계</td></tr>
    <tr><td>AVG()</td><td>평균</td></tr>
    <tr><td>MAX(), MIN()</td><td>최댓값, 최솟값</td></tr>
  </tbody>
</Table>

**계산 예시:**

```sql
SELECT AVG(학점) FROM 학생;
```

**해석:** 위 학생 테이블 전체의 평균 학점을 계산합니다: $(3.8+4.2+2.9)/3 \approx 3.63$

<Callout type="warning">
  **자주 틀리는 점:** WHERE와 집계 함수를 함께 쓸 때, WHERE는 "집계하기 전에" 행을 먼저 걸러내는 역할을 합니다. 예를 들어 `SELECT AVG(학점) FROM 학생 WHERE 학년=2;`는 "학년이 2인 학생들만" 골라낸 뒤 그들의 평균을 구합니다(2, 3학년 전체 평균이 아님). 이 실행 순서(WHERE로 걸러낸 뒤 집계)를 혼동하지 않도록 주의합니다.
</Callout>

## 핵심 정리

- **SELECT ~ FROM ~**: 특정 테이블에서 원하는 열을 조회하는 기본 문법.
- **WHERE**: 조건에 맞는 행만 걸러냄. AND(모두 만족)/OR(하나라도 만족)로 조건 결합.
- **ORDER BY**: 결과를 오름차순(ASC, 기본값)/내림차순(DESC)으로 정렬.
- **집계 함수**(COUNT, SUM, AVG, MAX, MIN): 여러 행을 하나의 요약값으로 계산. WHERE는 집계 이전에 행을 걸러냄.
