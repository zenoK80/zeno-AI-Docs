## 관계 대수란?

**관계 대수(Relational Algebra)**는 릴레이션을 입력받아 새로운 릴레이션을 결과로 반환하는 연산의 집합입니다. SQL의 이론적 기반이 됩니다.

## 기본 연산

### 1. SELECT (선택, σ)

조건을 만족하는 튜플(행)을 선택합니다.

$$\sigma_{조건}(릴레이션)$$

```
σ_{나이 >= 20}(학생)
→ 나이가 20 이상인 학생 튜플만 선택
```

### 2. PROJECT (투영, π)

원하는 속성(열)만 선택합니다.

$$\pi_{속성목록}(릴레이션)$$

```
π_{학번, 이름}(학생)
→ 학번과 이름 열만 추출 (중복 제거)
```

### 3. UNION (합집합, ∪)

두 릴레이션의 합집합입니다.

- **조건:** 두 릴레이션이 같은 속성(호환성 있는 스키마)을 가져야 함
- 중복 튜플 제거

### 4. DIFFERENCE (차집합, -)

첫 번째 릴레이션에서 두 번째 릴레이션에 있는 튜플을 제외합니다.

$$R - S$$

- R에는 있지만 S에는 없는 튜플

### 5. INTERSECTION (교집합, ∩)

두 릴레이션에 공통으로 있는 튜플입니다.

$$R \cap S$$

(UNION과 DIFFERENCE로 표현 가능: $R \cap S = R - (R - S)$)

### 6. CARTESIAN PRODUCT (카테시안 곱, ×)

두 릴레이션의 모든 튜플 조합입니다.

$$R \times S$$

- R에 n개 튜플, S에 m개 튜플이면 결과는 n×m개 튜플
- 조인 연산의 기반

## JOIN (조인) 연산

### 자연 조인 (Natural Join, ⋈)

두 릴레이션에서 공통 속성 값이 같은 튜플을 결합합니다. 공통 속성은 하나만 포함됩니다.

```
학생 ⋈ 수강
→ 공통 속성(학번)이 같은 튜플 결합
```

### 세타 조인 (Theta Join, ⋈θ)

지정한 조건을 만족하는 튜플을 결합합니다.

$$R \bowtie_{\theta} S$$

### 동등 조인 (Equi Join)

조건이 등호(=)인 세타 조인입니다.

```
학생 ⋈_{학생.학과코드 = 학과.학과코드} 학과
```

### 외부 조인 (Outer Join)

조건에 맞지 않는 튜플도 포함합니다 (NULL로 채움).

| 종류 | 설명 |
|------|------|
| **LEFT OUTER JOIN** | 왼쪽 테이블 모든 튜플 + 오른쪽 매칭 |
| **RIGHT OUTER JOIN** | 오른쪽 테이블 모든 튜플 + 왼쪽 매칭 |
| **FULL OUTER JOIN** | 양쪽 모든 튜플 포함 |

## DIVISION (나눗셈, ÷)

R ÷ S: S의 모든 튜플과 조합이 R에 존재하는 R의 튜플을 반환합니다.

```
예: "모든 과목을 수강한 학생" 찾기
수강 ÷ 과목목록
```

## 핵심 정리

- SELECT(σ): 조건에 맞는 행 선택
- PROJECT(π): 원하는 열만 선택, 중복 제거
- 집합 연산: UNION, DIFFERENCE, INTERSECTION (호환성 필요)
- 카테시안 곱: 모든 튜플 조합, 조인의 기반
- 자연 조인: 공통 속성 값 같은 튜플 결합, 중복 속성 제거
- 외부 조인: 조건 불만족 튜플도 NULL로 포함
