## 가상 메모리(Virtual Memory)란?

**가상 메모리**는 실제 물리 메모리보다 큰 주소 공간을 프로세스에 제공하는 기법입니다. 프로그램의 일부만 메모리에 올리고 나머지는 디스크에 두어도 실행할 수 있습니다.

### 가상 메모리의 장점

- 프로그램이 물리 메모리보다 커도 실행 가능
- 더 많은 프로세스를 동시에 실행 (다중 프로그래밍 정도 향상)
- 로딩 시간 단축 (실제 실행에 필요한 부분만 적재)

## 요구 페이징(Demand Paging)

**요구 페이징**은 페이지가 실제로 필요할 때만 메모리에 올리는 기법입니다.

- 처음에는 어떤 페이지도 메모리에 없는 상태로 시작
- 페이지에 접근할 때 메모리에 없으면 → **페이지 폴트(Page Fault)** 발생

### 페이지 테이블 항목 구조

| 프레임 번호 | 유효-무효 비트 |
|-----------|--------------|
| 3 | 1 (메모리에 있음) |
| - | 0 (디스크에 있음) |

## 페이지 폴트(Page Fault) 처리 과정

```
1. CPU가 페이지에 접근 시도
        ↓
2. 페이지 테이블 확인 → 유효-무효 비트 = 0
        ↓
3. 페이지 폴트 트랩 발생
        ↓
4. 운영체제가 페이지 폴트 처리 루틴 실행
        ↓
5. 필요한 페이지가 디스크의 어디에 있는지 확인
        ↓
6. 빈 프레임 확보 (없으면 페이지 교체)
        ↓
7. 디스크에서 해당 페이지를 프레임으로 읽어옴
        ↓
8. 페이지 테이블 업데이트 (유효-무효 비트 = 1)
        ↓
9. 페이지 폴트를 일으킨 명령어 재시작
```

### 페이지 폴트율과 유효 접근 시간

페이지 폴트율 $p$ (0 ≤ p ≤ 1)에서:

$$
EAT = (1 - p) \times m + p \times \text{페이지 폴트 처리 시간}
$$

페이지 폴트 처리 시간은 디스크 접근을 포함하므로 메모리 접근보다 수백~수천 배 느립니다.

## 지역성(Locality)

**지역성**은 프로그램이 짧은 시간 동안 메모리의 **특정 영역에 집중적으로 접근**하는 경향입니다.

| 종류 | 설명 |
|------|------|
| **시간적 지역성** | 최근 참조한 위치를 가까운 미래에 또 참조 (루프 반복) |
| **공간적 지역성** | 참조한 위치 근처의 위치를 참조 (배열 순차 접근) |

지역성 원리 덕분에 요구 페이징이 효율적으로 동작합니다.

## 워킹 셋(Working Set)

**워킹 셋**은 프로세스가 현재 활발히 사용 중인 페이지들의 집합입니다.

- 워킹 셋 크기 = $|W(t, \Delta)|$ (현재 시간 t에서 과거 $\Delta$ 시간 동안 참조된 페이지 집합)
- 프로세스에게 워킹 셋만큼의 프레임이 할당되면 페이지 폴트가 적게 발생

## 스래싱(Thrashing)

**스래싱**은 프로세스들이 페이지 폴트를 처리하는 데 대부분의 시간을 소비하여 **실제 작업 시간이 거의 없는** 현상입니다.

### 스래싱 발생 원인

```
다중 프로그래밍 정도 증가
    ↓
각 프로세스에 할당된 프레임 수 감소
    ↓
페이지 폴트 빈도 증가
    ↓
CPU 이용률 감소 (디스크 I/O 대기)
    ↓
운영체제가 다중 프로그래밍 정도를 더 높임 (CPU 이용률 높이려고)
    ↓
더 심한 스래싱 → CPU 이용률 급격히 감소
```

### 스래싱 해결 방법

- **워킹 셋 모델:** 프로세스의 워킹 셋 크기만큼 프레임 확보 후 실행
- **페이지 폴트 빈도(PFF) 기법:** 페이지 폴트율이 높으면 프레임 추가, 낮으면 반환
- **다중 프로그래밍 정도 감소:** 프로세스 수를 줄여 각 프로세스의 프레임 확보

## 프레임 할당 방식

| 방식 | 설명 | 특징 |
|------|------|------|
| **균등 할당** | 모든 프로세스에 동일한 수의 프레임 | 단순하지만 불공평 |
| **비례 할당** | 프로세스 크기에 비례하여 프레임 할당 | 공평하지만 구현 복잡 |
| **우선순위 할당** | 높은 우선순위 프로세스에 더 많은 프레임 | 중요 작업 우선 |

## 전역 교체 vs 지역 교체

| 구분 | 전역 교체 | 지역 교체 |
|------|---------|---------|
| 교체 범위 | 모든 프로세스의 프레임 중에서 선택 | 자신의 프레임 내에서만 선택 |
| 특징 | 유연하지만 타 프로세스에 영향 | 독립적이지만 부족 시 문제 |

## 핵심 정리

- 가상 메모리는 물리 메모리보다 큰 주소 공간을 제공하며, 요구 페이징으로 필요한 페이지만 적재한다
- 페이지 폴트 발생 시: 트랩 → 디스크에서 페이지 읽기 → 페이지 테이블 업데이트 → 명령어 재시작
- 지역성(시간적/공간적)이 요구 페이징의 효율성을 보장한다
- 스래싱은 프레임 부족으로 페이지 폴트가 과다하게 발생하는 현상이다
- 워킹 셋 모델과 PFF 기법으로 스래싱을 방지한다
