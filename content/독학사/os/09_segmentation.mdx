## 세그멘테이션(Segmentation)이란?

**세그멘테이션**은 프로세스를 논리적으로 의미 있는 **가변 크기의 세그먼트(Segment)**로 나누어 관리하는 기법입니다.

- 코드, 스택, 힙, 데이터 등 논리적 단위로 분할
- 각 세그먼트는 크기가 다를 수 있음
- 프로그래머가 주소 공간을 세그먼트 번호와 오프셋으로 인식

```
세그먼트 구성 예시:
┌──────────────────┐
│ 세그먼트 0: 코드  │ (5KB)
│ 세그먼트 1: 스택  │ (8KB)
│ 세그먼트 2: 힙    │ (3KB)
│ 세그먼트 3: 데이터│ (10KB)
└──────────────────┘
```

## 페이징 vs 세그멘테이션 비교

| 구분 | 페이징 | 세그멘테이션 |
|------|--------|-------------|
| 분할 크기 | **고정** (페이지 크기 동일) | **가변** (세그먼트마다 다름) |
| 논리적 단위 | 없음 (임의 분할) | 있음 (코드, 스택 등) |
| 외부 단편화 | 없음 | **발생** |
| 내부 단편화 | 소량 발생 | 없음 |
| 보호 | 페이지 단위 | 세그먼트 단위 (더 직관적) |
| 공유 | 가능 | 가능 (세그먼트 단위) |

## 세그먼트 테이블(Segment Table)

**세그먼트 테이블**은 각 세그먼트의 기준 주소(Base)와 크기(Limit)를 저장합니다.

| 세그먼트 번호 | 기준 주소(Base) | 한계(Limit) |
|-------------|----------------|------------|
| 0 | 1000 | 400 |
| 1 | 6300 | 100 |
| 2 | 4300 | 400 |
| 3 | 3200 | 1100 |

### 주소 변환 과정

논리 주소 = (세그먼트 번호 s, 오프셋 d)

```
1. 세그먼트 테이블에서 s의 기준 주소(base)와 한계(limit) 확인
2. d >= limit이면 → 세그먼트 오류 (접근 위반)
3. 물리 주소 = base + d
```

**예시:** 논리 주소 (2, 100)

- 세그먼트 2의 base = 4300, limit = 400
- 100 < 400이므로 정상
- 물리 주소 = 4300 + 100 = **4400**

## 세그멘테이션의 장점과 단점

### 장점

- **논리적 분리:** 코드, 데이터, 스택을 별도로 관리하여 보호가 직관적
- **공유 용이:** 세그먼트 단위로 공유 가능 (공유 라이브러리 등)
- **내부 단편화 없음:** 세그먼트가 필요한 크기만큼 할당

### 단점

- **외부 단편화 발생:** 가변 크기 할당으로 인해 빈 공간이 조각남
- **크기 예측 어려움:** 특히 스택, 힙은 실행 중 크기 변화

## 페이징과 세그멘테이션의 혼용

**세그멘테이션 + 페이징 혼용 기법**은 두 방법의 장점을 결합합니다.

- 먼저 프로세스를 **세그먼트**로 나눔 (논리적 분리)
- 각 세그먼트를 다시 **페이지**로 나눔 (외부 단편화 제거)

```
주소 변환 과정:
논리 주소 → [세그먼트 번호] → 세그먼트 테이블 → [페이지 번호] → 페이지 테이블 → 물리 주소
```

**Intel x86 아키텍처**가 이 혼용 방식을 사용합니다.

### 혼용의 결과

| 특성 | 결과 |
|------|------|
| 외부 단편화 | 페이징으로 제거 |
| 내부 단편화 | 마지막 페이지에서 소량 발생 |
| 논리적 분리 | 세그먼트로 유지 |
| 보호 | 세그먼트+페이지 두 단계 |

## STBR과 STLR

| 레지스터 | 역할 |
|---------|------|
| **STBR (Segment-Table Base Register)** | 세그먼트 테이블의 메모리 시작 주소 |
| **STLR (Segment-Table Length Register)** | 세그먼트 테이블의 항목 수 |

세그먼트 번호 s >= STLR이면 → 세그먼트 오류

## 핵심 정리

- 세그멘테이션은 가변 크기 세그먼트로 논리적 단위를 유지하지만 외부 단편화가 발생한다
- 세그먼트 테이블은 각 세그먼트의 기준 주소(base)와 한계(limit)를 저장한다
- 논리 주소 (s, d): d >= limit이면 오류, 물리 주소 = base + d
- 페이지는 외부 단편화 없음, 세그먼트는 내부 단편화 없음
- 혼용 기법은 두 장점을 결합하며 Intel x86이 사용한다
