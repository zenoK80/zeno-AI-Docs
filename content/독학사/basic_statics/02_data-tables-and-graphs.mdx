<Callout type="info">
  **이번 문서의 목표:** 표의 행·열 구조와 막대그래프·꺾은선그래프의 x축·y축을 정확히 읽고, 그래프에서 값을 직접 뽑아낼 수 있게 됩니다.
</Callout>

## 왜 이 문서가 필요한가?

기초통계학 시험 문제의 절반 가까이는 "다음 표를 보고 답하시오", "다음 그래프에서 ○○의 값은?" 형태입니다. 표·그래프를 빨리, 정확히 읽는 능력이 없으면 계산법을 알아도 문제를 풀 수 없습니다.

## 표(Table)의 기본 구조

| 학년 | 남학생 | 여학생 | 합계 |
|------|--------|--------|------|
| 1학년 | 12 | 15 | 27 |
| 2학년 | 10 | 18 | 28 |
| 3학년 | 14 | 11 | 25 |
| **합계** | **36** | **44** | **80** |

- **행**(Row): 가로 줄. 위 표에서 "1학년" 줄 전체.
- **열**(Column): 세로 줄. 위 표에서 "남학생" 칸 전체.
- **셀**(Cell): 행과 열이 만나는 하나의 칸. "2학년 여학생 = 18".

> **쉽게 말하면:** 표는 "가로(행)로는 대상을, 세로(열)로는 항목을 나열한 격자"입니다.

**교차표(Cross Table) 읽기 연습:** 위 표에서 "3학년 남학생"은 몇 명일까요? → 행 "3학년"과 열 "남학생"이 만나는 칸 = **14명**.

## x축과 y축

그래프에는 항상 두 개의 기준선이 있습니다.

- **x축**(가로축): 보통 "무엇을 비교하는지"(범주, 시간)를 나타냅니다.
- **y축**(세로축): 보통 "그 값이 얼마인지"(수치)를 나타냅니다.

> **비유:** x축은 "어떤 이야기인지", y축은 "그 이야기가 얼마나 큰지"라고 생각하면 됩니다.

## 막대그래프(Bar Chart)

각 범주의 값을 막대의 **길이**로 비교합니다.

<DataBarChart
  label="학년별 학생 수"
  unit="명"
  data={[
    { label: '1학년', value: 27 },
    { label: '2학년', value: 28 },
    { label: '3학년', value: 25 },
  ]}
/>

**읽는 법:** 막대가 길수록 값이 큽니다. 위 그래프에서 가장 학생이 많은 학년은 **2학년**(28명)입니다.

## 꺾은선그래프(Line Chart)

시간에 따른 **변화 추세**를 보여줄 때 사용합니다. 각 시점의 값을 점으로 찍고 선으로 연결합니다.

<DataBarChart
  label="월별 방문자 수"
  unit="명"
  data={[
    { label: '1월', value: 200 },
    { label: '2월', value: 250 },
    { label: '3월', value: 180 },
    { label: '4월', value: 400 },
    { label: '5월', value: 450 },
  ]}
/>

**읽는 법:** 실제 꺾은선그래프였다면 점들을 선으로 이었을 때, 값이 커지는 구간은 선이 오른쪽 위로, 작아지는 구간은 오른쪽 아래로 향합니다. 위 데이터에서는 3월에 감소했다가 4월부터 다시 증가하는 추세입니다.

## 원그래프(Pie Chart)

전체를 100%로 보고, 각 항목이 차지하는 **비율**을 부채꼴 크기로 나타냅니다.

<Callout type="info">
  원그래프는 "전체 중 비율"을 강조할 때, 막대그래프는 "항목 간 크기 비교"를 강조할 때, 꺾은선그래프는 "시간에 따른 변화"를 강조할 때 사용합니다. 셋의 목적을 구분해서 기억해두면 어떤 그래프를 골라야 하는지도 시험에 자주 나옵니다.
</Callout>

## 표에서 비율 계산하기

표의 각 셀 값을 합계로 나누면 비율을 구할 수 있습니다.

**예시:** 위 표에서 "1학년 여학생"의 비율은 전체(80명) 중 몇 %일까요?

$$
\frac{15}{80} = 0.1875 = 18.75\%
$$

## 핵심 정리

- **표**: 행(가로)×열(세로)로 이루어진 격자. 교차하는 셀에서 값을 읽는다.
- **x축**: 무엇을 비교하는지. **y축**: 그 값이 얼마인지.
- **막대그래프**: 항목 간 크기 비교. **꺾은선그래프**: 시간에 따른 변화. **원그래프**: 전체 중 비율.
- 표의 셀 값 ÷ 합계 = 비율(퍼센트로 표현 가능).
