## 두 변수 사이의 관계

변수 두 개가 함께 변하는 경향이 있을 때, 그 관계의 방향과 강도를 수치화하는 것이 **상관분석(correlation analysis)**입니다.

**예:** 공부 시간이 늘수록 시험 점수가 높아지는 경향이 있습니다. 이를 **양의 상관관계**라 합니다.

먼저 **산점도(scatter plot)**를 그려 두 변수의 관계를 시각적으로 확인하는 것이 중요합니다.

## 피어슨 상관계수

**피어슨 상관계수(Pearson correlation coefficient, $r$)**는 두 변수 $X$, $Y$ 사이의 선형 관계의 방향과 강도를 -1에서 1 사이의 값으로 나타냅니다.

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

또는 표본 공분산 $s_{xy}$와 표준편차 $s_x$, $s_y$를 이용해

$$r = \frac{s_{xy}}{s_x s_y}$$

### 상관계수 해석

| $r$ 범위 | 해석 |
|---|---|
| $r = 1$ | 완전한 양의 선형 관계 |
| $0.7 \le r < 1$ | 강한 양의 상관 |
| $0.3 \le r < 0.7$ | 약한 양의 상관 |
| $-0.3 < r < 0.3$ | 거의 없음 |
| $-0.7 < r \le -0.3$ | 약한 음의 상관 |
| $r = -1$ | 완전한 음의 선형 관계 |

<Callout type="warning">
  상관관계는 인과관계를 의미하지 않습니다. 두 변수가 상관관계를 보이더라도 한 변수가 다른 변수를 직접 원인이라 결론 내릴 수 없습니다.
</Callout>

## 단순선형회귀

**회귀분석(regression analysis)**은 독립변수 $X$로 종속변수 $Y$를 예측하는 모형을 수립합니다.

**단순선형회귀(simple linear regression)**는 독립변수가 하나인 경우입니다.

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

- $\beta_0$: 절편(intercept) — $X=0$일 때의 $Y$ 예측값
- $\beta_1$: 기울기(slope) — $X$가 1 증가할 때 $Y$의 평균 변화량
- $\varepsilon$: 오차항(error term)

## 최소제곱법

회귀계수 $\beta_0$, $\beta_1$은 **최소제곱법(ordinary least squares)**으로 추정합니다. 실제 값과 예측값의 차이(잔차) 제곱합을 최소화합니다.

$$SSE = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 = \min$$

추정된 회귀계수:

$$\hat{\beta}_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2} = \frac{s_{xy}}{s_x^2}$$

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$$

회귀직선은 항상 $(\bar{x}, \bar{y})$를 지납니다.

**예:** 공부 시간 $X$와 점수 $Y$의 자료입니다.

| $x$ | $y$ |
|---|---|
| 1 | 50 |
| 2 | 60 |
| 3 | 70 |
| 4 | 80 |
| 5 | 90 |

$\bar{x} = 3$, $\bar{y} = 70$

$$\hat{\beta}_1 = \frac{(1-3)(50-70)+(2-3)(60-70)+(3-3)(70-70)+(4-3)(80-70)+(5-3)(90-70)}{(1-3)^2+(2-3)^2+\cdots+(5-3)^2}$$

$$= \frac{40+10+0+10+40}{4+1+0+1+4} = \frac{100}{10} = 10$$

$$\hat{\beta}_0 = 70 - 10 \times 3 = 40$$

추정 회귀식: $\hat{Y} = 40 + 10X$

공부를 1시간 더 할 때마다 점수가 평균 10점 오른다고 해석합니다.

## 결정계수 ($R^2$)

**결정계수(coefficient of determination)**는 회귀모형이 종속변수의 변동을 얼마나 설명하는지 나타냅니다.

$$R^2 = r^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

- $SST = \sum(y_i - \bar{y})^2$: 총 변동
- $SSR = \sum(\hat{y}_i - \bar{y})^2$: 회귀로 설명된 변동
- $SSE = \sum(y_i - \hat{y}_i)^2$: 설명되지 않은 잔차 변동

$R^2 = 1$이면 완벽한 예측, $R^2 = 0$이면 회귀모형이 아무것도 설명하지 못합니다.

단순선형회귀에서 $R^2 = r^2$이므로 위 예에서 $r = 1$이면 $R^2 = 1$입니다.

## 핵심 정리

- 상관계수 $r$: $-1 \le r \le 1$, 선형 관계의 방향과 강도
- $r > 0$: 양의 상관, $r < 0$: 음의 상관, $r = 0$: 선형 관계 없음
- 단순선형회귀: $\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X$
- 기울기: $\hat{\beta}_1 = s_{xy}/s_x^2$, 절편: $\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$
- 결정계수 $R^2 = r^2$: 0에서 1 사이, 높을수록 모형 적합도 좋음
