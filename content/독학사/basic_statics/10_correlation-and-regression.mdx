## 왜 상관분석과 회귀분석이 필요할까?

"공부 시간이 길수록 시험 점수가 높을까?", "광고비를 늘리면 판매량이 오를까?", "키가 크면 몸무게도 무거울까?" 이런 질문들은 두 변수 사이의 관계를 묻고 있습니다.

- **상관분석(correlation analysis, 코릴레이션 어낼러시스):** 두 변수가 어느 정도 함께 변하는지 방향과 강도를 수치화합니다.
- **회귀분석(regression analysis, 리그레션 어낼러시스):** 한 변수로 다른 변수를 예측하는 수식(모형)을 만듭니다.

## 두 변수 사이의 관계

변수 두 개가 함께 변하는 경향이 있을 때, 그 관계의 방향과 강도를 수치화하는 것이 **상관분석**입니다.

- **양의 상관관계(positive correlation):** 한 변수가 증가하면 다른 변수도 증가하는 경향. 예: 공부 시간과 시험 점수
- **음의 상관관계(negative correlation):** 한 변수가 증가하면 다른 변수는 감소하는 경향. 예: 결석 횟수와 성적
- **무상관(no correlation):** 두 변수 사이에 일정한 경향이 없음. 예: 신발 크기와 시험 점수

**중요:** 분석 전에 먼저 **산점도(scatter plot, 스캐터 플랏)**를 그려 두 변수의 관계를 시각적으로 확인해야 합니다. 숫자만 보면 놓칠 수 있는 특이한 패턴(곡선 관계, 이상값)을 발견할 수 있습니다.

## 피어슨 상관계수

**피어슨 상관계수(Pearson correlation coefficient, 피어슨 코릴레이션 코이피션트, $r$)**는 두 변수 $X$, $Y$ 사이의 **선형 관계**의 방향과 강도를 -1에서 1 사이의 값으로 나타냅니다.

기호: $r$ (소문자 알파벳 r, 표본 상관계수)

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

또는 표본 공분산 $s_{xy}$와 표준편차 $s_x$, $s_y$를 이용해

$$r = \frac{s_{xy}}{s_x s_y}$$

기호 설명:
- $r$: 표본 상관계수 (sample correlation coefficient)
- $x_i$, $y_i$: 각 관측쌍의 값
- $\bar{x}$, $\bar{y}$: X와 Y의 평균
- $s_{xy}$: 표본 공분산 (covariance), X와 Y가 함께 변하는 정도
- $s_x$, $s_y$: X와 Y의 표준편차

### 상관계수 해석

| $r$ 범위 | 해석 |
|---|---|
| $r = 1$ | 완전한 양의 선형 관계 (모든 점이 오른쪽 위로 직선 위에 있음) |
| $0.7 \le r < 1$ | 강한 양의 상관 |
| $0.3 \le r < 0.7$ | 약한 양의 상관 |
| $-0.3 < r < 0.3$ | 거의 없음 |
| $-0.7 < r \le -0.3$ | 약한 음의 상관 |
| $-1 < r \le -0.7$ | 강한 음의 상관 |
| $r = -1$ | 완전한 음의 선형 관계 (모든 점이 오른쪽 아래로 직선 위에 있음) |

**비유:** 상관계수는 "두 변수가 같은 방향으로 변하는 정도"입니다. r=0.9는 "한쪽이 오르면 다른 쪽도 거의 항상 오른다", r=-0.9는 "한쪽이 오르면 다른 쪽은 거의 항상 내려간다"는 뜻입니다.

<Callout type="warning">
  상관관계(correlation)는 인과관계(causation, 코제이션)를 의미하지 않습니다. 두 변수가 상관관계를 보이더라도 한 변수가 다른 변수의 원인이라고 결론 내릴 수 없습니다. 예: 아이스크림 판매량과 익사 사고 건수는 양의 상관관계지만, 아이스크림이 익사 사고의 원인이 아닙니다 (둘 다 여름에 높아지기 때문).
</Callout>

## 단순선형회귀

**회귀분석(regression analysis)**은 독립변수 $X$로 종속변수 $Y$를 예측하는 모형을 수립합니다.

- **독립변수(independent variable, 인디펜던트 베리어블):** 예측에 사용하는 변수. 예: 공부 시간
- **종속변수(dependent variable, 디펜던트 베리어블):** 예측하고 싶은 변수. 예: 시험 점수

**단순선형회귀(simple linear regression, 심플 리니어 리그레션)**는 독립변수가 하나인 경우의 회귀분석입니다.

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

기호 설명:
- $\beta_0$: 베타0(beta zero), 절편(intercept) — $X=0$일 때의 $Y$ 기대값
- $\beta_1$: 베타1(beta one), 기울기(slope) — $X$가 1 증가할 때 $Y$의 평균 변화량
- $\varepsilon$: 엡실론(epsilon), 오차항(error term) — 모형으로 설명되지 않는 랜덤한 변동

**쉽게 말하면:** "Y = 절편 + 기울기×X + 오차"입니다. 오차는 현실이 완벽한 직선을 따르지 않기 때문에 발생합니다.

## 최소제곱법

회귀계수 $\beta_0$, $\beta_1$은 **최소제곱법(ordinary least squares, OLS)**으로 추정합니다. 실제 값과 예측값의 차이(잔차) 제곱합을 최소화합니다.

**잔차(residual, 레지듀얼):** 실제 값과 회귀직선이 예측한 값의 차이. 기호 $e_i = y_i - \hat{y}_i$

$$SSE = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 = \min$$

기호 설명:
- $SSE$: Sum of Squared Errors (오차 제곱합)
- $\hat{y}_i$ (y 햇, y-hat): 회귀식으로 예측한 값
- $y_i$: 실제 관측값

**추정된 회귀계수:**

$$\hat{\beta}_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2} = \frac{s_{xy}}{s_x^2}$$

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$$

기호 $\hat{}$(햇, hat)은 추정값임을 나타냅니다.

**중요한 성질:** 회귀직선은 항상 $(\bar{x}, \bar{y})$(두 변수의 평균 점)을 지납니다.

**예:** 공부 시간 $X$와 점수 $Y$의 자료입니다.

| $x$(공부 시간) | $y$(점수) |
|---|---|
| 1 | 50 |
| 2 | 60 |
| 3 | 70 |
| 4 | 80 |
| 5 | 90 |

$\bar{x} = 3$, $\bar{y} = 70$

$$\hat{\beta}_1 = \frac{(1-3)(50-70)+(2-3)(60-70)+(3-3)(70-70)+(4-3)(80-70)+(5-3)(90-70)}{(1-3)^2+(2-3)^2+0^2+(4-3)^2+(5-3)^2}$$

$$= \frac{40+10+0+10+40}{4+1+0+1+4} = \frac{100}{10} = 10$$

$$\hat{\beta}_0 = 70 - 10 \times 3 = 40$$

추정 회귀식: $\hat{Y} = 40 + 10X$

**해석:** 공부를 1시간 더 할 때마다 점수가 평균 10점 오른다. 공부를 0시간 하면 예측 점수는 40점이다.

## 결정계수 ($R^2$)

**결정계수(coefficient of determination, 코이피션트 오브 디터미네이션)**는 회귀모형이 종속변수의 변동을 얼마나 설명하는지 나타냅니다.

$$R^2 = r^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

기호 설명:
- $R^2$: 결정계수, 0에서 1 사이의 값
- $SST$: Sum of Squares Total (총 변동) $= \sum(y_i - \bar{y})^2$
- $SSR$: Sum of Squares Regression (회귀로 설명된 변동) $= \sum(\hat{y}_i - \bar{y})^2$
- $SSE$: Sum of Squares Error (설명되지 않은 잔차 변동) $= \sum(y_i - \hat{y}_i)^2$

관계: $SST = SSR + SSE$ (총 변동 = 설명된 변동 + 설명 안 된 변동)

**해석:**
- $R^2 = 1$: 모든 점이 회귀직선 위에 있어 완벽한 예측 (현실에서는 불가능)
- $R^2 = 0$: 회귀모형이 아무것도 설명하지 못함
- $R^2 = 0.81$: 종속변수 변동의 81%를 회귀모형이 설명함

단순선형회귀에서 $R^2 = r^2$ (상관계수의 제곱)이므로 위 예에서 $r = 1$이면 $R^2 = 1$입니다.

**비유:** $R^2 = 0.81$은 "이 모형이 Y의 변동에서 81%는 설명해 주고, 나머지 19%는 다른 요인에 의한 것"이라는 의미입니다.

## 핵심 정리

- **상관계수(correlation coefficient)** $r$: $-1 \le r \le 1$, 선형 관계의 방향과 강도
- $r > 0$: 양의 상관, $r < 0$: 음의 상관, $r = 0$: 선형 관계 없음
- **상관관계 $\ne$ 인과관계**
- **단순선형회귀(simple linear regression)**: $\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X$
- 기울기: $\hat{\beta}_1 = s_{xy}/s_x^2$, 절편: $\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$
- 회귀직선은 $(\bar{x}, \bar{y})$를 통과함
- **결정계수(coefficient of determination)** $R^2 = r^2$: 0에서 1 사이, 높을수록 모형 적합도 좋음
