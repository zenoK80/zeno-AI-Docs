## 왜 의사결정 트리가 필요한가?

"이 환자가 심장병이 있는가?"를 판단할 때, 의사는 "혈압이 높은가? → 예. 콜레스테롤 수치가 높은가? → 예. → 고위험군"처럼 여러 조건을 순서대로 확인합니다. 이런 의사 결정 과정을 나무(tree) 구조로 표현한 것이 **의사결정 트리**(decision tree, 의사결정 나무) 입니다.

**비유:** 스무고개 게임. "그것은 동물인가요? → 예. 날 수 있나요? → 아니오. 4개의 다리가 있나요? → 예. → 호랑이!"처럼 질문을 던지면서 정답을 찾아갑니다.

> 쉽게 말하면: 데이터를 조건에 따라 계속 쪼개서 나무처럼 분류하는 방법입니다.

---

## 의사결정 트리의 구조

```
           [혈압 > 140?]       ← 루트 노드(root node, 최상단 노드)
           /           \
          예            아니오
         /                \
  [콜레스테롤 > 200?]    [저위험군]  ← 리프 노드(leaf node, 최종 노드)
       /       \
      예        아니오
     /              \
 [고위험군]       [중위험군]  ← 리프 노드
```

- **루트 노드(root node):** 트리의 최상단 시작점
- **내부 노드(internal node):** 조건(질문)을 담은 중간 노드
- **리프 노드(leaf node):** 최종 예측값(분류 결과)을 담은 끝 노드
- **분기(branch):** 조건에 따라 나뉘는 경로

**장점:**
- 해석이 쉬움 — 결정 과정을 눈으로 볼 수 있음 (화이트박스 모델)
- 특성 스케일링 불필요
- 분류와 회귀 모두 가능

**단점:**
- 과적합(overfitting, 훈련 데이터에 지나치게 맞춰지는 현상) 경향이 강함
- 데이터가 조금만 바뀌어도 트리 구조가 크게 달라짐 (불안정)

## 불순도 측정 지표

**왜 필요한가?** 어떤 조건으로 데이터를 분할해야 가장 효과적으로 클래스를 나눌 수 있는지 수치로 평가해야 합니다. "불순도(impurity, 불순도)"가 낮을수록 한 클래스가 모여 있는 순수한 그룹입니다.

### 엔트로피 (entropy, 엔트로피)

정보이론에서 불확실성을 측정하는 지표입니다:

$$H = -\sum_{k=1}^{K} p_k \log_2 p_k$$

각 변수의 의미:

- $K$: 클래스 수
- $p_k$: k번째 클래스가 차지하는 비율
- $\log_2$: 2를 밑으로 하는 로그

**직관:** 모든 데이터가 한 클래스면 엔트로피 = 0 (완전히 확실). 클래스가 균등하게 섞이면 엔트로피 최대 (완전히 불확실).

### 정보이득 (information gain, 정보이득)

분할 전후의 엔트로피 차이로, 분할이 얼마나 유용한지 측정합니다:

$$IG = H(\text{부모 노드}) - \sum_{v} \frac{|D_v|}{|D|} H(D_v)$$

각 변수의 의미:

- $H(\text{부모 노드})$: 분할 전 엔트로피
- $\frac{|D_v|}{|D|}$: 자식 노드 v가 차지하는 데이터 비율 (가중치)
- $H(D_v)$: 자식 노드 v의 엔트로피

**정보이득이 클수록 좋은 분할** → 불확실성이 크게 줄어들었다는 의미

### 지니 불순도 (Gini impurity, 지니 불순도)

CART(Classification and Regression Trees) 알고리즘에서 사용합니다:

$$G = 1 - \sum_{k=1}^{K} p_k^2$$

각 변수의 의미:

- $p_k$: k번째 클래스의 비율
- $p_k^2$: 같은 클래스끼리 올바르게 분류할 확률

**직관:**
- 모든 데이터가 한 클래스 → $p_k = 1$ → $G = 1 - 1 = 0$ (완전 순수)
- 두 클래스가 50:50 → $G = 1 - (0.5^2 + 0.5^2) = 0.5$ (최대 불순도, 이진 분류 기준)

| 지표 | 수식 | 사용 알고리즘 |
| --- | --- | --- |
| 엔트로피 | $-\sum p_k \log_2 p_k$ | ID3, C4.5 |
| 지니 불순도 | $1 - \sum p_k^2$ | CART |

---

## 주요 알고리즘

| 알고리즘 | 분할 기준 | 특징 |
| --- | --- | --- |
| ID3(Iterative Dichotomiser 3) | 정보이득(엔트로피 기반) | 범주형 특성에 최적, 이진 분류 |
| C4.5 | 정보이득 비율 | 연속/범주형 특성 모두 가능, 다치 분류 |
| CART(Classification And Regression Trees) | 지니 불순도 | 이진 분할만, 분류/회귀 모두 가능 |

**C4.5가 ID3를 개선한 점:** ID3는 값의 종류가 많은 특성을 선호하는 편향(bias)이 있습니다. C4.5는 정보이득을 분할 정보로 나눈 **정보이득 비율**(gain ratio)을 사용하여 이 편향을 완화합니다.

## 과적합 방지 — 가지치기 (pruning, 가지치기)

**왜 필요한가?** 제한 없이 트리를 키우면 훈련 데이터의 잡음(noise)까지 외워버려 새로운 데이터에서 성능이 나빠집니다.

### 사전 가지치기 (pre-pruning, 조기 종료)

트리가 성장하는 도중에 조건을 걸어 더 이상 분기하지 않도록 합니다:

- `max_depth`: 최대 깊이 제한 (예: 깊이 5 이상으로 안 키움)
- `min_samples_split`: 분할하기 위한 최소 샘플 수
- `min_samples_leaf`: 리프 노드에 있어야 하는 최소 샘플 수
- `max_leaf_nodes`: 최대 리프 노드 수

### 사후 가지치기 (post-pruning, 사후 정리)

트리를 완전히 성장시킨 후, 성능에 기여하지 않는 불필요한 가지를 제거합니다.

<Callout type="warning">
  의사결정 트리는 훈련 데이터에 과적합되기 쉽습니다. 가지치기(Pruning)나 앙상블 방법(랜덤 포레스트)으로 이를 완화합니다. 실제로 단독으로 사용하기보다는 앙상블의 기본 학습기로 많이 활용됩니다.
</Callout>

---

## 핵심 정리

- **의사결정 트리:** 조건으로 데이터를 반복 분할하는 화이트박스 모델
- **ID3:** 정보이득, **C4.5:** 정보이득 비율, **CART:** 지니 불순도
- **지니 불순도:** $1 - \sum p_k^2$ (순수할수록 0에 가까움)
- **엔트로피:** $-\sum p_k \log_2 p_k$ (불확실할수록 큰 값)
- **사전 가지치기:** 성장 중 조기 중단 (max_depth 등)
- **사후 가지치기:** 다 키운 후 불필요한 가지 제거
