## 머신러닝이란?

**머신러닝(Machine Learning)** 은 명시적으로 프로그래밍하지 않고 데이터로부터 패턴을 학습하여 예측이나 의사결정을 하는 인공지능 분야입니다.

**아서 사무엘(Arthur Samuel, 1959):** "명시적으로 프로그래밍하지 않고 컴퓨터가 학습할 수 있도록 하는 연구 분야"

## 머신러닝의 세 가지 패러다임

### 지도 학습 (Supervised Learning)

입력 데이터(X)와 정답 레이블(y)이 쌍으로 제공된 훈련 데이터로 학습합니다.

| 종류 | 예시 알고리즘 | 출력 |
| --- | --- | --- |
| 분류(Classification) | 로지스틱 회귀, SVM, 의사결정 트리 | 클래스 레이블 |
| 회귀(Regression) | 선형 회귀, 릿지, 라쏘 | 연속값 |

### 비지도 학습 (Unsupervised Learning)

레이블 없는 데이터에서 숨겨진 구조나 패턴을 발견합니다.

| 종류 | 예시 알고리즘 |
| --- | --- |
| 군집화(Clustering) | K-means, DBSCAN |
| 차원 축소(Dimensionality Reduction) | PCA, t-SNE |
| 연관 규칙(Association Rule) | Apriori |

### 강화 학습 (Reinforcement Learning)

에이전트가 환경과 상호작용하며 보상(Reward)을 최대화하는 방향으로 학습합니다.

- **에이전트(Agent):** 학습하는 주체
- **환경(Environment):** 에이전트가 상호작용하는 공간
- **상태(State), 행동(Action), 보상(Reward)**
- 예: 게임 플레이, 로봇 제어

## 머신러닝 vs 딥러닝

| 항목 | 머신러닝(ML) | 딥러닝(DL) |
| --- | --- | --- |
| 특성 추출 | 수동(Feature Engineering) | 자동(Feature Learning) |
| 데이터 양 | 소량 가능 | 대량 필요 |
| 해석 가능성 | 높음 | 낮음 (블랙박스) |
| 대표 모델 | SVM, 의사결정 트리 | CNN, RNN, Transformer |
| 계산 자원 | 적게 필요 | 많이 필요(GPU) |

<Callout type="warning">
  딥러닝은 머신러닝의 하위 분야입니다. 즉 모든 딥러닝은 머신러닝이지만, 모든 머신러닝이 딥러닝은 아닙니다.
</Callout>

## 머신러닝 파이프라인

1. 문제 정의
2. 데이터 수집 및 탐색적 분석(EDA)
3. 데이터 전처리 및 특성 공학
4. 모델 선택 및 학습
5. 모델 평가 및 튜닝
6. 배포 및 모니터링

## 훈련/검증/테스트 분리

| 데이터 세트 | 역할 | 일반 비율 |
| --- | --- | --- |
| 훈련 세트(Train) | 모델 학습 | 60~70% |
| 검증 세트(Validation) | 하이퍼파라미터 튜닝 | 10~20% |
| 테스트 세트(Test) | 최종 성능 평가 | 20~30% |

## 핵심 정리

- 지도 학습: 레이블 있는 데이터, 분류/회귀
- 비지도 학습: 레이블 없는 데이터, 군집/차원 축소
- 강화 학습: 보상 최대화를 위한 에이전트-환경 상호작용
- 딥러닝: 머신러닝의 하위 집합, 자동 특성 추출
