## 앙상블 학습(Ensemble Learning)이란?

> **쉽게 말하면:** 앙상블은 "여러 전문가의 의견을 모아 하나의 최종 결정을 내리는" 것처럼, 여러 개의 모델을 결합해 하나의 모델보다 더 좋은 성능을 내는 방법입니다.

**비유:** 어려운 문제를 풀 때 한 명의 전문가보다, 서로 다른 관점을 가진 여러 전문가의 의견을 종합하면 더 정확한 결론에 도달하기 쉬운 것과 같은 원리입니다.

## 투표(Voting) — 가장 단순한 결합 방식

> **쉽게 말하면:** 여러 모델의 예측 결과를 모아서 다수결(분류) 또는 평균(회귀)으로 최종 결정을 내리는 방식입니다.

**예시:** 세 개의 서로 다른 모델이 각각 [양성, 양성, 음성]으로 예측했다면, 다수결 투표로 최종 예측은 **양성**이 됩니다.

## 배깅(Bagging) — Bootstrap Aggregating

**단어 풀이:**

| 단어 | 뜻 |
|------|-----|
| Bootstrap | 원본 데이터에서 중복을 허용해 무작위로 다시 뽑는 샘플링 방법 |
| Aggregating | 여러 결과를 하나로 모으는(집계하는) 것 |

> **쉽게 말하면:** 배깅은 원본 데이터에서 여러 번 무작위로(중복 허용) 샘플을 뽑아 여러 개의 훈련 데이터셋을 만들고, 각각으로 모델을 따로 학습시킨 뒤 결과를 투표로 합치는 방법입니다.

<Steps>
### 1단계: 부트스트랩 샘플링
원본 데이터(예: 100개)에서 중복을 허용하며 무작위로 100개를 뽑아, 서로 조금씩 다른 여러 개의 훈련 데이터셋을 만듭니다.

### 2단계: 각 데이터셋으로 개별 모델 학습
만들어진 각 데이터셋으로 독립적인 모델(예: 의사결정나무)을 학습시킵니다.

### 3단계: 결과 결합
모든 모델의 예측을 투표(분류) 또는 평균(회귀)으로 합쳐 최종 예측을 만듭니다.
</Steps>

<Callout type="info">
  **배깅이 성능을 높이는 이유:** 11번 문서에서 배운 것처럼, 하나의 깊은 의사결정나무는 과적합되기 쉽습니다. 배깅은 조금씩 다른 데이터로 학습된 여러 나무의 결과를 평균 냄으로써, 개별 나무의 "과도한 특이성"이 서로 상쇄되어 더 안정적인 예측을 만듭니다.
</Callout>

## 랜덤 포레스트(Random Forest)

> **쉽게 말하면:** 랜덤 포레스트는 배깅에 "각 나무가 분할할 때마다 사용할 특성도 무작위로 일부만 고르게" 하는 규칙을 추가한, 의사결정나무 여러 개(숲)로 이루어진 앙상블 모델입니다.

<Callout type="warning">
  **자주 틀리는 점:** 랜덤 포레스트가 단순히 "배깅을 의사결정나무에 적용한 것"이라고만 이해하면 부족합니다. 핵심 차이는 각 나무가 분할 기준을 정할 때 **전체 특성이 아니라 무작위로 선택된 일부 특성만** 고려한다는 점입니다. 이렇게 하면 여러 나무가 서로 덜 닮게 되어(다양성 증가), 앙상블의 효과가 더 커집니다.
</Callout>

## 부스팅(Boosting)

> **쉽게 말하면:** 부스팅은 배깅처럼 모델을 독립적으로 만드는 대신, "이전 모델이 틀린 데이터에 더 집중해서" 다음 모델을 순차적으로 학습시키는 방법입니다.

<Table>
  <thead>
    <tr><th></th><th>배깅</th><th>부스팅</th></tr>
  </thead>
  <tbody>
    <tr><td>모델 학습 순서</td><td>병렬(서로 독립적으로 동시에 가능)</td><td>순차적(이전 모델의 결과를 반영해야 함)</td></tr>
    <tr><td>핵심 아이디어</td><td>다양한 모델을 만들어 평균으로 분산을 줄임</td><td>이전 모델의 오차(약점)를 보완하는 데 집중</td></tr>
    <tr><td>과적합 위험</td><td>상대적으로 낮음</td><td>지나치게 반복하면 과적합 위험이 커짐</td></tr>
  </tbody>
</Table>

## Gradient Boosting

> **쉽게 말하면:** Gradient Boosting은 "이전 모델이 남긴 오차(잔차)를 다음 모델이 예측하도록" 훈련시켜, 그 오차를 계속 줄여나가는 부스팅 방법입니다.

**계산 예시**(직관적 과정): 실제 집값이 5억인데, 첫 번째 모델이 4.5억으로 예측했다면 오차(잔차)는 0.5억입니다. 두 번째 모델은 원래 집값이 아니라 이 "0.5억"이라는 오차 자체를 예측하도록 학습됩니다. 두 모델의 예측을 더하면($4.5+0.5\times\text{학습률}$) 원래 정답에 더 가까워집니다.

<Callout type="info">
  **06번 문서와의 연결:** "오차를 줄이는 방향으로 조금씩 개선한다"는 아이디어는 경사하강법의 원리와 본질적으로 같습니다. 실제로 Gradient Boosting이라는 이름의 "Gradient"(기울기)는, 매 단계에서 비용 함수의 기울기 방향으로 모델을 개선해나간다는 뜻에서 붙여졌습니다.
</Callout>

## 핵심 정리

- **앙상블 학습**: 여러 모델의 예측을 결합해 하나의 모델보다 더 좋은 성능을 얻는 방법.
- **배깅**: 데이터를 부트스트랩 샘플링해 여러 모델을 병렬로 학습 후 투표·평균으로 결합. 과적합 감소에 효과적.
- **랜덤 포레스트**: 배깅 + 각 분할마다 무작위로 일부 특성만 고려 → 나무들의 다양성을 높임.
- **부스팅**: 이전 모델의 오차에 집중하며 순차적으로 모델을 학습. **Gradient Boosting**은 잔차를 예측하는 방식으로 오차를 줄여나감.
