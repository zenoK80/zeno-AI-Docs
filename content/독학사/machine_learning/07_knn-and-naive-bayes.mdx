## Part 1. KNN — K-Nearest Neighbors (K 최근접 이웃)

### 왜 KNN이 필요한가?

"비슷한 것들끼리 모인다"는 직관에서 출발합니다. 새로운 영화 추천을 받을 때, 나와 취향이 비슷한 사람들(이웃)이 좋아한 영화를 추천받는 것과 같습니다. KNN은 이 아이디어를 수학적으로 구현합니다.

**비유:** 동네에서 이사 온 집의 위치를 보고 주변 K개 집이 어느 학교 구역인지 확인해서 그 집의 학교 구역을 판단하는 것과 같습니다.

### KNN 작동 원리

새로운 데이터 포인트에서 가장 가까운 K개의 이웃을 찾아:
- **분류(classification):** 다수결 투표 → 가장 많은 이웃의 클래스로 예측
- **회귀(regression):** 평균 계산 → K개 이웃의 값 평균을 예측

**게으른 학습(lazy learning, 게으른 학습):**

> 쉽게 말하면: 훈련 단계에서 아무것도 배우지 않고(모델을 만들지 않고), 새로운 데이터가 들어올 때마다 훈련 데이터 전체와 비교합니다.

| 특징 | 설명 |
| --- | --- |
| 비모수적(non-parametric) | 데이터 분포를 가정하지 않음 |
| 게으른 학습 | 훈련 시간 거의 없음 (데이터 저장만) |
| 예측 시간 | 느림 (전체 데이터와 거리 계산) |
| K 선택 | K가 작으면 과적합, K가 크면 과소적합 |

### 거리 측정

KNN에서 "가장 가까운 이웃"을 찾으려면 거리를 수치로 측정해야 합니다:

| 거리 | 수식 | 특징 |
| --- | --- | --- |
| 유클리드 거리(Euclidean distance) | $\sqrt{\sum (x_i - y_i)^2}$ | 직선 거리, 가장 일반적 |
| 맨해튼 거리(Manhattan distance) | $\sum \|x_i - y_i\|$ | 격자 위 이동 거리 |
| 민코프스키 거리(Minkowski distance) | $(\sum \|x_i - y_i\|^p)^{1/p}$ | 유클리드(p=2)와 맨해튼(p=1)의 일반화 |

**비유:** 유클리드 거리는 새가 날아가는 거리, 맨해튼 거리는 도시의 격자 도로를 따라 가는 거리입니다.

<Callout type="warning">
  KNN은 특성의 스케일(scale, 크기)에 매우 민감합니다. 예를 들어 나이(0~100)와 연봉(0~100,000,000)이 있으면 연봉이 거리를 지배합니다. 반드시 특성 스케일링(표준화 또는 정규화)을 해야 합니다.
</Callout>

### KNN의 K 선택

K 값 선택은 모델 성능에 크게 영향을 미칩니다:

- **K = 1:** 가장 가까운 이웃 하나만 보므로 과적합(노이즈에 민감), 복잡한 결정 경계
- **K가 매우 큰 경우:** 너무 많은 이웃을 보므로 과소적합, 단순한 결정 경계
- **일반적 방법:** 교차 검증(cross-validation)으로 최적 K 선택, K는 홀수로 설정(동률 방지)

## Part 2. 베이즈 정리와 나이브 베이즈

### 왜 나이브 베이즈가 필요한가?

이메일이 스팸인지 판단할 때, 이미 본 스팸 메일의 패턴을 활용하고 싶습니다. 베이즈 정리(Bayes' theorem)는 이미 알고 있는 정보(사전 지식)를 새로운 증거로 업데이트하는 수학적 도구입니다.

### 베이즈 정리 (Bayes' theorem, 베이즈 정리)

$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}$$

각 변수의 의미:

| 용어 | 표기 | 설명 |
| --- | --- | --- |
| 사전 확률(prior, 사전 확률) | $P(A)$ | B를 보기 전 A가 참일 확률 |
| 우도(likelihood, 우도) | $P(B \mid A)$ | A가 참일 때 B가 관찰될 확률 |
| 사후 확률(posterior, 사후 확률) | $P(A \mid B)$ | B를 관찰한 후 A가 참일 확률 |
| 증거(evidence, 증거) | $P(B)$ | B가 관찰될 전체 확률 |

**예시:** "무료"라는 단어가 있을 때 스팸일 확률 계산
- $P(\text{스팸})$: 전체 메일 중 스팸 비율 (사전 확률)
- $P(\text{무료} \mid \text{스팸})$: 스팸에서 "무료" 단어가 나올 확률 (우도)
- $P(\text{스팸} \mid \text{무료})$: "무료"가 있을 때 스팸일 확률 (사후 확률, 우리가 원하는 값)

### 나이브 베이즈 분류기 (Naive Bayes classifier, 나이브 베이즈 분류기)

베이즈 정리를 분류에 적용하되, "특성들이 클래스 조건부로 서로 독립"이라고 **가정**합니다:

$$P(y \mid x_1, \ldots, x_n) \propto P(y) \prod_{i=1}^{n} P(x_i \mid y)$$

각 변수의 의미:

- $P(y \mid x_1, \ldots, x_n)$: 특성들이 주어졌을 때 클래스 y일 확률
- $P(y)$: 클래스 y의 사전 확률
- $P(x_i \mid y)$: 클래스 y에서 특성 $x_i$가 관찰될 확률
- $\propto$: 비례 관계

**"나이브(naive)"한 이유:** 특성 독립 가정이 현실에서 성립하기 어렵지만(예: 스팸에서 "무료"와 "이벤트"는 함께 나오는 경향이 있음), 이 가정 덕분에 계산이 단순해지고 실용적으로 좋은 성능을 보입니다.

**비유:** 의사가 여러 증상을 독립적으로 보고 판단하는 것처럼, 각 특성을 독립적으로 고려하여 빠르게 분류합니다.

### 나이브 베이즈의 종류

| 종류 | 특성 분포 가정 | 적용 |
| --- | --- | --- |
| 가우시안 나이브 베이즈(Gaussian Naive Bayes) | 정규 분포 | 연속형 특성 |
| 다항 나이브 베이즈(Multinomial Naive Bayes) | 다항 분포 | 텍스트 분류(단어 빈도) |
| 베르누이 나이브 베이즈(Bernoulli Naive Bayes) | 베르누이 분포 | 이진 특성(단어 있음/없음) |

---

## KNN vs 나이브 베이즈 비교

| 항목 | KNN | 나이브 베이즈 |
| --- | --- | --- |
| 학습 방식 | 게으른 학습(lazy learning) | 즉각 학습 |
| 훈련 시간 | 매우 빠름 (저장만) | 빠름 |
| 예측 시간 | 느림 (전체와 거리 계산) | 빠름 |
| 특성 독립 가정 | 없음 | 있음 |
| 스케일 민감도 | 매우 민감 | 덜 민감 |
| 적합한 경우 | 소규모 데이터, 지역적 패턴 | 텍스트 분류, 고차원 데이터 |

---

## 핵심 정리

- **KNN:** 게으른 학습, 훈련 없음, K개 이웃의 다수결로 분류
- **K 선택:** 작으면 과적합, 크면 과소적합, 교차 검증으로 최적값 탐색
- **특성 스케일링:** KNN에서 필수 (거리 기반이므로)
- **베이즈 정리:** 사전 확률을 새 증거로 업데이트 → 사후 확률
- **나이브 베이즈:** 특성 조건부 독립 가정, 빠르고 단순, 텍스트 분류에 강점
