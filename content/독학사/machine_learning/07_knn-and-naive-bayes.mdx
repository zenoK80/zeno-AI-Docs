## K-최근접 이웃 (K-Nearest Neighbors, KNN)

새로운 데이터 포인트에서 가장 가까운 K개의 이웃을 찾아 다수결(분류) 또는 평균(회귀)으로 예측합니다.

**게으른 학습(Lazy Learning):** 훈련 시 모델 파라미터를 학습하지 않고, 예측 시 전체 훈련 데이터를 사용합니다.

| 특징 | 설명 |
| --- | --- |
| 비모수적 | 데이터 분포 가정 없음 |
| 게으른 학습 | 훈련 시간 거의 없음 |
| 예측 시간 | 느림 (전체 데이터와 거리 계산) |
| K 선택 | K가 작으면 과적합, 크면 과소적합 |

## 거리 측정

| 거리 | 수식 |
| --- | --- |
| 유클리드 | $\sqrt{\sum (x_i - y_i)^2}$ |
| 맨해튼 | $\sum \mid x_i - y_i \mid$ |
| 민코프스키 | $(\sum \mid x_i - y_i \mid^p)^{1/p}$ |

<Callout type="warning">
  KNN은 특성의 스케일에 민감합니다. 반드시 특성 스케일링(표준화 또는 정규화)을 해야 합니다.
</Callout>

## KNN의 K 선택

- **K = 1:** 과적합 경향, 결정 경계가 복잡
- **K가 큰 경우:** 과소적합 경향, 결정 경계가 단순
- **일반적:** 교차 검증으로 최적 K 선택, K는 홀수 선택 (동률 방지)

## 베이즈 정리 (Bayes' Theorem)

사전 확률(Prior)을 새 데이터(증거)로 업데이트하여 사후 확률(Posterior)을 계산합니다.

$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}$$

| 용어 | 설명 |
| --- | --- |
| $P(A)$ | 사전 확률(Prior) |
| $P(B \mid A)$ | 우도(Likelihood) |
| $P(A \mid B)$ | 사후 확률(Posterior) |
| $P(B)$ | 증거(Evidence) |

## 나이브 베이즈 분류기 (Naive Bayes)

베이즈 정리를 분류에 적용하되, 특성들이 클래스 조건부로 서로 독립이라고 가정합니다.

$$P(y \mid x_1, ..., x_n) \propto P(y) \prod_{i=1}^{n} P(x_i \mid y)$$

**"나이브(Naive)"한 이유:** 특성 독립 가정이 현실적으로 성립하기 어렵지만 성능이 좋습니다.

### 나이브 베이즈의 종류

| 종류 | 특성 분포 | 적용 |
| --- | --- | --- |
| 가우시안 나이브 베이즈 | 정규 분포 | 연속 특성 |
| 다항 나이브 베이즈 | 다항 분포 | 텍스트 분류 (단어 빈도) |
| 베르누이 나이브 베이즈 | 베르누이 분포 | 이진 특성 |

## KNN vs 나이브 베이즈 비교

| 항목 | KNN | 나이브 베이즈 |
| --- | --- | --- |
| 학습 방식 | 게으른 학습 | 즉각 학습 |
| 훈련 시간 | 빠름 | 빠름 |
| 예측 시간 | 느림 | 빠름 |
| 특성 독립 가정 | 없음 | 있음 |
| 스케일 민감도 | 민감 | 둔감 |

## 핵심 정리

- KNN: 게으른 학습, K개 이웃의 다수결로 분류
- 특성 스케일링 필수
- 베이즈 정리: P(A|B) = P(B|A)P(A)/P(B)
- 나이브 베이즈: 특성 독립 가정, 빠르고 간단
