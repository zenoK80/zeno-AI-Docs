## 왜 로지스틱 회귀가 필요한가?

선형 회귀로 "스팸인가 아닌가"를 예측하면 어떨까요? 출력값이 0.3이면 아니고, 1.5면 맞다는 건지 기준이 모호합니다. 또한 선형 회귀의 출력은 음수도, 1보다 큰 수도 나올 수 있어 "확률"로 해석하기 어렵습니다.

**분류**(classification, 분류) 문제에서는 출력이 0~1 사이의 확률이어야 합니다. 이를 위해 **로지스틱 회귀**(logistic regression, 로지스틱 회귀) 가 사용됩니다.

> 쉽게 말하면: 이름에 "회귀"가 있지만 실제로는 분류 알고리즘입니다!

**비유:** 체온계로 38도 이상이면 발열, 미만이면 정상으로 판단하는 것처럼, 로지스틱 회귀는 확률을 계산하고 임계값(0.5)과 비교하여 클래스를 결정합니다.

---

## 시그모이드 함수 (sigmoid function, 시그모이드 함수)

선형 결합 $z = \theta^T x$ (선형 회귀 출력)를 0~1 사이의 확률값으로 변환합니다.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

각 변수의 의미:

- $z$: 선형 결합 결과 (어떤 값이든 가능)
- $e$: 자연상수(약 2.718)
- $\sigma(z)$: 출력 확률 (반드시 0~1 사이)

| z 값 | $\sigma(z)$ 결과 | 의미 |
| --- | --- | --- |
| 매우 큰 양수 | 약 1 | 양성 클래스일 확률 거의 100% |
| 0 | 0.5 | 50:50 |
| 매우 큰 음수 | 약 0 | 양성 클래스일 확률 거의 0% |

**시그모이드 모양:** S자 형태의 곡선으로, 어떤 값이 들어와도 0과 1 사이로 압축됩니다.

---

## 이진 분류 (binary classification, 이진 분류)

**예측 과정:**

$$\hat{p} = \sigma(\theta^T x)$$

- $\hat{p}$가 0.5 이상이면 → 양성 클래스(1)로 예측
- $\hat{p}$가 0.5 미만이면 → 음성 클래스(0)로 예측

**비용 함수 — 로그 손실(log loss) / 교차 엔트로피(cross-entropy, 교차 엔트로피):**

$$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{p}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{p}^{(i)}) \right]$$

각 변수의 의미:

- $m$: 훈련 샘플 수
- $y^{(i)}$: i번째 샘플의 실제 레이블 (0 또는 1)
- $\hat{p}^{(i)}$: i번째 샘플에 대한 예측 확률
- $\log$: 자연로그

**직관적 이해:**
- 실제 정답이 1인데 확률을 0에 가깝게 예측 → 손실 매우 큼
- 실제 정답이 1인데 확률을 1에 가깝게 예측 → 손실 거의 0

<Callout type="warning">
  로지스틱 회귀의 비용 함수는 MSE가 아닌 교차 엔트로피(Cross-Entropy)입니다. 이 함수는 볼록(convex) 함수여서 경사하강법으로 전역 최솟값(global minimum)을 확실히 찾을 수 있습니다.
</Callout>

---

## 결정 경계 (decision boundary, 결정 경계)

$\sigma(\theta^T x) = 0.5$, 즉 $\theta^T x = 0$인 직선(또는 초평면)이 두 클래스를 나누는 경계선입니다.

**비유:** 시험 점수가 60점 이상이면 합격, 미만이면 불합격으로 나누는 선과 같습니다. 이 경계를 기준으로 모든 데이터를 두 그룹으로 분류합니다.

---

## 다중 분류 (multiclass classification, 다중 분류)

클래스가 2개가 아닌 3개 이상일 때 사용합니다. 예: 고양이/개/새를 분류하거나, 숫자 0~9를 인식하는 문제.

### OvR (One-vs-Rest, 일대다) 전략

각 클래스에 대해 "이 클래스 vs 나머지 전부"의 이진 분류기를 따로 학습합니다.

- K개 클래스 → K개의 이진 분류기
- 예: 고양이/개/새를 분류하면, "고양이냐 아니냐", "개냐 아니냐", "새냐 아니냐" 3개의 분류기

### 소프트맥스 회귀 (softmax regression, 소프트맥스 회귀)

K개 클래스에 대한 확률을 동시에 계산하는 방법입니다:

$$\hat{p}_k = \text{softmax}(\mathbf{s})_k = \frac{e^{s_k}}{\sum_{j=1}^{K} e^{s_j}}$$

각 변수의 의미:

- $\hat{p}_k$: k번째 클래스에 속할 확률
- $s_k = \theta_k^T x$: 클래스 k에 대한 점수(score)
- 분자 $e^{s_k}$: k번째 클래스의 지수 변환 점수
- 분모: 전체 클래스 점수의 합

**소프트맥스의 핵심 특성:**
- 출력값이 K개 클래스에 대한 확률 → 모두 더하면 반드시 1
- 점수가 가장 높은 클래스를 선택
- 비용 함수: 다중 클래스 교차 엔트로피

**비유:** 시험에서 A/B/C 등급을 받을 확률을 각각 계산하면 모두 합쳐 100%가 되는 것과 같습니다.

---

## 핵심 정리

- **로지스틱 회귀:** 이름과 달리 분류 알고리즘, 선형 결합 + 시그모이드
- **시그모이드:** 0~1 범위의 확률값 출력, S자 곡선
- **비용 함수:** 교차 엔트로피 (MSE 아님), 볼록 함수
- **결정 경계:** 확률 0.5 기준, $\theta^T x = 0$인 경계선
- **다중 분류:** OvR 전략(K개 이진 분류기) 또는 소프트맥스 회귀
