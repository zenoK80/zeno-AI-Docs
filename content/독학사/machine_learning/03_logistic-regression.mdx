## 로지스틱 회귀 (Logistic Regression)

분류(Classification) 문제를 위한 선형 모델입니다. 이름에 "회귀"가 있지만 실제로는 분류 알고리즘입니다.

## 시그모이드 함수 (Sigmoid Function)

선형 결합 $z = \theta^T x$를 0~1 사이의 확률값으로 변환합니다.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

| z | σ(z) |
| --- | --- |
| 매우 큰 양수 | ≈ 1 |
| 0 | 0.5 |
| 매우 큰 음수 | ≈ 0 |

## 이진 분류 (Binary Classification)

$$\hat{p} = \sigma(\theta^T x), \quad \hat{y} = \begin{cases} 1 & \text{if } \hat{p} \geq 0.5 \\ 0 & \text{if } \hat{p} < 0.5 \end{cases}$$

**비용 함수 (로그 손실, Cross-Entropy):**

$$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{p}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{p}^{(i)}) \right]$$

<Callout type="warning">
  로지스틱 회귀의 비용 함수는 MSE가 아닌 **교차 엔트로피(Cross-Entropy)** 입니다. 이 함수는 볼록(Convex)하여 경사하강법으로 전역 최솟값을 찾을 수 있습니다.
</Callout>

## 결정 경계 (Decision Boundary)

$\sigma(\theta^T x) = 0.5$일 때, 즉 $\theta^T x = 0$인 직선(또는 초평면)이 결정 경계가 됩니다.

## 다중 분류 (Multiclass Classification)

### OvR (One-vs-Rest) 전략

각 클래스에 대해 이진 분류기를 훈련시킵니다. K개 클래스 → K개의 이진 분류기

### 소프트맥스 회귀 (Softmax Regression)

K개 클래스에 대한 확률을 동시에 계산합니다.

$$\hat{p}_k = \text{softmax}(\mathbf{s})_k = \frac{e^{s_k}}{\sum_{j=1}^{K} e^{s_j}}$$

여기서 $s_k = \theta_k^T x$는 클래스 k에 대한 점수입니다.

**특성:**
- 출력은 K개 클래스에 대한 확률 (합이 1)
- 비용 함수: 다중 클래스 교차 엔트로피

## 핵심 정리

- 로지스틱 회귀: 분류 문제에 사용, 선형 결합 + 시그모이드
- 시그모이드: 0~1 범위의 확률값 출력
- 비용 함수: 교차 엔트로피 (MSE 아님)
- 다중 분류: OvR 전략 또는 소프트맥스 회귀
