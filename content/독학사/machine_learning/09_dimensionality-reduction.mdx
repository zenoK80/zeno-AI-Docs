## 왜 차원 축소가 필요한가?

100가지 특성을 가진 데이터가 있다고 합시다. 이 중 많은 특성이 서로 비슷하거나 중요하지 않을 수 있습니다. 또한 100차원 데이터는 시각화가 불가능합니다.

**비유:** 사람을 설명할 때 이름, 나이, 키, 몸무게, 성별, 혈액형... 수백 가지 특성이 있지만, 대부분의 경우 몇 가지 핵심 특성만으로도 충분히 구별할 수 있습니다.

**차원 축소의 필요성:**
- 시각화 (2D, 3D로 표현하여 패턴 이해)
- 계산 비용 감소 (특성이 적을수록 학습이 빠름)
- 과적합 방지 (불필요한 특성 제거)
- 노이즈 제거 (중요하지 않은 변동 제거)

**종류:**

| 방법 | 설명 |
|------|------|
| 특성 선택(feature selection) | 원래 특성 중 중요한 것만 골라냄 |
| 특성 추출(feature extraction) | 원래 특성을 조합하여 새로운 특성 생성 |

## 차원의 저주 (curse of dimensionality, 차원의 저주)

차원이 증가할수록 발생하는 문제입니다.

> 쉽게 말하면: 특성(차원)이 늘어날수록 같은 양의 데이터로는 공간을 채울 수 없어 데이터가 점점 희소해집니다.

**핵심 현상:**
- 데이터 포인트 간 거리가 모두 비슷해져 유사도 측정이 어려워짐
- 같은 밀도(density)를 유지하려면 지수적으로 더 많은 데이터 필요
- 모델 학습에 필요한 데이터 수가 차원에 따라 기하급수적으로 증가

**예시:**
- 1차원(선) 위의 1000개 점: 충분히 조밀
- 10차원: 같은 밀도를 유지하려면 $1000^{10}$개 필요
- 100차원: 현실적으로 불가능한 양의 데이터 필요

## PCA — Principal Component Analysis (주성분 분석)

데이터의 **분산(variance, 퍼짐 정도)이 최대화**되는 방향의 축(주성분)을 찾아 차원을 축소합니다.

**왜 분산 최대화인가?** 분산이 크다는 것은 그 방향으로 데이터가 많이 퍼져 있다는 의미, 즉 정보가 많다는 뜻입니다. 분산이 작은 방향은 정보가 거의 없습니다.

**비유:** 공을 던지는 야구 선수를 촬영할 때, 옆에서 찍으면 투구 모션(분산 큼)이 잘 보이지만, 정면에서 찍으면 앞뒤 움직임만 보여 정보가 적습니다. PCA는 정보가 가장 많이 보이는 방향을 선택합니다.

### 핵심 원리

- **제1 주성분(PC1, first principal component):** 데이터의 분산이 가장 큰 방향
- **제2 주성분(PC2):** 제1 주성분과 직교(수직)하면서 다음으로 분산이 큰 방향
- 각 주성분은 서로 직교(orthogonal, 독립)

### PCA 절차

1. 데이터 표준화 (평균 0, 분산 1로 스케일링)
2. 공분산 행렬(covariance matrix, $\Sigma$) 계산
3. 공분산 행렬의 **고유값(eigenvalue, 고유값)과 고유벡터**(eigenvector, 고유벡터) 계산
4. 고유값 크기 순으로 정렬
5. 상위 k개의 고유벡터를 선택하여 데이터를 투영(projection)

### 고유값과 고유벡터

공분산 행렬 $\Sigma$에 대해 다음을 만족하는 벡터 $\mathbf{v}$와 스칼라 $\lambda$:

$$\Sigma \mathbf{v} = \lambda \mathbf{v}$$

각 변수의 의미:

- **고유벡터 $\mathbf{v}$:** 주성분의 방향 (분산이 최대가 되는 축의 방향)
- **고유값 $\lambda$:** 해당 방향의 분산 크기 (고유값이 클수록 해당 주성분이 정보를 많이 담음)

### 설명 분산 비율 (explained variance ratio)

$$\text{설명 분산 비율} = \frac{\lambda_i}{\sum_j \lambda_j}$$

**일반적 기준:** 누적 설명 분산 비율(cumulative explained variance ratio)이 95% 이상이 되는 최소 주성분 수를 선택합니다.

**예시:** 고유값이 큰 순서로 [50%, 30%, 15%, 5%]라면, 상위 3개 주성분이 95%의 분산을 설명합니다.

## SVD — Singular Value Decomposition (특이값 분해)

임의의 행렬 $A$를 세 행렬의 곱으로 분해합니다:

$$A = U \Sigma V^T$$

각 변수의 의미:

- $U$: 좌 특이벡터 행렬 (입력 공간의 직교 기저)
- $\Sigma$: 특이값 대각 행렬 (0 이상의 값, 클수록 중요)
- $V^T$: 우 특이벡터 행렬의 전치 (출력 공간의 직교 기저)

**PCA와의 관계:** 데이터 행렬에 SVD를 적용하면 PCA 결과와 동일합니다. 공분산 행렬을 계산하지 않아 수치적으로 더 안정적입니다.

**활용:**
- 이미지 압축 (상위 특이값만 유지)
- 추천 시스템 (사용자-아이템 행렬 분해)
- 자연어 처리 — LSA(Latent Semantic Analysis, 잠재 의미 분석)

## t-SNE (t-distributed Stochastic Neighbor Embedding, t-분포 확률적 이웃 임베딩)

고차원 데이터를 **2D 또는 3D로 시각화**하기 위한 비선형 차원 축소 기법입니다.

**왜 PCA로 안 되는가?** PCA는 선형 변환만 가능합니다. 복잡한 비선형 구조(예: 달팽이 형태, 원형 고리)는 t-SNE가 더 잘 표현합니다.

> 쉽게 말하면: 고차원에서 가까운 점은 저차원에서도 가깝게, 먼 점은 멀게 배치합니다.

### 핵심 개념

1. 고차원에서 점들 사이의 유사도를 가우시안(Gaussian) 확률로 표현
2. 저차원에서 점들 사이의 유사도를 t-분포로 표현
3. 두 분포의 차이(KL Divergence)를 최소화

$$\text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

각 변수의 의미:

- $p_{ij}$: 고차원에서 점 i와 j가 이웃일 확률
- $q_{ij}$: 저차원에서 점 i와 j가 이웃일 확률

### t-SNE 특징

| 장점 | 단점 |
|------|------|
| 클러스터 구조를 잘 시각화 | 계산 비용이 높음 |
| 비선형 구조 표현 가능 | 실행마다 결과가 다를 수 있음 (랜덤 요소) |
| 이상치에 강건 | 축 간 거리에 절대적 의미 없음 |
| 클러스터 사이를 명확히 분리 | 전처리/특성 추출 용도로는 부적합 |

**perplexity(퍼플렉시티) 하이퍼파라미터:** 각 점의 효과적인 이웃 수를 제어합니다 (보통 5~50).

## PCA vs t-SNE 비교

| 항목 | PCA | t-SNE |
|------|-----|-------|
| 변환 방식 | 선형 | 비선형 |
| 목적 | 분산 최대화 | 이웃 관계 보존 |
| 계산 속도 | 빠름 | 느림 |
| 재현성 | 항상 동일 | 랜덤 요소 있음 |
| 주 용도 | 전처리, 노이즈 제거 | 시각화 |
| 새 데이터 투영 | 가능 | 어려움 |

---

## 핵심 정리

- **차원의 저주:** 차원 증가 시 데이터 희소성, 거리 구별 어려움
- **PCA:** 분산 최대화 방향(고유벡터)으로 투영, 고유값 = 설명 분산량
- **SVD:** 행렬을 $U \Sigma V^T$로 분해, PCA의 수치 안정적 구현
- **t-SNE:** 비선형, 고차원 데이터 시각화에 특화, 재현성 없음
- **주성분 수 결정:** 누적 설명 분산 비율 95% 이상 기준
