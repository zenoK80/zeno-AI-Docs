## 차원 축소란?

고차원 데이터를 정보 손실을 최소화하면서 저차원으로 변환하는 기법입니다.

**필요성:**
- 시각화 (2D, 3D로 표현)
- 계산 비용 감소
- 과적합 방지
- 노이즈 제거

**종류:**
| 방법 | 설명 |
|------|------|
| **특징 선택 (Feature Selection)** | 원래 특징 중 중요한 것만 선택 |
| **특징 추출 (Feature Extraction)** | 원래 특징을 조합해 새로운 특징 생성 |

## 차원의 저주 (Curse of Dimensionality)

차원이 증가할수록 발생하는 문제입니다.

- 데이터 포인트 간 거리가 모두 비슷해져 유사도 측정이 어려워짐
- 동일한 밀도를 유지하려면 지수적으로 더 많은 데이터 필요
- 모델 학습에 필요한 데이터 수가 차원에 따라 기하급수적으로 증가

**예시:** 10개 특징에서 100개 특징으로 늘어나면, 같은 밀도를 유지하기 위해 $10^{90}$배 더 많은 데이터가 필요합니다.

## PCA (Principal Component Analysis, 주성분 분석)

데이터의 **분산이 최대화**되는 방향의 축(주성분)을 찾아 차원을 축소합니다.

### 핵심 원리

- **제1 주성분:** 데이터의 분산이 가장 큰 방향
- **제2 주성분:** 제1 주성분과 직교하면서 다음으로 분산이 큰 방향
- 각 주성분은 서로 직교(독립)

### PCA 절차

1. 데이터 표준화 (평균 0, 분산 1)
2. 공분산 행렬 $\Sigma$ 계산
3. 공분산 행렬의 **고유값(Eigenvalue)과 고유벡터(Eigenvector)** 계산
4. 고유값 크기 순으로 정렬
5. 상위 k개의 고유벡터를 선택하여 투영

### 고유값과 고유벡터

공분산 행렬 $\Sigma$에 대해 다음을 만족하는 벡터 $\mathbf{v}$와 스칼라 $\lambda$:

$$\Sigma \mathbf{v} = \lambda \mathbf{v}$$

- **고유벡터(Eigenvector) $\mathbf{v}$:** 주성분 방향 (분산이 최대인 축)
- **고유값(Eigenvalue) $\lambda$:** 해당 방향의 분산 크기

고유값이 클수록 해당 주성분이 설명하는 분산이 많습니다.

### 설명 분산 비율

$$\text{설명 분산 비율} = \frac{\lambda_i}{\sum_j \lambda_j}$$

보통 누적 설명 분산 비율 95% 이상을 목표로 주성분 수를 선택합니다.

## SVD (Singular Value Decomposition, 특이값 분해)

행렬 $A$를 세 행렬의 곱으로 분해합니다:

$$A = U \Sigma V^T$$

- $U$: 좌 특이벡터 (입력 공간의 직교 기저)
- $\Sigma$: 특이값 행렬 (대각 행렬, 0 이상의 값)
- $V^T$: 우 특이벡터 (출력 공간의 직교 기저)

**PCA와의 관계:** 데이터 행렬에 SVD를 적용하면 PCA 결과와 동일합니다. 공분산 행렬을 계산하지 않아 수치적으로 더 안정적입니다.

**활용:** 이미지 압축, 추천 시스템, 자연어 처리(LSA)

## t-SNE (t-distributed Stochastic Neighbor Embedding)

고차원 데이터를 **2D 또는 3D로 시각화**하기 위한 비선형 차원 축소 기법입니다.

### 핵심 개념

- 고차원에서 가까운 점은 저차원에서도 가까이 배치
- 고차원에서 멀리 떨어진 점은 저차원에서도 멀리 배치
- t-분포를 사용하여 클러스터 간 거리를 넓게 분리

### 알고리즘

1. 고차원에서 점들 사이의 유사도를 가우시안 확률로 표현
2. 저차원에서 점들 사이의 유사도를 t-분포로 표현
3. 두 분포의 KL Divergence를 최소화

$$\text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

### t-SNE 특징

| 장점 | 단점 |
|------|------|
| 클러스터 구조를 잘 시각화 | 계산 비용이 높음 ($O(n^2)$) |
| 비선형 구조 표현 가능 | 매번 실행마다 결과가 다를 수 있음 |
| 이상치에 강건 | 축 간 거리에 절대적 의미 없음 |

**perplexity 하이퍼파라미터:** 각 점의 이웃 수를 결정 (보통 5~50)

## PCA vs t-SNE 비교

| 항목 | PCA | t-SNE |
|------|-----|-------|
| 방법 | 선형 | 비선형 |
| 목적 | 분산 최대화 | 이웃 관계 보존 |
| 계산 속도 | 빠름 | 느림 |
| 재현성 | 항상 동일 | 랜덤 요소 있음 |
| 주 용도 | 전처리, 노이즈 제거 | 시각화 |

## 핵심 정리

- 차원의 저주: 차원 증가 시 데이터 희소성 문제
- PCA: 분산 최대화 방향(고유벡터)으로 투영, 고유값 = 설명 분산량
- SVD: 행렬을 $U \Sigma V^T$로 분해, PCA의 수치 안정적 구현
- t-SNE: 비선형, 고차원 데이터 시각화에 특화
- 누적 설명 분산 비율 95% 이상 기준으로 주성분 수 결정
