## 왜 군집화가 필요한가?

마트에서 구매 기록을 분석해 "비슷한 쇼핑 패턴을 가진 고객 그룹"을 찾고 싶다면? 정답(레이블)이 없는데도 비슷한 것끼리 묶어야 합니다. 이것이 **군집화**(clustering, 군집화) 입니다.

**비유:** 초등학교 운동회에서 줄 서기 없이 자유롭게 모이면, 친한 친구들끼리 자연스럽게 모이는 것처럼 데이터가 스스로 비슷한 그룹으로 모입니다.

군집화는 **비지도 학습**(unsupervised learning) 의 대표적인 방법입니다.

**활용 사례:**
- 고객 세분화(비슷한 구매 패턴으로 마케팅 대상 분류)
- 이상치 탐지(정상 데이터 군집에 속하지 않는 점 발견)
- 문서 분류(비슷한 주제의 문서끼리 묶기)
- 이미지 압축(비슷한 색깔을 대표 색깔로 묶기)

## K-means 알고리즘

K개의 군집으로 데이터를 나누는 가장 기본적인 군집화 알고리즘입니다.

**알고리즘 작동 단계:**

1. K개의 센트로이드(centroid, 군집 중심점)를 무작위로 초기화
2. 각 샘플을 가장 가까운 센트로이드에 할당 (군집 형성)
3. 각 군집의 새로운 센트로이드를 해당 군집 샘플의 평균으로 업데이트
4. 센트로이드 변화가 없을 때까지 2~3 반복

**비유:** 학급을 3모둠으로 나눌 때, 처음에 임의로 3명을 모둠장으로 정하고, 모두 가장 가까운 모둠장 쪽으로 이동. 그다음 각 모둠의 중심을 새 모둠장으로 설정. 이를 반복합니다.

**목적 함수 — 관성(inertia, 관성):**

$$J = \sum_{k=1}^{K} \sum_{x \in C_k} \|x - \mu_k\|^2$$

각 변수의 의미:

- $K$: 군집 수
- $C_k$: k번째 군집에 속한 데이터 집합
- $\mu_k$: k번째 군집의 센트로이드(중심)
- $\|x - \mu_k\|^2$: 데이터 포인트와 센트로이드 사이의 거리 제곱

관성이 작을수록 데이터가 군집 중심에 가깝게 모여 있습니다.

### K-means의 한계

- K를 사전에 지정해야 함 (최적 K를 모르는 경우 어려움)
- 구형(spherical, 원형) 군집에 최적화 → 비구형 군집 탐지 어려움
- 이상치(outlier)에 민감 → 이상치가 센트로이드를 왜곡
- 초기 센트로이드에 따라 결과가 달라질 수 있음

### 최적 K 선택 — 엘보우 방법 (Elbow Method)

K를 1부터 늘려가며 관성을 측정하고 그래프로 그립니다. 관성이 급격히 감소하다가 완만해지는 지점(팔꿈치 모양, 엘보우)의 K를 선택합니다.

### K-means++ (K-means 플러스 플러스)

기존 K-means의 무작위 초기화를 개선합니다:
- 첫 센트로이드는 무작위 선택
- 이후 센트로이드는 기존 센트로이드와 멀리 있는 점이 선택될 확률이 높음 → 더 안정적인 결과

## DBSCAN (Density-Based Spatial Clustering of Applications with Noise, 밀도 기반 군집화)

밀도가 높은 영역을 군집으로 인식하는 알고리즘입니다. K-means와 달리 K를 미리 지정할 필요가 없습니다.

**핵심 개념:**

- **핵심 포인트(core point, 핵심 점):** $\epsilon$(엡실론) 반경 안에 `min_samples` 이상의 이웃이 있는 점
- **경계 포인트(border point, 경계 점):** 핵심 포인트의 $\epsilon$ 반경 안에 있지만 스스로는 핵심 포인트가 아닌 점
- **잡음 포인트(noise point, 잡음 점):** 핵심 포인트도 경계 포인트도 아닌 점 → 이상치로 처리

**비유:** 사람이 많이 모인 곳(밀도 높음)이 군집이고, 사람이 없는 빈 공간(밀도 낮음)이 군집 경계입니다. 혼자 떨어진 사람은 이상치입니다.

**장점:**
- K를 미리 지정하지 않아도 됨
- 비구형 군집(달팽이 모양, 원형 고리 등) 탐지 가능
- 이상치를 자동으로 탐지 및 분류

**한계:**
- $\epsilon$과 `min_samples` 매개변수에 민감 (잘못 설정하면 결과가 크게 달라짐)
- 밀도가 다른 군집에서 성능 저하

## 계층적 군집화 (hierarchical clustering, 계층적 군집화)

데이터를 **계층적 트리**(덴드로그램, dendrogram) 구조로 군집화합니다. 군집 수를 미리 정하지 않아도 되며, 덴드로그램을 잘라서 원하는 수의 군집을 얻을 수 있습니다.

| 종류 | 설명 |
| --- | --- |
| 병합적(agglomerative, 상향식) | 각 샘플을 개별 군집으로 시작 → 유사한 것끼리 합침 (Bottom-up) |
| 분할적(divisive, 하향식) | 전체를 하나의 군집으로 시작 → 반복해서 나눔 (Top-down) |

**연결 방법(linkage, 연결 기준):**

| 방법 | 설명 |
| --- | --- |
| 단일 연결(single linkage) | 두 군집의 가장 가까운 쌍의 거리 |
| 완전 연결(complete linkage) | 두 군집의 가장 먼 쌍의 거리 |
| 평균 연결(average linkage) | 두 군집 쌍들의 평균 거리 |
| 워드 연결(Ward linkage) | 군집 내 분산을 최소화하는 방향으로 합병 |

**비유:** 학교 가계도처럼, 개개인(샘플)에서 시작해 가족(군집) → 씨족 → 민족 순으로 점점 더 크게 묶어가는 구조입니다.

---

## 알고리즘 비교

| 항목 | K-means | DBSCAN | 계층적 군집화 |
| --- | --- | --- | --- |
| K 지정 | 필요 | 불필요 | 불필요 (나중에 선택) |
| 군집 모양 | 구형에 최적 | 임의 형태 가능 | 임의 형태 가능 |
| 이상치 처리 | 민감 | 자동 탐지 | 보통 |
| 시각적 결과 | 센트로이드 | 군집 + 이상치 | 덴드로그램 |
| 대규모 데이터 | 빠름 | 보통 | 느림 |

---

## 핵심 정리

- **군집화:** 레이블 없이 비슷한 데이터를 그룹으로 묶는 비지도 학습
- **K-means:** 센트로이드 기반, K 미리 지정 필요, 구형 군집에 최적
- **엘보우 방법:** 관성 변화로 최적 K 선택
- **DBSCAN:** 밀도 기반, K 불필요, 이상치 자동 탐지, 비구형 군집 가능
- **계층적 군집화:** 덴드로그램, Bottom-up(병합) 또는 Top-down(분할)
