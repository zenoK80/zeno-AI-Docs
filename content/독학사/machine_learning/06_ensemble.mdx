## 앙상블 학습 (Ensemble Learning)

여러 개의 기본 모델(Base Learner)을 결합하여 단일 모델보다 좋은 성능을 내는 방법입니다.

**앙상블의 핵심 가정:** 개별 모델들이 서로 다른 오류를 만들면, 조합했을 때 오류가 상쇄됩니다.

## 배깅 (Bagging)

**Bootstrap Aggregating:** 훈련 데이터에서 중복을 허용한 부트스트랩 샘플링으로 여러 모델을 병렬 훈련합니다.

- **분류:** 다수결 투표 (Voting)
- **회귀:** 평균 계산 (Averaging)
- **효과:** 분산(Variance) 감소

### 랜덤 포레스트 (Random Forest)

배깅 + 특성 무작위 선택

1. 각 트리 훈련 시 부트스트랩 샘플링
2. 각 분기마다 전체 특성 중 일부만 무작위 선택
3. 여러 트리의 예측을 다수결 또는 평균으로 결합

**장점:**
- 의사결정 트리보다 과적합이 적음
- 특성 중요도 제공
- 병렬 처리 가능

## 부스팅 (Boosting)

약한 학습기들을 순차적으로 훈련하여 이전 모델의 오류를 보완합니다.

- **효과:** 편향(Bias) 감소
- **순차적:** 이전 모델의 잔차/가중치를 다음 모델에 반영

### AdaBoost

잘못 분류된 샘플에 더 높은 가중치를 부여하여 다음 모델이 집중하도록 합니다.

### 그래디언트 부스팅 (Gradient Boosting)

이전 모델의 잔차(Residual)를 예측하는 새 모델을 순차적으로 추가합니다.

### XGBoost (eXtreme Gradient Boosting)

그래디언트 부스팅의 최적화 구현:
- 병렬 처리 지원
- L1/L2 정규화 내장
- 결측값 처리 자동화
- 빠른 속도와 높은 성능

## 배깅 vs 부스팅 비교

| 항목 | 배깅 | 부스팅 |
| --- | --- | --- |
| 훈련 방식 | 병렬 | 순차적 |
| 집중 대상 | 분산 감소 | 편향 감소 |
| 과적합 위험 | 낮음 | 높음 (일부) |
| 대표 방법 | 랜덤 포레스트 | AdaBoost, XGBoost |

<Callout type="warning">
  부스팅은 배깅보다 과적합 위험이 있지만, 적절한 정규화와 반복 횟수 조절로 매우 높은 성능을 달성할 수 있습니다.
</Callout>

## 스태킹 (Stacking)

여러 기본 모델의 예측을 메타 모델(Meta-learner)의 입력으로 사용합니다.

## 핵심 정리

- 배깅: 병렬 훈련, 분산 감소, 랜덤 포레스트
- 부스팅: 순차 훈련, 편향 감소, AdaBoost/XGBoost
- 랜덤 포레스트: 배깅 + 무작위 특성 선택
- XGBoost: 그래디언트 부스팅 최적화 구현
