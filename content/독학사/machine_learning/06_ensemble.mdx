## 왜 앙상블이 필요한가?

한 명의 전문가보다 여러 명의 평범한 전문가가 함께 결정하는 것이 더 정확할 수 있습니다. 각자가 다른 실수를 하면, 다수결로 결정할 때 실수가 상쇄됩니다.

**비유:** 의사 한 명의 진단보다, 여러 의사가 독립적으로 진단하고 다수결로 결정하는 것이 더 신뢰할 수 있습니다.

---

## 앙상블 학습 (ensemble learning, 앙상블 학습)

여러 개의 기본 모델(base learner, 기본 학습기)을 결합하여 단일 모델보다 좋은 성능을 내는 방법입니다.

**앙상블의 핵심 가정:** 개별 모델들이 서로 다른 오류를 만들면, 조합했을 때 오류가 상쇄됩니다. 모델들이 서로 달라야(다양성이 있어야) 효과가 있습니다.

---

## 배깅 (bagging, Bootstrap Aggregating)

**왜 필요한가?** 단일 모델의 **분산(variance, 출력이 불안정하게 변하는 정도)** 을 줄이기 위해 사용합니다.

**원리:** 훈련 데이터에서 **중복을 허용한 무작위 샘플링(부트스트랩 샘플링, bootstrap sampling)** 으로 여러 개의 훈련 세트를 만들고, 각각 독립적으로 모델을 학습합니다.

**예측 결합:**
- **분류:** 다수결 투표(voting)
- **회귀:** 평균 계산(averaging)

**효과:** 분산(variance) 감소 → 과적합 방지

**비유:** 같은 교과서(훈련 데이터)로 공부하되, 각자 다른 페이지를 강조해서 공부한 10명의 학생이 다수결로 답을 결정합니다.

### 랜덤 포레스트 (random forest, 랜덤 포레스트)

**배깅 + 특성 무작위 선택**을 결합한 강력한 앙상블입니다.

**작동 방식:**
1. 각 트리 훈련 시 부트스트랩 샘플링으로 훈련 데이터 구성
2. **각 분기(split)마다** 전체 특성 중 일부만 무작위로 선택하여 최적 분기 탐색
3. 여러 트리의 예측을 다수결 또는 평균으로 결합

**단계 2가 핵심:** 특성을 무작위로 선택하면 트리들이 서로 다른 특성을 주로 사용하게 되어 **트리 간 상관관계가 줄어들고 다양성이 높아집니다.**

**장점:**
- 단일 의사결정 트리보다 과적합이 적음
- 특성 중요도(feature importance) 제공
- 병렬 처리 가능 (각 트리가 독립적)

---

## 부스팅 (boosting, 부스팅)

**왜 필요한가?** 약한 모델(weak learner)들을 순차적으로 연결하여 강한 모델을 만들기 위해 사용합니다. 주로 **편향(bias, 예측이 체계적으로 틀리는 정도)** 을 줄입니다.

**비유:** 처음에 잘 못 푼 문제들을 모아 다시 집중 연습하고, 또 못 푼 문제를 모아 집중 연습하는 방식으로 점차 실력을 높입니다.

### AdaBoost (Adaptive Boosting, 적응형 부스팅)

잘못 분류된 샘플에 **더 높은 가중치**를 부여하여 다음 모델이 그 샘플에 집중하도록 합니다.

**작동 흐름:**
1. 첫 번째 모델 학습 (모든 샘플 동일 가중치)
2. 잘못 분류된 샘플의 가중치 증가
3. 두 번째 모델은 가중치가 높은 샘플에 집중
4. 위 과정 반복
5. 최종 예측: 모든 모델의 가중 투표

### 그래디언트 부스팅 (gradient boosting, 그래디언트 부스팅)

이전 모델의 **잔차(residual, 오차)** 를 예측하는 새 모델을 순차적으로 추가합니다.

**직관:** 처음 모델이 집값을 2억으로 예측했는데 실제가 2.5억이면, 다음 모델은 잔차 0.5억을 예측하도록 학습합니다. 이를 반복하면 점점 정확해집니다.

### XGBoost (eXtreme Gradient Boosting, 익스트림 그래디언트 부스팅)

그래디언트 부스팅의 최적화 구현으로, Kaggle 등 머신러닝 대회에서 가장 많이 사용됩니다:

- **병렬 처리 지원:** 트리 성장을 병렬로 수행 → 빠른 학습
- **L1/L2 정규화 내장:** 과적합 방지 기능 포함
- **결측값(missing value) 처리 자동화**
- **트리 가지치기:** 손실이 없는 분기 자동 제거

---

## 배깅 vs 부스팅 비교

| 항목 | 배깅(Bagging) | 부스팅(Boosting) |
| --- | --- | --- |
| 훈련 방식 | 병렬(독립적) | 순차적(이전 결과 의존) |
| 집중 대상 | 분산(variance) 감소 | 편향(bias) 감소 |
| 과적합 위험 | 낮음 | 있음 (과도한 반복 시) |
| 대표 방법 | 랜덤 포레스트 | AdaBoost, XGBoost, LightGBM |
| 속도 | 빠름 (병렬) | 느림 (순차) |

<Callout type="warning">
  부스팅은 배깅보다 과적합 위험이 있지만, 적절한 정규화와 반복 횟수 조절로 매우 높은 성능을 달성할 수 있습니다. XGBoost는 현실적인 문제에서 매우 강력한 성능을 보입니다.
</Callout>

---

## 스태킹 (stacking, 스태킹)

여러 기본 모델의 예측값을 새로운 특성으로 사용하여 **메타 모델(meta-learner, 메타 학습기)** 을 학습하는 방법입니다.

**작동 흐름:**
1. 여러 기본 모델(예: SVM, 랜덤 포레스트, XGBoost) 학습
2. 기본 모델의 예측값을 모아 새로운 데이터셋 구성
3. 이 예측값들을 입력으로 사용하는 메타 모델 학습
4. 최종 예측: 메타 모델이 결정

---

## 핵심 정리

- **배깅:** 병렬 훈련, 분산 감소, 부트스트랩 샘플링, 대표: 랜덤 포레스트
- **랜덤 포레스트:** 배깅 + 무작위 특성 선택 → 트리 다양성 증가
- **부스팅:** 순차 훈련, 편향 감소, 이전 오류에 집중
- **AdaBoost:** 오분류 샘플 가중치 증가
- **그래디언트 부스팅:** 잔차를 예측하는 모델을 순차 추가
- **XGBoost:** 그래디언트 부스팅의 최적화 구현, 정규화 내장
- **스태킹:** 기본 모델 예측값을 메타 모델의 입력으로 사용
