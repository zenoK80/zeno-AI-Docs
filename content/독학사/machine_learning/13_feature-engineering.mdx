## 특징 공학이란?

도메인 지식을 활용하여 원시 데이터로부터 머신러닝 모델의 성능을 향상시키는 특징을 만들어내는 과정입니다.

**"Garbage In, Garbage Out"** — 모델의 성능은 데이터 품질에 직결됩니다.

**주요 단계:**
1. 결측치 처리
2. 이상치 처리
3. 특징 스케일링
4. 범주형 인코딩
5. 특성 선택/생성

## 결측치 처리 (Missing Value Handling)

### 결측치 확인

데이터에서 NULL, NaN, 빈 값 등을 확인합니다.

### 결측치 처리 방법

| 방법 | 설명 | 사용 시기 |
|------|------|-----------|
| **삭제** | 결측치가 있는 행/열 제거 | 결측 비율이 매우 낮을 때 |
| **평균/중앙값 대체** | 수치형 변수에 대체 | 결측이 무작위인 경우 |
| **최빈값 대체** | 범주형 변수에 대체 | 범주형 결측치 |
| **예측 모델 대체** | 다른 특징으로 결측치 예측 | 결측 비율이 높고 중요한 특징 |
| **결측 지시자 추가** | 결측 여부 자체를 특징으로 추가 | 결측이 정보를 담을 때 |

### 결측치 유형

- **MCAR (Missing Completely at Random):** 완전 무작위 결측
- **MAR (Missing at Random):** 다른 변수에 의존하는 결측
- **MNAR (Missing Not at Random):** 결측값 자체에 의존 (처리가 가장 어려움)

## 이상치 처리 (Outlier Handling)

**이상치 탐지 방법:**
- IQR 방법: Q1 - 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과
- Z-score: |z| > 3인 값
- 시각화: 박스플롯, 산점도

**처리 방법:** 제거, Winsorizing(경계값으로 대체), 로그 변환

## 특징 스케일링 (Feature Scaling)

수치 범위가 다른 특징들을 동일한 스케일로 변환합니다. 거리 기반 알고리즘(KNN, SVM, 신경망)에서 필수적입니다.

### Min-Max 정규화 (MinMaxScaler)

$$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

- 출력 범위: [0, 1]
- 이상치에 민감
- 분포를 보존하며 범위만 조정

### 표준화 (StandardScaler)

$$x' = \frac{x - \mu}{\sigma}$$

- 평균 0, 표준편차 1로 변환
- 이상치에 상대적으로 강건
- 정규 분포를 가정하지 않음 (단, 정규 분포 데이터에서 더 효과적)

### 스케일링 비교

| 항목 | MinMax | Standard |
|------|--------|----------|
| 출력 범위 | [0, 1] | 평균=0, 표준편차=1 |
| 이상치 영향 | 민감 | 덜 민감 |
| 분포 변형 | 선형 변환만 | 선형 변환만 |
| 적합한 경우 | 신경망 입력층 | 대부분의 알고리즘 |

**중요:** 훈련 세트로 fitting 후, 검증/테스트 세트는 transform만 (데이터 누수 방지)

## 범주형 변수 인코딩

머신러닝 모델은 수치 입력만 처리하므로 범주형 변수를 수치로 변환해야 합니다.

### 레이블 인코딩 (Label Encoding)

범주를 정수로 매핑합니다:

```
색상: ['빨강', '파랑', '초록']
→    [  0,     1,     2  ]
```

- 장점: 단순, 메모리 효율적
- 단점: 순서 관계가 없는 변수에 적용 시 모델이 순서를 학습할 수 있음
- 적합: 순서형 범주(예: 등급 낮음/보통/높음), 트리 기반 모델

### 원-핫 인코딩 (One-Hot Encoding)

각 범주를 이진 열로 확장합니다:

```
색상:  빨강  파랑  초록
빨강: [  1,    0,    0 ]
파랑: [  0,    1,    0 ]
초록: [  0,    0,    1 ]
```

- 장점: 순서 관계 없음, 선형 모델에 적합
- 단점: 범주 수가 많으면 차원이 폭발적으로 증가 (희소 행렬)
- 적합: 명목형 범주, 선형 모델, 신경망

**더미 변수 함정:** n개 범주에서 n-1개 열만 사용 (다중 공선성 방지)

### 타겟 인코딩 (Target Encoding)

범주를 해당 범주의 타겟 평균값으로 대체 (데이터 누수 주의)

## 특성 선택 (Feature Selection)

불필요한 특징을 제거하여 모델 성능을 높이고 과적합을 방지합니다.

### 필터 방법 (Filter Methods)

통계적 기준으로 특징을 선택 (모델 독립적):
- 분산 임계값: 분산이 낮은 특징 제거
- 상관관계: 타겟과 상관관계 높은 특징 선택
- 카이제곱 검정, ANOVA

### 래퍼 방법 (Wrapper Methods)

특징 부분 집합으로 모델을 학습하여 성능 비교:
- 전진 선택법(Forward Selection): 특징을 하나씩 추가
- 후진 제거법(Backward Elimination): 특징을 하나씩 제거
- 재귀적 특징 제거(RFE): 중요도 낮은 특징 반복 제거

### 임베디드 방법 (Embedded Methods)

모델 학습 과정에서 특징 중요도를 결정:
- Lasso(L1) 정규화
- 트리 기반 모델의 특징 중요도(Feature Importance)

## 특성 생성 (Feature Creation)

기존 특징을 조합하여 새로운 특징을 만듭니다:
- 다항 특징: $x_1^2$, $x_1 \times x_2$
- 로그 변환: 비대칭 분포 정규화
- 날짜에서 파생: 연, 월, 요일, 계절

## 핵심 정리

- 결측치: 삭제/대체/예측 중 데이터 특성에 맞게 선택
- MinMax: [0,1] 범위로 정규화, 이상치에 민감
- Standard: 평균 0, 표준편차 1, 대부분 상황에 적합
- Label Encoding: 순서형 또는 트리 모델에 적합
- One-Hot Encoding: 명목형, 순서 없음, 차원 증가 단점
- 스케일러는 훈련 세트로 fit 후 검증/테스트 세트에는 transform만
