## 왜 SVM이 필요한가?

두 클래스를 분리하는 직선은 여러 개 그릴 수 있습니다. 어떤 직선이 가장 좋은 결정 경계일까요? SVM은 "두 클래스 사이의 간격(마진)을 최대화하는 직선이 가장 좋다"는 아이디어에서 출발합니다.

**비유:** 고속도로의 중앙선처럼, 양쪽 방향의 자동차(클래스)와 가장 거리가 먼 위치에 경계선을 긋는 것이 SVM입니다. 마진이 넓을수록 새로운 데이터가 와도 안전하게 분류됩니다.

---

## SVM — Support Vector Machine (서포트 벡터 머신)

클래스 간 **마진(margin, 여유 공간)을 최대화**하는 결정 경계(초평면)를 찾는 분류 알고리즘입니다.

> 쉽게 말하면: 두 그룹 사이의 "도로 폭"을 최대로 넓히는 경계선을 찾습니다.

---

## 핵심 개념

### 초평면 (hyperplane, 초평면)

n차원 공간에서 데이터를 분리하는 (n-1)차원 경계입니다:

$$w^T x + b = 0$$

각 변수의 의미:

- $w$: 법선 벡터(초평면의 방향을 결정하는 가중치)
- $x$: 입력 데이터 벡터
- $b$: 편향(초평면의 위치)

- 2차원 데이터 → 초평면 = 직선
- 3차원 데이터 → 초평면 = 평면
- n차원 데이터 → 초평면 = (n-1)차원 경계

### 서포트 벡터 (support vector, 서포트 벡터)

결정 경계에 가장 가까이 있는 데이터 포인트들입니다.

**핵심:** SVM의 결정 경계는 오직 이 서포트 벡터들에 의해서만 결정됩니다. 다른 데이터를 제거해도 결과가 바뀌지 않습니다.

### 마진 (margin, 마진)

두 클래스의 서포트 벡터 사이의 거리:

$$\text{마진} = \frac{2}{\|w\|}$$

마진을 최대화하려면 $\|w\|$를 최소화해야 합니다.

---

## 하드 마진 vs 소프트 마진

| 종류 | 설명 | 특징 |
| --- | --- | --- |
| 하드 마진(hard margin) | 모든 샘플이 마진 밖에 위치 | 선형 분리 가능할 때만 적용 가능, 이상치에 매우 민감 |
| 소프트 마진(soft margin) | 일부 오분류 허용 | 실제 데이터에 더 유연, C 매개변수로 조절 |

**소프트 마진의 C 매개변수:**

- **C가 크면:** 오류를 거의 허용하지 않음 → 마진이 좁아짐 → 과적합 위험
- **C가 작으면:** 오류를 더 많이 허용 → 마진이 넓어짐 → 과소적합 위험

**비유:** C가 큰 경우는 엄격한 선생님(하나도 틀리면 안 됨), C가 작은 경우는 너그러운 선생님(다소 틀려도 괜찮음)과 같습니다.

---

## 커널 트릭 (kernel trick, 커널 트릭)

**왜 필요한가?** 선형으로 분리되지 않는 데이터는 직선으로 경계를 그을 수 없습니다. 예를 들어 원 모양으로 두 클래스가 섞여 있는 경우입니다. 이때 데이터를 더 높은 차원으로 변환하면 선형 분리가 가능해질 수 있습니다.

**핵심 아이디어:** 실제로 데이터를 고차원으로 변환하지 않고도, 커널 함수 $K(x_i, x_j)$를 통해 변환 후 내적(dot product)을 직접 계산합니다.

**비유:** 종이 위에 뒤엉킨 빨간 점과 파란 점이 있다면, 종이를 구기면(고차원 변환) 두 그룹을 평면으로 나눌 수 있습니다. 커널 트릭은 실제로 구기지 않고도 구긴 것처럼 계산하는 방법입니다.

| 커널 | 함수 | 특징 |
| --- | --- | --- |
| 선형 커널(linear kernel) | $x_i^T x_j$ | 선형 분리 가능한 데이터 |
| 다항식 커널(polynomial kernel) | $(x_i^T x_j + r)^d$ | d차 다항식으로 변환 |
| RBF(Radial Basis Function) / 가우시안 커널 | $\exp(-\gamma\|x_i - x_j\|^2)$ | 무한 차원, 가장 범용적으로 사용 |
| 시그모이드 커널(sigmoid kernel) | $\tanh(\gamma x_i^T x_j + r)$ | 신경망과 유사한 동작 |

<Callout type="warning">
  커널 트릭의 핵심은 실제로 고차원으로 변환하지 않고도 고차원에서의 내적을 효율적으로 계산한다는 것입니다. 이 덕분에 계산 비용을 크게 줄일 수 있습니다.
</Callout>

---

## SVM 최적화 문제

**프라이멀 문제(primal problem):**

$$\min_{w,b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y^{(i)}(w^T x^{(i)} + b) \geq 1, \forall i$$

- 목적: $\frac{1}{2}\|w\|^2$를 최소화 (= 마진 최대화)
- 제약조건: 모든 샘플이 자신의 클래스 쪽 마진 경계 바깥에 위치

**마진 최대화 = $\|w\|$ 최소화** 인 이유: 마진 크기 = $\frac{2}{\|w\|}$이므로, 마진을 늘리려면 $\|w\|$를 줄여야 합니다.

---

## SVM 회귀 (SVR, Support Vector Regression)

분류 외에도 회귀에 사용 가능합니다. SVR은 $\epsilon$-tube(엡실론 튜브, 예측 오차를 허용하는 범위) 안에 가능한 많은 샘플이 들어오도록 학습합니다. 튜브 밖의 샘플만 손실로 계산합니다.

---

## 핵심 정리

- **SVM:** 마진을 최대화하는 초평면 찾기, 이진 분류에 강력
- **서포트 벡터:** 결정 경계에 가장 가까운 샘플들 (경계를 결정)
- **마진:** $\frac{2}{\|w\|}$, 최대화 = $\|w\|$ 최소화
- **소프트 마진:** 일부 오류 허용, C가 클수록 엄격
- **커널 트릭:** 고차원 변환 없이 비선형 분류 가능
- **RBF 커널:** 가장 범용적, 무한 차원 변환과 동등
