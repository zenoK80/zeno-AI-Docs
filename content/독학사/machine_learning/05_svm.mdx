## SVM (Support Vector Machine)

클래스 간 **마진(Margin)을 최대화**하는 결정 경계(초평면)를 찾는 분류 알고리즘입니다.

## 핵심 개념

**초평면(Hyperplane):** n차원 공간에서 데이터를 분리하는 (n-1)차원 경계

$$w^T x + b = 0$$

**서포트 벡터(Support Vector):** 결정 경계에 가장 가까운 데이터 포인트들

**마진(Margin):** 두 클래스의 서포트 벡터 사이의 거리 = $\frac{2}{\|w\|}$

## 하드 마진 vs 소프트 마진

| 종류 | 설명 | 특징 |
| --- | --- | --- |
| 하드 마진 | 모든 샘플이 마진 밖 | 선형 분리 가능할 때만 |
| 소프트 마진 | 일부 오류 허용 | 실제 데이터에 더 유연, 매개변수 C 사용 |

**소프트 마진의 C 매개변수:**
- C가 크면: 오류 허용 적음 (과적합 위험)
- C가 작으면: 오류 허용 많음 (과소적합 위험)

## 커널 트릭 (Kernel Trick)

선형 분리가 불가능한 데이터를 **고차원으로 변환**하여 선형 분리 가능하게 합니다.

**커널 함수** $K(x_i, x_j)$는 변환 후 내적을 직접 계산합니다:

| 커널 | 함수 | 특징 |
| --- | --- | --- |
| 선형 | $x_i^T x_j$ | 선형 분리 가능 |
| 다항식 | $(x_i^T x_j + r)^d$ | d차원 변환 |
| RBF(가우시안) | $\exp(-\gamma\|x_i - x_j\|^2)$ | 무한 차원, 가장 일반적 |
| 시그모이드 | $\tanh(\gamma x_i^T x_j + r)$ | 신경망과 유사 |

<Callout type="warning">
  커널 트릭의 핵심은 실제로 고차원으로 변환하지 않고도 고차원에서의 내적을 효율적으로 계산한다는 것입니다.
</Callout>

## SVM 최적화 문제

**프라이멀 문제:**

$$\min_{w,b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y^{(i)}(w^T x^{(i)} + b) \geq 1, \forall i$$

마진 최대화 = $\|w\|$ 최소화

## SVM 회귀 (SVR)

SVR은 $\epsilon$-tube(엡실론 튜브) 안에 가능한 많은 샘플이 들어오도록 학습합니다.

## 핵심 정리

- SVM: 마진을 최대화하는 초평면 찾기
- 서포트 벡터: 결정 경계에 가장 가까운 샘플
- 소프트 마진: 일부 오류 허용, C 매개변수로 조절
- 커널 트릭: 고차원 변환 없이 비선형 분류 가능
