## 왜 선형 회귀가 필요한가?

숫자로 된 결과를 예측해야 할 때 사용합니다. 예를 들어, "집의 방 수, 면적, 위치로 집값을 예측하고 싶다"면? 이처럼 연속적인 숫자값(집값, 기온, 매출액 등)을 예측하는 것이 **회귀(regression, 연속값 예측)** 문제입니다.

**비유:** 키가 클수록 몸무게가 많이 나가는 경향이 있습니다. 키(입력)와 몸무게(출력) 사이에 직선을 그어 새로운 키가 주어졌을 때 몸무게를 예측하는 것이 선형 회귀입니다.

## 선형 회귀 (linear regression, 선형 회귀)

입력 특성(feature, 특성)과 연속형 출력값(target, 타겟) 사이의 **선형 관계**를 모델링합니다.

$$\hat{y} = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_n x_n = \mathbf{\theta}^T \mathbf{x}$$

각 변수의 의미:

- $\hat{y}$: 모델이 예측한 출력값 (hat은 예측을 의미)
- $\theta_0$: 편향(bias, 절편) — 입력이 0일 때의 기본값
- $\theta_1, \ldots, \theta_n$: 가중치(weight) — 각 특성이 예측에 미치는 영향력
- $x_1, \ldots, x_n$: 입력 특성값들

> 쉽게 말하면: $\hat{y} = a \cdot x + b$ 형태의 직선 방정식을 여러 차원으로 확장한 것입니다.

---

## 비용 함수 (cost function, 비용 함수)

**왜 필요한가?** "이 직선이 얼마나 데이터에 잘 맞는가?"를 수치로 표현해야 파라미터(parameter, 모델 변수)를 개선할 수 있습니다.

**MSE(Mean Squared Error, 평균 제곱 오차):**

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2$$

각 변수의 의미:

- $J(\theta)$: 비용(오차의 크기를 나타내는 수치)
- $m$: 훈련 데이터의 개수
- $\hat{y}^{(i)}$: i번째 샘플에 대한 예측값
- $y^{(i)}$: i번째 샘플의 실제 정답값
- 앞에 $\frac{1}{2}$를 붙이는 이유: 미분 계산을 편하게 하기 위함

선형 회귀의 목표: **$J(\theta)$를 최소화하는 $\theta$를 찾기**

**비유:** 활 쏘기에서 과녁과 화살의 거리를 측정하는 것처럼, MSE는 예측값과 정답값의 "거리"를 측정합니다. 이 거리를 최소화하는 방향으로 활 조준(파라미터)을 조정합니다.

---

## 정규방정식 (normal equation, 정규방정식)

$J(\theta)$를 $\theta$에 대해 미분하여 0으로 놓으면 한 번에 최적해를 구할 수 있습니다:

$$\hat{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

각 기호의 의미:

- $\mathbf{X}$: 훈련 데이터 행렬 (m행 × n열)
- $\mathbf{X}^T$: X의 전치행렬
- $(\mathbf{X}^T \mathbf{X})^{-1}$: 역행렬
- $\mathbf{y}$: 실제 정답값 벡터

**장단점:**

| 항목 | 정규방정식 |
| --- | --- |
| 장점 | 학습률 불필요, 단번에 최적해 계산 |
| 단점 | 특성 수가 많으면 느림 (역행렬 계산 비용이 특성 수의 세제곱에 비례) |

---

## 경사하강법 (gradient descent, 경사 하강법)

**왜 필요한가?** 특성이 수만 개인 경우 정규방정식은 너무 느립니다. 반복적으로 조금씩 파라미터를 개선하는 방법이 필요합니다.

**비유:** 눈을 감고 산에서 내려올 때, 발 아래 경사를 느끼면서 가장 가파르게 내려가는 방향으로 한 발씩 내딛는 것과 같습니다.

비용 함수의 기울기(gradient, 경사) 반대 방향으로 파라미터를 업데이트합니다:

$$\theta_{j} \leftarrow \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$$

각 변수의 의미:

- $\alpha$: 학습률(learning rate) — 한 번에 얼마나 이동할지 결정하는 값
- $\frac{\partial J(\theta)}{\partial \theta_j}$: $j$번째 파라미터 방향의 기울기

### 경사하강법의 종류

| 종류 | 설명 | 특징 |
| --- | --- | --- |
| 배치 경사하강법(batch GD) | 전체 훈련 세트 사용 | 안정적, 데이터가 많으면 느림 |
| 확률적 경사하강법(SGD, stochastic GD) | 무작위 1개 샘플 사용 | 빠름, 업데이트가 불안정 |
| 미니배치 경사하강법(mini-batch GD) | 소규모 배치(32~256개) | 절충안, 실제로 가장 많이 사용 |

<Callout type="warning">
  학습률(alpha)이 너무 크면 최솟값을 지나쳐 발산하고, 너무 작으면 수렴이 매우 느립니다. 적절한 학습률 선택이 매우 중요합니다.
</Callout>

---

## 다항 회귀 (polynomial regression, 다항 회귀)

**왜 필요한가?** 실제 데이터가 직선보다 곡선에 더 잘 맞을 때 사용합니다.

비선형 데이터를 다항 특성으로 변환하여 선형 회귀를 적용합니다:

$$\hat{y} = \theta_0 + \theta_1 x + \theta_2 x^2 + \cdots$$

**핵심 아이디어:** $x^2$, $x^3$ 등 고차항을 새로운 특성으로 추가하면, 파라미터에 대해서는 여전히 선형 회귀입니다.

다항식의 차수가 높을수록 훈련 데이터에 더 잘 맞지만, 너무 높으면 **과적합(overfitting, 훈련 데이터에 지나치게 맞춰지는 현상)** 위험이 있습니다.

---

## 규제화된 회귀 (regularized regression, 규제 회귀)

**왜 필요한가?** 과적합을 방지하기 위해 가중치가 너무 커지는 것을 막는 제약을 추가합니다.

- **릿지 회귀(ridge regression):** L2 정규화 추가 → 가중치 크기를 작게 유지 (0에 가깝지만 정확히 0은 아님)
- **라쏘 회귀(lasso regression, Least Absolute Shrinkage and Selection Operator):** L1 정규화 추가 → 일부 가중치를 정확히 0으로 만들어 특성 선택 효과

---

## 핵심 정리

- **선형 회귀:** 연속값 예측, $\hat{y} = \theta^T x$ 형태의 직선
- **비용 함수(MSE):** 예측값과 실제값 차이의 제곱 평균, 최소화가 목표
- **정규방정식:** 한 번에 최적해 계산, 특성 수가 많으면 느림
- **경사하강법:** 기울기 반대 방향으로 $\theta$를 반복 업데이트
- **학습률:** 너무 크면 발산, 너무 작으면 수렴 느림
- **다항 회귀:** 고차항을 특성으로 추가하여 곡선 데이터에 적용
