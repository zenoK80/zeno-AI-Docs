## 선형 회귀 (Linear Regression)

입력 특성(feature)과 연속형 출력값(target) 사이의 선형 관계를 모델링합니다.

$$\hat{y} = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_n x_n = \mathbf{\theta}^T \mathbf{x}$$

- $\theta$: 모델 파라미터 (가중치)
- $\hat{y}$: 예측값
- $x_i$: 입력 특성

## 비용 함수 (Cost Function)

**평균 제곱 오차(Mean Squared Error, MSE):**

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2 = \frac{1}{2m} \|\mathbf{X\theta} - \mathbf{y}\|^2$$

선형 회귀의 목표는 $J(\theta)$를 최소화하는 $\theta$를 찾는 것입니다.

## 정규방정식 (Normal Equation)

$J(\theta)$를 $\theta$에 대해 편미분하여 0으로 놓으면:

$$\hat{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

**장단점:**

| 항목 | 정규방정식 |
| --- | --- |
| 장점 | 학습률 불필요, 단번에 최적해 계산 |
| 단점 | 특성 수가 많으면 느림 (역행렬 계산: $O(n^3)$) |

## 경사하강법 (Gradient Descent)

비용 함수의 기울기(gradient) 반대 방향으로 파라미터를 업데이트합니다.

$$\theta_{j} \leftarrow \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$$

여기서 $\alpha$는 **학습률(Learning Rate)** 입니다.

### 경사하강법의 종류

| 종류 | 설명 | 특징 |
| --- | --- | --- |
| 배치 경사하강법 | 전체 훈련 세트 | 안정적, 느림 |
| 확률적 경사하강법(SGD) | 무작위 1개 샘플 | 빠름, 불안정 |
| 미니배치 경사하강법 | 소규모 배치 | 절충안, 일반적 사용 |

<Callout type="warning">
  학습률이 너무 크면 발산하고, 너무 작으면 수렴이 매우 느립니다. 적절한 학습률 선택이 중요합니다.
</Callout>

## 다항 회귀 (Polynomial Regression)

비선형 데이터를 다항 특성으로 변환하여 선형 회귀를 적용합니다.

$$\hat{y} = \theta_0 + \theta_1 x + \theta_2 x^2 + \cdots$$

다항식의 차수가 높을수록 훈련 데이터에 더 잘 맞지만 과적합 위험이 있습니다.

## 규제화된 회귀

- **릿지 회귀(Ridge):** L2 정규화 추가 → 가중치 크기 제한
- **라쏘 회귀(Lasso):** L1 정규화 추가 → 일부 가중치를 0으로 (특성 선택)

## 핵심 정리

- 선형 회귀: $\hat{y} = \theta^T x$, 비용 함수 MSE 최소화
- 정규방정식: $\hat{\theta} = (X^TX)^{-1}X^Ty$ (소규모 특성에 적합)
- 경사하강법: 기울기 반대 방향으로 $\theta$ 업데이트
- 학습률: 너무 크면 발산, 너무 작으면 수렴 느림
