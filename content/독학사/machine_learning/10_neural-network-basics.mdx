## 생물학적 뉴런에서 인공 뉴런으로

생물학적 뉴런은 수상돌기에서 신호를 받아 임계값을 초과하면 축삭을 통해 신호를 전달합니다. 인공 뉴런은 이를 수학적으로 모델링합니다.

## 퍼셉트론 (Perceptron)

가장 단순한 인공 신경망으로 1957년 Rosenblatt이 제안했습니다.

**구조:**

$$\hat{y} = \text{step}(w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b)$$

- $x_i$: 입력값
- $w_i$: 가중치(Weight)
- $b$: 편향(Bias)
- step: 계단 함수 (임계값 초과 시 1, 이하 시 0)

**한계:** 선형 분리 불가능한 문제(XOR 등) 해결 불가

## 다층 퍼셉트론 (MLP, Multi-Layer Perceptron)

여러 층의 뉴런을 쌓아 비선형 문제를 해결합니다.

**구조:**

```
입력층 (Input Layer)
    ↓
은닉층 (Hidden Layer 1)
    ↓
은닉층 (Hidden Layer 2)  ← 깊어질수록 "딥러닝"
    ↓
출력층 (Output Layer)
```

- **입력층:** 특징 수만큼 뉴런
- **은닉층:** 중간 표현 학습 (하이퍼파라미터로 설정)
- **출력층:** 회귀(1개), 이진분류(1개), 다중분류(클래스 수)

각 층의 연산:

$$\mathbf{h} = \text{activation}(W\mathbf{x} + \mathbf{b})$$

## 활성화 함수 (Activation Function)

뉴런의 출력에 비선형성을 도입하여 신경망이 복잡한 패턴을 학습할 수 있게 합니다. 활성화 함수 없이는 여러 층을 쌓아도 선형 변환만 됩니다.

### Sigmoid

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

- 출력 범위: (0, 1)
- 이진 분류 출력층에 주로 사용
- 단점: **기울기 소실(Vanishing Gradient)** 문제, 출력이 0 중심이 아님

### Tanh (Hyperbolic Tangent)

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

- 출력 범위: (-1, 1)
- 0 중심으로 sigmoid보다 학습 안정적
- 단점: 기울기 소실 문제 여전히 존재

### ReLU (Rectified Linear Unit)

$$\text{ReLU}(z) = \max(0, z)$$

- 출력 범위: [0, ∞)
- 계산이 단순하고 기울기 소실 문제 완화
- 은닉층의 기본 활성화 함수로 가장 많이 사용
- 단점: **Dying ReLU** (음수 입력에서 기울기가 0)

### 활성화 함수 비교

| 함수 | 범위 | 주 용도 | 문제점 |
|------|------|---------|--------|
| Sigmoid | (0, 1) | 이진 분류 출력 | 기울기 소실 |
| Tanh | (-1, 1) | 은닉층 (RNN 등) | 기울기 소실 |
| ReLU | [0, ∞) | 은닉층 기본값 | Dying ReLU |
| Leaky ReLU | (-∞, ∞) | Dying ReLU 개선 | - |
| Softmax | (0, 1), 합=1 | 다중 분류 출력 | - |

## 순전파 (Forward Propagation)

입력에서 출력 방향으로 계산을 진행합니다.

```
Layer 1: z¹ = W¹x + b¹,  a¹ = activation(z¹)
Layer 2: z² = W²a¹ + b², a² = activation(z²)
출력:    ŷ = a²
```

**손실 함수(Loss Function):**
- 회귀: 평균제곱오차 $\text{MSE} = \frac{1}{n}\sum(y - \hat{y})^2$
- 분류: 교차 엔트로피 $L = -\sum y \log \hat{y}$

## 역전파 (Backpropagation)

손실을 최소화하기 위해 **출력에서 입력 방향**으로 기울기를 계산하여 가중치를 업데이트합니다.

### 체인룰 (Chain Rule)

합성 함수의 미분 법칙입니다:

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w}$$

**예시:** 출력층 → 은닉층 → 입력층 순으로 기울기 역방향 전파

### 가중치 업데이트 (경사 하강법)

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

- $\eta$: 학습률(Learning Rate)
- $\frac{\partial L}{\partial w}$: 손실에 대한 가중치의 기울기

### 기울기 소실 문제

Sigmoid/Tanh의 포화 영역에서 기울기가 0에 가까워져 역전파 시 기울기가 소멸합니다.

**해결책:** ReLU 사용, 배치 정규화, 잔차 연결(ResNet)

## 핵심 정리

- 퍼셉트론: 단일 뉴런 모델, 선형 분리 가능 문제만 해결
- MLP: 다층 구조로 비선형 문제 해결
- 활성화 함수: 비선형성 도입 (sigmoid→기울기소실, ReLU→은닉층 기본)
- 역전파: 체인룰로 기울기를 역방향 전파하여 가중치 업데이트
- 기울기 소실: 깊은 네트워크에서 sigmoid/tanh의 포화 문제
