## 왜 신경망이 필요한가?

사람의 뇌는 1000억 개의 뉴런(neuron, 신경세포)이 연결되어 복잡한 패턴(얼굴 인식, 언어 이해)을 처리합니다. 이를 수학적으로 모방한 것이 **인공 신경망**(artificial neural network) 입니다.

SVM, 선형 회귀 등은 선형 결정 경계밖에 만들 수 없지만, 신경망은 층(layer)을 깊게 쌓아 매우 복잡한 비선형 패턴을 학습할 수 있습니다.

**비유:** 뇌의 뉴런이 여러 개의 시냅스에서 신호를 받아 합산하고, 임계값을 넘으면 다음 뉴런으로 신호를 전달합니다. 인공 뉴런도 이를 수학적으로 모방합니다.

---

## 퍼셉트론 (perceptron, 퍼셉트론)

가장 단순한 인공 신경망으로 1957년 Rosenblatt이 제안했습니다.

$$\hat{y} = \text{step}(w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b)$$

각 변수의 의미:

- $x_i$: 입력값 (특성)
- $w_i$: 가중치(weight) — 각 입력의 중요도
- $b$: 편향(bias) — 임계값 조정
- step: 계단 함수 — 합이 임계값 초과 시 1, 이하 시 0 출력

**비유:** 여러 가지 음식 재료의 점수(입력)에 중요도(가중치)를 곱해서 합산하고, 총점이 일정 기준 이상이면 "맛있다"(1), 아니면 "맛없다"(0)로 판단합니다.

**한계:** 선형 분리 불가능한 문제(XOR 게이트 등) 해결 불가 → 이를 극복하기 위해 다층 퍼셉트론이 등장합니다.

## 다층 퍼셉트론 (MLP, Multi-Layer Perceptron, 다층 퍼셉트론)

여러 층의 뉴런을 쌓아 비선형 문제를 해결합니다.

**구조:**

```
입력층 (Input Layer)    → 데이터를 받음 (특성 수만큼 뉴런)
    ↓
은닉층 (Hidden Layer 1) → 중간 표현 학습
    ↓
은닉층 (Hidden Layer 2) ← 층이 깊어질수록 딥러닝(Deep Learning)
    ↓
출력층 (Output Layer)   → 최종 예측 출력
```

| 층 종류 | 역할 |
|------|------|
| 입력층(input layer) | 데이터 입력, 특성 수만큼 뉴런 |
| 은닉층(hidden layer) | 중간 표현 학습, 개수와 뉴런 수는 설계자가 결정 |
| 출력층(output layer) | 회귀: 1개, 이진분류: 1개, 다중분류: 클래스 수만큼 |

각 층의 연산:

$$\mathbf{h} = \text{activation}(W\mathbf{x} + \mathbf{b})$$

각 변수의 의미:

- $W$: 가중치 행렬 (이전 층 → 현재 층 연결)
- $\mathbf{x}$: 이전 층의 출력
- $\mathbf{b}$: 편향 벡터
- $\text{activation}$: 활성화 함수

## 활성화 함수 (activation function, 활성화 함수)

**왜 필요한가?** 활성화 함수 없이 여러 층을 쌓으면 결국 하나의 선형 변환과 동일합니다. 활성화 함수가 **비선형성**(non-linearity) 을 도입해야 MLP가 복잡한 패턴을 학습할 수 있습니다.

> 쉽게 말하면: 선형 함수를 아무리 여러 개 연결해도 결과는 선형입니다. 비선형 활성화 함수가 있어야 진짜 복잡한 관계를 배울 수 있습니다.

### Sigmoid (시그모이드)

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

- 출력 범위: (0, 1)
- 이진 분류 출력층에 주로 사용
- 단점: **기울기 소실**(vanishing gradient) 문제 — 양 끝에서 기울기가 0에 가까워짐

### Tanh (하이퍼볼릭 탄젠트)

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

- 출력 범위: (-1, 1)
- 0 중심 출력으로 sigmoid보다 학습 안정적
- 단점: 기울기 소실 문제 여전히 존재

### ReLU (Rectified Linear Unit, 정류 선형 유닛)

$$\text{ReLU}(z) = \max(0, z)$$

- 출력 범위: [0, ∞)
- 계산이 매우 단순하고 기울기 소실 문제 크게 완화
- 은닉층의 기본 활성화 함수로 가장 많이 사용
- 단점: **Dying ReLU** — 음수 입력에서 기울기가 0이 되어 뉴런이 죽을 수 있음

### 활성화 함수 비교

| 함수 | 범위 | 주 용도 | 문제점 |
|------|------|---------|--------|
| Sigmoid | (0, 1) | 이진 분류 출력층 | 기울기 소실 |
| Tanh | (-1, 1) | 은닉층(RNN 등) | 기울기 소실 |
| ReLU | [0, ∞) | 은닉층 기본값 | Dying ReLU |
| Leaky ReLU | 음수도 허용 | Dying ReLU 개선 | - |
| Softmax | (0, 1), 합=1 | 다중 분류 출력층 | - |

## 순전파 (forward propagation, 순전파)

입력에서 출력 방향으로 계산을 진행하여 예측값 $\hat{y}$를 계산합니다.

```
Layer 1: z_1 = W_1 x + b_1,  a_1 = activation(z_1)
Layer 2: z_2 = W_2 a_1 + b_2, a_2 = activation(z_2)
출력:    y_hat = a_2
```

**손실 함수(loss function, 손실 함수):**

- 회귀: 평균제곱오차 MSE
- 이진 분류: 이진 교차 엔트로피
- 다중 분류: 범주형 교차 엔트로피

---

## 역전파 (backpropagation, 역전파)

손실을 최소화하기 위해 **출력에서 입력 방향**으로 기울기를 계산하여 가중치를 업데이트합니다.

**왜 필요한가?** 손실 함수가 어떤 가중치 때문에 커졌는지 계산해야 해당 가중치를 조정할 수 있습니다. 역전파는 각 가중치가 손실에 기여한 정도(기울기)를 효율적으로 계산합니다.

### 체인룰 (chain rule, 연쇄 법칙)

합성 함수의 미분 법칙입니다. 역전파의 핵심 수학 도구입니다:

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w}$$

각 항의 의미:

- $\frac{\partial L}{\partial \hat{y}}$: 예측값에 대한 손실의 기울기
- $\frac{\partial \hat{y}}{\partial z}$: 활성화 함수의 기울기
- $\frac{\partial z}{\partial w}$: 가중치에 대한 선형 결합의 기울기

**비유:** 도미노처럼, 마지막 블록이 어떻게 쓰러졌는지가 앞 블록들의 영향 때문임을 거꾸로 추적합니다.

### 가중치 업데이트 (경사 하강법)

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

각 변수의 의미:

- $\eta$ (eta): 학습률(learning rate)
- $\frac{\partial L}{\partial w}$: 손실에 대한 가중치의 기울기

## 기울기 소실 문제 (vanishing gradient problem)

Sigmoid와 Tanh의 **포화 영역**(saturated region) 에서 기울기가 0에 가까워져 역전파 시 기울기가 소멸합니다.

**과정:**
1. Sigmoid 함수: 양 끝(매우 큰 음수 또는 양수)에서 기울기 ≈ 0
2. 체인룰로 기울기를 곱하면 → 깊은 층으로 갈수록 기울기 → 0
3. 기울기가 0이 되면 가중치 업데이트가 안 됨 → 학습이 멈춤

**해결책:**
- ReLU 사용 (양수 구간에서 기울기 = 1)
- 배치 정규화(Batch Normalization) 적용
- 잔차 연결(Residual Connection) — ResNet에서 사용

---

## 핵심 정리

- **퍼셉트론:** 단일 뉴런 모델, 선형 분리 가능 문제만 해결
- **MLP:** 다층 구조로 비선형 문제 해결
- **활성화 함수:** 비선형성 도입 — sigmoid(기울기 소실), ReLU(은닉층 기본)
- **순전파:** 입력 → 출력 방향으로 예측값 계산
- **역전파:** 출력 → 입력 방향으로 기울기 계산하여 가중치 업데이트
- **체인룰:** 합성 함수 기울기 = 각 구성요소 기울기의 곱
- **기울기 소실:** Sigmoid/Tanh의 포화 영역 문제, ReLU로 완화
