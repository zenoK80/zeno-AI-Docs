## 모델 평가의 중요성

학습 데이터에서 좋은 성능을 보여도 새로운 데이터에서 실패할 수 있습니다. 올바른 평가 방법으로 **일반화 성능**을 측정해야 합니다.

## 데이터 분할

| 분할 | 목적 |
|------|------|
| **훈련 세트 (Train)** | 모델 학습 |
| **검증 세트 (Validation)** | 하이퍼파라미터 조정 |
| **테스트 세트 (Test)** | 최종 성능 평가 (한 번만 사용) |

## 교차 검증 (Cross-Validation)

데이터를 여러 번 분할하여 모델을 평가합니다. 데이터 크기가 작을 때 유용합니다.

### k-폴드 교차 검증 (k-Fold Cross-Validation)

1. 데이터를 k개의 동일한 크기의 폴드로 분할
2. 각 반복에서 하나의 폴드를 검증 세트, 나머지 k-1개를 훈련 세트로 사용
3. k번 반복 후 평균 성능 계산

**예시 (k=5):**
```
폴드 1: [검증] [훈련] [훈련] [훈련] [훈련]
폴드 2: [훈련] [검증] [훈련] [훈련] [훈련]
폴드 3: [훈련] [훈련] [검증] [훈련] [훈련]
폴드 4: [훈련] [훈련] [훈련] [검증] [훈련]
폴드 5: [훈련] [훈련] [훈련] [훈련] [검증]
→ 5번 성능의 평균
```

### Stratified k-Fold

클래스 불균형 데이터에서 각 폴드의 클래스 비율을 유지합니다.

### LOOCV (Leave-One-Out Cross-Validation)

n개 데이터에서 k=n으로 설정. 계산 비용이 매우 높음.

## 혼동 행렬 (Confusion Matrix)

분류 모델의 예측 결과를 실제값과 비교하여 표로 나타냅니다.

|  | 예측: Positive | 예측: Negative |
|--|---|---|
| **실제: Positive** | TP (True Positive) | FN (False Negative) |
| **실제: Negative** | FP (False Positive) | TN (True Negative) |

- **TP:** 실제 양성을 양성으로 올바르게 예측
- **TN:** 실제 음성을 음성으로 올바르게 예측
- **FP:** 실제 음성을 양성으로 잘못 예측 (1종 오류)
- **FN:** 실제 양성을 음성으로 잘못 예측 (2종 오류)

## 주요 평가 지표

### 정확도 (Accuracy)

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

클래스 불균형 시 신뢰할 수 없음 (예: 99% 음성 데이터에서 항상 음성 예측 시 99% 정확도)

### 정밀도 (Precision)

$$\text{Precision} = \frac{TP}{TP + FP}$$

양성으로 예측한 것 중 실제 양성의 비율. **FP를 줄이는 것이 중요**할 때 사용 (예: 스팸 필터)

### 재현율 (Recall, 민감도)

$$\text{Recall} = \frac{TP}{TP + FN}$$

실제 양성 중 양성으로 예측한 비율. **FN을 줄이는 것이 중요**할 때 사용 (예: 암 진단)

### F1 점수 (F1 Score)

**F1 = 2 × (Precision × Recall) / (Precision + Recall)**

정밀도와 재현율의 조화 평균. 두 지표 사이의 균형이 필요할 때 사용

### 정밀도-재현율 트레이드오프

임계값(Threshold)을 높이면 정밀도 증가, 재현율 감소. 임계값을 낮추면 정밀도 감소, 재현율 증가.

## ROC 곡선과 AUC

### ROC 곡선 (Receiver Operating Characteristic)

임계값을 변화시키면서 **TPR(재현율)과 FPR**의 관계를 그래프로 표시합니다.

$$\text{TPR} = \frac{TP}{TP + FN} \quad \text{(재현율)}$$

$$\text{FPR} = \frac{FP}{FP + TN}$$

### AUC (Area Under the Curve)

ROC 곡선 아래의 넓이 (0~1):
- AUC = 1.0: 완벽한 분류
- AUC = 0.5: 무작위 분류 (대각선)
- AUC가 클수록 모델 성능이 좋음

클래스 불균형 상황에서도 신뢰할 수 있는 지표입니다.

## 회귀 평가 지표

| 지표 | 수식 | 특징 |
|------|------|------|
| MAE | $\frac{1}{n}\sum\|y - \hat{y}\|$ | 이상치에 강건 |
| MSE | $\frac{1}{n}\sum(y - \hat{y})^2$ | 이상치에 민감 |
| RMSE | √MSE | 원래 단위와 동일 |
| R² | 1 - SS_res/SS_tot | 1에 가까울수록 좋음 |

## 오버피팅과 언더피팅

### 오버피팅 (Overfitting, 과적합)

모델이 훈련 데이터의 노이즈까지 학습하여 새로운 데이터에서 성능이 떨어지는 현상

- **증상:** 훈련 오차 &lt;&lt; 검증 오차
- **원인:** 모델이 너무 복잡, 데이터 부족
- **해결:** 정규화(L1/L2), 드롭아웃, 더 많은 데이터, 모델 단순화

### 언더피팅 (Underfitting, 과소적합)

모델이 데이터의 패턴을 충분히 학습하지 못하는 현상

- **증상:** 훈련 오차도 높음
- **원인:** 모델이 너무 단순, 특징 부족
- **해결:** 더 복잡한 모델, 특징 추가, 정규화 감소

### 편향-분산 트레이드오프

**오류 = 편향² + 분산 + 불가피한 오류**

- **높은 편향(High Bias):** 언더피팅
- **높은 분산(High Variance):** 오버피팅
- 최적 모델: 편향과 분산 모두 낮은 지점

## 핵심 정리

- k-폴드 교차 검증: 데이터를 k등분, 순환적으로 검증 세트 변경
- 혼동 행렬: TP/TN/FP/FN으로 분류 결과 정리
- 정밀도: FP 최소화 목적 / 재현율: FN 최소화 목적
- F1: 정밀도와 재현율의 조화 평균
- ROC-AUC: 임계값 변화에 따른 TPR-FPR 곡선의 넓이
- 오버피팅: 훈련 좋고 검증 나쁨 / 언더피팅: 모두 나쁨
