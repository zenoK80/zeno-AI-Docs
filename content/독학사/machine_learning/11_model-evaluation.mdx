## 왜 모델 평가가 중요한가?

훈련 데이터에서 100점을 받은 학생이 실전 시험에서는 60점을 받을 수 있습니다. 모델도 마찬가지입니다. 학습한 데이터에서는 잘 동작해도 새로운 데이터에서 실패할 수 있습니다. 올바른 평가 방법으로 **일반화 성능**(generalization performance, 새로운 데이터에서의 성능) 을 측정해야 합니다.

| 분할 | 목적 |
|------|------|
| 훈련 세트(train set) | 모델 학습 |
| 검증 세트(validation set) | 하이퍼파라미터 조정, 모델 선택 |
| 테스트 세트(test set) | 최종 성능 평가 (딱 한 번만 사용!) |

## 교차 검증 (cross-validation, 교차 검증)

**왜 필요한가?** 데이터가 적을 때, 하나의 고정된 검증 세트는 우연에 따라 결과가 달라질 수 있습니다. 데이터를 여러 번 분할하여 더 신뢰할 수 있는 성능 추정을 합니다.

### k-폴드 교차 검증 (k-fold cross-validation)

1. 데이터를 k개의 동일한 크기의 폴드(fold)로 분할
2. 각 반복에서 하나의 폴드를 검증 세트, 나머지 k-1개를 훈련 세트로 사용
3. k번 반복 후 k번 성능의 평균을 최종 지표로 사용

**예시 (k=5):**
```
반복 1: [검증] [훈련] [훈련] [훈련] [훈련]
반복 2: [훈련] [검증] [훈련] [훈련] [훈련]
반복 3: [훈련] [훈련] [검증] [훈련] [훈련]
반복 4: [훈련] [훈련] [훈련] [검증] [훈련]
반복 5: [훈련] [훈련] [훈련] [훈련] [검증]
→ 5번 성능의 평균을 최종 성능으로 사용
```

### Stratified k-Fold (층화 k-폴드)

클래스 불균형(class imbalance) 데이터에서 각 폴드의 클래스 비율을 전체 데이터와 동일하게 유지합니다.

**예시:** 암 환자 1%, 정상 99%인 데이터에서 일반 k-Fold를 사용하면 어떤 폴드에 암 환자가 하나도 없을 수 있습니다.

### LOOCV (Leave-One-Out Cross-Validation, 일대일 교차 검증)

n개 데이터에서 k=n으로 설정합니다. 계산 비용이 매우 높지만 데이터가 매우 적을 때 사용합니다.

## 혼동 행렬 (confusion matrix, 혼동 행렬)

분류 모델의 예측 결과를 실제값과 비교하여 4가지 경우로 정리한 표입니다.

|  | 예측: Positive(양성) | 예측: Negative(음성) |
|--|---|---|
| **실제: Positive**(양성) | TP (True Positive, 참 양성) | FN (False Negative, 거짓 음성) |
| **실제: Negative**(음성) | FP (False Positive, 거짓 양성) | TN (True Negative, 참 음성) |

- **TP:** 실제 암 환자를 암으로 올바르게 예측 ✓
- **TN:** 실제 정상인을 정상으로 올바르게 예측 ✓
- **FP:** 실제 정상인을 암으로 잘못 예측 (1종 오류, Type I error) ✗
- **FN:** 실제 암 환자를 정상으로 잘못 예측 (2종 오류, Type II error) ✗

**어떤 오류가 더 나쁜가?** 상황에 따라 다릅니다. 암 진단에서는 FN(환자를 놓침)이 더 치명적입니다.

## 주요 평가 지표

### 정확도 (accuracy, 정확도)

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

전체 중 올바르게 예측한 비율.

**한계:** 클래스 불균형 시 신뢰할 수 없습니다!
- 예: 암 환자 1%, 정상 99% 데이터에서 항상 "정상"으로 예측해도 정확도 99% → 의미 없음

### 정밀도 (precision, 정밀도)

$$\text{Precision} = \frac{TP}{TP + FP}$$

양성으로 예측한 것 중 실제 양성의 비율. **FP를 줄이는 것이 중요**할 때 사용합니다.

**예시:** 스팸 필터 — 정상 메일을 스팸으로 잘못 분류(FP)하면 중요한 메일을 놓칠 수 있습니다.

### 재현율 (recall, 재현율 / sensitivity, 민감도)

$$\text{Recall} = \frac{TP}{TP + FN}$$

실제 양성 중 양성으로 예측한 비율. **FN을 줄이는 것이 중요**할 때 사용합니다.

**예시:** 암 진단 — 실제 암 환자를 정상으로 놓치면(FN) 치명적입니다.

> 쉽게 말하면: 정밀도는 "양성이라고 했을 때 얼마나 믿을 수 있는가?", 재현율은 "실제 양성을 몇 개나 잡아냈는가?"

### F1 점수 (F1 score)

$$F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

정밀도와 재현율의 **조화 평균**(harmonic mean) 입니다. 두 지표 사이의 균형이 필요할 때 사용합니다.

**조화 평균의 특성:** 두 값 중 하나라도 낮으면 결과가 크게 낮아집니다. 정밀도와 재현율이 모두 높아야 F1이 높습니다.

### 정밀도-재현율 트레이드오프

임계값(threshold)을 높이면 정밀도 증가, 재현율 감소. 임계값을 낮추면 정밀도 감소, 재현율 증가.

## ROC 곡선과 AUC

### ROC 곡선 (Receiver Operating Characteristic curve)

임계값을 0부터 1까지 변화시키면서 **TPR(재현율)과 FPR**의 관계를 그래프로 표시합니다.

$$\text{TPR} = \frac{TP}{TP + FN} \quad \text{(재현율)}$$

$$\text{FPR} = \frac{FP}{FP + TN} \quad \text{(거짓 양성률)}$$

### AUC (Area Under the Curve, 곡선 아래 넓이)

ROC 곡선 아래의 넓이 (0~1):
- AUC = 1.0: 완벽한 분류 (좌상단 꼭짓점 통과)
- AUC = 0.5: 무작위 분류 (대각선 = 동전 던지기 수준)
- **AUC가 클수록 모델 성능이 좋음**

**클래스 불균형 상황에서도 신뢰할 수 있는 지표입니다.**

## 회귀 평가 지표

| 지표 | 수식 | 특징 |
|------|------|------|
| MAE(Mean Absolute Error, 평균 절대 오차) | $\frac{1}{n}\sum\|y - \hat{y}\|$ | 이상치에 강건, 직관적 |
| MSE(Mean Squared Error, 평균 제곱 오차) | $\frac{1}{n}\sum(y - \hat{y})^2$ | 이상치에 민감, 미분 쉬움 |
| RMSE(Root MSE, 제곱근 평균 제곱 오차) | $\sqrt{\text{MSE}}$ | 원래 단위와 동일하게 표현 |
| R² (결정계수) | $1 - \frac{\text{SS\_res}}{\text{SS\_tot}}$ | 1에 가까울수록 좋음 (설명 분산 비율) |

## 오버피팅과 언더피팅

### 오버피팅 (overfitting, 과적합)

모델이 훈련 데이터의 노이즈까지 학습하여 새로운 데이터에서 성능이 떨어지는 현상.

- **증상:** 훈련 오차는 매우 낮고, 검증 오차는 높음
- **원인:** 모델이 너무 복잡함, 데이터 부족
- **해결:** 정규화(L1/L2), 드롭아웃, 더 많은 데이터, 모델 단순화

**비유:** 시험 문제를 통째로 외웠지만 새 문제를 풀지 못하는 경우.

### 언더피팅 (underfitting, 과소적합)

모델이 데이터의 패턴을 충분히 학습하지 못하는 현상.

- **증상:** 훈련 오차도 높음 (훈련도 잘 못 함)
- **원인:** 모델이 너무 단순, 특성 부족
- **해결:** 더 복잡한 모델, 특성 추가, 정규화 감소

**비유:** 덧셈만 배운 학생이 미적분 문제를 풀려는 경우.

### 편향-분산 트레이드오프 (bias-variance tradeoff)

$$\text{오류} = \text{편향}^2 + \text{분산} + \text{불가피한 오류(노이즈)}$$

- **높은 편향(high bias):** 언더피팅 → 모델이 너무 단순
- **높은 분산(high variance):** 오버피팅 → 모델이 너무 복잡
- **최적 모델:** 편향과 분산 모두 낮은 균형점 찾기

---

## 핵심 정리

- **k-폴드 교차 검증:** 데이터를 k등분, 순환적으로 검증 세트 변경, 평균 성능 사용
- **혼동 행렬:** TP/TN(옳은 예측), FP/FN(틀린 예측) 4가지 경우
- **정밀도:** FP 최소화 목적 (스팸 필터 등)
- **재현율:** FN 최소화 목적 (암 진단 등)
- **F1:** 정밀도와 재현율의 조화 평균
- **ROC-AUC:** 임계값 변화에 따른 TPR-FPR 곡선의 넓이, 불균형 데이터에 유용
- **오버피팅:** 훈련 좋고 검증 나쁨 / **언더피팅:** 훈련도 나쁨
