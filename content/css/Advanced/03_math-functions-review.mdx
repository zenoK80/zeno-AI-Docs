## 실습 — 유동적인 제목 크기 만들기

화면이 작을 땐 `1.25rem`, 클 땐 `2.5rem`이고 그 사이는 뷰포트 너비의 `5vw`에 비례해서 커지는 제목 스타일을 `clamp()`로 만들어보자.

```css
.title {
  font-size: /* 여기를 채워보자 */;
}
```

<Collapse title="정답 보기">

```css
.title {
  font-size: clamp(1.25rem, 5vw, 2.5rem);
}
```

브라우저 창 크기를 좁혔다 넓혔다 하면서 글자 크기가 부드럽게 바뀌는지 직접 확인해 보자.
</Collapse>
