## 03편 복습

## 핵심 퀴즈

**Q1. `clamp(1rem, 4vw, 3rem)`에서 화면이 아주 작아지면 최종 값은?**

<Collapse title="정답 보기">
`1rem`으로 고정된다. `4vw`가 최솟값 `1rem`보다 작아지면 최솟값이 적용된다.
</Collapse>

**Q2. `min(90%, 600px)`이 "최대 너비 제한"으로 쓰이는 이유는?**

<Collapse title="정답 보기">
둘 중 더 작은 값을 고르므로, 화면이 커져서 90%가 600px을 넘으면 600px로 고정되기 때문이다. "최대"를 표현하는데 `min()`을 쓰는 게 직관과 반대라 헷갈리기 쉽다.
</Collapse>

**Q3. `calc()`에서 곱셈·나눗셈은 어떤 조건을 지켜야 하나?**

<Collapse title="정답 보기">
최소 한쪽이 단위 없는 순수 숫자여야 한다. (덧셈·뺄셈은 반대로 양쪽 다 단위가 있어야 한다.)
</Collapse>

## 실습 — 유동적인 제목 크기 만들기

화면이 작을 땐 `1.25rem`, 클 땐 `2.5rem`이고 그 사이는 뷰포트 너비의 `5vw`에 비례해서 커지는 제목 스타일을 `clamp()`로 만들어보자.

```css
.title {
  font-size: /* 여기를 채워보자 */;
}
```

<Collapse title="정답 보기">

```css
.title {
  font-size: clamp(1.25rem, 5vw, 2.5rem);
}
```

브라우저 창 크기를 좁혔다 넓혔다 하면서 글자 크기가 부드럽게 바뀌는지 직접 확인해 보자.
</Collapse>
