## 03편 복습

## 문제 1

`clamp(1rem, 4vw, 3rem)`에서 화면이 아주 작아지면 최종 폰트 크기는?

- A. `4vw` 값 그대로 계속 작아진다
- B. `1rem`으로 고정된다
- C. `3rem`으로 고정된다
- D. `0`이 된다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`clamp(최솟값, 기본값, 최댓값)`의 구조에서, 가운데 값(`4vw`, 화면 너비에 비례하는 값)이 최솟값(`1rem`)보다 작아지려고 하면 **최솟값에서 멈춘다.** 반대로 화면이 커져서 `4vw`가 최댓값(`3rem`)을 넘으려 하면 최댓값에서 멈춘다. 그 사이 구간에서만 `4vw`가 실제로 적용된다.
</Collapse>

## 문제 2

`min(90%, 600px)`을 "최대 너비를 600px로 제한한다"는 뜻으로 쓸 수 있는 이유는?

- A. `min()`은 사실 최댓값을 정하는 함수라서
- B. 둘 중 더 작은 값을 고르는데, 화면이 커져서 90%가 600px을 넘으면 결국 더 작은 쪽인 600px이 선택되기 때문에
- C. 브라우저가 자동으로 반대로 해석해주기 때문에
- D. 실제로는 최대 너비를 제한하지 못한다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`min()`은 이름 그대로 "여러 값 중 더 작은 값"을 고른다. 화면이 좁을 땐 `90%`가 `600px`보다 작으니 `90%`가 쓰이고(유동적으로 줄어듦), 화면이 넓어져 `90%`가 `600px`을 넘어서면 이제 `600px`이 더 작은 값이 되어 그쪽이 선택된다. 그 결과 "600px을 넘지 않으면서, 작은 화면에서는 유동적인" 효과가 난다. "최대"를 표현하는데 `min()`을 쓰는 게 직관과 반대라 헷갈리기 쉬운 부분이다.
</Collapse>

## 문제 3

`calc()`에서 곱셈·나눗셈을 할 때 지켜야 하는 조건은?

- A. 양쪽 다 단위가 있는 값이어야 한다
- B. 최소 한쪽이 단위 없는 순수 숫자여야 한다
- C. 반드시 둘 다 픽셀(px) 단위여야 한다
- D. 특별한 조건은 없다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`calc(100% / 3)`처럼 곱셈·나눗셈은 최소 한쪽이 **단위 없는 순수 숫자**(여기서는 `3`)여야 한다. `calc(100px * 100%)`처럼 양쪽 다 단위가 있으면 에러가 난다. 참고로 덧셈·뺄셈은 반대로 **양쪽 다 단위가 있어야** 하고 그 단위가 서로 호환돼야 한다(`calc(100% - 40px)`처럼).
</Collapse>

## 실습 — 유동적인 제목 크기 만들기

화면이 작을 땐 `1.25rem`, 클 땐 `2.5rem`이고 그 사이는 뷰포트 너비의 `5vw`에 비례해서 커지는 제목 스타일을 `clamp()`로 만들어보자.

```css
.title {
  font-size: /* 여기를 채워보자 */;
}
```

<Collapse title="정답 보기">

```css
.title {
  font-size: clamp(1.25rem, 5vw, 2.5rem);
}
```

브라우저 창 크기를 좁혔다 넓혔다 하면서 글자 크기가 부드럽게 바뀌는지 직접 확인해 보자.
</Collapse>
