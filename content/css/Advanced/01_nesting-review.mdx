## 실습 — 반복되는 CSS를 중첩으로 리팩터링하기

아래 CSS를 네이티브 중첩을 써서 다시 써보자.

```css
.card { padding: 1rem; border: 1px solid #ddd; }
.card h2 { font-size: 1.5rem; }
.card p { color: gray; }
.card:hover { box-shadow: 0 2px 8px rgb(0 0 0 / 0.15); }
```

<Collapse title="정답 보기">

```css
.card {
  padding: 1rem;
  border: 1px solid #ddd;

  h2 { font-size: 1.5rem; }
  p  { color: gray; }

  &:hover { box-shadow: 0 2px 8px rgb(0 0 0 / 0.15); }
}
```

</Collapse>

## 정리 체크리스트

<Callout type="default">
- [ ] `&`가 부모 선택자 자리에 대입된다는 걸 안다
- [ ] Sass와 다른 점(문자열 결합 불가)을 설명할 수 있다
- [ ] 반복되는 CSS를 중첩으로 리팩터링할 수 있다
</Callout>
