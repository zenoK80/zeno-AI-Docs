## CSS 규칙의 구조

CSS의 가장 작은 단위는 **규칙(rule set)** 입니다. 규칙은 크게 **선택자(selector)** 와 **선언 블록(declaration block)** 으로 이루어집니다.

```css
h1 {              /* ← 선택자 (selector) */
  color: royalblue;  /* ← 선언 (declaration): 속성 + 값 */
  font-size: 2rem;
}                 /* 선언 블록은 { } 로 감쌉니다 */
```

각 구성 요소를 정리하면 다음과 같습니다.

- **선택자(selector)** — 스타일을 적용할 대상을 고릅니다. (위 예시의 `h1`)
- **선언 블록(declaration block)** — 중괄호 `{ }` 안에 하나 이상의 선언을 담습니다.
- **선언(declaration)** — `속성: 값;` 형태의 한 줄. (`color: royalblue;`)
- **속성(property)** — 바꾸려는 스타일의 종류. (`color`, `font-size`)
- **값(value)** — 속성에 부여할 실제 값. (`royalblue`, `2rem`)

<Callout type="warning">
  각 선언은 **세미콜론(`;`)** 으로 끝냅니다. 마지막 선언의 세미콜론은 생략해도 동작하지만, 나중에 줄을 추가할 때 실수를 줄이려면 **항상 붙이는 습관**을 권합니다.
</Callout>

여러 선택자에 같은 스타일을 주려면 쉼표로 묶습니다.

```css
h1,
h2,
h3 {
  font-family: sans-serif;
  line-height: 1.2;
}
```

## 주석

주석은 `/* */` 로 감쌉니다. 한 줄이든 여러 줄이든 동일하며, `//` 같은 한 줄 주석 문법은 CSS에 없습니다.

```css
/* 이건 주석입니다 */
.button {
  padding: 0.5rem 1rem; /* 상하 0.5rem, 좌우 1rem */
}
```

## 공백과 대소문자

- **공백·줄바꿈은 자유롭습니다.** 가독성을 위해 들여쓰기와 줄바꿈을 넣어도 결과는 같습니다.
- **선택자와 속성명은 대소문자를 구분하지 않습니다.** 다만 관례적으로 소문자를 씁니다.
- **값 중 일부는 대소문자를 구분합니다.** 예를 들어 클래스명·`font-family`의 폰트 이름, `content`의 문자열 등은 대소문자가 의미를 가집니다.

## CSS를 문서에 적용하는 3가지 방법

HTML에 CSS를 연결하는 방법은 크게 세 가지입니다.

<Tabs items={['외부 스타일 (권장)', '내부 스타일', '인라인 스타일']}>
  <Tabs.Tab>
    별도의 `.css` 파일을 만들어 `<link>` 로 연결합니다. 여러 페이지가 스타일을 공유할 수 있고 캐시도 잘 되어, **실무에서 가장 권장되는 방식**입니다.

    ```html
    <!-- index.html -->
    <head>
      <link rel="stylesheet" href="styles.css" />
    </head>
    ```

    ```css
    /* styles.css */
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
    }
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    HTML 문서의 `<head>` 안 `<style>` 태그에 직접 작성합니다. 그 **문서 하나에만** 적용됩니다. 단일 페이지나 빠른 실험에 쓸 수 있습니다.

    ```html
    <head>
      <style>
        body {
          background: #f5f5f5;
        }
      </style>
    </head>
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    요소의 `style` 속성에 직접 선언을 씁니다. **해당 요소 하나에만** 적용됩니다.

    ```html
    <p style="color: crimson; font-weight: bold;">중요한 문장</p>
    ```

    간편하지만 재사용이 안 되고 명시도가 매우 높아 유지보수를 어렵게 만듭니다. 되도록 피하는 것이 좋습니다.
  </Tabs.Tab>
</Tabs>

<Callout type="info">
  세 방식은 **명시도(specificity)와 우선순위**가 다릅니다. 대략 인라인 > 내부·외부(작성 순서와 명시도에 따름) 순으로 강하게 적용됩니다. 우선순위의 정확한 규칙은 03장(캐스케이드·명시도·상속)에서 다룹니다.
</Callout>

## @import 로 다른 스타일시트 불러오기

`@import` 는 하나의 CSS 안에서 다른 CSS 파일을 불러올 때 씁니다. CSS를 주제별 파일로 나눠 관리할 때 유용합니다.

```css
/* main.css */
@import "reset.css";
@import "typography.css";
```

조건을 붙여 특정 상황에만 불러올 수도 있습니다.

```css
/* 화면 너비가 넓을 때만 불러오기 */
@import "wide.css" (min-width: 60rem);

/* 특정 기능을 지원할 때만 불러오기 */
@import "grid.css" supports(display: grid);

/* 캐스케이드 레이어로 불러오기 (04장 참고) */
@import "components.css" layer(components);
```

<Callout type="warning">
  **`@import` 는 규칙**이 있습니다.

  - 스타일시트의 **가장 위**에 와야 합니다. (`@charset`, `@layer` 선언을 제외한 다른 규칙보다 앞) 그렇지 않으면 무시됩니다.
  - **성능상 주의**가 필요합니다. `@import` 는 파일을 순차적으로 요청하게 만들어(요청 체인) 로딩을 느리게 할 수 있습니다. 성능이 중요한 실무에서는 여러 개의 `<link>` 를 쓰거나 빌드 단계에서 하나로 합치는(번들링) 방식이 더 유리한 경우가 많습니다.
</Callout>

## 어떤 방법을 언제 쓸까

- **외부 스타일 (`<link>`)** — 대부분의 상황에서 기본 선택. 캐시·재사용·유지보수에 유리합니다.
- **내부 스타일 (`<style>`)** — 단일 페이지, 데모, 이메일 템플릿, 또는 첫 화면에 필요한 최소 스타일(critical CSS)을 인라인할 때.
- **인라인 스타일 (`style=`)** — 자바스크립트로 값을 동적으로 계산해 넣는 경우 등 예외적으로. 정적 스타일에는 피합니다.
- **`@import`** — CSS 내부에서 파일을 조직화하거나 조건부로 불러올 때. 단, 성능 트레이드오프를 염두에 둡니다.
