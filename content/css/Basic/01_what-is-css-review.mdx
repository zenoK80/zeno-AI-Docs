## 실습 — 적용되지 않는 스타일 설명하기

다음 HTML과 CSS에서 문단이 왜 파란색인지 설명하고, `!important` 없이 빨간색으로 바꿔 보자.

```html
<p id="intro">CSS 복습</p>
```

```css
#intro { color: blue; }
p { color: red; }
```

<Collapse title="예시 답안 보기">
`#intro`의 명시도가 `p`보다 높아 파란색이 적용된다. 같은 ID 선택자를 사용해 뒤에서 덮어쓸 수 있다.

```css
#intro { color: blue; }
#intro { color: red; }
```

실제 코드에서는 불필요하게 강한 선택자를 계속 추가하기보다 처음의 선택자 설계도 함께 점검한다.
</Collapse>
