## 01편 복습

코드를 보지 않고 CSS가 누구에게 무엇을 적용하는 언어인지 먼저 설명해 보자.

## 핵심 퀴즈

**Q1. `h1 { color: navy; }`에서 선택자, 속성, 값은 각각 무엇인가?**

<Collapse title="정답 보기">
선택자는 `h1`, 속성은 `color`, 값은 `navy`다.
</Collapse>

**Q2. HTML과 CSS를 분리하면 어떤 점이 좋아지는가?**

<Collapse title="정답 보기">
문서의 구조와 표현을 독립적으로 수정할 수 있어 중복이 줄고, 사이트 전체 스타일을 한곳에서 일관되게 관리할 수 있다.
</Collapse>

**Q3. 브라우저가 DOM과 CSSOM을 만든 다음 거치는 주요 단계는 무엇인가?**

<Collapse title="정답 보기">
두 트리를 바탕으로 렌더 트리를 만들고, 레이아웃으로 위치와 크기를 계산한 뒤 페인트 단계에서 픽셀을 그린다.
</Collapse>

**Q4. 나중에 작성한 `p` 규칙이 앞의 `#intro` 규칙을 이기지 못할 수 있는 이유는 무엇인가?**

<Collapse title="정답 보기">
캐스케이드에서는 작성 순서뿐 아니라 명시도 등도 비교한다. ID 선택자 `#intro`가 요소 선택자 `p`보다 명시도가 높다.
</Collapse>

## 실습 — 적용되지 않는 스타일 설명하기

다음 HTML과 CSS에서 문단이 왜 파란색인지 설명하고, `!important` 없이 빨간색으로 바꿔 보자.

```html
<p id="intro">CSS 복습</p>
```

```css
#intro { color: blue; }
p { color: red; }
```

<Collapse title="예시 답안 보기">
`#intro`의 명시도가 `p`보다 높아 파란색이 적용된다. 같은 ID 선택자를 사용해 뒤에서 덮어쓸 수 있다.

```css
#intro { color: blue; }
#intro { color: red; }
```

실제 코드에서는 불필요하게 강한 선택자를 계속 추가하기보다 처음의 선택자 설계도 함께 점검한다.
</Collapse>
