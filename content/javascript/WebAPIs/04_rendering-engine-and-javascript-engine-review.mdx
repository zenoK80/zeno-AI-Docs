## 실습 — 메인 스레드 블로킹 재현하기

```html
<button id="btn">3초 멈추기</button>
<input placeholder="여기 타이핑 해보세요" />
```

```js
document.querySelector('#btn').addEventListener('click', () => {
  const start = Date.now()
  while (Date.now() - start < 3000) {}
  console.log('끝')
})
```

<Steps>

### 버튼을 누르기 전에 먼저 입력창에 타이핑해 본다

잘 입력되는 걸 확인한다.

### 버튼을 누르고, 3초 안에 입력창에 다시 타이핑해 본다

무슨 일이 일어나는지 관찰한다.

### 왜 이런 일이 일어나는지 이 편의 내용으로 설명해 본다

</Steps>

<Collapse title="예상 결과">
3초 동안 입력창이 먹통이 된다. `while` 반복문이 메인 스레드를 붙잡고 있어서, 사용자 입력에 반응하는 코드도 순서를 기다려야 하기 때문이다.
</Collapse>
