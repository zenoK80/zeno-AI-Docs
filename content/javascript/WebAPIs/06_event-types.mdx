## 마우스 이벤트

```js
const box = document.querySelector('.box')

box.addEventListener('click', (e) => console.log('클릭', e.clientX, e.clientY))
box.addEventListener('dblclick', () => console.log('더블 클릭'))
box.addEventListener('mouseenter', () => console.log('마우스 진입'))
box.addEventListener('mouseleave', () => console.log('마우스 이탈'))
box.addEventListener('mousemove', (e) => console.log(e.offsetX, e.offsetY))
box.addEventListener('contextmenu', (e) => {
  e.preventDefault()  // 우클릭 메뉴 방지
  console.log('우클릭')
})
```

| 이벤트 | 설명 |
| --- | --- |
| click | 클릭 |
| dblclick | 더블 클릭 |
| mouseenter | 요소 진입 (버블링 없음) |
| mouseleave | 요소 이탈 (버블링 없음) |
| mouseover | 요소 진입 (버블링 있음) |
| mouseout | 요소 이탈 (버블링 있음) |
| mousemove | 마우스 이동 |

## 폼 이벤트

```js
const form = document.querySelector('form')
const emailInput = document.querySelector('#email')

form.addEventListener('submit', (e) => {
  e.preventDefault()   // 기본 폼 제출 방지
  const data = new FormData(form)
  console.log(data.get('email'))
})

emailInput.addEventListener('input', (e) => {
  console.log('현재 값:', e.target.value)  // 매 입력 마다
})

emailInput.addEventListener('change', (e) => {
  console.log('변경 완료:', e.target.value)  // 포커스 잃을 때
})

emailInput.addEventListener('focus', () => console.log('포커스 얻음'))
emailInput.addEventListener('blur', () => console.log('포커스 잃음'))
```

## 로드 이벤트

```js
// DOM 파싱 완료
document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM 준비됨')
  // 이미지/스타일시트는 아직 로딩 중일 수 있음
})

// 모든 리소스 로딩 완료
window.addEventListener('load', () => {
  console.log('페이지 완전 로딩')
})

// 페이지 떠날 때
window.addEventListener('beforeunload', (e) => {
  e.preventDefault()
  e.returnValue = ''  // 확인 대화상자 표시
})
```

## 스크롤 이벤트

```js
window.addEventListener('scroll', () => {
  const scrollY = window.scrollY
  const scrollHeight = document.documentElement.scrollHeight
  const clientHeight = window.innerHeight
  const progress = scrollY / (scrollHeight - clientHeight) * 100

  console.log(`스크롤 진행률: ${progress.toFixed(1)}%`)
})
```

<Callout type="warning">
  스크롤 이벤트는 매우 빈번하게 발생합니다. 성능을 위해 `requestAnimationFrame`이나 `IntersectionObserver`를 고려하세요.
</Callout>

## 포인터 이벤트 (Pointer Events)

마우스와 터치를 통합한 최신 API입니다.

```js
const canvas = document.querySelector('canvas')

canvas.addEventListener('pointerdown', (e) => {
  console.log('포인터 타입:', e.pointerType)  // 'mouse', 'touch', 'pen'
  console.log('압력:', e.pressure)
})
```

## 핵심 정리

- 마우스 이벤트는 click, mouseenter/leave, mousemove 등이 있습니다.
- 키보드 이벤트에서 `e.key`는 문자, `e.code`는 물리적 키 위치입니다.
- 폼에서 `input`은 매 입력마다, `change`는 포커스를 잃을 때 발생합니다.
- `DOMContentLoaded`는 DOM 파싱 완료, `load`는 모든 리소스 로딩 완료 시 발생합니다.
