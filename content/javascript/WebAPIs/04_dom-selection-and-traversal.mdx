## querySelector / querySelectorAll — CSS 선택자로 찾기

가장 널리 쓰이는 방법입니다. CSS에서 쓰는 선택자 문법을 그대로 사용합니다.

```js
// 첫 번째로 일치하는 요소 하나
const title = document.querySelector('.title')
const container = document.querySelector('#container')
const firstP = document.querySelector('p')

// 일치하는 모든 요소 (NodeList로 반환)
const allItems = document.querySelectorAll('li')
allItems.forEach(item => console.log(item.textContent))
```

CSS를 배운 적이 있다면 `.클래스`, `#아이디`, `태그명`, `div > p`(자식 결합자) 같은 문법을 그대로 재사용할 수 있어 매우 유연합니다.

## getElementById, getElementsByClassName — 예전부터 있던 방법

```js
const el = document.getElementById('container')  // ID 전용, 매우 빠름
const byClass = document.getElementsByClassName('title')  // HTMLCollection 반환
const byTag = document.getElementsByTagName('p')           // HTMLCollection 반환
```

## 살아있는 컬렉션(Live Collection) vs 정적 컬렉션(Static Collection)

이것이 자주 놓치는 함정입니다. `getElementsByClassName`, `getElementsByTagName`이 반환하는 **HTMLCollection**은 **살아있는**(live) **컬렉션**입니다. DOM이 변경되면 이 컬렉션도 **자동으로 즉시 갱신**됩니다. 반면 `querySelectorAll`이 반환하는 **NodeList**는 만들어진 시점의 스냅샷으로 고정된 **정적**(static) **컬렉션**입니다.

<Callout type="warning">
  live 컬렉션을 `for` 반복문 안에서 요소를 추가·삭제하며 순회하면, 컬렉션 길이가 실시간으로 바뀌어 예상치 못한 무한 루프나 요소 누락이 생길 수 있습니다. 순회 중 DOM을 변경할 계획이라면 `querySelectorAll`(정적)을 쓰거나, 배열로 미리 복사([...collection])한 뒤 순회하는 것이 안전합니다.
</Callout>

## 노드 탐색 — 부모, 자식, 형제

찾은 요소를 기준으로 주변 노드로 이동할 수 있습니다.

```js
const container = document.querySelector('#container')

// 부모
console.log(container.parentElement.tagName)

// 자식
console.log(container.children.length)          // 자식 "요소"의 개수(텍스트 노드 제외)
console.log(container.firstElementChild.tagName) // 첫 번째 자식 요소
console.log(container.lastElementChild.tagName)  // 마지막 자식 요소

// 형제
const title = document.querySelector('.title')
console.log(title.nextElementSibling.textContent) // 다음 형제 요소
console.log(title.previousElementSibling)          // 이전 형제 요소(없으면 null)
```

## children vs childNodes — 자주 헷갈리는 짝

02번 문서에서 배운 노드 종류를 떠올려봅시다. `<div>제목<span>내용</span></div>`처럼 요소와 텍스트가 섞여 있으면 두 프로퍼티의 결과가 다릅니다.

```js
// container 내부: 텍스트 '제목' + <span>내용</span> 요소
console.log(container.children)    // [span] — 요소 노드만
console.log(container.childNodes)  // [텍스트 "제목", span] — 텍스트 노드까지 모두 포함
```

## closest — 조상 탐색

현재 요소에서 시작해 DOM 위로 올라가며 CSS 선택자에 맞는 가장 가까운 조상을 찾습니다.

```js
const button = document.querySelector('button')
const form = button.closest('form')   // 가장 가까운 form 조상 (여러 단계 위여도 찾음)
```

`closest`는 08번 문서(이벤트 위임)에서 클릭된 요소가 특정 부모 안에 있는지 확인할 때 매우 자주 쓰이는 실전 패턴입니다.

## matches — 선택자 일치 확인

```js
const el = document.querySelector('p')
console.log(el.matches('.active'))   // true/false — el이 .active 선택자에 맞는지
```

## 핵심 정리

- querySelector/querySelectorAll은 CSS 선택자로 유연하게 요소를 찾는다.
- getElementsByClassName 등이 반환하는 HTMLCollection은 live(자동 갱신), querySelectorAll의 NodeList는 static(고정)이다.
- children은 요소 노드만, childNodes는 텍스트 노드까지 포함한다.
- closest(선택자)는 조상 방향으로, nextElementSibling은 형제 방향으로 탐색한다.
- 이름에 Element가 붙은 탐색 프로퍼티는 요소 노드만 대상으로 한다.
