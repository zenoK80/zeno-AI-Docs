## IntersectionObserver란?

특정 요소가 **뷰포트**(화면에 보이는 영역, 08번 문서에서 배운 개념과 연결)나 다른 요소 안으로 진입·이탈할 때 콜백을 호출합니다. 08번 문서에서 배운 scroll 이벤트로 직접 위치를 계산하는 대신, 브라우저가 최적화해서 처리해줍니다.

```js
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      console.log('화면에 보입니다:', entry.target)
    } else {
      console.log('화면에서 벗어났습니다:', entry.target)
    }
  })
})

const target = document.querySelector('.watch-me')
observer.observe(target)

observer.unobserve(target)  // 특정 대상만 감시 중단
observer.disconnect()        // 모든 감시 중단
```

## 옵션 — threshold와 rootMargin

```js
const observer = new IntersectionObserver(callback, {
  root: null,              // null이면 뷰포트, 특정 요소를 넣으면 그 요소 내부 기준
  rootMargin: '0px',       // 감시 영역을 CSS margin 형식으로 확장/축소
  threshold: [0, 0.5, 1],  // 0%, 50%, 100% 교차할 때마다 콜백 실행
})
```

## 실전 활용 — 이미지 지연 로딩(Lazy Loading)

```html
<img data-src="/large-image.jpg" alt="지연 로딩 이미지" class="lazy">
```

```js
const lazyObserver = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      const img = entry.target
      img.src = img.dataset.src   // 실제로 화면에 보일 때만 이미지 로드
      img.classList.remove('lazy')
      lazyObserver.unobserve(img) // 로드 후에는 더 이상 감시할 필요 없음
    }
  })
}, { rootMargin: '200px' })  // 화면에 닿기 200px 전에 미리 로딩 시작

document.querySelectorAll('img.lazy').forEach(img => lazyObserver.observe(img))
```

`rootMargin: '200px'`로 감시 영역을 실제 화면보다 살짝 넓혀두면, 사용자가 스크롤해서 도착하기 **직전에** 이미지가 준비되어 있어 로딩 지연이 덜 느껴집니다.

## ResizeObserver — 요소 크기 변화 감지

**ResizeObserver**는 특정 요소의 **크기가 바뀔 때마다** 콜백을 실행합니다. 브라우저 창 크기 변화(`window.resize` 이벤트)와 달리, **특정 요소 하나**의 크기 변화(부모 레이아웃 변경, 내용물 증가 등으로 인한)를 감지할 수 있습니다.

```js
const box = document.querySelector('.resizable-box')

const resizeObserver = new ResizeObserver((entries) => {
  entries.forEach((entry) => {
    const { width, height } = entry.contentRect
    console.log(`크기 변경: ${width.toFixed(0)} x ${height.toFixed(0)}`)
  })
})

resizeObserver.observe(box)
```

<Callout type="warning">
  `window.addEventListener('resize', ...)`는 **브라우저 창 전체**의 크기가 바뀔 때만 발생합니다. 특정 요소가 내용물 증가나 CSS 변화로 커지는 것은 감지하지 못합니다. 반응형 차트 라이브러리나 컨테이너 쿼리 같은 기능을 직접 구현할 때는 `ResizeObserver`가 필요합니다.
</Callout>

## 핵심 정리

- IntersectionObserver는 요소의 뷰포트 진입/이탈을 scroll 이벤트보다 효율적으로 감지한다.
- threshold로 교차 비율 기준을, rootMargin으로 감시 영역 확장을 설정한다.
- 이미지 지연 로딩은 IntersectionObserver의 대표적인 실전 활용이다.
- ResizeObserver는 window.resize와 달리 특정 요소 자체의 크기 변화를 감지한다.
