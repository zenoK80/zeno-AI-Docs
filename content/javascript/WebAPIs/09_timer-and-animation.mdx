## setTimeout — 지연 실행

지정한 시간(밀리초) 후 함수를 한 번 실행합니다.

```js
const timerId = setTimeout(() => {
  console.log('1초 후 실행')
}, 1000)

// 실행 전 취소
clearTimeout(timerId)
```

## setInterval — 반복 실행

지정한 시간마다 함수를 반복 실행합니다.

```js
let count = 0
const intervalId = setInterval(() => {
  count++
  console.log(`${count}초 경과`)
  if (count >= 5) {
    clearInterval(intervalId)  // 5번 후 중단
  }
}, 1000)
```

<Callout type="warning">
  `setInterval`은 이전 실행이 완료되지 않아도 다음 실행을 예약합니다. 실행 시간이 지연 간격보다 길어지면 쌓일 수 있습니다. 이런 경우 `setTimeout` 재귀 호출 패턴이 더 안전합니다.
</Callout>

## setTimeout 재귀 패턴

```js
function tick() {
  // 작업 수행
  console.log('작업 실행')

  setTimeout(tick, 1000)  // 완료 후 다음 예약
}

setTimeout(tick, 1000)  // 시작
```

## setTimeout vs setInterval vs requestAnimationFrame

| | setTimeout | setInterval | requestAnimationFrame |
| --- | --- | --- | --- |
| 실행 횟수 | 1회 | 반복 | 반복 (화면 갱신과 동기) |
| 적합한 용도 | 지연 실행 | 주기적 작업 | 애니메이션 |
| 정확성 | 낮음 | 낮음 | 높음 (60fps) |
| 탭 비활성화 | 실행 유지 | 실행 유지 | 일시정지 |

## cancelAnimationFrame

```js
const rafId = requestAnimationFrame(animate)
cancelAnimationFrame(rafId)  // 취소
```

## 타임스탬프 활용

`requestAnimationFrame`의 콜백은 타임스탬프를 받아 경과 시간 기반 애니메이션을 만들 수 있습니다.

```js
let start = null

function animate(timestamp) {
  if (!start) start = timestamp
  const elapsed = timestamp - start  // 경과 시간(ms)
  const progress = Math.min(elapsed / 2000, 1)  // 2초 동안 0→1

  box.style.opacity = progress
  box.style.transform = `translateX(${progress * 200}px)`

  if (progress < 1) {
    requestAnimationFrame(animate)
  }
}

requestAnimationFrame(animate)
```

## 핵심 정리

- `setTimeout`은 지연 후 1회, `setInterval`은 반복 실행합니다.
- 애니메이션에는 `requestAnimationFrame`을 사용하세요. 화면 갱신과 동기화되어 부드러운 애니메이션을 만듭니다.
- 탭이 비활성화되면 `requestAnimationFrame`은 자동으로 일시정지됩니다.
