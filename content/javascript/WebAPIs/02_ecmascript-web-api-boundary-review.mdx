## 실습 — 환경 판별 코드 짜보기

아래 함수를 완성해 보자. 브라우저면 `'브라우저'`를, 아니면 `'브라우저 아님'`을 반환해야 한다.

```js
function whichEnvironment() {
  // 여기를 채워보자
}

console.log(whichEnvironment())
```

<Collapse title="정답 예시">

```js
function whichEnvironment() {
  if (typeof window !== 'undefined') {
    return '브라우저'
  }
  return '브라우저 아님'
}
```

브라우저 콘솔에서 실행하면 `'브라우저'`, Node.js에서 실행하면 `'브라우저 아님'`이 나오는지 두 곳 다 직접 확인해 보자.
</Collapse>
