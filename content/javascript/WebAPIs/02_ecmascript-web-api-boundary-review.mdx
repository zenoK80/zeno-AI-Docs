## 02편 복습

## 핵심 퀴즈

**Q1. 브라우저와 Node.js에서 `setTimeout`의 반환값 타입이 다른 이유는?**

<Collapse title="정답 보기">
`setTimeout` 자체가 ECMAScript 명세에 없는 호스트 API라서, 각 실행 환경이 반환값을 어떻게 표현할지는 각자 자유이기 때문이다.
</Collapse>

**Q2. 여러 환경에서 동작해야 하는 코드를 뭐라고 부르나?**

<Collapse title="정답 보기">
유니버설 코드(Universal Code) 또는 아이소몰픽 코드(Isomorphic Code).
</Collapse>

**Q3. 지금 실행 중인 코드가 브라우저인지 확인하는 흔한 패턴은?**

<Collapse title="정답 보기">
`typeof window !== 'undefined'` — window는 브라우저에만 있는 이름이므로, 이 존재 여부로 환경을 판별한다.
</Collapse>

## 실습 — 환경 판별 코드 짜보기

아래 함수를 완성해 보자. 브라우저면 `'브라우저'`를, 아니면 `'브라우저 아님'`을 반환해야 한다.

```js
function whichEnvironment() {
  // 여기를 채워보자
}

console.log(whichEnvironment())
```

<Collapse title="정답 예시">

```js
function whichEnvironment() {
  if (typeof window !== 'undefined') {
    return '브라우저'
  }
  return '브라우저 아님'
}
```

브라우저 콘솔에서 실행하면 `'브라우저'`, Node.js에서 실행하면 `'브라우저 아님'`이 나오는지 두 곳 다 직접 확인해 보자.
</Collapse>
