## Clipboard API — 클립보드 복사

"복사되었습니다" 버튼을 만들 때 사용합니다.

<CodePlayground
  template="vanilla"
  activeFile="/index.js"
  showConsole
  label="클립보드 복사 실습"
  files={{
    '/index.html': `<input id="code" value="EXAMPLE-COUPON-1234" readonly />
<button id="copy">복사하기</button>
<script src="/index.js"></script>`,
    '/index.js': `document.querySelector('#copy').addEventListener('click', async () => {
  const code = document.querySelector('#code').value
  try {
    await navigator.clipboard.writeText(code)
    console.log('복사 완료:', code)
  } catch (err) {
    console.error('복사 실패:', err)
  }
})`,
  }}
/>

`navigator.clipboard.writeText()`는 Promise를 반환하는 비동기 API입니다(ECMAScript 28번 문서 참고). 클립보드는 민감한 사용자 데이터에 접근하는 기능이라, **HTTPS 환경**과 **사용자의 직접적인 상호작용**(버튼 클릭 등) 없이는 대부분 브라우저가 호출을 거부합니다.

## 클립보드 읽기

```js
async function pasteFromClipboard() {
  try {
    const text = await navigator.clipboard.readText()
    console.log('클립보드 내용:', text)
  } catch (err) {
    console.error('읽기 실패 — 권한이 필요합니다:', err)
  }
}
```

<Callout type="warning">
  클립보드 **읽기**(`readText`)는 쓰기보다 더 엄격하게 제한됩니다. 사용자가 명시적으로 권한을 허용해야 하며, 악의적인 사이트가 사용자 모르게 클립보드 내용(비밀번호 등)을 훔쳐보지 못하도록 하는 보안 장치입니다.
</Callout>

## Drag and Drop API — 파일을 끌어다 놓기

파일 업로드 UI에서 자주 보는 "여기에 파일을 끌어다 놓으세요" 기능입니다.

<CodePlayground
  template="vanilla"
  activeFile="/index.js"
  label="Drag and Drop 실습 — 파일을 끌어다 놓아보세요"
  files={{
    '/index.html': `<div id="drop-zone" style="width:100%;height:150px;border:2px dashed #999;display:flex;align-items:center;justify-content:center;">
  여기에 파일을 끌어다 놓으세요
</div>
<div id="result"></div>
<script src="/index.js"></script>`,
    '/index.js': `const dropZone = document.querySelector('#drop-zone')
const result = document.querySelector('#result')

// dragover에서 반드시 preventDefault를 호출해야 drop 이벤트가 발생함
dropZone.addEventListener('dragover', (e) => {
  e.preventDefault()
  dropZone.style.borderColor = 'crimson'
})

dropZone.addEventListener('dragleave', () => {
  dropZone.style.borderColor = '#999'
})

dropZone.addEventListener('drop', (e) => {
  e.preventDefault()
  dropZone.style.borderColor = '#999'

  const files = e.dataTransfer.files
  result.textContent = '받은 파일: ' + [...files].map(f => f.name).join(', ')
})`,
  }}
/>

## dragover에서 preventDefault가 필요한 이유

<Callout type="warning">
  브라우저의 **기본 동작은 드롭을 거부**하는 것입니다(파일을 끌어다 놓으면 새 탭에서 파일이 열리는 것이 기본 동작). `dragover` 이벤트에서 `e.preventDefault()`를 호출하지 않으면, `drop` 이벤트 자체가 아예 발생하지 않습니다. 이 한 줄을 빠뜨리는 것이 드래그 앤 드롭 구현에서 가장 흔한 실수입니다.
</Callout>

## dataTransfer — 드래그되는 데이터 담기

```js
// 요소 자체를 드래그 가능하게 만들기(HTML 요소 사이의 드래그)
const item = document.querySelector('.draggable')
item.setAttribute('draggable', 'true')

item.addEventListener('dragstart', (e) => {
  e.dataTransfer.setData('text/plain', item.id)  // 드래그할 데이터 담기
})

const target = document.querySelector('.drop-target')
target.addEventListener('drop', (e) => {
  e.preventDefault()
  const draggedId = e.dataTransfer.getData('text/plain')
  console.log('드래그된 요소 ID:', draggedId)
})
```

`e.dataTransfer`는 드래그 중인 데이터를 담는 특별한 객체로, 파일뿐 아니라 텍스트나 요소 ID 같은 임의의 데이터도 실어 나를 수 있습니다.

## 핵심 정리

- Clipboard API는 비동기(Promise) 방식이며, HTTPS와 사용자 상호작용이 있어야 대부분 동작한다.
- 클립보드 읽기는 쓰기보다 더 엄격한 권한이 필요한 보안 민감 기능이다.
- dragover 이벤트에서 preventDefault()를 호출하지 않으면 drop 이벤트가 아예 발생하지 않는다.
- e.dataTransfer로 파일뿐 아니라 텍스트, 요소 식별자 등 임의의 데이터를 드래그로 실어 나를 수 있다.
