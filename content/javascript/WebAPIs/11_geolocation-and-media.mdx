## Geolocation API

사용자의 위치 정보를 요청합니다. 사용자의 명시적 허가가 필요합니다.

```js
// 현재 위치 가져오기
navigator.geolocation.getCurrentPosition(
  (position) => {
    const { latitude, longitude, accuracy } = position.coords
    console.log(`위도: ${latitude}, 경도: ${longitude}`)
    console.log(`정확도: ${accuracy}m`)
    console.log(`시각: ${new Date(position.timestamp)}`)
  },
  (error) => {
    switch (error.code) {
      case error.PERMISSION_DENIED:
        console.error('위치 접근 권한이 거부되었습니다.')
        break
      case error.POSITION_UNAVAILABLE:
        console.error('위치 정보를 가져올 수 없습니다.')
        break
      case error.TIMEOUT:
        console.error('요청 시간이 초과되었습니다.')
        break
    }
  },
  {
    enableHighAccuracy: true,
    timeout: 5000,
    maximumAge: 0,
  }
)
```

## 위치 변화 감시

```js
const watchId = navigator.geolocation.watchPosition(
  (position) => {
    console.log('위치 변경:', position.coords)
  },
  (error) => console.error(error)
)

// 감시 중단
navigator.geolocation.clearWatch(watchId)
```

## MediaDevices API — 카메라/마이크

```js
async function startCamera() {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({
      video: { width: 1280, height: 720 },
      audio: true,
    })

    const video = document.querySelector('video')
    video.srcObject = stream
    await video.play()

    // 스트림 중단
    stream.getTracks().forEach(track => track.stop())
  } catch (err) {
    if (err.name === 'NotAllowedError') {
      console.error('카메라 권한이 거부되었습니다.')
    }
  }
}
```

## 기기 목록 조회

```js
const devices = await navigator.mediaDevices.enumerateDevices()
const cameras = devices.filter(d => d.kind === 'videoinput')
const mics = devices.filter(d => d.kind === 'audioinput')
console.log(`카메라 ${cameras.length}개, 마이크 ${mics.length}개`)
```

## FileReader 메서드

```js
const reader = new FileReader()

reader.readAsText(file)          // 텍스트로 읽기
reader.readAsDataURL(file)       // Data URL (base64)
reader.readAsArrayBuffer(file)   // ArrayBuffer (이진 데이터)

reader.onload = (e) => { /* e.target.result */ }
reader.onprogress = (e) => { /* e.loaded / e.total */ }
reader.onerror = (e) => { /* 오류 처리 */ }
```

## Drag and Drop

```js
const dropZone = document.querySelector('.drop-zone')

dropZone.addEventListener('dragover', (e) => {
  e.preventDefault()
  dropZone.classList.add('drag-over')
})

dropZone.addEventListener('drop', (e) => {
  e.preventDefault()
  dropZone.classList.remove('drag-over')

  const files = e.dataTransfer.files
  [...files].forEach(file => processFile(file))
})
```

## 핵심 정리

- Geolocation은 `navigator.geolocation.getCurrentPosition()`으로 위치를 요청하며 사용자 허가가 필요합니다.
- `navigator.mediaDevices.getUserMedia()`로 카메라/마이크 스트림을 얻습니다.
- `FileReader`로 파일을 읽고 `URL.createObjectURL()`로 미리보기를 만듭니다.
