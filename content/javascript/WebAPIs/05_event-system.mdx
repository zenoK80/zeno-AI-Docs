## 이벤트 등록 — addEventListener

```js
const button = document.querySelector('button')

function handleClick(event) {
  console.log('클릭됨', event.target)
}

button.addEventListener('click', handleClick)

// 이벤트 제거 (같은 함수 참조 필요)
button.removeEventListener('click', handleClick)
```

## 이벤트 객체 (Event)

핸들러 함수가 받는 이벤트 객체에는 다양한 정보가 담겨 있습니다.

```js
button.addEventListener('click', (event) => {
  console.log(event.type)       // 'click'
  console.log(event.target)     // 실제 클릭된 요소
  console.log(event.currentTarget) // 리스너가 등록된 요소
  console.log(event.clientX, event.clientY) // 클릭 좌표

  event.preventDefault()         // 기본 동작 취소
  event.stopPropagation()        // 버블링 중단
})
```

## 이벤트 전파 — 버블링과 캡처링

이벤트는 세 단계로 전파됩니다.

1. **캡처링 단계**: 최상위(`document`)에서 이벤트 발생 요소로 내려옵니다.
2. **타겟 단계**: 이벤트 발생 요소에서 처리합니다.
3. **버블링 단계**: 이벤트 발생 요소에서 최상위로 올라갑니다.

```js
const parent = document.querySelector('.parent')
const child = document.querySelector('.child')

// 버블링 단계 처리 (기본)
parent.addEventListener('click', () => console.log('parent 버블링'))
child.addEventListener('click', () => console.log('child 버블링'))
// child 클릭 시: child → parent 순으로 출력

// 캡처링 단계 처리 (세 번째 인수 true 또는 { capture: true })
parent.addEventListener('click', () => console.log('parent 캡처링'), true)
// child 클릭 시: parent 캡처링 → child 순으로 출력
```

## stopPropagation vs preventDefault

```js
// stopPropagation: 이벤트 전파(버블링/캡처링)를 중단
child.addEventListener('click', (e) => {
  e.stopPropagation()   // 부모로 버블링 안 됨
})

// preventDefault: 기본 동작만 취소 (전파는 계속)
const link = document.querySelector('a')
link.addEventListener('click', (e) => {
  e.preventDefault()    // 페이지 이동 취소
  // 버블링은 계속됨
})
```

## 이벤트 위임 (Event Delegation)

개별 요소가 아닌 부모에 리스너를 달고, 이벤트가 버블링될 때 `event.target`으로 구분합니다.

```js
const list = document.querySelector('ul')

list.addEventListener('click', (event) => {
  if (event.target.tagName === 'LI') {
    event.target.classList.toggle('done')
  }
  if (event.target.matches('.delete-btn')) {
    event.target.closest('li').remove()
  }
})
```

장점:
- 리스너 수가 적어 메모리 절약
- 동적으로 추가된 요소에도 자동 적용

## once 옵션 — 한 번만 실행

```js
button.addEventListener('click', handler, { once: true })
// 한 번 실행 후 자동으로 리스너 제거
```

## 커스텀 이벤트

```js
const myEvent = new CustomEvent('userLogin', {
  detail: { username: '철수' },
  bubbles: true,
})

document.dispatchEvent(myEvent)

document.addEventListener('userLogin', (e) => {
  console.log(e.detail.username)  // '철수'
})
```

## 핵심 정리

- `addEventListener(type, handler)`로 이벤트를 등록하고 `removeEventListener`로 제거합니다.
- 이벤트는 캡처링 → 타겟 → 버블링 순으로 전파됩니다.
- `stopPropagation()`은 전파를 중단하고, `preventDefault()`는 기본 동작을 취소합니다.
- 이벤트 위임으로 동적 요소를 효율적으로 처리합니다.
