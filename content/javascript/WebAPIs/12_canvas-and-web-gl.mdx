## Canvas 기본 설정

```html
<canvas id="canvas" width="600" height="400"></canvas>
```

```js
const canvas = document.querySelector('#canvas')
const ctx = canvas.getContext('2d')  // 2D 렌더링 컨텍스트
```

## 직사각형 그리기

```js
// 채운 직사각형
ctx.fillStyle = 'skyblue'
ctx.fillRect(50, 50, 200, 100)  // x, y, width, height

// 테두리 직사각형
ctx.strokeStyle = 'navy'
ctx.lineWidth = 3
ctx.strokeRect(300, 50, 200, 100)

// 지우기
ctx.clearRect(0, 0, canvas.width, canvas.height)
```

## 경로(Path) 그리기

```js
ctx.beginPath()
ctx.moveTo(100, 200)     // 시작점
ctx.lineTo(200, 100)     // 선 그리기
ctx.lineTo(300, 200)     // 계속
ctx.closePath()           // 시작점으로 닫기
ctx.fillStyle = 'coral'
ctx.fill()               // 채우기
ctx.strokeStyle = 'darkred'
ctx.stroke()             // 테두리 그리기
```

## 원 그리기 (arc)

```js
ctx.beginPath()
ctx.arc(
  300, 200,        // 중심 x, y
  80,              // 반지름
  0,               // 시작 각도 (라디안)
  Math.PI * 2,     // 끝 각도 (360도)
)
ctx.fillStyle = 'gold'
ctx.fill()
```

## 텍스트 그리기

```js
ctx.font = 'bold 32px sans-serif'
ctx.fillStyle = 'black'
ctx.textAlign = 'center'
ctx.textBaseline = 'middle'
ctx.fillText('Hello Canvas!', canvas.width / 2, canvas.height / 2)

// 테두리 텍스트
ctx.strokeStyle = 'red'
ctx.lineWidth = 1
ctx.strokeText('Hello!', 100, 100)
```

## 이미지 그리기

```js
const img = new Image()
img.onload = () => {
  // 원본 크기
  ctx.drawImage(img, 10, 10)

  // 크기 지정
  ctx.drawImage(img, 10, 10, 300, 200)

  // 소스 잘라내기 + 크기 지정
  // drawImage(img, sx, sy, sWidth, sHeight, dx, dy, dWidth, dHeight)
  ctx.drawImage(img, 0, 0, 100, 100, 200, 200, 200, 200)
}
img.src = '/image.png'
```

## 변환 (Transform)

```js
ctx.save()                          // 현재 상태 저장

ctx.translate(canvas.width / 2, canvas.height / 2)  // 원점 이동
ctx.rotate(Math.PI / 4)             // 45도 회전
ctx.scale(1.5, 1.5)                 // 1.5배 확대

ctx.fillRect(-50, -50, 100, 100)    // 원점 기준으로 그리기

ctx.restore()                       // 상태 복원
```

## 그라디언트

```js
// 선형 그라디언트
const gradient = ctx.createLinearGradient(0, 0, 600, 0)
gradient.addColorStop(0, 'red')
gradient.addColorStop(0.5, 'yellow')
gradient.addColorStop(1, 'blue')

ctx.fillStyle = gradient
ctx.fillRect(0, 0, 600, 100)

// 원형 그라디언트
const radial = ctx.createRadialGradient(300, 200, 10, 300, 200, 150)
radial.addColorStop(0, 'white')
radial.addColorStop(1, 'black')
```

## 핵심 정리

- `canvas.getContext('2d')`로 2D 컨텍스트를 얻습니다.
- `fillRect`, `strokeRect`로 직사각형을, `arc`로 원을, `beginPath` + `lineTo`로 경로를 그립니다.
- `save()`/`restore()`로 상태를 저장/복원해 변환을 안전하게 적용합니다.
- `drawImage()`로 이미지를 그리고 잘라낼 수 있습니다.
