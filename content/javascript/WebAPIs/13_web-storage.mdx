## localStorage — 영구 저장

탭이나 브라우저를 닫아도 데이터가 유지됩니다. 같은 출처(11번 문서에서 배운 개념)라면 모든 탭에서 공유됩니다.

    '/index.js': `document.querySelector('#save').addEventListener('click', () => {
  localStorage.setItem('theme', 'dark')
  localStorage.setItem('user', JSON.stringify({ name: '철수', age: 20 }))
  console.log('저장 완료')
})

document.querySelector('#load').addEventListener('click', () => {
  const theme = localStorage.getItem('theme')
  const user = JSON.parse(localStorage.getItem('user'))
  console.log('theme:', theme)
  console.log('user:', user)
})

document.querySelector('#remove').addEventListener('click', () => {
  localStorage.removeItem('theme')
  localStorage.clear()
  console.log('삭제 완료')
})`,
  }}
/>

<Callout type="warning">
  localStorage는 **문자열만** 저장할 수 있습니다. 객체는 `JSON.stringify()`로 직렬화해서 저장하고, 읽을 때 `JSON.parse()`로 역직렬화해야 합니다(ECMAScript 23번 문서 참고).
</Callout>

## sessionStorage — 탭 단위 저장

문법은 localStorage와 완전히 동일하지만, 탭(또는 창)을 닫으면 데이터가 사라집니다.

```js
sessionStorage.setItem('step', '2')
const step = sessionStorage.getItem('step')  // '2'
sessionStorage.removeItem('step')
```

## Cookie — 서버와 자동으로 오가는 유일한 저장소

```js
document.cookie = 'name=철수; expires=Fri, 31 Dec 2026 23:59:59 GMT; path=/'
document.cookie = 'lang=ko; max-age=86400; SameSite=Strict; Secure'

console.log(document.cookie)  // 'name=철수; lang=ko' — 모든 쿠키가 하나의 문자열로

function getCookie(name) {
  const cookies = document.cookie.split(';')
  for (const cookie of cookies) {
    const [key, value] = cookie.trim().split('=')
    if (key === name) return value
  }
  return null
}

document.cookie = 'name=; expires=Thu, 01 Jan 1970 00:00:00 GMT'  // 만료 시간을 과거로 설정해 삭제
```

쿠키의 가장 중요한 특징: **같은 도메인으로 보내는 모든 HTTP 요청에 자동으로 포함되어 전송됩니다.** 이 성질 때문에 로그인 세션 유지에 적합하지만, 동시에 CSRF 같은 공격의 대상이 되기도 합니다.

## 쿠키 속성으로 보안 강화하기

```
Set-Cookie: token=abc123;
  HttpOnly;         // JavaScript에서 document.cookie로 접근 불가(XSS 방어)
  Secure;           // HTTPS에서만 전송
  SameSite=Strict;  // 다른 사이트에서 오는 요청에는 포함 안 됨(CSRF 방어)
  Max-Age=3600;     // 1시간 후 만료
  Path=/api;        // 특정 경로에만 전송
```

<Callout type="warning">
  `HttpOnly` 쿠키는 JavaScript(`document.cookie`)로 **읽을 수도 쓸 수도 없습니다.** 서버만 설정·삭제할 수 있습니다. 인증 토큰처럼 민감한 값은 XSS 공격으로 훔쳐가지 못하도록 반드시 `HttpOnly`로 설정하는 것이 실무 표준입니다.
</Callout>

## storage 이벤트 — 다른 탭의 변경 감지

```js
window.addEventListener('storage', (event) => {
  console.log('변경된 키:', event.key)
  console.log('이전 값:', event.oldValue)
  console.log('새 값:', event.newValue)
})
```

**같은 출처의 다른 탭**에서 localStorage가 변경될 때만 현재 탭에서 발생합니다. 같은 탭 안에서 직접 변경한 경우에는 발생하지 않습니다. 여러 탭을 열어둔 사용자에게 "다른 탭에서 로그아웃하면 이 탭도 자동 로그아웃"같은 기능을 만들 때 사용합니다.

## 핵심 정리

- localStorage는 영구 저장, sessionStorage는 탭 단위 저장이며 둘 다 문자열만 저장하고 서버로 자동 전송되지 않는다.
- 쿠키는 용량이 작지만 모든 HTTP 요청에 자동 포함되어 서버 인증에 적합하다.
- HttpOnly 쿠키는 JavaScript로 접근할 수 없어 XSS 공격을 방어하고, SameSite는 CSRF를 방어한다.
- storage 이벤트는 같은 출처의 "다른 탭"에서 localStorage가 변경될 때만 발생한다.
