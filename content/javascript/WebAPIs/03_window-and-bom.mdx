## DOM과 BOM의 차이

02번 문서에서 배운 DOM은 **문서**(HTML 내용)**를 다룹니다**. 반면 **BOM**(Browser Object Model, 브라우저 객체 모델)은 **브라우저 자체**(주소창, 탭, 화면 크기, 방문 기록 등)를 다루는 객체들의 모음입니다.

  </thead>
  <tbody>
    <tr><td>다루는 대상</td><td>HTML 문서의 내용</td><td>브라우저 창·탭 자체</td></tr>

  </tbody>
</Table>

## window — 모든 것의 최상위 전역 객체

**`window`**는 브라우저가 제공하는 가장 바깥의 전역 객체입니다. 사실 지금까지 써온 `document`도 `window.document`의 줄임 표현이었습니다.

```js
console.log(window.document === document)  // true — 사실 window.을 생략하고 써온 것
console.log(window.innerWidth)    // 브라우저 창의 너비(픽셀)
console.log(window.innerHeight)   // 브라우저 창의 높이(픽셀)

window.alert('알림창')   // 그냥 alert('알림창')과 동일 — window는 생략 가능
```

<Callout type="warning">
  전역 스코프(ECMAScript 12번 문서)에서 선언한 변수는 사실 `window`의 프로퍼티가 됩니다. `var x = 1`은 `window.x = 1`과 같습니다(단, `let`/`const`는 예외적으로 window에 붙지 않습니다). 이 때문에 브라우저 환경의 "전역"은 결국 `window` 객체입니다.
</Callout>

## navigator — 브라우저와 기기 정보

```js
console.log(navigator.userAgent)   // 브라우저 종류·버전 정보 문자열
console.log(navigator.language)    // 'ko-KR' — 사용자 언어 설정
console.log(navigator.onLine)      // true/false — 현재 인터넷 연결 여부
console.log(navigator.geolocation) // 위치 정보 API 진입점(18번 문서에서 다룸)
```

## history — 방문 기록 이동

```js
history.back()      // 뒤로가기 (브라우저의 ← 버튼과 동일)
history.forward()   // 앞으로가기
history.go(-2)      // 2페이지 뒤로가기
```

`history` 객체로 페이지 이동 없이 방문 기록만 조작할 수도 있습니다. 이 내용은 14번 문서(History API)에서 더 깊게 다룹니다.

## window의 크기 관련 프로퍼티 정리

브라우저 화면 크기를 다루는 프로퍼티가 여러 개라 헷갈리기 쉽습니다.

<Table>
  <thead>
    <tr><th>프로퍼티</th><th>의미</th></tr>
  </thead>
  <tbody>
    <tr><td>window.innerWidth/Height</td><td>스크롤바를 포함한 브라우저 뷰포트(실제 콘텐츠가 보이는 영역) 크기</td></tr>
    <tr><td>window.outerWidth/Height</td><td>브라우저 창 전체(주소창, 탭 포함) 크기</td></tr>
    <tr><td>screen.width/height</td><td>사용자 모니터(화면) 전체 해상도</td></tr>
  </tbody>
</Table>

```js
console.log(window.innerWidth)   // 예: 1280 — 웹페이지가 실제로 보이는 너비
console.log(window.outerWidth)   // 예: 1300 — 브라우저 창 테두리까지 포함
console.log(screen.width)        // 예: 1920 — 모니터 전체 해상도
```

## alert, confirm, prompt — 브라우저 기본 대화상자

```js
alert('저장되었습니다')                     // 확인 버튼만 있는 알림창

const isOk = confirm('정말 삭제하시겠습니까?')  // 확인/취소 선택, boolean 반환
console.log(isOk)  // true 또는 false

const name = prompt('이름을 입력하세요', '기본값')  // 텍스트 입력, 문자열 또는 null 반환
console.log(name)
```

<Callout type="warning">
  `alert`, `confirm`, `prompt`는 호출되는 즉시 **자바스크립트 실행을 완전히 멈추고** 사용자가 응답할 때까지 기다립니다(30번 이벤트 루프 문서 관점에서 보면 이례적으로 동기적으로 블로킹합니다). 실무에서는 사용자 경험이 나빠 커스텀 모달 UI로 대체하는 것이 일반적입니다.
</Callout>

## 핵심 정리

- DOM은 문서 내용을, BOM은 브라우저 자체(창, 탭, 방문 기록 등)를 다룬다.
- window는 브라우저의 최상위 전역 객체이며, document도 사실 window.document의 줄임 표현이다.
- navigator는 브라우저·기기 정보를, location은 현재 URL을, history는 방문 기록을 다룬다.
- innerWidth는 콘텐츠 뷰포트, outerWidth는 브라우저 창 전체, screen.width는 모니터 해상도를 의미하며 서로 다르다.
- alert/confirm/prompt는 응답을 받을 때까지 실행을 멈추는 동기적 대화상자다.
