## Intersection Observer란

특정 요소가 **뷰포트**(화면에 보이는 영역)나 다른 요소 안으로 진입하거나 이탈할 때 콜백을 호출합니다. 스크롤 이벤트 대신 사용해 성능을 개선합니다.

## IntersectionObserverEntry 속성

```js
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    console.log(entry.isIntersecting)     // 교차 여부 (boolean)
    console.log(entry.intersectionRatio)  // 교차 비율 (0~1)
    console.log(entry.target)             // 감시 대상 요소
    console.log(entry.boundingClientRect) // 요소의 크기/위치
    console.log(entry.intersectionRect)   // 교차된 영역
    console.log(entry.rootBounds)         // 루트(뷰포트) 영역
  })
})
```

## 옵션 설정

```js
const observer = new IntersectionObserver(callback, {
  root: null,           // null이면 뷰포트 (또는 특정 요소 지정)
  rootMargin: '0px',    // 루트 영역 확장/축소 (CSS margin 형식)
  threshold: [0, 0.5, 1], // 0%, 50%, 100% 교차 시 콜백 호출
})
```

## 이미지 지연 로딩 (Lazy Loading)

```html
<img data-src="/large-image.jpg" alt="지연 로딩 이미지" class="lazy">
```

```js
const lazyObserver = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      const img = entry.target
      img.src = img.dataset.src   // 실제 이미지 로드
      img.classList.remove('lazy')
      lazyObserver.unobserve(img)  // 로드 후 감시 중단
    }
  })
}, {
  rootMargin: '200px',  // 200px 앞에서 미리 로딩
})

document.querySelectorAll('img.lazy').forEach(img => lazyObserver.observe(img))
```

## 무한 스크롤

```js
const sentinel = document.querySelector('#load-more')

const infiniteObserver = new IntersectionObserver(async (entries) => {
  if (entries[0].isIntersecting) {
    await loadMoreItems()
  }
})

infiniteObserver.observe(sentinel)

async function loadMoreItems() {
  const response = await fetch('/api/items?page=...')
  const items = await response.json()

  const list = document.querySelector('.list')
  items.forEach(item => {
    const li = document.createElement('li')
    li.textContent = item.name
    list.append(li)
  })
}
```

## 스크롤 애니메이션 트리거

```js
const animObserver = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate')
    }
  })
}, {
  threshold: 0.2,  // 20% 이상 보일 때 트리거
})

document.querySelectorAll('.animate-on-scroll').forEach(el => {
  animObserver.observe(el)
})
```

```css
.animate-on-scroll {
  opacity: 0;
  transform: translateY(20px);
  transition: opacity 0.5s, transform 0.5s;
}
.animate-on-scroll.animate {
  opacity: 1;
  transform: translateY(0);
}
```

## Intersection Observer vs 스크롤 이벤트

| | Intersection Observer | scroll 이벤트 |
| --- | --- | --- |
| 성능 | 브라우저가 최적화 | 잦은 호출로 부하 |
| 코드 복잡도 | 간단 | 복잡 (위치 계산 필요) |
| 정확도 | 높음 | 스로틀 필요 |

## 핵심 정리

- Intersection Observer로 요소의 뷰포트 진입/이탈을 효율적으로 감지합니다.
- 이미지 지연 로딩, 무한 스크롤, 스크롤 애니메이션에 활용합니다.
- `threshold` 옵션으로 교차 비율 기준을 설정합니다.
- `rootMargin`으로 미리 감지 영역을 확장할 수 있습니다.
