## 01편 복습

## 문제 1

Web API의 명세(공식 규격 문서)는 누가 관리하나?

<Quiz>
  <Quiz.Option>TC39</Quiz.Option>
  <Quiz.Option correct>WHATWG · W3C</Quiz.Option>
  <Quiz.Option>각 브라우저 회사가 마음대로 정한다</Quiz.Option>
  <Quiz.Option>정해진 관리 주체가 없다</Quiz.Option>

  <Quiz.Explanation>
  **WHATWG**와 **W3C**는 웹 표준을 정하는 단체 이름이다. 이들이 DOM, Fetch, HTML 같은 Web API의 규격을 관리한다. 반면 **TC39**는 자바스크립트 언어(ECMAScript) 규격을 관리하는 별도의 단체다. 관리하는 곳 자체가 다르다는 게 이 편의 핵심이었다 — 그래서 "언어인가, 브라우저가 주는 기능인가"를 구별할 때 "이 명세를 누가 관리하나"가 좋은 판별 기준이 된다.
  </Quiz.Explanation>
</Quiz>

## 문제 2

다음 중 Web API에 속하는 것을 모두 고른 조합은? (`fetch` / `class` / `localStorage` / `Map` / `addEventListener`)

<Quiz>
  <Quiz.Option>`fetch`, `class`, `Map`</Quiz.Option>
  <Quiz.Option correct>`fetch`, `localStorage`, `addEventListener`</Quiz.Option>
  <Quiz.Option>`class`, `Map`, `addEventListener`</Quiz.Option>
  <Quiz.Option>전부 다 Web API다</Quiz.Option>

  <Quiz.Explanation>
  `fetch`(서버에 요청 보내기), `localStorage`(브라우저에 데이터 저장하기), `addEventListener`(클릭 등 사용자 동작 감지하기)는 전부 브라우저가 추가로 얹어주는 Web API다. `class`(클래스 문법)와 `Map`(자료구조)은 언어(ECMAScript) 자체에 내장된 기능이라 Web API가 아니다.
  </Quiz.Explanation>
</Quiz>

## 문제 3

`setTimeout`, `fetch`처럼 Node.js에서도 쓸 수 있는 API를 이 시리즈(Web APIs)에서 다루는 이유는?

<Quiz>
  <Quiz.Option>Node.js에서도 쓸 수 있으니 사실 언어 자체 기능이기 때문에</Quiz.Option>
  <Quiz.Option correct>이들은 원래 브라우저(WHATWG) 명세의 API이고, Node.js가 나중에 가져다 구현한 것이기 때문에</Quiz.Option>
  <Quiz.Option>이름이 헷갈려서 그냥 편의상 여기서 다루는 것뿐, 원칙적으로는 언어 소속이 맞다</Quiz.Option>
  <Quiz.Option>Node.js가 이 API들을 처음 만들었고 브라우저가 나중에 따라 했기 때문에</Quiz.Option>

  <Quiz.Explanation>
  `fetch`나 `setTimeout`은 **원래 브라우저를 위해 만들어진 WHATWG 명세의 API**다. Node.js가 개발자 편의를 위해 나중에 자기 환경에도 비슷하게 구현해서 넣은 것이지, 그렇다고 해서 이 API들이 ECMAScript(언어) 소속으로 바뀌는 건 아니다. "출신 소속"이 기준이라는 점을 기억하자.
  </Quiz.Explanation>
</Quiz>

## 실습 — 판별 기준 적용해 보기

아래 목록을 보고, 배운 판별 기준(① Node.js에는 없는가? ② WHATWG·W3C 명세인가? ③ 렌더링·상호작용·네트워크 관련인가?)으로 Web API인지 언어인지 스스로 분류해 보자.

```
1. querySelector
2. Promise
3. JSON.parse
4. MutationObserver
5. Array.map
6. CustomEvent
```

<Collapse title="정답 보기">
Web API: 1(querySelector), 4(MutationObserver), 6(CustomEvent)
언어(ECMAScript): 2(Promise), 3(JSON.parse), 5(Array.map)
</Collapse>

콘솔에서 각각을 직접 쳐서 `[native code]`가 나오는지도 확인해 보자. (힌트: 둘 다 `[native code]`로 나오므로 출력만으로는 구별 안 된다 — 그래서 판별 기준이 필요하다.)
