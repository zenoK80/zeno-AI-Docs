## 01편 복습

## 핵심 퀴즈

**Q1. Web API의 명세는 누가 관리하나? ECMAScript는?**

<Collapse title="정답 보기">
Web API는 WHATWG·W3C가, ECMAScript는 TC39가 관리한다. 관리 주체 자체가 다르다.
</Collapse>

**Q2. 아래 중 Web API에 속하는 것을 모두 고르면? `fetch` / `class` / `localStorage` / `Map` / `addEventListener`**

<Collapse title="정답 보기">
`fetch`, `localStorage`, `addEventListener`가 Web API다. `class`와 `Map`은 ECMAScript(언어) 소속이다.
</Collapse>

**Q3. `setTimeout`, `fetch`처럼 Node.js에도 있는 API를 이 시리즈에서 다루는 이유는?**

<Collapse title="정답 보기">
이들은 원래 브라우저(WHATWG) 명세의 API이고, Node.js가 나중에 가져다 구현한 것이기 때문이다. 소속 자체가 브라우저 쪽이다.
</Collapse>

## 실습 — 판별 기준 적용해 보기

아래 목록을 보고, 배운 판별 기준(Node.js에 없는가? / WHATWG·W3C 명세인가? / 렌더링·상호작용·네트워크 관련인가?)으로 Web API인지 언어인지 스스로 분류해 보자.

```
1. querySelector
2. Promise
3. JSON.parse
4. MutationObserver
5. Array.map
6. CustomEvent
```

<Collapse title="정답 보기">
Web API: 1(querySelector), 4(MutationObserver), 6(CustomEvent)
언어(ECMAScript): 2(Promise), 3(JSON.parse), 5(Array.map)
</Collapse>

콘솔에서 각각을 직접 쳐서 `[native code]`가 나오는지도 확인해 보자. (힌트: 둘 다 `[native code]`로 나오므로 출력만으로는 구별 안 된다 — 그래서 판별 기준이 필요하다.)
