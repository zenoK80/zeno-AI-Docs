## localStorage

탭/브라우저를 닫아도 데이터가 유지됩니다. 같은 출처(origin)라면 모든 탭에서 공유됩니다.

<CodePlayground
  template="vanilla"
  activeFile="/index.js"
  showConsole
  label="localStorage 실습 — 저장하고 새로고침해도 유지되는지 확인해보세요"
  files={{
    '/index.html': `<button id="save">저장</button>
<button id="load">읽기</button>
<button id="remove">삭제</button>
<script src="/index.js"></script>`,
    '/index.js': `document.querySelector('#save').addEventListener('click', () => {
  localStorage.setItem('theme', 'dark')
  localStorage.setItem('user', JSON.stringify({ name: '철수', age: 20 }))
  console.log('저장 완료')
})

document.querySelector('#load').addEventListener('click', () => {
  const theme = localStorage.getItem('theme')
  const user = JSON.parse(localStorage.getItem('user'))
  console.log('theme:', theme)
  console.log('user:', user)
})

document.querySelector('#remove').addEventListener('click', () => {
  localStorage.removeItem('theme')
  localStorage.clear()
  console.log('삭제 완료')
})`,
  }}
/>

`setItem(key, value)`로 저장하고 `getItem(key)`로 읽습니다. `removeItem(key)`는 특정 키만, `clear()`는 전체를 삭제합니다.

<Callout type="warning">
  localStorage는 문자열만 저장합니다. 객체는 `JSON.stringify()`로 직렬화하고 `JSON.parse()`로 역직렬화해야 합니다.
</Callout>

## sessionStorage

탭/창이 닫히면 데이터가 삭제됩니다. 같은 탭 안에서만 공유됩니다.

```js
sessionStorage.setItem('step', '2')
const step = sessionStorage.getItem('step')  // '2'
sessionStorage.removeItem('step')
```

## localStorage vs sessionStorage vs Cookie

| | localStorage | sessionStorage | Cookie |
| --- | --- | --- | --- |
| 만료 | 없음 (영구) | 탭 닫으면 삭제 | 설정 가능 |
| 용량 | ~5MB | ~5MB | ~4KB |
| 서버 전송 | 안 됨 | 안 됨 | HTTP 요청마다 자동 전송 |
| 접근 | JS | JS | JS, 서버 |
| 적합한 용도 | 설정, 테마 | 폼 임시 저장 | 인증, 세션 |

## Cookie

```js
// 쓰기
document.cookie = 'name=철수; expires=Fri, 31 Dec 2025 23:59:59 GMT; path=/'
document.cookie = 'lang=ko; max-age=86400; SameSite=Strict; Secure'

// 읽기 (모든 쿠키를 하나의 문자열로 반환)
console.log(document.cookie)
// 'name=철수; lang=ko'

// 특정 쿠키 파싱 함수
function getCookie(name) {
  const cookies = document.cookie.split(';')
  for (const cookie of cookies) {
    const [key, value] = cookie.trim().split('=')
    if (key === name) return value
  }
  return null
}

// 삭제 (만료 시간을 과거로 설정)
document.cookie = 'name=; expires=Thu, 01 Jan 1970 00:00:00 GMT'
```

## 쿠키 속성

```
Set-Cookie: token=abc123; 
  HttpOnly;         // JS에서 접근 불가 (XSS 방어)
  Secure;           // HTTPS에서만 전송
  SameSite=Strict;  // 크로스 사이트 요청에 포함 안 됨 (CSRF 방어)
  Max-Age=3600;     // 1시간 후 만료
  Path=/api;        // 특정 경로에만 전송
```

## storage 이벤트

같은 출처의 다른 탭에서 localStorage가 변경될 때 발생합니다.

```js
window.addEventListener('storage', (event) => {
  console.log('키:', event.key)
  console.log('이전 값:', event.oldValue)
  console.log('새 값:', event.newValue)
})
```

## 핵심 정리

- `localStorage`는 영구 저장, `sessionStorage`는 탭 단위 저장입니다.
- 쿠키는 용량이 작지만 서버 요청에 자동 포함되어 인증에 적합합니다.
- `HttpOnly` 쿠키는 JavaScript로 접근할 수 없어 XSS 공격을 방어합니다.
- Web Storage는 동기 API이며 문자열만 저장합니다.
