## 05편 복습

## 핵심 퀴즈

**Q1. `document`, `console`은 사실 무엇의 프로퍼티인가?**

<Collapse title="정답 보기">
`window`. `window.document`, `window.console`을 줄여서 쓰고 있던 것이다.
</Collapse>

**Q2. 최상위에서 `var siteName = 'A'`로 선언하면 `window.siteName`은?**

<Collapse title="정답 보기">
`'A'`가 나온다. `var`로 선언한 최상위 변수는 `window`의 프로퍼티로 등록된다.
</Collapse>

**Q3. `window`와 `globalThis`의 차이는?**

<Collapse title="정답 보기">
`window`는 브라우저 전용 이름이라 Node.js에는 없다. `globalThis`는 환경을 가리지 않고 "지금 환경의 전역 객체"를 가리킨다.
</Collapse>

## 실습 — window 뜯어보기

브라우저 콘솔에서 순서대로 실행해 보자.

```js
// 1. window 안에 프로퍼티가 몇 개나 있는지
Object.keys(window).length

// 2. var로 선언해서 window에 등록되는지 확인
var testVar = 'var는 등록됨'
console.log(window.testVar)

// 3. let으로 선언하면 어떻게 다른지 확인
let testLet = 'let은 등록 안 됨'
console.log(window.testLet)

// 4. globalThis로 확인
console.log(globalThis === window)
```

<Collapse title="예상 결과">
1. 수백 개
2. `'var는 등록됨'`
3. `undefined`
4. `true`
</Collapse>
