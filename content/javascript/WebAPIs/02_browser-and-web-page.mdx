## 주소를 입력하면 무엇이 열릴까

브라우저 주소창에 URL을 입력하면 브라우저는 서버에서 HTML 파일을 받아 **탭**(tab) 안에 표시합니다. 이때 화면에 보이는 한 페이지를 JavaScript에서는 보통 **문서**(document) 라고 부릅니다.

여기서 브라우저는 Chrome, Firefox처럼 웹을 여는 프로그램이고, 탭은 브라우저 안에서 페이지 하나를 여는 자리입니다.

## HTML은 문서의 뼈대다

웹 서버가 보내는 HTML은 화면에 보여 줄 구조를 적은 텍스트입니다.

```html
<h1>오늘의 할 일</h1>
<p id="message">아직 시작하지 않았어요.</p>
<button>시작</button>
```

브라우저는 이 HTML을 읽어 제목, 문장, 버튼을 화면에 만듭니다. 그리고 JavaScript가 이 문서를 찾고 바꾸도록 `document`라는 Web API를 제공합니다.

```js
console.log(document.title)
```

`document.title`은 현재 탭의 문서 제목을 읽습니다. `document`는 JavaScript 문법 자체가 아니라 **브라우저가 제공하는 기능**입니다.

## 화면의 HTML은 DOM으로도 다룬다

브라우저는 HTML을 JavaScript가 다룰 수 있는 객체 구조로 바꿉니다. 이것을 **DOM**(Document Object Model) 이라고 합니다.

- HTML: 서버가 보낸 문서의 원본 구조
- DOM: 브라우저가 메모리에 만든, JavaScript로 조작 가능한 문서 구조

<CodePlayground
  template="vanilla"
  activeFile="/index.js"
  label="DOM 조작 실습"
  files={{
    '/index.html': `<main>
  <p id="message">아직 시작하지 않았어요.</p>
</main>
<script src="/index.js"></script>`,
    '/index.js': `const message = document.querySelector('#message')
message.textContent = '학습을 시작했어요!'`,
  }}
/>

`querySelector()`는 문서에서 `#message`를 찾고, `textContent`는 그 요소의 글자를 바꿉니다. 사용자가 버튼을 누른 뒤 문구가 바뀌는 이유도 이런 DOM 조작 덕분입니다.

<Callout type="warning">
  브라우저 탭마다 document가 따로 있습니다. A 탭의 JavaScript가 특별한 권한 없이 B 탭의 문서를 마음대로 읽거나 바꿀 수는 없습니다.
</Callout>

## 네 단어만 정확히 기억하기

| 단어 | 뜻 | 예 |
| --- | --- | --- |
| 브라우저 | 웹 페이지를 여는 프로그램 | Chrome, Firefox |
| 탭 | 브라우저 안에서 페이지 하나를 여는 자리 | 새 탭 |
| 웹 페이지 | 사용자가 보는 화면 | 로그인 화면, 글 목록 |
| document | JavaScript가 다루는 현재 페이지의 문서 | `document.querySelector()` |

## 핵심 정리

- URL을 열면 브라우저가 HTML을 받아 탭 안에 웹 페이지로 표시합니다.
- HTML은 페이지 구조이고, DOM은 JavaScript가 다룰 수 있게 만든 문서 객체 구조입니다.
- `document`는 현재 탭의 문서를 나타내는 브라우저 Web API입니다.
