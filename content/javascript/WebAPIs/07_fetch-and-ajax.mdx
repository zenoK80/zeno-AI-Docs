  **이번 문서의 목표:** Fetch API로 서버에 요청을 보내고 JSON 데이터를 받아 처리하는 방법을 익힙니다.
</Callout>

## 기본 GET 요청

```js
async function fetchUsers() {
  const response = await fetch('https://jsonplaceholder.typicode.com/users')

  if (!response.ok) {
    throw new Error(`HTTP 오류: ${response.status}`)
  }

  const users = await response.json()
  console.log(users)
}

fetchUsers().catch(err => console.error(err))
```

`fetch()`는 Promise를 반환하며 `await`으로 응답을 기다립니다. `response.json()`도 비동기 메서드입니다.

## Response 객체

```js
const response = await fetch('/api/data')

console.log(response.status)     // 200, 404, 500 등
console.log(response.ok)         // 200-299면 true
console.log(response.statusText) // 'OK', 'Not Found' 등
console.log(response.headers.get('content-type'))

// 응답 본문 파싱 (한 번만 읽을 수 있음)
const json = await response.json()     // JSON
const text = await response.text()     // 텍스트
const blob = await response.blob()     // 파일/이미지
const buffer = await response.arrayBuffer()
```

## POST 요청

```js
async function createUser(userData) {
  const response = await fetch('/api/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer token123',
    },
    body: JSON.stringify(userData),
  })

  return response.json()
}

await createUser({ name: '철수', email: 'chul@example.com' })
```

## 에러 처리

```js
async function fetchData(url) {
  try {
    const response = await fetch(url)

    if (!response.ok) {
      throw new Error(`서버 오류: ${response.status}`)
    }

    return await response.json()
  } catch (error) {
    if (error instanceof TypeError) {
      console.error('네트워크 오류:', error.message)  // 연결 실패
    } else {
      console.error('서버 오류:', error.message)
    }
    throw error
  }
}
```

<Callout type="warning">
  `fetch()`는 네트워크 오류일 때만 reject됩니다. 404, 500 등 HTTP 오류는 resolve로 처리되므로 `response.ok`를 반드시 확인하세요.
</Callout>

## AbortController — 요청 취소

```js
const controller = new AbortController()

setTimeout(() => controller.abort(), 3000)  // 3초 후 취소

try {
  const response = await fetch('/api/slow', {
    signal: controller.signal,
  })
  const data = await response.json()
} catch (err) {
  if (err.name === 'AbortError') {
    console.log('요청이 취소되었습니다')
  }
}
```

## 병렬 요청

```js
async function loadAll() {
  const [users, posts, comments] = await Promise.all([
    fetch('/api/users').then(r => r.json()),
    fetch('/api/posts').then(r => r.json()),
    fetch('/api/comments').then(r => r.json()),
  ])

  return { users, posts, comments }
}
```

## FormData 전송

```js
const form = document.querySelector('form')
const formData = new FormData(form)

const response = await fetch('/api/upload', {
  method: 'POST',
  body: formData,  // Content-Type 헤더 자동 설정
})
```

## 핵심 정리

- `fetch(url, options)`로 HTTP 요청을 보내고 Promise를 받습니다.
- `response.ok`로 HTTP 성공 여부를 확인하세요.
- `response.json()`으로 JSON 응답을 파싱합니다.
- `AbortController`로 진행 중인 요청을 취소할 수 있습니다.
