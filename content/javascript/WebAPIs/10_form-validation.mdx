## 폼 요소 값 읽기

```js
// 텍스트 인풋
const name = document.querySelector('#name').value

// 체크박스
const agreed = document.querySelector('#agree').checked

// 라디오 버튼 (선택된 것 찾기)
const gender = document.querySelector('input[name="gender"]:checked')?.value

// 셀렉트박스
const country = document.querySelector('#country').value  // 선택된 option의 value
const selected = document.querySelector('#country options:checked')

// 파일 인풋
const file = document.querySelector('#file').files[0]
```

## FormData

폼 전체 데이터를 손쉽게 수집합니다.

```js
const form = document.querySelector('form')

form.addEventListener('submit', async (e) => {
  e.preventDefault()

  const formData = new FormData(form)

  // 값 읽기
  console.log(formData.get('email'))
  console.log(formData.getAll('tags'))  // 다중 선택

  // 값 추가/변경/삭제
  formData.set('timestamp', Date.now())
  formData.append('extra', '추가값')
  formData.delete('unusedField')

  // 순회
  for (const [key, value] of formData) {
    console.log(key, value)
  }

  // 서버 전송
  const response = await fetch('/api/submit', {
    method: 'POST',
    body: formData,  // multipart/form-data 자동 설정
  })
})
```

## HTML5 Constraint Validation API

브라우저 내장 유효성 검사를 JavaScript로 제어합니다.

```js
const input = document.querySelector('#email')

// 유효성 검사 결과
console.log(input.validity.valid)           // 모든 조건 만족 시 true
console.log(input.validity.valueMissing)    // required 인데 비어 있을 때
console.log(input.validity.typeMismatch)    // type에 맞지 않을 때
console.log(input.validity.patternMismatch) // pattern 정규식 불일치
console.log(input.validity.tooLong)         // maxLength 초과
console.log(input.validity.rangeUnderflow)  // min 미만

// 커스텀 오류 메시지
input.setCustomValidity('올바른 이메일을 입력해 주세요.')
input.setCustomValidity('')  // 초기화

// 오류 메시지 표시
input.reportValidity()
```

## 커스텀 유효성 검사

```js
const passwordInput = document.querySelector('#password')
const confirmInput = document.querySelector('#confirm-password')

function validatePasswords() {
  if (passwordInput.value !== confirmInput.value) {
    confirmInput.setCustomValidity('비밀번호가 일치하지 않습니다.')
  } else {
    confirmInput.setCustomValidity('')
  }
}

passwordInput.addEventListener('input', validatePasswords)
confirmInput.addEventListener('input', validatePasswords)
```

## novalidate와 수동 검사

```html
<form novalidate>...</form>
```

`novalidate`를 추가하면 브라우저 기본 검사를 비활성화하고 JavaScript로 제어합니다.

```js
form.addEventListener('submit', (e) => {
  e.preventDefault()

  const inputs = form.querySelectorAll('input, textarea, select')
  let isValid = true

  inputs.forEach(input => {
    if (!input.checkValidity()) {
      input.classList.add('error')
      isValid = false
    } else {
      input.classList.remove('error')
    }
  })

  if (isValid) {
    // 제출 처리
  }
})
```

## 입력 마스킹 예시

```js
const phoneInput = document.querySelector('#phone')

phoneInput.addEventListener('input', (e) => {
  const digits = e.target.value.replace(/\D/g, '')  // 숫자만
  const formatted = digits
    .replace(/(\d{3})(\d)/, '$1-$2')
    .replace(/(\d{3}-\d{4})(\d)/, '$1-$2')
    .slice(0, 13)
  e.target.value = formatted
})
```

## 핵심 정리

- `FormData`로 폼 전체 데이터를 수집하고 서버에 전송합니다.
- HTML5 Constraint Validation API로 `validity` 상태를 확인하고 커스텀 오류 메시지를 설정합니다.
- `novalidate`로 브라우저 기본 검사를 끄고 JavaScript로 직접 제어할 수 있습니다.
