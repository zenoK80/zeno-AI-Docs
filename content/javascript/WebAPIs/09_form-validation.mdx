## 폼 요소 값 읽기

```js
const name = document.querySelector('#name').value               // 텍스트 인풋
const agreed = document.querySelector('#agree').checked           // 체크박스
const gender = document.querySelector('input[name="gender"]:checked')?.value  // 라디오 그룹
const country = document.querySelector('#country').value          // 셀렉트박스

```

## FormData — 폼 전체를 한 번에 수집

<CodePlayground

  <input name="email" type="email" placeholder="이메일" />

  <button type="submit">가입</button>
</form>

    '/index.js': `const form = document.querySelector('#signup')

form.addEventListener('submit', (e) => {
  e.preventDefault()

  const formData = new FormData(form)
  console.log('이메일:', formData.get('email'))
  console.log('닉네임:', formData.get('nickname'))

  formData.set('timestamp', Date.now())
  formData.append('extra', '추가값')

  for (const [key, value] of formData) {
    console.log(key, '=', value)
  }
})`,
  }}
/>

`FormData`는 각 `<input>`의 `name` 속성을 키로 삼아 폼의 모든 값을 자동으로 모아줍니다. 서버로 전송할 때는 `fetch(url, { method: 'POST', body: formData })`처럼 body에 바로 넣을 수 있으며, 파일이 포함되어도 `multipart/form-data` 형식으로 자동 처리됩니다.

## HTML5 Constraint Validation API — 브라우저 내장 검증

HTML 속성(`required`, `pattern`, `minlength` 등)만으로도 기본 검증이 되지만, JavaScript로 그 결과를 세밀하게 제어할 수 있습니다.

```js
const input = document.querySelector('#email')

console.log(input.validity.valid)           // 모든 조건을 만족하면 true
console.log(input.validity.valueMissing)    // required인데 비어 있을 때 true
console.log(input.validity.typeMismatch)    // type에 맞지 않을 때(예: 이메일 형식 아님)
console.log(input.validity.patternMismatch) // pattern 정규식 불일치
console.log(input.validity.tooLong)         // maxLength 초과

input.setCustomValidity('올바른 이메일을 입력해 주세요')  // 커스텀 오류 메시지
input.setCustomValidity('')  // 초기화(빈 문자열이어야 유효한 상태로 돌아감)

input.reportValidity()  // 오류 메시지를 화면에 표시
```

`validity`는 어떤 조건이 왜 실패했는지 세분화해 알려주는 **ValidityState** 객체입니다.

    '/index.js': `const password = document.querySelector('#password')
const confirm = document.querySelector('#confirm')
const form = document.querySelector('form')

function validatePasswords() {
  if (password.value !== confirm.value) {
    confirm.setCustomValidity('비밀번호가 일치하지 않습니다')
  } else {
    confirm.setCustomValidity('')
  }
}

password.addEventListener('input', validatePasswords)
confirm.addEventListener('input', validatePasswords)

form.addEventListener('submit', (e) => {
  e.preventDefault()
  console.log('유효함:', confirm.checkValidity())
  console.log('메시지:', confirm.validationMessage)
})`,
  }}
/>

## novalidate — 브라우저 기본 UI를 끄고 직접 제어

```html
<form novalidate>...</form>
```

`novalidate`를 추가하면 브라우저의 기본 유효성 검사 팝업(예: "이 필드를 작성하세요")이 비활성화되고, 검증 로직 전체를 JavaScript로 직접 제어할 수 있습니다.

```js
form.addEventListener('submit', (e) => {
  e.preventDefault()

  const inputs = form.querySelectorAll('input, textarea, select')
  let isValid = true

  inputs.forEach(input => {
    if (!input.checkValidity()) {
      input.classList.add('error')  // 커스텀 스타일로 오류 표시
      isValid = false
    } else {
      input.classList.remove('error')
    }
  })

  if (isValid) {
    // 제출 처리
  }
})
```

## 입력 마스킹 예시 — 전화번호 자동 하이픈

```js
const phoneInput = document.querySelector('#phone')

phoneInput.addEventListener('input', (e) => {
  const digits = e.target.value.replace(/\D/g, '')  // 숫자만 남김
  const formatted = digits
    .replace(/(\d{3})(\d)/, '$1-$2')
    .replace(/(\d{3}-\d{4})(\d)/, '$1-$2')
    .slice(0, 13)
  e.target.value = formatted
})
```

## 핵심 정리

- FormData는 form의 name 속성 기준으로 모든 값을 자동으로 수집하며, fetch의 body로 바로 사용할 수 있다.
- validity 객체로 검증 실패 원인을 세분화해 확인하고, setCustomValidity로 커스텀 오류 메시지를 설정한다.
- novalidate로 브라우저 기본 검증 UI를 끄고 JavaScript로 직접 제어할 수 있다.
- checkValidity()는 유효 여부를 boolean으로 반환하며, reportValidity()는 오류를 화면에 표시한다.
