## Web Worker란

JavaScript는 기본적으로 싱글 스레드입니다. 무거운 계산이 실행되면 UI가 멈춥니다. **Web Worker**를 사용하면 별도 스레드에서 계산을 처리할 수 있습니다.

```js
// main.js
const worker = new Worker('/worker.js')

// 워커에 메시지 보내기
worker.postMessage({ type: 'calculate', data: [1, 2, 3, 4, 5] })

// 워커에서 결과 받기
worker.onmessage = (event) => {
  console.log('결과:', event.data)
}

worker.onerror = (error) => {
  console.error('워커 오류:', error.message)
}

// 워커 종료
worker.terminate()
```

```js
// worker.js
self.onmessage = (event) => {
  const { type, data } = event.data

  if (type === 'calculate') {
    const result = data.reduce((sum, n) => sum + n, 0)
    self.postMessage(result)
  }
}
```

## Web Worker 제한 사항

- DOM에 직접 접근 불가
- `window` 객체 없음
- 파일 시스템 접근 제한
- 동일 출처 정책 적용

## 전용 워커 vs 공유 워커

```js
// 전용 워커 (Dedicated Worker) - 하나의 페이지와 1:1
const worker = new Worker('/worker.js')

// 공유 워커 (Shared Worker) - 여러 탭/페이지가 공유
const shared = new SharedWorker('/shared-worker.js')
shared.port.onmessage = (e) => console.log(e.data)
shared.port.postMessage('hello')
```

## Service Worker 개요

**Service Worker**는 브라우저와 네트워크 사이에 있는 프록시입니다. 오프라인 지원, 백그라운드 동기화, 푸시 알림에 사용됩니다.

## Service Worker 등록

```js
// main.js
if ('serviceWorker' in navigator) {
  window.addEventListener('load', async () => {
    try {
      const registration = await navigator.serviceWorker.register('/sw.js')
      console.log('SW 등록됨:', registration.scope)
    } catch (err) {
      console.error('SW 등록 실패:', err)
    }
  })
}
```

## Service Worker 파일 (sw.js)

```js
const CACHE_NAME = 'my-app-v1'
const CACHED_URLS = ['/', '/index.html', '/style.css', '/app.js']

// 설치 단계: 리소스 캐시
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(CACHED_URLS))
  )
})

// 활성화 단계: 이전 캐시 정리
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(
        keys
          .filter(key => key !== CACHE_NAME)
          .map(key => caches.delete(key))
      )
    )
  )
})

// 네트워크 요청 가로채기: 캐시 우선 전략
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then(cached => {
      return cached || fetch(event.request)
    })
  )
})
```

## 핵심 정리

- Web Worker는 메인 스레드와 별도로 무거운 계산을 수행합니다.
- `postMessage()`와 `onmessage`로 메인 스레드와 통신합니다.
- Service Worker는 네트워크 요청을 가로채 캐싱, 오프라인 지원을 구현합니다.
- HTTPS 환경에서만 Service Worker가 등록됩니다.
