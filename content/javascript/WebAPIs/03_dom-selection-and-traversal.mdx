## DOM 트리 구조

HTML이 로딩되면 브라우저는 이를 **DOM 트리**로 변환합니다.

```html
<body>
  <div id="container">
    <h1 class="title">제목</h1>
    <p>단락</p>
  </div>
</body>
```

`document`가 루트이며 각 HTML 요소가 노드(node)가 됩니다.

## querySelector / querySelectorAll

CSS 선택자로 요소를 찾습니다.

```js
// 첫 번째 매칭 요소 하나
const title = document.querySelector('.title')
const container = document.querySelector('#container')
const firstP = document.querySelector('p')

// 매칭되는 모든 요소 (NodeList 반환)
const allItems = document.querySelectorAll('li')
allItems.forEach(item => console.log(item.textContent))
```

## getElementById, getElementsByClassName

```js
const el = document.getElementById('container')  // 단 하나 (빠름)

const byClass = document.getElementsByClassName('title')  // HTMLCollection
const byTag = document.getElementsByTagName('p')           // HTMLCollection
```

<Callout type="warning">
  `getElementsByClassName`과 `getElementsByTagName`이 반환하는 **HTMLCollection**은 살아 있는(live) 컬렉션입니다. DOM이 변경되면 자동으로 업데이트됩니다. `querySelectorAll`의 NodeList는 정적입니다.
</Callout>

## closest — 조상 탐색

현재 요소에서 시작해 DOM 위로 올라가며 CSS 선택자에 맞는 가장 가까운 조상을 찾습니다.

```js
const button = document.querySelector('button')
const form = button.closest('form')   // 가장 가까운 form 조상
```

## matches — 선택자 확인

요소가 특정 CSS 선택자에 매칭되는지 확인합니다.

```js
const el = document.querySelector('p')
console.log(el.matches('.active'))   // true/false
```

## 핵심 정리

- `querySelector`는 CSS 선택자로 첫 번째 요소를, `querySelectorAll`은 모든 요소를 반환합니다.
- `getElementById`는 ID로 요소를 빠르게 찾습니다.
- 부모/자식/형제 노드는 `parentElement`, `children`, `nextElementSibling` 등으로 탐색합니다.
- `closest()`는 조상 요소를 탐색하고, `matches()`는 선택자 일치를 확인합니다.
