<Callout type="info">
  **이번 문서의 목표:** DOM 요소의 내용을 읽고 변경하고, 새 요소를 만들어 추가하는 방법을 익힙니다.
</Callout>

## 내용 읽기와 변경

```js
const title = document.querySelector('h1')

// textContent: 텍스트만 다룸 (HTML 태그 무시)
console.log(title.textContent)
title.textContent = '새 제목'

// innerHTML: HTML 마크업 포함
const list = document.querySelector('ul')
console.log(list.innerHTML)
list.innerHTML = '<li>첫 번째</li><li>두 번째</li>'
```

<Callout type="warning">
  `innerHTML`에 사용자 입력을 직접 삽입하면 **XSS(Cross-Site Scripting)** 공격에 취약합니다. 사용자 입력은 반드시 `textContent`로 처리하거나 DOMPurify 등으로 정화하세요.
</Callout>

## 요소 생성과 추가

```js
// 새 요소 생성
const newItem = document.createElement('li')
newItem.textContent = '새 항목'
newItem.className = 'item active'

// 부모에 추가
const list = document.querySelector('ul')
list.appendChild(newItem)    // 마지막에 추가
list.prepend(newItem)        // 첫 번째에 추가

// 특정 위치에 추가
const referenceNode = list.querySelector('li:nth-child(2)')
list.insertBefore(newItem, referenceNode)  // referenceNode 앞에

// 여러 요소 한 번에
list.append('텍스트', newItem, document.createElement('li'))
```

## insertAdjacentHTML

특정 위치에 HTML을 삽입합니다.

```js
const container = document.querySelector('#container')

container.insertAdjacentHTML('beforebegin', '<p>컨테이너 앞</p>')
container.insertAdjacentHTML('afterbegin', '<p>컨테이너 내부 첫 번째</p>')
container.insertAdjacentHTML('beforeend', '<p>컨테이너 내부 마지막</p>')
container.insertAdjacentHTML('afterend', '<p>컨테이너 뒤</p>')
```

## 요소 제거와 교체

```js
const item = document.querySelector('.item')

item.remove()  // 자기 자신 제거

// 교체
const newEl = document.createElement('span')
item.replaceWith(newEl)  // item 대신 newEl

// 복사
const clone = item.cloneNode(true)  // true: 자식 노드까지 복사
```

## 속성 조작

```js
const img = document.querySelector('img')

img.getAttribute('src')           // 속성 값 읽기
img.setAttribute('alt', '설명')   // 속성 설정
img.removeAttribute('disabled')   // 속성 제거
img.hasAttribute('hidden')        // 속성 존재 여부

// data 속성
const el = document.querySelector('[data-user-id]')
el.dataset.userId          // data-user-id 값
el.dataset.createdAt = '2024'  // data-created-at 설정
```

## 클래스 조작

```js
const el = document.querySelector('.card')

el.classList.add('active')           // 추가
el.classList.remove('disabled')      // 제거
el.classList.toggle('hidden')        // 없으면 추가, 있으면 제거
el.classList.contains('active')      // 존재 여부 (boolean)
el.classList.replace('old', 'new')   // 교체
```

## 스타일 조작

```js
const box = document.querySelector('.box')

// 인라인 스타일
box.style.backgroundColor = 'red'
box.style.fontSize = '20px'

// 계산된 스타일 읽기
const computed = getComputedStyle(box)
console.log(computed.color)
```

## 핵심 정리

- `textContent`는 텍스트만, `innerHTML`은 HTML 마크업을 다룹니다.
- `createElement()` + `appendChild()` 로 새 요소를 만들어 추가합니다.
- `classList`로 클래스를 안전하게 추가/제거/토글합니다.
- `dataset`으로 data-* 속성에 쉽게 접근합니다.
