## 언제 useReducer를 쓰나?

다음 상황에서 useState 대신 useReducer를 고려합니다.

- 상태가 여러 개이고 서로 연관되어 있을 때
- 다음 상태가 이전 상태에 의존할 때
- 상태 업데이트 로직이 길고 복잡할 때

```jsx
// useState로 관리하기 복잡한 예
const [todos, setTodos] = useState([])
const [filter, setFilter] = useState('all')
const [loading, setLoading] = useState(false)

// 할 일 추가 시 todos 업데이트
// 필터 변경 시 filter 업데이트
// 비동기 작업 시 loading 업데이트
// → 상태들이 얽혀 있어 로직이 흩어짐
```

## useReducer 구조

```
dispatch(액션)
     ↓
reducer(현재상태, 액션) → 새 상태
     ↓
컴포넌트 리렌더링
```

**Reducer 함수**: 현재 상태와 액션을 받아 새 상태를 반환하는 **순수 함수**(Pure Function).

> **순수 함수란?** 같은 입력을 넣으면 항상 같은 출력이 나오고, 함수 바깥의 어떤 것도 변경하지 않는(부작용이 없는) 함수입니다. reducer 안에서 `fetch`를 호출하거나 `state.todos.push(...)`처럼 원본을 직접 수정하면 안 됩니다. 항상 새로운 상태 객체를 만들어 반환해야 합니다.
**Action**: `{ type: '액션타입', payload: 데이터 }` 형태의 객체.
**dispatch**: 액션을 보내는 함수.

> **쉽게 말하면:** 은행 창구와 같습니다. "출금 5만원(액션)"을 접수(dispatch)하면 창구(reducer)에서 잔액(상태)을 업데이트합니다.

## 기본 사용 예제 — 카운터

<CodePlayground

// reducer 함수: 액션 타입에 따라 상태를 업데이트
function counterReducer(state, action) {
  switch (action.type) {
    case 'INCREMENT':
      return { count: state.count + 1 }
    case 'DECREMENT':
      return { count: state.count - 1 }
    case 'RESET':
      return { count: 0 }
    default:
      return state
  }
}

export default function Counter() {
  const [state, dispatch] = useReducer(counterReducer, { count: 0 })

  return (
    <div>
      <p>카운트: {state.count}</p>
      <button onClick={() => dispatch({ type: 'INCREMENT' })}>+1</button>
      <button onClick={() => dispatch({ type: 'DECREMENT' })}>-1</button>
      <button onClick={() => dispatch({ type: 'RESET' })}>초기화</button>
    </div>
  )
}`,
  }}

## 실전 예제 — 할 일 목록

```jsx
const initialState = {
  todos: [],
  filter: 'all',
}

function todoReducer(state, action) {
  switch (action.type) {
    case 'ADD_TODO':
      return {
        ...state,
        todos: [
          ...state.todos,
          { id: Date.now(), text: action.payload, done: false },
        ],
      }
    case 'TOGGLE_TODO':
      return {
        ...state,
        todos: state.todos.map(todo =>
          todo.id === action.payload
            ? { ...todo, done: !todo.done }
            : todo
        ),
      }
    case 'DELETE_TODO':
      return {
        ...state,
        todos: state.todos.filter(todo => todo.id !== action.payload),
      }
    case 'SET_FILTER':
      return { ...state, filter: action.payload }
    default:
      return state
  }
}

function TodoApp() {
  const [state, dispatch] = useReducer(todoReducer, initialState)
  const [input, setInput] = useState('')

  const visibleTodos = state.todos.filter(todo => {
    if (state.filter === 'active') return !todo.done
    if (state.filter === 'done') return todo.done
    return true
  })

  return (
    <div>
      <input
        value={input}
        onChange={e => setInput(e.target.value)}
        placeholder="할 일 입력"
      />
      <button onClick={() => {
        if (input.trim()) {
          dispatch({ type: 'ADD_TODO', payload: input })
          setInput('')
        }
      }}>
        추가
      </button>

      <div>
        {['all', 'active', 'done'].map(f => (
          <button key={f} onClick={() => dispatch({ type: 'SET_FILTER', payload: f })}>
            {f}
          </button>
        ))}
      </div>

      <ul>
        {visibleTodos.map(todo => (
          <li key={todo.id} style={{ textDecoration: todo.done ? 'line-through' : 'none' }}>
            {todo.text}
            <button onClick={() => dispatch({ type: 'TOGGLE_TODO', payload: todo.id })}>
              완료
            </button>
            <button onClick={() => dispatch({ type: 'DELETE_TODO', payload: todo.id })}>
              삭제
            </button>
          </li>
        ))}
      </ul>
    </div>
  )
}
```

## useState vs useReducer 선택 기준

| 상황 | 추천 |
| --- | --- |
| 독립된 간단한 값 (count, isOpen) | useState |
| 여러 상태가 함께 바뀌는 경우 | useReducer |
| 상태 전환 로직이 복잡한 경우 | useReducer |
| 테스트 코드 작성이 중요한 경우 | useReducer (reducer 순수 함수라 테스트 용이) |

---

## 핵심 정리

- `useReducer(reducer, 초기상태)` — `[state, dispatch]` 반환.
- **Reducer**: `(현재상태, 액션) => 새상태` 형태의 순수 함수. switch-case로 액션 타입 처리.
- **Action**: `{ type: '액션명', payload: 데이터 }` 형태의 객체.
- **dispatch**: 액션을 보내 상태 변경을 요청하는 함수.
- 상태가 복잡하거나 서로 연관될 때 useReducer가 useState보다 관리하기 쉽다.
