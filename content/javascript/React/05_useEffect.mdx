## useEffect 기본

```jsx
import { useState, useEffect } from 'react'

function App() {
  const [count, setCount] = useState(0)

  useEffect(() => {
    // 렌더링 후 실행
    document.title = `클릭 ${count}회`
  })  // 의존성 배열 없음 → 매 렌더링 후 실행

  return <button onClick={() => setCount(count + 1)}>클릭 ({count})</button>
}
```

## 의존성 배열

```jsx
useEffect(() => {
  // 의존성 배열에 따른 실행 시점
}, [])           // 마운트 시 1회만
}, [count])      // count 변경 시마다
}, [a, b])       // a 또는 b 변경 시마다
// 배열 없음    // 매 렌더링 후
```

## 데이터 패칭

```jsx
function UserList() {
  const [users, setUsers] = useState([])
  const [loading, setLoading] = useState(true)

  useEffect(() => {
    fetch('/api/users')
      .then(res => res.json())
      .then(data => {
        setUsers(data)
        setLoading(false)
      })
  }, [])  // 마운트 시 1회만

  if (loading) return <p>로딩 중...</p>

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  )
}
```

## 클린업 함수

```jsx
function Timer() {
  const [seconds, setSeconds] = useState(0)

  useEffect(() => {
    const id = setInterval(() => {
      setSeconds(prev => prev + 1)
    }, 1000)

    // 클린업: 컴포넌트 언마운트 또는 재실행 전에 호출
    return () => clearInterval(id)
  }, [])

  return <p>{seconds}초</p>
}
```

```jsx
function EventLogger() {
  useEffect(() => {
    const handler = () => console.log('resize')
    window.addEventListener('resize', handler)

    return () => window.removeEventListener('resize', handler)
  }, [])
}
```

## AbortController로 Fetch 정리

```jsx
function PostDetail({ postId }) {
  const [post, setPost] = useState(null)

  useEffect(() => {
    const controller = new AbortController()

    fetch(`/api/posts/${postId}`, { signal: controller.signal })
      .then(res => res.json())
      .then(data => setPost(data))
      .catch(err => {
        if (err.name === 'AbortError') return  // 취소된 요청
        console.error(err)
      })

    return () => controller.abort()  // 언마운트 시 요청 취소
  }, [postId])

  return post ? <h1>{post.title}</h1> : <p>로딩 중...</p>
}
```

## 핵심 정리

- useEffect는 렌더링 후 사이드 이펙트를 실행합니다.
- 의존성 배열로 실행 시점을 제어합니다.
- 클린업 함수(return 함수)로 리소스를 정리합니다.
- 데이터 패칭 시 AbortController로 언마운트 후 상태 업데이트를 방지합니다.
