## Next.js란?

Next.js는 React 기반의 풀스택 프레임워크로 다음을 기본 제공합니다.

```
- 파일 기반 라우팅
- 서버 사이드 렌더링 (SSR)
- 정적 사이트 생성 (SSG)
- API Routes (백엔드 API)
- 이미지 최적화
- 폰트 최적화
```

## App Router 파일 구조

```
app/
├── layout.tsx          # 루트 레이아웃 (필수)
├── page.tsx            # / 경로
├── about/
│   └── page.tsx        # /about 경로
├── blog/
│   ├── page.tsx        # /blog 경로
│   └── [slug]/
│       └── page.tsx    # /blog/:slug 경로
└── api/
    └── users/
        └── route.ts    # /api/users API 엔드포인트
```

## 기본 파일 역할

```tsx
// app/layout.tsx — 모든 페이지에 적용되는 루트 레이아웃
export default function RootLayout({ children }) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  )
}

// app/page.tsx — 홈 페이지
export default function HomePage() {
  return <h1>홈 페이지</h1>
}

// app/blog/[slug]/page.tsx — 동적 경로
export default function BlogPost({ params }) {
  return <h1>포스트: {params.slug}</h1>
}
```

## Server Components vs Client Components

```tsx
// Server Component (기본) — 서버에서 렌더링, 번들에 포함 안 됨
// 'use client' 없이 작성
async function UserList() {
  // 서버에서 직접 DB나 API 호출 가능
  const users = await fetch('https://api.example.com/users').then(r => r.json())

  return (
    <ul>
      {users.map(u => <li key={u.id}>{u.name}</li>)}
    </ul>
  )
}

// Client Component — 브라우저에서 실행
'use client'

import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>
}
```

## SSR, SSG, ISR

```tsx
// SSR — 매 요청마다 서버에서 렌더링
// fetch에 cache: 'no-store' 옵션
async function SSRPage() {
  const data = await fetch('https://api.example.com/data', {
    cache: 'no-store',
  }).then(r => r.json())
  return <div>{data.title}</div>
}

// SSG — 빌드 시 한 번 생성
// fetch 기본값 (force-cache)
async function SSGPage() {
  const data = await fetch('https://api.example.com/data').then(r => r.json())
  return <div>{data.title}</div>
}

// ISR — 일정 시간마다 재생성
async function ISRPage() {
  const data = await fetch('https://api.example.com/data', {
    next: { revalidate: 60 },  // 60초마다 재검증
  }).then(r => r.json())
  return <div>{data.title}</div>
}
```

## 동적 경로 — generateStaticParams

```tsx
// app/blog/[slug]/page.tsx

// SSG: 빌드 시 생성할 경로를 정의
export async function generateStaticParams() {
  const posts = await fetch('https://api.example.com/posts').then(r => r.json())
  return posts.map(post => ({ slug: post.slug }))
}

export default function BlogPost({ params }) {
  return <div>{params.slug}</div>
}
```

## API Routes

```ts
// app/api/users/route.ts

import { NextRequest, NextResponse } from 'next/server'

export async function GET(request: NextRequest) {
  const users = [{ id: 1, name: 'Alice' }]
  return NextResponse.json(users)
}

export async function POST(request: NextRequest) {
  const body = await request.json()
  return NextResponse.json({ created: true, data: body }, { status: 201 })
}
```

## next/image와 next/link

```tsx
import Image from 'next/image'
import Link from 'next/link'

function Component() {
  return (
    <div>
      {/* 이미지 자동 최적화 */}
      <Image src="/photo.jpg" alt="사진" width={800} height={600} />

      {/* 클라이언트 사이드 이동 */}
      <Link href="/about">소개 페이지</Link>
    </div>
  )
}
```

## 핵심 정리

- App Router는 `app/` 디렉터리 기반의 파일 시스템 라우팅을 사용합니다.
- 기본적으로 모든 컴포넌트는 Server Component이며, `'use client'`를 선언해야 Client Component가 됩니다.
- fetch 옵션(`cache: 'no-store'`, `next: { revalidate }`)으로 SSR/SSG/ISR을 제어합니다.
- API Routes는 `app/api/*/route.ts`에 GET, POST 등 HTTP 메서드로 정의합니다.
