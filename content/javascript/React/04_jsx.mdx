## JSX란?

**JSX(JavaScript XML)** 는 JavaScript 안에서 HTML처럼 UI를 작성하는 문법 확장입니다. 브라우저는 JSX를 직접 이해하지 못하므로 Babel이 JavaScript 코드로 변환합니다.

```jsx
// JSX
const element = <h1>안녕하세요!</h1>

// Babel이 변환한 결과 (내부적으로)
const element = React.createElement('h1', null, '안녕하세요!')
```

> **쉽게 말하면:** JSX는 HTML처럼 생긴 JavaScript입니다. 실제로는 `React.createElement()` 호출로 바뀌는 '편의 문법'입니다.

## JSX 기본 규칙

### 1. 반드시 하나의 루트 요소

JSX는 반드시 하나의 부모 요소로 감싸야 합니다.

```jsx
// ❌ 오류 — 루트 요소가 두 개
return (
  <h1>제목</h1>
  <p>내용</p>
)

// ✅ div로 감싸기
return (
  <div>
    <h1>제목</h1>
    <p>내용</p>
  </div>
)

// ✅ Fragment 사용 (불필요한 div 없이)
return (
  <>
    <h1>제목</h1>
    <p>내용</p>
  </>
)
```

`<>...</>` 는 **Fragment**라고 하며 실제 DOM에 요소를 추가하지 않습니다.

### 2. 모든 태그는 닫아야 한다

```jsx
// ❌ HTML에서는 되지만 JSX에선 오류
<input type="text">
<br>
<img src="logo.png">

// ✅ 자기 닫기 필수
<input type="text" />
<br />
<img src="logo.png" alt="로고" />
```

### 3. className, htmlFor

HTML 속성 중 JavaScript 예약어인 것들은 다른 이름을 씁니다.

```jsx
// ❌
<div class="box">...</div>
<label for="email">...</label>

// ✅
<div className="box">...</div>
<label htmlFor="email">...</label>
```

## 중괄호 `{}`로 JavaScript 표현식 사용

JSX 안에서 `{ }` 로 JavaScript 표현식을 쓸 수 있습니다. **표현식(값이 나오는 코드)만** 가능합니다.

```jsx
const name = '김철수'
const age = 25

function Profile() {
  return (
    <div>
      <h1>{name}님의 프로필</h1>        {/* 변수 */}
      <p>나이: {age}세</p>             {/* 변수 */}
      <p>내년: {age + 1}세</p>         {/* 계산식 */}
      <p>{name.toUpperCase()}</p>      {/* 메서드 호출 */}
    </div>
  )
}
```

**표현식 vs 문(statement)**:
- ✅ 표현식: `1 + 1`, `name.toUpperCase()`, `isOn ? 'ON' : 'OFF'`
- ❌ 문: `if (...)`, `for (...)`, `const x = 1` (직접 사용 불가)

## 인라인 스타일

스타일은 문자열이 아닌 **JavaScript 객체**로 전달합니다.

```jsx
// ❌ 문자열 방식 (HTML 방식) — JSX에서 오류
<p style="color: red; font-size: 16px">텍스트</p>

// ✅ 객체 방식 — 속성 이름은 camelCase
<p style={{ color: 'red', fontSize: '16px' }}>텍스트</p>

// 변수로 분리하기
const style = { color: 'red', fontSize: '16px' }
<p style={style}>텍스트</p>
```

## 조건부 렌더링

JSX 안에서 `if/else` 는 직접 쓸 수 없고, 표현식을 활용합니다.

```jsx
function Status({ isOnline }) {
  // 방법 1: 삼항 연산자
  return (
    <span>{isOnline ? '온라인' : '오프라인'}</span>
  )
}

function Notification({ count }) {
  // 방법 2: && (단축 평가) — 값이 있을 때만 렌더링
  return (
    <div>
      {count > 0 && <span>알림 {count}개</span>}
    </div>
  )
}
```

<Callout type="warning">
  `&&`로 숫자를 조건으로 쓸 때 `0`은 화면에 0이 출력됩니다. `count > 0 && ...` 처럼 명시적으로 boolean 변환을 하세요.
</Callout>

## 리스트 렌더링

배열의 `.map()`으로 여러 요소를 렌더링합니다. 각 요소에는 고유한 `key` prop이 필요합니다.

```jsx
const fruits = [
  { id: 1, name: '사과', emoji: '🍎' },
  { id: 2, name: '바나나', emoji: '🍌' },
  { id: 3, name: '포도', emoji: '🍇' },
]

function FruitList() {
  return (
    <ul>
      {fruits.map(fruit => (
        <li key={fruit.id}>
          {fruit.emoji} {fruit.name}
        </li>
      ))}
    </ul>
  )
}
```

**key는 왜 필요한가?** React가 리스트가 바뀔 때 어느 항목이 추가·삭제·이동됐는지 효율적으로 파악하기 위해서입니다. key는 형제 요소 사이에서 고유하면 됩니다.

```jsx
// ❌ index를 key로 쓰면 리스트 순서가 바뀔 때 문제 발생
fruits.map((fruit, index) => <li key={index}>...</li>)

// ✅ 고유 id 사용 권장
fruits.map(fruit => <li key={fruit.id}>...</li>)
```

## 핵심 정리

- JSX는 JavaScript 안에서 HTML처럼 UI를 쓰는 문법. Babel이 `React.createElement()`로 변환.
- 반드시 하나의 루트 요소로 감싸야 한다. 불필요한 div가 싫으면 `<>...</>`(Fragment) 사용.
- `class` → `className`, `for` → `htmlFor`, 모든 태그는 닫아야 한다.
- `{ }` 안에 JavaScript 표현식을 쓸 수 있다. `if/for` 같은 문(statement)은 직접 불가.
- 조건부 렌더링: 삼항 연산자(`? :`) 또는 단축 평가(`&&`).
- 리스트 렌더링: `.map()` + `key` prop 필수.
