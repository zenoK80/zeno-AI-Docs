## Compound Component 패턴

관련 컴포넌트들을 하나의 그룹으로 묶어 유연한 조합을 가능하게 합니다.

```jsx
// Context로 내부 상태 공유
const TabsContext = createContext(null)

function Tabs({ children, defaultTab }) {
  const [activeTab, setActiveTab] = useState(defaultTab)
  return (
    <TabsContext.Provider value={{ activeTab, setActiveTab }}>
      <div>{children}</div>
    </TabsContext.Provider>
  )
}

function TabList({ children }) {
  return <div role="tablist">{children}</div>
}

function Tab({ id, children }) {
  const { activeTab, setActiveTab } = useContext(TabsContext)
  return (
    <button
      role="tab"
      aria-selected={activeTab === id}
      onClick={() => setActiveTab(id)}
      style={{ fontWeight: activeTab === id ? 'bold' : 'normal' }}
    >
      {children}
    </button>
  )
}

function TabPanel({ id, children }) {
  const { activeTab } = useContext(TabsContext)
  if (activeTab !== id) return null
  return <div role="tabpanel">{children}</div>
}

// 서브 컴포넌트를 속성으로 노출
Tabs.List = TabList
Tabs.Tab = Tab
Tabs.Panel = TabPanel

// 사용
function App() {
  return (
    <Tabs defaultTab="profile">
      <Tabs.List>
        <Tabs.Tab id="profile">프로필</Tabs.Tab>
        <Tabs.Tab id="settings">설정</Tabs.Tab>
      </Tabs.List>
      <Tabs.Panel id="profile">프로필 내용</Tabs.Panel>
      <Tabs.Panel id="settings">설정 내용</Tabs.Panel>
    </Tabs>
  )
}
```

## Render Props 패턴

컴포넌트의 렌더링 결과를 함수 prop으로 제어합니다.

```jsx
function MouseTracker({ render }) {
  const [position, setPosition] = useState({ x: 0, y: 0 })

  const handleMouseMove = (e) => {
    setPosition({ x: e.clientX, y: e.clientY })
  }

  return (
    <div onMouseMove={handleMouseMove} style={{ height: '300px' }}>
      {render(position)}
    </div>
  )
}

// children as function (일반적인 패턴)
function DataFetcher({ url, children }) {
  const { data, loading, error } = useFetch(url)
  return children({ data, loading, error })
}

// 사용
function App() {
  return (
    <div>
      <MouseTracker
        render={({ x, y }) => <p>위치: {x}, {y}</p>}
      />
      <DataFetcher url="/api/users">
        {({ data, loading }) =>
          loading ? <p>로딩...</p> : <ul>{data?.map(u => <li key={u.id}>{u.name}</li>)}</ul>
        }
      </DataFetcher>
    </div>
  )
}
```

## HOC (Higher-Order Component) 패턴

컴포넌트를 받아 강화된 컴포넌트를 반환하는 함수입니다.

```jsx
// withAuth — 인증된 사용자만 접근 가능하게 하는 HOC
function withAuth(WrappedComponent) {
  return function AuthenticatedComponent(props) {
    const { isLoggedIn } = useAuthStore()

    if (!isLoggedIn) {
      return <Navigate to="/login" />
    }

    return <WrappedComponent {...props} />
  }
}

// withLoading — 로딩 상태 처리 HOC
function withLoading(WrappedComponent) {
  return function WithLoadingComponent({ isLoading, ...props }) {
    if (isLoading) return <Spinner />
    return <WrappedComponent {...props} />
  }
}

// 사용
const ProtectedDashboard = withAuth(Dashboard)
const DashboardWithLoading = withLoading(withAuth(Dashboard))
```

## Composition 패턴 (합성)

작은 컴포넌트를 조합해 복잡한 UI를 만드는 React의 기본 철학입니다.

```jsx
// 특수화(Specialization) — 범용 컴포넌트를 특수화
function Dialog({ title, content, footer }) {
  return (
    <div className="dialog">
      <div className="dialog-header">{title}</div>
      <div className="dialog-body">{content}</div>
      <div className="dialog-footer">{footer}</div>
    </div>
  )
}

function ConfirmDialog({ message, onConfirm, onCancel }) {
  return (
    <Dialog
      title="확인"
      content={<p>{message}</p>}
      footer={
        <>
          <button onClick={onConfirm}>확인</button>
          <button onClick={onCancel}>취소</button>
        </>
      }
    />
  )
}

// 컨테이너/프레젠테이션 분리
function UserListContainer() {
  const { data: users, loading } = useFetch('/api/users')
  return <UserListView users={users} loading={loading} />
}

function UserListView({ users, loading }) {
  if (loading) return <Skeleton />
  return <ul>{users?.map(u => <li key={u.id}>{u.name}</li>)}</ul>
}
```

## 패턴 선택 기준

```
Compound Component
  - 관련 컴포넌트가 상태를 공유해야 할 때
  - 유연한 레이아웃 조합이 필요할 때
  예: 탭, 드롭다운, 아코디언

Render Props
  - 렌더링 로직을 외부에서 제어해야 할 때
  - 커스텀 훅으로 대체 가능한 경우가 많음
  예: 마우스 트래커, 데이터 페처

HOC
  - 여러 컴포넌트에 동일한 기능을 주입할 때
  - 인증, 권한, 로깅, 에러 처리
  주의: 커스텀 훅 도입 후 HOC의 사용 빈도가 줄었음

Composition
  - React의 기본 원칙
  - 거의 모든 상황에서 우선적으로 고려
```

## 핵심 정리

- Compound Component는 Context로 상태를 공유하며 유연한 컴포넌트 조합을 만듭니다.
- Render Props는 렌더링 로직을 함수 prop으로 위임합니다 (커스텀 훅으로 대부분 대체 가능).
- HOC는 컴포넌트를 받아 강화된 컴포넌트를 반환하는 함수입니다.
- Composition은 작은 컴포넌트를 조합하는 React의 핵심 설계 원칙입니다.
