## 왜 커스텀 훅이 필요한가?

여러 컴포넌트에서 같은 로직이 반복될 때, 커스텀 훅으로 추출해 재사용합니다.

```jsx
// UserProfile.jsx — 데이터 패칭 로직
function UserProfile({ userId }) {
  const [user, setUser] = useState(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    fetch(`/api/users/${userId}`)
      .then(r => r.json())
      .then(data => { setUser(data); setLoading(false) })
      .catch(err => { setError(err.message); setLoading(false) })
  }, [userId])

  ...
}

      .catch(err => { setError(err.message); setLoading(false) })
```

## 커스텀 훅 만들기

커스텀 훅은 `use`로 시작하는 함수입니다. 내부에서 React 훅을 사용할 수 있습니다.

```jsx
// hooks/useFetch.js
function useFetch(url) {
  const [data, setData] = useState(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    setLoading(true)
    setError(null)

    fetch(url)
      .then(r => {
        if (!r.ok) throw new Error('응답 오류')
        return r.json()
      })
      .then(data => {
        setData(data)
        setLoading(false)
      })
      .catch(err => {
        setError(err.message)
        setLoading(false)
      })
  }, [url])

  return { data, loading, error }
}
```

```jsx
// 사용 — 로직이 한 줄로 줄어듦
function UserProfile({ userId }) {
  const { data: user, loading, error } = useFetch(`/api/users/${userId}`)

  if (loading) return <p>로딩 중...</p>
  if (error) return <p>에러: {error}</p>
  return <h1>{user.name}</h1>
}

function PostList() {
  const { data: posts, loading, error } = useFetch('/api/posts')

  if (loading) return <p>로딩 중...</p>
  if (error) return <p>에러: {error}</p>
  return <ul>{posts.map(p => <li key={p.id}>{p.title}</li>)}</ul>
}
```

## 자주 쓰이는 커스텀 훅 패턴

### useLocalStorage

```jsx
function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const stored = localStorage.getItem(key)
    return stored ? JSON.parse(stored) : initialValue
  })

  function setStoredValue(newValue) {
    setValue(newValue)
    localStorage.setItem(key, JSON.stringify(newValue))
  }

  return [value, setStoredValue]
}

// 사용
function Settings() {
  const [theme, setTheme] = useLocalStorage('theme', 'light')

  return (
    <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
      현재 테마: {theme}
    </button>
  )
}
```

### useDebounce

입력이 멈춘 후 일정 시간이 지났을 때만 값을 업데이트합니다. 검색창 API 호출 최소화에 사용합니다.

```jsx
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}

// 사용 — 타이핑 500ms 후 검색
function SearchBar() {
  const [query, setQuery] = useState('')
  const debouncedQuery = useDebounce(query, 500)

  useEffect(() => {
    if (debouncedQuery) {
      console.log('검색:', debouncedQuery)
    }
  }, [debouncedQuery])

  return <input value={query} onChange={e => setQuery(e.target.value)} />
}
```

## 커스텀 훅 규칙

1. 이름은 반드시 `use`로 시작 — React가 훅 규칙을 적용할 수 있도록.
2. 다른 훅(useState, useEffect 등)을 내부에서 사용할 수 있음.
3. 값(상태, 함수)을 반환. 배열, 객체, 또는 단일 값 모두 가능.
4. 일반 함수처럼 여러 컴포넌트에서 호출 가능. 각 컴포넌트는 독립적인 상태를 가짐.

### 왜 훅은 조건문·반복문 안에서 호출하면 안 되는가?

"훅은 항상 컴포넌트 최상위에서, 조건 없이 호출해야 한다"는 규칙을 들어봤을 것입니다. 이 규칙이 왜 존재하는지 이해하면 훅을 훨씬 안전하게 쓸 수 있습니다.

React는 각 컴포넌트의 훅들을 **호출된 순서대로** 하나의 목록처럼 기억합니다. `useState`, `useEffect`를 순서대로 3번 호출하면, React 내부에는 "1번째 훅, 2번째 훅, 3번째 훅"이라는 순서로 상태가 저장됩니다. 리렌더링될 때도 React는 "이번에도 순서대로 호출되겠지"라고 가정하고 각 훅에 저장된 값을 순서대로 다시 연결합니다.

```jsx
// ❌ 조건문 안에서 훅 호출 — 절대 금지
function BadComponent({ isLoggedIn }) {
  if (isLoggedIn) {
    const [name, setName] = useState('')  // 조건에 따라 호출되거나 안 되거나
  }
  const [count, setCount] = useState(0)
  // isLoggedIn이 true→false로 바뀌면, count가 "1번째 훅"에서 "2번째 훅" 자리로 밀려버림
  // → React가 엉뚱한 값을 연결해 버그 발생
}
```

`isLoggedIn`이 바뀌어 호출되는 훅의 개수나 순서가 달라지면, React가 "몇 번째 훅"과 실제 상태를 잘못 연결해 완전히 엉뚱한 값을 돌려주거나 에러가 발생합니다.

> **쉽게 말하면:** React에게 훅은 "이름표가 없는 옷장 서랍" 같아서, 오직 "순서"로만 어떤 서랍인지 구별합니다. 조건에 따라 서랍을 열었다 안 열었다 하면, 다음번에 몇 번째 서랍을 열어야 할지 알 수 없게 됩니다.

---

## 핵심 정리

- 커스텀 훅: `use`로 시작하는 함수. 내부에서 React 훅 사용 가능.
- 반복되는 훅 로직을 추출해 재사용. 컴포넌트는 깔끔해지고 로직은 분리됨.
- 각 컴포넌트에서 커스텀 훅을 호출하면 **독립적인 상태**를 가짐.
- 자주 쓰는 패턴: `useFetch`, `useLocalStorage`, `useDebounce`, `useToggle`.
