## React 이벤트 핸들러

HTML에서는 `onclick="함수()"` 처럼 문자열로 이벤트를 등록합니다. React에서는 JSX prop으로 **함수를 직접 전달**합니다.

```jsx
// HTML 방식
<button onclick="handleClick()">클릭</button>

// React 방식
function Button() {
  function handleClick() {
    alert('클릭!')
  }

  return <button onClick={handleClick}>클릭</button>
}
```

주요 차이점:
- 이벤트 이름은 **camelCase**: `onclick` → `onClick`, `onchange` → `onChange`
- **함수를 전달**하지 문자열을 전달하지 않는다
- `onClick={handleClick}` — 괄호 없이 함수 자체를 전달. `onClick={handleClick()}` 은 실행 결과(보통 undefined)를 전달.

## 합성 이벤트 (SyntheticEvent)

React는 브라우저마다 다른 이벤트를 **합성 이벤트(SyntheticEvent)** 로 통일합니다. 덕분에 크로스 브라우저 호환성 걱정 없이 `event.target.value` 같은 표준 속성을 씁니다.

```jsx
function InputExample() {
  function handleChange(event) {
    console.log(event.target.value)  // 입력된 값
    console.log(event.type)          // 'change'
  }

  return <input onChange={handleChange} />
}
```

## 자주 쓰는 이벤트 핸들러

```jsx
function EventExamples() {
  return (
    <div>
      {/* 마우스 이벤트 */}
      <button onClick={() => console.log('클릭')}>클릭</button>
      <div onMouseEnter={() => console.log('마우스 올림')}>호버</div>

      {/* 키보드 이벤트 */}
      <input
        onKeyDown={e => {
          if (e.key === 'Enter') console.log('엔터 키 누름')
        }}
      />

      {/* 폼 이벤트 */}
      <input onChange={e => console.log(e.target.value)} />

      {/* 포커스 이벤트 */}
      <input
        onFocus={() => console.log('포커스 들어옴')}
        onBlur={() => console.log('포커스 나감')}
      />
    </div>
  )
}
```

## 이벤트 핸들러에 인수 전달하기

이벤트 핸들러에 추가 데이터를 전달하려면 화살표 함수로 감쌉니다.

```jsx
function ItemList() {
  const items = ['사과', '바나나', '포도']

  function handleDelete(itemName) {
    console.log(`${itemName} 삭제`)
  }

  return (
    <ul>
      {items.map(item => (
        <li key={item}>
          {item}
          {/* 화살표 함수로 감싸서 인수 전달 */}
          <button onClick={() => handleDelete(item)}>삭제</button>
        </li>
      ))}
    </ul>
  )
}
```

## 이벤트 버블링과 전파 제어

**이벤트 버블링(Event Bubbling)** 은 자식 요소의 이벤트가 부모 요소로 전파되는 현상입니다.

```jsx
function BubblingExample() {
  return (
    <div onClick={() => console.log('div 클릭됨')}>
      <button onClick={() => console.log('button 클릭됨')}>
        클릭
      </button>
    </div>
  )
}
// 버튼 클릭 시: "button 클릭됨" → "div 클릭됨" 순서로 출력
```

전파를 막으려면 `event.stopPropagation()`을 호출합니다.

```jsx
<button onClick={e => {
  e.stopPropagation()  // 부모로 전파 차단
  console.log('button만 실행됨')
}}>
  클릭
</button>
```

폼의 기본 동작(페이지 새로고침)을 막으려면 `event.preventDefault()`를 사용합니다.

```jsx
function LoginForm() {
  function handleSubmit(e) {
    e.preventDefault()  // 폼 기본 제출 동작 차단
    console.log('폼 제출')
  }

  return (
    <form onSubmit={handleSubmit}>
      <input type="email" />
      <button type="submit">로그인</button>
    </form>
  )
}
```

## 이벤트 핸들러와 상태 함께 사용

이벤트 핸들러에서 상태를 바꾸면 리렌더링이 일어납니다.

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>카운트: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(count - 1)}>-1</button>
    </div>
  )
}

function ToggleButton() {
  const [isOn, setIsOn] = useState(false)

  return (
    <button
      onClick={() => setIsOn(!isOn)}
      style={{ backgroundColor: isOn ? 'green' : 'gray' }}
    >
      {isOn ? '켜짐' : '꺼짐'}
    </button>
  )
}
```

## 핵심 정리

- React 이벤트 이름은 **camelCase**: `onClick`, `onChange`, `onKeyDown` 등.
- 이벤트 핸들러에 **함수를 전달**. `onClick={fn}` (O), `onClick={fn()}` (X).
- React가 합성 이벤트로 브라우저 차이를 통일. `e.target.value`로 입력 값 접근.
- 추가 인수 전달: `onClick={() => fn(인수)}` 화살표 함수로 감싸기.
- `e.stopPropagation()`: 이벤트 버블링 차단. `e.preventDefault()`: 기본 동작 차단.
