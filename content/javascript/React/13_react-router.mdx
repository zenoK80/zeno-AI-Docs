## React Router v6 기본 설정

```bash
npm install react-router-dom
```

```jsx
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom'

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">홈</Link>
        <Link to="/about">소개</Link>
        <Link to="/users">사용자</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/users" element={<Users />} />
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  )
}
```

## useNavigate — 프로그래밍 방식 이동

```jsx
import { useNavigate } from 'react-router-dom'

function LoginForm() {
  const navigate = useNavigate()

  const handleSubmit = async (e) => {
    e.preventDefault()
    await login()
    navigate('/dashboard')          // 이동
    // navigate(-1)                 // 뒤로 가기
    // navigate('/home', { replace: true })  // 히스토리 교체
  }

  return <form onSubmit={handleSubmit}>...</form>
}
```

## useParams — URL 파라미터 읽기

```jsx
import { useParams } from 'react-router-dom'

// Route: <Route path="/users/:id" element={<UserDetail />} />
function UserDetail() {
  const { id } = useParams()

  return <p>사용자 ID: {id}</p>
}
```

## useSearchParams — 쿼리 문자열

```jsx
import { useSearchParams } from 'react-router-dom'

// URL: /search?q=react&page=1
function SearchPage() {
  const [searchParams, setSearchParams] = useSearchParams()
  const query = searchParams.get('q') || ''
  const page = Number(searchParams.get('page')) || 1

  return (
    <div>
      <p>검색어: {query}</p>
      <button onClick={() => setSearchParams({ q: query, page: page + 1 })}>
        다음 페이지
      </button>
    </div>
  )
}
```

## 중첩 라우팅 (Nested Routes)

```jsx
import { Outlet } from 'react-router-dom'

// Layout 컴포넌트 — Outlet이 자식 라우트를 렌더링
function DashboardLayout() {
  return (
    <div>
      <nav>
        <Link to="profile">프로필</Link>
        <Link to="settings">설정</Link>
      </nav>
      <main>
        <Outlet />
      </main>
    </div>
  )
}

// 라우트 정의
function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/dashboard" element={<DashboardLayout />}>
          <Route index element={<DashboardHome />} />      {/* /dashboard */}
          <Route path="profile" element={<Profile />} />  {/* /dashboard/profile */}
          <Route path="settings" element={<Settings />} />{/* /dashboard/settings */}
        </Route>
      </Routes>
    </BrowserRouter>
  )
}
```

## NavLink — 활성 링크 스타일

```jsx
import { NavLink } from 'react-router-dom'

function Nav() {
  return (
    <nav>
      <NavLink
        to="/home"
        style={({ isActive }) => ({ color: isActive ? 'red' : 'black' })}
      >
        홈
      </NavLink>
      <NavLink
        to="/about"
        className={({ isActive }) => isActive ? 'active-link' : ''}
      >
        소개
      </NavLink>
    </nav>
  )
}
```

## v5 vs v6 주요 변경점

```
v5                              v6
Switch                       →  Routes
exact prop 필요              →  기본이 exact 매칭
component={Comp}             →  element={<Comp />}
useHistory()                 →  useNavigate()
중첩 라우트 별도 설정        →  <Outlet />으로 간단하게
```

## 핵심 정리

- `BrowserRouter`로 앱을 감싸고 `Routes`/`Route`로 경로를 정의합니다.
- `Link`와 `NavLink`는 페이지 새로고침 없이 이동합니다.
- `useNavigate()`로 코드에서 이동하고, `useParams()`로 URL 파라미터를 읽습니다.
- 중첩 라우팅은 `Outlet`을 통해 부모 레이아웃 안에 자식 라우트를 렌더링합니다.
