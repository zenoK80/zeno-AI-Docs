## React 이벤트 기본

```jsx
function Button() {
  const handleClick = (event) => {
    event.preventDefault()
    console.log('클릭됨', event.type)
  }

  return <button onClick={handleClick}>클릭</button>
}
```

HTML과의 차이:

- 이벤트 이름: camelCase (`onclick` → `onClick`)
- 핸들러: 함수 참조 (`"handleClick()"` → `{handleClick}`)
- 기본 동작 방지: `return false` 불가, `e.preventDefault()` 사용

## 합성 이벤트 (SyntheticEvent)

React는 브라우저 네이티브 이벤트를 래핑한 **합성 이벤트**를 사용합니다.

```jsx
function InputTracker() {
  const handleInput = (e) => {
    console.log(e.target.value)       // 입력값
    console.log(e.type)               // 'input'
    console.log(e.nativeEvent)        // 네이티브 이벤트
  }

  return <input onInput={handleInput} />
}
```

## 이벤트에 인수 전달

```jsx
function TodoList() {
  const handleDelete = (id, e) => {
    e.stopPropagation()
    console.log('삭제:', id)
  }

  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id} onClick={() => handleDelete(todo.id)}>
          {todo.text}
          <button onClick={(e) => handleDelete(todo.id, e)}>삭제</button>
        </li>
      ))}
    </ul>
  )
}
```

## 자주 사용하는 이벤트

```jsx
function Form() {
  return (
    <form onSubmit={(e) => {
      e.preventDefault()
      console.log('폼 제출')
    }}>
      <input
        onChange={(e) => console.log(e.target.value)}
        onFocus={() => console.log('포커스')}
        onBlur={() => console.log('블러')}
        onKeyDown={(e) => {
          if (e.key === 'Enter') console.log('엔터 입력')
        }}
      />
      <button type="submit">제출</button>
    </form>
  )
}
```

## 마우스 이벤트

```jsx
function HoverCard() {
  const [isHovered, setIsHovered] = useState(false)

  return (
    <div
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      style={{ background: isHovered ? '#e0e0e0' : 'white' }}
    >
      {isHovered ? '마우스가 올라와 있습니다!' : '마우스를 올려보세요'}
    </div>
  )
}
```

## 핵심 정리

- React 이벤트는 camelCase로 작성합니다.
- 핸들러에 함수 참조를 전달합니다(즉시 호출 `{fn()}` 금지).
- 합성 이벤트로 브라우저 간 일관성을 제공합니다.
- `e.preventDefault()`로 기본 동작을 막고, `e.stopPropagation()`으로 전파를 중단합니다.
