  **이번 문서의 목표:** useRef로 DOM에 직접 접근하고, 렌더링 없이 값을 유지하는 방법을 이해합니다.
</Callout>

## useRef 기본

`useRef`는 `.current` 프로퍼티를 가진 객체를 반환합니다. 값이 변해도 리렌더링을 발생시키지 않습니다.

```jsx
import { useRef } from 'react'

function TextInput() {
  const inputRef = useRef(null)  // 초기값 null

  const focusInput = () => {
    inputRef.current.focus()  // DOM에 직접 접근
  }

  return (
    <>
      <input ref={inputRef} type="text" placeholder="입력하세요" />
      <button onClick={focusInput}>포커스</button>
    </>
  )
}
```

## DOM 접근 패턴

```jsx
function ImageWithDimensions() {
  const imgRef = useRef(null)
  const [dimensions, setDimensions] = useState({ width: 0, height: 0 })

  useEffect(() => {
    if (imgRef.current) {
      setDimensions({
        width: imgRef.current.naturalWidth,
        height: imgRef.current.naturalHeight,
      })
    }
  }, [])

  return (
    <>
      <img ref={imgRef} src="/photo.jpg" alt="사진" onLoad={() => {
        setDimensions({
          width: imgRef.current.naturalWidth,
          height: imgRef.current.naturalHeight,
        })
      }} />
      <p>크기: {dimensions.width} x {dimensions.height}</p>
    </>
  )
}
```

## 렌더링 없는 값 유지

```jsx
function StopwatchWithRef() {
  const [time, setTime] = useState(0)
  const intervalRef = useRef(null)  // 인터벌 ID 저장

  const start = () => {
    if (intervalRef.current) return  // 이미 실행 중
    intervalRef.current = setInterval(() => {
      setTime(prev => prev + 1)
    }, 100)
  }

  const stop = () => {
    clearInterval(intervalRef.current)
    intervalRef.current = null
  }

  return (
    <div>
      <p>{(time / 10).toFixed(1)}초</p>
      <button onClick={start}>시작</button>
      <button onClick={stop}>정지</button>
    </div>
  )
}
```

## 이전 값 기억하기

```jsx
function CountWithPrev() {
  const [count, setCount] = useState(0)
  const prevCountRef = useRef(0)

  useEffect(() => {
    prevCountRef.current = count  // 렌더링 후 업데이트
  })

  return (
    <div>
      <p>현재: {count}, 이전: {prevCountRef.current}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  )
}
```

## useRef vs useState

| | useRef | useState |
| --- | --- | --- |
| 리렌더링 | 발생 안 함 | 발생 |
| 용도 | DOM 접근, 값 유지 | UI에 반영될 데이터 |
| .current | 직접 수정 가능 | setter 함수로만 변경 |

## 핵심 정리

- `useRef`로 DOM 요소에 직접 접근합니다.
- `ref.current`는 렌더링 없이 값을 저장하고 변경할 수 있습니다.
- 타이머 ID, 이전 값, 포커스 제어 등에 활용합니다.
