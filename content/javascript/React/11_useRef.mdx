</Callout>

## useRef란?

`useRef`는 두 가지 용도로 쓰입니다.

1. **DOM 요소에 직접 접근** — 포커스 이동, 스크롤, 미디어 재생 등
2. **리렌더링 없이 값을 보관** — 이전 값 기억, 타이머 ID 저장 등

`useRef(초기값)` 는 `{ current: 초기값 }` 형태의 객체를 반환합니다. `current` 값을 바꿔도 리렌더링이 일어나지 않습니다.

> **쉽게 말하면:** `useRef`는 컴포넌트 함수 밖에 있는 "메모장"입니다. 적어도 화면이 바뀌지 않고, 함수가 재실행돼도 값이 유지됩니다.

<Callout type="warning">
  **렌더링 도중에는 ref를 읽거나 쓰지 않습니다.** `useState`의 state는 "이번 렌더링에서의 스냅샷"이라 렌더링 중에 읽어도 안전하지만, `ref.current`는 렌더링 중간에도 바뀔 수 있는 값이라 예측 불가능한 결과를 만들 수 있습니다. `ref.current`는 이벤트 핸들러나 `useEffect` 안에서만 읽고 쓰는 것이 원칙입니다.
</Callout>

## DOM 접근 — input 포커스

<CodePlayground
  template="react"
  activeFile="/App.js"
  label="DOM 포커스 실습"
  files={{
    '/App.js': `import { useRef, useEffect } from 'react'

export default function AutoFocusInput() {
  const inputRef = useRef(null)

  useEffect(() => {
    // 컴포넌트가 마운트되면 자동 포커스
    inputRef.current.focus()
  }, [])

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="자동 포커스" />
      <button onClick={() => inputRef.current.focus()}>
        다시 포커스
      </button>
    </div>
  )
}`,
  }}
/>

`ref={inputRef}` 로 DOM 요소에 ref를 연결하면, `inputRef.current` 가 실제 DOM 요소를 가리킵니다.

## DOM 접근 — 스크롤·미디어 제어

```jsx
function VideoPlayer() {
  const videoRef = useRef(null)

  function handlePlay() {
    videoRef.current.play()
  }

  function handlePause() {
    videoRef.current.pause()
  }

  return (
    <div>
      <video ref={videoRef} src="/video.mp4" />
      <button onClick={handlePlay}>재생</button>
      <button onClick={handlePause}>일시정지</button>
    </div>
  )
}

function ScrollToBottom() {
  const bottomRef = useRef(null)

  function scrollDown() {
    bottomRef.current.scrollIntoView({ behavior: 'smooth' })
  }

  return (
    <div>
      <p>긴 내용...</p>
      <button onClick={scrollDown}>맨 아래로</button>
      <div ref={bottomRef} />
    </div>
  )
}
```

## 렌더링 없이 값 보관

`useState`와 달리 `useRef`의 `current`를 바꿔도 리렌더링이 일어나지 않습니다. 타이머 ID, 이전 값, 렌더링 횟수 같은 것을 저장할 때 씁니다.

<CodePlayground
  template="react"
  activeFile="/App.js"
  label="타이머 ID 보관 실습 — 시작/정지 버튼을 눌러보세요"
  files={{
    '/App.js': `import { useState, useRef } from 'react'

export default function StopwatchWithRef() {
  const [seconds, setSeconds] = useState(0)
  const [running, setRunning] = useState(false)
  const timerRef = useRef(null)  // 타이머 ID 보관

  function start() {
    setRunning(true)
    timerRef.current = setInterval(() => {
      setSeconds(prev => prev + 1)
    }, 1000)
  }

  function stop() {
    setRunning(false)
    clearInterval(timerRef.current)
  }

  return (
    <div>
      <p>{seconds}초</p>
      <button onClick={start} disabled={running}>시작</button>
      <button onClick={stop} disabled={!running}>정지</button>
    </div>
  )
}`,
  }}
/>

## useState vs useRef 비교

| 기준 | useState | useRef |
| --- | --- | --- |
| 값 변경 시 | 리렌더링 발생 | 리렌더링 없음 |
| 주요 용도 | 화면에 표시되는 데이터 | DOM 접근, 타이머 ID, 이전 값 |
| 값 읽기 | `state` | `ref.current` |

```jsx
// ❌ 렌더링 횟수를 useState로 세면 무한 루프
function RenderCount() {
  const [count, setCount] = useState(0)
  // setCount(count + 1)를 렌더링 중에 호출하면 또 렌더링 → 무한 루프

  // ✅ useRef를 쓰면 렌더링 없이 카운트 유지
  const renderCount = useRef(0)
  renderCount.current++

  return <p>렌더링 횟수: {renderCount.current}</p>
}
```

## 이전 값 기억

현재 값과 이전 값을 함께 보여주고 싶을 때 useRef로 이전 값을 저장합니다.

```jsx
function PreviousValue() {
  const [count, setCount] = useState(0)
  const prevCountRef = useRef(null)

  useEffect(() => {
    prevCountRef.current = count  // 렌더링 후 현재 값을 저장
  })

  return (
    <div>
      <p>현재: {count}</p>
      <p>이전: {prevCountRef.current}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  )
}
```

## 핵심 정리

- `useRef`는 `{ current: 값 }` 객체를 반환. `current` 변경 시 리렌더링 없음.
- `ref={refObject}` 로 DOM 요소에 연결하면 `refObject.current`가 DOM 요소.
- **DOM 접근 용도**: 포커스, 스크롤, 미디어 재생 등 React가 직접 제어하기 어려운 DOM 작업.
- **값 보관 용도**: 타이머 ID, 이전 값, 렌더링 횟수 등 화면에 영향 없는 내부 데이터.
