## 함수형 컴포넌트

```jsx
// 기본 함수형 컴포넌트
function Greeting() {
  return <h1>안녕하세요!</h1>
}

// 화살표 함수
const Greeting = () => <h1>안녕하세요!</h1>

// 컴포넌트 이름은 반드시 대문자로 시작
export default Greeting
```

## Props

```jsx
// props로 데이터 전달
function UserCard({ name, age, role = '일반 사용자' }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>나이: {age}</p>
      <p>역할: {role}</p>
    </div>
  )
}

// 사용
function App() {
  return (
    <div>
      <UserCard name="김철수" age={25} role="관리자" />
      <UserCard name="이영희" age={30} />
    </div>
  )
}
```

## props는 읽기 전용

```jsx
function BadComponent({ count }) {
  count = count + 1  // 오류: props를 직접 수정하면 안 됨
  return <p>{count}</p>
}

function GoodComponent({ count }) {
  const displayCount = count + 1  // 새 변수 사용
  return <p>{displayCount}</p>
}
```

## children prop

```jsx
function Card({ title, children }) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-body">{children}</div>
    </div>
  )
}

function App() {
  return (
    <Card title="공지사항">
      <p>내용이 여기에 들어갑니다.</p>
      <button>확인</button>
    </Card>
  )
}
```

## 컴포넌트 합성

```jsx
function Avatar({ src, size = 50 }) {
  return <img src={src} width={size} height={size} style={{ borderRadius: '50%' }} alt="아바타" />
}

function UserInfo({ user }) {
  return (
    <div className="user-info">
      <Avatar src={user.avatarUrl} size={40} />
      <span>{user.name}</span>
    </div>
  )
}

function Comment({ author, text, createdAt }) {
  return (
    <div className="comment">
      <UserInfo user={author} />
      <p>{text}</p>
      <time>{createdAt}</time>
    </div>
  )
}
```

## props 스프레드

```jsx
const buttonProps = {
  type: 'button',
  className: 'btn-primary',
  disabled: false,
}

// 스프레드로 모든 props 전달
const el = <button {...buttonProps}>클릭</button>
```

## 핵심 정리

- 컴포넌트 이름은 대문자로 시작합니다.
- props는 부모에서 자식으로 전달하는 읽기 전용 데이터입니다.
- `children`으로 중첩된 JSX를 전달할 수 있습니다.
- 컴포넌트를 조합해 복잡한 UI를 구성합니다.
