## SPA와 라우팅

**SPA**(Single Page Application) 는 페이지 이동 시 서버에서 새 HTML을 받지 않고 JavaScript가 화면을 바꿉니다. URL은 바뀌지만 실제 페이지 새로고침은 없습니다. React Router가 URL과 컴포넌트를 연결합니다.

```bash
npm install react-router-dom
```

---

## 기본 설정

```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom'

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
        <Route path="/posts" element={<PostsPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Routes>
    </BrowserRouter>
  )
}
```

- `BrowserRouter`: HTML5 History API 기반 라우터
- `Routes`: 현재 URL에 맞는 첫 번째 `Route` 렌더링
- `Route path`: URL 패턴, `element`: 렌더링할 컴포넌트
- `path="*"`: 매칭되지 않는 모든 URL (404 페이지)

## 링크 컴포넌트

`a` 태그 대신 `Link`를 씁니다. 페이지 새로고침 없이 이동합니다.

```jsx
import { Link, NavLink } from 'react-router-dom'

function Navigation() {
  return (
    <nav>
      <Link to="/">홈</Link>
      <Link to="/about">소개</Link>

      {/* NavLink: 현재 페이지에 active 클래스 자동 추가 */}
      <NavLink
        to="/posts"
        style={({ isActive }) => ({ fontWeight: isActive ? 'bold' : 'normal' })}
      >
        게시글
      </NavLink>
    </nav>
  )
}
```

## 동적 경로 파라미터

```jsx
// :id가 URL 파라미터
<Route path="/posts/:id" element={<PostDetail />} />

// useParams로 파라미터 읽기
import { useParams } from 'react-router-dom'

function PostDetail() {
  const { id } = useParams()

  return <p>게시물 ID: {id}</p>
}
```

`/posts/42` 접속 시 `id === '42'`.

## 중첩 라우트

레이아웃을 공유하는 페이지들을 중첩 라우트로 만듭니다.

```jsx
function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<HomePage />} />
          <Route path="about" element={<AboutPage />} />
          <Route path="posts" element={<PostsPage />} />
          <Route path="posts/:id" element={<PostDetail />} />
        </Route>
      </Routes>
    </BrowserRouter>
  )
}

// 부모 레이아웃 컴포넌트
import { Outlet } from 'react-router-dom'

function Layout() {
  return (
    <div>
      <Navigation />
      <main>
        <Outlet />  {/* 자식 라우트가 여기에 렌더링됨 */}
      </main>
      <footer>푸터</footer>
    </div>
  )
}
```

`Outlet`은 현재 URL에 맞는 자식 라우트 컴포넌트를 렌더링하는 자리 표시자입니다.

## 쿼리 파라미터

```jsx
// /posts?category=react&page=2
import { useSearchParams } from 'react-router-dom'

function PostsPage() {
  const [searchParams, setSearchParams] = useSearchParams()
  const category = searchParams.get('category') || 'all'
  const page = Number(searchParams.get('page')) || 1

  return (
    <div>
      <p>카테고리: {category}, 페이지: {page}</p>
      <button onClick={() => setSearchParams({ category, page: page + 1 })}>
        다음 페이지
      </button>
    </div>
  )
}
```

## 프로그래매틱 네비게이션

버튼 클릭, 폼 제출 후 코드로 페이지를 이동합니다.

```jsx
import { useNavigate } from 'react-router-dom'

function LoginForm() {
  const navigate = useNavigate()

  async function handleSubmit(e) {
    e.preventDefault()
    // 로그인 처리...
    navigate('/dashboard')         // 이동
    navigate(-1)                   // 뒤로 가기
    navigate('/login', { replace: true })  // 히스토리 교체
  }

  return <form onSubmit={handleSubmit}>...</form>
}
```

---

## 핵심 정리

- `BrowserRouter` → `Routes` → `Route` 계층으로 설정.
- 링크: `Link to=""`, 현재 페이지 감지: `NavLink`.
- 동적 경로: `path="/posts/:id"` → `useParams()`로 읽기.
- 중첩 라우트: 부모 레이아웃에 `Outlet` 배치.
- 쿼리 파라미터: `useSearchParams()`.
- 코드로 이동: `useNavigate()`.
