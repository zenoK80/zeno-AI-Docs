## 조건부 렌더링 패턴

```jsx
function StatusBadge({ status }) {
  // 1. if 문 (컴포넌트 전체를 조건 분기)
  if (status === 'loading') return <p>로딩 중...</p>
  if (status === 'error') return <p>오류 발생</p>

  // 2. 삼항 연산자
  return (
    <span className={status === 'active' ? 'badge-green' : 'badge-gray'}>
      {status === 'active' ? '활성' : '비활성'}
    </span>
  )
}
```

```jsx
function Notification({ count }) {
  return (
    <div>
      {/* 3. && 단락 평가 */}
      {count > 0 && <span className="badge">{count}</span>}

      {/* 주의: 0은 렌더링됨 */}
      {count && <span>{count}</span>}  {/* count가 0이면 '0'이 출력 */}
      {count > 0 && <span>{count}</span>}  {/* 안전한 방법 */}
    </div>
  )
}
```

```jsx
function Page({ role }) {
  // 4. 변수에 저장
  let content
  if (role === 'admin') {
    content = <AdminPanel />
  } else {
    content = <UserDashboard />
  }

  return <main>{content}</main>
}
```

## 리스트 렌더링

```jsx
const products = [
  { id: 1, name: '노트북', price: 1200000 },
  { id: 2, name: '마우스', price: 45000 },
  { id: 3, name: '키보드', price: 85000 },
]

function ProductList() {
  return (
    <ul>
      {products.map(product => (
        <li key={product.id}>
          {product.name} - {product.price.toLocaleString()}원
        </li>
      ))}
    </ul>
  )
}
```

## key의 규칙

```jsx
// 올바른 key: 고유하고 안정적인 ID
{items.map(item => <li key={item.id}>{item.name}</li>)}

// 피해야 할 key: 인덱스 (순서 변경 시 문제)
{items.map((item, index) => <li key={index}>{item.name}</li>)}

// key는 형제 사이에서만 고유하면 됨
function Section({ items }) {
  return (
    <>
      <ul>
        {items.map(item => <li key={item.id}>{item.name}</li>)}
      </ul>
      <ol>
        {items.map(item => <li key={item.id}>{item.name}</li>)}
      </ol>
    </>
  )
}
```

## 필터링과 정렬

```jsx
function FilteredList({ items, filter }) {
  const filtered = items
    .filter(item => item.category === filter)
    .sort((a, b) => a.name.localeCompare(b.name))

  if (filtered.length === 0) return <p>결과가 없습니다.</p>

  return (
    <ul>
      {filtered.map(item => <li key={item.id}>{item.name}</li>)}
    </ul>
  )
}
```

## 핵심 정리

- JSX에서 조건부 렌더링은 삼항 연산자, `&&`, if 문 등으로 구현합니다.
- `&&` 사용 시 falsy 0은 렌더링되므로 `count > 0 &&`처럼 명확히 합니다.
- 리스트 각 항목에는 고유하고 안정적인 `key`를 부여합니다.
- 인덱스를 key로 쓰면 항목 순서 변경 시 버그가 생길 수 있습니다.
