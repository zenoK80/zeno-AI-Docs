## Portal — DOM 계층 밖에 렌더링

일반적으로 React 컴포넌트는 부모의 DOM 안에 렌더링됩니다. 하지만 **모달, 툴팁, 드롭다운** 같은 UI는 부모의 CSS(overflow: hidden, z-index 등)에 영향을 받으면 안 됩니다. Portal을 쓰면 DOM의 다른 위치에 렌더링할 수 있습니다.

function Modal({ isOpen, onClose, children }) {

  return createPortal(

      </div>
    </div>,

  )

  const [isOpen, setIsOpen] = useState(false)

  return (
    <div style={{ overflow: 'hidden' }}>
      <button onClick={() => setIsOpen(true)}>모달 열기</button>
      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
        <p>모달 내용. overflow: hidden 영향 안 받음!</p>
      </Modal>
    </div>
  )
}`,
  }}

Portal로 렌더링해도 React 이벤트 시스템과 Context는 정상 작동합니다.

## forwardRef — ref를 자식에게 전달

부모에서 자식 컴포넌트의 DOM 요소에 접근하려면 `forwardRef`가 필요합니다.

```jsx
import { forwardRef } from 'react'

// forwardRef로 감싸면 부모에서 전달한 ref를 받을 수 있음
const FancyInput = forwardRef(function FancyInput(props, ref) {
  return (
    <input
      ref={ref}  // 전달받은 ref를 DOM 요소에 연결
      className="fancy-input"
      {...props}
    />
  )
})

// 부모에서 자식 DOM에 접근
function Form() {
  const inputRef = useRef(null)

  function handleFocus() {
    inputRef.current.focus()
  }

  return (
    <div>
      <FancyInput ref={inputRef} placeholder="이름 입력" />
      <button onClick={handleFocus}>포커스</button>
    </div>
  )
}
```

## useImperativeHandle — ref API 제어

`forwardRef`와 함께 쓰면, 자식이 부모에 어떤 ref 인터페이스를 노출할지 제어할 수 있습니다.

```jsx
const VideoPlayer = forwardRef(function VideoPlayer(props, ref) {
  const videoRef = useRef(null)

  // 부모가 접근할 수 있는 메서드만 선택적으로 노출
  useImperativeHandle(ref, () => ({
    play: () => videoRef.current.play(),
    pause: () => videoRef.current.pause(),
    getTime: () => videoRef.current.currentTime,
  }))

  return <video ref={videoRef} src={props.src} />
})

function App() {
  const playerRef = useRef(null)

  return (
    <div>
      <VideoPlayer ref={playerRef} src="/video.mp4" />
      <button onClick={() => playerRef.current.play()}>재생</button>
      <button onClick={() => playerRef.current.pause()}>정지</button>
      {/* playerRef.current.style 같은 내부 DOM은 접근 불가 */}
    </div>
  )
}
```

## 코드 스플리팅 패턴

라우트 단위로 코드를 분할해 성능을 개선합니다.

```jsx
import { lazy, Suspense } from 'react'
import { Routes, Route } from 'react-router-dom'

const HomePage = lazy(() => import('./pages/HomePage'))
const AboutPage = lazy(() => import('./pages/AboutPage'))
const Dashboard = lazy(() => import('./pages/Dashboard'))

function App() {
  return (
    <Suspense fallback={<div>로딩 중...</div>}>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
        <Route path="/dashboard" element={<Dashboard />} />
      </Routes>
    </Suspense>
  )
}
```

## 옵티미스틱 업데이트

서버 응답을 기다리지 않고 먼저 UI를 업데이트해 반응성을 높이는 패턴입니다.

```jsx
function LikeButton({ postId, initialLiked, initialCount }) {
  const [liked, setLiked] = useState(initialLiked)
  const [count, setCount] = useState(initialCount)

  async function handleLike() {
    // 먼저 UI를 업데이트 (옵티미스틱)
    const newLiked = !liked
    setLiked(newLiked)
    setCount(c => newLiked ? c + 1 : c - 1)

    try {
      await fetch(`/api/posts/${postId}/like`, { method: 'POST' })
    } catch {
      // 실패 시 되돌리기
      setLiked(liked)
      setCount(c => newLiked ? c - 1 : c + 1)
    }
  }

  return (
    <button onClick={handleLike}>
      {liked ? '❤️' : '🤍'} {count}
    </button>
  )
}
```

## 핵심 정리

- **Portal**: 부모 DOM 외부에 렌더링. 모달, 툴팁, 드롭다운에 사용. `createPortal(JSX, 대상DOM)`.
- **forwardRef**: 부모가 자식의 DOM 요소를 ref로 접근할 수 있게 한다.
- **useImperativeHandle**: 자식이 노출할 ref 인터페이스를 직접 정의.
- **코드 스플리팅**: `lazy()` + `Suspense`로 라우트 단위 로딩 분리.
- **옵티미스틱 업데이트**: 서버 응답 전 UI를 먼저 변경해 반응성 향상.
