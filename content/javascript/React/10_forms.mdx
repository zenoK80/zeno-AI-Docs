## 제어 컴포넌트 vs 비제어 컴포넌트

폼 입력 값을 관리하는 방법은 두 가지입니다.

**비제어 컴포넌트**: HTML처럼 DOM이 값을 직접 관리. `useRef`로 필요할 때 읽음.
**제어 컴포넌트**: React state가 폼 값을 관리. 입력이 바뀔 때마다 state 업데이트.

React에서는 **제어 컴포넌트**를 권장합니다. 값을 항상 state에서 가져오므로 데이터 흐름이 일관됩니다.

> **쉽게 말하면:** 제어 컴포넌트는 입력창이 React 상태의 "거울"입니다. 상태가 바뀌면 입력창이 바뀌고, 입력창이 바뀌면 상태가 바뀝니다.

## 텍스트 입력 — 기본 패턴

```jsx
function NameForm() {
  const [name, setName] = useState('')

  function handleSubmit(e) {
    e.preventDefault()
    alert(`안녕하세요, ${name}님!`)
  }

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="name">이름:</label>
      <input
        id="name"
        type="text"
        value={name}         // state가 입력 값을 제어
        onChange={e => setName(e.target.value)}  // 입력 시 state 업데이트
      />
      <button type="submit">확인</button>
      <p>입력 중: {name}</p>
    </form>
  )
}
```

`value={name}` 으로 state와 연결하고, `onChange`로 바꿉니다. 이 두 가지가 항상 함께 다닙니다.

<Callout type="warning">
  **실무에서 자주 만나는 경고:** `useState(undefined)`나 `useState()`로 초기값을 안 주고 `value={state}`를 쓰면, 콘솔에 "A component is changing an uncontrolled input to be controlled"라는 경고가 뜹니다. 처음에는 `value`가 `undefined`라 "비제어"로 시작했다가, 값이 입력되는 순간 "제어" 컴포넌트로 바뀌기 때문입니다. 처음부터 빈 문자열(`useState('')`)로 초기화하면 이 문제가 생기지 않습니다.
</Callout>

## 여러 입력 필드 관리 — 객체 state

입력 필드가 여러 개라면 객체 state 하나로 관리합니다.

        type="email"
        value={form.email}
        onChange={handleChange}
        placeholder="이메일"
      />

        type="password"
        value={form.password}
        onChange={handleChange}
        placeholder="비밀번호"

    </form>

}`,

`e.target.name` 으로 어떤 필드인지 알고, `[name]: value` 처럼 계산된 속성 이름으로 해당 필드만 업데이트합니다.

## 체크박스와 라디오 버튼

체크박스는 `value` 대신 `checked`를 씁니다.

```jsx
function CheckboxExample() {
  const [agreed, setAgreed] = useState(false)

  return (
    <label>
      <input
        type="checkbox"
        checked={agreed}
        onChange={e => setAgreed(e.target.checked)}
      />
      이용약관에 동의합니다
    </label>
  )
}
```

라디오 버튼은 같은 `name` 그룹으로 묶고 `checked`를 비교합니다.

```jsx
function RadioExample() {
  const [size, setSize] = useState('medium')

  return (
    <div>
      {['small', 'medium', 'large'].map(s => (
        <label key={s}>
          <input
            type="radio"
            value={s}
            checked={size === s}
            onChange={() => setSize(s)}
          />
          {s}
        </label>
      ))}
      <p>선택: {size}</p>
    </div>
  )
}
```

## 기본 유효성 검사

```jsx
function LoginForm() {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [errors, setErrors] = useState({})

  function validate() {
    const newErrors = {}
    if (!email.includes('@')) {
      newErrors.email = '올바른 이메일을 입력하세요.'
    }
    if (password.length < 8) {
      newErrors.password = '비밀번호는 8자 이상이어야 합니다.'
    }
    return newErrors
  }

  function handleSubmit(e) {
    e.preventDefault()
    const newErrors = validate()
    if (Object.keys(newErrors).length > 0) {
      setErrors(newErrors)
      return
    }
    setErrors({})
    console.log('로그인:', { email, password })
  }

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <input
          type="email"
          value={email}
          onChange={e => setEmail(e.target.value)}
          placeholder="이메일"
        />
        {errors.email && <p style={{ color: 'red' }}>{errors.email}</p>}
      </div>
      <div>
        <input
          type="password"
          value={password}
          onChange={e => setPassword(e.target.value)}
          placeholder="비밀번호"
        />
        {errors.password && <p style={{ color: 'red' }}>{errors.password}</p>}
      </div>
      <button type="submit">로그인</button>
    </form>
  )
}
```

## 핵심 정리

- **제어 컴포넌트**: `value={state}` + `onChange={setState}` 쌍으로 입력과 상태를 연결.
- 여러 필드는 객체 state 하나로 관리. `e.target.name`으로 필드 구분.
- 체크박스: `checked={state}`, `onChange={e => setState(e.target.checked)}`.
- `e.preventDefault()`로 폼 기본 제출(새로고침) 차단.
- 유효성 검사는 제출 시 state 값을 검사하고 오류를 state로 표시.
