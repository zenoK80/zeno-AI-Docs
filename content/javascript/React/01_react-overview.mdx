## React란

**React**는 Facebook(Meta)이 만든 JavaScript UI 라이브러리입니다. 복잡한 UI를 컴포넌트 단위로 분리하고, 상태 변화에 따라 UI를 자동으로 갱신합니다.

- **선언적(Declarative):** "이런 UI를 보여줘"라고 선언하면 React가 DOM을 관리합니다.
- **컴포넌트 기반:** UI를 독립적이고 재사용 가능한 조각으로 나눕니다.
- **단방향 데이터 흐름:** 부모 → 자식으로 데이터(props)가 흐릅니다.

## 명령형 vs 선언형

```js
// 명령형 (Vanilla JS)
const btn = document.querySelector('button')
btn.textContent = `클릭 횟수: 0`
let count = 0
btn.addEventListener('click', () => {
  count++
  btn.textContent = `클릭 횟수: ${count}`
})
```

```jsx
// 선언형 (React)
function Counter() {
  const [count, setCount] = React.useState(0)
  return (
    <button onClick={() => setCount(count + 1)}>
      클릭 횟수: {count}
    </button>
  )
}
```

React에서는 상태(count)만 바꾸면 UI가 자동으로 갱신됩니다.

## 가상 DOM (Virtual DOM)

React는 실제 DOM 대신 **가상 DOM**(메모리 내 JavaScript 객체 트리)을 유지합니다.

1. 상태 변화 발생
2. 새로운 가상 DOM 트리 생성
3. 이전 가상 DOM과 비교 (**Diffing**)
4. 변경된 부분만 실제 DOM에 반영 (**Reconciliation**)

이 방식으로 불필요한 DOM 조작을 최소화합니다.

## 기본 구조

```jsx
// src/main.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
```

```jsx
// src/App.jsx
function App() {
  return <h1>Hello React!</h1>
}

export default App
```

## React 18의 주요 특징

- **Concurrent Mode:** 렌더링 우선순위 제어
- **Automatic Batching:** 여러 상태 업데이트를 한 번에 처리
- **`createRoot`:** 새 루트 렌더링 API

## 핵심 정리

- React는 컴포넌트 기반의 선언적 UI 라이브러리입니다.
- 가상 DOM으로 변경된 부분만 실제 DOM에 반영합니다.
- 상태가 바뀌면 UI가 자동으로 갱신됩니다.
