## 왜 HTML·CSS를 먼저 알아야 하나?

React는 화면(UI)을 만드는 라이브러리입니다. React가 만들어 내는 결과물은 결국 **HTML 문서**이고, 그 화면을 꾸미는 것은 **CSS**입니다. React에서 쓰는 JSX 문법은 HTML과 거의 똑같이 생겼기 때문에, HTML 태그와 CSS 기본 속성을 알아야 JSX를 읽을 수 있습니다.

> **쉽게 말하면:** React는 HTML을 JavaScript 안에서 더 편하게 쓸 수 있게 도와주는 도구입니다. HTML을 모르면 React 코드가 외계어처럼 보입니다.

## HTML 기본 구조

HTML(HyperText Markup Language)은 웹 페이지의 **뼈대**를 담당합니다. 내용을 **태그(tag)** 로 감싸서 의미를 부여합니다.

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <title>페이지 제목</title>
  </head>
  <body>
    <h1>제목</h1>
    <p>문단 내용</p>
    <button>클릭</button>
  </body>
</html>
```

### 자주 쓰는 HTML 태그

| 태그 | 용도 | 예시 |
| --- | --- | --- |
| `h1`~`h6` | 제목 (숫자가 클수록 작은 제목) | `<h1>큰 제목</h1>` |
| `p` | 문단(paragraph) | `<p>텍스트</p>` |
| `div` | 묶음 컨테이너 (의미 없음) | `<div>...</div>` |
| `span` | 인라인 묶음 컨테이너 | `<span>강조</span>` |
| `ul` / `li` | 순서 없는 목록 / 목록 항목 | `<ul><li>항목</li></ul>` |
| `button` | 버튼 | `<button>클릭</button>` |
| `input` | 입력창 | `<input type="text" />` |
| `img` | 이미지 | `<img src="..." alt="설명" />` |
| `a` | 링크 | `<a href="...">텍스트</a>` |

### 속성(attribute)

태그 안에 **속성**을 추가해서 태그의 동작이나 모습을 지정합니다.

```html
<!-- class: CSS 스타일 연결에 사용 -->
<div class="container">내용</div>

<!-- id: 고유 식별자 -->
<p id="intro">소개 문단</p>

<!-- href: 링크 주소 -->
<a href="https://react.dev">React 공식 문서</a>

<!-- src, alt: 이미지 주소와 대체 텍스트 -->
<img src="logo.png" alt="로고" />

<!-- type: input의 입력 종류 -->
<input type="email" placeholder="이메일 입력" />
```

## CSS 기본

CSS(Cascading Style Sheets)는 HTML 요소의 **색상, 크기, 위치**를 지정합니다.

```css
/* 태그 이름으로 선택 */
p {
  color: blue;
  font-size: 16px;
}

/* class로 선택 (.클래스명) */
.container {
  width: 800px;
  margin: 0 auto;
  padding: 20px;
}

/* id로 선택 (#id명) */
#intro {
  font-weight: bold;
}
```

### 자주 쓰는 CSS 속성

| 속성 | 의미 | 예 |
| --- | --- | --- |
| `color` | 글자 색 | `color: red` |
| `background-color` | 배경 색 | `background-color: #f0f0f0` |
| `font-size` | 글자 크기 | `font-size: 16px` |
| `font-weight` | 글자 굵기 | `font-weight: bold` |
| `margin` | 바깥 여백 | `margin: 10px` |
| `padding` | 안쪽 여백 | `padding: 20px` |
| `width` / `height` | 너비 / 높이 | `width: 100%` |
| `display` | 배치 방식 | `display: flex` |
| `border` | 테두리 | `border: 1px solid gray` |
| `border-radius` | 모서리 둥글기 | `border-radius: 8px` |

### Flexbox — 가장 많이 쓰는 레이아웃

```css
.row {
  display: flex;           /* flex 컨테이너로 만들기 */
  justify-content: center; /* 가로 정렬 */
  align-items: center;     /* 세로 정렬 */
  gap: 16px;               /* 자식 사이 간격 */
}
```

## React에서 달라지는 부분

React에서는 HTML을 JSX 형태로 씁니다. 거의 같지만 몇 가지 차이가 있습니다.

| HTML | JSX (React) | 이유 |
| --- | --- | --- |
| `class="box"` | `className="box"` | `class`는 JS 예약어 |
| `for="id"` | `htmlFor="id"` | `for`는 JS 예약어 |
| `<br>` | `<br />` | JSX는 반드시 태그를 닫아야 함 |
| `style="color:red"` | `style={{ color: 'red' }}` | JSX에서 스타일은 객체로 전달 |
| `onclick="fn()"` | `onClick={fn}` | 이벤트는 camelCase |

```jsx
// HTML
<div class="box" onclick="handleClick()">
  <p style="color: red">텍스트</p>
</div>

// JSX
<div className="box" onClick={handleClick}>
  <p style={{ color: 'red' }}>텍스트</p>
</div>
```

## 핵심 정리

- HTML은 웹 페이지의 구조(뼈대), CSS는 스타일(꾸밈)을 담당한다.
- 태그는 여는 태그와 닫는 태그로 내용을 감싼다. 내용 없는 태그는 `<img />` 처럼 자기 닫기.
- CSS는 `class` 속성으로 여러 요소에 같은 스타일을 적용한다.
- JSX에서는 `class` → `className`, `style`은 문자열이 아닌 객체로 전달한다.
- Flexbox(`display: flex`)는 요소를 가로·세로로 정렬하는 가장 일반적인 방법이다.
