## 인라인 스타일

```jsx
function Box() {
  return (
    <div
      style={{
        backgroundColor: 'blue',
        padding: '16px',
        borderRadius: '8px',
        color: 'white',
      }}
    >
      인라인 스타일
    </div>
  )
}
```

장점: 동적 값 적용 쉬움 / 단점: CSS 기능 제한, 클래스 재사용 불가, 성능 불리

## CSS Modules

파일 이름을 `.module.css`로 지정하면 클래스 이름이 자동으로 고유하게 변환됩니다.

```css
/* Button.module.css */
.button {
  padding: 8px 16px;
  border-radius: 4px;
  background-color: #3b82f6;
  color: white;
  border: none;
  cursor: pointer;
}

.button:hover {
  background-color: #2563eb;
}

.large {
  padding: 12px 24px;
  font-size: 1.125rem;
}
```

```jsx
import styles from './Button.module.css'

function Button({ size = 'normal', children }) {
  const className = size === 'large'
    ? `${styles.button} ${styles.large}`
    : styles.button

  return <button className={className}>{children}</button>
}
```

장점: 클래스 이름 충돌 없음, 기존 CSS 문법 그대로 사용  
단점: 동적 스타일이 복잡해질 수 있음

## Tailwind CSS

유틸리티 퍼스트 CSS 프레임워크입니다. 클래스를 조합해 스타일을 적용합니다.

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

```jsx
function Card({ title, description, featured }) {
  return (
    <div className={`
      rounded-xl shadow-md p-6
      ${featured ? 'bg-blue-600 text-white' : 'bg-white text-gray-800'}
    `}>
      <h2 className="text-xl font-bold mb-2">{title}</h2>
      <p className="text-sm opacity-80">{description}</p>
    </div>
  )
}

function Button({ variant = 'primary', children }) {
  const base = 'px-4 py-2 rounded font-medium transition-colors'
  const variants = {
    primary: 'bg-blue-600 text-white hover:bg-blue-700',
    secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300',
  }
  return (
    <button className={`${base} ${variants[variant]}`}>
      {children}
    </button>
  )
}
```

장점: 빠른 개발, 일관된 디자인, 번들 크기 최적화  
단점: 클래스 문자열이 길어짐, 초기 학습 필요

## styled-components

CSS를 JavaScript 안에 작성하는 CSS-in-JS 방식입니다.

```bash
npm install styled-components
```

```jsx
import styled from 'styled-components'

const Button = styled.button`
  padding: 8px 16px;
  border-radius: 4px;
  border: none;
  cursor: pointer;
  font-weight: 600;
  background-color: ${props => props.variant === 'primary' ? '#3b82f6' : '#e5e7eb'};
  color: ${props => props.variant === 'primary' ? 'white' : '#374151'};

  &:hover {
    opacity: 0.9;
  }
`

const Card = styled.div`
  padding: 24px;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  background: white;
`

function App() {
  return (
    <Card>
      <Button variant="primary">확인</Button>
      <Button>취소</Button>
    </Card>
  )
}
```

장점: props 기반 동적 스타일, 컴포넌트와 스타일 응집도 높음  
단점: 런타임 성능 비용, 번들 크기 증가

## 세 가지 방식 비교

```
                  CSS Modules   Tailwind CSS   styled-components
클래스 충돌 없음      O              O                O
동적 스타일          보통           쉬움             쉬움
기존 CSS 문법        O              X                O (template)
런타임 비용          없음           없음             있음
SSR 지원            쉬움           쉬움             설정 필요
팀 적합성        전통 CSS 선호  유틸리티 선호   JS 통합 선호
```

## 핵심 정리

- CSS Modules는 기존 CSS 문법을 유지하면서 클래스 이름 충돌을 방지합니다.
- Tailwind CSS는 유틸리티 클래스를 조합해 빠르게 UI를 구축합니다.
- styled-components는 props 기반 동적 스타일이 강점인 CSS-in-JS 방식입니다.
- 프로젝트 규모, 팀 성향, 성능 요구사항에 따라 방식을 선택합니다.
