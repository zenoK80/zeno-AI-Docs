## fetch + useEffect 기본 패턴

```jsx
function UserList() {
  const [users, setUsers] = useState([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    let cancelled = false

    fetch('https://jsonplaceholder.typicode.com/users')
      .then(res => {
        if (!res.ok) throw new Error(`HTTP 오류: ${res.status}`)
        return res.json()
      })
      .then(data => {
        if (!cancelled) {
          setUsers(data)
          setLoading(false)
        }
      })
      .catch(err => {
        if (!cancelled) {
          setError(err.message)
          setLoading(false)
        }
      })

    return () => { cancelled = true }
  }, [])

  if (loading) return <div>로딩 중...</div>
  if (error) return <div>에러: {error}</div>

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  )
}
```

## 로딩·에러 상태를 하나의 객체로 관리

```jsx
function useData(url) {
  const [state, setState] = useState({
    data: null,
    loading: true,
    error: null,
  })

  useEffect(() => {
    setState({ data: null, loading: true, error: null })
    let cancelled = false

    fetch(url)
      .then(r => r.json())
      .then(data => {
        if (!cancelled) setState({ data, loading: false, error: null })
      })
      .catch(err => {
        if (!cancelled) setState({ data: null, loading: false, error: err.message })
      })

    return () => { cancelled = true }
  }, [url])

  return state
}
```

## POST 요청 패턴

```jsx
async function createPost(post) {
  const res = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(post),
  })
  if (!res.ok) throw new Error('요청 실패')
  return res.json()
}

function NewPostForm() {
  const [submitting, setSubmitting] = useState(false)

  const handleSubmit = async (e) => {
    e.preventDefault()
    setSubmitting(true)
    try {
      const post = await createPost({ title: '제목', body: '내용', userId: 1 })
      console.log('생성됨:', post)
    } catch (err) {
      console.error(err)
    } finally {
      setSubmitting(false)
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit" disabled={submitting}>
        {submitting ? '제출 중...' : '제출'}
      </button>
    </form>
  )
}
```

## AbortController로 요청 취소

```jsx
useEffect(() => {
  const controller = new AbortController()

  fetch(url, { signal: controller.signal })
    .then(r => r.json())
    .then(setData)
    .catch(err => {
      if (err.name !== 'AbortError') setError(err.message)
    })

  return () => controller.abort()
}, [url])
```

## SWR 개념과 기본 사용

SWR(Stale-While-Revalidate)은 캐시된 데이터를 즉시 보여주고 백그라운드에서 최신 데이터를 가져오는 전략입니다.

```bash
npm install swr
```

```jsx
import useSWR from 'swr'

const fetcher = (url) => fetch(url).then(r => r.json())

function UserProfile({ id }) {
  const { data, error, isLoading } = useSWR(`/api/users/${id}`, fetcher)

  if (isLoading) return <p>로딩...</p>
  if (error) return <p>에러 발생</p>
  return <p>{data.name}</p>
}
```

SWR의 특징:
- 자동 재검증 (포커스 시, 인터벌, 재연결 시)
- 중복 요청 제거
- 낙관적 업데이트
- 페이지네이션 지원

## React Query (TanStack Query) 개념

```bash
npm install @tanstack/react-query
```

```jsx
import { useQuery, useMutation, QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <UserList />
    </QueryClientProvider>
  )
}

function UserList() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['users'],
    queryFn: () => fetch('/api/users').then(r => r.json()),
  })

  if (isLoading) return <p>로딩...</p>
  if (error) return <p>에러</p>

  return <ul>{data.map(u => <li key={u.id}>{u.name}</li>)}</ul>
}
```

React Query의 특징:
- 서버 상태와 클라이언트 상태를 분리
- 캐시, 백그라운드 업데이트, 자동 재시도
- 낙관적 업데이트, 무한 스크롤 등 고급 기능
- DevTools 제공

## 핵심 정리

- `fetch + useEffect`는 기본 패턴이지만 로딩·에러·취소를 직접 관리해야 합니다.
- SWR과 React Query는 캐싱, 자동 재검증, 중복 제거 등을 자동 처리합니다.
- 복잡한 서버 상태 관리에는 SWR이나 React Query 사용을 권장합니다.
