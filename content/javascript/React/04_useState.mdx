## useState 기본

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)  // 초기값 0

  return (
    <div>
      <p>카운트: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(count - 1)}>-1</button>
      <button onClick={() => setCount(0)}>초기화</button>
    </div>
  )
}
```

## 다양한 타입의 상태

```jsx
function Form() {
  const [name, setName] = useState('')
  const [age, setAge] = useState(0)

}
```

## 함수형 업데이트

이전 상태를 기반으로 업데이트할 때는 함수형 업데이트를 사용합니다.

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  const increment = () => {
    // 직접 값 사용 (잠재적 버그 가능)
    setCount(count + 1)

    // 함수형 업데이트 (안전)
    setCount(prev => prev + 1)
  }

  const incrementThree = () => {
    // 비동기 때문에 3번 호출해도 1만 증가
    setCount(count + 1)
    setCount(count + 1)
    setCount(count + 1)

    // 함수형 업데이트로 3 증가
    setCount(prev => prev + 1)
    setCount(prev => prev + 1)
    setCount(prev => prev + 1)
  }

  return <button onClick={incrementThree}>{count}</button>
}
```

## 객체 상태와 불변성

```jsx
function Profile() {
  const [user, setUser] = useState({ name: '김철수', age: 25 })

  const updateName = () => {
    // 틀린 방법: 직접 수정
    user.name = '이영희'
    setUser(user)  // 동일 참조라 리렌더링 안 됨

    // 옳은 방법: 새 객체 생성 (불변성 유지)
    setUser({ ...user, name: '이영희' })
  }

  return (
    <div>
      <p>{user.name} ({user.age})</p>
      <button onClick={updateName}>이름 변경</button>
    </div>
  )
}
```

## 배열 상태와 불변성

```jsx
function TodoList() {
  const [todos, setTodos] = useState([
    { id: 1, text: '공부하기', done: false },
  ])

  // 추가
  const addTodo = (text) => {
    setTodos([...todos, { id: Date.now(), text, done: false }])
  }

  // 삭제
  const deleteTodo = (id) => {
    setTodos(todos.filter(todo => todo.id !== id))
  }

  // 완료 토글
  const toggleTodo = (id) => {
    setTodos(todos.map(todo =>
      todo.id === id ? { ...todo, done: !todo.done } : todo
    ))
  }

  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>
          <span style={{ textDecoration: todo.done ? 'line-through' : 'none' }}>
            {todo.text}
          </span>
          <button onClick={() => toggleTodo(todo.id)}>완료</button>
          <button onClick={() => deleteTodo(todo.id)}>삭제</button>
        </li>
      ))}
    </ul>
  )
}
```

## 지연 초기화

초기값 계산이 복잡할 때 함수를 전달합니다.

```jsx
function App() {
  // 매 렌더링마다 호출됨 (비효율)
  const [data] = useState(expensiveCalculation())

  // 초기 렌더링 시에만 호출됨 (효율적)
  const [data2] = useState(() => expensiveCalculation())
}
```

## 핵심 정리

- `useState`로 컴포넌트 상태를 선언하고 setter 함수로 업데이트합니다.
- 이전 상태 기반 업데이트는 함수형 업데이트 `prev => prev + 1`을 사용합니다.
- 객체/배열 상태는 직접 수정하지 말고 새 값을 생성합니다(불변성).
