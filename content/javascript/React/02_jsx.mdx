## JSX란

**JSX**(JavaScript XML)는 JavaScript 안에 HTML과 비슷한 마크업을 쓸 수 있는 문법 확장입니다. Babel이 JSX를 `React.createElement()` 호출로 변환합니다.

```jsx
// JSX
const element = <h1 className="title">Hello</h1>

// Babel 변환 결과
const element = React.createElement('h1', { className: 'title' }, 'Hello')
```

## JSX 규칙

```jsx
// 1. 반드시 하나의 루트 요소 (또는 Fragment)
function App() {
  return (
    <>
      <h1>제목</h1>
      <p>내용</p>
    </>
  )
}

// 2. 모든 태그는 닫아야 함
const img = <img src="/logo.png" alt="로고" />

// 3. camelCase 속성명
// class → className, for → htmlFor, onclick → onClick
const btn = <button className="btn" onClick={handleClick}>클릭</button>
```

## 표현식 삽입

JSX 안에서 중괄호로 JavaScript 표현식을 삽입합니다.

```jsx
const name = '김철수'
const age = 25
const isAdmin = true

function Profile() {
  return (
    <div>
      <p>이름: {name}</p>
      <p>나이: {age}</p>
      <p>2 + 3 = {2 + 3}</p>
      <p>역할: {isAdmin ? '관리자' : '일반 사용자'}</p>
    </div>
  )
}
```

## 조건부 렌더링

```jsx
function Alert({ type, message }) {
  // 삼항 연산자
  return (
    <div className={type === 'error' ? 'alert-error' : 'alert-info'}>
      {message}
    </div>
  )
}

function UserGreeting({ isLoggedIn }) {
  // && 단락 평가
  return (
    <div>
      {isLoggedIn && <p>환영합니다!</p>}
      {!isLoggedIn && <p>로그인해 주세요.</p>}
    </div>
  )
}
```

## 리스트 렌더링

```jsx
const fruits = ['사과', '바나나', '딸기']

function FruitList() {
  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  )
}
```

<Callout type="warning">
  리스트의 각 항목에는 고유한 `key` prop이 필요합니다. 인덱스보다 항목 고유 ID를 사용하세요.
</Callout>

## 스타일 적용

```jsx
// 인라인 스타일: 객체 형태
const style = { color: 'red', fontSize: '16px' }
const el = <p style={style}>텍스트</p>

// className으로 CSS 클래스 적용
const el2 = <p className="highlight">텍스트</p>
```

## 핵심 정리

- JSX는 `React.createElement()` 호출로 변환되는 문법 설탕입니다.
- 중괄호로 JavaScript 표현식을 삽입합니다.
- 삼항 연산자나 `&&`로 조건부 렌더링합니다.
- `map()`으로 리스트를 렌더링하고 각 항목에 `key`를 줍니다.
