## 상태 관리 선택 기준

React 앱의 상태는 크게 세 종류입니다.

| 상태 종류 | 예시 | 적합한 도구 |
| --- | --- | --- |
| **로컬 UI 상태** | 모달 열림/닫힘, 입력 값 | useState |
| **공유 상태** | 로그인 사용자, 테마 | Context API 또는 전역 상태 |
| **서버 상태** | API에서 가져온 데이터 | TanStack Query |
| **복잡한 전역 상태** | 장바구니, 채팅 메시지 | Zustand, Redux Toolkit |

> **쉽게 말하면:** 한 컴포넌트만 쓰면 로컬 state, 여러 컴포넌트가 공유하면 Context 또는 전역 상태 라이브러리를 씁니다.

---

## 상태를 어디에 두나? — 상태 위치 결정

```
상태를 사용하는 컴포넌트가 하나뿐인가?
  → YES: 해당 컴포넌트에 로컬 state

상태를 여러 형제 컴포넌트가 공유하는가?
  → YES: 공통 부모로 "상태 올리기(lifting state up)"

상태가 앱 전반에 필요한가?
  → YES: Context 또는 전역 상태 라이브러리
```

## Zustand — 간단한 전역 상태 라이브러리

Zustand(독일어로 '상태')는 React Context 없이 전역 상태를 관리합니다. Redux보다 훨씬 간단합니다.

```bash
npm install zustand
```

### 스토어 만들기

```jsx
import { create } from 'zustand'

const useCartStore = create((set) => ({
  items: [],
  totalCount: 0,

  addItem: (product) =>
    set((state) => ({
      items: [...state.items, product],
      totalCount: state.totalCount + 1,
    })),

  removeItem: (productId) =>
    set((state) => ({
      items: state.items.filter(item => item.id !== productId),
      totalCount: state.totalCount - 1,
    })),

  clearCart: () => set({ items: [], totalCount: 0 }),
}))
```

### 스토어 사용하기

```jsx
function CartIcon() {
  const totalCount = useCartStore(state => state.totalCount)
  return <span>장바구니 {totalCount}개</span>
}

function ProductCard({ product }) {
  const addItem = useCartStore(state => state.addItem)

  return (
    <div>
      <h3>{product.name}</h3>
      <button onClick={() => addItem(product)}>담기</button>
    </div>
  )
}

function CartPage() {
  const { items, removeItem, clearCart } = useCartStore(state => ({
    items: state.items,
    removeItem: state.removeItem,
    clearCart: state.clearCart,
  }))

  return (
    <div>
      {items.map(item => (
        <div key={item.id}>
          {item.name}
          <button onClick={() => removeItem(item.id)}>삭제</button>
        </div>
      ))}
      <button onClick={clearCart}>전체 삭제</button>
    </div>
  )
}
```

`Context.Provider`로 감쌀 필요 없이 어디서든 `useCartStore()`를 호출하면 됩니다.

## Zustand vs Context API 비교

| 기준 | Context API | Zustand |
| --- | --- | --- |
| 설정 | Provider로 감싸야 함 | 없음 |
| 리렌더링 | value 전체 변경 시 모든 구독자 | 선택한 slice만 |
| 비동기 지원 | 직접 처리 | 액션 안에 async 가능 |
| 디버깅 | 어려움 | devtools 지원 |
| 적합한 상황 | 테마, 로그인 등 단순 공유 | 복잡한 전역 상태 |

---

## 핵심 정리

- 상태 위치: 하나면 로컬, 형제 간 공유면 부모로 올리기, 앱 전반이면 전역 상태.
- **상태 올리기**: 공통 부모에 상태를 두고 자식에 props로 전달.
- **Zustand**: `create()`로 스토어 정의, `set()`으로 상태 업데이트. Provider 불필요.
- 선택한 slice만 구독 → 불필요한 리렌더링 방지.
