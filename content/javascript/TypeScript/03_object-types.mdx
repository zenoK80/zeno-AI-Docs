## interface

```ts
interface User {
  id: number
  name: string
  email: string
}

const user: User = {
  id: 1,
  name: 'Alice',
  email: 'alice@example.com',
}

// 선택적 프로퍼티 ?
interface Product {
  id: number
  name: string
  description?: string   // 있어도 되고 없어도 됨
  price: number
}

const item: Product = {
  id: 1,
  name: '상품명',
  price: 9900,
  // description 생략 가능
}
```

## readonly 프로퍼티

```ts
interface Config {
  readonly apiUrl: string
  readonly maxRetries: number
  timeout: number
}

const config: Config = {
  apiUrl: 'https://api.example.com',
  maxRetries: 3,
  timeout: 5000,
}

config.timeout = 3000       // OK
config.apiUrl = 'other'     // 오류: readonly 프로퍼티는 변경 불가
```

## type alias

```ts
type Point = {
  x: number
  y: number
}

// 원시 타입, 유니온, 교차 타입에도 사용 가능
type ID = string | number
type Status = 'active' | 'inactive' | 'pending'

const point: Point = { x: 10, y: 20 }
```

## interface vs type alias

```ts
// interface — 확장(extends) 가능
interface Animal {
  name: string
}

interface Dog extends Animal {
  breed: string
}

// 선언 병합 — 같은 이름의 interface를 여러 번 선언하면 병합됨
interface Window {
  myCustomProp: string
}
// 기존 Window 타입에 myCustomProp가 추가됨

// type alias — 확장은 교차 타입(&)으로
type Animal2 = {
  name: string
}

type Dog2 = Animal2 & {
  breed: string
}

// type은 선언 병합 불가
```

## 주요 차이점

```
                    interface         type alias
객체 타입 정의         O                 O
원시 타입 별칭         X                 O
유니온 타입            X                 O
교차 타입              X (extends)       O (&)
선언 병합              O                 X
extends/implements    O                 제한적
```

## 인덱스 시그니처

```ts
// 동적 키를 가진 객체 타입
interface StringMap {
  [key: string]: string
}

const headers: StringMap = {
  'Content-Type': 'application/json',
  Authorization: 'Bearer token',
}

// 인덱스 시그니처 + 특정 프로퍼티
interface NumberMap {
  [key: string]: number
  count: number    // 반드시 value 타입(number)과 호환되어야 함
}
```

## 중첩 객체 타입

```ts
interface Address {
  street: string
  city: string
  country: string
}

interface Person {
  name: string
  age: number
  address: Address        // 중첩 객체
  hobbies: string[]       // 배열
}

const person: Person = {
  name: 'Bob',
  age: 30,
  address: {
    street: '123 Main St',
    city: '서울',
    country: 'Korea',
  },
  hobbies: ['reading', 'coding'],
}
```

## 핵심 정리

- `interface`는 객체 타입 정의에 최적화되어 있고 선언 병합과 extends를 지원합니다.
- `type alias`는 더 유연해 유니온, 교차, 원시 타입 별칭 등에 모두 사용됩니다.
- `?`로 선택적 프로퍼티를, `readonly`로 변경 불가 프로퍼티를 선언합니다.
- 객체 타입에서는 일반적으로 `interface`를 선호하고, 유니온/교차 등은 `type`을 사용합니다.
