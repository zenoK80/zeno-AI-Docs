## 클래스 기본

```ts
class Animal {
  name: string
  age: number

  constructor(name: string, age: number) {
    this.name = name
    this.age = age
  }

  speak(): string {
    return `${this.name}이(가) 말합니다.`
  }
}

const dog = new Animal('멍멍이', 3)
console.log(dog.speak())
```

## 접근 제어자

```ts
class BankAccount {
  public owner: string       // 어디서나 접근 가능 (기본값)
  private balance: number    // 클래스 내부에서만 접근 가능
  protected id: string       // 클래스와 서브클래스에서 접근 가능

  constructor(owner: string, initialBalance: number) {
    this.owner = owner
    this.balance = initialBalance
    this.id = Math.random().toString(36)
  }

  deposit(amount: number): void {
    if (amount > 0) {
      this.balance += amount
    }
  }

  withdraw(amount: number): boolean {
    if (amount > 0 && this.balance >= amount) {
      this.balance -= amount
      return true
    }
    return false
  }

  getBalance(): number {
    return this.balance
  }
}

const account = new BankAccount('Alice', 1000)
account.owner        // OK
account.balance      // 오류: private
account.getBalance() // OK — 메서드로 접근
```

## 생성자 매개변수 단축

```ts
// 장황한 방식
class Point {
  public x: number
  public y: number

  constructor(x: number, y: number) {
    this.x = x
    this.y = y
  }
}

// 단축 방식 — 생성자 매개변수에 접근 제어자 추가
class Point {
  constructor(
    public x: number,
    public y: number,
    private label: string = 'point'
  ) {}

  toString() {
    return `${this.label}(${this.x}, ${this.y})`
  }
}
```

## readonly와 static

```ts
class Config {
  readonly apiUrl: string         // 한 번 설정 후 변경 불가
  static instanceCount = 0        // 클래스 레벨 프로퍼티

  constructor(apiUrl: string) {
    this.apiUrl = apiUrl
    Config.instanceCount++
  }

  static create(apiUrl: string): Config {
    return new Config(apiUrl)
  }
}

const config = Config.create('https://api.example.com')
Config.instanceCount  // 1
config.apiUrl = 'other'  // 오류: readonly
```

## 상속과 protected

```ts
class Vehicle {
  constructor(
    protected make: string,
    protected model: string,
    private year: number
  ) {}

  getInfo(): string {
    return `${this.year} ${this.make} ${this.model}`
  }
}

class Car extends Vehicle {
  constructor(
    make: string,
    model: string,
    year: number,
    private doors: number
  ) {
    super(make, model, year)  // 부모 생성자 호출
  }

  describe(): string {
    // protected 접근 가능, private 접근 불가
    return `${this.make} ${this.model} - ${this.doors}도어`
  }
}
```

## implements — 인터페이스 구현

```ts
interface Printable {
  print(): void
}

interface Serializable {
  serialize(): string
  deserialize(data: string): void
}

class Document implements Printable, Serializable {
  private content: string = ''

  print(): void {
    console.log(this.content)
  }

  serialize(): string {
    return JSON.stringify({ content: this.content })
  }

  deserialize(data: string): void {
    const parsed = JSON.parse(data)
    this.content = parsed.content
  }
}
```

## 핵심 정리

- `public`: 어디서나 접근 가능 (기본값)
- `private`: 클래스 내부에서만 접근 가능
- `protected`: 클래스와 서브클래스에서 접근 가능
- `abstract class`: 직접 인스턴스화 불가, 서브클래스에서 추상 메서드를 구현해야 합니다.
- `implements`로 인터페이스를 구현하면 해당 타입 계약을 지킵니다.
