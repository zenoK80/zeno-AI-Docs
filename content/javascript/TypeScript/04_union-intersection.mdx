## 유니온 타입 (|)

여러 타입 중 하나가 될 수 있음을 나타냅니다.

```ts
type StringOrNumber = string | number

let value: StringOrNumber = 'hello'
value = 42   // OK

// 함수 매개변수
function printId(id: string | number) {
  if (typeof id === 'string') {
    console.log(id.toUpperCase())  // string 메서드 사용 가능
  } else {
    console.log(id.toFixed(2))     // number 메서드 사용 가능
  }
}

// 공통 메서드는 타입 좁히기 없이도 사용 가능
function getLength(value: string | string[]) {
  return value.length  // string과 string[] 모두 length 있음
}
```

## 교차 타입 (&)

여러 타입을 모두 만족해야 함을 나타냅니다. 합집합(union)이 아닌 교집합(intersection)입니다.

```ts
type HasName = { name: string }
type HasAge = { age: number }

type Person = HasName & HasAge
// Person은 name과 age 모두 필요

const person: Person = {
  name: 'Alice',
  age: 25,
}

// 인터페이스 확장과 유사
interface A { a: string }
interface B { b: number }
type AB = A & B  // { a: string; b: number }
```

## 리터럴 타입

구체적인 값 자체를 타입으로 사용합니다.

```ts
// 문자열 리터럴
type Direction = 'north' | 'south' | 'east' | 'west'
type Status = 'pending' | 'active' | 'closed'

// 숫자 리터럴
type DiceRoll = 1 | 2 | 3 | 4 | 5 | 6
type HttpSuccess = 200 | 201 | 204

// boolean 리터럴 (거의 true | false와 같음)
type AlwaysTrue = true

// as const — 객체의 모든 프로퍼티를 리터럴 타입으로
const config = {
  host: 'localhost',
  port: 3000,
} as const
// config.host: 'localhost' (string이 아닌 리터럴)
// config.port: 3000 (number가 아닌 리터럴)
```

## 판별 유니온 (Discriminated Union)

공통 리터럴 프로퍼티로 유니온 타입을 구별하는 패턴입니다.

<CodePlayground
  template="vanilla-ts"
  activeFile="/index.ts"
  showConsole
  label="판별 유니온 실습"
  files={{
    '/index.ts': `type Circle = {
  kind: 'circle'    // 판별자 (discriminant)
  radius: number
}

type Rectangle = {
  kind: 'rectangle'  // 판별자
  width: number
  height: number
}

type Triangle = {
  kind: 'triangle'
  base: number
  height: number
}

type Shape = Circle | Rectangle | Triangle

function getArea(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2
    case 'rectangle':
      return shape.width * shape.height
    case 'triangle':
      return (shape.base * shape.height) / 2
    default:
      const _exhaustive: never = shape  // 누락 감지
      return _exhaustive
  }
}

console.log('원 넓이:', getArea({ kind: 'circle', radius: 5 }).toFixed(2))
console.log('직사각형 넓이:', getArea({ kind: 'rectangle', width: 4, height: 3 }))
console.log('삼각형 넓이:', getArea({ kind: 'triangle', base: 6, height: 4 }))`,
  }}

## 유니온 타입의 함정

```ts
// 유니온 타입에서는 공통 프로퍼티만 접근 가능
type Cat = { name: string; meow(): void }
type Dog = { name: string; bark(): void }
type Pet = Cat | Dog

function greetPet(pet: Pet) {
  console.log(pet.name)  // OK — 공통 프로퍼티
  pet.meow()             // 오류 — Dog에 meow 없음
  pet.bark()             // 오류 — Cat에 bark 없음
}

// 타입 가드로 해결
function greetPetSafe(pet: Pet) {
  if ('meow' in pet) {
    pet.meow()  // Cat
  } else {
    pet.bark()  // Dog
  }
}
```

## 선택적 체이닝과 유니온

```ts
type User = {
  id: number
  profile?: {
    avatar?: string
  }
}

function getAvatar(user: User): string | undefined {
  return user.profile?.avatar  // undefined 안전하게 접근
}
```

## 핵심 정리

- 유니온(`|`)은 여러 타입 중 하나, 교차(`&`)는 여러 타입을 모두 만족해야 합니다.
- 리터럴 타입으로 허용값을 구체적으로 제한합니다.
- 판별 유니온은 공통 리터럴 프로퍼티(`kind` 등)로 유니온 멤버를 구별합니다.
- 유니온 타입에서는 공통 프로퍼티만 직접 접근 가능하며, 개별 타입 접근 시 타입 가드가 필요합니다.
