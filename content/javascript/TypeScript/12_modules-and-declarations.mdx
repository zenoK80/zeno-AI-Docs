## ESM import/export

```ts
// math.ts — 명명된 내보내기
export function add(a: number, b: number): number {
  return a + b
}

export function subtract(a: number, b: number): number {
  return a - b
}

export const PI = 3.14159

// 기본 내보내기
export default function multiply(a: number, b: number): number {
  return a * b
}
```

```ts
// main.ts — 가져오기
import multiply, { add, subtract, PI } from './math'
import type { SomeType } from './types'  // 타입만 가져오기

// 네임스페이스 가져오기
import * as MathUtils from './math'
MathUtils.add(1, 2)
```

## 타입 전용 import/export

```ts
// 타입만 내보내기
export type { User, Product }
export interface Config { ... }

// 타입만 가져오기 — 런타임에 제거됨
import type { User } from './types'
import { type User, createUser } from './users'
```

## .d.ts 선언 파일

타입 정보만 담은 파일로 런타임 코드는 없습니다.

```ts
// utils.d.ts — JavaScript 라이브러리의 타입 선언
export function formatDate(date: Date, format: string): string
export function parseDate(str: string): Date

export interface FormatOptions {
  locale?: string
  timezone?: string
}
```

```ts
// 사용
import { formatDate } from './utils'
// utils.js가 실행되고 타입은 utils.d.ts에서 가져옴
```

## @types 패키지

JavaScript 라이브러리의 타입 선언을 별도 패키지로 제공합니다.

```bash
# JavaScript 라이브러리 설치
npm install lodash

# 타입 선언 설치
npm install -D @types/lodash

# 이미 타입이 포함된 경우 @types 불필요
npm install axios  # 내장 타입 포함
```

```ts
// @types/lodash가 있으면 타입 지원됨
import _ from 'lodash'
const result = _.chunk([1, 2, 3, 4], 2)  // 타입: number[][]
```

## declare 키워드

타입 정보를 선언하며 실제 구현은 제공하지 않습니다.

```ts
// 전역 변수 선언
declare const __DEV__: boolean
declare const VERSION: string

// 전역 함수 선언
declare function require(module: string): unknown

// 모듈 선언 — 타입이 없는 패키지 보완
declare module 'some-untyped-lib' {
  export function doSomething(value: string): void
  export const VERSION: string
}

// CSS/SVG 파일 등 비JS 파일 가져오기
declare module '*.svg' {
  const content: string
  export default content
}

declare module '*.css' {
  const styles: Record<string, string>
  export default styles
}
```

## global 확장

```ts
// global.d.ts
declare global {
  interface Window {
    analytics: {
      track(event: string, data?: object): void
    }
  }

  namespace NodeJS {
    interface ProcessEnv {
      NODE_ENV: 'development' | 'production' | 'test'
      DATABASE_URL: string
      API_KEY: string
    }
  }
}

export {}  // 모듈로 만들어야 global 확장이 동작함

// 사용
window.analytics.track('page_view')
process.env.DATABASE_URL  // 타입: string
```

## 모듈 증강 (Module Augmentation)

```ts
// express 타입 확장
import 'express'

declare module 'express' {
  interface Request {
    user?: {
      id: number
      email: string
    }
  }
}

// 이후 req.user를 타입 안전하게 사용 가능
```

## 핵심 정리

- `import type`으로 타입만 가져오면 런타임 번들에 포함되지 않습니다.
- `.d.ts` 파일은 타입 선언만 포함하며 JavaScript 라이브러리에 타입을 추가합니다.
- `@types/*` 패키지는 커뮤니티가 유지하는 타입 선언 모음입니다.
- `declare`는 구현 없이 타입 정보를 선언합니다.
