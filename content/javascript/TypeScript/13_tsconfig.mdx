<Callout type="info">
  **이번 문서의 목표:** tsconfig.json의 핵심 옵션을 이해하고 프로젝트 목적에 맞게 설정합니다.
</Callout>

## tsconfig.json 기본 구조

```json
{
  "compilerOptions": {
    // 컴파일러 동작 설정
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist", "**/*.test.ts"],
  "extends": "./tsconfig.base.json"
}
```

## 출력 관련 옵션

```json
{
  "compilerOptions": {
    "target": "ES2020",        // 출력 JS의 ECMAScript 버전
    "module": "CommonJS",       // 모듈 시스템 (CommonJS/ESNext/NodeNext 등)
    "outDir": "./dist",         // 컴파일 출력 디렉터리
    "rootDir": "./src",         // 소스 파일 루트 디렉터리
    "declaration": true,        // .d.ts 파일 생성
    "declarationMap": true,     // 소스맵 포함 .d.ts
    "sourceMap": true           // .map 파일 생성 (디버깅용)
  }
}
```

## 타입 검사 옵션

```json
{
  "compilerOptions": {
    "strict": true,              // 아래 옵션들을 모두 활성화
    "strictNullChecks": true,    // null/undefined를 별도 타입으로 처리
    "noImplicitAny": true,       // 암묵적 any 금지
    "strictFunctionTypes": true, // 함수 매개변수의 반공변 검사
    "noUncheckedIndexedAccess": true, // 인덱스 접근 시 undefined 포함
    "noUnusedLocals": true,      // 사용하지 않는 지역 변수 오류
    "noUnusedParameters": true,  // 사용하지 않는 매개변수 오류
    "noImplicitReturns": true    // 모든 경로에서 return 요구
  }
}
```

## 경로 별칭 설정

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"],
      "@components/*": ["src/components/*"],
      "@utils/*": ["src/utils/*"],
      "@types/*": ["src/types/*"]
    }
  }
}
```

```ts
// 경로 별칭 사용
import { Button } from '@components/Button'
import { formatDate } from '@utils/date'
// 대신 ../../../components/Button과 같은 상대 경로 불필요
```

## lib 옵션

```json
{
  "compilerOptions": {
    // 포함할 내장 타입 선언 라이브러리
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    // ES2020: 최신 ES 표준 API
    // DOM: 브라우저 API (window, document, fetch 등)
    // DOM.Iterable: NodeList.forEach 등
  }
}
```

## esModuleInterop와 allowSyntheticDefaultImports

```json
{
  "compilerOptions": {
    "esModuleInterop": true,               // CommonJS 모듈을 기본 import로 가져오기 허용
    "allowSyntheticDefaultImports": true,  // 기본 export 없어도 default import 허용
    "resolveJsonModule": true,             // .json 파일 import 허용
    "allowJs": true,                       // JS 파일도 TypeScript 컴파일에 포함
    "checkJs": true                        // JS 파일도 타입 검사 (allowJs와 함께)
  }
}
```

## 실전 설정 예시

```json
// Node.js 백엔드 프로젝트
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "outDir": "dist",
    "rootDir": "src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "declaration": true,
    "sourceMap": true
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}
```

```json
// React 프로젝트 (Vite)
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

## 핵심 정리

- `strict: true`는 엄격한 타입 검사 옵션들을 한 번에 활성화합니다.
- `target`은 출력 JS 버전, `module`은 모듈 시스템을 지정합니다.
- `paths + baseUrl`로 경로 별칭을 설정해 긴 상대 경로를 줄입니다.
- `lib`으로 사용할 내장 타입 라이브러리를 지정합니다.
