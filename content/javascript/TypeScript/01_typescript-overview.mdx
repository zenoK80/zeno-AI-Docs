## TypeScript란?

TypeScript는 Microsoft가 개발한 JavaScript의 상위 집합(superset)입니다. 모든 JavaScript 코드는 유효한 TypeScript 코드이며, TypeScript는 타입 시스템과 최신 ECMAScript 기능을 추가합니다.

```
JavaScript  ⊂  TypeScript

TypeScript 추가 기능:
- 정적 타입 시스템
- 인터페이스, 타입 별칭
- 제네릭
- 열거형 (enum)
- 접근 제어자 (public/private/protected)
- 데코레이터
```

## JS vs TS 비교

```js
// JavaScript — 런타임에 타입 오류 발생
function greet(name) {
  return 'Hello, ' + name.toUpperCase()
}
greet(42)  // 런타임 오류: toUpperCase is not a function
```

```ts
// TypeScript — 컴파일 타임에 오류 감지
function greet(name: string): string {
  return 'Hello, ' + name.toUpperCase()
}
greet(42)  // 컴파일 오류: Argument of type 'number' is not assignable to parameter of type 'string'
```

## 타입 시스템의 장점

```
1. 조기 오류 발견: 실행 전에 타입 오류를 감지합니다.
2. IDE 지원 향상: 자동완성, 타입 추론, 리팩토링이 강력해집니다.
3. 코드 문서화: 타입이 함수의 입출력을 명확히 설명합니다.
4. 안전한 리팩토링: 타입이 변경 영향 범위를 알려줍니다.
5. 팀 협업: 타입 계약으로 컴포넌트 간 인터페이스가 명확해집니다.
```

## 설치 및 컴파일

```bash
# TypeScript 설치
npm install -D typescript

# TypeScript 버전 확인
npx tsc --version

# ts 파일 컴파일
npx tsc index.ts

# tsconfig.json 생성
npx tsc --init
```

## tsc 컴파일러

```bash
# 단일 파일 컴파일
npx tsc index.ts

# 감시 모드 (파일 변경 시 자동 컴파일)
npx tsc --watch

# tsconfig.json 기반 컴파일
npx tsc
```

## tsconfig.json 기초

```json
{
  "compilerOptions": {
    "target": "ES2020",          // 출력 JS 버전
    "module": "CommonJS",        // 모듈 시스템
    "outDir": "./dist",          // 출력 디렉터리
    "rootDir": "./src",          // 소스 디렉터리
    "strict": true,              // 엄격 타입 검사 활성화
    "esModuleInterop": true,     // CommonJS 모듈 호환성
    "skipLibCheck": true         // .d.ts 파일 타입 검사 생략
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

## 타입 추론 (Type Inference)

TypeScript는 값으로부터 타입을 자동으로 추론합니다.

```ts
// 명시적 타입 선언
let name: string = 'Alice'

// 타입 추론 — 값으로부터 자동 추론
let age = 25        // number로 추론
let active = true   // boolean으로 추론
let items = [1, 2]  // number[]로 추론

// 함수 반환 타입도 추론됨
function add(a: number, b: number) {
  return a + b  // 반환 타입: number로 추론
}
```

## 핵심 정리

- TypeScript는 JavaScript의 상위 집합으로 정적 타입 시스템을 추가합니다.
- 타입 오류를 컴파일 타임에 발견해 런타임 오류를 줄입니다.
- `tsc` 명령어로 TypeScript를 JavaScript로 컴파일합니다.
- `tsconfig.json`으로 컴파일러 옵션을 설정합니다.
- TypeScript는 값으로부터 타입을 자동 추론하므로 모든 곳에 타입을 명시할 필요는 없습니다.
