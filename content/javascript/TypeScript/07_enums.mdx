## 숫자 enum

```ts
enum Direction {
  Up,    // 0
  Down,  // 1
  Left,  // 2
  Right, // 3
}

const move = Direction.Up
console.log(move)           // 0
console.log(Direction[0])   // 'Up' — 역방향 매핑

// 시작 값 지정
enum StatusCode {
  OK = 200,
  Created = 201,
  BadRequest = 400,
  NotFound = 404,
  ServerError = 500,
}
```

## 문자열 enum

```ts
enum Color {
  Red = 'RED',
  Green = 'GREEN',
  Blue = 'BLUE',
}

// 장점: 디버깅 시 가독성 좋음
console.log(Color.Red)  // 'RED' (숫자 enum은 0)

// API 응답 상태
enum OrderStatus {
  Pending = 'PENDING',
  Processing = 'PROCESSING',
  Shipped = 'SHIPPED',
  Delivered = 'DELIVERED',
  Cancelled = 'CANCELLED',
}

function updateOrder(id: number, status: OrderStatus) {
  console.log(`주문 ${id}: ${status}`)
}

updateOrder(1, OrderStatus.Shipped)   // OK
updateOrder(1, 'SHIPPED')              // 오류 — 문자열 리터럴 직접 사용 불가
```

## const enum

컴파일 시 인라인으로 치환되어 런타임 객체를 생성하지 않습니다.

```ts
const enum Direction {
  Up = 'UP',
  Down = 'DOWN',
  Left = 'LEFT',
  Right = 'RIGHT',
}

// 컴파일 전
const move = Direction.Up

// 컴파일 후 — Direction.Up이 'UP'으로 인라인 치환됨
const move = 'UP'

// 장점: 번들 크기 감소
// 단점: 역방향 매핑 불가, isolatedModules에서 주의 필요
```

## enum vs 상수 객체

최근에는 enum 대신 as const 객체를 선호하는 경향이 있습니다.

```ts
// enum
enum Role {
  Admin = 'ADMIN',
  User = 'USER',
  Guest = 'GUEST',
}

// as const 대안
const Role = {
  Admin: 'ADMIN',
  User: 'USER',
  Guest: 'GUEST',
} as const

type Role = typeof Role[keyof typeof Role]  // 'ADMIN' | 'USER' | 'GUEST'

// as const 방식의 장점:
// - 순수 JavaScript 객체라 호환성 좋음
// - tree-shaking 유리
// - 타입과 값을 분리해 관리 가능
```

## enum 활용 패턴

  Read = 1 << 0,   // 1 (0001)
  Write = 1 << 1,  // 2 (0010)
  Execute = 1 << 2, // 4 (0100)
  Admin = Read | Write | Execute,  // 7 (0111)
}

function hasPermission(user: number, permission: Permission): boolean {
  return (user & permission) === permission
}

const userPermissions = Permission.Read | Permission.Write  // 3
console.log('Read 권한:', hasPermission(userPermissions, Permission.Read))
console.log('Execute 권한:', hasPermission(userPermissions, Permission.Execute))
console.log('Admin 권한:', hasPermission(Permission.Admin, Permission.Write))`,

## 핵심 정리

- 숫자 enum은 자동 증가 값을 가지며 역방향 매핑을 지원합니다.
- 문자열 enum은 가독성이 좋고 디버깅에 유리합니다.
- const enum은 컴파일 시 인라인 치환되어 런타임 코드를 생성하지 않습니다.
- 최근 트렌드는 enum 대신 `as const` 객체와 타입 추출을 사용합니다.
