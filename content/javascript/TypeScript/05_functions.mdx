## 함수 타입 기본

```ts
// 매개변수 타입 + 반환 타입
function add(a: number, b: number): number {
  return a + b
}

// 화살표 함수
const multiply = (a: number, b: number): number => a * b

// 반환 타입 추론 — 생략해도 됨
function greet(name: string) {
  return `Hello, ${name}`  // 반환 타입: string으로 추론
}
```

## 선택적 매개변수

```ts
function buildUrl(base: string, path?: string): string {
  if (path) {
    return `${base}/${path}`
  }
  return base
}

buildUrl('https://example.com')           // OK
buildUrl('https://example.com', 'users')  // OK
```

## 기본값 매개변수

```ts
function createUser(name: string, role: string = 'user', active: boolean = true) {
  return { name, role, active }
}

createUser('Alice')              // { name: 'Alice', role: 'user', active: true }
createUser('Bob', 'admin')       // { name: 'Bob', role: 'admin', active: true }
createUser('Charlie', 'admin', false)
```

## rest 파라미터

```ts
function sum(...numbers: number[]): number {
  return numbers.reduce((acc, n) => acc + n, 0)
}

sum(1, 2, 3)        // 6
sum(1, 2, 3, 4, 5)  // 15

// rest + 일반 매개변수
function log(level: string, ...messages: string[]): void {
  console.log(`[${level}]`, ...messages)
}
```

## 함수 타입 표현식

```ts
// 타입 별칭으로 함수 타입 정의
type MathFn = (a: number, b: number) => number

const add: MathFn = (a, b) => a + b
const subtract: MathFn = (a, b) => a - b

// 콜백 타입
function transform(arr: number[], fn: (n: number) => number): number[] {
  return arr.map(fn)
}

transform([1, 2, 3], x => x * 2)  // [2, 4, 6]
```

## void와 never 반환 타입

```ts
// void — 반환값이 없는 함수
function logError(message: string): void {
  console.error(message)
}

// never — 정상적으로 반환하지 않는 함수
function fail(message: string): never {
  throw new Error(message)
}

function assertNonNull<T>(value: T | null): T {
  if (value === null) fail('값이 null입니다.')
  return value  // 여기 도달하면 value는 T 타입
}
```

## 함수 오버로딩

같은 함수 이름으로 다른 시그니처를 정의합니다.

function process(input: string | number | string[]): string | number | string[] {
  if (typeof input === 'string') {
    return input.toUpperCase()
  } else if (typeof input === 'number') {
    return input * 2
  } else {
    return input.map(s => s.toUpperCase())
  }
}

const result1: string = process('hello')      // OK
const result2: number = process(42)            // OK
const result3: string[] = process(['a', 'b'])  // OK

console.log(result1, result2, result3)`,

## this 타입

```ts
interface Counter {
  count: number
  increment(): void
}

// this 매개변수로 타입 명시 (실제 매개변수가 아님)
function increment(this: Counter): void {
  this.count++
}

const counter: Counter = {
  count: 0,
  increment,
}

counter.increment()  // OK
```

## 핵심 정리

- 매개변수와 반환 타입을 명시하며 반환 타입은 추론되므로 생략 가능합니다.
- 선택적 매개변수는 `?`, 기본값은 `= value`로 지정합니다.
- rest 파라미터 `...params`는 나머지 인수를 배열로 받습니다.
- 오버로딩으로 입력 타입에 따른 출력 타입을 명확히 정의합니다.
