## 제네릭 기본

타입을 매개변수처럼 받아 다양한 타입에서 동작하는 코드를 작성합니다.

```ts
// any 사용 — 타입 정보를 잃음
function identity(arg: any): any {
  return arg
}

// 제네릭 — 타입 정보를 유지
function identity<T>(arg: T): T {
  return arg
}

const str = identity<string>('hello')  // 타입: string
const num = identity(42)               // 타입: number (타입 추론)
```

## 제네릭 함수

```ts
// 배열의 첫 번째 요소 반환
function first<T>(arr: T[]): T | undefined {
  return arr[0]
}

first([1, 2, 3])       // 타입: number | undefined
first(['a', 'b', 'c']) // 타입: string | undefined

// 두 값을 쌍으로 묶기
function pair<A, B>(first: A, second: B): [A, B] {
  return [first, second]
}

const result = pair('name', 42)  // 타입: [string, number]
```

## 제네릭 인터페이스

```ts
interface ApiResponse<T> {
  data: T
  status: number
  message: string
}

interface User {
  id: number
  name: string
}

// 사용
const userResponse: ApiResponse<User> = {
  data: { id: 1, name: 'Alice' },
  status: 200,
  message: 'OK',
}

const listResponse: ApiResponse<User[]> = {
  data: [{ id: 1, name: 'Alice' }],
  status: 200,
  message: 'OK',
}
```

## extends 제약

제네릭 타입 매개변수에 조건을 추가합니다.

```ts
// T는 length 프로퍼티를 가진 타입이어야 함
function getLength<T extends { length: number }>(arg: T): number {
  return arg.length
}

getLength('hello')     // OK — string은 length 있음
getLength([1, 2, 3])   // OK — array는 length 있음
getLength(42)          // 오류 — number는 length 없음

// 두 타입 간 관계 제약
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key]
}

const user = { id: 1, name: 'Alice', age: 25 }
getProperty(user, 'name')  // OK, 타입: string
getProperty(user, 'age')   // OK, 타입: number
getProperty(user, 'email') // 오류 — 'email' is not a key of user
```

## keyof 연산자

객체 타입의 모든 키를 유니온 타입으로 가져옵니다.

```ts
interface User {
  id: number
  name: string
  email: string
}

type UserKeys = keyof User  // 'id' | 'name' | 'email'

// 실용 예시
function pluck<T, K extends keyof T>(arr: T[], key: K): T[K][] {
  return arr.map(item => item[key])
}

const users = [
  { id: 1, name: 'Alice', email: 'a@example.com' },
  { id: 2, name: 'Bob', email: 'b@example.com' },
]

pluck(users, 'name')   // ['Alice', 'Bob'], 타입: string[]
pluck(users, 'id')     // [1, 2], 타입: number[]
```

## typeof 연산자 (타입 컨텍스트)

런타임 값의 타입을 추출합니다.

```ts
const point = { x: 10, y: 20 }
type Point = typeof point  // { x: number; y: number }

function createPoint(x: number, y: number): typeof point {
  return { x, y }
}

// 함수의 반환 타입 추출
function getUser() {
  return { id: 1, name: 'Alice' }
}

type User = ReturnType<typeof getUser>  // { id: number; name: string }
```

## 핵심 정리

- 제네릭 `<T>`는 타입을 매개변수로 받아 재사용 가능한 코드를 만듭니다.
- `<T extends Type>`으로 제네릭 타입에 제약을 추가합니다.
- `keyof T`는 타입 T의 모든 키를 유니온으로 반환합니다.
- `typeof value`는 값으로부터 타입을 추출합니다.
