## 매핑 타입 (Mapped Types)

기존 타입의 프로퍼티를 순회해 새 타입을 만듭니다.

```ts
// Partial 구현 원리
type MyPartial<T> = {
  [K in keyof T]?: T[K]
}

// Readonly 구현 원리
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K]
}

// 모든 값을 string으로
type Stringify<T> = {
  [K in keyof T]: string
}

interface User {
  id: number
  name: string
  active: boolean
}

type StringifiedUser = Stringify<User>
// { id: string; name: string; active: string }
```

## 매핑 타입 — 키 재매핑

```ts
// as로 키 이름 변환
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
}

interface User {
  id: number
  name: string
}

type UserGetters = Getters<User>
// { getId: () => number; getName: () => string }
```

## 조건부 타입 (Conditional Types)

```ts
// T extends U ? TrueType : FalseType
type IsString<T> = T extends string ? true : false

type A = IsString<string>  // true
type B = IsString<number>  // false

// 배열 타입에서 요소 타입 추출
type Flatten<T> = T extends Array<infer Item> ? Item : T

type Str = Flatten<string[]>   // string
type Num = Flatten<number[]>   // number
type Same = Flatten<string>    // string (배열이 아님)
```

## infer 키워드

조건부 타입에서 타입을 캡처합니다.

```ts
// Promise의 내부 타입 추출
type Awaited<T> = T extends Promise<infer Value> ? Value : T

type Result = Awaited<Promise<string>>  // string
type Same = Awaited<number>            // number (Promise 아님)

// 함수 반환 타입 구현
type MyReturnType<T extends (...args: unknown[]) => unknown> =
  T extends (...args: unknown[]) => infer R ? R : never

function getUser() {
  return { id: 1, name: 'Alice' }
}

type UserType = MyReturnType<typeof getUser>  // { id: number; name: string }
```

## 분산 조건부 타입

유니온 타입에 조건부 타입을 적용하면 각 멤버에 분산됩니다.

```ts
type ToArray<T> = T extends unknown ? T[] : never

type Result = ToArray<string | number>
// string[] | number[]  (분산 적용)

// 분산을 막으려면 대괄호로 감쌈
type NoDistribute<T> = [T] extends [unknown] ? T[] : never

type Result2 = NoDistribute<string | number>
// (string | number)[]
```

## Template Literal Types

```ts
// 문자열 타입을 조합
type Greeting = `Hello, ${string}`

type Direction = 'left' | 'right' | 'up' | 'down'
type EventName = `on${Capitalize<Direction>}`
// 'onLeft' | 'onRight' | 'onUp' | 'onDown'

// REST API 타입 생성
type HttpMethod = 'get' | 'post' | 'put' | 'delete'
type Endpoint = '/users' | '/posts' | '/comments'
type ApiRoute = `${Uppercase<HttpMethod>} ${Endpoint}`
// 'GET /users' | 'GET /posts' | ... (12가지 조합)

// 객체 이벤트 이름 생성
type EventMap<T extends object> = {
  [K in keyof T as `on${Capitalize<string & K>}Change`]: (value: T[K]) => void
}

interface FormValues {
  name: string
  email: string
  age: number
}

type FormEvents = EventMap<FormValues>
// { onNameChange: (value: string) => void; onEmailChange: ...; onAgeChange: ... }
```

## 실전 활용 예시

```ts
// 깊은 Partial (재귀 매핑 타입)
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K]
}

interface Config {
  db: { host: string; port: number }
  cache: { ttl: number }
}

type PartialConfig = DeepPartial<Config>
// { db?: { host?: string; port?: number }; cache?: { ttl?: number } }
```

## 핵심 정리

- 매핑 타입 `[K in keyof T]`로 기존 타입의 프로퍼티를 변환합니다.
- 조건부 타입 `T extends U ? A : B`로 타입을 조건에 따라 결정합니다.
- `infer`로 조건부 타입 내에서 타입을 추출합니다.
- Template Literal Types로 문자열 타입을 조합합니다.
