## 원시 타입

```ts
// string
let name: string = 'Alice'
let greeting: string = `Hello, ${name}`

// number — 정수와 부동소수점을 모두 포함
let age: number = 25
let price: number = 9.99
let hex: number = 0xff

// boolean
let active: boolean = true
let done: boolean = false
```

## null과 undefined

```ts
// strict 모드에서 null/undefined는 각자 자신의 타입에만 할당 가능
let n: null = null
let u: undefined = undefined

// strict가 false이면 모든 타입에 null/undefined 할당 가능 (권장하지 않음)
// strict가 true이면 명시적으로 유니온 타입을 써야 함
let value: string | null = null
let optionalName: string | undefined = undefined
```

## any

타입 검사를 완전히 비활성화합니다. 사용을 최소화해야 합니다.

```ts
let anything: any = 42
anything = 'hello'    // OK
anything = true       // OK
anything.method()     // OK — 타입 검사 없음, 런타임 오류 가능

// any는 타입 안전성을 포기합니다
function processData(data: any) {
  return data.value.toUpperCase()  // 런타임에 오류 가능
}
```

## unknown

any와 유사하지만 사용 전에 타입을 좁혀야 합니다. any보다 안전합니다.

## void

반환값이 없는 함수의 반환 타입입니다.

```ts
function logMessage(message: string): void {
  console.log(message)
  // return이 없거나 return undefined만 가능
}

// void 타입의 변수는 undefined만 할당 가능
let result: void = undefined
```

## never

절대 발생하지 않는 값의 타입입니다.

```ts
// 항상 예외를 던지는 함수
function throwError(message: string): never {
  throw new Error(message)
}

// 무한 루프 함수
function infinite(): never {
  while (true) {}
}

// 완전성 검사 (exhaustive check)
type Direction = 'left' | 'right' | 'up' | 'down'

function move(dir: Direction) {
  switch (dir) {
    case 'left': return '왼쪽'
    case 'right': return '오른쪽'
    case 'up': return '위'
    case 'down': return '아래'
    default:
      const exhaustive: never = dir  // Direction 타입이 누락되면 오류
      return exhaustive
  }
}
```

## 배열과 튜플

```ts
// 배열
let numbers: number[] = [1, 2, 3]
let strings: Array<string> = ['a', 'b', 'c']

// 튜플 — 고정된 길이와 각 위치의 타입이 정해진 배열
let coordinate: [number, number] = [10, 20]
let entry: [string, number] = ['age', 25]

// 구조 분해와 함께
const [x, y] = coordinate
```

## 리터럴 타입

```ts
// 구체적인 값으로 타입을 제한
let direction: 'left' | 'right' | 'up' | 'down' = 'left'
let statusCode: 200 | 400 | 404 | 500 = 200

// const로 선언하면 리터럴 타입으로 추론됨
const PI = 3.14       // 타입: 3.14
let mutable = 3.14   // 타입: number
```

## 타입 단언 (Type Assertion)

```ts
// as 문법 — 컴파일러에게 타입을 알려줌
const input = document.getElementById('name') as HTMLInputElement
input.value = 'Alice'

// 꺾쇠 문법 (JSX에서는 사용 불가)
const input2 = <HTMLInputElement>document.getElementById('name')

// 주의: 단언은 런타임에 아무것도 하지 않음
// 잘못된 단언은 런타임 오류로 이어질 수 있음
```

## 핵심 정리

- `string`, `number`, `boolean`은 JavaScript 원시 타입에 대응합니다.
- `any`는 타입 검사를 비활성화하며 사용을 최소화해야 합니다.
- `unknown`은 any보다 안전한 대안으로 사용 전 타입을 좁혀야 합니다.
- `void`는 반환값이 없는 함수, `never`는 절대 반환하지 않는 함수에 사용합니다.
- 리터럴 타입으로 허용되는 값을 구체적으로 제한할 수 있습니다.
