## 02편 복습

이번 편은 지식보다 **손으로 직접 해보는 것**이 중요하다. 퀴즈로 개념을 확인한 뒤, 실습으로 마무리하자.

## 문제 1

REPL이 정확히 무엇을 뜻하는 말인가?

<Quiz>
  <Quiz.Option>Run, Execute, Print, Loop (실행, 처리, 출력, 반복)</Quiz.Option>
  <Quiz.Option correct>Read, Eval, Print, Loop (읽고, 실행하고, 출력하고, 반복하는 것)</Quiz.Option>
  <Quiz.Option>Real-time Execution Programming Language</Quiz.Option>
  <Quiz.Option>Read-Only Execution Platform</Quiz.Option>

  <Quiz.Explanation>
  Read(코드를 한 줄 읽고) → Eval(그 자리에서 바로 실행하고, Eval은 Evaluate의 줄임말로 "계산해서 값을 낸다"는 뜻) → Print(결과를 화면에 출력하고) → Loop(이 과정을 계속 반복하는) 환경이라는 뜻이다. 브라우저 콘솔과 `node` 명령으로 여는 창 둘 다 이 방식으로 동작한다. 짧은 코드를 실험해볼 때 파일을 안 만들어도 돼서 편하다.
  </Quiz.Explanation>
</Quiz>

## 문제 2

Node.js를 가장 정확하게 설명한 것은?

<Quiz>
  <Quiz.Option>자바스크립트의 새로운 버전(문법이 다른 언어)</Quiz.Option>
  <Quiz.Option correct>브라우저 없이 자바스크립트를 실행시켜 주는 프로그램(런타임)</Quiz.Option>
  <Quiz.Option>자바스크립트 코드를 그림으로 바꿔주는 도구</Quiz.Option>
  <Quiz.Option>브라우저의 다른 이름</Quiz.Option>

  <Quiz.Explanation>
  **런타임**<sup>Runtime</sup>이란 "프로그램을 실제로 돌아가게 해주는 실행 환경"을 뜻한다. Node.js는 언어가 아니라, 자바스크립트라는 언어를 브라우저 없이도 돌아가게 해주는 프로그램이다. 1편에서 배운 "언어(ECMAScript)와 그걸 실행시켜 주는 호스트 환경은 다르다"는 구분이 여기서도 그대로 적용된다 — 브라우저가 하나의 호스트 환경이었다면, Node.js는 또 다른 호스트 환경이다.
  </Quiz.Explanation>
</Quiz>

## 문제 3

Node.js 설치 시 **LTS 버전**을 권장하는 이유는?

<Quiz>
  <Quiz.Option>유일하게 무료로 설치할 수 있는 버전이라서</Quiz.Option>
  <Quiz.Option correct>Long Term Support(장기 지원)의 줄임말로, 최신 실험 버전보다 안정적이라서</Quiz.Option>
  <Quiz.Option>한글을 지원하는 유일한 버전이라서</Quiz.Option>
  <Quiz.Option>용량이 가장 작아서</Quiz.Option>

  <Quiz.Explanation>
  LTS는 **Long Term Support**(장기 지원)의 줄임말이다. Node.js는 계속 새 버전이 나오는데, 그중 일부를 "당분간 오래 안정적으로 지원하겠다"고 지정한 게 LTS 버전이다. 최신 기능이 빠르게 들어간 버전(Current 버전)은 아직 검증이 덜 됐을 수 있어서, 처음 배우거나 실무에 쓸 때는 LTS가 안전하다.
  </Quiz.Explanation>
</Quiz>

## 실습 — 환경을 직접 갖추기

<Steps>

### Node.js 설치 확인

터미널(명령어를 입력하는 검은 화면)을 열고 아래를 입력한다.

```bash
node --version
```

버전이 안 나온다면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 내려받아 설치하고 다시 시도한다.

### REPL에서 계산기 놀이

```bash
node
```

REPL(위에서 배운 그 실행 환경)이 뜨면 아래를 순서대로 쳐본다.

```js
1 + 1
console.log('안녕')
typeof undefined
```

`.exit`을 입력하면 빠져나온다.

### 첫 파일 만들고 실행하기

편집기(코드를 짜는 프로그램, VS Code 등)로 `practice.js` 파일을 만들고 아래를 저장한다.

```js filename="practice.js"
const name = '나'
console.log(`안녕, ${name}!`)
```

터미널에서 실행한다.

```bash
node practice.js
```

터미널에 인사말이 뜨면 성공이다.

### 브라우저 콘솔과 비교하기

같은 코드를 브라우저 콘솔에도 쳐보자. 똑같이 동작하는가? (백틱(`` ` ``)으로 값을 끼워 넣는 문법은 24편에서 자세히 다루니 지금은 결과만 확인하면 된다.)

</Steps>
