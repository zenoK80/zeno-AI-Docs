## 템플릿 리터럴 (Template Literal)

백틱(`` ` ``)으로 감싸며 표현식을 `${}` 안에 넣을 수 있습니다.

```js
const name = '철수'
const age = 20

// 이전 방식
const old = '이름: ' + name + ', 나이: ' + age

// 템플릿 리터럴
const modern = `이름: ${name}, 나이: ${age}`

// 여러 줄
const multiLine = `첫 번째 줄
두 번째 줄`
```

## 구조 분해 할당 (Destructuring)

배열이나 객체에서 값을 꺼내 변수에 바로 할당합니다.

// 기본값 설정
const [a = 10, b = 20] = [5]
console.log(a, b)    // 5, 20

// 객체 구조 분해
const { name, age, job = '미정' } = { name: '영희', age: 25 }
console.log(name, age, job)  // '영희' 25 '미정'

## 전개 연산자 (Spread Operator)

배열/객체를 펼칩니다.

```js
// 배열 복사 및 합치기
const arr1 = [1, 2, 3]
const arr2 = [4, 5, 6]
const merged = [...arr1, ...arr2]  // [1, 2, 3, 4, 5, 6]
const copy = [...arr1]             // [1, 2, 3] (얕은 복사)

// 객체 복사 및 병합
const base = { a: 1, b: 2 }
const extended = { ...base, c: 3 }       // { a: 1, b: 2, c: 3 }
const overwrite = { ...base, b: 99 }     // { a: 1, b: 99 }

// 함수 인수로 펼치기
Math.max(...arr1)  // 3
```

## 나머지 매개변수 (Rest Parameter)

```js
function sum(first, ...others) {
  return first + others.reduce((acc, n) => acc + n, 0)
}
console.log(sum(1, 2, 3, 4))  // 10
```

## 단축 프로퍼티와 메서드

```js
const x = 10, y = 20
const point = { x, y }   // { x: 10, y: 20 }

const obj = {
  name: '예제',
  greet() {            // function 키워드 생략
    return `안녕, ${this.name}`
  }
}
```

## 선택적 체이닝 (?.)

중첩 프로퍼티 접근 시 null/undefined이면 오류 없이 undefined를 반환합니다.

```js
const user = { profile: { avatar: '/img.png' } }
console.log(user?.profile?.avatar)  // '/img.png'
console.log(user?.settings?.theme)  // undefined (오류 없음)
```

## 심볼 (Symbol)

고유하고 변경 불가능한 식별자입니다.

```js
const id1 = Symbol('id')
const id2 = Symbol('id')
console.log(id1 === id2)  // false (항상 고유)

const obj = {
  [id1]: '고유한 값',
  name: '일반 프로퍼티',
}
console.log(obj[id1])  // '고유한 값'
```

심볼은 `for...in`이나 `Object.keys()`에 열거되지 않습니다.

## 핵심 정리

- 템플릿 리터럴로 복잡한 문자열 조합을 간결하게 표현합니다.
- 구조 분해로 배열/객체에서 값을 빠르게 추출합니다.
- 전개 연산자로 배열/객체를 복사하거나 합칩니다.
- 선택적 체이닝으로 안전하게 중첩 프로퍼티에 접근합니다.
