## Symbol이란?

06번 문서에서 원시 타입 7가지 중 하나로 잠깐 언급했던 **Symbol**을 자세히 다룹니다.

> **쉽게 말하면:** Symbol은 `Symbol()`을 호출할 때마다 세상에 단 하나뿐인, 절대 겹치지 않는 값을 만들어주는 타입입니다.

```js
const id1 = Symbol('id')
const id2 = Symbol('id')

console.log(id1 === id2)  // false! — 같은 설명('id')을 줘도 매번 다른 고유한 값
console.log(typeof id1)   // 'symbol'
```

문자열은 `'id' === 'id'`가 항상 `true`이지만, `Symbol('id')`는 호출할 때마다 완전히 새로운 고유값을 만듭니다. `Symbol()`의 인수(`'id'`)는 디버깅할 때 알아보기 위한 설명일 뿐, 값 자체와는 무관합니다.

## Symbol을 객체의 키로 쓰는 이유 — 충돌 없는 프로퍼티

```js
const uniqueKey = Symbol('description')

const obj = {
  description: '일반 문자열 키',
  [uniqueKey]: 'Symbol 키',  // 계산된 프로퍼티 이름(15번 문서)으로 사용
}

console.log(obj.description)     // '일반 문자열 키'
console.log(obj[uniqueKey])      // 'Symbol 키'
console.log(Object.keys(obj))    // ['description'] — Symbol 키는 여기 안 나타남!
```

Symbol을 키로 쓰면 `Object.keys()`, `for...in`, `JSON.stringify`에 **나타나지 않습니다.** 이런 성질 때문에, 라이브러리가 일반 객체에 "몰래" 추가 정보를 붙이면서도 그 객체를 순회하는 일반적인 코드와 절대 충돌하지 않게 하는 용도로 쓰입니다.

## Well-known Symbol — Symbol.iterator

26번 문서에서 이미 Symbol을 만난 적이 있습니다. `Symbol.iterator`는 자바스크립트가 미리 정의해둔 특별한 Symbol로, "이 객체를 어떻게 순회할지"를 정의하는 규칙입니다.

```js
const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {  // 이 객체를 이터러블로 만드는 방법을 직접 정의
    let current = this.from
    const last = this.to
    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false }
        }
        return { value: undefined, done: true }
      },
    }
  },
}

console.log([...range])  // [1, 2, 3] — 원래는 순회 불가능한 일반 객체인데 for...of가 가능해짐!
for (const num of range) {
  console.log(num)
}
```

## Proxy — 객체의 기본 동작을 가로채기

**Proxy**(대리인)는 객체에 대한 접근(읽기, 쓰기, 삭제 등)을 **가로채서** 커스텀 동작을 끼워 넣을 수 있게 하는 객체입니다.

<CodePlayground
  template="vanilla"
  activeFile="/index.js"
  showConsole
  label="Proxy 실습"
  files={{
    '/index.js': `const target = { name: '철수', age: 25 }

const handler = {
  get(obj, prop) {
    console.log(\`읽기 시도: \${prop}\`)
    return prop in obj ? obj[prop] : '존재하지 않는 값'
  },
  set(obj, prop, value) {
    console.log(\`쓰기 시도: \${prop} = \${value}\`)
    if (prop === 'age' && typeof value !== 'number') {
      throw new Error('age는 숫자여야 합니다')
    }
    obj[prop] = value
    return true
  },
}

const proxy = new Proxy(target, handler)

console.log(proxy.name)        // '읽기 시도: name' 출력 후 '철수'
proxy.age = 26                 // '쓰기 시도: age = 26' 출력
console.log(proxy.email)       // '읽기 시도: email' 출력 후 '존재하지 않는 값'

try {
  proxy.age = '스물여섯'        // 검증 실패
} catch (e) {
  console.log('에러:', e.message)
}`,
  }}
/>

`new Proxy(target, handler)`에서 `handler`의 `get`, `set` 같은 메서드를 **트랩**(trap)이라고 부릅니다. 프로퍼티 읽기·쓰기 같은 기본 동작이 일어날 때마다 이 트랩이 먼저 호출되어, 로깅, 검증, 기본값 처리 같은 로직을 원본 객체 코드를 건드리지 않고 끼워 넣을 수 있습니다.

## Reflect — Proxy와 짝을 이루는 도구

`Reflect`는 객체의 기본 동작(get, set, delete 등)을 **함수로 그대로 실행**할 수 있게 해주는 내장 객체입니다. Proxy 트랩 안에서 "원래 동작을 그대로 수행하고 싶을 때" 자주 함께 씁니다.

```js
const handler = {
  get(obj, prop) {
    console.log(`읽기: ${String(prop)}`)
    return Reflect.get(obj, prop)  // obj[prop]과 동일하지만, 표준화된 방식
  },
}
```

## 메타프로그래밍이란?

> **쉽게 말하면:** 메타프로그래밍(metaprogramming)은 "프로그램이 프로그램 자신의 동작 방식을 다루는 것"입니다.

일반적인 코드는 데이터를 다룹니다(`user.name`을 읽고 쓰는 것). Proxy와 Reflect는 그 **"읽고 쓰는 행위 자체"**를 가로채고 재정의합니다. 이것이 "메타"(한 단계 위)라는 이름이 붙은 이유입니다. 이 도구들은 실무에서는 자주 직접 쓰이지 않지만, Vue.js의 반응형 시스템 같은 유명 라이브러리의 핵심 원리로 사용됩니다.

## 핵심 정리

- Symbol()은 호출할 때마다 절대 겹치지 않는 고유한 값을 만든다.
- Symbol을 프로퍼티 키로 쓰면 Object.keys(), for...in, JSON.stringify에서 제외되어 충돌 없는 "숨은" 프로퍼티를 만들 수 있다.
- Symbol.iterator를 직접 구현하면 일반 객체도 for...of로 순회 가능한 이터러블로 만들 수 있다.
- Proxy는 객체의 읽기·쓰기 같은 기본 동작을 가로채 커스텀 로직(로깅, 검증 등)을 끼워 넣을 수 있게 한다.
- Reflect는 객체의 기본 동작을 표준화된 함수로 수행하며, Proxy 트랩 안에서 원래 동작을 그대로 실행할 때 자주 사용된다.
