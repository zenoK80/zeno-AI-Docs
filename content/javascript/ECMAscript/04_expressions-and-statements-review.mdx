## 04편 복습

## 핵심 퀴즈

**Q1. 표현식과 문을 구별하는 가장 쉬운 판별법은?**

<Collapse title="정답 보기">
"콘솔에 쳐서 값이 나오면 표현식이다." `console.log(무언가)`로 감쌌을 때 에러 없이 값이 찍히면 표현식, `SyntaxError`가 나면 문이다.
</Collapse>

**Q2. 다음 중 표현식인 것을 모두 고르면? `1 + 1` / `let x = 1` / `x > 5` / `if (x) {}`**

<Collapse title="정답 보기">
`1 + 1`과 `x > 5`가 표현식이다. `let x = 1`과 `if (x) {}`는 문이다(값으로 평가되지 않는다).
</Collapse>

**Q3. `if문` 대신 삼항 연산자(`? :`)를 값 자리에 쓸 수 있는 이유는?**

<Collapse title="정답 보기">
삼항 연산자는 표현식이라 값으로 평가되지만, `if문`은 표현식이 아니라 값이 필요한 자리에 쓸 수 없기 때문이다.
</Collapse>

## 실습 — ASI 함정 직접 재현하기

아래 함수를 콘솔이나 파일에 그대로 쳐보고, 결과를 예상해 본 뒤 실행해서 확인하자.

```js
function getValue() {
  return
  {
    value: 1
  }
}

console.log(getValue())
```

<Collapse title="결과와 이유">
`undefined`가 나온다. `return` 다음 줄바꿈에서 ASI(자동 세미콜론 삽입)가 `return;`으로 만들어버려서, 그 아래 객체는 실행되지 않는 죽은 코드가 된다.
</Collapse>

이제 같은 함수를 아래처럼 고쳐서 다시 실행해 보자.

```js
function getValueFixed() {
  return {
    value: 1
  }
}

console.log(getValueFixed())
```

무엇이 달라졌는지, 왜 이번엔 제대로 나오는지 스스로 설명해 보자.

## 정리 체크리스트

<Callout type="default">
- [ ] 표현식과 문을 예시 코드로 구별할 수 있다

</Callout>
