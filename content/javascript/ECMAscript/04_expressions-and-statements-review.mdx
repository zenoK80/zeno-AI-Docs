## 04편 복습

## 문제 1

표현식인지 아닌지 가장 쉽게 확인하는 방법은?

- A. 세미콜론(`;`)이 붙어 있는지 본다
- B. `console.log(그것)`으로 감쌌을 때 에러 없이 값이 찍히는지 본다
- C. 글자 수가 짧은지 본다
- D. 중괄호(`{ }`)가 있는지 본다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
**표현식**<sup>Expression</sup>은 "평가되어 하나의 값이 되는 코드 조각"이다. 그래서 `console.log( )` 괄호 안에 넣었을 때 문제없이 값이 출력되면 표현식이고, `SyntaxError`(문법 오류)가 나면 표현식이 아니라 **문**<sup>Statement, 하나의 실행 지시</sup>이다. 예를 들어 `console.log(1 + 1)`은 `2`를 출력하지만, `console.log(let x = 1)`은 에러가 난다.
</Collapse>

## 문제 2

다음 중 **문**(Statement)에 해당하는 것은?

- A. `1 + 1`
- B. `age > 18`
- C. `let x = 1`
- D. `'hello'`

<Collapse title="정답 보기">
정답: **C**
</Collapse>

<Collapse title="해설 보기">
`let x = 1`은 "변수를 선언하고 값을 넣어라"는 **실행 지시**이지, 그 자체가 어떤 값으로 평가되지 않는다. 반면 A(`1 + 1`)는 `2`로, B(`age > 18`)는 `true`나 `false`로, D(`'hello'`)는 문자열 그 자체로 평가되는 표현식이다. 문은 표현식을 재료로 쓴다 — `let x = 1`이라는 문 안에도 `1`이라는 표현식이 들어있다.
</Collapse>

## 문제 3

`if문` 대신 삼항 연산자(`조건 ? 참일때 : 거짓일때`)를 값이 필요한 자리에 쓸 수 있는 이유는?

- A. 삼항 연산자가 타이핑하기 더 짧아서
- B. 삼항 연산자는 표현식이라 값으로 평가되지만, `if문`은 문이라 값이 되지 않기 때문에
- C. `if문`은 옛날 문법이라 곧 사라질 예정이라서
- D. 둘은 사실 완전히 똑같이 동작해서 아무 차이가 없다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
값이 필요한 자리(예: 함수 호출의 괄호 안, 변수에 대입하는 자리)에는 **표현식만** 올 수 있다. `if문`은 "조건에 따라 실행 흐름을 나누는 지시"일 뿐 그 자체가 값이 되지 않아서 그런 자리에 쓸 수 없다. 반면 삼항 연산자(`? :`)는 조건을 평가해서 **최종적으로 값 하나를 만들어내는 표현식**이라 그 자리에 들어갈 수 있다. 자세한 문법은 8편(제어문)에서 다룬다.
</Collapse>

## 실습 — ASI 함정 직접 재현하기

**ASI**<sup>Automatic Semicolon Insertion, 자동 세미콜론 삽입</sup>는 세미콜론을 생략해도 자바스크립트가 알아서 채워 넣어 주는 기능이다. 편리하지만 가끔 의도와 다르게 채워 넣는다. 아래 함수를 콘솔이나 파일에 그대로 쳐보고, 결과를 예상해 본 뒤 실행해서 확인하자.

```js
function getValue() {
  return
  {
    value: 1
  }
}

console.log(getValue())
```

<Collapse title="결과와 이유">
`undefined`가 나온다. `return` 다음에 줄바꿈이 있으면, ASI가 그 줄바꿈 자리에 세미콜론을 끼워 넣어 `return;`으로 만들어버린다. 그러면 그 아래 `{ value: 1 }`은 실행되지 않는 죽은 코드가 된다.
</Collapse>

이제 같은 함수를 아래처럼 고쳐서 다시 실행해 보자.

```js
function getValueFixed() {
  return {
    value: 1
  }
}

console.log(getValueFixed())
```

무엇이 달라졌는지, 왜 이번엔 제대로 나오는지 스스로 설명해 보자.
