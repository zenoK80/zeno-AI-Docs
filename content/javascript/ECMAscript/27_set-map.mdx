## Set — 중복 없는 값의 모음

> **쉽게 말하면:** Set(집합)은 "같은 값을 두 번 넣을 수 없는 특수한 목록"입니다.

```js
const numbers = [1, 2, 2, 3, 3, 3]

// 배열로 중복 제거하려면 이렇게 번거로웠다
const uniqueOld = numbers.filter((n, index) => numbers.indexOf(n) === index)

// Set을 쓰면 자동으로 중복이 제거된다
const uniqueSet = new Set(numbers)
console.log(uniqueSet)         // Set(3) {1, 2, 3}
console.log([...uniqueSet])    // [1, 2, 3] — 배열로 다시 변환
```

### Set의 기본 메서드

```js
const fruits = new Set()

fruits.add('사과')
fruits.add('바나나')
fruits.add('사과')  // 이미 있는 값 — 무시됨(에러 아님)

console.log(fruits.size)              // 2 — length가 아닌 size
console.log(fruits.has('사과'))       // true
fruits.delete('바나나')
console.log(fruits.has('바나나'))     // false

for (const fruit of fruits) {
  console.log(fruit)  // Set도 for...of로 순회 가능(이터러블)
}
```

<Callout type="warning">
  배열은 `.length`, Set은 `.size`로 개수를 확인합니다. 이름이 다르다는 점을 자주 헷갈립니다.
</Callout>

### Set으로 집합 연산 구현하기

```js
const setA = new Set([1, 2, 3, 4])
const setB = new Set([3, 4, 5, 6])

// 합집합(union) — 두 집합의 모든 값
const union = new Set([...setA, ...setB])
console.log([...union])  // [1, 2, 3, 4, 5, 6]

// 교집합(intersection) — 둘 다 포함된 값
const intersection = new Set([...setA].filter(x => setB.has(x)))
console.log([...intersection])  // [3, 4]

// 차집합(difference) — setA에만 있는 값
const difference = new Set([...setA].filter(x => !setB.has(x)))
console.log([...difference])  // [1, 2]
```

## Map — 어떤 값이든 키로 쓸 수 있는 저장소

> **쉽게 말하면:** Map은 일반 객체와 비슷하지만, 키(key)로 문자열뿐 아니라 숫자, 객체, 함수 등 **무엇이든** 쓸 수 있는 저장소입니다.

```js
const userRoles = new Map()

userRoles.set('철수', 'admin')
userRoles.set('영희', 'user')

console.log(userRoles.get('철수'))   // 'admin'
console.log(userRoles.has('민수'))   // false
console.log(userRoles.size)          // 2 — Map도 size

userRoles.delete('영희')
console.log(userRoles.size)          // 1
```

### 객체를 키로 쓸 수 있다는 차이

일반 객체 `{}`는 키가 자동으로 문자열로 변환됩니다. Map은 객체를 키로 써도 **그 객체 자체**로 구분합니다.

## Map 순회하기

```js
const scores = new Map([
  ['철수', 90],
  ['영희', 85],
])

for (const [name, score] of scores) {  // 구조 분해와 함께 순회
  console.log(name, score)
}

console.log([...scores.keys()])    // ['철수', '영희']
console.log([...scores.values()])  // [90, 85]
console.log([...scores.entries()]) // [['철수',90], ['영희',85]]
```

## 핵심 정리

- Set은 중복을 허용하지 않는 값의 모음이며, 개수는 `.size`로 확인한다.
- 스프레드와 Set을 조합하면 배열의 중복 제거, 합집합·교집합·차집합을 간결하게 구현할 수 있다.
- Map은 문자열이 아닌 값(객체, 숫자 등)도 키로 사용할 수 있어 일반 객체보다 유연하다.
- 일반 객체는 키를 항상 문자열로 변환하지만, Map은 객체를 참조 그대로 구분한다.
- Set과 Map 모두 이터러블이라 for...of로 순회할 수 있다.
