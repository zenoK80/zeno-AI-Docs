## 개발 환경 준비와 첫 실행

1편에서 자바스크립트가 무엇인지 봤으니, 이제 실제로 코드를 실행해 볼 차례다.
설치할 것도 많지 않다. 사실 지금 이 글을 보고 있는 브라우저만 있어도 당장 시작할 수 있다.

## 방법 1 — 브라우저 콘솔

가장 빠른 방법이다. 아무 웹사이트에서나 **개발자 도구**를 열면 된다.

<Steps>

### 개발자 도구를 연다

<kbd>F12</kbd> 또는 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> (Mac은 <kbd>Cmd</kbd>+<kbd>Option</kbd>+<kbd>I</kbd>)를 누른다.

### Console 탭으로 이동한다

여러 탭 중 **Console**을 클릭한다.

### 코드를 입력하고 Enter를 누른다

```js
1 + 1
```

`2`가 바로 출력된다.

</Steps>

<Callout type="info">
콘솔은 **한 줄씩 즉시 실행하고 결과를 보여주는 환경**이다. 이런 방식을 **REPL**<sup>Read-Eval-Print Loop</sup>이라 부른다.
"읽고(Read) → 실행하고(Eval) → 출력하고(Print) → 반복한다(Loop)"는 뜻이다. 짧은 코드를 실험할 때 유용하다.
</Callout>

콘솔에는 미리 만들어진 명령도 있다.

```js
console.log('안녕하세요')   // 값을 콘솔에 출력한다
console.error('문제 발생')  // 에러 스타일로 출력한다
```

`console.log`는 앞으로 이 시리즈 전체에서 결과를 확인하는 기본 도구로 계속 쓴다.

## 방법 2 — HTML 파일에 스크립트 넣기

콘솔은 실험용이다. 실제로는 **파일에 코드를 저장**해서 실행한다. 가장 간단한 방법은 HTML 파일에 넣는 것이다.

```html filename="index.html"
<!DOCTYPE html>
<html>
<body>
  <script>
    console.log('파일에서 실행됨')
  </script>
</body>
</html>
```

이 파일을 브라우저로 열고 콘솔을 보면 메시지가 찍혀 있다.

<Callout type="info">
`<script>` 태그와 HTML 문서의 관계(어디에 놓을지, 언제 실행되는지)는 이 시리즈의 범위를 벗어난다.
브라우저가 스크립트를 처리하는 자세한 규칙은 Web APIs 시리즈 8편에서 다룬다. 지금은 "동작한다"는 것만 확인하면 충분하다.
</Callout>

## 방법 3 — Node.js로 브라우저 없이 실행하기

콘솔과 HTML 파일은 둘 다 **브라우저가 필요**하다. 그런데 자바스크립트는 브라우저 밖에서도 돌아간다.
그걸 가능하게 하는 게 **Node.js**다.

<Callout type="important">
Node.js는 언어가 아니라 **자바스크립트를 브라우저 없이 실행시켜 주는 프로그램(런타임)**이다.
1편에서 본 "ECMAScript(언어)와 실행 환경은 다르다"는 구분이 여기서 실감 난다.
</Callout>

### 설치

[nodejs.org](https://nodejs.org)에서 **LTS**<sup>Long Term Support, 장기 지원</sup> 버전을 받아 설치한다. 최신 실험 버전보다 안정적이라 학습용으로 적합하다.

설치가 끝나면 터미널(명령 프롬프트)에서 확인한다.

```bash
node --version
```

버전 번호가 나오면 설치가 된 것이다.

### Node REPL

터미널에 `node`만 입력하면 브라우저 콘솔과 똑같은 REPL이 뜬다.

```bash
node
> 1 + 1
2
> console.log('안녕')
안녕
```

`.exit`을 입력하거나 <kbd>Ctrl</kbd>+<kbd>C</kbd>를 두 번 누르면 빠져나온다.

### 파일 실행

`.js` 확장자로 파일을 만들고 Node로 실행한다.

```js filename="hello.js"
console.log('파일 실행 성공')
```

```bash
node hello.js
```

터미널에 `파일 실행 성공`이 출력된다.

## 코드 편집기 준비

메모장으로도 코드를 짤 수는 있지만, 실무 편집기를 쓰면 훨씬 편하다.
가장 널리 쓰이는 건 **VS Code**([code.visualstudio.com](https://code.visualstudio.com))다. 무료이고, 자바스크립트 문법 강조와 자동완성을 기본 지원한다.

<Callout type="default">
지금부터 이 시리즈의 예제는 **"HTML 콘솔에서 실험 → 필요하면 `.js` 파일로 저장해 Node로 실행"** 순서로 다룬다.
브라우저 전용 기능(`document` 등)이 나오면 Node에서는 실행되지 않는다고 표시한다.
</Callout>

## 정리

<Callout type="default">
- 짧은 실험은 **브라우저 콘솔**(REPL)이 가장 빠르다
- 브라우저 밖에서 자바스크립트를 실행하려면 **Node.js**가 필요하다
- Node도 REPL과 파일 실행(`node 파일명.js`) 두 방식을 지원한다
- 코드는 되도록 **편집기(VS Code)** 로 파일에 저장해 관리한다
</Callout>

다음 편부터 본격적으로 문법을 배운다. 첫 주제는 값을 저장하는 **변수**다.
