## 타입 변환이란?

> **쉽게 말하면:** 자바스크립트가 서로 다른 타입의 값을 연산할 때, 한쪽 또는 양쪽 타입을 자동으로 바꾸는 것입니다.

타입 변환에는 두 종류가 있습니다.

- **명시적 변환**(explicit coercion): 개발자가 직접 `Number()`, `String()` 등으로 변환.
- **암묵적 변환**(implicit coercion): 연산자가 자동으로 변환. 예상치 못한 결과의 원인이 됩니다.

## 명시적 변환

```js
console.log(Number('42'))     // 42
console.log(Number('abc'))    // NaN — 숫자로 변환 불가
console.log(String(42))       // '42'
console.log(Boolean(1))       // true
console.log(Boolean(0))       // false
console.log(Boolean(''))      // false
console.log(Boolean('hello')) // true
```

## 암묵적 변환 — `+` 연산자의 특별한 규칙

`+`는 다른 산술 연산자와 다르게 동작합니다. **피연산자 중 하나라도 문자열이면 문자열 이어붙이기**(concatenation)**로 동작**합니다.

```js
console.log(1 + 2)      // 3 — 둘 다 숫자, 덧셈
console.log('1' + 2)    // '12' — 문자열이 섞임, 이어붙이기
console.log(1 + '2')    // '12' — 순서 상관없이 문자열 우선
console.log(1 + 2 + '3')  // '33' — 왼쪽부터 계산: (1+2)=3, 3+'3'='33'
console.log('1' + 2 + 3)  // '123' — '1'+2='12', '12'+3='123'
```

<Callout type="warning">
  `+` 연산의 결과는 **왼쪽에서 오른쪽 순서로** 계산됩니다. `1 + 2 + '3'`과 `'1' + 2 + 3`의 결과가 다른 이유는 문자열을 언제 만나느냐에 따라 이후 계산이 통째로 문자열 이어붙이기로 바뀌기 때문입니다.
</Callout>

## `-`, `*`, `/`는 다르다 — 숫자로 강제 변환

`+`를 제외한 산술 연산자(`-`, `*`, `/`, `%`)는 **항상 숫자로 변환**을 시도합니다.

## 배열과 객체의 변환

```js
console.log([1, 2, 3] + '')   // '1,2,3' — 배열이 문자열로 변환됨
console.log([] + [])          // '' — 빈 배열끼리 더하면 빈 문자열
console.log([] + {})          // '[object Object]' — 객체를 문자열로 변환한 결과
console.log(1 + [])           // '1' — 배열이 빈 문자열로 변환된 뒤 이어붙임
```

## Boolean 변환 — truthy와 falsy

`if`문의 조건처럼 boolean이 필요한 자리에서는 값이 자동으로 true/false로 취급됩니다. 이때 false로 취급되는 값을 **falsy**, 나머지 전부를 **truthy**라고 부릅니다.

### falsy 값 — 딱 6개뿐

```
false, 0, '', null, undefined, NaN
```

이 6개를 제외한 **모든** 값은 truthy입니다. `'0'`(문자 0), `[]`(빈 배열), `{}`(빈 객체)도 모두 truthy라는 점이 자주 틀리는 부분입니다.

</Callout>

## == 연산의 변환 규칙 요약

07번 문서에서 배운 `==`가 내부적으로 하는 일이 바로 이 타입 변환입니다.

<Table>
  <thead>
    <tr><th>비교</th><th>결과</th><th>이유</th></tr>
  </thead>
  <tbody>
    <tr><td><code>0 == false</code></td><td>true</td><td>false → 0으로 변환</td></tr>
    <tr><td><code>'' == false</code></td><td>true</td><td>둘 다 0으로 변환</td></tr>

## 핵심 정리

- `+`는 피연산자 중 문자열이 있으면 문자열 이어붙이기로 동작한다.
- `-`, `*`, `/`, `%`는 항상 숫자 변환을 시도한다.
- falsy 값은 `false, 0, '', null, undefined, NaN` 6가지뿐이며, 빈 배열·빈 객체는 truthy다.
- 예상치 못한 버그를 피하려면 암묵적 변환에 의존하지 말고 `Number()`, `String()`, `Boolean()`으로 명시적으로 변환하는 습관이 안전하다.
