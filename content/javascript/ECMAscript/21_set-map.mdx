## Set — 중복 없는 값 집합

`Set`은 고유한 값만 저장합니다.

```js
const set = new Set([1, 2, 3, 2, 1])
console.log(set)        // Set(3) {1, 2, 3}
console.log(set.size)   // 3

set.add(4)
set.delete(2)
set.has(3)      // true
set.has(2)      // false

// 순회
for (const v of set) {
  console.log(v)  // 1, 3, 4
}

// 배열로 변환
const arr = [...set]  // [1, 3, 4]
```

## Set 활용 — 배열 중복 제거

```js
const withDuplicates = [1, 2, 2, 3, 3, 4]
const unique = [...new Set(withDuplicates)]
console.log(unique)  // [1, 2, 3, 4]
```

## Set으로 집합 연산

```js
const a = new Set([1, 2, 3, 4])
const b = new Set([3, 4, 5, 6])

const union = new Set([...a, ...b])         // 합집합
const intersection = new Set([...a].filter(x => b.has(x)))  // 교집합
const difference = new Set([...a].filter(x => !b.has(x)))   // 차집합

console.log([...union])        // [1, 2, 3, 4, 5, 6]
console.log([...intersection]) // [3, 4]
console.log([...difference])   // [1, 2]
```

## Map — 키-값 쌍 컬렉션

`Map`은 모든 타입을 키로 사용할 수 있고, 삽입 순서를 유지합니다.

```js
const map = new Map()
map.set('name', '철수')
map.set(1, '숫자 키')
map.set({ id: 1 }, '객체 키')

console.log(map.get('name'))  // '철수'
console.log(map.has(1))       // true
console.log(map.size)         // 3

map.delete('name')

// 초기화
const map2 = new Map([
  ['a', 1],
  ['b', 2],
])
```

## Map 순회

```js
for (const [key, value] of map2) {
  console.log(key, value)
}

map2.forEach((value, key) => {
  console.log(key, value)
})

console.log([...map2.keys()])    // ['a', 'b']
console.log([...map2.values()])  // [1, 2]
console.log([...map2.entries()]) // [['a', 1], ['b', 2]]
```

## Map vs Object

| | Map | Object |
| --- | --- | --- |
| 키 타입 | 모든 타입 | 문자열/Symbol |
| 순서 | 삽입 순서 보장 | 정수 키 우선 |
| 크기 확인 | `.size` | `Object.keys().length` |
| 성능 | 잦은 삽입/삭제에 유리 | 정적 구조에 유리 |

## WeakSet과 WeakMap

`WeakSet`과 `WeakMap`은 객체만 키(또는 항목)로 가질 수 있고, 참조가 없어지면 가비지 컬렉션 대상이 됩니다.

```js
let obj = { data: '중요' }
const wm = new WeakMap()
wm.set(obj, '연결된 데이터')

console.log(wm.get(obj))  // '연결된 데이터'

obj = null  // 참조 해제 → obj와 wm의 항목 모두 GC 대상
```

WeakMap의 용도: DOM 요소에 연결된 데이터, 캐시, private 데이터 저장.

<Callout type="warning">
  WeakSet과 WeakMap은 이터러블이 아닙니다. `forEach`, `size`, `keys()` 등을 사용할 수 없습니다.
</Callout>

## 핵심 정리

- Set은 중복 없는 값 집합이며 배열 중복 제거에 유용합니다.
- Map은 모든 타입의 키를 지원하며 삽입 순서를 유지합니다.
- WeakSet/WeakMap은 가비지 컬렉션에 영향을 주지 않는 약한 참조를 유지합니다.
