## 객체란 무엇인가

**객체**(object) 는 관련된 데이터(프로퍼티)와 기능(메서드)을 하나로 묶은 구조입니다. 프로퍼티는 **키**(key) 와 **값**(value) 의 쌍으로 이루어집니다.

```js
const person = {
  name: '김철수',
  age: 28,
  job: '개발자',
}
```

중괄호 `{}`로 감싸고 콤마로 구분합니다. 이 방식을 **객체 리터럴**(object literal) 이라 합니다.

## 프로퍼티 접근

두 가지 방법으로 프로퍼티에 접근합니다.

```js
// 마침표 표기법
console.log(person.name)   // '김철수'
console.log(person.age)    // 28

// 대괄호 표기법
console.log(person['name']) // '김철수'
const key = 'age'
console.log(person[key])    // 28
```

키 이름이 변수에 들어 있거나, 숫자나 공백이 포함된 경우에는 대괄호 표기법을 씁니다.

## 프로퍼티 추가, 수정, 삭제

```js
person.email = 'kim@example.com'   // 추가
person.age = 29                    // 수정
delete person.job                  // 삭제

console.log(person)
// { name: '김철수', age: 29, email: 'kim@example.com' }
```

## 메서드

객체의 프로퍼티 값이 함수인 경우를 **메서드**(method) 라 합니다.

```js
const calculator = {
  value: 0,
  add(n) {
    this.value += n
    return this
  },
  result() {
    return this.value
  },
}

calculator.add(5).add(3)
console.log(calculator.result()) // 8
```

## ES6 단축 문법

변수 이름과 키 이름이 같으면 단축해서 쓸 수 있습니다.

```js
const name = '이영희'
const age = 25

// 이전 방식
const user1 = { name: name, age: age }

// ES6 단축 프로퍼티
const user2 = { name, age }

// 메서드 단축
const obj = {
  greet() {
    return `안녕하세요, ${this.name}입니다.`
  },
}
```

## 계산된 프로퍼티 키

대괄호 안에 표현식을 넣어 동적으로 키를 정할 수 있습니다.

```js
const prefix = 'user'
const obj = {
  [prefix + '_id']: 101,
  [prefix + '_name']: '홍길동',
}
console.log(obj.user_id)    // 101
console.log(obj.user_name)  // '홍길동'
```

## 프로퍼티 존재 확인

```js
console.log('name' in person)    // true
console.log('salary' in person)  // false
console.log(person.salary)       // undefined (없으면 undefined)
```

## 객체 복사 — Object.assign과 전개 연산자

```js
const original = { a: 1, b: 2 }
const copy1 = Object.assign({}, original)
const copy2 = { ...original }

copy1.a = 99
console.log(original.a)  // 1 (얕은 복사이므로 원본 불변)
```

<Callout type="warning">
  얕은 복사(shallow copy)는 중첩 객체까지 복사하지 않습니다. 중첩된 객체를 독립적으로 복사하려면 깊은 복사(deep copy)가 필요합니다.
</Callout>

## 핵심 정리

- 객체 리터럴은 중괄호로 키-값 쌍을 정의합니다.
- 프로퍼티 접근은 마침표 표기법과 대괄호 표기법을 씁니다.
- ES6 단축 프로퍼티와 메서드 단축으로 코드를 간결하게 쓸 수 있습니다.
- `in` 연산자로 프로퍼티 존재 여부를 확인합니다.
