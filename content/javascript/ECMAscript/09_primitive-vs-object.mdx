  **이번 문서의 목표:** 원시값과 객체가 메모리에 저장되고 전달되는 방식의 차이를 이해합니다.
</Callout>

## 원시값은 값으로 복사된다

원시 타입(number, string, boolean 등)은 변수에 값 자체가 저장됩니다. 다른 변수에 대입하면 **값이 복사**됩니다.

```js
let a = 10
let b = a   // a의 값 10이 b에 복사됨

b = 20
console.log(a)  // 10 (a는 변하지 않음)
console.log(b)  // 20
```

a와 b는 완전히 독립된 공간에 각자의 값을 가집니다.

## 객체는 참조로 전달된다

객체는 변수에 **참조**(reference), 즉 메모리 주소가 저장됩니다. 다른 변수에 대입하면 **같은 객체를 가리키는 참조가 복사**됩니다.

```js
const objA = { name: '철수' }
const objB = objA   // 같은 객체를 참조

objB.name = '영희'
console.log(objA.name)  // '영희' (같은 객체이므로 함께 변경됨)
```

objA와 objB는 메모리의 같은 객체를 가리킵니다.

## 함수 인수로 전달할 때

원시값은 복사본이 전달되고, 객체는 참조가 전달됩니다. 두 함수의 동작 차이를 직접 실행해서 확인해보세요.

console.log(num)        // 1 (원시값은 복사본 변경)

## 객체 동등 비교

두 변수가 같은 객체를 참조하는지 비교합니다.

```js
const x = { a: 1 }
const y = { a: 1 }
const z = x

console.log(x === y)  // false (내용이 같아도 다른 객체)
console.log(x === z)  // true  (같은 참조)
```

내용이 같은 두 객체를 비교하려면 JSON 직렬화나 재귀 비교가 필요합니다.

## 깊은 복사 만들기

객체를 완전히 독립적으로 복사하는 방법입니다.

```js
// JSON 방법 (단순한 경우)
const original = { a: 1, b: { c: 2 } }
const deep = JSON.parse(JSON.stringify(original))

deep.b.c = 99
console.log(original.b.c)  // 2 (원본 유지)
```

<Callout type="warning">
  JSON 방법은 함수, undefined, Symbol, 순환 참조를 가진 객체는 제대로 복사하지 못합니다. 복잡한 경우 structuredClone() 또는 라이브러리를 활용하세요.
</Callout>

```js
// structuredClone (모던 브라우저/Node.js 17+)
const deep2 = structuredClone(original)
```

## 핵심 정리

- 원시값은 변수에 값 자체가 저장되며 복사 시 독립적입니다.
- 객체는 참조가 저장되며 복사 시 같은 객체를 공유합니다.
- 함수에 객체를 전달하면 참조가 전달되어 내부에서 변경하면 원본도 바뀝니다.
- 독립된 객체를 만들려면 깊은 복사가 필요합니다.
