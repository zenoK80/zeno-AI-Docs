## 표현식 — 값을 만드는 코드

**표현식**(expression) 은 평가하면 하나의 값이 되는 코드 조각입니다.

```js
3 + 4        // 7
'hello'      // 'hello'
true         // true
a > 0        // true 또는 false
fn()         // 함수 호출 결과값
```

표현식은 항상 값을 반환합니다. 변수에 담거나, 다른 표현식 안에 중첩할 수 있습니다.

## 문 — JavaScript에 지시하는 단위

**문**(statement) 은 어떤 동작을 수행하라고 JavaScript에게 지시하는 단위입니다. 문은 값을 "만들기"보다 "무언가를 한다"는 개념입니다.

```js
const x = 5          // 변수 선언문
if (x > 0) {}        // 조건문
for (let i = 0; i < 3; i++) {}  // 반복문
```

| 구분 | 핵심 | 예 |
| --- | --- | --- |
| 표현식 | 값을 만든다 | `2 + 3`, `fn()`, `x > 0` |
| 문 | 동작을 지시한다 | `const x = 5`, `if (...)` |

## 표현식 문 — 표현식이 문이 될 때

표현식만 단독으로 쓰면 **표현식 문**(expression statement) 이 됩니다.

```js
console.log('hello')   // 함수 호출 표현식 → 표현식 문
x++                    // 증감 표현식 → 표현식 문
```

이 경우 계산된 값은 버려지고, 부수 효과(출력, 상태 변경 등)만 남습니다.

## 세미콜론 — 문의 끝을 표시

세미콜론(`;`)은 문의 끝을 명시합니다. JavaScript는 줄이 바뀌면 자동으로 세미콜론을 삽입하기도 합니다(**ASI, Automatic Semicolon Insertion**).

```js
const a = 1
const b = 2
console.log(a + b)
```

</Callout>

## 블록 — 여러 문을 묶기

중괄호 `{}` 로 여러 문을 하나로 묶은 것을 **블록**(block) 이라 합니다.

```js
{
  const x = 10
  console.log(x)
}
```

블록 자체는 표현식이 아닙니다. 값을 만들지 않기 때문입니다.

## 핵심 정리

- 표현식은 평가 결과가 값 하나인 코드입니다.
- 문은 동작을 지시하는 단위이며 표현식을 포함할 수 있습니다.
- 세미콜론은 문의 끝을 명시하며, 일관된 스타일을 유지하면 ASI 예외를 피할 수 있습니다.
