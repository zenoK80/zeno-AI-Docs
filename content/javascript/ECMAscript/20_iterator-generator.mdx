## 이터러블 프로토콜

**이터러블(iterable)** 은 `for...of`나 전개 연산자로 순회할 수 있는 객체입니다. `[Symbol.iterator]()` 메서드를 구현해야 합니다.

배열, 문자열, Map, Set, arguments, NodeList 등이 이터러블입니다.

```js
const arr = [1, 2, 3]
for (const item of arr) {
  console.log(item)
}

const str = 'hello'
for (const char of str) {
  console.log(char)  // h, e, l, l, o
}

const [first, ...rest] = arr  // 전개도 이터러블 활용
```

## 이터레이터

`[Symbol.iterator]()`가 반환하는 객체입니다. `next()` 메서드로 순회합니다.

```js
const arr = [1, 2, 3]
const iter = arr[Symbol.iterator]()

console.log(iter.next())  // { value: 1, done: false }
console.log(iter.next())  // { value: 2, done: false }
console.log(iter.next())  // { value: 3, done: false }
console.log(iter.next())  // { value: undefined, done: true }
```

## 커스텀 이터러블

```js
const range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() {
    let current = this.from
    const last = this.to
    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false }
        }
        return { value: undefined, done: true }
      }
    }
  }
}

for (const n of range) {
  console.log(n)  // 1, 2, 3, 4, 5
}
```

## 제너레이터 함수

`function*` 문법으로 정의하며 `yield`로 값을 하나씩 반환합니다.

```js
function* count() {
  yield 1
  yield 2
  yield 3
}

const gen = count()
console.log(gen.next())  // { value: 1, done: false }
console.log(gen.next())  // { value: 2, done: false }
console.log(gen.next())  // { value: 3, done: false }
console.log(gen.next())  // { value: undefined, done: true }

// for...of로 순회
for (const n of count()) {
  console.log(n)  // 1, 2, 3
}
```

## 무한 시퀀스

제너레이터로 무한한 값을 게으르게(lazily) 생성할 수 있습니다.

```js
function* naturals() {
  let n = 1
  while (true) {
    yield n++
  }
}

function* take(n, iter) {
  for (const item of iter) {
    if (n-- <= 0) return
    yield item
  }
}

console.log([...take(5, naturals())])  // [1, 2, 3, 4, 5]
```

## yield*로 위임

다른 이터러블에 순회를 위임합니다.

```js
function* combined() {
  yield* [1, 2, 3]
  yield* 'abc'
}

console.log([...combined()])  // [1, 2, 3, 'a', 'b', 'c']
```

## 핵심 정리

- 이터러블은 `[Symbol.iterator]()`를 구현한 객체이며 `for...of`로 순회합니다.
- 이터레이터의 `next()`는 `{ value, done }` 객체를 반환합니다.
- 제너레이터(`function*`, `yield`)는 이터레이터를 쉽게 만드는 문법입니다.
- 제너레이터는 호출마다 중단되고 재개되어 게으른 평가가 가능합니다.
