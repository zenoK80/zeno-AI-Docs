## this란

**this** 는 함수가 호출될 때 결정되는 특별한 키워드로, 현재 실행 문맥의 객체를 가리킵니다. Java나 Python처럼 고정된 것이 아니라, **호출 방식에 따라 달라집니다**.

## 바인딩 규칙 1: 기본 바인딩

단순 함수 호출 시 `this`는 전역 객체(브라우저에서는 `window`)입니다. strict 모드에서는 `undefined`입니다.

```js
function showThis() {
  console.log(this)
}
showThis()  // window (브라우저), undefined (strict mode)
```

## 바인딩 규칙 2: 암시적 바인딩

메서드로 호출 시 `this`는 점(`.`) 앞의 객체입니다.

```js
const person = {
  name: '철수',
  greet() {
    console.log(`안녕, 나는 ${this.name}`)
  },
}
person.greet()  // '안녕, 나는 철수'
```

메서드를 변수에 할당해 호출하면 암시적 바인딩이 사라집니다.

```js
const fn = person.greet
fn()  // '안녕, 나는 undefined' (this가 전역 또는 undefined)
```

## 바인딩 규칙 3: 명시적 바인딩

`call()`, `apply()`, `bind()`로 `this`를 직접 지정합니다.

```js
function greet(greeting) {
  console.log(`${greeting}, ${this.name}`)
}

const user = { name: '영희' }

greet.call(user, '안녕')         // '안녕, 영희'  (인수를 쉼표로)
greet.apply(user, ['안녕'])      // '안녕, 영희'  (인수를 배열로)
const boundGreet = greet.bind(user)
boundGreet('반가워')              // '반가워, 영희' (새 함수 반환)
```

## 바인딩 규칙 4: new 바인딩

`new`로 함수를 호출하면 새 객체가 생성되고 `this`는 그 객체를 가리킵니다.

```js
function Person(name) {
  this.name = name
}

const p = new Person('민준')
console.log(p.name)  // '민준'
```

## 화살표 함수의 this

화살표 함수는 자체 `this`를 갖지 않습니다. **정의된 위치의 외부 스코프 this를 캡처**합니다.

## this 바인딩 우선순위

new 바인딩 > 명시적 바인딩 > 암시적 바인딩 > 기본 바인딩

## 핵심 정리

- this는 호출 방식에 따라 동적으로 결정됩니다.
- 메서드 호출이면 점 앞 객체, new 호출이면 새 객체, call/apply/bind로 명시 가능합니다.
- 화살표 함수는 자체 this가 없고 정의 위치의 외부 this를 사용합니다.
