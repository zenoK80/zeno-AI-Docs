## 스코프란

**스코프**(scope) 는 변수나 함수가 참조될 수 있는 유효 범위입니다. 같은 이름의 변수라도 스코프가 다르면 서로 다른 변수입니다.

## 전역 스코프

파일의 최상위 레벨에서 선언된 변수는 **전역 스코프**를 가집니다.

```js
const globalVar = '전역'

function show() {
  console.log(globalVar)  // 접근 가능
}
show()  // '전역'
```

## 함수 스코프

함수 내부에서 선언된 변수는 함수 밖에서 접근할 수 없습니다.

```js
function fn() {
  const local = '함수 내부'
  console.log(local)  // 접근 가능
}
fn()
console.log(local)  // ReferenceError: local is not defined
```

`var` 키워드는 함수 스코프를 가집니다.

## 블록 스코프

`let`, `const`는 중괄호 `{}` 블록 단위로 스코프를 가집니다.

```js
{
  let blockVar = '블록 안'
  console.log(blockVar)  // 접근 가능
}
console.log(blockVar)  // ReferenceError

if (true) {
  const x = 10
}
// x에 여기서 접근 불가
```

## var vs let vs const

| | `var` | `let` | `const` |
| --- | --- | --- | --- |
| 스코프 | 함수 | 블록 | 블록 |
| 호이스팅 | 선언+초기화 | 선언만 (TDZ) | 선언만 (TDZ) |
| 재선언 | 가능 | 불가 | 불가 |
| 재할당 | 가능 | 가능 | 불가 |

```js
// var 호이스팅
console.log(x)  // undefined (선언은 호이스팅, 초기화는 안 됨)
var x = 5

// let TDZ
console.log(y)  // ReferenceError
let y = 10
```

**TDZ**(Temporal Dead Zone) : `let`/`const` 선언부에 도달하기 전까지 접근이 금지된 구역입니다.

## 스코프 체인

변수를 찾을 때 현재 스코프에서 시작해 바깥 스코프로 올라가며 찾습니다. 이를 **스코프 체인**(scope chain) 이라 합니다.

```js
const outer = '외부'

function outer_fn() {
  const mid = '중간'

  function inner_fn() {
    const inner = '내부'
    // inner, mid, outer 모두 접근 가능
    console.log(inner, mid, outer)
  }
  inner_fn()
}
outer_fn()
```

안쪽 스코프에서 변수를 찾지 못하면 바깥 스코프로 올라가고, 전역 스코프에도 없으면 `ReferenceError`가 발생합니다.

## 렉시컬 스코프

JavaScript는 함수가 **정의된 위치**를 기준으로 스코프를 결정합니다(렉시컬 스코프, 정적 스코프). `print()`가 `run()` 안에서 호출되는데도 왜 'local'이 아닌 'global'이 출력되는지 직접 실행해서 확인해보세요.

## 핵심 정리

- 스코프는 변수가 참조될 수 있는 유효 범위입니다.
- `var`은 함수 스코프, `let`과 `const`는 블록 스코프를 가집니다.
- 스코프 체인으로 안쪽 스코프에서 바깥쪽 변수에 접근할 수 있습니다.
- JavaScript는 정의된 위치를 기준으로 스코프를 결정하는 렉시컬 스코프입니다.
