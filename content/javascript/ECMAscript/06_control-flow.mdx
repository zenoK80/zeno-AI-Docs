  **이번 문서의 목표:** 조건문과 반복문을 사용해 코드의 실행 흐름을 제어하는 방법을 익힙니다.
</Callout>

## if 문

가장 기본적인 조건 제어입니다.

```js
const score = 75

if (score >= 90) {
  console.log('A')
} else if (score >= 80) {
  console.log('B')
} else if (score >= 70) {
  console.log('C')
} else {
  console.log('F')
}
// 'C'
```

조건식은 Boolean으로 변환됩니다. `0`, `''`, `null`, `undefined`, `NaN`, `false`는 **falsy**이고 나머지는 **truthy**입니다.

## switch 문

하나의 값을 여러 경우와 비교할 때 switch가 깔끔합니다.

```js
const day = '월'

switch (day) {
  case '월':
  case '화':
  case '수':
  case '목':
  case '금':
    console.log('평일')
    break
  case '토':
  case '일':
    console.log('주말')
    break
  default:
    console.log('알 수 없음')
}
```

<Callout type="warning">
  `break`를 빠뜨리면 다음 case로 **폴스루**(fall-through) 됩니다. 의도하지 않은 경우라면 반드시 `break`를 넣으세요.
</Callout>

## for 문

횟수가 정해진 반복에 사용합니다.

```js
for (let i = 0; i < 5; i++) {
  console.log(i)
}
// 0 1 2 3 4
```

`for...of`는 이터러블(배열, 문자열 등)을 순회합니다.

```js
const fruits = ['사과', '바나나', '체리']
for (const fruit of fruits) {
  console.log(fruit)
}
```

`for...in`은 객체의 열거 가능한 키를 순회합니다.

```js
const obj = { a: 1, b: 2 }
for (const key in obj) {
  console.log(key, obj[key])
}
```

## while 문

조건이 참인 동안 반복합니다.

```js
let count = 0
while (count < 3) {
  console.log(count)
  count++
}
// 0 1 2
```

`do...while`은 블록을 먼저 실행한 뒤 조건을 검사합니다.

```js
let n = 5
do {
  console.log(n)
  n++
} while (n < 3)
// 5 (조건이 false여도 한 번은 실행)
```

## break와 continue

`break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뜁니다.

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) continue   // 3은 건너뜀
  if (i === 6) break      // 6에서 종료
  console.log(i)
}
// 0 1 2 4 5
```

## 핵심 정리

- `if/else if/else`로 조건에 따른 분기를 처리합니다.
- `switch`는 하나의 값을 여러 case와 비교할 때 유용하며, `break`를 빠뜨리지 않아야 합니다.
- `for`, `while`로 반복을 제어하고, `break`/`continue`로 반복을 중단하거나 건너뜁니다.
