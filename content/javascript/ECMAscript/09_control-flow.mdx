## 제어 흐름이란?

> **쉽게 말하면:** 코드가 위에서 아래로 순서대로 실행되는 기본 흐름을 조건이나 반복으로 "바꾸는" 것입니다.

## if / else if / else

```js
const score = 75

if (score >= 90) {
  console.log('A')
} else if (score >= 80) {
  console.log('B')
} else if (score >= 70) {
  console.log('C')
} else {
  console.log('F')
}
// 출력: C
```

조건은 위에서부터 순서대로 검사되며, **처음으로 true인 조건**의 블록만 실행되고 나머지는 건너뜁니다.

## switch — 값이 여러 개일 때

하나의 값을 여러 경우와 비교할 때는 `switch`가 `if`보다 읽기 편할 수 있습니다.

```js
const day = 3

switch (day) {
  case 1:
    console.log('월요일')
    break
  case 2:
    console.log('화요일')
    break
  case 3:
    console.log('수요일')
    break
  default:
    console.log('알 수 없는 요일')
}
// 출력: 수요일
```

<Callout type="warning">
  **`break`를 빠뜨리면 안 됩니다.** `break`가 없으면 일치하는 `case`를 실행한 뒤에도 **다음 case로 계속 넘어가며 실행**됩니다(fall-through, 폴스루). 의도적으로 여러 case가 같은 동작을 하게 만들 때만 예외적으로 활용합니다.
</Callout>

```js
switch (day) {
  case 1:
  case 2:
  case 3:
  case 4:
  case 5:
    console.log('평일')  // 1~5 모두 이 코드로 흘러 들어옴 (의도적 fall-through)
    break
  case 6:
  case 7:
    console.log('주말')
    break
}
```

## for — 정해진 횟수만큼 반복

```js
for (let i = 0; i < 5; i++) {
  console.log(i)
}
// 0 1 2 3 4
```

`for(초기식; 조건식; 증감식)`의 세 부분:
1. **초기식**: 반복 시작 전 한 번만 실행 (`let i = 0`)
2. **조건식**: 매 반복 전 검사, false가 되면 반복 종료 (`i < 5`)
3. **증감식**: 매 반복이 끝난 뒤 실행 (`i++`)

## while과 do...while

```js
let count = 0
while (count < 3) {
  console.log(count)
  count++
}
// 0 1 2 — 조건을 먼저 검사하고 실행

let n = 0
do {
  console.log(n)
  n++
} while (n < 3)
// 0 1 2 — do...while은 조건과 상관없이 최소 1번은 실행됨
```

**`while`과 `do...while`의 차이:** `while`은 조건을 먼저 검사한 뒤 실행하지만, `do...while`은 **먼저 한 번 실행하고 나서** 조건을 검사합니다. 그래서 조건이 처음부터 false여도 `do...while`은 최소 1번은 실행됩니다.

## for...of와 for...in

배열이나 객체를 순회할 때 쓰는 특수한 for문입니다. (배열 메서드는 20번 문서에서 더 자세히 다룹니다.)

```js
const fruits = ['사과', '바나나', '포도']

for (const fruit of fruits) {
  console.log(fruit)  // '사과' '바나나' '포도' — 값을 직접 꺼냄
}

const user = { name: '철수', age: 25 }

for (const key in user) {
  console.log(key, user[key])  // 'name 철수', 'age 25' — 키를 꺼냄
}
```

<Callout type="warning">
  **`for...of`는 배열**(반복 가능한 값)**에, `for...in`은 객체**(키가 있는 값)**에** 사용하는 것이 원칙입니다. 배열에 `for...in`을 쓰면 인덱스를 문자열로 순회하며 예상치 못한 프로퍼티까지 포함될 수 있어 위험합니다.
</Callout>

## break와 continue

  console.log(i)
}

console.log('--- continue: 3만 건너뛰고 계속 진행 ---')

  if (i === 3) continue
  console.log(i)

- **break**: 반복 전체를 즉시 **중단**하고 반복문을 빠져나갑니다.
- **continue**: 현재 반복만 **건너뛰고** 다음 반복으로 넘어갑니다.

## 레이블(label)로 중첩 반복문 제어

`break`와 `continue`는 기본적으로 **가장 가까운 반복문 하나**에만 적용됩니다. 중첩된 반복문 전체를 한 번에 빠져나가고 싶다면 **레이블**을 사용합니다.

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (j === 1) break outer  // outer라는 이름의 바깥 반복문까지 통째로 중단
    console.log(i, j)
  }
}
// 0 0 만 출력되고 종료
```

레이블은 실무에서 자주 쓰이지는 않지만, 이중 반복문에서 특정 조건을 만나면 즉시 전체를 멈춰야 할 때 유용합니다.

## 핵심 정리

- `if/else if/else`는 조건을 순서대로 검사해 처음 true인 블록만 실행한다.
- `switch`는 `break`가 없으면 다음 case로 흘러 들어가는 fall-through가 발생한다.
- `while`은 조건을 먼저 검사, `do...while`은 최소 1번 실행 후 검사한다.
- `for...of`는 배열의 값을, `for...in`은 객체의 키를 순회할 때 사용한다.
- `break`는 반복을 완전히 중단, `continue`는 현재 반복만 건너뛴다.
