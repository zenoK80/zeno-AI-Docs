`const`, 곱셈과 덧셈, 함수, 매개변수와 반환값은 **JavaScript 언어의 규칙**입니다. 이 규칙을 표준 문서로 정리한 것이 **ECMAScript**(ECMA-262) 입니다.

## JavaScript와 ECMAScript의 차이

| 이름 | 쉽게 말하면 | 예 |
| --- | --- | --- |
| JavaScript | 우리가 작성하고 실행하는 언어의 이름 | 웹 페이지 스크립트, Node.js 프로그램 |
| ECMAScript | JavaScript의 문법과 동작을 정한 표준 | `const`, 함수, 배열, `Promise` |
| 실행 환경 | 표준을 실행하고 추가 기능을 제공하는 프로그램 | 브라우저, Node.js |

JavaScript와 ECMAScript는 경쟁하는 두 언어가 아닙니다. **JavaScript가 따라야 할 공통 규칙의 이름이 ECMAScript**라고 이해하면 됩니다.

브라우저와 Node.js는 같은 ECMAScript 표준을 구현하지만, 각자 다른 추가 기능을 제공합니다.

## 언어 기능과 환경 기능 구분하기

```js
const doubled = [1, 2, 3].map((number) => number * 2)
```

배열과 `map()`의 동작은 ECMAScript가 정합니다. 그래서 브라우저와 Node.js에서 모두 사용할 수 있습니다.

```js
const title = document.querySelector('h1')
title.textContent = '반가워요!'
```

`document`는 현재 HTML 문서를 다루도록 **브라우저가 제공하는 Web API**입니다. 일반적인 Node.js에는 HTML 문서가 없으므로 같은 코드를 실행하면 `document is not defined` 오류가 납니다.

```js
console.log(process.platform)
```

반대로 `process`는 **Node.js가 제공하는 API**입니다. 일반 브라우저에는 없습니다.

| 코드 | 분류 | 이유 |
| --- | --- | --- |
| `1 + 2`, `const`, `Array` | ECMAScript | 언어의 문법과 기본 객체 |
| `document`, `localStorage` | Web API | 브라우저의 문서·저장 기능 |
| `process`, 파일 시스템 API | Node.js API | Node.js 실행 환경의 기능 |

<Callout type="warning">
  JavaScript 코드 안에 보이는 이름이 모두 ECMAScript 기능인 것은 아닙니다. **누가 그 이름을 제공하는지** 확인해야 합니다.
</Callout>

## 빠르게 판단하는 법

1. 변수·함수·배열처럼 언어 문법이나 기본 객체인가?
2. 화면·주소·저장소·네트워크처럼 브라우저 기능을 사용하는가?
3. 파일·프로세스처럼 Node.js 환경에서만 제공되는 기능인가?

## 핵심 정리

- JavaScript는 언어의 이름이고 ECMAScript는 그 언어의 표준입니다.
- 브라우저와 Node.js는 ECMAScript를 실행하면서 서로 다른 API를 추가합니다.
- `document`는 Web API이고 `process`는 Node.js API입니다.
