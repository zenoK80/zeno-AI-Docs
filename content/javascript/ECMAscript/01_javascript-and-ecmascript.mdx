아래 코드는 Chrome에서도, Node.js에서도 같은 값 `5000`을 계산합니다.

```js
const price = 2000
const count = 2

function total(a, b) {
  return a + b
}

console.log(total(price * count, 1000)) // 5000
```

`const`, 숫자의 곱셈과 덧셈, 함수의 매개변수와 반환값은 **JavaScript 언어 자체의 규칙**입니다. 이 규칙을 표준으로 정리한 문서가 **ECMAScript(ECMA-262)** 입니다.

## JavaScript와 ECMAScript는 무엇이 다를까?

보통 코드를 작성할 때는 언어 이름을 **JavaScript**라고 부릅니다. **ECMAScript**는 여러 프로그램이 JavaScript 코드를 같은 방식으로 처리하도록 정한 표준의 이름입니다.

둘은 경쟁하는 다른 언어가 아닙니다. **JavaScript를 어떻게 해석해야 하는지 적은 규칙서가 ECMAScript**라고 이해하면 충분합니다.

<Callout type="info" emoji="💡">
  이 시리즈에서는 변수, 타입, 함수, 객체처럼 실행 장소가 달라도 유지되는 언어 규칙을 배웁니다.
</Callout>

## 언어만으로는 화면을 바꿀 수 없다

다음 코드는 브라우저에서는 제목을 찾지만 일반적인 Node.js 환경에서는 `document is not defined` 오류가 납니다.

```js
const title = document.querySelector('h1')
title.textContent = '반가워요!'
```

이유는 `document`가 ECMAScript에 들어 있는 이름이 아니기 때문입니다. 브라우저가 현재 HTML 문서를 JavaScript로 다룰 수 있게 제공한 **Web API**입니다. 여기서 **API**는 복잡한 기능을 정해진 방법으로 사용할 수 있게 만든 연결 창구를 뜻합니다.

반대로 Node.js의 `process`도 ECMAScript가 아니라 Node.js 실행 환경이 제공하는 기능입니다.

```js
console.log(process.platform) // 예: win32, linux, darwin
```

즉, JavaScript 코드는 항상 어떤 **실행 환경** 안에서 움직입니다. 실행 환경은 코드를 실제로 돌리면서 언어 밖의 기능을 더해 주는 프로그램입니다.

| 구분 | 언어 자체 | 실행 환경이 제공 |
| --- | --- | --- |
| 계산과 값 | `1 + 2`, 문자열, 배열 | 해당 없음 |
| 코드 구조 | 변수, 함수, 조건문, 클래스 | 해당 없음 |
| 브라우저 기능 | 해당 없음 | `document`, `fetch`, `localStorage` |
| Node.js 기능 | 해당 없음 | `process`, 파일 시스템 API |

## 코드를 볼 때 경계를 찾는 방법

낯선 이름을 만나면 다음 질문을 해보면 됩니다.

1. 이 기능이 값 계산이나 문법 규칙인가?
2. 브라우저의 화면·주소·저장소·네트워크를 사용하고 있는가?
3. Node.js처럼 특정 실행 환경에서만 존재하는가?

`Array.prototype.map()`은 배열이라는 언어 내장 객체의 기능이므로 ECMAScript입니다. `document.querySelector()`는 HTML 문서가 있어야 하므로 Web API입니다. `fetch()`는 여러 환경에서 제공될 수 있지만 ECMAScript 문법은 아니며, 각 실행 환경이 제공하는 API입니다.

## 핵심 정리

- JavaScript는 우리가 사용하는 언어이고 ECMAScript는 그 언어의 표준이다.
- 변수, 타입, 함수, 객체 같은 언어 규칙은 ECMAScript가 정한다.
- DOM, 네트워크, 저장소 기능은 브라우저 같은 실행 환경이 제공한다.
- 낯선 기능이 언어 규칙인지 환경 기능인지 구분하면 오류 원인을 찾기 쉬워진다.
