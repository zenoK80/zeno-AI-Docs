## 암묵적 타입 변환

JavaScript 엔진이 연산을 수행하기 위해 자동으로 타입을 변환하는 것을 **암묵적 타입 변환(implicit coercion)** 이라고 합니다.

```js
// 문자열로 변환
console.log(1 + '2')      // '12'
console.log(true + '!')   // 'true!'

// 숫자로 변환
console.log('5' - 3)      // 2
console.log('4' * '2')    // 8
console.log(true + 1)     // 2  (true → 1)
console.log(false + 1)    // 1  (false → 0)
console.log(null + 1)     // 1  (null → 0)
console.log(undefined + 1) // NaN (undefined → NaN)

// 불리언으로 변환
if ('hello') console.log('truthy')  // 출력됨
if (0) console.log('falsy')         // 출력 안 됨
```

## Falsy 값 목록

조건식에서 `false`로 평가되는 값들입니다.

| 값 | 타입 |
| --- | --- |
| `false` | boolean |
| `0`, `-0`, `0n` | number, bigint |
| `''` (빈 문자열) | string |
| `null` | null |
| `undefined` | undefined |
| `NaN` | number |

이 외의 값은 모두 **truthy**입니다. 빈 배열 `[]`과 빈 객체 `{}`도 truthy입니다.

## 명시적 타입 변환

개발자가 의도적으로 타입을 바꾸는 것입니다.

```js
// 숫자로 변환
Number('42')     // 42
Number('3.14')   // 3.14
Number('')       // 0
Number('abc')    // NaN
Number(true)     // 1
Number(null)     // 0
Number(undefined) // NaN
parseInt('42px') // 42 (선행 숫자만 파싱)
parseFloat('3.14em') // 3.14

// 문자열로 변환
String(42)      // '42'
String(true)    // 'true'
String(null)    // 'null'
(42).toString() // '42'

// 불리언으로 변환
Boolean(0)      // false
Boolean('hello') // true
Boolean([])     // true
!!0             // false (이중 부정)
!!'hello'       // true
```

## == vs ===

`==` (동등 연산자)는 타입이 다르면 변환 후 비교합니다. `===` (일치 연산자)는 타입과 값 모두 같아야 `true`입니다.

```js
0 == false       // true  (false → 0)
'' == false      // true  ('' → 0, false → 0)
null == undefined // true  (특수 규칙)
null == 0        // false
NaN == NaN       // false (NaN은 자기 자신과도 같지 않음)

0 === false      // false
'' === false     // false
null === undefined // false
```

<Callout type="warning">
  예상치 못한 타입 변환 버그를 막으려면 항상 `===`와 `!==`를 사용하세요. `null` 체크는 `== null`이 null과 undefined를 함께 처리하는 편리한 예외입니다.
</Callout>

## NaN 확인 방법

`NaN`은 자기 자신과도 같지 않으므로 `=== NaN`으로 확인할 수 없습니다.

```js
const x = NaN
console.log(x === NaN)     // false
console.log(isNaN(x))      // true (단, isNaN('abc') → true 주의)
console.log(Number.isNaN(x)) // true (더 엄격한 방법)
```

## 핵심 정리

- 암묵적 타입 변환은 예상치 못한 결과를 낳을 수 있어 주의가 필요합니다.
- Falsy 값은 false, 0, '', null, undefined, NaN이며 나머지는 truthy입니다.
- 명시적 변환에는 `Number()`, `String()`, `Boolean()`, `!!` 등을 사용합니다.
- 타입 비교 시 항상 `===`를 사용하세요.
