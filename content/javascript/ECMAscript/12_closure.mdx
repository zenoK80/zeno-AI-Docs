## 클로저란

**클로저**(closure) 는 함수가 정의될 때의 외부 스코프 변수를 기억하고, 그 함수가 실행될 때 해당 변수에 접근할 수 있는 메커니즘입니다.

```js
function makeCounter() {
  let count = 0           // 외부 함수의 변수

  return function() {     // 내부 함수(클로저)
    count++
    return count
  }
}

const counter = makeCounter()
console.log(counter())  // 1
console.log(counter())  // 2
console.log(counter())  // 3
```

`makeCounter()`가 반환한 내부 함수는 `count`를 기억합니다. 외부에서 `count`에 직접 접근할 수는 없고 `counter()`를 통해서만 변경할 수 있습니다.

## 클로저가 생기는 이유

JavaScript는 렉시컬 스코프(정의 위치 기준)이므로, 함수가 외부 스코프를 참조하면 그 스코프가 메모리에 유지됩니다.

<Steps>
### 1단계: `makeCounter()` 호출
### 2단계: `count = 0` 생성
### 3단계: 내부 함수 반환
### 4단계: `counter` 변수에 저장
### 5단계: `counter()` 호출 → `count` 참조 가능
</Steps>

## 데이터 은닉 패턴

```js
function createAccount(initialBalance) {
  let balance = initialBalance  // 외부에서 직접 접근 불가

  return {
    deposit(amount) {
      balance += amount
      return balance
    },
    withdraw(amount) {
      if (amount > balance) return '잔액 부족'
      balance -= amount
      return balance
    },
    getBalance() {
      return balance
    },
  }
}

const account = createAccount(1000)
console.log(account.deposit(500))   // 1500
console.log(account.withdraw(200))  // 1300
console.log(account.balance)        // undefined (직접 접근 불가)
```

## 팩토리 함수 패턴

```js
function makeGreeter(greeting) {
  return function(name) {
    return `${greeting}, ${name}!`
  }
}

const hello = makeGreeter('안녕하세요')
const hi = makeGreeter('Hi')

console.log(hello('철수'))  // '안녕하세요, 철수!'
console.log(hi('Alice'))    // 'Hi, Alice!'
```

각 클로저가 독립적으로 `greeting` 변수를 기억합니다.

## 반복문과 클로저 — 흔한 실수

```js
// 잘못된 예 (var 사용)
for (var i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i)  // 3, 3, 3 (i가 이미 3이 됨)
  }, 100)
}

// 올바른 방법 1: let 사용 (블록 스코프)
for (let j = 0; j < 3; j++) {
  setTimeout(function() {
    console.log(j)  // 0, 1, 2
  }, 100)
}

// 올바른 방법 2: 즉시 실행 함수로 값을 캡처
for (var k = 0; k < 3; k++) {
  ;(function(n) {
    setTimeout(function() {
      console.log(n)  // 0, 1, 2
    }, 100)
  })(k)
}
```

## 메모리 주의사항

클로저는 외부 스코프의 변수를 계속 참조하므로, 참조가 살아 있는 동안 가비지 컬렉션이 되지 않습니다.

```js
function heavyClosure() {
  const largeData = new Array(1000000).fill(0)  // 큰 데이터
  return function() {
    return largeData.length
  }
}

const fn = heavyClosure()
// fn이 살아 있는 한 largeData도 메모리에 유지
fn = null  // 참조 해제하면 가비지 컬렉션 대상이 됨
```

## 핵심 정리

- 클로저는 함수가 외부 스코프 변수를 기억하는 메커니즘입니다.
- 데이터 은닉, 상태 유지, 팩토리 함수 패턴에 활용합니다.
- `var`을 반복문에서 사용하면 클로저가 의도대로 동작하지 않을 수 있습니다. `let`을 사용하세요.
- 클로저가 큰 데이터를 참조하면 메모리 누수가 생길 수 있습니다.
