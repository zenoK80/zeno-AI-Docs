## for...of는 어떻게 동작하는 걸까?

9번 문서에서 `for...of`로 배열을 순회했습니다. 그런데 왜 배열과 문자열은 `for...of`가 되고, 일반 객체 `{}`는 안 될까요?

```js
for (const char of '안녕') { console.log(char) }  // OK — 문자열은 됨
for (const item of [1, 2, 3]) { console.log(item) }  // OK — 배열은 됨

for (const key of { a: 1, b: 2 }) { }  // TypeError! 일반 객체는 for...of 불가
```

## 이터러블(Iterable)과 이터레이터(Iterator)

> **쉽게 말하면:** "순회 가능한 값"이 되려면, 그 값이 "다음 값을 어떻게 꺼내는지"에 대한 규칙(프로토콜)을 스스로 가지고 있어야 합니다.

- **이터러블**(iterable): `for...of`로 순회할 수 있는 값. 배열, 문자열, Set, Map 등.
- **이터레이터**(iterator): "다음 값을 꺼내는 방법"을 아는 객체. `next()` 메서드를 호출할 때마다 `{ value, done }` 형태의 결과를 반환합니다.

```js
const arr = [10, 20, 30]
const iterator = arr[Symbol.iterator]()  // 배열에서 이터레이터를 직접 꺼냄

console.log(iterator.next())  // { value: 10, done: false }
console.log(iterator.next())  // { value: 20, done: false }
console.log(iterator.next())  // { value: 30, done: false }
console.log(iterator.next())  // { value: undefined, done: true } — 끝!
```

`for...of`는 사실 내부적으로 이 `next()` 호출을 `done`이 `true`가 될 때까지 자동으로 반복하는 문법입니다. 일반 객체 `{}`가 `for...of`에서 안 되는 이유는, `Symbol.iterator`(이터레이터를 꺼내는 특수한 메서드)를 갖고 있지 않기 때문입니다.

## 제너레이터(Generator) — 이터레이터를 쉽게 만드는 문법

이터레이터를 직접 만들려면 `next()`, `{value, done}` 반환을 손으로 다 구현해야 해서 번거롭습니다. **제너레이터**는 이 과정을 훨씬 간단하게 만들어주는 특수한 함수입니다.

```js
function* countTo3() {  // function 뒤에 * — 제너레이터 함수 표시
  yield 1
  yield 2
  yield 3
}

const gen = countTo3()  // 호출하면 즉시 실행되지 않고 제너레이터 객체를 반환

console.log(gen.next())  // { value: 1, done: false }
console.log(gen.next())  // { value: 2, done: false }
console.log(gen.next())  // { value: 3, done: false }
console.log(gen.next())  // { value: undefined, done: true }
```

`yield`(양보하다)는 함수 실행을 그 지점에서 **일시정지**하고 값을 반환합니다. 다음 `next()`가 호출되면, 멈췄던 지점부터 다시 이어서 실행됩니다. 일반 함수는 한 번 호출하면 끝까지 실행되고 끝나지만, 제너레이터는 **여러 번에 걸쳐 나눠서 실행**될 수 있습니다.

## 제너레이터는 이터러블이다 — for...of와 함께 사용

```js
function* countTo3() {
  yield 1
  yield 2
  yield 3
}

for (const num of countTo3()) {
  console.log(num)  // 1 2 3 — 제너레이터도 for...of로 순회 가능!
}

console.log([...countTo3()])  // [1, 2, 3] — 스프레드도 가능
```

## 실전 활용 — 무한 시퀀스 만들기

일반 배열은 크기가 정해져 있지만, 제너레이터는 **필요한 만큼만 값을 생성**하는 무한 시퀀스를 만들 수 있습니다.

  while (true) {  // 무한 루프이지만 문제없다 — yield로 매번 멈추기 때문
    yield n
    n++
  }

// take: 이터러블에서 개수만큼만 꺼내는 헬퍼 함수
function take(iterable, count) {
  const result = []
  const iterator = iterable[Symbol.iterator]()
  for (let i = 0; i < count; i++) {
    result.push(iterator.next().value)
  }
  return result
}

console.log(take(naturalNumbers(), 5))  // [1, 2, 3, 4, 5]
console.log(take(naturalNumbers(), 10)) // [1, 2, ..., 10]`,
  }}

`while (true)`처럼 무한 루프인데도 프로그램이 멈추지 않는 이유는, 제너레이터가 `yield`를 만날 때마다 **실제로 멈추고 호출자에게 제어권을 돌려주기** 때문입니다. `next()`를 호출하지 않으면 다음 값이 계산되지 않으므로, 필요한 만큼만(`take` 함수가 요청한 개수만큼만) 값이 생성됩니다.

## yield로 값 주고받기

```js
function* echoGenerator() {
  const first = yield '첫 번째 질문'
  console.log('받은 값:', first)
  const second = yield '두 번째 질문'
  console.log('받은 값:', second)
}

const gen = echoGenerator()
console.log(gen.next().value)        // '첫 번째 질문'
console.log(gen.next('답변1').value) // 콘솔에 '받은 값: 답변1' 출력 후 '두 번째 질문'
gen.next('답변2')                     // '받은 값: 답변2' 출력
```

`next()`에 인수를 넘기면, 그 값이 **이전에 멈췄던 `yield` 표현식의 결과값**이 됩니다. 이 양방향 통신은 제너레이터의 고급 활용법입니다.

## 핵심 정리

- `for...of`로 순회 가능한 값을 이터러블이라 하며, 내부적으로 이터레이터의 `next()`를 반복 호출한다.
- `next()`는 `{ value, done }` 형태의 결과를 반환하며 `done`이 true가 되면 순회가 끝난다.
- `function*`으로 정의하는 제너레이터는 `yield`를 만날 때마다 실행을 멈추고 값을 반환한다.
- 제너레이터 자체가 이터러블이라 `for...of`, 스프레드로 바로 사용할 수 있다.
- 제너레이터는 필요한 만큼만 값을 생성하므로 무한 시퀀스를 안전하게 표현할 수 있다.
