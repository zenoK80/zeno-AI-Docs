## class 기본 문법

`class`는 ES6에서 도입된 프로토타입 기반 상속의 문법적 설탕(syntactic sugar)입니다.

```js
class Animal {
  constructor(name) {
    this.name = name
  }

  speak() {
    return `${this.name}이(가) 소리를 냅니다.`
  }
}

const cat = new Animal('고양이')
console.log(cat.speak())  // '고양이이(가) 소리를 냅니다.'
```

## 상속 (extends, super)

  constructor(name) {

  }

  speak() {
    return \`\${this.name}이(가) 소리를 냅니다.\`
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name)           // 부모 클래스 constructor 호출
    this.breed = breed
  }

  speak() {
    return \`\${this.name}이(가) 멍멍!\`
  }

  info() {
    return \`\${super.speak()} / 품종: \${this.breed}\`
  }
}

const dog = new Dog('초코', '포메라니안')
console.log(dog.speak())   // '초코이(가) 멍멍!'
console.log(dog.info())    // '초코이(가) 소리를 냅니다. / 품종: 포메라니안'
console.log(dog instanceof Animal) // true (상속 체인)`,
  }}
/>

`super()`는 자식 클래스의 `constructor`에서 반드시 `this`를 사용하기 전에 호출해야 합니다.

## 정적 메서드와 프로퍼티 (static)

인스턴스가 아닌 클래스 자체에 속하는 멤버입니다.

```js
class MathHelper {
  static PI = 3.14159

  static circle(r) {
    return MathHelper.PI * r * r
  }
}

console.log(MathHelper.PI)          // 3.14159
console.log(MathHelper.circle(5))   // 78.53975
// new MathHelper().PI → undefined (인스턴스로 접근 불가)
```

## Private 필드 (#)

ES2022에서 공식 도입된 클래스 private 필드입니다.

```js
class Counter {
  #count = 0    // private 필드

  increment() {
    this.#count++
  }

  get value() {
    return this.#count
  }
}

const c = new Counter()
c.increment()
c.increment()
console.log(c.value)    // 2
console.log(c.#count)   // SyntaxError (외부 접근 불가)
```

## getter와 setter

```js
class Temperature {
  #celsius

  constructor(celsius) {
    this.#celsius = celsius
  }

  get fahrenheit() {
    return this.#celsius * 9 / 5 + 32
  }

  set fahrenheit(value) {
    this.#celsius = (value - 32) * 5 / 9
  }
}

const temp = new Temperature(100)
console.log(temp.fahrenheit)    // 212
temp.fahrenheit = 32
console.log(temp.fahrenheit)    // 32
```

## 클래스와 프로토타입

```js
console.log(typeof Dog)       // 'function' (클래스는 함수입니다)
console.log(dog instanceof Dog)    // true
console.log(dog instanceof Animal) // true (상속 체인)
```

## 핵심 정리

- `class`는 프로토타입 기반 상속의 문법적 설탕입니다.
- `extends`로 상속하고 `super()`로 부모 생성자를 호출합니다.
- `static`으로 클래스 자체에 속하는 멤버를 정의합니다.
- `#`으로 시작하는 private 필드는 클래스 외부에서 접근이 불가합니다.
