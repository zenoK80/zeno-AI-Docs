## 실습 — typeof 예측 게임

아래 결과를 실행 전에 먼저 예측해서 메모장에 적어보고, 실제로 콘솔에서 실행해 맞혔는지 확인하자.

```js
typeof 3.14
typeof 'hello'
typeof true
typeof undefined
typeof null
typeof 10n
typeof Symbol('x')
typeof {}
typeof []
typeof function(){}
typeof NaN
```

<Collapse title="정답 보기">

```
'number'
'string'
'boolean'
'undefined'
'object'   ← 버그!
'bigint'
'symbol'
'object'
'object'   ← 배열도 typeof로는 그냥 object로 나온다
'function'
'number'   ← NaN(Not a Number, "숫자가 아님"이라는 뜻의 특수 값)도 Number 타입에 속한다
```

</Collapse>

전부 맞혔다면 데이터 타입 감각이 잡힌 것이다. `[]`(배열)와 `function(){}`가 예상과 다르게 나왔다면, 12편(객체 리터럴)과 13편(원시 값 vs 객체)에서 왜 그런지 더 자세히 배운다.
