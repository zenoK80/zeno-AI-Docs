## 배열 순회 — forEach

반환값 없이 각 요소를 순회합니다.

```js
const numbers = [1, 2, 3, 4, 5]
numbers.forEach((n, index) => {
  console.log(`[${index}]: ${n}`)
})
```

## 변환 — map

각 요소를 변환한 **새 배열**을 반환합니다. 원본을 바꾸지 않습니다.

```js
const doubled = numbers.map(n => n * 2)
console.log(doubled)   // [2, 4, 6, 8, 10]
console.log(numbers)   // [1, 2, 3, 4, 5] (원본 유지)
```

## 필터링 — filter

조건에 맞는 요소만 모은 **새 배열**을 반환합니다.

```js
const evens = numbers.filter(n => n % 2 === 0)
console.log(evens)  // [2, 4]
```

## 집계 — reduce

배열을 하나의 값으로 줄입니다.

```js
const sum = numbers.reduce((acc, n) => acc + n, 0)
console.log(sum)  // 15

// 초기값 구조: reduce(callback, initialValue)
// callback(accumulator, currentValue, index, array)

// 객체로 집계
const people = [
  { name: '철수', age: 20 },
  { name: '영희', age: 25 },
  { name: '민준', age: 20 },
]
const groupByAge = people.reduce((acc, p) => {
  const key = p.age
  acc[key] = acc[key] || []
  acc[key].push(p.name)
  return acc
}, {})
// { 20: ['철수', '민준'], 25: ['영희'] }
```

## 탐색 — find, findIndex

조건에 맞는 첫 번째 요소 또는 인덱스를 반환합니다.

```js
const found = numbers.find(n => n > 3)
console.log(found)  // 4

const idx = numbers.findIndex(n => n > 3)
console.log(idx)    // 3
```

## 조건 검사 — some, every

```js
console.log(numbers.some(n => n > 4))    // true (하나라도 조건 충족)
console.log(numbers.every(n => n > 0))   // true (모두 조건 충족)
console.log(numbers.every(n => n > 3))   // false
```

## 평탄화 — flat, flatMap

```js
const nested = [1, [2, 3], [4, [5, 6]]]
console.log(nested.flat())    // [1, 2, 3, 4, [5, 6]] (1단계)
console.log(nested.flat(2))   // [1, 2, 3, 4, 5, 6] (2단계)

// flatMap: map 후 1단계 flat
const sentences = ['hello world', 'foo bar']
const words = sentences.flatMap(s => s.split(' '))
console.log(words)  // ['hello', 'world', 'foo', 'bar']
```

## 포함 여부 — includes

```js
console.log(numbers.includes(3))   // true
console.log(numbers.includes(10))  // false
```

## 정렬 — sort

```js
const arr = [3, 1, 4, 1, 5, 9]
arr.sort((a, b) => a - b)   // 오름차순
console.log(arr)  // [1, 1, 3, 4, 5, 9]

const strs = ['바나나', '사과', '딸기']
strs.sort()  // 유니코드 순 정렬
```

<Callout type="warning">
  sort()는 원본 배열을 수정합니다. 원본을 유지하려면 먼저 복사하세요: `[...arr].sort()`
</Callout>

## 핵심 정리

- `map`은 변환, `filter`는 필터링, `reduce`는 집계에 사용합니다.
- `find`/`findIndex`는 첫 번째 매칭을, `some`/`every`는 조건 충족 여부를 반환합니다.
- `flat`은 중첩 배열을 평탄화하고, `sort`는 원본을 수정합니다.
- 메서드를 체이닝해 데이터 파이프라인을 만들 수 있습니다.
