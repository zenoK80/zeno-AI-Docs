## 실습 — 콘솔에서 직접 구별해 보기

브라우저 개발자 도구 콘솔(<kbd>F12</kbd>를 눌러 연다)을 열고 아래를 하나씩 쳐보자.

<Steps>

### 언어 소속 확인하기

```js
console.log(Math.max)
```

`[native code]`라는 표시가 붙은 함수가 나온다. `Math`는 언어(ECMAScript) 소속의 **내장 객체**<sup>Built-in Object, 자바스크립트가 기본으로 미리 만들어둔 도구 모음</sup>다.

### 브라우저 소속 확인하기

```js
console.log(document.write)
```

이것도 `[native code]`가 나오지만, `document`는 브라우저가 주는 것이다. 즉 **출력 결과만 봐서는 둘을 구별할 수 없다.**

### Node.js였다면 어떻게 될지 예상해 보기

터미널에서 `node`를 실행하고(설치 방법은 2편에서 다룬다) `Math.max`를 쳐보자. 정상적으로 나오는가? 그럼 `document.write`는 어떻게 되는가? 왜 이런 차이가 나는지 1편 내용으로 설명해 보자.

</Steps>
