## 값(Value)이란?

> **쉽게 말하면:** 값은 프로그램이 다루는 "실제 데이터 한 조각"입니다.

`42`, `'안녕'`, `true`처럼 그 자체로 의미를 갖는 데이터를 **값**(value)이라고 부릅니다.

```js
42        // 숫자 값
'안녕'     // 문자열 값
true      // 불리언 값
```

## 표현식(Expression)이란?

> **쉽게 말하면:** 표현식은 "계산하면 값이 나오는 코드 조각"입니다.

**표현식**(expression)은 평가(evaluate, 계산)했을 때 값 하나로 정리되는 코드입니다.

```js
2 + 3          // 표현식 → 평가하면 5
'a' + 'b'      // 표현식 → 평가하면 'ab'
10 > 5         // 표현식 → 평가하면 true
```

값 하나만 있어도 표현식입니다. `42`도 표현식이고, `2 + 3`도 표현식입니다. 함수 호출도 표현식입니다.

```js
Math.max(1, 5, 3)   // 표현식 → 평가하면 5
```

## 문(Statement)이란?

> **쉽게 말하면:** 문은 "무언가를 실행하라는 하나의 명령"입니다. 표현식이 재료라면, 문은 그 재료로 할 일을 지시하는 문장 전체입니다.

**문**(statement)은 자바스크립트 엔진에게 "이 동작을 수행하라"고 지시하는 단위입니다. 문은 값으로 평가되지 않습니다.

```js
let age = 25        // 변수 선언문
if (age >= 18) {    // 조건문
  console.log('성인')
}
for (let i = 0; i < 3; i++) {  // 반복문
  console.log(i)
}
```

## 표현식과 문의 결정적 차이

이 구분이 왜 중요할까요? **표현식은 값이 필요한 자리에 쓸 수 있지만, 문은 쓸 수 없기 때문**입니다.

```js
// ✅ 표현식은 값 자리에 넣을 수 있다
const result = 2 + 3          // OK — 2+3은 표현식
const message = age >= 18 ? '성인' : '미성년자'  // OK — 삼항 연산자는 표현식

// ❌ 문은 값 자리에 넣을 수 없다
const result2 = if (age >= 18) { '성인' }  // 오류! if는 문이라 값이 아님
```

이 원칙은 나중에 React의 JSX를 배울 때 다시 등장합니다. JSX의 `{ }` 안에는 **표현식만** 들어갈 수 있고, `if`문 같은 문은 직접 넣을 수 없습니다. 지금 이 구분을 확실히 해두면 그때 훨씬 쉽게 이해됩니다.

## 표현식 문(Expression Statement)

표현식 뒤에 세미콜론을 붙이면 그 자체로 하나의 문이 될 수 있습니다. 이를 **표현식 문**이라고 부릅니다.

```js
console.log('안녕')  // 함수 호출 표현식 + 세미콜론 = 표현식 문
x = 5                // 대입 표현식 + 세미콜론 = 표현식 문
```

## 자주 틀리는 점

<Callout type="warning">
  `let x = 5`처럼 변수를 선언하는 문 자체는 값을 반환하지 않습니다. 하지만 `x = 5`(선언 없이 값만 대입)는 **대입 표현식**이라서 값(5)을 갖습니다. 이 미묘한 차이 때문에 `while ((line = readLine()) !== null)`처럼 대입을 조건식 안에 넣는 코드가 가능합니다.
</Callout>

## 핵심 정리

- **값**: 42, '안녕' 같은 데이터 조각.
- **표현식**: 평가하면 값 하나로 정리되는 코드(`2+3`, 함수 호출, 삼항 연산자 등).
- **문**: 동작을 지시하는 단위(변수 선언, if, for 등). 값으로 쓸 수 없다.
- 표현식은 값이 필요한 자리(변수 대입, 함수 인수, JSX의 `{}` 등)에 들어갈 수 있지만, 문은 들어갈 수 없다.
