## 구조 분해 할당(Destructuring Assignment)

> **쉽게 말하면:** 배열이나 객체 안의 값을, 상자를 하나씩 열어보지 않고 한 번에 여러 변수로 "꺼내는" 문법입니다.

### 객체 구조 분해 — 이름으로 꺼내기

```js
const user = { name: '철수', age: 25, city: '서울' }

// 기존 방식
const name = user.name
const age = user.age

// 구조 분해 — 한 줄로 동시에 꺼냄
const { name: n, age: a, city } = user
console.log(n, a, city)  // 철수 25 서울
```

객체 구조 분해는 **프로퍼티 이름**을 기준으로 꺼냅니다. 순서는 상관없습니다.

```js
const { city, name } = user  // 순서를 바꿔도 이름만 맞으면 정확히 꺼내짐
console.log(city, name)  // 서울 철수
```

### 배열 구조 분해 — 순서로 꺼내기

```js
const colors = ['빨강', '초록', '파랑']

// 기존 방식
const first = colors[0]
const second = colors[1]

// 구조 분해 — 순서대로 꺼냄
const [first2, second2, third2] = colors
console.log(first2, second2, third2)  // 빨강 초록 파랑
```

배열 구조 분해는 **위치**(순서)**를 기준**으로 꺼냅니다. 이 차이 때문에 문법이 다릅니다: 객체는 `{}`, 배열은 `[]`.

```js
const [, , third] = colors  // 앞 두 개를 건너뛰고 세 번째만
console.log(third)  // 파랑
```

## 구조 분해의 응용

### 기본값 지정

```js
const { name, role = '일반회원' } = { name: '철수' }
console.log(role)  // '일반회원' — role 프로퍼티가 없어서 기본값 사용
```

### 나머지(rest) 구조 분해

```js
const { name, ...rest } = { name: '철수', age: 25, city: '서울' }
console.log(name)  // '철수'
console.log(rest)  // { age: 25, city: '서울' } — name을 제외한 나머지가 객체로 묶임

const [first, ...restArr] = [1, 2, 3, 4]
console.log(first)    // 1
console.log(restArr)  // [2, 3, 4]
```

### 중첩 구조 분해

```js
const response = { data: { user: { id: 1, name: '철수' } } }
const { data: { user: { name: userName } } } = response
console.log(userName)  // '철수'
```

### 함수 매개변수에서의 구조 분해 — 11번 문서에서 미리 본 패턴

```js
function printUser({ name, age }) {
  console.log(`${name}, ${age}세`)
}
printUser({ name: '철수', age: 25, city: '서울' })  // '철수, 25세' — 필요한 것만 쏙 꺼내 씀
```

## 스프레드 연산자(Spread Operator) `...`

구조 분해와 정반대의 역할입니다. 배열이나 객체를 **펼쳐서** 새 배열/객체에 풀어 넣습니다.

<CodePlayground

  files={{
    '/index.js': `// 배열 병합
const arrA = [1, 2, 3]
const arrB = [4, 5, 6]
const merged = [...arrA, ...arrB]
console.log(merged)  // [1, 2, 3, 4, 5, 6]

// 배열 복사 (얕은 복사)
const copy = [...arrA]
copy.push(4)
console.log(arrA)  // [1, 2, 3] — 원본 안 바뀜
console.log(copy)  // [1, 2, 3, 4]

// 객체 병합 — 뒤에 오는 값이 앞의 같은 키를 덮어씀
const defaults = { theme: 'light', fontSize: 14 }
const userSettings = { fontSize: 18 }
const finalSettings = { ...defaults, ...userSettings }
console.log(finalSettings)  // { theme: 'light', fontSize: 18 }

// 함수 인수로 배열 펼치기
console.log(Math.max(...[3, 7, 2, 9]))  // 9`,
  }}
/>

## 구조 분해 vs 스프레드 — 방향이 반대

이 둘을 헷갈리는 경우가 많은데, 방향이 정확히 반대입니다.

<Table>
  <thead>
    <tr><th>구분</th><th>방향</th><th>예시</th></tr>
  </thead>
  <tbody>
    <tr><td>구조 분해</td><td>객체/배열 → 개별 변수로 <b>꺼내기</b></td><td><code>const {'{ a }'} = obj</code></td></tr>
    <tr><td>스프레드</td><td>개별 요소들을 객체/배열 안으로 <b>펼쳐 넣기</b></td><td><code>{'{ ...obj, b: 2 }'}</code></td></tr>
  </tbody>
</Table>

같은 `...` 기호를 쓰지만, 구조 분해 문맥(변수를 선언하는 왼쪽)에서 쓰이면 **rest 패턴**(나머지 모으기), 스프레드 문맥(값을 만드는 오른쪽)에서 쓰이면 **펼치기**로 동작합니다.

```js
const { a, ...rest } = { a: 1, b: 2, c: 3 }  // 왼쪽(선언부): rest는 나머지를 "모음"
const combined = { ...rest, d: 4 }            // 오른쪽(값 생성): rest를 "펼침"
```

## 스프레드로 안전하게 상태 업데이트하기

11번, 16번 문서에서 배운 "참조 vs 복사"의 실전 적용입니다. React 같은 라이브러리는 객체를 직접 수정하지 않고, 스프레드로 새 객체를 만들어 일부만 바꾸는 패턴을 자주 씁니다.

```js
const state = { count: 0, name: '철수' }

// ❌ 직접 수정 — 원본을 변경(mutate)함
state.count = 1

// ✅ 스프레드로 새 객체 생성 — 원본은 그대로 두고 새 상태를 만듦
const newState = { ...state, count: 1 }
console.log(state)     // { count: 0, name: '철수' } — 원본 유지
console.log(newState)  // { count: 1, name: '철수' } — 새 객체
```

## 핵심 정리

- 객체 구조 분해는 프로퍼티 이름으로, 배열 구조 분해는 순서로 값을 꺼낸다.
- 구조 분해에서 기본값, 이름 바꾸기, rest(나머지 모으기), 중첩 분해가 가능하다.
- 스프레드는 배열·객체를 펼쳐서 새 배열·객체를 만드는 데 사용하며, 원본은 변경하지 않는 얕은 복사를 만든다.
- 객체 스프레드에서 뒤에 오는 프로퍼티가 앞의 같은 키를 덮어쓴다.
- 같은 `...` 기호도 구조 분해(왼쪽)에서는 "모으기", 스프레드(오른쪽)에서는 "펼치기"로 정반대로 동작한다.
