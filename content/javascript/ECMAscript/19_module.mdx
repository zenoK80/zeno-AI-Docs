## 모듈이란

**모듈(module)** 은 독립적인 파일 단위로 코드를 구성하는 방법입니다. 각 파일이 자체 스코프를 가지며 필요한 것만 내보내고 가져올 수 있습니다.

## named export (이름 내보내기)

여러 항목을 이름으로 내보냅니다.

```js
// math.js
export const PI = 3.14159

export function add(a, b) {
  return a + b
}

export function multiply(a, b) {
  return a * b
}

// 한 번에 내보내기
const PI2 = 3.14159
function subtract(a, b) { return a - b }
export { PI2, subtract }
```

```js
// main.js
import { add, multiply } from './math.js'
import { PI2 as piAlias } from './math.js'  // 별칭 사용

console.log(add(2, 3))  // 5
```

## default export (기본 내보내기)

파일 당 하나만 내보낼 수 있습니다.

```js
// calculator.js
export default class Calculator {
  add(a, b) { return a + b }
}

// 함수 기본 내보내기
export default function greet(name) {
  return `안녕, ${name}!`
}
```

```js
// main.js
import Calculator from './calculator.js'   // 이름 자유롭게
import greetUser from './greet.js'

const calc = new Calculator()
```

## 혼합 사용

```js
// utils.js
export const version = '1.0'

export function helper() {}

export default function main() {}
```

```js
import main, { version, helper } from './utils.js'
```

## 전체 가져오기

```js
import * as math from './math.js'
console.log(math.PI)
console.log(math.add(1, 2))
```

## 동적 import

실행 중에 필요할 때 가져옵니다.

```js
async function loadModule() {
  const { add } = await import('./math.js')
  console.log(add(2, 3))
}

// 조건부 로딩
if (needFeature) {
  const feature = await import('./heavy-feature.js')
}
```

## 모듈의 특징

1. **엄격 모드 자동 적용**: 모듈은 항상 `'use strict'` 상태입니다.
2. **자체 스코프**: 모듈 내 변수는 외부에 노출되지 않습니다.
3. **싱글톤**: 같은 모듈을 여러 번 import해도 한 번만 실행됩니다.
4. **정적 분석**: import/export는 파일 최상위에 위치해야 합니다.

```html
<!-- 브라우저에서 모듈 사용 -->
<script type="module" src="main.js"></script>
```

## 핵심 정리

- named export는 여러 항목을 이름으로 내보내고, default export는 파일당 하나만 내보냅니다.
- import 시 named는 `{}` 안에, default는 자유로운 이름으로 가져옵니다.
- 동적 import로 코드를 필요한 시점에 로딩할 수 있습니다.
- 모듈은 자체 스코프를 가지며 자동으로 strict 모드가 적용됩니다.
