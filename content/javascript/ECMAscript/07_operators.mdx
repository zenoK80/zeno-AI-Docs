## 연산자란?

> **쉽게 말하면:** 연산자는 값을 계산하거나 비교하는 기호입니다. `+`, `-`, `===` 같은 것들입니다.

## 산술 연산자

```js
console.log(10 + 3)   // 13 — 덧셈
console.log(10 - 3)   // 7  — 뺄셈
console.log(10 * 3)   // 30 — 곱셈
console.log(10 / 3)   // 3.3333... — 나눗셈
console.log(10 % 3)   // 1  — 나머지(modulo)
console.log(10 ** 2)  // 100 — 거듭제곱

let count = 5
count++   // count = count + 1과 같음 → 6
count--   // count = count - 1과 같음 → 5
```

## 비교 연산자 — `==` vs `===`

이것은 자바스크립트에서 가장 자주 헷갈리는 부분입니다.

- `===`(일치 연산자): 값과 **타입까지** 같아야 true.
- `==`(동등 연산자): 타입이 다르면 **자동으로 변환한 뒤** 비교 (8번 타입 변환 문서에서 자세히 다룸).

    '/index.js': `console.log(1 === 1)     // true — 값, 타입 모두 같음
console.log(1 === '1')   // false — 타입이 다름 (number vs string)
console.log(1 == '1')    // true — '1'을 숫자로 변환 후 비교

console.log(0 == false)  // true — false를 0으로 변환
console.log(null == undefined)  // true — 이 조합만 예외적으로 true

  }}
/>

<Callout type="warning">
  실무에서는 **항상 `===`를 사용**하는 것이 원칙입니다. `==`는 예상치 못한 타입 변환으로 버그를 만들기 쉽습니다. 유일하게 널리 허용되는 예외는 `value == null`로 null과 undefined를 한 번에 검사하는 경우입니다.
</Callout>

기타 비교 연산자: `!==`(불일치), `>`, `<`, `>=`, `<=`는 숫자·문자열을 크기순으로 비교합니다.

## 논리 연산자

```js
console.log(true && false)  // false — AND: 둘 다 true여야 true
console.log(true || false)  // true  — OR: 하나라도 true면 true
console.log(!true)          // false — NOT: 반전
```

### 단축 평가(Short-circuit Evaluation)

`&&`와 `||`는 boolean만 반환하는 것이 아니라, **평가를 멈춘 시점의 실제 값**을 반환합니다.

```js
console.log('a' && 'b')   // 'b' — 둘 다 참이므로 마지막 값 반환
console.log(0 && 'b')     // 0   — 첫 값이 거짓이라 거기서 멈춤
console.log('a' || 'b')   // 'a' — 첫 값이 참이라 거기서 멈춤
console.log(0 || 'b')     // 'b' — 첫 값이 거짓이라 다음으로 넘어감

// 실전 활용 — 기본값 대체
function greet(name) {
  const finalName = name || '손님'  // name이 없으면 '손님' 사용
  console.log(`안녕하세요, ${finalName}님`)
}
greet()        // 안녕하세요, 손님님
greet('철수')   // 안녕하세요, 철수님
```

## `||`의 함정과 `??`(Nullish Coalescing)

`||`는 `0`, `''`(빈 문자열), `false`도 모두 "거짓"으로 취급합니다. 이것이 문제가 되는 상황이 있습니다.

```js
const stock = 0
console.log(stock || '재고 정보 없음')  // '재고 정보 없음' — 의도치 않은 결과! 재고가 0개인데 "정보 없음"으로 표시됨
```

**`??`**(null 병합 연산자)는 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 사용합니다. `0`이나 `''`은 유효한 값으로 취급해 그대로 둡니다.

## 삼항 연산자 — 유일한 3항 연산자

```js
const age = 20
const status = age >= 18 ? '성인' : '미성년자'
console.log(status)  // '성인'

// 조건 ? 참일 때 값 : 거짓일 때 값
```

## Optional Chaining(`?.`) — 안전한 접근

중첩된 객체의 속성에 접근할 때, 중간 단계가 `null`이나 `undefined`이면 에러가 납니다. `?.`는 중간이 비어있으면 에러 대신 `undefined`를 반환합니다.

```js
const user = { profile: null }

console.log(user.profile.city)   // TypeError! profile이 null인데 city에 접근 시도
console.log(user.profile?.city)  // undefined — 에러 없이 안전하게 처리
```

`?.`와 `??`는 함께 자주 쓰입니다.

```js
const cityName = user.profile?.city ?? '도시 정보 없음'
console.log(cityName)  // '도시 정보 없음'
```

## 핵심 정리

- `===`는 타입까지 비교하고, `==`는 타입을 변환한 후 비교한다. 실무에서는 항상 `===`를 쓴다.
- `&&`, `||`는 boolean이 아니라 평가를 멈춘 시점의 실제 값을 반환한다(단축 평가).
- `||`는 0, '', false도 거짓으로 취급하지만 `??`는 null/undefined만 검사한다.
- `?.`(optional chaining)로 중첩 객체 접근 시 중간값이 없어도 에러 없이 undefined를 얻는다.
