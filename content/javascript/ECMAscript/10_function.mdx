## 함수 선언문

가장 전통적인 함수 정의 방법입니다.

```js
function greet(name) {
  return `안녕하세요, ${name}님!`
}

console.log(greet('영희'))  // '안녕하세요, 영희님!'
```

함수 선언문은 **호이스팅**(hoisting) 됩니다. 선언 전에 호출해도 동작합니다.

```js
console.log(double(4))  // 8 (선언 전에 호출 가능)
function double(n) { return n * 2 }
```

## 함수 표현식

변수에 익명 함수를 할당하는 방식입니다.

```js
const greet = function(name) {
  return `안녕하세요, ${name}님!`
}
```

함수 표현식은 선언 전에 호출할 수 없습니다(TDZ 영향).

## 화살표 함수 (Arrow Function)

ES6에서 도입된 간결한 함수 표현입니다.

```js
// 일반 화살표 함수
const add = (a, b) => a + b

// 본문이 여러 줄인 경우
const multiply = (a, b) => {
  const result = a * b
  return result
}

// 매개변수가 하나면 괄호 생략 가능
const square = n => n * n

// 매개변수가 없으면 빈 괄호
const hello = () => 'Hello!'
```

화살표 함수는 자체적인 `this`를 갖지 않습니다. `this`는 11번 문서에서 자세히 다룹니다.

## 기본 매개변수 (Default Parameter)

```js
function greet(name = '익명') {
  return `안녕하세요, ${name}님!`
}

console.log(greet())         // '안녕하세요, 익명님!'
console.log(greet('철수'))   // '안녕하세요, 철수님!'
```

## 나머지 매개변수 (Rest Parameter)

```js
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0)
}

console.log(sum(1, 2, 3, 4))  // 10
```

## arguments 객체

일반 함수에서만 사용 가능한 유사 배열 객체입니다. 화살표 함수에는 없습니다.

```js
function showArgs() {
  console.log(arguments)
}
showArgs(1, 2, 3)  // Arguments [1, 2, 3]
```

나머지 매개변수(`...args`)가 더 명확하고 화살표 함수에서도 사용할 수 있으므로 현대 코드에서는 나머지 매개변수를 권장합니다.

## 즉시 실행 함수 (IIFE)

정의하자마자 실행되는 함수입니다.

```js
(function() {
  const private = '외부에서 접근 불가'
  console.log(private)
})()

// 화살표 함수 IIFE
(() => {
  console.log('즉시 실행!')
})()
```

변수 스코프를 격리할 때 사용했지만, 모듈 시스템이 발달한 현대에는 드물게 쓰입니다.

## 순수 함수

동일한 입력에 항상 같은 출력을 반환하고, 부수 효과가 없는 함수입니다.

```js
// 순수 함수
function add(a, b) { return a + b }

// 순수하지 않은 함수 (외부 상태에 의존)
let count = 0
function increment() { count++ }
```

## 핵심 정리

- 함수 선언문은 호이스팅되고, 함수 표현식은 선언 전 호출이 불가합니다.
- 화살표 함수는 간결하며 자체 `this`를 가지지 않습니다.
- 나머지 매개변수(`...args`)로 가변 인수를 배열로 받습니다.
- IIFE는 즉시 실행되는 함수이며 스코프 격리에 사용했습니다.
