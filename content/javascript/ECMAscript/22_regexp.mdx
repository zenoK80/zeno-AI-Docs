## 정규표현식이란?

> **쉽게 말하면:** 정규표현식(Regular Expression, 정규식)은 "문자열의 패턴을 표현하는 특수한 문법"입니다. "숫자만 3개 연속", "@가 포함된 문자열"처럼 규칙을 코드로 표현할 수 있습니다.

일반 문자열 검색(`includes`)은 정확히 일치하는 텍스트만 찾을 수 있지만, 정규표현식은 **패턴**(규칙)으로 찾기 때문에 훨씬 유연합니다.

```js
const text = '제 연락처는 010-1234-5678입니다'

console.log(text.includes('010-1234-5678'))  // true — 정확히 이 문자열이 있어야만 찾음

// 정규표현식 — "숫자 3개 - 숫자 4개 - 숫자 4개" 패턴이면 형태만 맞으면 찾음
const phonePattern = /\d{3}-\d{4}-\d{4}/
console.log(phonePattern.test(text))  // true
```

## 정규표현식 만들기

```js
const pattern1 = /hello/       // 슬래시로 감싸는 리터럴 문법 (가장 흔히 씀)
const pattern2 = new RegExp('hello')  // 생성자 문법 (패턴을 동적으로 만들 때 사용)
```

## test — 패턴이 있는지 확인 (boolean)

```js
const hasNumber = /\d/
console.log(hasNumber.test('abc123'))  // true
console.log(hasNumber.test('abcdef'))  // false
```

## match와 matchAll — 일치하는 부분 찾기

```js
const text = '연락처: 010-1234-5678, 사무실: 02-9876-5432'
const phonePattern = /\d{2,3}-\d{3,4}-\d{4}/g  // g: 전체(global)에서 모두 찾기

console.log(text.match(phonePattern))
// ['010-1234-5678', '02-9876-5432']
```

`g` 플래그가 없으면 첫 번째 일치만 찾고, 있으면 모든 일치를 배열로 반환합니다.

## replace — 패턴을 찾아 바꾸기

  files={{
    '/index.js': `const text = '제 이메일은 abc@test.com이고 전화번호는 010-1234-5678입니다'

// 이메일 형식인지 검증
const emailPattern = /\\w+@\\w+\\.\\w+/
console.log(emailPattern.test('abc@test.com'))     // true

const phonePattern = /\\d{3}-\\d{4}-(\\d{4})/
const masked = text.replace(phonePattern, '010-****-$1')
console.log(masked)

// 문자열 안의 모든 숫자를 '#'로 치환
console.log('a1b2c3'.replace(/\\d/g, '#'))  // 'a#b#c#'`,
  }}
/>

`replace`에서 `$1`은 정규표현식의 **첫 번째 그룹**(`(...)`으로 감싼 부분)을 그대로 가져오라는 뜻입니다. 이를 이용해 "일부는 남기고 일부만 바꾸는" 마스킹 처리를 할 수 있습니다.

## 자주 쓰는 실전 패턴

```js
// 이메일 형식 검증 (간단한 버전)
const emailPattern = /^[\w.-]+@[\w.-]+\.\w+$/
console.log(emailPattern.test('user@example.com'))  // true

// 비밀번호: 영문+숫자 포함 8자 이상 (실제 서비스는 더 엄격한 패턴 사용)
const passwordPattern = /^(?=.*[A-Za-z])(?=.*\d).{8,}$/
console.log(passwordPattern.test('abc12345'))  // true
console.log(passwordPattern.test('abcdefgh'))  // false — 숫자 없음

// 공백 여러 개를 하나로 합치기
console.log('안녕    하세요'.replace(/\s+/g, ' '))  // '안녕 하세요'
```

<Callout type="warning">
  정규표현식은 강력하지만 복잡해질수록 읽기 어려워집니다. **완벽한 이메일 검증 정규식**을 직접 만들려 하지 마세요. 실무에서는 간단한 형식 확인 정도로만 쓰고, 진짜 검증(실제 존재하는 이메일인지)은 인증 메일 발송 같은 별도 절차로 확인합니다.
</Callout>

## 핵심 정리

- 정규표현식은 문자열의 패턴을 표현하는 문법이며 `/패턴/플래그` 형태로 작성한다.
- `\d`(숫자), `\w`(영문자·숫자), `\s`(공백) 같은 기호로 문자 종류를, `*`, `+`, `{n}`으로 반복 횟수를 표현한다.
- `test()`는 패턴 일치 여부를 boolean으로, `match()`는 일치하는 부분을 배열로 반환한다.
- `g` 플래그가 있으면 모든 일치를, 없으면 첫 번째 일치만 찾는다.
- `replace()`에서 `$1`로 그룹 캡처한 부분을 재사용할 수 있다.
