## 배열 메서드가 왜 중요한가?

> **쉽게 말하면:** for문으로 배열을 하나씩 돌면서 할 수 있는 흔한 작업들(변환, 필터링, 압축)을, 이름이 붙은 전용 메서드로 훨씬 짧고 명확하게 표현한 것입니다.

```js
const numbers = [1, 2, 3, 4, 5]

// for문 방식 — 각 숫자를 2배로
const doubled1 = []
for (let i = 0; i < numbers.length; i++) {
  doubled1.push(numbers[i] * 2)
}

// map 방식 — 의도가 훨씬 명확하게 드러남
const doubled2 = numbers.map(n => n * 2)

console.log(doubled1, doubled2)  // 둘 다 [2, 4, 6, 8, 10]
```

## map — 변환해서 새 배열 만들기

```js
const prices = [1000, 2000, 3000]
const withTax = prices.map(price => price * 1.1)
console.log(withTax)  // [1100, 2200, 3300]
```

`map`은 배열의 **각 요소를 변환한 새 배열**을 반환합니다. 원본 배열의 길이와 항상 같은 길이를 유지합니다.

## filter — 조건에 맞는 것만 걸러내기

```js
const scores = [45, 78, 92, 61, 88]
const passed = scores.filter(score => score >= 60)
console.log(passed)  // [78, 92, 61, 88]
```

`filter`는 콜백이 `true`를 반환하는 요소만 모아 새 배열을 만듭니다. 원본보다 짧거나 같은 길이가 됩니다.

## find와 findIndex — 하나만 찾기

```js
const users = [
  { id: 1, name: '철수' },
  { id: 2, name: '영희' },
]

console.log(users.find(u => u.id === 2))       // { id: 2, name: '영희' } — 찾은 요소 자체
console.log(users.findIndex(u => u.id === 2))  // 1 — 찾은 요소의 인덱스
console.log(users.find(u => u.id === 99))      // undefined — 못 찾으면 undefined
```

## reduce — 배열을 하나의 값으로 압축하기

`reduce`는 가장 강력하지만 처음엔 헷갈리는 메서드입니다. 배열의 모든 요소를 순회하며 **누적값**(accumulator)**을 계속 갱신**해 최종적으로 값 하나를 만듭니다.

```js
const cart = [
  { name: '사과', price: 1000, qty: 3 },
  { name: '바나나', price: 500, qty: 5 },
]

const total = cart.reduce((acc, item) => acc + item.price * item.qty, 0)
console.log(total)  // 5500
```

### reduce가 실제로 계산하는 과정 — 손으로 따라가기

`cart.reduce((acc, item) => acc + item.price * item.qty, 0)`의 실행 과정을 한 단계씩 풀어보면:

<Table>
  <thead>
    <tr><th>단계</th><th>acc(들어오는 값)</th><th>item</th><th>계산</th><th>반환값(다음 acc)</th></tr>
  </thead>
  <tbody>
    <tr><td>시작</td><td>—</td><td>—</td><td>초기값 지정</td><td>0</td></tr>
    <tr><td>1번째</td><td>0</td><td>사과(1000×3)</td><td>0 + 3000</td><td>3000</td></tr>
    <tr><td>2번째</td><td>3000</td><td>바나나(500×5)</td><td>3000 + 2500</td><td>5500</td></tr>
    <tr><td>종료</td><td colSpan={3}>더 이상 요소 없음</td><td>최종 결과 5500</td></tr>
  </tbody>
</Table>

`reduce`의 두 번째 인수(`0`)는 **acc의 시작값**입니다. 생략하면 배열의 첫 번째 요소가 시작값으로 쓰이는데, 숫자 합산처럼 명확한 초기값이 필요한 경우에는 반드시 명시하는 것이 안전합니다.

## some과 every — 조건 검사

```js
const scores = [80, 90, 70]

console.log(scores.some(s => s >= 90))   // true — 하나라도 만족하면 true
console.log(scores.every(s => s >= 90))  // false — 모두 만족해야 true
console.log(scores.every(s => s >= 60))  // true
```

## forEach — 반환값 없이 그냥 실행만

```js
const fruits = ['사과', '바나나', '포도']
fruits.forEach(fruit => console.log(fruit))
// map과 달리 forEach는 undefined를 반환한다 — 새 배열이 필요 없을 때만 사용
```

<Callout type="warning">
  `forEach`의 반환값을 변수에 저장하려 하면 `undefined`만 얻게 됩니다. 배열을 변형한 **새 배열이 필요하다면 `map`**을, 그냥 각 요소로 어떤 동작(로그 출력 등)만 하고 싶다면 `forEach`를 사용합니다.
</Callout>

## 메서드 체이닝 — 여러 메서드를 이어붙이기

배열 메서드는 대부분 새 배열을 반환하므로, 뒤에 다른 메서드를 이어붙일 수 있습니다.

```js
const users = [
  { name: '철수', age: 25, active: true },
  { name: '영희', age: 17, active: true },
  { name: '민수', age: 30, active: false },
]

const result = users
  .filter(u => u.active)       // 활성 사용자만
  .filter(u => u.age >= 18)    // 성인만
  .map(u => u.name)            // 이름만 추출

console.log(result)  // ['철수']
```

## 핵심 정리

- map은 변환된 새 배열, filter는 조건에 맞는 요소만 걸러낸 새 배열을 반환한다.
- find는 조건에 맞는 첫 요소, findIndex는 그 인덱스를 반환하며 못 찾으면 각각 undefined, -1이다.
- reduce는 초기값에서 시작해 각 요소를 누적 계산하며 값 하나로 압축한다.
- some은 하나라도, every는 모두 조건을 만족하는지 검사한다.
- forEach는 반환값이 없어 단순 반복 실행에만 쓰고, 새 배열이 필요하면 map을 쓴다.
