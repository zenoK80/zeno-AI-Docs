## 문자열은 왜 원시 타입인데 메서드를 쓸 수 있나?

06번 문서에서 문자열이 원시 타입이라고 배웠습니다. 그런데 `'hello'.toUpperCase()`처럼 메서드를 호출할 수 있는 이유는, 자바스크립트가 문자열에 메서드를 호출하는 순간 **일시적으로 String 객체로 감싸서**(래핑, wrapping) **프로토타입**(18번 문서)**의 메서드를 빌려 쓰게 해주기** 때문입니다. 이 과정은 자동이라 신경 쓸 필요는 없지만, "원시값인데 왜 메서드가 되지?"라는 궁금증의 답입니다.

<Callout type="warning">
  문자열 메서드는 **원본을 절대 바꾸지 않고 항상 새 문자열을 반환**합니다. 16번 문서에서 배운 대로 문자열은 원시값이라 애초에 "직접 수정"이 불가능합니다. `text.trim()`을 호출해도 `text` 자체는 그대로이며, 결과를 쓰려면 변수에 다시 담아야 합니다.
</Callout>

## 템플릿 리터럴 복습과 여러 줄 문자열

```js
const name = '철수'
const age = 25

// 템플릿 리터럴로 변수 삽입
console.log(`${name}님은 ${age}세입니다`)

// 여러 줄 문자열 — 백틱은 줄바꿈을 그대로 유지한다
const multiline = `첫째 줄
둘째 줄
셋째 줄`
console.log(multiline)
```

## 숫자 메서드

```js
const price = 1234.5678

console.log(price.toFixed(2))         // '1234.57' — 소수점 2자리로 반올림 (문자열 반환!)
console.log(Math.round(price))        // 1235 — 가장 가까운 정수로 반올림
console.log(Math.floor(price))        // 1234 — 내림
console.log(Math.ceil(price))         // 1235 — 올림
console.log(Math.abs(-5))             // 5 — 절댓값
console.log(Math.max(3, 7, 2))        // 7
console.log(Math.min(3, 7, 2))        // 2
console.log(Math.random())            // 0 이상 1 미만의 무작위 실수

console.log(Number('42'))             // 42
console.log(Number.isInteger(42))     // true
console.log(Number.isInteger(42.5))   // false
console.log((255).toString(16))       // 'ff' — 16진수로 변환
```

<Callout type="warning">
  `toFixed()`는 숫자가 아닌 **문자열**을 반환합니다. `price.toFixed(2) + 1`을 하면 숫자 덧셈이 아니라 `'1234.571'`처럼 문자열 이어붙이기가 되어버리는 함정이 있습니다(8번 타입 변환 문서 참고). 계산이 더 필요하면 `Number(price.toFixed(2))`로 다시 숫자로 변환해야 합니다.
</Callout>

## 무작위 정수 만들기 — Math.random() 활용 패턴

```js
// 0 이상 max 미만의 무작위 정수
function randomInt(max) {
  return Math.floor(Math.random() * max)
}

console.log(randomInt(10))  // 0~9 중 하나

// min 이상 max 이하의 무작위 정수
function randomBetween(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min
}
console.log(randomBetween(1, 6))  // 주사위 굴리기: 1~6 중 하나
```

```js
const price = 1234567

```

## 핵심 정리

- 문자열 메서드는 원본을 바꾸지 않고 항상 새 문자열을 반환한다.
- slice(시작, 끝)는 끝 인덱스를 포함하지 않으며, 음수는 뒤에서부터 센다.
- toFixed()는 숫자가 아닌 문자열을 반환하므로, 이후 계산이 필요하면 다시 Number()로 변환해야 한다.
- Math.floor/round/ceil은 각각 내림/반올림/올림을 수행한다.
- Math.random()은 0 이상 1 미만의 실수를 반환하며, 정수 범위가 필요하면 Math.floor와 조합한다.
