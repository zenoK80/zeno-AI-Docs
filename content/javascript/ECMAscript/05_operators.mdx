## 산술 연산자

```js
console.log(10 + 3)   // 13
console.log(10 - 3)   // 7
console.log(10 * 3)   // 30
console.log(10 / 3)   // 3.3333...
console.log(10 % 3)   // 1  (나머지)
console.log(2 ** 10)  // 1024 (거듭제곱)
```

`+` 연산자는 피연산자에 문자열이 있으면 **문자열 연결**로 동작합니다.

```js
console.log(1 + '2')   // '12'
console.log('3' + 4)   // '34'
```

## 비교 연산자

```js
console.log(5 > 3)    // true
console.log(5 < 3)    // false
console.log(5 >= 5)   // true
console.log(5 <= 4)   // false
console.log(5 == '5')  // true  (타입 변환 후 비교)
console.log(5 === '5') // false (타입까지 같아야 true)
console.log(5 != '5')  // false
console.log(5 !== '5') // true
```

`==`는 타입을 변환한 뒤 비교하고, `===`는 타입과 값 모두 같아야 `true`를 반환합니다.

<Callout type="warning">
  예상치 못한 타입 변환을 피하려면 항상 `===`와 `!==`를 사용하세요.
</Callout>

## 논리 연산자

```js
console.log(true && true)   // true
console.log(true && false)  // false
console.log(false || true)  // true
console.log(!true)          // false
```

| 연산자 | 의미 | 결과가 true인 경우 |
| --- | --- | --- |
| `&&` | AND | 둘 다 truthy일 때 |
| `\|\|` | OR | 하나라도 truthy일 때 |
| `!` | NOT | 피연산자가 falsy일 때 |

## 단락 평가 (Short-circuit Evaluation)

논리 연산자는 결과가 확정되면 나머지를 평가하지 않고 **값을 반환**합니다.

```js
// &&: 왼쪽이 falsy면 왼쪽 값 반환, truthy면 오른쪽 값 반환
const a = null && 'hello'   // null
const b = 'hi' && 'hello'   // 'hello'

// ||: 왼쪽이 truthy면 왼쪽 값 반환, falsy면 오른쪽 값 반환
const c = null || '기본값'  // '기본값'
const d = '사용자' || '기본값' // '사용자'
```

이를 활용해 기본값을 설정하거나 조건부 실행을 간결하게 쓸 수 있습니다.

```js
const username = inputName || '익명'
isLoggedIn && showDashboard()
```

## 널 병합 연산자 (??)

`||`는 `0`이나 `''`처럼 falsy한 값도 기본값으로 대체합니다. `null`이나 `undefined`일 때만 대체하려면 `??`를 씁니다. 아래에서 `count`의 값을 0, '', null, undefined로 바꿔가며 `||`와 `??`의 차이를 직접 확인해보세요.

## 삼항 연산자

```js
const result = 점수 >= 60 ? '합격' : '불합격'
```

`조건 ? 참일_때_값 : 거짓일_때_값` 형태이며, 간단한 조건 표현에 유용합니다.

## typeof 연산자

```js
console.log(typeof 42)         // 'number'
console.log(typeof '안녕')     // 'string'
console.log(typeof undefined)  // 'undefined'
```

값의 타입을 문자열로 반환하며, 단항 연산자입니다.

## 핵심 정리

- 산술 연산자에서 `+`는 문자열이 있으면 연결로 동작합니다.
- 비교 시 `===`를 사용해 타입 변환 없이 비교하세요.
- 단락 평가를 활용하면 기본값 설정과 조건부 실행을 간결하게 쓸 수 있습니다.
- `??`는 null/undefined일 때만 기본값을 대체합니다.
