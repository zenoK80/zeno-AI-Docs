## 왜 ES6가 분기점일까?

2015년에 공개된 **ES6**(ECMAScript 2015)는 자바스크립트 역사상 가장 큰 변화였습니다. `let`/`const`, 화살표 함수, 클래스, 구조 분해, 모듈, Promise 등 지금까지 이 시리즈에서 배운 핵심 문법 대부분이 이때 추가되었습니다. 이 문서에서는 아직 다루지 않은 나머지 편의 문법들을 정리합니다.

## 템플릿 리터럴 — 백틱으로 문자열 만들기

```js
const name = '철수'
const age = 25

// 기존 방식 — 문자열을 + 로 이어 붙임
const message1 = name + '님은 ' + age + '세입니다.'

// 템플릿 리터럴 — ${} 안에 변수·표현식을 바로 삽입
const message2 = `${name}님은 ${age}세입니다.`
console.log(message2)

// 표현식도 넣을 수 있다
console.log(`내년이면 ${age + 1}세입니다`)

// 여러 줄 문자열 — 백틱은 줄바꿈을 그대로 유지
const html = `
  <div>
    <h1>${name}</h1>
  </div>
`
```

## 옵셔널 체이닝(`?.`)과 null 병합(`??`) — 복습

07번 문서에서 이미 다뤘지만, ES6+ 핵심 문법으로 다시 한번 짚습니다.

```js
const user = { profile: { city: '서울' } }
console.log(user.profile?.city)         // '서울'
console.log(user.address?.zipcode)      // undefined — address가 없어도 에러 안 남

// 메서드 호출에도 사용 가능
user.nonExistentMethod?.()  // 메서드가 없으면 그냥 아무 일도 안 일어남(에러 없음)

// 배열 인덱스에도 사용 가능
const arr = null
console.log(arr?.[0])  // undefined
```

## Optional Chaining + Nullish Coalescing 조합 — 실전 패턴

```js
function getDisplayName(user) {
  return user?.profile?.nickname ?? user?.name ?? '이름 없음'
}

console.log(getDisplayName({ profile: { nickname: '철수짱' } }))  // '철수짱'
console.log(getDisplayName({ name: '철수' }))                     // '철수'
console.log(getDisplayName(null))                                  // '이름 없음'
```

## 배열/객체 구조 분해 — 복습

17번 문서에서 자세히 다뤘습니다. ES6의 대표적인 문법 중 하나입니다.

```js
const [a, b] = [1, 2]
const { x, y } = { x: 10, y: 20 }
```

## Array.from — 유사 배열을 진짜 배열로

`Array.from()`은 배열이 아닌 것을 배열로 바꿔줍니다.

  label="Array.from 실습"
  files={{
    '/index.js': `// 문자열을 문자 배열로
console.log(Array.from('hello'))  // ['h', 'e', 'l', 'l', 'o']

console.log(Array.from([1, 2, 3], n => n * 2))  // [2, 4, 6]

// 지정된 길이의 배열을 채워서 만들기
console.log(Array.from({ length: 5 }, (_, i) => i))  // [0, 1, 2, 3, 4]

// 반복 가능한(iterable) 값에서 배열 생성
console.log(Array.from(new Set([1, 1, 2, 2, 3])))  // [1, 2, 3]`,

/>

`{ length: 5 }`처럼 배열이 아니지만 `length` 프로퍼티가 있는 값도 `Array.from`으로 배열로 만들 수 있습니다. 이는 `for`문 없이 "0부터 n까지의 숫자 배열"을 만드는 실전 패턴으로 자주 쓰입니다.

## 배열의 includes — indexOf보다 명확하게

```js
const fruits = ['사과', '바나나', '포도']

console.log(fruits.indexOf('바나나') !== -1)  // true — 예전 방식, 의도가 간접적
console.log(fruits.includes('바나나'))        // true — 의도가 명확
console.log(fruits.includes(NaN))             // indexOf는 NaN을 못 찾지만 includes는 찾을 수 있음
```

## Object.freeze — 객체를 불변으로 만들기

4번 문서에서 `const`가 재할당만 막을 뿐 내용 변경은 막지 못한다고 배웠습니다. 내용까지 변경을 막으려면 `Object.freeze()`를 사용합니다.

```js
const config = Object.freeze({ apiUrl: 'https://api.example.com' })

config.apiUrl = '변경 시도'  // 조용히 무시됨(strict mode에서는 에러)
console.log(config.apiUrl)  // 'https://api.example.com' — 그대로 유지

console.log(Object.isFrozen(config))  // true
```

<Callout type="warning">
  `Object.freeze()`도 **얕은** 동결입니다. 16번 문서에서 배운 얕은 복사와 같은 원리로, 중첩된 객체는 여전히 수정 가능합니다.
  ```js
  const config = Object.freeze({ nested: { value: 1 } })
  config.nested.value = 999  // 이건 성공함! nested는 동결 범위 밖
  console.log(config.nested.value)  // 999
  ```
</Callout>

## 지수 연산자 `**`

```js
console.log(2 ** 10)   // 1024 — Math.pow(2, 10)과 같음
console.log(2 ** 0.5)  // 1.414... — 제곱근
```

## 핵심 정리

- 템플릿 리터럴(백틱)은 변수 삽입과 여러 줄 문자열을 간결하게 표현한다.
- `?.`와 `??`를 조합하면 중첩된 값을 안전하게 읽고 기본값까지 지정할 수 있다.
- `Array.from()`은 유사 배열이나 iterable을 진짜 배열로 변환하며, 두 번째 인수로 map까지 한 번에 처리할 수 있다.
- `includes()`는 `indexOf() !== -1`보다 의도가 명확하며 NaN도 찾을 수 있다.
- `Object.freeze()`는 객체를 불변으로 만들지만 얕은 동결이라 중첩 객체는 여전히 수정 가능하다.
