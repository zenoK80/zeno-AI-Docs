## 데이터 타입

3편에서 변수에 값을 담았다. 이번 편에서는 **그 값이 어떤 종류인지**를 본다.
자바스크립트의 값은 크게 두 갈래로 나뉜다.

<Callout type="important">
**원시 타입**<sup>Primitive Type</sup> — 더 이상 쪼갤 수 없는 단순한 값 (숫자, 문자열 등)
**객체 타입**<sup>Object Type</sup> — 여러 값을 묶어 담는 복합적인 값

이번 편은 **원시 타입 7가지**를 다룬다. 객체는 12편부터 본격적으로 다루고,
둘의 근본적인 차이(왜 나뉘는지)는 13편에서 원리를 짚는다.
</Callout>

## 원시 타입 일곱 가지

### 1. Number — 숫자

```js
let age = 20
let price = 19.99
let negative = -5
```

<Callout type="info">
많은 언어가 정수(int)와 소수(float)를 구분하지만, **자바스크립트는 숫자를 하나의 타입으로만 다룬다.**
`20`과 `19.99`는 타입 관점에서 완전히 같은 `Number`다. 내부적으로는 모든 숫자를 실수(부동소수점) 방식으로 저장한다.
</Callout>

특수한 숫자 값도 `Number` 타입에 속한다.

```js
console.log(1 / 0)        // Infinity
console.log(-1 / 0)       // -Infinity
console.log(0 / 0)        // NaN — Not a Number
console.log(typeof NaN)   // 'number' — 이름과 달리 타입은 숫자다
```

### 2. String — 문자열

```js
let name = '지민'
let greeting = "안녕하세요"
let template = `${name}님, 안녕하세요`   // 백틱 — 값을 끼워 넣을 수 있다
```

작은따옴표·큰따옴표는 기능 차이가 없다. 백틱(`` ` ``)은 **템플릿 리터럴**이라는 별도 문법으로, 문자열 안에 변수를 바로 끼워 넣을 수 있다. 자세한 문법은 24편(String)에서 다룬다.

### 3. Boolean — 참/거짓

```js
let isAdult = true
let isLoggedIn = false
```

값은 `true`, `false` 딱 둘뿐이다. 조건문(8편)에서 핵심적으로 쓰인다.

### 4. undefined — 값이 없음 (아직)

```js
let score
console.log(score)   // undefined — 선언만 하고 값을 안 넣은 상태
```

**"값을 넣는 걸 깜빡했다"** 는 신호에 가깝다. 자바스크립트 엔진이 자동으로 부여하는 값이다.

### 5. null — 값이 없음 (의도적으로)

```js
let selectedUser = null   // "아직 아무도 선택 안 됨"을 의도적으로 표시
```

<Callout type="warning">
**`undefined`와 `null`은 둘 다 "없음"이지만 뉘앙스가 다르다.**

- `undefined` — 시스템이 "아직 값이 없다"고 자동으로 붙인 것
- `null` — 개발자가 "값이 없음을 의도했다"고 명시적으로 넣은 것

그런데 `typeof null`을 쳐보면:

```js
console.log(typeof null)   // 'object' ??
```

`'null'`이 아니라 `'object'`가 나온다. 이건 1988년 자바스크립트 최초 구현의 버그인데,
이미 전 세계 웹이 이 동작에 의존하게 되어 지금까지도 고쳐지지 않았다. **자바스크립트에서 가장 유명한 버그**로 꼽힌다.
</Callout>

### 6. BigInt — 아주 큰 정수

```js
const big = 9007199254740993n   // 끝에 n을 붙인다
console.log(typeof big)          // 'bigint'
```

일반 `Number`는 안전하게 표현할 수 있는 정수 범위가 있다(약 ±9000조). 그 범위를 넘는 정수가 필요할 때 쓴다.
실무에서 자주 쓰이지는 않지만, 존재는 알아두자.

### 7. Symbol — 유일한 값

```js
const id = Symbol('id')
console.log(typeof id)   // 'symbol'
```

호출할 때마다 세상에 하나뿐인 값을 만든다. 객체의 프로퍼티 키 충돌을 막을 때 쓰는데, 지금은 이름만 기억해 두자.
쓰임새는 29편(Symbol과 이터러블)에서 다룬다.

## typeof — 타입 확인하기

값의 타입은 `typeof` 연산자로 확인한다.

```js
typeof 20          // 'number'
typeof '안녕'       // 'string'
typeof true         // 'boolean'
typeof undefined    // 'undefined'
typeof null         // 'object'   ← 버그, 주의!
typeof 10n          // 'bigint'
typeof Symbol('a')  // 'symbol'
typeof {}           // 'object'
typeof function(){} // 'function' — 사실은 객체의 한 종류
```

<Callout type="info">
`typeof`는 **연산자**이지 함수가 아니다. `typeof(20)`처럼 괄호를 써도 되지만, 괄호는 그냥 표현식을 감싸는 것일 뿐 `typeof 20`과 동일하게 동작한다.
</Callout>

## 값을 요약하는 표

| 타입 | 예시 값 | typeof 결과 |
| --- | --- | --- |
| Number | `20`, `3.14`, `NaN` | `'number'` |
| String | `'안녕'` | `'string'` |
| Boolean | `true`, `false` | `'boolean'` |
| undefined | `undefined` | `'undefined'` |
| null | `null` | `'object'` (버그) |
| BigInt | `10n` | `'bigint'` |
| Symbol | `Symbol()` | `'symbol'` |

## 동적 타입 다시 보기

1편에서 "자바스크립트는 동적 타입 언어"라고 했다. 이제 그 의미를 더 정확히 말할 수 있다.

```js
let value = 10          // 지금은 Number
console.log(typeof value)   // 'number'

value = '열'             // 이제 String
console.log(typeof value)   // 'string'
```

**타입은 변수가 아니라 그 순간 담긴 값에 붙는다.** 같은 변수라도 무엇을 담느냐에 따라 타입이 그때그때 바뀐다.

## 정리

<Callout type="default">
- 값은 크게 **원시 타입**(7가지)과 **객체 타입**으로 나뉜다
- 원시 타입: `Number`, `String`, `Boolean`, `undefined`, `null`, `BigInt`, `Symbol`
- `undefined`는 시스템이 붙이는 "값 없음", `null`은 개발자가 명시하는 "값 없음"
- `typeof null`이 `'object'`인 건 고쳐지지 않는 오래된 버그다
- 타입은 변수가 아니라 **그 순간의 값**에 달려 있다
</Callout>

다음 편에서는 이 값들을 조합하고 계산하는 **연산자**를 배운다.
