## 동기 vs 비동기

```js
// 동기: 순서대로 실행
console.log('1')
console.log('2')
console.log('3')  // 1, 2, 3 순서

// 비동기: 나중에 실행
console.log('1')
setTimeout(() => console.log('2'), 1000)
console.log('3')  // 1, 3, 2 순서 (2는 1초 후)
```

## 콜백 지옥

비동기 작업을 중첩된 콜백으로 처리하면 코드가 복잡해집니다.

```js
fetchUser(id, function(user) {
  fetchOrders(user.id, function(orders) {
    fetchProduct(orders[0].productId, function(product) {
      // 점점 깊어지는 중첩...
    })
  })
})
```

## Promise

비동기 작업의 완료(또는 실패)를 나타내는 객체입니다. 세 가지 상태를 가집니다.

- `pending`: 대기 중
- `fulfilled`: 성공 완료 → `.then()` 실행
- `rejected`: 실패 → `.catch()` 실행

```js
const p = new Promise((resolve, reject) => {
  setTimeout(() => {
    const success = true
    if (success) {
      resolve('완료!')
    } else {
      reject(new Error('실패'))
    }
  }, 1000)
})

p.then(result => console.log(result))
 .catch(err => console.error(err.message))
 .finally(() => console.log('항상 실행'))
```

## Promise 체이닝

`.then()`은 새 Promise를 반환하므로 체이닝할 수 있습니다.

```js
fetchUser(id)
  .then(user => fetchOrders(user.id))
  .then(orders => fetchProduct(orders[0].productId))
  .then(product => console.log(product))
  .catch(err => console.error(err))
```

## Promise 유틸리티

```js
// 여러 Promise 동시 실행
const [user, settings] = await Promise.all([
  fetchUser(id),
  fetchSettings(id),
])

// 가장 먼저 완료된 것만
const result = await Promise.race([
  slowTask(),
  fastTask(),
])

// 모두 완료, 성공/실패 모두 포함
const results = await Promise.allSettled([
  fetchA(),
  fetchB(),
])
```

## async/await

`async` 함수는 항상 Promise를 반환합니다. `await`는 Promise가 완료될 때까지 기다립니다.

```js
async function loadUserData(id) {
  const user = await fetchUser(id)
  const orders = await fetchOrders(user.id)
  return { user, orders }
}
```

## 에러 처리

```js
async function getData() {
  try {
    const data = await fetchData()
    return data
  } catch (error) {
    console.error('에러:', error.message)
    return null
  } finally {
    console.log('완료')
  }
}
```

여러 await를 한 번에 처리하거나 각각 처리할 수 있습니다.

```js
// 각각 처리
async function fn() {
  try {
    const a = await fetchA()
  } catch (e) { /* A 에러 처리 */ }

  try {
    const b = await fetchB()
  } catch (e) { /* B 에러 처리 */ }
}
```

## 핵심 정리

- Promise는 비동기 결과를 pending/fulfilled/rejected 상태로 표현합니다.
- `.then().catch().finally()`로 체이닝하거나 `async/await`로 동기 코드처럼 작성합니다.
- `Promise.all`은 모두 완료, `Promise.race`는 가장 먼저 완료된 것을 처리합니다.
- `async/await`에서 에러는 `try/catch`로 처리합니다.
