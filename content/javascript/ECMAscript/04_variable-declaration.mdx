## 변수란 무엇인가?

> **쉽게 말하면:** 변수는 값에 이름표를 붙여서 나중에 그 이름으로 다시 꺼내 쓸 수 있게 하는 것입니다.

```js
let name = '철수'
console.log(name)  // '철수'라는 값을 name이라는 이름으로 꺼냄
```

이름표(name)가 없다면 값('철수')은 한 번 쓰이고 사라집니다. 변수는 값을 메모리에 붙잡아두고 나중에 재사용할 수 있게 합니다.

## 세 가지 선언 키워드

자바스크립트에는 변수를 선언하는 방법이 세 가지 있습니다: `var`, `let`, `const`. 역사적으로 `var`가 먼저 있었고, ES6(2015년)에서 `let`과 `const`가 추가되었습니다.

## 재선언과 재할당의 차이

이 둘을 헷갈리면 안 됩니다.

- **재선언**(redeclaration): 같은 이름으로 `let`/`const`/`var`를 **다시** 쓰는 것.
- **재할당**(reassignment): 이미 선언된 변수에 `=`로 **새 값을 넣는** 것.

```js
let count = 1
count = 2        // 재할당 — OK, let은 재할당 가능

let count = 3    // 재선언 — 오류! SyntaxError: 'count' has already been declared
```

```js
const price = 1000
price = 2000      // 재할당 — 오류! TypeError: Assignment to constant variable.
```

## var의 문제점 — 왜 지금은 잘 안 쓰나?

`var`는 함수 스코프라서, 블록(`{ }`) 안에서 선언해도 블록 밖에서 접근할 수 있습니다. 이는 종종 예상치 못한 버그를 만듭니다.

```js
if (true) {
  var x = 10
}
console.log(x)  // 10 — 블록 밖인데도 접근된다! (의도치 않을 수 있음)

if (true) {
  let y = 20
}
console.log(y)  // ReferenceError — y는 블록 밖에서 접근 불가 (의도한 대로)
```

`var`는 또한 재선언을 허용해서, 실수로 같은 이름을 두 번 선언해도 오류가 나지 않아 버그를 찾기 어렵게 만듭니다.

<Callout type="warning">
  현재 실무에서는 **`var`를 사용하지 않는 것**이 표준입니다. 오래된 코드(2015년 이전)를 읽을 때만 만나게 됩니다.
</Callout>

## const를 기본값으로 — let은 필요할 때만

최신 자바스크립트 스타일 가이드는 **"기본은 `const`, 값이 바뀔 필요가 있을 때만 `let`"**을 권장합니다.

```js
const MAX_USERS = 100     // 바뀌지 않는 값 → const
let currentUsers = 0      // 계속 증가할 값 → let

function addUser() {
  currentUsers = currentUsers + 1  // 재할당이 필요하므로 let이어야 함
}
```

**왜 const를 기본으로 삼을까?** 변수가 `const`로 선언되어 있으면, 코드를 읽는 사람은 "이 값은 이후로 절대 바뀌지 않는다"는 것을 바로 알 수 있습니다. `let`이 여기저기 있으면 "이 값이 코드 어딘가에서 바뀔 수도 있겠다"는 의심을 하며 읽어야 해서 코드 이해가 어려워집니다.

### const인데 내용이 바뀌는 경우 — 주의!

`const`는 "재할당 금지"이지, "내용 변경 금지"가 아닙니다. 객체나 배열처럼 **참조 타입**(16번 문서에서 자세히 다룸)은 `const`로 선언해도 내부 내용은 바꿀 수 있습니다.

```js
const user = { name: '철수' }
user.name = '영희'   // OK — 객체 내부 프로퍼티 변경은 재할당이 아님
console.log(user)    // { name: '영희' }

user = { name: '민수' }  // 오류! — user 자체를 다른 객체로 바꾸는 것은 재할당
```

## 핵심 정리

- `var`는 함수 스코프에 재선언이 가능해 버그를 만들기 쉬워 현재는 사용하지 않는다.
- `let`은 재할당 가능, 재선언 불가능, 블록 스코프.
- `const`는 재할당도 재선언도 불가능, 블록 스코프.
- 기본은 `const`를 쓰고, 값이 바뀌어야 할 때만 `let`을 쓴다.
- `const`는 재할당만 막을 뿐, 객체·배열의 내부 내용 변경은 막지 않는다.
