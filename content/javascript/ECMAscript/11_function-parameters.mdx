## 매개변수와 인수 — 용어 구분

> **쉽게 말하면:** 매개변수는 함수를 "정의할 때" 쓰는 이름표이고, 인수는 함수를 "호출할 때" 실제로 넣는 값입니다.

```js
function greet(name) {  // name = 매개변수(parameter)
  console.log(`안녕, ${name}`)
}

greet('철수')  // '철수' = 인수(argument)
```

## 매개변수 개수와 실제 인수 개수가 다를 때

자바스크립트는 매개변수 개수와 호출 시 넘긴 인수 개수가 달라도 에러를 내지 않습니다.

```js
function add(a, b) {
  return a + b
}

console.log(add(1))        // NaN — b가 undefined라서 1 + undefined = NaN
console.log(add(1, 2, 3))  // 3 — 초과 인수(3)는 그냥 무시됨
```

## 기본값 매개변수(Default Parameters)

인수를 넘기지 않았을 때 사용할 기본값을 지정할 수 있습니다.

```js
function greet(name = '손님') {
  console.log(`안녕하세요, ${name}님`)
}

greet()        // 안녕하세요, 손님님
greet('철수')   // 안녕하세요, 철수님
greet(undefined) // 안녕하세요, 손님님 — undefined를 넘기면 기본값 적용됨
greet(null)     // 안녕하세요, null님 — null은 "값이 있는 것"으로 취급되어 기본값 미적용
```

<Callout type="warning">
  기본값은 인수가 `undefined`일 때만 적용됩니다. `null`을 넘기면 "명시적으로 값을 준 것"으로 취급되어 기본값이 적용되지 않습니다. 이 차이는 06번 문서에서 배운 undefined와 null의 의미 차이와 정확히 일치합니다.
</Callout>

## rest 파라미터 — 개수가 정해지지 않은 인수 받기

`...`(점 세 개)를 매개변수 앞에 붙이면, 넘치는 인수들을 하나의 **배열**로 모아 받습니다.

</Callout>

## arguments 객체 — 오래된 방식 (참고용)

`function` 키워드로 만든 함수 안에서는 `arguments`라는 배열 비슷한 객체로 전달된 모든 인수에 접근할 수 있습니다. rest 파라미터가 나오기 전(ES5 이전)에 사용하던 방식입니다.

```js
function oldSum() {
  console.log(arguments)          // Arguments(3) [1, 2, 3] — 배열처럼 보이지만
  console.log(Array.isArray(arguments))  // false — 진짜 배열이 아님!

  let total = 0
  for (let i = 0; i < arguments.length; i++) {
    total += arguments[i]
  }
  return total
}
console.log(oldSum(1, 2, 3))  // 6
```

**arguments의 한계:**
- 진짜 배열이 아니라서 `map()`, `filter()` 같은 배열 메서드를 바로 쓸 수 없습니다.
- **화살표 함수에는 `arguments`가 없습니다.** 화살표 함수 안에서 `arguments`를 쓰면 바깥 함수의 arguments를 가리킵니다(this와 같은 원리).

```js
const arrowFn = () => {
  console.log(arguments)  // ReferenceError (바깥에 감싸는 함수가 없다면)
}
```

이런 한계 때문에 **현재는 rest 파라미터**(`...args`)**가 arguments보다 권장**됩니다. 진짜 배열이라 바로 배열 메서드를 쓸 수 있고, 화살표 함수에서도 동작하기 때문입니다.

## 구조 분해와 함께 쓰기 — 객체 매개변수 패턴

함수에 옵션이 여러 개일 때, 매개변수를 객체로 묶고 구조 분해로 받으면 순서를 외울 필요가 없어집니다. (구조 분해 자체는 17번 문서에서 자세히 다룹니다.)

```js
// 순서를 외워야 하는 방식 — 실수하기 쉬움
function createUser(name, age, isAdmin) { /* ... */ }
createUser('철수', 25, false)

// 객체 + 구조 분해 — 이름으로 전달, 순서 무관, 기본값도 가능
function createUser2({ name, age, isAdmin = false }) {
  console.log(name, age, isAdmin)
}
createUser2({ age: 25, name: '철수' })  // 순서 바뀌어도 문제없음
```

## 핵심 정리

- 인수가 부족하면 나머지 매개변수는 `undefined`, 초과하면 무시된다.
- 기본값 매개변수는 인수가 `undefined`일 때만 적용되며, `null`에는 적용되지 않는다.
- rest 파라미터(`...args`)는 남은 인수를 진짜 배열로 모아준다. 매개변수 목록 마지막에만 올 수 있다.
- `arguments`는 배열이 아닌 유사 배열 객체이며 화살표 함수에는 존재하지 않는다. 현재는 rest 파라미터가 권장된다.
- 옵션이 많은 함수는 객체 매개변수 + 구조 분해 패턴이 실무에서 자주 쓰인다.
