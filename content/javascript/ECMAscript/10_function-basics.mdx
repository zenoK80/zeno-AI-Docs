## 함수란 무엇인가?

> **쉽게 말하면:** 함수는 "입력을 받아서 어떤 일을 하고, 결과를 돌려주는 코드 뭉치"입니다. 한 번 정의해두면 몇 번이든 재사용할 수 있습니다.

```js
function add(a, b) {
  return a + b
}

console.log(add(2, 3))  // 5
console.log(add(10, 20)) // 30 — 같은 함수를 다른 입력으로 재사용
```

## 함수 선언문(Function Declaration)

```js
function greet(name) {
  return `안녕하세요, ${name}님`
}
```

5번 문서(호이스팅)에서 배운 대로, 함수 선언문은 **정의 전에 호출해도 동작**합니다.

```js
console.log(greet('철수'))  // 정상 동작

function greet(name) {
  return `안녕하세요, ${name}님`
}
```

## 함수 표현식(Function Expression)

함수를 변수에 담는 방식입니다.

```js
const greet = function (name) {
  return `안녕하세요, ${name}님`
}
```

함수 표현식은 변수 규칙을 따르므로, **정의 전에 호출하면 에러**가 납니다.

```js
console.log(greet('철수'))  // TypeError!

const greet = function (name) {
  return `안녕하세요, ${name}님`
}
```

### 이름 붙은 함수 표현식

함수 표현식에도 이름을 붙일 수 있습니다. 이 이름은 함수 내부(재귀 호출)에서만 쓸 수 있고, 외부에서는 변수 이름으로만 접근합니다.

```js
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1)  // 내부에서는 fact로 자기 자신 호출
}
console.log(factorial(5))  // 120
// fact(5)  // 오류! fact는 외부에서 보이지 않음
```

## 화살표 함수(Arrow Function)

ES6(2015)에서 추가된 더 짧은 문법입니다.

```js
const add = (a, b) => {
  return a + b
}

// 본문이 return문 하나뿐이면 중괄호와 return 생략 가능
const add2 = (a, b) => a + b

// 매개변수가 하나면 괄호 생략 가능
const double = n => n * 2

// 매개변수가 없으면 빈 괄호 필수
const sayHi = () => console.log('안녕')
```

## 화살표 함수와 일반 함수의 결정적 차이 — this

화살표 함수는 단순히 짧은 문법이 아닙니다. **자신만의 `this`를 갖지 않고, 자신을 둘러싼 스코프의 `this`를 그대로 물려받습니다.** (`this`는 14번 문서에서 깊게 다룹니다.)

```js
const obj = {
  name: '철수',
  regularFn: function () {
    console.log(this.name)  // '철수' — this가 obj를 가리킴
  },
  arrowFn: () => {
    console.log(this.name)  // undefined — this가 obj가 아닌 바깥 스코프를 가리킴
  },
}

obj.regularFn()  // '철수'
obj.arrowFn()    // undefined
```

이 차이 때문에, **객체의 메서드**를 정의할 때는 화살표 함수보다 일반 함수(또는 메서드 축약 문법)를 쓰는 것이 안전합니다.

## 함수도 값이다 — 일급 객체(First-class citizen)

자바스크립트에서 함수는 숫자나 문자열처럼 **하나의 값**입니다. 변수에 담을 수 있고, 다른 함수의 인수로 전달할 수 있고, 함수가 함수를 반환할 수도 있습니다. 이 성질을 "함수가 **일급 객체**(first-class citizen)다"라고 표현합니다.

```js
// 함수를 변수에 저장 (이미 위에서 계속 해왔음)
const fn = function () {}

// 함수를 다른 함수의 인수로 전달
function callTwice(f) {
  f()
  f()
}
callTwice(() => console.log('안녕'))  // '안녕'이 두 번 출력

// 함수가 함수를 반환
function makeAdder(a) {
  return function (b) {
    return a + b
  }
}
const add5 = makeAdder(5)
console.log(add5(3))  // 8
```

이 성질은 뒤에 나올 콜백, 고차 함수, 클로저(13번 문서)의 기초가 됩니다.

## 핵심 정리

- 함수 선언문은 호이스팅되어 정의 전에도 호출 가능하다.
- 함수 표현식은 변수 규칙을 따라 정의 전에 호출하면 에러가 난다.
- 화살표 함수는 짧은 문법이며, 자신만의 this를 갖지 않고 바깥 스코프의 this를 물려받는다.
- 객체 메서드는 일반 함수, 콜백은 화살표 함수를 쓰는 것이 일반적이다.
- 함수는 값처럼 변수에 담고, 인수로 전달하고, 반환할 수 있는 일급 객체다.
