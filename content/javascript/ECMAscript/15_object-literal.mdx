## 객체란?

> **쉽게 말하면:** 객체는 "이름표(key)와 값(value)"의 쌍을 여러 개 묶어놓은 상자입니다.

```js
const user = {
  name: '철수',
  age: 25,
  isActive: true,
}
```

`name`, `age`, `isActive`가 **키**(key, 프로퍼티 이름)이고, `'철수'`, `25`, `true`가 **값**(value)입니다.

## 프로퍼티 접근 — 점 표기법 vs 대괄호 표기법

```js
console.log(user.name)       // 점 표기법 — '철수'
console.log(user['name'])    // 대괄호 표기법 — '철수', 결과는 같음

const key = 'age'
console.log(user[key])       // 25 — 변수로 키 이름을 동적으로 지정할 때는 대괄호 필수
// console.log(user.key)     // undefined — 점 표기법은 'key'라는 리터럴 프로퍼티를 찾아버림
```

<Callout type="warning">
  프로퍼티 이름이 변수에 담겨 있거나, 공백·숫자로 시작하는 등 유효한 식별자가 아니라면 **반드시 대괄호 표기법**을 써야 합니다. `user['first name']`처럼 프로퍼티 이름에 공백이 있는 경우가 대표적입니다.
</Callout>

## 메서드 — 객체 안의 함수

객체의 값으로 함수를 넣으면 그 함수를 **메서드**(method)라고 부릅니다.

```js
const calculator = {
  value: 0,
  // 예전 방식
  add: function (n) {
    this.value += n
    return this
  },
  // ES6 메서드 축약 문법 — function 키워드 생략
  subtract(n) {
    this.value -= n
    return this
  },
}

calculator.add(5).subtract(2)  // this를 반환해 메서드 체이닝 가능
console.log(calculator.value)  // 3
```

`add(n) {}`처럼 `function` 키워드 없이 쓰는 것이 **메서드 축약 문법**(method shorthand)입니다. 현재 실무에서 표준으로 쓰입니다.

## 프로퍼티 값 축약(Property Shorthand)

변수 이름과 프로퍼티 이름이 같으면, 값을 생략하고 이름만 써도 됩니다.

```js
const name = '철수'
const age = 25

// 기존 방식
const user1 = { name: name, age: age }

// 축약 문법 — 이름과 값이 같은 변수일 때
const user2 = { name, age }

console.log(user2)  // { name: '철수', age: 25 } — 결과는 동일
```

이 축약 문법은 함수가 여러 값을 객체로 묶어서 반환할 때 특히 자주 쓰입니다.

```js
function createPoint(x, y) {
  return { x, y }  // { x: x, y: y }와 동일
}
console.log(createPoint(10, 20))  // { x: 10, y: 20 }
```

## 계산된 프로퍼티 이름(Computed Property Names)

프로퍼티 이름을 변수나 표현식으로 동적으로 정할 때 사용합니다.

```js
const key = 'score'
const dynamicKey = 'user_' + '01'

const obj = {
  [key]: 100,          // 대괄호 안의 표현식이 평가되어 프로퍼티 이름이 됨
  [dynamicKey]: '철수',
}

console.log(obj)  // { score: 100, user_01: '철수' }
```

`[key]`처럼 대괄호로 감싸면, 그 안의 표현식이 먼저 평가되고 그 결과가 프로퍼티 이름으로 쓰입니다. 이 문법이 없다면, 프로퍼티를 만들고 나중에 따로 대입해야 합니다.

```js
// 계산된 프로퍼티 이름이 없던 시절의 방식
const obj2 = {}
obj2[key] = 100
```

## 객체 안에 객체 — 중첩 구조

```js
const user = {
  name: '철수',
  address: {
    city: '서울',
    zipcode: '12345',
  },
}

console.log(user.address.city)          // '서울' — 점을 두 번 이어서 접근
console.log(user['address']['city'])    // '서울' — 대괄호로도 동일하게 접근
```

## 객체의 키를 확인하는 방법들

```js
const user = { name: '철수', age: 25 }

console.log(Object.keys(user))     // ['name', 'age'] — 키만 배열로
console.log(Object.values(user))   // ['철수', 25] — 값만 배열로
console.log(Object.entries(user))  // [['name','철수'], ['age',25]] — [키,값] 쌍의 배열
```

## 핵심 정리

- 객체는 키-값 쌍의 모음이며 점 표기법 또는 대괄호 표기법으로 프로퍼티에 접근한다.
- 동적인 키 이름(변수, 공백 포함 등)은 대괄호 표기법이 필수다.
- ES6 메서드 축약, 프로퍼티 값 축약, 계산된 프로퍼티 이름은 실무에서 널리 쓰이는 문법이다.
- `Object.keys()`, `Object.values()`, `Object.entries()`로 객체 전체를 배열로 변환해 순회할 수 있다.
