## 01편 복습

## 핵심 퀴즈

**Q1. `<canvas>` 태그만 써두면 화면에 무엇이 나타나나?**

<Collapse title="정답 보기">
아무것도 안 나타난다(빈 사각형). 그림은 전부 JavaScript로 지시해야 한다.
</Collapse>

**Q2. 캔버스 크기를 CSS로만 지정하면 안 되는 이유는?**

<Collapse title="정답 보기">
CSS로 크기를 주면 내부 좌표계(해상도)는 그대로인 채 화면에서만 늘어나서 그림이 흐릿해진다. HTML `width`/`height` 속성으로 실제 해상도를 정해야 한다.
</Collapse>

**Q3. 실제로 그림을 그리는 메서드는 `canvas`에 있나, `ctx`에 있나?**

<Collapse title="정답 보기">
`ctx`(컨텍스트 객체)에 있다. `canvas.getContext('2d')`로 받은 그 객체다.
</Collapse>

## 실습 — 사각형 두 개 나란히 그리기

아래 뼈대를 완성해서, 빨간 채워진 사각형과 파란 테두리 사각형을 나란히 그려보자.

```html
<canvas id="stage" width="300" height="150"></canvas>
```

```js
const canvas = document.querySelector('#stage')
const ctx = canvas.getContext('2d')

// 여기에 코드를 채워보자
// 1. fillStyle을 'crimson'으로, (20, 20) 위치에 80x60 채워진 사각형
// 2. strokeStyle을 'navy'로, (120, 20) 위치에 80x60 테두리 사각형
```

<Collapse title="정답 보기">

```js
ctx.fillStyle = 'crimson'
ctx.fillRect(20, 20, 80, 60)

ctx.strokeStyle = 'navy'
ctx.strokeRect(120, 20, 80, 60)
```

</Collapse>
