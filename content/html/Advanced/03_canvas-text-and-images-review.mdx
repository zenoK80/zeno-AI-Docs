## 03편 복습

## 문제 1

이미지를 `drawImage`로 그리기 전에 반드시 확인해야 하는 것은?

<Quiz>
  <Quiz.Option>이미지 파일 이름에 한글이 없는지</Quiz.Option>
  <Quiz.Option correct>이미지 로딩이 완료됐는지(`img.onload`)</Quiz.Option>
  <Quiz.Option>이미지 크기가 캔버스보다 작은지</Quiz.Option>
  <Quiz.Option>이미지 형식이 PNG인지</Quiz.Option>

  <Quiz.Explanation>
  이미지 파일을 내려받는 데는 시간이 걸린다. `img.src`를 설정한 바로 다음 줄에서 `drawImage`를 호출하면 **아직 이미지가 다 로드되지 않은 상태**일 수 있어서 아무것도 그려지지 않을 수 있다. 반드시 `img.onload`(로딩이 끝났을 때 자동으로 실행되는 함수) 안에서 그려야 안전하다.
  </Quiz.Explanation>
</Quiz>

## 문제 2

`drawImage`로 스프라이트 시트(여러 이미지가 모인 한 장의 큰 이미지)에서 일부만 잘라 그리려면 인자를 몇 개 넘겨야 하나?

<Quiz>
  <Quiz.Option>3개</Quiz.Option>
  <Quiz.Option>5개</Quiz.Option>
  <Quiz.Option correct>9개</Quiz.Option>
  <Quiz.Option>몇 개든 상관없다</Quiz.Option>

  <Quiz.Explanation>
  `drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)` — 이미지 객체(1개) 외에 8개의 숫자, 총 9개의 인자가 필요하다. 앞의 4개(`sx, sy, sw, sh`)는 원본 이미지에서 **잘라낼 영역**(source), 뒤의 4개(`dx, dy, dw, dh`)는 캔버스에서 **그릴 위치와 크기**(destination)를 뜻한다.
  </Quiz.Explanation>
</Quiz>

## 문제 3

`getImageData()`로 얻는 `data` 배열은 어떤 순서로 값이 반복되나?

<Quiz>
  <Quiz.Option>픽셀 번호, 밝기, 투명도</Quiz.Option>
  <Quiz.Option correct>R, G, B, A(빨강, 초록, 파랑, 알파) 네 개가 픽셀마다 반복</Quiz.Option>
  <Quiz.Option>가로 좌표, 세로 좌표</Quiz.Option>
  <Quiz.Option>색상 이름을 문자열로 나열</Quiz.Option>

  <Quiz.Explanation>
  픽셀 하나마다 **R(빨강), G(초록), B(파랑), A(알파, 즉 투명도)** 네 개의 숫자(0~255)가 순서대로 나오고, 이게 픽셀 개수만큼 반복된다. 예를 들어 완전히 불투명한 빨간 픽셀 하나는 `[255, 0, 0, 255]`로 표현된다. 이 배열을 직접 조작하면 흑백 필터 같은 효과를 만들 수 있다.
  </Quiz.Explanation>
</Quiz>

## 실습 — 텍스트를 캔버스 정중앙에 배치하기

```html
<canvas id="stage" width="300" height="150"></canvas>
```

`textAlign`(가로 정렬), `textBaseline`(세로 정렬)을 이용해서 "완료!"라는 텍스트를 캔버스 정중앙에 배치해 보자.

<Collapse title="정답 보기">

```js
const canvas = document.querySelector('#stage')
const ctx = canvas.getContext('2d')

ctx.font = '32px sans-serif'
ctx.textAlign = 'center'
ctx.textBaseline = 'middle'
ctx.fillText('완료!', canvas.width / 2, canvas.height / 2)
```

</Collapse>

`textAlign`/`textBaseline`을 지우고 다시 그려서, 위치가 어떻게 달라지는지도 비교해 보자.
