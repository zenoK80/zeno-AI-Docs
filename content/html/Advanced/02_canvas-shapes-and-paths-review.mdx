## 02편 복습

## 문제 1

`moveTo`/`lineTo`만 호출하고 `fill()`이나 `stroke()`를 호출하지 않으면 어떻게 되나?

- A. 자동으로 검은색으로 그려진다
- B. 아무것도 화면에 그려지지 않는다
- C. 에러가 난다
- D. 이전에 그린 도형이 지워진다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`moveTo`(펜을 옮기기)와 `lineTo`(선을 긋기)는 **경로**<sup>Path, 실제로 그리기 전에 "어떤 모양인지"만 미리 설계해두는 것</sup>를 설계할 뿐, 그 자체로는 화면에 아무것도 나타나지 않는다. 마지막에 `fill()`(채우기)이나 `stroke()`(테두리만 그리기)를 호출해야 비로소 실제로 그려진다.
</Collapse>

## 문제 2

`arc()`로 원을 그릴 때 각도의 단위는?

- A. 도(degree) — 360이 한 바퀴
- B. 라디안(radian) — `Math.PI * 2`가 한 바퀴
- C. 퍼센트 — 100이 한 바퀴
- D. 픽셀

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`arc()`는 우리에게 익숙한 "360도" 방식이 아니라 **라디안**<sup>Radian, 원의 반지름을 기준으로 각도를 재는 수학적 단위</sup>을 쓴다. 완전한 원 하나(360도에 해당)는 `Math.PI * 2`(약 6.28)로 표현한다. 90도는 `Math.PI / 2`, 180도는 `Math.PI`다. 처음엔 헷갈리지만 이 세 값만 기억해도 웬만한 건 다 그릴 수 있다.
</Collapse>

## 문제 3

새로운 도형을 그리기 전에 `beginPath()`를 호출하는 이유는?

- A. 캔버스 전체를 지우기 위해서
- B. 이전에 그리던 경로와 지금 그릴 경로를 분리하기 위해서
- C. 색상을 초기화하기 위해서
- D. 사실 없어도 결과는 똑같다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`beginPath()`를 호출하지 않으면, 새로 그리는 경로가 이전 경로에 계속 이어 붙어서 의도하지 않은 모양이 만들어질 수 있다. 그래서 새 도형을 시작할 때마다 "여기부터 새 경로"라고 선언하는 `beginPath()`를 부르는 습관을 들이는 게 안전하다.
</Collapse>

## 실습 — 집 모양 그려보기

삼각형(지붕)과 사각형(몸통), 원(창문)을 조합해서 간단한 집 모양을 그려보자.

```js
const ctx = document.querySelector('#stage').getContext('2d')

// 1. 몸통: fillRect로 사각형 하나
// 2. 지붕: beginPath → moveTo/lineTo 세 번 → closePath → fill로 삼각형
// 3. 창문: beginPath → arc → fill로 원 하나
```

<Collapse title="정답 예시">

```js
// 몸통
ctx.fillStyle = 'peru'
ctx.fillRect(50, 100, 120, 100)

// 지붕
ctx.beginPath()
ctx.moveTo(40, 100)
ctx.lineTo(110, 40)
ctx.lineTo(180, 100)
ctx.closePath()
ctx.fillStyle = 'firebrick'
ctx.fill()

// 창문
ctx.beginPath()
ctx.arc(110, 150, 20, 0, Math.PI * 2)
ctx.fillStyle = 'skyblue'
ctx.fill()
```

</Collapse>
