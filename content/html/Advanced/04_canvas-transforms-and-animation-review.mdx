## 04편 복습

## 문제 1

`save()`와 `restore()`를 쓰지 않고 여러 도형에 변형(이동·회전 등)을 걸면 생기는 문제는?

- A. 아무 문제 없다. 원래 안 써도 된다
- B. 변형이 계속 누적되어, 다음에 그리는 도형들의 위치가 의도치 않게 어긋난다
- C. 브라우저가 멈춘다
- D. 색상이 자동으로 초기화된다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`translate`(이동), `rotate`(회전) 같은 변형은 한 번 걸면 그 뒤의 모든 그리기에 계속 영향을 준다. `save()`(지금 상태를 저장)로 저장해두고 변형을 건 다음, 그리기가 끝나면 `restore()`(저장해둔 상태로 되돌리기)로 원상 복구하지 않으면, 다음 도형에도 그 변형이 그대로 남아 위치가 꼬인다.
</Collapse>

## 문제 2

`setInterval` 대신 `requestAnimationFrame`을 애니메이션에 쓰는 이유는?

- A. `requestAnimationFrame`이 문법적으로 더 짧아서
- B. 브라우저의 화면 주사율(1초에 몇 번 화면을 새로 그리는지)에 맞춰 정확한 타이밍에 실행되고, 탭이 백그라운드에 있으면 자동으로 멈춰 배터리를 아끼기 때문에
- C. `setInterval`은 더 이상 지원되지 않는 옛날 기능이라서
- D. `requestAnimationFrame`만 애니메이션에 쓸 수 있고 다른 용도로는 못 쓴다

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
`requestAnimationFrame`은 "다음 화면을 그릴 준비가 됐을 때 이 함수를 실행해 달라"고 브라우저에 맡기는 방식이다. 브라우저가 실제 화면 갱신 주기에 맞춰 호출해주고, 탭이 안 보이는 상태면 자동으로 멈춰 자원을 아낀다. `setInterval`은 이런 조율 없이 그냥 정해진 시간마다 실행되므로 화면이 끊기거나 불필요하게 자원을 쓸 수 있다.
</Collapse>

## 문제 3

`rotate()`로 회전시키면 항상 무엇을 기준으로 도는가?

- A. 캔버스 전체의 정중앙
- B. 현재 원점(translate로 옮겨둔 그 지점)
- C. 도형 자신의 중심 (자동으로 계산해준다)
- D. 마우스 커서 위치

<Collapse title="정답 보기">
정답: **B**
</Collapse>

<Collapse title="해설 보기">
회전은 항상 **현재 원점**을 중심으로 일어난다. 특정 도형을 그 도형 중심으로 돌리고 싶다면, 먼저 `translate()`로 원점을 그 도형의 중심 위치로 옮긴 다음 `rotate()`를 호출하고, 도형 자체는 옮겨진 원점(0, 0) 기준의 좌표로 그려야 한다.
</Collapse>

## 실습 — 좌우로 튕기는 공 만들기

아래 뼈대를 완성해서, 원이 캔버스 좌우 벽에 부딪히면 방향을 바꾸는 애니메이션을 만들어보자.

```html
<canvas id="stage" width="300" height="150"></canvas>
```

```js
const canvas = document.querySelector('#stage')
const ctx = canvas.getContext('2d')

let x = 50
let dx = 2   // 이동 방향과 속도

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  ctx.beginPath()
  ctx.arc(x, 75, 20, 0, Math.PI * 2)
  ctx.fillStyle = 'crimson'
  ctx.fill()

  x += dx

  // 여기에: x가 캔버스 경계에 닿으면 dx의 부호를 바꾸는 코드를 추가해 보자

  requestAnimationFrame(draw)
}

requestAnimationFrame(draw)
```

<Collapse title="정답 보기">

```js
if (x + 20 > canvas.width || x - 20 < 0) {
  dx = -dx
}
```

`draw()` 함수 안, `x += dx` 다음 줄에 넣으면 된다.
</Collapse>
