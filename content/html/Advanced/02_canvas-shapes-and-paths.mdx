## Canvas 도형과 경로

1편에서 `fillRect`로 사각형 하나를 그려봤다. 이번 편에서는 사각형을 벗어나 **선, 원, 곡선처럼 임의의 모양**을 그리는 법을 본다.
핵심 개념은 하나다. **"펜을 어디서 어디로 움직였는지"를 먼저 기록하고, 그다음 색을 칠하거나 선을 긋는다.**

## 사각형 계열 — 가장 쉬운 세 메서드

```js
ctx.fillRect(x, y, 너비, 높이)     // 채워진 사각형
ctx.strokeRect(x, y, 너비, 높이)   // 테두리만 있는 사각형
ctx.clearRect(x, y, 너비, 높이)    // 해당 영역을 지운다 (투명하게)
```

```js
ctx.fillStyle = 'crimson'
ctx.fillRect(20, 20, 100, 60)

ctx.strokeStyle = 'navy'
ctx.lineWidth = 4
ctx.strokeRect(140, 20, 100, 60)
```

<Callout type="info">
`clearRect`는 애니메이션의 기본이 된다. 매 프레임마다 이전에 그린 걸 지우고 새로 그리는데, 이때 캔버스 전체를 지우는 용도로 자주 쓰인다. 4편(변형과 애니메이션)에서 실제로 써본다.
</Callout>

## 경로 — 사각형이 아닌 모양을 그리려면

원이나 삼각형처럼 사각형이 아닌 도형은 **경로**<sup>Path</sup>를 그려서 만든다. 순서가 정해져 있다.

<Steps>

### 새 경로를 시작한다

```js
ctx.beginPath()
```

이전에 그리던 경로와 지금 것을 분리한다. **거의 모든 도형 그리기의 첫 줄**이라고 생각해도 된다.

### 펜의 시작 위치를 정한다

```js
ctx.moveTo(50, 50)
```

펜을 종이에서 뗀 채로 (50, 50) 위치로 옮긴다. 아직 아무것도 그려지지 않는다.

### 선을 긋거나 도형을 추가한다

```js
ctx.lineTo(150, 50)   // (50,50)에서 (150,50)까지 직선을 긋는다
```

### 실제로 그린다

```js
ctx.stroke()   // 지금까지의 경로를 선으로 그린다
// 또는
ctx.fill()     // 경로로 둘러싸인 영역을 채운다
```

</Steps>

네 단계를 이으면 이런 흐름이다.

```mermaid
flowchart LR
  A["beginPath()<br/>새 경로 시작"] --> B["moveTo()<br/>펜 위치 이동"]
  B --> C["lineTo() 등<br/>경로 설계"]
  C --> D["stroke() / fill()<br/>실제로 그리기"]
```

<Callout type="important">
**`moveTo`/`lineTo`는 그 자체로는 아무것도 그리지 않는다.** 경로를 "설계"만 할 뿐이다.
실제로 화면에 나타나는 건 마지막에 `stroke()`나 `fill()`을 호출하는 순간이다.
</Callout>

## 삼각형 그려보기

```js
ctx.beginPath()
ctx.moveTo(100, 20)   // 꼭짓점 1
ctx.lineTo(160, 120)  // 꼭짓점 2
ctx.lineTo(40, 120)   // 꼭짓점 3
ctx.closePath()       // 마지막 점에서 시작점으로 선을 자동으로 이어준다
ctx.fillStyle = 'seagreen'
ctx.fill()
```

`closePath()`는 마지막에 그린 점과 처음 `moveTo`한 점을 자동으로 이어준다. 삼각형·사각형처럼 닫힌 도형에 쓴다.

## 원 그리기 — arc()

원이나 부채꼴은 `arc()`로 그린다. 조금 다른 방식으로 값을 받는다.

```js
ctx.beginPath()
ctx.arc(centerX, centerY, 반지름, 시작각도, 끝각도)
ctx.fill()
```

```js
ctx.beginPath()
ctx.arc(100, 75, 50, 0, Math.PI * 2)   // 중심(100,75), 반지름 50, 0 ~ 360도(2π)
ctx.fillStyle = 'gold'
ctx.fill()
```

<Callout type="warning">
**각도는 도(degree)가 아니라 라디안이다.** 360도가 아니라 `Math.PI * 2`(약 6.28)를 써야 완전한 원이 된다.

| 원하는 각도 | 라디안 표현 |
| --- | --- |
| 90도 (4분의 1) | `Math.PI / 2` |
| 180도 (반원) | `Math.PI` |
| 360도 (완전한 원) | `Math.PI * 2` |
</Callout>

## 여러 색으로 채우기 — 그라디언트

단색이 아니라 색이 점점 바뀌는 효과를 주려면 그라디언트 객체를 만들어 `fillStyle`에 넣는다.

<Tabs items={['선형 그라디언트', '방사형 그라디언트']}>
<Tabs.Tab>

```js
// 왼쪽 위(0,0)에서 오른쪽 아래(200,0)로 색이 변한다
const gradient = ctx.createLinearGradient(0, 0, 200, 0)
gradient.addColorStop(0, 'orange')
gradient.addColorStop(1, 'purple')

ctx.fillStyle = gradient
ctx.fillRect(0, 0, 200, 100)
```

</Tabs.Tab>
<Tabs.Tab>

```js
// 중심에서 바깥으로 퍼지는 원형 그라디언트
const gradient = ctx.createRadialGradient(100, 75, 10, 100, 75, 80)
gradient.addColorStop(0, 'white')
gradient.addColorStop(1, 'steelblue')

ctx.fillStyle = gradient
ctx.fillRect(0, 0, 200, 150)
```

</Tabs.Tab>
</Tabs>

`addColorStop(위치, 색)`의 위치는 0(시작)부터 1(끝) 사이 비율이다. 필요한 만큼 여러 개 추가할 수 있다.

## 선 스타일 다듬기

```js
ctx.lineWidth = 8          // 선 굵기
ctx.lineCap = 'round'      // 선 끝 모양: butt(기본) | round | square
ctx.lineJoin = 'round'     // 꺾이는 지점 모양: miter(기본) | round | bevel
ctx.setLineDash([10, 5])   // 점선 — [선 길이, 간격 길이]
```

## 정리

<Callout type="default">
- 사각형은 `fillRect`/`strokeRect`/`clearRect`로 바로 그린다
- 그 외 도형은 **경로**(`beginPath` → `moveTo`/`lineTo`/`arc` → `fill`/`stroke`) 순서로 그린다
- `moveTo`/`lineTo`는 경로를 설계할 뿐, `fill()`/`stroke()`를 호출해야 실제로 그려진다
- `arc()`의 각도는 **라디안**이다. 완전한 원은 `Math.PI * 2`
- 여러 색은 `createLinearGradient`/`createRadialGradient`로 표현한다
</Callout>

다음 편에서는 도형을 넘어 텍스트를 그리고, 이미지를 캔버스 위에 그려 넣는 법을 본다.
