## 실습 — 의미만 보고 태그 고르기

다음 구조를 `div`만 사용하지 말고 의미에 맞는 요소로 작성해 보자.

```text
사이트 제목
주요 메뉴
독립적으로 배포 가능한 뉴스 글
글 작성자와 게시일
```

<Collapse title="예시 답안 보기">

```html
<header>
  <h1>오늘의 뉴스</h1>
  <nav aria-label="주요 메뉴">...</nav>
</header>
<main>
  <article>
    <h2>새 소식</h2>
    <p>기사 본문...</p>
    <footer>작성자 김제노 · 2026-08-08</footer>
  </article>
</main>
```

태그 이름보다 각 영역의 실제 역할이 선택 기준이다.
</Collapse>
