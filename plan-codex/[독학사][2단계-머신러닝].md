## 담당과 위치

- 담당 도구: Codex
- 상위 분류: 독학사
- 하위 분류: stage2_machine_learning
- 콘텐츠 위치: 'content/독학사/stage2_machine_learning/'
- 계획 파일명 규칙: '[상위분류][하위분류].md'
- MDX 파일명 규칙: '01_kebab-case.mdx'

## 독자 기준

- 머신러닝 개념과 주요 알고리즘을 시험 기준으로 공부하는 학습자
- 초보자가 혼자 읽고 실습하거나 문제 풀이로 연결할 수 있게 쓴다.
- 너무 길게 늘이지 않고, 핵심 개념과 시험/실무에서 쓰이는 포인트를 우선한다.

## 공통 작성 지침

- MDX 상단 frontmatter는 'title', 'description'만 넣는다.
- 본문 제목은 '##'부터 시작한다. '#'은 쓰지 않는다.
- 설명 순서는 가능하면 '개념 -> 왜 필요한가 -> 예시 -> 흔한 실수 -> 정리'로 잡는다.
- 처음 나오는 용어는 한 줄로 정의한다.
- 공식이나 명령어는 외우기 전에 의미를 먼저 설명한다.
- 실습이 가능한 주제는 작은 예제와 직접 확인할 수 있는 절차를 넣는다.
- 마지막에는 항상 '## 참고 자료'를 두고 관련 웹사이트를 링크로 정리한다.

## Nextra 사용 지침

- import 없이 전역 컴포넌트를 사용한다.
- 'Callout': 중요한 정의, 시험 포인트, 주의사항에 사용한다.
- 'Steps': 설치, 실습, 풀이 절차처럼 순서가 중요한 곳에 사용한다.
- 'Tabs': 비교 예시나 여러 풀이/환경을 나눌 때 사용한다.
- 'FileTree': 폴더 구조나 파일 배치를 설명할 때 사용한다.
- 'Cards': 관련 문서 묶음이나 다음 학습 경로를 보여줄 때 사용한다.
- 'Table': 용어 비교, 명령어 비교, 공식 비교에 사용한다.
- 컴포넌트를 과하게 쓰지 말고 읽기 흐름이 좋아질 때만 쓴다.

## _meta.js 규칙

- 새 MDX를 만들면 같은 폴더의 '_meta.js'에 반드시 추가한다.
- 새 하위 분류 폴더를 만들면 해당 폴더에도 '_meta.js'를 만든다.
- 루트 메뉴는 실제 Nextra 구조와 맞춘다. 예: '자격증 -> SQLD', '독학사 -> 1단계 기초통계학'.
- 없는 파일을 가리키는 오래된 meta 항목은 남기지 않는다.
