# PC정비사 2급 실기

## 본편과 복습 문서 구성

- 목차의 일반 본편 `NN_slug.mdx`마다 바로 뒤에 `NN_slug-review.mdx`를 한 쌍으로 작성한다.
- 본편은 개념과 예제 중심, 복습편은 회상 질문·퀴즈·실습·오류 진단·정답 해설 중심으로 구성한다.
- 복습편은 10~15분 안에 끝낼 수 있게 만들고 `_meta.js`에서도 본편 바로 다음에 배치한다.
- 기출문제, 실전 모의고사, 종합 프로젝트, 정답·해설 전용 문서, 시험 직전 체크리스트에는 별도 복습편을 만들지 않는다.

## 시리즈 설계

- **정체성**: 부품 이름과 메뉴 위치를 외우는 대신 증상에서 원인 후보를 세우고 안전하게 분리 진단하는 실기 과정이다.
- **완주 목표**: 하드웨어 조립·BIOS/UEFI·Windows 설정·장애 진단에서 작업 순서와 판정 근거를 설명한다.
- **일관된 예제**: `전원은 켜지지만 부팅되지 않는 PC`를 시작으로 부품·저장장치·운영체제 문제를 단계적으로 진단한다.
- **작성 원칙**: 안전 조치 -> 증상 확인 -> 최소 구성 -> 한 번에 하나 변경 -> 재검증 -> 작업 기록 순서를 지킨다.

## 담당과 위치

- 담당 도구: Codex
- 상위 분류: 자격증
- 하위 분류: PC정비사 2급 실기
- 콘텐츠 위치: `content/자격증/PC2/`
- MDX 파일명 규칙: `01_kebab-case.mdx`

## 목표와 작성 기준

- 목표는 메뉴 암기가 아니라 PC의 증상을 보고 하드웨어, 펌웨어, Windows 단계로 원인을 좁히는 능력이다.
- 문서 하나는 안전한 작업 하나 또는 장애 유형 하나를 다룬다.
- 모든 실습 문서에는 증상/목표, 작업 전 확인, 설정 절차, 결과 확인, 되돌리는 방법, 흔한 실수를 넣는다.
- BIOS/UEFI 메뉴 이름은 제조사마다 다르므로 설정의 목적과 확인 방법을 중심으로 쓴다.
- 포맷, BIOS 초기화, 파티션 삭제처럼 위험한 작업에는 데이터 손실 경고를 먼저 넣는다.

## 시험 기준과 환경

- ICQA 공식 안내 기준: 해당 등급 필기 합격일로부터 2년 안에 실기 응시 가능.
- 최근 ICQA 실기 공지 기준: 80분, Windows 10·Windows 11 환경.
- 시험 시간과 운영체제, 장비 구성은 회차별 공지로 최종 확인한다.
