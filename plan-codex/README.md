# plan-codex — Codex 과목 계획

Codex가 담당하는 독학사·자격증 과목의 **학습 설계와 목차**를 모아 둔다.
공통 품질 기준은 루트 `AGENTS.md`가 단일 기준이며, 각 계획 파일은 과목에만 필요한 목표·예제 맥락·공식 출처·주의점을 추가한다.

## 파일 이름 규칙

```txt
[상위 메뉴][하위 분류].md
```

예: `[자격증][SQLD].md`, `[독학사][1단계-기초통계학].md`

## 본편과 복습편

- 계획 목차의 일반 본편 `NN_slug.mdx`는 `NN_slug-review.mdx`와 한 쌍이다.
- 실제 사이드바에서는 `01 본편 -> 01-복습 -> 02 본편 -> 02-복습` 순서로 배치한다.
- 기출·모의고사·종합 프로젝트·해설 전용 문서는 복습편을 추가하지 않는다.
- 복습편은 새 진도가 아니라 해당 본편을 회상하고 직접 풀어 보는 10~15분 학습 단계다.

## 계획 파일에 반드시 들어갈 것

- **시리즈의 정체성**: 무엇을 어디까지 다루고 무엇은 다른 시리즈로 넘기는지
- **완주 목표**: 시리즈가 끝났을 때 설명·계산·작업할 수 있어야 하는 것
- **독자와 선수지식**: 초보라는 말로 끝내지 말고 필요한 기초를 구체적으로 명시
- **과목별 작성 지침**: 일관된 예제, 표기법, 실습 환경, 자주 틀리는 지점
- **근거 자료의 우선순위**: 시행기관, 공식 매뉴얼, 표준, 공개 교재
- **목차**: 실제 파일명과 각 편에서 해결할 핵심 질문

## MDX 완성 판정

다음 질문에 모두 `예`라고 답할 수 있어야 완성으로 본다.

- 학습 목표가 본문의 예제와 확인 문제로 검증되는가?
- 초보자가 중간 단계를 추측하지 않고 계산하거나 실습할 수 있는가?
- 시험에서 어떻게 묻는지와 왜 오답인지 설명하는가?
- 명령이나 작업의 성공 여부를 독자가 스스로 확인할 수 있는가?
- 다음 편이 왜 필요한지 자연스럽게 이어지는가?

파일 추가·삭제·이동 시 `_meta.js`를 같은 작업에서 갱신하며, 현재 없는 문서를 미리 등록하지 않는다.
