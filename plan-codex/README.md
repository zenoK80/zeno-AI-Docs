# Codex 계획 문서

이 폴더는 Codex가 작성할 과목별 계획을 모아 둔다.

## 파일명 규칙

계획 파일은 실제 문서 구조처럼 쓴다.

- `[자격증][SQLD].md`
- `[자격증][리눅스마스터1급].md`
- `[독학사][1단계-기초통계학].md`
- `[독학사][2단계-자료구조].md`

즉, 첫 번째 대괄호는 헤더의 상위 메뉴이고 두 번째 대괄호는 그 아래 하위 분류다.

## 공통 규칙

- 먼저 루트의 `AGENTS.md`를 따른다.
- 각 과목 파일은 상세 목차와 작성 방향을 담는다.
- 새 MDX를 만들면 같은 폴더의 `_meta.js`를 반드시 갱신한다.
- 새 폴더를 만들면 그 폴더에도 `_meta.js`를 만든다.
- MDX frontmatter는 `title`, `description`만 사용한다.
- 본문 제목은 `##`부터 시작한다.
- 문서 마지막에는 `## 참고 자료`를 둔다.
- 초보자가 읽고 바로 복습/실습할 수 있게 짧고 명확하게 쓴다.
