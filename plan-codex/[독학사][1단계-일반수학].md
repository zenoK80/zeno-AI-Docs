# 독학사 1단계 일반수학

## 범위와 목표

- 위치: `content/독학사/basic_math/`
- 집합과 함수부터 행렬, 벡터, 미적분까지 시험에 필요한 기본 원리를 익힌다.
- 공식을 외우기 전에 기호를 읽고 작은 수로 직접 계산할 수 있게 한다.

## 작성 기준

- 작은 문제를 먼저 보여 주고 필요한 개념과 공식을 연결한다.
- 기호가 처음 나오면 읽는 법과 뜻을 바로 적는다.
- 계산은 중간 단계를 생략하지 않고, 마지막에 자주 틀리는 부호·조건을 확인한다.
- 본문 약 5분 뒤 같은 문서의 4지선다 3문제로 복습한다.

## 목차 (17편)

1. `01_sets-and-operations.mdx` — 집합, 원소, 부분집합과 집합 연산
2. `02_functions.mdx` — 함수, 합성함수와 역함수
3. `03_matrix-basics.mdx` — 행렬의 뜻과 기본 연산
4. `04_matrix-multiplication-and-inverse.mdx` — 행렬곱, 역행렬과 연립방정식
5. `05_determinants.mdx` — 행렬식과 역행렬 존재 조건
6. `06_vectors.mdx` — 벡터, 크기와 내적
7. `07_lines-and-planes.mdx` — 직선과 평면의 방정식
8. `08_linear-programming.mdx` — 부등식과 선형계획
9. `09_limits.mdx` — 함수의 극한
10. `10_derivatives.mdx` — 미분계수와 기본 미분법
11. `11_derivative-applications.mdx` — 증가·감소, 극값과 근사
12. `12_indefinite-integrals.mdx` — 부정적분
13. `13_definite-integrals.mdx` — 정적분과 미적분학의 기본정리
14. `14_integration-techniques.mdx` — 치환적분과 부분적분
15. `15_first-order-differential-equations.mdx` — 간단한 일계 미분방정식
16. `16_coordinate-systems.mdx` — 직교좌표, 극좌표와 구면좌표
17. `17_multivariable-calculus.mdx` — 편도함수, 다중적분과 합성함수
